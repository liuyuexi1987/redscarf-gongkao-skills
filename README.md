# 行测复盘一体版

面向公考行测学习者的复盘助手。它不只是给出选项，还会带你识别题型、寻找关键信号、走最短解法、检查思路，并把反复出错的方法沉淀下来。

适用于言语理解、逻辑填空、资料分析、数量关系、判断推理和常识判断。申论的“给定资料、作答要求、字数限制、身份文种”等主观题，请使用申论复盘技能，不要和行测混用。

## 你可以怎么用

### 直接讲解

适合现在只想知道这道题怎么做。

```text
行测解答，我选 B。请讲这道题：
【题目】……
A. ……
B. ……
C. ……
D. ……
```

如果有官方答案，也一并发来：`行测解答，我选 B，官方答案是 D，请完整讲解。`

完整讲解通常包括题型识别、答案结论、关键线索、逐步推理、你的选项为什么不稳、方法讲解、预计用时、易错点和复盘动作。

### 复盘这道题

适合先整理自己的思路，再听讲解。

```text
行测复盘，我选 B：
【题目和选项】……
```

第一轮会先问你“为什么这么选、怎样排除其他选项”，不提前公布答案或提示错因。你也可以直接说“讲吧”或“不知道”，下一轮就会进入完整讲解。

### 只存档

适合暂时不想听讲、只想保存题目。

```text
行测解答，只存档，不讲解：
【题目】……
【我的答案】……
【官方答案】……
```

### 考我、复习或错题复测

```text
行测解答，考我
行测解答，考我 3 题
行测解答，错题复测
行测解答，方法热身：资料分析
```

“考我”优先使用已经保存且答案明确的错题、题库题或弱点方法，不会为了凑数量编造真题。没有可用材料时，会提示导入题目或选择一个模块做方法热身。

### 导入题库

```text
行测解答，把这张错题页加入题库
行测解答，把这个 PDF 加入题库
行测解答，导入这份题目
```

导入时只做识别、切题、答案核验和保存，不会擅自讲解。题干、选项或答案看不清的题会标为“待核对”，不会自动判分。

## 怎样发题最容易得到好结果

### 文字题

最好一次提供完整题干、全部选项、你的答案、可靠答案（如有）和最困惑的地方（可选）。

```text
行测解答，我选 C，官方答案是 A，请完整讲解。

【题型】资料分析
【题目】……
【选项】
A. ……
B. ……
C. ……
D. ……
```

### 图片、整页和 PDF

可以直接上传截图、整页照片或 PDF。单题图片可以说“讲这道题”；整页图片建议说“只讲错题”或“逐题复盘”。题干、选项、数字或答案不清楚时，会标记待核对，不会把猜测当正式答案。

### 答案有冲突时

客观计算题会独立复核。若你的答案和官方答案冲突，会并列计算或推理过程，请你核对题面、年份、单位和答案页；言语理解等有争议且没有可靠答案时，只会说明方法倾向，不会把模型判断包装成唯一标准。

## 不同模块重点

- **言语理解**：主题、意图、行文结构、转折递进和选项边界。
- **逻辑填空**：语境关系、搭配、感情色彩、词义轻重和前后照应。
- **资料分析**：先判断能否估算、比较或排除，再决定是否精算。
- **数量关系**：先识别题型，再选择代入、赋值、枚举、方程或公式。
- **判断推理**：先找题干结构，再看定义、类比、逻辑判断、削弱加强或图形规律。
- **常识判断**：按法律、政治、经济、历史、科技、地理等方向分析；明确知识点以可靠答案来源为准。

## 你会看到什么

一次完整讲解会说明：题型和考点、最快的切入点、推理或计算过程、其他选项为什么不选、你的思路从哪里偏、方法如何复用、预计用时和应沉淀的复盘动作。


## 安装

本仓库提供行测 Skill 源码和离线安装包。实际 Skill 目录为 `skills/gongkao-review-pro/`；这是历史目录名，用户可见名称仍为“行测复盘一体版”。

### 通用安装方式

```bash
git clone https://github.com/liuyuexi1987/xingce-review-pro.git
```

将克隆目录中的 `skills/gongkao-review-pro/` 安装到你所使用智能体的 Skill 目录；若当前客户端支持从 GitHub 安装 Skill，可直接把本仓库地址交给智能体，并要求它加载该目录下的 `SKILL.md`。安装后重启或新建任务，再发送“行测解答”或“行测复盘”验证。

### 离线包

仓库 `dist/` 中提供已打包的 `gongkao-review-pro-v1.4.0.zip`。解压后按客户端的 Skill 导入方式安装即可；离线包包含 `LICENSE` 和 `NOTICE`，不包含维护工具、测试和用户学习记录。

## 使用边界

题目、选项、图表或答案缺失时，先补齐内容，讲解和批改才会可靠。用户提供的官方答案优先作为判定依据；没有可靠答案的争议题，只能给出方法倾向，不能伪造确定结论。用户导入的题目和复盘记录只服务于自己的学习，不应提交到公开仓库。
