# 行测复盘一体版

这是一个面向公考行测学习者的复盘助手。它不只是给出选项，还会带你看题型、找信号、走最短解法、检查你的思路，并把真正反复出错的方法沉淀下来。

适用于言语理解、逻辑填空、资料分析、数量关系、判断推理和常识判断。遇到申论的“给定资料、作答要求、字数限制、身份文种”等主观题，请使用申论复盘技能，不要和行测混用。

## 先选一种用法

### 1. 直接讲解

适合你现在只想知道这道题怎么做，不想先回答问题。

把题目、选项和你的答案发来，并使用“行测解答”或“讲解”开头。例如：

```text
行测解答，我选 B。请讲这道题：
【题目】……
A. ……
B. ……
C. ……
D. ……
```

如果有官方答案，也一并写上：

```text
行测解答，我选 B，官方答案是 D，请完整讲解。
```

完整讲解通常包括：题型识别、答案结论、关键线索、逐步推理、你的选项为什么不稳、方法讲解、预计用时、易错点和复盘动作。

### 2. 复盘这道题

适合你想先整理自己的思路，再听讲解。

使用：

```text
行测复盘，我选 B：
【题目和选项】……
```

第一轮只会问你：为什么选这个答案、怎样排除其他选项，不会提前公布答案或提示错因。你可以认真回答，也可以直接说“讲吧”或“不知道”，下一轮就会进入完整讲解。

复盘讲解会先复述你的思路，再指出哪一步合理、从哪里开始偏、漏看了什么信号，以及以后遇到同类题如何处理。

### 3. 只存档

适合你暂时不想听讲，只想把题目保存下来。

```text
行测解答，只存档，不讲解：
【题目】……
【我的答案】……
【官方答案】……
```

如果只是发来一张错题页、但没有说明想怎么处理，助手会先识别有几道题，再让你选择：只存档、讲错题，或逐题复盘。

### 4. 考我或复习

```text
行测解答，考我
行测解答，考我 3 题
行测解答，错题复测
行测解答，方法热身：资料分析
```

“考我”优先使用你已经保存且答案明确的错题、题库题或弱点方法，不会为了凑数量编造真题。没有可用材料时，会先提示你导入题目或选择一个模块做方法热身。

方法热身题不是正式真题，会明确标注“非真题·方法自测·不计真题正确率”。

### 5. 导入题库

```text
行测解答，把这张错题页加入题库
行测解答，把这个 PDF 加入题库
行测解答，导入这份题目
```

导入题库时只做识别、切题、答案核验和保存，不会擅自讲解。题干、选项或答案看不清的题，会标为“待核对”，不会自动判分。

## 怎样发题最容易得到好结果

### 文字题

最好一次提供：

1. 完整题干。
2. 全部选项。
3. 你的答案。
4. 官方、粉笔或其他已确认答案（如果有）。
5. 你最困惑的地方（可选）。

推荐格式：

```text
行测解答，我选 C，官方答案是 A，请完整讲解。

【题型】资料分析
【题目】……
【选项】
A. ……
B. ……
C. ……
D. ……
```

### 图片、整页和 PDF

可以直接上传截图、整页照片或 PDF。单题图片可以直接说“讲这道题”；整页图片建议说“只讲错题”或“逐题复盘”。

如果图片中的题干、选项、数字或答案不清楚，助手会标记待核对，不会把猜测当成正式答案。资料分析图表、判断推理图形和空间图形尤其建议单独截清楚。

### 答案有冲突时

客观计算题会独立复核。若你的答案和官方答案冲突，不会立刻强行判定谁错，而是把两边的计算或推理并列出来，先请你核对题面、年份、单位和答案页。

言语理解等存在争议的题，没有可靠官方答案时，只会说明“方法倾向于哪个选项”，不会把模型判断包装成唯一标准答案。

## 不同模块怎么用

- **言语理解**：重点看主题、意图、行文结构、转折递进和选项边界，不只看某个词顺不顺眼。
- **逻辑填空**：重点看语境关系、搭配、感情色彩、词义轻重和前后照应；有近义词时会结合词语辨析资料。
- **资料分析**：先判断能否估算、比较或排除，再决定是否精算；讲解会说明最快路径和考场是否值得做。
- **数量关系**：优先识别题型，再选择代入、赋值、枚举、方程或公式，避免一上来硬算。
- **判断推理**：区分定义、类比、逻辑判断、削弱加强和图形推理，先找题干结构再看选项。
- **常识判断**：按法律、政治、经济、历史、科技、地理等方向分析；涉及明确知识点时以可靠答案来源为准。

## 你会看到什么

一次完整讲解不会只返回“选 A”或几句结论，而会尽量回答：

- 这是什么题型，题目真正考什么。
- 最快应该先看哪里，哪些信息可以忽略。
- 你的思路哪一步有效，哪一步产生了偏差。
- 其他选项为什么不能选。
- 方法叫什么，遇到同类题怎么操作。
- 考场预计需要多久，时间紧时是否值得做。
- 这道题应该沉淀成什么复盘动作。

## 常用口令

```text
行测解答，我选 B，请直接讲。
行测复盘，我选 B，先问我思路。
行测解答，官方答案是 D，请核对我的答案。
行测解答，只存档，不讲解。
行测解答，考我 3 题。
行测解答，错题复测。
行测解答，导出错题报告。
行测解答，学情报告。
```

## 使用边界

题目、选项、图表或答案如果缺失，先补齐内容，批改才会可靠。用户提供的官方答案优先作为判定依据；没有核验答案的主观题，只能给方法倾向，不能伪造确定结论。

这是个人复习使用的私密技能，不内置公共真题题库。你导入的题目和复盘记录只服务于自己的学习。
