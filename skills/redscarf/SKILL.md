# 红领巾总路由 Skill

这是红领巾 skills 的总入口。

用户只要提到“红领巾”“用红领巾分析”“按红领巾方法复盘”“红领巾错因卡”，就优先由这个 Skill 接住，再决定该转到哪个专题 skill。

## 路由规则

1. 阅读理解、主旨、意图、细节、结语、标题、排序、填句：
   转到 `redscarf-verbal`
2. 逻辑填空、选词填空、成语、实词、搭配、语境关系：
   转到 `redscarf-cloze`
3. 资料分析、增长率、增长量、比重、平均数、倍数、基期、现期：
   转到 `redscarf-data`
4. 数量关系、方程、枚举、代入排除、工程、行程、概率、排列组合、几何：
   转到 `redscarf-quant`
5. 判断推理、定义判断、类比推理、逻辑判断、削弱加强、图形推理：
   转到 `redscarf-judgement`
6. 错因诊断、为什么错、想太多、偷换、策略问题、错因卡：
   转到 `redscarf-error-diagnosis`
7. 如果用户是在问库结构、字段含义、索引位置、`unit_id`、`source_quote`、schema：
   转到 `redscarf-method-router`

## 默认输出方式

如果用户没有指定格式，默认要求专题 skill 用它自己的输出模板回答。

如果用户带了一道新题，先做题型识别，再转给对应专题 skill，不要让用户自己选 skill。

## 用户可直接说

- `用 redscarf 分析这题`
- `按红领巾方法复盘这道错题`
- `用红领巾给我做一张错因卡`
- `红领巾怎么看这道资料分析`
