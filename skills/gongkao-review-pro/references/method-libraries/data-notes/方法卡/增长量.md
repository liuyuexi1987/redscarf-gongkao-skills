# 增长量

confidence: high

## 适用题型

求增长量、减少量、平均增长量、指定增长量、增长量比较、增长量倍数、增长贡献率、拉动率。

## 触发场景

- 题干出现"增长量/增加量/减少了/增长了 X"等求绝对量的问题。
- 题干出现"平均每年增长……"。
- 题干出现"增长量超过 X 的有几个"。
- 题干出现"哪项增长最多/最少"或"增长量排序"。
- 题干出现"贡献率/拉动……增长几个百分点"。

## 方法卡

### 1. 基本公式

```text
增长量 = 现期 - 基期
增长量 = 现期 / (1 + r) × r
减少量 = 现期 / (1 - |r|) × |r|
```

变量说明：r 为现期对应增长率（带符号），现期 = 基期 × (1+r)。当 r<0 时，"减少量"是增长量的绝对值。

### 2. 给现期和增长率

先百化分:

```text
若 r = 1/N（N 为正数）
增长量 = 现期 / (N + 1)
减少量 = 现期 / (N - 1)
```

当 |r| 较小，且近似误差明显小于选项有效差距时:

```text
增长量 ≈ 现期 × r
正增长时误差量级 ≈ 现期 × r² / (1+r)
```

是否使用近似由误差相对选项分界的大小决定；结果靠近选项边界时必须用百化分或精确公式。

### 3. 平均增长量

```text
平均增长量 = (现期 - 基期) / 年份差
```

年份差按时间轴数间隔，不按年份个数机械数。如 2016—2020 年的年份差为 4（不是 5）。

### 4. 指定增长量

判断"增长量大于某数有几个":

```text
现期 - 基期 > 指定增长量
等价于 基期 + 指定增长量 < 现期
```

图表题可直接看柱间高度差。

### 5. 增长量比较

给现期和基期:

- 柱状图: 看柱间高度差。
- 折线图: 看斜率/差值。
- 表格: 先找单位，再排序。

给现期和增长率:

```text
增长量 = 现期 / (1+r) × r
```

比较两个对象 X、Y（现期 A1、A2，增长率 r1、r2），令 f(A,r)=A·r/(1+r)：

- 两个对象都增长（r1, r2 > 0）时：若 A1 ≥ A2 且 r1 ≥ r2（至少一个为严格不等），则 X 的增长量大于 Y；因为现期和正增长率任一增大，增长量都会增大。
- 涉及下降（r 为负）时，不套用“现期大且增长率大”的正增长判断；应统一比较带符号增长量，或改用减少量公式比较下降的绝对量。
- 现期与 r 一大一小时：无法直接判断，用百化分或代入公式比较。

### 6. 多项增长

总体增长量等于各部分增长量之和。有升有降时，先抵消，再计算。

### 7. 增长贡献率和拉动率

```text
增长贡献率 = 部分增长量 / 总体增长量
拉动率 = 部分增长量 / 总体基期
```

## 方法步骤

1. 识别所求是增长量、减少量、平均增长量还是比较/贡献率。
2. 判断已知条件：给现期+基期、给现期+增长率，还是给图表。
3. 选择公式：增长率便于转成分数时可用百化分；否则使用精确公式，只有误差不会跨项时才估算。
4. 比较题先判断是否满足"都为增长"前提：满足则用单调性，不满足则代入公式。
5. 多项题先抵消再计算，避免漏项。

## 不适用条件

- 题目问的是增长率（相对量），不要套增长量公式。
- 题目给的是"同比/环比"且需要还原基期时，先还原再求增长量。
- 近似误差接近选项分界时，不可用 `现期 × r` 近似。
- 涉及下降（r<0）的比较题，不可直接套用"现期大且 r 大则增长量大"。

## 反向验证

- 计算所得增长量加基期，应等于现期：`基期 + 增长量 = 现期`。
- 用百化分和精确公式分别算一遍，结果应一致。
- 平均增长量 × 年份差 + 基期 = 现期。
- 当总体增长量不为 0 且所有部分都已计入时，各部分增长贡献率之和应等于 1。

## 高频错因

- 求增长量时错用 `现期×r` 当精确值；该式只能在误差不会跨越选项分界时近似使用。
- 平均增长量年份差数错（如把 2016—2020 数成 5 年）。
- 只看增长率大，不看现期规模。
- 增长贡献率和拉动率分母混淆（前者是总体增长量，后者是总体基期）。
- 涉及下降的比较题直接套"现期大且 r 大则增长量大"，导致方向判断相反。
