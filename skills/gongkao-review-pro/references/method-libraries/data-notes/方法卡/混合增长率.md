# 混合增长率

confidence: high

## 适用题型

整体由部分组成，已知部分增长率，求整体增长率或反推部分量比例。

## 触发场景

常见拆分:

- 进口 + 出口 = 进出口
- 城镇 + 农村 = 全国
- 邮政 + 电信 = 邮电
- 移动 + 固定 = 电信
- 人民币 + 外币 = 本外币
- A + 非 A = 总体

时间拆分:

- 一季度 = 1-2月 + 3月
- 全年 = 1-11月 + 12月

差值转化:

```text
顺差 = 出口 - 进口
逆差 = 进口 - 出口
出口 = 进口 + 顺差
进口 = 出口 + 逆差
```

## 方法卡

### 1. 范围规律

```text
最小部分增长率 ≤ 总体增长率 ≤ 最大部分增长率
```

等号成立条件：某一部分基期量为 0，或两部分增长率相等。

严格开区间成立的前提：两部分基期量均非 0 且增长率不相等。

总体增长率更接近基期量更大一方的增长率（偏向由基期量权重决定，不是由现期量决定）。

注意：只靠范围只能排除选项，不能在两个相近选项之间判断最终偏向。

### 2. 加权公式

若部分基期为 A、B，增长率为 ra、rb:

```text
R = (A×ra + B×rb) / (A+B)
A/B = (rb - R) / (R - ra)
```

若给的是现期 A'、B':

```text
(A'/(1+ra)) / (B'/(1+rb)) = (rb - R) / (R - ra)
```

当 `ra`、`rb` 相差不大时，`(1+rb)/(1+ra) ≈ 1`，可近似用现期比；当 `|ra - rb|` 较大时，近似误差是否影响选项判断必须由选项差距决定，应优先用基期比验证。

### 3. 线段法

把两个部分增长率放在线段两端，总体增长率在线段中间。距离越近，说明对应部分基期量权重越大。

距离与权重成反比：

```text
|ra - R| / |R - rb| = B / A
```

即 R 距某部分越近，该部分基期量越大。

## 不适用条件

- 三者及以上混合时，"总体落在最小和最大之间"仍成立，但线段法和加权公式须按两两合并或拆分使用，不能直接套用两部分公式。
- 题目给出"增长率之差"或"比重之差"等已加工指标时，不能直接当作部分增长率套公式。
- 某部分增长率即使由更细分项混合而成，只要它与对应部分基期量口径一致，仍可作为一个整体参与加权；只有口径不一致或题目要求细分项时才继续拆分。

## 反向验证

- 算出 R 后，代入 `(A×ra + B×rb) / (A+B)` 检查是否等于 R；若不等，检查用的是基期还是现期。
- 用线段法得到 A:B 后，回代 `R = (A×ra + B×rb)/(A+B)` 验证。
- 用 R 是否落在 `[min(ra,rb), max(ra,rb)]` 之外快速判断计算错误。
- 若 R 距离 ra、rb 的远近与 A、B 大小关系相反，说明 R 算反或 A、B 用反。

## 高频错因

- 只判断范围，不判断偏向。
- 用现期量代替基期量时不看部分增长率差距。
- 进出口、顺差、逆差的拆分关系写错。
- 多者混合时忘记总体仍落在最小和最大之间。
- 把"偏向基期量更大一方"误为"偏向现期量更大一方"。
- 范围规律误用为严格不等式，忽略两部分增长率相等或某部分基期为 0 的边界。
