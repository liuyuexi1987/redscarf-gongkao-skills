# 平均数

confidence: high

## 适用题型

现期平均数、基期平均数、两期平均数比较、两期平均数差、平均数倍数、中位数、众数。

## 触发场景

- 题干出现"人均/每/单位面积/单位产量/平均"等词。
- 题干问"……平均为多少"或"……是……的几倍"且涉及除以一个数量。
- 题干给出"总收入/总产量"和"人数/面积/个数"，问平均到单位的结果。
- 题干比较两期"人均"或"单位 X"的升降。

## 方法卡

### 1. 识别平均数

看到这些词，优先想到平均数:

- 均
- 每
- 单位面积
- 人均

平均数本质:

```text
平均数 = 分子 / 分母
```

例如人均收入 = 收入 / 人数。

### 2. 现期平均数

直接找分子、分母，做分数比较或计算。

### 3. 基期平均数

给现期分子 A、分母 B，分子增长率 a、分母增长率 b:

```text
基期平均数 = A / B × (1+b) / (1+a)
```

变量说明：A、B 都是现期值；a 是分子增长率，b 是分母增长率（均带符号）。修正项 `(1+b)/(1+a)` 来自基期平均数 = [A/(1+a)] / [B/(1+b)]。

### 4. 两期平均数比较

比较分子增长率 `a` 和分母增长率 `b`:

```text
a > b: 平均数上升
a < b: 平均数下降
a = b: 平均数不变
```

依据：现期平均数 / 基期平均数 = (1+a)/(1+b)，故 a 与 b 的大小关系直接决定升降。

### 5. 两期平均数差

```text
两期平均数差 = A / B × (a-b) / (1+a)
```

其中 A/B 是现期平均数，a 是分子增长率，b 是分母增长率。结果带符号：正为上升，负为下降。

### 6. 平均数倍数

两个平均数相比:

```text
(A/B) ÷ (C/D) = (A·D) / (B·C)
```

若不给分母，先找分母相同的平均数，再用倍数关系补齐。

### 7. 中位数和众数

- 中位数: 排序后中间位置。偶数个数据取中间两项的平均。
- 众数: 出现次数最多。

## 方法步骤

1. 识别"平均数"题型（看到均/每/单位面积/人均等）。
2. 明确分子和分母：通常"每 X 的 Y"中 X 是分母、Y 是分子。
3. 现期题直接代入 A/B。
4. 基期题用 `A/B × (1+b)/(1+a)`，注意 a 是分子增长率、b 是分母增长率。
5. 比较两期升降时只比较 a 和 b，无需算出具体平均数。
6. 求差值时用 `A/B × (a-b)/(1+a)`，注意符号。

## 不适用条件

- 题目问的是总量（如总收入、总产量），不要套平均数公式。
- 题目问增长率，应直接用 (现期-基期)/基期，不是平均数公式。
- 中位数/众数只适用于一组同类数据分布，不适用于两个不同口径数据。
- 分子分母增长率口径不一致（如分子是产量、分母是销量）时，应先统一口径再用平均数公式。

## 反向验证

- 基期平均数 × (1+a) / (1+b) = 现期平均数。
- 两期平均数差 / 现期平均数 = (a-b)/(1+a)，应与分别算出的两个平均数之差吻合。
- 中位数位置：n 个数据排序后，n 为奇数取第 (n+1)/2 项，n 为偶数取第 n/2 与 n/2+1 项的平均。
- 平均数 × 分母 = 分子（可用于验算）。

## 高频错因

- 只看到"收入/产量"就算总量，漏掉"人均/每/单位面积"。
- 两期平均数比较时把分子、分母增长率放反（a 是分子，b 是分母）。
- 基期平均数修正项写反（应为 `(1+b)/(1+a)`，不是 `(1+a)/(1+b)`）。
- 求平均数差忘记除以 `1+a`。
