# 言语理解综述校验

## 使用边界

用于言语主卡讲解后的结构和选项复核。具体方法以题型协议和已读取主卡为准；没有官方或已核验答案时，只给方法倾向。

## 分题型检查

| 题型 | 优先定位 | 选项核验 | 反向检查 |
|---|---|---|---|
| 主旨概括 | 文段围绕谁、谈什么、得出什么核心认识 | 是否覆盖核心话题与主要关系，是否过窄或过宽 | 转折、因果、并列、总分结构都可能共同承载主旨，不能只截一句 |
| 意图判断 | 在主旨基础上判断作者希望强调的问题、观点或对策 | 推断是否紧贴文段，是否越过原文证据 | 文段只陈述事实时，不强行补出对策；有明确对策时不退回背景描述 |
| 标题选择 | 核心对象、事件和表达重点 | 是否准确、完整，并符合标题概括范围 | 生动不等于准确；局部细节或材料中的例子不能代替全文重点 |
| 细节判断 | 回到原文定位对应句和上下文 | 逐项核对主体、时间、范围、程度、条件和因果 | 相关不等于一致；可能、部分、主要等限定不能被放大 |
| 词句理解 | 结合所在句、上下文和文段主题确定语境义 | 解释能否代回原句且不改变指代和感情色彩 | 不能只按词典常用义解释，也不能脱离上下文任意引申 |
| 语句衔接/填入 | 横线前后的指代、话题、逻辑和句式 | 代入后是否承上启下，主语和时态是否连续 | 只承上或只启下的选项，在中间位置通常证据不足 |
| 语句排序 | 首句特征、指代关系、捆绑句和逻辑顺序 | 排序后话题推进是否自然，代词是否有明确指向 | 不能只靠一个关联词锁定全序，要用多组关系交叉验证 |
| 结语推断 | 尾句当前话题和待展开方向 | 后文是否紧接尾句，而非重复已讲内容或跳到远处 | 全文主旨不等于下一段内容，优先看尾句的未完成信息 |

## 选项五项核验

1. 主体：谁在做、谁被评价，是否被替换。
2. 话题：选项是否仍围绕文段核心对象。
3. 范围：局部是否被扩大为整体，个别是否被扩大为普遍。
4. 程度：可能、主要、部分等限定是否被强化或削弱。
5. 关系：因果、条件、并列、对比、目的是否保持一致。

## 结论前复核

- 能否用原文中的核心句或结构关系回指答案？
- 排除项错在具体哪一项核验，而不是仅凭“感觉不符”？
- 两个选项都相关时，谁更完整覆盖核心关系且改动更少？
