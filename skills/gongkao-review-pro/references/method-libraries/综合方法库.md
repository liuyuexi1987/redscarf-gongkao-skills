# 综合方法库

这是方法库的统一入口。底层仍保留多个分区，方便质量控制、去重和回查；对外使用时按题型和证据质量动态择优，不写死某个分区优先。

调用前先执行 [`方法质量规则.md`](方法质量规则.md) 的质量门槛：A/B 级才能作为讲解依据，C 级只作检索线索，D 级跳过。

## 分区

| 分区 | 适合内容 |
|---|---|
| `gongkao-review/` | 通用复盘流程、言语理解、逻辑填空、资料分析、数量关系、判断推理、错因诊断 |
| `advanced-methods/` | 补充方法卡、数量关系、判断推理、资料分析、言语理解扩展技巧 |
| `data-notes/` | 资料分析公式、概念和专项速算要点 |

## 动态择优规则

当多个分区都命中时，不按固定来源优先级排序。按以下质量标准选择：

1. **题型匹配度**：方法是否直接覆盖当前题型、设问和考点。
2. **方法依据质量**：方法论字段是否完整；步骤是否可复用；卡片 id 作为来源锚点是否清楚。
3. **流程完整度**：是否能给出可复用的判断流程，而不是只解释单个选项。
4. **当前题适配度**：是否能解释用户具体错在哪一步，并能给出下次可执行动作。
5. **冲突处理**：若两个方法结论冲突，优先采用依据质量更高、题型更贴合、流程更完整的一方；无法判断时说明“方法库无确定优先依据”。

若候选只达到 C 级提示材料，不得把它写成确定讲法；必须继续检索 A/B 级依据，或说明“方法库无稳定依据”。

## 输出规则

- 对用户统一输出“方法依据”，不要暴露底层分区选择过程，除非用户要求。
- 方法依据以方法论字段 + 卡片 id 作为来源锚点为准。
- 没有方法依据时，明确写“方法库无依据”，再把模型当前推理单独标明。
- 不把题库内容当作方法依据。

## 建议检索顺序

1. 先识别题型和考点。
2. 先读题型协议的内联主卡。
3. 未命中再查 AdvancedMethods 题型索引。
4. 资料分析公式读取 DataNotes。
5. GongkaoReview 只作二次校验与综述补充。
6. 按 `方法质量规则.md` 给候选方法做 A/B/C/D 可用性判断。
7. 比较 A/B 级候选的依据质量和适配度。
8. 输出一个最稳的方法依据；必要时补充“另一个方法分区也有相近说法”。
