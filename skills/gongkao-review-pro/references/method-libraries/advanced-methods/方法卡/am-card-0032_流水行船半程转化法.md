# 方法卡：流水行船半程转化法
## 基本信息
| 字段 | 值 |
|------|-----|
| 方法名 | 流水行船半程转化法 |
| 适用题型 | 数量关系-流水行船/扶梯问题 |
| 触发场景 | 两人同向行走（如登扶梯），给出行走台阶数和速度比，求总路程 |
| 步骤逻辑 | 1. 将路程不同的两人统一为半程比较；2. 由速度比设赋值（甲速=2乙速=1）；3. 用各自半程台阶÷自身速度，得各自时间；4. 路程相同时间比→总速度比（反比）；5. 总速度=自身速度+介质速度，列方程求介质速度；6. 由总速度×时间得全程 |
| 高频错因 | 用自己走的台阶数代替总台阶数；混淆"自身速度"和"总速度"（总速度含介质速度） |
| confidence | high |
## 补充说明
核心类比：扶梯问题 = 流水行船。人走的台阶数 = 船行距离（自身分量），扶梯带的台阶数 = 水流分量。两人走的台阶数不同，统一为半程后路程相同，时间比可由速度反推。总速度 = 人速 + 扶梯速度，路程 = 总速度 × 时间。解析法通常较复杂，此法更直观。
## 不适用条件
- 题目只给一人数据或无法形成两人对比参照，无法建立半程关系。
- 扶梯/水流速度本身随位置变化（非匀速介质），不满足恒定介质速度的前提。
- 题目直接给出总速度或总台阶数，无需半程转化即可求解。
## 反向触发
- 题面含"往返""顺逆交替"等字眼但本质是简单顺水逆水代数题，无需半程转化。
- 问题只涉及单人扶梯长度计算且已有总速度，不需要两人对比。
