# 方法卡：比重趋势逆运用

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 比重趋势逆运用 |
| 适用题型 | 资料分析·部分增速与总体增速比较 |
| 触发场景 | 题干问"部分增速高于/低于总体增速"，或"比重比上年上升/下降"时 |
| 步骤逻辑 | 1. 识别题干：部分R是否大于总体R 2. 直接比较部分R和总体R的数值大小：部分R>总体R→比重上升；部分R<总体R→比重下降 3. 逆运用：当题目给出两期比重数据但未直接给出增速时，通过比较两期比重判断增速关系（比重上升→部分R>总体R），省去计算增长率公式 |
| 高频错因 | 分不清R1和R2分别对应部分还是总体；同比/环比的时间基准搞混 |
| confidence | high |

## 补充说明

比重趋势逆运用的典型场景：题干问"某项增速是否高于总体增速"，即部分R是否大于总体R。可将其转化为"只要比重上升即可"来快速判断。另一个常见场景：比较前几项的R1与全国R2，统计有多少项R1>R2。

## 不适用条件
1. 当部分和总体的比重数据都不完整、无法比较两期比重时，此法不适用
2. 当比重变化受多层嵌套结构影响（如三级以上汇总）时，需逐层分析而非直接逆推

## 反向触发
1. 当比重变化方向不明确时，应直接计算R1和R2再比较，而非依赖趋势逆推
2. 当题目要求精确计算比重差值而非判断升降时，需回归公式计算
