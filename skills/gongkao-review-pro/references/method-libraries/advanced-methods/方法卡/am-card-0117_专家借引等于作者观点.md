# 方法卡：尾段借引观点等同主旨

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 尾段借引观点等同主旨 |
| 适用题型 | 言语理解——中心理解题 |
| 触发场景 | 文段结尾以"因此XX认为""XX指出""研究表明"等句式引述专家、学者或权威研究的观点作为收束，且该引述内容与前文分析论证的推导方向一致 |
| 步骤逻辑 | 1. 梳理前文分析论证的推导方向（作者在论证什么、倾向什么）<br>2. 判断结尾引述的专家观点是否与该方向一致<br>3. 若一致：该引述即为作者借权威之口表达的主旨，主旨选项应包含专家观点的核心内容<br>4. 若不一致：该引述可能是被反驳对象（参考"有人认为+转折"结构），不作为主旨 |
| 验证动作 | 将结尾引述的专家观点改写为作者直接陈述（去掉"XX认为"），验证主旨选项是否仍能匹配；若匹配不变，确认借引成立 |
| 不适用条件 | 专家观点与前文分析方向矛盾时（此时为"引述+反驳"结构，非借引）；引述仅作为例证出现在文段中部而非收束结论时；引述引出了全新话题且前文无任何铺垫时 |
| 高频错因 | 因"不是作者原话"而不敢选含专家观点内容的主旨选项；忽略引述与前文方向的一致性验证，对"借引"和"反驳"两种结构混淆不清 |
| confidence | high |
| 反向触发 | ①将专家观点去除引述外壳后，主旨选项仍无法覆盖其核心内容，说明该引述可能仅为论据而非主旨；②前文有明确的作者自身结论句（如"因此""可见"），且该结论与引述内容方向不完全重合，应以作者结论为主旨而非借引；③选项同时包含引述内容和前文独立观点，需回代验证哪个更全面覆盖文段推导方向 |

> **使用边界**：本方法用于提供优先检查方向，不可单独据此作答；最终需回到题干关系、原文证据或选项条件完成验证。
