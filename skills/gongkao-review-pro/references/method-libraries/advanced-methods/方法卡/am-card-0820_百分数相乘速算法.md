# 方法卡：百分数相乘速算法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 百分数相乘速算法 |
| 适用题型 | 资料分析——间隔增长率/乘积增长率中需要计算R1×R2（两个百分数相乘） |
| 触发场景 | 公式中有R1×R2项，需要快速估算两个百分数的乘积 |
| 步骤逻辑 | ① 把其中一个百分数换成分数或小数（如31%→1/3，5%→0.05）；② 另一个百分数的百分号当作单位保留；③ 用分数/小数乘以另一个数值；④ 结果直接加百分号 |
| 高频错因 | 两个百分号都消掉导致量级错（应只消一个）；换分数时方向反了（31%应换1/3，不是3） |
| confidence | medium |

## 补充说明

核心操作：两个百分数相乘时，消一个百分号，结果仍为百分数。常用换算参考：5%可近似为0.05（1/20），10%为0.1（1/10），25%为0.25（1/4），33%为1/3。一个数估大、另一个数估小可互相补偿。当估算误差可能跨越选项或改变结论时，改用精算/验证。

## 不适用条件

1. 换算后的分数与实际百分数差异过大（如31%换1/3误差超过1个百分点），且选项间距较窄时精度不足。
2. 题目要求精确结果而非估算，速算法只能给出近似值。
3. 只有一个百分数参与运算（非两个百分数相乘场景），不需要此消百分号技巧。

## 反向触发

1. 两个百分数相乘时把两个百分号都消掉，结果量级少了一个百分号。
2. 换分数时方向反了（如31%换成了3而非1/3），导致结果放大了百倍。
