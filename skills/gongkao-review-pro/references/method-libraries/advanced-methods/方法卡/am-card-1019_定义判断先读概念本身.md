# 方法卡：定义判断先读概念本身

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 定义判断先读概念本身 |
| 适用题型 | 判断推理——定义判断 |
| 触发场景 | 定义判断题，概念名称本身包含信息 |
| 步骤逻辑 | ① 先读概念名称本身（如"绿色消费"→关键词=绿色+消费）；② 从概念名称预判定义的核心要件；③ 再读定义验证预判；④ 概念名称往往包含主体+客体+方式等关键信息 |
| 高频错因 | ① 直接读定义→忽略概念名称中的关键信息；② 概念名称中的限定词（如"绿色"）是判断标准 |
| confidence | high |

## 补充说明
定义判断的高效入口：先看概念名称。如"总分定义法"→先识别"总"（大概念）和"分"（具体解释）。概念名称往往包含最重要的限定信息。

## 不适用条件

1. 概念名称为纯专业术语且无字面拆解价值时。
2. 概念名称与定义核心要件关联较弱时。
3. 题干给出多个并列定义需交叉比对时。

## 反向触发

1. 当概念名称无法提供拆解线索时，应换用直接读定义提取要件。
2. 当选项间差异不在概念名称限定范围时，应补充比对选项的客体差异。
3. 当定义包含多个并列要件时，应核验每个要件的对应关系而非只看名称。
