# 方法卡：基期比重选项陷阱

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 基期比重选项陷阱 |
| 适用题型 | 资料分析——基期比重选择题 |
| 触发场景 | 基期比重题的选项中，通常会有一个现期比重（本期比重）作为干扰项；可利用这个规律快速猜出左边那个数是多少 |
| 步骤逻辑 | ① 知道选项中必有一个现期比重（本期比重）做干扰；② 看选项猜出左边数的值（拆分验证）；③ 右侧乘一个比1稍大或稍小的数，直接判断选哪个 |
| 高频错因 | 没注意年份，直接用现期比重选了答案；时间审题不仔细把"去年"看成"今年" |
| confidence | medium |

## 补充说明

基期比重题的选项中通常包含一个现期比重作为干扰项。利用这个规律：先算出或估出本期比重（即干扰项的值），再根据R1与R2的大小关系判断基期比重比本期更大还是更小，结合选项间距筛选答案。注意必须确认题干问的是基期（去年/上月），避免年份审题失误。

## 速算边界

当估算误差可能跨越选项或改变结论时，改用精算/验证。

## 不适用条件

- 选项中没有明显等于本期比重的干扰项时，此规律不成立，不能强行套用。
- 题目为综合判断题（"以下说法正确/错误的有几个"）而非单选时，选项结构不同，不适用此技巧。

## 反向触发

- 选项间距很小且基期比重与本期比重数值接近，靠选项特征无法锁定，需精算。
- 材料数据残缺或增长率有歧义，无法可靠估算本期比重。
