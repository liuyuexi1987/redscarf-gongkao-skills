# 方法卡：概率分步乘法分类加法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 概率分步乘法分类加法 |
| 适用题型 | 数量关系-概率问题 |
| 触发场景 | 涉及多种情况的抽调/抽取，求某事件发生的总概率 |
| 步骤逻辑 | 1. 分清"情况"和"步骤"：同一情况内的多个连续步骤是分步，不同情况之间是分类；2. 分步用乘法：同一情况内的各步骤概率相乘（如先从甲调人再从乙调人）；3. 分类用加法：不同情况的概率相加（如调英语专业和调非英语专业是两种情况）；4. 每种情况单独计算：注意调走一人后，原单位人数变化，会影响后续概率；5. 各情况概率相加得最终结果 |
| 高频错因 | 把分步当成分类用了加法；调走一人后忘记更新后续概率的分母和分子 |
| confidence | medium |

## 不适用条件

1. 只有单一步骤或单一情况，无需分类/分步
2. 题目求的是排列组合的方案数，而非事件发生概率
3. 独立重复试验（伯努利试验），需用二项分布公式

## 反向触发

1. 题目问"有多少种方案/方法"，属于排列组合而非概率
2. 出现"独立重复""n次中恰好k次成功"，用二项分布
3. 只有一种抽取情形，无需分类讨论
