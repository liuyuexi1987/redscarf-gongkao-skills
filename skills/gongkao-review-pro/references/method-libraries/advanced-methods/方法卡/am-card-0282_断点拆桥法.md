# 方法卡：断点拆桥法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 断点拆桥法 |
| 适用题型 | 质疑/削弱题（论据结论间存在断点） |
| 触发场景 | 质疑题中论据和结论涉及不同话题/关键词 |
| 步骤逻辑 | 1. 找出论据关键词和结论关键词，确认存在断点；2. 质疑时选择能拆断二者联系的选项（与搭桥相反）；3. 直接否定论据与结论之间的因果联系 |
| 高频错因 | 误用归因质疑思路去处理非归因题 |
| 不适用条件 | 论据和结论之间无断点（关键词一致）或题目为支持/假设题型时 |
| 反向触发 | 论据与结论指向同一话题且无逻辑跳跃时 |
| confidence | high |
