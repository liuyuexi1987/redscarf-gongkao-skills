# 方法卡：类比推理错因诊断卡

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 类比推理错因诊断卡 |
| 适用题型 | 一级关系、二级辨析、语义关系、逻辑关系、经验常识关系 |
| 触发场景 | 用户做错该类题后，讲解/复盘结束，需要判断错因并写入错因卡或弱点档案时 |
| 步骤逻辑 | ① 先查一级关系是否判断正确；② 再查是否需要二级辨析以及二级辨析是否遗漏；③ 再查集合关系（种属/交叉/并列）是否搞混；④ 最后归因写入弱点档案 |
| 高频错因 | 一级关系判断错、二级辨析遗漏或滥用、种属与交叉混淆、语义关系搞混、过度分析、命题意图未识别 |
| confidence | high |
| 不适用条件 | 1. 资料分析模块中的图表理解题不在本卡诊断范围
| 反向触发 | 1. 用户做对类比推理题后自行复核答案且无需诊断错因
2. 同一类比推理题型连续答对多次无需诊断
3. 题目属于纯语义近义词辨析题超出本卡范围 |
2. 题干定义缺失无法拆解要件时不做诊断
3. 用户已自行复核正确答案且无错因可诊断时不停留 |

## 诊断流程

### 第一步：查一级关系

- 两词之间最直接的关系是什么？组成、功能、属性、因果、种属、并列？
- 用户是否先判断了题型（成语→语义、名词→集合、前后词性不同→对应）再做题？
- 一级关系是否判断正确？还是把组成当成了种属，把因果当成了功能？

### 第二步：查二级辨析

- 一级关系相同时，是否需要二级辨析？（主客体方向、语义色彩、程度、用途）
- 是漏做了二级辨析（一级关系相同选不出），还是滥用了一级辨析就能解决的题（过度分析）？
- 二级辨析的方向是否正确？（如主被动搞反、褒贬色彩搞混）

### 第三步：查集合关系

- 种属（小圈在大圈内）和交叉（有交集+有独立部分）是否搞混？
- 判断交叉的方法："除了 A 以外有没有别的 A？除了 B 以外有没有别的 B？"都有的且有重叠→交叉。
- "木碗"和"汤碗"：按材料命名 vs 按功能命名，主体相同→交叉而非种属。

### 第四步：查语义关系与归因

- 成语题：语义关系（近义、反义、比喻）是否判断正确？
- 两词题优先想因果，三词题优先想时间——是否遵循了这个概率规律？
- 归因到具体层：是一级关系、二级辨析、集合关系还是语义关系？

## 错因分类表

| 错因类型 | 判定信号 | 典型表现 | 写入弱点档案的建议标签 |
|----------|----------|----------|------------------------|
| 一级关系判断错 | 词间基本关系判断错 | 组成、功能、属性、因果、种属、并列关系混淆 | 判断-类比推理-一级关系误判 |
| 二级辨析遗漏 | 一级关系相同但二级差异没看 | 主客体方向、语义色彩、程度、用途不同 | 判断-类比推理-二级辨析遗漏 |
| 二级辨析滥用 | 一级关系就能解决却上了二级 | 过度分析，把简单关系复杂化 | 判断-类比推理-二级辨析滥用 |
| 种属交叉混淆 | 有重叠的两个名词关系判断错 | 木碗和汤碗应为交叉（按材料vs按功能），误判为种属 | 判断-类比推理-集合关系混淆 |
| 语义关系搞混 | 近义、反义、比喻关系判断错 | 把反义当近义，或比喻关系没看出来 | 判断-类比推理-语义关系误判 |
| 命题意图未识别 | 没有先判断命题人想考什么关系 | 盲目套用各种关系，浪费时间 | 判断-类比推理-命题意图未识别 |
| 概率规律未遵循 | 两词题没优先想因果 | 两词题想时间关系（概率低），忽略了因果关系 | 判断-类比推理-概率规律未遵循 |
| 过度朴素理解 | 太直觉而忽略了明确的关系 | "朴素理解"过头，没有做必要的分析 | 判断-类比推理-朴素理解过度 |

## 写回建议

- `判断-类比推理-一级关系误判`：两词之间最直接的关系判断错，把功能关系当成了因果关系
- `判断-类比推理-二级辨析遗漏`：一级关系相同（都是功能关系），但没有继续比较作用对象方向
- `判断-类比推理-集合关系混淆`：木碗和汤碗是交叉关系（按材料vs按功能命名），误判为种属
- `判断-类比推理-命题意图未识别`：没有先判断命题人想考什么关系就开始乱猜，浪费时间

## 使用边界

1. 本卡只用于错因诊断，不替代具体解题方法卡（如 am-card-1006 类比词对空预判法、am-card-1004 类比集合关系判断法）。
2. 无官方/已核验答案的类比推理题，不得硬判错因，只能写方法倾向或待核对。
3. 用户给出思路时优先对照用户思路归因；没给思路时只能做低置信诊断。
4. 客观题官方答案冲突时先走冲突复核流程，不立即写错因卡。
