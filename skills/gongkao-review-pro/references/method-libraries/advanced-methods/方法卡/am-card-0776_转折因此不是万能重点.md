# 方法卡：转折因此不是万能重点

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 转折因此不是万能重点 |
| 适用题型 | 片段阅读-中心理解题 |
| 触发场景 | 文段中出现"但是/因此/然而"等关联词，但整体结构不是二层转折 |
| 步骤逻辑 | 1. 只有二层转折结构中，转折才是重点；后对策结构中，"因此"引出对策才是重点；2. 论证过程中的转折/因此只是分析说明的一部分，不是全文重点；3. 判断方法：先确定文段整体结构，再看关联词在结构中的位置；4. 不要看到转折/因此就机械地认为后面是重点 |
| 高频错因 | 看到"但是/因此"就认为后面必是重点，忽略了整体结构 |
| confidence | medium |

## 不适用条件

1. 文段为标准二层转折结构，转折后确实为重点
2. "因此"出现在文段末尾结论句中，确实是全文总结
3. 关联词引出的是全文核心观点而非局部论证环节

## 反向触发

1. 文段有多处转折或因果关联词，需判断哪一处才是主转折/主结论
2. 转折后紧跟让步或再次转折，重点可能进一步后移
3. "因此"后的内容被后续论述推翻或限定，不是最终结论
