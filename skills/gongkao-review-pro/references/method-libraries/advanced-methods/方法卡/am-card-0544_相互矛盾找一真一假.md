# 方法卡：相互矛盾找一真一假——两真两假题核心

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 相互矛盾找一真一假——两真两假题核心 |
| 适用题型 | 真假话题（逻辑判断） |
| 触发场景 | 四人说话，已知"两人说真话两人说假话"，需要判断谁真谁假 |
| 步骤逻辑 | 1. 找出四句话中是否存在矛盾关系（有些vs所有非、所有vs有些非）；2. 矛盾关系的两句必然一真一假；3. 剩下的两句也必然一真一假（因为整体是两真两假）；4. 在剩下的两句中用假设法判断真假；5. 用确定的信息回代到矛盾对中判断 |
| 高频错因 | 找不到矛盾关系，四句话逐一代入浪费时间找到矛盾后忘记"剩下两句也必然一真一假" |
| confidence | high |
| 不适用条件 | - 四句话中找不到任何矛盾关系对（无"所有vs有些非"或"所有非vs有的是"结构）
- 约束条件不是"两真两假"（如"只有1人说真话"或"至少2人说假话"），剩下两句的真假分布不必然各一
- 需要排列组合而非真假话判断（如四人抽四花色各不同） |
| 反向触发 | - 题目要求判断四句话中哪一句为真，且约束条件为"只有1人说真话"→应优先假设法而非矛盾法
- 四句话相互独立、无逻辑交叉，只能逐一代入验证 |

## 补充说明

第6题。甲"有人拿走了"（有些式）vs 乙"都没拿走"（所有非）→ 矛盾 → 必然一真一假。剩下丙"非乙或非丁"和丁"非丁"也必然一真一假。假设非丁为真 → 丙也真 → 两真，矛盾。所以非丁为假 → 丁拿了 → 丙"非乙或非丁"为真 → 非乙 → 甲对丙对。
