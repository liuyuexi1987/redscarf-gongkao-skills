# 方法卡：效率变化统一基准法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 效率变化统一基准法 |
| 适用题型 | 工程问题中，某人效率在不同阶段有变化（如合作时提升10%，单独干时恢复原效率） |
| 触发场景 | 题干出现"效率提升/下降百分之N"，且同一人在不同阶段效率不同，直接计算需要分段列方程 |
| 步骤逻辑 | 1. 找到效率低的那个阶段（如单独干时效率为1），算出该阶段对应的工作总量（如44天×效率1=44份）；2. 将效率高的阶段折算：效率1→效率1.1，原来需44天 → 现在需44÷1.1=40天；3. 所有阶段统一到同一基准效率后，按标准"给时间设最小公倍数"流程求解；4. 设最小公倍数为工作总量，求各人效率，再求三人合作时间 |
| 高频错因 | 分段列式计算，中间效率变化导致方程复杂、容易算错百分比转化搞混（"提升10%"是乘1.1不是加0.1） |
| confidence | medium |

## 补充说明

- 核心思路：把效率变化"抹平"，统一到同一个效率基准下，再用最小公倍数法一步求解。
- 相比按原始阶段分段列方程，统一基准后计算路径更短、出错率更低。

## 不适用条件

- 各阶段效率变化幅度不一致且无明确比例关系，无法折算到统一基准。
- 题目要求分别求各阶段的具体用时，统一基准后会丢失分段信息。

## 反向触发

- 当效率变化涉及多个不同基准（如先升后降且幅度不同）时，应改用"不同完工情况列方程"分段建模。
- 当题目仅需比较两阶段总量而非求合作时间时，可直接用比例比较，无需统一基准。
