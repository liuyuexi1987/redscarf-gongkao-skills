# 方法卡：对策的对策陷阱

## 基本信息

| 字段 | 值 |
|------|------|
| 方法名 | 对策的对策陷阱 |
| 适用题型 | 言语理解-中心理解题（对策类文段） |
| 触发场景 | 文段结构为"目标/问题→对策"，选项出现对对策手段本身的操作性描述（即"如何+对策手段"） |
| 步骤逻辑 | 1.识别文段的目标/问题和对策/手段分别是什么；2.对策类文段的主旨应围绕"如何解决目标问题"；3.检查选项：若选项讨论的是"如何执行/做好对策手段"，则为对策的对策——排除；4.正确选项应表述为解决目标问题的方向或策略，而非对手段的再细化 |
| 验证动作 | 将被排除的选项改写为"如何+对策手段"的形式，确认其确实把对策手段当作了新的讨论目标 |
| 不适用条件 | (1)文段不是"问题→对策"结构（如为"现象→分析→结论"结构）；(2)选项直接复述原文对策本身（非对手段的再操作化） |
| 高频错因 | 把对策的下一层当作主旨——如文段讨论"如何解决A问题"，对策是"B手段"，错误地选了"如何做好B"而非"如何解决A" |
| confidence | high |

## 验证动作

将被排除的选项改写为"如何+对策手段"的形式，确认其确实把对策手段当作了新的讨论目标。

## 不适用条件

- 文段不是"问题→对策"结构（如为"现象→分析→结论"或"并列论述"结构），不存在对策层级。
- 选项直接复述原文对策本身（非对手段的再操作化），属于正确表述而非对策的对策。
- 题目问的是文段主要内容或作者意图而非"主旨概括"，对策层级判断不适用。

## 反向触发

- 文段结构为"现象/数据→分析→结论"而非"问题→对策"，对策层级陷阱不存在。
- 所有选项都在讨论目标问题本身而非对策手段的执行细节，无需排查对策的对策。
- 文段包含多层递进（如问题→原因→对策→效果），题目问的是效果或原因层面。

> **使用边界**：本方法用于提供优先检查方向，不可单独据此作答；最终需回到题干关系、原文证据或选项条件完成验证。
