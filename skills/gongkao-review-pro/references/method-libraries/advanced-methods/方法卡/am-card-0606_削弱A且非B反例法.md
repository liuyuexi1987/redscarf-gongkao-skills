# 方法卡：削弱A且非B反例法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 削弱A且非B反例法 |
| 适用题型 | 判断推理——削弱题（结论含"所有A都是B"类全称表述） |
| 触发场景 | 结论可翻译为"所有A都是B"（如"所有12生肖都源于崇拜"），问反驳/削弱 |
| 步骤逻辑 | ① 将结论翻译为逻辑语言：所有A→B；② 最强反驳 = 找A且非B的实例（是生肖但不被崇拜）；③ 注意区分A且非B（正确反驳方向）和B且非A（话题不一致，无效） |
| 高频错因 | 选了B且非A方向的选项（如"崇拜但不是生肖"）；选了话题不一致的无关项（如"是否现实中存在的动物"） |
| confidence | high |

## 补充说明

A且非B 即"是 A 但不被 B 所指称"，是反驳"所有 A 都是 B"的正确方向；B且非A（"是 B 但不是 A"）方向反了，话题不一致，不构成削弱。判定"B 是否成立"时需以题干对 B 的定义为依据，不能按常识替换 B 的内涵；若选项中的实例只是 B 的近义而非题干 B 本身，则仍属话题不一致。

## 不适用条件

1. 结论非全称命题（特称命题、概率性/趋势性主张）时不适用本反例法。
2. 问法为加强或解释而非削弱/反驳时不适用。
3. 结论为"有些 A 是 B"等存在命题时，单点反例不构成削弱。

## 反向触发

1. 若结论为概率性/趋势性主张，应换用样本偏差或他因削弱。
2. 若选项中均不存在 A且非B 实例，应考虑是否存在 A且非B 的等价表述（如"是 A 却与 B 相悖"）被忽略。
3. 若选项均指向因果机制，应换用切断机制链条法而非反例法。
