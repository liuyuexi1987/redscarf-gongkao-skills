# 方法卡：环比月份差传递估算

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 环比月份差传递估算 |
| 适用题型 | 资料分析 - 已知环比增速求单月值，问某月与另一月的差值 |
| 触发场景 | 题目给1-5月、1-4月等累计值和同比增速，要求5月与3月的差值大小 |
| 步骤逻辑 | 1. 用累计值做差得到目标单月值（如5月 = 1-5月 - 1-4月）；2. 找到中间月份（4月）的值，算出5月比4月少了多少；3. 用4月增速估算4月比3月多了多少；4. 传递关系：5月比3月少的量 ≈（5月比4月少的量）-（4月比3月多的量），锁定选项 |
| 高频错因 | 不会用中间月份做传递，直接算3月基期再做差，浪费时间且精度不够 |
| confidence | high |

## 不适用条件

- 题目只要求计算单月具体数值（无需做差比较，直接用累计值做差即可）
- 累计值和增速数据缺失导致中间月份无法推算（传递链条断裂）
- 题目问的是同比增长量而非月份间差值（应选同比增速相关的列式路径）

## 反向触发

- 当中间月份的增速与目标月份增速差异很大时，传递估算精度下降，应考虑直接精确计算
- 当选项差距不足以覆盖传递估算误差时，应改用精确列式
