# 方法卡：经济利润基础公式体系

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 经济利润基础公式体系 |
| 适用题型 | 经济利润问题 |
| 触发场景 | 所有经济利润相关题目 |
| 步骤逻辑 | 1. 核心公式：总利润 = 总收入 - 总成本；2. 总成本 = 进价（单价）× 购入量；3. 总收入 = 售价 × 销量；4. 总利润 = 单件利润 × 销量（仅当全部售出时可用）；5. 利润率 = 总利润 ÷ 总成本（数量关系默认成本利润率，不同于资料分析的收入利润率）；6. 售价 = 成本 ×（1 + 利润率） |
| 高频错因 | 购入量≠销量时误用"单件利润×销量"算总利润（有损耗/未售完时必须用总收入-总成本） |
| confidence | high |

## 补充说明

数量关系的利润率=利润÷成本，资料分析的利润率=利润÷收入，两者不同。

## 不适用条件

- 涉及分段定价、阶梯优惠等非单一售价结构（基础公式需扩展为分段求和后才能适用）。
- 涉及多批次进货、不同进价混算（需先按加权平均或分批核算处理再套公式）。
- 题目所求是定价策略或最值问题（基础公式只解决核算，不解决优化）。

## 反向触发

- 当题目包含损耗、退货、未售完等情况时，应改用"总收入-总成本"路径而非"单件利润×销量"。
- 当题目涉及分段定价或阶梯优惠时，应改用分段求和法或最值法。
- 当题目问的是利润率本身（数量关系语境）时，应反向套用 售价=成本×（1+利润率）求解，而非直接用基础公式算总利润。
