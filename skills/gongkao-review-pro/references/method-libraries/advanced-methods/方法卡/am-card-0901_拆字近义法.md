# 方法卡：拆字近义法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 拆字近义法 |
| 适用题型 | 判断推理——类比推理·语义关系（成语拆分） |
| 触发场景 | 题干把一个成语拆成两个词，选项也是成语拆分 |
| 步骤逻辑 | ① 将题干成语拆成单字；② 分析前后两个字之间的关系（近义/反义/方向相反等）；③ 选项中找拆字后具有相同字间关系的成语 |
| 高频错因 | ① 只看整体意思相似，忽略了拆字后的字间关系；⑷ 分不清"字间近义"和"字间反义/方向"的区别 |
| confidence | high |

## 补充说明

拆字近义法的要点：拆开后字间关系（近义/反义/方向）要匹配，整体合起来也要语义通顺。仅看整体意思相似而忽略字间关系是常见错因。

## 不适用条件

- 题干不是成语或固定词组拆分结构时，本方法不适用。
- 题干两词是整体近义关系而非拆字结构时，应换用语义近义辨析。
- 拆字后字间关系无规律可循时，本方法不适用。

## 反向触发

- 当题干是整体近义词组（非拆字）时，应换用语义近义辨析。
- 当拆字后多选项均符合字间关系需进一步区分时，应补用二级辨析。
- 当选项含明显褒贬差异时，应补用二级辨析·褒贬色彩。
