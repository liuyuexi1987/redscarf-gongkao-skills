# 方法卡：断点搭桥识别法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 断点搭桥识别法 |
| 适用题型 | 论证题（支持/削弱/补前提） |
| 触发场景 | 问"最能支持上述论证"；结论出现"有些""一般"等量词，论据出现"所有"等全称表述 |
| 步骤逻辑 | 1. 读完结论，检查是否出现"有些""一般""部分"等量词；2. 回看论据，检查是否出现"所有""全部"等全称表述；3. 若论据和结论中反复出现同一关键词（如"相信UFO"），说明存在断点；4. 找出论据主体与结论主体之间的差异（如"参加讲座的人" vs "严谨的科学家"）；5. 直接找搭桥选项（连接断点两端的主体），其他选项直接排除 |
| 高频错因 | 被论据长度干扰，通读全文后才判断；选了与断点无关的选项（如D选项"严谨的讲座"偷换了"严谨的科学家"） |
| confidence | high |

## 不适用条件

1. 论据与结论主体完全一致，不存在跳跃断点
2. 问法为"前提假设"以外的推理类（如"以下哪项能推出"）
3. 题干论证结构为纯因果归因或类比论证，而非主体跳跃

## 反向触发

1. 论据和结论使用完全相同的关键词和主体表述，无断点可搭
2. 题目考查的是因果归因力度比较，而非论证结构完整性
3. 题干结论中的量词"有些""一般"与论据的"所有"针对同一主体，差异仅在量词
