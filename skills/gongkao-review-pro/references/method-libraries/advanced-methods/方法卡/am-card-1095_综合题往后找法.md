# 方法卡：综合题往后找法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 综合题往后找法 |
| 适用题型 | 资料分析——综合分析题 |
| 触发场景 | 资料分析综合题中，某个选项涉及的数据在材料后面 |
| 步骤逻辑 | ① 综合题中比较复杂的选项→往往在材料后面找；② 不要只看材料前面的数据→后面的可能更相关；③ 国考综合题的计算量通常比前面的大→需要更多耐心 |
| 高频错因 | ① 只看前面的数据→漏掉后面的关键数据；② 综合题急于求成→验证不充分 |
| confidence | medium |
| 不适用条件 | - 资料分析非综合题（前4题各题数据集中在材料前半段，不需要往后找）
| 反向触发 | - 综合题中已按ABCD顺序逐项验证，前两项数据均在材料前部找到，后续选项也在前部
- 材料只有单一图表且数据量很少，前后位置无区分意义 |
- 综合题中所有选项涉及的数据在材料前部即可全部定位 |

## 补充说明
综合题是资料分析中计算量最大的部分。"比算比较复杂的往往在国考综合题里，往后面找。"综合题需要验证所有选项，不能只看一个就选。
