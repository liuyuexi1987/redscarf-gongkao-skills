# 方法卡：联言命题肯一否一

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 联言命题肯一否一 |
| 适用题型 | 判断推理——涉及"A且B"命题的真假判断 |
| 触发场景 | 已知A且B为假，且已知A（或B）的真假，需要推B（或A） |
| 步骤逻辑 | ① A且B为真 → A真且B真（范围：仅一种情况）；② A且B为假 → 至少一个为假（范围：三种情况）；③ 在A且B为假的前提下：若已知A为真 → B必为假；若已知B为真 → A必为假（肯一否一）；④ 但仅知A为假时，B可真可假（无法判定） |
| 高频错因 | ① 误以为A且B为假时知A假就能推B真（不能，B可真可假）；② 混淆"至少一假"和"恰好一假" |
| confidence | high |

## 补充说明

肯一否一仅在A且B为假时成立：已知其中一个为真，另一个必为假。但已知一个为假时，另一个无法确定。联言命题的矛盾面是"否A或否B"。

## 不适用条件

1. 当前提未给出"A且B为假"这一条件时，不能使用肯一否一进行推导。
2. 涉及三个及以上联言肢（A且B且C）时，肯一否一仅能推出其余肢至少一个为假，不能推出具体哪个为假。

## 反向触发

1. 当需要从"A且B为真"出发推导时，两个肢均为真，直接使用联言拆分即可，无需肯一否一。
2. 当题目问的是"A且B"与"A或B"之间的关系时，应优先用矛盾/等价关系分析，而非逐肢推导。
