# 方法卡：肯后不推前

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 肯后不推前 |
| 适用题型 | 翻译推理题（涉及充分/必要条件判断） |
| 触发场景 | 需要判断"结果正确能否推出条件正确"时 |
| 步骤逻辑 | 1. 原命题 A → B 中，肯前（A成立）可推出B；2. 否后（B不成立）可推出非A（逆否）；3. 肯后（B成立）不能推出A——可能A成立，也可能只是巧合/偶然做对；4. 否前（A不成立）不能推出B——可能其他条件也能导致B |
| 高频错因 | 把"做对了"等同于"识别出了正确答案"，忽略可能偶然做对的情况 |
| 不适用条件 | 题目考查的是肯前推后或否后推否前的正确推理方向时 |
| 反向触发 | 题目明确要求从前提推出结论（肯前推后），而非从结果反推条件时 |
| confidence | high |
