# 方法卡：前提题三步法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 前提题三步法 |
| 适用题型 | 前提/假设题——问法为"补充以下哪项为前提/假设" |
| 触发场景 | 问法出现"前提""假设""必须补充"等关键词 |
| 步骤逻辑 | ① 先找论据和结论，定位断点（论据中的关键词与结论中的关键词之间的跳跃）；② 若有断点→直接搭桥（选项同时包含断点两端的概念，建立联系）；③ 若无断点→没它不行（否定代入验证：假设该选项不成立，结论是否还能推出，不能则为答案） |
| 高频错因 | 没找准论据和结论就选选项；混淆断点与无关概念；无断点场景下选了补充漏洞而非必要条件 |
| confidence | high |

## 补充说明

断点搭桥示例：论据"面试能了解能力"→结论"面试不可取代"，断点在"了解能力"与"不可取代"之间；若直接搭桥选项不存在，转向补充漏洞方向，找到"应聘者能力很难通过其他环节展示"这类必要条件。无断点搭桥示例：论据"投入了但论文数没增长"→结论"投入对科研发展没用"，断点在"论文数"与"科研发展"之间，搭桥选项为"发表文章数量是衡量科研发展的重要指标"。

## 不适用条件

- 题干问法为"以下哪项能加强/削弱/解释"而非"补充前提/假设"时，不适用搭桥-补漏二分法
- 论据与结论之间存在多个跳跃（断点≥3个），单一搭桥选项无法弥合时，需先识别核心断点再套用本法
- 题干论证结构为类比推理或枚举归纳时，前提题的搭桥逻辑不直接适用

## 反向触发

- 若否定代入后结论仍然成立（假设某选项不成立时结论还能推出），说明该选项不是必要前提，应排除并继续检验其他选项
- 若多个选项都包含断点两端概念，注意区分"搭桥"与"补充漏洞"：前者直接建立因果/条件联系，后者排除反例或补全范围；选错方向会导致误选干扰项
