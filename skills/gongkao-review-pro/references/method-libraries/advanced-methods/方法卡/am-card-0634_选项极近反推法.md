# 方法卡：选项极近时用反推法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 选项极近时用反推法（带入选项） |
| 适用题型 | 资料分析——选项差距极小时求增量 |
| 触发场景 | 假设分配法因选项过于接近（如差1~2）而无法直接算出时；直除需要算到较深位数 |
| 步骤逻辑 | ① 先用分数法（四幺五）估算大致范围，排除明显错误选项；② 在剩余接近的选项中选一个好算的数作为增量X；③ 用B-X反推基期A；④ 用A×R验算，看是否能回到选项中的值；⑤ 若有误差，误差量 = |选的X-实际X| × R，通常远小于选项间距 |
| 高频错因 | 选项极近时仍强行使用假设分配精确计算，浪费时间；不会利用选项本身作为已知条件 |
| confidence | medium |
| 不适用条件 | 选项差距较大、四幺五或假设分配可直接区分时；题目要求精确到特定位数且无整数选项可带入时；不是求增量/基期的题型 |
| 反向触发 | 直除需要算到第三位以后才能区分选项时；四幺五分数法估算后剩余选项仍无法区分时，应反推验算 |

## 补充说明

"利用答案算答案"——当选项极近时，选项本身就是增量X的近似值，带回去求A再验算，误差被R进一步缩小。强化方法举例：五位数选项差7时，带入任意一个选项算出的A再乘R，结果都在正确选项附近，不会选错。
