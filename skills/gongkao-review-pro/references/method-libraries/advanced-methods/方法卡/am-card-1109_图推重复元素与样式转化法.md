# 方法卡：图推重复元素与样式转化法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 图推重复元素与样式转化法 |
| 适用题型 | 判断推理——图形推理 |
| 触发场景 | 图形中出现重复的独立小图形（如多个圆、多个星星、多个箭头）、各图整体轮廓相同但内部填充不同、或各图有明显的样式交替规律 |
| 步骤逻辑 | ① 识别样式特征类型：重复独立小图形（各图都有多个相同的小图形）→ 整体轮廓相同（各图外形一致，内部不同）→ 相同位置有相同元素；② 重复独立小图形的优先级：元素数量规律（恒定/递增/递减/运算）→ 元素种类规律（同种/不同种/交替）→ 元素位置规律（移动/旋转/对称）→ 元素样式规律（填充/方向/大小）；③ 整体轮廓相同的优先级：黑白运算（黑+黑=白/黑+白=黑等）→ 旋转翻转 → 遍历（每个位置每种元素各出现一次）；④ 样式交替规律：元素可能按固定模式交替出现（如ABAB、AABB、ABCABC），识别周期后预测下一个；⑤ 元素数量转化：数量之间可能存在加减乘除关系（如第一个图元素数+第二个图元素数=第三个图元素数） |
| 高频错因 | ① 只看元素数量不看种类和位置，漏掉更深层的规律；② 整体轮廓相同题中只看旋转翻转，忽略黑白运算这个最常见考点；③ 重复小图形题中把所有元素混在一起数，不区分不同种类的元素分别计数；④ 样式交替规律识别不出周期，被表面变化干扰 |
| confidence | high |

## 补充说明

**重复独立小图形的触发逻辑：** 当各图都包含多个相同或相似的小图形时，先统计元素数量和种类，再看位置、方向或样式是否稳定变化。

**整体轮廓相同的触发逻辑：** 当各图整体外形一致，只有内部填充或细节不同时，优先比对黑白状态、旋转翻转和遍历关系。黑白运算的真值表必须从已知图反推，不预设某一组固定的黑白运算规则。

**与已有卡的关系：** am-card-1061（图推两种元素组合题）侧重两种元素的组合分析，本卡侧重重复元素的数量和样式变化。am-card-1089（图推规律库）包含更多具体规律，本卡是特征触发层的判断方法。

## 不适用条件

1. 图形无重复独立小图形时（应改用1121数量规律分层排查法）
2. 重复元素的数量、种类、位置和样式转化均无规律，而黑白网格运算能稳定解释时。
3. 整体轮廓和元素类型缺少可比性，无法建立重复或样式变化关系时。

## 反向触发

1. 元素数量规律验证无果时，应补充核验元素种类和位置规律
2. 整体轮廓相同但黑白运算无果时，应补充核验旋转翻转和遍历
3. 样式交替周期识别不出时，应换用1124图形间关系细分法分析元素间关系

## 输出要求

- 看到重复元素特征时，先说明触发的是哪种子类型
- 重复独立小图形优先数元素数量，再看种类和位置
- 整体轮廓相同优先验证黑白运算
- 样式交替规律要识别周期长度
- 与 am-card-1061、am-card-1089 配合使用
