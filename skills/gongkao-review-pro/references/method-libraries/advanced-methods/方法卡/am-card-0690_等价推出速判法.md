# 方法卡：等价推出速判法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 等价推出速判法 |
| 适用题型 | 逻辑判断——等价推出题（题干和选项都是命题，无具体事实） |
| 触发场景 | 题干有逻辑关联词（如果就、只有才、除非否则等），问"以下哪项正确表达了上述断定" |
| 步骤逻辑 | ① 将题干翻译成A推B的形式；② 正确答案要么是A推B本身，要么是其逆否命题非B推非A；③ 如果选项以B或非A开头（终点），直接排除；④ 只看A或非B开头的选项（始发站） |
| 高频错因 | 选了逆命题（B推A）或否命题（非A推非B），它们不等价；选了终点开头的选项 |
| confidence | medium |

## 补充说明

等价推出是送分题，核心是"忠于箭头"。A推B的等价形式只有两种：A推B（原命题）和非B推非A（逆否命题）。其他形式（B推A、非A推非B）都不等价。快速判断技巧：看选项开头，如果是B或非A开头（终点站），直接排除不看。

## 不适用条件

- 命题含联言、选言、量词或多层嵌套，不能只按单一箭头处理。
- 题目问充分、必要关系而非严格等价表达。

## 反向触发

- 翻译后主体或否定范围不一致时，先纠正命题符号再判断逆否。
- 复杂命题无法直接识别时，改用真值表或逐项代入反例验证。
