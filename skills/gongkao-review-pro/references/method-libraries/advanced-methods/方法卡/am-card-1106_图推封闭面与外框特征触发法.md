# 方法卡：图推封闭面与外框特征触发法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 图推封闭面与外框特征触发法 |
| 适用题型 | 判断推理——图形推理 |
| 触发场景 | 图形中出现明显的封闭面特征：只有一个面、各图都有封闭多边形外框、外框内被分割成多个区域 |
| 步骤逻辑 | ① 识别封闭面类型：单一面（图形只有一个封闭区域）→ 多个面（图形有多个封闭区域）→ 封闭多边形外框（所有图都有明确的外框，内部被线条分割）；② 单一面的优先级：一笔画（单一面必为一笔画）→ 对称性 → 面数量 → 线数/点数；③ 封闭多边形外框的优先级：框内交点数 → 框内线条数 → 框上公共边数 → 最大面/最小面的形状和属性；④ 框内交点是核心考点：外框内线条相交形成的交点数，可能是恒定值、递增/递减、或与外框边数有运算关系；⑤ 特殊面分析：面多时不考面数量，考最大面/最小面的边数、形状、位置 |
| 高频错因 | ① 只数面数量，面多时找不到规律就放弃，忽略特殊面分析；② 封闭多边形外框题上来就数边，忽略框内交点数这个更常见的考点；③ 单一面题忘记先验证一笔画和对称性；④ 忽略面与外框的公共边数这个隐蔽考点 |
| confidence | high |
| 不适用条件 | - 图形无封闭区域（全是开放线条、弧线组合），不触发封闭面相关分析
| 反向触发 | - 图形中所有区域均由开放线条构成，无任何封闭区域
- 封闭面数量已找到明确规律但答案不符合，应转向点数、线数或其他属性
- 题目明确考察旋转、翻转、叠加等与封闭面无关的运动规律 |
- 图形为立体图形（折纸盒、截面图），封闭面分析逻辑不适用
- 所有图的封闭面数量和形状完全一致，封闭面本身无变化规律 |

## 补充说明

**单一面的触发逻辑：** 当一组图中至少有一个图是单独一个封闭区域时，触发此判断。单一面的信息量有限，能考的规律也有限。优先验证：一笔画（单一面必为一笔画）→ 对称性 → 面数量 → 线数/点数。一笔画和对称性是"万物皆可考"的规律，任何图形都应先验。

**封闭多边形外框的触发逻辑：** 当所有图都有明确的封闭外框，且内部被线条分割成多个区域时，触发此判断。这类题图形复杂，正确率普遍偏低。核心考点是框内交点数（外框内线条相交形成的点数），而不是框的边数。框内交点数可能是恒定值、递增/递减、或与外框边数做加减运算。

**特殊面分析的触发逻辑：** 当面数量很多且无规律时，转向特殊面分析。最大面/最小面是最典型的特殊面。检查：特殊面的边数、形状（是否与外框形状相关）、属性（是否含曲线）、位置（与外框的公共边数）。

**与已有卡的关系：** 本卡是特征触发层，侧重"看到什么特征就往哪个方向想"。am-card-1008（特殊面分析法）是具体分析方法，am-card-1059（内外图形分析法）是内外关系分析。三者配合使用：本卡负责触发判断，1008/1059负责具体分析。

## 输出要求

- 看到封闭面特征时，先说明触发的是哪种子类型（单一面/多面/外框）
- 单一面优先验证一笔画和对称性，再验证面数量
- 封闭多边形外框优先验证框内交点数
- 面多无规律时转向特殊面分析
- 与 am-card-1008、am-card-1059 配合使用
