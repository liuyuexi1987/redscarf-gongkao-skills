# 方法卡：类比支持力度弱

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 类比支持力度弱 |
| 适用题型 | 支持类题目中出现类比选项的识别与排除 |
| 触发场景 | - 选项用"现在的人/其他国家/类似物种"的做法来类推过去/本国/目标物种
- 选项出现"A和B相似，所以A有X，B也有X"的推理结构 |
| 步骤逻辑 | 1. 识别选项是否为类比推理（从特殊推特殊）；2. 类比支持基本不会是正确答案——力度太弱；3. 有更强选项时直接排除类比项；4. 只有其他三个选项完全无关时，类比才可能勉强当选 |
| 高频错因 | 被类比项的"表面相关性"迷惑误以为"最接近的现存物种"就能代表目标物种的特征 |
| confidence | medium |

## 补充说明

类比推理是从特殊推特殊，力度最弱。即使两个对象在多个维度上高度相似（如地理位置、气候带、季节特征相近），也不能由此推出它们在某一特定属性上也相同。在支持题中，类比选项几乎永远不是最优解；当存在更强选项时，应直接排除类比项。只有其他三个选项完全无关时，类比才可能勉强当选。

## 不适用条件

- 当题干本身就是类比推理题、要求评价类比有效性时，本方法不适用。
- 当所有选项均为类比且无更强选项时，需在类比项之间比较相似度的相关性。

## 反向触发

- 当存在非类比的直接论据或断点搭桥选项时，应优先选用更强支持项而非类比。
- 当类比项的相似维度与结论属性高度相关时，应核验是否存在更强选项再决定是否排除类比项。
