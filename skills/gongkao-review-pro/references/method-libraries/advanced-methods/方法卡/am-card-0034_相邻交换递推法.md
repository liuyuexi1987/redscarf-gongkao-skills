# 方法卡：相邻交换递推法（斐波那契）
## 基本信息
| 字段 | 值 |
|------|-----|
| 方法名 | 相邻交换递推法（斐波那契） |
| 适用题型 | 数量关系-排列组合/相邻限制交换问题 |
| 触发场景 | n个人排队，每人只能与相邻人交换或不交换，要求与原来不同 |
| 步骤逻辑 | 1. 最后一人只有两种选择：与前面人交换或不交换；2. 若不交换→等价于前n-1人的问题=D(n-1)；3. 若交换→等价于前n-2人的问题=D(n-2)；4. 递推公式：D(n)=D(n-1)+D(n-2)；5. 初始值：D(2)=2，D(3)=3；6. 最终结果减1（去掉全不交换的情况） |
| 高频错因 | 忘记减去"全不交换"的1种情况（题目要求与原来不同）；递推初始值记错 |
| confidence | high |
## 补充说明
本质是斐波那契数列的应用。考场实战建议：若选项数值较小，直接枚举所有可能排列比递推更快。捆绑法分类（换0人、换2人、换4人...换n人）也可求解，用C(n-k/2, k/2)逐步累加。斐波那契递推更优雅但理解门槛高，考场首选枚举。
## 不适用条件
- 允许非相邻位置的交换或自由排列（属普通错排/排列问题，非本法递推结构）。
- 题目要求排列到特定目标顺序而非仅要求"与原来不同"，递推公式不适用。
- 初始条件不满足 D(2)=2、D(3)=3（如题目加了额外限制），需重新推导递推关系。
## 反向触发
- 题面含"交换"但实为任意两两交换的排列计数或错排问题，无"相邻"限制。
- 问题本质是图论中的相邻约束染色或路径计数，非线性排列交换。
