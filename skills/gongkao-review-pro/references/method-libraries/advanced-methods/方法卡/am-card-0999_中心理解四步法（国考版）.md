# 方法卡：中心理解四步法（国考版）

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 中心理解四步法（国考版） |
| 适用题型 | 言语理解——中心理解 |
| 触发场景 | 国考中心理解题（主旨概括/意图判断） |
| 步骤逻辑 | ① 找主旨句：优先从后面找（最后一句或倒数第二句），通过逻辑关联词（因此/所以/必须/需要/只有才）定位；② 判断结构：无主旨句时看结构（并列结构最常见）；③ 找主题词：反复出现的词语，辅助排除无关选项；④ 详读内容：判断每句话的功能（论据/背景/展开/转折） |
| 高频错因 | ① 只看最后一句不看前面→主体缺失；② 并列结构不知道怎么选主旨→需要概括全面；③ 主旨句在中间时被后面的话带走→后面可能是论据或展开 |
| confidence | high |

## 补充说明
中心理解核心框架。关键：主旨句优先从后面找；目的式/对策式表达（需要/应该/想要）是高频主旨信号；主旨之后的句子要判断是服务主旨还是另开话题。四步顺序为：定位主旨句→判断结构→找主题词→详读内容核验。

## 不适用条件
- 文段为细节题、语句排序题或语句填空题时，本方法不适用。
- 文段主旨句位置明确无歧义（如开头直陈观点后全为论据）时，四步流程可简化，无须完整套用。
- 文段为多主体并列、无明显主旨句的纯并列结构时，需以概括全面为主，本方法的"主旨句定位"步骤失效。

## 反向触发
- 当从后找主旨句得到多个候选时，应换用"代词回找主题词法"通过代词指代反向锁定主旨。
- 当文段含正反对比结构时，应补充"正反对比反推法"判断主旨落在对比的哪一侧。
- 当选项间差异仅在范围大小或限定词时，应结合"择优思维"比较瑕疵程度，避免因小瑕疵误选以偏概全的选项。
