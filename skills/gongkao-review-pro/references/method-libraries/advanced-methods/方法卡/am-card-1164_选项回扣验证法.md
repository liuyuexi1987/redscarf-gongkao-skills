# 方法卡：选项回扣验证法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 选项回扣验证法 |
| 适用题型 | 行测通用：资料分析、数量关系、判断推理、常识判断、言语题的选项核验 |
| 触发场景 | 选项本身就是候选答案、候选对象、候选关系、候选表述或候选图形时，优先用选项回扣题干/材料/定义/公式/规律验证 |
| 步骤逻辑 | 1. 先看选项是否能直接代入或回扣题干；2. 优先试中间项、顺手项、最接近项或限制最强项；3. 将候选带回公式、条件、定义要件、文段主旨或图形规律；4. 能唯一闭合全部关键条件就立即停止；5. 若选项无法直接验证、多个选项同时闭合或题面信息不完整，再回到正向推导 |
| 高频错因 | 明明选项可直接验证，却从头完整推导，浪费时间；只验证一个条件就下结论，漏掉其它限制；多个选项都能部分符合时没有继续核验唯一性；把模型猜测当作闭合验证 |
| confidence | high |

## 核心判断

选项不是只能最后看。很多行测题的选项本身就是一组候选解，先拿候选回扣题干，往往比从头推导更快。

判断标准不是“有没有完整推导”，而是“候选是否能同时满足题干的关键条件，并唯一排除其它选项”。

讲解时不要只说“代入验证”。要说明为什么先试这个选项、怎么试、试到什么程度就停：

1. 先说明选项为什么能当候选解。
2. 说明优先试哪个选项：中间项、最接近项、限制最强项或计算最顺项。
3. 逐个回扣题干最硬的 2–3 个条件。
4. 条件全部闭合后直接停止，不再补长方程。

## 常见用法

- 资料分析：选项是基期、现期、增长率、比重时，可反乘、反除或代入公式验证。
- 数量关系：选项是时间、年龄、人数、次数、总量或整数值时，可先代入中间项或顺手项。
- 分析推理：选项是排列、对应关系或真假判断时，可逐项带入条件。
- 定义判断：选项案例要回扣主体、条件、行为、结果等定义要件。
- 图形推理：候选图形必须满足全部已知规律，不能只满足一个数量或一个特征。
- 常识判断：选项是主体、权限、文种或政策工具时，可回扣主体、对象、作用变量和适用边界。
- 言语理解：标题、填句、结语、主旨选项可回扣文段主体、话题、范围和逻辑位置。

## 不适用条件

- 选项不能直接对应题目所求量或所判关系。
- 题干条件尚未读清，代入会变成盲试。
- 多个选项都能满足部分条件，仍需继续找限制或正向推导。
- 主观/易争议题没有官方答案时，选项回扣只能给方法倾向，不能硬判对错。

## 反向触发

- 如果选项是具体数值、时间点、排列关系、政策主体、定义案例或候选图形，先想能否回扣验证。
- 如果已经有一个候选同时满足全部关键条件，不要为了展示完整性继续长算。
- 如果只验证了一个条件就想选，先检查单位、时间、主体、范围、定义要件或图形唯一性限制。
