# 方法卡：化除为乘

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 化除为乘 |
| 适用题型 | 资料分析——用现期与增长率近似计算增长量 |
| 触发场景 | 增长量=现期×R/(1+R)，且省略分母修正的误差不足以影响选项判断 |
| 步骤逻辑 | ① 先算近似值现期×R；② 该值相对精确增长量偏大；③ 误差量为现期×R²/(1+R)，用它与选项间距比较；④ 误差可能跨越选项时，直接使用完整公式或反乘验证 |
| 高频错因 | ① 不估计R²修正项就直接作答；② 把近似结果偏大的方向记反；③ 将增长量公式与基期公式混淆 |
| confidence | high |

## 补充说明

化除为乘利用增长量=现期×R/(1+R)。省略分母得到现期×R，近似值偏大，绝对误差为现期×R²/(1+R)。是否可用应比较这项误差与选项间距，而不是采用固定增速门槛。

## 不适用条件

1. R²修正项可能改变选项判断时，不宜省略分母。
2. 选项差距不足以覆盖近似误差时，需要精算而非估算。
3. 题目求的是基期值（现期÷(1+R)）而非增量，本法适用对象不同。

## 反向触发

1. 题目要求计算增长量，且现期×R的误差经核验不会跨越选项。
2. 分母为(1+R)形式且增速较小，化除为乘比直接除法更快。
3. 选项差距明显大于R²修正项，可使用近似结果快速判断。
