# 方法卡：想太多自检三步法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 想太多自检三步法 |
| 适用题型 | 逻辑填空/言语理解——过度推理错因 |
| 触发场景 | 做题时出现"我觉得这个也可以""好像两个都对""这个好像也有道理"的纠结状态 |
| 步骤逻辑 | ① 停下来问自己："这个推断是原文直接告诉我的，还是我自己补脑的？"；② 如果是补脑的→立刻停止，回到原文找直接证据；③ 如果原文有直接证据→按证据选，不再多想；④ 如果两个选项都有直接证据→选更贴近原文表述的那个 |
| 高频错因 | ① 把"可能对"当成"一定对"，选了过度推断的选项；② 在两个选项间反复纠结，最后选了最初排除的那个 |
| confidence | high |
| 不适用条件 | 题目是数学运算或资料分析，需要精确计算而非语感判断；题目是逻辑判断中的形式逻辑推理，推断步骤有明确规则 |
| 反向触发 | 做题时思路清晰、没有纠结状态，不需要自检干预；选项之间差异明确，不存在"好像两个都对"的情况 |

## 补充说明
"想太多"是逻辑填空和言语理解中最高频的错因之一。核心原则：公考选项设计是"最佳答案"而非"唯一正确答案"——当两个选项都看似合理时，选更直接、更贴近原文的那个。考场上的策略：选完就走，不要回头改。
