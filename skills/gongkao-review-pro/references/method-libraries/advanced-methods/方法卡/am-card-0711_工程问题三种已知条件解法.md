# 方法卡：工程问题三种已知条件解法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 工程问题三种已知条件解法 |
| 适用题型 | 数量关系——工程问题（合作完工类） |
| 触发场景 | 工程合作题中已知完工时间、效率比或分段完工条件，需要选择总量赋值或列方程路径 |
| 步骤逻辑 | 工程问题根据已知条件类型选择固定解法：给时间设公倍数，给效率比直接用，给完工情况列方程。；1. **给时间**（如甲需20天，乙需30天）：设最小公倍数为工作总量→求效率→继续；2. **给效率比**（如甲乙效率比2:1）：直接把2和1当效率用；3. **给不同完工情况**（如甲先做15天，乙再做多少天完成）：根据工作总量相等列方程 |
| 高频错因 | 给时间条件时忘记设公倍数为总量，导致效率出现分数增加计算量给效率比时误用具体数值代替比值列方程时搞错"已完成天数"与"剩余天数"的关系，漏加已干天数 |
| confidence | medium |

## 补充说明

- 设最小公倍数是为了让效率变成整数，方便计算
- 公倍数不一定要最小的，只要是公倍数就行，但尽量小
- 最后注意问的是"共需多少天"还是"还需多少天"，别漏加已干天数

## 不适用条件

- 行程问题、利润问题等非工程类题目不适用本三分法
- 工程问题中涉及三人及以上合作且条件交叉时，三分法可能不够直观，需列方程组
- 题目给的是工作量比例而非时间或效率时，需先转化为标准条件

## 反向触发

- 若无法判断题目属于哪种已知条件类型，先列已知量再选解法
- 若设公倍数后效率仍为分数，检查是否选错了公倍数或条件理解有误
