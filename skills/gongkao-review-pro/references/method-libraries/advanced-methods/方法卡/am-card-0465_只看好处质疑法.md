# 方法卡：只看好处质疑法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 只看好处质疑法 |
| 适用题型 | 判断推理 > 削弱质疑（只展示好处/优点的论证） |
| 触发场景 | 论证结构为"X有好处A、B、C，所以应该推广/采用X"，忽略了X的副作用或代价 |
| 步骤逻辑 | 1. 识别论证漏洞：只说了好处，没提坏处；2. 质疑方向：指出X存在重大副作用/代价，使好处被抵消或无法实施；3. 如帽子保暖但太贵/影响听力；技术提升能力A但削弱关键能力B；4. 含"前提""基础""关键"等词的选项需重点关注，出题人用严谨措辞保证力度 |
| 高频错因 | 选了"不接受也能提高"这类选项，没注意提升幅度和效率差异；忽略副作用选项 |

## 不适用条件

1. 论证已考虑坏处或代价（如"虽然有副作用但好处更大"），不存在"只看好处"的漏洞
2. 题目问的是加强而非削弱
3. 选项中没有提及副作用/代价，只有"好处不够大"的角度

## 反向触发

1. 当论证结构不是"只看好处"而是"因果推理"时，应换用因果削弱方法
2. 当选项给出"前提不成立"时，前提质疑力度通常大于副作用质疑，应优先选择
3. 当所有选项都在讨论好处多少时，无法用副作用质疑，需要换用比较力度的方式
