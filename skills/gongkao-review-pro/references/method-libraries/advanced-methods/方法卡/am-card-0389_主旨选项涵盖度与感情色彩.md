# 方法卡：主旨选项涵盖度与感情色彩

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 主旨选项涵盖度与感情色彩 |
| 适用题型 | 中心理解题（主旨大意） |
| 触发场景 | 总分结构的文段，选项需要同时覆盖"总"和"分"的态度 |
| 步骤逻辑 | 1. 总分结构：总括句提出内容，分述段展开并表态；2. 正确选项需涵盖总括内容+分述态度（如两个都批判→选"都不可取"）；3. 感情色彩须与原文一致：原文批判→选项不能是中性或积极（如"都有生存土壤"）；4. 只覆盖其中一个方向的选项（如只提理论，不提现象）是片面的 |
| 高频错因 | 选项只涵盖总括，没涵盖分述的批判态度感情色彩与原文不一致（原文批判、选项中性）引申过度（如原文只说不好，选项上升到"始终是难题"） |
| confidence | high |

## 补充说明

总分结构文段的选项筛选需同时满足两个条件：内容涵盖度（选项覆盖了"总"和"分"两部分）和感情色彩一致性（选项态度与原文一致）。常见陷阱是选项只覆盖总括部分而遗漏分述的立场，或态度方向与原文相反（如原文批判、选项却用中性或积极表述）。此外需警惕引申过度——原文仅陈述某现象不好，选项却上升到"始终是难题"等过度概括。

## 不适用条件

- 文段为并列结构或转折结构而非总分结构时，涵盖度判断逻辑不同
- 文段感情色彩本身为中性客观陈述，无明显褒贬倾向
- 选项均为概括性表述，难以通过"覆盖总/分"来筛选

## 反向触发

- 当两个选项都覆盖了总和分的内容时，应比较感情色彩的精确匹配度，而非仅看涵盖范围
- 当正确选项看似只提了总括部分但实际隐含了分述态度时，不要轻易排除
- 当文段分述部分出现转折（如先扬后抑），选项的感情色彩应跟最终落点一致，而非跟开头一致
