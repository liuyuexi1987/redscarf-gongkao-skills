# 方法卡：年均增长量与小增率估算

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 年均增长量与小增率估算 |
| 适用题型 | 资料分析——年均增长量/率计算 |
| 触发场景 | 题干出现"X年到Y年年均增长约多少" |
| 步骤逻辑 | ① 按题目措辞确定首期、末期和增长次数 n，不用地区经验替代题意；② 年均增长量精确式为 `(末期量-首期量)/n`；③ 若首期量需由现期量 B 和增速 r 反推，单期增长量精确式为 `B×r/(1+r)`；④ 需要速估时可先用 `B×r`，但其高估量约为 `B×r²/(1+r)`，必须确认误差不跨选项；⑤ 年均增长率用 `(末期量/首期量)^(1/n)-1`，正增长时可用总增长率÷n作为上界辅助排除 |
| 验证动作 | 检查年份差、首末期口径和单位；将估算误差与最近选项间距比较 |
| 不适用条件 | 增长率较大或选项接近时，不用 `B×r` 代替精确增长量；总增长率为负时，不直接套正增长上界判断 |
| 高频错因 | 把年份个数当增长次数；按地区口诀擅自前推；把现期量乘增速当成精确增长量；混淆年均增长量与年均增长率 |
| confidence | high |
| 反向触发 | 1. 选项间距极小，B×r估算的误差可能跨越选项时，改用精确公式B×r/(1+r)
2. 增长次数n不确定或首末期口径存在歧义时，先确认年份定义（是间隔年数还是年份数）再代入公式 |
