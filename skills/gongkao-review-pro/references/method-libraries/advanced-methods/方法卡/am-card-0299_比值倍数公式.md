# 方法卡：比值倍数公式

| 字段 | 内容 |
|------|------|
| 方法名 | 比值倍数公式 |
| 适用题型 | 资料分析-比值倍数（如"份额是去年多少倍""比重是去年几倍"） |
| 触发场景 | 题目问的是某个比值（占比/份额/平均值等）现期是基期的多少倍 |
| 步骤逻辑 | 1. 识别所求为比值的倍数 → 2. 找分子增速(RA)和分母增速(RB) → 3. 比值增长率 = (RA - RB) / (1 + RB) → 4. 比值倍数 = 比值增长率 + 1 |
| 高频错因 | 混淆比值倍数和比值差；误用比重差公式代替比值增长率公式 |
| confidence | high |

补充说明：此公式与直接用"现期比值÷基期比值"等价，但更高效——只需找两个增速即可，不必算出具体比值。当题目问"比值比上年多/少多少百分点"时用比重差公式，问"比值是多少倍"时用本公式。

## 不适用条件

- 分子或分母为负数时，比值正负方向需单独判断，不能直接套公式
- 题目问的是比值差（百分点变化）而非比值倍数时，应改用比重差公式
- 分子分母的增速本身难以确定（如涉及多步增长率复合计算）时，公式无法直接应用

## 反向触发

- 当计算出的比值倍数接近1（比值增长率接近0）时，正负方向可能受精度影响，应代入数值验证
- 题目问"比值比上年多几个百分点"而非"是几倍"时，应改用比重差公式
- 当分子分母之一为负增长时，比值增减方向需结合符号判断，不能仅凭增速大小
