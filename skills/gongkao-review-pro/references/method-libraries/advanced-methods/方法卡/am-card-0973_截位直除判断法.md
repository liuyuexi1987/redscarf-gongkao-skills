# 方法卡：截位直除判断法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 截位直除判断法 |
| 适用题型 | 资料分析——截位直除适用判断 |
| 触发场景 | 资料分析中遇到除法计算，需要判断是否用截位直除还是其他速算方法 |
| 步骤逻辑 | ① 看选项差距：选项差距>5%→截两位直除；选项差距1%-5%→截三位直除；选项差距<1%→精确计算或换方法；② 截位规则：分子不动，分母截位（四舍五入）；③ 直除出前两位或前三位，与选项比对；④ 如果截位后无法区分→改为精确除法 |
| 高频错因 | ① 选项差距很小时仍然截位，导致精度不够选错；② 截位时分子分母都截了，误差叠加；③ 忘记"不上不下"时干脆直除算了的策略 |
| confidence | high |

## 补充说明
截位直除是资料分析中最通用的速算方法，但不是万能的。核心判断标准是选项差距：差距大可以粗截，差距小必须精算或换方法。"不上不下"（选项差距中等）时，最稳妥的做法是直接精确除法，不要冒险截位。

## 不适用条件

- 选项差距极小、估算误差可能跨越选项时，应直接精算，不走截位直除。
- 需要保留多位有效数字的连除或嵌套运算（如 A/B÷C），截位误差会层层放大，不宜使用。
- 题干要求精确结果（如求具体数值而非占比）时，截位直除无法保证精度。

## 反向触发

- 当分子分母同量级且差距极小，截位后无法区分选项时，应改用直除精算或换用其他速算方法（如首数法、特征数字法）补充核验。
- 当除式涉及多步复合运算时，应改用分步精算或先化简再计算，避免截位误差累积。
- 当选项含"约""接近"等限定词且数值相邻时，应补一步精算核验，不直接采信截位结果。
