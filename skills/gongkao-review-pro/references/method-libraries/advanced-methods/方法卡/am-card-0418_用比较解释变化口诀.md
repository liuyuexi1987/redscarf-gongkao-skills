# 方法卡：用比较解释变化口诀

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 用比较解释变化口诀 |
| 适用题型 | 逻辑判断-加强削弱（变化类/比较类论证） |
| 触发场景 | 题干用变化趋势或比较关系作为论据推出结论 |
| 步骤逻辑 | 1. 识别两句话口诀：「用比较来解释变化」和「比较说两边」；2. 当题干中一方发生了变化（如销量上升），解释原因时：- 有效：通过与另一方的比较来解释（用比较解释变化）- 有效：比较涉及变化的双方（比较说两边）；3. 加强/削弱时，选项如果涉及比较对象的一致性，往往是关键选项；4. 这是越来越常考的逻辑题型，需反复练习才能内化 |
| 高频错因 | 只看变化的一方，忽略比较对象；选项偷换比较主体未识别 |
| confidence | medium |

## 不适用条件

- 题干只有一方发生了变化，没有对照组或参照对象，无法构成比较关系时
- 结论本身是对趋势的直接描述（如"销量在上升"），而非对变化原因的因果推理时
- 题目考查的是概念定义或分类关系，而非因果解释或归因分析时

## 反向触发

- 当选项涉及基数差异而非实际趋势变化时，应先验证增长率是否受基数影响，改用基数分析法而非比较法
- 当题干的"变化"是时间序列上的自然波动而非真实因果变化时，直接套用比较法可能误判因果方向，需先确认变化是否显著
- 当选项同时涉及"比较"和"他因"时，不应只看比较是否成立，还需评估他因选项是否提供了更强的因果解释
