# 方法卡：冠军模型

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 冠军模型 |
| 适用题型 | 判断推理-多选一的真假话题目（最终只有一人/一个中标、获奖、正确等） |
| 触发场景 | 题干特征：多人判断谁中选，且限定"最终只有一人中标"；明确告知几人对几人错 |
| 步骤逻辑 | 1. **识别**：多选一 + 真假话 + 告知正确人数 → 冠军模型；2. **转化为正向形式**：- "不是甲就是乙" → 甲或乙- "不是丙" → 甲乙丁戊己（排除丙的所有项都对）- "戊和己均未中标" → 甲乙丙丁中标；3. **数出场次数**：统计每个候选人在正向形式中被提到的次数；4. **正确数 = 出场数**：告知几人正确，就找出场几次的候选人；5. 出场次数少的候选人可以确定没中标 |
| 高频错因 | 用逐个假设的方法去推，人数多时容易混乱忘记转化为正向形式，直接在原句间推理 |
| confidence | high |

## 不适用条件

1. 题干未明确告知正确/错误人数，无法用"出场数=正确数"的对应关系
2. 不是"多选一"结构（如多人可同时中标/获奖）
3. 判断语句中存在"当且仅当""除非"等复杂逻辑联结词，需改用符号化推理

## 反向触发

1. 题干明确说"最终只有一人XX"且给出了几人对几人错
2. 多人分别对若干候选人做出判断，且判断形式含"不是甲就是乙"类选言表述
3. 选项需要在多个候选人中确定唯一中标者/获奖者
