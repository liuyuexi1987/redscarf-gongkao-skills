# 方法卡：举例支持（"某些"情况）

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 举例支持（"某些"情况） |
| 适用题型 | 支持类题目中结论含"某些/有些/存在"等限定词 |
| 触发场景 | 结论使用“某些/有些/存在”等存在量词，选项给出一个与结论条件完全一致的具体实例 |
| 步骤逻辑 | ① 先确认结论量词；② 核对实例是否满足结论中的主体、条件和结果；③ 一个有效实例可以证明“至少存在一个”，因此可支持存在性结论；④ 再与其他选项比较是否有更直接、更完整的支持 |
| 高频错因 | 不看量词就认为举例一定弱；实例只满足部分条件却被当作完整支持；把一个实例用于证明“所有/全部” |
| 不适用条件 | 结论要求“所有/全部/普遍”成立；实例与结论主体、条件或结果不一致；题目要求证明因果机制而实例只说明个案共现 |
| 反向触发 | 结论是全称命题时，单个正例不能证明整体，应寻找一般规则或代表性证据；具体实例只能证明相关个体，无法覆盖结论中的附加条件时，应降低其支持力度 |
| confidence | medium |

## 补充说明

举例支持的力度取决于结论量词。结论只主张“存在某种情况”时，一个满足全部条件的实例即可提供直接支持；结论主张普遍规律时，单个实例通常不足。最终仍需核对实例与结论是否同主体、同条件、同结果。
