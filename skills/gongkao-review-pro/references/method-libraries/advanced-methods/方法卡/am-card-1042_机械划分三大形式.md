# 方法卡：机械划分三大形式

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 机械划分三大形式 |
| 适用题型 | 数量关系——数字推理（机械划分） |
| 触发场景 | 数列都是多位数（两位起步），有时带小数点 |
| 步骤逻辑 | ① 识别：数列全为多位数（两位及以上）且无单调/倍数规律→考虑机械划分；② 形式一：拆分后各位独立成规律（如前两位等差+后两位等差）；③ 形式二：拆分后各位做和（如每位数字加起来=固定值，形成等差或循环）；④ 形式三：内部递推（如某一位由其他位运算得到）；⑤ 每种形式必须覆盖全部已知项，且推得的目标项能唯一锁定选项 |
| 高频错因 | ① 多位数数列已有单调/倍数规律却仍强行机械划分，破坏主规律；② 内部递推从数小的位置入手→规律不稳定→应从数大的位置入手；③ 只验证了一种拆分形式就下结论，未排除其他等价拆法 |
| confidence | high |

## 补充说明
机械划分是数字推理中多位数题型的专属方法。识别信号：数列全是两位及以上的数。三种形式优先级：拆分独立规律→各位求和→内部递推。

## 不适用条件
- 数列中有单位数（个位数），机械划分不适用
- 多位数之间有明显倍数或等差关系（优先用常规方法）
- 数列含小数且小数位数不一致，拆分规则不明确

## 反向触发
- 如果数列全是单位数，不使用机械划分。
- 如果多位数可直接做差/做商得到规律，无需拆分。
- 如果三种形式都验证失败，回退到"分组数列识别总卡"，检查是否存在小数点/根号/分式等其他分组特征。

## 最终验证动作

1. 用选定的拆分形式逐项回代，确认每一位的规律都覆盖全部已知项。
2. 推出目标项后，按拆分方式还原完整多位数，与选项比对。
3. 对内部递推形式，必须验证递推关系在至少两个连续位置都成立，不能只验证末位。
