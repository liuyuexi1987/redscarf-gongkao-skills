# 方法卡：每N个数求和反推单数

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 每N个数求和反推单数 |
| 适用题型 | 数量关系 |
| 触发场景 | 题目给出"每N个数之和"的多个数值，要求反推某个数 |
| 步骤逻辑 | 1. 把所有"每N个数之和"加起来，得到总和的(N-1)倍；2. 除以(N-1)得到所有数的总和；3. 用总和减去最小的和→得到最大的数；减去次小的和→得到次大的数；以此类推；4. 不用列方程，直接利用"缺失哪个数，和就最小"的对应关系 |
| 高频错因 | 直接列五元方程组求解，计算繁琐易错；搞不清"和越小说明缺的数越大"的反向对应 |
| confidence | medium |

## 不适用条件

- 题目只给出一组"和"而非多组"每N个数之和"时不适用此法（无法反推）。
- 题目要求的是中间某个数而非"最大/最小"等极值对应数时不适用此法的极值反推部分。
- "每N个数之和"中N=1（即直接给出每个数本身）时不适用此法。

## 反向触发

- 当各"和"之间存在重复覆盖、无法直接相加得到总和的(N-1)倍时，应换用方程组法求解。
- 当题目含"每N个连续数之和"且数的顺序信息重要时，应补充用数列位置关系核验。
- 当反推结果代入原题验算不成立时，应回归原始方程组重新求解，检查是否存在抄录或运算错误。
