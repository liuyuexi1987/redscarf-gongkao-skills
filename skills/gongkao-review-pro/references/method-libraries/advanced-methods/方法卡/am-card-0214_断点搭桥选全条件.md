# 方法卡：断点搭桥选全条件

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 断点搭桥选全条件 |
| 适用题型 | 判断推理——前提假设类（断点搭桥型） |
| 触发场景 | 题干论据含概念A、结论含概念B，AB之间有跳跃；问法含"最可能假设" |
| 步骤逻辑 | ① 提取论据中新概念（如神秘感）和结论中新概念（如精神世界）；② 找同时包含两项的选项即为搭桥；③ 若有多项可选，优先选用完所有已知条件的选项——"最可能假设"要求逻辑链完整，不能跳过某个环节 |
| 高频错因 | 选了只搭部分断点的选项（跳过中间环节）；误以为搭桥只需包含两项之一 |
| 不适用条件 | 题干无明显的概念跳跃（论据与结论用同一概念）；问法为"削弱"而非"前提假设" |
| 反向触发 | 选项同时包含论据新概念和结论新概念，且用完所有已知条件，应优先选择 |
| confidence | high |

## 补充说明

前提假设80%是断点搭桥、10%补充漏洞、10%必要条件。论据搭结论的概率高于结论内部搭桥。若两个选项都像搭桥，优先选论据到结论方向的那个。
