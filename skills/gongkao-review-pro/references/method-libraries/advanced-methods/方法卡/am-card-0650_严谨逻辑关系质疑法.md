# 方法卡：严谨逻辑关系质疑法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 严谨逻辑关系质疑法 |
| 适用题型 | 逻辑判断——一般质疑（结论含"如果...那么""只有...才"等逻辑关联词） |
| 触发场景 | 结论中使用了逻辑关联词，形成绝对化表达（如"如果A那么B""只有A才B"） |
| 步骤逻辑 | ① 将结论翻译为逻辑关系：A→B；② 找A且非B的反例即可质疑；③ 这类题中"某些"等反例选项特别容易是正确答案（在其他题型中"某些"力度弱，此处恰好是致命反例） |
| 高频错因 | 用一般质疑的方法（补充反向论据等）来解这类题；不敢选"某些"这种看似力度弱的选项 |
| confidence | medium |

## 补充说明

"某些"在严谨逻辑关系题中的特殊地位：该方法比喻为"斗兽棋"——"某些"在一般质疑中是"老鼠"（力度弱，谁也干不过），但在严谨逻辑关系题中能吃"大象"（直接否定绝对化结论）。例如"所有A都是B"只需一个"某个A不是B"就能推翻。做题时如果结论有逻辑关联词，优先找反例，不要用一般质疑的思路去套。

## 不适用条件

- 结论不含逻辑关联词、仅作事实陈述时，不适用本法。
- 题干为归纳/类比论证而非演绎推理时，"找反例"力度不足。
- 选项中没有提供反例的项时，本法的选项定位失效。

## 反向触发

- 结论为归纳概括且需质疑样本代表性时，改用"以偏概全/样本质疑"。
- 结论含程度限定词时，改用"程度词精准匹配法"。
- 论据与结论关键词不一致存在断点时，转用"断点拆桥法"。
