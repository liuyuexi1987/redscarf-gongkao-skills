# 方法卡：真假话与已知条件同义替换快判

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 真假话与已知条件同义替换快判 |
| 适用题型 | 判断推理——真假话问题 |
| 触发场景 | 多人发言判断真假，其中某人的表述与已知条件（如"只有一人说对"）含义相同 |
| 步骤逻辑 | ① 梳理已知条件（如"只有一人说对"= "有人是错的"）；② 逐一比对各人发言，找与已知条件同义的那句；③ 该句必定为真；④ 剩余各句为假，取反后推理实际结果 |
| 高频错因 | 逐句假设验证耗时过长；未识别同义表述（如"有人预测是错的"="只有一人说对"） |
| confidence | high |
| 不适用条件 | 1. 不适用于排列组合类（如座位排序、物品分组）和命题推理类（P→Q形式）的真假话题\n2. 各人发言均与已知条件无法形成同义对应时，本方法不适用，改用假设法或矛盾法\n3. 已知条件不明确（如未给出 |
| 反向触发 | 1. 看到条件为命题逻辑形式（如果A那么B、只有C才D），不用本方法，改用命题推理\n2. 题目要求排列顺序或分组匹配而非判断真假，不用本方法\n3. 当某句表述与已知条件存在明显矛盾（而非同义）时，该句必假，改用矛盾法直接锁定 |

## 补充说明

例："只有一人说对"→ 有人错。丁说"你们肯定有人是错的"，与已知条件同义，丁必真。甲乙丙为假，取反后：乙丙上一个、选3人、丙当选 → 甲丙丁。
