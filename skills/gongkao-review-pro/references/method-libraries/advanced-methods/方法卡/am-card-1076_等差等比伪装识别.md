# 方法卡：等差等比伪装识别

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 等差等比伪装识别 |
| 适用题型 | 数量关系——数字推理 |
| 触发场景 | 数字推理中等差/等比的规律被"伪装"（非整数公差/公比） |
| 步骤逻辑 | ① 公差带0.5（如1, 1.5, 2, 2.5...）→不是整数但仍是等差；② 首项为负（如-3, -1, 1, 3...）→仍是等差；③ 公比为1.5倍→不是整数倍但仍是等比；④ 这些都是"加大难度"的常见手法 |
| 高频错因 | ① 只看整数公差/公比→忽略0.5公差和1.5倍公比；② 首项为负→不习惯→找不到规律 |
| confidence | high |

## 补充说明
等差/等比的伪装手法：公差0.5、首项为负、公比1.5倍。这些是命题中"加大难度"的常用方式。做题时不要只看整数规律，要对小数和负数也保持敏感。

## 不适用条件
- 数列明显呈递推或分组特征时，不应套用等差/等比伪装识别。
- 数列含分数且分母变化无规律时，伪装等差/等比假设难以成立。
- 可用项太少，候选公差或公比无法连续验证时。

## 反向触发
- 当伪装等差/等比验证不通过时，应换用做和或递推倍数法。
- 当数列首尾项差值远大于中间项差值时，应改用二级差或分组分析。
- 当公差/公比候选值过多时，应补充延展验证（推下一项并比对），避免误判。
