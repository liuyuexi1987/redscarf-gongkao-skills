# 方法卡：反比关系识别法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 反比关系识别法 |
| 适用题型 | 数量关系·和差倍比 |
| 触发场景 | 题目出现A=B×C的关系，且A不变（总量固定），求B与C的反向变化 |
| 步骤逻辑 | 1. 识别A=B×C结构，确认A（总量）不变；2. B与C成反比：B越高→C越低；3. 速度比M:N → 时间比为N:M（路程不变时）；4. 写出反比关系后，结合已知数据求解 |
| 高频错因 | 混淆正比和反比的前提条件（不变量搞错） |
| confidence | high |

## 补充说明

反比在经济利润（总价不变买更多）、行程（路程不变速度快时间短）、工程（工程量不变效率高时间短）中广泛使用。

## 不适用条件

- 总量A本身变化（无固定锚点，B与C之间无反比关系）。
- 关系结构不是 A=B×C 的乘积式（加和或差量关系不适用反比）。
- 题目所求为正比关系（某因子不变时另外两量同向变化），不应误用反比。

## 反向触发

- 当某因子（B或C）不变、要求总量与另一因子关系时，应改用正比关系识别法。
- 当总量与各因子均变化、需直接求具体值时，应改用比例和份数法或赋值法。
- 当题目给出百分比形式的速度差异时，应先用"百分比转比例"化为整数比再求反比。
