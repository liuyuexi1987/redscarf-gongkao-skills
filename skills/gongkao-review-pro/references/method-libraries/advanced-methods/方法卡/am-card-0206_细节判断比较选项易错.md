# 方法卡：细节判断比较选项易错

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 细节判断比较选项易错 |
| 适用题型 | 细节判断 |
| 触发场景 | 选项涉及两个对象的比较（"地位接近""同等重要""比XX更"等） |
| 步骤逻辑 | 1. 看到比较结构的选项先标记；2. 判断文段是否确实进行了明确对比；3. 若文段只分别陈述两事物而未比较，该选项大概率错；4. "重要"在细节判断中力度极低，什么都能叫重要 |
| 高频错因 | 误认为"一起出现=比较"，实际文段未做比较 |
| confidence | high |

## 不适用条件

1. 文段确实对两个对象进行了明确对比（如"前者…后者…"），比较选项可能是正确的
2. 题目问的是"说法错误"——比较选项的陷阱在排除模式下方向相反
3. 选项中的比较属于常识性并列而非文段逻辑对比（如"张三和李四都参加了"）

## 反向触发

1. 选项出现"地位接近""同等重要""比XX更"等比较结构时，先回文段确认是否存在真实对比
2. 文段只是分别陈述两个事物而未建立比较依据时，比较结论缺少原文支撑
3. "重要"在细节判断中力度极低，不要因为文段同时提到两个事物就认为它们有比较关系
