# 方法卡：时间对比归因削弱

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 时间对比归因削弱 |
| 适用题型 | 削弱/另有他因——题干出现"近年来/最近/自…以来"等时间变化标志，将变化归因于某因素 |
| 触发场景 | 论据结构：某时间点前后出现结果变化（如"近年来受伤病例明显增加"），结论归因于某因素（如"管理人员缺乏安全意识"） |
| 步骤逻辑 | ① 识别时间对比结构：分组为"变化前vs变化后"；② 削弱时必须回归时间——找另一个也"在该时间点发生了变化"的因素作为他因；③ 排除常见设错：选项中的因素"一直存在"（如逐年提高=一直有），无法解释"近年来的突然变化" |
| 高频错因 | 选了"一直存在的因素"（常见设错）；选了"近年来也存在"但没有明确变化的选项；未回归时间，选了与时间变化无关的选项 |
| confidence | high |

## 补充说明

"一直存在的没法解释变化"是核心逻辑。示例：近年来某类病例增加→归因某管理因素，削弱方向应选"近年来另一基数因素也在增加"（如参训人数增加→基数变大→病例自然增加），而"一直存在的因素"（如管理规范逐年提高）无法解释"近年来的突然变化"，直接排除。另一示例：某物种数量急剧减少→归因于某新因素，削弱方向应选"另一因素也在同一时间点后发生变化"，而"每年平均消失一定栖息地"属于一直存在的因素，无法解释"急剧"减少。

## 不适用条件

- 结论没有明确的时间变化标志（如"近年来""自…以来"），仅做静态因果归因时，应按普通归因削弱处理
- 题干论据中变化幅度极小或无统计显著性差异时，时间对比结构不成立，本法的"回归时间"思路不适用
- 题目要求加强而非削弱时，"回归时间"的思路需反转（找与该因素同步变化的支持性因素）

## 反向触发

- 若所有选项描述的因素在时间点前后都有变化，无法通过"一直存在"排除，应比较各因素变化幅度与结果变化幅度的匹配程度，选匹配最紧密的
- 若削弱选项中的"时间变化"因素在题干中已被提及或排除（如题干已说"参训人数稳定"），该选项不构成新信息，削弱力度不足，应换选
