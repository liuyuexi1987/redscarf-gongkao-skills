# 方法卡：论证部分非主旨识别法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 论证部分非主旨识别法 |
| 适用题型 | 言语理解——中心理解题 |
| 触发场景 | 文段中出现用于支撑前述观点的举例、解释说明、具体分析、数据列举或正反对比论证等内容 |
| 步骤逻辑 | 1. 判断某句话的功能：该句是在表达独立观点，还是在支撑前文某个观点<br>2. 识别论证标志："例如""比如""也就是说""具体而言"、具体数据、正反对比、因果解释等均提示该句为论证部分<br>3. 论证部分的内容不是主旨，出处仅落在论证区域的选项应作为"出处有误"优先排除<br>4. 主旨应回到被论证支撑的那句观点 |
| 验证动作 | 将候选选项的核心内容与文段逐句对照：若该内容仅出现在论证区域（举例段、解释说明段、数据段），不出现在观点句中，确认出处有误应排除 |
| 不适用条件 | 并列结构中被后文论证支撑的方面可能是重点（并非所有论证都降低其重要性）；总分结构中分述部分可能承载主旨的展开，需结合具体行文结构判断 |
| 高频错因 | 把论证部分的具体内容（举例细节、解释说明中的关键词、具体数据）当成主旨，选了出处有误的选项；仅凭信号词判断论证而忽略了该句是否真正服务于前文观点 |
| confidence | high |
| 反向触发 | ①文段为并列结构且每段都含论证成分，此时论证区域本身可能是并列各方的载体，不能简单降级，应换用并列概括法；②判断为"被支撑的观点句"本身只是过渡句或旧话题，而论证区域引出了新话题并被后文展开，此时重点可能在论证引出的新方向而非旧观点；③选项核心同时涉及观点句关键词和论证区域关键词，需用回代法对比两者出处权重，不可仅凭"论证非主旨"就排除 |

> **使用边界**：本方法用于提供优先检查方向，不可单独据此作答；最终需回到题干关系、原文证据或选项条件完成验证。
