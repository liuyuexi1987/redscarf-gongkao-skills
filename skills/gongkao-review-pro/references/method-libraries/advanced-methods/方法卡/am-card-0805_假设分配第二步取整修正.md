# 方法卡：假设分配第二步取整修正

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 假设分配第二步取整修正 |
| 适用题型 | 资料分析——假设分配法的第二步操作 |
| 触发场景 | 假设分配第一步完成后有余数待分，需快速决定第二步给"增量"多少 |
| 步骤逻辑 | ① 对剩余量选择便于口算且接近实际增率的分数或百分数作锚点；② 实际增率高于锚点时向上修正，低于锚点时向下修正；③ 比较修正误差与选项间距，足以影响答案时继续计算，否则可停止 |
| 高频错因 | ① 搞反向上/向下方向（实际r大于参照率要向上取整）；② 余数小时仍细分小数点，拖慢速度 |
| confidence | medium |

## 补充说明

参照率是便于口算的锚点，向上或向下修正取决于实际增长率与锚点的大小关系。能否省略剩余修正取决于误差是否可能跨越选项，不能仅凭余数位数判断。

## 不适用条件

1. 假设分配第一步尚未完成，不存在需要修正的余数。
2. 剩余修正虽小但可能改变相邻选项判断时，不能省略。
3. 增率无法用简单锚点稳定近似时，应改用份数关系或精算。

## 反向触发

1. 假设分配第一步完成后有余数待分，且能找到便于口算的增率锚点。
2. 余数数量级足够，参照率估算可给出有意义的修正量。
3. 需要在第二步快速决定增量的分配量，缩短计算时间。
