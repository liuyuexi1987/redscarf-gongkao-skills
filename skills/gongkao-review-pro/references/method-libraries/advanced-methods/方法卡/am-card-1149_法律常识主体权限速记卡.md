# 方法卡：法律常识主体权限速记卡

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 法律常识主体权限速记卡 |
| 适用题型 | 常识判断——法律常识（宪法、行政法、民法、刑法） |
| 触发场景 | 用户做法律常识题，需要快速判断主体权限、程序、责任归属时 |
| 步骤逻辑 | ① 确定法律部门；② 定位主体和权限；③ 检查是否匹配题干描述；④ 不确定时标注需核验 |
| 高频错因 | 主体权限混淆、程序顺序错、刑事责任年龄/能力混淆、行政复议与行政诉讼混淆 |
| confidence | high |
| 不适用条件 | 1. 考查法条原文背诵、最新修法细节或具体司法解释原文时，本卡只能辅助排错，不能替代核验；2. 题目只考查抽象价值判断而不涉及主体、程序或责任性质时，不宜套本卡 |
| 反向触发 | 1. 非法律类常识题（政治、经济、科技等）应读对应领域卡；2. 纯考查公民义务、法律原则或概念记忆而不涉及主体权限、程序、责任区分时，应先回到题干具体考点 |

## 核心判断

法律常识题的核心是"谁有什么权力/权利，按什么程序，承担什么责任"。答题时先锁定主体，再查权限，最后验证程序。

## 使用流程

### 第一步：确定法律部门

| 题干关键词 | 法律部门 |
|-----------|---------|
| 宪法、国家机构、公民基本权利、根本制度 | 宪法 |
| 合同、物权、侵权、婚姻、继承、民事行为能力 | 民法 |
| 犯罪、刑罚、正当防卫、紧急避险、刑事责任 | 刑法 |
| 行政许可、行政处罚、行政复议、行政诉讼、国家赔偿 | 行政法 |
| 法的制定、法的效力、法的实施、法律关系 | 法理学 |

### 第二步：主体权限速查

#### 宪法主体权限

| 主体 | 核心权限/特征 | 易混点 |
|------|-------------|--------|
| 全国人大 | 最高立法权、修改宪法、监督宪法实施、选举国家主席 | 不是"制定"宪法，是"修改"宪法 |
| 全国人大常委会 | 解释宪法、监督宪法实施、制定和修改除基本法律以外的法律 | 不能修改宪法，只能解释 |
| 国务院 | 最高行政机关、制定行政法规 | 不能制定法律，只能制定行政法规 |
| 国家主席 | 国家元首、公布法律、任免国务院组成人员 | 是"公布"法律，不是"制定" |
| 中央军委 | 领导全国武装力量 | 不向人大报告工作（特殊） |
| 监察委 | 监察机关、独立行使监察权 | 不是司法机关 |
| 法院 | 审判机关 | 不是法律监督机关 |
| 检察院 | 法律监督机关 | 不是审判机关 |

#### 民法核心判断

| 概念 | 内容 | 易混点 |
|------|------|--------|
| 完全民事行为能力人 | 18周岁以上；16-18周岁以自己劳动收入为主要生活来源 | 16-18有例外 |
| 限制民事行为能力人 | 8-18周岁；不能完全辨认自己行为的成年人 | 8周岁是分界线 |
| 无民事行为能力人 | 不满8周岁；不能辨认自己行为 | 不满8不是限制，是无 |
| 法人 | 依法成立、有独立财产、能独立承担民事责任 | 法人不是"人"，是组织 |
| 诉讼时效 | 一般3年 | 不是2年（已修改） |

#### 刑法核心判断

| 概念 | 内容 | 易混点 |
|------|------|--------|
| 完全刑事责任 | 16周岁以上 | 不是18 |
| 相对刑事责任 | 14-16周岁，只对八种严重犯罪负责 | 只对故意杀人、故意伤害致人重伤或死亡、强奸、抢劫、贩毒、放火、爆炸、投放危险物质负责 |
| 主刑 | 管制、拘役、有期徒刑、无期徒刑、死刑 | 只能独立适用 |
| 附加刑 | 罚金、剥夺政治权利、没收财产、驱逐出境 | 可独立适用也可附加 |
| 正当防卫 | 针对正在进行的不法侵害 | 不能事后防卫 |
| 紧急避险 | 针对正在发生的危险，不得已损害较小利益 | 不能针对人（区别于正当防卫） |

#### 行政法核心判断

| 概念 | 内容 | 易混点 |
|------|------|--------|
| 行政复议 | 向上级行政机关申请，审查行政行为合法性/合理性 | 是"复议"不是"复审" |
| 行政诉讼 | 向法院起诉，主要审查合法性 | 法院主要审合法性，合理性有限 |
| 行政处罚 | 对违法行为的制裁（罚款、拘留、吊销许可证等） | 区别于行政强制 |
| 行政许可 | 申请→审查→批准 | 是"赋权"不是"限制" |
| 国家赔偿 | 行政赔偿+司法赔偿 | 赔偿≠补偿 |

### 第三步：程序责任性质判断

题干涉及处罚、许可、强制、复议、诉讼、犯罪、侵权、违约时，按以下维度区分责任性质：

| 区分维度 | 民事 | 行政 | 刑事 |
|----------|------|------|------|
| 触发 | 违约或侵权 | 违反行政管理秩序 | 触犯刑法 |
| 责任形式 | 赔偿、违约金、恢复原状 | 罚款、拘留、吊销许可、责令改正 | 主刑+附加刑 |
| 追究方式 | 当事人起诉 | 行政机关主动或依申请 | 公诉 |
| 关键检查 | 约定义务/权利受损/归责原则 | 行为阶段（事前准入/事中控制/事后追责） | 罪名/年龄/主体 |

高频混淆排查：

| 混淆点 | 正确区分 |
|--------|---------|
| 行政许可 vs 行政处罚 | 许可是事前准入；处罚是事后惩戒 |
| 行政强制措施 vs 强制执行 | 措施偏临时控制；执行偏迫使履行 |
| 行政拘留 vs 刑事拘留 | 行政拘留是行政处罚；刑事拘留是刑事强制措施 |
| 民事违约 vs 侵权 | 违约看约定义务；侵权看权利受损与归责 |
| 责令改正 vs 行政处罚 | 责令改正不机械等同于处罚，需核验具体法律定性 |
| 正当防卫 vs 紧急避险 | 防卫针对不法侵害人；避险针对第三方较小利益，看时间/对象/限度 |

### 第四步：验证匹配

- 题干问"谁有权"→对照主体权限表
- 题干问"按什么程序"→对照程序流程
- 题干问"承担什么责任"→对照责任类型
- 不确定时：排除明显错误选项，标注"需核验"

## 速记/排除规则

- "制定宪法"→错，应为"修改宪法"（全国人大）
- "国务院制定法律"→错，国务院制定行政法规
- "不满16周岁不承担刑事责任"→错，14-16对八种严重犯罪负责
- "行政拘留是刑罚"→错，行政拘留是行政处罚
- "正当防卫可以事后进行"→错，必须是正在进行的不法侵害
- "检察院是审判机关"→错，检察院是法律监督机关
- 涉及具体法条修订日期、最新司法解释的，标注"需以最新法律规定为准"

## 高频易混点

| 易混点 | 正确区分 | 常见误判 |
|--------|---------|---------|
| 全国人大 vs 全国人大常委会 | 人大修改宪法、制定基本法律；常委会解释宪法、制定其他法律 | 混淆二者的立法权限 |
| 行政拘留 vs 刑事拘留 | 行政拘留=行政处罚；刑事拘留=刑事强制措施 | 把行政拘留当刑罚 |
| 正当防卫 vs 紧急避险 | 正当防卫针对不法侵害人；紧急避险针对第三方较小利益 | 混淆适用对象 |
| 行政复议 vs 行政诉讼 | 复议找上级机关；诉讼找法院 | 混淆受理主体 |
| 法人 vs 法定代表人 | 法人=组织；法定代表人=代表组织的自然人 | 把法人当自然人 |
| 主刑 vs 附加刑 | 主刑只能独立适用；附加刑可独立可附加 | 混淆适用方式 |

## 使用边界

1. 本卡不是法律条文汇编，不能替代最新法律法规核验。
2. 民法典、刑法修正案等法律修订可能改变具体规定，涉及具体条文时提醒以最新法律文本为准。
3. 无法确认法律条文最新状态时，只能说"方法倾向/需核验"，不能硬判。
4. 法律速记只作辅助排除，不得编造法律条文。
