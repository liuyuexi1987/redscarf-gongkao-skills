# 方法卡：排列组合解题框架——先定名额再选取

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 排列组合解题框架——先定名额再选取 |
| 适用题型 | 排列组合基础题 |
| 触发场景 | 面对排列组合题目不知如何下手 |
| 步骤逻辑 | 1. 先确定各个组/人分别需要从库中挑几个东西（定名额）；2. 再到对应的库中分别进行挑选；3. 每组的挑选方式确定后，用乘法原理求总方案；4. 不同组之间用加法原理汇总 |
| 高频错因 | 不区分"分类"和"分步"；不明确"名额"就直接计算 |
| confidence | high |

## 补充说明

排列组合入门门槛较高但上限很低，一旦入门做题会比较轻松

## 不适用条件

1. 题目本身已明确分组方案与名额，无需再"定名额"，直接计算即可。
2. 涉及约束条件复杂的排列（如多人相邻/不相邻、特定位置限制），需配合捆绑插空法。
3. 涉及可重复选取（放回抽样）或同元素去重，需使用对应特殊公式而非本框架。

## 反向触发

1. 当题目包含相邻、不相邻、定距等位置约束时，应换用捆绑法或插空法，本框架不足以覆盖。
2. 当题目为分组分配且各组有差异（如有标签的组），应核验是否需要除序，避免重复计数。
3. 当题目本质是组合而非排列时，应补充顺序性判断，否则可能误用排列公式。
