# 方法卡：替代比较法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 替代比较法 |
| 适用题型 | 比较增速大小（给现期和增量） |
| 触发场景 | 给出现期值和增长率对应的增量，需要比较多个项目的增速排序 |
| 步骤逻辑 | 1. 证明：增速 = 增量/基期，基期 = 现期 - 增量；2. 分子分母同除增量 → 比较 X/基期 等价于比较 X/现期（排序不变）；3. 直接用 增量/现期 替代 增量/基期 进行分数大小比较，省去算基期 |
| 高频错因 | 不知道可以用增量/现期替代，仍老老实实算基期再除 |
| confidence | medium |

## 补充说明

替代比较法的数学依据：比较 增量/基期 时，由于基期 = 现期 - 增量，分子分母同除增量后，比较 增量/基期 等价于比较 增量/现期（排序不变）。因此直接用 增量/现期 进行排序即可，省去了逐一算基期的步骤。此法特别适合题目给出多个项目的"现期值+增量"、要求增速排序的场景。

## 不适用条件

- 增量为负值（即下降）时，替代比较的符号方向需额外判断，容易出错
- 增量与现期量级差异极大时，直接比 增量/现期 的精度可能不如先算基期再比
- 题目要求精确求出增速值而非仅排序

## 反向触发

- 当 增量/现期 的比值非常接近、排序难以肉眼判断时，应切换为精确计算基期再比
- 当有增量为负（下降）的项目混在其中时，需先区分增长/下降再分别排序
- 当题目同时要求增速排序和具体增速值时，替代法只解决排序，具体值仍需算基期
