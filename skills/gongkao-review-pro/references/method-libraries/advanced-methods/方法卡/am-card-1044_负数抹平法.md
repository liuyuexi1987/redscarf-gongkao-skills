# 方法卡：负数抹平法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 负数抹平法 |
| 适用题型 | 数量关系——数字推理 |
| 触发场景 | 数字推理数列中出现负数 |
| 步骤逻辑 | ① 数列有负数→先做加法抹平（每个数加上一个固定值使所有数变正）；② 抹平后再做多级数列运算（差/商）；③ 注意正负正负周期数列（如-1, 2, -3, 4...） |
| 高频错因 | ① 负数直接做差→差值规律不明显；② 不抹平就尝试其他运算→找不到规律 |
| confidence | high |

## 补充说明
负数是数字推理的常见干扰。先抹平（加一个常数使所有数变正），再用常规方法做。注意正负交替出现可能是周期数列。

## 不适用条件
- 数列中只有1个负数且绝对值很小（可能是计算误差或特殊规律的一部分）
- 正负交替有明显周期规律（直接用周期法，不抹平）
- 抹平后数列仍无规律（应换思路，如递推或机械划分）

## 反向触发
- 如果数列全为正数，不使用负数抹平法
- 如果负数出现在等差/等比数列的正常延伸中（如等差数列穿过零点），直接用原规律
