# 方法卡：星期几连推跨月分析

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 星期几连推跨月分析 |
| 适用题型 | 数量关系——日期星期、跨月周期 |
| 触发场景 | 相邻月份的活动次数或零散天数共同约束星期，需要跨月合并分析 |
| 步骤逻辑 | 1. 每月至少4周 = 至少12次活动（每周3次）；2. 多出的次数对应多出的天数（月末/月初零散天）；3. 将相邻两月的零散天连起来分析：9月多2天 + 10月多3天 = 连续5天；4. 在这5天中安排"2次活动"，只有两种可能的星期组合；5. 排除不符合的组合，确定某天的星期，再用"先粗算后修正"推12月31日 |
| 高频错因 | 不把相邻月的零散天连起来看，而是分开分析推星期时忘记"先粗算后修正"三步法 |
| confidence | medium |
| 不适用条件 | 题目只涉及单月内的星期推算，无需跨月合并；题目直接给出两个日期间的完整天数间隔，可直接用总天数取余 |
| 反向触发 | 跨月涉及闰年二月时，检查2月是28天还是29天；合并零散天后推出的星期与粗算修正法不一致，回溯检查零散天合并是否正确 |

## 补充说明

关键技巧是把9月末和10月初的零散天合并为连续5天分析。这样星期序列是连续的，容易判断。确定起始星期后，用粗算修正法推到年末即可。
