# 方法卡：间隔增长率公式

| 字段 | 内容 |
|------|------|
| 方法名 | 间隔增长率公式 |
| 适用题型 | 资料分析-增长率（时间间隔≥2年） |
| 触发场景 | 题目时间与材料时间间隔两年，如"2022年与2020年相比"，求间隔增长率或间隔基期值 |
| 步骤逻辑 | 1. 识别时间间隔，确定考间隔增长率 → 2. 找今年增速R1和去年增速R2 → 3. 代入公式：间隔增长率 = R1 + R2 + R1×R2 → 4. 乘积项可粗略估算（如30%×40%≈12%） |
| 高频错因 | 忘记加R1×R2交叉项；误把间隔题当年均增长处理 |
| confidence | high |

补充说明：选项差距大时，R1×R2项可粗略估算（如R1=-38%、R2=-31%，乘积看成约12%即可）。两年平均增长率也可转化为间隔增长率情形（令R1=R2=平均增速）。

## 不适用条件

- 时间间隔仅一年（直接用单期增长率公式）
- 间隔超过两年（需用连乘或其他方法）
- 题目仅给出单期增速且无法推断另一期增速

## 反向触发

- 当R1×R2方向与RA-RB方向矛盾时，应重新检查是否混淆了两年增速的对应关系
- 当忘记R1×R2项导致结果与选项不匹配时，应补上交叉项再验证
- 当题目问"年均增长率"时，不应直接套间隔增长率公式，应区分两种问法后选择正确公式
