# 方法卡：数列变化幅度判断法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 数列变化幅度判断法 |
| 适用题型 | 数量关系——数字推理（方法选择） |
| 触发场景 | 数字推理题，需要判断用什么方法 |
| 步骤逻辑 | ① 一位数→两位数变化不大→优先加减法（等差/多级数列）；② 有明显倍数关系→优先做商（等比数列）；③ 数字忽大忽小→尝试递推；④ 有分数→尝试反约分 |
| 高频错因 | ① 变化幅度小却尝试做商→浪费时间；② 有明显倍数关系却做差→找不到规律 |
| confidence | high |

## 补充说明
数字推理的方法选择取决于数列变化幅度。幅度小→加减法；幅度大且有倍数关系→做商；忽大忽小→递推；有负数→先抹平。1.5倍是容易被忽略的等比规律。

## 不适用条件
- 已知项太少、存在多种同样合理的变化规律时，仅凭变化幅度不能定型
- 数列包含分数/小数混合，幅度判断失准
- 题目已明确指定用某种方法（如"用递推法求解"）

## 反向触发
- 如果数列全是多位数（两位起步），优先考虑机械划分而非幅度判断
- 如果数列出现明显周期特征，直接尝试周期规律
