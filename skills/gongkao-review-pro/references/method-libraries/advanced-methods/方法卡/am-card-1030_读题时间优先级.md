# 方法卡：读题时间优先级

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 读题时间优先级 |
| 适用题型 | 资料分析——审题 |
| 触发场景 | 资料分析读材料和读题目时 |
| 步骤逻辑 | ① 首先看时间（最重要！）；② "末"的数据要往前推一年（如"十三五末"=2020年数据，但要算的是2020年不是2025年）；③ "下半年"不能算全年；④ "月均"要除以对应月数；⑤ 时间看错→后面全白费 |
| 高频错因 | ① 不看时间直接找数据→找错年份；② "末"和"期间"混淆→数据对应错误；③ "月均"当成"年均"→差12倍 |
| confidence | high |

## 补充说明
读题首先看时间。资料分析中时间看错会导致后续数据全部对应错误，审题的细致程度比计算能力更关键。

## 不适用条件

1. 题目未涉及时间维度（如纯概念判断）时。
2. 材料时间单一且无歧义时。
3. 题目明确给定计算周期时。

## 反向触发

1. 当材料含多个时间节点时，应补充核验每个数据对应的年份。
2. 当出现"末""期间""下半年""月均"等时间表述时，应换用时间换算核对。
3. 当选项差距极小且涉及时间换算时，应补充精算核验。
