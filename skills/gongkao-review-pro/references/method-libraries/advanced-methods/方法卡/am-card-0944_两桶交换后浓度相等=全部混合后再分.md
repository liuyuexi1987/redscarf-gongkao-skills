# 方法卡：两桶交换后浓度相等=全部混合后再分

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 两桶交换后浓度相等=全部混合后再分 |
| 适用题型 | 两桶溶液相互交换一定量后浓度相等，求交换量 |
| 触发场景 | 题目说"交换X千克后两桶浓度相等" |
| 步骤逻辑 | 1. 把两桶全部倒入一个大桶混合，浓度自然相等；2. 大桶中任意一份都保持原来的质量比（M:N）；3. 从大桶中分回各桶时，每桶中新增部分占该桶的比例 = 对方质量 ÷ 总质量；4. 例如甲90kg乙60kg，交换量 = 90×(60/150) = 36kg |
| 高频错因 | 列复杂方程求解，计算量大易出错 |
| confidence | high |

## 不适用条件
- 两桶交换后浓度不相等时，不能直接套用全部混合后再分的思路
- 交换过程不满足等量转移，或交换后浓度并不相等时，不能直接使用“全部混合后再分”的等效关系
- 题目为单桶蒸发/加水问题或多桶混合问题（非两桶交换）时

## 反向触发
- 看到"交换X千克后两桶浓度相等"时，立即想到全部混合后再分的等价思路
- 两桶质量比为简单整数比（如3:2、2:1）时，交换量计算更简便

## 补充说明
此方法绕过复杂方程，直接利用混合后各组分比例不变的性质
