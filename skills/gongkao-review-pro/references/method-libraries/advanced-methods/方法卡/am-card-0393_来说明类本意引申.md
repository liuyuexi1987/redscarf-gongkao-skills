# 方法卡：来说明类本意引申

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 来说明类本意引申 |
| 适用题型 | 中心理解题（"来说明"类） |
| 触发场景 | 题干问"某某用来说明什么"，选项是对词语的解释 |
| 步骤逻辑 | 1. "来说明"不能停留在词语的字面本意（本意不能选）；2. 要在本意基础上适度引申，看它在文段中起什么论证作用；3. 注意它是正面还是反面例证（反面例证不能选正面含义的选项） |
| 高频错因 | 直接选了词语的字面意思（本意）忽略了词语在文段中的感情色彩（反面例证选了正面选项） |
| confidence | high |

## 不适用条件

- 选项中对词语的解释直接符合文段语境，无需引申
- 词语在文段中作为并列成分出现（平行举例），而非用来"论证"某一观点
- 文段是纯叙述性内容，没有论证结构（词语不是例证，只是描述）

## 反向触发

- 若选项是词语的字面意思且与文段主题高度一致，可能不需要引申，应回文确认词语在文段中的实际功能
- 若词语在文段中出现多次且含义有变化（有时正面、有时反面），不能套用单一的引申方向，应回文定位每次出现的具体语境
- 若选项是引申后的含义但引申过度、偏离文段实际论点，应选择引申幅度较小且更贴近文段论证作用的选项
