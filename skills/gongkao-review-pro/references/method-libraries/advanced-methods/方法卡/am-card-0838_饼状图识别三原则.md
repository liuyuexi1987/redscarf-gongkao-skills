# 方法卡：饼状图识别三原则

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 饼状图识别三原则 |
| 适用题型 | 资料分析——饼状图（扇形图）相关选择题，需通过图形判断各部分占比或排列顺序 |
| 触发场景 | 材料为饼状图/扇形图，选项涉及各部分占比大小、排列顺序或占比数值判断 |
| 步骤逻辑 | ① 抓特殊数字：先找25%（四分之一圆）、50%（半圆）、75%（四分之三圆）等特殊角度对应的扇形，快速定位占比关系；② 看两部分之间的比值或倍数关系：如果A是B的二倍，面积上要有体现；也可看两部分之和与25%的关系；③ 利用软件生成规则：从12点钟方向顺时针排列各部分（计算机出题时适用），可据此判断选项中各部分的对应位置 |
| 高频错因 | ① 忽略饼状图中特殊角度（25%/50%/75%）的快速定位作用；② 手绘饼状图不遵守顺时针排列规则时仍套用规则三导致排错；③ 把两部分之和与25%/50%的关系当作独立占比 |
| confidence | medium |
| 不适用条件 | 材料为柱状图、折线图或表格而非饼状图；题目不要求判断占比大小或排列顺序，而是直接读取标注的数值 |
| 反向触发 | 题目考查的是具体数值的计算（如部分值=整体值×占比），而非通过图形观察判断占比关系；饼状图已有明确的数值标注，无需图形识别技巧 |

## 补充说明

原则三（顺时针排列）仅适用于计算机/软件生成的饼状图，手绘饼状图不一定遵守此规则。考试中饼状图题常结合"根据整体求部分"出题：假设某子部分的情况和整体一样，再求该子部分的相关数据。此时可用整体的增速或占比直接代入该子部分。此卡覆盖的三个小知识点是本期比重模块下饼状图子考点的快速识别方法。
