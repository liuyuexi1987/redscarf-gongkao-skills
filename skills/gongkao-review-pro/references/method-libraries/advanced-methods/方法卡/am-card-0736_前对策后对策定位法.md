# 方法卡：前对策后对策定位法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 前对策后对策定位法 |
| 适用题型 | 中心理解、标题拟定 |
| 触发场景 | 文段为说理类，需要快速定位对策/观点句在文段中的位置 |
| 步骤逻辑 | 1. 先读首句抓主题词（首句常含全文话题词，决定选项范围）；2. 检查第二句是否为前对策：开门见山直接给观点/对策，后文为解释论证；3. 若非前对策，则盯尾句是否为后对策：先引话题、分析论证，尾句给出观点/对策；4. 对策句确认后，找对策核心（多数在必要条件上：前提/关键/基础/必不可少/离不开）；5. 选项必须同时包含主题词+对策核心 |
| 高频错因 | 只盯尾句忽略前对策结构；找到对策句但抓不住对策核心（必要条件部分）；选项缺主题词 |
| confidence | medium |

## 补充说明

- 前对策与后对策的判别顺序：先看第二句是否为前对策（开门见山给观点/对策，后文为解释论证），若不是，再看尾句是否为后对策（先引话题、分析论证，尾句给观点/对策）
- 对策核心多数在必要条件上：前提/关键/基础/必不可少/离不开
- 正确选项必须同时包含主题词+对策核心，二者缺一不可

## 不适用条件

- 文段为并列结构（多对策并列、无明显主次）时，前后对策定位法可能失效，应换用并列结构分析
- 文段为科普介绍类（无作者主观态度/对策）时，不应使用对策定位法

## 反向触发

- 当首句和尾句都看似对策但内容不一致时，应换用整体结构分析判断主次，而非二选一
- 当选项中没有同时包含主题词+对策核心的选项时，应重新核验对策核心定位是否准确
