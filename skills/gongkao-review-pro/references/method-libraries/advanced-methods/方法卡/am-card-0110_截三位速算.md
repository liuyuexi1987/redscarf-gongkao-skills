# 方法卡：截三位速算

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 截三位速算 |
| 适用题型 | 资料分析·多位数加减比较 |
| 触发场景 | 多位数做差、除法取大数或选项差距较大的比较题，需要快速估算或比较大小时 |
| 步骤逻辑 | 1. 将大数截取前三位有效数字 2. 在截取后的数字上进行加减运算 3. 用截取后的结果进行大小比较 |
| 高频错因 | 截取位数不一致导致比较失误；对精度要求高的题目不宜使用 |
| confidence | high |

## 补充说明

截三位速算适用于多位数加减比较场景，将千位以上大数截取前三位后快速做差比较。该方法适用于选项差距较大的比较类题目，配合"大大则大"的逻辑可以进一步减少计算量。

## 不适用条件
1. 当截断误差可能跨越选项时，截三位的精度不足，应保留更多有效位
2. 当数据涉及百分比或小数而非整数大小比较时，截三位法不直接适用

## 反向触发
1. 当截三位后两个数仍非常接近难以判断时，应恢复更多位数或改用精确做差
2. 当估算误差可能跨越选项或改变结论时改用精算
