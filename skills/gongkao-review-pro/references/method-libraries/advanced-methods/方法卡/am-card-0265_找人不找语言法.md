# 方法卡：找人不找语言法（逆向等价思维）

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 找人不找语言法（逆向等价思维） |
| 适用题型 | 条件匹配/多人多语言共通题 |
| 触发场景 | 问"三个人都会说的语言是什么"；条件给出的是谁会说什么、谁不会说什么 |
| 步骤逻辑 | 1. 问法问的是语言，但直接找语言很难（需逐个尝试）；2. 逆向思考：语言是人说的，找到"哪三个人有共语"即可用排除法确定语言；3. 利用条件中"甲丙需要翻译"→甲丙无共语→三人不能同时含甲丙→只剩甲乙丁或乙丙丁；4. 条件"乙丙丁谈不到一起"→排除乙丙丁→三人只能是甲乙丁；5. 用"乙不会说英语""丁不会说日语"等条件排除语言选项 |
| 高频错因 | 被问法带偏，执着于找语言本身，画表逐个试，浪费大量时间 |
| confidence | high |

## 不适用条件

1. 条件数量极少，直接枚举即可确定答案，无需逆向排除
2. 问法是"谁会说什么语言"（求单一归属）而非"三人共通的语言"
3. 只涉及两人之间的语言匹配，不存在多人多语言交叉

## 反向触发

1. 条件中已直接给出答案所需的语言组合，无需逆向推理
2. 题目只涉及两人间的关系判断，不需要找三人共语
3. 问法是排序或位置推理，与语言匹配无关
