# 方法卡：逻辑型论证搭桥拆桥法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 逻辑型论证搭桥拆桥法 |
| 适用题型 | 有论据+论点的加强削弱题（"论据…因此论点…""…所以…"） |
| 触发场景 | 题干有明确的论据→论点推导关系，问"最能加强/削弱" |
| 步骤逻辑 | 1. 找论点和论据，判断论据能否推出论点（重点在于"是否可推"）；2. 识别暗含前提：论据A推到论点C，中间缺了B→C的前提；3. 加强=搭桥：补上暗含前提（如"热量高→变胖"需要"摄入热量高是变胖主因"）；4. 削弱=拆桥：否定暗含前提，或攻击论据本身（如调查样本不具代表性） |
| 高频错因 | 在逻辑型论证中找"他因"——他因只适用于因果型论证（由果推因），不适用于由因推果的逻辑型论证 |
| confidence | high |

## 补充说明

逻辑型论证重在攻击论据或前提，不按他因题处理。区分方法：由因推果=逻辑型论证（攻击论据/前提），由果推因=因果型论证（可用他因）。

## 不适用条件

- 题干是由果推因的因果型论证（"B发生了，所以是A导致的"），此时应优先考虑他因削弱或因果倒置，而非搭桥拆桥。
- 题目考查的是论证谬误的类型识别（如强加因果、以偏概全），而非加强削弱推导关系。

## 反向触发

- 题干有明确的"论据→论点"推导关系，且问的是"最能加强/削弱"。
- 论据和论点之间存在明显或隐含的前提缺口（需要搭桥补前提或拆桥否定前提）。
