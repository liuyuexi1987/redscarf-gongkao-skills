# 方法卡：不能同时入选翻译为非A或非B

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 不能同时入选翻译为非A或非B |
| 适用题型 | 排列组合/分析推理（判断推理） |
| 触发场景 | 题干出现"不能同时入选""至多一个入选""至少一个不能入选"等表述，需要翻译为逻辑语言以便推理 |
| 步骤逻辑 | 1. 识别自然语言约束："A和B不能同时入选"="A和B至多一个入选"="A和B至少一个不能入选"，三者等价；2. 翻译为逻辑语言：非A或非B（符号化为 ¬A ∨ ¬B）；3. 明确"非A或非B"包含三种可能：A不选B选、A选B不选、AB都不选——只有"AB都选"不成立；4. 避免将"非A或非B"误写为"非A且非B"（后者表示都不选，范围过窄） |
| 验证动作 | 列举所有 A/B 入选/不入选的组合，检查不违反约束的组合是否恰好为三种；若只有两种或组合数不对，说明翻译有误 |
| 不适用条件 | 约束为"至少入选一个"时，翻译为"A或B"而非"非A或非B"；注意区分"至多一个"和"至少一个"的翻译方向 |
| 高频错因 | 不会把日常表述翻译为逻辑语言，导致推理链断裂；误以为"不能同时入选"等价于"恰好一个入选"，遗漏"都不入选"的情况 |
| confidence | high |
| 反向触发 | 约束实际为"恰好一个入选"（即一选一不选）而非"至多一个"时，需在"非A或非B"基础上额外排除"都不选"的情况，否则会遗漏或多余选项；将约束翻译后与题目其他条件组合推理出现矛盾时，应回溯检查翻译方向是否弄反了"至多"和"至少 |
