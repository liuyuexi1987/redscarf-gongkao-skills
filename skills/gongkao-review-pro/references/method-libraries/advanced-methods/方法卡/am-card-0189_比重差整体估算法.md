# 方法卡：比重差-整体估算法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 比重差-整体估算法 |
| 适用题型 | 资料分析——两期比重差（问比重比上年高了/低了几个百分点） |
| 触发场景 | 选项差距大，不需要精算比重差具体值，只需判断方向或粗略范围 |
| 步骤逻辑 | ① 判定题型：A占B的比重与上年比→两期比重差；② 找A、B及各自增速R1、R2；③ 先抄分子增速差 R1-R2（负值直接带符号）；④ 对 A/(B×(1+R1)) 做整体估算：A和B取近似值，1+R1粗略取值；⑤ 选项差距大时大胆估算到"几分之一到几分之一之间"即可锁定答案 |
| 高频错因 | ① 选项差距大却精算浪费时间；② 比重差公式中忘记带符号（R1-R2为负时比重下降）；③ R1非常小时直接忽略分子位置导致方向判断错误 |
| confidence | high |

## 不适用条件

1. 选项差距非常小，需要精确计算比重差具体值
2. 材料中无法找到部分和总体各自的增速数据
3. 题目要求精确求出比重差而非判断方向或粗略范围

## 反向触发

- 题干明确要求计算两期比重差，且选项差距较大，估算即可锁定

## 补充说明

词义辨析强调比重差题应尽量不动笔，通过整体估算动作快速判断。估算的核心是：A/B的比值落在哪个简单分数附近（1/2、1/3等），再乘以|R1-R2|即可判断结果量级。选项差距小时可用R1-R2直接锁定。
