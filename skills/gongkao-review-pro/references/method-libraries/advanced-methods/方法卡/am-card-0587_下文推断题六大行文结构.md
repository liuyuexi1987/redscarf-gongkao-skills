# 方法卡：下文推断题六大行文结构

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 下文推断题六大行文结构 |
| 适用题型 | 言语理解——下文推断题（"接下来文章最可能讲述的是"） |
| 触发场景 | 问法为"接下来最可能讲什么"，需根据尾句或全文结构推断下文内容 |
| 步骤逻辑 | ① 通读全文并定位尾句话题；② 判断尾句是在引入新话题、提出问题、给出宏观方向、形成时间对比、留下并列项，还是发生转折；③ 预判紧接着最可能展开的内容；④ 排除前文已充分论述、跨越中间环节或偏离尾句话题的选项 |
| 高频错因 | 只看尾句不看全文结构，忽略了结构(5)的并列未展开情况；选了已被前文论述过的内容（重复项）；选了转折前的内容 |
| confidence | high |
| 不适用条件 | 非下文推断问法；尾句只是总结收束，没有留下待展开内容；选项均与尾句缺少直接衔接时，不宜机械套用结构模板 |
| 反向触发 | 尾句提出的问题已在前文完成分析时，下一步更可能转向解决或具体展开，但仍需核对选项与尾句的衔接；全文存在尚未展开的并列项时，应优先检查该并列项，而不能只看最后一个词 |
