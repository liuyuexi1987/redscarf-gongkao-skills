# 方法卡：四要素转换

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 四要素转换 |
| 适用题型 | 资料分析——基期/现期/增量/增速·互相求解 |
| 触发场景 | 题目给出四要素中的任意两个，要求求第三个；或材料给出限期+增速求基期、给出限期+增量求增速等 |
| 步骤逻辑 | ① 明确题目问的是四要素（基期、现期、增量、增速）中的哪一个；② 找到材料中已给出的另外两个要素；③ 套用对应公式：基期=现期÷(1+增速)、基期=现期-增量、增速=增量÷基期、增量=基期×增速、现期=基期×(1+增速)；④ 注意"同比"指与去年比，"环比"指与上一个时间段比 |
| 高频错因 | ① 增量（绝对量，加减关系）和增速（比例，乘除关系）混淆；② 同比和环比混用；③ 下降时忘记在基期公式中代入负增长率；④ 把“百分点”误当“百分比” |
| confidence | high |

## 补充说明

资料分析的四个核心要素：基期（以前的值）、现期（现在的值）、增量（现期-基期，绝对量）、增速（增量÷基期，比例）。增量是加减关系，增速是乘除关系。百分号(%)表示比例/增速，百分点表示量的差值（用于增速的增减）。"降幅扩大7.22个百分点"意思是增速的绝对值增加了7.22个百分点，是一个加减关系。

## 不适用条件

- 题目涉及"翻番"（倍数关系）时，需用倍数公式而非四要素公式
- 增速为负且幅度很大（如-50%以上）时，基期=现期÷(1+R)中R需带负号，计算容易出错，建议验算
- 材料给出的是指数（如CPI指数、价格指数）而非直接增速时，需先从指数推导增速再套公式

## 反向触发

- 看到"基期是多少""求去年""求前年"且给了现期和增速/增量 → 用本方法
- 看到"增速是多少""增长率"且给了现期和增量 → 用本方法
- 看到"增长了多少"（绝对量）且给了基期和增速 → 用本方法
- 看到"翻了X番" → 不用本方法，用倍数关系（2的X次方）
