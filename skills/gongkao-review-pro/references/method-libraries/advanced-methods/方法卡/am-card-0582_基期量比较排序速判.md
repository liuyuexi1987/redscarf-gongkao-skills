# 方法卡：基期量比较排序速判

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 基期量比较排序速判 |
| 适用题型 | 资料分析——多主体基期量从高到低排序 |
| 触发场景 | 给出多个主体的现期占比和同比增速，要求按基期量排序 |
| 步骤逻辑 | ① 占比即反映量，占比越大→现期量越大；② 若某主体现期量最大且同比增速为负（下降），则其基期量一定更大（去年比今年还大）→直接锁定为最大；③ 若某主体现期量最小且增速最高，则基期量一定最小→排末位；④ 利用上述结论快速排除C、D选项；⑤ 剩余A、B只需简单计算一个基期量做PK即可 |
| 高频错因 | 忽略"同比下降→基期更大"这个反向关系；把占比和增速的含义搞混；不需要四个都算，只需找到确定的最大/最小即可排除 |
| confidence | high |

## 补充说明

此类题核心逻辑是：现期量大+增速下降→基期量一定比现期量更大。这可以快速锁定最大值，配合排除法大幅减少计算量。排序题只需确定首尾和中间两两PK即可，能看出来的尽量不算。

## 不适用条件

- 各主体现期量接近且增速方向相同（同为正或同为负）时，无法靠"增速下降→基期更大"快速锁定首尾，需精算。
- 题目要求的是现期量排序而非基期量排序时，本方法不适用。

## 反向触发

- 当多个主体增速均为正且接近时，应换用基期量=现期量÷(1+增速)逐一计算比较。
- 当选项中排序差异仅在中间两位时，需补充精算中间主体的基期量做PK。
