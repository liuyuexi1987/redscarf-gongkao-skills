# 方法卡：类比朴素理解原则

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 类比朴素理解原则 |
| 适用题型 | 判断推理——类比推理 |
| 触发场景 | 类比推理题纠结时 |
| 步骤逻辑 | ① 不要钻牛角尖想极端情况；② 命题人思路很简单→朴素理解即可；③ 有确定的关系选项就不选不确定的；④ 不确定时优选确定项，即使确定项不够完美 |
| 高频错因 | ① 想太多极端情况→选了牵强的选项；② 有确定项不选→选了不确定的"更好"项 |
| confidence | high |

## 不适用条件
- 题目要求严格逻辑等价关系而非朴素对应时
- 选项中有两个都"确定"但关系类型不同时，需用其他方法区分
- 类比推理中涉及多层嵌套关系（如A:B:C:D）时，朴素理解可能不够

## 反向触发
- 题目明确要求找"最相似""最一致"的严格逻辑关系时，应先分析关系类型再择优
- 所有选项关系都很明确、没有纠结项时，不需要此方法
