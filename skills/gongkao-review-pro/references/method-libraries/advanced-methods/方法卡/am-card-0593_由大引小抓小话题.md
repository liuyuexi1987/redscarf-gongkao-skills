# 方法卡：由大引小抓小话题

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 由大引小抓小话题 |
| 适用题型 | 言语理解——中心理解题 |
| 触发场景 | 文段开头讲一个大话题（如"传记"），后文用"正是""然而"等引导语将话题缩小到具体子话题（如"中国古典传记"），且尾句用强调词或指代词总结 |
| 步骤逻辑 | ① 识别文段是否"由大引小"：开头话题范围大，后面通过强调词/转折缩小到具体话题；② 小话题才是文段重点论述的对象，选项主题词应选小话题而非大话题；③ 区分"由大引小"和"举例"：由大引小的尾句有强调词（如"正是"），且小话题是文段最终的落脚点 |
| 高频错因 | 选了大话题的选项（出处有误/背景段）；误把"由大引小"当成"举例子"，导致选错主题词；选项用"最为"等绝对化表述（如"最为生动的记载"） |
| confidence | high |

## 补充说明

由大引小识别关键：文段从大范围话题切入，通过强调词（如"正是"）或转折词缩小到具体子话题，尾句对子话题的强调是文段最终落脚点。选项主题词应选小话题而非大话题。

区分"由大引小"与"举例子"：举例子通常没有强调词放在尾句，也不会用"正是"等词对例子进行总结性强调；由大引小的尾句则用强调词锁定小话题为核心论述对象。

警惕绝对化表述：选项若在大话题上叠加"最为""最"等绝对化词语，往往同时具备主题词错误和表述绝对两个缺陷。

## 不适用条件

- 文段通篇围绕同一话题展开、无明显范围收束过程时不适用此法。
- 文段结构为"总—分"且分述部分为并列举例（非话题收束）时不适用此法。
- 选项主题词均与文段话题一致、无大小之分时不适用此法。

## 反向触发

- 当难以判断尾句是"总结小话题"还是"举例"时，应换用"主题词出现频次+尾句指代词回指"双线索核验。
- 当选项同时出现大小话题且均无绝对化表述时，应回归文段强调词位置判断重点所在。
- 当文段无明确强调词时，应补充用转折词/指代词定位重点句，再判断主题词归属。
