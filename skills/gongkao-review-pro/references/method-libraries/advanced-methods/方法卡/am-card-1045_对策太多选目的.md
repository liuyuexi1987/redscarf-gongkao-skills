# 方法卡：对策太多选目的

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 对策太多选目的 |
| 适用题型 | 言语理解——中心理解（对策式文段） |
| 触发场景 | 文段后半部分有一大堆具体对策，无法浓缩成一句话 |
| 步骤逻辑 | ① 识别后面是对策群（多个逗号分隔的小对策）；② 不要试图把所有对策概括→往前找目的/问题；③ 目的/问题=主旨→选目的式选项；④ 如果对策太琐碎→只能往大了选 |
| 高频错因 | ① 试图概括一堆对策→概括不准确→选了以偏概全的选项；② 选了对策中的一个小点→忽略其他 |
| confidence | high |

## 补充说明
对策群是中心理解的高频陷阱。当对策太琐碎无法浓缩时，往上找目的或问题才是正解。

## 不适用条件
- 文段对策可以被准确概括时，优先选择覆盖全部对策的概括项
- 文段是"提出问题—分析原因"结构，无对策
- 题目要求选"接下来最可能讲述的内容"（推下文题）

## 反向触发
- 如果对策数量较少且能够被准确概括，应优先概括对策本身，不必跳到更上位的目的
- 如果对策之间有明确的递进或因果关系，应概括对策本身而非跳到目的
