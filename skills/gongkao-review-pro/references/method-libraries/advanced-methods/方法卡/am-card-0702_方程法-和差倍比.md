# 方法卡：方程法-和差倍比

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 方程法-和差倍比 |
| 适用题型 | 数量关系-和差倍比问题、基础方程应用题 |
| 触发场景 | 题目给出若干量之间的和、差、倍、比关系，存在明显的等式条件 |
| 步骤逻辑 | 1. 找等式关系（和、差、积、商的条件）；2. 设未知数（优先设与多个量都有关联的那个）；3. 用未知数把其他量都表示出来；4. 代入等式关系列方程、解方程 |
| 高频错因 | 等式关系找漏；未知数设得不好导致后续计算麻烦；求差时顺序与题干不一致导致正负号错误 |
| confidence | medium |

## 补充说明

方程法是和差倍比问题的核心方法，具有普适性和稳定性。相比依赖特殊技巧，方程法在考场上更稳妥可靠。求差时注意顺序：题干说"甲比乙"就用"甲减乙"，顺序与题干保持一致可避免正负号错误。

## 不适用条件

- 题目无明显等量关系（无法列方程）。
- 题目数据过大且选项差距明显（可直接估算更快）。

## 反向触发

- 当方程中未知数多于方程个数时，应换用不定方程解法（倍数法/奇偶性/尾数法）。
- 当题目含小数/分数系数时，需配合"巧设整除未知数"方法简化计算。
