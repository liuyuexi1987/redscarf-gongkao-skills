# 方法卡：三者并列推断法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 三者并列推断法 |
| 适用题型 | 逻辑填空——并列结构 |
| 触发场景 | 三个词并列，中间一个是空格（如"捕捉、___、弘扬"） |
| 步骤逻辑 | ① 看已知的两个词的逻辑发展顺序；② 根据顺序推断中间空应该填什么；③ 如"捕捉→激活→弘扬"，中间是"激活"（从抓取到传播的中间步骤） |
| 高频错因 | ① 不看前后词的逻辑顺序→随便选一个近义词；② 三个并列词的性质（动作/状态/结果）要一致 |
| confidence | high |

## 补充说明
## 不适用条件
- 并列项少于三个或空格不在中间位置时，本卡不适用
- 三个并列项之间无明确逻辑发展顺序时，推断依据不足
- 并列项为同类近义词（无递进/先后关系）时，应换用程度或搭配分析

## 反向触发
- 若题目只有两个并列项，不使用本卡
- 若三个并列项是独立列举（无逻辑先后），先排除再决定方法
