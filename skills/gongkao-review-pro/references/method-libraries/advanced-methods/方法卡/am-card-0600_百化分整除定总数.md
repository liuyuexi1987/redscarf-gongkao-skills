# 方法卡：百化分+整除特性确定不定数量

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 百化分+整除特性确定不定数量 |
| 适用题型 | 数量关系 |
| 触发场景 | 题目给出百分比形式的命中率/占比，且数量为整数、范围有限（如"不到100"） |
| 步骤逻辑 | 1. 百分化分数：62.5%→5/8，44.4%→4/9，6%→3/50；2. 化为最简分数后，分母即为总数的倍数（如50的倍数）；3. 结合范围约束唯一确定总数（如不到100→只能是50）；4. 确定总数后，用盐水法或直接计算分配各部分；5. 最后代入验算 |
| 高频错因 | 百分化分数不化到最简导致倍数判断错误；用6%→6/100→100的倍数（错，应化为3/50→50的倍数） |
| confidence | medium |

## 不适用条件

- 占比无法化为有限分母分数（如33.3%循环小数等无理近似）时不适用此法。
- 总数范围无上界约束、无法唯一确定倍数时不适用此法。
- 题目占比本身已是最简分数形式且无需"百化分"转换时不适用此法。

## 反向触发

- 当多个百分比的最简分母不互素时，应换用通分后求最小公倍数法确定总数。
- 当整数解不唯一（多个倍数都满足范围约束）时，应补充用"各部分均为整数"等其他约束核验唯一解。
- 当百分比含小数（如12.5%）需先化为分数时，应回归原始百分比的精确分数表达，避免近似误差累积。
