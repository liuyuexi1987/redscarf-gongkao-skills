# 方法卡：问题表述的傻瓜对策法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 问题表述的傻瓜对策法 |
| 适用题型 | 中心理解——说理类文段，主旨为问题表述 |
| 触发场景 | 文段指出某个做法/认知有问题（如"把区块链等同于虚拟货币是认识偏颇"），问主旨/意在强调 |
| 步骤逻辑 | ① 确认主旨是"XX做法/认知有问题"；② 正确选项只有两种形式：A) 直接评价"这种做法是错的"；B) 提傻瓜对策即直接否定该行为（"不要把区块链等同于虚拟货币"）；③ 对策不能无中生有，不能脑补"挖掘潜在价值"等原文未提的内容；④ 若已有一个选项完美匹配主旨，即使另一个选项有小瑕疵，也优先选主旨匹配的 |
| 高频错因 | 提了无中生有的对策（如原文没提"挖掘潜在价值"就写进去）；纠结选项中的细节瑕疵而忽略了主旨优先级；选了问题表述的选项但其概括不准确 |
| confidence | high |

## 补充说明

问题表述和对策表述没有优先级高低——选问题是因为对策有无中生有，选对策是因为问题概括不准。关键是检查：问题是否概括准？对策是否针对该问题？有没有无中生有？

## 不适用条件

- 文段主旨不是"某做法有问题"，而是正面论证某个观点或对策的合理性时
- 文段虽指出问题，但随后给出了详细的解决方案，此时主旨应转向对策而非问题表述
- 题目问的是"作者意在强调"且文段有明确的制度/机制层面分析时，分析型选项优先于简单的否定型选项

## 反向触发

- 当"傻瓜对策"选项虽直接否定问题行为，但遗漏了文段中另一个同样重要的问题时，应考虑问题概括型选项是否更完整
- 当两个选项一个是问题概括、一个是对策，且对策未无中生有时，不可机械地优先选问题表述，应根据文段重心（问题篇幅大还是对策篇幅大）判断
- 当文段问题的表述涉及多层嵌套（如"A导致B，B又引发C"），简单的"不要做A"可能不够完整，应回到文段检查是否需要更上位的概括
