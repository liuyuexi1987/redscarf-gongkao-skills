# 方法卡：前提假设类题三种正确答案模式

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 前提假设类题三种正确答案模式 |
| 适用题型 | 判断推理——前提假设类 |
| 触发场景 | 题目问法出现"前提""假设""必要条件"等关键词 |
| 步骤逻辑 | ① 识别题型：问法含"前提""假设"；② 三种常见正确答案模式：第一种"论点搭桥"——在论据和论点之间搭建逻辑桥梁；第二种"补充漏洞"——指出论据无法直接推出结论的漏洞并补上；第三种"排除他因"——排除可能削弱结论的其他原因；③ 验证方法：否定代入法——否定选项后看结论是否还能成立，若不成立则为必要前提 |
| 高频错因 | 将"加强"当成"前提"，选了支持项而非必要项；忽视"搭桥"模式，只关注"补充漏洞" |
| confidence | high |

## 补充说明

"搭桥"适用于论据与论点存在概念跳跃时（如论据说"捐款1000元"，论点说"总额超过1000"，搭桥即"总额大于已知捐款"）。"补充漏洞"适用于推理链条本身有缺口。

## 不适用条件

- 当问法为"加强"而非"前提"时，三种模式不完全适用——加强项不要求是必要条件。
- 当论证中论据和论点之间没有概念跳跃且推理链条无明显漏洞时，三种模式可能都不直接匹配，需从选项反推。
- 当选项涉及直接否定论点或偷换概念时，属于无关项或削弱项，不属于前提假设范畴。

## 反向触发

- 问法含"加强"而非"前提"时，换用加强题分析框架，选"有了更好"的项而非"没它不行"的项。
- 三种模式均不匹配时，检查选项是否为无关项或削弱项。
- 否定代入法否定后结论仍成立时，该选项不是必要前提，继续排查其他选项。
