# 方法卡：VT图像盈亏面积法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | VT图像盈亏面积法 |
| 适用题型 | 行程问题·匀变速运动·两车同时到达 |
| 触发场景 | 甲匀速、乙变速（上坡慢下坡快），同时到达终点，求路程比 |
| 步骤逻辑 | 1. 画VT图：甲为水平线，乙先低后高（或先高后低）；2. 同时到达 → 总面积（总路程）相等；3. 乙低于甲的面积 = 乙高于甲的面积（盈亏相等）；4. 速度差的宽度相同 → 时间的长度也相同；5. 例：乙上坡0.5V下坡1.5V → 亏0.5V和盈0.5V宽度一样 → 上坡时间=下坡时间 → 上坡路程:下坡路程=1:3 |
| 高频错因 | 不画图直接凭想象推导 |
| confidence | high |

## 补充说明

匀变速问题的核心就是"画图"，VT图像能直观展示路程关系

## 不适用条件

- 两车并非同时到达终点（盈亏相等的核心前提不成立）。
- 甲并非匀速（如甲也变速）的复合运动。
- 速度变化非线性的运动（VT图为曲线，盈亏面积难以直观计算）。

## 反向触发

- 两车到达时间不同时，应换用各自独立计算路程再比较的方法。
- 甲也做匀变速运动时，需引入双图像或代数方程组联立求解。
- 题目求的是速度比而非路程比时，直接从图像纵坐标读取更直接。
