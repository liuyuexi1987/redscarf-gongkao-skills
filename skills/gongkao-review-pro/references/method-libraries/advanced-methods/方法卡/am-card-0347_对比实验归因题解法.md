# 方法卡：对比实验归因题解法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 对比实验归因题解法 |
| 适用题型 | 判断推理——削弱加强类（对比实验归因） |
| 触发场景 | 题干描述两组实验对比，得出因果结论；选项涉及实验结果补充、质疑或支持 |
| 步骤逻辑 | ① 画图表示分组：用一条线分两组，标注实验组/对照组及其差异变量；② 判断分组依据：选项的分组标准必须与题干一致，分组错误直接排除；③ 补充漏洞：题干未给出实验结果时，正确答案一定是补入该结果；④ 质疑三类型——另有他因（A选项，引入未控制变量）、因果倒置（选项含"只有才"表时间先后，果变因）、否定此因（直接否定原因果链）；⑤ 支持时选"呆立时间更长"方向，质疑时选"呆立时间更短"方向 |
| 高频错因 | 分组标准搞混（如题干按喝不喝酒分组，选项按时间分组→直接排除）；忽视题干关键词"呆立"（吓呆≠跑掉）；支持与质疑方向搞反 |
| confidence | high |
| 不适用条件 | 1. 题干是单组实验或调查，没有对照组，不涉及分组对比\n2. 题目要求判断因果方向（哪个是因哪个是果），但题干本身没有做对比实验 |
| 反向触发 | 1. 选项指出的变量差异并非实验的控制变量，而是两组本身就存在的固有差异（干扰因素），应按另有他因排除\n2. 题干问的是"实验设计是否合理"而非"从实验结果能得出什么结论"，需换用实验设计评价思路 |

## 补充说明

本学习材料用三道题反复强化此方法：Q1（大白鼠实验，分组排除BD，呆立=吓呆）、Q5（母女妊娠剧吐，D分组错误排除）、Q13（双语与痴呆，B为因果倒置/另有他因）。核心口诀：分组不对直接排，结果缺失必须补。
