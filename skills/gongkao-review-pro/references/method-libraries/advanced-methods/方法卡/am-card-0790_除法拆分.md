# 方法卡：除法拆分

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 除法拆分 |
| 适用题型 | 资料分析-除法-分数/比重类计算（分子在分母的50%、100%、10%-20%附近） |
| 触发场景 | 求比重、占比、分数值，且分子明显在分母的某个好算比例附近时 |
| 步骤逻辑 | 1. 将分子拆成"分母的好算比例+剩余部分"（如拆出分母的50%、100%、10%）2. 左边直接得到50%/100%/10%等 3. 右边剩余部分用"包子法"估算：分母的百分之一即一个包子的价格 4. 看剩余部分能买几个包子，加减得到最终比例 |
| 高频错因 | 分子拆分时数值算错；包子价格（分母的1%）小数点位置搞错 |
| confidence | medium |

## 不适用条件

1. 分子远离分母的50%、100%、10%等好算比例时，拆分步骤过多，不如直除
2. 选项保留三位有效数字后差距在0.5以内时，拆分的估算精度可能不够
3. 当估算误差可能跨越选项或改变结论时，改用精算/验证

## 反向触发

1. 看到比重/占比类计算，且分子在分母的50%、100%、10%-20%附近时，优先考虑除法拆分
2. 用拆分法估算后选项仍难以区分时，检查是否需要切换到直除
3. 自己在计算包子价格（分母的1%）时出错或小数点位置不确定时，先验证再继续

## 补充说明

除法拆分的核心优势是省去"试商"步骤（不用纠结商4还是商5），且不用做乘法。例如322/608：608的一半是304，322=304+18，左边是50%，右边一个包子6.08元、18元能买不到3个，所以结果约53%减。本方法"包子"即分母的1%，如608的1%是6.08。该方法可精确可估算：需要更精确时继续拆分剩余部分，大部分情况估算即可选对答案。当选项极近时可考虑改用直除。当估算误差可能跨越选项或改变结论时，改用精算/验证。
