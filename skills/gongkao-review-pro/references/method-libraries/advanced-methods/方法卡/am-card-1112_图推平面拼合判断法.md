# 方法卡：图推平面拼合判断法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 图推平面拼合判断法 |
| 适用题型 | 判断推理——图形推理（平面拼合） |
| 触发场景 | 题目要求判断哪个选项能由给定的几个图形拼合而成，或判断哪个选项不能拼合 |
| 步骤逻辑 | ① 识别拼合类型：只能平移（图形只能平移不能旋转翻转）→ 可旋转（图形可以旋转但不能翻转）→ 可翻转（图形允许镜像翻面）→ 俄罗斯方块式（不规则形状拼合成规则图形）；② 只能平移的判断方法：找最大/最特殊的图形作为锚点，验证其余图形能否通过平移与锚点拼合；③ 可旋转的判断方法：在平移基础上增加旋转验证，注意旋转后方向变化；④ 可翻转的判断方法：翻转后图形变成镜像，左右/朝向/凹凸关系会反向；若题面明确涉及正反面、颜色或黑白面，再按题面规则处理颜色变化；⑤ 排除法：验证选项时，先排除明显不能拼合的选项（如面积不等、形状明显不符），再对剩余选项做精确验证 |
| 高频错因 | ① 忽略题目条件（只能平移/可旋转/可翻转），用错拼合方式；② 把旋转当翻转，或把翻转后的镜像方向看成原方向；③ 未区分题面是否规定颜色/正反面规则，擅自处理黑白变化；④ 不找锚点直接尝试拼合，效率低且容易出错；⑤ 俄罗斯方块式拼合中忽略形状的精确匹配，只看大致相似 |
| confidence | high |

## 补充说明

**只能平移的触发逻辑：** 当题目明确说"只能平移"或没有说可以旋转翻转时，触发此判断。核心方法：找最大/最特殊的图形作为锚点，将其固定在目标位置，然后验证其余图形能否通过平移与锚点拼合。如果不能，排除该选项。

**可旋转的触发逻辑：** 当题目说"可以旋转"时，触发此判断。在平移基础上增加旋转验证。注意：旋转后图形的方向会变化，需要验证旋转后的方向是否与目标一致。

**可翻转的触发逻辑：** 当题目说"可以翻转"时，触发此判断。翻转与旋转的核心区别：翻转会形成镜像，左右、朝向、凹凸关系会反向；颜色或黑白面是否变化，必须以题面是否说明正反面/颜色规则为准，不能默认黑白互换。

**俄罗斯方块式拼合的触发逻辑：** 当给定的图形是不规则形状（如L形、T形、Z形），需要拼合成规则图形（如正方形、长方形）时，触发此判断。核心方法：先验证总面积是否等于目标面积，再验证形状能否精确匹配。

**与已有卡的关系：** am-card-1087（立体拼合一层一层看法）是立体拼合，本卡是平面拼合，两者不同维度。本卡专注于平面拼合的特征触发和判断方法。

## 不适用条件

1. 立体拼合题（应改用1087立体拼合一层一层看法）
2. 三视图题（应改用1131三视图判定法）
3. 截面题（应改用1130截面判定法）

## 反向触发

1. 只能平移题锚点法排除不了选项时，应补充核验其余图形的精确位置
2. 可旋转题旋转后方向不明确时，应回到题面确认旋转角度限制
3. 俄罗斯方块式拼合面积相等但形状无法匹配时，应补充核验形状的精确边长对应

## 输出要求

- 看到拼合题时，先说明触发的是哪种拼合类型
- 只能平移时找锚点验证
- 可旋转时增加旋转验证
- 可翻转时注意镜像方向；颜色变化只在题面明确时处理
- 俄罗斯方块式先验证面积再验证形状
- 与 am-card-1087 区分平面拼合和立体拼合
