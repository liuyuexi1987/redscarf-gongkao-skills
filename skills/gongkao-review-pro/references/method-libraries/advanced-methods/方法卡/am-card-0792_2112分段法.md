# 方法卡：2112分段法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 2112分段法 |
| 适用题型 | 资料分析——减法计算，尤其涉及借位 |
| 触发场景 | 减法中高位不够减需要借位，希望避免借位直接口算 |
| 步骤逻辑 | ① 看个位是否够减：够减则按"高位段+低位段"二一分段（前两位-前两位，个位-个位）；② 个位不够减则四一分段（前一位单独，后两位-后两位）；③ 两段独立计算互不干扰；④ 若高位段结果为负数，直接与另一段合并（如80+(-1)=79） |
| 高频错因 | 不敢用负数表示高位段结果；分段位置选错导致仍然需要借位 |
| confidence | medium |

## 补充说明

与整数基本值法互补：基本值法通过引入整百基准消除借位，2112分段法通过高位段允许负数消除借位。两法可灵活选用，哪个好算用哪个。当估算误差可能跨越选项或改变结论时，改用精算/验证。

## 不适用条件

1. 数据位数过少（如两位数减两位数）时，直接口算比分段更快
2. 选项差异极大、估算即可区分时，不必精确分段
3. 当估算误差可能跨越选项或改变结论时，改用精算/验证

## 反向触发

1. 看到多位数减法需要借位时，提醒自己考虑分段而非硬借位
2. 某一段算出负数时，直接与另一段合并，不必重新借位
3. 用借位法耗时过长时，切换到分段法或整数基本值法
