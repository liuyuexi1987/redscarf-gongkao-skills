# 方法卡：以偏概全/缺少对照组识别

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 以偏概全/缺少对照组识别 |
| 适用题型 | 逻辑谬误题、加强削弱中的样本质疑题 |
| 触发场景 | 仅凭一组数据/一个群体的统计就下结论，未与对照组比较 |
| 步骤逻辑 | 1. 看论据是否只有一组数据（如"成绩不好的学生56.3%早恋"）；2. 缺少对照组（成绩好的学生早恋比例是多少？）；3. 也可能缺少比较基准（"81%死亡率"——不接受治疗的死亡率是多少？）；4. 正确做法：需要同时比较两组才能断定因果 |
| 高频错因 | 看到"56.3%高占比"就认为有因果关系；忽略了成绩好的人可能早恋比例更高 |
| confidence | high |

## 补充说明

此谬误在加强削弱题中极为常见。没有对照组时，不能直接认定两者存在因果关系。

## 不适用条件

- 题干已经提供了完整的对照组数据，需要做的是数据分析而非识别样本缺陷。
- 题目考查的是比例/百分比的计算错误，而非样本代表性问题。

## 反向触发

- 论据仅基于单一样本或单一数据组得出因果结论，且未给出对照组。
- 加强削弱题中，选项涉及"样本是否代表""是否缺少比较基准"等质疑。
