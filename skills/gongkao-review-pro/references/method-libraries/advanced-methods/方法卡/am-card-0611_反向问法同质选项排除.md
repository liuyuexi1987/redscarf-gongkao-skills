# 方法卡：反向问法同质选项排除

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 反向问法同质选项排除 |
| 适用题型 | 判断推理——"除哪项外均能削弱/加强"类反向问法 |
| 触发场景 | 题目问"除哪项外均能削弱"，需要找不能削弱的选项 |
| 步骤逻辑 | ① 反向问法下，三个正确选项（能削弱的）往往具有"同质"特征——角度相同或结构相似；② 找到三个同质选项后，剩下的异质选项即为答案；③ 结合具体题目验证：ABC都从商家/消费者已遭遇问题角度削弱，D讲"不知情"——角度不同 |
| 高频错因 | 只看选项表面意思，不比较选项间的角度差异；将"力度弱"等同于"不能削弱" |
| confidence | high |

## 补充说明

"同质"可以是角度相同（多个选项都从同一类事实出发）、也可以是跟题干的逻辑结构相似。若某选项涉及的要素不影响结论中的关键行为（如对购买行为无影响的因素），则属无关，不能削弱。注意区分"力度弱"与"不能削弱"：力度弱仍属削弱，只是同质比较中位于较弱一档；不能削弱则属于角度不同的异质选项。

## 不适用条件

1. 正向问法（"哪项最能削弱/加强"）时不适用本同质排除法。
2. 选项数量少于4个或同质特征不明显时不适用。
3. 题干逻辑结构复杂、各选项角度本就分散时不适用。

## 反向触发

1. 若同质特征难以辨识，应回到正向逐项验证削弱/加强力度。
2. 若多个选项均看似异质，应复核题干逻辑结构，确认是否漏看了共同角度。
3. 若需区分"力度弱"与"不能削弱"，应换用力度比较法逐项排序。
