# 方法卡：用变化解释变化法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 用变化解释变化法 |
| 适用题型 | 支持类题目中结论为"逐渐退化/越来越差/不断削弱"等趋势型表述 |
| 触发场景 | - 结论说的是某种能力/指标随时间变化的趋势
- 论据提供了部分变化证据
- 需要选项补充对应的同向变化证据 |
| 步骤逻辑 | 1. 识别结论是否为变化型——"逐渐/越来越/不断"等词；2. 正确选项也应该是变化型——提供另一个同向变化的数据；3. 静态数据（不知道过去是什么样）不能支持变化趋势；4. 不同人群之间的横向比较也不能支持纵向变化趋势 |
| 高频错因 | 选了静态数据（如"目前有390个基因能编码"）——不知道以前是多少选了横向比较（如"老年人嗅觉低于年轻人"）——不是纵向变化选了另一感官的比较（如"嗅觉不如视觉重要"）——比较对象错误 |
| confidence | medium |

## 补充说明

本方法的关键是区分"纵向变化"与"静态/横向"数据。当结论是某能力随时间逐渐退化（纵向变化）时，正确选项必须提供另一个同向变化的数据（如对应脑区面积逐渐减少）；静态数据（只给当前数值不知过去）不能支持变化趋势，横向比较（不同人群间的差异）也不能支持纵向变化趋势。

## 不适用条件

- 结论为静态状态而非变化趋势时，本方法不适用，应改用静态数据支持。
- 结论为横向比较结果而非纵向变化时，应改用横向对比类支持法。

## 反向触发

- 当选项只给当前数值而无历史对照时，应换用带时间序列的同向变化数据核验。
- 当选项比较对象与结论对象不一致（如结论说嗅觉、选项说视觉）时，应核验对象匹配性而非强行套用。
