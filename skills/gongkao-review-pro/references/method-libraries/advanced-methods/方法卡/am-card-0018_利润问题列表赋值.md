# 方法卡：利润问题列表赋值
## 基本信息
| 字段 | 值 |
|------|-----|
| 方法名 | 利润问题列表赋值 |
| 适用题型 | 数量关系-利润/经济问题 |
| 触发场景 | 利润题干中全是比例条件，无具体数值 |
| 步骤逻辑 | 1.列表：进价/售价/单件利润/销量四列 2.全比例条件可双赋值（价格+量各赋值） 3.三量关系只给其一则只赋一个方向 4.边读题边赋值边列式求解 |
| 高频错因 | 赋值方向错误导致方程无解；不列表导致关系混乱 |
| confidence | high |

## 不适用条件

1. 题干已给出所有具体数值（进价、售价、销量均已知），无需赋值
2. 涉及复利/折旧/连续比例变化，非传统利润单次交易模型
3. 存在多个独立未知量超过约束条件，赋值后方程组不可解

## 反向触发

1. 题目所有数值直接给出，只需列等式计算
2. 题目涉及存款利率、复利增长等连续模型，非买卖利润
3. 题干明确要求求解某一具体数值（如"进价是多少"），赋值法会改变该数值

## 补充说明
赋值技巧：进价通常赋100，使百分比计算变整数。双赋值适用于"全是比例"；若题干给了一个具体量则只能单赋值。示例提示"无脑操作"——进价100、售价125、利润25这类赋值，配合列表极快出答案。
