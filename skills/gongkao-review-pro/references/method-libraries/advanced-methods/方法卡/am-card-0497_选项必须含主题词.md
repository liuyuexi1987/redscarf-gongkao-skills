# 方法卡：选项必须含主题词

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 选项必须含主题词 |
| 适用题型 | 言语理解——中心理解 |
| 触发场景 | 选项与原文之间做取舍时，优先检查选项是否包含全文的核心主题词。主题词缺失的选项即使内容看似合理也应排除。 |
| 步骤逻辑 | 1. 通过首句和高频词确定全文主题词；2. 排除不含主题词的选项（如全文讲"要素禀赋理论"，选项没有该词则排除）；3. 主题词丢失通常意味着选项偷换了讨论对象或概括片面；4. 配合"原文用啥词咱就跟着用啥词"的快速选答案策略 |
| 高频错因 | 被选项的"合理性"吸引，忽略主题词是否出现在两个看似都对的选项中纠结时，忽略了其中一个缺少主题词 |
| confidence | medium |

## 补充说明

## 不适用条件

- 细节理解题（如"以下哪项正确/不正确"）不以主题词为核心判断标准
- 文段主题词本身就是多个或不明确时，不能机械排除缺词选项
- 选项使用了主题词的同义替换或上位概念时，不能视为"缺失"

## 反向触发

- 若题目问的是"作者意在强调"或"文段主旨"但选项均不含原词，应检查是否有合理同义替换，而非直接排除所有选项
- 若文段是并列结构且没有单一主题词，不适用本卡的排除逻辑
