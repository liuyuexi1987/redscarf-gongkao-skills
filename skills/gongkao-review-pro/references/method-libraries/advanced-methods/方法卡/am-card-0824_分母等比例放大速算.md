# 方法卡：分母等比例放大速算

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 分母等比例放大速算 |
| 适用题型 | 资料分析——除法中分母非常接近1000时的快速计算 |
| 触发场景 | 遇到如373/985这类分母非常接近1000的除法，且不好用拆分（不在50%或10%附近） |
| 步骤逻辑 | ① 分母加一个小数（如985+15=1000）使分母变为1000；② 计算分子等比例放大的量（分母扩大了约1.5%，分子也扩大约1.5%，即373×1.5%≈6，分子变成379）；③ 结果直接读为379‰即37.9% |
| 高频错因 | 只放大分母不放大分子，导致结果偏小；误认为这种方法适用于所有除法，实际上只在分母接近1000时好用 |
| confidence | medium |

## 补充说明

核心原理是分数的分子分母等比例放大后值不变。估算时按"分母差值占分母的百分比"同比例放大分子，得到近似值后再直接读千分位即可。适用于985、966、991等接近1000的分母。

## 速算边界

当估算误差可能跨越选项或改变结论时，改用精算/验证。

## 不适用条件

- 分母不接近1000（如373/720）时，等比例放大的修正量反而不好估，不如直接用拆分法。
- 分母调整到整千后，分子同比例修正不便或估算误差可能跨越选项时，不宜使用。

## 反向触发

- 分母明显远离1000且选项间距极小，需直接动笔精算。
- 题目给的数据可以拆成常见比例（50%、10%附近），拆分法更快。
