# 方法卡：三类文段判断选答案

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 三类文段判断选答案 |
| 适用题型 | 中心理解、标题拟定、下文推断、语句填入 |
| 触发场景 | 做片段阅读时，无法判断选项大方向；纠结于对策型选项和概括型选项 |
| 步骤逻辑 | 1. 读完全文后，判断文段属于三类中的哪一类；2. 说理类（作者有主观态度/观点/对策/指出问题）→ 原文有对策选对策，有问题选体现问题的选项；3. 科普介绍类（客观描述现象/知识/研究，无作者主观态度）→ 选中性、客观的概括选项，不选对策；4. 新闻类（突出新发现/新突破/新进展）→ 选项必须体现"新" |
| 高频错因 | 在科普类文段中选了对策型选项；把作者客观介绍当成主观表态 |
| confidence | medium |

## 补充说明

- 三类文段的判别核心是"作者主观态度的有无"：有主观态度/观点/对策→说理类；客观描述现象/知识/研究→科普介绍类；突出新发现/新突破/新进展→新闻类
- 选项类型必须与文段类型匹配：说理类选对策或问题项，科普类选中性概括项，新闻类选体现"新"的选项

## 不适用条件

- 文段同时具备多类特征（如科普中夹杂作者评论）时，需先判断主导类型再套用，不能机械分类
- 选项本身有明显硬伤（无中生有、偷换概念、偷换时态等）时，先用排错法，不必依赖文段类型判断

## 反向触发

- 当文段类型难以判定时，应换用首句主题词+行文结构分析，而非强行套三类标签
- 当选项中同时存在可适用的对策型与概括型选项时，应回到文段作者态度判断核验，而非凭类型机械取舍
