# 方法卡：意义表述优先级高于中性描述

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 意义表述优先级高于中性描述 |
| 适用题型 | 中心理解 |
| 触发场景 | 文段先有"是什么"的定义/客观描述，后有"意义/影响/好处"的表述 |
| 步骤逻辑 | 1. 识别文段中"是什么"为中性客观描述；2. 识别"意义/影响/好处"为意义表述；3. 意义表述的主旨性高于中性描述；4. 主旨应选择意义表述，排除取自客观描述的选项 |
| 高频错因 | 把"是什么"的客观表述当作主旨，选了前半段的内容 |
| 不适用条件 | 对策后的意义表述可能只是论证支撑，不自动成为主旨；需结合文段结构判断意义表述是否承载作者核心观点 |
| confidence | high |
| 反向触发 | 文段中意义表述出现在转折之前、转折之后才是作者真正主张时，意义表述不应作为主旨；若多个选项均含意义表述但覆盖范围不同，应回到文段结构验证哪个选项完整对应作者的核心论述层次 |

> **使用边界**：本方法用于提供优先检查方向，不可单独据此作答；最终需回到题干关系、原文证据或选项条件完成验证。

**不适用条件**：对策后的意义表述可能只是论证支撑，不自动成为主旨；需结合文段结构判断意义表述是否承载作者核心观点。
