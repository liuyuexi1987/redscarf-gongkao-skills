# 方法卡：VT图像面积比较法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | VT图像面积比较法 |
| 适用题型 | 行程问题·两人运动比较 |
| 触发场景 | 题目给出两人速度随时间变化的图像，问何时路程相等 |
| 步骤逻辑 | 1. VT图像中，曲线下方面积 = 路程；2. 两人路程相等 = 两人曲线下方面积相等；3. 速度交点不等于路程相等（交点只说明此刻速度相同）；4. 路程相等的时刻 = 面积差为零的时刻；5. 从后往前看更简单：终点同时到达→总路程相等→找面积差归零的点 |
| 高频错因 | 把速度相等（交点）误认为路程相等 |
| confidence | high |

## 补充说明

VT图像题要区分"速度相等"和"路程相等"，两者完全不同

## 不适用条件

- 题目未提供VT图像或无法从文字条件重建图像信息。
- 路程关系不以"相等"为参照（如求路程差的具体值）的比较题。
- 图像为非线性（曲线）且面积难以直观估算的情况。

## 反向触发

- 题目问速度相等时刻而非路程相等时刻时，直接找图像交点即可。
- 图像复杂（多段折线）且面积难以肉眼判断时，应改用积分或分段求和。
- 终点并非同时到达时，不能以"总路程相等"为前提反推面积归零点。
