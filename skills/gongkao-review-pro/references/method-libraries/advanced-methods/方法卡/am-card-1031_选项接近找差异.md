# 方法卡：选项接近找差异

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 选项接近找差异 |
| 适用题型 | 言语理解——中心理解（选项纠结时） |
| 触发场景 | 两个或多个选项很接近，不知道选哪个 |
| 步骤逻辑 | ① 找选项之间的差异点；② 带着差异点回文段验证；③ 差异处往往是判断关键；④ 主题词是否在选项中→快速排除 |
| 高频错因 | ① 在两个接近选项间纠结→不找差异→浪费时间；② 找到差异但不回文段验证→凭感觉选 |
| confidence | high |

## 不适用条件

1. 选项差异明显无需纠结时。
2. 题目为细节题而非中心理解题时。
3. 文段主题词明确且唯一对应选项时。

## 反向触发

1. 当选项差异点回文段验证均不成立时，应换用主题词排除法。
2. 当两个接近选项实为并列关系时，应核验是否有更上位的概括选项。
3. 当差异点过多无法聚焦时，应补充优先比对主题词。
