# 方法卡：基准法省算

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 基准法省算 |
| 适用题型 | 资料分析·多列数据逐个算值比较（如5年单价是否>150） |
| 触发场景 | 算出第一年的值恰好等于或非常接近阈值，后续年份只需与第一年做分数比较 |
| 步骤逻辑 | 1. 老实算出第一年的精确值 2. 若发现该值非常接近阈值（如151≈150）→它是基准 3. 后续年份不重新计算，只比较分子/分母相对于基准年的增速 4. 分子涨得快→超阈值，分母涨得快→低于阈值 |
| 高频错因 | 每一年都按第一年方式精算，浪费时间；看不出第一年是"设计好的基准" |
| confidence | high |

## 补充说明

典型场景：5年出让单价需判断是否大于150万/亩。算出首年=151万/亩，恰好是基准。后续4年只需用趋势法判断：分子涨得快则超阈值，分母涨得快则低于阈值。全题只算了一次精确值。要点："出题人就设计成这样——首年精确值接近阈值，后续年份只需比较趋势。"

## 不适用条件

1. 当首年精确值离阈值较远（如阈值150而算出200），基准比较的优势不明显，需另算其他年份
2. 当需要输出所有年份的精确数值（而非仅判断是否超过阈值）时，此法不适用
3. 当分子分母增速变化方向频繁交替、难以快速判断趋势时，可能需要逐个精算

## 反向触发

1. 当基准年之外的某年分子分母增速接近、趋势不明显时，应改用精算确认
2. 当题目要求排序各年份具体数值而非二分判断时，应换用逐个计算法
