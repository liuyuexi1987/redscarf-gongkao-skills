# 方法卡：经济利润成本识别"其他无区别"

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 经济利润成本识别"其他无区别" |
| 适用题型 | 经济利润问题（两种产品成本对比） |
| 触发场景 | 题目说两种产品"其他无区别"，只在某一部件上有成本差异 |
| 步骤逻辑 | 1. 识别"其他无区别"：两种产品的其他成本完全相同；2. 设变量表示有差异的部件成本（如存储器成本X）；3. 根据比例关系推算其他成本（如X是其他的20%→其他=5X）；4. 两种产品的其他成本相等，仅存储器成本不同，列利润方程求解 |
| 高频错因 | 忽视"其他无区别"导致对256G产品重复设未知数；利润率/成本率换算出错 |
| confidence | high |

## 不适用条件

- 题目未说明"其他无区别"（两种产品可能有多处成本差异，不能假设其他成本相等）
- 利润率/成本率的关系不涉及比例换算（如直接给绝对成本值）
- 产品种类超过两种且各产品成本结构差异较大

## 反向触发

- 当列方程后出现两个未知数却只有一个方程时，可能遗漏了"其他无区别"的等量关系，应回头检查成本结构
- 当利润率/成本率换算方向搞混时（利润率 = 利润/售价 vs 成本率 = 成本/售价），应先确认题目给的是哪一种
- 当题目条件涉及售价差异（而非成本差异）时，本方法的前提不适用，应重新识别利润方程的核心变量
