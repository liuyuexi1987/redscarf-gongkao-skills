# 方法卡：增速差额=基期×增长率简化差额计算

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 增速差额=基期×增长率简化差额计算 |
| 适用题型 | 资料分析——倍差关系下的差额计算 |
| 触发场景 | 题目要求计算两个相关量（如城镇与农村、进口与出口）的差额，且其中一个量是另一个量的若干倍（倍差已知或可求） |
| 步骤逻辑 | 1. 差额 = 城镇 - 农村 = 农村×倍差 - 农村 = 农村×(倍差-1)；2. (倍差-1) 就是增长率，所以差额 = 基期量 × 增长率；3. 不需要分别求城镇和农村再相减，一步到位；4. 两年差额之差可用因式分解或"一加一减"技巧简化（如两数幅度接近10%以内可互调使一个因数相等，提公因式后减法更简单） |
| 高频错因 | 分别算城镇和农村再做减法，步骤多容易出错忘记倍差不减一（求"值"时直接乘倍差，求"差额"时才减一）思维惯性：前面题减一，后面不减一时也跟着减一 |
| confidence | medium |

## 不适用条件

- 两个量之间不存在倍差关系（如各自独立的两个指标）时，不能套用"基期×增长率"简化公式
- 倍差数值无法从材料中获取时，本法缺少关键输入，应分别计算再做减法
- 题目要求的不是差额而是比值或其他运算结果时，本法不适用

## 反向触发

- 若倍差的正负方向无法确认（如"城镇是农村的几倍"还是"农村是城镇的几倍"搞混），先标注清楚再代入
- 若增长率数值过大（超过20%），简化公式的误差可能偏大，需评估是否仍可使用
