# 方法卡：加减法口算从高位往低位

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 加减法口算从高位往低位 |
| 适用题型 | 资料分析——口算 |
| 触发场景 | 资料分析中的加减法计算 |
| 步骤逻辑 | ① 不要从个位开始竖式计算→从高位往低位算；② 加法：先加高位→看低位是否满十需要进位→心里修正；③ 减法：先减高位→不够减时心里默念结果减一→后面补位；④ 凑整法：把其中一个数的个位抹成0→先算整数→最后加上/减去抹掉的部分 |
| 高频错因 | ① 从个位开始→速度慢；② 不凑整→计算量大 |
| confidence | high |

## 补充说明
## 不适用条件
- 题目涉及乘除法而非加减法时，本卡不适用
- 数字位数多、连续进退位复杂且要求精确结果时，口算风险较大，应改用列式或分段校验
- 需要精确到个位的结果且选项差距极小时，应精算而非估算

## 反向触发
- 若题目是乘除法或混合运算，不使用本卡
- 若选项差距很小需要精确结果，先判断是否允许估算再决定方法
