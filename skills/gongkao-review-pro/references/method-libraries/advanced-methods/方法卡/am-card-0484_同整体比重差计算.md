# 方法卡：同整体比重差计算

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 同整体比重差计算 |
| 适用题型 | 资料分析-比重差/百分点差 |
| 触发场景 | 求两个类别"占同一整体"的比重之差（几个百分点），且整体相同 |
| 步骤逻辑 | 确认两者占同一整体 -> 直接拿两部分做差 -> 差值 ÷ 整体 = 比重差 |
| 高频错因 | 误以为整体不同需分别求比重再相减；找错总量基数 |
| confidence | high |

## 不适用条件

1. 两部分不属于同一整体（分母不同）时，不能直接做差再除以整体，需分别计算比重再相减。
2. 题目要求的是部分增速差而非比重差时，应改用增速公式，不适用本方法。
3. 整体值本身是未知量需要先求解时，需先用整体占比求值法求出整体，再计算比重差。

## 反向触发

1. 当题目给出两个部分的占比直接相减即可得比重差时，不需要做"差值÷整体"的步骤。
2. 若涉及的是同一整体下多个部分的比重比较（而非两部分之差），应改用排序法或比例分析。
3. 估算误差可能跨越选项时改用精算，用精确数值计算差值÷整体。
