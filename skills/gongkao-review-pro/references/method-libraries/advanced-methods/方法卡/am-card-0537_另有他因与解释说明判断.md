# 方法卡：另有他因与解释说明的判断——看因果联系强弱

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 方法卡：另有他因与解释说明的判断——看因果联系强弱 |
| 适用题型 | 削弱题（逻辑判断） |
| 触发场景 | 选项引入了一个与题干结论相关的"新变量"，需要判断它是"解释说明的支持"还是"另有他因的削弱" |
| 步骤逻辑 | 1. 提取选项引入的新变量；2. 检查新变量与原有变量之间是否有明确的因果逻辑联系；3. 若新变量是原变量的具体化或组成部分（如肥胖→腹部脂肪→压迫→海马体变小）→ 因果机制的解释说明，属支持；4. 若新变量与原变量相关但构成独立的替代原因（如"久坐者也长期低头看手机"，低头是独立于久坐的致病因素）→ 另有他因，属削弱；5. 关键区分点：新变量是原变量的机制表现，还是独立的替代原因 |
| 高频错因 | 看到新变量和原变量有相关性就当支持，忽略因果方向不明确把"另有他因"误判为"解释说明" |
| confidence | high |

## 补充说明

- 解释说明与他因的区分在于新变量的独立性。若新变量是原变量的具体化或组成部分，它在解释原变量为何导致结果，属于支持。例如：原结论"肥胖导致海马体萎缩"，选项说"肥胖者腹部脂肪含量较高，腹部脂肪可能压迫海马体"——腹部脂肪是肥胖的具体表现，这是解释因果机制，不是他因。
- 若新变量与原变量相关但构成独立的替代原因，它在暗示"可能不是原变量而是这个新变量在起作用"，属于削弱。例如：原结论"久坐导致颈椎病"，选项说"久坐者更可能长期低头看手机，低头也导致颈椎病"——低头是独立于久坐的致病因素，这是真正的他因。
- 相关性观察（如"肥胖的人海马体也小"）本身不构成他因，也不能仅凭此判断为支持。需进一步追问新变量是原变量的具体化机制，还是独立的替代原因。

## 不适用条件

- 题干结论本身不涉及因果关系（如纯形式逻辑或定义判断），此法不适用。
- 选项引入的新变量是原变量的具体化或组成部分（如脂肪之于肥胖），应直接归为解释说明，不必用此法判断。
- 题目要求找"最能削弱"且存在因果倒置选项时，他因削弱力度不如因果倒置，应优先选因果倒置。

## 反向触发

- 当新变量与原变量可建立完整的因果推导链时，直接判定为解释说明的支持，不需要继续用此法区分。
- 当选项同时否定原有因果联系并给出新原因时，属于"否定此因+另有他因"，力度强于单纯他因，优先选之。
- 当多个选项都是他因、无法仅凭因果链有无区分时，比较新变量对原有结论的解释覆盖范围再择优。
