# 方法卡：论证评价题

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 论证评价题 |
| 适用题型 | 判断推理——论证评价题 |
| 触发场景 | 选项都是问题（"是否……"），要求找出对结论最有评价力的问题 |
| 步骤逻辑 | ① 找论据→论点的逻辑漏洞；② 针对漏洞提一个问题；③ 该问题的"是/否"两种答案分别对应最强支持和最强削弱；④ 选那个"能决定逻辑链是否成立"的问题 |
| 高频错因 | ① 选了与论据→论点推导关系无关的问题；② 选了只影响一方面（只支持或只削弱）的问题 |
| confidence | high |

## 补充说明

核心思路：像答辩导师一样找茬。问的问题要"两面都有用"——回答"是"则支持，回答"否"则削弱。这样才是最关键的评价点。

## 不适用条件

- 选项不是问题形式（不是"是否……"句式）时，本方法不适用。
- 题干论据→论点逻辑链完整无漏洞时，本方法不适用。
- 题干要求加强或削弱而非评价时，本方法不适用。

## 反向触发

- 当题干要求直接给出加强项时，应换用因果加强搭桥法。
- 当题干要求解释矛盾现象时，应换用解释转折现象法。
- 当题干要求削弱因果方向时，应换用共同原因削弱法。
