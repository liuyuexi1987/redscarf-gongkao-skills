# 方法卡：细节判断低正确率题选项设置规律

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 细节判断错误等级核对法 |
| 适用题型 | 言语理解——细节判断题 |
| 触发场景 | 多个选项都有疑点，需要比较哪项与原文冲突最直接、最关键 |
| 步骤逻辑 | ①逐项定位原文依据；②先查主体、对象、范围、时态和逻辑关系是否直接冲突；③再查是否存在轻微措辞差异或合理概括；④按题目问法选择证据最明确的一项，不依据外部正确率猜命题结构 |
| 高频错因 | 把“符合常识”当成原文依据；看到多个选项有瑕疵就凭感觉比较，而没有区分直接矛盾、偷换范围和普通概括 |
| confidence | high |

## 补充说明

错误等级用于安排核对顺序：直接违背原文、偷换主体或把两个事实杂糅，通常比措辞略有概括更严重。但最终仍需逐项回到原文取证，不能根据题目正确率或预设的“一重多轻”结构判断答案。

## 不适用条件

1. 题目没有可核对的原文依据，或材料识别不完整时，不能靠错误等级硬判
2. 多个选项分别在不同维度与原文冲突时，需要逐项核对题目问法
3. 选项涉及专业事实而原文未说明时，不能仅凭常识补充判断

## 反向触发

1. 当选项中找不到致命错误项时，应换用逐句精确对照原文的方法
2. 当两个选项瑕疵程度接近无法区分轻重时，应放弃"抓大放小"改用逐项核实
3. 无论题目难易，都应以原文证据为最终依据
