# 方法卡：藐视法（粗略估算）

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 藐视法（粗略估算） |
| 适用题型 | 资料分析——多步估算比较类题目 |
| 触发场景 | 选项差距较大，列式复杂但只需比较大小、数量级或首位，精算成本明显高于估算 |
| 步骤逻辑 | 1. 心态上"藐视"题目——看着难实际简单，不要被计算量吓到；2. 每个分式只算粗略值（如 37.2÷575≈0.06，不写过程心算）；3. 算完一个看下一个选项，能排除就排除，不必每个都精算；4. 最终通过粗略值的大小关系选出答案 |
| 高频错因 | 被复杂列式吓到，花大量时间精算每项算完一个选项不算其他，错失排除机会粗算时数量级搞错（如 0.06 和 0.6 混淆） |
| confidence | medium |

## 不适用条件

- 选项差距极小（如差值在 1% 以内）时，粗算精度不足以区分，需精算
- 题目要求精确值（如求具体增长量）时，不能仅靠粗算
- 涉及多步加减混合运算时，粗算误差累积可能导致误判

## 反向触发

- 若列式只有一步简单除法且选项差距小，精算更快，不必用本法
- 若数量级不明确（如分式分子分母量级接近），先确认数量级再粗算
