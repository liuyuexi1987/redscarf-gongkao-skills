# 方法卡：增加正向论据法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 增加正向论据法 |
| 适用题型 | 支持类题目（题干推理链完整但力度不足） |
| 触发场景 | - 论据→结论之间无明显断点，但推理力度不够
- 题干存在可被攻击的漏洞
- 需要从新角度补充支持证据 |
| 步骤逻辑 | 1. 先检查有无断点——有断点优先搭桥；2. 无断点时，识别题干漏洞或薄弱环节；3. 选项方向：补充漏洞/用数据事实说话/从其他角度增加支持力度；4. 优先选题干没提到的新角度，慎选重复题干内容的选项 |
| 高频错因 | 选了重复题干论据的选项——已有论据再说一遍没有增量只盯着一个角度反复加固，忽略另一侧（如只说测量次数多，不考虑设备是否可靠） |
| confidence | medium |

## 补充说明

增加正向论据的核心思路是"替出题人补漏洞"：题干往往在一侧论据充分（如数据量充足），却忽略另一侧的可靠性验证（如测量工具本身是否可靠），补上缺失的那一侧即为最有力的支持。此外，支持类选项中重复题干已有内容的选项力度极弱，基本不选；应优先选题干未提到的新角度。

## 不适用条件

- 论据→结论存在明显逻辑断点时，应优先用断点搭桥法而非本方法。
- 题干推理链完整且无明显漏洞可补时，本方法不适用。

## 反向触发

- 当发现选项只是重复题干已有论据时，应换用新角度论据或转向断点搭桥法核验。
- 当题干漏洞属于因果倒置或另有他因类时，应换用归因论证质疑三法而非补充正向论据。
