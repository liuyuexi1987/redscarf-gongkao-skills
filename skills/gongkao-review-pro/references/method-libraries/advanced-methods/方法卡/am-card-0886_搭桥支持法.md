# 方法卡：搭桥支持法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 搭桥支持法 |
| 适用题型 | 判断推理——加强削弱·逻辑论证（支持/前提） |
| 触发场景 | 论据→论点存在"断点"（论点中出现论据未提及的新概念） |
| 步骤逻辑 | ① 找论据和论点；② 识别断点（论点中论据没提到的新东西C）；③ 补一个"B→C"或"A→C"的桥梁选项，把论据和论点连起来 |
| 高频错因 | ① 看似相关但没有真正连接断点的选项当搭桥；② 把"支持项"误认为"前提假设" |
| confidence | high |

## 补充说明

搭桥是逻辑论证中最常见的支持方式。核心判断标准：选项是否把论据和论点中"不一样的地方"给连起来了。

## 不适用条件

- 论据和论点之间没有概念断点（两者讨论的是完全相同的对象和属性），此时搭桥不适用，应考虑直接加强论据。
- 题目问的是削弱而非加强，应转用搭桥削弱法。

## 反向触发

- 题目要求加强/支持，且论点中出现了论据未提及的新概念（断点）。
- 题干有"论据…因此论点…"的结构，需要找一个能把论据和论点连接起来的前提。
