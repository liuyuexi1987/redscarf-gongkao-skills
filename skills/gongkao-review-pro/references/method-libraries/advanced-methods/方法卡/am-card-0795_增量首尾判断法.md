# 方法卡：增量首尾判断法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 增量首尾判断法 |
| 适用题型 | 资料分析——判断连续月份/年份增量是否超过某阈值（如500万） |
| 触发场景 | 题目问"增量超过X"的月份/年份有几个，需要逐个比较相邻数据 |
| 步骤逻辑 | ① 确定阈值的有效位（如500万→看百位，后两个零不看）；② 只算两数之差的首位：首位>5→增量一定超阈值；首位<5→一定不够；③ 首位=5时，看后面位够不够减：够减则超，不够则不超；④ 无需计算完整差值 |
| 高频错因 | 忘记从哪一年开始比（第一个数据无法判断增量）；首位=5时忘记检查后续位 |
| confidence | medium |

## 补充说明

本质是减法分段法在增量比较中的应用：只看关键位，跳过低位。第一个数据（如2012年）无法判断增量因为没有上一年数据。此法可将逐个精确减法简化为逐个首位比较，大幅提速。当估算误差可能跨越选项或改变结论时，改用精算/验证。

## 不适用条件

1. 阈值的有效位与数据的有效位不在同一量级时，首位判断可能不充分
2. 首位等于阈值首位的频率过高（如连续多个月份首位=5），退化为逐个精算，本法提速效果有限
3. 当估算误差可能跨越选项或改变结论时，改用精算/验证

## 反向触发

1. 看到"增量超过X的有几个"这类逐个比较题型时，立即考虑首尾判断
2. 首位等于阈值首位时，不要跳过，必须检查后续位
3. 自己对某个数据的增量判断不确定时，用完整减法验证一次
