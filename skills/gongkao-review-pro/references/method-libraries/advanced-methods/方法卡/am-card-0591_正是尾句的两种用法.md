# 方法卡："正是"尾句的两种用法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | "正是"尾句的两种用法 |
| 适用题型 | 言语理解——中心理解题 |
| 触发场景 | 文段尾句出现"正是""正是由于"等表述时，需要判断其功能是"强调"还是"引出结论" |
| 步骤逻辑 | ① 用法一（强调）：尾句"正是+X"直接对前文某个观点进行强化说明，此时"正是"后面的内容就是文段中心；② 用法二（引出结论）：尾句是"正是由于...的原因"结构，前面铺垫原因/价值，"正是"后面引出结论/做法/结果，此时结论部分才是重点；③ 判断方法：看"正是"后面是否有"由于""因为"等表原因的词，若有则用法二，结论在更后面 |
| 高频错因 | 只看到"正是"就认为是强调，忽略了"正是由于"是引出结论的结构；把"正是"前面铺垫的原因当成文段中心 |
| confidence | high |

## 补充说明

用法一（强调）："正是+X"直接对前文某个观点进行强化说明，"正是"后面的内容即文段中心。用法二（引出结论）："正是由于…（原因/价值），（结论/做法/结果）"结构中，前面铺垫原因或价值，"正是"后面引出结论或做法，此时结论部分才是重点。判断方法：看"正是"后面是否跟"由于""因为"等表原因的词，若有则为用法二，结论在更后面；若无则为用法一，"正是"后即中心。

## 不适用条件

- 文段尾句无"正是""正是由于"等表述时，本方法不适用。
- "正是"出现在文段中间而非尾句时，其功能判断需结合整体结构，本尾句方法不直接适用。

## 反向触发

- 当"正是"后跟"由于/因为"但结论部分缺失或不明确时，应换用中心理解题的一般方法，结合全文找重点。
- 当"正是"前后内容均为原因铺垫、无明确结论时，应换用概括类方法提取全文核心。
