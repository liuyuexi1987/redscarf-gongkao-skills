# 方法卡：百分点与百分比辨析

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 百分点与百分比辨析 |
| 适用题型 | 资料分析-占比变化表述理解 |
| 触发场景 | 材料中出现"占比提高X""占比下降X"等表述，需判断是百分点差值还是百分比增速 |
| 步骤逻辑 | 材料中占比的变化一律理解为百分点（差值）-> 不可当作占比的"增速"来用 -> 占比的增速在实际题目中无意义 |
| 高频错因 | 把"占比下降0.8个百分点"误读为占比增速-0.8%，导致乘积增长率公式中R2取错 |
| confidence | high |

## 不适用条件

1. 题目明确要求计算占比自身的百分比增速时，需按公式精确计算
2. 材料中的"提高/下降"描述对象不是占比而是其他比例指标时，不适用本辨析规则

## 反向触发

1. 若题目考查百分点差值的具体计算（如"占比提高了几个百分点"），直接做减法即可
2. 若估算误差可能跨越选项时改用精算
3. 若材料同时给出前后两年占比，可直接比较而无需辨析表述含义
