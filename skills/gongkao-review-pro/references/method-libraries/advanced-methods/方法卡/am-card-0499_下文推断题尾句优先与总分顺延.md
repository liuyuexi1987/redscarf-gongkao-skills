# 方法卡：下文推断题尾句优先+总分顺延

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 下文推断题尾句优先+总分顺延 |
| 适用题型 | 下文推断题 |
| 触发场景 | 下文推断题，需判断下文会讲什么 |
| 步骤逻辑 | 1)优先看尾句，从尾句话题出发找选项 2)尾句找不到答案时，看前文是否有总分结构 3)总句提到两方面但分述只讲了一方面，下文顺延讲另一方面 4)排除跳跃性选项（跳到文段中间某个细节去展开） |
| 高频错因 | 只看尾句细节（如"牛看着两岸"），选了跳跃性选项（如讲神话传说）；忽略总分结构中未展开的部分 |
| confidence | medium |

## 不适用条件

1. 尾句是对前文的总结且无新话题引入时，需回到文段主题而非尾句话题
2. 文段为递进或转折结构而非总分并列时，尾句可能不是下文衔接的关键

## 反向触发

1. 若尾句和前文均无明显话题落点，需回到文段整体主题来推断
2. 若选项中有两个都与尾句话题相关，需对比哪个与前文逻辑更连贯
3. 若文段有明确结论句（如"因此""综上"），结论句优先于尾句
