# 方法卡：转折强弱判断法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 转折强弱判断法 |
| 适用题型 | 言语理解——主旨概括/意图判断（转折结构文段） |
| 触发场景 | 文段中出现"但是""然而""却"等转折词时，需判断该转折是强转折还是弱转折 |
| 步骤逻辑 | ① 强转折：前面铺垫（夸奖、介绍），转折后直接说问题/否定→转折后是重点，前面只是铺垫；② 弱转折：前面是主体内容，转折后只是补充（如"但也得注意身体"）→转折更像并列，不是重点；③ 判断标准：转折后是否改变了前面的核心判断——若完全逆转则强，若只是补充则弱；④ 晚出现的转折（前面铺垫很长）往往是强转折，关注转折后内容 |
| 高频错因 | 把弱转折当成强转折，忽略前面的主体内容；转折后只是小补充却当成重点选；对比文段没有把变化体现出来 |
| confidence | medium |

## 补充说明

- 强转折的生活类比：先夸对方各种好，然后说"但是我们不太合适"——前面是铺垫，后面才是真意。
- 弱转折的生活类比：考前要努力学习，"但也得注意身体"——后面只是补充，不是重点。
- 对比文段（时间对比/他国vs我国）：重点在变化，选项要体现"过去怎么样→现在怎么样"的对比。我国往往是重点。

## 不适用条件

1. 文段中无转折词，不适用本方法，应按文段整体结构判断。
2. 转折词出现在从句或非主干位置（如"他认为……然而……"），此处转折是引述内容内部的转折，不代表作者的立场转向。
3. 文段为并列结构（一方面……另一方面），即使有转折词也是补充性质，不能简单按"转折后=重点"处理。

## 反向触发

1. 如果转折后内容是具体对策，应结合前对策结构抓对策法锁定答案。
2. 如果转折后只是换了一个角度继续介绍同一事物（非否定前文），应视为并列，用主体一致性排除法判断选项。
3. 如果文段为对比结构（时间/地域），转折弱不等于不用关注——需看整个对比关系，选项要同时体现两端。
