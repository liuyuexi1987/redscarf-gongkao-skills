# 方法卡：加法思路比减法简单

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 加法思路比减法简单 |
| 适用题型 | 资料分析——计算策略 |
| 触发场景 | 资料分析中需要做减法计算时 |
| 步骤逻辑 | ① 能用加法代替减法时优先用加法；② 从右往左用加法思考（如算A-B→想B+?=A→从右往左逐位加）；③ 加法口算比减法快且不容易出错；④ 涉及减法时：先判断能不能转化为加法 |
| 高频错因 | ① 直接做减法→容易借位出错；② 不习惯加法思维→效率低 |
| confidence | high |

## 补充说明
核心计算策略。做减法时，从右往左用加法思考（如算347-189→想9+8=17→进位...），比直接减法更不容易出错。前提：加减法口算要特别熟练。

## 不适用条件
- 减数和被减数位数差异大、加法逆向凑数反而不直观时，仍用直接减法。
- 涉及连减或带括号的多步运算时，简单加法逆向思维可能掩盖符号错误。
- 数字含小数/分数且精度要求高时，加法凑算误差风险增大。

## 反向触发
- 当选项差距很小、需要精确到末位时，应改用直接精算并逐位核对。
- 当题目考查的是估算范围而非精确值时，应换用首数法或尾数法。
- 当减法运算嵌套在乘除中时，应优先整体结构分析，再决定是否转化为加法。
