# 方法卡：选项主干优先不抠字眼

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 选项主干优先不抠字眼 |
| 适用题型 | 主旨题/中心理解题 |
| 触发场景 | 选项主干（主语+宾语）正确，但在动词或修饰词上有差异时纠结 |
| 步骤逻辑 | 1)看选项先看主干（主语和宾语），主干不对直接排 2)一般不抠修饰词或动词 3)只有当两个选项主干完全相同时，才去抠修饰词/动词/形容词的差异 |
| 高频错因 | 主干还没对比清楚就纠结"促使""促进"等动词用词 |
| confidence | medium |

## 不适用条件

1. 题目明确考查词语辨析或文段细节时，需要抠字眼而非只看主干
2. 两个选项主语和宾语完全相同，差异仅在动词或修饰词时，必须对比修饰词差异

## 反向触发

1. 选项主干有两组都匹配文段主旨时，需通过修饰词和动词的准确性来进一步排除
2. 文段是细节理解题而非主旨题时，不能用主干优先，必须逐项对照原文
