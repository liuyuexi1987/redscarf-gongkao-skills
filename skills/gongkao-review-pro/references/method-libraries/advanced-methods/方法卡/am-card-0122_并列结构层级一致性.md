# 方法卡：并列结构层级一致性

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 并列结构层级一致性 |
| 适用题型 | 语句填入题、排序题、中心理解题 |
| 触发场景 | 文段出现分号、"一方面…另一方面""同时""此外"等并列标志，需要判断并列部分是否成立或填入内容是否对齐 |
| 步骤逻辑 | 1. 识别并列结构的标志（分号、相同句式、并列关联词） 2. 判断并列的两部分是否在同一逻辑层面但不同角度（如功能层面 vs 数量层面） 3. 若两部分实际在重复同一话题（如都在讲同一事物的同一侧面），则不能构成有效并列 4. 语句填入题中，填入内容须与并列的另一部分在话题和结构上平行 5. 排序题中，并列的两部分必须紧邻且层级对等 |
| 验证动作 | 填入或排列后，检查并列的两部分是否确实分属不同逻辑层面；若两部分可被合并为同一句话，则不构成有效并列 |
| 不适用条件 | 主旨题中并列结构的解题重点是概括全面（参见"并列结构全面概括法"），而非层级判断；本方法侧重结构层面的对等性验证 |
| 高频错因 | 仅从语感判断流畅性而忽略结构层级；将同一话题的重复表述误认为有效并列（如两部分都在讲"数量"而非分属"功能"与"数量"两个层面） |
| confidence | high |
| 反向触发 | ①并列的两部分虽表面层级对等，但其中一个部分与后文构成递进或因果关系（而非简单并列），此时应换用递进/因果分析法；②语句填入题中，填入内容与并列另一部分层级对齐后仍有多余选项符合，需进一步用话题顺承或关联词精确定位；③并列两部分合并后文意基本不变（仅为修辞效果），说明层级差异不是解题关键，应换用其他排除手段 |
