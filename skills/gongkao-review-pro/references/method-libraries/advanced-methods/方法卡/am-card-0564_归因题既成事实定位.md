# 方法卡：归因题既成事实定位

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 归因题既成事实定位 |
| 适用题型 | 判断推理——归因质疑题（题干包含研究发现+原因解释） |
| 触发场景 | 题干先给出研究发现（既成事实），再给出原因解释；选项容易干扰在"为什么会有该现象"而非"为什么会传染/传播" |
| 步骤逻辑 | ① 分清既成事实和原因解释：研究发现了什么（如"肥胖具有传染性"）vs 研究者解释了什么（如"因为体重接受标准提高"）；② 质疑时只针对原因解释，不质疑既成事实本身；③ 排除所有讨论"为什么会发生该现象"的选项（话题偏移），只保留讨论"为什么会传染/传播"的选项 |
| 高频错因 | 把"为什么胖"和"为什么传染"混为一谈；用讨论个体成因的选项去质疑传播机制 |
| confidence | high |

## 补充说明

核心难点：题干归因的是"传染/传播原因"（为什么A发生变化后B也发生同样变化），不是"个体发生原因"（为什么个体会出现该现象）。质疑时只针对原因解释，不质疑既成事实本身。

干扰项识别：
- 讨论个体成因的选项（如基因影响、个人情绪压力导致行为变化等）不涉及传染/传播机制，应排除。
- 讨论群体聚集方式（如"同类人倾向相互结交"）的选项不涉及传染机制，应排除。
- 只有切中"传染/传播机制"（如行为习惯受密切接触者影响）的选项才是有效质疑。

既成事实（研究发现的传播性本身）不可质疑，所有质疑必须指向"为什么会传染/传播"。

## 不适用条件

- 题干不含"研究发现+原因解释"的双重结构（只有单一结论）时不适用。
- 题目问法为"加强"而非"削弱/质疑"时，应换用补强原因解释的思路。
- 题干归因的是个体成因而非传播机制时，应按一般归因削弱处理。

## 反向触发

- 当题干归因的是个体成因而非传播机制时，应换用"他因削弱"或"因果倒置"法。
- 当选项中没有切中传播机制的项时，应回头核验"既成事实"与"原因解释"的区分是否准确。
- 当既成事实本身存在样本或统计瑕疵时，可换用"样本代表性质疑"法（但需确认题目允许质疑事实）。
