# 方法卡：经济利润利润率与乘积增长率

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 经济利润利润率与乘积增长率 |
| 适用题型 | 数量关系-经济利润问题 |
| 触发场景 | 题目涉及钱、利润、标价、成本、打折、提价等关键词 |
| 步骤逻辑 | 1. 识别题型：出现钱/利润/标价/成本 → 经济利润问题；2. 利润率定义：数量关系中 = 利润÷成本（注意：资料分析中 = 利润÷收入，二者不同！）；3. 由利润率和售价反推成本：成本 = 售价 / (1+利润率)；4. 先涨R1再降R2 ≠ 原价！实际变化率 = R1 + R2 + R1×R2；例：涨10%再降10% → 10%-10%+10%×(-10%) = -1%，实际变为原价的99%；5. 多段变化逐次连乘：最终价格 = 原价 × (1+R1) × (1+R2) × ... |
| 高频错因 | 误以为涨10%再降10%等于原价；混淆数量关系和资料分析中利润率的定义 |
| confidence | medium |

## 不适用条件

1. 题目只涉及单次买卖，无多段涨跌或打折提价的连乘结构
2. 给出所有具体金额，无需用利润率反推或用乘积增长率
3. 题目属于资料分析中的利润率（利润/收入），而非数量关系的利润率（利润/成本）

## 反向触发

1. 题目直接给出成本、售价、利润的具体数值，无需反推
2. 出现"资料分析""利润率 = 利润/收入"，定义不同不能套用
3. 只有一次涨价或一次降价，无多段连乘
