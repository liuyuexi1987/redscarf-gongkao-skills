# 方法卡：工程最少花费优化
## 基本信息
| 字段 | 值 |
|------|-----|
| 方法名 | 工程最少花费优化 |
| 适用题型 | 数量关系-工程问题（求最少花费/报酬） |
| 触发场景 | 已知两两合作的时间和总报酬，求三人合作的最少花费 |
| 步骤逻辑 | 1.由两两时间和报酬算出各人时薪（总报酬÷时间得两两时薪之和，再解方程组）；2.由时间和最小公倍数设工作量，算出各人效率；3.优先安排时薪低的人全程工作；4.剩余工作量由次便宜的人补足，算出总花费 |
| 高频错因 | 酬劳是按小时计算而非按项目总额计算，需确认题目含义；未验证时薪低的人效率能否在限定时间内完成 |
| confidence | high |
## 不适用条件
- 题目报酬按项目总额计算而非按小时计算，无法拆出时薪
- 人数超过三人或仅给出少于两组的合作数据，方程组不可解
- 存在最低工作时长、必须同时开工等约束条件，纯贪心策略不成立

## 反向触发
- 题目问"最多花费"而非最少花费——需反向贪心，选最贵的人优先
- 所有人时薪相同——无优化空间，直接用总工作量乘时薪即可
- 题目只给总时间和总报酬，未给出两两合作数据——无法拆分时薪

## 补充说明
这类题的核心思路：先算单价（时薪），再用贪心策略安排人。步骤：(1)两两时薪之和=总报酬÷时间；(2)三组方程联立解出各人时薪；(3)设工作量为时间最小公倍数，算出各人效率；(4)优先让便宜的人干满全程，差额由次便宜的人补齐。计算时可用尾数法验证。
