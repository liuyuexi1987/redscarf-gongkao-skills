# 方法卡：假设法判断真假话

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 假设法判断真假话 |
| 适用题型 | 真假话/达标判断题（逻辑判断） |
| 触发场景 | 题干给出多个关于"谁达标/谁没达标"的条件，其中一个条件具有二选一结构（如"两人要么都达标要么都没达标""要么都选要么都不选"） |
| 步骤逻辑 | 1. 找到最特殊的二选一条件（只能取两种情况之一）；2. 假设其中一种情况成立，沿所有条件逐步推理；3. 若推出矛盾（如与另一已知条件冲突）→ 该假设不成立 → 另一种情况必然成立；4. 将确定情况代入其余条件，继续推理至能回答题目 |
| 验证动作 | 将得出的确定结论代回所有原始条件，检查是否全部满足；若有任一条件不满足则回溯检查推理链 |
| 不适用条件 | 题干条件之间存在明显矛盾对（一真一假）时，优先用矛盾法而非假设法；所有条件均为同一方向（无二选一结构）时，本法不触发 |
| 高频错因 | 从普通条件入手推不出来就放弃，不敢假设；想一步到位推出所有信息而不逐步推理；假设一种情况推出矛盾后忘了记录确定结论 |
| confidence | high |
| 反向触发 | 假设一种情况后推理未出现矛盾，但也无法推出确定结论（即两种假设均自洽），说明遗漏了某个条件或条件之间的隐含关系，应回溯补充条件再重新假设；假设后推出的结论与题干"只有一人说真话/只有一人达标"等数量约束冲突时，该假设不成立，无需继续推理即可确定另一种情况 |
