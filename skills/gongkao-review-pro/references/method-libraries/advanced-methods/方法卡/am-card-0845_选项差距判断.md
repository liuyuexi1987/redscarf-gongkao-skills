# 方法卡：选项差距判断

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 选项差距判断 |
| 适用题型 | 资料分析——所有题目·决定计算精度的关键前置步骤 |
| 触发场景 | 找到数据后、开始计算前，需要判断选项间差距大小以决定计算精度 |
| 步骤逻辑 | ① 乘除类结果先看选项的相对差距（差值÷较小选项），不要只看绝对差值；② 根据选项差距与所用近似方法的误差上界选择精度；③ 差距明显大于误差时可估算，差距接近误差时必须提高精度或反代验证；④ 若计算的是中间量，应检查中间量误差最终会否跨选项 |
| 高频错因 | ① 只看绝对差值，不看结果量级；② 机械套固定百分比档位，忽略具体估算方法的误差；③ 题目问A却只检查中间量B的差距；④ 估算结果位于选项边界附近仍强行选择 |
| confidence | high |

## 补充说明

乘除关系主要看相对差距，加减关系主要看绝对差值。精度判断的核心不是死记固定档位，而是比较“选项间距”和“当前算法可能产生的误差”：只有误差不足以跨越选项时，估算才安全。

## 不适用条件

- 加减类运算（如增长量求和、比重差值）看的是绝对差值而非比例，本方法的"比例差距"逻辑不适用
- 题目选项为"以上都对/以上都不对"等非数值型选项时，无法判断差距
- 选项包含不同量级（如一个选项是百位数、另一个是万位数）时，差距一目了然，无需本方法

## 反向触发

- 看到任何资料分析题、开始计算前 → 用本方法判断选项差距以决定精度
- 选项差距已明确很大（一眼看出） → 可跳过本方法直接估算
- 题目是纯文字判断题（无数值计算） → 不用本方法
