# 方法卡：前提假设不要求唯一性

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 前提假设不要求唯一性 |
| 适用题型 | 前提假设类题目（逻辑判断） |
| 触发场景 | 选项出现"唯一有效方法""唯一途径""唯一方式""只有这样才能"等唯一性表述 |
| 步骤逻辑 | 1. 看到"唯一"字眼先警觉——前提假设不要求方法的唯一性；2. 题干只需论证"某个方法有效"，不要求"它是唯一有效的方法"；3. 用否定代入法检验：否定"它是唯一的"（即"还有其他途径"）→ 原方法仍有效 → 结论仍成立 → 该唯一性表述不是必要前提 |
| 验证动作 | 对含"唯一"的选项做否定代入：否定唯一性后，若结论仍能成立，则该选项不是必要前提；若否定后结论不成立，则该选项确为前提 |
| 不适用条件 | 当题干论证结构确实隐含"只能通过这一种方式"时（如定义性约束），唯一性表述可能是真正的前提；需结合题干逻辑判断，不能机械排除所有"唯一"选项 |
| 高频错因 | 把"力度强"等同于"是前提"——含"唯一"的选项支持力度通常很强，但强支持不等于必要前提；忽略否定代入法的验证步骤 |
| confidence | high |
| 反向触发 | 否定代入检验时发现否定该选项后结论确实不成立，说明该选项就是必要前提，应确定答案而非机械排除；题干论证的核心逻辑确实建立在"排他性"基础上（如"只有该因素能解释此现象"），则唯一性表述可能是真正的前提假设，不能仅因本法的通用倾向就排除 |
