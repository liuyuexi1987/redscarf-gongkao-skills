# 方法卡：除非否则翻译与肯后推不出

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 除非否则翻译与肯后推不出 |
| 适用题型 | 判断推理——翻译推理类（含"除非…否则""只有…才"等联结词） |
| 触发场景 | 题干含"除非A否则B"句式；或需判断"某条件在箭头中点（肯后）能否推出结论" |
| 步骤逻辑 | ① "除非A否则B"→拆开"否则"→翻译为"否A则B"；② 写出原命题和逆否命题两条链：否A→B，非B→A；③ 肯后（箭头终点）推不出任何结论；④ "有些"（部分）包含两种情况——真部分和全部——也推不出确定结论 |
| 高频错因 | 把"除非否则"翻译成"若A则B"（方向搞反）；在肯后位置强行推理（如"有人参与植树"→"能领证"，实际推不出） |
| 不适用条件 | 题干无联结词（"除非…否则""只有…才""若…则…"）；纯日常语义理解题不涉及形式逻辑翻译 |
| 反向触发 | 题干出现"除非A否则B"句式需翻译为"否A→B"；题目问"肯后能否推出结论"时答案为"不能" |
| confidence | high |

## 补充说明

题干问法三种变体需注意区分：一定为真、一定为假、无法判断真假。忠于箭头方向，起点能推、终点推不出。
