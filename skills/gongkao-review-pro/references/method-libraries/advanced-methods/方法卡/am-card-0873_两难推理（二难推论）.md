# 方法卡：两难推理（二难推论）

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 两难推理（二难推论） |
| 适用题型 | 组合排列题、选人/选物问题 |
| 触发场景 | 两个假言命题的后件相同（或可推导至相同），前件互为矛盾（A和否A） |
| 步骤逻辑 | 1. 识别两个命题：A→B 和 否A→B；2. 不管A成不成立，B都必然成立；3. 变体：A→B 且 A→否B → A必然不成立 |
| 高频错因 | 把两难推理和递推混淆；忘记"或"命题等价于否A推B的形式 |
| confidence | high |

## 补充说明

该方法将两难推理分为三种形式：①A推B、否A推B→B必真；②A推B、A推否B→A必假；③A推B、否A推C→B或C至少一真。考频最高的是前两种。

## 不适用条件

1. 两个假言命题的前件不是严格的矛盾关系（如A和B，而非A和否A）时，不能直接套用两难推理。
2. 当后件不能统一为同一命题或其矛盾时，两难结构不成立，应换用递推串联或假设法。

## 反向触发

1. 当两难推理只能推出"至少一个为真"（第三种形式）而题目要求确定具体哪个时，需结合其他条件进一步限定。
2. 当题干中"或"命题的等价转化不明确时，应先验证"否A推B"与"A或B"是否真等价，避免误用。
