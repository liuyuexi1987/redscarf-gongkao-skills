# 方法卡：相似比与面积比关系
## 基本信息
| 字段 | 值 |
|------|-----|
| 方法名 | 相似比与面积比关系 |
| 适用题型 | 数量关系-几何问题（折叠/相似三角形求面积） |
| 触发场景 | 图形折叠后求某部分面积，出现两个相似三角形 |
| 步骤逻辑 | 1.识别相似三角形，确定对应边；2.求出相似比（小比大）；3.面积比=相似比的平方；4.用面积比的份数关系算出所求区域面积 |
| 高频错因 | 相似比的顺序搞反（小/大 vs 大/小），导致面积比反向 |
| confidence | high |
## 不适用条件
- 图形不是相似关系（如不规则多边形折叠后无相似三角形）——无法用面积比=相似比²
- 题目已直接给出面积比，不需要再通过相似比推导
- 涉及三维体积问题——体积比是相似比的立方，公式不同

## 反向触发
- 题目给出面积比，要求反推边长比或相似比——需开方而非平方
- 求的是不规则区域面积且无法拆分为相似三角形组合——本法不适用
- 题目涉及的是全等而非相似——全等比是1:1，无需平方

## 补充说明
折叠问题中折痕两侧图形全等，利用"直角+公共角"识别基本相似模型。面积比是相似比的平方，所以1:2的相似比对应1:4的面积比。再结合全等区域的面积关系，即可用份数法快速求出目标面积。
