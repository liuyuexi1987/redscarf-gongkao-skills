# 方法卡：归因题分组看程度副词法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 归因题分组看程度副词法 |
| 适用题型 | 归因类论证题（支持/削弱），题干为对比实验 |
| 触发场景 | 题干结论出现"大量""过量""显著"等程度副词；实验涉及吃/没吃、多/少等分组 |
| 步骤逻辑 | 1. 读结论时注意是否有程度副词（如"大量食用"而非"食用"）；2. 确定分组依据：不是"吃vs没吃"，而是"大量vs不大量"；3. 支持/削弱选项的分组必须与结论的分组一致；4. 若选项分组与结论分组不匹配（如按"吃没吃过"分组而非"量"），则为分组错误 |
| 高频错因 | 忽略程度副词，把分组按常识理解为"吃vs没吃"，选了分组错误的选项 |
| confidence | high |

## 不适用条件

1. 题干结论不含程度副词（如"大量""过量""显著"），仅提"食用/使用"等无量级表述
2. 实验不涉及分组对比（如前后对比设计、单组观察）
3. 问法为推理/推出类，而非支持/削弱

## 反向触发

1. 题干结论只提"是否使用"而非"大量/少量使用"，不存在分组歧义
2. 实验设计为同一对象前后对比（如干预前vs干预后），而非分组对比
3. 选项的分组依据与结论的分组依据完全一致，无需额外校验
