# 方法卡：误差分析微调

## 基本信息
| 字段 | 值 |
|------|-----|
| 方法名 | 误差分析微调 |
| 适用题型 | 资料分析-估算后结果卡在两个选项之间 |
| 触发场景 | 粗算结果落在两个选项边界附近，无法直接判断 |
| 步骤逻辑 | 1. 明确近似取值的方向（把32.4%当成33.3%，降幅扩大）<br>2. 推导近似对中间结果的影响方向（降幅扩大→增量算大→基期算大）<br>3. 反向修正最终结果（减去的基期偏大→最终结果应偏大）<br>4. 根据修正方向选择正确选项 |
| 高频错因 | 忽略近似方向导致修正方向反了；不确定哪些量是精确的哪些有误差 |
| confidence | high |

## 补充说明
- 误差分析的核心逻辑链：近似方向 → 中间量偏移方向 → 最终结果偏移方向。
- 例如：-32.4%被近似为-33.3%（降幅扩大），导致增量（下降量）被算大，基期被算大，最终结果=总量-其他月之和（某月被高估）→结果应比粗算值略大。
- 误差分析通常只需判断"大一点"或"小一点"，不需要精确修正数值。

## 不适用条件
1. 当选项间距很大（粗算结果明显更靠近某选项）时，无需做误差分析。
2. 当粗算过程中的近似方向不确定（数据本身有正有负、方向不一致）时，误差分析难以得出可靠结论。
3. 当有多步近似且每步误差方向相反时，误差可能互相抵消，微调结论不可靠。

## 反向触发
1. 当粗算误差上界仍不足以跨越最近选项边界时，可以停止；否则继续做误差分析或精算。
2. 当误差分析后方向仍不确定时，改用精算校验。
3. 当原始数据本身精度有限（如百分比只保留整数），误差分析的精度已超出数据精度，收益不大。
