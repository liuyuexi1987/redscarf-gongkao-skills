# 方法卡：词汇盲区降权法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 词汇盲区降权法 |
| 适用题型 | 逻辑填空/言语理解——词汇盲区错因 |
| 触发场景 | 选项中出现不认识的词，无法判断其含义 |
| 步骤逻辑 | ① 不认识的词先降权（不作为首选项）；② 用其他认识的词先排除（搭配/语境/感情色彩）；③ 如果其他词都排除了，只剩不认识的词→选它（反向排除）；④ 如果都不认识→用字面拆解法猜方向（褒贬/程度/适用对象） |
| 高频错因 | ① 因为不认识某个词就直接跳过，没有用其他空的排除结果反推；② 凭字面感觉硬选，结果选了词义完全不对的词 |
| confidence | high |

## 补充说明
遇到不认识的词是常态，不要慌。策略：先用认识的词排除，再用不认识的词兜底。如果一个词的字面拆解能看出褒贬倾向（如"殚精竭虑"→"竭"→贬义偏执），可以作为辅助判断。做完题后，不认识的词要积累到词义辨析库中。

## 不适用条件
- 所有选项都认识，无词汇盲区需要降权处理。
- 不认识的词无法通过字面拆解获得任何方向信息，且其他空也无法排除。
- 其他空的排除结果已经能确定唯一答案，无需用到不认识的词。

## 反向触发
- 当所有选项都不认识时，应换用语感推断或主题词排除验证法从文段主题切入。
- 当字面拆解得出方向后仍需验证时，需补充搭配验证或感情色彩匹配法核验。
- 当不认识的词成为最终候选时，应结合语境解释对应法反向验证其语义方向。
