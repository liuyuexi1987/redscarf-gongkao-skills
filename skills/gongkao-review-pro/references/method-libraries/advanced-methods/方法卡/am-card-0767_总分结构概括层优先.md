# 方法卡：总分结构概括层优先

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 总分结构概括层优先 |
| 适用题型 | 片段阅读-中心理解题 |
| 触发场景 | 文段首句是总括句，后文分点展开（如总-分1-分2结构） |
| 步骤逻辑 | 1. 识别总分结构：首句概括，后文分述（用"首先/其次/另外"或并列展开）；2. 选对应总括句的选项，不选只对应某一分述点的选项；3. 如果选项B=A+C（A对应分1，C对应分2），选B；4. 总分结构中尾句不一定是重点，不要过度关注尾句 |
| 高频错因 | 只盯最后一个分述点选答案，选了片面选项；或被分述细节吸引 |
| confidence | medium |

## 不适用条件

1. 文段不是总分结构（如分总、并列、递进），总括句不存在时不能套用
2. 题目问的是细节或分述点中的某个具体内容，而非主旨概括
3. 首句只是引出话题的背景句，真正的总括在后文时，不能把首句当概括层

## 反向触发

1. 文段没有总括句，分述点之间是并列或对比关系——此时需归纳而非找概括层
2. 选项中有多个都对应总括句，需要进一步区分表述准确度
