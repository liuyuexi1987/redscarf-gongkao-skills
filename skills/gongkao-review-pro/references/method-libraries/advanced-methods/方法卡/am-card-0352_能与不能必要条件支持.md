# 方法卡：能与不能→必要条件支持

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 能与不能→必要条件支持 |
| 适用题型 | 判断推理——加强类（前提假设/必要条件） |
| 触发场景 | 结论涉及"将会迁移/将会发生"等未来判断；选项中出现"具备……能力""能……"等表述 |
| 步骤逻辑 | ① 识别结论是对未来的判断（"将会迁徙""将会怎样"）；② 看选项是否出现"能/不能""具备能力"类表述——这提示必要条件方向；③ 支持"将会迁徙"→必须先证明"能迁徙"（会迁徙的前提是能迁徙）；④ 如果题干有漏洞（没说能不能），正确答案优先补漏洞而非重复论据；⑤ 重复题干已有论据的选项（AC类）力度极弱，慎选 |
| 高频错因 | 选了重复题干论据的选项（如"大熊猫喜欢湿润气候"题干已隐含）；忽视"能"是"会"的必要条件，被其他似是而非选项带走 |
| confidence | high |
| 不适用条件 | 1. 题目问削弱而非加强（本方法专用于加强/前提假设方向）\n2. 结论是对已发生事实的描述而非未来判断，"能/不能"不是关键必要条件 |
| 反向触发 | 1. 结论不涉及"将会"类未来判断，而是对已有现象的原因解释——应换用因果链加强方法\n2. 选项既不是必要条件也不是充分条件，而是提供了额外论据支持因果关系——按一般加强力度排序选择 |

## 补充说明

当结论断言某行为“将会发生”时，行为主体具备完成该行为的能力通常是必要条件之一。但“有能力”只补上可行性，不等于证明行为必然发生；还需与其他选项比较是否存在更直接的搭桥、动机或条件支持。
