# 方法卡：倍数常数近似法（年均增长率）

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 倍数常数近似法（年均增长率） |
| 适用题型 | 资料分析——年均增长率计算 |
| 触发场景 | 题目要求计算年均增长率，已知首末年数据 |
| 精确关系 | 若首末倍数为 K、间隔为 n 年，则年均增长率 `r=K^(1/n)-1` |
| 步骤逻辑 | ① 末年÷首年得到倍数 K；② 用经验常数快速定位：1.5倍→42、2倍→75、2.5倍→100、3倍→125；③ 用“对应常数÷间隔年数”估算百分数；④ 将估算结果与选项比较；⑤ 选项接近时改用选项代入或开方计算，不把近似值当作精确答案 |
| 验证动作 | 对候选增长率计算 `(1+r)^n`，检查是否回到倍数 K；估算误差若可能跨越相邻选项，必须精算 |
| 不适用条件 | 间隔年数为1或很小且选项接近；倍数明显超出常数表范围；题目要求精确值 |
| 高频错因 | 把经验常数公式当成精确等式；年份间隔数错；未验证近似误差是否影响选项 |
