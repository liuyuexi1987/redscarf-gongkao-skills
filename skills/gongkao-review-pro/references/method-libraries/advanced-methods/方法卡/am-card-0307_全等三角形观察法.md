# 方法卡：全等三角形观察法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 全等三角形观察法 |
| 适用题型 | 数量关系——平面几何、图形面积 |
| 触发场景 | 规则图形中出现多组可由对应边角验证全等的三角形，需要简化面积计算 |
| 步骤逻辑 | 1. 观察正方形内的三角形，判断是否全等（对应边相等、角相等）；2. 全等三角形面积相同，只需算一个再乘个数；3. 利用正方形边长确定三角形边长（如边长为根号3的正方形）；4. 等腰直角三角形面积 = 直角边² ÷ 2 |
| 高频错因 | 试图严格证明全等而浪费时间不敢用"肉眼观察"判断全等，考试中适度观察是合理的 |
| confidence | medium |
| 不适用条件 | 三角形之间无明显对应边/角相等关系，或题目要求严格证明全等而非直接用结论时 |
| 反向触发 | 观察无法确认全等关系，或三角形虽面积相近但形状差异明显，需逐个计算时 |

## 补充说明

本方法强调：考试中几何题如果能观察出全等/相似关系，直接用结论即可，不必做严格证明。等腰直角三角形的面积公式简单，全等关系一旦确认，三个三角形面积各为1，加起来就是答案。
