# 方法卡：对比实验支持题看对比维度匹配

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 对比实验支持题看对比维度匹配 |
| 适用题型 | 判断推理——支持类（选项均为对比实验型论据） |
| 触发场景 | 结论涉及"不同X对Y有影响"，四个选项都是对比实验设计，需要选最能支持的 |
| 必要输入 | 论点中的对照变量（区分两组的维度）和因变量（要解释的结果差异） |
| 步骤逻辑 | ① 从论点提取完美对比实验的两个维度：对照变量（应有两种不同背景）和因变量（应有两种不同结果）；② 逐项检查选项的对比维度是否与论点匹配：对照变量必须对应论点中的区分因素，因变量必须对应论点中的结果差异；③ 优先选双维度完美匹配的选项，排除维度不匹配的选项后直接选定，不再纠结其余选项 |
| 验证动作 | 确认选定选项的对照变量和因变量均与论点一致，形成完整双维度对比 |
| 不适用条件 | 选项类型混杂（非全部为对比实验）时不能用此法；选项为原理/机制解释或类比支持时应参考其他方法 |
| 高频错因 | 看到选项都在做对比就逐个纠结细节差异，不先比对维度是否匹配；已有维度完美匹配的选项时仍花时间分析模棱两可的选项 |
| confidence | high |
| 反向触发 | 1. 当所有选项的对照变量都与论点匹配、但因变量维度有差异时，应比较哪个选项的因变量更精确对应论点中的结果差异，而非仅看对照变量 2. 当存在双维度完美匹配的选项但该选项的对比方向与论点因果方向相反时（如论点说A导致Y，选项显示A组Y更低），应标记为削弱项而非支持项 3. 当剩余选项均非对比实验型但包含原理/机制解释时，应切换为因果链分析法评估支持力度 |


> **使用边界**：本方法用于提供优先检查方向，不可单独据此作答；最终需回到题干关系、原文证据或选项条件完成验证。
