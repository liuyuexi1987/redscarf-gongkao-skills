# 方法卡：图推元素加减与去同求异法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 图推元素加减与去同求异法 |
| 适用题型 | 判断推理——图形推理 |
| 触发场景 | 题面出现两组或三组图形关系，前一组能看出“复合图 = 已知部分 + 剩余部分”，后一组要求从复合图中去掉已知部分；常见信号包括去同求异、图形相减、保留不同、叠加后拆分、两个图共同元素明显 |
| 步骤逻辑 | ① 先找示范组，不急着数线、数面、数角；② 判断第一幅是否由第二幅和第三幅叠加而成，或判断两幅图相同部分被去掉后是否得到第三幅；③ 明确运算规则：去同求异（去掉共同部分，保留剩余部分）、去异求同（去掉不同部分，保留共同部分）、元素相加（两个图叠成一个图）、元素相减（复合图减去已知图）；④ 把同一规则套到待求组：复合图 - 已知图 = 选项；⑤ 用选项反验证：把候选答案与已知图重新叠加，能否还原复合图 |
| 高频错因 | ① 把去同求异题误判成普通“找共同点”，只说都有线、都有圆，导致解释过泛；② 先数线条/封闭面，忽略题面给出的图形运算关系；③ 没区分“去同求异”和“去异求同”，把该保留的部分删掉；④ 只看选项是否含线/含圆，不做“已知图 + 候选图能否还原复合图”的反验证；⑤ 图片中有手写标注时，误把标注当图形元素参与运算 |
| confidence | high |
| 不适用条件 | 1. 判断推理中非图推子模块（定义判断、类比推理、逻辑判断）
| 反向触发 | 1. 图推题但规律是数量递增/递减时应参考数量规律卡
2. 图推题但规律是旋转/翻转/对称时应参考位置变换卡
3. 空间折叠/展开类立体图推不需要元素加减法 |
2. 图形规律为数量类（点线面角数量递增递减）、属性类（对称性、曲直性）、位置类（旋转翻转平移）、立体类（折叠展开、截面）而非元素运算类
3. 图片严重模糊、重叠部分无法辨认时只能给倾向判断不得硬判 |

## 使用说明

这类题的核心不是“某个元素出现了几次”，而是“两个图之间做了什么运算”。看到一组图形中明显有一幅更复杂、一幅更简单、一幅像剩余部分，就优先尝试图形加减。

常用判断句：

- 若第一图像“第二图 + 第三图”，则待求组也按“复合图 - 已知图 = 缺失图”处理。
- 若两图有明显重叠元素，题目问剩余或变化结果，优先看“去同求异”。
- 若题面强调共同部分或选项保留公共结构，才考虑“去异求同”。

## 输出要求

- 讲解时先写清“本题是图形运算，不是单纯数线/数面”。
- 必须指出示范组的运算关系，再迁移到待求组。
- 对选项至少做一次反验证：已知图 + 候选图是否能还原复合图。
- 若图片不清、重叠部分无法辨认，只能写“倾向于图形加减/去同求异路径”，不得硬判答案。
