# 方法卡：预测类题现在问题不质疑

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 预测类题现在问题不质疑 |
| 适用题型 | 判断推理 > 削弱质疑（对未来预测类论证） |
| 触发场景 | 题干结论是对未来的预测（如"该技术将改变XX"），而非对现状的判断 |
| 步骤逻辑 | 1. 识别结论性质：是对未来的预测/展望，不是对当前的描述；2. "现在还不行""还需很长时间""技术还不成熟"这类选项无法质疑对未来的预测；3. 类比理解：青少年球员现在打不过成人，不代表未来不能改变球队命运；4. 能质疑的选项：指出技术本身有根本缺陷（如影响美观）、替代品有其他功能（涂料还有别的功效） |
| 高频错因 | 看到"现在还不成熟"就以为能质疑，忽略了题干说的是"未来将"而非"现在已" |
| confidence | high |

## 不适用条件

1. 结论是对现状的判断（如"该技术已经改变了XX"），"现在还不成熟"的选项可以直接质疑现状描述。
2. 题干预测带有明确的时间限定（如"未来3年内"），"现在还不行"可以构成"短期内也难以实现"的合理质疑。
3. 选项中的"现在问题"实际上指向该技术的根本性缺陷（非阶段性局限），则属于有效质疑而非仅描述现状。

## 反向触发

1. 当题干结论是混合型（既包含预测又包含现状描述），需先拆分结论结构，再分别判断质疑方向。
2. 质疑选项涉及预测的前提假设（如"该领域不会有增长需求"）而非技术成熟度时，质疑方向正确，应评估力度而非直接排除。
3. 选项出现"永远不会""必然失败"等绝对化表述时，虽与"现在不行"不同，但绝对化本身可能使其力度偏弱，需谨慎评估。
