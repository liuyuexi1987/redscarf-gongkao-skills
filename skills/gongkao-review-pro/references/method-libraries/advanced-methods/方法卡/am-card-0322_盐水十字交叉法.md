# 方法卡：盐水十字交叉法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 盐水十字交叉法 |
| 适用题型 | 数量关系、资料分析——混合平均与十字交叉 |
| 触发场景 | 两组不同浓度、单价或平均值混合成已知总体均值，求两组数量比 |
| 步骤逻辑 | 1. 将两个已知值和混合值排成十字交叉形式；2. 交叉相减（大减小），得到的距离写在对角；3. 两个距离之比 = 对应两个群体的数量之比；4. 如需进一步求总平均值，可将已求出的比例再做一次十字交叉 |
| 高频错因 | 十字交叉得到的是数量（人数/份数）之比，不是浓度之比连续混合时（如ABC三班），需要先合并再交叉，不能跳步 |
| confidence | medium |
| 不适用条件 | 混合后均值未知需要反求原始值的题目；混合涉及三组以上且题目未提供足够两两混合关系的场景 |
| 反向触发 | 十字交叉得到的是数量比而非浓度比或分数比，误读后需重新理解结果含义；三组连续混合时不能跳步，必须先合并两组再与第三组交叉，否则换用设人数列方程的方法验证 |

## 补充说明

强化方法将所有"两组混合求比例"的问题统一为盐水模型。三个班平均分：AB交叉得人数比3:4，BC交叉得4:5，所以ABC=3:4:5。求总平均时再做一次AB(77分)与C(65分)的十字交叉即可。此法可替代设人数列方程的传统方法，速度快得多。
