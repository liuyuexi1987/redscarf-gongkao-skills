# 方法卡：方案-目的题削弱

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 方案-目的题削弱 |
| 适用题型 | 削弱论证——结论结构为"采取某方案/措施能达成某目的" |
| 触发场景 | 题干提炼后核心观点为"方案→能达成目的"，如"社会机构组织考试能令大学英语摆脱应试教育" |
| 步骤逻辑 | ① 提炼题干观点为"方案能达成目的"的结构；② 削弱方向只有两种：方案实施不了，或方案达不成目的（做了也白做）；③ 最强削弱是A且非B：方案实施了但目的达不成 |
| 高频错因 | 选了"有其他原因也会导致该问题"的选项（D），这只能削弱非唯一性，力度不如"做了也没用"强；选了方案带来的附带好处（A），但这可能反向支持方案有效 |
| confidence | high |
| 不适用条件 | 题干结论是纯因果关系（A导致B）而非"方案能达成目的"时，应用归因类削弱方法而非本方法；削弱方向是质疑方案的前提假设（如数据不可靠）而非方案本身的可行性或有效性时，不属于本方法覆盖范围 |
| 反向触发 | 选项中同时出现"方案不可行"和"做了也没用"两类削弱，力度接近时需逐一验证哪个选项的反例更确定再选定答案；题干存在多个并列方案，问题要求比较哪个方案更优时，应换用方案对比分析而非单方案削弱 |

## 补充说明

Q11示例：方案=社会机构组织考试，目的=摆脱应试教育。B"社会机构组织英语考试也会导致应试教育"→方案做了，目的没达成（A且非B），最强削弱。D"应试教育不仅由四六级造成"→虽能削弱（改革单个方案可能不够），但只是"有可能"没用，力度不如B的"一定没用"。
