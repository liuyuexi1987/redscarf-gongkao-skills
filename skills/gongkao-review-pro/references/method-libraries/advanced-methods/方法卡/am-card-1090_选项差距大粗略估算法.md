# 方法卡：选项差距大粗略估算法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 选项差距大粗略估算法 |
| 适用题型 | 资料分析——计算策略 |
| 触发场景 | 资料分析四个选项差距很大（如A.12% B.25% C.38% D.51%） |
| 步骤逻辑 | ① 先找相邻选项的最小间距；② 估计截位、百化分或粗除会带来的误差方向和量级；③ 误差明显小于最小选项间距时可估算，否则用直除、反向代入或精算；④ 算到能唯一区分选项即停，不追求无用小数位 |
| 高频错因 | ① 选项差距大还精确计算→浪费时间；② 选项差距小还粗略估算→精度不够选错 |
| confidence | high |

## 补充说明
计算精度要匹配选项差距。估算不是看见“约”就少算，而是在能判断误差边界且不会跨选项时少算；无法保证时就精算或反代验证。

## 不适用条件

- 选项差距小或选项间存在量级接近的尾数差异时，粗略估算可能导致误选。
- 题目要求精确结果（如求整数倍、求精确占比）时，估算结果不满足作答要求。

## 反向触发

- 估算误差可能跨越选项时改用精算。
- 多次估算结果落在不同选项区间时，应换用精确计算或反向代入验证。
