# 方法卡：两面对一面判断

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 两面对一面判断 |
| 适用题型 | 逻辑填空——语法匹配 |
| 触发场景 | 题干出现"能否/好坏/成败/高低"等两面表述 |
| 步骤逻辑 | ① 识别题干中的两面词（能否/好坏/成败/高低/是否）；② 选项也必须包含两面含义（如"优胜劣汰"=两面）；③ 选项只有一面→大概率错 |
| 高频错因 | ① 题干有"能否"→选项只有"能"→一面→错；② 忽略隐性两面词 |
| confidence | high |

## 补充说明
## 不适用条件
- 题干无两面词（能否/好坏/成败/高低/是否）时，本卡不适用
- 选项与题干均为单面表述且逻辑一致时，无需用两面对一面判断
- 题目考的是语义搭配而非逻辑对应时，应换用其他方法

## 反向触发
- 若题干中无明显的两面表述，不使用本卡
- 若选项中已有明显的两面词对应，无需再用本卡验证
