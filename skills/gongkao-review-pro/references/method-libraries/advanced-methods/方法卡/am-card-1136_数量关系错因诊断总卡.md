# 方法卡：数量关系错因诊断总卡

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 数量关系错因诊断总卡 |
| 适用题型 | 数量关系、数学运算、工程、行程、利润、几何、排列组合、概率、容斥、方程、最值等错因诊断 |
| 触发场景 | 用户做错数量关系题后，讲解/复盘结束，需要判断错因并写入错因卡或弱点档案时 |
| 步骤逻辑 | ① 先查审题限定；② 再查建模关系；③ 再查方法选择；④ 再查计算与单位；⑤ 最后判断是否有策略失误 |
| 高频错因 | 审题限定错、未知数设错、等量关系错、比例关系错、单位时间错、几何关系错、分类漏重、代入顺序不优、计算失误、策略失误 |

- 用户给出思路时，优先对照用户思路归因；用户没给思路时，只能做低置信诊断 |

## 诊断流程

### 第一步：查审题限定

- 问的是总量、单量、剩余量、至少、至多、平均、概率，还是方案数？
- 题干中的时间、单位、对象、条件是否读全？
- 用户答案是否来自看错问法，而不是不会方法？

### 第二步：查建模关系

- 未知数是否设对：总量、单人量、过程量、结果量有没有混在一起？
- 等量关系是否找准：工程、行程、利润、浓度、年龄、和差倍比等是否抓住核心关系？
- 是否把比例、倍数、百分数、份数关系转错？

### 第三步：查方法选择

- 这题更适合代入、特值、方程、枚举、分类讨论，还是先用选项排除？
- 用户是否硬列复杂方程，忽略了选项、奇偶、尾数、范围、倍数等快速信号？
- 排列组合/概率题是否先分清"分类相加"和"分步相乘"？

### 第四步：查计算与验证

- 式子是否正确但算错？
- 单位是否换算：小时/分钟、天/人/效率、面积/体积、半径/直径。
- 结果是否回代验证，是否落在合理范围内？

### 第五步：查策略失误

- 题目是否投入产出过低，应先跳过或放到最后？
- 用户是否在低价值复杂题上耗时过长？

## 错因分类表

| 错因类型 | 判定信号 | 典型表现 | 写入弱点档案的建议标签 |
|----------|----------|----------|------------------------|
| 审题限定错 | 问法和用户计算目标不一致 | 问"至少"算成"恰好"，问"剩余"算成"总量" | 数量-审题-问法限定误读 |
| 未知数设错 | 设的量不是题目真正需要的量 | 把单人效率设成总效率，把过程量当结果量 | 数量-建模-未知数设置错误 |
| 等量关系错 | 方程两边含义不一致 | 工程题没统一工作总量，行程题没统一路程/时间 | 数量-建模-等量关系错误 |
| 比例关系错 | 倍数、份数、百分数转换混乱 | 把"多20%"当成"是20%"，把比例差当实际差 | 数量-比例-比例关系转换错误 |
| 单位时间错 | 时间或单位没有统一 | 分钟和小时混算，人数和效率混算 | 数量-单位-时间单位混用 |
| 几何关系错 | 面积/体积/相似比混淆 | 半径直径混用，线度比平方/立方关系用错 | 数量-几何-空间关系误判 |
| 分类漏重 | 分类讨论不互斥或不穷尽 | 排列组合漏情况、重复计数、概率分母错 | 数量-计数-分类漏重 |
| 代入顺序不优 | 有选项信号却没利用 | 没从中间选项代入，没用尾数/奇偶/范围先排除 | 数量-方法-代入排除顺序不优 |
| 计算失误 | 建模正确但数字处理错 | 加减乘除、小数点、分数化简出错 | 数量-计算-算术失误 |
| 策略失误 | 方法可行但耗时明显不划算 | 复杂题硬做，影响后续高收益题 | 数量-策略-投入产出判断失误 |

## 写回建议

写错因卡/弱点档案时，不要只写"粗心"或"算错"，优先写清楚错在链条哪一层：

- `数量-建模-等量关系错误`：工程题没有统一工作总量，导致方程两边含义不一致
- `数量-计数-分类漏重`：排列组合题分类不互斥，重复计算同一类情况
- `数量-几何-空间关系误判`：相似体体积比应为线度比三次方，误用成平方关系
- `数量-方法-代入排除顺序不优`：选项可快速排除，但用户直接列复杂方程导致耗时

## 使用边界

1. 本卡只用于错因诊断，不替代具体解题方法卡。
2. 题干、选项、单位或答案来源不完整时，先标记待核验，不硬写错因。
3. 用户给出自己的思路时，优先对照用户思路归因；用户没给思路时，只能做低置信诊断。
4. 客观题若复核结果与用户给的官方答案冲突，先按答案冲突复核流程处理，不立即写错因卡。
