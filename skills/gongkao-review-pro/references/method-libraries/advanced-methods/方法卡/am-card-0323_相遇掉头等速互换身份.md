# 方法卡：相遇掉头等速互换身份

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 相遇掉头等速互换身份 |
| 适用题型 | 数量关系——直线往返、相遇掉头 |
| 触发场景 | 两个等速物体相遇后立即掉头，求最终到达时间或终点状态，可用互换身份等价简化 |
| 步骤逻辑 | 1. 两人速度相同，相遇后掉头 → 等价于两人互换身份继续前进；2. 不管中间相遇多少次，等效于每个物体都从自己出发点走到对面终点；3. 只需关注最后一个出发的物体：它的出发时间 + 全程行走时间 = 到达时间；4. 忽略所有中间相遇，直接算"从头到尾"的时间 |
| 高频错因 | 试图追踪每次相遇后的位置变化，计算量爆炸忘记"掉头+等速=互换身份"的核心等价关系 |
| confidence | medium |
| 不适用条件 | 两物体速度不同；运动轨迹为环形而非直线往返；相遇后不掉头而是停下或继续同向运动；题目只要求中间某次相遇的位置 |
| 反向触发 | 当两物体速度不等时，互换身份等价关系不成立，需逐步追踪每次相遇的位置和时间；题目仅要求中间某次相遇结果时，直接按常规相遇公式计算更准确 |

## 补充说明

核心洞察：速度相同条件下，相遇掉头等价于互换身份（"你中有我，我中有你"）。这使得复杂多次相遇问题简化为：只看最后一个士兵出发时间+全程时间。此技巧在"即时战略"类行军问题中尤其有效。
