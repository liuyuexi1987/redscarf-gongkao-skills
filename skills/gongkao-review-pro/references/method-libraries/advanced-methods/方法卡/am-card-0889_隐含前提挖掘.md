# 方法卡：隐含前提挖掘

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 隐含前提挖掘 |
| 适用题型 | 判断推理——加强削弱·前提/假设题 |
| 触发场景 | 论据→论点没有明显断点，但推导过程"莫名其妙" |
| 步骤逻辑 | ① 问自己"凭什么从这个论据能推出这个论点"；② 找出论据推论点必须默认成立的那个隐含条件；③ 用取反法验证：该条件取反后论点不成立 |
| 高频错因 | ① 脑补了论据没说的内容；② 找到的是"支持项"而非"必要前提"（支持项锦上添花但非必须） |
| confidence | high |

## 补充说明

典型例子：论据"辨别不出是否AI写的"→论点"不是AI写的"，隐含前提是"辨别不出=不是AI写的"（即"AI写的都能辨别出来"）。

## 不适用条件

- 论据和论点之间的逻辑关系已经明确，不需要补前提。
- 题目考查的是论证谬误类型识别（如强加因果、以偏概全），而非前提假设。

## 反向触发

- 题目问"上述论证依赖的假设是""上述论证的前提是"。
- 论据推论点的过程感觉"莫名其妙"，似乎跳过了某个关键环节。
