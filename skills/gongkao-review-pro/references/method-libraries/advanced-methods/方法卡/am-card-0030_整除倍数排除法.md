# 方法卡：整除倍数排除法
## 基本信息
| 字段 | 值 |
|------|-----|
| 方法名 | 整除倍数排除法 |
| 适用题型 | 数量关系-和差倍比/比例增长问题 |
| 触发场景 | 已知增长率可化为简单分数（如60%=3/5），求目标量的值 |
| 步骤逻辑 | 1. 将增长率化为最简分数（如60%→3/5）；2. 推断目标量大概率为分母的倍数（如5的倍数）；3. 排除不符合整除条件的选项；4. 代入剩余选项验证 |
| 高频错因 | 忽略增长率的分数特征，直接列方程；未考虑出题人取整数的惯例 |
| confidence | high |
## 补充说明
核心思路：出题人在设计选项时，若涉及增长率的分数运算，通常会让结果为整数。通过分析增长率的分母，可以快速推断目标量的整除性质，从而排除选项。例如60%=3/5，增量=原值×3/5，要使增量为整数，原值大概率是5的倍数。此法配合代入验证，可大幅提速。

## 不适用条件
- 增长率无法化为简单分数（如无理数或复杂百分比），不产生有效整除约束
- 题目答案可能是小数或分数，不依赖整除特性
- 选项之间数值差异极小（如仅差1-2），整除排除法区分度不足

## 反向触发
- 看到增长率/折扣/比例可化为简单分数（如25%=1/4、20%=1/5、60%=3/5）
- 选项中部分值是某分母倍数、部分不是，可用整除快速排除
- 题目涉及"原值""现值""增量"的整数关系推断
