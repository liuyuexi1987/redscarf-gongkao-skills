# 方法卡：一加利润率反比法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 一加利润率反比法 |
| 适用题型 | 经济利润·成本变化导致利润率变化 |
| 触发场景 | 售价不变，成本发生变化，求利润率变化 |
| 步骤逻辑 | 1. 售价 = 成本 ×（1 + 利润率）；2. 售价不变 → 成本与（1+利润率）成反比；3. 成本减少15% → 成本变为17/20 → 1+利润率变为20/17；4. 用份数法：去年17份，今年20份，差3份=24个百分点 → 1份=8个百分点 → 去年1+利润率=136% → 利润率=36% |
| 高频错因 | 只盯着利润率本身看，忽略"1+利润率"才是直接反映售价与成本关系的量 |
| confidence | high |

## 补充说明

类似资料分析中"1+增长率"与基期/现期的关系。

## 不适用条件

- 售价也发生变化（非保持不变）时，"1+利润率"反比关系不成立。
- 题目含税费、运费等附加成本项时，"成本"定义需先明确，否则反比关系失真。
- 涉及多阶段利润率（如先按A利润率卖一部分，再按B利润率卖剩余）时，不能整体套用反比法。

## 反向触发

- 当反比换算后利润率出现负值或超过100%等异常值时，应反向核验题目是否隐含售价变化。
- 当题目同时给"成本变化"和"售价变化"时，应换用售价=成本×(1+利润率)直接列方程。
- 当百分数无法化为简单分数（如17/20以外的复杂比例）时，应改用方程法核验。
