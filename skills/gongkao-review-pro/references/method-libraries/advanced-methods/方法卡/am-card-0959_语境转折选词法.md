# 方法卡：语境转折选词法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 语境转折选词法 |
| 适用题型 | 逻辑填空——语境关系（转折） |
| 触发场景 | 题目出现"但/然而/却/可是/不过/虽然…但是"等转折关联词，且空格在转折后或转折前 |
| 步骤逻辑 | ① 找到转折词，标记转折前后的语义方向；② 转折后为空格→选与转折前语义相反/相对的词；③ 转折前为空格→选与转折后语义相反的词；④ 验证：代入后整句是否构成合理转折 |
| 高频错因 | ① 忽略隐性转折（"其实""事实上""实际上"也算转折信号）；② 转折前后不是完全相反而是程度递减，选了过强的反义词 |
| confidence | high |

## 补充说明
转折定位是逻辑填空最高频的语境信号之一。核心原则：转折后是作者真正想表达的重点，空格在转折后时优先选与前文语义相反的选项。注意"即使…也"不是转折而是让步，不要混淆。

## 不适用条件

1. 文段为纯并列结构（"同时""另一方面""既…也…"），无转折语义，应改用并列选词法。
2. 文段为递进结构（"甚至""不仅…而且"），应改用语境递进选词法。
3. 空格所在句与上下文不存在语义对照关系（如纯定义说明句），转折法无从下手。

## 反向触发

1. 当题目关联词为"甚至""更""不仅…还"等递进词时，应换用语景递进选词法。
2. 当题目关联词为"因此""由于""导致"等因果词时，应换用语境因果选词法。
3. 当题目为并列结构且要求填入与上下文同义同强度的词时，应换用并列同义选词法，不应套用转折相反原则。
