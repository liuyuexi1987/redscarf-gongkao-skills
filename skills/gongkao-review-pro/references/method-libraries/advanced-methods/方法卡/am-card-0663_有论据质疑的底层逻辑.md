# 方法卡：有论据质疑的底层逻辑

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 有论据质疑的底层逻辑 |
| 适用题型 | 一般质疑（有论据有结论 / 无论据有结论） |
| 触发场景 | 题干有论据+结论，问"以下哪项最能质疑"；或题干无论据直接给结论 |
| 步骤逻辑 | 1. 判断题干结构：有论据有结论 vs 无论据有结论；2. 有论据有结论 → 近似看成"论据A推结论B"，质疑找"A且非B"（肯定论据，得出相反结论）；3. 无论据有结论 → 直接用"非A"质疑结论（A与非A的矛盾）；4. 有论据有结论时，不能只说"非B"，必须带上A，否则不构成矛盾 |
| 高频错因 | 只否定结论(非B)而不肯定论据；把"无论据"误判为"有论据" |
| confidence | medium |
| 不适用条件 | 1. 题目问支持/加强而非质疑；2. 论据和结论之间需要补桥而非直接质疑（应先考虑搭桥法）；3. 题干是比较型结论（应考虑比较要说两边法） |
| 反向触发 | 1. 题干问 |

## 补充说明

底层都是A推B与A且非B的矛盾关系。"你考双百我给你买兔子"——女儿说"没买"不能质疑，因为她可能没考双百。
