# 方法卡：先减后比判断增率阈值

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 先减后比判断增率阈值 |
| 适用题型 | 资料分析-增率是否超过某百分比 |
| 触发场景 | 需要判断多个年份的增率是否超过10%/15%/25%等阈值 |
| 步骤逻辑 | 1.用今年数据减去去年数据得到增量；2.将增量与去年数据的阈值百分比比较（如判断是否超10%，就看增量是否>去年×10%）；3.直接读有效数字前几位即可判断 |
| 高频错因 | 用"先乘再加"法（去年×(1+R)再和今年比），计算量大且易错 |
| confidence | high |

## 不适用条件

1. 阈值不是整数百分比（如3.7%）时，"去年×阈值"本身变成非整数心算，先减后比的速度优势下降。
2. 基期数据不可得或仅有图表近似值时，无法精确做"基期×阈值"的比较。
3. 各年增量与阈值差距非常小、需要精确定位边界时，本法只能定性判断大小，可能不足以在极近选项间取舍。

## 反向触发

1. 题目只问"哪一年增速最高/最低"而不设具体阈值——应换用口算比较增速方法（am-card-0060）。
2. 先减后比不能减少计算量，或近似误差可能改变阈值判断时，直接用增速=增量/基期计算更稳妥。
3. 需要精确算出增率数值（而非仅判断是否超阈值）时，本法不提供精确结果，应使用完整增速公式。

## 补充说明

对比两种方法：先减后比只需一次减法+一次比较；先乘再加需要乘法+加法+比较，计算量更大。先减后比只需看增量的前几位有效数字与基期的十分之一（判断10%）比较。方法提示：加法会慢一点。建议多做此类题目感受两种方法的速度差异，特别是15%、25%这类不好直接看出的阈值。
