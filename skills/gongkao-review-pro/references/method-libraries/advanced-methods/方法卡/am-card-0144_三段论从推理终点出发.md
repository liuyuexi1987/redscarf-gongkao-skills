# 方法卡：三段论从推理终点出发

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 三段论从推理终点出发 |
| 适用题型 | 判断推理-三段论补充前提题（给出前提和结论，问需要补充什么前提） |
| 触发场景 | 题干给出若干前提如"所有工作都有报酬""有报酬的工作都用金钱衡量"，结论"公益劳动不是工作"，要求补前提 |
| 步骤逻辑 | 1. 确定推理方向：工作→有报酬→用金钱衡量（正向链条）；2. 逆否：非金钱→非报酬→非工作（反向链条）；3. 结论要推出"公益劳动不是工作"→从**推理终点（非工作）**出发；4. 需要把"公益劳动"和"非金钱"连起来：公益劳动→非金钱→非报酬→非工作；5. **优先选全连起来的选项**（从终点出发把所有前提都用上） |
| 高频错因 | 选了中间断开的选项（如B或C，虽然逻辑上能推出但没把全链连起来）出题人设的正确答案是从推理终点出发、把所有前提都用上的选项 |
| confidence | high |
| 不适用条件 | 1. 题目要求判断现有推理是否有效（而非补充前提）时，不适用本法，应使用三段论有效性判定规则 2. 题干前提涉及多个中项且推理链条超过三步时，从推理终点出发容易遗漏中间环节，应先画推理链路图再定位缺口 |
| 反向触发 | 1. 从推理终点出发后发现需要补的前提涉及题干未出现的新概念，说明推理链路有断裂，应先确认结论中的概念是否都能在已有前提中找到或通过逆否推导得到 2. 剩余选项中有两个都能把全链连起来时，应检查是否有多余前提被引入（有效三段论应恰好用完前提），引入多余前提的选项不是最优 3. 题干前提中有隐含的逆否关系未展开时，直接从结论出发可能遗漏逆否路径，应先将所有前提写成正向和逆否两套再定位缺口 |
