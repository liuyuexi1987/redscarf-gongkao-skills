# 方法卡：图推规律网与观察顺序

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 图推规律网与观察顺序 |
| 适用题型 | 判断推理——图形推理（系统性知识框架） |
| 触发场景 | 需要系统梳理图推规律时；做题卡壳需要切换思路时 |
| 步骤逻辑 | ① 规律不要逐条散背，要整理成排查框架；② 核心框架："345"——3类移动（移动/旋转/翻转）+ 4类变化（变形/叠加/遍历/对称轴旋转）+ 5种叠加（相加/相减/去同存异/去异存同/黑白运算）；③ 观察顺序：先整体预判（相似→移转叠、工整→对称、杂乱→藏与找）→再找相同/识不同→再具体验证规律；④ 九宫格额外路径：横看、竖看、S形看、对角线看、内外圈看 |
| 高频错因 | ① 把规律当字典背，越背越多越混乱，遇到新题还是套不出来；② 不会切换观察路径（如九宫格只横看不竖看）；③ 规律池不全导致漏掉可能的方向 |
| confidence | high |

## 补充说明

规律要整理成排查框架，而不是散点清单。框架的价值是帮助解题时快速切换观察方向；散点清单容易越背越多，遇到新变化仍然不知道从哪里下手。

九宫格观察路径优先级：横看 > 竖看 > S形/对角线 > 内外圈。但不要死板——先看哪条路径取决于图的整体特征。

移动的两种关键考点：怎么移（横/竖/斜/转着移）和移到头怎么办（循环/反弹/消失）。叠加的五种考法中，相减和去同存异的区别在于顺序——相减顺序相关，去同存异顺序无关。

## 输出要求

- 讲图推时先说明观察顺序（宏观→预判→微观）
- 至少展示 2-3 层排查过程
- 图片不清、选项缺失、截图太小时，不得硬判答案
- 没读到具体细卡时，不得伪造卡号
- 有官方答案时按答案核验；无官方答案但图形清晰时，可写"按当前图形规律，我的复核倾向于 X"

## 不适用条件

- 非九宫格题型（如分组分类、立体拼合）的观察路径不适用本卡的九宫格路径部分。
- 图形明显属于单一规律类型（如纯对称轴题）时，无需走完整规律网排查。

## 反向触发

- 规律网排查全部走完仍无规律时，应换用"藏与找"模型或"找相同识不同"策略补充切入。
- 九宫格所有常规路径（横、竖、S形、对角线、内外圈）均不成立时，应考虑跨行/跨列的非常规组合方式。
