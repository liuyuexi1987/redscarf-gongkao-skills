# 方法卡：果因结构抓首句

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 果因结构抓首句 |
| 适用题型 | 片段阅读-中心理解题 |
| 触发场景 | 首句提出结论/结果，后文用大量篇幅解释"为什么" |
| 步骤逻辑 | 1. 首句给出结论（如"中华民族偏爱黄色"），后文全是原因分析；2. 这是果因结构，首句是总括，后文是分述原因；3. 选项应概括首句的结论+后文的原因方向；4. 不要被后文的细节（五行说/儒家/魏文帝）带跑偏，它们只是原因的一部分 |
| 高频错因 | 被后文分述中的某个细节（如皇权观念）吸引，选了片面选项 |
| confidence | medium |

## 不适用条件

1. 文段为并列结构或分总结构时，首句并非结论
2. 首句仅为引子或问句，后文才给出真正的结论
3. 文段无明确因果逻辑链，首句与后文之间不是果因关系

## 反向触发

1. 后文出现强转折（但/然而），结论可能在转折后而非首句
2. 首句是现象描述而非结论判断，需继续读下去才能定主旨
3. 后文分述中嵌套了新的总括句，覆盖了首句的结论
