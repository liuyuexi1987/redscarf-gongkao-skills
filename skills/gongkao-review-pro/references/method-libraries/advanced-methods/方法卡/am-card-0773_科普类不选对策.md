# 方法卡：科普类不选对策

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 科普类不选对策 |
| 适用题型 | 片段阅读-中心理解题 |
| 触发场景 | 文段为科普介绍类（客观介绍现象/知识，无作者观点态度） |
| 步骤逻辑 | 1. 判断文段为科普介绍类（像"十万个为什么"式的客观介绍）；2. 文段无观点无对策无批评，选中性客观概括；3. 出现对策性选项时直接排除——作者没有让人做某事的意思；4. 用反推验证：看选项能否还原出原文的文段类型 |
| 高频错因 | 把科普类文段的积极表述误选为对策（如"大象鼻子为什么长"选成"大象应更努力"） |
| confidence | medium |

## 不适用条件

1. 文段末尾由科普介绍转入作者建议或呼吁，已带有对策倾向
2. 文段虽涉及科普内容但包含作者明确的批评或观点表态
3. 题目要求选"意在强调"或"作者意图"，需比概括更进一步

## 反向触发

1. 文段末尾出现"应该/需要/必须"等对策信号词
2. 文段带有明显的褒贬态度，不是纯中性介绍
3. 文段结尾从现象介绍转入观点陈述或建议
