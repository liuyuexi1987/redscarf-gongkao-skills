# 方法卡：前提类题从论据到结论的推理方向

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 前提类题的推理方向 |
| 适用题型 | 判断推理——前提假设类（"得出上述结论的前提"问法） |
| 触发场景 | 题目问法为"得出上述结论的前提"或"以下哪项是上述论证成立的前提" |
| 步骤逻辑 | ① 确认问法：问的是"前提"而非"加强"；② 推理方向：从论据到结论（正向），而非从结论到论据；③ 找搭桥项：找到能将论据和结论逻辑连接的选项；④ 验证：否定该选项后结论无法成立 |
| 高频错因 | 从结论往回找前提，导致选了结论本身或论据的重复；混淆"前提"和"加强" |
| confidence | high |

## 补充说明

核心区别："前提"是论证成立的必要条件（没它不行），"加强"是让论证更充分的条件（有了更好）。前提类题目一定要用否定代入法验证。

## 不适用条件

- 当题目问法为"加强"而非"前提"时，不需要用必要条件标准判断，选"有帮助"的选项即可。
- 当题干论证中存在多个逻辑跳跃时，单一搭桥可能不够，需识别所有跳跃并确认选项覆盖最关键的缺口。
- 当选项否定后结论依然成立时，该选项不是前提，说明判断有误，需重新排查。

## 反向触发

- 问法为"以下哪项最能加强上述论证"时，换用加强题分析框架。
- 搭桥后仍有多余假设未被覆盖时，检查是否需要补充排除他因。
- 否定代入法无法明确判断时，对比剩余选项的必要性程度，选"没有它论证一定不成立"的选项。
