# 方法卡：程度匹配原则

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 程度匹配原则 |
| 适用题型 | 逻辑填空——程度词辨析 |
| 触发场景 | 选项中有程度不同的词（如"窥察"vs"洞悉"、"得天独厚"vs"无可比拟"） |
| 步骤逻辑 | ① 判断语境需要的程度深浅；② 程度词必须与语境匹配（部分了解→"窥察"，完全知道→"洞悉"）；③ 强逻辑必须有强对应（"优势"→"得天独厚"而非"无可比拟"） |
| 高频错因 | ① 过度推断→选了程度过深的词；② 程度太弱→与语境不匹配 |
| confidence | high |

## 补充说明
## 不适用条件
- 语境无明显程度差异、选项程度相近时，本卡不适用
- 当题目考的是语义方向而非程度深浅时，应优先用语义排除法
- 选项均为同程度近义词时，需换用搭配或语境分析

## 反向触发
- 若题目核心考点是褒贬色彩而非程度深浅，不使用本卡
- 若语境无程度对比信号（如"更""最""稍微"等），先确认是否真的考程度匹配
