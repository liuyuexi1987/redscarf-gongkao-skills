# 方法卡：等差数列抓住中间项

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 等差数列抓住中间项 |
| 适用题型 | 数量关系——等差数列求和与相关计算 |
| 触发场景 | 等差数列求和，或已知项数与部分条件求总和、中间项及相关项 |
| 步骤逻辑 | 等差数列求和时抓住中间项：Sn = 中间项 × 项数（奇数项），或中间两项平均数 × 项数（偶数项）。；1. **奇数项**：Sn = 中间项 × 项数；2. **偶数项**：Sn = (中间两项之和 ÷ 2) × 项数；3. **通项公式**：An = A1 + (n-1) × d；4. **首项+末项公式**：Sn = (首项 + 末项) ÷ 2 × 项数 |
| 高频错因 | 忽略奇偶项数的公式差异，套错公式搞错中间项的位置，尤其在偶数项时误取单个中间值忘记利用"总和通常是项数的倍数"来快速排除选项 |
| confidence | medium |

## 补充说明

- 项数通常是整数，所以总和通常是项数的倍数（可用于快速排除选项）
- 多个等差数列时，用中间项之间的关系列方程，不需要求首项
- 等差三角形：从1开始的递增数列，首项+末项除2乘项数

## 不适用条件

- 非等差数列（如等比数列、递推数列）不适用本法
- 已知条件不涉及求和（如只求某一项的值）时，通项公式可能更直接
- 项数未知且无法推断时，中间项法无法展开

## 反向触发

- 若题目未明确数列为等差，先验证公差是否恒定
- 若选项均为非整数且差距小，中间项倍数排除法失效，需精算
