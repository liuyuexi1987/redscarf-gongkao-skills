# 方法卡：诉诸权威力度极弱

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 诉诸权威力度极弱 |
| 适用题型 | 判断推理-加强/削弱题（前提假设、支持、质疑类） |
| 触发场景 | 选项中出现"某权威机构称""某专家认为""某研究指出"等表述，且选项内容仅是权威方的宣称，不含逻辑推导 |
| 步骤逻辑 | 1. 识别选项是否含有"某权威/某专家/某机构称/认为/指出"等字样；2. 如果权威方宣称的内容**本身有逻辑链**→可选（力度取决于逻辑本身）；3. 如果仅是权威方单方面宣称，**没有逻辑支撑**→力度极弱，基本等同无关；4. 对比其他选项：如有围绕题干逻辑漏洞的选项，优先选逻辑选项，不选诉诸权威 |
| 高频错因 | 看到"权威机构"就认为有说服力，误选诉诸权威选项不区分"权威说了什么有道理的话"和"权威单方面宣称" |
| confidence | high |

## 不适用条件

1. 权威方的陈述附带了具体数据、实验结果或逻辑推导，而非仅凭身份背书
2. 题干讨论的就是"某权威机构的观点是否正确"，权威方本身就是论证对象
3. 选项中的权威引用是作为事实来源（如官方统计数据）而非论证论据

## 反向触发

1. 选项仅含"某专家认为""某权威机构称"等表述，不含推理过程
2. 同一题中存在直接针对题干逻辑漏洞的选项
3. 题目问"最能加强/削弱"且诉诸权威选项无实质逻辑支撑
