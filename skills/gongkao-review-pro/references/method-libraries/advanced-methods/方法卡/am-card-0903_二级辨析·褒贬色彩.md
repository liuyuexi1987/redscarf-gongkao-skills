# 方法卡：二级辨析·褒贬色彩

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 二级辨析·褒贬色彩 |
| 适用题型 | 判断推理——类比推理·语义关系 |
| 触发场景 | 多个选项都是近义词，且选项中出现明显贬义词 |
| 步骤逻辑 | ① 判断题干两词的情感色彩（褒/中/贬）；② 选项中找情感色彩匹配的一组；③ 若选项中有明显贬义词出现，提示本题可能考褒贬辨析 |
| 高频错因 | ① 只看意思相近就选，忽略褒贬；② 分不清"中性词"和"褒义词"的边界 |
| confidence | high |

## 补充说明

褒贬辨析的识别信号：选项中出现明显贬义词时，提示本题可能考查情感色彩。需将题干两词的褒贬属性与选项逐一匹配。

## 不适用条件

- 题干两词均为中性词且选项无褒贬差异时，本方法不适用。
- 题干两词关系是程度递进而非情感色彩时，本方法不适用。
- 题干是成语拆字结构时，应换用拆字近义法。

## 反向触发

- 当选项间存在程度递进差异时，应换用二级辨析·程度递进。
- 当题干是整体近义关系而非情感色彩辨析时，应换用语义近义辨析。
- 当题干是成语拆字结构时，应换用拆字近义法。
