# 方法卡：最值问题构造法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 最值问题构造法 |
| 适用题型 | 数量关系——最值问题 |
| 触发场景 | 题目问"至少…最多…""最少需要…""最大可能是…"，且涉及分配、分组或排列 |
| 步骤逻辑 | ① 明确约束条件（如"每人至少1个""总数固定""不能重复"）；② 构造极端情况：求最大值→让其他项尽量小；求最小值→让其他项尽量大；③ 用不等式或方程表达约束→解出极值；④ 验证构造是否满足所有约束条件 |
| 高频错因 | ① 构造极端情况时忽略了某个约束条件（如"互不相同"）；② 求"至少"时用了最大化思路，求"最多"时用了最小化思路（方向搞反）；③ 没有验证构造结果是否真的满足所有条件 |
| confidence | high |
| 不适用条件 | 题目只问平均值、期望值或常规计算，不涉及极端分配；约束条件过于模糊，无法明确方向；题目为概率或排列组合计数，非极值构造 |
| 反向触发 | 题目问平均值或期望值，不涉及极端分配；题干只给数据求常规运算结果，无极值关键词 |

## 补充说明
最值问题的核心是"构造极端"——不是计算平均值或期望值，而是找到满足约束条件的极端分配方式。常见模型：至少一个抽屉有几个（抽屉原理）、最多一个人分到几个（反向构造）。口诀："求最少让别人最多，求最多让别人最少"。
