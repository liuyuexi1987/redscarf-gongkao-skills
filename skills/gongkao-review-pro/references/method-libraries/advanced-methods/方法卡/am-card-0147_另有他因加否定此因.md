# 方法卡：另有他因+否定此因

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 另有他因+否定此因 |
| 适用题型 | 判断推理-削弱题（题干将A认定为B的原因，选项需质疑该因果关系） |
| 触发场景 | 题干：研究发现A和B相关，推测A导致B。选项需要找最能削弱/质疑的 |
| 步骤逻辑 | ① 判断选项是否提出能解释结果的其他原因；② 检查它是否同时削弱原原因的必要性、充分性或主导地位；③ 比较各选项对题干因果链的作用位置和证据强度；④ “主要/根本”等词本身不保证力度，仍需核对新原因与结果、原原因之间的关系 |
| 高频错因 | 只看是否"另有他因"就选，忽略了"主要因素"同时否定了原原因选了单纯的反向论据（如"低脂肪也有好处"）而错过既有他因又否定此因的选项 |
| confidence | high |

## 不适用条件

1. 题干不是因果推理结构，而是类比推理或条件推理
2. 选项中未出现任何替代原因或对原原因的否定
3. 题目要求找"最能加强/支持"该因果关系的选项

## 反向触发

1. 题干出现"研究发现A与B相关，推测A导致B"
2. 某选项同时提出了新原因C并用"主要""根本"等词否定原原因A的主导地位
3. 题目问"最能削弱/质疑上述结论"
