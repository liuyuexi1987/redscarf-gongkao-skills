# 方法卡：相近选项提示词辨析

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 相近选项提示词辨析 |
| 适用题型 | 中心理解题（主旨大意） |
| 触发场景 | A和C两个选项含义相近，难以抉择（如"盲目从众"vs"复制与模仿"） |
| 步骤逻辑 | 1. 回文找"提示词"——文段中反复出现的关键表述；2. 看提示词与哪个选项更对应：如文段反复说"模仿""山寨"→对应"复制与模仿"；3. 另一选项虽有一定道理，但与提示词不匹配则排除 |
| 高频错因 | 凭感觉选"差不多"的选项，不回文核对提示词混淆相近词语的侧重点（从众=不分析就跟随 vs 山寨=模仿复制） |
| confidence | high |

## 不适用条件

- 两个选项含义差异明显，不存在"相近难辨"的情况
- 文段中没有出现可作为判断依据的提示词或反复出现的关键词
- 选项之间的区别不是语义侧重问题，而是范围大小或程度高低的区别

## 反向触发

- 若回文找到的提示词同时指向两个相近选项（如文段既说"从众"又说"模仿"），不能仅靠一个提示词决定，应回看文段的落脚重心（结论句更支持哪个方向）
- 若两个选项的关键词都出现在文段中但位置不同（一个在背景、一个在核心），应优先选择核心部分对应的选项，而非背景部分
- 若选项中一个是文段原词、一个是引申概括，优先核对原词是否足够概括文段主旨，若不够则选引申概括
