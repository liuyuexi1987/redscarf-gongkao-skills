# 方法卡：高位叠加法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 高位叠加法 |
| 适用题型 | 资料分析·多个数据求和（如六个产业增加值加总求比重） |
| 触发场景 | 需要把多个数据相加，选项差距明显，只算高位已足以区分 |
| 步骤逻辑 | 1. 优先从百分位（最高位）开始叠加 2. 百分位算完得到大数后，十分位和个位"意思意思"即可 3. 不追求低位精确，因为选项差距足够大 |
| 高频错因 | 从个位开始逐位精确叠加浪费时间；低位算太准但选项差距根本不需要 |
| confidence | high |

## 补充说明

典型场景：多个数据求和后求占比，选项差距较大。从百分位开始叠加得到大数，十分位和个位粗略加即可。核心理念：根据选项差距决定计算精度，高位决定数量级，低位只影响细调。选项差距越大，低位越可以忽略。

## 不适用条件

1. 当低位舍入误差可能跨越选项时，高位叠加的精度不足，需补算更多有效位
2. 当数据项少（仅2个）且可直接相加时，无需分位叠加，直接加更高效
3. 当题目要求精确求和（如计算平均值需除法后续处理）时，此法精度可能不够

## 反向触发

1. 当叠加后各选项数值仍非常接近时，应补算低位或换用精算
2. 当求和后还需做除法或与其他大数比较时，低位误差可能被放大，应提高计算精度
