# 方法卡：趋势法比较分数大小

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 趋势法比较分数大小 |
| 适用题型 | 比较多个分数的数值大小（增速比较、占比比较等） |
| 触发场景 | 需要比较 A/B 与 C/D 的大小，不动笔直接看 |
| 步骤逻辑 | 1. 看分子倍数：C 的分子是 A 的几倍；2. 看分母倍数：D 的分母是 B 的几倍；3. 若分子倍数 > 分母倍数 → C/D 更大；4. 若分子倍数 < 分母倍数 → A/B 更大；5. 关键：不需要精确计算，看倍数关系即可判断 |
| 高频错因 | 习惯性用包子法精算，浪费时间 |
| confidence | medium |

## 补充说明

趋势法的核心是"看倍数关系，不精确计算"：分子增大了几倍、分母增大了几倍，比较这两个倍数即可判断分数大小变化方向。若分子增大的倍数大于分母增大的倍数，则新分数更大；反之则更小。此法适合两个分数之间分子分母变化方向一致的比较场景。

## 不适用条件

- 分子分母变化方向相反（如分子增大而分母减小），倍数比较不适用，直接判断即可
- 两个分数的分子分母差距极小，倍数关系接近1，判断模糊
- 需要精确求出两个分数的差值

## 反向触发

- 当分子倍数和分母倍数非常接近（如1.05倍 vs 1.03倍）时，趋势法判断不可靠，应切换为包子法或截位直除
- 当要比较三个以上分数且排序关系复杂时，逐一两两比较趋势可能反而比统一用包子法换算更慢
- 当分子分母存在量级跳跃（如从三位数跳到五位数）时，简单倍数比较容易忽略量级因素
