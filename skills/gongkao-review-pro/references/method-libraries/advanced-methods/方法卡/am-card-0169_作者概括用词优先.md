# 方法卡：总结句用词优先

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 总结句用词优先 |
| 适用题型 | 言语理解——片段阅读主旨题（选项用词取舍） |
| 触发场景 | 两个选项意思接近，一个用的是总结句中的用词，另一个用的是分析/论证部分中的用词 |
| 步骤逻辑 | ① 先确认两个选项表达的核心意思相同或非常接近；② 定位文段总结句（通常是首句或末句）；③ 判断哪个选项的用词与总结句一致，优先选择该选项 |
| 不适用条件 | 两个选项意思不同（此时应按主旨内容判断，而非用词来源）；仅有一个选项与主旨相关时（不涉及用词比对） |
| 高频错因 | 被分析部分的细节用词吸引，忽略了总结句中更精炼的概括性表达；认为分析部分的用词更具体，误以为具体比概括好 |
| confidence | high |
| 反向触发 | 两个选项虽用词来源不同但核心意思本身有差异时，应回到主旨内容判断而非本法；若总结句是过渡性概括而非全文收束，用词优先策略可能不成立，需重新审视文段结构 |


> **使用边界**：本方法用于提供优先检查方向，不可单独据此作答；最终需回到题干关系、原文证据或选项条件完成验证。
