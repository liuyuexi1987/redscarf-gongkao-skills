# 方法卡：五种对策表述识别法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 五种对策表述识别法 |
| 适用题型 | 中心理解、标题拟定 |
| 触发场景 | 需要判断文段中哪些语句是对策；选项用不同句式改写了对策需要识别 |
| 步骤逻辑 | 1. 祈使句/建议句：不妨、必须、应该、需要、要等；2. 禁止型：不能、要避免、不可、不应该等；3. 逻辑关联词：如果…那么…、只有…才…、除非…否则…（注意：逻辑关键词不一定都是对策，需结合位置判断）；4. 必要条件表述：前提、基础、关键、必不可少、不可或缺、离不开、必须等（对策核心通常在必要条件上）；5. 语义表对策：有助于、有利于、时代使命、必经之路、重要议题等（"B有助于A"等价于"A需要B"，是对策的同义替换） |
| 高频错因 | 看不出"有助于"是对策的变体；把逻辑关联词误认为一定是对策（有时是论证）；对策核心抓不准（应聚焦必要条件部分） |
| confidence | medium |

## 补充说明

- 五种对策表述的本质是"句式识别"：祈使/建议句、禁止型、逻辑关联词、必要条件表述、语义表对策（如"有助于""有利于"等价于"A需要B"）
- 必要条件表述中，对策核心通常在必要条件上（前提/基础/关键/必不可少/不可或缺/离不开）

## 不适用条件

- 文段为纯科普介绍类（无作者主观态度）时，识别出的"对策性表述"可能只是客观陈述，不应作为对策选项
- 逻辑关联词出现在论证部分（用于连接论据而非给出对策）时，不应判定为对策

## 反向触发

- 当句式识别结果与文段类型判断冲突时（如识别出对策句但文段是科普类），应回到文段整体结构核验
- 当多个句式同时出现时，应聚焦必要条件部分作为对策核心，而非把所有句式都当对策
