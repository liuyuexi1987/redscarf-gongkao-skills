# 方法卡：词语辨析四层次

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 词语辨析四层次 |
| 适用题型 | 逻辑填空——词语辨析 |
| 触发场景 | 遇到近义词难以区分时 |
| 步骤逻辑 | ① 大意：了解词语的大体含义（大部分题做到这步就够）；② 字面：拆字理解准确定义（如"浮光"=水面反光，"掠影"=掠过的影子→印象不深刻）；③ 语法：注意搭配问题（主谓宾定状补，什么词做谓语/状语/定语）；④ 辨析：多个近义词的细微差别（如浮光掠影侧重"印象浅"，走马观花侧重"看得快"） |
| 高频错因 | ① 只知大意不知准确含义→选错近义词；② 望文生义→如"惨淡经营"以为很惨；③ 不注意语法搭配→如"手到擒来"一般不做定语 |
| confidence | high |
| 不适用条件 | ['空格考查的是固定搭配而非近义词辨析（应优先查搭配）', '选项间含义差距明显、无辨析必要时不需要逐层拆解', '语义轻重差异已足够区分选项时，不需要拆到字面或语法层'] |
| 反向触发 | ['选项不是近义词而是含义差别明显的词，四层辨析无用武之地', '空格考点明确是搭配关系而非词语辨析'] |

## 补充说明
词语辨析不是短期速记能掌握的，需要长期积累。积累时重点关注：①容易望文生义的词（首当冲、首鼠两端、不赞一词、目无全牛、差强人意）；②成对的词（不以为然/不以为意、不负众望/不孚众望）。可以从官媒文章（求是、人民网、光明网）中找规范搭配用法。
