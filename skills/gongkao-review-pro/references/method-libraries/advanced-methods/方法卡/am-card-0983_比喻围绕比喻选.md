# 方法卡：比喻围绕比喻选

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 比喻围绕比喻选 |
| 适用题型 | 逻辑填空——形象化表达 |
| 触发场景 | 文段中有比喻、双引号、形象化表达（如"阳光""红线""任督二脉"） |
| 步骤逻辑 | ① 识别文段中的比喻/形象化元素；② 空格处的词要与比喻的逻辑一致（如"阳光"→选"风吹草动"而非"蛛丝马迹"）；③ 双引号往往提示要选更形象的词 |
| 高频错因 | ① 忽略比喻元素，选了与比喻不搭的词；② 双引号出现时不注意，选了太抽象的词 |
| confidence | high |

## 补充说明
当文段存在比喻或形象化意象时，空格词应与该意象的逻辑保持一致：若意象偏动态（如"阳光""潮流"），优先选具动态形象的词；若意象偏循环通畅（如"任督二脉"），优先选表示畅通的词；若意象偏浑浊掺杂（如"泥沙俱下"），优先选与"浑浊"相关的词。但注意：不是所有带形象词的题都要形象化选词，需判断命题人是否刻意营造意象一致性。

## 不适用条件

- 文段虽有比喻，但比喻仅用于修饰背景、与空格处逻辑无直接关联时，不强行套用本卡。
- 空格所在分句是严肃的政策/法律/学术表述，形象化选词会破坏语体庄重性时，不适用。
- 选项中无明显的形象化词语对立（均为抽象词或均为形象词）时，本卡失去区分作用。

## 反向触发

- 当意象指向不单一（同一文段出现多个不同意象）时，应改用以核心话题为准的辨析，而非围绕任一比喻选词。
- 当选项形象词与抽象词各有一个看似都可搭配时，应补一步语体色彩核验：庄重语境偏抽象，生动语境偏形象。
- 当命题人用比喻作干扰（正确答案反而不与比喻搭配）时，应换用逻辑对应法核验，避免被比喻误导。
