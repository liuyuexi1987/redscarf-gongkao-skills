# 方法卡：500心算锚点

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 500心算锚点 |
| 适用题型 | 资料分析——假设分配法中的快速估算技巧 |
| 触发场景 | 假设分配或增长量估算时，500接近待估基期且能减少心算步骤 |
| 步骤逻辑 | ① 把500视为1000的一半；② 先算 `1000×R`，再除以2得到 `500×R`；③ 将500作为一个候选锚点，而不是固定起点；④ 若其他整百数更接近真实基期或更便于验证，改用其他锚点 |
| 验证动作 | 用估出的增长量与现期量反推基期，检查是否比其他整百锚点更接近 |
| 不适用条件 | 500远离合理基期范围；增长率或选项结构使其他锚点更易计算 |
| 高频错因 | 把500当成所有题的最佳起点；为了套技巧而增加修正次数 |
| confidence | medium |
| 反向触发 | 合理基期明显远离 500 时，改用更接近真实范围的整百数；增长率可与其他整百锚点形成更简洁的乘除关系时，不必固定使用 500；估算误差可能跨越选项时，改用更接近真实值的锚点或精算 |
