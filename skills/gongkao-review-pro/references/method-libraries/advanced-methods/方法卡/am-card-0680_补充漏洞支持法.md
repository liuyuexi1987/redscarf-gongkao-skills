# 方法卡：补充漏洞支持法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 补充漏洞支持法 |
| 适用题型 | 逻辑判断——支持/前提假设题（题干有未考虑的方面） |
| 触发场景 | 题干论据只考虑了部分情况，结论却涉及整体；或只说了A部分，结论涉及A+B |
| 步骤逻辑 | ① 识别漏洞：题干是否只考虑了部分（如只说男同学，结论说全班）；② 补充方式：可以说"B部分也有同样特征"或"不存在B部分"；③ 两种都行：如"女同学也很努力"或"我们班没有女同学" |
| 高频错因 | 选了与漏洞无关的选项；选了加强论据但没补漏洞的选项 |
| confidence | medium |
| 不适用条件 | 1. 题干论据和结论的范围完全一致，没有部分到整体的跳跃；2. 题目问质疑/削弱而非支持或前提假设；3. 选项只是加强了已有论据而非补充缺失部分 |
| 反向触发 | 1. 论据只讨论了部分群体或部分情况，结论却推广到整体，立刻想到补充另一部分或排除其他可能；2. 支持题/前提假设题中，选项表述 |

## 补充说明

补充漏洞是支持/前提假设的重要方式。例如：题干说"中药材总产量增加，野生没增加→种植增加"，漏洞是"是否有第三种来源"。选项"中药材只能通过种植和野外采集获得"就补上了这个漏洞（排除第三种可能）。类似：题干说"男同学很努力→全班努力"，补漏洞可以说"女同学也很努力"或"没有女同学"。
