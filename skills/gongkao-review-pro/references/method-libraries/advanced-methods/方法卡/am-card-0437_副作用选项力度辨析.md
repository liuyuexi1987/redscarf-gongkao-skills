# 方法卡：副作用选项-力度辨析

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 副作用选项-力度辨析 |
| 适用题型 | 判断推理-逻辑判断-削弱题 |
| 触发场景 | 选项说某方案/方法有副作用（如破坏生态平衡、有安全隐患等），需要判断其削弱力度 |
| 步骤逻辑 | 1. 先判断题干结论的性质：纯理论/纯事实 vs 具体要实施的方案 2. 纯理论→副作用选项是"无关"，不能选 3. 具体方案/方法→副作用选项是"削弱"，力度较弱但可保留 |
| 高频错因 | 不区分结论性质，把所有副作用选项一律当削弱或一律当无关 |
| confidence | high |

## 补充说明

例：结论是"某植物能治感冒"（纯理论）→说它有副作用=无关；结论是"应将其作为草药推广"（实施方案）→说它有副作用=削弱。副作用选项力度一般不是最强的，但比无关要强。

## 不适用条件

- 题型不是削弱题（如加强题、前提假设题），副作用选项在这些题型中的功能不同
- 题干结论本身就是关于副作用或安全性的，此时副作用属于同范畴直接论据，不适用"力度较弱"的判断

## 反向触发

- 当结论是纯理论但其他选项明显更弱时，副作用选项虽原则上"无关"，仍需对比各选项是否确实都不构成削弱，避免误排最强选项
- 当多个副作用选项同时出现且力度相近时，不要在它们之间纠结选哪个，应先检查是否有力度更强的切断因果关系的选项
