# 方法卡：同组概率（逐人放置法）
## 基本信息
| 字段 | 值 |
|------|-----|
| 方法名 | 同组概率（逐人放置法） |
| 适用题型 | 数量关系-概率（分组/同排/同桌问题） |
| 触发场景 | N人分组或排列，求特定人同组/同排/不同组/不相邻的概率 |
| 步骤逻辑 | 1.先定位一个人（放甲到某组） 2.依次放入其他人，每步计算满足条件的剩余位置数与总剩余位置数之比 3.连乘各步概率即为结果 |
| 高频错因 | 直接用组合公式算复杂；放完人后忘记剩余位置变化 |
| confidence | high |

## 不适用条件

1. 事件为独立重复试验（如抛硬币），无分组/排列/座位结构
2. 题目求期望值或方差，而非特定人同组/同排的概率
3. 条件为"至少 k 人"型不等式约束，无法用逐人放置连乘

## 反向触发

1. 题目问"至少有几人同组"的期望或最值，而非概率
2. 各次抽取相互独立（有放回），无需考虑剩余位置变化
3. 题目为条件概率（已知某事件发生的前提下求另一事件），需贝叶斯公式

## 补充说明
此法通解多种变体：4人两两分组同组概率=1/3；6人三三分组三人同组=1/10（即2/5×1/4，第一步2/5=放第二人到同一组，第二步1/4=放第三人到同一组）；4×4方格同排=3/15；不同排不同列=9/15×4/14；5人圆桌不相邻=2/4。核心逻辑：固定一个，逐个放人，每步算满足/剩余比值并连乘。
