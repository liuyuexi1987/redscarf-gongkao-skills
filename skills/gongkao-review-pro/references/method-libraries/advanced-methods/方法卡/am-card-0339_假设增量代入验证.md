# 方法卡：假设增量代入验证

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 假设增量代入验证 |
| 适用题型 | 资料分析——增量计算（选项密集接近） |
| 触发场景 | 选项集中在某一范围（如533/549/555/561），增速较小（≤5%），直接计算精度不够 |
| 步骤逻辑 | ① 在选项中间取一个整值（如550）作为假设增量X；② 算出基期=现期−X；③ 用基期×增速验算增量X'=基期×R；④ 若X'≈X，选最接近的选项；若X'<X说明实际增量更小，选偏小选项 |
| 高频错因 | 假设增量取值离正确值太远导致二次验证仍不确定；增速较大时误差放大不可忽略 |
| confidence | high |

## 补充说明

原理：假设增量与真实值的差（如20），乘以小增速（如4%）后误差仅0.8，对选项判断几乎无影响。适合"怎么算都差一点"的纠结场景，比放缩或小丑法更快。

## 不适用条件

- 假设误差经增速放大后可能跨越选项，无法稳定区分答案
- 选项间距本身较大，直接计算精度足够
- 增速为负值时，基期大于现期，假设增量的取值范围需调整

## 反向触发

- 若假设增量取中值后验算出的X'仍无法区分两个相邻选项，说明假设精度不够，应换用精确除法
- 若验算结果X'明显偏离所有选项，先检查基期计算是否正确（现期−X），不要直接选最接近项
