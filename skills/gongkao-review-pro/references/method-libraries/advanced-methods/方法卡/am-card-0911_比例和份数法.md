# 方法卡：比例和份数法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 比例和份数法 |
| 适用题型 | 数量关系·和差倍比·比例和问题 |
| 触发场景 | 已知两个量的比值，又知道它们的和（或差），求各自具体值 |
| 步骤逻辑 | 1. 将比例看作份数（如8:1 → 8份和1份）；2. 利用已知的和或差，求出一份的值；3. 例：时间比8:1，总时间90分钟 → 9份=90分钟 → 1份=10分钟 → 分别为80分钟和10分钟 |
| 高频错因 | 把比例直接当具体数值使用，忘记需要通过和/差还原 |
| confidence | high |

## 补充说明

份数思想是比例问题的核心思想，贯穿整个数量关系模块。

## 不适用条件

- 仅知比值、缺少和或差约束（无法还原一份的值，份数思想无落点）。
- 比值并非最简形式且未约分，直接套用易导致份数计算错误。
- 题目本身需要先反比才能得到正确比值（直接对原始比值取份数会出错）。

## 反向触发

- 当题目给出速度比要求时间时，应先做反比变换再换算份数（即"反比+比例和联合求解"）。
- 当缺少和/差信息时，应改用赋值法或方程法补充约束。
- 当比值涉及三个及以上量时，应改用多元方程或分层比例法处理。
