# 方法卡：分组数列识别总卡

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 分组数列识别总卡 |
| 适用题型 | 数量关系——数字推理（机械划分、小数点分组、根号分组、分式分组） |
| 触发场景 | 数列项含小数点、根号、分式，或全为多位数且无单调/倍数规律；或项数明显偏多（通常 7 项以上）暗示奇偶/分段分组 |
| 步骤逻辑 | ① 按外观特征分流：含小数点→按小数点左右拆分，左右各自成规律或左右交叉递推；含根号→按根号内外拆分，内外各自成规律或内外交叉；含分式→按分子分母拆分，分子分母各自成规律或交叉递推（详见"分数数列反约分法"）；全为多位数→按数位拆分或各位求和（详见"机械划分三大形式"）；② 项数偏多且无外观特征→尝试奇偶位置分组（奇数项一列、偶数项一列），各自成规律；③ 奇偶分组无规律→尝试每两项/每三项为一组，组内做和/做差/做积；④ 每条候选规律必须覆盖全部已知项，分组后每组各自独立验证 |
| 高频错因 | ① 看到小数点就只拆左右，忽略左右交叉递推的可能；② 奇偶分组只验证了奇数项就断定规律，未用偶数项交叉验证；③ 多位数拆分后只看一组数位的规律，未验证另一组数位是否同步成规律；④ 把分组数列当成普通数列作差/作商，因分组规律被掩盖而找不到 |
| confidence | high |

## 不适用条件

1. 数列项数少于 6 项时，奇偶/分段后每组样本较少，只能作为候选路径；必须有非常简单的组内规律并结合选项验证，不能仅凭分组定型。
2. 数列外观特征（小数点/根号/分式）只是偶发，主体仍为整数且呈单调/倍数规律时，应优先验证主规律，不强行分组。
3. 多位数之间已存在明显等差/等比/倍数关系时，机械拆分反而破坏主规律，应先用常规方法。
4. 分组后某组只有 2-3 项时，证据较弱；若另一组、位置关系和选项都不能提供额外约束，应放弃分组假设。

## 反向触发

1. 当按外观特征拆分后，某一侧（如小数点左侧）无任何规律时，应检查左右是否交叉递推（如左=前左+前右）。
2. 当奇偶分组后两组规律都成立但推出不同目标项时，应改用每两项为一组的组内运算（和/差/积）。
3. 当机械拆分后各位数各自成规律但与选项不符时，应检查是否存在"内部递推"（如某一位由其他位运算得到）。
4. 当所有分组方式都失败时，回退到"数字推理总纲"的回退路径，改用作差/作和/递推。

## 最终验证动作

1. 分组后，对每一组分别用其规律逐项回代，确认每组每一项都吻合，无遗漏。
2. 推出目标项后，按分组方式还原完整项（如小数点分组需还原为"左.右"形式），与选项比对。
3. 对交叉递推（如左=前左+前右），必须验证递推关系在至少两个连续位置都成立。
4. 对奇偶分组，先判断目标位置属于奇数组还是偶数组；目标所在组负责推出答案，另一组至少要能解释全部已知项，用于验证分组成立。
