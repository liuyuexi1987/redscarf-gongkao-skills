# 方法卡：现期比重替代估算法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 现期比重替代估算法 |
| 适用题型 | 资料分析 — 比重差计算中缺少基期总量（GDP等） |
| 触发场景 | 比重差公式中小A/B（部分基期÷整体基期）未知，但已知大A/B（现期比重） |
| 步骤逻辑 | 1. 比重差 = 小A/B × (R1-R2)，其中小A/B为部分基期÷整体基期；2. 小A/B < 大A/B（因为部分增速>整体增速时，基期比重<现期比重）；3. 用大A/B（现期比重39.8%）代替小A/B，乘以增速差（如3.4%），得到比重差的上界；4. 若上界已经很小（如1.4个百分点），则可直接判断选项是否合理 |
| 高频错因 | 直接把现期比重当基期比重代入，未意识到这是高估值忘记基期比重和现期比重的方向关系（增速差正负） |
| confidence | high |

## 不适用条件

- 题目要求精确计算比重差值而非估算上界/下界，必须按比重差公式精确代入基期比重。
- 部分增速与整体增速非常接近（增速差趋近于零），替代估算的误差方向不确定，需精确计算。
- 题目给出的增速不是百分比形式而是倍数或其他表达，需先转换再用公式。

## 反向触发

- 题干出现比重差公式中的部分基期÷整体基期（小A/B）未知，但已知现期比重（大A/B）时，提示用替代估算。
- 选项数值都很接近，需要用估算上界快速排除时，提示本方法。
