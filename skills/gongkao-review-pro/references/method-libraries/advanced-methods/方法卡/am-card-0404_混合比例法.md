# 方法卡：混合比例法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 混合比例法 |
| 适用题型 | 数量关系 — 经济利润 / 折扣促销题 |
| 触发场景 | 已知整体的现价/原价（或总价比），各商品有不同折扣方式，汢单价 |
| 步骤逻辑 | 1. 将整体现价/原价写成比值（如55/80），这是"混合后的比值"；2. 分别求出每个商品的现价÷原价的比值（数量不变时，总价值比=单价之比）；3. 利用混合比的"十字交叉"或"交叉相减"得到各商品原价之比；4. 结合已知单价或数量关系求解 |
| 高频错因 | 分不清现价/原价方向（现价/原价<1不能反）；忘记"数量不变"前提才能用单价比代替总价值比 |
| confidence | high |

## 不适用条件

- 商品数量发生变化（如卖出部分商品后再比较），总价值比不再等于单价之比时
- 题目只涉及单一商品的折扣计算，无需交叉混合时
- 折扣方式不是简单的现价/原价比例关系，而是满减、买赠等非线性促销时

## 反向触发

- 当十字交叉得到的比值无法与已知单价或数量关系对应时，应检查"数量不变"前提是否成立，必要时改用方程法
- 当出现利率混合、浓度混合、增长率混合等非价格类混合问题时，应改用对应题型的十字交叉法，不可套用价格比值的交叉逻辑
- 当题目给出的是折扣比例（如八折）而非直接的现价/原价数值时，需先统一为比值形式再交叉，不可直接用折扣数交叉
