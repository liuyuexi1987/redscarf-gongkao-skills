# 方法卡：矛盾命题三组速查

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 矛盾命题三组速查 |
| 适用题型 | 判断推理——真假话类、矛盾推理类 |
| 触发场景 | 题干给出多句话，告知"只有一真""只有两真"等条件，要求推出事实 |
| 步骤逻辑 | ① 记忆三组矛盾：A与非A；A且B与非A或非B；A或B与非A且非B；以及所有/有些不互换、A推B与A且非B；② 在多人发言中找矛盾对——矛盾必然一真一假；③ 若"只有N真"，且找到两组矛盾（各占一真一假），则剩余发言必为假；④ 从假话推出事实；⑤ 另一种用法：A推B为假时，A且非B为真（如某条件语句"只有X才是Y"为假→"X且非Y"为真） |
| 高频错因 | 将反对关系（可同假）误认为矛盾关系（必一真一假）；不熟悉"所有/有些"互换的矛盾形式；忘记A推B的矛盾是A且非B |
| confidence | high |

## 补充说明

典型用法一：某条件语句（"只有X才是Y"）为假时，其矛盾形式（"X且非Y"）为真，可直接用于选答案。典型用法二：多人发言中找到两组矛盾，若题设"只有N真"，则矛盾各占一真一假，剩余发言必为假，从假话推出事实即可。三组矛盾必须背熟，考场现找基本都是反对关系（可同假）而非矛盾关系（必一真一假），容易混淆。

## 不适用条件

- 题目要求判断可能性而非确定事实，无需找矛盾
- 发言中找不到明确的矛盾对，只有反对关系（可同假）
- 题干未给出"只有N真/只有N假"的限制条件，无法利用矛盾推理

## 反向触发

- 当找到的"矛盾对"实际上是反对关系（可以同假）时，不能套用"必一真一假"规则，应换用反对关系推理或枚举法
- 当用矛盾推出事实后，代入剩余发言发现不一致时，说明矛盾对识别有误，应回退重新配对
