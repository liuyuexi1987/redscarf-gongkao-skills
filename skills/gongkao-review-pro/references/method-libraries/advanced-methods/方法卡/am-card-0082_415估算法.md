# 方法卡：415估算法（整数附近用分数估增量）

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 415估算法（整数附近用分数估增量） |
| 适用题型 | 资料分析-判断增长量是否超过某阈值（增长率接近简单分数如 1/3、1/4 时） |
| 触发场景 | 需要判断增量是否超过某个整数（如 1000），且增长率接近 33.3%（约 1/3）或其他简单分数 |
| 步骤逻辑 | 1. 将增长率近似为简单分数（如 33.3% 当做 1/3）；2. 分数含义：去年是 3 份，变化量是 1 份，今年是 4 份；3. 近似增量 = 现期 ÷ 4（近似），判断是否超过阈值；4. 判断方向：近似增长率是估大了还是估小了——如实际29.5%近似为33.3%（估大），近似增量偏大；如实际35%近似为33.3%（估小），近似增量偏小；5. 方向明确时可直接判断：近似是估小→近似超过阈值则确定超过；近似是估大→近似低于阈值则确定未超过；方向不明确（估大时超过阈值/估小时低于阈值）→近似误差可能跨越阈值，需精算确认 |
| 高频错因 | 忽略"估大/估小"的方向判断，直接用近似值下结论；增长率为负时，分数关系需要反向理解 |
| confidence | high |

## 不适用条件

- 增长率不接近任何便于心算的简单分数，且近似误差可能跨越选项时，不宜强行凑分数
- 题目选项间距很小，需要精确到个位数才能区分时，估算精度不够
- 增长率为负且幅度较大时，分数关系需要反向处理，出错风险高

## 反向触发

- 当增长率明显偏离简单分数，且选项间距较小时，应改用直除法精确计算
- 当增长率本身就是简单分数（如恰好25%、20%）时，直接用倍数关系比415法更快
- 当题目要求的是精确值而非判断"是否超过"时，估算方向不确定，应换用精确方法
