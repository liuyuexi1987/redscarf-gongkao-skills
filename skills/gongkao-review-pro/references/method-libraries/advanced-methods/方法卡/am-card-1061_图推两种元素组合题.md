# 方法卡：图推两种元素组合题

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 图推两种元素组合题 |
| 适用题型 | 判断推理——图形推理（双元素） |
| 触发场景 | 图形中有黑白两部分/两种不同元素 |
| 步骤逻辑 | ① 黑白两部分→考黑白关系；② 关系可能是属性（对称轴）或数量（点/线/面/角）；③ 单独看每行没规律时→列表式写出黑白数量差值（如1,0,-1）→更容易发现规律；④ 数量呈"少到多"整体趋势→考虑换算（如2黑=1白） |
| 高频错因 | ① 不列表→看不出差值规律；② 忽略换算可能 |
| confidence | high |

## 不适用条件
- 图形中只有一种元素时
- 两部分不是黑白关系而是其他组合（如重叠、包含）时需换思路
- 数量规律完全无规律可循时，可能考的是位置或属性规律

## 反向触发
- 图形中两种元素无明显的数量关系或黑白对比时，不应强行列表数差值
- 题目只有一种元素的不同形态（如大小圆）时，不属于双元素组合题
