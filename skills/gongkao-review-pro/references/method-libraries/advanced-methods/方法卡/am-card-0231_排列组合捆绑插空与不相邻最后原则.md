# 方法卡：排列组合捆绑插空与不相邻最后原则

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 排列组合捆绑插空与不相邻最后原则 |
| 适用题型 | 数量关系-排列组合（含相邻/不相邻约束） |
| 触发场景 | 题目要求部分元素相邻或不相邻，需要选择并排列 |
| 步骤逻辑 | 1. 先选：只挑选不分顺序 → 用C；有顺序要求 → 用A；2. 相邻用捆绑：将必须相邻的元素绑成一个整体，内部用A做全排列；3. 不相邻用插空：必须最后一步处理！先把其他所有元素排好，形成N个空位，再将不相邻元素插入空位(用A选空位)；4. 为什么最后：插空的前提是空位已确定，其他人没排好则无空可插；5. 整体与其他元素之间的顺序也要排列（如2部分互换位置→A22或×2） |
| 高频错因 | 先处理不相邻导致空位未确定；忘记捆绑体内部有顺序需乘A；忘记整体与其他元素之间的互换顺序 |
| confidence | medium |

## 不适用条件

1. 题目没有相邻/不相邻约束，仅需全排列或简单组合
2. 元素存在重复（如相同的球），需用除重复排列处理，不属于本方法的捆绑/插空场景
3. 圆排列/环形排列问题，空位结构与线性排列不同，需单独处理

## 反向触发

1. 题目出现"随意排""无限制"等关键词，无相邻约束
2. 出现"相同""重复元素"，需除以重复阶乘
3. 出现"围成一圈""圆桌"，属于圆排列而非线性插空
