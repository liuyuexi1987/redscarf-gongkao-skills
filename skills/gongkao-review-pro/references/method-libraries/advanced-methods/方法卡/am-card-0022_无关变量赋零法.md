# 方法卡：无关变量赋零法
## 基本信息
| 字段 | 值 |
|------|-----|
| 方法名 | 无关变量赋零法 |
| 适用题型 | 数量关系-流水行船/追及问题（条件不足型） |
| 触发场景 | 行船题中船速或水速未在题干中给出，答案与该变量无关 |
| 步骤逻辑 | 1.判断谁是无关变量（题干中未给出的速度） 2.令无关变量=0 3.理解赋零的物理含义：船速为0则船随水漂（水到哪船到哪），水速为0则物停原地 4.直接用剩余条件计算 |
| 高频错因 | 不会判断谁是无关变量；不理解赋零的物理意义 |
| confidence | high |
## 补充说明
示例两道对比场景：场景一——题干只给水速和时间、未给船速→船速为无关变量→令船速=0→船随水漂，水走多远船也走多远，往返距离相同直接相加。场景二——题干给船速、未给水速→水速为无关变量→令水速=0→浮标停原地，用船速除距离得时间。排除判断辅助：先算简单条件得出基本结果，找选项中对应倍数。

## 不适用条件
1. 当题干中两个速度变量都未给出且答案依赖两者关系时，赋零法不适用，需列方程
2. 未能证明目标量与该变量无关，或赋零会改变题目约束、相遇顺序和运动状态时，不得使用赋零法

## 反向触发
1. 当赋零后得到的结果与所有选项均不匹配时，应重新验证“答案与该变量无关”是否成立，必要时换用列方程法
2. 当题干条件足以列等量关系时，直接列方程更稳妥，无需赋零简化
