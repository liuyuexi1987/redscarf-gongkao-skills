# 方法卡：调查类题目样本问题

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 调查类题目样本问题 |
| 适用题型 | 判断推理-削弱题（基于调查/问卷得出结论的题目） |
| 触发场景 | 题干出现"某杂志在读者中调查""某网站在用户中调查""某组织在会员中调查"等表述，并据此推广到一般人群 |
| 步骤逻辑 | 1. 读完题干看到调查类描述，**第一时间检查样本是否具有代表性**；2. 如果调查对象本身有偏向性（如消费导向杂志的读者本身就爱消费），则样本不能代表总体；3. 正确答案通常指出：样本本身≠一般人群，存在选择偏差；4. 这类答案力度通常最强，直接否定推理基础 |
| 高频错因 | 忽略调查对象的特殊性，只关注题干逻辑链选了其他削弱选项（如成本高、副作用等）而错过最强的样本质疑 |
| confidence | high |

## 不适用条件

1. 调查对象本身就是总体（如调查某校学生对该校食堂的满意度，对象即总体）
2. 题干已说明采用了随机抽样且样本量足够大
3. 结论没有从样本推广到更大范围，仅描述样本本身的特征

## 反向触发

1. 题干出现"某杂志/网站/组织在自己的读者/用户/会员中调查"并推广结论
2. 调查对象群体存在天然偏向（如消费杂志读者偏向消费、运动APP用户偏向运动）
3. 正确答案指出"样本不能代表一般人群"或"存在选择偏差"
