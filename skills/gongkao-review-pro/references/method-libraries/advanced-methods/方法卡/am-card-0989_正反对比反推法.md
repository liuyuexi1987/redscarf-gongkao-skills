# 方法卡：正反对比反推法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 正反对比反推法 |
| 适用题型 | 逻辑填空——正反对比结构 |
| 触发场景 | 文段中有正反对比（A和B相反），空格在其中一侧 |
| 步骤逻辑 | ① 识别正反对比结构（不是A而是B、一方面另一方面、过去现在）；② 确定空格在哪一侧；③ 从另一侧的描述反推空格应填的逻辑；④ 例：互联网"快餐式传播"→反面=戏曲"耐咀嚼"→再反推前面=不可重复欣赏→泡沫化 |
| 高频错因 | ① 只看空格所在句不看对比的另一侧→漏掉关键逻辑；② 正反对比中反面逻辑推导不到位→选了不直接对应的词 |
| confidence | high |

## 补充说明
正反对比是逻辑填空中常见的语境结构。关键是通过对比的另一侧反推空格逻辑：先识别对比的两侧描述，再以一侧描述为锚点反推另一侧（空格处）应填的语义方向，确保所选词与对比侧构成清晰的相反或相对关系。

## 不适用条件
- 文段无明确对比结构（既无"不是A而是B"类关联词，也无并列反义表述）时，不宜套用反推，应改用语境呼应或词义辨析。
- 空格所在侧本身已自带充分语义提示（如紧邻同义复指、修饰语直接限定），无需跨侧反推。
- 对比两侧为递进而非反义关系（"不仅A而且B"递进型）时，不应作反义反推。

## 反向触发
- 当对比结构识别不确定（如分号并列但语义并非相反）时，应换用"分号并列对应法"做同向呼应验证，而非反推。
- 当反推得到的词落入选项中两个近义词之间难以抉择时，应补充"自带逻辑词判断法"核验词义前提是否成立。
- 当文段除对比外还出现代词指向主题词时，应结合"代词回找主题词法"双重确认空格语义方向。
