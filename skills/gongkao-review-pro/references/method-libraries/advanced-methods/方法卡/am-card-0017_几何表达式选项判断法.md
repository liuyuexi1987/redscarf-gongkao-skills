# 方法卡：几何表达式选项判断法
## 基本信息
| 字段 | 值 |
|------|-----|
| 方法名 | 几何表达式选项判断法 |
| 适用题型 | 数量关系-几何问题（含π或根号的表达式） |
| 触发场景 | 选项出现含π和含根号的不同表达式，需判断哪个更易算 |
| 步骤逻辑 | 1.识别选项中含π和含根号的表达式 2.判断哪个"更好算" 3.先算好算的部分（如等边三角形面积）进行突破 |
| 高频错因 | 两个表达式都尝试计算浪费时间；不知道优先算哪个 |
| confidence | high |

## 不适用条件

1. 选项均为纯数值（无 π、无根号），不存在表达式选择问题
2. 所有选项结构相同（如全含 π），无法通过形式差异区分难易
3. 题目涉及复杂几何证明而非面积/体积计算，表达式判断不适用

## 反向触发

1. 选项全是整数或简单分数，无需判断哪个表达式更好算
2. 题目要求直接代入数值求解，不需要对表达式做形式判断
3. 各选项的几何含义相同（等价变形），选哪个算结果都一样

## 补充说明
以莱洛三角形为例：直接表达是"三个小扇+三角"（加法），但选项全是减法形式。此时应转换为"三个大扇减二倍三角"的减法表达。等边三角形面积公式S=(√3/4)a²是常识，代入边长即可快速突破。
