# 方法卡：回归实验另有他因

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 回归实验另有他因 |
| 适用题型 | 判断推理——削弱/质疑类（对比实验归因题） |
| 触发场景 | 题干做对比实验后归因X导致Y；选项需质疑该归因 |
| 步骤逻辑 | ① 识别对比实验结构：两组受试者有差异X，结果有差异Y，结论为X导致Y；② 正确削弱选项需回归实验：指出实验组/对照组本身存在另一个差异Z，且Z也能导致Y；③ 若纠结两个选项，偏向明确回归实验的"另有他因"选项——该模式在对比实验归因题中正确率最高 |
| 高频错因 | 选了"伪他因"选项（只说Z与Y有关，但没有回归实验指出两组在Z上有差异）；分不清"另有他因"与"否定此因"的力度区别 |
| 不适用条件 | 题干非对比实验归因结构；选项为"否定此因"而非"另有他因" |
| 反向触发 | 选项明确指出实验组与对照组在另一因素Z上存在差异且Z也能导致Y，应优先选择 |
| confidence | high |

## 补充说明

"伪他因"只是说Z也与Y有关（如多巴胺也影响情绪），但没有指出两组在Z上确实有差异，无法替代原归因。真正的另有他因必须回归实验数据。
