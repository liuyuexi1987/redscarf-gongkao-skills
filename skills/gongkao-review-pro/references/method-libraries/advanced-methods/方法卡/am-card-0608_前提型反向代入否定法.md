# 方法卡：前提型反向代入否定法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 前提型反向代入否定法 |
| 适用题型 | 判断推理——前提假设类（无明显断点时） |
| 触发场景 | 前提型题目中论据与结论之间没有明显概念跳跃（断点），无法直接搭桥 |
| 步骤逻辑 | ① 确认无断点；② 对各选项做"否定代入"：假设该选项不成立；③ 若否定后结论仍然成立 → 该选项不是必要前提；④ 若否定后结论不成立 → 该选项为必要前提（"没他不行"） |
| 高频错因 | 在有断点时仍用否定代入（应直接搭桥更高效）；否定选项时推理不严谨 |
| confidence | high |

## 补充说明

该方法是断点搭桥的备选。有断点时优先搭桥（更快更准），无断点时才用反向代入。前提型固定思路：找准论据结论 → 有断点搭桥 → 无断点反代。

## 不适用条件

1. 论据与结论之间存在明显概念跳跃（断点）时不适用，应直接搭桥更高效。
2. 问法非前提假设类（如削弱、解释、加强）时不适用。
3. 选项否定后代入推理链条过长、复杂度爆炸时不适用。

## 反向触发

1. 若识别出断点，应优先换用断点搭桥法。
2. 若选项否定后代入推理复杂度爆炸，应改用排除法或回到题干复核论据结论结构。
3. 若多个选项否定后代入都使结论不成立，应复核题干是否为充分条件而非必要前提问法。
