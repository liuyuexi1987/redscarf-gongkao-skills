# 方法卡：年均增速排序用末除初

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 年均增速排序用末除初 |
| 适用题型 | 资料分析——比较年均增长率大小或排序 |
| 触发场景 | 多个指标的年均增速排序，且增长次数（年数差）相同 |
| 步骤逻辑 | ① 确认各指标增长次数相同（都是n年）；② 用末期值÷初期值代替年均增长率来比较（因为n相同，根号下末/初的大小关系与末/初一致）；③ 瞪算各比值大小，完成排序或排除 |
| 验证动作 | 若各指标增长次数不同，必须分别比较 `(末期/初期)^(1/n)-1`，不能只比末初倍数 |
| 高频错因 | 不确认增长次数是否相同就直接比较；年份差算错；把末初差值当成末初倍数 |
| confidence | high |
| 不适用条件 | 各指标的增长次数（年数差）不全相同时，末/初的大小关系不能直接代表年均增速排序；初期值接近零或为负数时，比值无意义或方向相反 |
| 反向触发 | 增长次数不一致时，必须分别计算(末/初)^(1/n)-1或根号比较，不能只比末初倍数；题目要求排序的是年均增长量而非年均增长率时，末除初法不适用，应改为比较(末-初)/n |
