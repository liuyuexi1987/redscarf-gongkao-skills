# 方法卡：盐水法慎用原则

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 盐水法慎用原则 |
| 适用题型 | 涉及混合比例、浓度比较的问题 |
| 触发场景 | 看到混合/占比问题就想套盐水法（十字交叉法）时的自我提醒 |
| 步骤逻辑 | 1. 只有**典型盐水题**（纯浓度混合、必须用盐水法才能解的）才用；2. 非典型题用其他方法（如整除特性、直接比较）更稳妥；3. 资料分析中 r=x/a 的盐水近似，用现期代替基期会产生误差，需慎用 |
| 高频错因 | 学了盐水法后"什么题都想往盐水上靠"（方法提醒），导致解题变慢或产生误差多部分混合问题套盐水法需要反复掺，耗时远超其他方法 |
| confidence | medium |

## 补充说明

- 多部分混合（如四区域占比）问题套盐水法需反复掺，耗时远超其他方法，直接用整除特性+比较更快
- 此条为方法论层面的提醒，不是具体解题技巧

## 不适用条件

- 典型盐水题（纯浓度混合、必须用盐水法才能解的）仍应使用盐水法，本提醒不适用
- 题干已经明确给出浓度/比例且无近似误差风险时，无需切换方法

## 反向触发

- 当盐水近似中"现期代替基期"的估算误差可能跨越选项时，应改用精算或换其他方法核验
- 当混合部分超过两个时，应优先考虑整除特性或直接比较，而非反复套盐水法
