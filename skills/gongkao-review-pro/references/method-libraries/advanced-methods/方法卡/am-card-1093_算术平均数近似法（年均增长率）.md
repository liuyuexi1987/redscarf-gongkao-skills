# 方法卡：算术平均数近似法（年均增长率）

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 算术平均数近似法（年均增长率） |
| 适用题型 | 资料分析——年均增长率计算 |
| 触发场景 | 需要计算年均增长率，数据不方便用倍数常数法 |
| 步骤逻辑 | ① 年均增长率不能用简单平均(末年-首年)/首年/年数，该式偏大；正确思路是逐年累加验证；② 实操：先用首末年比值估算大致范围；③ 以10%为试算起点，逐年累加比对首末年实际值；④ 偏大就下调试算值、偏小就上调，迭代至误差不跨选项 |
| 高频错因 | ① 直接用(末年-首年)/首年/年数→结果偏大；② 不做逐年累加验证→误差不可控 |
| confidence | high |

## 补充说明
年均增长率的两种速算方法：倍数常数法（1.5~3倍区间）和算术平均数近似法（其他情况）。算术平均数法更通用但精度稍低。

## 不适用条件

- 首末年比值落在倍数常数法适用区间（约1.5~3倍）时，应优先使用倍数常数法。
- 年份跨度极大（如10年以上）时，试算迭代次数多，效率下降，应考虑精确开方法。

## 反向触发

- 试算结果与某选项非常接近但无法判定偏大偏小时，应换用倍数常数法或缩小试算步长补充核验。
- 题目要求精确到小数点后两位或更高精度时，应改用精确开方法计算。
