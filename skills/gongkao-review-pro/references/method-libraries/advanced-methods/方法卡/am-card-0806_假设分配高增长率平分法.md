# 方法卡：假设分配高增长率平分法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 假设分配高增长率平分法 |
| 适用题型 | 资料分析——假设分配中增量份额不可忽略的情况 |
| 触发场景 | 增长率较大导致"增量"占比高，不能忽略，常规取整修正不适用 |
| 步骤逻辑 | ① 将增长率近似为简单分数p/q；② 按基期:增量=q:p分配剩余量；③ 现期对应q+p份，用原式反算检查近似误差；④ 误差可能跨越选项时改用精算 |
| 高频错因 | 在高增长率时仍用小r的取整修正法，导致增量份额严重低估 |
| confidence | medium |

## 补充说明

此方法是假设分配法在高增长率场景下的延伸。核心判断依据：看余数中"增量"占比是否大到不能忽略。r越大，增量占比越高，第二步越需要精确分配。当r接近100%时，基期和增量几乎一样大，平分是最快的处理方式。当估算误差可能跨越选项或改变结论时，改用精算/验证。

## 不适用条件

1. 常规取整修正已经足以区分选项，无需再做份数分配。
2. 假设分配第一步分配精度已足够，余数极小，无需第二步修正。
3. 题目不涉及基期或增量的求解，假设分配法本身不适用。

## 反向触发

1. 常规取整修正明显低估增量份额，且增长率可近似为简单分数。
2. r接近100%，基期与增量几乎等量，需要对称处理。
3. 第一步分配后余数中增量占比明显，不能忽略。
