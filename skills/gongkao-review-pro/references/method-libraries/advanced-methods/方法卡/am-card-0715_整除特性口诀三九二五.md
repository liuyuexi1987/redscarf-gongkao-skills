# 方法卡：整除特性口诀三九二五

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 整除特性口诀三九二五 |
| 适用题型 | 数量关系——整除、倍数与不定方程 |
| 触发场景 | 题目出现“整除、倍数、平均分”等条件，需要用末位或数字和快速筛选整数候选 |
| confidence | medium |
| 步骤逻辑 | 纯整除问题用"三九二五"口诀快速判断：三九看各位数字和，二四八看末位/末两位/末三位。；1. **三的倍数**：个位数字之和是3的倍数→该数是3的倍数；2. **九的倍数**：个位数字之和是9的倍数→该数是9的倍数；3. **五的倍数**：尾数是0或5；4. **二四八**：看末位/末两位/末三位能否被2/4/8整除；5. **二十五**：看末两位能否被25整除；6. **一百二十五**：看末三位能否被125整除 |
| 高频错因 | 只记口诀不检查题目是否要求完整求解；混淆“各位数字和”与“末位/末两位/末三位”规则；排除候选后没有回代原方程。 |

## 补充说明

- 9=3×3，需要两个3因子才是9的倍数
- 这个口诀在不定方程中非常实用，能快速缩小未知数范围

## 不适用条件

- 除数不属于这些基础整除特征，或题目要求完整求解而非筛选候选。
- 数值含小数、分数或单位换算后不是整数。

## 反向触发

- 多个整除条件同时出现时，结合最小公倍数、奇偶和尾数共同筛选。
- 整除特征只能排除，无法唯一确定时继续代入原方程验证。
