# 方法卡：图推田字型两笔画识别

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 图推田字型两笔画识别 |
| 适用题型 | 判断推理——图形推理（笔画数） |
| 触发场景 | 图形中出现"田"字型结构 |
| 步骤逻辑 | ① 看到田字型→马上想到两笔画；② 田字型有4个奇点→两笔画；③ 对常见一笔画/两笔画特征图要有敏感性；④ 一笔画特征图：人字型、五角星、圆+切线等 |
| 高频错因 | ① 看到田字型不敏感→数笔画浪费时间；② 一笔画和两笔画特征图记混→判断错误 |
| confidence | high |

## 补充说明
特征图可快速提示笔画数，但最终仍要用连通性和奇点数核验。线条断开、相接位置改变时，笔画数也可能随之变化。

## 不适用条件

- 图形整体高度相似且呈现移动、旋转、翻转规律时，应优先走移转叠路径。
- 图形以封闭区域数量、对称轴等更明显的规律为主导时，笔画数通常不是主考点。

## 反向触发

- 田字型结构出现但笔画数规律不成立时，应补充核验面的数量、交点数等其他维度。
- 图形并非典型特征图但奇点数明显时，应直接通过奇点计数判定笔画数而非依赖特征图。
