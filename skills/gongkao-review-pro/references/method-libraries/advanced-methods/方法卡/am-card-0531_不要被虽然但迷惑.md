# 方法卡：不要被"虽然……但……"迷惑

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 不要被"虽然……但……"迷惑 |
| 适用题型 | 质疑/削弱题（逻辑判断） |
| 触发场景 | 选项用"虽然（承认原结论的一部分）……但（给出新论据）"结构，容易让考生误以为它在质疑题干 |
| 步骤逻辑 | 1. 看到"虽然A但B"结构时，不要自动认为它能质疑；2. 将"虽然"后面的A和"但"后面的B拆开，分别检验与题干论证链的关联性；3. 重点检验B是否与题干的核心概念有逻辑关联——若B引入的主体或概念与题干完全无关，则整个选项是无关项；4. "虽然……但……"只是语言包装，不等于逻辑论证 |
| 验证动作 | 问自己：B中提到的概念是否出现在题干的前提或结论中？若B的主体/概念与题干毫无交集，则该选项无法构成质疑 |
| 不适用条件 | 当B确实与题干核心概念有逻辑关联时，此结构可以构成有效质疑；本法仅防范"形式像质疑但内容无关"的陷阱，不是否定所有"虽然……但……"选项 |
| 高频错因 | 看到"虽然……但……"就下意识觉得选项能质疑，被选项的语言形式迷惑，不去检验实际内容的逻辑关联性 |
| confidence | high |
| 反向触发 | 拆解后发现B中的概念确实出现在题干前提或结论中，且B对题干论证链构成实质性削弱或支持时，放弃本法的"无关项"判断，按正常削弱/加强逻辑分析该选项 |

> **使用边界**：本方法用于提供优先检查方向，不可单独据此作答；最终需回到题干关系、原文证据或选项条件完成验证。
