# 方法卡：主旨匹配三维筛选

## 基本信息

| 字段 | 值 |
|---|---|
| 方法名 | 主旨匹配三维筛选 |
| 适用题型 | 言语理解-中心理解题 |
| 触发场景 | 主旨已确定，两个或多个选项都看似正确，需要最终比较筛选 |
| 必要输入 | 已确定的文段主旨或正确方向；待比较的2个以上选项 |
| 步骤逻辑 | 1. **比形式**：判断选项属于哪种表述类型（对策/问题/意义/中性描述）；形式不匹配时优先核对内容覆盖关系，不直接排除 2. **比针对性**：形式相同的选项中，哪个更精准针对文段核心问题，而非只抓了问题的一部分或泛泛而谈 3. **比论证支撑**：剩余选项中，哪个有文段中的对应论证，而非无中生有或过度引申；三步依次执行，每步都可能直接筛出答案 |
| 验证动作 | 选中选项可回代验证：该选项是否覆盖文段核心议题，是否与文段整体态度一致 |
| 不适用条件 | 主旨尚未确定时不应使用——应先完成主旨判断再进入选项筛选；单选项可直接判断对错时无需使用 |
| 高频错因 | 1. 在第一步（比形式）之前就纠结选项细节词（如动词、修饰词），忽略形式类型的优先判断 2. 形式不同时仍试图比较针对性和论证支撑，本该直接排除的形式不符选项未排除 3. 仅凭选项措辞是否"漂亮"判断，未回看文段验证针对性和支撑 |
| confidence | high |
| 反向触发 | 1. 当剩余选项形式一致、针对性相当且文段无明确论证支撑某一项时，该方法无法筛出答案，应代入原文逐句精算验证 2. 当两个选项在三步筛选后均未被淘汰且均有文段支撑时，说明维度不足区分，应比较选项与文段核心句的覆盖完整度而非继续沿用三步顺序 |

---

> **使用边界**：本方法用于提供优先检查方向，不可单独据此作答；最终需回到题干关系、原文证据或选项条件完成验证。
