# 方法卡：混合增长率区间判断

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 混合增长率区间判断 |
| 适用题型 | 资料分析——总体由两部分构成，求总体增速或判断某部分增速范围 |
| 触发场景 | 出现"A+B=C"的加法关系，给出两部分增速判断总体增速，或给出总体和一部分判断另一部分 |
| 步骤逻辑 | ① 识别总体由哪两部分构成；② 总体增速一定介于两部分增速之间；③ 已知总体和一部分增速 → 另一部分在另一侧 |
| 高频错因 | 分不清哪部分高于总体、哪部分低于总体；误认为总体是两部分增速的平均值（仅在两部分量相等时成立） |
| confidence | high |

## 补充说明

典型场景一：本外币存款=本币+外币，本币9.2%、外币9%→总体在9%~9.2%之间。典型场景一到四月=一到三月+四月，总体8.6%、四月17.3%→一到三月低于8.6%。核心原则：总体增速一定介于两部分增速之间，据此可快速排除超出区间的选项。

## 不适用条件

1. 两部分不是加法关系（如乘法、除法关系构成总体）时，区间判断法不适用
2. 两部分基数差距极大时，总体增速明显偏向基数大的一方，仅靠区间判断精度不够
3. 选项全部落在区间内部且间距极小时，区间判断无法区分，需改用加权精算

## 反向触发

1. 当选项全部落在区间内部时，应换用十字交叉法或加权计算来判断偏向方向和具体位置
2. 当题目给出的不是两部分而是一个整体拆分为三部分以上时，两两区间判断会过于宽泛，需额外核验或拆分处理
3. 当增速数据涉及不同基数（如名义增速与实际增速混用）时，区间判断的前提可能不成立，应先确认数据口径一致
