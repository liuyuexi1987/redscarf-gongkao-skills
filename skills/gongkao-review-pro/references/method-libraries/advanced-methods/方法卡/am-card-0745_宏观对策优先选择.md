# 方法卡：宏观对策优先选择

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 宏观对策优先选择 |
| 适用题型 | 言语理解——片段阅读（主旨/意图题，对策类） |
| 触发场景 | 文段先给宏观对策，后文展开为多条具体措施，具体措施过于细碎不好概括 |
| 步骤逻辑 | ① 识别“宏观对策 + 具体展开”的总分结构；② 检查后文措施是否都受该宏观对策统领；③ 优先比较能覆盖主体、核心问题和全部措施的概括项；④ 排除只对应某一条措施或把多条措施杂糅错位的选项 |
| 高频错因 | 试图概括所有具体措施导致选了一个片面或杂糅的选项；选了只对应某一条具体措施的选项（片面） |
| confidence | medium |
| 不适用条件 | - 文段没有"总-分"前对策结构，对策出现在文段末尾（先问题后对策）时，不适用宏观对策优先。- 后文具体措施可以精炼概括为一条对策且有对应选项时，优先选概括选项而非笼统的宏观表述。 |
| 反向触发 | - 文段是"问题→原因→对策"的递进结构，对策在末尾且只有一个，应触发尾部对策选择。- 文段是并列结构（几个独立观点），没有宏观统领性对策，应触发并列主旨概括法。 |

## 补充说明

典型场景是文段先提出统领性规划，后文再分述不同对象的具体治理措施。此时可优先检查概括该规划的选项，但仍要核对主体、范围和目的是否覆盖后文；指示代词常可帮助识别统领关系。
