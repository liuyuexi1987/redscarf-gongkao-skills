# 方法卡：否定代入法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 否定代入法 |
| 适用题型 | 前提假设题（判断选项是否为必要前提） |
| 触发场景 | 需要判断某选项是否为必要前提/假设时 |
| 步骤逻辑 | 1. 将选项内容进行否定；2. 将否定后的选项代入题干论证；3. 若否定后代入导致结论不成立，则该选项是必要前提；4. 若否定后代入结论仍可成立（有它也行没它也行），则该选项不是必要前提 |
| 高频错因 | 认为选项"听起来有道理"就选，未验证其必要性；忽略"有它也行没它也行"的选项不是必要前提 |
| 不适用条件 | 题目不要求验证必要性（如问"以下哪项最能削弱"时削弱力度与必要性不同）；选项内容无法明确否定（模糊或主观表述） |
| 反向触发 | 题目问的是削弱/加强力度排序，而非"是否为必要前提" |
| confidence | high |
