# 方法卡：等差数列中间项跨段传递

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 等差数列中间项跨段传递 |
| 适用题型 | 多段等差数列（如连续几个五年计划），已知各段关系求总和 |
| 触发场景 | 题目给出多个相邻等差数列段（公差相同），并给出各段总和的比例关系 |
| 步骤逻辑 | 1. 用公差 d 表示各段的中间项（如第二段中间项 = 第一段中间项 + 5d）；2. 利用"项数相同时，总和比 = 中间项比"，将总和比例关系转化为中间项方程；3. 解出中间项的值；4. 把所有段看作一个完整的等差数列，用中间项 × 总项数求总和 |
| 高频错因 | 分别算每段再相加，计算量大且易错；忽略"项数相同可约掉"的简化 |
| confidence | medium |
| 不适用条件 | - 各段等差数列的项数不同时，"总和比=中间项比"不再成立，不能直接用中间项传递。- 各段公差不同（不是同一个等差数列的连续段）时，跨段传递公式不适用。 |
| 反向触发 | - 题目只涉及单段等差数列的求和或求某项，不需要跨段传递，直接用等差数列求和公式。- 题目是等比数列而非等差数列，应触发等比数列相关方法。 |

## 补充说明

- 示例：十二五/十三五/十四五各5年，公差1.5亿。A3为十二五中间项，十三五中间项=A3+7.5，十四五中间项=A3+15
  - "十四五=（十二五+十三五）×80%" → 中间项方程：A3+15 = 0.8×(2A3+7.5)，解得A3=15
  - 最后整体15年，中间项A8=22.5，总和=22.5×15=337.5
  - 口诀提醒：等差数列整体同乘可约掉，优先看中间项
