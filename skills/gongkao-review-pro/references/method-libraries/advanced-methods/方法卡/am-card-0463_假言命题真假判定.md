# 方法卡：假言命题真假判定

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 假言命题真假判定 |
| 适用题型 | 判断推理 > 基础逻辑（假言命题/如果那么） |
| 触发场景 | 题目问"如果那么"命题在什么情况下为真/为假；判断必定为假的选项 |
| 步骤逻辑 | 1. A→B（如果A那么B）为假**只有一种情况**：A真B假（前件真后件假）；2. A→B为真有**三种情况**：A真B真、A假B真、A假B假；3. 核心理解：命题为真 ≠ 事实一定发生。A→B为真，不代表A一定发生B一定发生；4. 考场口诀："只有前真后假才为假，其余三种都为真"；5. 判断"必定为假"：直接找前件真后件假的选项，其他都可能为真 |
| 高频错因 | 认为"A→B为真"就说明A和B都发生了；分不清命题真伪和事实真伪的区别 |
| confidence | high |

## 补充说明

假言命题A→B的真假只取决于前件A和后件B的真假组合，共四种情况。其中前真后假（A真B假）是唯一使A→B为假的情况。其余三种（A真B真、A假B真、A假B假）都使A→B为真。考场应用：看到"必定为假"，直接找前件真后件假的选项；看到"可能为真"，只需排除前真后假那一项即可。

## 不适用条件

- 题目涉及的是等价关系（A↔B）而非条件关系（A→B）时，真假判定规则不同（等价关系在前假后假和前真后真时为真）
- 题目问的是"哪个选项与题干矛盾"而非"哪个必定为假"时，应找题干的矛盾命题（A且非B），而非逐个判断A→B的真假
- 题目涉及多层嵌套条件（如A→(B→C)）时，需分层判断，不能直接套单层规则

## 反向触发

- 若选出的"必定为假"选项在某一赋值下确实为真（存在使A为假的情况），说明未穷尽四种情况，应回到真值表重新检查
- 若题目条件为"当且仅当"（充分必要条件），A→B和B→A同时成立，此时应分别判断两个方向的真假，不能只看单向
