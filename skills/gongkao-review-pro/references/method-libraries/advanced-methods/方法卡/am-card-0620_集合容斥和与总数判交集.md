# 方法卡：集合容斥和与总数判交集

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 集合容斥和与总数判交集 |
| 适用题型 | 判断推理/数量关系——集合容斥类 |
| 触发场景 | 已知各集合人数和总人数，问是否一定有交集或能否推出某结论 |
| 步骤逻辑 | ① 算各集合数量之和；② 若和 ≤ 总数：不一定有交集（可能完全不重叠）；③ 若和 > 总数：一定有交集，多余部分即交集最小值；④ 圈内总人数 = A + B - 交集，圈外 = 总数 - 圈内 |
| 高频错因 | 混淆"不一定有交集"与"一定没有交集"；忘记9+7=16<17说明可能存在无人参加的情况 |
| confidence | high |
| 不适用条件 | 1. 不适用于三集合及以上容斥（需用容斥公式而非简单和与总数比较）\n2. 题目已给出具体交集数值或给出集合间数量关系时，不需要用和与总数判断\n3. 题目问的是最大交集或并集人数时，本方法不适用 |
| 反向触发 | 1. 看到三个及以上集合重叠（如同时参加舞蹈、合唱、朗诵），不用本方法，改用容斥公式\n2. 题目给出A∩B的具体值或比例关系，直接用公式算圈内人数，不需要先判断是否有交集\n3. 题目问的是 |

## 补充说明

例：舞蹈9人 + 合唱7人 = 16人，总17人，16<17不一定有交集，故"肯定有交集"为错。若A交B=2，则圈内=9+7-2=14，圈外=3。
