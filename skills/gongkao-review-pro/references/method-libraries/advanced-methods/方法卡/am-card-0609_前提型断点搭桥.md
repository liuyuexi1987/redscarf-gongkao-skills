# 方法卡：前提型断点搭桥

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 前提型断点搭桥 |
| 适用题型 | 判断推理——前提假设类 |
| 触发场景 | 题目问"前提""假设""必要条件"，且论据和结论之间存在概念跳跃（断点） |
| 步骤逻辑 | ① 找准论据和结论；② 整理论据（若多句可连锁推理合并）；③ 对比论据与结论的关键词，找出论据有但结论没有、或结论有但论据没有的话题——即断点；④ 从选项中找同时连接断点两端的选项，直接搭桥；⑤ 其余选项因未搭桥而排除（"以我为主"） |
| 高频错因 | 被无关选项干扰、试图用逆否等复杂推理、未识别论据可链式推理整理后的简化形式 |
| confidence | high |

## 补充说明

若论据为多句连锁推理，可先合并简化为"X→Y"形式；结论若为"非X→非Y 的等价表述"，断点常在"Y"与结论主语之间。识别断点后不需做逆否推理，直接找同时连接断点两端的搭桥选项即可。

## 不适用条件

1. 论据与结论之间无明显概念跳跃时不适用。
2. 问法非前提假设类（如削弱、解释、加强）时不适用。
3. 行文逻辑反常（按原文顺序推导不通）时不适用，应先做论据结论颠倒识别。

## 反向触发

1. 若无断点，应换用反向代入否定法。
2. 若行文逻辑反常（颠倒），应先做论据结论颠倒识别再搭桥。
3. 若多个选项均看似搭桥，需复核哪个选项同时覆盖断点两端关键词，排除单边覆盖的干扰项。
