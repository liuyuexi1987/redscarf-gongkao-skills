# 方法卡：倍数比较看分数大小

| 字段 | 内容 |
|------|------|
| 方法名 | 倍数比较看分数大小 |
| 适用题型 | 资料分析-比较多个比值大小（如"每支平均金额排序"） |
| 触发场景 | 比较多个"某量÷某量"的比值大小，分子分母单位不同，数值差异明显 |
| 步骤逻辑 | 1. 列出每个选项的分子分母 → 2. 看分子分母的倍数关系（如分子是2倍，分母也是2倍则比值相近） → 3. 分子倍数远超分母倍数→该比值大；分母倍数远超分子倍数→该比值小 |
| 高频错因 | 逐个算除法比较，没有利用倍数关系快速淘汰 |
| 不适用条件 | 分子分母数值接近、倍数关系不明显时，仍需精确计算 |
| 反向触发 | 比值之间数值差异极小，倍数观察法无法区分大小时 |
| confidence | high |

补充说明：如比较 668/0.92 和 1394/22.2，分母约2倍关系（668→1394约2倍），分子约24倍关系（0.92→22.2约24倍），分母倍数远大→该比值大。核心是"圈圈勾勾画"看倍数。
