# 方法卡：不完美选项接受规则

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 不完美选项接受规则 |
| 适用题型 | 言语理解——中心理解（选项择优） |
| 触发场景 | 选项有小瑕疵但其他选项更差时 |
| 步骤逻辑 | ① 主题词同义替换可接受（如"信息平台"≈"数字技术"）；② 漏限定词可接受（如"职业教育"代替"高水平职业教育"）；③ 扩大概念可接受（如"针灸铜人"代替"天圣针灸铜人"）；④ 有瑕疵但其他更差→选有瑕疵的 |
| 高频错因 | ① 选项有瑕疵就不选→选了更差的；② 追求完美答案→反而选错 |
| confidence | high |

## 补充说明
命题人对小瑕疵不care→考生也别care。如C选项漏了"高水平"三个字→但其他选项也没有→接受C。

## 不适用条件
- 存在完美匹配主旨且无瑕疵的选项时
- 选项瑕疵是核心概念错误而非细节偏差时
- 题目明确要求选"最准确""最恰当"且有明显更优选项时

## 反向触发
- 选项有明显逻辑错误、偷换概念或偏离主题时，不应当作"小瑕疵"接受
- 所有选项都有同等瑕疵且无法比较优劣时，此法无法帮助决策
