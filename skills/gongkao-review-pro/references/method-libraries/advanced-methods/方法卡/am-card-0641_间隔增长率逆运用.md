# 方法卡：间隔增长率逆运用

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 间隔增长率逆运用 |
| 适用题型 | 资料分析——已知总增长率和其中一个分段增长率，求另一个分段增长率 |
| 触发场景 | 题目给出23年比21年的总增长率R和23年比22年的R1，求22年比21年的R2 |
| 步骤逻辑 | ① 画时间轴确定总增长率 R 与已知分段增长率 R1；② 由 `1+R=(1+R1)(1+R2)` 得 `R2=(R-R1)/(1+R1)`；③ 先判断符号和量级，再代入公式计算并复合回验 |
| 高频错因 | 符号判断错误；忘记乘积项的影响 |
| confidence | medium |

## 补充说明

当 `1+R1` 为正时，R2 的符号由 `R-R1` 决定；其绝对值与差值的关系还取决于 R1 的正负，不能一概而论。最稳妥的路径是直接用精确公式并回代。

## 不适用条件

- R1 接近使分母异常的边界，或增长口径在两段之间发生变化。
- 给出的总变化不是连续复合增长率。

## 反向触发

- 只需判断 R2 正负时，可先比较 R 与 R1。
- 需要具体数值或选项接近时，必须使用精确公式，不用“比差值略小”的口算结论。
