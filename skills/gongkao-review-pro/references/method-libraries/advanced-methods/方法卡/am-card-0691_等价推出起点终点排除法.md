# 方法卡：等价推出起点终点排除法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 等价推出起点终点排除法 |
| 适用题型 | 逻辑——推出类·等价推出（"由此可以推出"/"以下哪项正确表述了上述断定"） |
| 触发场景 | 题干含逻辑关联词（如果那么/只有才/除非否则等），选项也都是逻辑表述，要求选与题干等价的选项 |
| 步骤逻辑 | ① 翻译题干为 A→B（可含链式 A→B→C→D）；② 记住起点站=A或非B，终点站=B或非A；③ 先看选项开头：以B或非A开头的选项直接排除（终点站推不下去）；④ 剩余选项逐个翻译比对逻辑关系，找与题干等价者；⑤ 等价的只有两种：原命题 A→B 和逆否命题 非B→非A |
| 高频错因 | 选了逆命题（B→A）或否命题（非A→非B），它们与原命题不等价；把终点站开头的选项当正确答案 |
| confidence | medium |
| 不适用条件 | - 题目要求找矛盾命题而非等价命题时，不适用起点终点排除法，矛盾关系与等价关系判断逻辑不同。- 题干没有逻辑关联词、选项只是事实陈述对比时，不套用翻译排除。 |
| 反向触发 | - 题干出现"所有/有些"量词命题要求取矛盾，应触发am-card-0686（所有有些两词互换否定法）。- 题干要求找"可以推出"的单向蕴含而非"等价"表述，起点仍可用但终点排除规则不完全适用，需逐项验证充分条件推导。 |

## 补充说明

类比火车轨道：题干给 A→B，A 和非B 是"始发站"可以发车往下推，B 和非A 是"终点站"推不下去。逆命题（B→A）和否命题（非A→非B）常作为干扰项出现。对于链式推理 A→B→C→D，正确答案通常是 A→D 或 非D→非A，起点终点判断法同样适用。示例提示"无情的翻译机器"——不需要理解内容含义，只看逻辑结构。
