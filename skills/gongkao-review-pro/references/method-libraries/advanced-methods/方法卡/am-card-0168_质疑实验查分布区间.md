# 方法卡：质疑实验查分布区间

| 字段 | 内容 |
|------|------|
| 方法名 | 质疑实验查分布区间 |
| 适用题型 | 逻辑判断——削弱质疑（题干用两极端值做对比得出结论） |
| 触发场景 | 题干给出极端组A的数值和极端组B的数值，用分布差异得出因果结论；选项给出中间组的数值 |
| 步骤逻辑 | 1. 记录题干两端数值：极端好=X%、极端差=Y% |
| | 2. 正常/中间组数值若落在X%~Y%之间→支持结论（分布合理） |
| | 3. 正常/中间组数值若超出X%~Y%区间→质疑结论（说明极端组并无优势/劣势） |
| | 4. 选择超出区间的选项作为质疑答案 |
| 高频错因 | ①只要数字看起来有差异就认为是质疑②忽略中间值应落在两极端之间的逻辑要求 |
| confidence | high |

## 不适用条件

- 题干只给出单组数据（无两端极端值对比），不存在区间概念，不适用。
- 题干结论为直接因果论证而非分布差异推论时，应按常规削弱方式处理。
- 题目要求的是加强而非质疑时，应反向选择落在区间内的选项。

## 反向触发

- 题干给出"最高组/最低组"或"最好/最差"两端数据，且选项涉及中间组时，提示用区间分析。
- 选项数字与题干两端数字构成明显超出或落入关系时，提醒检查区间逻辑。

**补充说明：**
- 典型案例：基因得分最低者大学毕业率10%、最高者50%→结论"基因与学历有关"。中间组60%毕业率超出[10%,50%]区间→质疑（说明正常人反而比基因好的毕业率高，基因没什么优势）。
- 反向也成立：中间组若<10%同样可质疑（说明基因差但正常人更差，逻辑不成立）。
- 关键是"区间外"而非"绝对值大小"——30%在区间内则支持，60%在区间外则质疑。
