# 方法卡：集合推理画图法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 集合推理画图法 |
| 适用题型 | 判断推理——集合推理题（直言命题推理） |
| 触发场景 | 题目给出多个关于A、B、C之间"所有/有的/不是"关系的条件，问能推出什么 |
| 步骤逻辑 | ① 先画确定关系：所有A都是B（A实线在B内）、所有A都不是B（A与B完全分离）；② 再画不确定关系：有的A是B（在A内画B的虚线部分）、有的A不是B（在A外画B的虚线部分）；③ 虚线表示范围可变，实线表示范围确定；④ 逐条添加条件，利用已确定范围推导新关系 |
| 高频错因 | ① 先画"有的"再画"所有"，导致范围混乱；② 把虚线当实线用，忘记范围可以变化；③ 有的A是B≠有的B不是A（不可逆推） |
| confidence | high |

## 不适用条件

- 纯假言命题推理题（如果…则…，无直言命题）
- 不含"所有/有的/不是"关系的判断题
- 题目条件全部为确定关系、无需画虚线的情况

## 反向触发

- 题目只有假言条件，没有直言命题
- 条件均为"如果…那么…"结构，无集合包含关系

## 补充说明

虚线代表"存在但范围不确定"，可以变大变小甚至包住对方。所有A都是B时A是实线（范围确定），有的A是B时B用虚线（范围任意）。判断"一定为真"时，需要在所有可能情况下都成立。
