# 方法卡：定序插空公式
## 基本信息
| 字段 | 值 |
|------|-----|
| 方法名 | 定序插空公式 |
| 适用题型 | 数量关系-排列组合/插空 |
| 触发场景 | 已有若干人排好且相对位置不变，新人插入，求排列数 |
| 步骤逻辑 | 1.分步：先选人（如C82），再算插空排列数 2.插空法公式：A(总人数,总人数)÷A(定序人数,定序人数) 3.如6人中4人定序→A66÷A44=6×5=30 4.或分两类：在一起→C(空数,1)×A22；不在一起→A(空数,2) 5.两种插空方法结果相同 |
| 高频错因 | 混淆"在一起"和"不在一起"的插空方式；忘记乘以新人的排列A22 |
| confidence | high |

## 不适用条件

1. 没有定序约束，所有人自由排列时，直接用全排列A(n,n)即可
2. 定序元素之间有间隔要求（如不能相邻）时，不能用A(n,n)÷A(k,k)，需改用插空排除法

## 反向触发

1. 题目要求"在一起"和"不在一起"两种情况都求时，分别计算再相加验证总数是否等于全排列
2. 插入人数超过2人且有各自位置约束时，需分步讨论，不能直接套用公式
## 补充说明
A66÷A44的推导思路：先将6人全排列（含4人定序的多种排列），再除以4人的排列数消掉定序部分，得到4人固定时2人插空的排列数。也等价于分"在一起/不在一起"两类的C51×A22+A52=10+20=30。
