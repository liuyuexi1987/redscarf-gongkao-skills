# 方法卡：数字置换9的倍数特性
## 基本信息
| 字段 | 值 |
|------|-----|
| 方法名 | 数字置换9的倍数特性 |
| 适用题型 | 数量关系-数字特性/数字置换 |
| 触发场景 | 题干出现"数字交换位置""数字置换"等描述 |
| 步骤逻辑 | 1.识别数字交换位置的描述 2.理解交换前后差值必为9的倍数 3.直接在选项中找9的倍数锁定答案 |
| 高频错因 | 不识别"交换位置"即数字置换；不敢直接用特性判断 |
| confidence | high |
## 补充说明
两位数AB变为BA：(10A+B)-(10B+A)=9(A-B)，恒为9的倍数。三位数同理。示例提示"直接用特性判断"，考试中应快速锁定。

## 不适用条件
- 置换涉及不同位数的数字拼接（如AB变成ABA），差值不再恒为9的倍数
- 题目要求精确求解数字本身而非排除选项，此时特性仅缩小范围，不能直接锁定答案
- 非十进制进位体系下的数字置换

## 反向触发
- 看到"交换位置""调换""互换"数字的描述，立即联想差值为9的倍数
- 选项中有明显9的倍数且其他选项不是，可用本法快速排除
- 题目描述两位数或三位数的各位数字重组，但未给出具体数字，优先考虑数字特性
