# 方法卡：严谨逻辑关系找反例

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 严谨逻辑关系找反例 |
| 适用题型 | 判断推理——削弱/质疑类（结论含"只要就""所有""如果那么"等逻辑关联词） |
| 触发场景 | 结论出现逻辑关联词（只要就、所有、如果那么等），问法为削弱/质疑 |
| 步骤逻辑 | ① 识别题型：结论含逻辑关联词 → 判定为"严谨逻辑关系"题；② 将结论翻译为A推B（如"高分进好学校→好教育"）；③ 最强削弱找矛盾：A且非B（如"高分进好学校却没得到好教育"）；④ 结论若为绝对化表述（所有/只要），一个反例即可最强质疑 |
| 高频错因 | 仍按一般归因思路分析，未识别出逻辑关联词；找到矛盾选项后还犹豫比较其他选项 |
| confidence | high |

## 补充说明

结论含"只要就""所有""如果那么"等逻辑关联词时，将结论翻译为A→B（如"具备条件A就得到结果B"），最强削弱即找"A且非B"的反例（具备条件A却未得到结果B的情境）。

这类题的关键是快速识别逻辑关联词判定题型，不要用归因思路去纠结选项比较——一个符合"A且非B"的反例即可最强质疑绝对化结论。

## 不适用条件

- 结论不含逻辑关联词（"只要就""所有""如果那么"等）时，不适用此法，应按一般归因削弱处理。
- 结论是概率性/趋势性表述（非绝对化）时，单个反例不足以构成最强削弱。
- 题目问法为"加强/支持"而非"削弱/质疑"时，应换用补强思路。

## 反向触发

- 当结论是归因关系而非条件推理时，应换用"因果倒置"或"他因削弱"法。
- 当结论含逻辑关联词但选项中没有"A且非B"的反例时，应换用"切断关联"或"前提不成立"等削弱思路。
- 当选项中出现多个看似反例的项时，应核验哪个真正构成"A且非B"的完整矛盾，而非选择部分匹配项。
