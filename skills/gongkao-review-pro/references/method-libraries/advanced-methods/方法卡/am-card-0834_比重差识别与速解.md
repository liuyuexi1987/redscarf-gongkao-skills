# 方法卡：比重差识别与速解

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 比重差识别与速解 |
| 适用题型 | 资料分析——两期比重比较·定量分析（比重差），求比重上升/下降了几个百分点 |
| 触发场景 | 题干含"比重/占比/赞…比上年"且选项单位为"百分点"（百分数做差得到百分点） |
| 步骤逻辑 | ① 识别题型：题干有比重/占比/赞 + 选项百分点 → 确定考比重差；② 先判断方向：R1大于R2则比重上升（排除两个下降选项），反之排除两个上升选项；③ 尝试快速判断：比重差的数值（绝对值）一定小于增速差的数值（绝对值），即|R1-R2| > |比重差|，据此排除不符选项；④ 若仍无法确定，套公式：比重差 = 去年的部分/今年的整体 × (R1-R2)，其中"去年的部分"用假设分配第一步估算（选项间距远时粗估即可，间距近时用假设分配精确算） |
| 高频错因 | ① 百分点和百分数混淆（10%减5%=5个百分点，不是5%）；② 快速判断时把增速差算反或忘取绝对值；③ 找R1/R2时把分子分母对应指标搞反；④ 用假设分配第一步时过于粗糙导致选项间距小时选错 |
| confidence | medium |

## 补充说明

公式中"去年的部分/今年的整体"是一个部分÷整体的关系，一般小于1（因为部分 < 整体），所以比重差 = 小于1的数 × 增速差，数值一定小于增速差。公式中"去年的部分"题目不直接给，需要用假设分配求基期的第一步近似。选项间距大时粗估误差不影响选择；选项间距小时需认真用假设分配算出去年的部分。比值差（如平均单价、亩产）的计算见"非比重比值差"卡。

## 速算边界

当估算误差可能跨越选项或改变结论时，改用精算/验证。

## 不适用条件

- 题目问的是定性判断（上升/下降）而非定量百分点时，用"两期比重趋势判断"卡即可，不需要套公式。
- "去年的部分/今年的整体"中的部分和整体不好确认（如多层嵌套结构），公式展开难度大，需改用分别求基期再算。
- R1和R2差距极小且选项精度要求高（如精确到0.01百分点），粗估无法区分选项。

## 反向触发

- 题目只问"比重上升还是下降"，不需要算百分点，走趋势判断卡。
- 材料只给了增长率没给基期量，且选项间距小，需先补基期数据。
