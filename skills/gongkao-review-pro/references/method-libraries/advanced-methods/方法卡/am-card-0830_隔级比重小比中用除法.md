# 方法卡：隔级比重-小比中用除法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 隔级比重-小比中用除法 |
| 适用题型 | 资料分析——三层嵌套结构中求最小层占中间层的比重 |
| 触发场景 | 数据分三层，求最内层占中间层的比重；材料给小比大和中比大两个占比 |
| 步骤逻辑 | ① 理清三层关系（小、中、大）；② 小比中 = 小比大 ÷ 中比大（除法约掉最外层）；③ 如制造业占GDP=35.8%，二产占GDP=44.5%，则制造业占二产=35.8÷44.5 |
| 高频错因 | 混淆乘法和除法——小比大用乘法（约中间层），小比中用除法（约最外层）；用错年份的占比数据 |
| confidence | medium |
| 不适用条件 | 数据只有两层而非三层嵌套结构；题目问的是小比大（用乘法约中间层）而非小比中；材料未同时给出小比大和中比大两个占比 |
| 反向触发 | 题目考查的是小层占最外层的比重（应用乘法）；材料直接给出了小层占中层的比重，无需计算；题目涉及的是增长率比较而非比重换算 |

## 补充说明

隔级比重的本质就是约分：把不需要的那一层约掉。小比大要让中间层在分子分母各出现一次再约掉，所以用乘法；小比中要让最外层在分子分母各出现一次再约掉，所以用除法。考试中这种题出现频率不高，但一旦出现很多同学会被绕晕。
