# 方法卡：范畴推理一分为二画图法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 范畴推理一分为二画图法 |
| 适用题型 | 判断推理——范畴推理/三段论 |
| 触发场景 | 题干出现"所有A是B""有些A是B"等集合关系表述，选项判断是否能推出 |
| 步骤逻辑 | ① 找B和非B（矛盾关系）构成全集，一分为二；② 把题干条件分别归入两侧（如"同意开展"放左、"报名外语培训"放右）；③ "有些"条件用交集标记；④ 对照选项，看图判断是否必然成立或不一定成立 |
| 高频错因 | 将"有些"等同于"部分"（"有些"可以代表全部）；混淆集合包含与交集关系 |
| confidence | high |

## 补充说明

替代方法为直接连锁推理：前提A→B，前提B→C，整理得A→C，再与结论对比找答案。两种方法结果一致，画图法更快。

## 不适用条件

- 题干条件非集合包含/交集关系（如纯条件命题、模态命题）时不适用。
- 关系为传递性、对称性等二元关系而非范畴关系时不适用。
- 选项问的是"能否推出某具体实例"而非"能否推出某集合关系"时收益有限。

## 反向触发

- 题干为条件命题连锁时，改用"连锁推理/假言推理"直接整理。
- 题干含模态词（必然/可能）时，转用模态逻辑方法。
- 选项涉及数量比较时，改用数量关系推理或枚举验证。
