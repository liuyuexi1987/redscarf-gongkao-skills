# 方法卡：严谨逻辑削弱找A且非B

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 严谨逻辑削弱找A且非B |
| 适用题型 | 判断推理——削弱类（题干含"只有才""只要就"等严谨逻辑关联词） |
| 触发场景 | 结论中出现"只有A才B""只要A就B"等关联词，问削弱/反驳 |
| 步骤逻辑 | ① 翻译逻辑关系：只有A才B→后推前=B推A；只要A就B→前推后=A推B；② 找矛盾削弱：A推B的矛盾=A且非B，即"前件成立但后件不成立"；③ 如"只有实行目标责任制才能经济增长"→经济增长推目标责任制→矛盾=经济增长且未实行目标责任制；④ 主体一致的A且非B力度最强，类比推理（不同主体的A且非B）力度次之 |
| 高频错因 | 把"只有才"方向翻译反；选了他因削弱（力度弱于直接矛盾）；忽略主体一致性的力度差异 |
| confidence | high |

## 补充说明

此题型考查形式逻辑推理，与归因类削弱（对比实验、因果倒置）是不同题型。区分标志：结论中有明确逻辑关联词"只有才""只要就"。典型场景："只有实行目标责任制才能经济增长"→经济增长推目标责任制→矛盾=经济增长且未实行目标责任制。主体一致的A且非B力度最强，不同主体的类比推理力度次之，他因削弱力度最弱。

## 不适用条件

1. 当结论中无明确逻辑关联词（"只有才""只要就"等），而是一般因果表述时，应判断为归因类削弱而非逻辑矛盾类
2. 当选项中无"A且非B"形式的选项时，需换用力度排序法在其他削弱类型中选择
3. 当题干逻辑关系含有多层嵌套条件时，需先理清逻辑链再套用此法

## 反向触发

1. 当结论是实验归因（含对比实验/分组设计）时，应换用对比实验他因削弱法回归分组判断
2. 当结论是纯因果关系（无逻辑联结词）且问力度排序时，应换用因果倒置>他因削弱>拆桥的通用力度排序
