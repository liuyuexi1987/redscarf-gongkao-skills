# 方法卡：数位拆分求和法

| 字段 | 内容 |
|------|------|
| 方法名 | 数位拆分求和法 |
| 适用题型 | 资料分析-多位数求和（如5年数据求总和、判断范围） |
| 触发场景 | 多个三位或四位数求和，需要快速判断总和范围，不需精确值 |
| 步骤逻辑 | 1. 按百位、十位、个位分别求和 → 2. 百位求和确定千位 → 3. 十位求和确定百位进位 → 4. 个位求和结合进位判断最终范围 |
| 高频错因 | 逐个数完整相加效率低；忘记进位导致范围判断错误 |
| confidence | high |

补充说明：例如求178、320、760、523、596之和：百位=1+3+7+5+5=21（即2100），十位=7+2+6+2+9=26（进位后260），个位不需要精确算——百位已确定在2000~2200之间，再结合十位可锁定范围。

## 不适用条件

- 数据超过8个时，按位求和的工作量可能不如直接加总
- 数值位数不统一（混杂两位数和四位数）时，拆分规则需要额外对齐处理
- 题目要求精确求和值而非范围判断

## 反向触发

- 当百位求和后仍无法区分选项时，应继续精确到十位甚至个位
- 选项范围间隔极小（百位相同、仅个位差异）时，按位拆分精度不够，应直接求和
- 题目实际是求平均值而非总和时，应先精确算出总和再除以个数
