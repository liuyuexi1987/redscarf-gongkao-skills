## 核心判断

历史人文题的核心是"时间线+对应关系"。大部分错误来自两个方面：①时间顺序搞反（如把唐朝事件放到宋朝）；②对应关系搞错（如把A的作品说成B的）。建立清晰的时间线框架和对应表是关键。

## 使用流程

1. **识别考查类型**：
   - 朝代顺序：哪个在前哪个在后
   - 人物作品：谁写了什么、谁做了什么
   - 制度演变：某制度属于哪个朝代
   - 成语典故：某成语出自哪里、什么故事

2. **时间线定位**：按下方速记规则确定大致时间范围

3. **对应检查**：人物/作品/事件/制度是否匹配

4. **排除**：时间错配或对应错误的选项直接排除

## 速记/排除规则

### 中国朝代顺序速记

三皇五帝始，尧舜禹相传
夏商与西周，东周分两段
春秋和战国，一统秦两汉
三分魏蜀吴，两晋前后延
南北朝并立，隋唐五代传
宋元明清后，皇朝至此完

关键节点：
- 禅让制→世袭制：夏朝（禹传启）
- 奴隶→封建：春秋战国之交
- 第一次大一统：秦朝
- 科举制创立：隋朝；科举制完善：唐朝

### 重要制度与朝代对应速记

| 制度 | 朝代 | 要点 |
|------|------|------|
| 禅让制 | 尧舜禹时期 | 贤能传位，非世袭 |
| 分封制 | 西周 | "封建亲戚，以藩屏周" |
| 郡县制 | 秦朝 | 中央集权，废分封 |
| 科举制 | 隋朝创立，唐朝完善 | 隋炀帝设进士科 |
| 三省六部 | 隋唐 | 中书省（决策）→门下省（审议）→尚书省（执行） |
| 行省制 | 元朝 | 地方行政制度 |
| 内阁制 | 明朝 | 废丞相后设内阁 |
| 军机处 | 清朝 | 雍正设立，标志君主专制顶峰 |

### 文学作品与人物对应速记

- **四书**：《大学》《中庸》《论语》《孟子》——速记"中学论子"
- **五经**：《诗》《书》《礼》《易》《春秋》
- **四大名著**：《红楼梦》（曹雪芹/清）、《西游记》（吴承恩/明）、《水浒传》（施耐庵/明）、《三国演义》（罗贯中/明）
- **史记**：司马迁/西汉，被鲁迅称为"史家之绝唱，无韵之离骚"
- 易混：《红楼梦》又名《石头记》，是清代作品；其他三大名著都是明代作品

### 成语与出处对应速记

| 成语 | 出处 | 人物/故事 |
|------|------|-----------|
| 破釜沉舟 | 《史记·项羽本纪》 | 项羽 |
| 鸿鹄之志 | 《史记·陈涉世家》 | 陈胜 |
| 运筹帷幄 | 《史记·高祖本纪》 | 张良 |
| 纸上谈兵 | 《史记·廉颇蔺相如列传》 | 赵括 |
| 韦编三绝 | 孔子读《易》 | 孔子 |
| 卧薪尝胆 | 勾践 | 越王勾践 |

易混：运筹帷幄出自《高祖本纪》不是《平原君列传》——注意区分《史记》中的不同篇章

### 世界史关键节点速记

- **文艺复兴**：14-16世纪，意大利开始
- **工业革命**：18世纪60年代，英国开始
- **法国大革命**：1789年
- **美国独立**：1776年《独立宣言》
- **两次世界大战**：一战1914-1918，二战1939-1945
- 易混：文艺复兴≠启蒙运动——文艺复兴（14-16世纪）是文化运动，启蒙运动（17-18世纪）是思想运动

## 高频易混点

| 易混点 | 正确区分 | 常见误判 |
|--------|----------|----------|
| 科举制创立 vs 完善 | 隋朝创立（隋炀帝设进士科），唐朝完善 | 把创立归到唐朝 |
| 分封制 vs 郡县制 | 分封=西周（地方分权），郡县=秦朝（中央集权） | 混淆两者朝代和性质 |
| 四书 vs 五经 | 四书=《大学》《中庸》《论语》《孟子》；五经=《诗》《书》《礼》《易》《春秋》 | 交叉混淆 |
| 文艺复兴 vs 启蒙运动 | 文艺复兴=14-16世纪/文化；启蒙运动=17-18世纪/思想 | 混淆时间和性质 |
| 运筹帷幄出处 | 《史记·高祖本纪》 | 误以为出自《平原君列传》 |
| 内阁 vs 军机处 | 内阁=明朝；军机处=清朝（雍正） | 搞反朝代 |

## 使用边界

1. 本卡不是历史百科全书，只覆盖常识判断高频考点和易混点。
2. 历史事件的具体年份可能有不同说法（如某些事件的精确年份有争议），需提醒"以权威历史教材为准"。
3. 人物与作品的对应关系有时存在争议（如某些作品的作者有争议），需结合题目语境判断。
4. 无法确认某个历史细节时，只能说"方法倾向/需核验"，不能硬判。
5. 速记口诀和朝代歌仅辅助记忆，不能替代对历史事件的准确理解。
