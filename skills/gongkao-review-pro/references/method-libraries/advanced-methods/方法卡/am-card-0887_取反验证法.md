# 方法卡：取反验证法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 取反验证法 |
| 适用题型 | 判断推理——加强削弱·前提/假设题 |
| 触发场景 | 题目问"前提""假设"，选项之间区分度不够明显 |
| 步骤逻辑 | ① 将选项取反（说"不是"）；② 代入原论证；③ 若取反后论点不成立→该选项是必要前提；④ 若取反后论点仍成立→非必要前提 |
| 高频错因 | ① 混淆"支持项"和"前提"（支持项取反后论点仍可成立）；② 取反时方向搞反 |
| confidence | high |

## 不适用条件

- 非前提/假设类题目（如"最能削弱""最能加强"）
- 选项区分度很高、能直接判断哪个是前提的情况

## 反向触发

- 题目问"最能削弱"或"最能加强"（用加强削弱三步法）
- 选项之间差异明显，无需逐一取反验证

## 补充说明

前提是"无它不行"的必要条件。搭桥型前提和必要性前提本质上都是必要条件，只是搭桥有明显断点更容易识别，必要性前提更隐蔽。
