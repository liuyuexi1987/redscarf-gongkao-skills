# 方法卡：加法关系识别混合增长率

## 基本信息

| 字段 | 值 |
|---|---|
| 方法名 | 加法关系识别混合增长率 |
| 适用题型 | 资料分析-总体由部分相加构成时的增速判断 |
| 触发场景 | 数据呈"总体=部分1+部分2"的加法关系（如1-6月=1-3月+4-6月、存款=本币+外币），需要判断总体或某部分的增速范围 |
| 步骤逻辑 | 1. 列出加法关系式，明确哪是总体、哪是部分 2. 识别加法关系即为混合关系：总体的增率一定介于两部分增率之间 3. 画线段辅助判断：两端写两部分增率，中间为总体增率 4. 已知总体和一部分增率 → 另一部分增率在总体的另一侧 5. 若需精确区分，验证线段距离比与基期量比成反比（增率场景）或与现期量比成反比（非增率场景） |
| 验证动作 | 线段距离比验证：在线段上标记各增率位置，两段距离之比应与对应部分的量（增率场景用基期量，非增率场景用现期量）成反比；若不符则判断有误 |
| 不适用条件 | 1. 非加法关系（如乘积关系、除法/比值关系）不适用 2. 同比增率与环比增率不可混用 3. 增率场景必须用基期量做距离比验证，非增率场景（如占比、人均收入）用现期量，混用会导致判断错误 |
| 高频错因 | 1. 不列关系式直接找数据，判断错哪部分对应哪段 2. 误以为总体增率等于两部分增率的简单平均（仅当两部分基期量相等时成立） 3. 把同比增率当环比混用 4. 忘记"总体增率一定在两部分之间"的基本约束，得出越界结论 |
| confidence | high |
| 反向触发 | 1. 线段距离比验证与已知基期量/现期量比不一致时，应回查加法关系是否正确、数据对应是否搞反，或是否误将非加法关系当加法处理 2. 当两部分增率非常接近时，线段法区分度低，总体增率的实际位置难以肉眼判断，应改用精算公式（基期量加权）确认精确值 3. 题目给出的是现期量而非基期量时，需先还原基期量再做距离比验证，不能直接用现期量代入增率场景的反比关系 |
