# 方法卡：四圈支持与三圈质疑

| 字段 | 内容 |
|------|------|
| 方法名 | 四圈支持与三圈质疑 |
| 适用题型 | 逻辑判断——加强/削弱题（因果实验类） |
| 触发场景 | 题干建立因果联系（A导致B），选项通过对比实验支持或质疑 |
| 步骤逻辑 | 四圈支持（一因一果）： |
| | 1. 题干已建立A→B的因果联系（逻辑链条完整） |
| | 2. 正确选项补"非A→非B"（对比实验，反面验证） |
| | 3. 本质是控制变量法：A与非A对照，观察结果差异 |
| | 三圈质疑（同因异果 / 异因同果）： |
| | 1. 同因异果：同一原因A，一个场景导致B，另一个场景未导致B→质疑因果 |
| | 2. 异因同果：不同原因A和B，都导致相同结果C→质疑唯一因果 |
| | 3. 注意：三圈质疑严谨度较低，有ABD可选时一般不优先选三圈 |
| 高频错因 | ①在逻辑链条断开时误用四圈支持（需先搭桥再补四圈）②不区分四圈（支持）和三圈（质疑）的方向性 |
| confidence | high |

**补充说明：**
- 四圈=加强，三圈=质疑，两者方向相反。
- 四圈支持要求题干逻辑链条已完整（如已做对比实验发现A→B），选项补反面证据即可。
- 三圈质疑力度较弱，因为：①异因同果中，A和B可能各自都能导致结果C（如饿肚子和吃撑都对身体不好）②可能存在未控制的第三变量。
- 三圈质疑可选情况：无其他更好选项时。

## 不适用条件

- 题干未建立因果联系（如纯相关性论证或形式逻辑），四圈/三圈框架不适用。
- 题干逻辑链条不完整（缺少搭桥）时，直接用四圈补反面证据无效，需先搭桥。
- 题目涉及的是前提假设题而非加强/削弱题时，四圈/三圈不适用。

## 反向触发

- 当存在因果倒置选项时，因果倒置力度通常强于四圈支持或三圈质疑，优先选之。
- 当四圈支持的对比实验选项中，"非A→非B"表述不严谨或存在混杂变量时，检查是否为伪四圈。
- 当三圈质疑是唯一削弱选项时可选，但若有否定此因+另有他因选项，后者力度更强，优先选之。
