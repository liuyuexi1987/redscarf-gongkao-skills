# 方法卡：类比推理属性题判断

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 类比推理属性题判断 |
| 适用题型 | 判断推理——类比推理（属性关系） |
| 触发场景 | 类比推理题中涉及属性/特征关系 |
| 步骤逻辑 | ① 属性一般是形容词或名词（如"红色""圆形""坚硬"）；② 动词一般不算属性（如"跑步""飞翔"是行为不是属性）；③ 属性题和功能题容易混淆：属性=是什么样的，功能=能做什么 |
| 高频错因 | ① 把行为/功能当属性→关系判断错误；② 属性和功能分不清→选错对应关系 |
| confidence | high |

## 补充说明
属性关系的核心判断标准：形容词/名词→属性，动词→行为/功能。如"苹果：红色"是属性关系，"苹果：吃"是功能关系。

## 不适用条件
- 题目考查的是因果关系、组成关系或其他非属性关系时
- 选项中的关系都是功能/行为关系、无需区分属性时
- 动词和形容词界限模糊（如"发光""振动"）时需结合语境判断

## 反向触发
- 题目关系明确是功能（能做什么）而非属性（是什么样的）时，不应套用属性判断法
- 所有选项都是同类关系（全属性或全功能）时，此法无法帮助筛选
