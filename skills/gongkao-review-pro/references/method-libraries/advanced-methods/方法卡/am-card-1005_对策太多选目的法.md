# 方法卡：对策太多选目的法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 对策太多选目的法 |
| 适用题型 | 言语理解——中心理解 |
| 触发场景 | 文段后面出现一大堆具体对策/措施，无法全部概括 |
| 步骤逻辑 | ① 后面有一大堆对策→不可能全部浓缩成一个短选项；② 往前看这些对策的共同目的/要解决的问题；③ 用目的/大对策作为主旨，而非具体小对策；④ 例：保护、传承、弘扬、创新→主旨=黄河文化的保护传承弘扬创新（大对策），而非"讲好黄河故事"（小对策之一） |
| 高频错因 | ① 试图把所有对策概括→做不到→纠结；② 选了其中一个小对策→以偏概全 |
| confidence | high |

## 补充说明
对策过多时，选项不会要求概括所有对策，而是选对策的共同目的。多个具体对策往往指向一个上位目的，应选目的而非具体对策之一。

## 不适用条件
- 文段只有单一对策（无"太多"问题，该对策即为主要选项）
- 文段主旨本身就是具体对策而非目的

## 反向触发
- 选项中无"目的"类表述→改用对策概括法
- 目的表述也不止一个→改用以偏概全判断法排除小对策
