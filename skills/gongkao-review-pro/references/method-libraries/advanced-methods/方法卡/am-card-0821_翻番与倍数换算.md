# 方法卡：翻番与倍数换算

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 翻番与倍数换算 |
| 适用题型 | 资料分析/数量关系——涉及"翻番""增长X倍"的表述换算 |
| 触发场景 | 题目出现"翻一番""翻两番""增长1.05倍"等需要换算成百分数或倍数的表述 |
| 步骤逻辑 | ① 翻番=×2：翻N番=2的N次方；② 增长X倍=X×100%（1倍=100%）；③ 倍数=1+增长率（如增长1.05倍=105%的增长率）；④ 比值倍数=1+比值增长率 |
| 高频错因 | 把"增长1倍"当成1%（实际是100%）；混淆"是几倍"和"增长几倍"（是2倍=增长1倍）；翻番搞不清是×2还是+2 |
| confidence | medium |
| 不适用条件 | 题目不涉及翻番或倍数表述，直接给百分比或小数增长率；数量关系题中翻番仅作为文字描述而非计算目标 |
| 反向触发 | 题目直接给出增长率百分数，无需换算；考查的是年均增长率或复合增长率的求解，而非翻番/倍数的语义转换 |

## 补充说明

"倍"是一个单位，1倍=100%，就像1公斤=2斤。增长1.5倍=150%=原来的2.5倍。考场上常见坑："是X倍"vs"增长X倍"——是2倍=增长1倍=增长100%。比值倍数（如人均接入流量是12年的多少倍）=1+比值增长率，先算比值增长率再加1即可。
