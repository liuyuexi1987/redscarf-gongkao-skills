# 方法卡：常识判断总纲与答题边界

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 常识判断总纲与答题边界 |
| 适用题型 | 常识判断——所有子领域通用 |
| 触发场景 | 用户做常识题讲解/复盘，需要先识别领域、判断能否硬判、选择排除策略时 |
| 步骤逻辑 | ① 识别题目所属领域；② 判断题型是知识题/排除题/时政题；③ 确定是否有明确知识依据；④ 无依据时标注"需核验"，不硬判 |
| 高频错因 | 领域识别错误、用生活经验替代专业知识、不确定时硬选、时政题用过期信息 |
| confidence | high |
| 不适用条件 | 资料分析、数量关系、言语理解和判断推理等非常识模块；需要核对最新政策、法律修订、机构调整或实时数据但当前无法联网核验的题目 |
| 反向触发 | 识别出法律、经济、科技、历史、地理等具体领域且有对应领域卡时，转读领域卡；涉及易变时政或最新规定时，先核验当前权威信息；缺少可靠知识依据时，只给排除过程和待核验提示，不硬判答案 |

## 核心判断

常识判断不是百科全书背诵题，而是"已知信息下的快速判断"。核心原则：**有依据才判，没依据就排除，绝对不编**。

## 使用流程

### 第一步：领域识别

看到常识题后，先判断属于哪个子领域：

| 领域关键词 | 归属领域 |
|-----------|---------|
| 宪法、国家机构、公民权利、立法程序 | 法律-宪法 |
| 合同、物权、侵权、婚姻、继承 | 法律-民法 |
| 犯罪、刑罚、正当防卫、紧急避险 | 法律-刑法 |
| 行政许可、行政处罚、行政复议、行政诉讼 | 法律-行政法 |
| 马哲、毛思想、中特、党史、国家制度 | 政治理论 |
| 最新会议、最新政策、年度热点 | 时政 |
| GDP、CPI、财政、货币、市场机制 | 经济 |
| 物理化学生物现象、航天、医学、环保 | 科技生活 |
| 朝代、人物、作品、战役、制度演变 | 历史人文 |
| 地形、气候、河流、资源、区域特征 | 地理国情 |
| 公文格式、行文规则、管理学原理 | 公文管理 |

### 第二步：题型判断

| 题型 | 特征 | 答题策略 |
|------|------|---------|
| 知识题 | 直接考查某个事实/概念/规定 | 有可靠依据时据此判断；依据不足时说明待核验，不把猜测写成结论 |
| 排除题 | "下列说法错误/不正确的是" | 逐项排除确定错的，不确定项不硬判 |
| 时政题 | 涉及最新会议/政策/数据 | 提醒"需以最新官方信息为准"，不编造 |

### 第三步：判断边界

**可以明确判断的情况：**
- 知识点在方法库中有明确覆盖
- 属于稳定的基础知识（如宪法根本制度、行政区划数量）
- 属于客观可验证的科学事实

**不能硬判的情况：**
- 涉及最新法律修订、机构调整、政策变化
- 知识点模糊、记忆不确定
- 选项之间差异细微且涉及专业边界
- 涉及具体年份、数据、排名等易变信息

**处理方式：** 不能硬判时，用排除法缩小范围，标注"此选项倾向排除/保留，需核验"，给出方法倾向但不宣称正确答案。

## 速记/排除规则

- 先用确定知识排除与事实、主体、时间或权限明显冲突的选项
- 绝对化和缓和词只是核查信号，不能据此判断正误
- 无法确认事实时保留候选并标注待核验，不编造知识点补齐理由

## 高频易混点

| 易混点 | 正确区分 | 常见误判 |
|--------|---------|---------|
| 根本制度 vs 根本政治制度 | 根本制度=社会主义制度；根本政治制度=人民代表大会制度 | 混为一谈 |
| 国体 vs 政体 | 国体=人民民主专政；政体=人民代表大会制度 | 把国体答成人大制度 |
| 法律题 vs 政治题 | 法律题看条文规定；政治理论看理论表述 | 用生活常识答法律题 |
| 稳定知识 vs 时政热点 | 稳定知识可直接判断；时政需标"需核验" | 用过期时政信息硬选 |
| 知识缺失 vs 排除可行 | 知识缺失≠无法答题，排除法仍可缩小范围 | 不知道就放弃整题 |

## 写回/复盘标签

- 常识-总纲-领域识别错误
- 常识-总纲-不确定硬选
- 常识-总纲-时政信息过期
- 常识-总纲-生活经验误判
- 常识-总纲-绝对化误选

## 使用边界

1. 本卡不是事实百科库，不能替代最新官方信息核验。
2. 时政、法律修订、机构调整等可能变化的内容，必须提醒以最新权威来源为准。
3. 无法确认事实时，只能说"方法倾向/需核验"，不能硬判正确答案。
4. 常识速记只作辅助排除，不得编造知识点。
5. 本卡是常识判断的总入口，识别领域后应转读对应领域卡。
