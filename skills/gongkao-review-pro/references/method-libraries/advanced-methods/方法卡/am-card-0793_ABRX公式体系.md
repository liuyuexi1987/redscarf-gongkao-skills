# 方法卡：ABRX公式体系

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | ABRX公式体系 |
| 适用题型 | 资料分析——现期/基期/增长量/增长率四量互求 |
| 触发场景 | 题目涉及增长相关计算，需要在基期A、现期B、增长率R、增长量X之间转换 |
| 步骤逻辑 | ① 记忆字母含义：A=基期，B=现期（本期），R=增长率，X=增长量；② 核心公式：B=A(1+R)，A=B/(1+R)，R=X/A，X=AR；③ 已知增长情况求基期：A=X/R；④ 考场上直接套公式变形，不要现场推导 |
| 高频错因 | 记混A和B对应基期还是现期；R=X/A不熟练导致考场上反复变形浪费时间；已知X和R求基期时误以为求的是现期 |
| confidence | medium |
| 不适用条件 | 1. 题目涉及比重问题（部分/整体）而非增长问题——应使用比重公式体系
| 反向触发 | 1. 题目给出比重数据而非增长数据——应切换到比重相关公式
2. 题目涉及两个增长率的混合——需用混合增长率或盐水法
3. 题目要求判断增量大小而非求精确值——可用分段法或截位直除快速判断 |
2. 题目涉及间隔增长率或年均增长率——需要专门的跨期/年均公式
3. 题目考查的是读数比较而非计算——直接读材料数据即可 |

## 补充说明

A/B取自"基期"和"本期"首字母，R是行业通用增长率符号，X来自方程设未知数的习惯。R=X/A是资料分析中用得最多的公式，必须滚瓜烂熟。此体系是后续ABRX专题课和假设分配的基础框架。
