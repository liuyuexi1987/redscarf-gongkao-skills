# 方法卡：匀变速运动速度增量正比法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 匀变速运动速度增量正比法 |
| 适用题型 | 行程问题·匀加速 |
| 触发场景 | 已知初速度、某段时间内的路程，求加速到某速度需要的时间 |
| 步骤逻辑 | 1. 先算平均速度 = 路程 ÷ 时间；2. 平均速度 = (初速度+末速度)/2 → 反推出末速度；3. 速度增量 = 末速度 - 初速度；4. 速度增量与时间成正比（匀加速的定义）；5. 例：初速60km/h，50秒走了1km → 平均速度72km/h → 末速84km/h → 50秒增加24 → 加速到120需增加60 → 60/24×50=125秒 |
| 高频错因 | 单位不统一（km/h和秒需要转换） |
| confidence | high |

## 补充说明

不需要用公式S=V₀T+½at²，直接用平均速度和正比关系更快

## 不适用条件

- 非匀加速（加速度变化或存在减速段）的运动。
- 初速度为零且只给出加速度的纯公式题（直接用运动学公式更直接）。
- 涉及多段加速度不同的运动（需分段处理）。

## 反向触发

- 加速度未知且无法通过路程反推时，应换用运动学公式组联立求解。
- 题目要求加速度本身或运动学公式推导时，直接套用公式更稳妥。
- 单位混合且无法统一时（如不同单位制混用），需先做单位换算再代入。
