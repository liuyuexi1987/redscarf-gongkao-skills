# 方法卡：1.5倍敏感度训练

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 1.5倍敏感度训练 |
| 适用题型 | 数量关系——数字推理（等比数列） |
| 触发场景 | 数字推理中数字间有1.5倍关系但不容易看出 |
| 步骤逻辑 | ① 对1.5倍关系要特别敏感（3→4.5→6.75...）；② 1.5倍是近年考试常见的等比公比；③ 做商时优先考虑1.5倍（3/2）；④ 1.5倍常数=42（年均增长率法中） |
| 高频错因 | ① 1.5倍不容易心算→忽略这个规律；② 只关注整数倍（2倍/3倍）→漏掉1.5倍 |
| confidence | high |
| 不适用条件 | ['数字间的倍数关系明显偏离1.5倍（如2倍或3倍）', '题目考查的是和差关系或递推关系，非等比', '数列数字较大，做商后无法快速判断是否接近1.5'] |
| 反向触发 | ['数字做商后接近2倍或3倍，不走1.5倍路径', '数列规律是加减关系或前两项递推，非等比数列'] |

## 补充说明
1.5倍是近年数字推理的高频公比。需要专门训练对1.5倍的敏感度：3×1.5=4.5、4×1.5=6、5×1.5=7.5、6×1.5=9、8×1.5=12。
