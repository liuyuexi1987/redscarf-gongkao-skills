# 方法卡：平均数偏差法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 平均数偏差法（比盐水法更直观） |
| 适用题型 | 数量关系/资料分析——多次平均数相关问题 |
| 触发场景 | 题目给出分组平均数（如前几次平均、后几次平均）与总平均数的关系，求某一组的值 |
| 步骤逻辑 | ① 以总平均数为基准线；② 计算一组的偏差总量：偏差×次数（如"前三次比总平均高2分"→总偏差+6）；③ 另一组偏差总量与之相反：后两次总偏差-6→每次-3；④ 两组的平均数之差 = |偏差A| + |偏差B|（一个高一个低，差值相加） |
| 高频错因 | 用盐水混合公式（交叉相乘）导致计算复杂；忘记将偏差乘以次数得到总偏差 |
| confidence | high |

## 不适用条件

1. 各组次数未知且无法从条件中确定，偏差总量无法计算
2. 题目涉及加权平均且权重不等，偏差抵消关系不成立
3. 求的是单次具体数值而非分组平均数（如"第几次得分最高"）

## 反向触发

1. 题干只给了总平均数和其中一个组的平均数，没有另一组的任何约束
2. 题目是增长率混合/浓度混合，有专门的十字交叉法或线段法适用
3. 各组数据为乘积关系（如单价×数量）而非简单求平均

## 补充说明

此方法比盐水法更直观：将平均数偏差理解为"高出的部分"和"低出的部分"必须相互抵消。强化方法提到"这比盐水其实还要更好"，因为避免了交叉相乘的复杂性。
