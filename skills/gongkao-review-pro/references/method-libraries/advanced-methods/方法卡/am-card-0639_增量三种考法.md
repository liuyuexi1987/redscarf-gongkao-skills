# 方法卡：增量三种考法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 增量三种考法 |
| 适用题型 | 资料分析——求增长量的各种变形 |
| 触发场景 | 题目问增长量、变化量、同比增量等 |
| 步骤逻辑 | ① 一般增量：直接用四幺五或假设分配求X；② 增量比值/倍数：分别求两个增量再做除法（容错空间大，可大胆估算）；③ 各部分增量相加=总增量：已知部分增量求另一部分 |
| 高频错因 | 增量比值题忘记添零（量级错误）；各部分增量相加时符号搞反 |
| confidence | medium |
| 不适用条件 | 增长率无法近似为简单分数、需要精确计算单个增量时；增量比值题中两个增长率均为负且选项含符号陷阱时；各部分增量存在符号相反的混合增长时 |
| 反向触发 | 题目问增长量、同比增量、变化量时，优先梳理属于三种考法中的哪一种，再选对应子方法 |

## 补充说明

增量倍数/比值题容错空间很大（如150斤的2倍是300斤，3倍是450斤，差距巨大），可大胆估算。各部分增量相加=总增量，只含一个未知数时可直接求解。方法统一用四幺五和假设分配。
