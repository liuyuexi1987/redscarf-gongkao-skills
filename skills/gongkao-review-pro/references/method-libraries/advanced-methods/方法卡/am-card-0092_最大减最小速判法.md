# 方法卡：最大减最小速判法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 最大减最小速判法 |
| 适用题型 | 资料分析-"差距最大"类题目（已知多个分组数据，求哪组差值最大） |
| 触发场景 | 题目问"以下哪个月份A与B差距最大"，且A、B的大小关系一致（A > B 或 A < B 在所有月份中不变） |
| 步骤逻辑 | 1. 差距 = |A - B|，要最大化差距；2. 如果所有月份都是 A > B（或反之），则差距最大的 = 最大的A - 最小的B；3. 直接找"被减数最大"且"减数最小"的那一组 → 快速判断；4. 如不确定正负，粗略估算即可（如550×30 ≈ 1500，4600-1500 还是正数） |
| 高频错因 | 不敢用此法，逐组计算差值浪费时间未确认 A > B 的前提（若存在正负翻转则不能直接用） |
| confidence | high |

## 不适用条件

1. A 和 B 在不同月份存在大小关系翻转（有时 A>B，有时 A<B），此时不能直接用"最大减最小"
2. 题目要求算出具体的差值大小，而非判断哪组差距最大

## 反向触发

1. 所有分组的差值在同一量级，"最大减最小"无法快速区分
2. 题目问的是差距变化趋势而非最大差距的位置
