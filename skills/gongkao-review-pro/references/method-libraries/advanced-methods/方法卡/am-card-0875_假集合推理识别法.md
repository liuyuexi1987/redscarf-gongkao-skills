# 方法卡：假集合推理识别法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 假集合推理识别法 |
| 适用题型 | 看着像集合推理但含特殊个体的逻辑题 |
| 触发场景 | 题干出现"所有A都是B""有些C是D"等集合语言，但同时给出某个特定的人/物的具体信息（"李明是教授""李明29岁"） |
| 步骤逻辑 | 1. 看到特殊个体（某人是什么/不是什么）→ 这是直言命题，不是集合推理；2. 将"所有A都是B"理解为 A推B（假言命题）；3. 用直言命题去启动假言命题链条，一路推到底；4. 不要画韦恩图，直接用推导 |
| 高频错因 | 误以为是集合推理去画图，浪费时间且画不出来；忽略特殊个体信息 |
| confidence | high |

## 补充说明

方法提示：前面的集合语言可能是烟雾弹，真正的突破口在最后给出的特殊个体直言命题。

## 不适用条件

1. 题干只有集合语言（所有/有些）且无任何特殊个体信息时，此法不适用，应按标准三段论或韦恩图处理。
2. 集合语言中包含"有些"（特称命题）且无直言命题可联动时，推导链条可能断裂，需结合排除法。

## 反向触发

1. 当特殊个体代入后推出矛盾时，说明对集合语言的理解有误，应回头重新检查"所有A都是B"的含义是否被正确转化为A推B。
2. 当题干同时包含多个特殊个体且彼此之间无假言命题连接时，应改为列表逐个匹配，而非单一链条推导。
