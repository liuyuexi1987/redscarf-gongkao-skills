# 方法卡：质疑结论新内容法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 质疑结论新内容法 |
| 适用题型 | 逻辑判断——一般质疑（结论含论据未提及的新内容） |
| 触发场景 | 结论中出现了论据里完全没有涉及的新关键词（如"预防""颠覆""大大改善"等），且该新内容无依据支撑 |
| 步骤逻辑 | ① 定位结论中的新关键词（论据里没有的词）；② 检查论据是否支持这个新内容；③ 如果不支持，针对该新内容进行质疑 |
| 高频错因 | 忽略结论中的新词，只盯着论据和结论的表面逻辑；选了浮于表面的万金油选项（如"仍在进行临床实验"） |
| confidence | medium |

## 补充说明

识别技巧：读题时特别注意结论中有没有论据里没出现过的"突兀"新词，这往往就是出题人的漏洞设置点。常见质疑方向：当结论把"检测能力"夸大为"预防能力"时，质疑检测只能确诊不能预防；当结论把"线性发展"夸大为"颠覆性"时，质疑该技术仍属线性发展未颠覆现有体系。核心是把结论中的新内容与论据实际支持的范围做对照，凡论据未覆盖的新内容均可作为质疑点。

## 不适用条件

- 结论中没有出现论据之外的新关键词时，本方法不适用，应改用常规断点搭桥或加强论据法。
- 结论的新内容已由论据隐含支持、能合理推出时，不构成可质疑的漏洞。

## 反向触发

- 当题干结论的新内容确实有隐含论据支撑时，应换用"识别隐含前提"类方法核验而非直接质疑。
- 当选项中无任何针对新内容的质疑项时，应转向论据本身的有效性核验，避免强行套用本方法。
