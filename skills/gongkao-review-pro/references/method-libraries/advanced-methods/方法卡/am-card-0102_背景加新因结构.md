# 方法卡：背景加新因结构

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 背景加新因结构 |
| 适用题型 | 中心理解题 |
| 触发场景 | 文段出现"基于此/因此/由此"等词，引出"新X"的概念 |
| 步骤逻辑 | 1. 定位"基于此/因此/由此"等概括上文的连接词；2. 连接词之前的全部内容是背景，不需要细读；3. 连接词之后提出的就是"新因"，是主旨所在；4. 如果文段直接告诉了"新X"是什么（如"新金融"），答案必须对应；5. 与下文推断不同：下文推断可以自己组词（新方法/新思想），但主旨题必须严格匹配原文表述 |
| 高频错因 | 自己编造"新X"的表述（如原文说"新金融"，选项选了"新需求"）没有识别"基于此"等概括词，还在纠结前面的背景内容和下文推断题的方法混淆 |
| confidence | high |

## 不适用条件

1. "基于此/因此"等连接词后面跟的是具体对策而非新概念——对策题应走对策抓取逻辑，不套用"新X"匹配。
2. 文段没有"基于此/因此/由此"等概括连接词，而是通过语义转折或递进引出核心内容——不能生套此结构。
3. 连接词后面的内容是对前文观点的反驳或修正（如"然而""但实际上"），不属于"新因"引出。

## 反向触发

1. "新X"出现在文段中间而非连接词之后，可能只是过渡性表述而非主旨核心。
2. 连接词引导的是对前文的举例或具体化（如"例如在此基础上"），并非引出新概念。
3. 选项中没有与"新X"对应的表述，应考虑文段主旨可能不在此结构上。
