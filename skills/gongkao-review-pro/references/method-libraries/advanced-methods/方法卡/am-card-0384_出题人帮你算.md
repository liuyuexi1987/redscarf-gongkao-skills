# 方法卡：出题人帮你算

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 出题人帮你算 |
| 适用题型 | 基期比重、基期差 |
| 触发场景 | 题目求基期比重或基期差，选项中出现现期比重/现期差作为干扰项 |
| 步骤逻辑 | 1. 先算出现期比重（或现期差），不精算，仅确认它对应哪个选项；2. 识别该选项为出题人故意设置的坑（忘记算基期）；3. 判断基期比重相对现期偏大还是偏小，向正确方向微调即可选出 |
| 高频错因 | 未区分"计划"与"实际"，直接用现期数除以现期数；忽略超额完成导致占比>100% |
| confidence | medium |

## 补充说明

此法的核心是"利用出题人设置的干扰项反向定位答案"。求基期比重/基期差时，先算出现期比重/差，找到对应选项——该选项就是出题人故意放的坑（忘记换算到基期）。然后只需判断基期值相对现期偏大还是偏小，向正确方向微调即可。这比从零精算基期比重快得多。

## 不适用条件

- 选项中没有现期比重/现期差作为明显干扰项时，此法失去"定位陷阱"的前提
- 基期与现期差距很小时，若微调不足以区分选项，应改用更直接的计算
- 题目本身是求现期值而非基期值

## 反向触发

- 当算出现期比重后无法确定对应哪个选项（多个选项数值接近），应直接精算
- 当所需微调幅度过大、估算误差可能跨越选项时，应切换为公式精算
- 当题目涉及多个分类维度的嵌套比重时，单纯靠现期定位坑位不够，需逐步精算
