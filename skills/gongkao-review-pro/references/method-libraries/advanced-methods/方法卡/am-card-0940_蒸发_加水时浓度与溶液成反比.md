# 方法卡：蒸发/加水时浓度与溶液成反比

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 蒸发/加水时浓度与溶液成反比 |
| 适用题型 | 只蒸发水或只加水的溶液问题 |
| 触发场景 | 题目出现"蒸发""加水""稀释"等关键词，溶质不变 |
| 步骤逻辑 | 1. 确认溶质不变（只蒸发/加水，不加溶质）；2. 浓度比 = 溶液质量的反比；3. 例如浓度从10%变为12%，浓度比=10:12=5:6，则溶液比=6:5，蒸发了一份水；4. 结合溶液差或溶液和求具体数值 |
| 高频错因 | 搞反正反比关系；忘记"浓度与溶液成反比"的前提是溶质不变 |
| confidence | high |

## 补充说明

若溶剂不变（加溶质），浓度与溶质不成正比，因为加溶质时溶液也变

## 不适用条件

- 加溶质（非纯蒸发/加水）时不适用，此时溶质也变
- 多种溶液混合时不适用

## 反向触发

- 题目同时加溶质又加水时，应改用方程法列守恒等式
- 反复倒出再补满时，应改用"循环倒出+补满"公式
