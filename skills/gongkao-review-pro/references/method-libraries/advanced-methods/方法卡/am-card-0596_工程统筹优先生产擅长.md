# 方法卡：工程统筹——优先生产各自擅长部分

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 工程统筹——优先生产各自擅长部分 |
| 适用题型 | 数量关系（工程统筹） |
| 触发场景 | 两个车间/工人生产不同产品，效率不同，求最多配套产量 |
| 步骤逻辑 | 1. 比较各车间在不同产品上的效率比，判断谁"更擅长"哪个产品；2. 让更擅长某产品的车间专门生产该产品；3. 另一车间先配合配套，剩余时间再自行配套生产；4. 求最多配套数时取极限情况：一方全做一种，另一方用剩余时间配套 |
| 高频错因 | 不比较效率比直接平均分配；忽略"剩余时间还可以配套生产"的优化空间 |
| confidence | medium |

## 不适用条件

- 两车间/工人在两种产品上效率完全相同时不适用此法（无"擅长"之分）。
- 题目未要求"最多配套产量"而要求其他指标（如最短时间、最少成本）时不适用此法。
- 两种产品之间无配套关系（独立产出）时不适用此法。

## 反向触发

- 当两车间效率比接近、难以判断谁更擅长时，应换用"试算两种分配方案取优"法比较结果。
- 当涉及三车间及以上多产品配套时，应换用线性规划或表格分析法统筹求解。
- 当题目含"中途切换产品有切换成本/损失"等约束时，应补充用分段计算核验最优切换点。
