# 方法卡：拆分法（乘法）

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 拆分法（乘法） |
| 适用题型 | 资料分析——一个数乘以百分比（如632×55%） |
| 触发场景 | 乘数可拆成50%+5%、50%-1%、10%+5%等组合时 |
| 步骤逻辑 | ① 关注1%、5%、10%、50%这几个关键节点；② 将乘数拆分成这些节点的加减组合；③ 分别计算后合并（错位相加/减） |
| 高频错因 | 拆分后各部分计算方向搞反（该加的减了）；错位对齐错误 |
| confidence | medium |

## 补充说明

核心技巧：50%=本身的一半，10%=小数点左移一位，1%=小数点左移两位，5%=10%的一半或50%的1/10。拆分后错位相加/减，不用动笔列竖式。可配合误差抵消技巧使用。

## 不适用条件

- 百分比无法拆成少量熟悉比例，拆分后步骤反而更多。
- 题目要求精确值且拆分中包含未经控制的近似。

## 反向触发

- 拆分项超过数个或容易错位时，改用直接乘法或分数换算。
- 估算误差可能跨越选项时，保留精确拆分或回代验证。
