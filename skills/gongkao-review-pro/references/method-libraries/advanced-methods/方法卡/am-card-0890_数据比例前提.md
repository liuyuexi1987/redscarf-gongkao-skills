# 方法卡：数据比例前提

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 数据比例前提 |
| 适用题型 | 判断推理——加强削弱·前提/假设（涉及数据推理） |
| 触发场景 | 论据给出部分群体的数据比例，论点推整体的比例或有效率 |
| 步骤逻辑 | ① 识别论据是"部分群体的率"，论点是"整体的率"；② 前提必须保证另一部分群体的率满足混合后能推出论点的条件；③ 注意"分母不变"是常见隐含前提（如有效率推理中总量不变） |
| 高频错因 | ① 把分子增加等同于率增加（忽略了分母也可能变）；② 用占比推绝对数量（占比不高≠数量不多） |
| confidence | high |

## 不适用条件

- 论据和论点讨论的是同一群体的同一数据（无需从部分推整体）
- 论点不涉及比例或率的推理

## 反向触发

- 论据直接给出整体数据而非部分群体数据
- 题目不涉及"部分→整体"的推理结构

## 补充说明

核心逻辑：从部分率推整体率，必须知道另一部分的率才能做混合判断。"分母不变"是出题人常考的隐含假设。
