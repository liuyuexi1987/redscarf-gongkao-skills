# 方法卡：频率倍数约束法
## 基本信息
| 字段 | 值 |
|------|-----|
| 方法名 | 频率倍数约束法 |
| 适用题型 | 数量关系-频率/概率（抓娃娃等频率问题） |
| 触发场景 | 题干给出初始频率（如1/16），经过若干次操作后频率变化（如变为1/10），求总次数 |
| 步骤逻辑 | 1.频率=成功次数/总次数，分母即为总数的约束 2.最终频率的分母决定新总数是该数的倍数 3.用选项验证：新总数减去变化次数，看差值是否符合初始频率的分母整除关系 4.代入验算：回推成功次数应为整数，且满足前后两个频率 |
| 高频错因 | 不理解频率即分母代表总数；不利用倍数关系排除判断；搞错"变前""变后"对应的分母 |
| confidence | high |
## 补充说明
示例：原频率1/16，再抓2次全中后频率变为1/10。设新总数=x，则原总数=x-2。新频率分母10→新总数是10的倍数；原频率分母16→原总数是16的倍数，即x-2是16的倍数。逐一验证选项：40-2=38（不是16倍数），50-2=48=16×3（是）→选50。验算：原成功次数=48/16=3，原频率3/48=1/16；新频率5/50=1/10，正确。

## 不适用条件
- 频率无法化为简单整数比（如无理数频率），分母不构成有效整除约束
- 多个变量同时变化（如频率和成功次数都未知），倍数筛选条件不足
- 题目不涉及频率变化前后的对比，无"变前变后"的约束结构

## 反向触发
- 看到频率从一个分数变到另一个分数（如1/16变1/10），立刻联想分母即总数的倍数约束
- 选项之间差异可用分母的公倍数解释
- 题目提到"再抓X次全中/全中后频率变为"，说明变化量已知，可反推总数
