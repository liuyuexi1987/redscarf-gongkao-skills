# 方法卡：1月2月合并统计陷阱

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 1月2月合并统计陷阱 |
| 适用题型 | 资料分析-综合判断题（含"几个月""哪个最低/最高"等数月份的表述） |
| 触发场景 | 材料中1月和2月的数据合并展示（通常是1-2月累计值），题目要求判断"有几个月低于X"或"哪个月最低" |
| 步骤逻辑 | 1. 看到材料有"1-2月合并"的数据时，立即警惕；2. 凡是问"某几个月"需要逐月判断的题目，涉及1-2月的选项无法确定；3. 举例：已知1-2月合计进口量8514万吨，问低于4000万吨的有几个月 → 1月可能是7000+2月1514，也可能是4500+4014，无法确定；4. 只要题目要求"数月份个数"且包含1-2月的合并区间 → 该选项大概率是陷阱；5. 其他月份可以正常判断 |
| 高频错因 | 把1-2月合并值当成两个月的平均值来判断，忽略了极端分布的可能；做题时没注意到合并统计，直接逐月比较 |
| confidence | high |

## 不适用条件

- 材料中1月和2月分别给出单独数据时，不涉及合并陷阱
- 题目只要求比较合计值或排名，不需要拆到逐月判断时，合并值可直接使用
- 题目明确说明"按累计值"或"1-2月合计"比较时，合并数据本身就是正确口径

## 反向触发

- 当材料同时给出1月、2月单独数据和1-2月合计值时，可直接用单月数据判断，无需警惕合并陷阱
- 当题目问的是"哪个季度最低"且1-2月合计值与其他单月不可比时，应按季度口径重新整理而非逐月拆分
- 当题目问"低于X的有几个月"且1-2月合计值已明确低于X时，可直接计入两个月，无需讨论分布
