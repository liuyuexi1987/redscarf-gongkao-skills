# 方法卡：不谈剂量质疑

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 不谈剂量质疑 |
| 适用题型 | 判断推理 > 削弱质疑（实验→日常应用类） |
| 触发场景 | 题干用"某提取物/成分对动物有效"推出"日常摄入该食物有好处" |
| 步骤逻辑 | 1. 实验结论 → 日常应用，存在"剂量/浓缩度"的跳跃；2. 关键质疑：只有大剂量/提取浓缩后的有效成分才起效，日常摄入量远远不够；3. 选项中含"只有""提取浓缩后""大剂量"等限定词时高度警惕——可能是正确答案；4. 典型例子：秋葵素对动物有效≠秋葵泡水降血糖；大蒜提取物致癌≠炒菜用大蒜致癌 |
| 高频错因 | 误以为"有效果"就能直接推到日常；没注意剂量差异 |
| confidence | high |

## 补充说明

实验结论到日常应用的跳跃，核心在于"剂量/浓缩度"差异。只有大剂量或提取浓缩后的有效成分才起效，日常摄入量远远不够。典型模式：某提取物对动物有效≠日常摄入该食物有好处；某成分在高浓度下致癌≠日常烹饪使用该食物致癌。遇到选项含"只有""提取浓缩后""大剂量"等限定词时高度警惕，可能是正确答案。

## 不适用条件

- 题干论证不涉及实验→日常应用的跳跃（如直接讨论某药物临床效果），剂量质疑不适用
- 题干已明确说明日常摄入量与实验剂量一致或等效换算时，本法的质疑前提不成立
- 题目要求加强/支持结论而非质疑时，应找"日常剂量已足够有效"的支持项而非质疑项

## 反向触发

- 若选项虽涉及剂量，但说的不是"日常摄入量不够"而是"过量摄入有害"，这属于另一种质疑方向（有害性而非无效性），应结合题干结论的具体内容判断是否匹配
- 若题干本身已有"适量""日常用量"等限定词来弥合剂量跳跃，说明出题者已意识到该问题，应寻找其他质疑方向（如因果倒置、样本偏差等）
