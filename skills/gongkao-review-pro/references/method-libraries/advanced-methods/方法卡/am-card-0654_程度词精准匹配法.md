# 方法卡：程度词精准匹配法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 程度词精准匹配法 |
| 适用题型 | 逻辑判断——一般质疑（结论含"大大""所有""大部分"等程度限定词） |
| 触发场景 | 结论使用了程度限定词（如"大大改善""所有""大部分"），需判断选项是否在程度上有效质疑 |
| 步骤逻辑 | ① 识别结论中的程度限定词；② 判断选项是否在程度上与之精准对应；③ 如选项说"大部分发生X"而结论说"大大改善"，则"大部分"足以质疑"大大" |
| 高频错因 | 忽略程度词的精确含义；认为"大部分"留有余地就不能质疑"大大改善" |
| confidence | medium |

## 补充说明

典型示例：结论称某措施能"大大改善"某问题，选项指出"大部分"该问题发生在该措施作用范围之外。虽选项未说"全部"，但既大部分问题在作用范围外，该措施最多只能解决小部分问题，不足以称为"大大改善"——程度词在量级上能够对得上，构成有效质疑。

## 不适用条件

- 结论不含程度限定词、仅作定性陈述时不适用。
- 选项与结论的程度词不在同一维度（如"频率"对"范围"）时无法直接匹配。
- 题干为纯演绎推理且无程度量化时，改用其他方法。

## 反向触发

- 结论含"如果…那么""只有…才"等绝对化逻辑关联词时，改用"严谨逻辑关系质疑法"找A且非B。
- 论据与结论关键词不一致存在断点时，转用"断点拆桥法"。
- 结论为归纳概括且需质疑样本时，改用"以偏概全/样本质疑"。
