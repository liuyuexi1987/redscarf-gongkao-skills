# 方法卡：整数基本值法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 整数基本值法 |
| 适用题型 | 资料分析——减法计算（尤其三位减三位或四位减三位） |
| 触发场景 | 需要做涉及借位的减法，希望口算完成 |
| 步骤逻辑 | ① 找到两数之间的整百基准值（如632和589之间取600）；② 分别计算：被减数的零头（632-600=32）和减数到基准的差（600-589=11）；③ 两个结果相加：32+11=43 |
| 高频错因 | 基准值选错导致拆分后的两个数不对；零头和差的方向搞反 |
| confidence | medium |

## 补充说明

核心是"口算替代列竖式"。熟练后可直接想：零头+距离基准的差=结果。不涉及借位，适合考场上紧张时使用。

## 不适用条件

- 两数相距较远，选基准后仍需多步拆分。
- 小数位、单位或正负号未统一。

## 反向触发

- 基准不能让两边都变成简单差值时，改用分段减法或竖式。
- 结果为负数时先确定大小方向，再决定差值符号。
