# 方法卡：前观点与论证主旨

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 前观点与论证主旨 |
| 适用题型 | 中心理解题（主旨大意） |
| 触发场景 | 文段开头的句子带有观点性（主观判断），后文是对该观点的论证 |
| 步骤逻辑 | 1. 判断开头是"观点"还是"事实"：观点含主观判断，事实是客观陈述；2. 如果开头是观点，后面分述都在论证它→观点本身就是主旨；3. ABDE都是分述细节，不能选；选能概括观点的选项 |
| 高频错因 | 分不清观点和事实，误把观点当背景引入选了分述中的某个细节，没选观点句 |
| confidence | high |

## 不适用条件

- 开头句子是客观事实陈述，不含主观判断或评价性词语
- 文段为并列结构或递进结构，没有单一的前置观点统领全文
- 后文不是在"论证"前文观点，而是对其进行反驳或转折（如出现"然而""但实际上""事实上"等否定信号）

## 反向触发

- 若开头句子看似观点，但后文出现"然而""但实际上"等转折信号在反驳它，说明该句不是作者认同的主旨，应转用"转折后重点"思路
- 若文段各句之间是并列或递进关系，没有谁在"论证"谁，应换用"全面概括"或"并列归纳"思路
- 若后文对前文做了重大限定或修正（如"但更关键的是"），说明前文观点不是最终主旨，应关注修正后的内容
