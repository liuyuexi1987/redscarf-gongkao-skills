# 方法卡：完美选项识别

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 完美选项识别 |
| 适用题型 | 言语理解——片段阅读（主旨/意图题，尤其对策类） |
| 触发场景 | 选项既包含要解决的问题/目标，又包含对策核心内容，两者都被概括在同一个选项中 |
| 步骤逻辑 | ① 提炼文段中的"对策核心"和"要解决的问题/目标"；② 寻找同时涵盖两者的选项——即"问题+对策"的完美概括；③ 此类选项往往就是正确答案，尤其在对策类文段中 |
| 高频错因 | 只关注对策而忽略选项是否也对应了问题/目标；或只看到问题就选，缺少对策核心 |
| confidence | medium |

## 补充说明

完美选项的结构是：问题/目标 + 对策核心。例如原文说"数字经济时代的劳动保障需要加强法律体系协同"，其中"数字经济时代的劳动保障"是问题/背景，"加强法律体系协同"是对策核心，二者合一即为完美选项。当遇到"一方面...另一方面"的双主语并列结构时，正确选项也需要同时覆盖两个主体。

## 不适用条件

1. 文段无对策性内容（纯现象描述、纯因果分析），完美选项的"问题+对策"结构不适用。
2. 所有选项均为单一维度（只谈问题或只谈对策），无法同时匹配两项时，需改用文段结构分析法。
3. 文段存在多个并列对策且选项各自对应不同对策时，完美选项标准不适用，需判断哪个对策是核心。

## 反向触发

1. 若最优选项只涵盖问题/背景而无对策成分，先检查文段是否有明确对策——若无，则选概括性最强的选项即可。
2. 若"问题+对策"选项的对策部分与原文对策有偏差（偷换概念），应选对策准确但可能缺少问题描述的选项。
