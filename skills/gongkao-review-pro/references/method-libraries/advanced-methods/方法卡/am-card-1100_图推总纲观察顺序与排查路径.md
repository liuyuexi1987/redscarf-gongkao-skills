# 方法卡：图推总纲：观察顺序与排查路径

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 图推总纲：观察顺序与排查路径 |
| 适用题型 | 判断推理——图形推理 |
| 触发场景 | 所有图形推理题的第一步观察 |
| 步骤逻辑 | ① 先整体后局部：扫一眼所有图，感受整体特征（相似度、对称感、封闭感、线条感、独立感）；② 按层级排查：整体变化（移动/旋转/翻转/叠加）→ 数量变化（点/线/面/角/元素个数）→ 属性变化（对称/曲直/开闭/笔画）→ 组合运算（元素加减/换算）→ 空间关系（内外/相邻/包含）；③ 宏观感觉先行：高度相似→考移动旋转翻转叠加；工整对称→考对称轴；封闭感强→考面；线条感强→考线；独立分散→考元素；④ 确定方向后再抠细节验证 |
| 高频错因 | ① 上来就抠细节（数点线面）→丢失宏观信息，陷入偶然成立的"微观解"；② 没有观察顺序→排查跳跃，效率低；③ 被表面复杂性干扰→忽略稳定结构和核心变化 |
| confidence | high |

## 补充说明

**核心原则：图推不是背规律字典，而是先观察。**

拿到图推题的第一动作不是套规律，而是"扫一眼所有图"——用3-5秒做整体感知：
- 这些图像不像？→ 高度相似 → 优先想移动/旋转/翻转/叠加
- 这些图工不工整？→ 对仗工整 → 优先想对称轴
- 有没有明显封闭区域？→ 封闭感强 → 优先数面
- 线头多不多？→ 线条感强 → 优先数线
- 元素散不散？→ 独立分散 → 优先数元素

## 不适用条件

- 定义判断、类比推理、削弱加强等文字题不使用图推观察顺序。
- 用户没有提供图形或选项不可见时，本卡只用于讲观察流程，不用于硬判答案。

## 反向触发

- 按总纲排查路径走完整体→数量→属性→组合→空间仍无规律时，应换用"找相同识不同"或"藏与找"模型补充切入。
- 宏观预判方向与选项结构完全冲突时，应回查是否被偶然微观规律误导，重新从整体特征出发。

**排查路径：**
> 整体先行定方向，数量属性逐层降，组合运算放后头，空间关系最后想。

**为什么不能先抠细节：**
1. 细节里可能出现偶然成立的"微观规律"（如笔画数恰好有规律），容易误导选项判断
2. 钻进细节出不来，丢失整体共性信息
3. 真正的规律往往是整体层面的（移动、对称、数量关系），不需要抠细节就能发现
