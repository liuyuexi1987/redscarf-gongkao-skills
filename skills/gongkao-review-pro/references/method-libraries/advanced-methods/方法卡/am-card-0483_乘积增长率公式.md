# 方法卡：乘积增长率公式

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 乘积增长率公式 |
| 适用题型 | 资料分析-求某部分的增速（该部分=整体×占比） |
| 触发场景 | 已知整体增速(R1)和占比变化(百分点/增速R2)，求该部分实际增速 |
| 步骤逻辑 | 部分 = 整体 × 占比 -> R(部分) = R1 + R2 + R1×R2 -> R2需先由占比变化换算为增速（百分点÷上期占比）-> 三项相加求总增速 |
| 高频错因 | 把占比的百分点变化直接当增速R2用，未除以上期占比；忽略R1×R2交叉项 |
| confidence | high |

## 不适用条件

1. 占比变化直接以增速（而非百分点）给出时，R2可直接使用，无需先做百分点÷上期占比的换算步骤。
2. 题目要求用比重差公式（部分占整体的比重之差）而非部分增速时，应改用比重差公式。
3. 本卡给出的是完整公式，原则上应保留R1×R2；只有明确证明省略误差不影响选项时才可估算。

## 反向触发

1. 当题目只问比重差（几个百分点）而不要求部分增速时，应切换为比重差公式。
2. 若占比变化以增速形式给出且无百分点换算步骤，直接套用R=R1+R2+R1×R2即可，无需额外换算。
3. 估算误差可能跨越选项时改用精算，完整计算R1+R2+R1×R2三项。
