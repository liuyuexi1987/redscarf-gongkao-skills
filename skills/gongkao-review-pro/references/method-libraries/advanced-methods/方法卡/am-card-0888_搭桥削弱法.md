# 方法卡：搭桥削弱法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 搭桥削弱法 |
| 适用题型 | 判断推理——加强削弱·逻辑论证（削弱） |
| 触发场景 | 论据→论点有断点，题目问削弱 |
| 步骤逻辑 | ① 找论据和论点的断点；② 选一个"否定连接"的选项，指出B推不出C；③ 或选一个直接攻击论据→论点推导关系的选项 |
| 高频错因 | ① 选了无关项而非真正攻击逻辑链的选项；② 攻击论据事实本身而非推导过程 |
| confidence | high |

## 补充说明

削弱逻辑论证的优先级：拆桥（断点明确时）> 攻击推导关系 > 攻击论据事实。当逻辑链已比较完整时，用反面论据去反对。

## 不适用条件

- 题目问的是加强/支持而非削弱，应转用搭桥支持法。
- 题干是由果推因的因果型论证，优先考虑他因削弱或因果倒置，而非拆桥。

## 反向触发

- 题目要求削弱，且论据和论点之间存在概念断点。
- 选项中出现否定论据与论点之间推导关系的表述（"即使论据成立，也推不出论点"）。
