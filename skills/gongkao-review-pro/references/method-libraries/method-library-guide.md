# Method Libraries

这里放综合方法库及底层方法分区，供复盘引擎和 skills 调用。

默认入口：[`综合方法库.md`](综合方法库.md)

质量门槛：[`方法质量规则.md`](方法质量规则.md)

方法库路由顺序：

1. 先读题型协议的内联主卡。
2. 未命中再查 AdvancedMethods 题型索引。
3. 资料分析公式读取 DataNotes。
4. GongkaoReview 只作二次校验与综述补充。

| 目录 | 内容 |
|---|---|
| `gongkao-review/` | 公考复盘方法库 |
| `advanced-methods/` | 强化方法库 |
| `data-notes/` | 资料分析专项方法库 |

使用原则：

- 方法 claims 必须来自具体分区，以方法论 + 卡片 id 作为来源锚点支撑。
- 对用户输出“方法依据”摘要 + 卡片 id 作为来源锚点。
- A/B 级方法可作为讲解依据；C 级只作检索线索；D 级不采用。
- 如果多个分区都命中，按题型匹配度、依据质量、流程完整度、当前题适配度动态择优。
- 不能把通用模型推理冒充为方法库方法。
