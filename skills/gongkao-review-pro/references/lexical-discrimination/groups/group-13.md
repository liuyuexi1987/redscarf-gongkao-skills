# 词义辨析补救库 第 13 组

用途: 近义词、成语、实词辨析；不作为方法库依据；不用于自动判题。

## 词组辨析

| 词组 | 辨析要点 |
|---|---|
| 相辅相成 | 侧重两方相互配合、缺一不可，共同构成整体。 |
| 相得益彰 | 侧重两方相互配合使各自优点更显，效果优于单独存在。 |
| 锦上添花 | 侧重在原有美好基础上再添美好，有主次之分，主体本已出色。 |
| 珠联璧合 | 侧重两方面都优秀且结合完美，强调匹配相当。 |
| 互为表里 | 侧重两方面互为内外、相互依存，可用于中性或贬义语境。 |
| 交相辉映 | 侧重光辉互相映照，可用于光影、文化、宏大实物等。 |
| 相映成趣 | 侧重景物、事物之间相互映衬而增添趣味，多用于小巧、具体的景色事物。 |
| 双峰并峙 | 比喻同一领域两个突出的对象并立，各有地位。 |

## 使用边界

- 在复盘、解法或考我流程中自动用于词语辨析补充、同义词对比、搭配提醒。
- 不写作“方法依据”，不冒充方法库方法。
- 如果需要讲解解题流程，仍应调用综合方法库。
