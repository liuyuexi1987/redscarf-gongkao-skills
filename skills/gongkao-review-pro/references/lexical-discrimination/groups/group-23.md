# 词义辨析补救库 第 23 组

用途: 近义词、成语、实词辨析；不作为方法库依据；不用于自动判题。

## 词组辨析

| 词组 | 辨析要点 |
|---|---|
| 休戚与共 | 同甘共苦，无论是福是祸都共同承担，强调关系密切、命运相连。 |
| 同舟共济 | 同坐一条船渡河，比喻在困难情境中同心协力，强调面对共同困难时的协作。 |
| 同心同德 | 思想、信念一致，强调目标与心意的统一，不一定有困难背景。 |
| 和衷共济 | 同心协力、共同克服困难，重在思想一致并协力解决问题；“同舟共济”更突出共同处境下的互助。 |
| 水乳交融 | 像水和奶融合在一起，比喻关系非常融洽或结合紧密，强调深度融合、不可分离。 |
| 相濡以沫 | 泉水干涸，鱼用唾沫相互润湿，比喻在困境中相互支持、扶持，强调共同度难的互助。 |
| 守望相助 | 邻里之间相互警戒、防备盗贼并互相帮助，强调主动的互助关系，多用于社区、邻里语境。 |
| 一衣带水 | 像一条衣带那么宽的水，形容地理位置邻近、仅隔一条水域，多用于国家、地区之间。 |
| 唇齿相依 | 嘴唇和牙齿互相依存，比喻双方关系密切、相互依存，强调不可分离的依存关系。 |
| 以邻为壑 | 拿邻国当排水沟，比喻把灾祸或困难转嫁给别人，含贬义，强调"转嫁"的恶意。 |
| 波诡云谲 | 像云彩和水波那样变幻莫测，形容事态、局势难以捉摸，多用于市场、国际局势。 |
| 风云变幻 | 像风云那样变幻不定，形容局势动荡多变，强调变化的动态，与"风起云涌"近义但侧重"变幻"而非"兴起"。 |
| 纵横捭阖 | 在诸侯国之间游说联合或分化，泛指在国际、政治舞台上运用手段操纵局势，多含中性，强调手段和多方周旋，属于较书面的表达。 |
| 沆瀣一气 | 贬义。比喻臭味相投的人勾结在一起，强调坏人的同流合污，与"同流合污"近义但侧重"本性相投的勾结"。 |
| 同流合污 | 贬义。跟坏人一起做坏事，或随同不良风气行事；“沆瀣一气”更突出坏人之间臭味相投、相互勾结。 |

## 使用边界

- 在复盘、解法或考我流程中自动用于词语辨析补充、同义词对比、搭配提醒。
- 不写作"方法依据"，不冒充方法库方法。
- 如果需要讲解解题流程，仍应调用综合方法库。
