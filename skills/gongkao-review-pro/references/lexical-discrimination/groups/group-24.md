# 词义辨析补救库 第 24 组

用途: 近义词、成语、实词辨析；不作为方法库依据；不用于自动判题。

## 词组辨析

| 词组 | 辨析要点 |
|---|---|
| 因地制宜 | 根据不同地区的具体情况制定相应的办法，强调地域差异，多用于政策、规划、产业等语境。 |
| 量体裁衣 | 比喻根据实际情况办事，强调个体化、个性化的对应，比"因地制宜"更突出"个体"层面。 |
| 对症下药 | 原指针对病症用药，比喻针对具体问题采取相应办法，强调措施与问题相匹配。 |
| 有的放矢 | 对着靶子射箭，比喻说话做事有明确目的性，重在"目的明确"。 |
| 因势利导 | 顺着事物发展的趋势加以引导，强调顺势引导和利用，重在"顺势"与"引导"。 |
| 保驾护航 | 保护、保卫使其顺利推进，多为侧面性、辅助性的保障措施，与"添砖加瓦"近义但更侧重"守卫"。 |
| 穿针引线 | 比喻从中联系、撮合，多用于中介、联络、搭桥的情境，重在"撮合"作用。 |
| 广开言路 | 广泛开辟进言的途径，指给下属或民众提供发表意见的机会和渠道，重在"给渠道"。 |
| 集思广益 | 集中众人的智慧，广泛吸收有益的意见，强调在集体讨论中获取好办法，重在"集体讨论"。 |
| 正本清源 | 从根本上整顿、清理源头，比喻从源头上彻底解决问题，重在"从源头"的彻底性。 |

## 使用边界

- 在复盘、解法或考我流程中自动用于词语辨析补充、同义词对比、搭配提醒。
- 不写作"方法依据"，不冒充方法库方法。
- 如果需要讲解解题流程，仍应调用综合方法库。
