# 词义辨析补救库 第 33 组

用途: 近义词、成语、实词辨析；不作为方法库依据；不用于自动判题。

## 词组辨析

| 词组 | 辨析要点 |
|---|---|
| 顺势而为 | 借助客观形势行事，强调顺应外势做出恰当选择，偏褒义 |
| 大势所趋 | 整体局势发展的必然方向，强调趋势不可逆转 |
| 势在必行 | 由形势决定非做不可，强调行动的必要性 |
| 随波逐流 | 自己没有主见，跟着别人走，含贬义 |
| 因陋就简 | 沿用简陋条件办事；既可表节俭务实，也含降低标准凑合之意 |
| 推波助澜 | 比喻从旁鼓动助长事态，多用于推动坏事物，含贬义 |
| 顺水推舟 | 顺着情势说话办事，趁便成全，偏中性 |
