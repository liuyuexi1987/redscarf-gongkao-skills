# 词义辨析补救库 第 34 组

用途: 近义词、成语、实词辨析；不作为方法库依据；不用于自动判题。

## 词组辨析

| 词组 | 辨析要点 |
|---|---|
| 理所当然 | 从道理上讲应当如此，强调按情理本就该这样，多用于责任义务 |
| 顺理成章 | 合乎逻辑发展自然产生结果，强调因果推演的必然 |
| 天经地义 | 指非常正确、不容置疑的道理，强调绝对正确不可改变 |
| 水到渠成 | 条件成熟后自然成功，强调前置条件的积累过程 |
| 顺其自然 | 不强求不干预，任其自然发展，强调处世态度 |

## 使用边界

- 在复盘、解法或考我流程中自动用于词语辨析补充、同义词对比、搭配提醒。
- 不写作“方法依据”，不冒充方法库方法。
- 如果需要讲解解题流程，仍应调用综合方法库。
