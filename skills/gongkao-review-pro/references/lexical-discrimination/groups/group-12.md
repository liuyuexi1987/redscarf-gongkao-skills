# 词义辨析补救库 第 12 组

用途: 近义词、成语、实词辨析；不作为方法库依据；不用于自动判题。

## 词组辨析

| 词组 | 辨析要点 |
|---|---|
| 走马观花 | 侧重观察过程不深入，强调粗略浏览，常用于参观、游览等场景。 |
| 浮光掠影 | 侧重观察结果不深刻、印象浅，强调看得表面。 |
| 蜻蜓点水 | 侧重做事不深入、浮于表面，常用于调研、执法等工作态度。 |
| 浅尝辄止 | 侧重学习、研究、探索等只做表面、不求深入，强调停止过早。 |
| 囫囵吞枣 | 侧重读书、学习等不加理解地全盘接受，强调缺乏甄别。 |
| 不求甚解 | 侧重读书、学习不肯深入理解，强调理解不深。 |
| 举一反三 | 侧重由一个事理类推到其他事理，强调类推能力。 |
| 融会贯通 | 侧重把各方面知识融合贯穿，达到全面透彻的理解。 |
| 触类旁通 | 侧重掌握一类事物的规律后能类推到相近事物；与“举一反三”相比更强调同类的横向类推。 |

## 使用边界

- 在复盘、解法或考我流程中自动用于词语辨析补充、同义词对比、搭配提醒。
- 不写作“方法依据”，不冒充方法库方法。
- 如果需要讲解解题流程，仍应调用综合方法库。
