# 词义辨析补救库 第 46 组

用途: 近义词、成语、实词辨析；不作为方法库依据；不用于自动判题。

## 词组辨析

| 词组 | 辨析要点 |
|---|---|
| 驾轻就熟 | 比喻对事情熟悉，做起来容易，侧重经验丰富、能力出众。 |
| 轻车熟路 | 比喻对情况熟悉做起来容易，侧重路径熟练、流程顺畅。 |
| 了如指掌 | 形容对事物了解得极其清楚，多用于底细、细节、内情。 |
| 耳熟能详 | 指听得次数多，能详尽复述，侧重听闻频繁。 |
| 如数家珍 | 比喻对事物非常熟悉，能像点数家珍一样逐一陈述，侧重列举清晰。 |
| 烂熟于心 | 形容记忆极其牢固，多用于考点、知识点。 |
| 妇孺皆知 | 形容知晓范围很广，连妇女和儿童都知道，不表示内容本身简单。 |
| 家喻户晓 | 形容传播范围广，每家每户都知道。 |
| 不甚了了 | 指对事物了解很浅，一知半解。 |
| 默默无闻 | 指没有名声、不为人所知，可形容人或事迹；不必然表示主动低调。 |
| 鲜为人知 | 指很少有人知道，侧重客观上的知者少。 |
| 匪夷所思 | 形容事物奇怪或想法离奇，出乎常理，令人难以想象。 |
| 不可思议 | 形容无法想象、难以理解，含有惊讶之意。 |

## 使用边界

- 在复盘、解法或考我流程中自动用于词语辨析补充、同义词对比、搭配提醒。
- 不写作"方法依据"，不冒充方法库方法。
- 如果需要讲解解题流程，仍应调用综合方法库。
