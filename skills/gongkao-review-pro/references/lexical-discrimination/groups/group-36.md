# 词义辨析补救库 第 36 组

用途: 近义词、成语、实词辨析；不作为方法库依据；不用于自动判题。

## 词组辨析

| 词组 | 辨析要点 |
|---|---|
| 尾大不掉 | 属下或分支势力过大，难以指挥调度，含贬义 |
| 各行其是 | 各人按自己认为对的去做，含贬义，强调思想上的分歧 |
| 各自为政 | 各搞各的互不配合，含贬义，强调行动上不协作 |
| 如鱼得水 | 形容遇到投合的人或环境而感到畅快自如 |
| 面面俱到 | 各个方面都照顾到，强调处理周全 |
| 独当一面 | 单独负责一个方面的工作，强调能力胜任 |

## 使用边界

- 在复盘、解法或考我流程中自动用于词语辨析补充、同义词对比、搭配提醒。
- 不写作“方法依据”，不冒充方法库方法。
- 如果需要讲解解题流程，仍应调用综合方法库。
