# 词义辨析补救库 第 27 组

用途: 近义词、成语、实词辨析；不作为方法库依据；不用于自动判题。

## 词组辨析

| 词组 | 辨析要点 |
|---|---|
| 触手可及 | 空间或心理距离近，强调伸手即可触达 |
| 唾手可得 | 极容易取得，强调获取的难度低 |
| 手到擒来 | 做事有把握成功，强调能力足以胜任 |
| 信手拈来 | 多用于写作、说话时引用素材，强调积累丰厚、取用自如 |
| 游刃有余 | 因熟练而显得轻松，强调技巧与经验带来的从容 |
| 束手无策 | 无办法可施，强调完全没有对策 |
| 一筹莫展 | 一点计策也想不出，强调思考后仍无进展 |
| 功亏一篑 | 差最后一步而未完成，强调接近成功却失败 |
| 适得其反 | 结果与预期相反，强调做法导致反向效果 |
| 功败垂成 | 接近成功时失败，强调失败节点的临近 |
| 失之交臂 | 好机会近在眼前却错过，强调错失而非主动放弃 |

## 使用边界

- 在复盘、解法或考我流程中自动用于词语辨析补充、同义词对比、搭配提醒。
- 不写作“方法依据”，不冒充方法库方法。
- 如果需要讲解解题流程，仍应调用综合方法库。
