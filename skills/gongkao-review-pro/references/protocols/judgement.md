# 公考复盘判断推理 Skill

本文件只规定判断推理的题型边界、方法导航和输出结构。意图门禁以 `SKILL.md` 为准；答案来源需要裁决时读 `references/protocols/answer-authority.md`；状态处理读 `references/review-engine/复盘引擎说明.md`。

## 与常识判断的边界

- 题面出现“下列属于/不属于”不自动等于定义判断。若题目考查法律、政治、经济、科技、历史、人文、地理、时政、公文管理等已有常识知识点，应转入 `references/protocols/common-sense.md`。
- 经济政策、货币政策、财政政策、存款准备金率、再贴现率、公开市场操作、财政支出、税收减免等题，属于常识判断·经济常识；不得用定义判断要件拆解卡作为第一依据。
- 只有题干先给出一个新定义或概念边界，再要求判断某个案例是否符合该定义时，才进入定义判断。

## 强制模式确认

每次触发本 skill，回答开头必须先写：

```text
已进入 gongkao-review-judgement · 判断推理模式。
```

## 强制回答协议

- 必须按“输出模板”的 1-8 项顺序回答，不得改成普通聊天段落。
- 用户以“我不懂/分不清/有什么区别/帮我讲讲”等方式主动求助具体考点或方法时，按【解法】讲解，不自动写入待巩固队列；只有用户明确要求记录时才写入。
- 必须先识别对象和关系，再对选项做排除；不得先贴标签后找理由。
- 翻译推理、分析推理和图形规律在信息完整时属于客观可复核题；定义、类比、削弱加强和归纳推断属于易争议题。易争议题没有官方答案时必须读 `references/protocols/answer-authority.md`，只给方法倾向，不写“正确/错误/选对/选错”；用户给出/后补答案或客观题出现冲突时也读取该协议。
- 必须区分”方法依据”和”当前题推理”；没有 `source anchor（card id/文件名）` 时，不得把模型推理说成公考复盘原方法。
- 完整讲解结束后仅在满足写回条件时按 `references/review-engine/复盘引擎说明.md` 写回。

## 方法库使用（讲解/解法的第一动作，必做，不是可选检索）

讲解或解法时，**第一步动作就是定位 AdvancedMethods 高频卡并读取**，不要先读综述、不要等“用户要检索”。

1. **先按下表内联导航直接定位高频卡**：识别子题型后，直接读对应的 `方法卡/am-card-*.md`（相对 `advanced-methods/`，保留 `方法卡/` 前缀，不要拼成裸卡名）。

   | 子题型 | 必读方法卡 |
   |---|---|
   | 定义判断 | `方法卡/am-card-0974_定义判断要件拆解法.md`（多定义题加 `方法卡/am-card-1063_多定义题对比策略.md`） |
   | 类比推理 | `方法卡/am-card-1006_类比词对空预判法.md`、`方法卡/am-card-1004_类比集合关系判断法.md` |
   | 削弱/加强 | `方法卡/am-card-0157_加强削弱三步法与论点先行.md`（最不能削弱加 `方法卡/am-card-0245_最不能削弱找无关项.md`） |
   | 前提假设 | `方法卡/am-card-0007_前提假设三种模式.md` |
   | 翻译推理 | `方法卡/am-card-0661_必要条件翻译法.md`、`方法卡/am-card-0690_等价推出速判法.md` |
   | 分析推理（配对/排列） | `方法卡/am-card-0528_三选二配合限制推出必然入选.md`、`方法卡/am-card-0579_配对条件选人排除.md` |
   | 图形推理 | 先读 `方法卡/am-card-1100_图推总纲观察顺序与排查路径.md`（总纲层），再按图形特征读 1105-1112 特征触发卡（特征触发层），最后读细分实战卡（1121 数量规律分层、1122 局部规律遍历、1123 规整图形、1124 图形间关系、1125 一笔画判定、1126 切点曲直交点、1127 六面体折叠等）、空间类专项卡（1130 截面判定、1131 三视图判定、1132 空间方块定位、1133 立体拼合空间占位）及已有细卡（黑白球、九宫格、开闭、内外图形、立体拼合等）；若题面呈现“复合图 - 已知图 = 缺失图”“去同求异/去异求同”“图形相加相减”等关系，必须经索引读取 `方法卡/am-card-1156_图推元素加减与去同求异法.md`，不得只用“都有线/都有圆”泛泛解释；**上述 1105-1156 等图推细卡一律先经 `按题型索引/判断推理.md` 查到 `方法卡/am-card-xxxx_完整名.md` 再按全名读取，不要凭编号+描述拼裸卡名**；图片不清、缺图、选项不可见时，只讲观察路径，不硬判答案 |

### 图推结论前自检

图推给出结论前，内部依次完成“视觉事实 → 候选规律 → 全部已知图验证 → 选项唯一性验证”，不强制逐项显示该自检。任一步因缺图、图片不清或规律不唯一无法完成时，只给分析方向或标记待核验，不硬写答案。本自检仅用于图推分支。

2. 表里没有对应子题型时，再读 `references/method-libraries/advanced-methods/按题型索引/判断推理.md`，按关键词找 1-3 张候选卡，按其 `方法卡/am-card-*.md` 相对路径读取。
3. 读完高频卡后，再读 `references/method-libraries/gongkao-review/判断推理.md` 作**综述补充**（仅补充，不作为第一入口）。
4. 只要输出“用户答案处理/易错点/错因分析/复盘动作/弱点标签”，非图推题必须先读 `方法卡/am-card-1137_判断推理错因诊断总卡.md`，再按子题型读取对应细卡（保留 `方法卡/` 前缀、按下列全名读取，不要凭编号+描述拼裸名）：定义判断 `方法卡/am-card-1143_定义判断错因诊断卡.md`、类比推理 `方法卡/am-card-1144_类比推理错因诊断卡.md`、翻译推理与分析推理 `方法卡/am-card-1145_翻译推理与分析推理错因诊断卡.md`、削弱加强与前提假设 `方法卡/am-card-1146_削弱加强与前提假设错因诊断卡.md`、归纳推断 `方法卡/am-card-1147_归纳推断错因诊断卡.md`。未读这些错因卡前，只能讲当前题推理，不得把错因归为“要件漏看/关系级别错/论点没抓准/因果倒置”等具体标签。图推仍优先按图推总纲和图推细卡归因。
5. **只有在第 1、2 步都真读过、确无同构卡时**，才可写“方法库无直接同构案例”。方法依据写具体 card id（如 am-card-0974），引用 source anchor，不长贴原文。

## 边界

- 对图形推理，若缺图或 OCR 明显错位，只能讲思路，不能编造图形。
- 图推、空间图形和图形选项不写入可自动复测题库；当场上传原图可正常讲解/复盘，但错题复测改考图推方法工作流。不得把图形转成文字描述后当作原题让用户作答。
- 对文字类判断题，OCR 可作为题面候选；若有截偏/不匹配警告，先用题干关键词、选项和讲解主题交叉核对，大体吻合时可低/中置信使用。
- 没有明确 source anchor（card id/文件名）支撑的内容不能声称来自学习材料。
- 如果方法库没有直接命中的同构 `source anchor（card id/文件名）`，必须明确写”方法库无直接同构案例，以下主要是模型按公考复盘框架做的当前题推理”。
- 不要把时间点、范围、主体、程度差异自动写成“偷换概念”；只有当方法证据能支撑这个错因标签时，才能这样归类。

## 常用问法

- “这道定义判断为什么 A 是偷换？”
- “这个削弱加强题按公考复盘方法先看论点还是选项？”
- “图形推理我缺图，只能帮我复盘可能的观察顺序吗？”

## 输出模板

1. 题型识别：<图形/定义/类比/逻辑/削弱加强/归纳>
2. 答案来源与结论：<官方/已核验答案、客观复核结果或方法倾向>
3. 公考复盘判断流程：<识别对象 -> 抓关系 -> 对选项 -> 排除干扰>
4. 当前题推理：<只基于用户给出的题干/图形描述>
5. 用户答案处理：<易争议题有官方答案时按其判定；无官方答案只写“与方法倾向一致/不一致，本题不判对错”；无用户答案时省略>
6. 方法讲解与速度评估：<为什么用、怎么做、先看什么、何时停 + 预计用时区间、关键步骤数、模型推理风险、是否值得做 + 方法来源 card id/文件名>
7. 易错点 / 复盘动作：<关系错配、条件漏看、图形信息与下次固定动作>
8. 写回回执：<仅满足写回条件且实际写盘并验证文件存在后才写“已落盘”；未写成功就报告失败路径>

无官方/已核验答案的易争议判断题不判用户对错；选项表使用“更贴合/不贴合/无关/力度不足”等描述。
