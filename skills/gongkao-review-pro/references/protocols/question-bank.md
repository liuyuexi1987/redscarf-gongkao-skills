# 题库导入协议

Skill 包不包含用户题库正文。`references/question-banks/templates/总题库.md` 只是一份模板；运行时复制到当前状态根的 `题库/总题库.md` 后再写入。

题库是可选用户数据，用于题库测验、自动判题和复习，不影响方法库和复盘引擎运行。

## 导入边界

用户说“把这页加入题库”“把这张图加入题库”“把这个 PDF 加入题库”“把这个 doc 加入题库”“导入题库”或类似表达时，只做提取/OCR、切题、答案识别、核验标记、结构化保存和导入报告；不讲解、不复盘、不写错因卡。

只把可完整还原为文字或 Markdown 表格的题写入 `题库/总题库.md`；依赖原图的图形推理、空间图形、图形选项和不完整复杂图表只记录跳过原因。

每题必须包含 `batch_id`、`question_id`、`source_user_provided`、`source_type`、`来源声明`、`使用范围`、`状态`、`可自动判题`、`答案核验`、`核对备注`。

默认使用：`状态: 待核对`、`可自动判题: false`、`答案核验: 未核验`。只有题干/选项完整、答案明确、题答数量匹配且无 OCR 疑点时，才允许启用自动判题。

只有 `可自动判题: true` 且 `答案核验: 已核验` 的题能进入“题库测验”。

## 与错题讲解区分

“导入题库”只存档；“看错题页/讲错题/复盘这页”可以讲解和按规则写错因卡，但不能把未核验题自动设置为 `可自动判题: true`。

## 视觉题边界

- 先判断题面能否完整复现为文字或 Markdown 表格。
- 图形推理、空间图形、图形选项和其他必须依赖原图的题不写入题块；当前聊天可见不等于之后可持久复用。
- 资料分析图表只有在数值、标签、图例、年份、单位、题干和选项全部完整核验时才能入库，否则跳过并记录原因。
- 跳过题只记录题型和原因；识别到的答案只能来自原图或已核验答案页，不得使用模型推断答案。

## 每题字段

Every imported question must include:

| 字段 | 默认值 | 说明 |
|---|---|---|
| `batch_id` | — | 导入批次标识 |
| `question_id` | — | 批次内递增编号 |
| `source_user_provided` | `true` | 用户导入固定为 true |
| `source_type` | — | `photo` / `pdf` / `doc` / `manual` |
| `来源声明` | `用户上传` | 来源声明 |
| `使用范围` | `个人复习` | 使用范围 |
| `状态` | `待核对` | 核验状态 |
| `可自动判题` | `false` | 是否允许自动判题 |
| `答案核验` | `未核验` | 答案核验状态 |
| `核对备注` | — | 核验说明 |

## 失败关闭规则

所有导入题从失败关闭默认值开始：`状态: 待核对`、`可自动判题: false`、`答案核验: 未核验`。

只有题干完整、选项完整、答案明确、题答数量匹配且无 OCR 疑点时，才允许设置 `可自动判题: true`。答案缺失、答案不确定、答案仅来自未核验 OCR 或题答数量不匹配时，保持待核对，不自动判题。
