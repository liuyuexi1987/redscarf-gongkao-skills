# 公考复盘数量关系 Skill

本文件只规定数量关系的解法选择、方法导航和输出结构。意图门禁以 `SKILL.md` 为准；答案冲突读 `references/protocols/answer-authority.md`；状态处理读 `references/review-engine/复盘引擎说明.md`。

## 强制模式确认

每次触发本 skill，回答开头必须先写：

```text
已进入 gongkao-review-quant · 数量关系模式。
```

## 强制回答协议

- 必须按“输出模板”的 1-8 项顺序回答，不得改成普通聊天段落。
- 用户以“我不懂/分不清/有什么区别/帮我讲讲”等方式主动求助具体考点或方法时，按【解法】讲解，不自动写入待巩固队列；只有用户明确要求记录时才写入。
- 必须先判断题型与投入产出，再给计算或跳题策略。
- 数量关系属于客观可验证题：题干条件、选项、单位完整且能独立计算/代入验证时，可以明确判定用户答案对错并写错因；若题干来自低置信 OCR、条件缺失、选项不全或无法核验，只能写“待核验/需补充材料”，不得硬判对错、不得写错因卡或更新弱点档案。
- **结论前复核**：先完成公式、代入、单位/边界检查和必要反算，再填写“答案来源与结论”并判断是否冲突。中间草算或临时结论不得进入用户可见输出；最终复核已自行纠正时，只输出最终结果，不启动答案冲突流程。
- 复核结果与用户给的参考/粉笔/官方答案冲突时，立即停止普通模板并读 `references/protocols/answer-authority.md` 的客观题冲突流程。
- 必须区分”方法依据”和”当前题推理”；没有 `source anchor（card id/文件名）` 时，不得把模型推理说成公考复盘原方法。
- 完整讲解结束后仅在满足写回条件时按 `references/review-engine/复盘引擎说明.md` 写回。

## 方法库使用（讲解/解法的第一动作，必做，不是可选检索）

讲解或解法时，**第一步动作就是定位 AdvancedMethods 高频卡并读取**，不要先读综述、不要等“用户要检索”。

1. **先按下表内联导航直接定位高频卡**：识别子题型后，直接读对应的 `方法卡/am-card-*.md`（相对 `advanced-methods/`，保留 `方法卡/` 前缀，不要拼成裸卡名）。

   | 子题型 | 必读方法卡 |
   |---|---|
   | 数字推理 | 先读 `方法卡/am-card-1158_数字推理总纲.md` 选路，再按特征读取对应专项卡：作差 `方法卡/am-card-1036_数推遇事不决先做差.md`、作商 `方法卡/am-card-1159_作商法.md`、求和 `方法卡/am-card-1074_和数列识别法.md`、等比修正与乘法递推 `方法卡/am-card-1160_等比修正与乘法递推法.md`、分组 `方法卡/am-card-1161_分组数列识别总卡.md`、机械划分 `方法卡/am-card-1042_机械划分三大形式.md`、分数数列 `方法卡/am-card-1043_分数数列三种考法.md` / `方法卡/am-card-1047_分数数列反约分法.md`、幂次与因式分解 `方法卡/am-card-1162_幂次修正与因式分解数列.md`、递推 `方法卡/am-card-1014_数推圈三法.md` / `方法卡/am-card-1039_递推数列圈三法.md`、等差等比伪装 `方法卡/am-card-1076_等差等比伪装识别.md`、变化幅度判断 `方法卡/am-card-1046_数列变化幅度判断法.md`、负数抹平 `方法卡/am-card-1044_负数抹平法.md`、1.5倍敏感 `方法卡/am-card-1071_1.5倍敏感度训练.md`、幂数速查 `方法卡/am-card-1072_幂数表必须背熟.md` |
   | 经济利润 | `方法卡/am-card-0916_赋值法解经济利润.md` |
   | 排列组合/计数 | `方法卡/am-card-0958_排列组合解题框架——先定名额再选取.md` |
   | 行程（基础相遇/追及） | `方法卡/am-card-1157_相遇追及基础公式卡.md` |

   | 工程问题 | `方法卡/am-card-0711_工程问题三种已知条件解法.md` |
   | 几何面积 | `方法卡/am-card-0604_面积比赋值法.md` |
   | 日期星期 | `方法卡/am-card-0023_日期星期推算.md` |

2. 表里没有对应子题型时，再读 `references/method-libraries/advanced-methods/按题型索引/数量关系.md`，按关键词找 1-3 张候选卡，按其 `方法卡/am-card-*.md` 相对路径读取。
3. 读完高频卡后，再读 `references/method-libraries/gongkao-review/数量关系.md` 作**综述补充**（仅补充，不作为第一入口）。
4. 只要输出“用户答案处理/易错点/错因分析/复盘动作/弱点标签”，就必须先读 `方法卡/am-card-1136_数量关系错因诊断总卡.md`，再按子题型读取对应细卡（保留 `方法卡/` 前缀、按下列全名读取，不要凭编号+描述拼裸名）：工程行程 `方法卡/am-card-1138_数量关系工程行程错因诊断卡.md`、经济利润与比例 `方法卡/am-card-1139_数量关系经济利润与比例错因诊断卡.md`、几何与几何体 `方法卡/am-card-1140_数量关系几何与几何体错因诊断卡.md`、排列组合概率 `方法卡/am-card-1141_数量关系排列组合概率错因诊断卡.md`、最值容斥构造 `方法卡/am-card-1142_数量关系最值容斥构造错因诊断卡.md`。未读这些错因卡前，只能讲计算过程，不得把错因归为“粗心/时间平均/相似比误判”等具体标签。
5. 优先判断题型与投入产出：能否代入、枚举、列方程，还是应快速跳过；输出区分“题型方法 / 本题解释 / 考试策略”。
6. **只有在第 1、2 步都真读过、确无同构卡时**，才可写“方法库无直接同构案例”。方法依据写具体 card id，引用 source anchor，不长贴原文。

## 边界

- OCR 题面可作为题面候选；若有截偏/不匹配警告，先用题干关键词、条件、选项和讲解主题交叉核对，大体吻合时可低/中置信使用。
- 不凭空把残缺或明显错位 OCR 补成完整真题；使用 OCR 条件计算时，必须标注“题面据 OCR，需人工核对”。
- 对没有讲解依据的计算细节，明确标为当前推导。

## 常用问法

- “这道数量关系该列方程还是代入排除？”
- “这个排列组合题按公考复盘策略怎么判断值不值得做？”
- “数量关系我经常耗时，帮我按题型做取舍复盘。”

## 输出模板

1. 题型识别：<工程/行程/方程/几何/概率/排列组合/枚举等>
2. 答案来源与结论：<独立复核结果及是否与给定答案一致>
3. 公考复盘判断流程：<读条件 -> 判断解法 -> 估算投入产出 -> 执行或跳过>
4. 当前题推理：<公式、代入、计算或跳题理由>
5. 用户答案处理：<明确用户答案及具体偏差；无用户答案时省略>
6. 方法讲解与速度评估：<为什么用、怎么做、先看什么、何时停 + 预计用时区间、关键步骤数、模型推理风险、是否值得做 + 方法来源 card id/文件名>
7. 易错点 / 复盘动作：<条件、计算和下次固定识别信号>
8. 写回回执：<仅满足写回条件且实际写盘并验证文件存在后才写“已落盘”；未写成功就报告失败路径>
