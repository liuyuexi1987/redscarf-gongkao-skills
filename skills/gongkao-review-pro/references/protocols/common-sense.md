# 公考复盘常识判断 Skill

本文件只规定常识判断的领域路由、方法导航和输出结构。意图门禁以 `SKILL.md` 为准；答案来源需要裁决时读 `references/protocols/answer-authority.md`；状态处理读 `references/review-engine/复盘引擎说明.md`。

## 与判断推理的边界

- 常识题常写成“下列属于/不属于/正确的是/错误的是”，这类问法本身不决定题型；先看知识域。
- 若选项考查法律主体、政治表述、经济政策工具、科技事实、历史地理、公文管理等已有公共知识，必须按常识判断处理，不转定义判断。
- 经济政策题尤其要先区分货币政策与财政政策：存款准备金率、再贴现率、公开市场操作属于货币政策；财政支出、税收减免、国债等属于财政政策。

## 常识判断核心原则

1. **先识别领域**：法律/政治/经济/科技/历史人文/地理国情/公文管理/时政
2. **先读总纲卡**：`references/method-libraries/advanced-methods/方法卡/am-card-1148_常识判断总纲与答题边界.md`
3. **再按领域读对应卡**：识别领域后读对应方法卡
4. **没有明确知识依据时，不得硬判答案**
5. **时政/法律修订/最新政策类必须提示核验**
6. **涉及答案来源、后补答案或事实冲突时，读取 `references/protocols/answer-authority.md`**

## 强制模式确认

每次触发本 skill，回答开头必须先写：

```text
已进入 gongkao-review-common-sense · 常识判断模式。
```

## 方法库使用（讲解/解法的第一动作）

讲解或解法时，**第一步动作就是读取常识判断总纲卡和对应领域卡**。提示中同时有用户答案和官方/已核验答案时，错因卡 `references/method-libraries/advanced-methods/方法卡/am-card-1155_常识判断错因诊断卡.md` 与 `references/review-engine/复盘引擎说明.md` 也属于首轮必读。未读取总纲卡与对应领域卡前，不得写“无对应方法卡/通用常识判断”，也不得把常识点当成方法库依据。

1. **必读总纲卡**：`references/method-libraries/advanced-methods/方法卡/am-card-1148_常识判断总纲与答题边界.md`（总纲层）

2. **按领域读对应卡**：

   | 子领域 | 必读方法卡 |
   |---|---|
   | 法律常识 | `references/method-libraries/advanced-methods/方法卡/am-card-1149_法律常识主体权限速记卡.md` |
   | 政治理论/时政 | `references/method-libraries/advanced-methods/方法卡/am-card-1150_政治理论与时政常识边界卡.md` |
   | 经济常识 | `references/method-libraries/advanced-methods/方法卡/am-card-1151_经济常识政策工具速记卡.md` |
   | 科技/生活常识 | `references/method-libraries/advanced-methods/方法卡/am-card-1152_科技生活常识易错速记卡.md` |
   | 历史人文 | `references/method-libraries/advanced-methods/方法卡/am-card-1153_历史人文常识时间线速记卡.md` |
   | 地理国情 | `references/method-libraries/advanced-methods/方法卡/am-card-1154_地理国情常识速记卡.md` |
   | 公文管理/行政管理 | `references/method-libraries/advanced-methods/方法卡/am-card-1163_公文管理常识场景速记卡.md`；涉及主体权限时配合读 am-card-1149，涉及政策表述时配合读 am-card-1150 |

3. **跨领域题**：若题目涉及多个领域，读取涉及的各领域卡

4. **领域快速路由表**（用于首步领域识别和优先检查方向）：

   | 题目信号 | 所属领域 | 优先检查 | 是否必须核验 |
   |----------|---------|---------|------------|
   | 谁制定/批准/任免/监督 | 法律主体权限 | 主体、动作、层级 | 是 |
   | 许可/处罚/强制/复议 | 行政法 | 行为类型、程序、救济 | 是 |
   | 犯罪/侵权/违约/拘留 | 法律责任 | 民事/行政/刑事性质 | 是 |
   | 根本/核心/主线/布局 | 政治理论 | 原文表述、概念层级 | 新提法必须 |
   | 财政/货币/利率/税债 | 经济政策 | 工具主体和作用变量 | 当年政策必须 |
   | CPI/通胀/供需/价格 | 经济运行 | 口径、方向、时间 | 数据必须 |
   | 燃烧/用电/药物/急救 | 科技生活 | 科学机制与适用条件 | 医学安全必须 |
   | 朝代/人物/作品/制度 | 历史人文 | 时间轴和对应关系 | 新发现必须 |
   | 区划/地形/气候/资源 | 地理国情 | 空间尺度、层级、年份 | 区划数据必须 |
   | 请示/报告/函/公告 | 公文管理 | 行文方向、对象、目的 | 规则细节必须 |
   | 最新/今年/通过/施行 | 时政 | 主体、时间、状态、口径 | 是 |

5. **错因诊断**：只要输出"你错在哪里/易错点/复盘动作/弱点标签"，就必须先读 `references/method-libraries/advanced-methods/方法卡/am-card-1155_常识判断错因诊断卡.md`；未读前只能做事实解释，不得归类错因。

6. **兜底**：只有在 1148 + 对应领域卡都已读取且确无覆盖时，才可写"方法库无依据，以下为通用常识判断"。`references/method-libraries/gongkao-review/` 只作综述补充，不作为第一入口。

## 答案权威性

- 稳定事实且题面完整时可独立复核；时政、最新政策和法律修订先标待核验。
- 用户提供/后补答案，或稳定事实复核结果与给定答案冲突时，按 `references/protocols/answer-authority.md` 裁决。
- 完整讲解结束后仅在满足写回条件时按 `references/review-engine/复盘引擎说明.md` 写回。

## 边界

- 对常识题，只有读取 1148 总纲卡和对应领域卡后仍无直接覆盖，才允许写"方法库无依据，以下为通用常识判断"
- 没有明确 source anchor（card id/文件名）支撑的内容不能声称来自学习材料
- 不要把生活经验误判为科学事实
- 时政类题目必须提醒核验最新信息
- 常识速记口诀只作辅助排除，不得编造知识点

## 常用问法

- "这道法律常识题选哪个主体？"
- "这个经济概念怎么区分？"
- "常识判断这道题为什么选A不选B？"
- "这个历史事件的先后顺序是什么？"

## 输出模板

1. 题型识别：<法律/政治/经济/科技/历史人文/地理/时政/综合>
2. 答案来源与结论：<稳定事实复核、官方答案或待核验>
3. 领域判断：<所属子领域>
4. 当前题推理：<逐项事实判断>
5. 用户答案处理：<按 answer-authority 裁决；无用户答案时省略>
6. 方法讲解与速度评估：<为什么用、怎么做、先看什么、何时停 + 预计用时区间、关键步骤数、模型推理风险、是否值得做 + 方法来源 card id/文件名>
7. 易错点 / 复盘动作：<主体、时间、概念和下次固定检查项>
8. 写回回执：<仅满足写回条件且实际写盘并验证文件存在后才写“已落盘”；未写成功就报告失败路径>
