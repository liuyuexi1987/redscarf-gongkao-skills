# 方法工作流题模板（回路 A：方法卡变式出题）

题库为空或不足时，从方法库方法卡的 `高频错因 / 触发场景 / 步骤逻辑` 字段构造**方法工作流题**作为兜底。**不是真题**，不抄原题，只考方法本身。

## 允许的四类题型

1. 公式/方法选择：「这题该用哪个公式/方法？」
2. 触发词识别：「看到什么特征就该想到 X 方法？」
3. 陷阱预判：「这一步最容易错在哪？」
4. 归因：「上次你为什么不能直接相加？」

## fail-closed 约束

- **不生成仿真计算新题**（答案不可靠 + 仿真过近原题有版权风险）。
- 每道题必须显式标注固定三段，不可省略：`非真题 · 方法自测 · 不计真题正确率`
- 结果记入弱点档案「方法掌握度」，不计入真题正确率。

## 输出格式

```text
[非真题 · 方法自测 · 不计真题正确率]
（来源方法卡：am-card-xxxx_xxx）

题：<四类之一>
A. …  B. …  C. …  D. …
```

判定与讲解依据该方法卡的 `步骤逻辑 / 高频错因`，按方法依据摘要 + source anchor 给出，不直接贴 source_quote。
