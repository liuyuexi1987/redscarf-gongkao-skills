# 红领巾判断推理 Skill

用于判断推理各题型的方法调用、陷阱识别和错因复盘。

## 使用流程

1. 先读 `references/判断推理.md`。
2. 若用户要按题型检索，再读 `references/判断推理题型索引.md`。
3. 根据题型输出稳定流程：识别对象、抓关系、排除干扰、检查选项。
4. 需要案例时引用 `unit_id/source_quote`，不要长贴原文。

## 边界

- 对图形推理，若缺图或 OCR 错位，只能讲思路，不能编造图形。
- 没有 source_quote 的内容不能声称来自红领巾讲解。

## 常用问法

- “这道定义判断为什么 A 是偷换？”
- “这个削弱加强题按红领巾方法先看论点还是选项？”
- “图形推理我缺图，只能帮我复盘可能的观察顺序吗？”

## 输出模板

1. 题型识别：<图形/定义/类比/逻辑/削弱加强/归纳>
2. 红领巾判断流程：<识别对象 -> 抓关系 -> 对选项 -> 排除干扰>
3. 易错点 / 陷阱：<主体偷换、关系错配、必要条件漏看、图形信息缺失>
4. 库内依据：<`source_quote` + `unit_id`；没有时说明无直接依据>
5. 当前题推理：<只基于用户给出的题干/图形描述>
6. 复盘动作：<下次固定检查项>
