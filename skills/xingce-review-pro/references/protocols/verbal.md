# 公考复盘言语理解 Skill

本文件只规定言语理解的题型方法、导航和输出结构。意图门禁以 `SKILL.md` 为准；答案来源需要裁决时读 `references/protocols/answer-authority.md`；单题写回读 `references/review-engine/写回运行协议.md`，考我、复习和汇总状态读 `references/review-engine/复盘引擎说明.md`。

## 强制模式确认

每次触发本 skill，回答开头必须先写：

```text
已进入 xingce-review-verbal · 言语理解模式。
```

## 强制回答协议

- 必须按“输出模板”的 1-8 项顺序回答，不得改成普通聊天段落。
- 批量读取只优化工具调用；用户可见回复仍执行完整模板，不得合并或省略“方法讲解与速度评估”的必填字段。
- 用户以“我不懂/分不清/有什么区别/帮我讲讲”等方式主动求助具体考点或方法时，按【解法】讲解，不自动写入待巩固队列；只有用户明确要求记录时才写入。
- 必须区分”方法依据”和”当前题推理”；没有 `source anchor（card id/文件名）` 时，不得把模型推理说成公考复盘原方法。
- 言语主旨、意图、标题、排序、填句等属于易争议题。只要没有官方/已核验答案，必须读取 `references/protocols/answer-authority.md`，整轮只写“方法倾向”，用户答案只记为“与方法倾向一致/不一致”，不写“正确/错误/选对/选错”。用户后补答案时也读取该协议。
- 完整讲解结束后仅在满足写回条件时按 `references/review-engine/写回运行协议.md` 调用一次脚本，不在讲解前输出状态摘要或落盘回执。

## 方法库使用（讲解/解法的第一动作，必做，不是可选检索）

讲解或解法时，**第一步动作就是定位 AdvancedMethods 高频卡并读取**，不要先读综述、不要等“用户要检索”。

1. **先按下表内联导航直接定位高频卡**：识别子题型后，直接读对应的 `方法卡/am-card-*.md`（相对 `advanced-methods/`，保留 `方法卡/` 前缀，不要拼成裸卡名）。

   | 子题型 | 必读方法卡 |
   |---|---|
   | 主旨/意图/中心 | `方法卡/am-card-0405_主旨优先级法则.md` |
   | 下文推断/接语 | `方法卡/am-card-0194_下文推断背景加新.md`、`方法卡/am-card-0408_推断题紧扣主旨法.md` |
   | 标题拟定 | `方法卡/am-card-0204_标题拟定问句更生动.md` |
   | 语句排序 | `方法卡/am-card-0175_科普类语句排序分堆法.md`、`方法卡/am-card-1085_排序题捆绑法.md` |
   | 语句填入 | `方法卡/am-card-0411_语句填入的逻辑关系推导法.md` |
   | 细节判断 | `方法卡/am-card-0970_细节题四要素核对法.md`、`方法卡/am-card-0130_细节判断先看相对选项.md` |
   | 词句理解/引用作用 | `方法卡/am-card-0393_来说明类本意引申.md` |

2. 表里没有对应子题型时，再读 `references/method-libraries/advanced-methods/按题型索引/言语理解.md`，按关键词找 1-3 张候选卡，按其 `方法卡/am-card-*.md` 相对路径读取。
3. 读完高频卡后，再读 `references/method-libraries/xingce-review/言语理解.md` 对应题型段落作**综述补充**（仅补充，不作为第一入口）。
4. 有官方/已核验答案且需要输出“用户答案处理/易错点/错因分析/复盘动作/弱点标签”时，必须先读 `方法卡/am-card-1134_言语理解错因诊断总卡.md`，把错因归到主题词、结构、主旨句、对策、偷换、局部概括或择优失误等具体标签；未读前不得写具体错因，不得泛写“没看清/理解不好”。无官方/已核验答案时仍按答案权威性规则，只写方法倾向，不写错因。
5. **只有在第 1、2 步都真读过、确无同构卡时**，才可写“方法库无直接同构案例”。方法依据写具体 card id，引用 source anchor，不长贴原文。

## 质量规则

- 没有明确 source anchor（card id/文件名）支撑的内容，只能作为推理建议，不能说成公考复盘原方法。
- 用户拿新题来问时，可以应用方法，但要区分“方法依据”和“当前题推理”。
- 不凭空补全缺失题面；使用 OCR 题面候选时，必须说明“题面据 OCR，已按讲解关键词核对/仍需人工核对”。

## 常用问法

- “这道中心理解题我为什么排错了？帮我看主旨和选项偷换。”
- “这道结语题按公考复盘方法应该看最后一句还是全文脉络？”
- “这段阅读理解我总想太多，帮我做一张言语复盘。”

## 输出模板

1. 题型识别：<主旨/意图/细节/结语/标题/排序/填句 + 触发依据>
2. 答案来源与结论：<官方/已核验答案，或无官方时的方法倾向>
3. 公考复盘判断流程：<找主题词/逻辑关系/选项分歧/排除路径>
4. 当前题推理：<基于用户题干；必要时可用已核对的 OCR 题面候选，并标注置信>
5. 用户答案处理：<有官方答案时按其判定；无官方答案固定写“你的选择是 X，与方法倾向一致/不一致，本题不判对错”；无用户答案时省略>
6. 方法讲解与速度评估：<用简短正文说明为什么用、怎么做、先看什么、何时停止；随后逐项写“预计用时：”“关键步骤数：”“模型推理风险：”“是否值得做：”“方法来源：card id/文件名”>
7. 易错点 / 陷阱：<偷换、过度推理、细节错位、主体变化等>
8. 复盘动作与写回：<下次固定检查项；仅满足写回条件、实际写盘并验证后才回执>

无官方/已核验答案的言语主观题套模板时，不判用户对错；选项表用“更贴合/不贴合/仅背景提及”等描述，不用对错符号。
