# 公考复盘逻辑填空 Skill

本文件只规定逻辑填空的语境、词义辨析、方法导航和输出结构。意图门禁以 `SKILL.md` 为准；答案来源需要裁决时读 `references/protocols/answer-authority.md`；单题写回读 `references/review-engine/写回运行协议.md`，考我、复习和汇总状态读 `references/review-engine/复盘引擎说明.md`。

## 强制模式确认

每次触发本 skill，回答开头必须先写：

```text
已进入 xingce-review-cloze · 逻辑填空模式。
```

如果是虚词或关联词题，必须明确写成：

```text
已进入 xingce-review-cloze · 逻辑填空/虚词辨析模式。
```

## 强制回答协议

- 必须按“输出模板”的 1-9 项顺序回答，不得改成普通聊天段落；第 9 项落盘回执必须最后输出。
- 批量读取只优化工具调用；用户可见回复仍执行完整模板，不得合并或省略“方法讲解与速度评估”的必填字段。
- 用户以“我不懂/分不清/有什么区别/帮我讲讲”等方式主动求助具体考点或方法时，按【解法】讲解，不自动写入待巩固队列；只有用户明确要求记录时才写入。
- 用户明确说“讲解/看解法/怎么解”且给出参考答案/官方答案时，必须先输出完整讲解，再落盘；禁止一开头就输出“✅ 已落盘”、错因卡摘要、弱点标签或“本题速记项内容”。写回内容不得替代讲解正文。
- 对有官方/参考答案且用户答错的逻辑填空题，完整讲解至少包含：题型识别、语境关系、词义/搭配逐项排除、用户答案为什么不稳、正确项为什么贴合、词语辨析（如命中）、方法依据、易错点/复盘动作。完成这些内容后，才允许输出落盘回执。
- “本题速记项/错因卡内容/弱点标签”只能作为落盘后的简短附录，且不得放在完整讲解之前；如果输出会压缩讲解，则宁可省略该附录。
- 每一道题必须先判断空格之间的逻辑关系，再判断词义、搭配和排除项。
- 逻辑填空在答案权威性上始终按易争议题处理，不得写成“客观可复核题”。没有官方/已核验答案时必须读取 `references/protocols/answer-authority.md`，整轮只给方法倾向，不写“正确/错误/选对/选错”；用户给出或后补官方答案时也读取该协议。
- “方法依据”只允许写有 `source anchor（card id/文件名）` 支撑的内容；没有直接依据时必须写：`方法库无直接同构案例，以下主要是模型按公考复盘框架做的当前题推理。`
- 截图 OCR 可作为题面候选；若有“题面截图与讲解不匹配/疑似截偏”警告，先用空格位置、选项词、讲解主题和用户提供信息交叉核对，大体吻合时可低/中置信使用。
- 不得把公考通用语感、模型补充知识或临场推理包装成公考复盘原话。
- 完整讲解结束后仅在满足写回条件时按 `references/review-engine/写回运行协议.md` 调用一次脚本。

## 方法库使用（讲解/解法的第一动作，必做，不是可选检索）

讲解或解法时，**第一步动作就是定位 AdvancedMethods 高频卡并读取**，不要先读综述、不要等“用户要检索”。只要提示中同时有用户答案和官方/已核验答案，必须在生成内容前一并读取通用流程卡 `方法卡/am-card-0976_逻辑填空三步法.md` 和错因卡 `方法卡/am-card-1135_逻辑填空错因归因卡.md`；讲解完成且确认判错后按轻量写回协议执行，不预读完整复盘引擎。

1. **先按下表内联导航直接定位高频卡**：识别子题型后，直接读对应的 `方法卡/am-card-*.md`（相对 `advanced-methods/`，保留 `方法卡/` 前缀，不要拼成裸卡名）。

   | 子题型 | 必读方法卡 |
   |---|---|
   | 逻辑填空通用流程 | `方法卡/am-card-0976_逻辑填空三步法.md` |
   | 语境对应/呼应 | `方法卡/am-card-0962_语境对应分析法.md` |
   | 语境转折/反义 | `方法卡/am-card-0959_语境转折选词法.md` |
   | 实词搭配/成语搭配 | `方法卡/am-card-0963_搭配验证选词法.md` |

2. **词义辨析强触发（必做）**：题目涉及成语、近义实词、虚词、关联词搭配、词义轻重/感情色彩时，**必须读取 skill 包内** `references/lexical-discrimination/groups/*.md`（按 skill 安装目录的相对路径读，**不要用 `**/` 从当前工作目录递归搜**）中命中的词条，作为“词语辨析”短节展示命中词条原文。词义辨析**只作辅助**，不得写成“方法依据”，与方法卡来源分开呈现。
3. 表里没有对应子题型时，再读 `references/method-libraries/advanced-methods/按题型索引/言语理解.md`，按关键词找 1-3 张候选卡，按其 `方法卡/am-card-*.md` 相对路径读取。
4. 读完高频卡后，再读 `references/method-libraries/xingce-review/逻辑填空.md` 作**综述补充**（仅补充，不作为第一入口）。
5. 有官方/已核验答案且需要输出“用户答案处理/易错点/错因分析/复盘动作/弱点标签”时，必须先读 `方法卡/am-card-1135_逻辑填空错因归因卡.md`，把错因归到词义、辨析、语境、搭配、对应关系、感情色彩或轻重程度等具体标签；未读前不得写具体错因，不得泛写“词汇量不够”。无官方/已核验答案时仍按答案权威性规则，只写方法倾向，不写错因。
6. **只有在第 1、3 步都真读过、确无同构卡时**，才可写“方法库无直接同构案例”。方法依据写具体 card id，引用 source anchor，不长贴原文。

## 边界

- 不认识词时，不要硬凑词义；可以建议建立词表或标低置信。
- 只把有明确 source anchor（card id/文件名）支撑的内容当作公考复盘依据；对用户默认输出摘要。
- 使用 OCR 题面候选时，必须说明“题面据 OCR，已按讲解关键词核对/仍需人工核对”。

## 常用问法

- “这个成语填空为什么不能选 A？帮我看语境和搭配。”
- “这道逻辑填空两个词都像对，按公考复盘方法怎么排？”
- “我总被词义轻重坑，帮我用这题复盘。”

## 输出模板

1. 题型识别：<成语/实词/虚词/混合填空 + 空格关系>
2. 答案来源与结论：<官方/已核验答案，或无官方时的方法倾向>
3. 公考复盘判断流程：<语境关系 -> 词义约束 -> 搭配检查 -> 排除项>
4. 词语辨析：<命中词条时展示；未命中可省略，不得写成方法依据>
5. 当前题推理：<逐项比较正确项与干扰项>
6. 用户答案处理：<有官方答案时按其判定；无官方答案固定写“你的选择是 X，与方法倾向一致/不一致，本题不判对错”；无用户答案时省略>
7. 方法讲解与速度评估：<用简短正文说明为什么用、怎么做、先看什么、何时停止；随后逐项写“预计用时：”“关键步骤数：”“模型推理风险：”“是否值得做：”“方法来源：card id/文件名”>
8. 易错点 / 复盘动作：<错因信号和下次固定动作>
9. 写回回执：<仅满足写回条件、1-8 完整输出且实际写盘并验证文件存在后，最后一行列真实类型>
