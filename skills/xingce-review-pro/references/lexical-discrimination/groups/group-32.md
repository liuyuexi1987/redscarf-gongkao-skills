# 词义辨析补救库 第 32 组

用途: 近义词、成语、实词辨析；不作为方法库依据；不用于自动判题。

## 词组辨析

| 词组 | 辨析要点 |
|---|---|
| 一成不变 | 一经形成就不再改变，常用于否定句，强调固定不变 |
| 亘古不变 | 从古到今都不改变，多用于真理、规律等，强调恒常性 |
| 改弦更张 | 改变原来的计划、制度或方法，强调对体系的调整 |
| 改弦易辙 | 改变原来的方向或路线，强调另择路径而非调弦 |
| 变化莫测 | 变化难以预测，强调不可估量 |
| 瞬息万变 | 极短时间内发生大量变化，强调变化的快速与密集 |
| 经久不衰 | 经过长时间仍保持不衰减，多用于热度、人气、活力等，强调持续性 |
| 长盛不衰 | 长时间繁荣而不衰退，多用于事业、产业、行情等，强调兴盛的延续 |
| 今非昔比 | 现在与过去已有明显不同，常用于变化较大的语境；是否变好由上下文决定。 |
| 天翻地覆 | 变化极大或闹得极凶，强调变化的剧烈 |
| 时过境迁 | 时间推移，环境与情况随之改变，强调时间带来的变化 |
| 沧海桑田 | 世事变化巨大，强调变化彻底如沧海变桑田 |
| 斗转星移 | 星辰位置移动，强调时间的流逝 |
| 白云苍狗 | 世事变幻无常，强调变化的不可捉摸 |
| 恍如隔世 | 因变化大而好像隔了一个时代，强调变化给人带来的陌生感 |
| 根深蒂固 | 多用于观念、思想、性格等基础牢固难以动摇，强调根基的稳固；中性或偏贬义 |
| 积习难改 | 长期形成的旧习惯难以改变，多含贬义 |
| 积重难返 | 问题长期积累难以扭转，强调积弊的深重 |

## 使用边界

- 在复盘、解法或考我流程中自动用于词语辨析补充、同义词对比、搭配提醒。
- 不写作“方法依据”，不冒充方法库方法。
- 如果需要讲解解题流程，仍应调用综合方法库。
