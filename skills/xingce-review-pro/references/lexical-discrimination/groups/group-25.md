# 词义辨析补救库 第 25 组

用途: 近义词、成语、实词辨析；不作为方法库依据；不用于自动判题。

## 词组辨析

| 词组 | 辨析要点 |
|---|---|
| 开源节流 | 同时增加收入与节约支出，强调两条路径并重 |
| 精打细算 | 在使用人力物力时仔细计算，强调使用过程中的精细与节制 |
| 细水长流 | 一点一滴持续积累，强调长期坚持使少量汇成总量 |
| 量入为出 | 按收入确定支出，强调收支匹配、不超过承受能力 |

## 使用边界

- 在复盘、解法或考我流程中自动用于词语辨析补充、同义词对比、搭配提醒。
- 不写作“方法依据”，不冒充方法库方法。
- 如果需要讲解解题流程，仍应调用综合方法库。
