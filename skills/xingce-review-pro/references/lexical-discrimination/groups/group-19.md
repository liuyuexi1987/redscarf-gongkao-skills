# 词义辨析补救库 第 19 组

用途: 近义词、成语、实词辨析；不作为方法库依据；不用于自动判题。

## 词组辨析

| 词组 | 辨析要点 |
|---|---|
| 条分缕析 | 一条一条地细密分析，强调分析的条理性和细致程度，多用于对复杂事物的拆解。 |
| 抽丝剥茧 | 形容分析问题层层深入，逐步理清事物的层次和脉络，强调由表及里的过程。 |
| 深入浅出 | 用浅显的语言或表达讲明深刻的道理，多用于讲话、写文章，强调表达的化繁为简。 |
| 纲举目张 | 提起渔网的总绳，网眼便都张开，比喻抓住关键，整体就能顺势把握，强调"关键带动全局"。 |
| 提纲挈领 | 提起渔网的总绳、拎住衣服的领子，比喻抓住事物的关键或要领，重在"抓要领"的动作。 |
| 以一持万 | 提起一个总纲便能统御万端，比喻抓住根本关键即可掌控全局，与"提纲挈领"近义但更强调"统御"关系，属于较书面、罕见的表达，建议结合语境判别。 |
| 博采众长 | 广泛采纳各家的长处，强调吸收众人之优以补己之短，重在"广采"。 |
| 见贤思齐 | 看到德才兼备的人就向他看齐，强调主动学习效仿榜样，重在"齐"的看齐动作。 |
| 量力而行 | 根据自己能力的大小去做，强调做事要衡量自身实力、不勉强，重在"量力"。 |
| 厚积薄发 | 长期积累深厚，而后慢慢释放，强调积累在先、输出在后，多用于学问、创作。 |
| 当仁不让 | 面对应该做的好事主动承担、不推让，强调基于道义和能力的主动担当，重在"主动"。 |
| 义不容辞 | 道义上不允许推辞，强调责任源于道义要求，多用于表态承担某事，重在"道义"。 |
| 责无旁贷 | 自己的责任不能推卸给别人，强调属于本职或本分内的责任，重在"本职"。 |

## 使用边界

- 在复盘、解法或考我流程中自动用于词语辨析补充、同义词对比、搭配提醒。
- 不写作"方法依据"，不冒充方法库方法。
- 如果需要讲解解题流程，仍应调用综合方法库。
