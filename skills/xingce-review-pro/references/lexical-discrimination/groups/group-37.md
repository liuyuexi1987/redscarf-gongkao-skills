# 词义辨析补救库 第 37 组

用途: 近义词、成语、实词辨析；不作为方法库依据；不用于自动判题。

## 词组辨析

| 词组 | 辨析要点 |
|---|---|
| 纸上谈兵 | 只会空谈理论不能解决实际问题，含贬义 |
| 无根之木 | 比喻没有根据或基础的事物，强调缺乏根基 |
| 坐而论道 | 光说不做，口头讲大道理，含贬义 |
| 水中捞月 | 比喻白费力气徒劳无功，强调根本做不到 |
| 画饼充饥 | 借空想安慰自己，强调用虚幻应付眼前 |
| 空中楼阁 | 比喻脱离实际没有基础的事物，强调虚悬无据 |
| 镜花水月 | 比喻虚幻不实不可触及的事物，强调看似美好 |
| 海市蜃楼 | 比喻虚幻不存在的事物，强调看似壮观实则不真 |

## 使用边界

- 在复盘、解法或考我流程中自动用于词语辨析补充、同义词对比、搭配提醒。
- 不写作“方法依据”，不冒充方法库方法。
- 如果需要讲解解题流程，仍应调用综合方法库。
