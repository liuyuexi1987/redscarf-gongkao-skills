# 词义辨析补救库 第 16 组

用途: 近义词、成语、实词辨析；不作为方法库依据；不用于自动判题。

## 词组辨析

| 词组 | 辨析要点 |
|---|---|
| 揠苗助长 | 指违背客观规律急于求成，强调违反事物发展规律。 |
| 越俎代庖 | 指超出自己职责范围去处理别人的事，强调越权代办。 |
| 削足适履 | 指不顾实际而迁就既有标准，强调生搬硬套、勉强迁就。 |
| 闭门造车 | 指凭主观意愿办事而不顾客观实际，强调封闭脱离现实。 |
| 刻舟求剑 | 指不顾事物变化而仍用旧方法，强调缺乏发展眼光。 |
| 守株待兔 | 指拘泥于偶然经验而不知变通，又含心存侥幸、不劳而获之意。 |
| 掩耳盗铃 | 指自欺欺人地掩盖明显事实，强调掩盖是徒劳的。 |
| 邯郸学步 | 指模仿他人不成反而丧失自己原有的本领，强调模仿失败的后果。 |
| 东施效颦 | 指盲目模仿他人而显得更丑，强调模仿反而出丑。 |
| 与虎谋皮 | 指要求对方放弃其根本利益，强调所求不可能实现。 |

## 使用边界

- 在复盘、解法或考我流程中自动用于词语辨析补充、同义词对比、搭配提醒。
- 不写作“方法依据”，不冒充方法库方法。
- 如果需要讲解解题流程，仍应调用综合方法库。
