# 词义辨析补救库 第 17 组

用途: 近义词、成语、实词辨析；不作为方法库依据；不用于自动判题。

## 词组辨析

| 词组 | 辨析要点 |
|---|---|
| 潜移默化 | 暗中影响人的思想、性格或行为，多指氛围、环境的长期熏陶，不带强制，强调影响的隐蔽与渐进。 |
| 耳濡目染 | 长期耳听眼看，不知不觉中受到影响。主语只能是被影响者，强调结果而非方式，与"潜移默化"相比更突出"看和听"的接触途径。 |
| 如沐春风 | 形容与有学问、有修养的人交往时感到温暖舒适，多用于被教导、被引导时的主观感受。 |
| 润物无声 | 形容影响细微而持久，使人在不知不觉中受到熏陶，多用于教育、文化语境，与"潜移默化"近义但更强调"无声"的隐蔽性。 |
| 成风化人 | 通过树立良好风气来感化他人，多用于宏观层面的社会引领，常与文化建设、舆论引导搭配。 |
| 耳提面命 | 形容恳切而严格地当面教导、叮嘱，多用于长辈对晚辈或上级对下级，含殷切之意。 |
| 苦口婆心 | 怀着好心再三恳切劝解，多用于劝人改过或听从建议，强调"苦口"的劝解难度。 |
| 循循善诱 | 有步骤地耐心引导、启发，强调教育者善于带动被教育者逐步深入，重在"引导"的过程。 |
| 诲人不倦 | 教导人特别耐心、从不厌倦，多用于评价教师或教育者的态度，重在"耐心"的品格。 |
| 春风化雨 | 比喻良好的教育和感化，强调温柔、主动的影响，多用于教育情境，与"润物无声"近义但更突出"教育者主动施教"。 |
| 和风细雨 | 比喻方式温和、不粗暴，多用于批评、劝说或处理问题的态度，与"雷霆万钧"相对。 |
| 醍醐灌顶 | 比喻听了高明的意见使人受到极大启发、顿时醒悟，强调启发来自外部他人而非自己想通。 |
| 振聋发聩 | 比喻用语言文字唤醒糊涂麻木的人，强调话语的唤醒力量，多用于言论、文章的影响。 |

## 使用边界

- 在复盘、解法或考我流程中自动用于词语辨析补充、同义词对比、搭配提醒。
- 不写作"方法依据"，不冒充方法库方法。
- 如果需要讲解解题流程，仍应调用综合方法库。
