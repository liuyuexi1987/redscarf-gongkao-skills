# 词义辨析补救库 第 29 组

用途: 近义词、成语、实词辨析；不作为方法库依据；不用于自动判题。

## 词组辨析

| 词组 | 辨析要点 |
|---|---|
| 前仆后继 | 前面的人倒下、后面的人跟上，强调不惜牺牲、接连奋进 |
| 视死如归 | 把死看作回家一样，强调面对死亡的从容无畏 |
| 大义凛然 | 为正义而表现严峻不可侵犯，强调神态与立场的坚定 |
| 踔厉奋发 | 精神振奋、斗志昂扬地前行，强调精神状态 |
| 笃行不怠 | 坚定践行而不松懈，强调行动上的坚持 |
| 赓续前行 | 承接既往并继续前进，强调传承基础上的延续 |
| 奋楫争先 | 奋力划桨争取领先，强调争先的姿态 |
| 砥砺前行 | 经历磨炼仍向前进，强调克服困难的奋进 |
| 勇毅前行 | 勇敢坚毅地前进，强调意志品质 |

## 使用边界

- 在复盘、解法或考我流程中自动用于词语辨析补充、同义词对比、搭配提醒。
- 不写作“方法依据”，不冒充方法库方法。
- 如果需要讲解解题流程，仍应调用综合方法库。
