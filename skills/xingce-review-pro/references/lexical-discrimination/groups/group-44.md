# 词义辨析补救库 第 44 组

用途: 近义词、成语、实词辨析；不作为方法库依据；不用于自动判题。

## 词组辨析

| 词组 | 辨析要点 |
|---|---|
| 毋庸置疑 | 指用不着怀疑，强调事实确定无疑。 |
| 显而易见 | 形容道理、结果、好处等明显能够看到。 |
| 不言而喻 | 指不用说明就能明白，侧重道理明显。 |
| 不言自明 | 指本身自带道理，不用解释自然清楚，多用于常识、定义、道理。 |
| 昭然若揭 | 形容真相或目的完全暴露，贬义。 |
| 有目共睹 | 形容人人都能看见，极其明显，多用于成效、事实。 |
| 一目了然 | 形容一眼就能看清楚，侧重直观。 |
| 大张旗鼓 | 形容声势和规模很大。 |
| 语焉不详 | 指虽然提及但不详细，侧重说得不充分。 |
| 讳莫如深 | 指隐瞒得很紧，不愿透露。 |
| 谈虎色变 | 指提及令人害怕的事物就脸色大变，侧重恐惧。 |
| 噤若寒蝉 | 形容因害怕而不敢说话。 |
| 避而不谈 | 指回避话题，不愿提及，多因心虚或有所顾忌。 |
| 暗度陈仓 | 指暗中进行某种活动，侧重不公开。 |
| 不露声色 | 指不让感情或意图从表情、言语中表现出来。 |
| 闪烁其词 | 指说话故意含糊躲闪，回避真相。 |

## 使用边界

- 在复盘、解法或考我流程中自动用于词语辨析补充、同义词对比、搭配提醒。
- 不写作"方法依据"，不冒充方法库方法。
- 如果需要讲解解题流程，仍应调用综合方法库。
