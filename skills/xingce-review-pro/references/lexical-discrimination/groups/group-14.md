# 词义辨析补救库 第 14 组

用途: 近义词、成语、实词辨析；不作为方法库依据；不用于自动判题。

## 词组辨析

| 词组 | 辨析要点 |
|---|---|
| 并行不悖 | 指同时进行而不冲突，强调可同时存在。 |
| 齐头并进 | 指多方面同时前进、进度相当，常用于工作、任务推进。 |
| 双管齐下 | 指为解决一件事同时采用两种办法，常用于治理乱象的措施。 |
| 并驾齐驱 | 指水平、实力相当，齐头同行而不分先后。 |

## 使用边界

- 在复盘、解法或考我流程中自动用于词语辨析补充、同义词对比、搭配提醒。
- 不写作“方法依据”，不冒充方法库方法。
- 如果需要讲解解题流程，仍应调用综合方法库。
