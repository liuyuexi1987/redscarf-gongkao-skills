# 词义辨析补救库 第 08 组

用途: 近义词、成语、实词辨析；不作为方法库依据；不用于自动判题。

## 词组辨析

| 词组 | 辨析要点 |
|---|---|
| 岌岌可危 | 侧重形势危险、即将倾覆，多形容建筑物不稳或局势危急。 |
| 危如累卵 | 像堆叠的蛋一样容易倾覆，侧重根基不稳、随时可能崩塌，多形容局势或处境。与“岌岌可危”没有稳定的程度高下。 |
| 命悬一线 | 侧重生命危在旦夕，多用于人命关天的情境。 |
| 风雨飘摇 | 侧重政权或局势动荡不稳，强调在外部冲击下摇动。 |
| 危在旦夕 | 侧重危险就在眼前、时间极为紧迫，强调短时间内即将发生。 |

## 使用边界

- 在复盘、解法或考我流程中自动用于词语辨析补充、同义词对比、搭配提醒。
- 不写作“方法依据”，不冒充方法库方法。
- 如果需要讲解解题流程，仍应调用综合方法库。
