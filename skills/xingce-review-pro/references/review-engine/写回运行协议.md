# 写回运行协议

本文件是 v1.4 单题及复习结果脚本写回的唯一运行接口。答案裁决、错因判断和方法选择由 Skill 完成；`scripts/writeback.py` 只校验并写入已决定的结构化结果。

## 单次调用快路径

1. 完成题面核验、答案复核、错因判断和完整讲解后，确认满足写回条件。写回必须是本轮最后一个工具动作；讲解正文完成前不得生成 payload 或调用脚本。
2. 直接组装一个 JSON payload，并只调用一次：

```text
python3 <skill-install-dir>/scripts/writeback.py --cwd <当前工作目录> --payload <payload.json>
```

3. 不读取 `writeback.py` 源码，不在调用前手动扫描状态根，不默认执行 `--dry-run`。脚本会完成字段校验、状态根解析、路径限制、幂等检查、文件锁、事务替换和失败回滚。
4. `wrong_answer` 成功后只接受脚本回执中的事件记录、错因卡和弱点档案；不得额外写每日记忆、学习记录或逐题刷新画像。
5. 临时 payload 只用于本次调用，不作为学习状态或用户产物展示。

## 公共字段

所有动作都必须提供：

```json
{
  "schema_version": 1,
  "event_id": "字母数字及 . _ : - 组成的稳定唯一编号",
  "action": "wrong_answer",
  "date": "YYYY-MM-DD"
}
```

`event_id` 最长 128 字符；同一事件重复调用应返回 `noop`，不得重复计数。

## 动作字段

- `wrong_answer`：必须提供 `explanation_completed: true`、`module`、`question_type`、`weakness_key`、`question_text`、`user_answer`、`verified_answer`、`error_reason`；`method_refs` 为真实读取的方法卡字符串数组。可选 `short_title`、`source`、`correct_method`、`next_review_prompt`。
- `review_result`：必须提供 `explanation_completed: true`、`module`、`question_type`、`weakness_key`、`result`；`result` 只能是 `correct`、`incorrect`、`passed`、`failed`。
- `pending_topic`：必须提供 `topic_key`、`module_question_type`、`user_performance`、`next_review_prompt`，且只有用户明确要求记录时使用。
- `mastery_upgrade`：必须提供 `method_name`、`key_point` 和非空 `method_refs`，且 Skill 已确认达到掌握门槛后使用。
- `profile_refresh`：只在复盘引擎规定的刷新时机使用，不重新解题。

## 回执处理

- `written`：确认回执中的文件列表后，才能向用户显示“已落盘”。
- `noop`：说明同一 `event_id` 已处理，不重复增加错误次数。
- `blocked`：报告 `code` 和 `message`。只有 Python 或脚本不可用时，才读取 `复盘引擎说明.md` 走手工 Markdown 降级。
- 答案冲突、状态根冲突、输入校验失败、路径不安全或其它安全门禁失败时，必须停止写回，不得用手工方式绕过。

## 运行边界

- 当前工作目录由运行环境提供；状态根只能由脚本在其下解析 `review-engine`、`.workbuddy/memory`、`复盘引擎`。
- 不向 Skill 安装目录、其它项目、用户主目录或当前工作目录之外写入。
- 不把脚本用于判答案、生成错因、选择方法或补全缺失题面。
- 用户可见回复只展示完整讲解和最终机器回执，不展示 payload 构造、文件扫描或内部工具过程。
- `explanation_completed` 是顺序门禁，不是答案裁决字段；脚本不判断讲解内容，只拒绝讲解未完成的写回请求。
