# 方法质量规则

本文件用于提升复盘质量。它不规定固定分区优先级，只规定方法卡能不能被用于讲解、复盘和出题反馈。

## 质量判断核心维度

方法质量判断以下列 6 项维度为准，不依赖已不存在的来源字段：

1. 题型匹配
2. 公式或逻辑正确
3. 适用条件明确
4. 步骤完整
5. 反向验证可靠
6. 当前题适配

## 质量分级

| 等级 | 可用方式 | 判断标准 |
|---|---|---|
| A 稳定依据 | 可作为主要方法依据 | 题型直接命中；步骤完整；方法论字段完整；卡片 id 作为来源锚点清楚；能解释当前题错因 |
| B 可用依据 | 可作为辅助方法依据 | 题型或考点命中；流程基本完整；依据可核验但表达略口语、略短或边界不完整 |
| C 提示材料 | 只能作为检索线索 | 只有片段口诀或单题经验；不能单独支撑结论 |
| D 不采用 | 不用于讲解结论 | 无来源锚点、题型不匹配、明显错字影响含义、与题目冲突且无法解释 |

## 调用门槛

- 讲解和复盘优先使用 A/B 级候选。
- C 级只能帮助继续检索，不得在用户输出中写成确定方法。
- D 级直接跳过。
- 如果只有 C 级材料，输出必须写“方法库无稳定依据”，再把模型推理单独标明。
- 如果多个候选同时可用，不按分区名排序；按“题型匹配度 → 依据质量 → 流程完整度 → 当前题适配度”排序。

## 单题复盘核验清单

每次输出解法或复盘前，至少完成以下检查：

1. 当前题型是否已经明确。
2. 候选方法是否真的覆盖这个题型或考点。
3. 方法步骤是否能复用到下一题，而不是只解释本题选项。
4. 用户错因是否能对应到某一步，例如审题、公式、逻辑关系、选项比较、计算、词义辨析。
5. 方法依据是否有清楚的卡片 id 作为来源锚点支撑。
6. 用户输出是否只展示“方法依据”摘要 + 卡片 id 作为来源锚点。

## 冲突处理

- 若两个候选方法方向一致，选更完整、更贴合当前题的一条作为主依据，另一条只在必要时补充。
- 若两个候选方法方向冲突，先检查题型是否误判；再检查其中一条是否只是 C 级提示材料。
- 若冲突仍无法解决，明确写“方法库无确定优先依据”，不要硬选。

## 质量维护

- 新增方法卡时，必须补齐：方法名、适用题型、触发场景、步骤逻辑、高频错因、方法依据摘要、卡片 id 作为来源锚点、confidence。历史卡片可保留“常见错因”作为正文小标题，但标准字段统一使用“高频错因”。
- 发现低质量卡时，不急着删除；先在索引或卡片中标记 `quality: C` 或 `quality: D`，避免误用。
- 批量清洗时优先处理高频题型和已在错因卡中反复出现的考点。
