# 间隔增长率

confidence: high

## 适用题型

隔一年/隔一期增长率、间隔倍数、间隔基期、间隔现期、间隔增长量、逆向求某期增长率。

## 触发场景

- 题干出现"隔年""间隔""两年后""第二年比前年"等表述，且给出两个连续时期的增长率。
- 已知某期相对基期的总增长率（间隔增长率）与其中一期增长率，反推另一期。
- 求间隔倍数、间隔基期、间隔现期、间隔增长量等派生量。

## 方法卡

### 1. 核心公式

```text
R = r1 + r2 + r1 × r2
```

乘积项 `r1 × r2` 是否可以忽略，必须由选项误差决定：

1. 先算 `r1 + r2`。
2. 计算 `r1 × r2`，精度至少要能判断它是否会改变选项选择。
3. 比较 `r1 × r2` 与"最接近的两个选项之差"：
   - 若 `r1 × r2` 远小于该差，可忽略。
   - 若 `r1 × r2` 接近或大于该差，必须计入。
4. 任何情况下，若选项差距很小，都不能直接忽略乘积项。

### 2. 间隔倍数

```text
是 n 倍 = 间隔增长率 + 1
多 n 倍 = 间隔增长率
```

注意：题目问"是几倍"用前者，问"多几倍/增长几倍"用后者。

### 3. 间隔基期

1. 先估算间隔增长率 `R`。
2. 再用 `现期 = 基期 × (1+R)` 反推基期：

```text
基期 = 现期 / (1 + R)
```

### 4. 间隔现期

保持某增长率不变、隔一期问具体值:

```text
现期 = 基期 × (1 + 间隔增长率)
```

### 5. 间隔增长量

先估算间隔增长率，再百化分求增长量：

```text
增长量 = 现期 × 间隔增长率 / (1 + 间隔增长率)
```

### 6. 逆向求某期增长率

已知间隔增长率 `R` 和其中一期增长率 `r1`:

```text
r2 = (R - r1) / (1 + r1)
```

判断符号:

- 当 `R > r1` 时，`r2 > 0`。
- 当 `R < r1` 时，`r2 < 0`。
- 当 `R = r1` 时，`r2 = 0`。

## 不适用条件

- 三期及以上的连续增长不能只套两期公式，应按各期增长系数连乘；只有题目问年均增长率时才进一步开方。
- 题目给出"平均增长率"但实际是算术平均而非几何平均时，不能直接当作 r1 或 r2 代入。
- 当乘积项相对选项差距不可忽略时，必须保留；增长率绝对值越大，越应优先使用完整公式而非加法近似。

## 反向验证

- 算出 R 后，回代 `(1+r1)(1+r2) - 1` 检查是否等于 R。
- 逆向求 r2 时，回代 `R = r1 + r2 + r1×r2` 验证。
- 用符号判断快速校验：若 R 与 r1 同向且 `|R|>|r1|`，则 r2 与 r1 同号；若 R 介于 0 和 r1 之间，则 r2 与 r1 异号。
- 间隔倍数算完后，检查"是 n 倍" = "多 (n-1) 倍"，避免口误。

## 高频错因

- 只算 `r1+r2`，漏乘积项。
- "是 n 倍"和"多 n 倍"混淆。
- 已知两年平均增长率时，没有先转成间隔增长率。
- 逆向求增长率时把分母写成 `1+R`。
- 把乘积项当作可无条件忽略的小量。
- 间隔基期误用 `现期 / (1+r1)` 而忽略 r2 的累积效应。
