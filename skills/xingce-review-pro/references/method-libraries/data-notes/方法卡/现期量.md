# 现期量

confidence: medium

## 适用题型

给基期、增长量或增长率，推未来某年/月的现期量；或问追上、超过、达到几倍、名义与实际增长。

## 触发场景

- 题干问"到哪一年首次超过 X""A 何时追上 B"。
- 题干给出"保持增长量不变"或"保持增长率不变"，求未来值。
- 题干涉及名义增长率与实际增长率、CPI 的换算。
- 题干未直接给出增长率，需要根据现期和基期关系推断趋势。

## 方法卡

### 1. 现期追赶

常见条件:

- 保持增长量不变。
- 保持增长率不变。

常见问法:

- 到哪一年首次超过某数。
- A 何时追上 B。
- A 与 B 差距在哪一年进入某范围。
- A 何时达到 B 的 n 倍。

保持增长量不变时:

```text
未来现期 = 当前现期 + 年数差 × 每年增长量
```

追赶类:

```text
所需年数 = 当前差距 / 每期缩小的差距
```

若问“达到 B 的 n 倍”，目标写成 `A >= nB`；若问“超过 B 的 n 倍”，目标写成 `A > nB`。

方法步骤:
1. 先判断题目假设的是"增长量不变"还是"增长率不变"，二者公式不同。
2. 仅在双方每期增长量恒定且差距持续缩小时，才用“当前差距 / 每期缩小的差距”：求首次达到可向上取整；求首次严格超过时，整除情形还要再增加一期。
3. n 倍类先按“达到/超过”分别整理为 `A >= nB` 或 `A > nB`，再代入增长公式求解。

### 2. 保持增长率不变

```text
未来现期 = 基期 × (1 + r)^n
```

如果增长率较小，可用连续增长估算；如果增长率较大，要计算乘方。

### 3. 不给增长率时

方法步骤:
1. 先确认题干是否明确给出“增长量保持不变”“增长率保持不变”或其他延续规则。
2. 若只给历史数据而没有延续假设，不能自行选择线性增长或复合增长模型外推未来值。
3. 若题目只要求描述已给区间内的趋势，可比较相邻时期的变化方向；这不等于能预测区间外数据。

不要使用"大作小看"这类含混话术：所有估算都要落到具体的倍数、增长量或增长率上。

### 4. 名义增长率和实际增长率

```text
1 + 名义增长率 = (1 + 实际增长率) × (1 + CPI增长率)
名义增长率 ≈ 实际增长率 + CPI增长率 + 实际增长率×CPI增长率
```

当物价指数增长率为正时，名义增长率通常高于实际增长率；通缩时二者大小关系可能相反。

## 不适用条件

- 题目未明确"增长量不变"或"增长率不变"时，不能默认二者等价：增长量不变下现期线性增长，增长率不变下现期指数增长，多年后差距显著。
- 追赶类不能用"当前差距 / 增长量差"估算年数的情况：增长量差逐年变化时应逐年累加，不能简单做除法。
- 名义/实际增长率换算需要区分精确乘积关系与省略交叉项的近似；选项接近时使用精确式。

## 反向验证

- 保持增长率不变：回代 `(未来现期 / 基期)^(1/n) - 1`，应等于题目给出的 r。
- 追赶类：把求得的年数代回原不等式 `A ≥ nB` 或 `A ≥ 目标值`，确认是否真的首次超过。
- 名义/实际换算：用 `(1+实际)(1+CPI) - 1` 反算名义增长率，与题目数据一致。

## 高频错因

- 保持增长量不变和保持增长率不变混用。
- 追赶题没有先写"差距/增长量差"。
- 到 n 倍时没有把目标式子写成 `A >= nB`。
- 名义增长率、实际增长率、CPI 三者关系混乱。
- "大作小看"等含混话术导致无法落地计算。
