# 一般增长率

confidence: high

## 适用题型

资料分析中问增长率、增速、增幅、增长幅度、下降幅度、百分点变化、增长率比较。

## 触发场景

- 给现期和基期，求增长率。
- 给现期和增长量，求增长率。
- 给增长率和百分点，求另一期增长率。
- 比较多个对象的增长率大小。
- 图表中要求判断趋势、排序、查找个数、降幅比较。

## 方法卡

### 1. 基础概念

- 增长率可正可负。
- `增长 n 倍` 对应 `增长率 = n`；`是 n 倍` 对应 `增长率 = n - 1`。
- 百分数表示比例；百分点表示百分数的变化量。
- 增长幅度、下降幅度、变化幅度，本质都要先判断方向和绝对变化。

### 2. 增长率公式

```text
增长率 = 增长量 / 基期
增长率 = 增长量 / (现期 - 增长量)
增长率 = 现期 / 基期 - 1
```

公式中各变量含义：
- 现期：题目给出的当期数值。
- 基期：作为对比基准的上一期数值。
- 增长量 = 现期 - 基期，可正可负。

### 3. 给百分点时先还原基期增长率

- 增速上升/下降: 用现期增长率加减百分点。
- 降幅扩大/收窄: 先把“下降”当负增长，再判断绝对值扩大还是缩小。
- 给“现期 r、百分点变化，求基期 r”时，先判方向，再加减。

### 4. 比较增长率

- 给现期、基期: 比较 `现期/基期`，倍数越大增长率越大。
- 给现期、增长量: 比较 `增长量/基期`，也可转成 `增长量/(现期-增长量)`。
- 选项差距足够大时，可直接比较倍数或增长量与基期的比值；选项差距接近时，需要把分子分母都代入计算出差值再判断。

## 方法步骤

1. 识别题目所求：是求增长率，还是求增速/增幅/下降幅度等同义概念。
2. 列出已知量：现期、基期、增长量、百分点变化中的哪几个。
3. 选择对应公式：
   - 已知增长量和基期 → `增长率 = 增长量 / 基期`。
   - 已知现期和增长量 → `增长率 = 增长量 / (现期 - 增长量)`。
   - 已知现期和基期 → `增长率 = 现期 / 基期 - 1`。
   - 涉及百分点变化 → 先按方向加减还原，再代入上述公式。
4. 代入计算或估算，结合选项差距决定精度。
5. 比较类题目：统一化为同一公式形式后再比较，避免公式不一致导致误判。

## 高频错因

- 把“是 n 倍”和“增长 n 倍”混用。
- 把百分点当百分数直接乘除。
- 降幅扩大/收窄时忘记下降是负增长。
- 增长率比较时直接比较增长量，忽略基期。

## 不适用条件

- 题目问的是“增长量”而非“增长率”时，不适用本卡公式，应直接用 `增长量 = 现期 - 基期`。
- 题目问的是“比重”或“占比”时，应转用比重相关方法卡，不能用增长率公式。
- 题目问的是“年均增长率/复合增长率”时，不适用本卡的简单增长率公式，需用年均增长率方法卡。
- 题目问的是“两个乘积因素形成的总量增长率”时，应转用乘积增长率方法卡。

## 反向验证

- 用算出的增长率反推：`现期 ≈ 基期 × (1 + 增长率)`，若与题干现期不一致则计算有误。
- 涉及百分点的题目：把还原后的基期增长率按题干方向加减百分点，应能得到题干给出的现期增长率。
- 比较类题目：把判断出的最大/最小增长率对应的现期与基期比值口算一遍，确认排序方向一致。
