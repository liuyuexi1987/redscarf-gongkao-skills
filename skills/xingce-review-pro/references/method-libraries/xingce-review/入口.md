# 公考复盘综述校验入口

本分区是主方法卡之后的二次校验层，只承担三件事：复核题型是否识别正确、检查方法是否满足适用条件、在输出结论前排查遗漏。它不替代题型协议、`advanced-methods/` 主卡或 `data-notes/` 公式卡。

## 使用顺序

1. 先按题型协议读取对应主卡；资料分析还要读取对应公式卡。
2. 完成当前题推理后，再读本分区对应文件做跨步骤检查。
3. 若综述与题型协议、已读取主卡或客观复核不一致，以题型协议、主卡和可验证结果为准，不用综述翻转结论。
4. 本分区只补充检查动作，不单独作为“方法依据”。

## 校验问题

- 题型、问法、主体、时间和单位是否识别正确？
- 当前方法的触发条件是否真的出现？
- 是否存在不适用条件或更稳的验证路径？
- 结论能否通过原文回指、公式反算、边界检查或选项唯一性复核？
