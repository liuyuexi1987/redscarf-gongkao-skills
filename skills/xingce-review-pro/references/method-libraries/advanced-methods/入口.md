# 强化方法库入口

这是强化方法（AdvancedMethods）的方法库，用于讲解、复盘和溯源强化方法的方法。方法依据以方法论字段 + 卡片 id 作为来源锚点为准。

**这不是题库。** 如需词义辨析练习题，按包内 `references/question-banks/templates/` 导入用户自备题库。

## 调用规则

1. **优先按题型查**：先读题型协议的内联主卡，未命中再查 AdvancedMethods 题型索引；资料分析公式读取 DataNotes；XingceReview 只作二次校验与综述补充。
2. **必须下钻到具体卡**：模块分片中的 `主卡/别名` 路径已带 `方法卡/` 前缀；命中后按该相对路径读取具体卡（如 `方法卡/am-card-xxxx_*.md`），不得把裸文件名拼到 `advanced-methods/` 根目录。
3. **方法依据以卡片 id 为来源锚点**：以方法卡方法论字段 + 卡片 id 作为来源锚点支撑；输出方法依据摘要 + 卡片 id 作为来源锚点。
4. **低质量卡不得作为强依据**：confidence 为 low 的卡，不得作为“强化方法原方法”的强依据。可标注“疑似，待核实”。
5. **公开卡片字段**：发布包只保留答题所需的方法论字段；维护信息不进入公开方法卡。
6. **无覆盖时说清楚**：如果方法库没有覆盖用户问的题型或方法，必须明确说“方法库无依据”，不得用通用常识冒充强化方法。
