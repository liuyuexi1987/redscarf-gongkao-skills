# 方法卡：另有他因vs解释说明区分法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 另有他因vs解释说明区分法 |
| 适用题型 | 归因类论证题（支持/削弱） |
| 触发场景 | 题干给出因果关系（A导致B），选项看似在说另一个因素C |
| 步骤逻辑 | 1. 看选项中C因素与A因素的关系——是A导致C（链条关系）还是A和C并列存在；2. 若A→C→B（如玩手机→睡眠不足→情绪问题），这是**解释说明**，本质在解释因果链条，支持因果；3. 若A和C同时存在且互不导致（如长时间玩手机的人**同时**睡眠不足），这是**另有他因**，削弱因果；4. 关键判断：C因素是由A导致的？还是与A并列独立存在的？ |
| 高频错因 | 把解释说明（链条关系）误当成另有他因（并列关系），选错削弱项 |
| confidence | high |

## 不适用条件

1. 题干不涉及因果关系论证（如纯事实描述、定义判断）
2. 选项不是在讨论C因素与A因素的关系，而是直接否定因果链条
3. 问法为"前提假设"或"推理"而非支持/削弱

## 反向触发

1. 选项明确描述的是独立第三方因素C，与A无任何关联
2. 题干本身已明确说明多因素并存，考查的是因素优先级而非归因
3. 问"哪个选项能推出"，属于推出类而非归因论证
