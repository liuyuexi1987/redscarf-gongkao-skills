# 方法卡：或关系逆否规则

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 或关系逆否规则 |
| 适用题型 | 推理题中涉及"或"关系的逆否推理（逻辑判断） |
| 触发场景 | 条件为"若A或B则C"，需要逆否推理时 |
| 步骤逻辑 | 1. 原命题：若(A或B) -> C；2. 逆否命题：非C -> 非(A或B)；3. 非(A或B) = 非A 且 非B（德摩根律）；4. 规则：或关系的否定，前后都否，同时"或"变"且" |
| 高频错因 | 逆否时只否一个分支，忘记否另一个；把"或"的否定仍写成"或"而非"且" |
| confidence | high |
| 不适用条件 | 条件为"若A则C"（单条件命题，无"或"连接词）时，逆否直接是"非C则非A"，不需要德摩根律；条件为"若A且B则C"时，逆否是"非C则非A或非B"，"且"变"或"，规则方向相反 |
| 反向触发 | 对含"或"的条件做逆否后，推理结果与题目其他条件矛盾时，检查是否将"且"关系误判为"或"关系；条件为多层嵌套复合命题（如"若(A或B)且C则D"）时，本法仅处理单层"或"关系，需逐层拆解后分别应用对应规则 |
