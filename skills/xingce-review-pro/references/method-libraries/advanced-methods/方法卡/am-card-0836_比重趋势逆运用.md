# 方法卡：比重趋势逆运用

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 比重趋势逆运用 |
| 适用题型 | 资料分析——已知比重变化方向，反推各部分增速的大小排序或范围 |
| 触发场景 | 材料给了各部分占比的变化方向（如"东部占比由80.3%变为80.5%"或"比重上升了0.5个百分点"），要求判断哪个地区增速最快/最慢，或判断增速是否大于某值 |
| 步骤逻辑 | ① 看各部分的比重是上升、不变还是下降；② 比重上升 → R1 > R2（该部分增速大于整体）；比重不变 → R1 = R2；比重下降 → R1 < R2；③ 整体增速充当"桥梁"，通过各部分与整体的大小关系间接排定增速顺序（如东部>全国>西部 → 东部最快西部最慢）；④ 若题目还给了整体增速的具体数值，可直接判断部分增速的范围（如比重上升且整体增速26% → 部分增速 > 26%） |
| 高频错因 | ① 方向搞反：比重上升应对应"R1大于R2"而非"小于"；② 多个部分共用同一个R2（整体增速）时，误以为各部分R2不同；③ 已知整体增速具体值时，忘记结合趋势直接定位范围 |
| confidence | medium |

## 补充说明

与"比重趋势判断"互为逆命题。正向：已知R1和R2判断比重变化；逆向：已知比重变化反推R1与R2的关系。典型应用场景：给了各地区占比的同比变化，要求判断增速排序。"全国增速"是关键桥梁——不需求出具体值，只需利用它与各部分增速的大小关系做排序。

## 不适用条件

1. 材料只给了各部分的绝对量或增速，未给占比变化方向，无法用比重趋势反推。
2. 需要求出部分增速的具体数值时，仅靠比重变化方向只能定大小关系，不能定位数值。
3. 各部分之间不是"部分与整体"关系（如各品牌之间互相独立），整体增速不存在，无法做桥梁。

## 反向触发

1. 材料给了各部分占比的同比变化（"由X%变为Y%"或"上升/下降了N个百分点"），且题目要求判断增速排序或范围。
2. 已知整体增速的具体数值，结合占比变化方向可直接定位部分增速的范围。
3. 直接计算各部分增速缺乏数据（只有占比变化而无各部分绝对量），但通过趋势比较仍可作答。常见于快递业务量、进出口额、区域经济等"全国→分地区"的材料结构。
