# 方法卡：平均数增长率速算与方向判断

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 平均数增长率速算与方向判断 |
| 适用题型 | 资料分析——平均数增长率·快速判断结果方向和大致数值 |
| 触发场景 | 算出增速差后，需要判断结果比增速差大还是小，以及大致在哪个量级 |
| 步骤逻辑 | ① 先算增速差R1-R2（分子增速减分母增速，看带符号的实际值）；② 判断分母增速R2的正负：R2为正→结果的绝对值相对增速差缩小；R2为负→结果的绝对值相对增速差放大；③ 修正幅度随R2的绝对值增大而增大；④ 精确公式为(R1-R2)÷(1+R2) |
| 高频错因 | ① 用绝对值比较负增速导致增速差算反；② 忘记除以(1+R2)；③ 选项接近时仍只凭方向判断；④ 分子、分母增速口径不一致仍直接套公式 |
| confidence | high |

## 补充说明

平均数增长率=R=(R1-R2)÷(1+R2)。速算核心是先做差，再根据R2判断修正方向；当R2绝对值较小且选项差距足以容纳近似误差时，可用一阶近似：(R1-R2)÷(1+R2)≈(R1-R2)×(1-R2)。

## 不适用条件

- 分母增速R2的绝对值较大时，方向判断仍成立，但一阶近似误差增大，应精确计算
- 题目要求精确到小数点后一位或更高精度时，速判不够，需完整计算
- 分子分母的增速数据口径不一致时，不能直接做差

## 反向触发

- 看到“平均数增长率”且选项差距明显大于近似误差 → 可用本方法速判方向和量级
- 看到“平均数增长率”且选项接近 → 使用精确公式，本方法只作方向校验
- 看到"乘积增长率""间隔增长率" → 不用本方法，公式虽同源但触发场景不同
