# 方法卡：因果倒置力度最强——削弱首选因果倒置

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 因果倒置力度最强——削弱首选因果倒置 |
| 适用题型 | 削弱题（逻辑判断） |
| 触发场景 | 题干建立了"A导致B"的因果关系，选项给出"B导致A"的可能性 |
| 步骤逻辑 | 1. 识别题干因果方向：A（因）→ B（果）；2. 检查选项是否给出了相反的因果方向：B（因）→ A（果）；3. 因果倒置彻底否定了"A是B的原因"这一可能性，力度最强；4. 在多个削弱选项中，因果倒置 > 他因削弱 > 举例削弱 > 类比削弱 |
| 高频错因 | 把因果倒置和他因混淆看到力度最强的削弱方式就忽略其他限制条件（如时间不一致） |
| confidence | high |

## 补充说明

- 因果倒置（如"记忆缺陷导致肥胖"而非"肥胖导致记忆缺陷"）彻底否定原因果方向，力度最强。
- 他因（如"肥胖的人海马体也小"）只是引入平行变量，力度弱于因果倒置。
- 力度排序：因果倒置 > 他因 > 举例/类比。
- 注意：因果倒置必须发生在同一时间框架内；若时间不一致，反向论述可能是无关项而非因果倒置。

## 不适用条件

- 题干因果关系发生在明确的先后时间序列中（如先A后B、B不可能导致A），因果倒置不成立。
- 题目问"最能支持/加强"时，因果倒置是削弱手段，不适用。
- 因果倒置选项与题干涉及的变量不完全重合（偷换了变量），不属于真正的因果倒置。

## 反向触发

- 当因果倒置选项存在时间不一致疑点时，优先检查是否为无关项，不要默认为因果倒置。
- 当题干结论为纯统计相关（未断言因果），优先用"关联性不等于因果性"方法，不必用因果倒置。
- 当多个削弱选项力度接近且无法确认因果方向时，改用否定代入法或比较覆盖范围再择优。
