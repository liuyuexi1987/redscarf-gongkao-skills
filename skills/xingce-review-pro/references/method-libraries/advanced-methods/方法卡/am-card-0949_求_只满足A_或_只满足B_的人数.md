# 方法卡：求"只满足A"或"只满足B"的人数

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 求"只满足A"或"只满足B"的人数 |
| 适用题型 | 题目问"只做对第一题""只喜欢唱歌"等 |
| 触发场景 | 已知总人数、两个集合大小、重叠人数，求只满足一种的人数 |
| 步骤逻辑 | 1. 先求出重叠人数（既A又B）；2. 只A = |A| - 重叠人数；3. 只B = |B| - 重叠人数 |
| 高频错因 | 直接用|A|作为"只A"的人数，忘记减去重叠部分 |
| confidence | high |

## 补充说明

满足某集合的总人数 = 既满足A又满足B的人数 + 只满足该集合的人数；据此可由该集合总人数和重叠人数反推只满足该集合的人数

## 不适用条件

- 三集合容斥求"只满足一个"时不适用本双集合公式
- 未先求出重叠人数时不能直接套用

## 反向触发

- 三集合场景应改用三集合容斥公式分解
- 题目问"既A又B又C"时，应改用三集合交集公式
