# 方法卡：调和平均数快速判断蒸发/加水后浓度

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 调和平均数快速判断蒸发/加水后浓度 |
| 适用题型 | 等量蒸发或等量加水，给出两次浓度求第三次 |
| 触发场景 | 题目给出连续两次等量蒸发/加水后的浓度，求下一次浓度 |
| 步骤逻辑 | 1. 记住高频数据组合：10-12-15、20-25-30-60、12-15-20、24-30-40 等；2. 这些数满足调和平均数关系（可写成60÷整数的形式）；3. 看到10%→12%直接接15%；20%→25%直接接30%→60%；4. 反向加水则逆序 |
| 高频错因 | 死记数据但不理解原理，遇到非常规数据无法判断 |
| confidence | high |
| 不适用条件 | ['每次蒸发或加水的量不同，浓度序列不满足调和关系，速记数据失效。', '题目给出的浓度数据不在常见整数组合中，无法直接套用速记模式。'] |
| 反向触发 | ['题目要求求具体溶液质量、溶质质量或加水量，而非快速判断下一组浓度。', '题目涉及多种溶液混合而非同一种溶液反复蒸发或加水。'] |

## 补充说明

此方法本质是"偏记住"的速算技巧，出题人偏好使用这些整数数据
