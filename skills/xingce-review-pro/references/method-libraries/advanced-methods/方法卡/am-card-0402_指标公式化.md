# 方法卡：指标公式化

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 指标公式化 |
| 适用题型 | 资料分析——材料未直接给出所问指标，需用其他已知量表达 |
| 触发场景 | 找所问指标在材料中不存在，但存在相关的收入、利润率、增速等可组合信息 |
| 步骤逻辑 | ① 找所问指标，判断有/没有；② 没有时，想该指标可由哪些材料信息表示（如 利润 = 收入 × 利润率）；③ 用相关量列式代入计算；④ 判断题型（求值/比较升降/求增速等）选择对应运算 |
| 高频错因 | 找不到指标就放弃或乱猜；不知道利润率 = 利润/收入这类基本表达式；求升降时误用双线法等不匹配的方法 |
| confidence | high |

## 补充说明

本方法强调的做题总框架：找所问指标 → 有则直接用，没有则指标公式化（找相关信息表达）。利润率 = 利润/收入，所以求利润 = 收入 × 利润率。"每百元收入中的成本" = 成本/收入 × 100。求乘积升降时用乘积增长率公式 rA+B = rA + rB + rA×rB 判断正负即可。

## 不适用条件

- 所问指标在材料中已直接给出，可直接读取计算时
- 所需组合关系涉及三个及以上变量的交叉乘除，公式化后过于复杂易出错时，应考虑代入法或排除法
- 题目选项均为"无法判断""信息不足"等元选项时，应先判断信息完整性而非公式化

## 反向触发

- 当组合公式涉及乘积增长率 rA+B = rA + rB + rA×rB 判断升降时，如果 rA 和 rB 一正一负且数值接近，交叉项不可忽略，应代入具体数值验证方向，不可仅凭 rA + rB 的正负判断
- 当公式化过程中发现两个候选表达式的计算结果不一致，应重新检查变量对应关系（如分子分母是否颠倒、百分比与小数是否混淆），不可直接取整数位近似
- 当题目同时涉及"同比"和"环比"的指标组合时，需明确分子分母对应的时间窗口，不可混用不同周期的增长率
