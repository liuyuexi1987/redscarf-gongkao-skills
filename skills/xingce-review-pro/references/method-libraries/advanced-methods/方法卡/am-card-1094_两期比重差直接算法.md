# 方法卡：两期比重差直接算法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 两期比重差直接算法 |
| 适用题型 | 资料分析——两期比重差 |
| 触发场景 | 题目问"比重上升/下降了多少个百分点" |
| 步骤逻辑 | ① 先判断正负：R部分>R整体→比重上升（正），反之下降（负）；② 可以直接算两年比重做差；③ 也可以套公式：现期比重×(R部分-R整体)/(1+R部分)；④ 选项差距大时用估算法；⑤ 注意"百分点"vs"%"：两期比重差用"百分点" |
| 高频错因 | ① 正负判断错→排除错误选项后选了反向的；② 混淆"百分点"和"%"→计算结果对但单位错 |
| confidence | high |

## 补充说明
两期比重差是资料分析高频考点。两种做法：直接算两年比重做差（简单直观）或套公式（快速但需记公式）。正负判断是第一步，也是最关键的一步。

## 不适用条件

- 题目未给出部分增长率或整体增长率且无法估算时，公式法无法直接套用。
- 部分与整体的基期比重未知且无法估算时，直接做差法缺少必要数据。

## 反向触发

- 公式法结果与直接做差法结果不一致时，应换用第三种方法（如代入选项验证）补充核验。
- 正负方向与选项结构冲突时（如所有选项都是正数但判定为下降），应回查增长率的正负与大小关系。
