# 方法卡：最不利原则（运气最差情况+1）

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 最不利原则（运气最差情况+1） |
| 适用题型 | 求"至少拿几个才能保证拿到N个相同颜色/类型" |
| 触发场景 | 题目出现"至少""保证""最多需要多少次"等关键词 |
| 步骤逻辑 | 1. 确定格子数（颜色数/类型数）；2. 确定需要达到的层数（如拿到6个相同颜色=第6层）；3. 最不利情况 = 先铺满下面（目标层数-1）层；4. 注意特殊情况：某些格子可能铺不满（如只有4个红色球，铺不到第5层）；5. 答案 = 最不利情况 + 1 |
| 高频错因 | 忘记"+1"（最后一根稻草）；没注意某些格子数量有限的特殊情况 |
| confidence | high |

## 补充说明

"至少"和"至多"在此类问题中是同一个临界点——至多需要X次保证，至少需要X次保证

## 不适用条件

1. 题目问"平均需要多少次"或"期望次数"（属于期望计算，非最不利原则场景）。
2. 题目未出现"保证"等强制条件，仅问"取一次可能取到什么"等概率事件，不涉及临界值。
3. 各格子容量充足且无差异时，直接用抽屉原理公式 n÷m 即可，无需构造最不利情况。

## 反向触发

1. 当题目明确求"概率"而非"保证次数"时，应换用古典概型或条件概率方法。
2. 当需要构造的并非"最不利情况"而是"最有利情况"（如"最少取几次可能拿到"）时，使用最有利原则而非最不利原则。
3. 当格子容量不一致且涉及多层铺设时，应配合抽屉原理识别"物品/格子"角色后再使用本方法，否则易漏算特殊情况。
