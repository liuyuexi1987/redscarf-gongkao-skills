# 方法卡：误差分析与量级判断

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 误差分析与量级判断 |
| 适用题型 | 资料分析——所有需要估算、判断结果量级或选项能否区分开的计算题 |
| 触发场景 | 选项差距较大但不确定估算能否选对；需要判断结果是几百还是几千；汇率/单位换算后判断量级是否合理 |
| 步骤逻辑 | 误差分析：① 估算误差 = 近似值与真实值的差距（如380看成330，误差约15%）；② 选项差距 = 相邻选项之间的比例差；③ 若估算误差远小于选项差距，直接用估算结果选答案。量级判断：① 方法一根据原式估算量级；② 方法二根据生活常识判断（如外国人消费水平约为国内3倍左右，不可能0.3或30） |
| 高频错因 | 估算后不敢选，实际误差只有10%但选项差50%以上；不会用生活常识辅助判断量级；汇率单位混用导致量级错误 |
| confidence | high |
| 不适用条件 | 选项间距极小需要精确到小数位或特定百分点时，仅凭量级判断无法区分；题目涉及多步乘除混合运算且中间结果量级不确定时，需列出算式逐步计算而非靠常识估计 |
| 反向触发 | 估算或量级判断后仍有多个候选选项无法确定答案时，立即改用精确计算；涉及百分点、倍数关系等需要精确到单位的题，量级判断只能排除极端项，不能直接确定答案 |

## 补充说明

示例：算出结果约3.3，估算误差约10~20%，即使往大了说20%的误差也只有约4，远到不了选项的5，所以直接选"不到5"。量级判断的第二种方法来自生活实际——入境游客平均消费不可能是国内游客的0.3倍（太少）也不可能是30倍（太多），只能是3倍左右的选项。
