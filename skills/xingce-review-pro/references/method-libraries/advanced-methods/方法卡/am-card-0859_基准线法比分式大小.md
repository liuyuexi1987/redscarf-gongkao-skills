# 方法卡：基准线法比分式大小

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 基准线法比分式大小 |
| 适用题型 | 资料分析——两个分式都接近某个常用值（如1、1/2）时的大小比较 |
| 触发场景 | 两个分式数值都靠近同一个基准值（如都接近1或都接近50%），直接比大小不直观 |
| 步骤逻辑 | ① 选定基准值（如1、1/2等）；② 分别计算两个分式到基准值的距离（做差）；③ 距离基准值越远的分式，在基准值同侧时更大或更小（需判断方向） |
| 高频错因 | ① 忘记判断分式在基准线的哪一侧（上方还是下方）；② 距离大不一定意味着值大，需结合方向 |
| confidence | high |

## 不适用条件

- 两个分式不接近任何常用基准值（如1、1/2、50%等）
- 分式差距明显，可直接通过分子分母大小关系判断

## 反向触发

- 分子分母大小关系一目了然（如一个分子大且分母小）
- 两个分式离基准值都很远，做差后仍不直观

## 补充说明

原理类似比身高：正面差距不明显时，换到平均线看差距立刻清晰。适用范围较窄，仅当分式靠近常用好算数值时使用。
