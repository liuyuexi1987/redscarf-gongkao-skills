# 方法卡：递进升华方向法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 递进升华方向法 |
| 适用题型 | 言语理解-中心理解题（说理类文段）、语句填空题 |
| 触发场景 | 文段呈现"小切口→中层次→大升华"的逐层递进结构，题目要求选出最终结论或填入最后一层 |
| 步骤逻辑 | 1. 识别文段中的递进层次：小（具体切入点）→中（扩展层面）→大（升华层面）；2. 结论句必须在中层基础上做"更大的升华"，不能回到小层或中层；3. 排除任何"回落"到前文已提内容的选项；4. 升华内容不必在原文中逐字出现，仅在原文存在明确价值或因果指向时考虑上位概括 |
| 不适用条件 | 1. 非递进结构文段（并列、转折、总分等）不适用；2. 文段结论本身回顾或总结前文各层时，不强制要求"升华" |
| 高频错因 | 选了跟前文重复的选项（回落到小层或中层）；误认为升华内容是"无中生有"而排除正确选项 |
| confidence | high |

> **使用边界**：本方法用于提供优先检查方向，不可单独据此作答；最终需回到题干关系、原文证据或选项条件完成验证。

## 不适用条件

- 非递进结构文段（并列、转折、总分等）不适用
- 文段结论本身回顾或总结前文各层时，不强制要求"升华"
- 题目仅考查局部信息匹配（如细节判断题），不需要把握整体方向

## 反向触发

- 当文段结构为"提出问题→多角度分析→总结回顾"时，结论更可能是回顾式总结而非递进升华
- 当所有选项均在原文同一层次内时，应逐项比对原文细节而非追求升华方向
- 当文段存在明显转折词（但、然而、不过）时，结论方向由转折后内容决定，不走递进路径
