# 方法卡：追击思路（比增速快慢）

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 追击思路（比增速快慢） |
| 适用题型 | 资料分析-判断两组数据谁增速更快（无需算出具体增速） |
| 触发场景 | 题目问"某段时间内 A 的增速快于 B 的增速"，材料给的是柱状图或折线图，两组数据走势可见 |
| 步骤逻辑 | 1. 逐年/逐月观察两组数据的差距变化；2. 差距在缩小 → 后面的在追赶 → 后面的增速更快；3. 差距在扩大 → 前面的在拉开 → 前面的增速更快；4. 出现反超 → 反超方增速更快；5. 把每一年/月的"谁快"标记出来，对照题目要求筛选即可；6. 全程不需要算增速百分比，只看相对关系 |
| 高频错因 | 习惯性去算百分比再比较，浪费时间忽略"反超"这个关键信号，只看数值大小 |
| confidence | high |

## 不适用条件

1. 题目要求算出具体的增速百分比，追击思路只判断快慢无法给出数值
2. 两组数据量级差距悬殊（如一个在百位一个在万位），绝对差距变化不反映增速快慢

## 反向触发

1. 材料只有一期数据（无时间序列），不存在"追赶/拉开"的判断基础
2. 题目问的是"增速是多少"而非"谁增速更快"
