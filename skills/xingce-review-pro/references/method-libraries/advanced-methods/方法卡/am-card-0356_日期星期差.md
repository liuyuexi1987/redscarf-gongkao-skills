# 方法卡：日期星期差计算
## 基本信息
| 字段 | 值 |
|------|-----|
| 方法名 | 日期星期差计算 |
| 适用题型 | 数量关系-日期问题/两天同星期/跨月推算 |
| 触发场景 | 已知两天都是星期X，且知道日期和或差，求具体日期 |
| 步骤逻辑 | 1.同星期→天数差=7的倍数 2.跨月天数差=30×跨月数+大月修正(31天月加1)+日期差(Y-X) 3.令该表达式=7k，枚举合理的k值 4.联立X+Y=已知值求解，验证X、Y为正整数且在合法日期范围内 |
| 高频错因 | 大月修正遗漏（3月/5月/7月/8月/10月/12月为31天，跨过时要加1）；天数差公式中日期差方向写反；k值枚举范围过大或过小 |
| confidence | high |
| 不适用条件 | 1. 题目只问某一天是星期几，不需求具体日期数值\n2. 涉及闰年二月且题干未说明是否闰年，天数差可能差1天 |
| 反向触发 | 1. 题目问"某日是星期几"而非求日期数值，直接用"天数差为7的倍数"反推即可，无需联立方程\n2. 两个日期跨越闰年2月且无法确定是否闰年时，需先判断闰年再代入，否则天数差可能错1 |
## 补充说明
本方法的"先粗算后修正"口诀：(1) 先按每月30天粗算；(2) 对31天的月份逐一加1修正；(3) 加上日期差Y-X。示例：3月X日到4月Y日=30(粗算)+1(3月31天)+Y-X=31+Y-X。联立X+Y=32，设31+Y-X=49→Y-X=18→Y=25, X=7。验证：3月7日到4月25日=31+18=49天=7×7，符合。
