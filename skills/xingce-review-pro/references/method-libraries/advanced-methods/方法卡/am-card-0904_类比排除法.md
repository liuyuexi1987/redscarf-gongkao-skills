# 方法卡：类比排除法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 类比排除法 |
| 适用题型 | 判断推理——类比推理 |
| 触发场景 | 有不认识的词/成语，不确定答案 |
| 步骤逻辑 | ① 先看能判断的选项，排除明显不对的；② 剩下的选项即使不认识，排除不掉就选它；③ 不认识的词可以通过"其他都被排了所以只能选这个"来确认 |
| 高频错因 | ① 遇到不认识的词就放弃；② 没有利用排除法 |
| confidence | medium |

## 补充说明

类比推理的核心是"找最像的"。当某个词不认识时，只要其他选项能通过已知关系排除，剩余选项即可作为候选答案锁定。

## 不适用条件

- 所有选项均不认识、无法启动排除时，本方法不适用。
- 题干关系明确、选项可直接匹配无需排除时，本方法不适用。
- 题干是成语拆字结构需结构分析时，应换用拆字近义法。

## 反向触发

- 当多个选项无法通过排除区分时，应换用语义近义辨析做关系匹配。
- 当选项间存在程度或褒贬差异时，应补用二级辨析方法。
- 当排除后剩余两项仍无法决断时，应回到题干重新核验语义关系。
