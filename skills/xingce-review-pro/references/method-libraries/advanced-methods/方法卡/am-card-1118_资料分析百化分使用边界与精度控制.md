# 方法卡：资料分析百化分使用边界与精度控制

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 资料分析百化分使用边界与精度控制 |
| 适用题型 | 资料分析——涉及增长率的乘除运算，如增长量、基期量和比重差 |
| 触发场景 | 增长率接近熟悉的简单分数，需要判断能否用分数近似简化计算 |
| 必要输入 | 原增长率、候选分数、计算目标、选项间距或可接受误差 |
| 步骤逻辑 | ① 找到与增长率接近且便于计算的简单分数；② 计算或判断替换误差及方向；③ 估计误差传到最终结果后的影响；④ 与相邻选项间距比较；⑤ 误差不会改变选项时使用百化分，否则直除或精算 |
| 验证动作 | 用原增长率反代候选答案，或给出结果上下界，确认真实值与近似值仍落在同一选项范围 |
| 不适用条件 | 增长率没有简洁分数对应；近似误差经过公式传递后可能跨越选项；多步估算会叠加误差；题目要求精确值 |
| 反向触发 | 无法判断误差方向或上界时停止百化分，改用直除、反乘验证或精算；选项越接近，越要先验证误差而不是套固定阈值 |
| 高频错因 | 只因“约为”就粗估；记住分数对应却不看选项差距；不判断误差方向；多步近似叠加后仍按单步精度作答 |
| confidence | high |

## 常用对应

常见分数与百分数的准确或近似对应可以作为计算工具，例如二分之一、三分之一、四分之一、八分之一等。是否采用某个对应，不由增长率本身单独决定，而由“近似误差会不会改变最终选项”决定。

## 使用流程

1. **建立候选分数**：选择自己熟悉、运算明显更简洁的分数。
2. **判断误差方向**：比较候选分数与原增长率的大小，确定结果会偏大还是偏小。
3. **估计结果误差**：把增长率误差代入当前公式，关注最终量的变化，而不是只看增长率相差多少。
4. **对照选项间距**：若真实结果可能落到相邻选项，继续修正或改用精算。
5. **完成反代验证**：用原增长率检查候选答案能否还原题面数据。

## 使用边界

百化分是计算路径，不是固定精度规则。选项差距、公式敏感度和误差叠加情况不同，同一个近似在不同题里可能分别可用或不可用。不得用固定百分比区间替代误差判断。
