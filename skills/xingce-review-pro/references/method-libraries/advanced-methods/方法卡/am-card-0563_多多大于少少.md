# 方法卡：多多大于少少

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 多多大于少少 |
| 适用题型 | 判断推理——多维度划分类推理题（"由此可以得出"类问法） |
| 触发场景 | 总量固定，从两个维度对同一集合进行划分（如借阅/自购 × 中文/英文），且每个维度内部都是矛盾关系（非此即彼、无剩余） |
| 步骤逻辑 | ① 画出二维表格，填入已知数量；② 确认两个划分维度各自是矛盾关系（总量恰好被完全划分，无"其他"）；③ 找出两个维度中"多"的一方，交叉得到"多多"；找"少"的一方，交叉得到"少少"；④ 恒成立结论：多多 > 少少 |
| 高频错因 | 在维度不构成矛盾关系（有剩余类别）时误用此法；维度数量加总不等于总量时仍套用 |
| confidence | high |

## 补充说明

当两个维度各自构成矛盾关系（总量被完全划分，无剩余）时，"多多"（两维度中多的一方交叉）恒大于"少少"（两维度中少的一方交叉），差值恒为两维度差值之和。

一般化推导：总量N，维度一划分为A与B（A>B），维度二划分为C与D（C>D），则"AC"（多多）恒大于"BD"（少少），差值恒为(A-B)+(C-D)。

若划分不完整（某一维度加总不等于总量，说明存在其他类别），此法不适用。

## 不适用条件

- 两个维度不构成矛盾关系（存在"其他"剩余类别）时不适用。
- 维度数量加总不等于总量时（数据不一致或划分标准有遗漏）不适用。
- 题目问法不是"由此可以得出"的恒成立结论，而是要求比较具体数值时，需精算而非套用此法。

## 反向触发

- 当维度内部是反对关系而非矛盾关系（存在第三类）时，应换用精算或补全类别后再比较。
- 当题目要求的是"最多""最少"而非"恒成立的大小关系"时，应换用极值分析法。
- 当总量未知或维度划分不明确时，应先确认数据完整性，再决定是否套用此法。
