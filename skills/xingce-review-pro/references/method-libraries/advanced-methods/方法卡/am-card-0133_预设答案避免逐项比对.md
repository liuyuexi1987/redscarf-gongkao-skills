# 方法卡：预设答案方向避免逐项比对

## 基本信息

| 字段 | 值 |
|---|---|
| 方法名 | 预设答案方向避免逐项比对 |
| 适用题型 | 言语理解-中心理解题 |
| 触发场景 | 已确定文段主旨，即将进入选项筛选阶段 |
| 必要输入 | 已从文段结构分析中确定的主旨或答案方向 |
| 步骤逻辑 | 1. 根据文段结构类型预设答案方向：转折结构→预设转折后内容；对策类→预设对策表述；并列结构→预设共性概括 2. 用预设方向快速扫描四个选项，形式或方向不符的直接排除 3. 不逐个详细分析每个选项"为什么对、为什么错"——这是细节判断题的做法 4. 仅在剩余2个以上选项时做最终比较（可参考"主旨匹配三维筛选"） |
| 验证动作 | 剩余选项仍多时，使用三维筛选（比形式→比针对性→比论证支撑）做最终决策 |
| 不适用条件 | 主旨尚未确定时不应跳到选项筛选；细节判断题、推断题等需逐项核对原文的题型不适用此法 |
| 高频错因 | 1. 不预设方向，逐个分析选项，把中心理解题做成细节判断题，浪费时间且易被无中生有选项迷惑 2. 预设方向过窄（如只想到"对策"），导致排除了形式不同但实质正确的选项 3. 对无中生有选项仍花时间去原文逐句搜索验证 |
| confidence | high |
| 反向触发 | 1. 预设方向扫描后仍剩余3个以上选项无法排除时，说明预设方向过窄或文段主旨判断有误，应回到文段重新分析结构再重新预设 2. 当文段结构为非典型（如隐性转折、多层嵌套）导致无法明确预设方向时，应切换为逐项核对原文的细节比对法 |

---

> **使用边界**：本方法用于提供优先检查方向，不可单独据此作答；最终需回到题干关系、原文证据或选项条件完成验证。
