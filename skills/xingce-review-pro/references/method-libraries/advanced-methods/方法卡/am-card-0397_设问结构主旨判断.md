# 方法卡：设问结构主旨判断

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 设问结构主旨判断 |
| 适用题型 | 中心理解题（主旨大意） |
| 触发场景 | 文段开头为设问句（如"XX如何影响YY？"），后文为对该问题的回应 |
| 步骤逻辑 | 1. 识别开头是否为设问（提出问题）；2. 设问本身已框定主旨方向——后文回应的就是主旨；3. 选择能概括"回应内容"的选项 |
| 高频错因 | 选了只提"问题"而非"回应"的选项选了回应中的某个细节而非整体回应 |
| confidence | high |

## 不适用条件

- 开头问句不是设问（没有后文对其回应），而是疑问或反问
- 文段设问后没有给出明确回应，后文转入了新话题
- 开头问句只是引子，文段重心在后文的分析或结论，而非对问句的直接回应

## 反向触发

- 若后文对设问的回应不完整或分散在多个段落，主旨可能不是简单的"回应内容"，应回看文段末尾是否有总结性表述
- 若设问后文出现"其实""然而"等转折信号，说明文段的重点不在设问的回应本身，而在转折后的内容
- 若选项中同时存在"提问题"和"给回应"两类表述，应选回应类；但若文段回应部分过于分散且文段末尾有总结，应选总结性选项而非回应细节
