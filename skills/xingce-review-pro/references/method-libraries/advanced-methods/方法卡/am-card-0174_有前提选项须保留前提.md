# 方法卡：有前提选项须保留前提

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 有前提选项须保留前提 |
| 适用题型 | 言语理解——片段阅读（细节判断、主旨题） |
| 触发场景 | 原文结论附带前提条件（"如果……""在……情况下"），选项去掉前提直接给出结论 |
| 步骤逻辑 | ① 识别原文结论是否带有前提条件（如"如果C不变""在……条件下"）；② 若选项将前提省略、直接给出结论，该选项犯了"无中生有扩大范围"的逻辑错误；③ 排除去掉前提的选项 |
| 验证动作 | 将被省略的前提代回选项，检查结论是否仍然成立；若前提对结论有约束作用，则选项不成立 |
| 高频错因 | 看到选项和原文末句内容相似就选，忽略前提条件被省略；不理解前提条件对结论的约束作用 |
| confidence | high |
| 不适用条件 | 选项对前提做了合理同义替换而非省略时，不构成排除理由；原文多个前提嵌套而选项只省略了其中一层约束时，需分层判断省略的那层是否影响结论成立 |
| 反向触发 | 选项保留了前提但语义范围仍与原文不一致（前提本身被改写或缩放）时，应精算验证；原文前提与结论为必要条件而非充分条件关系时，即使保留前提也不能直接确认选项正确，需回到原文核实逻辑关系 |


> **使用边界**：本方法用于提供优先检查方向，不可单独据此作答；最终需回到题干关系、原文证据或选项条件完成验证。
