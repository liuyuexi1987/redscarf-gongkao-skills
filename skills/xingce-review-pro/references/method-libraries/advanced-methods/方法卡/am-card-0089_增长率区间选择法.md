# 方法卡：增长率区间选择法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 增长率区间选择法 |
| 适用题型 | 资料分析-根据增长率大小选择不同速算方法 |
| 触发场景 | 拿到一个增长率，需要快速决定用哪种方法计算增长量或基期 |
| 步骤逻辑 | 1. **增长率 r ≤ 0（下降）**：用化除为乘，基期 B₀ ≈ B×(1−r)，误差为 r² 量级，r 绝对值越小越准；2. **0 < r ≤ 20%**：用假设分配法，把 r 拆成整数百分数分段（如 15% 拆为 10% + 5%），分别乘后累加；3. **r 接近简单分数（1/3、1/4、1/5 等）**：直接用分数关系估算（如 r=25% 即 1/4，增量 ≈ 现期÷5，基期 ≈ 现期÷1.25 = 现期×4÷5）；4. **r 较大且接近整十百分数**：拆整再修正（如 r=38% 拆为 40%−2%）；5. 实战中增长率集中在 5%~20%，假设分配法覆盖最多场景 |
| 高频错因 | 不区分区间，所有题都用同一种方法；增长率很小时硬用直接除法，浪费时间 |
| confidence | high |

## 不适用条件

- 题目要求精确到选项才能判断答案时，选方法不如直接计算
- 增长率很小、一阶近似误差不会影响选项判断时，直接用 B₀≈B×(1−r) 即可
- 区间范围仍覆盖多个选项、无法形成有效排除时，应直接套公式

## 反向触发

- 当已选定方法但计算量仍然很大时，应考虑换用直除法一步到位
- 当题目直接求基期值且增长率很简单（如10%整）时，直接用 B₀=B÷(1+r) 心算即可
- 当增长率恰为负值且接近0%时，化除为乘的方向需特别注意（负负得正），容易算反
