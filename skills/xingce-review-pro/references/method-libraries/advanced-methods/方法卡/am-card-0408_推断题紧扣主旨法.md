# 方法卡：推断题紧扣主旨法

## 基本信息

| 字段 | 值 |
|---|---|
| 方法名 | 推断题紧扣主旨法 |
| 适用题型 | 言语理解——推断最准确题（非下文推断、非简单细节判断） |
| 触发场景 | 题干问"推断最准确的是"，四个选项均为比较类或需要推理的表述 |
| 步骤逻辑 | ① 先明确文段主旨和作者核心观点；② 排除与文段主旨话题无关的选项——即使该选项在常识层面"有道理"，只要作者在文段中未讨论该话题，就不选；③ 在剩余选项中，选择推理链最短、直接对应主旨的选项——推理链越短越"准确" |
| 不适用条件 | 不适用于下文推断题（看尾句顺延）、简单细节判断题（逐项比对原文） |
| 高频错因 | 选了语感上"有道理"但与文段主旨无关的推断；误认为推理链越长、越"深刻"的选项越"准确" |
| confidence | high |
| 反向触发 | 所有选项都紧扣主旨无法区分时，需回到文段逐句比对选项与原文的具体表述，看哪个对应更精准而非只看主旨方向；当剩余选项推理链长度相近时，检查每个选项是否引入了原文未提及的新信息，引入新信息越多的选项越不"准确" |
