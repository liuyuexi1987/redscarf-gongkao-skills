# 方法卡：历程类选项识别与匹配

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 历程类选项识别与匹配 |
| 适用题型 | 主旨题/中心理解题 |
| 触发场景 | 文段有明显时间词（改革开放以来/以往/现在/未来），描述事物变化过程 |
| 步骤逻辑 | 1)文段出现时间词或变化描述时，判断为历程类文段 2)历程类选项应体现"变化"特征（如"XX促使YY发展"） 3)只讲其中一个时间点/阶段的选项是片面选项 4)并列的多个变化部分需用"社会变迁"等概括词统一 |
| 高频错因 | 文段讲了多阶段变化，选项只对应其中某一个阶段就选了（片面选项） |
| confidence | medium |

## 不适用条件

1. 文段虽有时间词但核心是在分析原因或提出对策时，不按历程类处理
2. 文段只有单一时间点描述而无变化过程时，不构成历程类

## 反向触发

1. 若文段有明确对策句，配合"原文对策选对策"方法
2. 若选项出现因果表述，配合"原因类选项反推验证法"
3. 若历程描述是文段的背景或铺垫而非核心，需回到文段整体结构判断主旨
