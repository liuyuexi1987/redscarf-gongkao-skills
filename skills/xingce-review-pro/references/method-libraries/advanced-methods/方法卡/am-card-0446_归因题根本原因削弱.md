# 方法卡：归因题根本原因削弱

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 归因题根本原因削弱 |
| 适用题型 | 削弱论证——结论出现"根本原因"等限定词 |
| 触发场景 | 归因结论中出现"根本/根源/最根本"等程度限定，问法为"最能削弱" |
| 步骤逻辑 | ① 识别结论中的"根本原因"限定词；② 向"根儿"的方向找选项——找到比题干原因更深层的原因即可削弱；③ 核心逻辑：题干说A是根本原因，选项说B→A（B促进了A），则A不是根，B才更像根 |
| 高频错因 | 忽视"根本"限定词，按普通归因题选"另有他因"；选了"还有其他原因也是原因"的选项（如D：工业化也是原因），但这只能说明不唯一，不能否定根本性 |
| confidence | high |

## 补充说明

典型选项对比：选项中出现"X促进了Y，进而带动Z"这类更深层因果链（B→A→结果）时，说明原结论认定的A并非根本原因，削弱力度最强；选项中出现"另一因素也是原因"时，仅说明原因不唯一，但不否定根本性，削弱力度较弱。关键区分：程度副词（根本/主要/往往）出现时，削弱方向要对应该限定词——问"根本"就找更深层的原因，问"主要"就找反例或更主要的原因。

## 不适用条件

- 结论中没有“根本、主要”等程度限定词时，应按普通归因削弱处理，比较另有他因、否定此因和因果倒置中哪项最直接针对论证
- 题干问法为"最能加强"或"解释"而非"削弱"时，本法不适用
- 结论为数据型归因（如"增长率提高是因为基数变化"）而非定性归因时，需用数值分析而非深层因果比较

## 反向触发

- 若选项描述的深层原因（B→A）在题干中已有明确提及或暗示，则该选项不构成新信息，削弱力度有限，应检查是否有其他未被覆盖的更深层原因
- 若所有选项都是"另有他因"型（只说另一因素也起作用），没有一个选项呈现更深层因果链，说明本题可能不适用"根本原因削弱"，应退回普通削弱思路比较各因重要性
