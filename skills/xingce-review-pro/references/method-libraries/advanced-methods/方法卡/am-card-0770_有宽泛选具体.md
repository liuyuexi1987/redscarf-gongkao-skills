# 方法卡：有宽泛选具体

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 有宽泛选具体 |
| 适用题型 | 片段阅读-中心理解题/标题拟定题 |
| 触发场景 | 两个选项内容都对，一个宽泛概括一个具体展开 |
| 步骤逻辑 | 1. 一般有宽泛的和具体的，都选具体；2. 具体选项能把原文的核心内容说清楚，宽泛选项可能只是标签；3. 例："发现了关键致病机理"（宽泛）vs"基因突变导致酸性失衡或诱发帕金森"（具体）→ 选具体；4. 但如果具体选项本身有错（无中生有/过度推断），则退而选宽泛 |
| 高频错因 | 被宽泛选项的"正确感"吸引，觉得不会错就选了，但其实没说清楚原文内容 |
| confidence | medium |

## 不适用条件

1. 具体选项本身有错误（无中生有、过度推断、偷换概念），不能因为"具体"就忽视其错误
2. 题目问的是文段主旨或整体概括，原文覆盖面很宽，此时宽泛概括可能更合适
3. 两个选项的宽泛/具体程度相当，不存在明显区分

## 反向触发

1. 具体选项虽然具体，但表述的范围比原文窄或偏——此时宽泛但准确的选项更优
2. 多个选项都有具体细节，需要比较哪个细节才是文段的核心重点
