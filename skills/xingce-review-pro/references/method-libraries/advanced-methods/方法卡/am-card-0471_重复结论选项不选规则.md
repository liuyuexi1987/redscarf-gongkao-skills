# 方法卡：重复结论选项不选规则

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 重复结论选项不选规则 |
| 适用题型 | 判断推理 > 支持/质疑（力度比较） |
| 触发场景 | 选项内容与题干结论高度重合（换了说法本质一样）；需区分支持题和质疑题 |
| 步骤逻辑 | 1. 最能支持题：重复论据/重复结论的选项一般不选，力度不够，通常有更强选项；2. 不能支持题：重复结论虽力度弱，但仍算"有一定支持力度"，强于无关项（无关=0），一般也不选；3. 类比支持：通过举例类比来支持，力度也弱，最能不能支持题和不能支持题一般都不选；4. 关键区分：弱力度（有）vs 无关项（零），不能支持题应选无关项而非弱力度 |
| 高频错因 | 把"重复结论不能选"死记硬背，不区分支持题和质疑题的语境 |
| confidence | high |

## 不适用条件

1. 加强/支持题中，当所有选项力度都偏弱且无更强选项时，重复结论虽弱但仍可能成为相对最优。
2. 论证结构题（问"以下哪项论证方式与题干最相似"），重复结论与力度无关，应按结构匹配判断。
3. 题干本身为纯逻辑推理（如数学/排列），选项是否重复结论不影响逻辑有效性判断。

## 反向触发

1. 质疑题中出现"不能质疑"时，应选无关项（力度为零），而非重复结论（力度虽弱但非零）。
2. 题干论据本身不充分且选项未提供新信息时，重复结论可忽略，但需注意与纯无关项的区分——弱力度不等于零。
3. 当题干要求比较最强/最弱的支持或质疑力度排序时，重复结论排在实质论据之后、无关项之前。
