# 方法卡：等比修正与乘法递推法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 等比修正与乘法递推法 |
| 适用题型 | 数量关系——数字推理（等比修正数列、累乘递推数列） |
| 触发场景 | 相邻项存在相近倍数关系但非整数倍，作商得到的商在某固定值附近波动；或后项可由前若干项相乘（含修正）得到 |
| 步骤逻辑 | ① 先作商，观察相邻项是否接近某个固定倍数 m；② 对“倍数+加法修正”路径，逐项计算残差 b(n)=a(n+1)-m·a(n)，再判断 b(n) 是否为常数、交替数列、等差/等比或简单递推；③ 用 a(n+1)=m·a(n)+b(n) 回代全部已知项；④ 对“前两项相乘”路径，逐项计算残差 c(n)=a(n+2)-a(n)·a(n+1)，再判断 c(n) 是否固定或自成简单规律；⑤ 两条路径分别验证，不能把相邻倍数修正与前两项累乘混为同一公式，也不能只在一个位置成立就定型 |
| 高频错因 | ① 作商后只看到商接近某整数就断定等比修正，未连续验证修正项 b(n) 的规律；② 把"倍数+修正"和"累乘递推"混用，公式套错位置；③ 修正项 b(n) 本身是等差/等比/递推时，只验证了 b(1) 就下结论，未用后续项交叉验证 |
| confidence | high |

## 不适用条件

1. 相邻项不存在近似固定倍数，且前两项乘积也不能解释后项量级时，本方法不适用，应回退到总纲的其他路径。
2. 数列项数少于 5 项时，修正项 b(n) 的规律样本不足，等比修正假设难以稳定验证。
3. 累乘递推要求至少 3 个连续项交叉验证，项数不足时不可套用 a(n+2)=a(n)·a(n+1)+c。
4. 修正项 b(n) 本身需要再作差/作商才能定型，且二次规律样本不足时，整条路径不可靠。

## 反向触发

1. 当残差 b(n)=a(n+1)-m·a(n) 在前几项成立、末项偏离时，应先检查 m 是否选错；只有 b(n) 能形成简单且可重复验证的规律时，才保留等比修正路径。
2. 当累乘残差 c(n)=a(n+2)-a(n)·a(n+1) 在不同位置取值不同时，只有 c(n) 自成简单规律时才可继续，否则应放弃累乘路径。
3. 当商序列既不接近固定值也不成等差/等比时，应切换到幂次修正路径，检查是否为 a(n)=n^k+c 类幂次结构。

## 最终验证动作

1. 用求得的 m、残差 b(n) 或累乘残差 c(n)，从首项逐项递推，确认每一项都与原数列完全吻合。
2. 推出目标项后，与选项比对；若目标项与最近选项有固定差值，检查修正项 b(n) 在末位是否有方向反转或符号变化。
3. 对累乘递推，必须验证 a(n)·a(n+1)+c 在至少两个不同位置都成立，不能只验证末位一项。
4. 对修正项 b(n) 本身成规律的情况，b(n) 的规律同样必须覆盖全部已知 b 值，无遗漏。
