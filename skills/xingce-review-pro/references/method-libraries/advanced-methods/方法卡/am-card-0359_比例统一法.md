# 方法卡：比例统一法
## 基本信息
| 字段 | 值 |
|------|-----|
| 方法名 | 比例统一法 |
| 适用题型 | 数量关系-比例变化/人数增减/前后两阶段比例不同 |
| 触发场景 | 前后两次操作导致比例变化，其中某量保持不变 |
| 步骤逻辑 | 1.找不变量（如某次操作中研究生人数不变） 2.将不变量在两阶段比例中统一对齐（7:5和3:1→研究生统为5份→15:5） 3.算新增份数差，对应实际量差 4.求每份实际值，回推原始量 |
| 高频错因 | 找错不变量（应找未被操作的那一方）；比例统一时计算错误导致份份数对应错；忘记"年度引进=两阶段新增之和" |
| confidence | high |
## 补充说明
前后两次操作中，找未被操作的不变量作为统一桥梁，将两个阶段的比例统一对齐。统一后算份数差对应实际量差，即可求出每份实际值，回推原始量。此方法纯靠份数运算，无需列方程，比列代数方程更快更直觉。

## 不适用条件

- 前后两个阶段所有量都发生了变化，找不到不变量作为统一桥梁
- 比例涉及三个及以上组别，仅统一对齐两组无法覆盖所有关系
- 题目要求精确数值而非比例关系，且数据不支持整数份数（出现分数份数时计算易出错）

## 反向触发

- 当统一份数后求出的实际值不是整数或明显不合理时，应检查不变量是否找错——应找未被操作的那方，而非刚被操作的那方
- 当题目涉及三阶段以上连续变化且中间不变量不同时，单次统一可能不够，需分段处理或考虑换用代数方程
