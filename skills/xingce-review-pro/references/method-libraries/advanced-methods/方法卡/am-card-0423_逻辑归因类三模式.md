# 方法卡：逻辑归因类三模式

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 逻辑归因类三模式 |
| 适用题型 | 逻辑判断-加强削弱（归因类/因果类） |
| 触发场景 | 题干给出一个已发生事实，问原因、要求加强或削弱该原因 |
| 步骤逻辑 | 1. 识别归因类特征：有既成事实（已发生的结果）+ 对原因的讨论；2. 归因分为三种模式：- 对比实验归因（最常见）：有实验组和对照组- 一般实践归因：直接分析事实原因- 直接根本原因：追根溯源；3. 加强方式：排除他因、解释说明；4. 削弱方式：另有他因、因果倒置、否定此因；5. 考场上犹豫时按此分类对号入座，正确概率高 |
| 高频错因 | 分不清"另有他因"和"因果倒置"；未识别出题目属于归因类就盲目选 |
| confidence | medium |
| 不适用条件 | 题干没有既成事实（纯预测/假设类）时不适用归因模式，应转用一般加强削弱方法；题目讨论的是多个方案优劣比较而非因果归因时，不套用三模式 |
| 反向触发 | 削弱选项同时涉及"另有他因"和"因果倒置"时，需逐一对比削弱力度再确定答案，不可凭直觉选定；题目未明确是归因类但选项出现因果表述时，应先判断是否属于归因再决定是否用此方法 |
