# 方法卡：年均增长率

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 年均增长率 |
| 适用题型 | 资料分析——求年均增速、平均增长率（实际是年均增长率） |
| 触发场景 | 题目问"年均增速""平均增长率"，材料给出初期和末期数据及年份 |
| 步骤逻辑 | ① 年均增长率定义：由初期按相同增速增长到末期；② 近似公式：年均增长率 ≈ (R1+R2+...+RN)/N（各年增速越接近越准）；③ 也可用末期/初期开N次方根精确求解 |
| 高频错因 | 混淆"平均增长率"和"年均增长率"；年份差算错（如2017-2021年是4年不是5年） |
| confidence | high |
| 不适用条件 | 各年增速差异较大时，算术平均近似误差不可接受，不能直接用(R1+R2+...+RN)/N；题目要求精确的年均增长率数值或选项间距极小时，需用开N次方根的精确公式 |
| 反向触发 | 题目给出各年单独增速且增速差异较大时，近似公式误差可能跨越选项，应改用开N次方根精确求解；若仅需判断年均增长率的大致范围或排除极端选项，近似公式可优先使用以节省时间 |

## 补充说明

近似公式适用条件：各年增速越接近，近似越准。年份差N = 末期年份 - 初期年份（如2017到2021是4年）。"平均增长率"在资料分析中就是"年均增长率"，不是求增长率的平均值。
