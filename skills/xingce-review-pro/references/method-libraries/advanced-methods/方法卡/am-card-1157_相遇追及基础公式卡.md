# 方法卡：相遇追及基础公式

## 基本信息

| 字段 | 值 |
|---|---|
| 方法名 | 相遇追及基础公式 |
| 适用题型 | 数量关系-行程问题-基础相遇/追及 |
| 触发场景 | 两人相向而行求相遇，或同向而行求追及 |
| 步骤逻辑 | 1. 先定义初始距离差 S；2. 相遇用 S=(v₁+v₂)t，追及用 S=(v快-v慢)t；3. 求某人实际路程时另算 sᵢ=vᵢ×t；4. 追及题校验 v快>v慢 |
| 高频错因 | 相遇误用速度差；追及误用速度和；把速度和/差与时间的乘积误当成某个人的实际路程；速度差方向搞反 |
| confidence | high |
| 不适用条件 | 1. 多人多段行程、变速运动等超出基础相遇追及公式的复杂行程问题
| 反向触发 | 1. 题目考查等距往返平均速度时应读 am-card-0933
2. 题目涉及多次相遇或环形追及时应读对应专用卡（am-card-0931、am-card-0237）
3. 工程问题/浓度问题/利润问题等其他数量关系子模块不需要相遇追及公式 |
2. 环形跑道追及、流水行船、自动扶梯等特殊场景（有专用卡）
3. 非行程问题的数量关系题（工程问题、溶液混合、利润计算、数字推理等） |

## 适用边界

- 环形追及读 `am-card-0237_追击问题比例法（含环形跑道）.md`。
- 多次相遇读 `am-card-0931_相遇问题路程比法.md`。
- 等距往返平均速度读 `am-card-0933_等距离平均速度（调和平均数）.md`。
