# 方法卡：除非否则否一推一

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 除非否则否一推一 |
| 适用题型 | 判断推理-命题翻译题（含"除非...否则..."句式） |
| 触发场景 | 题干出现"除非A，否则不B""除非出现飞蛾，否则不能申请"等句式 |
| 步骤逻辑 | 1. "除非A，否则不B" = **否一推一**：否前推后 或 否后推前；2. 翻译：非A→不B（否前推后），等价于 B→A（否后推前，逆否命题）；3. 实操：如果后半句有"不"，优先否后半句（消掉"不"更简洁）；4. 例："除非出现飞蛾，否则不能申请" → 否后半句"能申请" → 推出"出现飞蛾"；5. 注意：A→B成立 ≠ B→A成立（原命题正确，逆命题不一定正确） |
| 高频错因 | 把"除非否则"翻译错方向忘记逆否命题：A→B 只能推出 非B→非A，不能推出 B→A |
| confidence | high |

## 不适用条件

- 题干句式为"只要...就...""只有...才..."等非"除非否则"结构时，翻译规则不同，不适用本方法的否一推一规则。
- 题干本身没有逻辑推理要求，仅为阅读理解或语义判断时，无需翻译命题。

## 反向触发

- 题面出现"只要...就..."时，应想到充分条件翻译规则。
- 题面出现"只有...才..."时，应想到必要条件翻译规则。
