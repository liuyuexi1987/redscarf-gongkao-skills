# 方法卡：归因题支持方式——解释说明与增加实验结果

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 归因题支持方式——解释说明与增加实验结果 |
| 适用题型 | 判断推理——加强类（因果论证/对比实验） |
| 触发场景 | 题干为对比实验或因果论证，要求选"能支持实验结论"的选项 |
| 步骤逻辑 | ① 确认结论是因果关系（如"碳酸锂治疗安全且有效"）；② 支持"安全"可用"没有副作用"——支持部分即可，不必支持全部；③ 支持"有效"最直接的方式是"增加实验结果"——补上题干缺失的对比结果（如B组比A组恢复更快）；④ "解释说明"也是一种支持——解释因果机制（如转速放缓→昼夜变化→强震多发） |
| 高频错因 | 误以为"国际权威认可"能支持实验结论（这是诉诸权威，属于无关项）；误以为支持必须"全真才真"——支持A且B的结论，单独支持A或B也可以 |
| confidence | high |
| 不适用条件 | 题干不是因果/实验型论证（如纯数字推理、排列组合）时，不套用"支持安全/有效"的拆分思路 |
| 反向触发 | 结论是复合命题且选项仅支持其中一部分时，若另有选项能同时支持各部分，应优先比较覆盖面与作用位置；题干只陈述相关性而未主张因果时，解释因果机制不能直接视为有效支持，应检查选项是否真正强化了题干关系。 |
