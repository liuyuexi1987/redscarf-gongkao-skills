# 方法卡：新话题出现看后续是否围绕

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 新话题出现看后续是否围绕 |
| 适用题型 | 中心理解 |
| 触发场景 | 文段中途突然出现新话题或新名词 |
| 步骤逻辑 | ① 标记新话题出现的位置；② 观察后续内容是否继续围绕该新话题展开；③ 若后续均围绕新话题展开，则新话题是文段主体或主题；④ 若后续又转回原话题，则新话题只是过渡 |
| 验证动作 | 新话题必须经后文持续展开或结论回扣验证，确认最终落脚点是否在新话题上 |
| 不适用条件 | 新话题出现在尾句（属接语题判断范畴）；新话题是反面论证的一部分而非正面论述对象 |
| 高频错因 | 认为新话题出现晚就不是重点 |
| 反向触发 | ①新话题仅在一句话中被提及且后文未再展开，说明只是过渡或举例，应回到原话题找主旨；②新话题出现在从句或修饰成分中，主句仍在论述原话题，此时新话题不是文段重心；③新话题出现后文段很快又转回原话题并给出结论，说明新话题只是插入性讨论，主旨仍在原话题 |
| confidence | high |

> **使用边界**：本方法用于提供优先检查方向，不可单独据此作答；最终需回到题干关系、原文证据或选项条件完成验证。
