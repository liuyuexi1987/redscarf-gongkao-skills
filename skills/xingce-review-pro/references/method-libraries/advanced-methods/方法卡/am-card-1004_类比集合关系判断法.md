# 方法卡：类比集合关系判断法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 类比集合关系判断法 |
| 适用题型 | 判断推理——类比推理 |
| 触发场景 | 两个词都是名词，需要判断集合关系（种属/交叉/并列/全异） |
| 步骤逻辑 | ① 判断有没有交集部分（重叠）；② 判断有没有独立部分（各自独有的）；③ 有交集+无独立=种属（小圈在大圈内）；④ 有交集+有独立=交叉；⑤ 无交集=并列或全异 |
| 高频错因 | ① 混淆种属和交叉→只看有没有交集，没看有没有独立部分；② "木碗"和"汤碗"→除了木碗有别的碗吗？有→除了汤碗有别的碗吗？有→种属而非交叉 |
| confidence | high |

## 补充说明
判断交叉的方法："除了A以外有没有别的A？除了B以外有没有别的B？"如果都有，且两者有重叠→交叉。命名方式不同（按材料vs按功能）但主体相同→优先考虑交叉。

## 不适用条件
- 两个词不都是名词（无法判断集合关系）
- 词项间明显为属性/功能等非集合关系

## 反向触发
- 集合关系判断后仍有多个选项→补充二级辨析（命名方式、范围大小）
- 明显是种属关系且无独立部分→种属关系即为主要选项，无需用交叉判断流程
