# 方法卡：严谨逻辑质疑法（A推B找A且非B）

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 严谨逻辑质疑法（A推B找A且非B） |
| 适用题型 | 论证题（质疑/削弱），结论含逻辑关联词（如果...则、只有...才、要...就） |
| 触发场景 | 结论出现"想要A就B"等逻辑关联词；问法为"质疑/质疑上述观点" |
| 步骤逻辑 | 1. 判定：结论含逻辑关联词 + 问法为论证类 → 严谨逻辑关系；2. 把结论翻译为A→B（前推后或后推前）；3. 矛盾= A且非B（且命题的矛盾取非后项）；4. 若结论含"或"命题，取矛盾时变为"且"：(A或B)的矛盾 = 非A且非B；5. 在选项中找同时满足A成立且B不成立的选项 |
| 高频错因 | 忘记取或命题的矛盾；翻译时推导方向搞反 |
| confidence | high |
| 不适用条件 | 结论不含逻辑关联词（如纯事实描述、数据结论），或题目问"支持"而非"质疑" |
| 反向触发 | 题目问"以下哪项最能支持"时，应找使A→B成立的选项（如A发生时B也确实发生），而非找A且非B的矛盾 |
