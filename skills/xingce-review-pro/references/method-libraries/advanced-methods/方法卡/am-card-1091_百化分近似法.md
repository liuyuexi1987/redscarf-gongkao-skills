# 方法卡：百化分近似法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 百化分近似法 |
| 适用题型 | 资料分析——增长率相关计算 |
| 触发场景 | 增长率接近某个常见分数（如16.7%≈1/6、14.3%≈1/7） |
| 步骤逻辑 | ① 将增长率近似为好算的分数（如16.7%≈1/6、14.3%≈1/7、12.5%≈1/8）；② 用分数代替百分数计算（除法变乘法）；③ 算出后判断偏大偏小进行调整；④ 误差调整：差值×0.6或0.7×原数=误差修正量 |
| 高频错因 | ① 近似值偏差太大→结果不准；② 不做误差调整→系统性偏大或偏小 |
| confidence | high |

## 补充说明
百化分是资料分析的基础速算技巧。常用分数对应：50%=1/2、33.3%=1/3、25%=1/4、20%=1/5、16.7%=1/6、14.3%=1/7、12.5%=1/8、11.1%=1/9。前提：多位数×一位数乘法要熟练。

## 不适用条件

- 增长率远离所有常见分数对应值时，近似偏差可能影响选项判断。
- 选项差距小且近似方向不确定时，百化分近似可能落入错误区间。

## 反向触发

- 近似结果与某选项非常接近但无法确定偏大偏小时，应换用直除或截位直除补充核验。
- 增长率介于两个常见分数之间时，应取两个分数分别试算，比较哪个更接近再调整。
