# 方法卡：纯整除判定三九与二四八

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 纯整除判定三九与二四八 |
| 适用题型 | 题干明确要求判断整除关系的纯整除问题 |
| 触发场景 | 题干直接说"能被X整除"或"不能被X整除"，需要结合多个整除条件确定数字 |
| 步骤逻辑 | **三九判定（个位数字和）：**；1. 被3整除：各位数字之和是3的倍数（如12→1+2=3，能整除）；2. 被9整除：各位数字之和是9的倍数（如18→1+8=9，能整除）**二四八判定（看末几位）：**；1. 被2整除：看末1位（偶数即可）；2. 被4整除：看末2位；3. 被8整除：看末3位；4. 规律：2的n次方看末n位**复合因子拆解：**如24 = 3 × 8，同时满足3和8的整除判定如85 = 5 × 17，分别验证各因子 |
| 高频错因 | 混淆"能被3整除"与"能被9整除"的条件（3只要求和是3的倍数，9必须是9的倍数）2的n次方看末几位的n记错，如8=2³应看末3位而非末2位复合因子未拆解就直接判断 |
| confidence | medium |

## 补充说明

- 三九判定中"能被3整除但不能被9整除"意味着该数恰好含1个3因子（即不是9的倍数）
- 五个连续自然数之积：若含2个3的倍数则必被9整除，若仅含1个则只能被3整除
- 复合因子拆解示例：五位数同时是8和3的倍数→先由8的判定锁定末三位取值，再由3的判定（各位数字和）锁定首位

## 不适用条件

- 题目问"是否能整除某非2/3/4/8/9的质数"（如7、11、13）时，需用其他判定规则
- 题目只要求判断单一因子（如只问能否被4整除），无需复合拆解

## 反向触发

- 当题干条件不足以单凭整除判定唯一确定数字时，应结合方程、枚举或其他数论方法核验
- 当复合因子中含未知因子（如85=5×17中的17）时，应分别验证各因子，不要直接套三九或二四八判定
