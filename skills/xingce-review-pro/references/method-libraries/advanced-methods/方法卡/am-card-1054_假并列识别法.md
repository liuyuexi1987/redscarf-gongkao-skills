# 方法卡：假并列识别法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 假并列识别法 |
| 适用题型 | 言语理解——中心理解/逻辑填空 |
| 触发场景 | 文段有"A和B"看似并列，但实际是包含关系 |
| 步骤逻辑 | ① 并列的两个词至少不能是包容关系（不能是"西瓜和水果"）；② 如果一个是另一个的子集→假并列→真正的重点是子集那个；③ 假并列时看文段其他部分围绕哪个词展开→那个才是重点 |
| 高频错因 | ① 看到"和"就当并列→选了包含两者的选项→以偏概全；② 不判断包含关系→选了错误的并列概括 |
| confidence | high |

## 补充说明
假并列的判断核心是看两个词是否存在包含关系。如果一个是另一个的子集，则为假并列，重点在子集。

## 不适用条件
- 文段中"A和B"确实是同一层级的并列（无包含关系）
- A、B确属同一层级且后文分别展开时，应按真并列概括，不能强行判为包含关系
- 文段使用"或者""还是"等选择连词而非"和"

## 反向触发
- 如果文段没有出现"和""与""及"等并列连词，不应触发本方法
- 如果题目问文段整体概括，仍需先判断A、B是真并列还是包含关系，再决定是否都写入主旨
