# 方法卡：比重差速算公式

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 比重差速算公式 |
| 适用题型 | 资料分析-比重差（上升/下降多少个百分点） |
| 触发场景 | 题目问"比重约上升了多少个百分点"或"下降了多少个百分点" |
| 步骤逻辑 | 1.先算R1-R2（分子增率减分母增率）；2.根据正负排除方向错误的选项（正→上升，负→下降）；3.再用现期比重×(R1-R2)/(1+R1)精算或根据选项差距直接选 |
| 高频错因 | 把比重差当成增率之差直接选；不先判断正负就急着算 |
| confidence | high |

## 不适用条件

1. R1或R2为负值且绝对值较大时，公式中(1+R1)可能接近零，分母趋近导致公式不稳定，需回到比重差的定义式（现期比重-基期比重）精确计算。
2. 选项间距不足以覆盖速算误差时，近似精度不足以区分正确选项。
3. 题目要求精确的比重差值（如用于后续计算）而非仅判断方向和量级时，速算公式仅做粗估，可能不够。

## 反向触发

1. 题目只问"比重是上升还是下降"而不要求具体数值——只需看R1-R2的正负号即可，无需用完整公式。
2. 现期比重与增速差的乘积接近选项边界时，速算判断不可靠，应使用完整公式。
3. 分子或分母本身是负值（如利润亏损情况）——比重的含义已改变，公式前提不成立。

## 补充说明

核心公式：比重差 = (A/B) × (R1-R2)/(1+R1)。其中A/B为现期比重，R1为分子增率，R2为分母增率。考试时先算R1-R2的符号排除选项，再根据现期比重大小判断量级。部分题目选项间量级差异明显（如0.17和1.7），量级一眼可辨。方法提示：能快速判断时，不必硬算。
