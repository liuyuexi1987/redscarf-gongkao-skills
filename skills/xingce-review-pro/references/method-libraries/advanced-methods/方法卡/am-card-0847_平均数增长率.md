# 方法卡：平均数增长率

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 平均数增长率 |
| 适用题型 | 资料分析——平均数增速·已知分子分母增速求平均数增速（如单位面积产量、人均收入、均价等） |
| 触发场景 | 题目问"单位面积产量增长多少""人均XX增长多少""均价增长多少"等，且给出了分子和分母各自的增速 |
| 步骤逻辑 | ① 识别所求平均数的分子与分母；② 找分子增速R1和分母增速R2；③ 计算带符号的增速差R1-R2；④ 用(R1-R2)÷(1+R2)修正；⑤ 只有当修正误差明显小于选项差距时，才可用增速差近似 |
| 高频错因 | ① 用绝对值比较负增速导致增速差算反；② 忘记除以(1+R2)；③ 把分子、分母增速对应错；④ 选项接近时仍直接用增速差 |
| confidence | high |

## 补充说明

公式：R = (R1 - R2) ÷ (1 + R2)。其中R1是分子增速，R2是分母增速。这是乘积增长率的逆运算。速算技巧：先做增速差R1-R2，再看R2的正负决定修正方向——R2正→结果比增速差小一点；R2负→结果比增速差大一点。修正幅度取决于R2的大小：R2越小修正越小。大部分平均数增长率题选项差距较大，只算增速差+方向判断即可选出答案。

## 不适用条件

- 题目给出的不是增速而是绝对值（如具体产量、具体收入）时，需先算出增速再套公式
- 分子和分母的统计口径或时间范围不一致时，不能直接套用
- R2的绝对值较大或选项接近时，仅靠增速差和方向判断不够，应精确计算

## 反向触发

- 看到"单位面积产量增长多少""人均XX增长多少""均价增长多少"且给了分子分母各自增速 → 用本方法
- 看到"增速差"本身是题目所求（如"增速高几个百分点"） → 不用本方法，直接做差即可
- 看到"乘积增长率""间隔增长率" → 不用本方法，公式虽同源但触发场景不同
