# 方法卡：背景非重点识别法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 背景非重点识别法 |
| 适用题型 | 言语理解——主旨概括/意图判断（所有文段类型） |
| 触发场景 | 文段开头出现"随着……的发展""随着……的推进"等引入语，或大段专业性介绍后才进入正文 |
| 步骤逻辑 | ① 识别背景句——典型标志："随着……"开头、专业术语堆砌的引出段、历史/现状铺垫；② 背景中出现的关键词不等于正文重点——背景说到跟没说到一样；③ 主要看正文（后文）有什么新变化、新发现、新突破；④ 背景太专业读不懂也不用管，直接看后文 |
| 高频错因 | 被背景中的关键词迷惑，以为"第一句话就有这俩字"就选它（地下党接头式做题）；把背景中提到的内容当成正文重点；被专业背景吓到，读不懂就慌了随便选 |
| confidence | medium |

## 补充说明

- "地下党接头"式做题：把重要信息隐藏在没用的话里，就盯着第一句话的关键词对选项——做言语不能这样。全文都要为一个主题服务，不能只看局部。
- 背景+正文的常见形式是新闻稿：背景引入→新成绩/新变化。若是"背景+我国的新成绩"，要重点夸我国。
- 背景读不懂不用慌：重点在后文内容，不用纠缠背景细节。

## 不适用条件

1. 文段开头的"随着……"不是背景铺垫，而是核心论据或前提（后文没有转折或新话题），此时开头就是正文的一部分。
2. 文段为"背景+多角度展开"的并列结构，没有明确的"铺垫-正文"分割线，不能只看后文。
3. 题目问的是背景部分提到的具体信息（如定义、起源），此时背景本身是答案来源。

## 反向触发

1. 如果文段开头是背景铺垫但后文出现"对此/针对/因此"等对策词，应结合前对策结构抓对策法。
2. 如果后文也是泛泛介绍没有新变化或新结论，文段整体可能属于科普类，用科普类客观概括法。
3. 如果背景部分和正文部分出现同一主体的不同方面，需结合主体一致性排除法判断选项。
