# 方法卡：下文推断背景加新

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 下文推断背景加新 |
| 适用题型 | 下文推断（接语题） |
| 触发场景 | 文段有过去时态提示词（"从来""一直以来""此前"等），表达"过去做不好" |
| 步骤逻辑 | 1. 判断不是总分结构→看最后一句；2. 注意最后一句是否有过去时态提示词；3. 有时态→选"背景+新"结构（体现"现在和以前不一样"的突破/变化）；4. 无时态→按"问题+分析/对策"结构推断 |
| 高频错因 | 无脑套"问题+对策"，忽略时态差异；选了不体现"新"的对策 |
| 不适用条件 | 末句为总结性收束时，下文应顺延总结而非转向新话题；总分结构中末句为分述时，下文应回到总论点而非引入新变化 |
| confidence | high |
| 反向触发 | 末句同时含过去时态和明显结论性语义时，时态信号可能被结论性信号覆盖，需判断哪层语义更强再决定结构；若多个选项均体现"变化/突破"，应比较各选项的变化内容与文段末句的逻辑衔接紧密度，而非仅看是否含"新"字 |

> **使用边界**：本方法用于提供优先检查方向，不可单独据此作答；最终需回到题干关系、原文证据或选项条件完成验证。

**不适用条件**：末句为总结性收束时，下文应顺延总结而非转向新话题；总分结构中末句为分述时，下文应回到总论点而非引入新变化；新内容必须与文段主题保持话题一致性。
