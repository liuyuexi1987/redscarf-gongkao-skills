# 方法卡：倍数表述易错识别

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 倍数表述易错识别 |
| 适用题型 | 资料分析-综合分析（倍数判断） |
| 触发场景 | 综合分析题选项出现"涨了X倍""增长了X倍""是X倍"等表述 |
| 步骤逻辑 | 1.先看选项中哪个涉及倍数表述（高频易错点）；2."涨了2.36倍"="是以前的3.36倍"；3.快速用现期/基期验证：若现期/基期≈3.36则"涨了2.36倍"正确，若≈2.36则错误；4.综合分析题优先验证此类易错选项 |
| 高频错因 | 把"涨了X倍"和"是X倍"混淆——"涨了"不包含基数，"是"包含基数 |
| confidence | high |

## 不适用条件
- 选项中无倍数表述（全为百分比或绝对值比较）——本法触发前提不成立
- 题目问"正确的是"且倍数选项恰好正确——虽可验证但非优先检查对象
- 增长率或比重问题被伪装成倍数表述——需先还原实际考查点再判断

## 反向触发
- 题目直接问"是几倍"且选项不含"涨了/增长了"等易混淆表述——无需辨析
- 选项全为增长量或增长率比较——考查点不在倍数表述，本法不适用
- 题目涉及"多几倍"与"少几倍"的反向关系——除混淆外还需注意方向性

## 补充说明

"涨了N倍"=现在的值是原来的(N+1)倍。综合分析题问"错误的是"时，优先看倍数类选项，因为这是高频易错点，出题人喜欢在这里设坑。验证时用简单除法：如13万/5万≈2.6倍，说明是以前的2.6倍、涨了1.6倍，而非涨了2.36倍。此法叫"以坑治坑"。
