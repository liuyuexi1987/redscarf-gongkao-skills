# 方法卡：反驳谬论不被牵着走

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 反驳谬论不被牵着走 |
| 适用题型 | 判断推理-反驳类题目（对方用"别人也这样"来为自己辩护） |
| 触发场景 | 题干结构：某人做了违法/违规行为，被制止后反问"别人做的更过分你怎么不管"，要求找最能反驳的选项 |
| 步骤逻辑 | 1. 识别对方的辩解逻辑：用别人的问题来转移对自己行为的追究；2. 最有力的反驳 = **直接指出"你本身违法/违规，就该被处理"**；3. 不选讨论"别人问题严不严重""成本高不高"的选项——这些都被对方的逻辑牵着走；4. 类比：小偷偷东西说"命案你都还没破"→ 回答"你违法了我就抓你"，不回答"命案还没破所以放你走" |
| 高频错因 | 选了C/D选项（讨论别人的违法程度或查处情况），被谬论牵着鼻子走误以为"比较严重程度"是一种有效反驳 |
| confidence | high |

## 不适用条件

1. 对方未使用"别人也这样"的转移逻辑，而是正面论述自身行为合理性
2. 题干要求找"最能支持/加强"而非反驳的选项
3. 辩解逻辑是"事出有因""迫不得已"等非比较型理由

## 反向触发

1. 题干中某人被指出违规后，反问"别人更严重你为什么不管"
2. 选项涉及"你自身行为的对错与别人无关"vs"别人的问题同样严重"
3. 题干要求选择"最能反驳上述辩解"的选项
