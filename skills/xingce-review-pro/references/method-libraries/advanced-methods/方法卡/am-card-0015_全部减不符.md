# 方法卡：全部减不符（排列组合排除法）
## 基本信息
| 字段 | 值 |
|------|-----|
| 方法名 | 全部减不符 |
| 适用题型 | 数量关系-排列组合（有约束条件的计数） |
| 触发场景 | 直接求符合条件的数量较复杂，但求不符合的更容易 |
| 步骤逻辑 | 1.求总情况数（如C93） 2.分析不符合条件的情况（如三点共线） 3.总-不符=所求 |
| 高频错因 | 遗漏某类不符合的情况；忘记共线点的组合数 |
| confidence | high |

## 不适用条件

1. 不符合条件的情况类别过多或难以穷举，反而直接计数更快
2. 涉及圆排列/重复排列等需要额外除以阶乘的情形，不满足简单"总-不符"模型
3. 题目约束为"至少""至多"型，直接分类讨论更清晰

## 反向触发

1. 直接分类（如选 A 的情况 + 选 B 的情况）比反面求解更简洁
2. 不符合条件本身涉及多重嵌套排除，容易遗漏
3. 题目为简单的线性排列，无复杂约束，直接公式即可

## 补充说明
