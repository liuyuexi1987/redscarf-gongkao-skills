# 方法卡：速算方法区间选择

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 速算方法区间选择 |
| 适用题型 | 资料分析——根据增长率大小选择最优速算方法 |
| 触发场景 | 需要求基期、增量、比重等，增长率落在不同区间时 |
| 步骤逻辑 | ① 增长率在 -10%~0%：用化除为乘（B/(1+R) ≈ B×(1-R)）；② 增长率在 0%~20%：用假设分配最合适；③ 增长率能凑到某个简单分数附近（如1/4、1/3等）：用百化分（分数法）；④ 增长率很大（>50%）且凑不到分数：各方法无明显优势，直除即可 |
| 高频错因 | 增长率较小时仍选择直除而不用假设分配，效率低下；不判断增长率区间而随机选择方法 |
| confidence | high |

## 补充说明

这是速算体系的核心选择框架。具体方法（假设分配、百化分、化除为乘）各有独立方法卡。

## 不适用条件

- 当增长率很小、现期值与基期值的差异不会影响选项判断时，可直接用现期值近似。
- 当选项间距很大，粗略估算即可区分答案时，精细速算是多余步骤。
- 当增长率的符号或量级使近似误差可能跨越选项时，直除或分步计算更稳妥。

## 反向触发

- 当增长率绝对值很小且选项间距大时，直接用现期值近似代替基期值。
- 当误差可能跨越选项或改变结论时，改用精算/验证。
- 当增长率为负且绝对值较大时，先判断基期值明显大于现期值，再选择是否需要精算。
