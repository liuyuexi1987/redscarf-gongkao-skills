# 方法卡：间隔增长率反推

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 间隔增长率反推 |
| 适用题型 | 资料分析——间隔/平均数增长率·已知整体增速和一段增速求另一段增速 |
| 触发场景 | 给了22→24年的整体增速和23→24年的增速，求22→23年的增速；或反过来 |
| 步骤逻辑 | ① 识别出需要拆分一次变化为两次；② 用公式：R未知=(R总-R已知)÷(1+R已知)；③ 其中R总是整体增速，R已知是已知的那一段增速；④ 注意哪个是分子哪个是分母——被减的那段放在分母(1+R)中 |
| 高频错因 | ① 分子分母搞反——应该用"总-已知"做分子，"1+已知"做分母；② 正负号处理错误，尤其是两段都是负增速时；③ 误以为间隔只能按年度，忽略月度、季度等时间间隔同样适用 |
| confidence | high |

## 补充说明

这是平均数增长率公式的直接应用。关键理解：乘积增长率是"两次合并为一次"，平均数增长率是"一次拆分为两次"，公式本质相同。实战中若时间间隔跨多年（如05年→10年），需要找到中间跳板年份（如06年有相对05年的增速），分段用乘积增长率合并。若增速特别大（>50%）且问倍数，直接用倍数相乘(1+R1)×(1+R2)更高效。

## 不适用条件

- 时间间隔中存在数据缺失或口径变化时，不能直接套公式
- 题目给出的是绝对值而非增速时，需先转化为增速再用公式
- 增速较大且题目问倍数关系时，公式仍成立，但改用增长倍数计算通常更直观

## 反向触发

- 看到"已知整体增速和一段增速，求另一段增速"或"已知22→24年增速和23→24年增速，求22→23年增速" → 用本方法
- 看到"已知两段增速求整体增速" → 不用本方法，应用乘积增长率公式 R总=R1+R2+R1×R2
- 看到"平均数增长率"（分子分母各自增速已知） → 不用本方法，应用 am-card-0847
