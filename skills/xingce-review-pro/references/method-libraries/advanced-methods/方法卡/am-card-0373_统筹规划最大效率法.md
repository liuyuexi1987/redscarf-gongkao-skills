# 方法卡：统筹规划最大效率法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 统筹规划最大效率法 |
| 适用题型 | 统筹规划/资源分配（工程分配、运输调度） |
| 触发场景 | 多人做多任务，问总用时最少或总费用最少 |
| 步骤逻辑 | 1. 求每个人/地点对各项任务的效率比（时间反比=效率）；2. 找出谁在哪个任务上效率优势最大（倍数差最大的）；3. 让优势最大者优先做其最擅长的任务；4. 做完后再与其他人合作完成剩余任务 |
| 高频错因 | 随意分配而不比较效率优势倍数；不按"最大优势优先"原则分配 |
| confidence | high |

## 不适用条件

- 任务有先后顺序约束（必须先完成 A 才能做 B），此时效率比较的前提不成立
- 所有人对所有任务效率相同（无优势可言，随意分配即可）
- 问题涉及排队或等待机制（如流水线节拍），非简单效率分配问题

## 反向触发

- 当分配方案出现某人既做 A 又做 B、但总用时没有减少时，应重新检查优势比较是否正确
- 当任务不可分割（如一人必须完成整个任务才能开始下一个）时，比较优势应考虑完成顺序的连锁效应
- 当答案与直觉分配差异大时，应列出效率比表格验证，而非依赖直觉分配
