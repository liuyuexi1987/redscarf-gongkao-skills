# 方法卡：整体相同时现期占比代替现期值比较

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 整体相同时现期占比代替现期值比较 |
| 适用题型 | 资料分析——同一整体下比较部分的大小或增长量 |
| 触发场景 | 多个部分共享同一整体，材料给出各部分占比，需要比较部分的现期值或增长量 |
| 步骤逻辑 | ① 确认各部分属于同一整体；② 因为部分=整体×占比，比较时整体可消掉；③ 直接用占比代替部分值进行比较，省去计算实际值 |
| 高频错因 | 没有识别出"同一整体"，先把实际值算出来再比较；套用公式时忽略了整体相同这一前提 |
| confidence | high |

## 补充说明

典型场景：东部占比80.2%、中部占比11.3%，增速相近（都约20%多），此时增长量大小直接看占比——东部占比远大于中部，东部增量更大。与"同一整体下部分比等于占比比"配合使用效果最佳。

## 不适用条件

1. 各部分不属于同一整体（如不同地区对应不同总体指标），整体无法消掉
2. 题目要求计算具体数值而非仅比较大小
3. 材料给出的不是占比而是绝对值且无法推算占比

## 反向触发

1. 当增速差异很大导致增长量不能仅由占比决定时，应换用精算方法逐个计算
2. 当题目问的是具体数值大小而非排序比较时，应换用公式直接求解
3. 当部分之间存在重叠或交叉统计时，占比直接比较可能失真，需要额外核验
