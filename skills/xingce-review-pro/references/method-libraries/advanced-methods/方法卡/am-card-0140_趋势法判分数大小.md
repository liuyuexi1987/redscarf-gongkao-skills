# 方法卡：趋势法判分数大小

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 趋势法判分数大小 |
| 适用题型 | 资料分析·分数比较（增率/比重/单价等分子分母形式的比较） |
| 触发场景 | 需判断某指标（比重、单价、增率等）的现期值相比基期是上升还是下降 |
| 步骤逻辑 | 1. 分子增速>分母增速→分数数值变大 2. 分子增速<分母增速→分数数值变小 3. 直接比较分子和分母的相对增长率即可判断趋势 |
| 高频错因 | 习惯性把分数算出来再比；不看增速关系直接硬算 |
| confidence | high |

## 补充说明

典型场景：比较连续多年增速大小时，只需判断分子和分母的增速谁快谁慢，无需计算实际分数值。分子增速>分母增速则分数变大，反之则变小。全程只看趋势方向，不看绝对数值。此法是资料分析分数比较的核心思路，适用于增率、比重、单价等所有分子分母形式的比较。

## 不适用条件

1. 当需要精确数值（如"精确到小数点后一位"或"选出最大/最小的具体值"）时，趋势法只能判断方向，需精算
2. 当分子分母增速非常接近、方向难以肉眼判断时，趋势法可靠性下降，需辅助精算

## 反向触发

1. 当题目要求的是具体差值或比值而非趋势方向时，应改用精算法
2. 当涉及多个分数交叉比较（非简单的两个分数对比）时，应先用趋势法排序，但排序后需精算验证
