# 方法卡：除以9/11/111速算

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 除以9/11/111速算 |
| 适用题型 | 资料分析——放缩法中分母凑成9、11、111等全同数字后的快速计算 |
| 触发场景 | 分母被放缩成111、1111（全1数字）或9、99（全9数字）时，可用错位加减法秒算 |
| 步骤逻辑 | ① 除以111/1111等全1数：错位相减（如158÷111=158-1.58=142.2，即158×10-158再定位小数点）；② 除以9/99等全9数：错位相加（如158÷9≈158+15.8=173.8，即158×10+158再定位）；③ 记住误差方向：错位加减均偏小约1%（除以9偏小约1%，除以11偏小约1%，除以111偏小约0.1%） |
| 高频错因 | ① 除以9和除以11搞混（一个是错位相加一个是错位相减）；② 忘记两种方法都偏小约1%，在精度要求高的题中未做补偿；③ 小数点位置定位错误 |
| confidence | high |
| 不适用条件 | 分母无法通过放缩凑成9、11、111等全同数字；精度要求极高且选项间距极小，误差补偿后仍无法区分；分母放缩幅度太大导致结果偏离超出允许范围 |
| 反向触发 | 分母可以凑成整百或整千数，用普通除法更直接；题目选项间距很大，粗略估算即可锁定答案，无需速算技巧；分母放缩后变成非全同数字（如112、98），本法不适用 |

## 补充说明

原理：1/9=0.1111...（循环小数），所以除以9≈乘以0.111=乘以(10+1)/100，即错位相加后缩小100倍。1/11=0.0909...，所以除以11≈乘以0.0909=乘以(10-1)/111，即错位相减。误差来源：实际1/9=0.1111...而我们用了0.111，分母被放大了约1%，结果偏小约1%。除以111时误差仅约0.1%（三个1已非常接近），通常可忽略。
