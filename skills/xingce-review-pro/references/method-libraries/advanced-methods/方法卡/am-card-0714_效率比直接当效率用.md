# 方法卡：效率比直接当效率用

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 效率比直接当效率用 |
| 适用题型 | 工程问题中，已知条件不给具体时间，而是给出甲乙效率之比 |
| 触发场景 | 题干出现"甲的效率是乙的2倍""甲乙效率比为3:2"等效率比表述 |
| 步骤逻辑 | 1. 将效率比的数值直接赋值为效率（如2:1 → 甲效率=2，乙效率=1）；2. 结合工作总量或时间条件继续列式求解；3. 不需要额外换算，比例数就是效率的份数 |
| 高频错因 | 把效率比当成其他比值（如时间比），误以为需要取倒数多此一举设工作总量再求效率，增加计算量 |
| confidence | medium |

## 不适用条件

- 题目给出的比值并非效率比（如为时间比、工作量比），直接套用会导致方向相反。
- 效率比与工作总量条件均缺失，仅靠比值无法求出具体数值。

## 反向触发

- 当题目给出的是各自完成时间而非效率比时，应改用"给时间设最小公倍数为工作总量"。
- 当效率比涉及多人且关系复杂时，应先用"份数思想对应实际量"建立份数与实际量的对应。
