# 方法卡：五种对策识别法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 五种对策识别法 |
| 适用题型 | 言语理解——主旨概括/意图判断中的对策类题目 |
| 触发场景 | 文段关键位置出现对策标志词，或选项含建议、要求、措施类表述，需要判断其是否属于文段重点 |
| 步骤逻辑 | 1. **起始或建议型**: 直接命令/建议，如"要努力"、"应该努力"、"必须努力"、"不妨..."；2. **禁止型对策**: "不能..."、"不要..."、"避免..."、"如果这样做就会有不好结果"；3. **逻辑关联词表对策**: "只有才"、"如果就必须"、"否则"；4. **必要条件表对策**: "离不开"、"前提"、"基础"、"关键"、"必不可少"、"不可或缺"；5. **语义表对策**: "必经之路"、"有助于"、"长远目标"、"时代命题"、"重要议题" |
| 高频错因 | 不识别"有助于"等语义表对策，误认为是意义/作用；不识别"必须"等必要条件词，误认为是绝对化表述 |
| confidence | medium |

## 不适用条件

- 纯主旨概括题（文段无对策成分）不适用，应关注总论点而非对策标志
- 文段对策仅为举例说明时，不应将其提升为文段核心
- 当题干明确问"原因"或"影响"时，不应对策化作答

## 反向触发

- 若文段无任何对策标志词且尾句为总结/意义表述，不调用本卡
- 若题目问的是"文段意在说明"且文段为并列结构，先判断是否需要对策优先
