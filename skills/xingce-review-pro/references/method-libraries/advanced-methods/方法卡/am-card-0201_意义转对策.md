# 方法卡：意义转对策

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 意义转对策 |
| 适用题型 | 语句填入/中心理解 |
| 触发场景 | 文段先阐述某做法的好处/意义（E表述），未提对策 |
| 步骤逻辑 | 1. 意义表述可转化为"应该做此事"的对策；2. 正确对策必须紧扣意义表述，不能延伸；3. "必然趋势""更大程度"等绝对化/过度延伸→无中生有；4. 对策只能提"傻瓜反推"式的（问题是什么就反推什么） |
| 高频错因 | 对策无中生有、绝对化；选了"必然趋势"之类过度推断 |
| confidence | high |

## 不适用条件

1. 文段本身已有明确对策表述，不需要从意义反推
2. 意义表述与对策选项之间存在明显概念偷换或范围扩大
3. 文段为纯客观说明类（无隐含"应该做"的倾向）

## 反向触发

1. 文段只阐述好处/意义而未提对策，但选项中有对策表述——先用"傻瓜反推"法校验对策是否紧扣意义
2. 选项出现"必然趋势""更大程度"等强化表述时，回到文段核对力度；原文没有对应支撑时再排除
3. 意义表述越具体，可反推的对策也应越具体；对策过于笼统时考虑是否无中生有
