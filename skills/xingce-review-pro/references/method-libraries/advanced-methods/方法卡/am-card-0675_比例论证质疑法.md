# 方法卡：比例论证质疑法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 比例论证质疑法 |
| 适用题型 | 质疑类题目中题干用比例/百分比数据得出因果结论 |
| 触发场景 | - 题干用"X家庭得某病比例更高"得出因果关系
- 论据只关注分子（绝对数），忽略了分母（基数） |
| 步骤逻辑 | 1. 识别题干是否用比例数据支撑因果结论；2. 质疑方向：从分母入手——给出带比例的反向数据；3. 例如题干说"二手烟家庭得中耳炎比例高"，选项说"无烟家庭得中耳炎比例更高" |
| 高频错因 | 只在分子层面找反例，不考虑基数/分母选了不带比例的定性描述而非数据反驳 |
| confidence | medium |

## 补充说明

比例论证质疑是相对固定的套路：这类题"拿事实说话、拿数据说话"，质疑方式非常固定——用反向比例数据反驳。如果题干说X群体的比例更高，最有力的质疑是给出"非X群体比例更高"的数据。核心是从分母/基数入手，而非仅在分子层面找反例。

## 不适用条件

- 题干用绝对数量而非比例得出因果结论时，本方法不适用，应改用绝对数反驳。
- 题干结论不依赖比例数据支撑时，应改用常规质疑法。

## 反向触发

- 当选项只给定性描述而无比例数据时，应换用带比例数据的反向反驳项核验。
- 当题干比例已考虑基数、分母无漏洞时，应转向因果链或他因分析而非强行质疑比例。
