# 方法卡：整体把握优于盯逻辑关联词

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 整体把握优于盯逻辑关联词 |
| 适用题型 | 片段阅读-中心理解题 |
| 触发场景 | 文段中逻辑关联词多（转折/因此/但是），容易被单个关联词带跑偏 |
| 步骤逻辑 | 1. 先从整体上判断文段主要讲什么，属于哪类文段；2. 逻辑关联词只在特定结构中是重点：后对策的"因此"、二层转折结构的"但是"；3. 论证过程中的转折/因此不是重点，只是分析说明的一部分；4. 不能只见树木不见森林，只盯关联词会抓不准主旨 |
| 高频错因 | 看到"但是/因此"就认为后面是重点，被论证过程中的关联词带跑偏 |
| confidence | medium |

## 不适用条件

1. 文段只有一个明确的逻辑关联词且处于关键结构转折处（如二层转折的"但是"、后对策的"因此"），此时该关联词就是主旨信号
2. 题目本身问的是关联词的含义或作用，需要回到关联词所在位置
3. 文段结构简单、关联词少，不存在被"带跑偏"的风险

## 反向触发

1. 文段整体含义模糊、多个选项都有道理时，需要回到关联词的位置来判断作者真正强调的是哪一层
