# 方法卡：同质等价排除法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 同质等价排除法 |
| 适用题型 | 判断推理 > 真假推理/排列组合 |
| 触发场景 | 真假话问题中，两个对象在所有相关条件中出现方式完全一致（或关系中等价替换）；单选题中两个选项条件相同 |
| 步骤逻辑 | 1. 逐句翻译每个人的话，找出涉及相同对象的条件；2. 若甲和丙在所有相关语句中扮演相同角色（如"丁或丙"与"丁或甲"结构一致），则甲丙等价；3. 等价的两个人若有一个是正确答案，另一个也是——单选题不可能有两个答案；4. 排除等价对，在剩余对象中检验 |
| 高频错因 | 只看单句条件不看全局，未发现等价关系；忽略"或"关系中谁和谁可以互换 |

## 不适用条件

1. 两个对象的条件不完全一致（某个条件仅涉及其中一个对象），等价关系不成立
2. 题目为多选题或"可能正确"类型，等价对象可同时入选
3. 存在额外条件限制（如"至少一个为真""至多一个为真"）可能打破等价性

## 反向触发

1. 当识别出等价对但剩余选项均无法满足所有条件时，应重新审视等价关系是否成立
2. 当题目涉及三个以上对象且等价关系链较长时，应换用假设法逐项检验
3. 当选项中有"以上都不对"或"无法确定"时，需额外核验等价排除是否遗漏其他可能性
