# 方法卡：充要条件双向理解

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 充要条件双向理解 |
| 适用题型 | 加强削弱——法条/规则解释类，题干只写了A→B但隐含A↔B |
| 触发场景 | 题干引用一条法条或规则只写了正向（如"A→B"），问哪个选项能支持"应当理解为"包含反向条件 |
| 步骤逻辑 | ① 识别原文是A→B（如果越过则可通行）；② 交警/解释者认为还暗含非A→非B（未越过则不可通行）；③ 找选项时注意"如果那么"=前推后，加"才"=后推前，"如果那么…才"=双向（充要）；④ 支持交警的选项只要包含B→A（等价于非A→非B）即可 |
| 高频错因 | 把"只有才"理解为纯粹后推前而忽略"如果那么"的前推后，导致单向选项优于双向选项的误判；或者认为支持解释者就必须完全否定原文 |
| confidence | high |

## 补充说明

法条/规则解释类题中，若原文为A→B而解释者认为暗含非A→非B（即B→A），应找同时表达前推后和后推前的选项对应充要条件。"如果那么…才"是典型双向表达，比只含单向（后推前）的选项更完整。单向选项相当于否定条文正向含义，不合理。

## 不适用条件

- 题干规则本身已明确写成双向（A↔B），无需推断反向条件时，不适用本方法。
- 题干问的是规则适用范围或例外情形，而非推理方向时，不适用本方法。

## 反向触发

- 当选项中出现"除非…否则"等特殊逻辑联结词时，应改用"除非否则否一推一"方法处理。
- 当题干涉及多条法条联立推断时，应补充核验各条法条的方向是否一致，避免方向混淆。
