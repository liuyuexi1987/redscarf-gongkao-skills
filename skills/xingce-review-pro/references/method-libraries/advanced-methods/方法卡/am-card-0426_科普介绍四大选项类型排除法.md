# 方法卡：科普介绍类四大选项类型排除法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 科普介绍类四大选项类型排除法 |
| 适用题型 | 言语理解——主旨题（科普介绍类文段） |
| 触发场景 | 文段为科普介绍类（介绍事物的特点/原理/关系，无对策），选项中出现以下四种类型的表述时：原因类（"某某的原因/由来"）、具体类（"某某的方法/途径"）、区别比较联系类（"A与B的区别/关系"）、历程类（"某某的起源与发展"） |
| 步骤逻辑 | ① 判断文段为科普介绍类（无对策，纯介绍）；② 识别选项所属类型；③ 验证文段结构是否匹配该选项类型：原因类——文段有因果分析结构；具体类——文段有具体细节展开（可提炼为条目）；区别比较联系类——文段有双主语且A和B地位相当；历程类——文段有清晰时间轴（如"最初→某时期→现代"）；④ 选项类型与文段结构不匹配则排除；⑤ 特别注意：历程类选项需验证原文确有时间发展脉络才能选 |
| 不适用条件 | 不适用于说理文（有对策/观点的文段）、对策类主旨题；此类文段的选项匹配规则不同 |
| 高频错因 | 看到选项"听起来合理"就选，不验证选项类型是否匹配文段结构；选了历程类选项而原文没有时间轴；忽略区别比较类选项要求文段必须是真正的双主语结构 |
| confidence | high |
| 反向触发 | 选项类型与文段结构匹配但内容明显偏离文段核心话题时，应重新审视是否遗漏了文段重点；两个选项类型均与文段结构吻合时，需回原文验证哪个类型覆盖的信息量更大，不可仅凭类型匹配就确定答案 |

> **使用边界**：本方法用于提供优先检查方向，不可单独据此作答；最终需回到题干关系、原文证据或选项条件完成验证。
