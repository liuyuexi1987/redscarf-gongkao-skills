# 方法卡：总增量等于各部分增量之和

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 总增量等于各部分增量之和 |
| 适用题型 | 增量 / 整体与部分增量关系 |
| 触发场景 | 材料给出总增量和其中一个部分的增量，求另一部分的增量；或反过来由部分推总 |
| 步骤逻辑 | 1. 总增量 = 部分A增量 + 部分B增量（如行测+申论=总分，手机网民+非手机网民=总网民）；2. 已知任意两个可求第三个；3. 增量可正可负：一部分大幅增长、另一部分可能下降 |
| 高频错因 | 忘记增量可以为负数（一部分下降时）将增量比值当成总量比值 |
| confidence | medium |

## 不适用条件

1. 整体由三部分及以上组成且材料只给出其中一个部分的增量，此时单靠本公式无法直接求解。
2. 材料给出的是各部分占比而非增量绝对值，需要先换算再使用。
3. 题目要求的是总量（而非增量）的关系，需区分增量与总量。

## 反向触发

1. 拿到总增量和一个部分增量后，试图先分别求两个总量再做差，而未直接用增量相减。
2. 求出的"另一部分增量"为正但题目语境暗示该部分在下降，说明忘记增量可正可负。
