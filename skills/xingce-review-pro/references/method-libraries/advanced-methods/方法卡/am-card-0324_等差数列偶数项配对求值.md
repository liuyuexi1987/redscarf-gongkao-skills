# 方法卡：等差数列偶数项配对求值

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 等差数列偶数项配对求值 |
| 适用题型 | 数量关系——等差数列、年龄与排序 |
| 触发场景 | 偶数项等差数列给出总和及部分项，需要利用首尾配对和相等求未知项 |
| 步骤逻辑 | 1. 等差数列偶数项（如四项），首项+末项 = 第二项+第三项（配对相等）；2. 总和除以2，得到每一对的和（即平均数）；3. 已知其中一项，用对和减去已知项，得到配对项；4. 用选项约束排除不合理解（如年龄排序） |
| 高频错因 | 忽略偶数项没有真正的"中项"，但仍可用配对和47岁不知道排第几位时遗漏讨论，导致漏解 |
| confidence | medium |
| 不适用条件 | 等差数列为奇数项（有确定中项可直接求）；仅给出首项和公差、直接用公式求和的常规题目 |
| 反向触发 | 配对求出的和对应多组可能解时，需结合排序条件逐组讨论排除；若项数不确定，先根据总和反推项数再继续配对 |

## 补充说明

该方法核心是"偶数项等差数列首尾配对相等"，即使没有中间项，也能用总和/2得到配对之和，再结合具体条件（如年龄排序、选项约束）求解。
