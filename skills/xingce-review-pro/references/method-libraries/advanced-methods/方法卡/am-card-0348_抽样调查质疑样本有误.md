# 方法卡：抽样调查质疑——样本有误

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 抽样调查质疑——样本有误 |
| 适用题型 | 判断推理——削弱类（抽样调查/问卷/采访类题目） |
| 触发场景 | 题干通过随机采访/问卷调查得出某结论，问最能质疑的选项 |
| 步骤逻辑 | ① 识别题型：题干出现"随机采访""问卷调查""抽样"等关键词；② 正确质疑方向一定是样本有问题（取样不科学、以偏概全）；③ 看选项是否指出样本不具代表性（如采访场所仅限高档商场→样本偏向高收入群体）；④ "受访者夸大收入""有些人不清楚收入"等选项不确定性太强，不如直接指出取样场所偏颇来得有力 |
| 高频错因 | 选了"不确定"力度的选项（如B"夸大收入"，夸大多少不清楚）；选了看似相关但非样本问题的选项；未能识别调查类题的固定套路 |
| confidence | high |
| 不适用条件 | 1. 题目问的是加强/支持而非质疑（本方法专用于削弱方向）
| 反向触发 | 1. 选项质疑的是调查方法的措辞、问卷诱导性或受访者的态度问题，而非样本本身的代表性——这类选项力度通常不如直接指出样本偏颇
2. 当样本代表性没有问题但结论的推导逻辑有漏洞时，应换用逻辑漏洞类削弱方法 |
2. 选项均未涉及样本代表性问题，需要从其他角度（如因果、偷换概念）选择削弱项 |

## 补充说明

典型场景：五位大学生随机采访市民收入→推断该市收入高于全国。"采访场所都是高档商场"直接指出样本偏颇。类比经典题：上火车问大爷买着票没、杂志问卷调查读者消费水平。口诀：调查类题往样本上想，遇到完美样本质疑选项可优先选择。
