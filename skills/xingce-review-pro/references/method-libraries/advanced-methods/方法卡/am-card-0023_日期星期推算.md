# 方法卡：日期星期推算（平年余1闰年余2四年余5）
## 基本信息
| 字段 | 值 |
|------|-----|
| 方法名 | 日期星期推算（平年余1闰年余2四年余5） |
| 适用题型 | 数量关系-日期星期问题 |
| 触发场景 | 给定某天是星期几，求若干年后同月同日是星期几 |
| 步骤逻辑 | 1.记住核心口诀：平年余1，闰年余2，四年余5 2.将年数差拆为整4年周期+零头年数 3.整4年周期部分：周期数×5 4.零头年数：逐个判断是否经过2月29日，经过则余2否则余1 5.总余数对7取模，凑7的倍数后反推星期几 |
| 高频错因 | 忘记判断是否经过2月29日；余数凑整后反推方向搞反 |
| confidence | high |
## 补充说明
原理：365÷7=52余1（平年），366÷7=52余2（闰年），3平1闰=52×3+1+52+2余5（四年周期）。示例：2019→2039差20年=5个四年周期余25，再加2039→2040一年（未过2月29）余1，共余26。凑28（7的倍数）后退2，周六退2=周四。关键判断：日期是否经过中间年份的2月29日。

## 不适用条件
- 跨世纪大范围（如超过100年）且题目要求精确到具体日期时，逐周期累加易出错，宜直接查表
- 题目已给出总天数差，直接对7取模更简洁，无需拆年周期
- 起止日期不在同月同日，需要额外计算日差时，本口诀仅覆盖"同月同日跨年"场景

## 反向触发
- 看到"若干年后同一天是星期几""X年后的今天是星期几"，立刻联想平年余1闰年余2口诀
- 选项中星期几的值差异为7的倍数关系，说明需要精确算余数
- 题目涉及跨多个闰年的日期推算，且中间年份需判断是否经过2月29日
