# 方法卡：假设增量法与误差分析

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 假设增量法与误差分析 |
| 适用题型 | 资料分析——已知现期和增速求增量，选项间距较大 |
| 触发场景 | 选项差距足以覆盖假设误差，需要快速估算增量；或配合份数法、假设分配使用 |
| 步骤逻辑 | ① 选一个好算的增量假设值（让基期凑整）；② 反推基期 = 现期 - 假设增量；③ 用基期×增率验算增量；④ 分析误差 = 假设偏差×增率，判断是否影响选项判断 |
| 高频错因 | 不做误差分析就下结论；假设值离选项太远导致误差不可控 |
| confidence | high |

## 补充说明

假设增量法演示：假设增量值使基期凑整（如假设增量4910→基期刚好3万），验算3万×18.4%≈5开头，锁定答案。误差分析核心：假设值与各选项的差只有一定量级，乘以增率后误差仍在选项间距以内则可接受。与假设分配本质一致，区别在于"直接假设增量"而非"逐步分配"。

## 不适用条件

1. 假设增量法的传播误差可能跨越选项时，应改用精算
2. 假设偏差经增率放大后无法稳定区分选项时，方法可靠性不足
3. 题目给出的现期值不好凑整、找不到合适的假设增量时，应换用其他估算路径

## 反向触发

1. 当假设增量的误差分析结果显示误差已超出选项间距时，应换用精算模式或假设分配法
2. 当增率值不明确（题目只给范围或间接条件）时，需先确定增率再使用此法，否则误差分析无从做起
3. 当题目同时涉及多个时间段或多个组成部分时，单次假设增量可能不够，需额外核验或拆分处理
