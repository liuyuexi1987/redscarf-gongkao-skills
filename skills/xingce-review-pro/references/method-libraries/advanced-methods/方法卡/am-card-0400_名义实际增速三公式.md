# 方法卡：名义实际增速三公式

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 名义实际增速三公式 |
| 适用题型 | 资料分析——涉及"扣除价格因素""按实际增长""按可比价"的收入/产值/消费等题目 |
| 触发场景 | 材料给出名义增速、实际增速（或价格增速），要求按实际增速求增量、取值或反推价格增速 |
| 步骤逻辑 | 关系式：名义增速 = 实际增速 + 价格增速 + 实际增速×价格增速。三种应用：① 求按实际增速的增量：基期 = 现期/(1+名义增速)，增量 = 基期×实际增速；② 求按实际增速的取值：先求基期(同上)，再×(1+实际增速)；③ 反推价格增速：由名义和实际增速代入关系式解出 |
| 高频错因 | "扣除价格因素""按可比价"等于单价不变，不是名义；未识别百分点是增长量而非增长率；求实际增速增量时忘记先用名义增速求基期 |
| confidence | high |

## 补充说明

公式形式与乘积增长率相同（因为产值 = 价格 × 产量）。"扣除价格因素""实际增长""可比价"三者含义相同，均指单价不变。材料未提及这些词时，默认用名义数据。基期值无论名义还是实际都相同（同一时间点的原始值）。

## 不适用条件

- 材料直接给出实际值和基期值，无需通过名义增速和价格增速间接推算时
- 题目仅涉及名义值的简单增长率计算，未出现"扣除价格因素""按可比价"等提示词时
- 名义增速与实际增速差异小到不影响选项判断、近似加法已经足够时

## 反向触发

- 当题干同时给出名义增速和价格增速，但要求的是名义值（而非实际值）的增量时，应直接用名义增速计算，无需套用本方法的三步框架
- 当材料中"扣除价格因素"后的基期值本身已给出，应直接用给出的基期值乘以实际增速，不必再用名义增速反求基期
- 当题目要求比较名义增速和实际增速的大小关系本身（而非求值），应直接用关系式判断大小方向，不必代入具体数值计算
