# 方法卡：年均增速比大小用末期/基期

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 年均增速比大小用末期/基期 |
| 适用题型 | 资料分析 - 多个对象年均增速排序 |
| 触发场景 | 题目问"年均增速最快/最慢的是"，且各对象年份区间相同 |
| 步骤逻辑 | 1. 年份区间相同时，直接比较 末期值/基期值 即可；2. 无需真正开N次方根，比值最大的就是增速最快的；3. 逐个算末期/基期的倍数，找最大值 |
| 高频错因 | 老老实实算年均增长率公式开根号，浪费时间；搞混基期和末期的年份 |
| confidence | high |

## 不适用条件

- 各对象的年份区间不同（如A是2015-2020年，B是2016-2020年），不能直接比末期/基期，需换算到相同年份区间。
- 题目要求算出具体的年均增速数值而非排序比较时，不能跳过开根号步骤。
- 基期值为零或负数时，比值无意义，本方法不适用。

## 反向触发

- 题目问的是具体的年均增长率百分比数值而非比较大小。
- 各对象基期和末期的年份不一致，需要分别调整后再比较。
- 题目给出的是年均增长量而非年均增长率，比大小看的是绝对增量而非比值。
