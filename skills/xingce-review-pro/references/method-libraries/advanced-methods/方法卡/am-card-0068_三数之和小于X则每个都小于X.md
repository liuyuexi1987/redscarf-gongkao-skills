# 方法卡：三数之和<X则每个都<X（正数推理）

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 三数之和<X则每个都<X（正数推理） |
| 适用题型 | 资料分析 - 隐藏数据的逻辑推理判断 |
| 触发场景 | 表格只列部分数据，其余数据不可见但可算出总和，需要判断每个隐藏值是否满足某条件 |
| 步骤逻辑 | 1. 若 N 个正数之和 < X，则可推出每个数都 < X；2. 若 N 个正数之和 > X，则无法确定每个数都 > X（可能一大两小）；3. 应用：算出隐藏省市的总量，若总量<阈值，则每个省市都<阈值，无需逐个知道 |
| 高频错因 | 反向推理错误——看到和大于X就以为每个都大于X；忘记数据必须是正数的前提 |
| confidence | high |

## 不适用条件

1. 数据可能为零或负值时（如利润、同比变化量），"正数之和<X则每个<X"的前提不成立。
2. N个数的和恰好等于X——"每个<X"不成立（可能有一个恰好等于X其余为零），需更精确的条件判断。
3. 需要确定每个隐藏值的具体大小时——本法只能推上界，不能给出具体数值或下界。

## 反向触发

1. 题目表格已直接列出所有项的独立数据——无需通过总和反推隐藏值。
2. 需要判断的是"每个都>X"（下界推理）而非"每个<X"（上界推理）——N个正数之和>X无法推出每个>X，本法逻辑不适用。
3. 数据量N很大且总量接近N×X——每个数可能接近X但均未超过，此时仅靠总量判断粒度不足，可能需更精细的分析。
