# 方法卡：图形题必估

## 基本信息
| 字段 | 值 |
|------|-----|
| 方法名 | 图形题必估 |
| 适用题型 | 资料分析-图形题（饼图/柱状图选图题） |
| 触发场景 | 题目要求从ABCD四个图形中选出正确的一个 |
| 步骤逻辑 | 1. 识别题型为图形题<br>2. 大胆估算数据（不需要精算）<br>3. 排除明显不符的选项（如占比明显超过/不到一半排D）<br>4. 通过关键比例关系（如是否接近50%、1/4、1/8）在剩余选项中选择 |
| 高频错因 | 对图形题进行精算浪费时间；不会用拆分思想判断占比大小 |
| confidence | high |

## 补充说明
- 逻辑依据：如果数据需要精算才能区分，图形就不可能被肉眼识别出来，因此图形题选项间必然有较大差距。
- 拆分思想在此类题中高频使用：先判断是否超过50%（排除选项），再看与关键比例的差距大小。
- 本例中1月占比=1.7/4.5，接近50%但略小，拆分后判断比50%少约11%，对应饼图中约1/8的扇形。

## 不适用条件
1. 题目要求精确读数（如"XX年XX月的具体数值"），不能只靠估算。
2. 图形本身精度很高且选项差距很小（如折线图上相邻两根线），估算不足以区分。
3. 题目不是选图题而是常规计算题时，此方法不适用。

## 反向触发
1. 当四个选项的图形差异极小（如仅有细微角度差别），需要精算数据才能区分。
2. 当图形题选项中有"无法确定"或"以上都不对"时，不能仅凭估算排除，需要部分精算验证。
3. 当题目涉及多个子图形的联合判断（如双饼图、组合柱状图），单靠拆分思想可能不够，需要辅助计算。
