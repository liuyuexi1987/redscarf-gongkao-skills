# 方法卡：且或矛盾口诀

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 且或矛盾口诀 |
| 适用题型 | 判断推理-逻辑判断-矛盾关系辨析 |
| 触发场景 | 需要写出"且"或"或"命题的矛盾命题时 |
| 步骤逻辑 | 1. A且B的矛盾是：非A或非B 2. A或B的矛盾是：非A且非B 3. 口诀：且或互换，前后都否定 |
| 高频错因 | 把A且B的矛盾错误写成A且非B（这是A推B的矛盾）；把且关系和或关系的矛盾搞混 |
| confidence | high |
| 不适用条件 | 题目涉及三段论推理、充分必要条件或模态命题时，矛盾关系另有规则，不套用且或口诀；题干是"A推B"求矛盾，应直接用"A且非B"而非且或互换口诀 |
| 反向触发 | 口诀写出的矛盾命题代入原题后无法推出任何结论时，应检查是否将"A推B"误当成"A且B"来求矛盾；题目要求找等价命题而非矛盾命题时，应换用逆否命题等价转换方法 |

## 补充说明

三组标准矛盾关系：(1) 所有A是B ↔ 有些A不是B；(2) A推B ↔ A且非B；(3) A且B ↔ 非A或非B（以及 A或B ↔ 非A且非B）。牢记这三组，不要自己"发明"矛盾关系。
