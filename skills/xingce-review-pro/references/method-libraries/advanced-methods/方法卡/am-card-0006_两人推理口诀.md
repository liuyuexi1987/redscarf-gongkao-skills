# 方法卡：两人推理口诀

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 两人推理两个口诀 |
| 适用题型 | 判断推理——逻辑判断中的条件推理（涉及两人/两物的条件命题） |
| 触发场景 | 题目给出涉及A、B两个主体的条件命题，要求推出结论 |
| 步骤逻辑 | ① 口诀一"A不A都B"：A→B 和 ¬A→B 同时成立时，必有B成立（无论A是否成立，B都成立）；② 口诀二"A推B，A推非B"：A→B 和 A→¬B 同时成立时，必有¬A（A的前提不成立）；③ 直接口算，无需绕逆否命题 |
| 高频错因 | 遇到此类题时走逆否命题推导路径，浪费时间；口诀记混导致判断错误 |
| confidence | high |

## 补充说明

"A不A都B"本质是：两个条件推出同一个结论B，等价于"不论A如何，B都成立"。"A推B，A推非B"本质是：从A出发推出了矛盾，说明A本身不成立。

## 不适用条件

- 当条件涉及三个及以上主体时，两个口诀均不适用，需用更一般的逻辑推理方法。
- 当条件命题的前件不是简单的 A 与非 A 关系（如 A→B 和 C→B，C 不等于非 A），口诀不直接适用。
- 当题目涉及模态命题或假言连锁推理时，需要完整的逻辑链分析，口诀无法覆盖。

## 反向触发

- 题目包含三人以上条件关系时，用一般真值表或逻辑链推理。
- 当两个条件的前件不构成 A 与非 A 的互斥关系时，重新审视前提结构。
- 当推理链条超过两步时，画逻辑关系图辅助判断。
