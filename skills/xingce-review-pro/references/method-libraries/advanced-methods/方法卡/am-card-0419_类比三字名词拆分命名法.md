# 方法卡：类比三字名词拆分命名法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 类比三字名词拆分命名法 |
| 适用题型 | 类比推理（三字名词类） |
| 触发场景 | 题干给出三个字的物体名称，要求找命名方式的对应关系 |
| 步骤逻辑 | 1. 三字名词中，最后一个字决定物体的属性/类别（是什么东西）；2. 前面两个字是从某个角度对物体进行的命名/修饰；3. 常见命名角度：功能（驱蚊药→从作用角度命名）、材质、形状、颜色等；4. 解题时先确定"末字=类别"，再判断前两字的命名角度；5. 找选项中命名角度一致的对应项 |
| 高频错因 | 把三个字当成整体理解，不拆分属性和命名角度；混淆"功能"和"用途" |
| confidence | medium |

## 不适用条件

- 题干为两字名词或四字成语/熟语类比，命名逻辑与三字名词不同，不可套用末字定类别的拆分规则
- 三字名词中，前两字的命名角度无法明确归为功能/材质/形状/颜色等常见类别时，应从整体语义关系判断
- 题目考查的是词语间的逻辑关系（如因果、包含、并列）而非命名方式对应时

## 反向触发

- 当末字不构成同一语义类别（如一个末字指物体、另一个末字指动作），应考虑整体语义关系而非拆分命名
- 当前两字涉及两种不同的命名角度（如一个是功能、一个是材质），选项中可能只匹配其中一种角度，应逐角度比较而非笼统匹配
- 当题干中出现叠字或谐音等修辞命名时，拆分逻辑可能不适用，应从修辞手法角度寻找对应
