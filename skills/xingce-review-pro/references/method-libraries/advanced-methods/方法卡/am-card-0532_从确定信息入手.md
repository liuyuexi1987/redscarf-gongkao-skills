# 方法卡：从确定信息入手

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 从确定信息入手 |
| 适用题型 | 排列组合/分析推理（判断推理） |
| 触发场景 | 题干给出多个条件，既有确定信息（如"某人去了某地""某职位由某人担任"）又有条件信息（如"若A则B""只有C才D"） |
| 步骤逻辑 | 1. 区分确定信息和条件信息：确定信息可直接使用，条件信息需要前提触发；2. 优先从确定信息入手，将其填入表格或画图；3. 确定信息填完后，检查哪些条件信息可以被已填入的信息触发；4. 能触发的继续填入，暂时不能触发的先跳过；5. 循环往复，直到所有能推的都推完 |
| 验证动作 | 检查最终推理结果是否满足所有条件（确定信息和条件信息都无矛盾）；若出现冲突则回溯检查是否有条件被误触发 |
| 不适用条件 | 当所有信息都是条件信息、没有确定信息时，此法无法启动，需换用假设法或最大信息法（参见 am-card-0533、am-card-0557）；注意"只有X"等限定词标识的是必要条件而非确定信息，不要混淆 |
| 高频错因 | 从条件信息入手，发现推不动就卡住；忽略"只有"等限定词，把条件信息误当确定信息 |
| confidence | high |
| 反向触发 | 从确定信息出发推理到某一步时出现矛盾或无解，应回溯检查是否误判了确定信息与条件信息的边界（如把必要条件当成了确定事实）；确定信息全部用完但仍有多个对象未确定且无条件可触发时，切换为假设法对剩余未定对象做分支推理 |
