# 方法卡：五种对策识别标志

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 五种对策识别标志 |
| 适用题型 | 言语理解——片段阅读（主旨/意图题） |
| 触发场景 | 需要在文段中快速识别哪些句子是对策性表述 |
| 步骤逻辑 | ① 祈使/建议型：直接告诉该做什么（应该、需要、要、可以）；② 禁止型：告诉不能做什么（不能、不得、禁止）；③ 逻辑关键词型：条件句表对策（只有才、如果就、必须、既然就）；④ 必要条件型：基础、关键、前提、离不开、必不可少、不可或缺；⑤ 语义型：用语义暗示对策（必由之路、时代命题、重要议题、关系到） |
| 高频错因 | 只认"应该/必须"等明显标志词，忽略语义型和必要条件型；混淆对策与问题描述（如"任重道远"是描述而非对策） |
| confidence | medium |
| 反向触发 | - 题干问的是"作者的态度/观点"而非对策选择，文段为纯议论分析无对策意图，不需要对策标志词扫描。- 题目选项均为原因分析或背景描述，没有对策性选项，应触发因果关系分析或主旨概括。 |
| 不适用条件 | 标志词仅作为定位线索，不能仅凭标志词就判定该句为对策；语义型标志词（如"有利于""重要议题"）需要结合文段整体语境验证是否真正表达对策意图，不能单独证明是对策。 |

> **使用边界**：本方法用于提供优先检查方向，不可单独据此作答；最终需回到题干关系、原文证据或选项条件完成验证。

**不适用条件**：标志词仅作为定位线索，不能仅凭标志词就判定该句为对策；语义型标志词（如"有利于""重要议题"）需要结合文段整体语境验证是否真正表达对策意图，不能单独证明是对策。
