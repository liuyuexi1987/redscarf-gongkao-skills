# 方法卡：循环倒出+补满的浓度变化

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 循环倒出+补满的浓度变化 |
| 适用题型 | 反复倒出部分溶液再加水（或其他溶液）补满 |
| 触发场景 | 题目出现"倒出X比例后加水补满，重复N次" |
| 步骤逻辑 | 1. 每次倒出再补满，浓度按固定比例变化；2. 若倒出a比例再加水补满，每次浓度变为原来的(1-a)；3. 重复N次后浓度 = 初始浓度 × (1-a)^N；4. 若补的不是水而是其他浓度的溶液，可用"平移法"：统一减去补液浓度，计算后再加回来 |
| 高频错因 | 误认为倒出部分会影响浓度（倒出不影响浓度，只有补满才影响） |
| confidence | high |

## 补充说明

补液非水时的"平移法"：把所有浓度统一减去补液浓度，按纯水方式算，最后再加回来

## 不适用条件

- 只倒出不补满时不适用（浓度不变）
- 非固定比例倒出或不规律操作时不适用

## 反向触发

- 补液为不同浓度溶液且规律复杂时，可改用方程法逐步列式
- 单次倒出补满时可直接列方程，无需套用幂次公式
