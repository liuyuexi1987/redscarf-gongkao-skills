# 方法卡：主体一致性排除

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 主体一致性排除 |
| 适用题型 | 片段阅读-中心理解题 |
| 触发场景 | 选项主语/主体与原文不一致，或与其他选项相比主体缺失 |
| 步骤逻辑 | 1. 原文全文反复出现的主体（主语），选项必须匹配；2. 若选项完全没提到原文的高频主体，直接排除；3. 主体缺失比主体多一个修饰语（如省略"我国"）更严重；4. 但"我国"在都给自己人写的文章中可以省略，需结合语境判断 |
| 高频错因 | 只看选项内容对不对，不看主体是否匹配原文 |
| confidence | medium |

## 不适用条件

1. 题目问的不是主旨/概括，而是文段中某个具体细节或定义，此时主体缺失的选项不一定是错的。
2. 文段存在多个并列主体，且没有明确的主次关系，不能只看高频主体排除。
3. 选项使用了原文主体的上位概念或下位概念（如原文说"数字经济"选项说"经济"），需要结合语境判断是否属于偷换，而非直接排除。

## 反向触发

1. 主体匹配的选项有两个以上时，需回到原文对比内容覆盖度，结合选项逆推反推法。
2. 如果选项主体与原文一致但褒贬倾向相反，排除时不仅要看主体，还要看倾向是否匹配。
3. 文段为对比结构（如"他国vs我国"），两个主体都在文中高频出现，不能只排除其一，需看哪个是作者侧重。
