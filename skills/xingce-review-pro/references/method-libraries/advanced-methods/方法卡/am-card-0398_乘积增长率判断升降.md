# 方法卡：乘积增长率判断升降

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 乘积增长率判断升降 |
| 适用题型 | 资料分析——判断A×B（如利润=收入×利润率）相对于去年是上升还是下降 |
| 触发场景 | 所问指标可表示为两数之乘积，题目问"高于/低于去年"即求变化趋势 |
| 步骤逻辑 | ① 用指标公式化将所问量表达为A×B；② 分别找A、B各自的增长率rA、rB；③ 代入乘积增长率公式 rA×B = rA + rB + rA×rB；④ 判断结果正负：正→上升，负→下降 |
| 高频错因 | 百分点当百分比用——"同比下降0.64个百分点"是增长量（差值），不是增长率，需先算增速；把利润率的现期值(6.09%)当成增速 |
| confidence | high |

## 不适用条件

- 数据中缺少A、B两个量中至少一个的增长率，无法代入乘积增长率公式
- 所问指标不是两数之乘积形式（如直接给出总量及增速），乘积公式不适用
- 题目要求的是具体数值大小而非升降趋势，仅判断正负号不满足需求

## 反向触发

- 若利润率等百分数指标给的是"百分点"变动，不能直接当作增长率使用，应回文确认是百分点差值还是百分比增速后再代入公式
- 若公式中 rA 或 rB 的符号相反且绝对值接近，rA×rB 项可能影响正负判断，不能仅凭 rA+rB 的符号下结论，应代入完整公式再判断
- 若利润不是"收入×利润率"（如利润=收入-成本），乘积公式不适用，应换用加减关系的增长率判断方式

## 补充说明

关键区分：百分点代表百分数的差值，不是增长率。若给出现期百分比值和"下降N个百分点"，利润率增速 = -N / (现期百分比数值+N) ，不能直接将百分点当百分比使用。代入乘积增长率公式后只需判断正负号即可判断升降趋势，无需精确计算。
