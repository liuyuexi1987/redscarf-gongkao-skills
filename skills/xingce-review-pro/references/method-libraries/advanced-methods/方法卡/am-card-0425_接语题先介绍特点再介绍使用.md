# 方法卡：接语题先介绍特点再介绍使用

## 基本信息

| 字段 | 值 |
|---|---|
| 方法名 | 接语题先介绍特点再介绍使用 |
| 适用题型 | 言语理解——接语题（下文推断） |
| 触发场景 | 尾句引出一个新概念，选项分别对应定义、特点、原则、使用方法等不同展开方向 |
| 步骤逻辑 | ① 尾句引出新概念时，下文应先介绍"是什么"（定义/界定）；② 再介绍特点、原则等属性；③ 最后介绍如何使用；④ 若尾句已有"较为典型的一个"等暗示性表述，"典型"虽暗含"有特点"，但概念本身还未介绍过，仍应先给定义；⑤ 选最符合"先是什么→再特点→再怎么用"展开顺序的选项 |
| 不适用条件 | 仅当尾句引出全新概念时适用；若尾句是总结、转折或问题，应使用其他下文推断方法（如尾句优先、总分顺延） |
| 高频错因 | 跳过定义直接选"特点"或"使用方法"，逻辑顺序不对；被"典型""著名"等暗示性词汇误导，直接选了特点类选项 |
| confidence | high |
| 反向触发 | 尾句已有完整定义或介绍，引出的是"如何应用"而非新概念时，应选定使用方法类选项而非按先定义再特点的顺序；选项中同时出现原因解释和定义介绍，且尾句暗示需要解释"为什么"时，应优先原因类选项 |


> **使用边界**：本方法用于提供优先检查方向，不可单独据此作答；最终需回到题干关系、原文证据或选项条件完成验证。
