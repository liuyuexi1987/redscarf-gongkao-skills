# 方法卡：年均增速反向验证

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 年均增速反向验证 |
| 适用题型 | 资料分析——判断同比增速是否高于年均增速 |
| 触发场景 | 题目问"某年同比增速是否高于X~Y年的年均增速"，不需要开根号，反向验证即可 |
| 步骤逻辑 | ① 算出同比增速（待判断值）；② 把这个增速代入，用复合公式算出N年的总增速；③ 再算实际N年的总增速（末年/初年-1）；④ 代入总增速 < 实际总增速 → 年均增速高于该值 → 同比低于年均 |
| 高频错因 | 反向操作（去开根号求年均）；年数搞错；复合计算时把简单乘法当成复利 |
| confidence | high |

## 补充说明

完整演示：同比增速约8%，代入4年总增速≈36%，但实际总增速（如2.79→4.45）超50%，36%<50% → 实际年均高于8% → 同比低于年均。核心要点：不需要开根号，通过代入验证即可判断高低关系。此方法在正确率极低的高难度题中尤为实用。

## 不适用条件

1. 题目要求精确求出年均增速数值时，反向验证只能判断高低，不能给出精确结果
2. 年数为1年时不存在年均概念，反向验证无意义
3. 基期或末期数据缺失无法算出实际总增速时，此法无法使用

## 反向触发

1. 当需要精确计算年均增速（而非仅判断高低）时，应换用年均增速比例法或近似公式
2. 当代入验证后发现总增速差距极小时（如36% vs 37%），反向验证的判断可能不可靠，需额外核验
3. 当题目给出的不是整年区间（如3.5年）时，复合公式的年数处理需特别注意，应先确认年数取值
