# 方法卡：比例乘除法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 比例乘除法 |
| 适用题型 | 数量关系、资料分析——比例关系与复合量 |
| 触发场景 | 两个复合量之间存在明确乘除关系，需要由已知比值推出新的比值 |
| 步骤逻辑 | 1. 确认两个比值之间是乘法或除法关系（如 总量 = 单量 × 数量）；2. 对应项直接相乘或相除：甲的比值与乙的比值分别运算；3. 得到新的比值；4. 注意：加减法不能直接对比例操作，必须保证每份的量相同 |
| 高频错因 | 把加减法关系的比例直接相加减（错误）混淆"总成本之比"和"单个成本之比" |
| confidence | medium |
| 不适用条件 | 比例之间为加减法关系（如合并求总比）时不能直接对比例做加减，必须先统一分母；单一比例直接比较大小的题目不需要此法 |
| 反向触发 | 当比例之间实为加减法关系却误用乘除、或统一分母后仍无法简化时，改用设份数列方程的常规方法精算 |

## 补充说明

示例：甲乙月薪比3:4，工作月数比1:2，则总工资比 = 3×1 : 4×2 = 3:8。但加减法不行——必须先统一分母才能加减。在利润率问题中，已知总成本之比和单个成本之比，用除法得数量之比。
