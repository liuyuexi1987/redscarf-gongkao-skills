# 方法卡：图推截面判定法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 图推截面判定法 |
| 适用题型 | 判断推理——图形推理·截面题 |
| 触发场景 | 题目给出一个立体图形，问"用一个平面去切，可能/不可能看到哪个截面形状"；或给出截面图，问由哪个立体图形切出 |
| 步骤逻辑 | ① 识别题型：看到"切""截面""切面"→确认是截面题，不是三视图题；② 记住截面三原则：一刀切（一个平面切一次）、无限延展（切面可延伸到整个立体）、平面不拐弯（同一截面不能中途折转）；③ 按立体类型判断常见截面：六面体→三角形/四边形/五边形/六边形（边数3-6），圆柱→横切圆/斜切椭圆/纵切矩形，圆锥→横切圆/斜切椭圆/纵切三角；④ 排除违反原则的选项：需要多刀或折线切割才能形成的形状→排除；边数超出该立体可切范围→排除 |
| 高频错因 | ① 把截面题当三视图题做，用投影思维而非切割思维；② 忘记"一刀切"原则，以为可以切两次拼出形状；③ 不知道六面体不能切出7边及以上的多边形；④ 圆柱斜切误以为是正圆（实际是椭圆）；⑤ 把"平面不拐弯"误解成截线不能转折——多面体截面本来可以是多边形 |

## 方法说明

截面题的核心思维是**切割想象**：用一个无限大的平面去"切"立体图形，看切口轮廓是什么形状。

**截面三原则：**
1. **一刀切**：只能切一次，不能切两次拼在一起。如果某形状需要切两次才能得到，则不可能是截面。
2. **无限大**：切面可以无限延伸，不必局限于立体图形的大小。所以切面可以"穿过"立体的任意位置。
3. **平面不拐弯**：切割面本身必须是同一个平面，不能中途折转或分两刀拼接。多面体截面通常是直线段围成的多边形，边与边之间当然会形成角；圆柱/圆锥等曲面体的截面可以是圆、椭圆等曲线形状。

**六面体常见截面：**
- 三角形：切过三个面；是否为直角三角形要看切面与立体的位置关系，不能仅凭"六面体"一概排除
- 四边形：切过四个面（正方形/矩形/梯形/平行四边形都可能）
- 五边形：切过五个面
- 六边形：切过六个面（正六边形需要特殊角度）
- 不可能出现：7边及以上、含曲线的形状

**圆柱/圆锥/圆台截面区分：**
- 圆柱：横切→圆，斜切→椭圆，纵切→矩形
- 圆锥：横切→圆，斜切→椭圆，纵切→三角形（等腰），过底面斜切→半椭圆+直线段
- 圆台：横切→圆（比底面小），斜切→椭圆

**组合方块截面题：**
遇到由多个小方块组成的立体，先确定切割平面穿过哪些层/哪些列，再分析每层被切到的方块数和位置分布；不要把方块投影视图当作截面。

## 使用边界

- 适用于：截面题（问"切出来是什么形状"）
- 不适用于：三视图题（问"从某个方向看是什么轮廓"）→用 1131 三视图判定法
- 不适用于：六面体展开图折叠题→用 1127
- 截面有正反两面：同一个截面旋转180度后可能对应不同切割方式

## 不适用条件

1. 三视图题（问"从某方向看是什么轮廓"，应改用1131三视图判定法）
2. 六面体展开图折叠题（应改用1127六面体折叠判定法）
3. 立体拼合题（应改用1087立体拼合一层一层看法）

## 反向触发

1. 截面边数在合理范围内但形状无法确定时，应补充核验切面穿过的面数和位置
2. 圆柱/圆锥截面形状判断不清时，应补充核验切割角度（横切/斜切/纵切）
3. 组合方块截面与三视图混淆时，应回到关键词"切/截面"vs"看/视图/投影"重新确认题型

## 观察顺序

1. 确认题型：是截面题还是三视图题？（关键词：切/截面 vs 看/视图/投影）
2. 确定立体类型：六面体？圆柱？圆锥？组合体？
3. 用截面三原则逐项排除：边数是否合理？是否含非法曲线？是否需要切两次？
4. 对剩余选项做精确验证：切割角度和位置是否能产生该形状

## 常见错因

1. 截面题和三视图题混淆——截面是"切"，三视图是"看"
2. 看到三角形就只凭直角/锐角判断——应回到切面是否能同时穿过对应的面与边
3. 圆柱斜切误判为正圆——斜切是椭圆
4. 忘记截面可旋转180度——同一形状正反面可能不同
5. 不知道六面体截面边数上限是6
