# 方法卡：立体拼合一层一层看法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 立体拼合一层一层看法 |
| 适用题型 | 判断推理——图形推理（立体拼合） |
| 触发场景 | 立体拼合题（不旋转类型） |
| 步骤逻辑 | ① 一层一层看，按九宫格分析每层已有/缺少的部分；② 用排除法：选项中某层多了/少了的部分→排除；③ 空间想象能力不足时可以买积木从各角度观察练习 |
| 高频错因 | ① 不分层看→整体想象不了；② 不用排除法→在所有选项中纠结 |
| confidence | medium |

## 补充说明
立体拼合的核心策略是"分层分析"。把立体图形分成若干层，每层分析已有/缺少的部分，用排除法逐步缩小选项范围。

## 不适用条件

- 题目允许旋转的立体拼合题，分层分析前需先处理旋转可能性。
- 拼合件数量极少（如仅2-3块）且整体形态简单时，分层分析反而增加步骤。

## 反向触发

- 分层后某层缺口与所有选项都不匹配时，应换用整体投影法或三视图法补充核验。
- 拼合件存在明显旋转特征时，应先做旋转判定再回到分层分析。
