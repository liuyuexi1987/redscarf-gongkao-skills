# 方法卡：图推开闭图形分类法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 图推开闭图形分类法 |
| 适用题型 | 判断推理——图形推理 |
| 触发场景 | 图推中图形有开放/封闭特征 |
| 步骤逻辑 | ① 将图形按开闭性分类：全开放/全封闭/半开半闭；② 分类后看是否有规律（如开放→封闭→开放→封闭）；③ 开闭性是图推的"隐藏考点"，不容易第一时间想到 |
| 高频错因 | ① 不注意开闭性→漏掉规律；② 开闭性与其他规律混合→难以识别 |
| confidence | medium |

## 补充说明
开闭性是图推中较隐蔽的考点。观察特殊图形时注意：断开的图形（开放）vs 封闭的图形（封闭）vs 部分开放部分封闭（半开半闭）。

## 不适用条件

- 图形明显呈现移动、旋转、翻转、叠加等低变化规律时，开闭性通常不是主考点。
- 图形以数量关系（点、线、面、角、元素个数）为明显规律时，优先走数量路径。

## 反向触发

- 多数图都有封闭区域且封闭区域数量稳定时，应换用"数面"路径而非仅判开闭。
- 开闭性规律不成立但图形属性仍可疑时，应补充核验对称、曲直等其他属性维度。
