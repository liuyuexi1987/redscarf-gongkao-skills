# 方法卡：图推藏与找模型：变藏不变与不变设变

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 图推藏与找模型：变藏不变与不变设变 |
| 适用题型 | 判断推理——图形推理 |
| 触发场景 | 理解图推命题逻辑，建立解题思维框架 |
| 步骤逻辑 | ① 理解命题逻辑：图推常通过变化隐藏稳定规律；② 规律必须相对唯一、稳定、可验证；③ 两种藏法识别：变藏不变（表面变化大→稳定规律被干扰项遮住）、不变设变（有共同背景/结构→变化被共同背景衬托）；④ 变藏不变应对：图变化很大时，先找共同属性或稳定约束；⑤ 不变设变应对：先找到不变的背景/结构，再看围绕它怎么变化 |

| confidence | high |

## 补充说明

**底层命题逻辑：图推 = 稳定规律识别**

判定一条候选规律时的验证标准：
1. 规律必须是**不变的**（恒定唯一）
2. 规律能解释已知图并对未知图产生有效约束
3. 不把只在个别图中出现的偶然细节当成主规律
4. 有多条规律都能解释时，用选项和全组图继续证伪

**两种常见结构：不变设变，变藏不变**

### 不变设变（相对简单）
- 结构：用**不变**的背景/结构来衬托**变化**
- 特点：有明显的共同背景（如九宫格、棋盘、外框）
- 应对：先找到不变的背景，再观察什么在变、怎么变
- 举例：九宫格里小球每次顺时针移动一格（九宫格不变，小球在变）

### 变藏不变（真正的难题）
- 结构：用**各种变化**来包装/隐藏**不变的规律**
- 特点：表面变化很大，感觉"所有图都在变"
- 应对：不要被表面复杂性干扰，先找共同属性、共同数量或共同结构
- 举例：所有图都长得很不一样，但都有3个面（变化藏住了"3个面"这个不变规律）

**经验判断：**
- 变藏不变 → 表面差异大，优先找共同属性或稳定约束
- 不变设变 → 有背景衬托，优先观察背景内的变化方式

**思维框架：**
> 看到图变化很大时 → 想"变藏不变" → 先找所有图的共同属性
> 看到图有共同背景时 → 想"不变设变" → 先锁定背景，再观察变化规律

## 不适用条件

- 图形数量过少无法判断"稳定规律"时，本模型难以成立。
- 图形规律明显属于纯数量类（点、线、面计数）或纯属性类（对称、曲直）时，不需要套用藏与找模型。

## 反向触发

- "变藏不变"找到的共同属性无法解释个别图形时，应换用"识不同"策略补充核验。
- "不变设变"锁定背景后变化规律仍不清晰时，应回查背景选择是否正确，或换用总纲观察顺序重新排查。
