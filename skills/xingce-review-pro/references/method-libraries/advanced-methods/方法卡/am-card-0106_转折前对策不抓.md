# 方法卡：转折前对策不抓

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 转折前对策不抓 |
| 适用题型 | 中心理解题（说理类文段） |
| 触发场景 | 文段前面有对策，中间出现"但是/然而/不过"转折，转折后提出新问题 |
| 步骤逻辑 | 1. 识别转折词位置；2. 转折前即使有对策，也不能抓（因为后面有转折）；3. 转折后提出的新问题才是主旨方向；4. 针对新问题的对策才是真正的主旨对策；5. 转折前的对策作用只是引出话题 |
| 高频错因 | 看到前面有对策就机械选对策，忽略后面的转折把转折前的对策和转折后的对策搞混没有分析转折后的新问题到底是什么 |
| confidence | high |

## 不适用条件

1. 转折后没有提出新问题，而是对前面对策的补充或具体化——转折前后方向一致，前面的对策仍是主旨组成部分。
2. "但是/然而"是弱转折或补充性转折（如"但更重要的是"），转折前后对策方向一致——弱转折不否定前面对策。
3. 转折前的对策是全文主旨句，转折后内容是举例或展开说明——转折后内容服务于前面的主旨。

## 反向触发

1. 转折后提出的是对策而非问题，应判断新对策是否替代了前面对策——参见"问题对策无优先级"。
2. 转折词出现在文段中部，后面还有进一步的总结或概括句——主旨可能在最终总结处而非转折处。
3. 转折前的对策有非常明确的论据支撑，转折后的问题只是引子——需综合判断哪个是核心。
