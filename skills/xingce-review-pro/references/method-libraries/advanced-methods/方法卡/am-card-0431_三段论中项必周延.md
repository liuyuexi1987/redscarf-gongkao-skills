# 方法卡：三段论-中项必周延

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 三段论-中项必周延 |
| 适用题型 | 判断推理-逻辑判断-三段论 |
| 触发场景 | 三段论题目中，前三项判断（量词/肯否/主体）无法排除所有错误选项时，用周延做终极排除 |
| 步骤逻辑 | ① 找中项：只出现在两个前提、不出现在结论中的概念；② 按命题类型判断周延：全称肯定“所有S是P”周延S；全称否定“所有S不是P”周延S和P；特称肯定“有些S是P”均不周延；特称否定“有些S不是P”周延P；③ 中项必须至少在一个前提中周延，否则排除；④ 结论中周延的项，在前提中也必须周延，否则属于大项或小项不当周延 |
| 验证动作 | 先把自然语言改写为四种标准直言命题，再逐项标记周延；最后用文氏图检查结论是否必然成立 |
| 不适用条件 | 命题不是直言命题，或主谓项尚未统一时，不直接套周延表 |
| 高频错因 | 误认为“所有”同时周延主项和谓项；忘记特称否定只周延谓项；只检查中项而漏掉结论项的不当周延 |
| confidence | high |
| 反向触发 | 周延检查通过但文氏图显示结论只是"可能成立"而非"必然成立"时，应放弃该选项；周延规则排除后无剩余选项，说明题目可能涉及关系推理或复合命题，应回头检查是否套错规则 |
