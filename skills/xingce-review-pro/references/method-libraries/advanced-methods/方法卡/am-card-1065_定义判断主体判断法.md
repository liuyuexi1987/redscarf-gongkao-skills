# 方法卡：定义判断主体判断法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 定义判断主体判断法 |
| 适用题型 | 判断推理——定义判断 |
| 触发场景 | 定义中明确或隐含主体（谁做的） |
| 步骤逻辑 | ① 找到定义的主体（如"政府""企业""个人"）；② 检查选项的主体是否匹配；③ 主体不匹配→直接排除 |
| 高频错因 | ① 忽略主体→选了主体不对的选项；② "互益素"→"他种生物"vs"同种生物"直接决定选项 |
| confidence | high |

## 不适用条件
- 定义中没有明确或隐含的主体（如纯描述性定义）
- 题目考查的是条件、方式或结果而非主体
- 多个选项的主体都匹配时，需用其他要素进一步筛选

## 反向触发
- 定义中找不到"谁做的"这类主体指向时，不应强行套用主体判断法
- 题目问的是"属于""不属于"且定义本身不含主体信息时
