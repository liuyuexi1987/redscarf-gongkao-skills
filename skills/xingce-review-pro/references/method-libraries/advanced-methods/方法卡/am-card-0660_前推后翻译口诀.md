# 方法卡：前推后翻译口诀

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 前推后翻译口诀 |
| 适用题型 | 翻译推理（充分条件假言命题） |
| 触发场景 | 题干出现"如果那么""只要就""一就""若则""所有都"等关联词 |
| 步骤逻辑 | 1. 识别充分条件关联词：如果…就、只要…就、一…就、若…则、所有…都；2. 翻译规则：前件推后件（A推B）；3. "所有A都是B"等价于"如果A那么B"，也翻译成A推B；4. "A就能B"也是前推后：A推B |
| 高频错因 | 把"只要就"误判为后推前；混淆"所有都"的翻译方向 |
| confidence | medium |
| 不适用条件 | - 关联词是 |
| 反向触发 | - 出现 |

## 补充说明

正常言语表达"如果…就…"就是前推后，翻译成逻辑语言即可。
