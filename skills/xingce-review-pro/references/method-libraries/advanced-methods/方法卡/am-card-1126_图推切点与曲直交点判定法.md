## 方法说明

切点与曲直交点是图推中一个隐蔽但高频的考点。当图形包含曲线（圆弧、半圆、椭圆）与直线段相交的结构时，曲直交点数往往就是规律所在。

**切点**：曲线与直线（或曲线与曲线）仅在一个点处接触，不穿过。视觉上表现为"轻轻碰了一下"。

**交点**：曲线与直线（或曲线与曲线）相互穿过。视觉上表现为"交叉"或"穿过去"。

**混合型**：同一图中既有切点又有交点，需要分别计数后再分别验证规律。

**排查三层法**：
- 第一层：总数（切点+交点）→ 快速验证，命中即选
- 第二层：分类型（切点数、交点数各自独立）→ 总数无规律时分开验证
- 第三层：位置关系（内部/边界/与面的关系）→ 前两层都不成立时深入分析

切点特征在近年考试中出现频率较高。当图形中出现圆弧与线段相切的结构时，优先考虑切点数量规律。

## 使用边界

- 适用于：图形包含曲线与直线/曲线相交的结构
- 不适用于：纯直线图形（无曲线元素）
- 不适用于：曲线元素与直线元素分离不相交的情况
- 与 1105（线条笔画特征触发法）区分：1105 处理一笔画/两笔画判定，本卡处理曲线与直线交点数量规律

## 观察顺序

1. 扫图识别：是否有曲线元素（圆弧、半圆、椭圆）与直线相交
2. 粗数曲直交点总数，验证是否有规律
3. 总数无规律时，分别数切点数和交点数，各自验证
4. 前两层都无规律时，检查交点位置（内部/边界/与面的关系）

## 常见错因

1. 切点和交点混数，导致规律不成立
2. 漏数封闭面内部的曲直交点
3. 线条多时只数直线交点，忽略曲线交点
4. 总数有规律时直接选，不验证分类型是否有更精确的规律

## 与已有卡关系

- 与 1105（线条笔画特征触发法）：1105 处理"一根线/两根线→笔画数"，本卡处理"曲线与直线相交→交点数量"
- 与 1107（圆形与相交图形特征触发法）：1107 处理"圆与圆相交→交点/封闭区域"，本卡处理"曲线与直线相交→切点/交点"
- 与 1121（数量规律分层排查法）：1121 是数量规律的整体排查框架，本卡是切点/曲直交点这一具体考点的专项判定
- 与 1122（局部规律系统遍历法）：1122 中"点"的排查提到"总交点数、框内交点数"，本卡专门针对曲直交点和切点的细分判定
