# 方法卡：份额即占比理解法

| 字段 | 内容 |
|------|------|
| 方法名 | 份额即占比理解法 |
| 适用题型 | 资料分析-涉及"份额""市场份额""占比"的题目 |
| 触发场景 | 题目出现"份额""市场占比"等表述，需要用存续规模/产值等计算占比 |
| 步骤逻辑 | 1. 读题看到"份额"→理解为"占比" → 2. 份额 = 部分的量 ÷ 整体的量 → 3. 用题目给定的规模指标作分子，整体规模作分母 → 4. 再套用比值倍数或比重差公式 |
| 高频错因 | 不理解"份额"即"占比"，找不到分子分母关系；误把份额当绝对量 |
| 不适用条件 | 题目中的"份额"明确指绝对数量（如销量份额=具体件数）而非比率时 |
| 反向触发 | 题目用"份额"表达的是绝对量或排名，无需计算比率时 |
| confidence | high |

补充说明：本方法强调"份额就是占比"，题目说"用存续规模计算市场份额"，就意味着理财公司存续规模÷整体存续规模=市场份额。部分在前找，整体往前找，确定分子分母后套公式。
