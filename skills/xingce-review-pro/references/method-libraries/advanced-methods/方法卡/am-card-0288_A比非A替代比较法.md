# 方法卡：A比非A替代比较法

| 字段 | 内容 |
|------|------|
| 方法名 | A比非A替代比较法 |
| 适用题型 | 资料分析-比较多个部分占整体比重大小 |
| 触发场景 | 多年份比较"某部分占整体比重最大"，用部分÷(整体-部分)替代部分÷整体来比较 |
| 步骤逻辑 | 1. 识别需要比较 A/(A+B) 的大小 → 2. 转化为比较 A/(B的其他部分)，即A比非A → 3. 分母变小但排序不变，计算更简单 → 4. 数值越大比重越大 |
| 高频错因 | 不知道可以用此替代法，直接算每个年份的比重再比较，计算量大 |
| 不适用条件 | 题目要求精确计算比重值而非比较排序，或只有单个年份无需比较时 |
| 反向触发 | 题目要求的是具体比重数值，或分母差异过大导致替代法精度不足时 |
| confidence | high |

补充说明：原理是 A/(A+B) 与 A/B 的排序关系一致（A越大、B越小，两者都越大）。实际操作时直接用部分÷其余部分，省去算总量的步骤，比较排序更快。
