# 方法卡：对比时间归因回归时间法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 对比时间归因回归时间法 |
| 适用题型 | 归因类论证题（支持/削弱），涉及时间前后对比 |
| 触发场景 | 题干通过时间对比得出因果结论（如去年A，今年B，所以某因素导致B）；问削弱/最不能削弱 |
| 步骤逻辑 | 1. 识别题干是否在做时间对比归因（过去vs现在）；2. 要削弱该归因，他因选项**必须回归时间**才有力度；3. 若他因选项未涉及时间变化（如"一直存在"的因素），则无法解释"为什么现在和过去不同"；4. 直接用"回归时间"检验：选项是否能回答"之前也这样，为什么现在变了？" |
| 高频错因 | 选了看似有道理但他因没有回归时间的选项（如"一直存在"的因素），无法解释时间差异 |
| confidence | high |

## 不适用条件

1. 题干归因不涉及时间前后对比（如同期不同群体的对比实验）
2. 问法为"前提假设"或"推理"，而非削弱/支持
3. 题干通过分组对比而非时间变化得出结论

## 反向触发

1. 题干对比的是同期不同组别，而非过去vs现在
2. 选项讨论的因素在时间前后都不变（如遗传因素），无法解释差异
3. 问"最能支持"且选项能正向强化时间归因，无需用回归时间法检验
