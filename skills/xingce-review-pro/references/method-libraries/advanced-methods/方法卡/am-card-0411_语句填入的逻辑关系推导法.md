# 方法卡：语句填入的逻辑关系推导法

## 基本信息

| 字段 | 值 |
|---|---|
| 方法名 | 语句填入的逻辑关系推导法 |
| 适用题型 | 言语理解——语句填入题（横线在句中或句尾） |
| 触发场景 | 横线位于句子中间（前后有逗号），前后文有明确的逻辑关系（如否定+转折、对比、并列） |
| 步骤逻辑 | ① 看横线前的句式判断逻辑方向：若为否定句式（如"并非X""不是X"），则后面应接肯定表述Y；② 看横线后的论据或解释，反推Y的具体内容——后文论据在强调什么，Y就应指向什么；③ 排除与前后文逻辑关系不匹配的选项：如后文论据只支持单一方向（如"动态"），则排除"动静交替"等过度推断的选项 |
| 不适用条件 | 仅适用于横线前后有明确逻辑标记（否定+转折、对比、并列等）的情况；若横线前后无明显逻辑关系，应使用总括性、话题一致性等其他语句填入方法 |
| 高频错因 | 只看横线前的否定句式就仓促选答案，忽略了用后文论据验证；忽略"并非X"后面应接肯定表述，选了否定或折中表述 |
| confidence | high |
| 反向触发 | 横线处既无逻辑标记也无前后文明显逻辑关系时，本方法不适用，应改用话题一致性、总括性等方法判断填入内容；逻辑推导后仍有多个选项匹配时，需进一步检查选项与前后文的具体话题、主语和表述是否一一对应 |
