# 方法卡：杂糅选项识别

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 杂糅选项识别 |
| 适用题型 | 言语理解——中心理解题、细节题 |
| 触发场景 | 选项中的关键词都能在文段中找到出处，但分别来自不同位置的句子，东拼西凑组合在一起后改变了原意 |
| 步骤逻辑 | ① 看到选项内容能对应文段时不要急着选；② 逐一确认选项中的每个关键词是否出自同一句话或同一段落；③ 若关键词分别来自文段不同位置（如第二句的A和尾句的B拼在一起），判定为杂糅选项，排除 |
| 高频错因 | 觉得"文段里都提到了"就直接选，忽略了这些内容分布在不同段落、不同语境中；杂糅选项的逻辑关系可能被篡改（如因果变并列） |
| confidence | high |

## 不适用条件

- 文段本身用总结句把不同位置的信息建立了明确关系。
- 选项虽整合多处信息，但主体、逻辑关系和范围均与原文一致。

## 反向触发

- 关键词来自不同句子不等于必然杂糅，应检查原文是否允许跨句概括。
- 只有选项擅自改变因果、并列、时间或主体关系时，才能据此排除。
