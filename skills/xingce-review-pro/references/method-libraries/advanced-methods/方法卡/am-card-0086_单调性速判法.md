# 方法卡：单调性速判法（正负相关）

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 单调性速判法（正负相关） |
| 适用题型 | 资料分析-调查问卷中"收入与选择是否完全正/负相关" |
| 触发场景 | 题目说"收入高低与某选择倾向完全正相关/负相关"，需要从表格中判断哪些选项满足条件 |
| 步骤逻辑 | 1. 正相关 = 从上到下（收入递增方向），该列数据也递增；2. 负相关 = 从上到下（收入递增方向），该列数据递减；3. 逐一检查每一列：要么一直变大，要么一直变小 → 符合；4. 出现"先大后小再大"的波动 → 不符合任何相关性 → 排除；5. 不用管具体数值，只看单调性即可 |
| 高频错因 | 花时间理解"正相关""负相关"的概念，其实只需看递增/递减漏看某一列的波动，误判为单调 |
| confidence | high |

## 不适用条件

- 数据非逐行排列的收入分组表格（如散点图、折线图）时，视觉判断单调性不可靠
- 仅有一两个数据点时，单调性判断无意义
- 题目问的是具体数值大小或比例关系而非相关性趋势时，不需要此法

## 反向触发

- 当某列数据出现"先升后降再升"的非单调波动时，不能强行判定为正/负相关，应直接排除
- 当题目要求的是"完全正/负相关"的严格判断，而数据仅有微小波动时，需逐个核实而非粗看单调性
- 当收入分组不是按严格递增排列时，需先确认排列顺序再判断方向
