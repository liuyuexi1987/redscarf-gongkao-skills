# 方法卡：盐水混合定全年增速

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 盐水混合定全年增速 |
| 适用题型 | 资料分析 - 已知上半年同比增速，假设下半年相同，求全年增速或全年值 |
| 触发场景 | 材料给出上半年同比增速，题目要求"按上半年增速测算全年"；其他年份只有全年数据 |
| 步骤逻辑 | 1. 上半年增速是与上年同期相比的同比增速；2. 若假设下半年也按相同同比增速增长，则上半年和下半年各自较上年同期涨了相同比例；3. 根据盐水混合原理：两部分增速相同时，整体增速等于该增速；4. 因此全年增速 = 上半年增速，直接用全年基期 ×（1+增速）得到全年现期 |
| 高频错因 | 把"按上半年增速测算"误理解为环比关系，错误地用上下半年做差再算 |
| confidence | high |

## 不适用条件

- 题目分别给出了上半年和下半年各自的增速（两部分增速不同，不能直接取相同增速）
- 题目要求的是环比增速而非同比增速（盐水混合前提是同比口径）
- 上下半年基期值差异极大时，权重效应不可忽略，整体增速受权重影响而非简单等于分项增速

## 反向触发

- 当题目出现"下半年增速为 X%"且与上半年不同时，应改用加权盐水公式分别代入
- 当材料只给出全年同比增速、要求反推上半年增速时，本方法方向相反，应反向列式
- 当选项接近且上下半年权重差异可能改变排序时，需按权重计算，不宜直接套用全年增速等于某一阶段增速
