# 方法卡：尾数法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 尾数法 |
| 适用题型 | 资料分析·简单加减计算 |
| 触发场景 | 选项精确到的量级（小数点后位数）与题干数据一致时 |
| 步骤逻辑 | 1. 确认选项与题干数据的精确量级是否一致 2. 只算各项的末位尾数进行加减 3. 用计算出的尾数锁定选项 |
| 高频错因 | 未确认量级一致就使用，导致尾数对应位错误 |
| confidence | high |

## 补充说明

尾数法适用于精确求和题。使用条件的关键判断标准是：选项保留的最后量级与题干数据的精确度相同——即选项单位保留的最后量级与题干数据精确度一致时即可使用。

## 不适用条件

1. 选项与题干数据的精确量级不一致（如题干精确到个位，选项精确到小数点后一位）——尾数无法对应匹配。
2. 计算涉及乘除法或混合运算——尾数法仅适用于简单加减运算。
3. 存在数据近似或四舍五入的情况，原始数据精度被改变——尾数法要求原始数据精确无损。

## 反向触发

1. 各项尾数相同或计算结果的尾数与多个选项匹配，无法锁定唯一选项——尾数法区分度不足，需换方法。
2. 题目要求求的不是各数据项的加减结果，而是比率、比重或增长量等需要乘除的量——不满足运算类型。
3. 加减项数过多（超过5项），逐项取尾数容易出错——先确认是否有更高效的方法（如首数法）。
