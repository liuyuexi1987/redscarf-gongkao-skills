# 方法卡：指标公式化与乘积增长率

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 指标公式化与乘积增长率 |
| 适用题型 | 资料分析——乘积增长率 / 指标间公式关系推导 |
| 触发场景 | 题目要求某指标的增长率，但材料未直接给出该指标增速，而是给出了与其存在乘积（或加减、比值）关系的两个子指标的增速 |
| 步骤逻辑 | 1. 找不到指标 → 找与其相关的 → 用公式表示（加减乘除关系）；2. 若指标 = A × B，则增长率 R = RA + RB + RA×RB（乘积增长率公式）；3. 分别算两个相关指标的增速，代入公式；4. 若 RA 和 RB 都较小，乘积项 RA×RB 可忽略 |
| 高频错因 | 找不到指标就慌，想不到去找相关指标将乘积关系误认为比值关系，用错公式倍差的增速方向搞反（倍差下降应取负值） |
| confidence | medium |

## 不适用条件

- 两个子指标之间不是乘积关系而是比值关系（A/B）时，应使用比值增长率公式而非乘积公式
- 子指标增速无法从材料中获取或推算时，本法缺少输入数据，应改用其他估算方法
- 题目直接给出了目标指标的增速，无需公式拆解时，不必使用本法

## 反向触发

- 若无法确认指标间的数学关系是乘积还是比值，先列公式推导关系再决定用哪张卡
- 若 RA 或 RB 的符号（正/负）无法从材料中确认，先标记待核验再代入公式
