# 方法卡：背景与总分分结构识别

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 背景与总分分结构识别 |
| 适用题型 | 中心理解题（主旨大意） |
| 触发场景 | 文段开头看似总括，后文提及不同对象（如其他国家→我国），容易误判为"总分分"结构 |
| 步骤逻辑 | 1. 后文是否对前文做了"展开"？如果后文各说各的、话题转入新对象，则不是展开；2. 从政治立足点判断：公考文段若先说国外再说我国，落脚点在我国，国外部分是背景；3. 结论：前文是背景引入，不是总括句；后文是真正话题 |
| 高频错因 | 误把背景当总括句，选了只覆盖背景内容的选项忽略"我国"的政治立足点，选了涵盖国外的宽泛选项 |
| confidence | high |

## 不适用条件

- 文段开头与后文话题一致、没有发生对象转换（如始终讨论同一主体）
- 各部分篇幅相当且无明显"引入"与"深入"之分，属于真正的并列结构
- 文段是"问题—分析—结论"结构，第一部分是问题本身而非背景引入

## 反向触发

- 若文段先说国外后说我国，但"我国"部分非常简短且不是论述重点，可能真正的主旨是中外对比而非单方面落脚，应回文比较两部分的篇幅和论证深度
- 若文段的第一句和后文之间没有转折信号（如"然而""不过""在我国"），可能不是背景-正文结构，而是真正的总分结构，应重新判断
- 若选项中存在一个能同时覆盖"背景"和"正文"的概括性表述，且比只覆盖正文的选项更全面，应优先选择更全面的选项
