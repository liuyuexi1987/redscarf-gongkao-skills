# 方法卡：拆桥否隐含前提比否论据更强

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 拆桥否隐含前提比否论据更强 |
| 适用题型 | 判断推理——削弱类（论证过程存在隐含前提/默认假设） |
| 触发场景 | 论据→论点的推理链条中存在一个未明说的前提，问"最能削弱/反驳" |
| 步骤逻辑 | ① 分析论据到结论的隐含前提；② 检查选项是否切断该前提；③ 再比较否定论据、另有他因等选项实际攻击的位置与力度；④ 拆桥选项只有在主体、范围和推理缺口都匹配时才优先 |
| 高频错因 | 只在论据层面打转（否论据），忽略了可以直接攻击隐含前提的拆桥选项；对隐含前提不敏感 |
| confidence | high |

## 补充说明

典型场景：论证为"茶叶有营养物质→应该吃茶叶"，A选项（还有很多没营养的物质）属否论据，但默认"有营养就该吃"前提仍成立；C选项（喝茶只是习惯，不在意营养）属拆桥，直接否定"该不该吃取决于有没有营养"这个隐含前提，力度最强。同一拆桥模式在其他题中也出现过：论据为"节电量微乎其微"、论点为"没有实际效果"→隐含前提="效果取决于节电量"→拆桥选项="目的不是省电而是唤醒意识"。

## 不适用条件

1. 论证中没有隐含前提（论据到论点的推理是直接的、无跳跃）时，拆桥与否论据的力度区分不适用
2. 当题目问的是"最能支持/加强"时，需找搭桥选项而非拆桥，方向相反
3. 论证结构为三段论或形式逻辑推理时，应使用逻辑规则而非拆桥/否论据的力度比较

## 反向触发

1. 当选项中没有直接针对隐含前提的表述，只有针对论据本身的选项时，应换用否论据力度比较法，而非执着于找拆桥
2. 当论证链条中有多个隐含前提，且不同选项攻击不同前提时，需额外核验哪个前提更核心、切断哪个更能动摇结论
3. 当出现"最能反驳"但选项既有拆桥又有因果倒置时，应补充比较拆桥与因果倒置的力度差异
