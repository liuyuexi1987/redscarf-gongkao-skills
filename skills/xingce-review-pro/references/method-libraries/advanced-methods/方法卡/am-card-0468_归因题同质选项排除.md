# 方法卡：归因题同质选项排除

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 归因题同质选项排除 |
| 适用题型 | 判断推理 > 削弱质疑（归因题/对比实验归因） |
| 触发场景 | 题干将结果归因于X，选项中有两个都提出"另有他因"且质疑角度类似（各针对一个子群体） |
| 步骤逻辑 | 1. 先看是否有选项提出"另有他因"（针对不同子群体分别质疑）；2. 若有两个选项质疑方式同质（如A质疑AB型、C质疑O型，都是用个体差异而非血型来解释），则同质选项一起排除；3. 寻找更根本的质疑——直接否定此因（如"蚊子选目标跟血型无关"）；4. 否定此因 > 另有他因（片面）；否定此因更全面 |
| 高频错因 | 看到一个"另有他因"就觉得有力，没发现还有另一个同质选项；未比较力度就选 |
| confidence | high |

## 不适用条件

1. 结果明显有多重原因且题干已承认多因素（不存在归因单一化的漏洞）
2. 只有一个选项在"另有他因"，不存在同质配对
3. "另有他因"选项的质疑角度完全不同（分别针对不同变量），不构成同质

## 反向触发

1. 当识别出同质选项对但剩余选项也全是"另有他因"时，应比较力度大小而非直接排除
2. 当"否定此因"选项的表述力度不足（如用"不一定"而非"无关"）时，需额外核验力度
3. 当题目为"最能削弱"且多个选项力度接近时，应换用力度梯度排序法
