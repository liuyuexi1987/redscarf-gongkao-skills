# 方法卡：选取顺序不影响总方案数

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 选取顺序不影响总方案数 |
| 适用题型 | 多人从同一组对象中分别选取 |
| 触发场景 | 题目说"小明先取，小红后取"，担心顺序影响结果 |
| 步骤逻辑 | 1. 无论谁先取谁后取，总方案数不变；2. 先取者有M种选择，后取者有M-1种 → M×(M-1)；3. 反过来：后取者有M种，先取者有M-1种 → 同样是M×(M-1)；4. 因为乘法满足交换律，顺序不影响结果 |
| 高频错因 | 担心后取者"少了一种选择"会导致结果不同 |
| confidence | high |

## 补充说明

排列组合的"依次"只是帮助思考的工具，实际结果包含所有可能的分配方式

## 不适用条件

1. 选取中存在"优先权"或"限制条件"导致前后步骤不再对称（如某对象必须被特定人选走）。
2. 题目本身要求按特定顺序计算（如"第k个取到特定对象的概率"），顺序即问题核心。
3. 选取是无放回但需分别计算每个对象的概率分布时，顺序会影响分布表达。

## 反向触发

1. 当题目显式问"第N次取到特定对象的概率"时，应换用条件概率或位置概率方法。
2. 当存在"必须先取某对象"的强制约束时，应改用受限排列方法，不能直接套用对称性结论。
3. 当题目区分"分给不同人"且人有差异时，应核验分配对象是否等价，必要时改用分组分配公式。
