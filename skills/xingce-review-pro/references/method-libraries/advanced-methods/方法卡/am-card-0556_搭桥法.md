# 方法卡：搭桥法

| 字段 | 内容 |
|------|------|
| 方法名 | 搭桥法 |
| 适用题型 | 逻辑判断——前提假设题（论据→结论有逻辑断点） |
| 触发场景 | 论据话题与结论话题不一致，需找到连接二者的桥梁选项 |
| 步骤逻辑 | 1. 分别提取论据和结论中的关键词（主体/话题） |
| | 2. 找出论据中有但结论中没有的概念（断点A）和结论中有但论据中没有的概念（断点B） |
| | 3. 正确选项应同时包含断点A和断点B，建立"若A则B"的连接 |
| | 4. 有搭桥选项时优先选搭桥（力度最强，为必要条件） |
| 高频错因 | ①看不出断点在哪，选了只涉及论据或只涉及结论的选项②动物实验→人的情况，忘了需在"动物"和"人"之间搭桥 |
| confidence | high |

**补充说明：**
- 搭桥是前提假设题中优先级最高的正确选项类型（优先级：搭桥 > 修补漏洞 > 必要条件）。
- 典型场景：动物实验→人（需搭"动物基因与人相近"）、理论→应用（需搭"该理论可应用于实践"）。
- 片面搭桥（只搭了一条断点）也可以选，只要方向正确且是唯一可选项。

## 不适用条件

- 论据与结论之间不存在概念断点（话题一致、逻辑连贯）时，不适用搭桥法，应改用必要条件或漏洞修补思路。
- 题目问法为"削弱/质疑"而非"前提假设"时，搭桥不是正确答案类型。
- 断点已被题干自身解释完整闭环（无跳跃）时，无需搭桥。

## 反向触发

- 当论据与结论概念完全一致却仍存在因果方向问题时，应换用"修补漏洞"法排查因果方向。
- 当题干无断点但存在"没有它一定不行"的依赖关系时，应换用"必要条件"法。
- 当选项中没有同时包含两个断点概念的项时，应回头核验断点识别是否准确，而非强行选择单概念选项。
