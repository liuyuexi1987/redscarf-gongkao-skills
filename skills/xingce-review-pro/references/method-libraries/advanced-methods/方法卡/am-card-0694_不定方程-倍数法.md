# 方法卡：不定方程-倍数法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 不定方程-倍数法 |
| 适用题型 | 不定方程（未知数多于方程个数），尤其系数较大或含5、10等易识别倍数时 |
| 触发场景 | 列出不定方程后，观察到方程右边和某项系数有公因数/倍数关系 |
| 步骤逻辑 | 1. 观察方程中哪些项是某个数的倍数（如25大是5的倍数，555也是5的倍数）；2. 由"若A和B都是k的倍数，则A±B也是k的倍数"推出另一项也必须是k的倍数；3. 从最小可行倍数开始依次代入试算；4. 结合奇偶性可进一步缩小试算范围 |
| 高频错因 | 没有识别出隐含的倍数关系，导致从1逐一代入浪费时间；忘记验证第三个未知数是否为正整数 |
| confidence | medium |

## 补充说明

倍数法是不定方程求解中最常用且最高效的方法。核心原理：若方程中两项都是某数k的倍数，则第三项也必为k的倍数，从而把未知数的取值限定在k的倍数范围内，减少试算次数。从最小可行倍数开始依次代入试算即可快速锁定解。当方程含三个未知数时，推出一个未知数后还需验证其他未知数是否为正整数且满足题意约束。

## 不适用条件

- 方程各项系数与右边无明显公因数（无法识别倍数关系）。
- 方程右边与各项系数互质，倍数关系不成立。

## 反向触发

- 当倍数关系不明显时，应优先尝试奇偶性法筛选搜索范围。
- 当倍数法和奇偶性均无法缩小范围时，改用尾数法或精算代入。
