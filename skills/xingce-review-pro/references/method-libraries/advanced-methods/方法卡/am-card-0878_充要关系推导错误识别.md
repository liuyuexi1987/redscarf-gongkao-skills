# 方法卡：充要关系推导错误识别

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 充要关系推导错误识别 |
| 适用题型 | 逻辑谬误相似性判断题、加强削弱中的逻辑漏洞识别 |
| 触发场景 | 题干有"A推B"形式的条件，有人从"否A"推出"否B"，或从"B"推出"A" |
| 步骤逻辑 | 1. 正确推理只有两种：肯前推肯后、否后推否前；2. 错误推理有两种：否前推否后（"不学习→分数不高"）、肯后推肯前（"分数高→学习了"）；3. 做题时先判断题干犯的是哪种错误，再找选项中犯同样错误的 |
| 高频错因 | 把"否前推否后"和"因果关系中的否定原因"混淆；生活中的直觉常犯此错 |
| confidence | high |

## 补充说明

广东近几年常考此类逻辑错误。在因果关系中同样存在——"紫外线导致变黑"不等于"不晒就会变白"。

## 不适用条件

- 题干给出的是充分条件或必要条件的直接判定题（"以下哪个是必要条件"），而非推导形式的相似性判断。
- 讨论的是日常建议或政策可行性，不涉及条件推理的形式结构。

## 反向触发

- 题干或选项出现"如果A则B""只有A才B"等形式，且需要判断推导形式是否与题干一致。
- 题目考查的是哪种推理错误与题干相同（相似性判断）。
