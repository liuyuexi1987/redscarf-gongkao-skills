# 方法卡：感情色彩匹配法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 感情色彩匹配法 |
| 适用题型 | 逻辑填空——感情色彩判断 |
| 触发场景 | 选项中有褒义/贬义/中性词混搭，且上下文有明确的感情倾向（积极/消极/客观） |
| 步骤逻辑 | ① 判断上下文语境的感情倾向（积极→褒义词、消极→贬义词、客观→中性词）；② 排除感情色彩与语境不匹配的选项；③ 剩余选项再用语境关系和搭配二次筛选 |
| 高频错因 | ① 忽略语境的隐性感情倾向（如"谨小慎微"在消极语境中不合适）；② 把中性语境误判为积极/消极，排除了正确选项 |
| confidence | medium |

## 补充说明
感情色彩是逻辑填空的辅助判断手段，一般不单独使用。典型场景："亦步亦趋"是消极词，不能用在积极语境中。注意：同一个词在不同语境中感情色彩可能不同（如"固执"在某些语境中可褒可贬）。

## 不适用条件
- 选项感情色彩一致（同为褒义/贬义/中性），无区分度可言。
- 上下文感情倾向不明确，处于中性陈述语境难以判定倾向。
- 题目以纯搭配或纯语义轻重为核心考点，感情色彩不构成关键差异。

## 反向触发
- 当感情色彩筛选后剩余多个选项时，需补充搭配验证选词法或语境对应分析法进一步筛选。
- 当语境感情倾向难以判断时，应换用语境解释对应法寻找显式解释信号。
- 当选项差异在词义轻重而非感情色彩时，应换用词义轻重排序法。
