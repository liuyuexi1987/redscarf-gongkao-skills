# 方法卡：分式比较增速大小

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 分式比较增速大小 |
| 适用题型 | 资料分析——增速比较·已知现期和增量，比较多个对象的增速谁最快 |
| 触发场景 | 题目问"增速最快/最慢的是哪个"，且材料给了现期值和增量值（或可算出增量） |
| 步骤逻辑 | ① 确认各对象数据口径一致，现期与基期为正；② 用增量÷现期比较大小，无需先求基期；③ 该比值随实际增速单调增加，因此比值越大，实际增速越大；④ 若数值接近，可用差分或交叉相乘精确比较 |
| 高频错因 | ① 多此一举先算基期再比较；② 增量和现期单位或口径不一致仍直接相除；③ 把变化幅度（绝对值）和增速（比例）混为一谈 |
| confidence | high |

## 补充说明

设实际增速为 r，则“增量÷现期”=r÷(1+r)。在 r>-1 且基期、现期为正时，该函数随 r 单调增加，因此可以直接用于比较增速大小。此法省去逐项计算基期的步骤。

## 不适用条件

- 题目要求算出具体增速值（而非仅比较大小）时，仍需用完整公式计算
- 增量和现期单位不一致或数据口径不同时，不能直接相除比较
- 题目问的是“变化量/增加量”而非“增速”时，应比较增量；若问“变化幅度”，还要先确认题目指绝对变化量还是增速绝对值

## 反向触发

- 看到"增速最快/最慢""增速最高/最低"且材料给了现期值和增量值 → 用本方法（增量÷现期直接比较）
- 看到"变化最大/最小""增加最多/最少" → 不用本方法，应直接比较增量绝对值
