# 方法卡：对策优先选对策

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 对策优先选对策 |
| 适用题型 | 言语理解——中心理解（对策类文段） |
| 触发场景 | 原文中出现作者的对策、观点、建议（无论是前对策还是后对策），选项必须体现该对策；对策标志词包括：需要、应该、建议、不妨、禁止、只有才、必须否则等 |
| 步骤逻辑 | 1. 判断文段是否有作者的对策/观点（说理类 vs 科普类）；2. 对策位置二选一：要么在首句/第二句（前对策），要么在尾句（后对策）；3. 选项必须体现对策的具体做法，不能只选问题描述或背景信息；4. 对策 = 作者想让我们怎么做，和"观点"本质相同，做题方法一致 |
| 高频错因 | 被论证/解释说明段落吸引，选了分析内容而非对策把"问题描述"当成正确答案（如选"会限制创新者的思维"而非对策本身）混淆科普类和说理类，说理类有主旨句要找句子，不能像科普类那样概括 |
| confidence | medium |

## 不适用条件

- 科普介绍类文段（无作者观点/对策）不使用本卡
- 文段中的对策是引用他人观点而非作者主张时，需结合上下文判断

## 反向触发

- 若文段是纯问题描述、无对策表述，不使用本卡
- 若选项中的对策与原文对策内容不符（偷换概念），不能选
