# 方法卡：不定方程三种解法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 不定方程三种解法 |
| 适用题型 | 数量关系——不定方程 |
| 触发场景 | 未知数个数多于方程个数（如3个未知数2个方程）；需要求整数解 |
| 步骤逻辑 | 不定方程（未知数多于方程个数）用奇偶、尾数、倍数三种方法缩小范围求解。；1. **奇偶法**：两数差为偶数→两数奇偶相同；利用奇偶排除选项；2. **尾数法**：观察系数尾数特征（如1.7X尾数为0.6→X尾数必为8）；3. **倍数法**（最常用）：如果一个数是4的倍数，另一个也是4的倍数→和与差都是4的倍数 |
| 高频错因 | 未利用题目隐含条件（如正整数、范围限制）缩小范围；奇偶判断错误导致排除了正确选项 |
| confidence | medium |

## 补充说明

- 倍数法用得最多、最快
- 尾数法本质也是倍数法（如5的倍数尾数只能是0或5）
- 三个未知数时，消元后用奇偶/倍数缩小范围，再代入验证

## 不适用条件

- 题目未限定整数解时，不定方程有无穷多解，三种方法不适用
- 系数之间没有明显的奇偶、尾数或倍数关系时，方法效果有限
- 选项之间差距很小且解的范围较大时，缩小范围后仍需逐一代入验证

## 反向触发

- 若未知数个数等于方程个数（普通方程组），不使用本卡
- 若题目要求的是方程的解集或表达式而非具体整数解，不适用不定方程解法
