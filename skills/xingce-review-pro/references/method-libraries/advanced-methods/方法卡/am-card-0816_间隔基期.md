# 方法卡：间隔基期

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 间隔基期 |
| 适用题型 | 基期 / 间隔基期 |
| 触发场景 | 材料年份与问题年份之间隔了一年（或一个月），如材料给2019年数据，问2017年 |
| 步骤逻辑 | 1. 识别间隔基期：问题年份比材料年份往前推了两年（跳过一年）；2. 先求间隔增长率 R = R1 + R2 + R1×R2（口诀"1+2加一二"）；3. 若R1、R2均小于10%，乘积R1×R2可忽略不计；4. 用间隔增长率对现期量做假设分配或直除，求出基期 |
| 高频错因 | 误将间隔基期当成一般基期，只用一个增长率计算忘记求间隔增长率，直接用单期公式不会判断何时可忽略乘积项 |
| confidence | medium |

## 不适用条件

1. 材料年份与问题年份之间只隔一期（同比/环比），属于普通基期计算，不涉及间隔增长率。
2. 间隔超过两年（如问2017年相对于2014年），公式变为三层复合，不能直接套用R1+R2+R1×R2。
3. R1和R2中有一个为负且绝对值较大，乘积项不可忽略；当估算误差可能跨越选项或改变结论时，改用精算/验证。

## 反向触发

1. 两个年份只差一年却用间隔增长率公式计算，说明误判时间间隔。
2. 忽略R1×R2项后结果偏离选项范围，说明该项不可忽略，需补上精算。
