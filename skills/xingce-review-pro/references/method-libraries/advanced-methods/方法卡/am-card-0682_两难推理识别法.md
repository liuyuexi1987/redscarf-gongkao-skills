# 方法卡：两难推理识别法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 两难推理识别法 |
| 适用题型 | 逻辑判断——两难推理题（题干全是命题，推出一个事实） |
| 触发场景 | 题干出现A推B和非A推B两个命题，问能推出什么 |
| 步骤逻辑 | ① 找到A推B和非A推B两个命题；② 因为A和非A必有一个成立（矛盾），所以B必然成立；③ 汉语表达：无论A不A，都B；④ 如"你去我也去，你不去我也去"→无论你去不去，我都去 |
| 高频错因 | 没识别出两难推理结构；中间有桥不会消掉 |
| confidence | medium |
| 不适用条件 | 1. 题干有既成事实而非全是条件命题（有事实需先做推理而非识别两难）；2. 题干条件不构成A与非A的矛盾关系（两个条件不是互斥的）；3. 题目问的是 |
| 反向触发 | 1. 题干全是 |

## 补充说明

两难推理是送分题。识别特征：题干全是"如果那么"命题（无既成事实），最后问"可以推出什么"。解法：找A推B和非A推B，中间可能有桥（如A推C，C推D，D推B），消掉中间项后，无论A不A都B，B必然成立。
