# 方法卡：以偏概全与他因择优

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 以偏概全与他因择优 |
| 适用题型 | 加强削弱——题干以偏概全，选项有"举反例"和"他因"两种质疑方向 |
| 触发场景 | 题干用部分对象的统计量估算整体指标（统计范围不完整，遗漏其他渠道），问哪个最能削弱 |
| 步骤逻辑 | ① 识别逻辑漏洞：以偏概全（只统计了打印机这一种渠道）；② 优先找直接命中漏洞的选项（"员工也使用传真机和手写"=指出遗漏渠道）；③ C选项（也用复印扫描）=反向支持（说主要耗纸都在打印机上），排除；④ 若多个选项都能质疑，取力度最强的 |
| 高频错因 | 被"也使用已统计渠道进行其他操作"类选项迷惑，以为是在指出不完整，实际反而支持了"主要消耗在已统计渠道上"的结论 |
| confidence | high |

## 补充说明

以偏概全类削弱识别关键：题干用部分对象统计量估算整体指标时，找选项是否指出题干统计/论证范围之外的遗漏。

干扰项识别：
- 选项仍在已统计范围内打转（如"双面打印""周末也用"等仍属于同一已统计渠道）=未跳出统计范围，不能削弱。
- 选项表明其他操作也走已统计渠道=反向支持（说明主要消耗仍在已统计渠道内），排除。
- 只有指出统计范围之外存在其他未统计渠道的选项才直接命中漏洞。

## 不适用条件

- 题干统计范围已覆盖全部对象（无遗漏）时不适用，应换用其他削弱思路。
- 题目问法为"加强/支持"而非"削弱"时，应换用补强思路。
- 题干不存在"以部分估算整体"的结构（如直接给出整体数据）时，不适用此法。

## 反向触发

- 当题干不是以偏概全结构而是对比实验归因时，应换用"因果倒置"或"他因削弱"法。
- 当选项中没有指出遗漏渠道的项时，应换用"他因择优"或"样本代表性质疑"法。
- 当多个选项都指出遗漏时，应比较哪个遗漏的占比更大、对结论影响更强。
