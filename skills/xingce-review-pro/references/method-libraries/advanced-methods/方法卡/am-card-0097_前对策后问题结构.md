# 方法卡：前对策后问题结构

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 前对策后问题结构 |
| 适用题型 | 中心理解题（说理类文段） |
| 触发场景 | 文段先提出对策/观点，再用现实问题/反面例证来支撑 |
| 步骤逻辑 | 1. 识别文段结构：前对策 → 后问题（反面例证）；2. 后面的问题/现实情况不是重点，它们是来论证前面对策的必要性；3. 呼吁大家做这个对策、说明对策有必要，才是文段的核心；4. 因此主旨还是抓对策，不要被后面大量问题描述带偏；5. 这种结构下对策一般在文段开头就已明确 |
| 高频错因 | 看到后面大段的问题/现实描述，误以为问题才是重点机械套用"后面是重点"的规则，忽略了结构的特殊性选了问题表述的选项而非对策表述的选项 |
| confidence | high |

## 不适用条件

1. 文段是"先问题后对策"结构（对策在尾句），不能套用"前对策后问题"的判断
2. 文段末尾有转折或新结论，后文问题可能指向新结论而非前面的对策
3. 前面的表述是背景铺垫而非对策（没有祈使/建议/应该等对策标志词）

## 反向触发

1. 文段尾句出现了"因此/所以/总之"引出的新结论，主旨应抓尾句
2. 文段结构为"问题+对策"（对策在后），套用此卡会抓错位置
