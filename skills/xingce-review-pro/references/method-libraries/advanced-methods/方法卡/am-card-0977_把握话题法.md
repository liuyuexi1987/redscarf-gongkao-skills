# 方法卡：把握话题法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 把握话题法 |
| 适用题型 | 逻辑填空——话题判断 |
| 触发场景 | 文段较长（3-4行）、多空题、选项难以区分时 |
| 步骤逻辑 | ① 快速略读全文，确定这段话围绕什么核心话题展开；② 前后文段通常有系统性和连续性，用词不会偏离话题太远；③ 选项必须与话题相关，偏离话题的选项大概率错误 |
| 高频错因 | ① 只看局部不看整体→选了与话题无关的词；② 被空格附近的干扰信息带偏→忘记整体话题 |
| confidence | high |

## 不适用条件
- 文段过短（1-2行）、话题线索不足时
- 单空题且有明确逻辑对应点时，不需要整体把握话题
- 四个选项差异主要在搭配而非话题相关性时

## 反向触发
- 文段较长（3-4行）且为多空题时，先快速确定核心话题再逐空解题
- 某选项与文段核心话题明显偏离时，该选项大概率错误

## 补充说明
国考逻辑填空越来越需要从整体把握。3-4行的文段通常围绕特定话题展开，前后有系统性。例如话题是"发挥音乐在电影中的文化传播作用"，第二空就应选与"文化传播"最相关的"共鸣"而非"互动"。
