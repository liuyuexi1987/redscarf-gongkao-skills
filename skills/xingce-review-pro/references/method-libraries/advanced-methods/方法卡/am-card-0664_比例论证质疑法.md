# 方法卡：比例论证质疑法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 比例论证质疑法 |
| 适用题型 | 逻辑判断——题干用分子数量比较，结论涉及比例/概率 |
| 触发场景 | 题干只说了分子（如投诉数、患病人数），没说分母（总数），就得出比例结论 |
| 步骤逻辑 | ① 识别漏洞：题干只看分子，没看分母；② 在选项中找带比例/数字的分母（总数）；③ 用分子÷分母算出比例，看是否与题干结论相反；④ 如果算出来比例相反（如题干说A容易得病，但算出来A的得病率反而低），就是质疑 |
| 高频错因 | 被"个别/有些"迷惑（这类题个别可以选）；选了不带数字的选项 |
| confidence | medium |
| 不适用条件 | 1. 题干已经同时给出了分子和分母（比例数据完整）；2. 结论本身就是绝对数量而非比例/概率；3. 题目问支持而非质疑；4. 选项不涉及分母或总数信息 |
| 反向触发 | 1. 题干只给出某一群体的数量或百分比（分子），结论却涉及概率/比例/风险，立刻想到需要找分母来质疑；2. 选项中出现总人数、总样本量等分母数据，大概率是正确答案 |

## 补充说明

强化方法总结的固定题型。做题步骤：① 题干给的分子（如"75%患者都吸烟"）；② 选项给分母（如"吸烟者占总人口80%"）；③ 算比例：患者中吸烟比例(75%) vs 总人口吸烟比例(80%)，吸烟者得病率反而低→质疑。这类题的正确答案几乎总是带数字+总数的选项。注意：有些选项给的是"风险""就诊人数"等，不能构成比例，要排除。
