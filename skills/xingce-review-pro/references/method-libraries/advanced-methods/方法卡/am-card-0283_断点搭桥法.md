# 方法卡：断点搭桥法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 断点搭桥法 |
| 适用题型 | 前提假设题、支持题 |
| 触发场景 | 论据和结论中出现不同关键词/不同话题时 |
| 步骤逻辑 | 1. 找出论据中的核心关键词；2. 找出结论中的核心关键词；3. 判断二者是否为同一话题（若不一致则存在断点）；4. 正确答案必须同时包含论据关键词和结论新关键词，将其搭成桥；5. 若选项只涉及一侧关键词而未覆盖另一侧，直接排除 |
| 高频错因 | 只看到选项提到了论据中的关键词就选，忽略了结论中的新内容必须在选项中有所体现 |
| 不适用条件 | 论据和结论之间无断点（关键词一致）或题目为质疑/削弱题型时 |
| 反向触发 | 论据与结论之间不存在关键词跳跃或话题转移时 |
| confidence | high |
