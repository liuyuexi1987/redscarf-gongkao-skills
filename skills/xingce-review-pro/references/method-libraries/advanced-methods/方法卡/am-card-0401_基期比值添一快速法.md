# 方法卡：基期比值添一快速法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 基期比值添一快速法 |
| 适用题型 | 资料分析——求基期比值（基期A/基期B），且分子分母增长率接近 |
| 触发场景 | 题目给出两个主体的现期值和增长率，要求基期比值；两个增长率差值在50个百分点以内 |
| 步骤逻辑 | ① 将分母的1+rB补成整百数（添一），分子也加同样幅度（约rB%）；② 补整后分母变为整数可消掉，分子变为新值；③ 直接用调整后的分子相除得出结果 |
| 高频错因 | 增长率差过大（超50个百分点）时添一误差大，不宜用此法；忘记对分子做等比例调整导致分子分母不匹配 |
| confidence | high |

## 补充说明

核心原理：基期比值 = A/(1+rA) ÷ B/(1+rB)，当(1+rA)与(1+rB)接近时，通过给分子分母同时补差值使分母统一为整数后消掉。增长率差过大（如109% vs 48%）时添一幅度不好估算，应改用直接分别求基期值再相除。

## 不适用条件

- 添一近似造成的误差可能改变选项判断时
- 题目要求的不是基期比值，而是现期比值或增长率比值时
- 分子或分母的增长率为负数，且绝对值较大，导致 (1+r) 接近或小于零时

## 反向触发

- 当添一后的估算误差足以跨越选项时，应改用分别求基期值再相除的精确方法
- 当题目给出的增长率形式为百分点变化而非百分比时，需先换算为百分比再判断是否满足添一条件，不可直接使用
- 当选项间距不足以覆盖添一法的估算误差时，应改用精确计算
