# 方法卡：放缩凑整直接计算法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 放缩凑整直接计算法 |
| 适用题型 | 资料分析——分式比较大小（分母接近整百整数时） |
| 触发场景 | 分母接近好算的数（如493→500、688→700），或分子分母有明显倍数关系 |
| 步骤逻辑 | ① 观察分母是否接近好算的整数；② 将分母凑整，同时对分子做象征性补偿（不必精确）；③ 算出近似值后与另一分式比较，或用代入验算反推 |
| 高频错因 | ① 放缩过于精细，花大量时间在个位数上凑准，舍本逐末；② 不敢放缩，每个地方都卡着精确值算 |
| confidence | high |

## 补充说明

放缩的核心原则：分母不动太多，分子象征性弥补即可。粗略放缩5秒出结果，精确算20秒，准度差异很小。先快速做，错了再回头调整精度。当估算误差可能跨越选项或改变结论时，改用精算/验证。

## 不适用条件

1. 分母不接近任何好算的整数（如537、683等），放缩空间有限。
2. 选项差距极小，放缩的误差可能跨越选项。
3. 需要精确结果（如选"约X.X%"且选项间差0.1个百分点）。

## 反向触发

1. 分母接近整百或整十（如493→500、688→700），放缩后一步可出结果。
2. 分子分母有明显的倍数关系，凑整后可快速估算。
3. 直除耗时且选项差距允许一定误差，放缩凑整更高效。
