# 方法卡：名义实际增长率求现期

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 名义实际增长率求现期 |
| 适用题型 | 现期 / 按固定价格计算 |
| 触发场景 | 题目说"按某年价格计算"或"扣除价格因素"，给出名义增长率R1和实际增长率R2 |
| 步骤逻辑 | 1. 公式：现期(按实际) = B / (1 + R名义) × (1 + R实际)；2. 理解：先用名义增长率退回基期，再用实际增长率算实际现期；3. 若实际增长率 < 名义增长率，结果比B小；反之比B大；4. 可用拆分简化：相当于B缩小或放大约(R名义-R实际)的比例 |
| 高频错因 | 不理解"名义"和"实际"的区别，不知道先除再乘的操作逻辑混淆R1和R2的位置 |
| confidence | medium |

## 不适用条件

1. 题目未涉及"名义/实际"或"扣除价格因素"区分，只是普通增长率计算。
2. 材料只给出名义增长率或实际增长率其中之一，无法构成双增长率公式。
3. 题目要求的是名义值与实际值的差额（而非转换后的现期量），需用差值公式而非先除再乘。

## 反向触发

1. 看到"按某年价格""扣除价格因素""实际增速"等关键词但直接用名义增长率算现期，说明未区分名义与实际。
2. 用 B/(1+R实际)×(1+R名义) 先除实际再乘名义，说明R1和R2位置混淆。
