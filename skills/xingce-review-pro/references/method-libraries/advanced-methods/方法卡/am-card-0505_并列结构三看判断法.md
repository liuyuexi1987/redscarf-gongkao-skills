# 方法卡：并列结构三看判断法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 并列结构三看判断法 |
| 适用题型 | 主旨题/中心理解题 |
| 触发场景 | 文段无明显转折/递进/因果，各部分话题一致，需判断是否为并列结构 |
| 步骤逻辑 | 1)看有无并列关联词（同时/一方面另一方面/此外/与此同时等） 2)看各部分是否围绕同一话题 3)看有无相同相似句式 4)确认并列后，选项需概括全部并列部分，片面选项（只对应其中一个部分）排除 |
| 高频错因 | 把并列误判为递进（"同时"后面的不一定是重点）；选项只概括了并列中的一个部分就选了 |
| confidence | medium |

## 不适用条件

1. 文段有明确的转折（"但""然而"）或递进（"不仅…而且"）关联词时，不按并列处理
2. 文段是因果链条或对策链条（"因此…所以…"）而非并列结构时

## 反向触发

1. 若文段有明确转折词，转折后为重点，不按并列概括
2. 若并列各部分之间存在隐含递进逻辑（后一部分比前一部分程度更深），按递进结构处理
3. 若选项无法概括全部并列部分，需检查是否遗漏了某个并列方面
