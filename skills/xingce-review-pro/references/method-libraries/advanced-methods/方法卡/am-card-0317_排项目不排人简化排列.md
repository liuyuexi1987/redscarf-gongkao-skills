# 方法卡：排项目不排人简化排列

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 排项目不排人简化排列 |
| 适用题型 | 数量关系——排列组合、赛程安排 |
| 触发场景 | 人员参加多个项目导致约束交叉，但可等价转化为项目之间的相邻或不相邻关系 |
| 步骤逻辑 | 1. 将"某人不能连续参加"转化为"该项目不能相邻排列"；2. 例如张某参加男双和混双 → 男双和混双在赛程中不相邻；3. 李某参加女双和混双 → 女双和混双也不相邻；4. 问题简化为：五个项目的排列中，特定项目两两不相邻 |
| 高频错因 | 直接排人员的出场顺序，涉及多人多项目交叉，复杂度爆炸不做"人→项目"的转化，导致无法使用插空法 |
| confidence | medium |
| 不适用条件 | 每个人只参加一个项目，不存在人与项目的交叉约束，无需转化 |
| 反向触发 | 若约束条件无法映射为项目不相邻（如涉及时间先后顺序依赖、场地冲突等），需直接处理人员排列或用状态转移法；项目数很少（3个以下）时可直接枚举验证 |

## 补充说明

核心转化技巧：把约束条件从"人的连续性"映射到"项目的相邻性"。排5个项目远比排多个人的出场顺序简单。转化后再用分类插空法处理不相邻约束即可。
