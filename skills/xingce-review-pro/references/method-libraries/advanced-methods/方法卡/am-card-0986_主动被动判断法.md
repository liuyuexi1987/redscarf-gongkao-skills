# 方法卡：主动被动判断法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 主动被动判断法 |
| 适用题型 | 逻辑填空——词语辨析 |
| 触发场景 | 近义词难以区分时，判断空格处动作是主动还是被动 |
| 步骤逻辑 | ① 判断空格处的动作是主动发出还是被动承受；② 主动动作→选主动性强的词（如"摒弃"=主动扔掉）；③ 被动动作→选被动性强的词（如"忽略"=被动没注意到）；④ 例："打破常规"是主动行为→"摒弃定式"比"忽略定式"更搭 |
| 高频错因 | ① 不区分主动被动→选了方向相反的近义词；② "摒弃"vs"忽略"：摒弃=主动扔掉，忽略=被动没看到 |
| confidence | high |

## 补充说明
近义词辨析时，主动/被动是常被忽略的维度。判断要点：先看空格处动作是施动者有意发出还是被动承受，再在选项中匹配相应语态的词。主动性强的词（如"摒弃""摒弃""打破"）用于施动者有意为之的语境；被动性强的词（如"忽略""遗漏""流失"）用于被动承受的语境。

## 不适用条件

- 空格所在语境本身不含动作方向（如状态描述、属性判断）时，本卡不适用。
- 选项中的近义词主动/被动语态一致、无法用此维度区分时，本卡失去区分作用。
- 文段为客观陈述且施动者不明时，强行判断主动被动易误判，不套用本卡。

## 反向触发

- 当主动/被动难以从空格附近判断时，应补一步主语核验：找到空格所在分句的主语，确认其是施动者还是受动者，再决定方向。
- 当选项含使动/使役用法（"使""让""令"）时，应换用语态分析，区分"使别人做"与"自己做"的方向，而非简单套用主动/被动。
- 当主动/被动判断与语义轻重、感情色彩冲突时，应以语义逻辑为优先，主动/被动作为辅助核验维度。
