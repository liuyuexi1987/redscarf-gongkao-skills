# 方法卡："从X到Y"表述不等于对策

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | "从X到Y"表述不等于对策 |
| 适用题型 | 标题题/主旨题 |
| 触发场景 | 选项用"从X到Y"结构，看似涵盖全面，实则是历程/变化表述而非对策表述 |
| 步骤逻辑 | 1)"从X到Y"表示变化过程，X和Y是同等地位 2)原文若有对策（如"只有才"），对策内容和目标是不对等关系 3)"从X到Y"把对策和目标变成了并重，没有突出对策核心 4)直接排除 |
| 高频错因 | 看到"从关键核心技术到创新动力"觉得涵盖全面，实际没有体现对策 |
| confidence | medium |

## 不适用条件

1. 文段本身没有对策句，核心是描述变化过程时，"从X到Y"可能恰好匹配主旨
2. "从X到Y"结构用于概括文段并列的多个方面（非对策目标并列）时不适用本排除法

## 反向触发

1. 若文段有明确对策句，配合"原文对策选对策"方法使用
2. 若选项同时存在对策项和"从X到Y"项，优先选对策项
3. 若文段核心是历程描述而非对策，需改用历程类选项识别方法
