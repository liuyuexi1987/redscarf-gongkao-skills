# 方法卡：上下限区间估计法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 上下限区间估计法 |
| 适用题型 | 资料分析 - 假设增速求后期/范围题 |
| 触发场景 | 多月增速各不相同，要求后期总量的范围；选项区间较大，不需要精确计算 |
| 步骤逻辑 | 1. 先算出基期（限期）的总值；2. 找到各月增速的最小值和最大值；3. 用最小增速乘基期算下限，用最大增速乘基期算上限；4. 确定范围后匹配选项；若区间足够窄可直接锁定答案 |
| 高频错因 | 拿单一增速做精确计算，浪费时间且易错；不敢用区间估计法怕选错 |

| confidence | high |

## 不适用条件

- 选项区间非常窄（如四个选项在很小范围内），区间估计无法区分，需精确计算
- 增速本身有正有负，用单一上下限估计可能方向相反导致区间过大失去参考价值
- 题目要求精确到小数点后一位或更高精度，区间估计只能给范围无法给精确值

## 反向触发

- 当用上下限估计得到的区间包含多个选项时，说明区间过宽，需改用更精确的计算方法或缩小增速取值范围
- 当题目给出的增速数据不完整或存在缺失月份时，不能简单取已知增速的极值，应先补全或估算缺失增速再做区间
