# 方法卡：容斥双公式与反向构造

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 容斥双公式与反向构造 |
| 适用题型 | 数量关系-容斥问题 |
| 触发场景 | 多个集合有交集，求总人数或某类人数；正向列公式未知数太多时用反向构造 |
| 步骤逻辑 | 90%题型用两个公式：①总人数 = A+B+C - 参与两项的 - 2×参与三项的；②总人数 = 只参与一项 + 只参与两项 + 只参与三项；③两公式联立即可解出未知量。10%题型（多集合/数据少）用反向构造：把“不会”转为总人数减去“会”，让不会的重叠部分为零以取得极值，再列方程；最多向下取整，最少向上取整。 |
| 高频错因 | 正向做多集合容斥陷入全是未知数的死胡同；反向构造时忘记让重叠为零以取极值 |
| 不适用条件 | 仅两个集合的简单容斥（直接用两集合公式即可）；题目给出完整各项数据无需反向构造 |
| 反向触发 | 题目要求精确求解“恰好参加两项”“恰好参加三项”等具体交集分布时，应转为标准容斥公式逐层展开交集；“重叠为零”的反向构造仅用于满足条件的极值问法，非极值问题不能套用。 |
| confidence | medium |
