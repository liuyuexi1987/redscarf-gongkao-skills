# 方法卡：无实际量时赋值法
## 基本信息
| 字段 | 值 |
|------|-----|
| 方法名 | 无实际量时赋值法 |
| 适用题型 | 数量关系-经济利润/比例问题 |
| 触发场景 | 题目全为百分比、比率，无任何具体数值 |
| 步骤逻辑 | 1.判断是否有实际量；2.无实际量则赋值，优先赋成本或原价为整百；3.列表格表示每天/每阶段利润和销量；4.计算总利润与总成本的比值 |
| 高频错因 | 赋值后忘记完整列出六天利润和销量；漏算最后一天销量的特殊条件 |
| confidence | high |
## 不适用条件
- 题目已给出具体实际量（如"成本为80元""总量为200件"），无需赋值
- 答案必须为确定整数且赋值会导致结果非整数、无法还原
- 涉及多个独立变量且变量间存在约束关系，简单赋值无法同时满足

## 反向触发
- 题目问"答案与下列哪个量无关"——赋值法会误导判断独立性
- 中间步骤需跨场景比较不同假设下的值——赋值后不同场景的值域冲突
- 题目要求用含变量的表达式回答（如"用x表示"）——赋值会丢失变量关系

## 补充说明
遇到只有比例/百分比、没有具体数值的题，第一步就应该赋值。通常设原价=100、成本=60等整百数便于计算。赋值后把每天的价格、利润、销量列成表格，避免遗漏。注意题目中对最后一天或特殊情况的额外条件。
