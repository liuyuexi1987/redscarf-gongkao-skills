# 方法卡：过度忠实原文错误

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 过度忠实原文错误 |
| 适用题型 | 片段阅读-中心理解题 |
| 触发场景 | 总分结构中，分述部分有具体细节，选项只对应分述某一点 |
| 步骤逻辑 | 1. 先判断问法要求概括全文还是核对局部细节；2. 概括全文时，选项若只覆盖一个分述点通常范围片面；3. 比较选项对核心主体、关系和多个分述点的覆盖程度；4. 选择覆盖完整且没有扩大范围、偷换概念的表述，不能只因某句话来自原文就选 |
| 高频错因 | 看到选项内容来自原文就选，不判断它对应的是总还是分；或只盯尾句忽略整体 |
| confidence | medium |

## 不适用条件

1. 文段为并列结构且无明显总括句时，各分述点可能均为正确选项的来源，不适用"概括层优先"判断
2. 题目问法明确限定某一具体细节（如"关于XX，下列说法正确的是"），此时选项对应单一细节反而是正确的
3. 分述部分本身即为文段核心观点（总分结构中"总"仅为引子），不能机械套用概括层优先

## 反向触发

1. 选项内容来自原文、但对应的是分述中的某个具体例子或数据时，应警惕"过度忠实原文"
2. 两个选项一个概括一个具体，且具体选项只覆盖部分分述内容时，优先考虑概括选项
3. 自己觉得"这个选项说的都对"但没有对照文段整体结构时，停下来检验它对应的是总还是分
