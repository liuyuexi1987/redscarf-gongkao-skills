# 方法卡：对策等价替换不绝对化

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 对策等价替换不绝对化 |
| 适用题型 | 言语理解——对策类主旨题、意图判断题 |
| 触发场景 | 原文与选项使用“需要、必须、前提、关键、有助于”等不同强度的对策表达，需要判断是否构成合理替换 |
| 步骤逻辑 | ① 先核对对策主体和内容是否一致；② 再比较语气强度：“必须/前提/不可或缺”表达必要性，“关键”表达重要性，“有助于/促进”只表达积极作用；③ 原文有同等强度依据时可视为合理替换，选项无依据强化或弱化时应谨慎；④ 不能只因出现“必须”等词就排除，也不能把所有对策词视为完全等价 |
| 高频错因 | 看到强语气词就机械排除；忽略原文是否提供必要性依据；把“有助于”误当成“必须”，造成程度偷换 |
| confidence | medium |
| 不适用条件 | 1. 选项涉及不同对策内容（如一个说努力、一个说方法），本卡不讨论内容差异\n2. 选项涉及纯事实概括而非对策类表述\n3. 题目考查的是文段主旨而非对策选择 |
| 反向触发 | 原文只说某措施有帮助，而选项升级为唯一前提或必经之路时，应检查程度偷换；原文明示必要条件时，不能仅因选项语气强就排除；主体或对策内容不同时时，先处理内容错位而非比较语气 |
