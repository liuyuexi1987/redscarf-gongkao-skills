# 方法卡：多次稀释代入法
## 基本信息
| 字段 | 值 |
|------|-----|
| 方法名 | 多次稀释代入法 |
| 适用题型 | 数量关系-溶液多次稀释问题 |
| 触发场景 | 药水/溶液依次倒入多个试管稀释，求初始浓度，选项为具体数值 |
| 步骤逻辑 | 1.盯住溶质质量不变；2.从选项中取值正向代入；3.每次稀释后浓度=原浓度×取出量÷（取出量+新水量）；4.代入各选项直到最终浓度匹配题目条件 |
| 高频错因 | 反推容易算错溶质占比；正向代入时遗漏每次稀释后总溶液量的变化 |
| confidence | high |
## 补充说明
多次稀释问题正向代入比反向推导更快。核心：每次取出10克溶液中溶质占比=该次混合后的浓度，倒入新试管时溶质质量不变，溶液总量=原溶液+新加水。逐次计算浓度，与题目最终浓度比对即可。反推虽然可行但需要反复计算占比，容易出错。
## 不适用条件
- 题目无选项可供代入且要求精确推导，正向代入法失去效率优势。
- 每次稀释的取用量不固定或取用量本身是未知量，代入路径不唯一。
- 稀释过程含"倒出后再回倒""部分替换"等非标准操作，模型需分段处理。
## 反向触发
- 题面只涉及一次混合/稀释，直接列方程即可，无需代入法。
- 问题要求求"最少稀释几次达到某浓度"，是逆推规划问题而非正向验证。
