# 方法卡：三排序问题

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 三排序问题 |
| 适用题型 | 资料分析——盐水类排序问题（已知两个大小关系，推第三个） |
| 触发场景 | 题目问某部分>整体，但材料只给了整体和另一部分的关系 |
| 步骤逻辑 | ① 混合浓度一定在两部分之间；② 如果A>R（部分>整体），则R>B（整体>另一部分）；③ 反向转化：找不着的条件转化为找得着的条件 |
| 高频错因 | 不会转化条件；忘记混合一定在中间 |
| confidence | medium |
| 不适用条件 | 题目要求计算具体数值而非判断大小关系时；混合关系不满足 |
| 反向触发 | 题目问某部分与整体的大小关系，且选项为 |

## 补充说明

 核心逻辑：混合一定在中间。如果问"男同学平均分>全班"，等价于"全班>女同学"。材料给的是全班和女同学的关系，我们就找这个关系。转化口诀："找不着的条件，转化为找得着的条件"。
