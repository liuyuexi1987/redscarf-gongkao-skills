# 方法卡：双引号两种作用

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 双引号两种作用 |
| 适用题型 | 逻辑填空——双引号题 |
| 触发场景 | 题干或选项中出现双引号的词 |
| 步骤逻辑 | ① 判断双引号是哪种作用：A）换用字面意思——把词的常规含义换成只看字面/底层逻辑（如"釜底抽薪"加引号→只看"抽走核心"的字面义）；B）表示强调——这个词比较形象，用引号突出；② A类→只看字面逻辑选词；B类→选更形象的词 |
| 高频错因 | ① 看到双引号不区分类型→一律按常规含义理解；② 应该看字面义时却按成语本义理解→选错 |
| confidence | high |

## 补充说明
双引号在题干中的两种典型作用需分别处理：A 类（换用字面意思）——当引号加在成语上时，往往要求只取其字面逻辑而非成语整体义，选词时按字面义匹配；B 类（表示强调）——当引号加在形象化词语上时，往往提示该词为意象中心，选词应向该意象靠拢。判断属于哪一类，可看引号内词语是否为成语：成语多属 A 类，普通词多属 B 类。

## 不适用条件

- 双引号表示反语、讽刺或否定（与字面义相反）时，不套用本卡的两类判断。
- 双引号仅表示专有名词、引语或标题名称时，与选词逻辑无关，本卡不适用。
- 题干无双引号、仅选项含引号且引号作用单一时，无需分类判断。

## 反向触发

- 当引号作用难以判断（既像字面又像强调）时，应补一步语境核验：看后文是否对引号内词语做了进一步解释，以确定其作用。
- 当选项中形象词与抽象词均可搭配引号内词语时，应换用语体色彩辨析：庄重语境偏抽象，生动语境偏形象。
- 当引号内是新兴网络词或专业术语时，应改用词义推断法，结合上下文推断其指代，而非套用本卡两类规则。
