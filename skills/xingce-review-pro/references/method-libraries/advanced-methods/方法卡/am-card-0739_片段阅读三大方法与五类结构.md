# 方法卡：片段阅读三大方法与五类结构

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 片段阅读三大方法与五类结构 |
| 适用题型 | 言语理解——中心理解/标题拟定/下文推断 |
| 触发场景 | 片段阅读题（中心理解、标题拟定、下文推断等）；需要快速定位文段主旨 |
| 步骤逻辑 | 片段阅读用三大方法解题：抓住关键信息、结构分析、选项分析。文段分为五类结构。；1. **先读问题**：判断题型（中心理解/标题/下文推断等）；2. **再读文段**：分析结构类型；3. **三类文段内容**：说理类（有作者主观观点/对策→选对策）、科普介绍类（客观描述→选中性概括）、新闻类（突出"新"字）；4. **五类文段结构**：后对策/后观点（尾句是对策→选对策）、前对策/前观点（首句或第二句是对策→选对策）、总分/分总/总分总（总句是重点）、并列/大并列（需要概括全文）、二层结构（背景+新发现、因果等） |
| 高频错因 | 被选项的"合理性"吸引，忽略文段结构判断；纠结于关联词而忽略整体主旨 |
| confidence | medium |

## 补充说明

- 五种常见对策表述：祈使句/建议句、禁止型、逻辑关联词（如果就/只有才/除非否则）、祈使句+禁止型、宏观对策
- 关联词重要程度远低于整体结构
- 首句确定谈话范围和基调
- 纠结时看首句关键词

## 不适用条件

- 文段结构不明确或混合多种结构时，不能机械套用五类分类
- 选项中出现多个含主题词的选项时，需结合结构进一步比较，不能仅靠主题词排除
- 下文推断题和标题拟定题的解题重心与中心理解不同，结构分析需调整权重

## 反向触发

- 若题目问的是细节理解（如"以下哪项正确"），不使用本卡的结构分析法
- 若文段为纯数据罗列或表格类材料，不适用片段阅读结构分析
