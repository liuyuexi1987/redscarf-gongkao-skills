# 方法卡：一直存在等于非他因

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 一直存在等于非他因 |
| 适用题型 | 判断推理——时间对比归因题（"近年来""随着XX的提高"等表述引出变化） |
| 触发场景 | 题干将某结果的变化归因于某原因的变化；选项提到的因素自古以来/一直存在，没有随时间变化 |
| 步骤逻辑 | ① 识别时间对比归因结构：结果A近年变多 → 归因于B近年变多；② 判断选项提到的因素是否"一直存在"（如遗传、免疫缺陷、地壳内部元素等）；③ 若一直存在，则它无法解释"近年变多"这一变化，直接排除（属于伪他因） |
| 高频错因 | 把"一直存在"的因素误认为是他因选项；未识别出题干是时间对比归因结构 |
| confidence | high |

## 补充说明

"一直存在"设错项的识别：当选项提到的因素属于自古存在、不随时间变化的内容（如地壳内部固有元素、遗传特征、先天性免疫缺陷等），它无法解释"近年变多"这种时间对比变化，应直接排除。

正确他因必须伴随时间变化（如"随着医疗水平提高""随着工业化推进"等），才能解释结果的时间变化。

## 不适用条件

- 题干不是时间对比归因结构（无"近年来""随着XX提高"等时间变化表述）时不适用。
- 选项提到的因素虽然一直存在，但其在近年发生了强度/范围上的变化（并非"完全不变"），此时不能简单按"一直存在"排除。
- 题干归因的是静态事实而非动态变化时，应换用其他削弱思路。

## 反向触发

- 当选项中的因素虽长期存在但其影响程度在近年有显著变化时，应换用"他因强度变化"思路重新评估。
- 当题干不是时间对比结构而是对比实验结构时，应换用"因果倒置"或"实验分组差异"法。
- 当所有选项都是"一直存在"因素时，应回头核验题干结构识别是否准确。
