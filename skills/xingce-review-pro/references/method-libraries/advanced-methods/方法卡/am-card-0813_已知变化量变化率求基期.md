# 方法卡：已知变化量变化率求基期

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 已知变化量变化率求基期 |
| 适用题型 | 基期 / 已知变化情况求基期 |
| 触发场景 | 材料同时给出增长量X和增长率R，问题要求基期量A（或用两个变化量推基期） |
| 步骤逻辑 | 1. 识别题型：材料给的是增长量（而非现期量）和增长率；2. 直接套公式：A = X / R；3. 不需要先算现期再反推，一步到位 |
| 高频错因 | 遗忘公式A=X/R，试图用B/(1+R)再反推，多做无用功将"下降"的增量方向搞错导致符号错误考前未复习此知识点，考场临时想不起来 |
| confidence | medium |

## 不适用条件

1. 材料只给出现期量B和增长率R，没有给出增长量X，需用B/(1+R)公式。
2. 材料给出的是两个现期量（而非增长量和增长率），需用差值求基期。
3. 增长率为负且增长量也为负时，需注意方向一致，若符号混乱需先理清再代入。

## 反向触发

1. 手中有增长量X和增长率R却先算现期B=X/(1+R)再算基期A=B/(1+R)，绕了远路。
2. 下降场景中把增量取了正值代入公式，导致基期量方向相反。
