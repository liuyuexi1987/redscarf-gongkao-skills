# 方法卡：排序题选项差异突破法

| 字段 | 内容 |
|------|------|
| 方法名 | 排序题选项差异突破法 |
| 适用题型 | 资料分析-排序/比较题（问最大/最小排第几） |
| 触发场景 | 排序题的四个选项中，最大项或最小项各不相同，只需验证其中一个即可选出答案 |
| 步骤逻辑 | 1. 观察选项中最大/最小是否各不相同 → 2. 若各不同，选计算量最小的那个方向（最大或最小）→ 3. 只验证一个即可确定答案 |
| 高频错因 | 逐个计算所有排序项，运算量过大浪费时间 |
| confidence | high |

补充说明：核心思路是"选项特征决定验证方向"。四个选项的最大/最小都不一样，意味着只需确认一个极值就能锁定答案。优先选观察图更容易判断的方向。

## 不适用条件

- 四个选项中最大或最小项存在重复时，单个极值验证无法锁定答案
- 题目要求排序所有项而非仅问最大或最小值
- 选项给出的不是排名而是具体数值区间

## 反向触发

- 当验证第一个极值后发现两个选项的值相同，应继续验证下一个极值
- 各选项极值项虽不同但数值非常接近（四舍五入可能影响判断）时，需额外确认
- 题目问的是"最大/最小的比哪个大/小"这类相对比较而非排名问题时，应换用直接比较法
