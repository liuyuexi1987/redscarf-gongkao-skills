# 方法卡：三类文段分类法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 三类文段分类法 |
| 适用题型 | 片段阅读-中心理解题 |
| 触发场景 | 拿到片段阅读题第一步，先判断文段属于说理类/科普介绍类/新闻类 |
| 步骤逻辑 | 1. 读完文段，判断作者有无观点/对策/态度；2. 有观点对策态度 → 说理类；无倾向纯介绍 → 科普介绍类；有"新发现/新突破/新进展" → 新闻类；3. 说理类选对策或观点；科普类选中性客观概括；新闻类突出"新" |
| 高频错因 | 不区分文段类型，一律用"尾句即重点"或"选对策"套用 |
| confidence | medium |

## 不适用条件

1. 文段类型模糊或混合（如前半段科普介绍、后半段说理），不能简单归入单一类型，需拆分处理。
2. 文段为非常规结构（如列举、对话、故事型），三分类法不直接覆盖，应以文段重心为准。
3. 题目问的是语句衔接、细节判断等非主旨类题型，不适用文段分类选主旨的方法。

## 反向触发

1. 分类为说理类后，如果文段有明确对策句，用前对策结构抓对策法。
2. 分类为科普介绍类后，用科普类客观概括法选中性概括选项。
3. 分类后仍无法在选项间区分，应结合选项逆推反推法做最终抉择。
