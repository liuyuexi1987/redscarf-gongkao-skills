# 方法卡：常见平方数速记

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 常见平方数速记 |
| 适用题型 | 数量关系——数字计算、数列与代入验证 |
| 触发场景 | 计算或选项中出现常见平方数及其附近数值，需要快速识别平方根或完全平方结构 |
| 步骤逻辑 | 1. 记忆20以内的平方数：11²=121, 12²=144, 13²=169, 14²=196, 15²=225, 16²=256, 17²=289, 18²=324, 19²=361, 20²=400；2. 遇到题目中出现这些数或接近的数，快速识别对应的平方根；3. 在代入法、等差数列求和、分组问题中高频使用 |
| 高频错因 | 只记到10²或12²，不够用18²=324, 19²=361 这两个容易记混 |
| confidence | medium |
| 不适用条件 | 平方根超过20或题目不涉及平方运算；涉及立方数、高次幂或其他非平方数列 |
| 反向触发 | 若需要判断的数字超出20²范围，需手动拆分计算（如25²=625单独记忆）；若题目涉及立方根（如求∛729），平方数速记不够用，需额外记忆常用立方数 |

## 补充说明

强化方法建议记到20以内即可。本题中直接用到18²=324和19²=361来快速验证选项。这些平方数在代入法、等差数列、完全平方判断中反复出现，是数量关系的基本功。
