# 方法卡：非比重比值差套用公式

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 非比重比值差套用公式 |
| 适用题型 | 资料分析——两期比值做差（如平均单价同比变化、亩产变化、每场演出收入变化），选项为具体数值或带量纲的差值 |
| 触发场景 | 题目求的不是"比重"而是"比值"（如出口额÷出口量=平均单价，收入÷场次=每场收入）的两期差值；题干含"平均/单价/均价/每…的…"且问变化量 |
| 步骤逻辑 | ① 先判断比值上升还是下降：R1（分子的增长率）> R2（分母的增长率）→ 上升，反之下降，排除不符选项；② 套用比重差公式：比值差 = 今年的分母分之去年的分子 × (R1-R2)；③ "去年的分子"即分子的基期值，用假设分配第一步估算或精确计算；④ 不能快速判断（分子/分母不具有部分÷整体关系，无法确定与1的大小关系） |
| 高频错因 | ① 误以为可以快速判断：非比重的比值不保证分子/分母 < 1，无法用"小于增速差"排除；② 分不清谁是R1谁是R2（分子的增长率是R1，分母的增长率是R2）；③ 比值差的单位与比重差不同，比重差是百分点，比值差是有量纲的数值（如元、元/斤） |
| confidence | medium |

## 补充说明

核心区别：比重差可以快速判断（比重差数值 < 增速差），因为"去年的部分/今年的整体"是一个部分÷整体，天然小于1；而非比重比值差中"去年的分子/今年的分母"没有这个约束（如去年出口额3000万÷今年出口量2000吨=1.5），所以不能快速判断，必须代入公式计算。识别要点：看选项单位——百分点=比重差（可快速判断），有量纲数值=比值差（必须代入公式计算）。此公式可推广至任何"两个量相除再做差"的场景。

## 不适用条件

1. 题目求的是比重差（部分÷整体），此时可用快速判断法，不必套用本公式。
2. 题目只要求判断比值上升还是下降，不需要算具体差值，只需比较R1与R2即可。
3. 缺少分子或分母的增速数据，无法代入公式。

## 反向触发

1. 题干出现"平均/单价/均价/每人/每场/每…的…"且问变化量，选项带量纲单位（元、吨/次等）。
2. 分子和分母不构成部分与整体关系，无法用比重差快速判断法，必须代入公式。
3. 选项差距较小，仅判断升降不够，需要算出具体差值才能选。
