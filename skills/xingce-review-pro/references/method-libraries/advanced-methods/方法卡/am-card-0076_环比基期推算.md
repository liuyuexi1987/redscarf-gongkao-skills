# 方法卡：环比基期推算（负增速→加自身分数）

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 环比基期推算（负增速→加自身分数） |
| 适用题型 | 资料分析 - 已知现期和环比增速求基期 |
| 触发场景 | 题目给当月数据和环比增速（如下降33.1%），求上月数值 |
| 步骤逻辑 | 1. 环比增速为负，如 -33.1% ≈ -1/3；2. 现期 : 基期 = (1+R) : 1 = 2 : 3（下降1/3意味着现期是基期的2/3）；3. 基期 = 现期 ÷ (1+R) = 现期 ÷ (2/3) ≈ 现期 + 现期/2（加自身的一半）；4. 可先按粗略分数（如1/3）算，再微调误差 |
| 高频错因 | 把环比和同比搞混；增速是负数时忘记基期比现期大 |
| confidence | high |

## 不适用条件

- 题目问的是同比增速而非环比增速时，不使用环比基期推算公式。
- 需要跨多期连续推算（如从3月推回1月）时，逐期推算累积误差大，应考虑是否有年度数据可用。
- 环比增速很小且选项紧密时，粗略分数近似可能跨越选项或改变结论，需用原始公式计算。

## 反向触发

- 题目给的是同比增长率，基期应按同比公式（基期=现期÷(1+同比增速)）计算。
- 题目要求求的是环比增速而非基期值，方向相反。
- 材料已直接给出上期数据，无需推算。
