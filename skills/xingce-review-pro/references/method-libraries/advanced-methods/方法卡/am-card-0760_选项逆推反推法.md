# 方法卡：选项逆推反推法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 选项逆推反推法 |
| 适用题型 | 言语理解——主旨概括（所有文段类型） |
| 触发场景 | 需要在多个选项之间做最终抉择，或选项类型可以反推文段结构时 |
| 步骤逻辑 | ① 把选项当标题/申论作文题目，逆推原文会怎么写；② 如果选了这个选项，原文应该是哪种结构（因果？历程？对比？具体枚举？）；③ 对照实际文段，看是否匹配；④ 不匹配则排除；⑤ 常见陷阱：选项只体现部分（片面），或选项的倾向（褒贬）与原文相反 |
| 高频错因 | 不做逆推，只凭感觉选；选项片面只对应文段一小块内容但没察觉；选项倾向（正面/负面）与原文矛盾但没发现 |
| confidence | medium |

## 补充说明

- 逆推法是做选项排除的核心方法。例如："D选项说良好社会环境很重要"→逆推原文：现在是在批评社会环境有问题，还是表扬社会环境太好了？→看不出来→D有问题。
- "正在改变"类选项要特别注意：原文在说问题+变化，"正在改变"可以是对的；但"需要进一步纠正"暗示改得不够，可能歪曲了原文态度。
- 选项逆推法的四类特殊选项（原因类/历程类/区别比较联系类/具体类）见am-card-0752_四大类选项逆推法。

## 不适用条件

1. 文段类型已明确且选项类型与之直接对应，无需逆推，直接匹配即可。
2. 题目属于细节判断题或语句衔接题，不能用逆推文段结构的方式做题。
3. 选项表述高度抽象或笼统，无法反推出具体的文段结构时，逆推无法产生有效信息。

## 反向触发

1. 如果逆推后发现多个选项都能对上文段结构，需回到原文对比哪个选项最全面地覆盖核心内容。
2. 如果逆推过程中发现选项有褒贬倾向与原文矛盾，应结合主体一致性排除法快速排除。
3. 如果选项涉及"对策"类型，逆推时应判断原文是否真的是说理类，避免科普类文段误选对策。
