# 方法卡：间隔增长率三节点知二求三（笑脸图）

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 间隔增长率三节点知二求三（笑脸图） |
| 适用题型 | 资料分析——间隔增长率计算（笑脸图法） |
| 触发场景 | 题目涉及三个时间节点，已知两段增长率求第三段，或需要使用 R间=R1+R2+R1×R2 连接相邻与间隔增长率 |
| 步骤逻辑 | 1. 识别三个时间节点，画出笑脸图（上左=R1，上右=R2，底下=R间）；2. R间 = R1 + R2 + R1×R2，三个量知二求一；3. 已知的两个增速可以是任意间隔，不必是等间距年份；4. 代入公式反推未知增速，可结合选项代入排除 |
| 高频错因 | 没有识别出"三个时间点"的特征，想不到用间隔增长三个时间节点对应关系搞混（谁是R1谁是R2谁是R间）误认为需要等间距年份才能用此法 |
| confidence | medium |

## 不适用条件

- 只有两个时间节点的简单增长率计算，用普通增长率公式即可
- 题目给出的是同比和环比混合数据，时间节点不连续时需谨慎
- 选项差距极小需精确值时，笑脸图辅助判断力度不足

## 反向触发

- 若无法从题干确认三个时间节点，先画时间轴标注再决定是否用本法
- 若 R1 或 R2 为负值，公式仍然成立但乘积项符号变化，需特别注意
