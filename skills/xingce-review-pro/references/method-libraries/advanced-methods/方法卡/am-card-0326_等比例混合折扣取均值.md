# 方法卡：等比例混合折扣取均值

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 等比例混合折扣取均值 |
| 适用题型 | 数量关系——经济利润、折扣与加权平均 |
| 触发场景 | 原价相同且数量相等的商品采用不同折扣，求整体折扣率 |
| 步骤逻辑 | 1. 识别各商品的折扣率（如四折=40%，一折=10%）；2. 确认是否"等比例混合"（即原价相同的商品数量相等）；3. 等比例混合时，整体折扣 = 各折扣率的算术平均值；4. 例如：40% + 10% = 50%，÷2 = 25%，即2.5折 |
| 高频错因 | 不识别"等比例混合"条件，直接用加权平均算混淆"折扣"和"折后比例"（2.5折 = 25%折后价 = 75%原价） |
| confidence | medium |
| 不适用条件 | 各商品原价不同或购买数量不等（需加权平均）；折扣形式为满减、阶梯折扣等非统一折扣率的促销方式 |
| 反向触发 | 当混合比例非等比例时，必须用加权平均而非简单算术平均；注意区分"折扣"和"折后比例"（如2.5折表示折后价为原价的四分之一），混淆时按定义重新推算验证 |

## 补充说明

此技巧在"买一送一"、"第二件半价"等促销问题中非常实用。关键前提：折扣商品原价相同且数量相等。满足时直接取折扣率平均值，省去复杂的金额计算。
