# 方法卡：言语理解错因诊断总卡

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 言语理解错因诊断总卡 |
| 适用题型 | 言语理解（中心理解、意图判断、细节判断、语句填入、语句排序、标题填入、结语推断）——错因诊断 |
| 触发场景 | 用户做错言语理解题后，讲解/复盘结束，需要判断错因并写入错因卡或弱点档案时 |
| 步骤逻辑 | ① 确认题型和正确答案；② 对照用户思路或选项差异定位错因类别；③ 写入弱点档案并标注模块标签 |
| 高频错因 | ① 主题词偏移；② 结构误判；③ 主旨句位置错判；④ 对策误判；⑤ 以偏概全；⑥ 偷换主体/范围/程度/时态；⑦ 只看局部；⑧ 选项比较失误 |
| confidence | high |
| 不适用条件 | - 没有官方/核验答案的主观言语题，不得硬判错因，只能写"待核对/方法倾向"
| 反向触发 | - 用户正在做题中（非复盘阶段）
- 只想要答案不想复盘时
- 题目来自用户上传的未核验题库，答案未确认时 |
- 用户没有给思路时，只能根据选项差异和题目结构做低置信诊断，标注"低置信"
- 诊断卡只在讲解/复盘第二轮使用，第一轮先完成正常讲解流程
- 细节判断题需额外核对四要素（主体、数据、时间、关系），参考 am-card-0970 |

## 诊断流程

智能体在讲解/复盘言语理解题后，按以下流程判断用户错因：

### 第一步：确认基本信息
- 题型是什么？（中心理解/意图判断/细节判断/语句填入/排序/标题/结语）
- 正确答案是什么？
- 用户选了什么？
- 用户是否给出了自己的思路？

### 第二步：定位错因类别

**如果用户给了思路**，优先对照用户思路归因：
- 用户的思路和正确思路差在哪里？
- 是理解偏差还是方法偏差？

**如果用户没给思路**，根据选项差异和题目结构做低置信诊断：
- 用户选的选项和正确选项的核心差异是什么？
- 这种差异对应哪类错因？

### 第三步：写入弱点档案
- 使用标准标签格式：`言语-题型-核心考点`
- 不要泛泛写"粗心"或"没看清"
- 要写清楚具体是哪一步出了问题

## 错因分类表

| 错因类型 | 判定信号 | 典型表现 | 写入弱点档案的建议标签 |
|----------|----------|----------|------------------------|
| 主题词偏移 | 用户选的选项主体与文段核心对象不一致 | 把"管理"选成"技术"，把"传统文化"选成"现代文化" | 言语-主旨理解-主题词偏移 |
| 结构误判 | 没看出转折/因果/并列/递进关系 | 转折前内容当选，因果倒置，递进前当选 | 言语-主旨理解-结构判断失误 |
| 主旨句位置错判 | 只看尾句或只看首句，漏掉真正主旨 | 并列结构只抓一半，设问结构没看回答 | 言语-主旨理解-主旨句定位错误 |
| 对策误判 | 无中生有对策，或有对策不选对策 | 文段没对策却选了对策，文段有对策却不选 | 言语-主旨理解-对策判断错误 |
| 以偏概全 | 拿局部细节当全文主旨 | 把例子当观点，把原因当结果 | 言语-主旨理解-以偏概全 |
| 偷换主体 | 选项主体和文段主体不一致 | 问"东部"答"全国"，问"张三"答"李四" | 言语-细节判断-主体偷换 |
| 偷换范围 | 扩大或缩小范围 | "部分"变"全部"，"某些"变"所有" | 言语-细节判断-范围偷换 |
| 偷换程度 | 绝对化、弱化、强化 | "可能"变"一定"，"重要"变"唯一" | 言语-细节判断-程度偷换 |
| 偷换时态 | 已然/未然/正在/将来混淆 | "将要"变"已经"，"正在"变"完成" | 言语-细节判断-时态偷换 |
| 只看局部 | 没统摄全文，只抓了部分内容 | 并列结构只选了一半，多因只选了一因 | 言语-主旨理解-概括不全 |
| 选项比较错 | 没做"最优项"比较，选了次优项 | 有因果阐明却选了因果并列，有完美选项却选了有瑕疵的 | 言语-主旨理解-择优失误 |
| 忽视观点提出方式 | 没识别出开门见山/借引/设问/反问等观点提出方式 | 把背景当观点，把问题当观点 | 言语-主旨理解-观点识别错误 |
| 因果关系错判 | 原因类文段结果不重要，或因果倒置 | 原因类文段只选原因不选结果 | 言语-主旨理解-因果关系错判 |

## 写回建议

写错因卡/弱点档案时的标准表达：

### 正确示例
- `言语-主旨理解-主题词偏移`：用户把"管理"理解成"技术"，选项主体偏移
- `言语-主旨理解-结构判断失误`：没看出转折后是重点，选了转折前内容
- `言语-细节判断-时态偷换`：选项把"将要"偷换成"已经"
- `言语-语句填入-衔接不当`：横线在中间，没做到承上启下

### 错误示例（不要这样写）
- ❌ "粗心"
- ❌ "没看清"
- ❌ "理解能力差"
- ❌ "逻辑不好"

## 使用边界

1. **没有官方/核验答案的主观言语题**，不得硬判错因，只能写"待核对/方法倾向"
2. **用户没有给思路时**，只能根据选项差异和题目结构做低置信诊断，标注"低置信"
3. **用户给了思路时**，必须优先对照用户思路归因
4. **诊断卡只在讲解/复盘第二轮使用**，第一轮先完成正常讲解流程
5. **细节判断题**需额外核对四要素（主体、数据、时间、关系），参考 am-card-0970

## 补充说明

- 本卡服务于"复盘讲解→错因归类→弱点档案更新→后续考我"完整闭环
- 错因分类基于言语理解常见错误模式，可覆盖大多数题型
- 对于原因类文段，特别注意"结果一定重要"原则，参考 am-card-0988
- 对于观点类文段，特别注意"以人为本"原则，抓准被观点主体
