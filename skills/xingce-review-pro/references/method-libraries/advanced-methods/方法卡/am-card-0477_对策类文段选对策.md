# 方法卡：对策类文段选对策选项

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 对策类文段选对策选项 |
| 适用题型 | 中心理解题（对策类文段） |
| 触发场景 | 文段中出现对策标志词：应该、需要、必须、应当、应、有赖于、关键在于、基石/支撑/保障/前提等，或文段结构为"问题→对策"。选项中有表对策的表述。 |
| 步骤逻辑 | 1. 文段有对策 → **一定选对策**，不选意义、影响、原因类选项；2. 对策类选项有三种长相：纯对策、对策+目的、对策+意义；3. 文段尾句如果是意义/好处，且前文有对策 → 选对策不选意义；4. 若多个选项都表对策 → 选**更具体**的那个（参见"具体>宏观"卡）；5. "有对策选对策"优先级高于"全面概括" |
| 高频错因 | 文段明明提了对策，却被意义/好处类选项吸引不识别"基石/支撑/保障/前提"等隐性对策标志词对策选项与意义选项纠结时，错误选择意义 |
| confidence | high |

## 不适用条件

1. 文段对策表述模糊笼统，而选项给出的对策超出了文段讨论范围（如文段说"加强管理"，选项具体到某一技术手段文段未提及），不能仅因为是对策就选。
2. 文段结构为"问题→原因→对策"但选项中没有对策表述，只有原因分析，此时需判断选项是否为最优，不能仅因缺对策就排除。
3. 题目问的是"文段主要介绍了"或"文段意在说明"，且文段重心在分析而非提出对策，对策选项可能不是主旨。

## 反向触发

1. 当文段以意义/好处结尾，且意义表述是对策的直接结果时，意义选项可能比对策选项更全面地概括了文段，需逐句核对。
2. 多个对策选项互相矛盾时，不能都选，需回到文段验证哪个对策与文段论证方向一致。
3. 估算误差可能跨越选项时改用精算：将对策选项与文段对策句逐词对比，确认具体手段、对象和范围均匹配。
