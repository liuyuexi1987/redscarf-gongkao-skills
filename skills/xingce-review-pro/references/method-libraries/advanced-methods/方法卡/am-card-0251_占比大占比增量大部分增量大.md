# 方法卡：同一整体下用占比变化比较部分增量

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 同一整体下用占比变化比较部分增量 |
| 适用题型 | 资料分析——同一整体内两个部分的增长量比较 |
| 触发场景 | 已知两个部分的现期占比及占比变化，需要判断哪个部分的增长量更大 |
| 必要输入 | 基期整体量、整体增长量、两个部分的现期占比及占比变化；各数据必须来自同一整体和同一时期 |
| 步骤逻辑 | ① 设基期整体为 T0、整体增长量为 ΔT、某部分现期占比为 s1、占比变化为 Δs=s1-s0；② 该部分增长量满足 ΔP=ΔT×s1+T0×Δs；③ 当 ΔT≥0 时，若部分甲的 s1 与 Δs 均不小于部分乙，且至少一项严格更大，则甲的增长量更大；④ 若一个指标更大、另一个更小，不能仅凭占比直接判断，需代入公式比较 |
| 验证动作 | 将比较结果代回 ΔP=ΔT×s1+T0×Δs；若整体下降、统计口径不同或两项指标方向相反，停止使用速判 |
| 不适用条件 | 整体增长量为负；两个部分不属于同一整体或时期；只知道占比大小但不知道占比变化；一个部分占比更大但占比增量更小 |
| 高频错因 | 把“一个条件更大”误当作充分条件；忽略整体增长方向；混用现期占比和基期占比 |
| confidence | high |
| 反向触发 | 当ΔT≥0但一个部分占比更大、另一个占比增量更大（指标方向相反）时，速判失效，必须代入ΔP=ΔT×s1+T0×Δs逐项计算比较；整体增长量为负时同理，不能仅凭单一指标判断 |
