# 方法卡：细节判断抓大放小

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 细节判断抓大放小 |
| 适用题型 | 言语理解——细节判断题（偏难题） |
| 触发场景 | 多个选项都与原文不完全同词，需要区分合理概括与实质性偷换 |
| 步骤逻辑 | ①定位每个选项对应的原文；②直接矛盾、主体偷换、范围扩大和因果强加属于实质错误；③同义改写或不改变原意的概括不因“没有原话”而判错；④根据题目要求选择与原文最一致或冲突最明确的选项 |
| 高频错因 | 把符合常识但原文无依据的内容当成正确；把正常同义改写误判为无中生有；没有核对主体和范围 |
| confidence | high |

## 补充说明

“抓大放小”不是容忍无依据内容，而是区分实质偷换与正常改写。将两个不同事实拼接、改变主体或扩大范围属于实质错误；没有复述原句但语义等价，可以保留。常识只能辅助理解，不能替代原文证据。

## 不适用条件

1. 题目要求核对数字、年份或专有概念时，应逐项精确匹配
2. 原文信息缺失或OCR不清时，不能用轻重判断代替核验
3. 所谓“轻微概括”已经改变主体、范围或因果关系时，仍属于实质错误

## 反向触发

1. 当一个选项已确认有严重问题但剩余选项中仍有致命错误时，应换用逐句核实法
2. 当轻重瑕疵无法区分时，应放弃"抓大放小"改用逐项对照原文
3. 当题目要求选"最准确"而非"排除错误"时，需要额外核验每个选项的精确表述
