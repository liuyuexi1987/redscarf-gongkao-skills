# 方法卡：有问题抓问题不选原因

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 有问题抓问题不选原因 |
| 适用题型 | 中心理解题（文段只有问题无对策时） |
| 触发场景 | 文段提出明确问题，但没有对策表述，而选项中同时存在"问题概括"和"原因分析/深层解读" |
| 步骤逻辑 | 1. 判断文段是否有对策表述 2. 没有对策时，主旨就是归纳这个问题本身 3. 选项必须是对问题的同义转述，选直接概括问题的选项 4. 排除"原因分析""根本原因""深层含义"类选项——这类选项超出了问题本身的范围 |
| 不适用条件 | ①文段本身含原因分析表述时，不排除原因选项 ②题目明确问"推断""隐含"时，需根据文意判断，不硬套本法 |
| 高频错因 | 选了"原因分析"或"深层解读"类选项而非问题本身；将问题的某个相关因素误当作主旨 |
| confidence | high |
| 反向触发 | ①文段虽提出问题但选项中无"问题概括"类选项，只有"原因"和"对策"类选项，此时本法无法直接适用，需结合文段重心在原因和对策间做选择；②文段的问题表述后紧跟了"这是因为""根源在于"等明确原因分析，且原因部分篇幅远超问题描述，此时原因可能才是主旨所在；③文段问题表述本身非常笼统（如"存在一些问题"），而具体展开都在原因或影响层面，此时主旨更可能在具体展开部分而非笼统问题本身 |


> **使用边界**：本方法用于提供优先检查方向，不可单独据此作答；最终需回到题干关系、原文证据或选项条件完成验证。
