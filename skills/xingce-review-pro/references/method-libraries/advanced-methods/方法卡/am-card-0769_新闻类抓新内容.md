# 方法卡：新闻类抓新内容

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 新闻类抓新内容 |
| 适用题型 | 片段阅读-中心理解题 |
| 触发场景 | 文段含"新发现/新突破/新进展/新研究"等标志，结构为背景+新内容 |
| 步骤逻辑 | 1. 识别新闻类文段：前面是专业背景知识铺垫，后面出现新研究/新发现/新结论；2. 背景部分快速略读不纠结，直接跳到新内容；3. "新"是重点：选突出新研究/新结论的选项；4. 传统/过去的局限性不是在批评过去，而是为引出新服务 |
| 高频错因 | 陷在背景知识里看不懂，忽略了后面的新发现；或选了笼统表述而非具体新结论 |
| confidence | medium |

## 不适用条件

1. 文段没有"新发现/新突破/新研究"等新闻类标志，不是新闻类结构时不能套用
2. 题目问的是背景知识或原因分析，而非新内容本身
3. 文段中的"新"只是修辞，并非真正的新结论或新成果

## 反向触发

1. 选项中没有一个突出新内容，全是背景或概括性表述时——需换思路比较选项与原文的匹配度
