# 方法卡：牛吃草识别与净损失法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 牛吃草识别与净损失法 |
| 适用题型 | 数量关系-牛吃草问题 |
| 触发场景 | 题目描述一个系统"有出有入"——既有增长也有消失（生产+运走、草生长+被吃、水流入+流出、赚钱+花钱），求库存耗尽时间或某个未知量 |
| 步骤逻辑 | 1. 识别题型：看到"有出有入"即牛吃草——常见四种场景：工厂生产与运走、牛吃草与草生长、水池注水与放水、赚钱与花钱；2. 判断出>入：必须运出大于生产，否则永远耗不完；3. 列方程：库存S = (每天运出量 - 每天生产量) × 天数，即 S = (nA - B) × t；4. 联立两种情形的方程解出未知数关系（通常用A表示B和S）；5. 代入第三种情形（效率变化/天数变化），解最终目标 |
| 高频错因 | 忘记判断出>入导致列反方向方程；效率变化后忘记重新计算B的新值 |
| confidence | medium |

## 不适用条件

1. 系统只有消耗无增长（或只有增长无消耗），不是"有出有入"的结构
2. 出入量相等，系统处于平衡状态，不会耗尽
3. 增长/消耗速率随时间变化（非匀速），净损失不是常数

## 反向触发

1. 题目只描述"运走"或"吃掉"，无任何补充/增长
2. 出现"刚好用完""永远不会用完"，属于边界讨论而非列方程
3. 增长率随时间递增/递减，不符合恒定净损失假设
