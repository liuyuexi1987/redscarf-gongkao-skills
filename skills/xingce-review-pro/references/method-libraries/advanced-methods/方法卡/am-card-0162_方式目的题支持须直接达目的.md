# 方法卡：方式目的题支持须直接达目的

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 方式目的题支持须直接达目的 |
| 适用题型 | 判断推理——支持类（方式目的型论证） |
| 触发场景 | 结论为"通过方式X达到目的Y"，问支持/加强/最能支持 |
| 必要输入 | 结论可拆解为"方式→目的"结构 |
| 步骤逻辑 | ① 明确结论中的方式和目的；② 逐个检查选项：支持项必须在方式与最终目的之间建立完整因果链或机制链（方式→中间效果→最终目的），仅证明方式本身有某项优势不等于支持；③ 排除只涉及方式端的选项：如只说明方式存在某优势但未说明该优势如何导向最终目的，不构成支持 |
| 验证动作 | 回看支持项能否回答"方式通过什么路径达成最终目的"；若选项只能说明方式有优势或可行性但无法串到目的端，应排除 |
| 不适用条件 | 仅适用于支持/加强方向；削弱方向（方案做了但目的没达成）参见"方案-目的题削弱" |
| 高频错因 | 把"方式有某个优势"当成"方式能达到目的"；只关注方式端是否成立，忽略选项是否真正回应了目的端 |
| confidence | high |
| 反向触发 | 1. 当所有选项都无法建立从方式到目的的完整因果链、但有选项能说明方式具有可行性或已有成功先例时，应判断"可行性/先例"是否隐含了因果路径，而非一律排除 2. 当结论中的目的可拆解为多个子目的时，仅证明方式达到其中一个子目的不一定支持整体结论，应检查选项是否覆盖最终目的而非中间目的 3. 当选项同时涉及方式端优势和目的端结果但因果链条中间有跳跃时，应评估跳跃幅度——若中间缺失的是常识性环节（如"减少污染→改善环境"）可接受，若缺失的是关键机制环节则应排除 |
