# 方法卡：牛吃草问题比例差法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 牛吃草问题比例差法 |
| 适用题型 | 工程问题·牛吃草（含恒定负效率） |
| 触发场景 | 有固定草量+每天草在生长/枯萎+牛在吃，给出两种情况求草量或牛数 |
| 步骤逻辑 | 1. 由两种情况的时间比→净效率比（反比）；2. 净效率差 = 两种情况的牛数差（如10头vs15头，差5头）；3. 比例差对应实际差 → 求出每份值 → 得到各情况的净效率；4. 由净效率推算草的生长效率（相当于几头牛）；5. 草总量 = 净效率 × 时间；6. 新情况：净效率 = 牛数 - 草效 → 时间 = 草总量 ÷ 净效率 |
| 高频错因 | 忘记草的生长是"帮倒忙"的负效率 |
| confidence | high |

## 补充说明

牛吃草、检票口、水池进出水本质相同——都有一个恒定的"负效率"在帮忙/帮倒忙

## 不适用条件

- 草量不恒定变化（如生长效率随时间递减/递增）的非典型场景。
- 单一情况无对比数据（比例差法依赖两种情况的差份）。
- 牛数变化但草的生长效率不可视为常数的问题。

## 反向触发

- 题目只给出一种情况且无时间比信息时，改用方程法设草效为未知数求解。
- 草的生长效率随季节/时段变化时，需分段建模而非用单一比例差。
- 涉及多块草地或多个水池且互不相关时，应分别独立计算而非套用比例差。
