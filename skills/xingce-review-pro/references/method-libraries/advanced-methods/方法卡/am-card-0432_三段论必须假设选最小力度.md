# 方法卡：三段论-必须假设选最小力度

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 三段论-必须假设选最小力度 |
| 适用题型 | 判断推理-逻辑判断-三段论前提假设 |
| 触发场景 | 三段论题目问"必须假设"，且C选项是"所有"、D选项是"有些"，两者都能推出结论时 |
| 步骤逻辑 | 1. "所有"可以推出"有些"，所以"所有"和"有些"都能让结论成立 2. 但题目问"必须假设"=必要条件=最小限度 3. "有些"已经够用→选"有些"；"所有"程度过重→不选 |
| 高频错因 | 看到"所有可以推有些"就选了"所有"，忽略了"必须假设"要求的是最小必要条件 |
| confidence | high |

## 补充说明

"所有可以推有些"是对的，但前提是假设题问的是"必须假设"，等同于"最小限度的必要条件"。只需要一部分成立就足够了，不需要全部，所以选"有些"而非"所有"。这是出题人常见的坑。

## 不适用条件

- 题目问的是"补充前提"或"最能加强论证"，而非"必须假设"时，"所有"可能比"有些"更合适
- 选项中不存在全称和特称的对比（如全部选项都是"有些"或全部都是"所有"）时，本方法的核心判据不适用
- 结论的逻辑结构要求周延性（如结论中主项必须周延），此时"有些"可能不足以推出结论，需检查量词是否满足三段论规则

## 反向触发

- 当"有些"选项虽能满足必要条件，但"所有"选项是充要条件且题目语境暗示更强的确定性时，应重新审视"必须"是否隐含了充分性要求
- 当结论中出现了全称量词（如"所有A都是B"），而前提选"有些"可能导致结论无法推出时，应检查三段论的周延规则，不可机械套用"选最小力度"
- 当选项涉及模态词（如"可能""必然"）而非量词（"所有""有些"）时，本方法不适用，应从模态逻辑角度判断必要条件的力度
