# 方法卡：尾数法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 尾数法 |
| 适用题型 | 资料分析——多个数字精确求和或求差 |
| 触发场景 | 题目要求多个整数或精确数值求和/求差，选项尾数不同 |
| 步骤逻辑 | ① 确认数字为精确值（无四舍五入）；② 观察选项：尾数不同看末一位，末一位相同看末两位；③ 只计算所需位数的尾数之和，与选项匹配 |
| 高频错因 | 对四舍五入后的"多少点几万"数据误用尾数法（如234.3万不是精确值）；未注意时间段导致多算/少算年份 |
| confidence | medium |

## 补充说明

使用前提是"精确求和"——人口234.3万这类四舍五入数据不能用，高校323所这类整数可以用。看几位取决于选项设置：末位不同看一位，末两位相同看两位。当估算误差可能跨越选项或改变结论时，改用精算/验证。

## 不适用条件

1. 数据为四舍五入值（如234.3万），尾数已不精确。
2. 选项尾数完全一致，需比较更高位数，尾数法失去效率优势。
3. 计算过程涉及乘法而非简单加减，尾数不能直接对应结果。

## 反向触发

1. 多个精确整数求和/求差，且选项尾数不同或仅末两位不同。
2. 题目数据均为整数（如"XX所""XX个"），不存在四舍五入误差。
3. 时间紧张，只需匹配末一两位即可快速排除干扰项。
