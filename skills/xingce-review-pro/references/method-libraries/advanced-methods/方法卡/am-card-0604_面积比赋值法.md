# 方法卡：面积比赋值法（几何比例题首选）

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 面积比赋值法（几何比例题首选） |
| 适用题型 | 数量关系（几何面积） |
| 触发场景 | 题目给出半径比/边长比等比例关系，求面积比或阴影面积比 |
| 步骤逻辑 | 1. 把半径/边长赋值为最简整数（如半径比1:2:3→赋值1,2,3）；2. 面积=半径比的平方（如1:4:9）；3. 利用角度比分配面积（如120度占1/3，240度占2/3）；4. 逐层计算：扇形面积→环形面积=大扇形-小扇形→按角度分；5. 各部分数值直接做比，不用列方程 |
| 高频错因 | 赋值后用方程求解（多余）；不从扇形入手而从环形分析（更复杂） |
| confidence | medium |

## 不适用条件

1. 题目给出具体数值（含单位）而非比例关系时不适用赋值法。
2. 几何图形无法用边长/半径比的平方直接表达面积关系时（如不规则图形、含曲线边）不适用。
3. 比例关系带单位且需保留单位换算时不应赋值，应改用精算。

## 反向触发

1. 若涉及曲线围成的复杂区域，应换用积分或割补法。
2. 若题目要求的是周长/角度而非面积，应改用对应边比或角度比公式，不套用面积平方关系。
3. 若赋值后比例换算跨数量级、估算误差可能跨越选项时改用精算。
