# 方法卡：标数法（网格最短路径计数）
## 基本信息
| 字段 | 值 |
|------|-----|
| 方法名 | 标数法（网格最短路径计数） |
| 适用题型 | 数量关系-排列组合/网格最短路径方案数/概率分母分子 |
| 触发场景 | 从甲到乙只能向右或向下走，求最短路径方案数；或经过某定点的概率 |
| 步骤逻辑 | 1.从起点出发，相邻线段标1 2.逐点标注：某点路径数=上方点+右方点之和 3.标注到终点即为总方案数 4.若需经过某点P，分段标：甲→P方案数 × P→乙方案数 |
| 高频错因 | 方向标反（不能向左或向上）；漏标某点导致后续累加错误；分段后忘记相乘而错用加法 |
| confidence | high |
## 补充说明
本质是组合计数C(m+n,m)，但当网格中有障碍物或需经过特定点时，标数法比直接用组合公式更稳健。当需经过某定点P时，分段标注：起点→P方案数与P→终点方案数分别标出后相乘。考点少但一旦出现很稳，自己标一分钟内可完成。

## 不适用条件

- 允许向左或向上走（非单向最短路径），标数法的前提不成立
- 路径方向不规则（如斜向移动），网格标数公式不适用
- 问题求的是具体路径枚举而非方案数，标数法只给数量不给具体路径

## 反向触发

- 当标数结果明显偏大时，应检查是否有隐含的障碍物或禁止经过的点被遗漏
- 当题目要求"恰好经过某点"但同时有条件限制（如经过次数限制），分段相乘可能失效，需改用枚举或排除法
