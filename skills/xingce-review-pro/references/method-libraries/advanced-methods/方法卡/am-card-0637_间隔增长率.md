# 方法卡：间隔增长率

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 间隔增长率 |
| 适用题型 | 资料分析——求前年的量（跨两年，材料给的是今年） |
| 触发场景 | 材料给23年数据，问21年；已知23年比22年增速R1、22年比21年增速R2 |
| 步骤逻辑 | ① 间隔增长率公式：`R = R1 + R2 + R1×R2`；② 先算加和，再根据选项间距判断乘积项需要保留到什么精度；③ 求出总增长率后，用现期量和 R 反推间隔基期 |
| 高频错因 | 忘记R1×R2项（虽然小但有时需要）；时间方向搞反 |
| confidence | medium |

## 补充说明

间隔增长率来自 `(1+R1)(1+R2)-1`。乘积项是否可近似，必须看它对最终结果的影响和选项间距，不能固定省略。

## 不适用条件

- 两段增长不是连续复合关系，或中间基准口径发生变化。
- 题目给的是增长量而非增长率且无法先换算。

## 反向触发

- 一段增长率未知时转用逆运用公式或方程。
- 乘积项可能改变选项时完整保留，并用复合式回代验证。
