# 方法卡：化除为乘求基期

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 化除为乘求基期 |
| 适用题型 | 已知现期和增长率求基期 |
| 触发场景 | 增长率较小（<10%），需要快速求基期值；选项差距足够大（>3%） |
| 步骤逻辑 | 1. 基期 = 现期 / (1+r)，当 r 较小时，1/(1+r) ≈ 1-r；2. 直接用 现期 × (1-r) 替代除法；3. 误差约为 r 的平方（如 r=5%，误差仅 2.5‰）；4. 考场上看到"÷1.05"即可反应为"×0.95" |
| 高频错因 | 增率较大时仍用化除为乘，误差超出选项差距 |
| confidence | medium |
| 不适用条件 | 增长率较大时，化除为乘的近似误差不可接受；选项间距极小，化除为乘后的估算误差可能跨越相邻选项 |
| 反向触发 | 看到"÷(1+r)"先判断r量级，若r较大或化除为乘后误差可能跨越选项，直接做精确除法；若选项间距足够大且r较小，优先用化除为乘提速 |
