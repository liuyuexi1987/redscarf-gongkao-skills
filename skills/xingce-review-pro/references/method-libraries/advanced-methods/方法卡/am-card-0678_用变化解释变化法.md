# 方法卡：用变化解释变化法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 用变化解释变化法 |
| 适用题型 | 逻辑判断——支持题（结论涉及变化/趋势） |
| 触发场景 | 结论涉及"逐渐退化""越来越差""迈了重要一步"等变化表述 |
| 步骤逻辑 | ① 识别变化：结论是否涉及从过去到现在的变化；② 选项也需变化：正确选项也应是变化的（如"面积逐渐减少"而非"面积只有390个"）；③ 静态数据不支持动态结论 |
| 高频错因 | 选了静态数据（如"只有390个基因"）而非动态变化（如"面积逐渐减少"）；选了与变化方向不一致的选项 |
| confidence | medium |

## 补充说明

用变化解释变化是支持题的重要原则。例如：结论说"嗅觉逐渐退化"，支持选项应是"嗅觉中枢面积逐渐减少"（变化），而非"只有390个基因"（静态数据）。类似：结论说"更实用更方便"，支持选项应是"过去需要大量运动，现在只需动手指"（变化对比），而非"新设备还能储电"（静态优点）。

## 不适用条件

- 结论是静态事实、必要条件或因果机制，不以时间变化为核心。
- 静态证据本身能直接补上论证缺口，不能仅因“静态”而排除。

## 反向触发

- 动态选项与结论变化方向、主体或时间范围不一致时不能支持。
- 多个选项都描述变化时，比较谁更直接作用于结论中的变量和因果链。
