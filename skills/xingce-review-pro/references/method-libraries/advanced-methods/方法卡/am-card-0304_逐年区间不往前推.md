# 方法卡：逐年区间不往前推

| 字段 | 内容 |
|------|------|
| 方法名 | 逐年区间不往前推 |
| 适用题型 | 资料分析-含"逐年"表述的判断题 |
| 触发场景 | 题目说"2019~2022年逐年增加/下降"，判断趋势是否正确 |
| 步骤逻辑 | 1. "逐年"指给定区间内每相邻两年 → 2. 2019~2022年逐年=19→20→21→22，共3段比较 → 3. 不需要推算2018年数据 → 4. 但需确认区间内每个年份数据都可求 |
| 高频错因 | 误以为需要往前推到前一年的增速或数据；或忽略区间内某年数据不可求 |
| confidence | high |

补充说明：核心规则——"逐年"只看区间内相邻年份，不需往前推到区间前一年。但若区间内某一年的数据或增速不可求，则该趋势表述无法验证，该选项应判断为错误。

## 不适用条件

- 题目明确要求计算区间起始年的前一年数据（如"与2018年相比"）
- 题目问的是"年均增长率"而非"逐年"趋势
- 材料中区间内有年份数据缺失，无法逐段验证

## 反向触发

- 当发现区间内某年数据需要前推才能获得时，应标记该年段无法验证，而非强行用前一年数据替代
- 当题目说"逐年增加"但其中某两年增速为负时，不应继续套用，应直接判定趋势不成立
- 当"逐年"表述与"年均"表述同时出现时，应区分两种问法，不应混用公式
