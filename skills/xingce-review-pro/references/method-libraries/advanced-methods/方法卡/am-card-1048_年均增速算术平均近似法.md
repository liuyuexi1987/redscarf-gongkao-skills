# 方法卡：年均增速算术平均近似法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 年均增速算术平均近似法 |
| 适用题型 | 资料分析——年均增长率 |
| 触发场景 | 需要快速估算年均增长率 |
| 步骤逻辑 | ① 先用首末年比值估算大致范围；② 年均增长率≈各年增长率的算术平均数（精度够用）；③ "三个十"法：连续用10%累加，最后一两年用实际差值调整，取算术平均 |
| 高频错因 | ① 算术平均在增速差距大时误差大→仅适用于增速较均匀的情况 |
| confidence | high |

## 补充说明
算术平均近似法是快速估算手段，精度取决于各年增速是否均匀。差距大时误差显著，仅适合增速波动小的场景。

## 不适用条件
- 各年增速波动明显、正负交替或存在极端年份时，算术平均误差可能较大
- 题目要求精确值，或近似误差可能跨越选项时，应使用几何平均或首末值关系
- 只有首末期数据、没有各年增速时，不能虚构中间增速做算术平均

## 反向触发
- 如果题目给的是几何平均或要求精确公式计算，不使用算术平均近似
- 如果只有首末两年数据而无中间年份，直接用首末比值法
