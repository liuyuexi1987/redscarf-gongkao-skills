# 方法卡：反向搭桥陷阱

| 字段 | 内容 |
|------|------|
| 方法名 | 反向搭桥陷阱 |
| 适用题型 | 逻辑判断——前提假设（有搭桥方向的题） |
| 触发场景 | 题干前提→结论有断点，选项中出现两个都像搭桥的选项，需判断搭桥方向 |
| 步骤逻辑 | 1. 识别题干中的断点（前提关键词A、结论关键词B） |
| | 2. 正确搭桥方向应为：A→B（前提推结论的方向） |
| | 3. 检查选项搭桥方向：若为B→A（反向），则是陷阱 |
| | 4. 用逆否命题验证：看选项的逆否是否符合正确方向 |
| 高频错因 | ①只看选项是否连接了A和B两个关键词，忽略方向②把逆否后的方向与原命题方向混淆 |
| confidence | high |

## 不适用条件

- 题干的论据和结论之间没有明显的逻辑断点（即前提已能直接推出结论），不需要搭桥。
- 题干为非因果推理类题型（如纯数据比较、排列组合），搭桥逻辑不适用。
- 题干论据和结论涉及同一事物的不同方面且无需跨概念连接时，不涉及搭桥方向。

## 反向触发

- 选项中出现"没有...就没有..."或"并非...才..."这类否定式搭桥时，提示可能存在反向搭桥。
- 两个选项都连接了前提和结论的关键词，但方向相反时，优先用逆否命题验证方向。

**补充说明：**
- 典型案例：题干论据说"财务自由→像企业"，结论说"独立性强"。正确搭桥应为"财务自由→独立性"（从论据关键词推结论关键词）。陷阱选项说"没有财务自由→没有独立性"，逆否后为"有独立性→有财务自由"，方向反了。
- 搭桥方向的判断原则：看论据和结论中哪个是"因为"、哪个是"所以"，搭桥必须保持这个因果方向。
- 出题人专门设置反向搭桥来坑"看到关键词就选"的同学。
