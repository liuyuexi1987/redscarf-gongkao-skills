# 方法卡：逻辑关联词识别对策

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 逻辑关联词识别对策 |
| 适用题型 | 言语理解——意图判断中的对策识别 |
| 触发场景 | 文段中出现"只有才""必须否则""如果那么"等逻辑关联词时，需要判断哪半截是对策、哪半截是目标/问题。 |
| 步骤逻辑 | 1. **只有A才B** → A是必要条件=对策，B是充分条件=目标。翻译：想B，需要A；2. **必须A否则不B / 除非A否则不B** → A=对策，B=目标。翻译：想B，必须A；3. **如果A那么B** → 注意含蓄表达。"如果更努力，就更可能考上"=隐性对策，让我们努力；4. 必要条件位置一般是对策的具体做法，充分条件位置一般是想达成的目标 |
| 高频错因 | 看到"只有才"不翻译，误把充分条件那半截当对策不识别含蓄的"如果那么"表达，漏掉隐性对策 |
| confidence | medium |

## 不适用条件

- 文段中关联词连接的不是对策与目标，而是两个并列事实时，不适用本法
- "虽然…但是…"等转折关联词不表对策，应关注转折后内容
- 关联词出现在举例或背景中，不代表文段核心对策

## 反向触发

- 若关联词前后均为客观描述（无建议/要求含义），不调用本卡
- 若无法确定哪半截是必要条件、哪半截是充分条件，先翻译再判断
