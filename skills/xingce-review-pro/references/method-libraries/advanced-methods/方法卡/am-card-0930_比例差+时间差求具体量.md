# 方法卡：比例差+时间差求具体量

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 比例差+时间差求具体量 |
| 适用题型 | 行程问题·速度变化导致时间变化 |
| 触发场景 | 已知速度比和时间差（如提前/迟到N分钟），求原时间或路程 |
| 步骤逻辑 | 1. 由速度比→时间比（反比）；2. 时间比的差份 → 对应已知的时间差；3. 求出每份值 → 得到各情况的具体时间；4. 有时间和速度→求路程；5. 例：速度比8:9→时间比9:8→差1份=10分钟→慢的90分钟快的80分钟→路程=80×1.5=120km |
| 高频错因 | 时间比和速度比方向搞反 |
| confidence | high |

## 补充说明

行程问题中常见的求解链条：速度比→时间比→比例差→具体量

## 不适用条件

- 速度并非恒定（途中变速）的场景。
- 时间差未明确给出或无法换算为同一参照的情况。
- 路程也未知且无法通过其他条件建立的二元问题。

## 反向触发

- 题目给出的是路程差而非时间差时，应换用路程差+速度比法。
- 涉及多次变速（如途中休息后又恢复速度）时，需分段列方程而非整体比例。
- 速度比不能化为简单整数比时，改用代数方程求解更稳妥。
