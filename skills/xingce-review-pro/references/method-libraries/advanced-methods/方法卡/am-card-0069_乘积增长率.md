# 方法卡：乘积增长率

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 乘积增长率 |
| 适用题型 | 资料分析 - 已知总量增速和占比增速，求其中一部分的增速 |
| 触发场景 | 题目给总量+某类型占比的现期值和增速，求该类型增速；或已知A=B×C形式且已知B和C的增速 |
| 步骤逻辑 | 1. 判断题目是否为乘积形式（如：B2C出口 = 总出口 × B2C占比）；2. R1 = 整体增速（如总出口增速）；3. R2 = 占比增速（如B2C占比从19%到19.7%，R2 = 19.7/19 - 1 ≈ 3.7%）；4. 乘积增长率 R = R1 + R2 + R1×R2；5. R1×R2 通常很小，口算即可，约等于 R1+R2 |
| 高频错因 | 拿B2B占比直接算增速（B2B占比下降不代表B2C增速就是那个数）；混淆占比方向（应算B2C而非B2B） |
| confidence | high |

## 不适用条件

- 材料未呈现 A=B×C 的乘积关系结构（如单纯求一个已知量的增长率），不使用本公式。
- 题目只问单一量的增长率或增长量，不涉及"总量×占比"或"价格×数量"等因子拆分。
- 两个量之间是加减关系而非乘除关系时，不能套用乘积增长率公式。

## 反向触发

- 题目给出总出口和某类型出口的直接现期值和增速，可直接算各量增速时，无需套乘积公式。
- 题目求的是整体增长率而非某个组成部分的增速。
- 材料中"占比"指的是构成比例但增速已直接给出，无需通过总量和占比分别推导。
