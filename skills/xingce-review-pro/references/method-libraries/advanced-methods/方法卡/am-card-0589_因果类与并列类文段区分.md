# 方法卡：因果类与并列类文段区分

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 因果类与并列类文段区分 |
| 适用题型 | 言语理解——中心理解题 |
| 触发场景 | 文段描述了多个信息点，选项中有"原因"类选项（"XXX的原因"）和"A且B"类并列选项，需要判断文段是因果结构还是并列结构 |
| 步骤逻辑 | ① 看文段是否全文围绕一个"结果"反复出现来寻找原因：若前文提出结果、中间分析原因、结尾回扣结果，则为因果/果因类；② 若文段只是分别介绍两个方面（如成因+影响），没有反复围绕结果讨论，则为并列类；③ 并列类选"A且B"选项（如"成因与影响"），因果类选"原因"选项 |
| 高频错因 | 看到文段末尾有结果就认为是因果类，但文段其实只在末尾提了一句结果，并非全文反复围绕该结果讨论；选了"原因"类选项但文段实际是并列结构 |
| confidence | high |

## 补充说明

区分关键在于文段是否"全文反复围绕一个结果寻找原因"：若前文提出结果、中间分析原因、结尾回扣结果，属因果/果因类，选"原因"类选项；若文段只是分别介绍两个方面（如成因+影响），没有反复围绕结果讨论，属并列类，选"A且B"类选项。可用对比理解：同一主题（如某洋流），若文段平行介绍其成因和影响，是并列类；若文段先抛出"某地冬季更温暖"的结果再分析洋流是其原因，则是因果类。

## 不适用条件

- 文段既非因果也非并列，而是转折、递进等其他结构时，本方法不适用。
- 文段只有一个信息点（纯定义或纯说明），无从判断因果或并列时，本方法不适用。

## 反向触发

- 当文段末尾仅一句结果、前文大量内容并非围绕该结果展开时，应换用并列类方法，不选"原因"类选项。
- 当选项中既无"原因"类也无"A且B"类，而是概括类或对策类时，应换用中心理解题的对策/概括方法。
