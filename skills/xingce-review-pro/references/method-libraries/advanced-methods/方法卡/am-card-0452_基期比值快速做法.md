# 方法卡：基期比值快速做法（填一法）

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 基期比值快速做法（填一法） |
| 适用题型 | 资料分析——基期比值（两个量的基期之比） |
| 触发场景 | 题目要求计算两个量的基期比值（如基期A/基期B），且两个分母的增长率rA和rB数值接近、选项差距较小需要精确处理 |
| 步骤逻辑 | 1. 分别写出分母的"添一"值：1+rA 和 1+rB（如 112 和 116）；2. 让较小的分母通过加一个差值 Δ 变成和较大的分母相等（如 112+4=116）；3. 计算分母变化幅度：Δ/(1+rA)（如 4/112≈4%）；4. 分子也加同样幅度（如 345×4%≈13），得到修正后的分子；5. 此时两个分母相等可消掉，只需算修正后的分子之比（如 358÷568） |
| 高频错因 | 忘记分子也要同比例调整，导致式子值改变取前三位时精度不够，选项差距小时可能出错误把 1+rA 和 1+rB 的差值方向搞反 |
| confidence | medium |

## 不适用条件

- 选项差距较大（如首位不同）时，直接粗算即可，无需用填一法精修分子
- 两个增长率rA和rB差距很大（如一个10%一个30%）时，填一法的修正幅度太大，精度优势消失
- 题目要求的是现期比值而非基期比值时，本法不适用

## 反向触发

- 若分子或分母的增长率正负号无法确认，先标记待核验再操作
- 若分母的"添一"值计算后与选项精度不匹配（如选项只给到小数点后一位），先评估粗算是否已足够
