# 方法卡：对策表述适用条件

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 对策表述适用条件 |
| 适用题型 | 中心理解题（对策选项辨析） |
| 触发场景 | 题干是问题型文段，选项中出现对策表述，需判断该对策是否为正确对策 |
| 步骤逻辑 | 1. 先从宏观把握文段核心问题是什么；2. 不能看到对策就选——对策的方向必须匹配核心问题；3. 如果对策的方向本身就不对（如核心是商业性不足，对策却说注意真实性），则排除 |
| 高频错因 | 看到对策选项就冲动选择，不核对对策方向是否正确被问题型文段的"问题→对策"套路误导 |
| confidence | high |

## 不适用条件

- 文段本身没有提出明确问题，而是分析原因或阐述利弊
- 选项中的对策虽然正确但方向与文段核心问题不匹配（对策"正确"不等于对策"对题"）
- 文段是并列多问题结构，没有单一核心问题可对对策

## 反向触发

- 若文段的问题被重新定义或多次转移（如从"效率问题"转为"制度问题"），不能直接匹配最初的对策方向，应回文确认最终落脚的核心问题
- 若选项对策来自文段外的常识性建议而非文段本身的问题回应，应排除该对策，换选文段内直接对应的表述
- 若文段用反问或讽刺描述问题，未必暗示直接对策，应先判断文段立场再决定是否适用对策选项
