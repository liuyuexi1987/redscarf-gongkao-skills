# 方法卡：速度比=路程比（同时间）

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 速度比=路程比（同时间） |
| 适用题型 | 行程问题·两人同时间出发 |
| 触发场景 | 两人同时出发、同时到达某点，或题目给出相同时间下的路程 |
| 步骤逻辑 | 1. 路程 = 速度 × 时间；2. 时间相同时，路程比 = 速度比；3. 利用两组"同时间不同路程"的条件，列出速度比的等式；4. 求出总路程后，再用速度比算各自走的距离；5. 例：甲走1/3路程时乙走了9km → 甲走完时乙走了27km → 距终点还有9km |
| 高频错因 | 混淆"相同时间"和"相同路程"的前提 |
| confidence | high |

## 补充说明

两人同时出发的行程题，若给出某段相同时间内各自走过的路程，即可直接建立速度比并外推全程

## 不适用条件

- 两人并非同时出发（有先后时差）的场景。
- 中途有停顿/变速导致"相同时间"前提被破坏。
- 题目给出的是相同路程而非相同时间（应换用时间比法）。

## 反向触发

- 题目只给路程差或时间差而无同时间路程数据时，改用比例差+时间差法求解。
- 速度比随时间变化（如有加速段）时，应分段计算各段路程。
- 路程比无法直接对应到全程结构时，需列方程组而非单一比例。
