# 方法卡：主旨句在尾句快速选

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 主旨句在尾句快速选 |
| 适用题型 | 言语理解——中心理解 |
| 触发场景 | 最后一句有"需要/应该/必须/想要"等对策/目的表达，且主体明确 |
| 步骤逻辑 | ① 从尾句寻找对策或目的表达；② 提取主体、对策和目的；③ 回看前文确认尾句确实统领全文而非局部补充；④ 比较选项是否完整对应三要素，排除主体错位、范围扩大和只概括局部的选项 |
| 高频错因 | ① 尾句太长看不懂→应简化为主体+对策+目的三要素；② 尾句没有主体→漏看前面→主体缺失 |
| confidence | high |
| 不适用条件 | 尾句是举例、转折或背景铺垫而非总结对策；文段为总分结构，主旨在首句而非尾句；尾句无主体且前文也找不到明确主体 |
| 反向触发 | 文段为总分结构且首句有明确观点时，主旨在首句而非尾句，应优先看首句；尾句是反问或感叹修辞而非实质对策时，主旨可能在倒数第二句 |

## 补充说明
尾句出现完整的主体、对策和目的时，可以快速形成主旨候选；仍需回看前文确认其统领关系，并用选项范围和主体一致性完成复核。
