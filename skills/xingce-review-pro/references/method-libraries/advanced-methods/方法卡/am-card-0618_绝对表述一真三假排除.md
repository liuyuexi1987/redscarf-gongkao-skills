# 方法卡：绝对表述一真三假排除

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 绝对表述一真三假排除 |
| 适用题型 | 判断推理——真假话问题 |
| 触发场景 | 多人发言，已知只有一人/几人说对，其中某人使用"只能""唯一""别无选择"等绝对表述 |
| 步骤逻辑 | ① 找出绝对表述（"只有…才""只能""唯一出路""别无选择"）；② 若该绝对表述为真，则其他所有表述必须为假（矛盾关系），会导致不满足"两真两假"等约束；③ 因此绝对表述者必为假，反向确定哪些人说真话 |
| 高频错因 | 逐一代入验证而忽略绝对表述的排他性；将"只能A"等同于普通建议 |
| confidence | high |

## 补充说明

示例：若两位发言者分别使用"只有…才""只能…"等绝对表述，则其中任一为真时其余发言必须全假，无法满足题干"两真两假"等约束；故两位绝对表述者必假，其余发言者必真。

## 不适用条件

- 题干未限定真假数量约束（如"几真几假"）时，绝对表述的排他性无法用于反推。
- 所有发言均无绝对化表述时，本法的切入点失效。
- 绝对表述与其他发言不构成矛盾关系时，无法通过排他性定位真假。

## 反向触发

- 发言间存在明显矛盾对（A与非A）时，改用"矛盾关系先定位真假"方法。
- 题干含充分/必要条件且可翻译为逻辑式时，改用"严谨逻辑关系质疑法"找A且非B。
- 真假约束为"至少一真"而非精确数量时，转用假设—排除法。
