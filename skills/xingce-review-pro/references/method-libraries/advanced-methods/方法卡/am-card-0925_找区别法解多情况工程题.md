# 方法卡：找区别法解多情况工程题

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 找区别法解多情况工程题 |
| 适用题型 | 工程问题·多人合作·有人休息 |
| 触发场景 | 题目给出多种完成情况（如甲单独、乙单独、甲乙合作），求某人休息天数 |
| 步骤逻辑 | 1. 比较不同情况之间的差异；2. 相同部分去掉，只看差异部分；3. 例：甲单独50天，甲乙合作40天 → 甲少做了10天 → 这10天的工作量就是乙做的 → 乙效率是甲的2/3 → 乙需要15天 → 休息25天；4. 本质：小王少做的量 = 小李多做的量 |
| 高频错因 | 不比较差异，直接列复杂方程 |
| confidence | high |

## 补充说明

面对多种假设情况的题，应优先寻找情况之间的差异。

## 不适用条件

- 各情况之间无共同基准（工程量不同、人员不同）时，差异比较无意义。
- 情况之间存在非线性叠加（如合作效率非简单相加）时，差异法易遗漏交互项。
- 题目只给一种情况而无对比时，找区别法无着力点，应换用方程法。

## 反向触发

- 当差异换算后某人休息天数为负或超过总工期时，应反向核验差异对应关系是否颠倒。
- 当多种情况差异方向不一致（有时甲多有时乙多）时，应换用分情况列式法。
- 当题目含"中途换人""部分移交"等复杂场景时，应补充核验差异是否仅由单一变量引起。
