# 方法卡：工程量最小公倍数赋值

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 工程量最小公倍数赋值 |
| 适用题型 | 工程问题（只给时间，未给工程总量） |
| 触发场景 | 题目只给出各人完成任务的时间，未给工程量具体数值 |
| 步骤逻辑 | 1. 取各人完成同一任务的时间的最小公倍数，赋值为工程总量；2. 用工程量÷时间=效率，算出各人效率；3. 按统筹规划或合作问题列式求解 |
| 高频错因 | 忘记赋值导致分数计算复杂出错；赋值时未取最小公倍数导致效率不是整数 |
| confidence | high |

## 不适用条件

- 题目已给出工程总量的具体数值（无需赋值，直接用给定数值计算效率）
- 各人时间数值的最小公倍数过大（如涉及 7、11、13 等质数），赋值后计算反而复杂
- 题目涉及效率变化（如中途休息、效率递增递减），赋值法不适用于动态效率场景

## 反向触发

- 当赋值后效率仍为分数且计算复杂时，应检查是否可以取时间的某个公共倍数简化，或改用特值法
- 当题目涉及多人合作但时间条件不是完成同一任务（如分段完成不同任务）时，赋值前提不成立，应重新审题
