# 方法卡：415份数法（增长率近似）

## 基本信息
| 字段 | 值 |
|------|-----|
| 方法名 | 415份数法（增长率近似） |
| 适用题型 | 资料分析-已知现期和环比增长率求基期/增量 |
| 触发场景 | 增长率靠近简单分数（如1/3、1/4、1/5），且选项差距允许估算 |
| 步骤逻辑 | 1. 观察增长率是否接近某简单分数（如-32.4%接近-1/3）<br>2. 按该分数写出基期:增量:现期的份数比（负1/3则为3:1:2）<br>3. 用现期值除以对应份数求出每份量<br>4. 算出基期或增量 |
| 高频错因 | 正负增长率的份数比搞混（负1/3是3:1:2，正1/3是3:1:4）；近似比例选错导致误差偏大 |
| confidence | high |

## 补充说明
- 415份数法的含义：4代表1/4对应5份（4+1），此处泛指"用简单分数对应的份数比"来近似计算。
- 负增长率的份数比：基期 > 现期。如负1/3，基期=3份，增量=1份（下降量），现期=2份。
- 正增长率的份数比：如正1/3，基期=3份，增量=1份，现期=4份。
- 适用前提：近似后的误差需通过后续误差分析验证，若选项间距小需回到精确计算。

## 不适用条件
1. 增长率远离简单分数（如27%、38%等无明显对应分数）时，强行凑分数比会导致误差过大。
2. 近似份数比的误差可能跨越选项时，应改用精确计算。
3. 负增长率的简单分数近似不稳定或份数关系容易混淆时，不宜强行套用。

## 反向触发
1. 当增长率可精确表示为分数（如正好25%），直接用分数关系计算，不必近似。
2. 当需要求多个中间量（基期、增量、现期中的两个以上）时，逐项精算比份数法更可靠。
3. 当近似结果落在两个选项之间且无法判断偏向时，改用精算确认。
