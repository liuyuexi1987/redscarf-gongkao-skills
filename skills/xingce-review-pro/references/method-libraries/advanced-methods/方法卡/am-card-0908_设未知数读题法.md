# 方法卡：设未知数读题法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 设未知数读题法 |
| 适用题型 | 数量关系——方程题 |
| 触发场景 | 读题过程中遇到比例/折扣等关系需要用符号表示 |
| 步骤逻辑 | ① 读到比例关系时，用倍数设未知数（如"人工是材料的一半"→材料2A，人工A）；② 读到等量关系时列方程；③ 方程数=未知数数时可解；④ 注意设未知数时尽量让系数为整数（如40%→设5A而非A，加40%后变7A） |
| 高频错因 | ① 设了太多未知数导致方程不够；② 没有利用比例关系消元；③ 问的是A但答案要求的是另一个量 |
| confidence | high |

## 补充说明

出题逻辑：先给部分信息要求设未知数，最后再给一个等量关系（方程）求解。审题时注意"所以""因此""比……高/低"等方程信号词。

## 不适用条件

- 题目仅有单一未知量且可直接由比例还原（直接比例法更快）。
- 题目所有量都已给出具体数值，无需设未知数。
- 关系链条过长且未知数过多，方程数明显少于未知数个数。

## 反向触发

- 当未知数个数超过方程数且无法消元时，应改用赋值法或比例法补充条件。
- 当题目以比值为主、无显式等量关系时，应改用比例和份数法直接求解。
- 当题目包含整除/倍数特征明显时，可改用公倍数赋值法简化计算。
