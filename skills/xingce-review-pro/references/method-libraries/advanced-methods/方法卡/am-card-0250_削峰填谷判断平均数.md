# 方法卡：削峰填谷判断平均数

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 削峰填谷判断平均数 |
| 适用题型 | 资料分析——判断多个数的平均值是否超过/低于某个特定值 |
| 触发场景 | 给出多年数据，问年均值是否超过某数，不需要精确计算 |
| 步骤逻辑 | ① 假设目标值为平均数；② 算每个数据与目标值的差值（多的为正，少的为负）；③ 比较正差之和与负差之和：正多则平均数高于目标值，负多则低于 |
| 高频错因 | 习惯性把所有数加起来除以个数，浪费时间；忘记比较正负差值的大小关系 |
| confidence | high |
| 不适用条件 | 需要精确计算平均值具体数值时，此法只能判断大小关系，不能给出精确结果 |
| 反向触发 | 题目问"年均增长量是多少"或要求精确平均值时，必须实际加总除以个数，不能仅做削峰填谷判断 |
