# 方法卡：反义双向可推法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 反义双向可推法 |
| 适用题型 | 逻辑填空——正反对比题 |
| 触发场景 | 文段有正反对比结构（"不是A而是B"、"不仅A而且B"的反面） |
| 步骤逻辑 | ① 找到对比的两端；② 验证反义关系是否双向成立（A的反面=B，B的反面=A）；③ 如果单向不成立→这个对比关系不成立→排除该选项 |
| 高频错因 | ① "温馨"的反面是"冰冷"不是"严肃"→温馨vs严谨不构成反义；② 只看一个方向就认为是反义→忽略了反向不成立 |
| confidence | high |

## 补充说明
正反对比是逻辑填空高频结构。核心原则：反义必须两个方向都成立。例如"温馨"→反面是冰冷/冷漠，不是严肃；"严谨"→反面是松散/随意，不是温馨。验证时应同时检查 A→B 与 B→A 两个方向，任一方向不成立即该对比关系不成立。

## 不适用条件
- 文段两端为递进、因果或并列同义关系（非反义）时，不应套用反义双向验证。
- 空格所在分句与对比另一侧之间存在中间过渡句，反义关系被弱化或转移时，单向推理已足够。
- 选项间差异不在反义方向而仅在语义轻重时，本方法不产生排除价值。

## 反向触发
- 当反义关系双向成立但选项仍剩余多个时，应换用"自带逻辑词判断法"或"前后空呼应关系"进一步区分。
- 当对比结构本身识别存疑（不确定是反义还是并列）时，应补充"分号并列对应法"做结构核验。
- 当选项中存在两个反义都成立但语义方向相反的词时，应回到文段核验空格应落在对比的哪一侧，避免选反方向。
