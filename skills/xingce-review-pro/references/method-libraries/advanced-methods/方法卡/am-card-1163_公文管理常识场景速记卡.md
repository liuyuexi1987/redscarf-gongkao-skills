# 方法卡：公文管理常识场景速记卡

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 公文管理常识场景速记卡 |
| 适用题型 | 常识判断——公文与管理（文种、行文方向、场景目的） |
| 触发场景 | 题干出现通知、通报、公告、通告、请示、报告、批复、函、纪要、意见等文种，或考查行文方向、适用对象、格式规则时 |
| 步骤逻辑 | ① 先看行文方向（上行/下行/平行）；② 再看目的（请求/答复/部署/告知/记录）；③ 检查对象（上级/下级/不相隶属机关/社会公众）；④ 涉及文种定义和格式细节时标注需核验 |
| 高频错因 | 请示与报告混用、公告与通告只按范围粗分、把意见固定为单一行文方向、报告中夹带请示事项、函与批复的对象错配 |
| confidence | high |
| 不适用条件 | 1. 纯考查管理学原理而非公文文种的题目；2. 需要精确到格式细节（如字号、页边距）的题目，本卡只覆盖文种与行文方向 |
| 反向触发 | 1. 题目涉及主体权限（如谁有权发布某类公文）时，应配合读 am-card-1149 法律常识主体权限速记卡；2. 题目涉及政策表述核验时，应读 am-card-1150 政治理论与时政常识边界卡；3. 纯管理学派理论题超出本卡范围 |

## 核心判断

公文管理题的核心是"什么文种、什么方向、给谁看、做什么"。错误选项通常是把文种的目的、对象或行文方向搞错。答题时先定行文方向，再核对目的和对象。

## 使用流程

### 第一步：确定行文方向

| 行文方向 | 典型文种 | 对象 |
|----------|---------|------|
| 上行文 | 请示、报告、意见（上行时） | 上级机关 |
| 下行文 | 通知、通报、批复、决定、意见（下行时） | 下级机关 |
| 平行文 | 函、意见（平行时） | 不相隶属机关 |
| 泛行文 | 公告、通告 | 社会公众 |

要点：意见可上行、下行、平行，不固定为单一方向。

### 第二步：文种辨析速查

| 文种 | 核心目的 | 易混点 |
|------|---------|--------|
| 请示 | 请求指示或批准 | 不能在报告中夹带请示事项；一文一事 |
| 报告 | 汇报工作、反映情况、答复询问 | 不夹带请示；不需要批复 |
| 批复 | 答复下级请示 | 必须针对请示，不主动行文 |
| 函 | 不相隶属机关之间商洽工作、询问答复 | 不是上下级之间使用 |
| 通知 | 发布、传达、部署 | 偏执行部署 |
| 通报 | 表彰、批评、传达情况 | 偏告知警示 |
| 公告 | 面向国内外宣布重要或法定事项 | 范围最广，事项重要 |
| 通告 | 一定范围内公布应遵守或周知事项 | 范围较窄，常带遵守性 |
| 纪要 | 记载会议主要情况和议定事项 | 不等于会议记录全文 |

### 第三步：高频混淆点排查

| 混淆点 | 正确区分 | 常见误判 |
|--------|---------|---------|
| 请示 vs 报告 | 请示求批准需批复；报告汇报情况不需批复 | 把报告当请示用 |
| 公告 vs 通告 | 公告面向国内外重要事项；通告面向一定范围周知或遵守 | 只按"范围大小"粗分 |
| 通知 vs 通报 | 通知偏部署执行；通报偏表彰批评告知 | 混用目的 |
| 函 vs 批复 | 函用于不相隶属机关；批复用于答复下级请示 | 混淆对象 |
| 意见 vs 通知 | 意见可多方向；通知偏下行部署 | 把意见固定为下行 |

### 第四步：验证与核验

- 题干问"应用什么文种"→对照目的和对象
- 题干问"行文方向"→对照发文与收文机关关系
- 涉及具体格式规则（如版头、发文字号、签发人）时→标注需核验《党政机关公文处理工作条例》

## 速记/排除规则

- 报告中夹带请示事项→错
- 函用于上下级之间→错，函用于不相隶属机关
- 批复不针对请示→错，批复必须针对请示
- 意见只能下行→错，意见可上行、下行、平行
- 公告和通告只按范围大小区分→不全面，还要看事项性质和是否带遵守性
- 纪要等于会议记录全文→错，纪要只记主要情况和议定事项

## 高频易混点

| 易混点 | 正确区分 | 常见误判 |
|--------|---------|---------|
| 请示 vs 报告 | 请示需批复，报告不需 | 混用 |
| 公告 vs 通告 | 公告范围最广事项重要；通告范围有限常带遵守性 | 只按范围粗分 |
| 通知 vs 通报 | 通知部署执行；通报表彰批评 | 混用目的 |
| 函 vs 批复 | 函=不相隶属；批复=答复下级请示 | 混淆对象 |
| 意见方向 | 意见可上行/下行/平行 | 固定为下行 |

## 写回/复盘标签

- 常识-公文-文种混淆
- 常识-公文-行文方向错
- 常识-公文-请示报告混用
- 常识-公文-公告通告粗分
- 常识-公文-格式规则需核验

## 使用边界

1. 本卡不是公文格式手册，不覆盖字号、页边距等格式细节。
2. 涉及具体格式规则时，提醒以《党政机关公文处理工作条例》为准。
3. 无法确认文种定义时，只能说"方法倾向/需核验"，不能硬判。
4. 公文速记只作辅助排除，不得编造文种定义。
