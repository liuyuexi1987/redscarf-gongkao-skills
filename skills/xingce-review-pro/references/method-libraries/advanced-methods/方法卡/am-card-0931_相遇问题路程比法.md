# 方法卡：相遇问题路程比法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 相遇问题路程比法 |
| 适用题型 | 行程问题·相向而行相遇 |
| 触发场景 | 两人从两端出发相向而行，给出两次相遇位置，求总路程 |
| 步骤逻辑 | 1. 速度比不变 → 每次相遇时各自走的路程比不变；2. 第一次相遇：甲走L₁，乙走L-L₁，总路程=L；3. 第二次相遇：甲走L+L₂（走到对面再回头），总路程=3L；4. 甲两次路程比 = (L+L₂) : L₁ = 3:1；5. 解方程求L |
| 高频错因 | 第二次相遇时忘记甲已经走了一个完整L再回头 |
| confidence | high |

## 补充说明

从两端出发的相遇，总路程为L, 3L, 5L, 7L...（奇数倍L）

## 不适用条件

- 两人并非从两端出发（同向出发的追及问题）。
- 速度比在过程中变化（如某人中途提速/降速）。
- 只有一次相遇数据且无第二次相遇信息的题目。

## 反向触发

- 题目只涉及单次相遇时，改用基础相遇公式"路程和=速度和×时间"。
- 多次折返且每次速度比不同时，应分段列方程分别求解。
- 相遇点位置以分数/比例描述但无具体距离时，需引入参数化建模。
