# 方法卡：断点搭桥法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 断点搭桥法 |
| 适用题型 | 支持类/前提假设题（论据→结论之间存在逻辑断裂） |
| 触发场景 | - 论据说的是A，结论说的是B，但A和B之间缺少直接推理链
- 选项中出现"如果...就..."、"只要...就..."、"只有...才..."等逻辑关联词 |
| 步骤逻辑 | 1. 标记论据中的关键词A和结论中的关键词B；2. 找出A→B推理链中断裂的位置（断点）；3. 在选项中找能连接断点的B→C或类似搭桥项；4. 优先选能用上所有已知条件的选项 |
| 高频错因 | 被"加强加固"类选项迷惑——断点处再加固也通不了车选了反向搭桥（B推A）而非正向搭桥（A推B）不识别隐藏的逻辑关键词（如"就"字省略了"如果"） |
| confidence | medium |

## 补充说明

断点搭桥是支持类题目中考频最高的方法之一。识别信号：选项一旦出现逻辑关联词（如果...就/只要...就/只有...才），往往考查断点搭桥。当题干有多个推理环节（如A→B→C→D→E），断点往往出现在中间某个被跳过的环节，选项只需补上缺失的那一段即可。

## 不适用条件

- 论据→结论之间无断点、推理链完整时，应改用增加正向论据法而非搭桥。
- 题干本质是归因论证而非推理链断裂时，应改用归因论证支持法。

## 反向触发

- 当选项只是对已有论据加强加固而未补上断点时，应换用能连接断点的搭桥项核验。
- 当选项方向为B→A（反向搭桥）时，应核验并改为正向A→B方向，避免方向错误。
