# 方法卡：单位带入计算

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 单位带入计算 |
| 适用题型 | 资料分析·涉及不同计量单位的数值计算 |
| 触发场景 | 题目要求的单位与材料给出的单位不一致（如万元/亩 vs 亿元/万公顷）；涉及母单位换算（每亩、每公顷、每平方米） |
| 必要输入 | 材料中的数值及其单位；题目要求的目标单位；两者之间的换算关系（如 1公顷=15亩、1亿=10000万） |
| 步骤逻辑 | 1. 计算时把单位带在数字旁边，不丢弃单位信息 2. 每一步运算都保留单位标记（如 26万公顷×15=390万亩） 3. 逐步换算，直到分子分母的单位均与题目要求一致 4. 确认最终结果单位=题目要求单位后，再开始计算数值 |
| 验证动作 | 把结果的单位换回材料原始单位，看能否还原近似原始数据；若不能还原，检查哪一步单位换算出错 |
| 不适用条件 | 材料单位与题目要求单位一致时不需要此法；题目已直接给出换算关系时直接使用即可 |
| 高频错因 | 忘记换算直接用原始单位数值计算；万和亿之间的换算出错（1亿=10000万）；只看数值大小忽略单位差异；常用换算关系记忆错误（如 1公顷=15亩） |
| confidence | high |
| 反向触发 | 1. 换算后数值与选项量级差距过大（如差10倍以上），说明单位换算链条某步出错，应逐步回溯单位标记定位错误环节 2. 题目同时涉及面积单位和长度单位换算（如亩→平方米→公里）且需要多步转换时，仅靠带单位计算易出错，应先列出完整换算链再逐带入 3. 选项单位与题目要求不完全一致（如选项是"万元"但题目要"亿元"），不能仅看数值匹配就选，必须确认最终结果单位与选项单位一致 |
