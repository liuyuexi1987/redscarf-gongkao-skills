# 方法卡：假设分配法

| 字段 | 内容 |
|------|------|
| 方法名 | 假设分配法 |
| 适用题型 | 资料分析-求基期值、增量（给现期值和增长率） |
| 触发场景 | 已知现期值和增长率，快速求基期值或增长量；增长率不太大时效果最佳 |
| 步骤逻辑 | 1. 在心中取整数作为"左边"（如现期276，取300） → 2. "右边"= 取整值 × 增长率 → 3. 基期 = 取整值 - 右边 → 4. 用拆分法精修右边的增量（如增长率29%，300×29%=87，但实际取300多算了24，24×29%≈7，所以增量≈80） |
| 高频错因 | 不熟练时速度不如直除；右边增量估算偏差太大导致基期值不准 |
| confidence | high |

补充说明：核心是心算分配：左边取整→右边按比例→多退少补。增长率用近似分数（如16.7%≈1/7，29%≈30%≈3/10）加速。右边增量的估算精度直接影响基期值准确度，需要多练习提高熟练度。

## 不适用条件

- 增长率较大、拆分后的修正量不再便于心算时，直除可能更快
- 数值本身很小（如两位数）时，心算误差占比过高
- 数值位数多且增长率不接近常见分数时，拆分难度过大

## 反向触发

- 当增量估算误差足以跨越选项时，应改用直除法
- 增长率恰为整数倍（如25%、50%）时，直接用倍数关系更简洁
- 当增长率本身为负数或数据包含负值时，拆分方向容易混淆，应换用其他方法
