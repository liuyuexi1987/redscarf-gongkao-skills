# 方法卡：除非否则否A则B翻译法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 除非否则否A则B翻译法 |
| 适用题型 | 逻辑——翻译推理（题干含"除非…否则…"/"A否则B"/"必须A否则B"等句式） |
| 触发场景 | 题干或选项中出现"除非A否则B"、"A否则B"、"必须A否则B"等表述，需要翻译成逻辑语言 |
| 步骤逻辑 | ① 把 A、B 分别视为完整命题；② “除非A，否则B”翻译为 `非A→B`；③ 等价形式为 `A或B`，逆否形式为 `非B→A`；④ 遇到 A、B 内部自带否定词时，先整体代入，再只对 A 取一次否定 |
| 验证动作 | 用反例检查：若 A 不成立且 B 也不成立，原句应被违反；再用逆否式 `非B→A` 复核方向 |
| 高频错因 | 把方向写成 `A→B`；没有把 A 当作完整命题，遇到双重否定时多加或少加一个“不” |
| confidence | medium |
| 反向触发 | - 题干出现"如果A那么B""只要A就B"等典型充分条件句式，应触发充分条件翻译（前推后），不用"否A则B"口诀。- 题干出现"X是Y的基础/关键/前提"等必要条件标志词，应触发am-card-0685（必要条件关键词翻译法）。 |
| 不适用条件 | 普通“如果 A 那么 B”或“只要 A 就 B”直接翻译为 `A→B`，不套“否 A 则 B”。；题干没有“除非/否则”及其等价强制句式时，不为了使用口诀而额外增加否定。 |

## 不适用条件

- 普通“如果 A 那么 B”或“只要 A 就 B”直接翻译为 `A→B`，不套“否 A 则 B”。
- 题干没有“除非/否则”及其等价强制句式时，不为了使用口诀而额外增加否定。
