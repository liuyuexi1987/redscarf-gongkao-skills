# 方法卡：差值增长率适用条件

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 差值增长率适用条件 |
| 适用题型 | 资料分析——差值增长率/混合增长率 |
| 触发场景 | 用线段法求差值增长率或混合增长率时 |
| 步骤逻辑 | ① 判断两个增长率差距：≤5个百分点→可用差值增长率；≤10个百分点→可用混合增长率求和；② 超出范围→老实算基期，不用线段法；③ 一增一减时误差最大，必须用基期量 |
| 高频错因 | ① 增长率差距大时仍用现期近似→误差不可控；② 一增一减时用现期代替基期→严重偏差 |
| confidence | high |

## 补充说明
线段法本质是溶液混合模型，应使用基期量计算比例。以现期代替基期属于近似处理，增长率差距较小时误差可接受；差距较大时估算误差可能跨越选项，应改用基期量精算。

## 不适用条件

1. 增长率差距明显超出近似适用范围时。
2. 一增一减且近似误差可能改变选项判断的场景。
3. 对结果精度要求高、不能接受近似误差时。

## 反向触发

1. 当两个增长率差距较大时，应换用基期量精算而非线段法。
2. 当出现一增一减时，先检查近似误差；可能跨选项再改用基期量计算。
3. 当选项差距小于估算误差时，应补充精算核验。
