# 方法卡：间隔代入法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 间隔代入法 |
| 适用题型 | 资料分析-年均增长率求解 |
| 触发场景 | 已知末期值、基期值和年份差N，求年均增长率R；选项区间明确时优先使用 |
| 步骤逻辑 | 先用常见N次方数(1.05^4=1.216/1.1^4=1.46等)排除极端选项 -> 将候选R假设为各年相同 -> 用间隔算两年增长率再叠加N/2次 -> 验证末期/基期比值是否匹配 |
| 高频错因 | 前推年份差算错（2022比2018应为4次方非5次方）；忘记加R1×R2交叉项导致偏小 |
| confidence | high |

## 不适用条件

1. 年份跨度使候选幂次不便口算时，间隔代入效率下降
2. 粗代入误差可能跨越选项时，需提高精度或使用对数/逐步反乘核验
3. 材料已直接给出年均增长率时无需代入

## 反向触发

1. 若题目只求年均增长量（非增长率），直接用等差公式
2. 若估算误差可能跨越选项时改用精算或逐年代入
3. 若材料给出连续多期数据且存在明显规律，可直接观察趋势
