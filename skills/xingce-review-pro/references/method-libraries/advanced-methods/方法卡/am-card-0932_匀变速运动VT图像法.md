# 方法卡：匀变速运动VT图像法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 匀变速运动VT图像法 |
| 适用题型 | 行程问题·匀加速/匀减速 |
| 触发场景 | 速度均匀变化（如匀加速到最大速度再匀减速停下） |
| 步骤逻辑 | 1. 画出V-T图像：速度随时间线性变化；2. 路程 = V-T曲线下方的面积；3. 匀加速：从V₀到V末的梯形面积 = (V₀+V末)/2 × T；4. 平均速度 = (初速度+末速度)/2；5. 从0加速到最大再减到0 → 平均速度 = 最大速度/2；6. 例：20km用20分钟 → 平均速度60km/h → 最大速度=120km/h |
| 高频错因 | 忘记VT图像面积代表路程 |
| confidence | high |

## 补充说明

匀变速运动的速度增量与时间成正比，平均速度=中间时刻的速度

## 不适用条件

- 非匀变速（加速度变化）的运动，VT图像为曲线而非直线。
- 仅给出某时刻速度而缺乏时间或路程信息的问题。
- 加速段与减速段加速度大小不一致的复合运动。

## 反向触发

- 加速度变化（如带阻尼的运动）时，应换用微积分或分段匀变速建模。
- 题目关注瞬时速度而非路程时，直接用速度公式求解即可。
- 多阶段运动且各阶段初末速度衔接复杂时，需分段画图逐一核算。
