# 方法卡：蝴蝶模型（梯形对角线面积比）

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 蝴蝶模型（梯形对角线面积比） |
| 适用题型 | 数量关系/资料分析（几何面积） |
| 触发场景 | 梯形中连对角线，求各三角形面积之比或阴影面积 |
| 步骤逻辑 | 1. 识别上下底之比（如1:2）；2. 套用结论：上下三角形面积比=底比的平方（1:4）；3. 左右翅膀面积相等（S3=S4）；4. S1与S3、S1与S4的面积比=底比（1:2）；5. 对角乘积相等：S1×S2=S3×S4；6. 常见比例直接记：底比1:2→面积1:2:2:4；底比1:3→面积1:3:3:9 |
| 高频错因 | 每次从头推导相似三角形浪费时间；不记得"翅膀面积相等"这个快捷结论 |
| confidence | medium |

## 不适用条件

1. 非梯形几何图形（普通三角形、平行四边形等）不适用本模型。
2. 题目未通过对角线分割梯形时不适用（仅给边长而无对角线分割关系）。
3. 上下底比例非整数比时需先化简为最简整数比再套用，避免比例换算错误。

## 反向触发

1. 若图形为任意四边形（非梯形），应换用一般四边形对角线面积关系公式。
2. 若题目问周长或边长比而非面积比，应改用相似三角形对应边比例法，不套用面积平方关系。
3. 若梯形内部还嵌套其他构造线（如中位线、辅助线），需先剥离额外构造再判断蝴蝶模型是否仍适用。
