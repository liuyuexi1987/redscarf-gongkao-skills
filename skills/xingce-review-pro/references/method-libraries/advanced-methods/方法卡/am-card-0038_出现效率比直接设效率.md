# 方法卡：出现效率比直接设效率
## 基本信息
| 字段 | 值 |
|------|-----|
| 方法名 | 出现效率比直接设效率 |
| 适用题型 | 数量关系-工程问题 |
| 触发场景 | 题目给出效率比或倍数关系，求工作时间或工作量 |
| 步骤逻辑 | 1.根据效率比直接设各人效率为具体整数；2.由已知条件求出总工作量；3.用新条件算出剩余工作量；4.用剩余工作量除以效率得答案 |
| 高频错因 | 效率比设值后忘记验证与题中其他倍数条件的兼容性 |
| confidence | high |
## 补充说明
工程问题核心公式：工作量=效率×时间。遇到效率比时，设具体整数可以大幅简化计算。例如甲乙效率比5:4，直接设甲=5、乙=4，再根据"甲乙和是丙的0.9倍"推出丙=10。后续用实际工作条件求出总工作量，再用新条件分配即可。
## 不适用条件
- 题目未给出效率比或倍数关系，只给了时间比或工作量比，需要先转换才可设值。
- 效率比涉及的数值过大或含分数，设整数后计算量不减反增。
- 问题只求效率之间的关系（如谁快谁慢），不需要算出具体工作量或时间。
## 反向触发
- 题面给的是时间比（如"甲用6天乙用10天"），需先取倒数转为效率比，不可直接当效率比设值。
- 工程问题中出现"轮流做""交替合作"等动态分工结构，仅设效率不够，需配合周期分析。
