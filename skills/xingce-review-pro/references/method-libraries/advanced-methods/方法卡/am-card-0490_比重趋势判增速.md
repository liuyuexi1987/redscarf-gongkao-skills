# 方法卡：比重趋势判增速

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 比重趋势判增速 |
| 适用题型 | 资料分析-判断部分增速与整体增速大小关系 |
| 触发场景 | 已知整体增速和某部分占比变化方向（上升/下降），需快速判断该部分增速是否大于整体 |
| 步骤逻辑 | 占比上升 -> 部分增速 > 整体增速 -> 整体增速已知(如3.9%)则部分增速>3.9% -> 占比下降则反之 |
| 高频错因 | 占比下降不代表部分数值下降，只是增速低于整体；忽略占比虽下降但总量仍在增长的情况 |
| confidence | high |

## 不适用条件

1. 占比变化方向未知或材料未明确给出时，无法用趋势反推
2. 需要精确计算部分增速具体数值时（本方法只做定性大小判断）
3. 整体增速为负且部分占比变化方向与常规直觉相反时，需慎用

## 反向触发

1. 若材料同时给出部分绝对值和整体绝对值，可直接用增长率公式精算
2. 若估算误差可能跨越选项时改用精算
3. 若题目要求比较多个部分的增速排序，本方法无法直接给出排序
