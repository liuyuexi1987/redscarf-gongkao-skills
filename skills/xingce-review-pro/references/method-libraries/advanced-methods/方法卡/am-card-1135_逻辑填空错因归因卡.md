# 方法卡：逻辑填空错因归因卡

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 逻辑填空错因归因卡 |
| 适用题型 | 逻辑填空（成语填空、实词填空、多空逻辑填空、混合成语实词题）——错因诊断 |
| 触发场景 | 用户做错逻辑填空题后，讲解/复盘结束，需要判断错因并写入错因卡或弱点档案时 |
| 步骤逻辑 | ① 确认空格位置和正确答案；② 对照用户思路或选项差异定位错因类别；③ 写入弱点档案并标注模块标签 |
| 高频错因 | ① 对应没找出来；② 对应找到但脑补过度；③ 词义不清；④ 近义词辨析错；⑤ 语境不匹配；⑥ 程度轻重错；⑦ 感情色彩错；⑧ 搭配对象错；⑨ 多空联动错；⑩ 逻辑关系错 |
| confidence | high |
| 不适用条件 | - 没有官方/核验答案的逻辑填空题，不得硬判错因，只能写"待核对/方法倾向"
| 反向触发 | - 用户正在做题中（非复盘阶段）
- 只想要答案不想复盘时
- 考场上快速解题时 |
- 用户没有给思路时，只能根据选项差异和题目结构做低置信诊断，标注"低置信"
- 多空题需要逐空诊断，不能只诊断一个空就下结论
- 成语题和实词题的错因侧重不同，成语侧重词义，实词侧重搭配 |

## 诊断流程

智能体在讲解/复盘逻辑填空题后，按以下流程判断用户错因：

### 第一步：确认基本信息
- 有几个空？每个空的正确答案是什么？
- 用户选了什么？
- 用户是否给出了自己的思路？

### 第二步：定位错因类别

**如果用户给了思路**，优先对照用户思路归因：
- 用户是怎么找对应的？
- 用户是怎么理解词语的？
- 用户是怎么在选项间取舍的？

**如果用户没给思路**，根据选项差异和题目结构做低置信诊断：
- 用户选的词和正确答案的核心差异是什么？
- 这种差异对应哪类错因？

### 第三步：写入弱点档案
- 使用标准标签格式：`逻辑填空-错因类型-具体考点`
- 不要泛泛写"词语不认识"
- 要写清楚是词义问题、对应问题还是辨析问题

## 错因分类表

| 错因类型 | 判定信号 | 典型表现 | 写入弱点档案的建议标签 |
|----------|----------|----------|------------------------|
| 对应没找出来 | 用户不知道从哪里找提示 | 没看到解释说明、反义结构、并列句式 | 逻辑填空-语境对应-对应点遗漏 |
| 对应找到但脑补过度 | 用户从题干信息跳到题外联想 | 从"创新"联想到"突破"再联想到"颠覆" | 逻辑填空-语境对应-脑补过度 |
| 词义不清 | 用户对词语含义理解有误 | 把"南辕北辙"理解成"背道而驰" | 逻辑填空-词义辨析-词义不清 |
| 近义词辨析错 | 只看大意，没看侧重点 | "层出不穷"和"此起彼伏"分不清 | 逻辑填空-词义辨析-近义词混淆 |
| 语境不匹配 | 词语常用语境和文段场景不合 | 用声音词形容数量，用自然词形容人工 | 逻辑填空-语境匹配-语境不搭 |
| 程度轻重错 | 词义程度过强或过弱 | "完全一样"放"大同小异"处 | 逻辑填空-程度匹配-程度过重/过轻 |
| 感情色彩错 | 褒贬中性不匹配 | 贬义词放褒义语境 | 逻辑填空-感情色彩-褒贬不当 |
| 实词搭配对象错 | 动词/名词搭配对象不对 | "鬼斧神工"搭配人工建筑 | 逻辑填空-搭配验证-搭配不当 |
| 多空联动错 | 只看一个空，没用前后空互相验证 | 第一空选了，第二空完全不考虑第一空 | 逻辑填空-多空联动-联动缺失 |
| 逻辑关系错 | 转折、递进、并列、因果判断错误 | 转折后选了转折前的意思 | 逻辑填空-逻辑关系-关系误判 |
| 推一步错误 | 在对应基础上多推了一步 | "媲美"变成"超越"，"有"变成"精通" | 逻辑填空-对应验证-过度推导 |
| 固定搭配不敏感 | 没识别出常见固定搭配 | "民生福祉"写成"民生幸福" | 逻辑填空-搭配验证-固定搭配遗漏 |
| 主语性质不契合 | 没注意主语是人还是物 | 人的词放物的主语上 | 逻辑填空-搭配验证-主语性质不匹配 |

## 写回建议

写错因卡/弱点档案时的标准表达：

### 正确示例
- `逻辑填空-语境对应-对应点遗漏`：没找到反义结构"并非...而是"
- `逻辑填空-词义辨析-近义词混淆`："层出不穷"和"此起彼伏"分不清
- `逻辑填空-程度匹配-程度过重`："完全一样"放"大同小异"处
- `逻辑填空-搭配验证-搭配不当`："鬼斧神工"搭配了人工建筑
- `逻辑填空-多空联动-联动缺失`：只看第一空，没用第二空验证

### 错误示例（不要这样写）
- ❌ "词语不认识"
- ❌ "语感不好"
- ❌ "没读懂"
- ❌ "选错了"

## 使用边界

1. **没有官方/核验答案的逻辑填空题**，不得硬判错因，只能写"待核对/方法倾向"
2. **用户没有给思路时**，只能根据选项差异和题目结构做低置信诊断，标注"低置信"
3. **用户给了思路时**，必须优先对照用户思路归因
4. **多空题**需要逐空诊断，不能只诊断一个空就下结论
5. **成语题**和**实词题**的错因侧重不同，成语侧重词义，实词侧重搭配

## 补充说明

- 本卡服务于"复盘讲解→错因归类→弱点档案更新→后续考我"完整闭环
- 错因分类基于逻辑填空常见错误模式，可覆盖大多数题型
- 特别注意"因果一致"原则：原因导致结果一定要保持一致
- 特别注意"成分一致"原则：谜底就在谜面上
- 特别注意"句式一致"原则：相同句式表并列，相同成分对应一致
- 特别注意"多对多对应"原则：多者并列时注意一一对应
- 特别注意"出题人小心思"：多空形式下，出题人可能选择带有互有逻辑的部分挖空
- 错因诊断后，建议用户参考 am-card-1128 进行三维复盘积累
