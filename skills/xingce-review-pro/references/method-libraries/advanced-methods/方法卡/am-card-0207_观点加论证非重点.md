# 方法卡：观点加论证非重点

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 观点加论证非重点 |
| 适用题型 | 中心理解 |
| 触发场景 | 文段先提观点（"离不开XX""因此"后为结论），后接具体论证（怎么做的/正反论证） |
| 步骤逻辑 | 1. 定位论点句；2. 论点后的解释说明/具体做法/正反论证均非重点；3. 有论证支撑的论点才是主旨；4. 选项只从论证部分提炼→错（出处有误） |
| 高频错因 | 从论证部分（如"科研成果""人才资源"）选了片面选项 |
| confidence | high |

## 不适用条件

1. 文段无论点句，仅为并列分述（各段地位平等，无主次之分）
2. 论点本身过于宽泛，论证部分才是信息增量（需具体判断）
3. 题目要求选择"文段涉及了哪些方面"之类全面概括，论证部分不可忽略

## 反向触发

1. 文段先提观点（"离不开XX""因此"后为结论），后接具体论证时，主旨取论点不取论证
2. 选项只覆盖论证细节而遗漏核心论点时，属于范围片面；若细节承担限定论点范围的作用，则不能机械忽略
3. "有论证支撑的论点"才是主旨——不要被论证部分的具体细节带偏
