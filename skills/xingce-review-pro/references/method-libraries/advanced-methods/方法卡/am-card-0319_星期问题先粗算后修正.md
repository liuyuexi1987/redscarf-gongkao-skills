# 方法卡：星期问题先粗算后修正

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 星期问题先粗算后修正 |
| 适用题型 | 数量关系——日期星期推算 |
| 触发场景 | 给出两个跨月日期及其中一个星期，求另一日期是星期几 |
| 步骤逻辑 | 1. **粗算**: 月份差 × 30（每月按30天算）；2. **修正**: 中间经过的大月（31天）每个加1天，不算最后一个月；3. **加日期差**: 目标日期 - 起始日期；4. 总天数 ÷ 7 取余数，余几就星期往后推几 |
| 高频错因 | 忘记修正大月（1/3/5/7/8/10/12月为31天）最后一个月不算修正，只算日期差余数为0代表星期相同，不要多推 |
| confidence | medium |
| 不适用条件 | 两个日期在同月内，直接算日期差取余更简单；题目问的是日期差天数而非星期几 |
| 反向触发 | 粗算修正后余数与选项不符，回溯检查：是否遗漏大月修正、是否把最后一个月的大月也算进修正、是否跨闰年二月（二月粗算按30天但实际28或29天需减回） |

## 补充说明

这是强化方法经典的星期推算三步法。核心口诀：粗算（月差×30）→ 修正（大月+1，不算末月）→ 加日期差。熟练后可在脑中直接完成。
