# 方法卡：白吃牛公式法
## 基本信息
| 字段 | 值 |
|------|-----|
| 方法名 | 白吃牛公式法 |
| 适用题型 | 数量关系-牛吃草/注排水问题 |
| 触发场景 | 两种不同效率组合完成同一任务，求第三种组合的完成时间 |
| 步骤逻辑 | 1. 白吃牛（草生长速度）=（时间₁×牛数₁ - 时间₂×牛数₂）÷（时间₁ - 时间₂）；2. 原有草 =（牛数 - 白吃牛）× 时间；3. 用新的牛数求完成时间 = 原有草 ÷（新牛数 - 白吃牛） |
| 高频错因 | 注排水问题中注水和吃草方向相反需注意正负号；混淆"白吃牛"代表的含义 |
| confidence | high |
## 补充说明
也可用方程法理解为工程问题：原有草量 = 净效率 × 时间，不同情况总量不变列方程。白吃牛法本质是方程法的速算口诀。注水=吃草（消耗），排水=草生长（增长），注意方向相反时的正负处理。方程法更通用易理解，白吃牛法更快但需理解含义。
## 不适用条件
- 生长/消耗速率不是恒定值（如速率随时间递增或递减），不满足白吃牛公式的线性前提。
- 题目只给一种组合情况，无法列两个方程解出白吃牛值和原有量。
- 问题为标准工程问题且无消耗/增长的对冲结构（如多人合作、分段施工），白吃牛法无优势。
## 反向触发
- 题面描述"效率""工作量""合作""分段"但无草生长/水注排的对冲含义，属工程问题，不用白吃牛。
- 多种组合但各组合中参与者的效率不同（非常规牛吃草结构），公式无法直接套用。
