# 方法卡：符号规避计算风险

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 符号规避计算风险 |
| 适用题型 | 资料分析·估算类题目（选项差距较大） |
| 触发场景 | 多步估算题中，需要控制误差传递以避免误差跨越选项或改变结论时 |
| 步骤逻辑 | 1. 将数据取近似值后进行估算 2. 用"大于"或"小于"符号标记结果（如"2665减"） 3. 通过符号传递推导最终结果范围 4. 与选项对比锁定答案 |
| 高频错因 | 估算取近似值时方向反了导致符号相反；忘记传递中间结果的符号 |
| confidence | high |

## 补充说明

符号规避计算风险的核心是用不等号标记代替精确计算。典型场景：将数据取近似值后估算，用"大于"或"小于"符号标记中间结果（如标记"比X小"），再通过符号传递推导最终结果范围，快速锁定选项。该方法的本质是用不等号传递代替精确计算，省去大量精算时间。

## 不适用条件
1. 当估算所得范围同时覆盖多个选项时，单靠符号传递不足以区分，应缩小误差范围
2. 当中间步骤过多时，符号传递的累积误差可能使结果失去判断意义

## 反向触发
1. 当估算误差可能跨越选项或改变结论时改用精算
2. 当符号标记的结果范围包含多个选项时，需缩小近似值的取值范围或恢复精算
