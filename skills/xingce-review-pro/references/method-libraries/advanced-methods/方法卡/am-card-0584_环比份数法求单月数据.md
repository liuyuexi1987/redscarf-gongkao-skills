# 方法卡：环比份数法求单月数据

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 环比份数法求单月数据 |
| 适用题型 | 资料分析——已知某月环比变化率和累计量，反推其中某个月的数据 |
| 触发场景 | 题目给出1~2月累计量、2月环比变化率，要求计算1月数据；或类似的用环比关系反推单月 |
| 步骤逻辑 | ① 标记时间：识别题目问的是单月，而材料只给累计和环比；② 设份：被比月（1月）设为100份，根据环比变化率计算另一月份数（下降26.3%→73.7份）；③ 加总：100+73.7=173.7份对应累计量52.5；④ 求目标：1月份=52.5÷173.7×100，有效数字锁定即可选答案 |
| 高频错因 | 搞混环比方向（谁比谁下降）；把"下降26.3"当百分点直接减，而不是算份数；忘记1月份本身也是100份要加进总份数 |
| confidence | high |
| 不适用条件 | - 题目只给出现期和基期的绝对量或同比变化率，不涉及环比关系
| 反向触发 | - 题目给出各月独立数据和累计量，要求验证或计算环比变化率（方向相反：从单月推环比，而非从环比推单月）
| needs_review | False |
| review_reason |  |
| is_alias_only | False |
| skip_reason |  |
- 题目给出多个月份的累计量和各月环比率，要求计算其中两个月份的差值，需要用到份数法但目标不是单月绝对量 |
- 需要求的是环比增长率本身而非单月绝对值
- 题目给出各月独立数据，无需通过累计量反推 |

## 补充说明

此方法本质是利用份数思想将环比关系转化为加法问题，避免列方程。方程法（设1月为X，X+0.737X=52.5）与份数法等价，但份数法更直观。示例提示此题是"好题"（星号题），因为逆向利用环比求单月在考试中较创新。
