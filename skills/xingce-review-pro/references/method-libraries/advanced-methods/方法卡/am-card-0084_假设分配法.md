# 方法卡：假设分配法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 假设分配法 |
| 适用题型 | 资料分析-计算基期/增长量（增长率 0%~20% 区间最适用） |
| 触发场景 | 给出现期值和增长率，需要快速估算基期值或增长量；选项差距较大时优先使用 |
| 步骤逻辑 | 1. 将现期值拆成"好算的整数"（如 3830 → 3000+500+356）；2. 用整数部分直接乘以增长率（整数乘小数比非整数快）；3. 分段累加增长量，得到近似基期值；4. 选项离得近时保留更多位数；选项差距大时粗估即可；5. 核心思想：不好算的数 → 换一个接近的好算的数来乘 |
| 高频错因 | 直接用非整数去乘，计算量大且易出错拆分后忘记累加各段增长量 |
| confidence | high |

## 不适用条件

- 增长率难以拆成便于心算的份数，或修正计算不再比公式简便时，假设分配法效率降低
- 数值为负数时，拆分方向容易混淆，容易算错符号
- 选项间距极小、分段近似误差可能跨越选项时，精度可能不够

## 反向触发

- 当增长率较大且接近整数倍（如25%、50%）时，直接用倍数关系更简洁
- 当数值位数少（两位数）且选项差距大时，直除法反而更快
- 当增长率本身为负时，应先判断方向再决定是否拆分，否则容易反向
