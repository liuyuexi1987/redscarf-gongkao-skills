# 方法卡：资料分析读题优先级

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 资料分析读题优先级 |
| 适用题型 | 资料分析——通用 |
| 触发场景 | 所有资料分析题 |
| 步骤逻辑 | ① 首先看时间（带"末"的数据要往前推、"下半年"不能算全年、"月均"要除以对应月数）；② 看主体（问的是谁）；③ 看指标（增长率/比重/倍数）；④ 计算前先看选项差距决定精度 |
| 高频错因 | ① 时间看错→后面全白费；② "1-2月合并"柱子→上半年是6个月不是5个月；③ 选项差距大时精算→浪费时间 |
| confidence | high |

## 补充说明
读题优先级适用于所有资料分析题，核心是"先定时间→再定主体→再定指标→最后看选项"。时间陷阱是第一杀手。

## 不适用条件
- 题面已经明确标出时间、主体和指标且不存在口径歧义时，可以简化检查，但仍需确认问法与选项
- 纯读数题可以减少计算步骤，但不能跳过时间、单位和主体核对

## 反向触发
- 如果题目是数量关系而非资料分析，不使用本读题流程
- 如果材料只有单一数据源且无时间、主体歧义，可快速完成核对，不必机械展开每一步
