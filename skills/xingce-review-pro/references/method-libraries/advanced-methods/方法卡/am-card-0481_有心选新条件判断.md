# 方法卡：有心选新的前提条件

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 有心选新的前提条件 |
| 适用题型 | 并列结构的中心理解题 |
| 触发场景 | 文段前后两部分都在讨论同一话题的不同面向（如都是在说"特点"），出现并列结构，且后半部分引入了新信息。此时"有心选新"（选含新信息的选项）才成立。 |
| 步骤逻辑 | 1. 先判断前后是否讨论**同一话题**；2. 如果前文说"怎么来的"，后文说"有什么新变化"——前后话题不同 → **不能有心选新**，应选概括全面的并列选项（A且B）；3. 如果前文说"旧特点"，后文说"新特点"——同一话题 → **可以有心选新**；4. 核心判断依据：前后话题是否一致，而非仅仅看有没有"新"字 |
| 高频错因 | 看到后半部分有新内容就盲目选新，忽略前后话题是否一致不区分"话题转换"和"话题深化" |
| confidence | high |

## 不适用条件

1. 前后文段讨论的是不同话题（如前文说"怎么来的"，后文说"有什么新变化"），此时不能有心选新，应选概括全面的并列选项。
2. 文段为转折结构（前后存在对立或修正关系）时，应按转折文段找重点，不适用本方法。
3. 后半部分的"新信息"是对前文的举例或具体展开而非新的面向时，不属于真正的新信息。

## 反向触发

1. 当选项中出现概括性并列表述（"A且B"）且覆盖前后两个面向时，应优先验证该选项而非盲目选新。
2. 若前后话题不一致，应回到并列文段"概括全面"的常规选法。
3. 当正确选项明显偏向后半部分但前半部分独立性强时，需检查是否存在话题转换，避免误判为"有心选新"。
