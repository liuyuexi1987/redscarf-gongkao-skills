# 方法卡：赋值法解经济利润

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 赋值法解经济利润 |
| 适用题型 | 经济利润·无具体数值的题目 |
| 触发场景 | 题目只给比例关系（如"售价是进价的1.4倍""下降原价的10%"），无具体价格 |
| 步骤逻辑 | 1. 设原价为方便计算的值（如设为10，便于算10%）；2. 设销量为方便计算的值（如设为1）；3. 逐天/逐条件列出售价、销量；4. 计算总收入、总成本、利润率；5. 注意：赋值只针对一个量赋一次，不要对同一量赋两次不同值 |
| 高频错因 | 对同一量重复赋值导致矛盾 |
| confidence | high |

## 补充说明

赋值法在经济利润中非常好用，尤其当题目全是百分比/比例时。

## 不适用条件

- 题目已给出具体价格数值时无需赋值，直接计算即可。
- 涉及多个变量之间存在非线性约束（如分段函数、阶梯计价）时，单纯赋值可能掩盖关系，应列方程。
- 题目要求求出的是比例关系本身而非具体数值时，赋值无意义。

## 反向触发

- 当赋值后计算出现非整数或矛盾结果，应反向核验所赋值是否与题目隐含条件冲突，改用列方程验证。
- 当题目含"求最值"语义（如求利润最大）时，应换用核定积最等方法。
- 当题目存在"前后两次赋值同一量"风险时，应补充核验或改用方程法避免赋值冲突。
