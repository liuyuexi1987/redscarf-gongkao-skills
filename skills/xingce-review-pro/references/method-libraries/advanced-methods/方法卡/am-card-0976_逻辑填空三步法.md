# 方法卡：逻辑填空三步法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 逻辑填空三步法 |
| 适用题型 | 逻辑填空——通用框架 |
| 触发场景 | 所有逻辑填空题，尤其是多空题和文段较长的题 |
| 步骤逻辑 | ① 略读：快速过一遍文段，把握核心话题和主旨（不需要像中心理解那样细读）；② 精读：围绕空格附近寻找逻辑对应点（主要信息=逻辑含义，重要细节=语法搭配）；③ 辨析：对选项词语进行准确辨析，结合话题和线索选出答案 |
| 高频错因 | ① 跳过略读直接看空格→抓不准话题方向；② 只看空格那句话忽略上下文→漏掉逻辑对应；③ 找到线索后不预判直接看选项→被干扰项带走 |
| confidence | high |

## 补充说明
核心做题框架。略读不需要像中心理解那么仔细，大概扫一下知道讲什么话题即可。精读时重点关注空格前后的逻辑对应点。如果实在找不到逻辑对应，再依靠词语辨析。联考题逻辑对应往往不如国考清晰，辨析比重更大。

## 不适用条件

- 主旨、意图、标题、细节判断等没有词语空格的题，不使用逻辑填空三步法。
- 题面只是讨论某个词的知识，而非结合具体语境选词时，不将本卡包装成通用言语方法。

## 反向触发

- 当文段极短、空格前后几乎找不到逻辑对应点时，应改用以词语辨析为主的策略，而非强求逻辑对应。
- 当选项是近义成语且语义差异极小、文段线索不足以区分时，应补一步语素拆解或感情色彩核验，再决定答案。
- 当空格位于文段首句且后文均为论据时，应反向使用"由后向前"线索回溯，而非按顺序略读—精读—辨析走完三步。
