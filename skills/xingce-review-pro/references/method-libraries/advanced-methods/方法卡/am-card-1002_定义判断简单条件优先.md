# 方法卡：定义判断简单条件优先

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 定义判断简单条件优先 |
| 适用题型 | 判断推理——定义判断 |
| 触发场景 | 长定义、多条件定义 |
| 步骤逻辑 | ① 不从头到尾逐句读长定义；② 先找最简单最容易判断的条件；③ 用简单条件快速排除选项；④ 剩余选项再用其他条件验证 |
| 高频错因 | ① 从头到尾逐句读→浪费时间且容易迷失；② 被复杂描述吓到→不敢判断 |
| confidence | high |

## 补充说明
长定义中常存在一个简单易判的条件（如某要素的肯定/否定形式、特定数量、特定主体），优先用该条件快速排除选项，再用复杂条件验证剩余选项。

## 不适用条件
- 短定义（条件少，逐句读即可完成判断）
- 所有条件复杂度相当的平行定义（无明显"简单条件"可挑）

## 反向触发
- 简单条件排除后仍剩多个选项→改用复杂条件逐项验证
- 选项差异在主体而非条件匹配→改用主体匹配法
