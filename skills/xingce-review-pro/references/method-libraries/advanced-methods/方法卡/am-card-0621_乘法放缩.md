# 方法卡：乘法放缩

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 乘法放缩 |
| 适用题型 | 资料分析——乘数接近整百（如×204、×103） |
| 触发场景 | 乘数可看成100+几或200+几时 |
| 步骤逻辑 | ① 把乘数拆成整百+零头（如204=200+4）；② 零头占整百的百分比（4是200的2%）；③ 先乘整百，再扩大该百分比 |
| 高频错因 | 百分比算错；扩大/缩小方向搞反 |
| confidence | medium |
| 不适用条件 | 乘数与整百差距较大、放缩误差可能影响选项判断；选项接近或题目要求精确结果时，不使用近似放缩 |
| 反向触发 | 乘数可直接拆成整百与小零头时，分别相乘更清晰；乘数能换成熟悉分数时，优先比较小分互换；两个乘数都远离整百或估算误差可能跨越选项时，改用拆分法、直乘或精算 |

## 补充说明

例：462×204，先算462×200=92400，4相对于200是2%，再扩大92400的2%（即924×2=1848），结果约94248。此方法比传统拆分成200+4再分别乘更快，因为第二步只需算百分比而非乘法。
