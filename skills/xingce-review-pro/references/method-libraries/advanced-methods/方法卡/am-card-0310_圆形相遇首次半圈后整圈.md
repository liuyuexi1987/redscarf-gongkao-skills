# 方法卡：圆形相遇首次半圈后整圈

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 圆形相遇首次半圈后整圈 |
| 适用题型 | 数量关系——环形相遇、多次相遇 |
| 触发场景 | 两人在圆周相对位置反向运动，求首次及后续相遇次数或时间 |
| 步骤逻辑 | 1. 第一次相遇：两人走半圈（相距半圈），时间 = 半圈距离 ÷ 速度和；2. 之后每次相遇：需走完整一圈，时间 = 一圈距离 ÷ 速度和；3. 总时间减去第一次相遇时间，剩余时间 ÷ 每圈时间 = 后续相遇次数；4. 总相遇次数 = 1（首次）+ 后续次数 |
| 高频错因 | 直接用总时间÷每圈时间，忘记首次只走半圈路程法和时间法结果相同，但首次半圈的处理容易遗漏 |
| confidence | medium |
| 不适用条件 | 直线往返相遇问题；环形追及问题（同向运动）；题目只问第一次相遇，无需区分首次与后续 |
| 反向触发 | 若为环形追及问题（同向），需换用追及公式（一圈÷速度差）；若用路程法验证结果与时间法不一致，回溯检查首次半圈是否被重复计算 |

## 补充说明

也可用路程法验证：总路程 = 速度和 × 总时间，再用 (总路程 - 半圈) ÷ 一圈 + 1 得到相同结果。两种方法互相印证。
