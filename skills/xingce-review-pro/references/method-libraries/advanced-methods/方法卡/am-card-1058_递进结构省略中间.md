# 方法卡：递进结构省略中间

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 递进结构省略中间 |
| 适用题型 | 言语理解——中心理解（递进链） |
| 触发场景 | 文段有A→B→C的递进链式结构 |
| 步骤逻辑 | ① 识别递进链：A→B→C；② 主旨经常忽略中间的B；③ 可作为排除线索A→C的选项（如"三农→乡村振兴→发展保险"→"三农要发展保险"） |
| 高频错因 | ① 选了包含中间环节的选项→太啰嗦；② 不识别递进链→抓不住首尾关系 |
| confidence | high |

## 不适用条件
- 文段为并列结构、转折结构或总分结构，而非递进链式结构时
- 递进链中B环节是核心论点、不可省略时
- 选项中没有跳过中间环节的A→C型选项时

## 反向触发
- 看到"不仅A，而且B，更重要的是C"等典型递进句式时，优先关注A→C的首尾关系
- 选项中出现同时包含A和C但省略B的表述时，该选项更可能是正确答案
