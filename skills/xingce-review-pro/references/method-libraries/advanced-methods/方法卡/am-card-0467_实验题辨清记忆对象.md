# 方法卡：实验题辨清记忆对象

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 实验题辨清记忆对象 |
| 适用题型 | 判断推理 > 解释说明（涉及实验过程的题目） |
| 触发场景 | 实验题题干长、干扰多；需区分实验的真正测量对象与辅助手段 |
| 步骤逻辑 | 1. 读题时锁定：实验最终检测的是什么（如"对词汇的记忆情况"而非"对图片的印象"）；2. 辅助手段（如看负面图片）只是条件，不是测量目标；3. 解释选项必须针对真正的测量对象：看到负面图片时大脑仍在记单词 → 能解释；负面图片更容易记忆 → 不能解释（解释的是图片不是单词）；4. 长题干读到后面容易混淆，建议在草稿上标注"测的是XX" |
| 高频错因 | 题干太长读到后面忘记测的是单词还是图片；被干扰项C"负面图片更易记忆深刻"迷惑 |

## 不适用条件

1. 题干明确只有一个测量对象且无干扰手段，不存在混淆问题
2. 实验设置简单（单变量、单指标），辨清对象不构成难点
3. 所有选项均针对同一对象，本方法无区分作用

## 反向触发

1. 当无法从题干中识别出真正的测量对象时，应先回到题目仔细梳理实验流程
2. 当选项解释的对象正确但结论方向错误时，应换用逻辑判断而非对象辨析
3. 当实验涉及多个测量指标（如同时测记忆准确率和反应时间）时，需要额外核验各选项对应哪个指标
