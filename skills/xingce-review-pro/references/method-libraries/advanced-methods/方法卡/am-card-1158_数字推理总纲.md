# 方法卡：数字推理总纲

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 数字推理总纲 |
| 适用题型 | 数量关系——数字推理（方法选路总入口） |
| 触发场景 | 拿到一串数字求下一项或缺失项，需要先判断从哪种特征入手 |
| 步骤逻辑 | ① 先观察数列整体特征：项数、正负、变化方向、变化幅度、是否含分数/小数/根号/多位数；② 按特征信号分流：平缓单调→优先作差；上下波动→优先作和或递推；前后项有倍数关系→优先作商；出现幂数或幂数邻居→优先幂次修正；含小数点/根号/分式/多位数→优先分组拆解；项数偏多→优先奇偶分组或分段；③ 选定主路径后读取对应专项卡执行；④ 主路径失败时按"作差→作和→作商→递推→分组→幂次"顺序回退尝试，每条路径必须覆盖全部已知项才能定型；⑤ 最终用推得的规律回代全部已知项，并推出目标项与选项比对 |
| 高频错因 | ① 只盯一种特征就锁定方法，忽略其他同样匹配的路径；② 主路径验证只覆盖部分项就下结论；③ 没有回退路径，主路径失败即放弃；④ 把观察提示（如"上下波动""有0.5"）当成必然规则套用 |
| confidence | high |

## 不适用条件

1. 数列项数过少（少于 4 项）时，特征信号不稳定，多条路径都可能成立，此时应以选项反推为主而非特征选路。
2. 数列含明显非数值元素（如时间、单位、符号）时，应先做格式归一，再套用本总纲。
3. 题目已明确指定方法（如"用递推法求解"）时，直接执行指定方法，不走总纲选路。

## 反向触发

1. 当按特征信号选定的主路径无法覆盖全部已知项时，立即切回退路径，不要在主路径上反复试数。
2. 当两条路径都能覆盖全部已知项但推出不同下一项时，必须用选项差距和题目语境二次裁决，不能凭"更常见"二选一。
3. 当数列特征信号矛盾（如既有倍数关系又上下波动）时，优先验证能同时解释两类特征的复合规律（如"作商后作差""求和后递推"），而非单选其一。

## 最终验证动作

1. 用选定规律逐项回代，确认每一项都能由前项（或前若干项）推出，无遗漏项。
2. 推出目标项后，与四个选项逐一比对：若目标项恰为某选项→锁定；若目标项与最近选项有固定差值→检查是否存在末项修正或单位换算；若目标项不在选项中→重新选路。
3. 对多解情况（两条规律都覆盖已知项），必须找到能排除其一的判据（如规律复杂度、与题目语境一致性），不得直接选其一。
