# 方法卡：语句填空四型判断

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 语句填空四型判断 |
| 适用题型 | 言语理解——语句填空 |
| 触发场景 | 所有语句填空题 |
| 步骤逻辑 | ① 首句/中间句：可能对应主旨（文言文题常见），也可能只是引出后文；② 尾句：可能是总结，也可能推对策（按一般人的想法推，不能推太远）；③ 半句话：注意前后衔接，必要时用语法判断；④ 未必需要主题词：可能只起衔接作用，或做了同义替换 |
| 高频错因 | ① 把首句一律当主旨，忽略其可能只是在引出话题；② 把尾句一律当总结，忽略其可能引出对策；③ 强求每个空都有主题词，忽略衔接作用 |
| confidence | high |

## 不适用条件
- 文段结构不完整或上下文缺失，无法判断空格位置类型时
- 题目为非语句填空的其他言语题型（如语句排序、接语推断）时
- 空格处为半句话且前后语境矛盾、无法用语法判断时

## 反向触发
- 空格在首句时，先看后文是否有总结性表述：有则首句可能为引出话题，无则首句可能为主旨
- 空格在尾句时，先看前文是分析论证还是提出问题：论证后可能总结，问题后可能推对策
- 空格在中间句时，重点看前后句的逻辑衔接关系
