# 方法卡：论点偷换概念识别法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 论点偷换概念识别法 |
| 适用题型 | 论点型加强削弱题中的干扰项排除 |
| 触发场景 | 论点讨论的是"有没有效果/保护/作用"，选项讨论的是"效果大不大/保护多少" |
| 步骤逻辑 | 1. 先抓准论点的核心：是"有无"还是"多少"；2. 若论点说"有保护作用"，选项说"不能完全保护"≠削弱（只是部分保护，仍有保护）；3. 若论点说"有保护作用"，选项说"穿了反而辐射更多"=真正的削弱（结果反向）；4. 排除讨论对象不一致的选项 |
| 高频错因 | 被"不能完全保护"迷惑选了削弱项，但论点只是说"有保护"；忽略"可能"二字不影响方向正确性 |
| confidence | high |

## 不适用条件

- 论点和选项讨论的概念完全一致（无偷换）
- 论点本身就是讨论"程度/多少"而非"有无"

## 反向触发

- 选项与论点的核心概念完全匹配
- 论点和选项都在同一维度（如都讨论"有无"或都讨论"多少"）

## 补充说明

方法强调"加强削弱不是铁板钉钉，更重要的是方向对"。"可能"二字虽然削弱力度不如"一定"，但方向正确就有效。
