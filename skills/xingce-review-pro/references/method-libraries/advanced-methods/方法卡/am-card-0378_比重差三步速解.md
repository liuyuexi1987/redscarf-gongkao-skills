# 方法卡：比重差三步速解

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 比重差三步速解 |
| 适用题型 | 资料分析——题干含"百分点"且问比重上升/下降多少 |
| 触发场景 | 看到"比重……百分点"→一定是比重差题型（注意：百分点≠百分号） |
| 步骤逻辑 | ①先算R1-R2判断比重升降方向；②用现期比重×(R1-R2)估计数量级；③判断省略1/(1+R1)造成的误差是否可能跨选项，不能跨越时可估算，可能跨越时使用完整公式 |
| 高频错因 | 把"百分点"混淆为"百分号"从而误用比值增长率公式；第一步判断方向后未利用剩余选项差距极大的特征直接选 |
| confidence | high |

## 补充说明

先用R1-R2判断方向，再用现期比重与增速差估计数量级。若省略分母修正后的误差不影响选项判断，可停止计算；否则使用完整公式。基期比重题也可先估计比重差，再从现期比重反推并核验。

## 不适用条件

1. 省略1/(1+R1)造成的误差可能跨越选项时，必须使用完整公式
2. 题目问的是基期比重而非比重变化量，需配合基期比重公式
3. R1使分母修正明显、无法由选项差距吸收时，不能忽略1/(1+R1)

## 反向触发

1. 当选项全部同方向（都上升或都下降）时，第一步判断方向无法排除，应换用完整公式计算
2. 当"百分点"与"百分号"表述不清时，需确认题型再决定方法，避免用错公式
3. 当估算误差可能跨越选项时，应改用精算
