# 方法卡：图推九宫格规律优先级

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 图推九宫格规律优先级 |
| 适用题型 | 判断推理——图形推理（九宫格） |
| 触发场景 | 九宫格类型的图形推理题 |
| 步骤逻辑 | ① 按行看（每行规律一致）→最高优先级；② 按列看（每列规律一致）→次优先级；③ 米字型/对角线→再次；④ S型/回字型→最后尝试 |
| 高频错因 | ① 不按优先级乱试→浪费时间；② 只按行看→漏掉列规律 |
| confidence | high |

## 补充说明
九宫格可先按行、列检查，无法解释再看对角线、米字、S 型或内外圈等路径。这是观察顺序，不是固定命题优先级；每条候选规律都要能连续解释已知图并区分选项。

## 不适用条件

1. 非九宫格形式（如类比型、分组型）图形推理时。
2. 九宫格考查整体属性（如对称性）而非行列规律时。
3. 图形间无明显样式/数量对应关系时。

## 反向触发

1. 当行、列、米字、S型/回字优先级均无规律时，应换用整体属性法。
2. 当加减求同运算无结果时，应补充考察旋转后运算或分主体运算。
3. 当优先级路径全部失败时，应核验是否为分类分组题。
