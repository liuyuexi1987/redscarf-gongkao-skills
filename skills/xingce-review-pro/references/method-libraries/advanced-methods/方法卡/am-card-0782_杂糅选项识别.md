# 方法卡：杂糅选项识别

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 杂糅选项识别 |
| 适用题型 | 言语理解——细节判断题中的选项辨析 |
| 触发场景 | 选项沿用原文词汇但重新拼接，需要核对组合后的主体、关系和整体语义是否仍与原文一致 |
| 步骤逻辑 | 1. 识别杂糅选项：选项里的词都是从原文提炼的；2. 但这句话提炼俩字，那句话提炼几个字，拼凑成一句话；3. 拼凑后的意思跟原文一点都不一样；4. 这种选项最坑人，因为用的都是原文的词，容易放松警惕 |
| 高频错因 | 看到选项用词都来自原文，就认为是对的没有仔细分析拼凑后的整体意思是否与原文一致 |
| confidence | medium |

## 不适用条件

- 主旨概括题中选项需概括全文，不能仅凭"是否杂糅"判断对错
- 当选项是对原文的合理归纳（非拼凑）时，不应误判为杂糅
- 排序题、填空题等非细节判断题型不适用本法

## 反向触发

- 若选项虽用词来自原文，但语义与原文一致，则不是杂糅，应正常判断
- 若无法确认原文出处，先回原文定位再判断是否杂糅
