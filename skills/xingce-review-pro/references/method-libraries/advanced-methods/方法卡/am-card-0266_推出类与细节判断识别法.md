# 方法卡：推出类与细节判断识别法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 推出类与细节判断识别法 |
| 适用题型 | 定义判断/推出类（逻辑判断中的"下列哪项能/不能推出"） |
| 触发场景 | 问法为"由此可以推出""以下哪项正确/一定为真" |
| 步骤逻辑 | 1. 先看题干和选项是否出现大量逻辑关联词（如果...则、只有...才）；2. 若有逻辑关联词 → **推出类**：写条件、逆否等价、推导；3. 若无逻辑关联词 → **细节判断**：当言语题做，逐项比对题干；4. 细节判断中警惕三种设错：绝对化（"最重要"偷换"重要"）、无中生有、杂糅 |
| 高频错因 | 推出类题目用言语方式做（逐句比对）；细节判断题强行翻译逻辑符号 |
| confidence | high |

## 不适用条件

1. 题干为纯言语理解题（如主旨概括、意图判断），无逻辑判断要素
2. 选项要求的是归纳概括或观点提炼，而非逻辑推导或细节比对
3. 题目涉及排列组合、数据分析或图形推理

## 反向触发

1. 题干和选项均无逻辑关联词，问法明确为"概括主旨"或"作者意在说明"
2. 所有选项都是对同一细节的不同表述，考查同义替换而非逻辑推理
3. 题干为类比推理或图形规律题，不属于逻辑判断范畴
