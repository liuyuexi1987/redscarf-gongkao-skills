# 方法卡：以偏概全归谬质疑

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 以偏概全归谬质疑 |
| 适用题型 | 加强削弱——题干由个别案例推出普遍结论，或结论含"一个国家""所有"等绝对化表述 |
| 触发场景 | 题干举了一个个别案例（如某对象在某事件后出现变化）就推出一般性结论，问哪个最能质疑 |
| 步骤逻辑 | ① 识别逻辑漏洞：以偏概全（个例→普遍）；② 找反例选项：其他国家加入WTO后经济增速无明显变化；③ 判断BD是否为同质选项（同为他因类削弱），若同质则一起排除；④ 慎重对待"同时发生"——时间同时不是削弱而是支持（效果立竿见影） |
| 高频错因 | 选了"经济增长与某事件几乎同时发生"（实际是支持选项）；选了同质他因选项中的一个却没意识到另一个也能选 |
| confidence | high |

## 补充说明

以偏概全类削弱识别关键：题干用个别案例推出普遍结论时，找选项是否举出反例（其他对象不成立）直接命中漏洞。同质选项判断法：当两个选项同为他因类削弱，要选都选要排除都排除——若选其一却选不了另一个，说明该选项也不该选。注意"同时发生"不是削弱——恰好同时说明因果效果立竿见影，是支持选项。

## 不适用条件

- 题干本身已是全面统计或大样本调查，不存在"以偏概全"漏洞时，不适用本方法。
- 选项中无反例类削弱，仅有他因/切断联系/因果倒置等其他削弱路径时，按对应方法处理。

## 反向触发

- 当题干结论本身是审慎的、非绝对化的（如"可能""一定程度上"），反例质疑力度不足，应改用他因削弱或因果链分析。
- 当选项中出现"同质他因"时，应补充核验：同质选项是否真为等价方向，避免误把方向不同的选项归为同质。
