# 方法卡：一分为二画图法（所有/有些推理）

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 一分为二画图法（所有/有些推理） |
| 适用题型 | 判断推理——翻译推理类（含"所有""有些"的推理题） |
| 触发场景 | 题干给出多条"所有A都是B""有些A是B"类命题，问哪项能/不能推出 |
| 步骤逻辑 | ① 用"所有A都是B"的B（如"不精通印尼语"）画线一分为二，分为B区域和非B区域；② 将每句话涉及的集合逐个标注到图中（圈的位置按包含/交叉/互斥关系确定）；③ "所有A都是B"→A整个圈在B区域内；"有些A是B"→虚线圈与B有交叉；④ 画完图后，看选项能否在图中找到对应实例（小人），能找到则可推出，找不到则推不出；⑤ 逆否命题同真同假，可辅助定位 |
| 高频错因 | 逐句逐选项组合尝试，浪费时间且易遗漏；画图时忘记用逆否命题补充信息；不确定"推不出"还是"我没推出"而纠结 |
| confidence | high |

## 补充说明

典型应用涉及多类集合关系：四条命题定义四种对象之间的包含/交叉/互斥，第五条为待验证结论。画图后每条命题的逻辑结构直接映射到区域中，再逐项检查：能在图中找到满足条件的实例则可推出，找不到则推不出（如某实例要求同时位于互斥区域，无法构造）。画图法比逐条组合枚举更高效。

## 不适用条件

- 命题只涉及两个对象且关系明确（如"所有A都是B"，无交叉），直接用逆否命题即可判断，无需画图
- 题干只有"所有"没有"有些"，且只需验证一个结论，逐条推理足够
- 图形过于复杂（涉及五类以上对象），画图本身耗时过长

## 反向触发

- 若画图后仍无法确定某选项是否能推出，先检查是否漏用了某条命题的逆否命题，补全后再判断
- 若某选项结论同时出现在两个互斥区域中，直接判定推不出，不必再尝试构造实例
