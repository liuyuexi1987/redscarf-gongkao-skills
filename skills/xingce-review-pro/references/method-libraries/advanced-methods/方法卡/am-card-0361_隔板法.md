# 方法卡：隔板法
## 基本信息
| 字段 | 值 |
|------|-----|
| 方法名 | 隔板法（插板法） |
| 适用题型 | 数量关系-排列组合/相同元素分配/每人至少N个 |
| 触发场景 | 将相同物品分给若干人，每人至少1个（或至少N个） |
| 步骤逻辑 | 1.每人至少1个：n个物品有n-1个空，分给m人需m-1块板→C(n-1,m-1) 2.每人至少k个(k>1)：先给每人预分k-1个，剩余元素转化为"每人至少1个"再隔板 3.关键：必须是相同元素，且分配对象有区别 |
| 高频错因 | 每人至少2个时忘记先预分1个导致公式套错；元素不同时不能用隔板法；分组对象无区别时不能直接用（需除以排列） |
| confidence | high |
## 补充说明
"切火腿肠"类比：n个相同物品分给m人每人至少1个，相当于n-1个空中选m-1个放板，即C(n-1,m-1)。当不同组别要求不同的最低数量时（如某类至少k个、另一类至少1个），先给要求较高的组预分多余的量，使其转化为统一的"每人至少1个"场景，再统一隔板。本质是把不等约束转化为等约束。

## 不适用条件

- 元素不相同（可区分），不能直接使用隔板法，需改用排列方法
- 分配对象无区别（如只分组不分人），直接用隔板法会重复计数，需要除以排列数
- 允许有人分到0个，需先做变量替换（每组加1）再套用隔板法，否则公式不适用

## 反向触发

- 当答案中出现需要除以排列数的情况时，应检查分配对象是否真的有区别，若无区别则直接隔板会多算
- 当题目中元素部分相同部分不同时，纯隔板法不适用，应拆分处理或改用插空法+分类讨论
