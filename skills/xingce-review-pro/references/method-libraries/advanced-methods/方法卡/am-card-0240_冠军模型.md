# 方法卡：冠军模型——多人猜对看谁出现N次

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 冠军模型（数出现次数法） |
| 适用题型 | 判断推理——真假分析（多人猜测同一结果） |
| 触发场景 | 多人（如甲乙丙丁）各自猜测"是谁做了某事"，已知其中有N人说对，要推出实际是谁 |
| 步骤逻辑 | ① 将每人的猜测简化为"我认为是X"或"我认为是X或Y"；② 统计每个被猜测者被提及的次数；③ 若N人说对，则被提及恰好N次的那个名字就是答案；④ 被提及次数不等于N的名字直接排除 |
| 高频错因 | 被"或"的表述搞晕，忘记把"乙说的对"翻译成"我认为是丙"再统计；不看选项就猜多人合作 |
| confidence | high |

## 不适用条件

1. 每人猜测的不是"是谁"而是"做某事的顺序/方式"，无法简单统计被提及次数
2. 说对的人数N不明确或有多人合作的可能，出现次数法不适用
3. 猜测涉及"且""或""非"的复合逻辑，不能简化为"我认为是X"

## 反向触发

1. 每人猜测的是排列顺序而非身份，需用排列代入法
2. 题目说"至少N人说对"而非"恰好N人说对"，出现次数法前提不满足
3. 猜测中含"不是X"（否定式），需反向推理而非统计出现次数
