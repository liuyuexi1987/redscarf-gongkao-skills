# 方法卡：语句填空用指代词承上启下

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 语句填空用指代词承上启下 |
| 适用题型 | 语句填空题（横线在中间） |
| 触发场景 | 横线前后有转折（"然而"），且选项中有含指代词（"这个过程""这种现象"）的表述，需要同时承接上文并开启下文。 |
| 步骤逻辑 | 1. 读横线前文，提炼核心观点；2. 看横线后有无转折词 → 如有，预判转折方向（前文说好 → 后文可能说不好/有矛盾）；3. 读横线后文验证，看后文实际在说什么；4. 选项中的指代词（"这个过程"）= 承接上文话题；5. 选项中的评价词（"令人困惑和不安"）= 启下（对应后文的例子/论证）；6. "有时"等限定词可体现"偶尔出现"的精准度，避免过于绝对 |
| 高频错因 | 选项B（如"不同知识的有效期不同"）看似合理但偷换了核心概念（"变化/反转"→"存活时间"）忽略"反推法"：如果选B，后文应怎么写？实际后文不匹配则排除 |
| confidence | high |

## 不适用条件

1. 横线在文段首句或尾句时，不需要同时承上启下，本方法不适用。
2. 横线前后无转折、因果等逻辑提示词，且选项均不含指代词时，应改用话题一致性和语义连贯性判断。
3. 需要填入的是整个文段的总结句（而非过渡句）时，不能只看横线前后一句，应看全文主旨。

## 反向触发

1. 当选项中的指代词在上文找不到明确对应时，该选项存在指代不清风险，应排除并改用话题匹配法。
2. 若横线后文内容与前文方向一致（无转折），应优先选顺承表述，避免选含转折评价词的选项。
3. 当多个选项都能承上时，重点比对"启下"功能，看哪个选项的后半句能准确衔接下文。
