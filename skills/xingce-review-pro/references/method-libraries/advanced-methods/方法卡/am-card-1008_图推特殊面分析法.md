# 方法卡：图推特殊面分析法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 图推特殊面分析法 |
| 适用题型 | 判断推理——图形推理（面） |
| 触发场景 | 一组图都有很多面，数面数量无规律 |
| 步骤逻辑 | ① 面多时→不考面数量，考特殊面（最大/最小面）；② 确定特殊面后检查：形状（边数）、属性（曲线/直线面）、对称性、位置（与外框公共边数）；③ 特殊面边数可能与外框边数做计算 |
| 高频错因 | ① 只数面数量→无规律就放弃；② 忽略特殊面与外框的交互关系 |
| confidence | high |

## 补充说明
近年国考图推趋势：不考简单数面，考特殊面。最大最小面是最典型的特殊面。面与外框的公共边数也是常见考点。

## 不适用条件
- 面数量有明确规律（无需转向特殊面分析）
- 图形无明显面分割（无法识别特殊面）

## 反向触发
- 特殊面分析无规律→改用面数量或其他属性（对称、曲直）
- 特殊面属性与外框无交互→改用整体对称性/旋转规律
