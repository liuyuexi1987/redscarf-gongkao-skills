# 方法卡：乘法放缩与除法放缩区分

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 乘法放缩与除法放缩区分 |
| 适用题型 | 资料分析——放缩法应用·区分乘法和除法放缩的误差特性 |
| 触发场景 | 使用放缩法时，需要判断是乘法场景（A×B）还是除法场景（A÷B），以控制误差方向和幅度 |
| 步骤逻辑 | ① 除法放缩：A÷B等价于A×(变化比例)，理论上无误差，实际误差来自比例控制不精确，可人为调控；② 乘法放缩：A×B中一数调大R%、另一数调小R%，结果≈原值×(1-R²)，天然存在误差；③ 乘法放缩误差≈R²（动5%→误差0.25%，动10%→误差1%），所以乘法放缩一定要少动；④ 两种放缩都是动得越小误差越小 |
| 高频错因 | ① 乘法放缩动幅太大（如441→400，动了近10%，误差约1%）；② 混淆两种放缩的误差来源——除法是比例控制不精确，乘法是R²天然存在；③ 在精度要求高的题中用乘法放缩导致选错 |
| confidence | high |
| 不适用条件 | 题目需要精确计算而非估算放缩；选项间距极小，乘法放缩的R平方误差可能跨越选项边界；放缩对象为加减法运算而非乘除法 |
| 反向触发 | 题目选项间距很大，直接截位估算即可区分；分母可以通过化除为乘转化为乘法运算再放缩；题目不要求估算，而是考查公式选择或概念判断 |

## 补充说明

除法放缩的误差是可调控的（像弹簧），乘法放缩天然存在R²误差（无法消除除非精确补偿）。乘法放缩的正确做法：动得尽量少（如442→440只动0.5%，误差仅0.0025%），同时另一数按倍数关系微调。不建议把分母凑成100——因为分母动幅太大，不如直接用化除为乘或保留更多位数。
