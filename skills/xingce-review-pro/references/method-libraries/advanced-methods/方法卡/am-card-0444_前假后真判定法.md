# 方法卡：前假后真判定法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 前假后真判定法 |
| 适用题型 | 真假话推理——给多个命题（含推出关系），告知真假数量，判定各命题真假 |
| 触发场景 | 题干给出含A→B形式的多个命题，且告知"一真两假"等真假分配，常规矛盾法找不到矛盾时 |
| 步骤逻辑 | ① 识别哪些命题含推出关系（A→B）；② A→B仅在"A且非B"时为假，前件非A或后件B为真时整个命题为真；③ 一真两假场景下，从最简单的条件做假设，假设某条件为真后若导致另一条件也为真（违反只有一真），则假设错误，该条件必假；④ 由确定的假推出新的事实（如非A），再用前件假使某命题确定为真 |
| 高频错因 | 混淆使用前提：只有在不知道A→B真假时才用前假后真，若已知A→B为真则不能用此法；假设时选的不是最简条件导致推导链过长 |
| confidence | high |

## 补充说明

推导链路示例：假设③为真（甲被录取）→②后件为真→后件真整个命题为真→②也为真→同真违反"只有一真"→③必假→甲未被录取→①前件为假→前件假整个命题为真→①为唯一真话→②必假→②的矛盾为"非乙且非甲"→甲乙都没录取。核心记忆："前件假后件真，整个命题一定为真"，原理来自或命题与推出的等价转换。

## 不适用条件

- 题干命题中不含任何推出关系（A→B），仅含直言命题或联言命题时，应改用矛盾法或反对关系法
- 已知某个推出关系命题为真，再用"前假后真"去判定其真假属于多余操作，直接利用已知信息推理即可
- 真假数量约束为"全部为真"或"全部为假"时，前假后真法的假设-排除流程不适用

## 反向触发

- 若假设某条件为真后，推导链无法产生矛盾也无法确定任何命题的真假，说明该假设方向不对，应换选更简单的条件重新假设
- 若题目存在明显的矛盾对（两个命题互为矛盾），优先用矛盾法确定真假数量分配，再用前假后真法处理剩余命题，不要跳过矛盾直接假设
