# 方法卡：增速不变则增量等比例变化

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 增速不变则增量等比例变化 |
| 适用题型 | 资料分析——增速大小比较、假设增速不变求未来值 |
| 触发场景 | 需要判断某年增速是否高于往年，或需要在增速不变假设下求未来量 |
| 步骤逻辑 | ① 记住性质：若增速不变，增量也按该增速等比例增长；② 比较时，若今年增量的增长幅度明显低于去年增速，则增速下降；③ 若增量增长幅度高于去年增速比例，则增速上升 |
| 高频错因 | ① 只看增量绝对值变化，忽略基数不同导致的比例差异；② 跨多年比较时仍用此法，导致误差过大 |
| confidence | high |
| 不适用条件 | 需要跨多年比较增速变化时；基数（前期值）未知导致无法判断增量比例；题目要求精确计算而非定性判断增速升降 |
| 反向触发 | 题目直接给出了各年增速数值，可直接比较大小；题目考查的是基期值或增长量的具体数值计算，而非增速升降方向的判断 |

## 补充说明

此性质可快速排除增速比较中的"不争气"选项：如果增量不仅没等比例增长反而下降，增速必然下降。适合相邻两年的快速判断，跨多年需回归正常比较。
