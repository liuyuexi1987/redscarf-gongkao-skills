# 方法卡：浓度=溶质÷溶液

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 浓度=溶质÷溶液 |
| 适用题型 | 所有溶液问题的基础公式 |
| 触发场景 | 题目涉及浓度、溶质、溶剂、溶液的质量关系 |
| 步骤逻辑 | 1. 浓度 = 溶质 ÷ 溶液（注意：是除以溶液，不是除以溶剂/水）；2. 溶液 = 溶质 + 溶剂（质量守恒）；3. 溶质 = 浓度 × 溶液 |
| 高频错因 | 浓度计算时误除以溶剂（水）的质量，而非溶液的总质量。例如100克水加20克盐，浓度是20÷120≈16.67%，而非20÷100=20% |
| confidence | high |

## 补充说明

加溶质时溶液也会增加，浓度不与溶质成简单正比关系

## 不适用条件

- 题目不涉及溶液/浓度概念（如纯行程、工程问题）时不适用
- 多步混合且需追踪各阶段浓度变化时，单用基础公式效率低，建议结合方程法

## 反向触发

- 只蒸发/加水且溶质不变时，可改用"蒸发/加水时浓度与溶液成反比"快速求解
- 两种溶液混合求比例时，可改用线段混合法或方程法
