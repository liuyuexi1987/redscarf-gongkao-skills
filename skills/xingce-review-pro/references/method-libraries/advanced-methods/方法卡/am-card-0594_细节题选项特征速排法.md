# 方法卡：细节题选项特征速排法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 细节题选项特征速排法 |
| 适用题型 | 言语理解——细节判断题（"下列说法正确/不正确/相符的是"） |
| 触发场景 | 细节题中四个选项特征各异，可以通过选项表面特征快速缩小排查范围 |
| 步骤逻辑 | ① 识别六类易错选项特征：a.绝对化表述（一定/必须/就是）；b.因果相悖（A导致B说反了）；c.时态偷换（未来→已完成）；d.比较项（A优于B可能说反或无关对比）；e.数据项（占比/百分比可能篡改）；f.带引号专有名词；② 选正确的：常规项优先验证，比较项/绝对化/因果项可后查；③ 选不正确的：先从比较项/绝对化/因果项入手 |
| 高频错因 | 逐个选项回文段对照耗时；不识别选项特征导致在容易出错的选项上反复纠结；对"偷换概念"类选项（如"调节能力下降"偷换成"视力下降"）不敏感 |
| confidence | high |

## 补充说明

六类特征选项只是"易错概率高"，并非必然错误，需优先回归文段验证。应用顺序：选正确的题目先验证常规项、再验证特征项；选不正确的题目先从特征项入手（绝对化/比较项/因果项最易定位错误）。

偷换概念类选项识别要点：当选项把文段中的概念替换为近义但外延不同的概念时（如把"调节能力下降"替换为"视力下降"，把"老了"替换为"老化后"），属于偷换，需对照原文概念的外延是否一致。

绝对化表述识别要点：选项出现"就是/必然/一定/不需要"等词语时，需对照文段是否有同等强度的限定；文段未给绝对化表述而选项强加绝对化，多为错误项。

## 不适用条件

- 选项均为常规表述、无任何六类特征时不适用速排法，需逐项回归文段对照。
- 文段本身含绝对化表述或比较关系时，选项的绝对化/比较可能是对文段的正确转述，不能仅凭特征排除。
- 题目要求选择"相符"且选项间无明显特征差异时不适用此法。

## 反向触发

- 当六类特征项回归文段验证后均为正确时，应换用"主旨对照法"重新核验题干要求与选项匹配关系。
- 当选项出现多个特征叠加（如绝对化+偷换）时，应优先验证特征叠加项而非逐个验证单一特征项。
- 当特征项验证耗时过长时，应回归"先读题干再回文定位"的基础解题流程，避免在特征判断上空耗。
