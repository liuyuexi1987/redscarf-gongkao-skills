# 方法卡：合并月份极值判断

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 合并月份极值判断 |
| 适用题型 | 资料分析 - 查找比较类 |
| 触发场景 | 材料中1-2月合并为一个数据，问某指标最低/最高月份在哪个季度 |
| 步骤逻辑 | 1. 将1-2月合计数除以2，得到月均值；2. 月均值一定介于两个月之间（一大一小或两相同）；3. 无论哪种情况，至少有一个月 ≤ 月均值；4. 用月均值与其他单月数据比较，判断极值归属 |
| 高频错因 | 忽略1-2月是合计数，误以为是一个月的数据直接参与比较 |

| confidence | high |

## 不适用条件

- 材料给出的是季度合计而非1-2月合并数据，无法拆分月均值
- 题目要求精确到具体是1月还是2月，月均值只能说明"至少一个月≤均值"，无法确定具体月份
- 1-2月合计数异常偏大或偏小（如含节假日因素），与其他单月不具可比性

## 反向触发

- 当用月均值比较后发现极值不在1-2月区间内时，可以直接用单月数据判断，无需继续拆分合并月份
- 当选项要求精确区分1月和2月时，仅靠月均值无法判定，应回退寻找其他条件或数据支持具体月份的判断
