# 方法卡：一般质疑识别法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 一般质疑识别法 |
| 适用题型 | 逻辑判断——质疑题（非归因论证） |
| 触发场景 | 题干没有"既成事实+原因分析"结构，选项没有明显的"另有他因/因果倒置/否定此因" |
| 步骤逻辑 | ① 看题干：是否有既成事实？作者是否在分析原因？如果不是，就是一般质疑；② 看选项：如果选项没有从原因角度质疑（没有另有他因、因果倒置、否定此因），就是一般质疑；③ 一般质疑不谈原因，只谈结论对不对 |
| 高频错因 | 把一般质疑当成归因论证，试图用"另有他因"等归因方法解题 |
| confidence | medium |
| 不适用条件 | - 题干存在 |
| 反向触发 | - 题干有既成事实且选项在分析原因→用归因论证方法卡\n- 结论含 |

## 补充说明

一般质疑和归因论证的核心区别：归因论证有"既成事实"（如"某人冬天过敏减轻了"），然后分析原因；一般质疑没有既成事实，只是一个观点或推测（如"寒冷天气有利于减轻过敏"）。做题时先判断题型，再选方法。
