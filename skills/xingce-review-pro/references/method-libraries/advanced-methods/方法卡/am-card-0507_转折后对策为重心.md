# 方法卡：转折后对策为重心

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 转折后对策为重心 |
| 适用题型 | 主旨题/中心理解题 |
| 触发场景 | 文段有转折词（但/然而/却），且转折前后都有对策或观点 |
| 步骤逻辑 | 1)识别转折结构 2)转折之后的内容（对策/观点）是重点 3)只有转折之前的内容一定不对 4)如果选项是A且B形式涵盖转折前后，需回原文验证 |
| 高频错因 | 看到转折前有对策就选了，没看完转折后的内容 |
| confidence | medium |

## 不适用条件

1. 转折后是对策但转折前是问题/背景而非对策时，"转折后为重心"仍然成立，但选项若同时概括问题+对策也可能是正确答案，需回原文验证
2. 文段为"虽然A，但B，所以C"的多层结构时，重心在结论C而非转折后B

## 反向触发

1. 转折后没有对策或明确观点，仅补充说明时，重心可能在转折前的结论
2. 选项出现"A但B"概括形式时，需验证是否真的涵盖了文段核心，而非仅是概括了结构
