# 方法卡：差值法省略全量计算

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 差值法省略全量计算 |
| 适用题型 | 数量关系——方案比较、费用差与工程差量 |
| 触发场景 | 两种方案大部分相同，问题只求差值，且差异部分的数量和单价差可直接确定 |
| 步骤逻辑 | 1. 识别两种方案的**唯一差异**部分（如甲少干3小时、乙多干3小时）；2. 计算差异部分的工作量（如3小时×200份/小时=600份）；3. 这600份在两种方案下分别由不同主体完成，单价不同；4. 差值 = 差异量 × 单价差，无需计算每种方案的总费用 |
| 高频错因 | 分别计算两种方案的全部费用再相减，计算量大且易出错没有识别出差异部分，导致做了无用功 |
| confidence | medium |
| 不适用条件 | 题目要求分别求出两种方案的绝对值（如各自花了多少钱），不能只算差值；两种方案有多处同时变化且各处单价不同，差值法需要逐项计算，优势不大 |
| 反向触发 | 两种方案有两个以上变量差异时，差值法需逐项计算容易遗漏，应分别算出总量再相减验证；用差值法算完后与选项不符，回溯检查差异部分是否识别完整 |

## 补充说明

核心思想：题目求的是差值，不是绝对值。只算变化部分，跳过不变部分。类似思维在行程问题（修车问题）、工程问题中都可复用——找差异、算差异、得结果。
