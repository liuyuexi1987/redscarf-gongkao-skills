# 方法卡：类比推理一级辨析优先

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 类比推理一级辨析优先 |
| 适用题型 | 判断推理——类比推理 |
| 触发场景 | 类比推理题，需要判断词语间关系 |
| 步骤逻辑 | ① 先用一级辨析（最直接的关系：包含/并列/因果/功能/组成等）；② 一级辨析选不出来→再上二级辨析（领域、主被动、感情色彩等）；③ 从命题人角度思考：他想考什么关系？④ 不要一上来就用高级辨析→容易过度分析 |
| 高频错因 | ① 一上来就用二级辨析→过度分析→选错；② 不先判断命题意图→盲目套用各种关系 |
| confidence | high |

## 补充说明
类比推理的核心原则：先简单后复杂。一级辨析（直接关系）优先，选不出来再上二级。属性题：属性一般是形容词/名词，动词一般不算属性。

## 不适用条件

1. 一级辨析关系明确且唯一时（无需上二级）。
2. 题目明确要求二级辨析（如考查感情色彩、领域差异）时。
3. 词语间存在多重嵌套关系需综合判断时。

## 反向触发

1. 当一级辨析出现多个选项均成立时，应补充二级辨析细化区分。
2. 当命题意图明显指向二级辨析时，应换用二级辨析优先。
3. 当词语关系罕见难以归入一级辨析时，应核验是否为特殊关系题。
