# 方法卡：放缩法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 放缩法 |
| 适用题型 | 资料分析——除法估算·基期计算、增速计算、比重计算等所有A÷B型问题 |
| 触发场景 | 需要计算一个除法（如基期=现期÷(1+增速)、比重=部分÷整体），分母位数较多不好直除 |
| 步骤逻辑 | ① 将分母调整为便于口算的邻近数；② 分子若能按近似相同比例调整，则用调整后的分数计算；③ 若不能同比例调整，分别记录分子、分母变化对结果的方向和误差；④ 将估算结果与选项比较；⑤ 误差可能跨越选项时，恢复更多有效位或用原式反乘验证 |
| 高频错因 | ① 只改分母却不记录结果偏移方向；② 分子分母按不同比例调整后仍当作等值分数；③ 未比较估算误差与选项间距；④ 为凑整改动过大，反而增加计算和修正成本 |
| confidence | high |

## 补充说明

放缩法本质是把难除的分数改写成便于口算的邻近分数。分子分母同比例变化时数值不变；不能同比例调整时，必须记录误差方向并结合选项差距判断是否可用。它是估算路径，不天然比直除更精确；当估算误差可能跨越选项或改变结论时，应改用精算或反乘验证。

## 不适用条件

1. 分母没有明显接近的整数或百化分数可凑，放缩空间很小。
2. 放缩的累积误差可能跨越选项，且无法通过方向判断排除时。
3. 分子分母数据位数很短，直接口算或直除反而更快。

## 反向触发

1. 分母位数较多、直接直除困难，且可找到接近的整数或百化分数。
2. 选项差距适中或较大，允许一定的估算误差。
3. 已尝试直除但算得太慢，需要更快的近似路径。
