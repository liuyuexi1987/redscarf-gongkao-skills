# 方法卡：盐水混合速判增速

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 盐水混合速判增速 |
| 适用题型 | 资料分析——已知总体增速和一个部分增速求另一部分增速；或判断哪个区间增速最高 |
| 触发场景 | 总体由两部分组成，已知总体增速和其中一个部分的增速及两部分的量，求另一部分增速；或给出多个区间（如各季度）的混合增速，判断哪个区间增速最高 |
| 步骤逻辑 | ① 判定题型：总体由两部分混合而成→盐水模型；② 求另一部分增速：先求另一部分的量（总体量-已知部分量），再用盐水比例公式——两部分量之比=两者增速到混合增速的距离之比的反比（即A量/B量 = |rB−rMix| / |rA−rMix|），分子分母不要颠倒；③ 判断哪个区间增速最高：当区间基期结构相近时，混合增速高的区间其成分增速也高，可直接比较各区间混合增速判断 |
| 高频错因 | 混合增速不是两成分增速的中点，它总是偏向量大的一方；判断区间增速最高时不能只看单月峰值，要理解混合增速是加权平均 |
| confidence | high |

## 补充说明

盐水比例公式：两部分量之比 = 两者增速到混合增速的距离之比的反比。这是十字交叉法的核心结果。注意混合增速总是靠近量大的一方（量大的成分对混合增速影响更大），不是两成分增速的算术平均。求另一部分增速时，务必先正确求出另一部分的量，再代入比例公式。

## 不适用条件

- 总体不是由两部分简单混合而成（如三部分或非线性叠加）时，盐水模型不适用。
- 已知部分增速但无法确定各部分量之比时，无法用份数比例求解，本方法不适用。

## 反向触发

- 当两部分量接近1:1时，混合增速接近两成分增速的中点，此时若需精确值应换用十字交叉法或列方程精算，若仅需比较可直接用中点判断。
- 当题目要求精确增速而非区间判断时，应换用十字交叉法或列方程精算。
