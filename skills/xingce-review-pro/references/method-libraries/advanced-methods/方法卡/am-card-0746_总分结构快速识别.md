# 方法卡：总分结构快速识别

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 总分结构快速识别 |
| 适用题型 | 言语理解——片段阅读（主旨/意图题） |
| 触发场景 | 首句为总概括/总观点，后文出现"一方面...另一方面"、分号、相同句式等并列/分论点标志 |
| 步骤逻辑 | ① 读首句，判断是否为总概括或总观点；② 看后文是否有分论点提示词（一方面/另一方面、分号、相同句式）；③ 如果是总分结构，重点在"总"（首句），"分"（后文各论点）只是对总的具体展开；④ 正确答案应概括首句，同时覆盖后文各分论点的共同主题 |
| 高频错因 | 被某个分论点吸引只选了它（片面）；选项只对应"分一"或"分二"而非"总"；忽略了并列结构的双主语 |
| confidence | medium |

## 补充说明

总分结构中"分"有两种形式：①条理清晰的分一、分二、分三（可以用一方面/另一方面标识）；②乱七八糟的一顿分析，分不清哪个是分一、分二，但知道说的是跟"总"差不多的事。不论哪种，重点都在"总"。当后文出现双主语（如"出海企业"和"相关部门"），正确选项需同时覆盖两个主体，只对应其中一个即为片面。

## 不适用条件

1. 首句仅为背景引入或问题描述，后文没有围绕首句展开的分论点时，不是总分结构。
2. 文段为并列结构（前后句地位平等，无"总"可言），需用全文概括法而非首句锚定。
3. 文段层次复杂，总与分之间隔了多层嵌套时，简单总分判断可能遗漏中间层重点。

## 反向触发

1. 首句不是概括性表述而是具体细节（如具体事例、数据），应重新分析文段脉络，可能为分总或并列结构。
2. 后文的"分"偏离首句主题（话题漂移），说明首句可能只是引子而非"总"，需换用其他结构判断法。
