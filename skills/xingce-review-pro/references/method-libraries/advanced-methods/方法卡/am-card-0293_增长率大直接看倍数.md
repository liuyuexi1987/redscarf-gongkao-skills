# 方法卡：增长率大直接看倍数

| 字段 | 内容 |
|------|------|
| 方法名 | 增长率大直接看倍数 |
| 适用题型 | 资料分析-比较多个增长率大小 |
| 触发场景 | 多个指标增长率差距很大（如有接近3倍的，有不到2倍的），直接比倍数比算百分比更快 |
| 步骤逻辑 | 1. 观察现期值和基期值的倍数关系 → 2. 倍数 = 现期 ÷ 基期 → 3. 倍数越大，增长率越大（因为增长率 = 倍数 - 1） → 4. 倍数差距明显时直接淘汰 |
| 高频错因 | 在倍数差距已经很大时仍逐个算增长率百分比，浪费时间 |
| confidence | high |

补充说明：当增长率差距大时（如一个接近3倍，其他远不到3倍），直接看现期÷基期的倍数关系即可判断。倍数上已有明显区别时，应立即切换为倍数比较而非逐个算百分比。

## 不适用条件

- 各指标倍数差距不大（差距在0.3倍以内）时，仍需精确计算增长率百分比
- 题目要求求出具体增长率值而非仅比较大小
- 多个指标需要精确排序（非仅找最大/最小）时，倍数法精度不够

## 反向触发

- 当各选项的倍数非常接近时，应改用百分比精确比较
- 题目同时考查比重、增量等其他考点时，倍数法无法覆盖，应综合计算
- 当现期值或基期值包含负数时，倍数关系失去直接意义，应换用其他判断方式
