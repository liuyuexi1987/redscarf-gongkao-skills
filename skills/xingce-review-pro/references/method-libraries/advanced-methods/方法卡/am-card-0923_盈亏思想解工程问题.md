# 方法卡：盈亏思想解工程问题

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 盈亏思想解工程问题 |
| 适用题型 | 工程问题·有故障/休息场景 |
| 触发场景 | 理想情况vs实际情况，中间有停工/故障导致效率变化 |
| 步骤逻辑 | 1. 理想情况：全程按原效率完成；2. 实际情况：中间一段时间停工（效率为0），后面提速补偿；3. 少做的部分（亏）= 多做的部分（盈）；4. 例：停工1.5小时（每小时少做32个）→ 后面每小时多做16个 → 需3小时补回 → 前面3.5小时+后面3小时+停工1.5小时=8小时；5. 时间比=亏盈效率的反比 |
| 高频错因 | 把停工期间也算入效率比的计算 |
| confidence | high |

## 补充说明

盈亏思想本质是"少的部分和多的部分相等"，比方程更快。

## 不适用条件

- 多次停工或多次提速（盈亏关系不止一组）时，单一盈亏等式难以覆盖，应分段列式。
- 效率变化非恒定（如阶梯提速）时，盈亏等式需分阶段建立，不能整体套用。
- 题目无明确"理想vs实际"对比框架时，盈亏思想无着力点。

## 反向触发

- 当盈亏等式两边单位不一致（一边是时间一边是工作量）时，应反向核验换算，改用方程法。
- 当题目含"中途换人""部分移交"等复杂场景时，应换用工程量不变列方程法。
- 当算出的补偿时间为负值或不合理时，应补充核验停工时长与提速幅度的对应关系。
