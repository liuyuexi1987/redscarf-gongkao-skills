# 方法卡：强转后重点从对策转问题

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 强转后重点从对策转问题 |
| 适用题型 | 中心理解 |
| 触发场景 | 文段先有对策/成就，后接强转折（"但是…还面临…""但还…"），转折后出现新问题 |
| 步骤逻辑 | 1. 强转折后出现的问题成为新的重点；2. 若问题后又接对策→最终重点在最后的对策；3. 转折前的对策/成就不再是最核心；4. 不要刻板套"有对策选对策"——要看对策在哪个位置 |
| 高频错因 | 刻板执行"有对策选对策"，忽略了强转折已将重点转移到问题/新对策上 |
| confidence | high |

## 不适用条件

1. 文段无强转折（如仅有"此外""同时"等并列/递进关联词）
2. 转折后未引入新问题，仅修正前文表述的细节
3. 文段本身不含对策，转折后也不出现对策或问题的转换

## 反向触发

1. 看到"但是…还面临…""但还…"等强转折后跟新问题表述，应立即想到本方法
2. 文段前半部分已有完整对策/成就描述，后半突然转折到问题，优先选问题相关的选项
3. 出现"有对策选对策"的刻板判断时，先检查对策是否在转折前（可能已不是重点）
