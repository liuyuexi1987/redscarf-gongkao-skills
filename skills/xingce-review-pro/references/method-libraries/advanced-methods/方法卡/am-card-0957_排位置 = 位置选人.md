# 方法卡：排位置 = 位置选人

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 排位置 = 位置选人 |
| 适用题型 | 若干人排成一列/一圈的排列问题 |
| 触发场景 | 题目涉及"排成一列""站队""排座位" |
| 步骤逻辑 | 1. 把"人排位置"转化为"位置选人"；2. 第一个位置从N人中选1个 → N种；3. 第二个位置从剩余N-1人中选1个 → N-1种；4. 以此类推，总方案 = N! |
| 高频错因 | 思路混乱，不知从人还是位置角度思考 |
| confidence | high |

## 补充说明

位置问题和拿东西本质相同——只是把"人"和"位置"的角色互换

## 不适用条件

1. 圆排列问题（环形座位），需使用 (N-1)! 而非 N!。
2. 存在相邻/不相邻约束（如"甲乙必须相邻"），需配合捆绑法或插空法。
3. 位置本身有差异（如不同岗位），但题目要求"先分组再分配"时，应改用分组分配法。

## 反向触发

1. 当题目为环形排列时，应换用圆排列公式 (N-1)!，并核验固定参考点。
2. 当存在相邻或定距约束时，应配合捆绑法或插空法处理，不能直接套用全排列。
3. 当出现"先选人再分配岗位"的两阶段结构时，应改用组合×排列的复合方法。
