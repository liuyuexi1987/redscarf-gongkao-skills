# 方法卡：差分法比分式大小

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 差分法比分式大小 |
| 适用题型 | 资料分析——两个分式大小比较（数据距离较近时） |
| 触发场景 | 两个分式数值接近，肉眼难以直接判断大小 |
| 步骤逻辑 | ① 将两个分式分别写出来；② 分子分母分别做差，得到"差分"分式；③ 比较差分分式与原分式的大小关系，利用"分子增速>分母增速则比值上升"的规律判断 |
| 高频错因 | ① 差分后距离太远时忘记等比例放大；② 放大后仍需比较变化比例，而非直接比差值 |
| confidence | high |

## 补充说明

差分法本质是把两个分式看成基期比和现期比，通过比较分子分母的增速来判断比值变化方向。数据靠近时效果最佳，不靠近时可先等比例放大再做差分。当估算误差可能跨越选项或改变结论时，改用精算/验证。

## 不适用条件

1. 两个分式的数值差距已经很大，肉眼可直接判断大小，无需差分。
2. 分子分母的量级差异极大，等比例放大后仍难以做差。
3. 题目不是比大小而是算具体值，差分法不适用。

## 反向触发

1. 两个分式数值接近，肉眼或简单截位无法判断大小。
2. 两个分式的分子分母数据格式相似但数值不同，适合做差比较。
3. 尝试直接计算两个分式的值太耗时，需要一种快速比较方法。
