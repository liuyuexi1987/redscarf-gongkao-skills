# 方法卡：削弱切断机制链条

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 削弱切断机制链条 |
| 适用题型 | 判断推理——削弱题（归因有明确机制链条） |
| 触发场景 | 题干给出了A通过机制M导致B的具体路径，问削弱 |
| 步骤逻辑 | ① 识别题干机制链：植物油→降低总胆固醇→保护心脏；② 从机制核心环节入手质疑：降总胆固醇≠达到高低密度胆固醇的特定比例→不一定降低心脏病风险；③ 用"不一定"而非"一定否定"来削弱，因机制可能成立也可能不成立 |
| 高频错因 | 只看表面话题相关（如"不是每个种类"），忽视机制核心；误选"他因"（其他因素也能达到同样效果） |
| confidence | high |

## 补充说明

类比理解：结论"人多→市场繁荣"，削弱"要看能消费的人多还是不消费的人多"——同样切断了"人多"直接到"繁荣"的机制。机制切断的核心是质疑中间环节是否必然传导，而非否定起点或终点的真实性。

## 不适用条件

1. 题干无明确机制链条（仅给出相关性或共变关系）时不适用。
2. 问法为加强或解释机制时不适用。
3. 题干为归纳论证（样本→总体）而非机制论证时不适用。

## 反向触发

1. 若题干为归纳论证而非机制论证，应换用样本代表性削弱法。
2. 若选项均为他因，需比较哪个他因更切中核心机制环节，而非数量多少。
3. 若机制链条含多个中间环节，应优先质疑最关键的那个环节而非边缘环节。
