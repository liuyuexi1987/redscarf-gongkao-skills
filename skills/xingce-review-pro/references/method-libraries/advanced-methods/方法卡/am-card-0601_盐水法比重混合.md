# 方法卡：盐水法解比重混合问题

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 盐水法解比重混合问题 |
| 适用题型 | 数量关系（比重/浓度/占比混合） |
| 触发场景 | 两部分混合后总占比已知，求各部分的数量比或总量 |
| 步骤逻辑 | 1. 确定三要素：第一部分占比、第二部分占比、混合总占比；2. 大数减小数交叉：大占比-总占比→对方量，小占比-总占比→对方量；3. 得到两部分的量之比；4. 由已知部分的数量反推另一部分或总量；5. 最值问题中让各部分占比取边界值（最多/最少） |
| 高频错因 | 交叉方向搞反；最值问题中没有取边界值而是取中间值 |
| confidence | medium |

## 不适用条件

- 三部分及以上混合时不适用此法（盐水法针对两部分混合）。
- 混合后总占比未知、需联立其他条件求解时不适用此法。
- 题目给出的是绝对数量而非占比/浓度时不适用此法（应换用方程法）。

## 反向触发

- 当两部分占比接近、交叉差值过小导致比例结果易错时，应换用方程法核验。
- 当最值问题中边界值不明确时，应补充用极值假设法分别取上下界验证。
- 当混合后总量已知但各部分占比未知且需多次迭代时，应换用比例方程组求解。
