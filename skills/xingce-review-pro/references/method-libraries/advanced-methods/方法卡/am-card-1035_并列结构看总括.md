# 方法卡：并列结构看总括

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 并列结构看总括 |
| 适用题型 | 言语理解——中心理解（并列结构） |
| 触发场景 | 文段有"一方面/另一方面""同时""此外"等并列提示词 |
| 步骤逻辑 | ① 找总括句（通常在并列之前或之后）；② 没有总括句→找并列内容的共性（重复出现的词）；③ 共性找不到→找作者帮我们总结的那句话（通常在开头）；④ 并列越长越不需要细看具体内容→直接找总括 |
| 高频错因 | ① 选了并列中的一个小点→以偏概全；② 并列很长时逐条细看→浪费时间且抓不住重点 |
| confidence | high |

## 不适用条件
- 文段并非真正并列而是递进或转折结构时，应优先识别主旨句而非总括。
- 并列分句间存在明显主次（一详一略）时，详述项往往承载主旨，不能套用"看总括"。
- 总括句本身含模糊表述、需结合分句细化时，单纯依赖总括会误选。

## 反向触发
- 当并列结构后紧跟转折词（"但是""然而"），应换用转折后重点法。
- 当文段为总分总且总括与分述矛盾时，应回到分句核验作者真实倾向。
- 当选项中无明显共性提炼项时，应补充对分述要点的逐项比对，避免空泛总括误选。
