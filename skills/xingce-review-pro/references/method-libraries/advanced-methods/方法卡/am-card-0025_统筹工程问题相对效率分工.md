# 方法卡：统筹工程问题（相对效率分工法）
## 基本信息
| 字段 | 值 |
|------|-----|
| 方法名 | 统筹工程问题（相对效率分工法） |
| 适用题型 | 数量关系-统筹/工程问题（多人多任务） |
| 触发场景 | 两人各做不同工作，求最短时间或各自工作量 |
| 步骤逻辑 | 1.算效率比：甲做A/乙做A、甲做B/乙做B，比值大的差异更显著 2.相对效率大的优先分配（比值大者做该任务） 3.先完成的任务方帮助未完成方 4.用未知数设效率，赋值工程量，列方程求解 |
| 高频错因 | 搞反分工方向；效率比只看一列不比较两列 |
| confidence | high |
## 补充说明
搬砖和水泥的比喻：甲擅长搬砖（效率比差距大），乙擅长和水泥。甲先干完搬砖后帮乙和水泥。具体步骤：①效率比定分工 ②赋值工程量（选2、3的公倍数如6） ③计算先完成者用时 ④剩余量由两人合干，用效率比分配各自工作量 ⑤列方程求未知数。此题可作为统筹问题的母题。

## 不适用条件
- 仅涉及单人单任务的简单工程问题，无分工协调需求
- 多人做同一项工作且效率已知，不存在"谁先做哪项"的统筹决策
- 任务之间存在严格先后顺序约束，无法自由分配

## 反向触发
- 看到"求最短完成时间""怎样安排最省时间"，且涉及两人以上各自擅长不同任务
- 题目同时给出甲做A、甲做B、乙做A、乙做B的效率数据，需要比较后做分工决策
- 出现"先完成者帮助另一方"这类协作表述
