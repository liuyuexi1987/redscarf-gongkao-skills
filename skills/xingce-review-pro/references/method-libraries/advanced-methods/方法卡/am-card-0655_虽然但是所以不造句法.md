# 方法卡：虽然但是所以不造句法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 虽然但是所以不造句法 |
| 适用题型 | 逻辑判断——一般质疑（推理过程漏洞） |
| 触发场景 | 题干有论据有结论，需要质疑推理过程中的漏洞 |
| 步骤逻辑 | ① 虽然：复述题干的论据（题干说的有利因素）；② 但是：引入选项中的反面因素（不利因素）；③ 所以不：得出与题干结论相反的结论；④ 检验：造的句子越有逻辑，越可能是正确答案 |
| 高频错因 | 造句时"但是"部分引入的因素与题干话题不一致；"所以不"部分没有直接反驳题干结论 |
| confidence | medium |
| 不适用条件 | - 题干论证是因果关系而非利弊分析，造句结构不适用\n- 没有明确的论据和结论可供拆分，无法造出 |
| 反向触发 | - 造句结果发现 |

## 补充说明

造句结构：虽然[题干论据]，但是[选项的反面因素]，所以[题干结论]不成立。例如：虽然未来几天有适量降雨有利于水稻生长，但是现在有水稻病菌正在传播，所以水稻不一定丰收，期货价格不一定下降。关键是"但是"部分要引入一个能影响结论的反面因素。
