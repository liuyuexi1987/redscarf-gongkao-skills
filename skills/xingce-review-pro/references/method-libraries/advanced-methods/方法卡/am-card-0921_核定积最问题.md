# 方法卡：核定积最问题

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 核定积最问题 |
| 适用题型 | 经济利润·售价与销量的最优平衡 |
| 触发场景 | 两个量相乘求最大值，且两量之和为定值（一个加一个减） |
| 步骤逻辑 | 1. 识别结构：两个量A和B，A+B=定值M，求A×B最大值；2. 结论：当A=B时，A×B取得最大值；3. 证明：A×B = A×(M-A) = -(A-M/2)² + M²/4，当A=M/2时最大；4. 应用：收入=售价×销量，涨价则销量降，求收入最高时的售价 |
| 高频错因 | 忽略"和为定值"的前提条件 |
| confidence | high |

## 补充说明

核定积最问题近年考频下降，但仍需掌握基本原理。

## 不适用条件

- 两量之和非定值（如涨价同时成本也变）时，A+B=M前提不成立，不能套用。
- 涉及整数约束（销量必须为整数）时，理论最值点可能非整数，需取邻近整数核验。
- 题目含分段函数或阶梯定价时，整体最值需分段比较，不能直接用A=B极值点。

## 反向触发

- 当算出的最值点与选项均不匹配时，应反向核验"和为定值"是否成立，改用列函数求最值。
- 当题目含"最多""至少"等约束语义时，应补充核验边界条件，不能只取极值点。
- 当涉及三个及以上变量时，应换用拉格朗日法或分步求最值。
