# 方法卡：两期比重比较

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 两期比重比较 |
| 适用题型 | 资料分析——判断比重是上升还是下降（不需求具体值） |
| 触发场景 | 题目问"比重比上年上升/下降"，只需判断方向 |
| 步骤逻辑 | ① 比重升降只看增长率：R部分 > R整体 → 比重上升；R部分 < R整体 → 比重下降；② 不需要算具体数值 |
| 高频错因 | 误以为需要算具体比重差；搞混谁和谁比 |
| confidence | medium |
| 不适用条件 | 题目要求算比重具体差值的百分点数时；部分增长率或整体增长率数据缺失时；题目不是比重类比较（如利润率、占比变化趋势图判读） |
| 反向触发 | 题目只问比重上升还是下降、不需求具体数值时，优先用此法而非比重差公式 |

## 补充说明

 判断口诀："部分增速>整体增速→比重上升，反之下降"。这是盐水思想的应用：浓度（比重）的变化取决于哪部分增长更快。不需要算具体差值，只需比较大小。
