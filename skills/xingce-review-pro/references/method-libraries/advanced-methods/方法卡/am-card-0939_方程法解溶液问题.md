# 方法卡：方程法解溶液问题

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 方程法解溶液问题 |
| 适用题型 | 各类溶液混合、加水、蒸发、加溶质问题 |
| 触发场景 | 题目给出混合前后浓度关系，求某个未知量 |
| 步骤逻辑 | 1. 识别不变量（通常是溶质不变）；2. 设未知数；3. 利用"浓度=溶质÷溶液"列方程；4. 混合前溶质之和 = 混合后溶质之和 |
| 高频错因 | 忽略加溶质时溶液总量也会变化；忘记混合前后溶质守恒 |
| confidence | high |

## 补充说明

方程法是溶液问题的通解，适用于几乎所有题型，简单题可用技巧快速判断，复杂题建议踏实列方程

## 不适用条件

- 题目完全不涉及溶液浓度关系时不适用
- 简单数值的纯蒸发/加水题，用反比法更快

## 反向触发

- 仅两种溶液混合且求比例时，可改用线段混合法
- 反复倒出补满的固定比例题，可改用"循环倒出+补满"幂次公式法
