# 方法卡：因果倒置与继发关联速判

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 因果倒置与继发关联速判 |
| 适用题型 | 判断推理-削弱题（两件事相伴发生，题干认定A是因B是果） |
| 触发场景 | 题干结构：研究发现A和B存在关联/伴随发生 → 推断A导致B。常见于医学/社会学研究类题目 |
| 步骤逻辑 | ① 识别题干是否把 A、B 的伴随关系解释成 A 导致 B；② 检查因果倒置：是否可能由 B 导致 A；③ 检查共同原因：是否存在 C 同时导致 A 和 B；④ 比较各选项是否真正作用于题干的主体、时间顺序和因果链，再判断削弱力度 |
| 高频错因 | 不区分"因果倒置"和"另有他因"的力度差异纠结于"哪个风险更高"之类的比较选项（这类选项不影响原因果关系） |
| confidence | high |

## 不适用条件

1. 题干已明确实验设计（随机对照），因果方向不存在争议
2. 题干不是"相伴发生→推断因果"的结构，而是给出明确的因果机制
3. 选项中既无因果倒置也无继发关联，需结合其他削弱方式判断

## 反向触发

1. 题干出现"研究发现A和B存在关联/伴随发生"并推断因果
2. 选项中出现"B才是原因，A才是结果"或"共同原因C同时导致A和B"
3. 常见于医学/社会学/心理学研究类题目
