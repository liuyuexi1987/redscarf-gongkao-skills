# 方法卡：年均增速前推规则

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 年均增速前推规则 |
| 适用题型 | 资料分析-年均增速（年均增长率） |
| 触发场景 | 已知起止年份数值，求年均增长率；或按相同年均增速预测未来值 |
| 必要输入 | 起始年份及数值、结束年份及数值；预测时还需预测年份 |
| 步骤逻辑 | 1.锁定公式中实际使用的起始值和结束值；2.增长期数 N=结束年份-起始年份，数年份之间的间隔，不数年份标签；3.代入 末值/初值=(1+R)^N；4.预测未来 k 年时，用 预测值/当前值=(1+R)^k；5.将结果复合 N 次回代，核对能否还原末值 |
| 高频错因 | 1.把5个年份标签误当成5个增长期；2.看到材料给了前一年数据就自动前推；3.预测时把基期或预测期数对应错 |
| confidence | high |

## 补充说明

例如求2018年至2022年的年均增长率，公式使用2018年和2022年的数值，增长期数为2022-2018=4，因此为：

`2022年值 / 2018年值 = (1+R)^4`

只有题目明确要求把2018年的同比增长也纳入平均区间，或明确把2017年作为起始基期时，才使用2017年的数值。材料中出现2017年数据，本身不构成前推理由。

若假定同一复合增速继续保持到2027年，则从2022年至2027年有5个增长期：

`2027年值 / 2022年值 = (1+R)^5`

## 不适用条件

1. 题目问各年增长率的算术平均，而不是起止水平对应的复合年均增长率。
2. 统计口径、单位或主体在区间内发生变化，起止值不能直接比较。
3. 题目只问两个相邻年份的同比增速，此时直接使用单期增长率公式。

## 反向触发

1. 仅仅出现区间首年的前一年数据，不自动前推；先看题目实际指定的起止水平。
2. 若题目明确写“从上一年末为基期”或明确把首年同比纳入若干年度增速，才按该定义前推。
3. 若回代后不能还原末值，优先检查起止年份、统计口径和增长期数，而不是强行调整答案。
