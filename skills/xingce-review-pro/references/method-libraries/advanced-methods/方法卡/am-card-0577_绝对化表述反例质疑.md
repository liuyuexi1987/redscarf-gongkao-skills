# 方法卡：绝对化表述反例质疑

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 绝对化表述反例质疑 |
| 适用题型 | 加强削弱——题干结论含"不可避免""迅速""一定会"等绝对化表述 |
| 触发场景 | 题干断言某事物"不可避免""迅速"等绝对化表述，选项中出现一个看似微小但实际覆盖了题干断言范围的反例 |
| 步骤逻辑 | ① 识别题干的绝对化表述（不可避免/迅速/所有）；② 绝对化表述只需一个反例即可被削弱，力度很强；③ 看选项是否有严谨性加码（如"近几年不会更新换代""扮演重要角色"）——这恰恰是出题人为了让你觉得"太小了不敢选"而设的干扰；④ 类比类选项（过去经历住了冲击→将来也行）力度极低，排除 |
| 高频错因 | 觉得反例太小不敢选，不知道绝对化表述下一个反例力度就很强；把类比质疑当成有效削弱（过去≠将来，力度极低） |
| confidence | high |

## 补充说明

绝对化表述（不可避免/迅速/所有）只需一个反例即可被削弱，力度很强。选项中的严谨性加码（如时间限定、角色限定）不是让力度变弱，而是出题人设的心理干扰。类比类选项（过去经历住了冲击→将来也行）力度极低，因为过去经验不适用于新情况。说明过去流通原因的选项帮不上忙。

## 不适用条件

- 题干结论是审慎的、非绝对化的（如"可能""一定程度上"），反例质疑力度不足，不适用本方法。
- 题干绝对化表述已被选项中的更强反例全面否定，无需比较力度时，该反例即为最强削弱。

## 反向触发

- 当选项中同时存在反例削弱和因果切断两类选项时，应换用"削弱力度比较法"横向比较力度大小。
- 当题干绝对化表述涉及数量阈值时，应补充核验反例是否真的落在题干断言范围内，避免范围错位。
