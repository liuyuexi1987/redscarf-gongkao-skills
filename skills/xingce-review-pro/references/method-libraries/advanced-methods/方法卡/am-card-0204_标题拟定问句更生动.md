# 方法卡：标题拟定问句更生动

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 标题拟定问句更生动 |
| 适用题型 | 标题拟定 |
| 触发场景 | 文段为递进探索过程（假设→理论证明→实证），选项有问句和陈述句可选 |
| 步骤逻辑 | 1. 先核对标题是否完整覆盖文段核心；2. 排除片面、偷换和力度失真的选项；3. 只有两个选项内容同样准确时，再结合文段是探索过程还是明确结论，比较问句与陈述句的贴合度；4. 表达形式只能用于同质选项的末位辨析，不能压过内容准确性 |
| 高频错因 | 同质选项中纠结取舍；选了只对应某一分句的片面选项 |
| confidence | high |

## 不适用条件

1. 文段为明确结论型（非探索/存疑过程），问句标题不适用
2. 选项中无问句可选，只有陈述句之间的比较
3. 问句选项未能覆盖文段核心内容，仅形式生动但内容片面

## 反向触发

1. 选项同时出现问句和陈述句时，先比较内容覆盖、对象和力度，不按句式直接选
2. 文段呈"假设→验证"的探索过程，且问句准确覆盖核心时，可把问句形式作为末位辨析依据
3. 若问句更生动但内容片面，仍应选择内容完整准确的陈述句
