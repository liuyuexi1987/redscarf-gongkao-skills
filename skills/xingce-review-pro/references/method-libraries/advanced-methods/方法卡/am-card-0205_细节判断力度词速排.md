# 方法卡：细节判断力度词速排

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 细节判断力度词速排 |
| 适用题型 | 细节判断（说法正确/理解正确） |
| 触发场景 | 细节判断题，选项中含强力度词（"主要""越来越""重要"等） |
| 步骤逻辑 | 1. 标出选项中的范围、程度和趋势词；2. 回文段核对是否有主次依据、连续变化或同等力度的原词；3. 强力度词缺少对应证据时优先排除，有明确支撑时不得仅凭词强排除；4. 按证据逐项核验，不根据选项字母或位置猜答案 |
| 高频错因 | 忽略力度词需要文段强支撑，凭感觉选"主要"或"越来越" |
| confidence | high |

## 不适用条件

1. 选项中的力度词（如"主要"）在文段中有明确的数据或比例支撑
2. 细节判断题问的是"说法错误"而非"说法正确"——力度词陷阱在正选和排除中方向不同
3. 文段本身已使用了同等力度的表述（如"主要是由…造成的"），选项复述不构成过度

## 反向触发

1. 选项含"主要""越来越"等强力度词时，先标记为高风险，回文段找是否有强支撑
2. 选项含"重要"等评价词时，仍需核对文段是否表达对应地位，不能只凭词语强弱判断
3. 先验证强力度词是否有原文证据，再检查其余选项；选项位置不构成判断依据
