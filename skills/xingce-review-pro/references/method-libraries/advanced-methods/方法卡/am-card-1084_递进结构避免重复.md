# 方法卡：递进结构避免重复

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 递进结构避免重复 |
| 适用题型 | 逻辑填空——递进结构 |
| 触发场景 | 出现"更重要的是""甚至""不仅…更"等递进提示词 |
| 步骤逻辑 | ① 识别递进结构（更重要的是/甚至/不仅…更）；② 递进前后的内容不能是同义词；③ 后面讲的内容提示前面空格不能填同类词（如后面讲"导向性"→前面不能选"导向性"相关） |
| 高频错因 | ① 递进前后选了同义词→变成废话；② 不注意递进的"更深一层"含义 |
| confidence | high |

## 补充说明
## 不适用条件
- 题干无递进提示词时，不使用本卡
- 并列结构（而非递进结构）应使用并列推断法
- 选项之间无语义层次差异时，递进分析不适用

## 反向触发
- 若题干出现的是转折词（"但是""然而"）而非递进词，不使用本卡
- 若空格前后内容本身已构成完整语义、无需递进补充，先排除递进结构
