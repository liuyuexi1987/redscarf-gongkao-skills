# 红领巾错因诊断 Skill

用于把用户的错题、复盘文字或模考表现诊断成可行动的错因卡。

## 使用流程

1. 先读 `references/错因诊断.md`。
2. 若用户要案例或证据，再读 `references/按错因查案例.md`。
3. 输出错因时固定包含：表现、原因、修正策略。
4. 可附 1-3 个库内相似 `unit_id/source_quote`，但不要贴长原文。

## 诊断边界

- 不把“不会”简单归因成粗心；要看定位、关系、词义、计算、策略哪个环节断了。
- 用户材料不足时，给低置信诊断并说明还需要哪类信息。
- ASR 来源标“据 ASR 讲解，术语/数字待核”。

## 常用问法

- “我这题选错了，按红领巾错因帮我诊断。”
- “这次模考言语错很多，是想太多还是定位问题？”
- “把这道资料分析错题整理成错因卡。”

## 输出模板

1. 错因结论：<主要错因家族 + 置信度>
2. 表现：<题面/选项/计算/策略上具体错在哪里>
3. 原因：<定位、关系、词义、计算、策略哪一环断了>
4. 修正策略：<下次遇同类题的固定动作>
5. 库内依据：<`source_quote` + `unit_id`；没有时说明无直接依据>
6. 需要补充：<材料不足时列出还缺什么>

## 错因卡输出模板

- 题目：<模块/题型，如 言语·结语题>
- 我的选择 / 正确答案：<X -> Y>
- 错误环节：□定位 □关系 □词义 □计算 □策略
- 表现：<一句话说明 what went wrong>
- 错因家族：<过度思考/偷换/细节误读/逻辑误判/计算估算失误/策略问题>
- 红领巾依据：<`source_quote` + `unit_id`；ASR 来源标待核>
- 修正策略：<下次遇同类题的固定动作>
- 置信度：<高/中/低；材料不足时给低并说明缺口>
