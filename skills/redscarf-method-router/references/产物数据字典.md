### file_index.jsonl

### unit_index.jsonl

## 核心字段说明

| 字段 | 说明 |
|------|------|
| unit_id | 格式 `文件名__u序号`，全局唯一 |
| card_id | 格式 `card/mcd/qdc/edc_序号`，全局唯一 |
| source_quote | ≤30 字的讲解原文片段 |
| confidence | high/medium/low；ASR 来源最高 medium |
| source_subtitle | ai/asr/missing，标识字幕来源 |
| skill | 言语理解/逻辑填空/资料分析/判断推理/数量关系/错因诊断/常识综合 |
| error_family | 过度思考/主题词偷换/细节误读/逻辑关系误判/词汇盲区/策略失误/计算估算失误/审题定位失误/蒙题放弃策略/选项陷阱/其他 |
