# 红领巾方法库入口

> 本页是红领巾方法库的主导航。所有规则均源自UP主「网友红领巾」的视频讲解转录。

## 解读安全规则
1. **OCR 是辅助定位**：OCR 题面用于确认题目位置，不作为方法证据
2. **source_quote 是证据**：每条规则必须有 source_quote + unit_id 可追溯
3. **ASR 内容待核**：ASR 来源的候选项标记「ASR待核」，置信度最高 medium
4. **不要直接套用**：规则来自特定题目讲解，通用化前需结合多处印证
