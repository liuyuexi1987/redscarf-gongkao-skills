# 公考复盘方法库路由 Skill

本文件只负责方法库查询和结构定位，不重复意图门禁、答案裁决或状态规则。

## 工作目录

本项目资料通常安装在：

- 技能目录：`.claude/skills/gongkao-review-*`
- 包内入口：`references/method-libraries/综合方法库.md`

## 触发后先做什么

1. 先读 `references/method-libraries/综合方法库.md`，只取与问题相关的部分。
2. 用户问文件结构或索引含义时，再读包内对应专题 `references/`。
3. 需要证据时优先用 `rg` 搜包内 `references/method-libraries/`。

## 回答原则

- 这是“讲解驱动”的方法库，不是完整真题库；但截图 OCR 可以作为“题面候选”参与复盘。
- OCR 不再一律降为不可用：即使标注“题面截图与讲解不匹配/疑似截偏”，也要先结合题干关键词、选项、讲解主题和用户提供信息交叉核对；大体吻合时可低/中置信使用。
- 方法依据以方法论字段（方法名/适用题型/触发场景/步骤逻辑/高频错因）+ 卡片 id/文件名作为锚点；对用户默认输出方法依据摘要 + 锚点。
- AdvancedMethods 按题型索引命中后，必须按索引里的 `方法卡/am-card-*.md` 相对路径读取具体卡；不得把裸卡名拼到 `advanced-methods/` 根目录。
- 不凭空补全缺失题面；若使用 OCR 题面候选，必须标注“题面据 OCR，已按讲解关键词核对/仍需人工核对”。
- 不把公考通用常识包装成公考复盘方法。

## 方法卡变式出题（回路 A，填题库空缺）

题库为空或不足时，可把方法卡当“出题素材库”，从其 `高频错因 / 触发场景 / 步骤逻辑` 字段构造**方法工作流题**，只出四类：① 公式/方法选择 ② 触发词识别 ③ 陷阱预判 ④ 归因。

- **不生成仿真计算新题**（答案不可靠 + 仿真过近原题有版权风险）。
- 每道题必须标注固定三段：`非真题 · 方法自测 · 不计真题正确率`。
- 结果记入 `review-engine/弱点档案/` 的方法掌握度，不计入真题正确率。
- 模板见 `references/question-banks/templates/方法工作流题-template.md`。

## 输出模板

1. 查询目标：<用户要找的方法/字段/索引/证据>
2. 应读资料：<入口/数据字典/具体 reference>
3. 全局约束：OCR 可作题面候选但需交叉核对；方法依据以方法论字段 + 卡片 id/文件名作为锚点；不凭空补题面
4. 方法依据：<依据摘要 + source anchor（card id/文件名）；没有时说明无直接依据>
5. 下一步建议：<继续查证/转为错因卡/交给对应专题 skill>

## 常用问法

- “公考复盘这套方法怎么判断结语题？”
- “我资料分析增长率老错，用公考复盘方法诊断一下。”
- “从库里找偷换概念/想太多的例子。”
- “按我的错题生成一张错因复盘卡。”
