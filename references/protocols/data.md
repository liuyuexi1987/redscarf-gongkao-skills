# 公考复盘资料分析 Skill

本文件只规定资料分析的公式、速算判定、方法导航和输出结构。意图门禁以 `SKILL.md` 为准；答案冲突读 `references/protocols/answer-authority.md`；状态处理读 `references/review-engine/复盘引擎说明.md`。

## 强制模式确认

每次触发本 skill，回答开头必须先写：

```text
已进入 gongkao-review-data · 资料分析模式。
```

## 强制回答协议

- 必须按“输出模板”的 1-8 项顺序和标题回答，不得改成普通聊天段落；尤其第 3 项必须独立写成“速算判定”，放在公式代入和正式计算之前。
- 用户以“我不懂/分不清/有什么区别/帮我讲讲”等方式主动求助具体考点或方法时，按【解法】讲解，不自动写入待巩固队列；只有用户明确要求记录时才写入。
- 计算题必须写明公式、代入数据、估算假设和误差边界。
- **速算判定必经**：资料分析讲解/复盘反馈时，在正式计算前必须先判断“是否可快速定位/是否需要精算”。输出时第 3 项固定写“速算判定”，且开头只能用三类标签之一：`可快速定位` / `不宜粗估，需直除或精算` / `数据不足，待核验`。判定依据：①问法是“约/最接近/比较/排序/能否推出”等允许近似的目标；②选项差距是否足以容纳截位、百化分、尾数、放缩等误差；③题面主体、年份、单位和数据完整；④OCR/截图数字可信。只有“允许近似 + 选项差距足够 + 数据可信”同时满足，才写 `可快速定位`，并说明可用的快速路径（百化分/截位/反推/比较/估到某位）；若选项间距很小、需要算到小数位，必须写 `不宜粗估，需直除或精算`，即使问法含“最接近/约为”也不能写 `可快速定位`；严禁写“可快速定位，但需控制精度”“可速算但不能粗估”“可估算但要精算”这类混合标签；若材料/OCR/单位/主体不可靠，写 `数据不足，待核验`。判定之后再进入公式、代入和计算。
- **速算判定一致性校验**：输出第 3 项前先自检“标签是否与依据一致”。若依据里出现“选项差距小 / 需算到小数位 / 粗估会跨选项 / OCR或单位不可靠 / 数据缺失”等任一信号，标签不得写 `可快速定位`；必须改为 `不宜粗估，需直除或精算` 或 `数据不足，待核验`。发生标签与依据冲突时，**改标签，不改事实依据**；不得为了保住 `可快速定位` 而弱化、删除或粉饰选项差距/数据风险。
- **小间距硬边界**：最接近两个选项的比例差距 `<5%` 时，第 3 项直接标 `不宜粗估，需直除或精算`。可以用高精度直除或精确反乘验证加快计算，但不得把这种精算路径标成 `可快速定位`。
- **速算卡识别**：方法卡标题或字段含 `速算`、`估算`、`截位`、`直除`、`百化分`、`尾数`、`放缩`、`首数`、`口算`、`选项差距`、`误差控制`、`图形题必估`、`增长量比较`、`两期比重差`、`415/份数` 等信号，或步骤逻辑明确要求用近似、比较、选项间距控精度时，视为速算/估算卡。命中此类卡时，输出里必须点明“本题使用/不使用该速算方法的理由”。
- 资料分析属于客观可验证题：题面数据、单位、年份、主体完整且可独立计算时，可以明确判定用户答案对错并写错因；若依赖低置信 OCR、材料/选项/答案页不完整，或计算条件无法核验，只能写“待核验/需补充材料”，不得硬判对错、不得写错因卡或更新弱点档案。
- **结论前复核**：先完成全部同口径计算、方向检查和必要反算，再填写“答案来源与结论”并判断是否与给定答案冲突。中间草算、临时排序或尚未完成的冲突不得进入用户可见输出；最终复核已自行纠正时，只输出最终结果，不启动答案冲突流程。
- 复核结果与用户给的参考/粉笔/官方答案冲突时，立即停止普通模板并读 `references/protocols/answer-authority.md` 的客观题冲突流程。
- 必须区分”方法依据”和”当前题推理”；没有 `source anchor（card id/文件名）` 时，不得把模型推理说成公考复盘原方法。
- 完整讲解结束后仅在满足写回条件时按 `references/review-engine/复盘引擎说明.md` 写回。

## 方法库使用（讲解/解法的第一动作，必做，不是可选检索）

讲解或解法时，**第一步动作就是定位资料分析公式卡 + AdvancedMethods 高频卡并读取**，不要先读综述、不要等“用户要检索”。

1. **DataNotes 公式卡路径固定**：资料分析专项只存在 `references/method-libraries/data-notes/按题型索引.md` 与 `references/method-libraries/data-notes/方法卡/*.md`；不得尝试读取不存在的 `references/method-libraries/data-notes/资料分析.md`。识别出下列子题型时，先直接读对应 DataNotes 公式卡，再继续读 AdvancedMethods 高频卡：基期量→`方法卡/基期量.md`，现期量→`方法卡/现期量.md`，增长量→`方法卡/增长量.md`，一般增长率→`方法卡/一般增长率.md`，间隔增长率→`方法卡/间隔增长率.md`，混合增长率→`方法卡/混合增长率.md`，比重→`方法卡/比重.md`，平均数→`方法卡/平均数.md`，倍数与比例→`方法卡/倍数与比例.md`，年均增长率→`方法卡/年均增长率.md`。

2. **再按下表内联导航直接定位 AdvancedMethods 高频卡**：识别子题型后，直接读对应的 `方法卡/am-card-*.md`（相对 `advanced-methods/`，保留 `方法卡/` 前缀，不要拼成裸卡名）。

   | 子题型 | 必读方法卡 |
   |---|---|
   | 两期比重差 | `方法卡/am-card-0338_两期比重差公式.md` |
   | 增长量比较/排序 | `方法卡/am-card-0004_增长量比较.md` |
   | 饼图/占比 | `方法卡/am-card-0832_饼状图三原则.md` |
   | 图形题（柱状/估算） | `方法卡/am-card-0520_图形题必估.md` |
   | 混合增长率/总量合并 | `方法卡/am-card-0135_加法等于混合增长率.md` |
   | 综合分析（可推出项） | `方法卡/am-card-0116_综合分析选项预设.md` |

   通用补充卡（按需读取，不替代上表）：
   - 所有题型的读题定位流程：`方法卡/am-card-1113_资料分析读题定位总纲.md`
   - 计算前的速算判定与精度选择：`方法卡/am-card-1114_资料分析速算判定与估算边界.md`
   - 比较/排序类题的优先路径：`方法卡/am-card-1115_资料分析比较类题优先路径.md`
   - 做错后的错因归因诊断：`方法卡/am-card-1116_资料分析常见错因诊断卡.md`

3. 表里没有对应子题型时，再读 `references/method-libraries/advanced-methods/按题型索引/资料分析.md`，按关键词找 1-3 张候选卡，按其 `方法卡/am-card-*.md` 相对路径读取。
4. 读完高频卡后，再读 `references/method-libraries/gongkao-review/资料分析.md` 与 `资料分析技巧索引.md` 作**综述补充**（仅补充，不作为第一入口）。
5. 只要输出“用户答案处理/易错点/错因分析/复盘动作/弱点标签”，必须先读通用补充卡 `方法卡/am-card-1116_资料分析常见错因诊断卡.md`；未读前只能讲公式和计算过程，不得把错因归为“主体错位/公式选错/估算越界/单位年份错看”等具体标签。回答优先给：题型识别、速算判定、公式/估算路径、陷阱、复盘动作；用户给新题时把计算假设写清楚。
6. **只有在第 1、2、3 步都真读过、确无同构卡时**，才可写“方法库无直接同构案例”。方法依据写具体 card id，引用 source anchor，不长贴原文。

## 质量规则

- OCR 数字需谨慎，但不是一律不可用；若截图 OCR 的主体、年份、单位和选项与讲解主题吻合，可作为低/中置信题面候选使用，并标注“数字据 OCR，需人工核对”。
- 资料分析计算若依赖 OCR 数字，必须写出误差边界；遇到主体、年份、单位不一致时，不得继续硬算。
- 题库导入和错题复测使用同一门禁：纯文字材料或已完整、可核验地转成 Markdown 表格的资料题可入库/复测；柱状图、折线图、饼图等复杂图表的数据、标签、图例、年份、单位、题干或选项任一缺失/未识别/使用问号占位时，不建立题块并在导入报告说明跳过；已有残缺记录不复测原题，改考关联方法。不得用不完整 OCR 文字冒充原题。
- 原库里的材料错位时，只沉淀讲解方法，不生成完整题卡。

## 常用问法

- “公考复盘资料分析增长率怎么速算？”
- “这道比重比较题用公考复盘方法怎么定位材料？”
- “我资料分析老超时，按公考复盘策略哪些题该估算？”

## 输出模板

1. 题型识别：<增长率/增长量/比重/平均数/倍数/基期/现期 + 触发词>
2. 答案来源与结论：<独立复核结果及是否与给定答案一致>
3. 速算判定：<可快速定位 / 不宜粗估，需直除或精算 / 数据不足，待核验 + 预计用时区间 + 关键步骤数 + 模型推理风险 + 是否值得做>
4. 当前题推理：<公式、代入、速算/精算路径、估算假设与误差边界>
5. 用户答案处理：<明确用户答案及具体偏差；无用户答案时省略>
6. 方法讲解与速度评估：<为什么用、怎么做、先看什么、何时停 + 预计用时区间、关键步骤数、模型推理风险、是否值得做 + 方法来源 card id/文件名>
7. 易错点 / 复盘动作：<单位、年份、主体、精度和下次固定动作>
8. 写回回执：<仅满足写回条件且实际写盘并验证文件存在后才写“已落盘”；未写成功就报告失败路径>
