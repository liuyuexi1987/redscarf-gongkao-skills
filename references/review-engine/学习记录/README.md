# 学习记录

学习记录用来保存会影响后续教学的真实学习证据，包括主动提问、已验证理解、批改和阶段成绩。

运行目录默认只放模板。用户运行态可生成普通学习记录，以及一份轻量的 `待巩固队列.md`。

## 命名

```text
0001-短标题.md
0002-短标题.md
```

## 什么时候写

- 用户针对具体行测题、考点或方法主动要求讲解/复盘：更新待巩固队列，表示“问过、尚待确认掌握”，不表示答错。
- 用户展示了非平凡理解，能正确使用某个方法或概念。
- 用户纠正了一个重要误区。
- 用户披露了会影响后续教学的先验知识。
- 用户的备考目标或阶段任务发生变化。

## 不写什么

- 不记录“今天讲了什么”的流水账。
- 不把刚覆盖过的知识点当成已经掌握。
- 不重复错因卡里已经足够清楚的事实。
- 不把主动提问次数写成错误次数，也不因队列复习未通过而创建真题错因。

## 模板

```md
# {短标题}

{1-3 句话：用户证明掌握/纠正/披露了什么，以及这对后续复盘难度有什么影响。}

## Evidence

- {用户回答、错因卡或复习表现的可追溯证据}
```
