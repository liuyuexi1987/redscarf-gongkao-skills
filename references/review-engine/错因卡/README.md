# 错因卡

事件层：每道错题一张 Markdown 卡片。运行目录默认只放本 README 与 `错因卡-template.md`。

命名：

```text
YYYY-MM-DD-模块-题型-短标题.md
```

模板（同 `错因卡-template.md`）：

```yaml
---
题型:
来源:
我的答案:
正确答案:
错在哪一步:
正确方法:
方法依据:
  source_quote:        # 内部核验用，默认不展示给用户
  时间戳:
关联弱点档案:           # 模块-题型-核心考点，链接到 ../弱点档案/
难度档: 基础            # 基础 / 中等变式 / 进阶
掌握程度: 待复习
上次复习:
下次复习:
复习次数: 0
---
```

掌握程度只使用：

- `待复习`
- `巩固中`
- `已掌握`
