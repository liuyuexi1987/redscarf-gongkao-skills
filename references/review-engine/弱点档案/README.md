# 弱点档案

知识点层：把同一考点的反复错误聚合起来，驱动后续出题难度与考点选择。

## 聚合 key 与命名

文件名 = 唯一 key = `模块-题型-核心考点`，例如：

```text
资料分析-增长-间隔增长率.md
```

- 核心考点必须取规范名，优先复用方法库 `按题型索引.md` 中的标准考点名。
- 禁止同义异写各立一档（如“间隔增长率 / 隔年增长率 / R=r1+r2+r1r2”）。
- 新建前先按 key 检索近义档案；命中则并入既有档案，同义写法记入 `别名` 字段。

运行目录默认只放本 README 与 `弱点档案-template.md`。

## 字段说明

模板见 `弱点档案-template.md`。`难度档` 取 `基础 / 中等变式 / 进阶`，用于「考我/复盘」开场决定本次难度。`掌握判定` 取 `未掌握 / 巩固中 / 已掌握`；只有满足《复盘引擎说明 · 确认掌握判定》才可升到“已掌握”并回流速查卡。
