# 词义辨析补救库

这是词义/成语/实词辨析的补救资源入口。公开包不内置正文；用户可把自备词义辨析材料整理到 `groups/`，或按模板导入。

## 定位

- 用于逻辑填空、成语辨析、实词辨析的错后补救。
- 用于“考我”时的词义差异小测、搭配判断、语义轻重判断。
- 用于学习者画像中记录反复混淆的词组。
- 不作为自动判题题库，不作为“方法依据”。

## 自动使用规则

用户不需要记住或输入任何额外命令。本库只由智能体在主流程中自动使用：

1. 用户说“复盘”“讲解”“考我”时，如果题型或错因涉及近义词、成语、词语搭配、褒贬色彩、语义轻重，智能体自动检索本库。
2. 复盘/解法输出中，如确有命中词条，可追加一个很短的“词语辨析”小节，并展示相关词条原文。
3. 若本库词条与题目语境不完全匹配，应标注“仅作词义提示”，不要强行套用。
4. 若要解释完整解题流程，仍调用包内 `references/method-libraries/综合方法库.md`。
