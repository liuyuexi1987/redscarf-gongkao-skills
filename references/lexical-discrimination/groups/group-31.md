# 词义辨析补救库 第 31 组

用途: 近义词、成语、实词辨析；不作为方法库依据；不用于自动判题。

## 词组辨析

| 词组 | 辨析要点 |
|---|---|
| 从谏如流 | 乐于接受下级或晚辈的劝告（“谏”指下对上、晚辈对长辈的规劝），强调接受意见的顺畅 |
| 从善如流 | 迅速接受别人正确的意见，强调接受的及时与对象为好意见 |
| 闻过则喜 | 听到别人指出自己过失就高兴，强调对批评的欢迎态度 |
| 虚怀若谷 | 胸怀像山谷般深广，强调谦虚而能容纳 |
| 文过饰非 | 用言辞掩饰自己的过失，强调掩饰的手法 |
| 怙恶不悛 | 坚持作恶不肯悔改，强调恶行延续与拒不悔改 |
| 欲盖弥彰 | 本想掩盖反而更显露，强调掩盖反而暴露 |
| 刚愎自用 | 固执自信、独断专行，强调不接受他人意见 |
| 固执己见 | 顽固坚持自己的意见，强调态度的执拗 |
| 洗心革面 | 多用于坏人或罪犯悔改自新，强调主体的彻底转变 |
| 脱胎换骨 | 彻底改变、本质转变，强调变化的根本性 |
| 改头换面 | 只改外表不变实质，多含贬义，强调表面改动而内容未变 |

## 使用边界

- 在复盘、解法或考我流程中自动用于词语辨析补充、同义词对比、搭配提醒。
- 不写作“方法依据”，不冒充方法库方法。
- 如果需要讲解解题流程，仍应调用综合方法库。
