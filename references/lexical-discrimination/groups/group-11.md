# 词义辨析补救库 第 11 组

用途: 近义词、成语、实词辨析；不作为方法库依据；不用于自动判题。

## 词组辨析

| 词组 | 辨析要点 |
|---|---|
| 力有未逮 | 指能力达不到要求，强调能力不足。 |
| 爱莫能助 | 指心里愿意帮助却无能为力，强调主观意愿与客观能力的落差。 |
| 鞭长莫及 | 侧重因距离远而力量达不到，强调空间距离。 |
| 望洋兴叹 | 侧重因能力不足或条件缺乏而感到无奈，强调叹息之情。 |
| 回天乏术 | 指局势或病情严重到无法挽回，强调无可奈何。 |
| 捉襟见肘 | 侧重资金、物资等不足而顾此失彼，强调短缺困难。 |
| 顾此失彼 | 指顾全这方却失去那方，强调忙乱中难以兼顾。 |
| 左支右绌 | 指应付了这头却困于那头，强调力量不足、难以支撑，多用于做事的人。 |
| 独木难支 | 指单独一人或一方力量难以支撑全局，强调孤立无援。 |
| 应接不暇 | 形容来人或事物太多而接待应付不过来，主语多为人。 |

## 使用边界

- 在复盘、解法或考我流程中自动用于词语辨析补充、同义词对比、搭配提醒。
- 不写作“方法依据”，不冒充方法库方法。
- 如果需要讲解解题流程，仍应调用综合方法库。
