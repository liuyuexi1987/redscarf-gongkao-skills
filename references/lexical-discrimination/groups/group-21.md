# 词义辨析补救库 第 21 组

用途: 近义词、成语、实词辨析；不作为方法库依据；不用于自动判题。

## 词组辨析

| 词组 | 辨析要点 |
|---|---|
| 画地为牢 | 在地上画圈当监狱，比喻只许在指定范围内活动，强调自我设限或被限制在小圈子里。 |
| 以邻为壑 | 拿邻国当排水沟，比喻把灾祸或困难转嫁给别人，含贬义，强调"转嫁"的恶意。 |
| 穿凿附会 | 把不相干的事物硬凑在一起作出牵强解释，强调解释的生硬不合理，含贬义。 |
| 亦步亦趋 | 别人走也跟着走，别人跑也跟着跑，比喻缺乏主见、盲目追随模仿，含贬义。 |
| 唯利是图 | 只贪图利益、不顾其他，强调逐利的极致，含贬义。 |
| 隔岸观火 | 隔着河看对岸着火，比喻对别人的危难不去救助，反而看热闹，含贬义，强调外部已有危险或冲突的情境。 |
| 置身事外 | 把自己放在事情之外，指对事情不闻不问、不尽责，多用于本应承担责任的情境，常涉及大事或国与国之间。 |
| 袖手旁观 | 缩手在袖子里旁观，比喻对事情不参与、不帮助，多用于小事或本无责任的情境。 |
| 作壁上观 | 在壁垒上看别人交战，比喻坐观双方成败、不表态不站队，多为中性。 |
| 坐收渔利 | 比喻利用别人之间的矛盾而获取利益，强调第三方身份的获利。 |
| 坐享其成 | 自己不出力而享受别人劳动的成果，强调"不付出而得利"。 |
| 竭泽而渔 | 排干池水捕鱼，比喻只图眼前利益而不做长远打算，多用于经济、资源开发语境，含贬义。 |
| 杀鸡取卵 | 比喻贪图眼前微小利益而损害长远的根本利益，与"竭泽而渔"近义，但更强调对"根本来源"的破坏。 |
| 寅吃卯粮 | 比喻入不敷出，预先支用未来的收入，多用于个人、政府或机构的财务透支。 |
| 饮鸩止渴 | 喝毒酒解渴，比喻用有害的方法解决眼前困难而不顾严重后果，强调方法的错误和危害性，含贬义。 |
| 急功近利 | 急于求成和贪图眼前利益，强调急于取得成功与名利的心态，含贬义。 |

## 使用边界

- 在复盘、解法或考我流程中自动用于词语辨析补充、同义词对比、搭配提醒。
- 不写作"方法依据"，不冒充方法库方法。
- 如果需要讲解解题流程，仍应调用综合方法库。
