# 词义辨析补救库 第 35 组

用途: 近义词、成语、实词辨析；不作为方法库依据；不用于自动判题。

## 词组辨析

| 词组 | 辨析要点 |
|---|---|
| 未雨绸缪 | 比喻事先做好准备，强调防患于未然 |

| 防患未然 | 在灾害事故发生前就采取防备措施 |
| 防微杜渐 | 在苗头出现时就制止，不让其发展扩大 |
| 居安思危 | 处于安全时想到可能出现的危险 |
| 曲突徙薪 | 比喻事先采取措施消除隐患 |
| 高枕无忧 | 垫高枕头无忧无虑，强调平安无事 |
| 临渴掘井 | 口渴才挖井，比喻事前无准备临时应付 |
| 江心补漏 | 船到江心才补漏洞，比喻补救已迟 |
| 亡羊补牢 | 丢羊后修补羊圈，比喻出问题后及时补救 |
