# 词义辨析补救库 第 30 组

用途: 近义词、成语、实词辨析；不作为方法库依据；不用于自动判题。

## 词组辨析

| 词组 | 辨析要点 |
|---|---|
| 好高骛远 | 追求过高目标而脱离实际，强调不切实际的心态 |
| 好大喜功 | 一味追求大功绩、显赫政绩，常用于形容主政者浮夸不实 |
| 沽名钓誉 | 用不正当手段谋取名誉为己有，强调手段的不正当与目的的虚荣 |
| 附庸风雅 | 本身不具备而硬装出文化素养的样子，强调装点门面 |
| 独善其身 | 原指在不得志时修养自身，现代语境也可指只顾自己、不管他人；褒贬要结合上下文。 |
| 明哲保身 | 为保自身而回避是非、不担责任，强调因怕受牵累而处事圆滑 |
| 虚与委蛇 | 对人虚情假意地敷衍，强调待人态度的虚伪 |
| 委曲求全 | 为顾全大局而暂时忍让，强调让步的目的性 |
| 敷衍塞责 | 做事不认真、应付了事，强调对责任的搪塞 |
| 曲意逢迎 | 违背本心去迎合他人，强调为讨好而扭曲自己 |
| 投其所好 | 迎合对方的喜好以取得好感，实际使用中常含贬义；是否贬义仍需结合行为目的和上下文。 |
| 阿谀奉承 | 用好话讨好他人，强调谄媚的程度 |
| 趋炎附势 | 奉承依附有权势的人，强调势利与依附对象 |
| 如蚁附膻 | 比喻许多人依附有势力的人，强调依附者的众多与势利 |
| 兴师动众 | 发动大批人力做某事，强调人多与阵仗 |
| 劳民伤财 | 既耗费人力又浪费财力，强调对民力的双重损耗 |
| 朝令夕改 | 早晨下令晚上就改，强调政令朝出夕改缺乏稳定性 |
| 粗枝大叶 | 做事不细致、马虎草率，强调不严谨 |
| 大而化之 | 做事粗疏、不注意细节，强调概括笼统而失之粗略 |
| 具体而微 | 整体规模小但各部分齐全，强调内容完整而形体小 |
| 哗众取宠 | 用浮夸言行为取悦众人以博取好感，强调手段的浮夸与目的的虚荣 |
| 凌空蹈虚 | 脱离实际、空泛不实，强调言辞或构想缺乏根基 |

## 使用边界

- 在复盘、解法或考我流程中自动用于词语辨析补充、同义词对比、搭配提醒。
- 不写作“方法依据”，不冒充方法库方法。
- 如果需要讲解解题流程，仍应调用综合方法库。
