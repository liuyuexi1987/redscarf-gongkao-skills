# 词义辨析补救库 第 45 组

用途: 近义词、成语、实词辨析；不作为方法库依据；不用于自动判题。

## 词组辨析

| 词组 | 辨析要点 |
|---|---|
| 视而不见 | 指虽然看到却当作没看到，侧重不注意或不重视。 |
| 置若罔闻 | 指放在一边好像没听到，侧重不予理会，多用于投诉、劝告。 |
| 熟视无睹 | 指看惯了某事物而漠不关心，侧重长期见惯后的忽视。 |
| 闭目塞听 | 指不与外界交流，对外界事物不闻不问。 |
| 充耳不闻 | 指故意不听别人的话，多用于劝解、意见。 |
| 置之不理 | 指放在一边不予理睬，侧重不予回应。 |
| 嗤之以鼻 | 表示轻蔑、看不起，用鼻音冷笑。 |
| 视如敝屣 | 比喻极度轻视，像对待破鞋一样不屑一顾。 |
| 不屑一顾 | 指认为不值得重视，轻视而不愿关注。 |
| 束之高阁 | 比喻把东西放着不用、不施展。 |
| 爱不释手 | 形容非常喜爱某物，舍不得放下。 |
| 手不释卷 | 形容勤于读书、喜爱读书。 |
| 视若珍宝 | 指把某物当作珍宝一样珍爱，不强调拿在手中。 |
| 奉为圭臬 | 指把某种道理、言论当作准则来尊奉。 |
| 举足轻重 | 指所处地位重要，一举一动关系到全局。 |
| 无足轻重 | 指无关紧要，不影响全局。 |
| 细枝末节 | 指事情或问题中无关紧要的部分，侧重局部、次要。 |
| 举重若轻 | 形容胜任繁重事务而显得轻松，侧重能力强大、应付自如。 |

## 使用边界

- 在复盘、解法或考我流程中自动用于词语辨析补充、同义词对比、搭配提醒。
- 不写作"方法依据"，不冒充方法库方法。
- 如果需要讲解解题流程，仍应调用综合方法库。
