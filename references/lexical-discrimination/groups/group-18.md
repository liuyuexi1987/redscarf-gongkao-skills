# 词义辨析补救库 第 18 组

用途: 近义词、成语、实词辨析；不作为方法库依据；不用于自动判题。

## 词组辨析

| 词组 | 辨析要点 |
|---|---|
| 如履薄冰 | 形容做事极为小心谨慎，像走在薄冰上一样，强调戒惧心态，多用于责任重大或风险高的情境。 |
| 兢兢业业 | 形容做事小心谨慎、认真负责，多用于日常工作、本职岗位的长期态度，重在"敬业"。 |
| 殚精竭虑 | 用尽精力、费尽心思，多用于脑力劳动，强调谋划、思考、布局上的全心投入。 |
| 呕心沥血 | 形容费尽心血，多用于创作、研究或长期投入的事业；“殚精竭虑”更侧重用尽心思、反复谋划。 |
| 苦心孤诣 | 苦心钻研并达到他人难以企及的境界，强调钻研、经营的费心与独特成就，含褒义。 |
| 废寝忘食 | 形容专心努力，顾不得睡觉、吃饭，多用于短期内刻苦投入的情境，强调时间集中。 |
| 皓首穷经 | 一直到头发白了仍在研读经书，形容终生勤学不辍，多用于学术、经典研读的长期投入。 |
| 心无旁骛 | 心思集中、没有其他杂念，强调注意力专注、不分心，可用于学习、工作、创作等多种情境。 |
| 乐此不疲 | 因喜欢做某事而不知疲倦，强调主观兴趣驱动下的持续投入，重在"乐"的内在驱动。 |
| 挖空心思 | 贬义。形容费尽心机、想方设法，多用于谋划不好的事，与"殚精竭虑"感情色彩相反。 |
| 夜以继日 | 形容日夜不停地工作或学习，强调时间投入的连续性，适用范围较广。 |
| 焚膏继晷 | 点起油灯接续日光，形容夜以继日地学习或工作，多用于学业、研读，语域较书面。 |
| 夙兴夜寐 | 早起晚睡，形容终日勤劳，适用范围较广，可用于多种勤勉情境，偏书面。 |
| 目不窥园 | 形容专心致志于学习，对外界事物不关注，多用于学业、研读的专注状态。 |
| 栉风沐雨 | 褒义。形容人经常在外面不避风雨地辛苦奔波，多用于实地工作、出差、考察等情境。 |
| 风餐露宿 | 在风里吃饭、露天睡觉，形容旅途或野外工作辛苦，重在客观条件艰苦，不带褒贬。 |
| 筚路蓝缕 | 形容创业的艰辛，强调从无到有开创事业的困难，多用于国家、企业、事业的初创阶段，含褒义。 |
| 披星戴月 | 身披星光月色，形容早出晚归或连夜赶路，强调时间上的辛苦奔波。 |
| 摩顶放踵 | 从头顶到脚跟都磨破，形容不惜牺牲自己、不辞劳苦，多用于为他人或理想奔走的情境。 |
| 胼手胝足 | 手脚磨出老茧，形容长期辛勤劳作，多用于体力劳动或长期艰苦奋斗，含褒义。 |
| 孜孜不倦 | 勤奋努力、不知疲倦，多用于学习、工作等持续投入的情境，重在"勤奋"的状态。 |
| 孜孜以求 | 不知疲倦地探求，比"孜孜不倦"多一层"探求"的目标方向，多用于研究、追问、求索。 |

## 使用边界

- 在复盘、解法或考我流程中自动用于词语辨析补充、同义词对比、搭配提醒。
- 不写作"方法依据"，不冒充方法库方法。
- 如果需要讲解解题流程，仍应调用综合方法库。
