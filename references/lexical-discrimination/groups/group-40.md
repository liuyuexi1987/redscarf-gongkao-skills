# 词义辨析补救库 第 40 组

用途: 近义词、成语、实词辨析；不作为方法库依据；不用于自动判题。

## 词组辨析

| 词组 | 辨析要点 |
|---|---|
| 参差不齐 | 长短高低大小不齐，形容水平或质量不一致 |
| 泥沙俱下 | 泥土沙子一同流下，比喻好坏不同的人或物混杂出现 |
| 良莠不齐 | 好人坏人混杂，强调品质好坏不齐 |
| 鱼龙混杂 | 好人坏人混在一起，强调混杂状态 |
| 鱼目混珠 | 拿鱼眼睛冒充珍珠，比喻以假充真 |
| 滥竽充数 | 没真本事的人混在行家里充数，比喻冒充凑数 |
| 买椟还珠 | 买下木匣退还珍珠，比喻没有眼光取舍失当 |

## 使用边界

- 在复盘、解法或考我流程中自动用于词语辨析补充、同义词对比、搭配提醒。
- 不写作“方法依据”，不冒充方法库方法。
- 如果需要讲解解题流程，仍应调用综合方法库。
