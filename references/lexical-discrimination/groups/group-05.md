# 词义辨析补救库 第 05 组

用途: 近义词、成语、实词辨析；不作为方法库依据；不用于自动判题。

## 词组辨析

| 词组 | 辨析要点 |
|---|---|
| 墨守成规 | 贬义，侧重拘守旧规矩、旧方法，不肯改变。 |
| 抱残守缺 | 贬义，侧重守着残破、残缺的事物不肯舍弃，强调保守固执。 |
| 因循守旧 | 贬义，侧重沿袭旧制度旧做法，不愿变革。 |
| 固步自封 | 贬义，侧重主观上安于现状、不愿进取，自我局限。 |
| 食古不化 | 贬义，侧重学习古法或前人言论但不能融会运用。 |

## 使用边界

- 在复盘、解法或考我流程中自动用于词语辨析补充、同义词对比、搭配提醒。
- 不写作“方法依据”，不冒充方法库方法。
- 如果需要讲解解题流程，仍应调用综合方法库。
