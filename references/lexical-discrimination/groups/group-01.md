# 词义辨析补救库 第 01 组

用途: 近义词、成语、实词辨析；不作为方法库依据；不用于自动判题。

## 词组辨析

| 词组 | 辨析要点 |
|---|---|
| 源远流长 | 侧重历史悠久，时间维度长，强调源头远、流传久。 |
| 连绵不绝 | 侧重连续不中断，强调事物接连不断。 |
| 博大精深 | 侧重内容丰富、理论深奥，多形容文化、思想、学问。 |
| 历久弥新 | 侧重经历长时间仍保持价值或更显价值，强调时间越久越有生命力。 |
| 兼收并蓄 | 侧重胸怀开放，把不同内容收纳并存。 |

## 使用边界

- 在复盘、解法或考我流程中自动用于词语辨析补充、同义词对比、搭配提醒。
- 不写作“方法依据”，不冒充方法库方法。
- 如果需要讲解解题流程，仍应调用综合方法库。
