# 词义辨析补救库 第 15 组

用途: 近义词、成语、实词辨析；不作为方法库依据；不用于自动判题。

## 词组辨析

| 词组 | 辨析要点 |
|---|---|
| 本末倒置 | 侧重把主次、轻重颠倒，强调顺序错误而非舍弃根本。 |
| 舍本逐末 | 侧重舍弃根本而追求枝节，强调动作的取舍错误。 |
| 喧宾夺主 | 侧重次要者占了主要者的地位，强调主次关系颠倒。 |
| 因小失大 | 指为了小利益而造成大损失，强调损失与利益的不成比例；与“得不偿失”相比更侧重因小失大而非付出回报。 |
| 因噎废食 | 指因小问题或偶发事故就全面停止本应做的事，强调一刀切式的过度规避。 |
| 背道而驰 | 指行动方向与目的相反，强调背离初衷，多主体各自方向相反。 |
| 南辕北辙 | 指行动方向与目的地相反，强调同一主体的方向错误。 |
| 分道扬镳 | 指原本同行的人因志趣不同而各走各路，强调分裂、分别。 |
| 缘木求鱼 | 指方法方向错误，不可能达到目的，强调方法与目标的背离。 |

## 使用边界

- 在复盘、解法或考我流程中自动用于词语辨析补充、同义词对比、搭配提醒。
- 不写作“方法依据”，不冒充方法库方法。
- 如果需要讲解解题流程，仍应调用综合方法库。
