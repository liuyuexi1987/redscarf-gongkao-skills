# 词义辨析补救库 第 22 组

用途: 近义词、成语、实词辨析；不作为方法库依据；不用于自动判题。

## 词组辨析

| 词组 | 辨析要点 |
|---|---|
| 颠沛流离 | 形容生活艰难、四处流浪，强调长期的困苦状态，多用于战乱、灾荒语境。 |
| 流离失所 | 失去住所、四处流浪，强调"失去安身之处"的结果，可用于人或动物。 |
| 背井离乡 | 离开家乡到外地去，可主动可被动，重在"离开故土"的事实，不带明显褒贬。 |
| 安居乐业 | 安定地生活、愉快地工作，多用于描述百姓、民众的生活状态，含褒义。 |
| 海晏河清 | 黄河水清、海波不兴，比喻太平盛世、政治清明，多用于国家层面的安定局面。 |
| 国泰民安 | 国家太平、人民安乐，强调国家与百姓双重层面的安定，使用范围比"海晏河清"更宽。 |
| 安土重迁 | 习惯于故土生活、不愿轻易迁徙，多形容农耕文化中的人，与游牧民族"逐水草而居"的习惯形成对比，重在"留恋故土"。 |

## 使用边界

- 在复盘、解法或考我流程中自动用于词语辨析补充、同义词对比、搭配提醒。
- 不写作"方法依据"，不冒充方法库方法。
- 如果需要讲解解题流程，仍应调用综合方法库。
