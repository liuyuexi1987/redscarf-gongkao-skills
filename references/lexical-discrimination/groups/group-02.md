# 词义辨析补救库 第 02 组

用途: 近义词、成语、实词辨析；不作为方法库依据；不用于自动判题。

## 词组辨析

| 词组 | 辨析要点 |
|---|---|
| 一脉相承 | 侧重纵向时间传承，强调前后派别、思想、血脉的承接关系。 |
| 血脉相通 | 侧重横向关系，强调同类同源之间的内在联系。 |
| 薪火相传 | 侧重学问、技艺、精神在代与代之间传递延续。 |
| 不绝如缕 | 侧重虽微弱但未断绝，多形容局势、声音、传统等。 |
| 陈陈相因 | 贬义，侧重因袭旧规、缺乏创新，多指制度、做法沿袭而无改进。 |
| 口耳相传 | 侧重传授方式为口说耳听，不借助文字记载。 |
| 难以为继 | 侧重无法再继续维持，多用于生活、经营、事业等难以延续。 |
| 后继无人 | 侧重没有继承人，强调承接者缺失。 |
| 继往开来 | 侧重承前与启后兼具，既有继承又有开创。 |
| 承上启下 | 侧重过渡连接，承接上文或前段并引出下文或后段。 |

## 使用边界

- 在复盘、解法或考我流程中自动用于词语辨析补充、同义词对比、搭配提醒。
- 不写作“方法依据”，不冒充方法库方法。
- 如果需要讲解解题流程，仍应调用综合方法库。
