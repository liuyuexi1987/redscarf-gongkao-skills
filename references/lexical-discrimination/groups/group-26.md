# 词义辨析补救库 第 26 组

用途: 近义词、成语、实词辨析；不作为方法库依据；不用于自动判题。

## 词组辨析

| 词组 | 辨析要点 |
|---|---|
| 立竿见影 | 实施后立刻见到效果，强调见效之快 |
| 一劳永逸 | 一次劳作即可长久受益，强调一次性解决后无需重复 |
| 行之有效 | 实施后已被证明有效，强调有实践验证的支持 |
| 一蹴而就 | 一步即可成功，常用于否定句，强调难以速成 |
| 迎刃而解 | 关键问题解决后其他问题随之解决，强调主因被攻克后的连锁效应 |
| 事半功倍 | 用力少而成效大，强调投入产出比的高效 |
| 釜底抽薪 | 从根源处着手处理，强调彻底消除问题产生的源头 |
| 标本兼治 | 表面症状与根本原因同时处理，强调治理的全面性 |

## 使用边界

- 在复盘、解法或考我流程中自动用于词语辨析补充、同义词对比、搭配提醒。
- 不写作“方法依据”，不冒充方法库方法。
- 如果需要讲解解题流程，仍应调用综合方法库。
