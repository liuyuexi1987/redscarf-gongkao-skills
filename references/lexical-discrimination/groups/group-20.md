# 词义辨析补救库 第 20 组

用途: 近义词、成语、实词辨析；不作为方法库依据；不用于自动判题。

## 词组辨析

| 词组 | 辨析要点 |
|---|---|
| 过犹不及 | 事情做得过头和做得不够一样不好，强调适度，重点在于批评"过头"的一面。 |
| 矫枉过正 | 纠正错误超过了应有的限度，反而引发新的问题，强调纠正过程中的失度。 |
| 于事无补 | 对事情没有帮助，强调措施、办法无法改变结果，多用于事后补救无效的情境。 |
| 作茧自缚 | 比喻自己做的事反而使自己受困，强调自陷其累，含贬义。 |
| 扬汤止沸 | 把锅里的水舀起来再倒回去以止沸腾，比喻办法不彻底，只能暂时缓解而不能从根本上解决问题，与"釜底抽薪"形成对照（"釜底抽薪"指从根本上解决）。 |
| 隔靴搔痒 | 比喻做事没有抓住关键，达不到效果，强调办法的无效性。 |
| 临渊羡鱼 | 站在水边希望得到鱼，比喻只有愿望而没有实际行动，强调空想无益。 |
| 有恃无恐 | 因为有所依仗而不害怕，多含贬义，强调凭借某种依托而放胆妄为。 |
| 堂而皇之 | 形容公开或毫不掩饰地做某事，多含贬义，强调表面理直气壮、毫不避讳。与"冠冕堂皇"近义，但"冠冕堂皇"侧重言辞、理由的貌似正当，需分别判别。 |
| 明目张胆 | 形容公开地、毫无顾忌地做坏事，强调公开和无畏，含贬义。 |

## 使用边界

- 在复盘、解法或考我流程中自动用于词语辨析补充、同义词对比、搭配提醒。
- 不写作"方法依据"，不冒充方法库方法。
- 如果需要讲解解题流程，仍应调用综合方法库。
