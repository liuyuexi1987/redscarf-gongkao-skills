# 词义辨析补救库 第 42 组

用途: 近义词、成语、实词辨析；不作为方法库依据；不用于自动判题。

## 词组辨析

| 词组 | 辨析要点 |
|---|---|
| 以讹传讹 | 把本来不正确的话又错误地传播开来，侧重谣言的链式传播。 |
| 无孔不入 | 比喻有空子就钻，形容分布极广，多用于贬义，常搭配谣言、病毒、歪风、广告。 |
| 铺天盖地 | 形容声势大、来势猛或数量多、范围广，褒贬由搭配对象和语境决定。 |
| 道听途说 | 指没有根据地听到后又传播，侧重消息来源不可靠；“捕风捉影”更强调依据不足、凭空臆测。 |
| 街头巷议 | 指民间的流言议论，侧重群众在街头巷尾的议论。 |
| 稗官野史 | 指非正式的史料记载，多为轶闻趣事、零散片段。 |
| 脍炙人口 | 形容诗文、歌曲、作品受人喜爱、流传广，侧重作品本身质量高；与"喜闻乐见"相比，后者侧重大众接受度。 |
| 津津乐道 | 形容很有兴趣地谈论，侧重对某话题感兴趣而乐于讨论，常搭配明星、趣事。 |
| 喜闻乐见 | 形容大众愿意听、愿意看，侧重大众接受度高。 |
| 深入人心 | 形容思想、观念、道理、政策等被广泛认同，强调内化接受；与"家喻户晓"相比，后者仅强调知晓范围广。 |

## 使用边界

- 在复盘、解法或考我流程中自动用于词语辨析补充、同义词对比、搭配提醒。
- 不写作"方法依据"，不冒充方法库方法。
- 如果需要讲解解题流程，仍应调用综合方法库。
