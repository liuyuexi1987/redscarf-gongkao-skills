# 词义辨析补救库 第 09 组

用途: 近义词、成语、实词辨析；不作为方法库依据；不用于自动判题。

## 词组辨析

| 词组 | 辨析要点 |
|---|---|
| 层出不穷 | 侧重事物持续大量涌现，多用于新应用、新模式、新技术等，一般不用于人。 |
| 风起云涌 | 多作谓语，形容局势动荡、力量竞起，常修饰时代浪潮、国际形势或宏大运动。 |
| 方兴未艾 | 多作谓语，侧重新事物正在兴起且远未停止，强调发展过程尚未完结。 |
| 雨后春笋 | 比喻新事物大量、迅速地出现，常与“如”“般”搭配。 |
| 横空出世 | 形容事物突然出现且气势惊人，带有震撼感。 |
| 异军突起 | 比喻原本不起眼的力量突然崛起，在竞争格局中脱颖而出。 |
| 应运而生 | 侧重顺应时机而产生，强调条件成熟与出现时机相契合。 |
| 高歌猛进 | 形容情绪高昂、勇猛前进，侧重主观状态积极向上。 |
| 如火如荼 | 形容气氛热烈、声势浩大，常用于生产建设、运动展开等场景。 |
| 如日中天 | 侧重事物处于最兴盛、最强盛的阶段。 |
| 势如破竹 | 侧重节节胜利、毫无阻碍，常用于攻势、推进等。 |
| 突飞猛进 | 侧重进步、发展异常迅速，强调速度。 |
| 一日千里 | 多作谓语，侧重发展或进步极速，强调速度之快。 |
| 日新月异 | 侧重变化快且不断更新，强调新意。 |
| 日渐式微 | 侧重地位、影响力、规模等逐渐变弱而非变坏，强调存在感降低。 |
| 每况愈下 | 侧重状况、水平、质量持续变差，常形容成绩、健康、生活水准、口碑等。 |
| 江河日下 | 侧重大局、大势、国运、事业运等整体性衰落。 |
| 水涨船高 | 强调事物随其所凭借的基础一同提高，需有因果连带关系。 |
| 此消彼长 | 表示一方减少、另一方增加，强调彼此消长的对比关系。 |
| 波澜壮阔 | 形容规模宏大、气势磅礴，常用于发展史、运动、浪潮等。 |
| 柳暗花明 | 侧重在困境中出现转机，常用于事情出现新的出路。 |
| 拨云见日 | 侧重疑虑消除、方向明朗，常用于心理或局势层面。 |

## 使用边界

- 在复盘、解法或考我流程中自动用于词语辨析补充、同义词对比、搭配提醒。
- 不写作“方法依据”，不冒充方法库方法。
- 如果需要讲解解题流程，仍应调用综合方法库。
