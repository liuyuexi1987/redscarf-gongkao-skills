# 词义辨析补救库 第 43 组

用途: 近义词、成语、实词辨析；不作为方法库依据；不用于自动判题。

## 词组辨析

| 词组 | 辨析要点 |
|---|---|
| 烟消云散 | 形容事物全部消失，多用于情绪、烦恼、疑虑，少用于积极事物。 |
| 荡然无存 | 形容原有事物全部失去，带有惋惜意味，多用于昔日繁华、名声、风貌。 |
| 销声匿迹 | 形容隐藏起来不再露面，多用于人或事物从公众视野中消失。 |
| 灰飞烟灭 | 形容事物彻底消亡、不复存在。 |
| 化为乌有 | 形容全部丧失或变成没有，多用于努力、积蓄等付诸东流。 |
| 子虚乌有 | 指本来就不存在的事，侧重虚构、不真实。 |
| 稍纵即逝 | 形容时间或机会等极易消失，多用于机会、时机、灵感。 |
| 昙花一现 | 形容事物出现的时间极短，多用于美好的或显赫的事物、热度。 |
| 偃旗息鼓 | 指停止行动、暂停活动，侧重主动停下。 |
| 死灰复燃 | 比喻已经消失的坏事又重新出现，贬义，多用于歪风、陋习、隐患、旧势力。 |
| 卷土重来 | 指失败后重新恢复势力再来，多用于人、集团、对手，中性偏贬。 |
| 沉渣泛起 | 比喻腐朽、落后、丑恶的旧事物或旧思想重新出现，贬义。 |
| 东山再起 | 指失势后重新崛起，多用于人，中性偏褒。 |
| 重整旗鼓 | 指失败或受挫后整顿力量重新开始，中性偏褒。 |
| 土崩瓦解 | 形容彻底崩溃、垮台，多用于思想观念、集团、政权。 |
| 分崩离析 | 形容国家、政权、集体、组织、家庭等内部分裂瓦解。 |

## 使用边界

- 在复盘、解法或考我流程中自动用于词语辨析补充、同义词对比、搭配提醒。
- 不写作"方法依据"，不冒充方法库方法。
- 如果需要讲解解题流程，仍应调用综合方法库。
