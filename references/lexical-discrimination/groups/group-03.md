# 词义辨析补救库 第 03 组

用途: 近义词、成语、实词辨析；不作为方法库依据；不用于自动判题。

## 词组辨析

| 词组 | 辨析要点 |
|---|---|
| 推陈出新 | 侧重剔除旧事物中的糟粕并推出新成果，多用于文化、技艺、思想领域。 |
| 吐故纳新 | 侧重吸纳新生事物、排出陈旧事物，多用于组织、人员、制度的更新。 |
| 革故鼎新 | 侧重破除旧制、建立新制，强调变革力度大，多用于制度、文化层面。 |
| 弃旧图新 | 侧重舍弃旧路、谋求新路，强调方向上的转变。 |
| 去芜存菁 | 侧重筛选剔除糟粕、保留精华，强调去取过程。 |
| 除旧布新 | 侧重清除旧事物并安排新事物，多用于节令、风俗、政令更替。 |
| 激浊扬清 | 侧重抨击恶浊、弘扬清正，多用于风气、言论、政绩两方面并立。 |

## 使用边界

- 在复盘、解法或考我流程中自动用于词语辨析补充、同义词对比、搭配提醒。
- 不写作“方法依据”，不冒充方法库方法。
- 如果需要讲解解题流程，仍应调用综合方法库。
