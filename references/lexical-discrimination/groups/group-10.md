# 词义辨析补救库 第 10 组

用途: 近义词、成语、实词辨析；不作为方法库依据；不用于自动判题。

## 词组辨析

| 词组 | 辨析要点 |
|---|---|
| 相形见绌 | 侧重与他人相比显出不足，强调对照之下的差距。 |
| 出类拔萃 | 侧重本身卓越超越同类，强调固有品质而非竞争中显现。 |
| 无与伦比 | 侧重独一无二、无可比拟，强调程度极端。 |
| 脱颖而出 | 侧重在竞争或对比中显现才能、胜出。 |
| 崭露头角 | 侧重初次显露突出的才能或本领。 |
| 大显身手 | 侧重充分施展才能、本领，强调动作的彻底性。 |
| 望其项背 | 表示能赶上、能看见前人背影，多用于否定式“不能/难以望其项背”。 |
| 望尘莫及 | 表示远远落后、追赶不上，强调差距悬殊。 |
| 相提并论 | 侧重地位、档次差距悬殊，把不该并列者放在一起比较，强调差距明显。 |
| 同日而语 | 侧重同一事物在不同时间的比较，多用于否定式“不可同日而语”。 |
| 等量齐观 | 侧重对不同类事物用同一标准看待，强调类别差异不宜等量比较，多用于否定。 |
| 一概而论 | 侧重用同一标准处理不同情况，强调处理方式单一，多用于否定式“不可一概而论”。 |

## 使用边界

- 在复盘、解法或考我流程中自动用于词语辨析补充、同义词对比、搭配提醒。
- 不写作“方法依据”，不冒充方法库方法。
- 如果需要讲解解题流程，仍应调用综合方法库。
