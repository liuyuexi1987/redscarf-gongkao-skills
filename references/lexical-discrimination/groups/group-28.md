# 词义辨析补救库 第 28 组

用途: 近义词、成语、实词辨析；不作为方法库依据；不用于自动判题。

## 词组辨析

| 词组 | 辨析要点 |
|---|---|
| 高屋建瓴 | 多用于讲话、分析、理论等居高临下的视角，强调站位高、视野宏大 |
| 高瞻远瞩 | 多用于布局、规划、战略，强调眼界高远、看得长远 |
| 深谋远虑 | 周密思考长远问题，强调谋划的深入与周全 |
| 审时度势 | 审视现状并估量未来走势，强调对形势的判断 |
| 运筹帷幄 | 在幕后筹划决策，强调统帅或主导者的谋划角色 |
| 统筹兼顾 | 把多方面因素统一安排、照顾到，强调全面性 |
| 身体力行 | 亲身体验、努力实行，强调亲自动手实践 |
| 亲力亲为 | 亲自操持不假手他人，强调主体责任的落实 |
| 克己奉公 | 约束私欲、奉献公事，强调对公的奉献与自律 |
| 以身作则 | 用自己的行为做榜样，强调示范带动作用 |
| 上行下效 | 上面怎么做下面就跟怎么学，强调层级间的示范传递效应 |
| 事必躬亲 | 每件事都亲自处理，强调办事方式而非职责评价 |
| 一以贯之 | 用一个原则贯穿始终，强调持续性与一致性 |
| 矢志不渝 | 立下志愿永不改变，强调志向的坚定 |

## 使用边界

- 在复盘、解法或考我流程中自动用于词语辨析补充、同义词对比、搭配提醒。
- 不写作“方法依据”，不冒充方法库方法。
- 如果需要讲解解题流程，仍应调用综合方法库。
