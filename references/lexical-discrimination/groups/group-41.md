# 词义辨析补救库 第 41 组

用途: 近义词、成语、实词辨析；不作为方法库依据；不用于自动判题。

## 词组辨析

| 词组 | 辨析要点 |
|---|---|
| 蔚然成风 | 形容良好的风气逐渐形成并盛行，褒义。 |
| 风靡一时 | 形容某事物在一时期内广泛流行，多用于潮流、风尚、商品款式，中性。 |
| 如雷贯耳 | 形容名声极大，多用于人的名字或名号。 |
| 炙手可热 | 本形容权势大，现多形容受关注度极高、热度盛。 |
| 名噪一时 | 形容在某段时间内名气很大，侧重名气本身，未必受人追捧，多用于人物、名望、事迹、口碑。 |
| 闻名遐迩 | 形容名声传遍远近，多用于名胜古迹、城市。 |
| 靡然成风 | 形容不良风气蔓延，贬义。 |
| 大行其道 | 形容某种事物（多为中性或贬义）成为一种风尚、盛行。 |
| 甚嚣尘上 | 形容某种言论嚣张、流言四起，贬义。 |
| 煊赫一时 | 形容权势、名望、地位在某段时间内极其显赫。 |
| 声名鹊起 | 形容名声迅速提升，强调从无名到有名的快速变化。 |
| 名声大噪 | 形容名气迅速变大，强调从有名到更有名的跃升。 |
| 趋之若鹜 | 形容许多人盲目追逐某一事物，贬义，多指追逐不该追逐的东西。 |

## 使用边界

- 在复盘、解法或考我流程中自动用于词语辨析补充、同义词对比、搭配提醒。
- 不写作"方法依据"，不冒充方法库方法。
- 如果需要讲解解题流程，仍应调用综合方法库。
