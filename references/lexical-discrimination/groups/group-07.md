# 词义辨析补救库 第 07 组

用途: 近义词、成语、实词辨析；不作为方法库依据；不用于自动判题。

## 词组辨析

| 词组 | 辨析要点 |
|---|---|
| 望而却步 | 侧重因客观困难或能力不足而停下脚步，强调行为上退缩。 |
| 望而生畏 | 侧重心理上产生畏惧，强调情感反应。 |
| 畏葸不前 | 贬义，侧重主观上畏惧而不敢前进，强调畏怯退缩。 |
| 骑虎难下 | 侧重迫于形势，中途无法停止也无法继续，强调处境两难。 |
| 进退维谷 | 侧重进退两难、陷入困境，强调处境困窘。 |
| 进退失据 | 侧重失去依据、进退失措，多用于决策、行动无凭依。 |
| 瞻前顾后 | 侧重顾虑太多、犹豫不决，强调心思上反复权衡。 |
| 踟蹰不前 | 侧重内心犹豫且行动上停步不前，强调心与行同在迟疑。 |
| 裹足不前 | 侧重行动上停步不前、不愿推进，强调行为上的停滞。 |
| 举步维艰 | 侧重行动艰难但仍在进行，强调过程艰辛。 |
| 寸步难行 | 侧重根本无法迈步、行动完全受阻，强调难度极大。 |

## 使用边界

- 在复盘、解法或考我流程中自动用于词语辨析补充、同义词对比、搭配提醒。
- 不写作“方法依据”，不冒充方法库方法。
- 如果需要讲解解题流程，仍应调用综合方法库。
