# 词义辨析补救库 第 04 组

用途: 近义词、成语、实词辨析；不作为方法库依据；不用于自动判题。

## 词组辨析

| 词组 | 辨析要点 |
|---|---|
| 另辟蹊径 | 侧重另找新的道路、方向或方法，强调路径创新。 |
| 标新立异 | 提出新奇主张或表现出与众不同，褒贬取决于语境；贬义语境中常含故意求异之意。 |
| 与时俱进 | 侧重随时间推移一同进步，强调与时代发展相适应。 |
| 剑走偏锋 | 侧重采取出奇偏险的方式以求胜，强调策略偏离常规。 |
| 不拘一格 | 侧重打破常规限制，多用于选拔人才、招生等不局限于固定标准。 |
| 匠心独运 | 侧重构思或技艺精巧独创，常用于文学、艺术、设计等作品。 |
| 别出心裁 | 侧重想法、办法或设计新颖，与通常做法不同，适用对象更宽。 |
| 独树一帜 | 侧重自成一家、与众不同，强调在众人中单独形成特色。 |
| 自成一家 | 侧重在学问、技艺上形成独立完整的体系。 |
| 别开生面 | 侧重形式新颖、场面别致，多形容活动、会议等给人新感受。 |
| 不落窠臼 | 侧重不落俗套、有独创风格，多用于文章、艺术创作。 |

## 使用边界

- 在复盘、解法或考我流程中自动用于词语辨析补充、同义词对比、搭配提醒。
- 不写作“方法依据”，不冒充方法库方法。
- 如果需要讲解解题流程，仍应调用综合方法库。
