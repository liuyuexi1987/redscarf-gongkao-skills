# 词义辨析补救库 第 38 组

用途: 近义词、成语、实词辨析；不作为方法库依据；不用于自动判题。

## 词组辨析

| 词组 | 辨析要点 |
|---|---|
| 接踵而至 | 一个接一个到来，强调连续不断的顺序 |
| 络绎不绝 | 来往人马连续不断，强调往来频繁 |
| 纷至沓来 | 连续不断地到来，强调多而杂 |
| 蜂拥而至 | 像蜂群一样拥挤着到来，强调人多杂乱 |
| 门庭若市 | 门口庭院像集市一样，强调来人很多 |
| 无人问津 | 无人过问，强调无人关注或购买 |
| 门庭冷清 | 门前冷落，强调来人稀少 |
| 门可罗雀 | 门前可张网捕雀，强调来人极少 |
| 人迹罕至 | 人很少到的地方，强调地点偏僻 |
| 不期而遇 | 没约定却意外相遇，多用于人与人 |
| 不期而至 | 没预料却到来，可用于人或事物 |
| 萍水相逢 | 像浮萍随水相遇，比喻素不相识者偶然相遇 |
| 如影随形 | 像影子跟着身体，比喻关系密切不可分离 |

## 使用边界

- 在复盘、解法或考我流程中自动用于词语辨析补充、同义词对比、搭配提醒。
- 不写作“方法依据”，不冒充方法库方法。
- 如果需要讲解解题流程，仍应调用综合方法库。
