# 词义辨析补救库 第 06 组

用途: 近义词、成语、实词辨析；不作为方法库依据；不用于自动判题。

## 词组辨析

| 词组 | 辨析要点 |
|---|---|
| 按部就班 | 侧重按照一定次序和步骤进行，强调条理与程序，中性词。 |
| 循规蹈矩 | 中性词，侧重遵守规矩、不走偏差，强调行为守规。 |
| 循规拘礼 | 侧重拘泥于礼节，强调在礼数上刻板遵守。 |
| 照本宣科 | 贬义，侧重照着稿子或课本死板宣讲，缺乏发挥。 |
| 循序渐进 | 褒义词，侧重逐步深入、按次序推进，多用于学习、训练、改革。 |
| 有条不紊 | 褒义词，侧重有条理、不混乱，多用于秩序、工作安排。 |

## 使用边界

- 在复盘、解法或考我流程中自动用于词语辨析补充、同义词对比、搭配提醒。
- 不写作“方法依据”，不冒充方法库方法。
- 如果需要讲解解题流程，仍应调用综合方法库。
