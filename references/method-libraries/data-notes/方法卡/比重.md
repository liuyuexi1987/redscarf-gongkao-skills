# 比重

confidence: high

## 适用题型

现期比重、基期比重、两期比重比较、两期比重差、饼状图比重。

## 触发场景

- 题干出现"占……比重""……所占比重""……比重是多少"。
- 题干出现"占比上升/下降了多少个百分点"。
- 题干给出饼状图，问某部分占比或比较占比。
- 题干问"……拉动……增长几个百分点"或"贡献率"。

## 方法卡

### 1. 基础公式

```text
比重 = 部分 / 整体
增长贡献率 = 部分增长量 / 总体增长量
产销率 = 销量 / 产量
```

变量说明：部分和整体必须同口径（同为现期或同为基期）。增长贡献率分母是总体增长量，不是总体量。

### 2. 现期比重

- 给部分量、总体量: 直接除。
- 比较比重: 估计比较，分母越大分数不一定越大，要同时看分子。
- 图形题: 看清是现期还是基期，饼图角度/面积只是辅助，不能替代精确计算。

### 3. 基期比重

给现期部分 A、整体 B，部分增长率 a，整体增长率 b:

```text
基期比重 = A / B × (1+b) / (1+a)
```

变量说明：A、B 都是现期值；a 是部分增长率，b 是整体增长率（均带符号）。修正项 `(1+b)/(1+a)` 来自基期比重 = [A/(1+a)] / [B/(1+b)]。

步骤:

1. 先算现期比重 `A/B`。
2. 再看修正项 `(1+b)/(1+a)`。
3. 判断比现期比重大还是小。

### 4. 两期比重比较

看部分增长率 `a` 与整体增长率 `b`:

```text
a > b: 比重上升
a < b: 比重下降
a = b: 比重不变
```

依据：现期比重 / 基期比重 = (1+a)/(1+b)，故 a 与 b 的大小关系直接决定升降。

### 5. 两期比重差

```text
两期比重差 = A / B × (a-b) / (1+a)
```

其中 A/B 是现期比重，a 是部分增长率，b 是整体增长率。结果带符号：正为上升，负为下降；单位为百分点。

## 方法步骤

1. 识别"比重"题型（占、比重、占比、含"占"字的百分比等）。
2. 明确部分与整体：通常"X 占 Y"中 X 是部分、Y 是整体。
3. 现期题直接用 部分/整体。
4. 基期题用 `A/B × (1+b)/(1+a)`，注意 a 是部分增长率、b 是整体增长率。
5. 比较两期升降时只比较 a 和 b，无需算出具体比重。
6. 求差值时用 `A/B × (a-b)/(1+a)`，注意符号与单位（百分点）。

## 不适用条件

- 题目问的是绝对量（部分量或整体量），不要套比重公式。
- 题目问增长率，应直接用 (现期-基期)/基期，不是比重公式。
- 部分、整体不同口径（如部分是产量、整体是销量）时，不能直接套比重公式，应改用对应口径或专用指标（如产销率）。
- 饼图角度/面积只是辅助，不能替代精确计算。
- 比重差结果单位是百分点，不要与百分比混淆。

## 反向验证

- 基期比重 × (1+a) / (1+b) = 现期比重。
- 两期比重差 / 现期比重 = (a-b)/(1+a)，应与分别算出的两个比重之差吻合。
- 各部分比重之和应等于 1（或 100%）。
- 现期比重 × 整体 = 部分（可用于验算）。

## 高频错因

- 部分增长率和整体增长率放反（a 是部分，b 是整体）。
- 问"上升/下降"时还在硬算比重（应只比较 a 与 b）。
- 两期比重差忘记除以 `1+a`。
- 把增长贡献率当普通比重（贡献率分母是总体增长量，不是总体量）。
- 混淆百分点与百分比：比重差结果单位是百分点。
