# 年均增长率

confidence: high

## 适用题型

比较或计算年均增长率，尤其是多年复合增长。

## 触发场景

- 题干给出"基期值、现期值、年份差"，要求计算年均增长率。
- 题干给出多个主体（省份、行业、企业）的基期和现期，要求比较年均增长率大小。
- 题干涉及多年复合增长，问"年均增长约多少"。
- 题干给出"总增长率"，要求折算为年均增长率。

## 方法卡

### 1. 年份差相同，比较年均增长率

年份差相同:

```text
基期 × (1+r)^n = 现期
```

比较年均增长率时，直接比较:

```text
现期 / 基期
```

现期/基期越大，年均增长率越大。

### 2. 年份差不同

年份差不同，不能直接比较现期/基期。要看:

```text
(1+r)^n = 现期 / 基期 = 1 + 增长量 / 基期
```

需要结合 n 比较。

方法步骤:
1. 对每个主体算出 `现期/基期`。
2. 把不同年份差归一：估算每个主体对应的 `(现期/基期)^(1/n)`，再比较。
3. 若 `现期/基期` 接近 1，可结合第 3 节近似比较；否则必须开方或用第 4 节平方/立方表反推。

### 3. r 较小时的估算

数学依据：`(1+r)^n = 1 + n·r + n(n-1)/2·r² + ...`，故 `总增长率 = (1+r)^n - 1 ≈ n·r + n(n-1)/2·r²`，从而 `总增长率/n ≈ r + (n-1)/2·r² > r`。

```text
年均 r ≈ 总增长率 / 年份差
```

该近似值系统性偏大于真实 r，偏大量级随 r 和 n 增大而增加（参考：r=5%、n=5 时偏大约 10%；r=10%、n=5 时偏大约 22%）。

判断方法:
1. 先用 `总增长率/年份差` 得到上界估计。
2. 结合 r 和 n 估算偏差量级（用上式 `(n-1)/2·r²` 量级）。
3. 与选项对照：把该结果当作上界帮助缩小范围；只有估算区间能唯一覆盖某个选项时才作答，否则用第 4 节方法精算或反推。

不要把"选项向小选"当成绝对规则：当所有选项都偏小或偏差量级与选项间距相近时，必须精算。

### 4. r 较大时的估算

增长率较大时，用平方、立方、四次方估算，不要简单除年份差。

常用平方:

```text
11²=121
12²=144
13²=169
14²=196
15²=225
16²=256
17²=289
18²=324
19²=361
20²=400
```

常用三次/四次近似:

```text
1.2³≈1.7
1.3³≈2.2
1.4³≈2.7
1.2⁴≈2.0
1.3⁴≈2.9
1.4⁴≈3.8
```

方法步骤:
1. 先算 `现期/基期`，落在哪个区间（如 1.7~2.2 之间对应三次方 r 在 20%~30%）。
2. 用平方/立方/四次方表反推 r 的范围。
3. 与选项对照取最接近者。

## 不适用条件

- 年份差 n=1 时，年均增长率计算退化为单期增长率，无需使用多年复合估算。
- 现期/基期接近 1（变化极小）时，开方数值极敏感，近似公式误差可能反超真值，应直算或保留更多位。
- 数据存在负增长（现期 < 基期）时，公式仍成立但 r 为负，不能套用"偏大向小选"的判断。

## 反向验证

- 将算出的 r 代回 `基期 × (1+r)^n`，结果应与题目给出的现期一致或落在选项间距内。
- 比较类：把每个主体的 r 反算回 `(1+r)^n × 基期`，验证现期排序与原始数据一致。
- 用 `总增长率/年份差` 估算时，反算 `(1+估算值)^n - 1` 应大于真实总增长率（验证上界性质）。

## 高频错因

- 把年均增长率当作总增长率除年份个数，忽略复利。
- 年份差数错（如 2018→2023 是 5 年差，不是 6 年）。
- 年份差不同时仍直接比较现期/基期。
- r 较大时仍使用小 r 近似。
- 把"选项向小选"当作绝对规则，忽视偏差量级与选项间距的关系。
