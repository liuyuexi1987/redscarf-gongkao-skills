# 基期量

confidence: high

## 适用题型

给现期、增长量、增长率、同比/环比，求上一期或某一基期量。

## 触发场景

- 题干给出"现期值 + 增长率/增长量"，问"上年/上期"或"基期"。
- 题干给出"现期值 + 同比/环比增长率"，需要还原基期。
- 题干给出"部分现期、整体现期及各自增长率"，求部分基期、整体基期或基期比重。
- 题干要求"A 基期 + B 基期"或"A 基期 - B 基期"。

## 方法卡

### 1. 基础关系

- 同比: 上年同期。
- 环比: 上一周期。
- 基期、现期、增长量、增长率四者要先定位清楚。

### 2. 基期三公式

```text
基期 = 现期 - 增长量
基期 = 增长量 / 增长率
基期 = 现期 / (1 + 增长率)
```

方法步骤:
1. 先定位题目给的是同比还是环比，确定 r 的方向。
2. 统一把 r 作为带符号增长率代入 `1+r`；若题干给“下降 d%”，则 r=-d，分母写成 `1-d`。
3. 比较选项前两位，判断是否需要精确计算或可用近似。

### 3. 小增长率化除为乘

数学依据：`A/(1+r) = A(1-r)/(1-r²)`，当 |r| 较小时 `1-r²` 接近 1，故 `A/(1+r) ≈ A(1-r)`。正增长时绝对误差为 `A·r²/(1+r)`；估算时可用 `A·r²` 判断误差量级。

```text
A / (1 + r) ≈ A × (1 - r) = A - A×r
A / (1 - r) ≈ A × (1 + r) = A + A×r
```

使用前提（同时满足才可用）:
- |r| 较小，使二阶误差可控；
- 估算误差明显小于候选答案之间的有效差距；
- 已确认误差方向不会把结果推过选项分界。

不要用固定百分比代替误差判断：增长率稍大但选项差距很大时仍可能可估；增长率很小但选项极接近时也可能必须直除。

### 4. 基期和差

基期和差常见形式:

```text
A/(1+a) ± B/(1+b)
```

- 分母相近时可先估。
- 分母不同且差距较大时，不要直接用现期和差代替基期和差。

### 5. 与比重结合

求部分基期或整体基期时，先分清:

- 部分现期、部分增长率。
- 整体现期、整体增长率。
- 现期比重或基期比重。

再选公式，避免把部分增长率套到整体上。

## 不适用条件

- 题目所给增长率方向不明时，不要直接套 `1+r`：必须先确定是增长还是下降。
- 选项前两位相同且第二位接近时，化除为乘的误差可能跨越选项边界，应改为直除或保留更多位。
- 按 `A·r²` 估得的误差已接近选项差距时，化除为乘不适用。

## 反向验证

- 将算出的基期代回 `现期 = 基期 × (1+r)`，看是否与题目给出的现期一致。
- 若使用化除为乘，反算 `估算基期 × (1+r) - 现期`，检查偏差是否足以跨越选项分界；若会跨项，应改直除。
- 基期和差：把两个基期分别算出后再加减，与直接用现期和差比较，差距是否符合"分母不同不能替换"的判断。

## 高频错因

- 同比、环比定位错。
- 增长率为负时仍用 `1+r` 的正增长直觉。
- 小 r 估算时不看选项差距。
- 部分/整体增长率混用。
- 用固定增长率门槛代替选项间距和误差方向判断。
