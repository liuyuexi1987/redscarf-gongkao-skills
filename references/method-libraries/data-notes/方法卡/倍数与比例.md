# 倍数与比例

confidence: medium

## 适用题型

问 A 是 B 的几倍、A 比 B 多几倍、A 与 B 的比例、A 超过 B 的 n 倍、混合比例、平均数倍数。

## 触发场景

- 题干出现“是几倍”“多几倍”“超过几倍”“比例之比”等关键词。
- 给出 A、B 两个量，要求判断倍数或比例关系。
- 给出两个平均数，要求比较其倍数关系。
- 给出两个部分及其比例，要求反推各部分规模比，或判断总体比例范围和偏向（盐水思想）。

## 方法卡

### 1. 倍数语言先翻译

```text
A 是 B 的 n 倍: A / B = n
A 与 B 的比例: A : B
A 比 B 多 n 倍: A / B - 1 = n
A 超过 B 的 n 倍: A > B × n
```

变量含义：
- A、B：题干给出的两个具体量，需根据问法确定谁是基准（分母）。
- n：题干给出的倍数或比例数值。

### 2. 现期倍数

先找 A、B，再算 `A/B`。如果问“多几倍”，最后要减 1。

### 3. 平均数倍数

平均数形如 `A/B`。两个平均数求倍数时:

```text
(A/B) ÷ (C/D) = (A/C) × (D/B)
```

优先约分，减少计算量。

### 4. 混合比例/盐水思想

总体比例落在两个部分比例之间，且偏向权重（即部分规模/数量）更大的一方。可用线段距离反推两个部分规模比：

```text
(总体比例 - 部分A比例) / (部分B比例 - 总体比例) = 部分B规模 / 部分A规模
```

注：若用于“增长率混合”场景（即两个部分增长率合成总体增长率），则权重应为各部分的基期量，偏向基期量更大的一方。

## 方法步骤

1. 根据问法确定题目类型：现期倍数、平均数倍数、比例比较，还是混合比例反推。
2. 翻译倍数语言，明确“是几倍”还是“多几倍”，决定最后是否减 1。
3. 确定基准量（分母）和目标量（分子），避免 A、B 位置颠倒。
4. 现期倍数：直接 `A/B` 计算；“多几倍”再减 1。
5. 平均数倍数：列出两个平均数，用 `(A/B) ÷ (C/D) = (A/C) × (D/B)` 约分后计算。
6. 混合比例：先判断总体比例是否在两个部分比例之间，再用线段距离公式反推规模比或总体比例。
7. 结合选项差距决定估算精度：选项差距大时可只算首几位，选项差距接近时需完整计算。

## 高频错因

- “多 n 倍”忘记减 1。
- 把比例 `A:B` 当作 `A/B - 1`。
- 混合比例只判断范围，不判断偏向。
- 平均数倍数中分子分母颠倒，导致结果取倒数。
- 混合比例场景下权重取错（比例混合应取部分规模，增长率混合应取基期量）。

## 不适用条件

- 题目问的是“增长率”而非“倍数”时，应转用增长率相关方法卡，倍数与增长率不能直接互换。
- 题目问的是“比重”及其变化时，应转用比重方法卡，不能用倍数公式套算。
- 题目给出的是多个量相加关系而非比例混合时，不适用盐水思想，应改用加权平均或直接求和。
- 题目要求基期倍数而非现期倍数时，需先还原基期量再算倍数，不能直接用现期量代入。

## 反向验证

- 现期倍数：用算出的 n 反推 `B × n`（或 `B × (n+1)` 对应“多几倍”），应与题干 A 一致。
- 平均数倍数：把结果分别代入 `(A/B)` 和 `(C/D)`，确认约分前后比值一致。
- 混合比例：把反推出的规模比代入加权公式 `(A规模×A比例 + B规模×B比例)/(A规模+B规模)`，应等于题干给出的总体比例。
- “多 n 倍”类题目：把答案加 1 还原为“是几倍”，再乘以 B，应得到 A，确认减 1 操作无误。
