# 乘积增长率

confidence: high

## 适用题型

两个因素相乘形成总量，问总量增长率。

## 触发场景

- 总额 = 单价 × 数量
- 产量 = 单产 × 面积
- 部分 = 总体 × 比重
- 其他形如 `A = B × C` 的指标

## 方法卡

若 `A = B × C`，B 的增长率为 `b`，C 的增长率为 `c`，则:

```text
A 的增长率 = b + c + b × c
```

公式中各变量含义：
- A：由两个因素相乘形成的总量（如总额、产量、部分值）。
- B、C：相乘的两个因子（如单价与数量、单产与面积）。
- b、c：分别为 B、C 的增长率，可正可负。

若其中一个因素不变（增长率为 0），则总量增长率等于另一个因素的增长率。

## 方法步骤

1. 先把题干指标拆成乘积关系，确认 `A = B × C` 结构成立。
2. 分别找两个因子的增长率 b、c。
3. 套 `b + c + b × c` 计算总量增长率。
4. 精度判断：选项差距足够大时，乘积项 `b × c` 可估算甚至忽略；当两个因子增长率绝对值都不小（例如都达到 5% 以上量级）时，乘积项不可省略，否则会偏离正确选项。
5. 若题干只给一个因子的增长率和总量增长率，可用公式反推另一因子增长率。

## 高频错因

- 只算 `b+c`，漏掉 `b×c`。
- 没先识别“总额/产量/部分”背后的乘积结构。
- 一个因子不变时仍套完整公式，增加不必要的计算量。

## 不适用条件

- 指标关系不是相乘而是相加（如 `A = B + C`）时，不适用本卡，应改用“混合增长率/加权平均”相关方法。
- 题目问的是“平均数”的变化（`A/B` 形式）时，应改用平均数增长率方法卡，公式为 `(a - b) / (1 + b)`，与本卡不同。
- 题目问的是“比重”变化时，应改用比重差或比重增长率方法卡。
- 题目直接给出总量增长率，要求比较两个因子的增长率大小，属于反向使用，需先确认是否有足够已知量支撑反推。

## 反向验证

- 用算出的总量增长率 r 反推：`现期 A ≈ 基期 A × (1 + r)`，若与题干给出的现期 A 不一致则计算有误。
- 一个因子不变时：检查总量增长率是否等于另一因子增长率，若不等则说明公式套用错误或因子识别错误。
- 乘积项取舍校验：把 `b + c` 与 `b + c + b × c` 两个结果都算出，与选项对比，确认省略乘积项是否会跨入另一选项区间。
