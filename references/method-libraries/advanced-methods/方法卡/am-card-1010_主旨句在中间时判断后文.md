# 方法卡：主旨句在中间时判断后文

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 主旨句在中间时判断后文 |
| 适用题型 | 言语理解——中心理解 |
| 触发场景 | 主旨句在文段中间，后面还有话 |
| 步骤逻辑 | ① 大致确定主旨句后，看后面那句话的功能；② 后句围绕主旨服务→主旨句判断正确，不需要看后句；③ 后句另开话题/讲其中一个小重点→可能需要重新判断主旨；④ 后句是反例/逆向表达→仍在为主旨服务（如"实践中很多没这么做→后果不好"=强调应该这么做） |
| 高频错因 | ① 主旨句后面有话就纠结→不知道该不该看后面；② 后句是反例但以为是新话题→主旨判断错误 |
| confidence | high |

## 补充说明
主旨句不在最后一句时，后面的话是最大干扰。判断方法：后句是论据/展开/反例/逆向表达→仍为主旨服务，不需要改主旨；后句是新话题/新重点→需要重新判断。"反向表达"特别容易误判为新话题。

## 不适用条件
- 主旨句在首句或末句（无"后文"需判断）
- 文段为并列结构，无明确主旨句

## 反向触发
- 后句功能难以判断→改用行文脉络整体分析
- 后句明显转向新话题→重新定位主旨句而非沿用原判断
