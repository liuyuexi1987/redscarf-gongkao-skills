# 方法卡：实验题支持选原理

| 字段 | 内容 |
|------|------|
| 方法名 | 实验题支持选原理 |
| 适用题型 | 逻辑判断——加强支持（题干论据为对比实验） |
| 触发场景 | 题干给出一组严谨的对比实验得出结论，但未解释原理/机制 |
| 步骤逻辑 | 1. 识别题干论据是实验类比/对比实验结果 |
| | 2. 判断实验本身是否严谨（已控制变量） |
| | 3. 若严谨但缺原理解释→支持方向优先选"解释说明/原理"类选项 |
| | 4. 类比支持（其他地方也有类似现象）力度弱，不优先选 |
| 高频错因 | ①选类比支持（其他地方也怎样）当作最强支持②不区分实验结果类题干和理论推导类题干的支持方向差异 |
| confidence | high |

## 不适用条件

- 题干实验本身有明显缺陷（如未控制变量、样本量过小），此时支持方向应转向排除他因或确认实验有效性，而非解释原理。
- 题干论据不是实验类（如纯理论推导、统计调查），应按常规加强方式判断。
- 题干已给出原理性前提，结论是原理的直接推论，无需再选原理选项。

## 反向触发

- 看到"实验发现""对比两组""研究人员观察到"等表述，且结论暗示因果关系时，提示选原理/机制。
- 选项中出现"这是因为...""机制在于..."等解释性表述时，优先考虑。

**补充说明：**
- 当题干论据是"做了对比实验发现A组比B组某指标高"这类结构时，最佳支持是解释"为什么A组会更高"的原理/机制。
- 类比支持（"其他地方也发现了类似现象"）虽然不算削弱，但力度远不如直接解释原理。
- 若实验不严谨（变量未控制好），则支持方向转为"排除他因"或"确认实验有效性"。
