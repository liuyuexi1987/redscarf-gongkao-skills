# 方法卡：比值升降速判法

| 字段 | 内容 |
|------|------|
| 方法名 | 比值升降速判法 |
| 适用题型 | 资料分析-判断比值上升/下降趋势（如"平均值比上年高/低""比重上升/下降"） |
| 触发场景 | 题目问比值（平均值、占比等）是上升还是下降，不需要精确值 |
| 步骤逻辑 | 1. 识别所求为比值（分子÷分母） → 2. 找分子增速和分母增速 → 3. 分子增速 > 分母增速 → 比值上升；分子增速 < 分母增速 → 比值下降 |
| 高频错因 | 把分子分母搞反；负数增速比较时忘记负号方向（-30% > -38%意味着分子增速更大） |
| confidence | high |

补充说明：此法只需比较两个增速大小即可，不需要计算比值。注意负数情况：-30% > -38%，即-30%的绝对值小但数值更大。

## 不适用条件

- 分子分母增速为负且符号不同时，升降方向需单独分析，不能简单比较大小
- 题目要求精确的升降幅度而非仅判断方向
- 分子分母本身难以识别（如复合比值或多层嵌套比值）时，不能直接应用

## 反向触发

- 分子与分母增速的大小关系仍可准确判断升降；只有题目要求具体变化幅度时，才需代入公式计算
- 增速数据为预估值且置信度不高时，升降方向不确定，应标注待验
- 题目涉及同一比值的多期变化需分别判断每期升降时，应逐期单独比较而非笼统判断
