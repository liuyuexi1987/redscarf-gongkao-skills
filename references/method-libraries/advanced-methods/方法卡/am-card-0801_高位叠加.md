# 方法卡：高位叠加

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 高位叠加 |
| 适用题型 | 资料分析——多个数字求和 |
| 触发场景 | 五个左右数字相加，需要快速得出结果或根据选项截断计算 |
| 步骤逻辑 | ① 从千位/最高位开始逐位相加，不抄原数；② 每位结果向右错一位写（如楼梯状）；③ 根据选项精度决定加到哪一位，可中途停下；④ 可利用等差数列等凑整简化计算 |
| 高频错因 | 习惯性从个位开始加导致需要反复进位；逐位抄写原数浪费时间 |
| confidence | medium |

## 补充说明

三大好处：不用抄数、不涉及进位（或少量进位）、可在任意位停下根据选项取舍。熟练后可直接口算，比从个位加起快很多。当估算误差可能跨越选项或改变结论时，改用精算/验证。

## 不适用条件

1. 数字个数过少（仅2~3个），直接相加即可，无需高位叠加。
2. 相加的数字不是精确值（如四舍五入后的统计数据），叠加后尾数无意义。
3. 选项精度要求很高（如需精确到个位），高位叠加需加到末位才够。

## 反向触发

1. 五个左右数字相加，需要快速得出近似结果。
2. 选项间距较大，只需计算到千位或百位即可区分。
3. 时间紧张，需避免抄数和反复进位的繁琐步骤。
