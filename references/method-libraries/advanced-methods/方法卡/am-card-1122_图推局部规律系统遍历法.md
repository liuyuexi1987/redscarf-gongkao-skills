# 方法卡：图推局部规律系统遍历法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 图推局部规律系统遍历法 |
| 适用题型 | 判断推理——图形推理·局部规律 |
| 触发场景 | 整体规律排查无果且无明显特征图可匹配，转向局部规律排查时 |
| 步骤逻辑 | ① 确认整体规律已排除：对称→取值→开闭→部分数→笔画，均无规律；② 转向局部规律，按顺序遍历：点→线→面→角；③ 点：总交点数、框内交点数、圆与直线交点数；④ 线：横线数、竖线数、平行线组数、横竖线数量关系（如横线比竖线多一）；⑤ 面：总面数、最大面/最小面特征；⑥ 角：几乎只考直角，通常靠遍历发现；⑦ 若某维度有规律但选项无法区分，转向该维度的细分规律或复合规律 |
| 高频错因 | ① 整体规律无果后直接放弃，不转向局部；② 局部排查无序，不按点→线→面→角顺序；③ 线规律只数总线数，不分别数横线/竖线/平行线；④ 角规律不知道几乎只考直角，浪费时间数其他角 |
| confidence | high |

## 方法说明

局部规律是整体规律失败后的"Plan B"。当对称/取值/开闭/部分数/笔画都排查无果时，规律可能在局部——点、线、面、角的数量关系。

**关键洞察**：排查顺序是点→线→面→角，但实际做题应根据图形特征灵活调整。若某幅图横线特别明显，可直接从线入手，不必死板先数点。

**线规律细分**：横线/竖线/平行线要分别计数。可能考其中某一种的数量，也可能考横竖线之间的数量关系（如横线比竖线多一）。做题时把横线数写在左边、竖线数写右边，一目了然。

**角规律的排查**：角的特征通常不如点、线、面显眼。当其他局部维度无法解释时，可分别统计直角数、锐钝角构成或特定位置的角，再用选项验证。

**平行线规律**：两条平行线称为一组，三条平行线也算一组（剩下一条不能单独成组）。平行线组数也是常见考点。

## 使用边界

- 适用于：整体规律排查无果、无明显特征图
- 不适用于：有明显特征图时优先用特征触发卡（1105-1112）
- 特征太明显时不必死板按顺序，可直接从特征切入

## 不适用条件

1. 有明显特征图时（应优先用1105-1112对应特征触发卡）
2. 整体规律（对称/取值/开闭/部分数/笔画）尚未排查时（应先用1121）
3. 图形以图形间关系（相交/相接/内外）为主要特征时（应优先用1124）

## 反向触发

1. 局部某维度有规律但选项无法区分时，应补充核验该维度的细分规律
2. 点线面角均无规律时，应换用1124图形间关系细分法
3. 直角数无规律时，再核验锐钝角组成、角的位置或回到整体属性重新评估

## 观察顺序

1. 确认整体规律已排除
2. 观察图形，找最明显的局部特征（横线多？交点多？）
3. 无明显特征时按点→线→面→角顺序遍历
4. 每个维度分别计数，写在图旁边
5. 某维度有规律但选不出时，转向细分规律

## 常见错因

1. 整体规律无果后直接放弃
2. 局部排查无序
3. 线规律只数总线数，不分类
4. 只统计直角，漏掉其他能稳定区分选项的角特征
