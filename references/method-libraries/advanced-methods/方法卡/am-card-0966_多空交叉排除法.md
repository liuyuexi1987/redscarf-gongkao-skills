# 方法卡：多空交叉排除法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 多空交叉排除法 |
| 适用题型 | 逻辑填空——多空题排除策略 |
| 触发场景 | 3空及以上逻辑填空题，单空无法确定唯一答案 |
| 步骤逻辑 | ① 先做最有把握的空（搭配最明确/语境最清晰的空）；② 用该空排除2-3个选项，缩小剩余选项范围；③ 在剩余选项中做第二有把握的空；④ 交叉验证：最终选项的每个空都要单独成立 |
| 高频错因 | ① 从第一空开始逐空做，第一空不确定时浪费时间纠结；② 只验证了一个空就选了答案，没有交叉验证其他空 |
| confidence | high |

## 补充说明
多空题的策略核心：不要从第一空开始死磕。先扫一遍所有空，找搭配最明确、语境最清晰的那个空入手。当一个空能排除2个以上选项时，优先做这个空。最后必须交叉验证——每个空都要单独成立，不能只看一个空就下结论。

## 不适用条件
- 单空题，无多空可交叉验证。
- 多空中每个空都有唯一确定答案，无需交叉排除即可定位。
- 各空之间无关联，无法通过一个空的排除结果推导另一个空。

## 反向触发
- 当所有空都无法确定时，需换用词汇盲区降权法先用认识的词排除可排除的选项。
- 当交叉验证发现多个空结果冲突时，应重新审视各空步骤逻辑或标记待复核。
- 当某一空排除后剩余选项仍过多时，需补充搭配验证或感情色彩匹配进一步缩小范围。
