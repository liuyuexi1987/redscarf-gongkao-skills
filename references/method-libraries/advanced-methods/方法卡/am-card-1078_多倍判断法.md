# 方法卡：多倍判断法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 多倍判断法 |
| 适用题型 | 资料分析——倍数计算 |
| 触发场景 | 题目中出现"多X倍""是X倍""超过X倍"等表述 |
| 步骤逻辑 | ① "多X倍"=是X+1倍（如"多4倍"=5倍）；② "是X倍"=X倍（如"是4倍"=4倍）；③ "超过X倍">X倍；④ 选项中有"多X倍"时要注意区分：选项说"多15倍"=16倍，看数据是否支持 |
| 高频错因 | ① "多4倍"和"是4倍"混淆→差一倍；② 不区分"多"和"是"→计算结果差一倍 |
| confidence | high |

## 补充说明
资料分析常见的文字陷阱。"多X倍"="是X+1倍"——这个区别在选项中经常被利用。例如数据约为16倍时，选项"多15倍"=16倍可能正确，"是15倍"=15倍则可能错误。

## 不适用条件
- 题目使用"占……比重""增长率"等其他口径而非倍数表述时，本方法不适用。
- 数据本身含近似或估算误差，且估算误差可能跨越选项时改用精算。
- 题目考查"翻番"等特殊倍数语义时，需按翻番定义单独换算。

## 反向触发
- 当选项同时给出"多X倍"和"是X倍"且数据接近临界值时，应改用精算核对。
- 当题干混合使用倍数与百分比时，应补充口径转换核验，避免单位错配。
- 当题目要求"超过X倍"判断时，应补充不等式核验，避免边界误判。
