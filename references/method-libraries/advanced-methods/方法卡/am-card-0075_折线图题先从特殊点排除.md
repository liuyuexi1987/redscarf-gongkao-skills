# 方法卡：折线图题先从特殊点排除

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 折线图题先从特殊点排除 |
| 适用题型 | 资料分析 - 折线图识别题（选出对应哪种类型的折线图） |
| 触发场景 | 题目给12个月的增量折线图（4个选项），让你判断是哪种车辆类型 |
| 步骤逻辑 | 1. 不要从1月入手（1月增量需和上年12月比，跨度大不好判断）；2. 从特征明显的月份入手（如3月是否最高、9月vs8月谁大）；3. 逐个排除：先看最明显的特征点，不符合就排掉；4. 再用辅助特征点（如10/11/12月的走势）确认剩余选项；5. 排除法优先于逐项计算 |
| 高频错因 | 从1月份开始算，浪费大量时间；逐个算12个月的增量，体力不支 |
| confidence | high |

## 不适用条件

- 折线图数据点过少（如仅3-4个点），缺乏足够特征点做排除法，需逐个核对。
- 题目要求的是具体月份的精确数值而非趋势判断时，排除法不适用。
- 选项折线图之间的差异过于细微，仅靠特征点无法区分时，需结合更多数据点辅助。

## 反向触发

- 题目直接问"哪个月份最大/最小"等具体数值问题，需回到数据计算而非排除法。
- 图表不是折线图（如柱状图、饼图），排除法的特征点判断方式不同。
- 所有选项在特征月份的走势完全一致，排除法失效，需逐月精确对比。
