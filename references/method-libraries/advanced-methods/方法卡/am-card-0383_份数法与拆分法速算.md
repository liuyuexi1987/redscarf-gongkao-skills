# 方法卡：份数法与拆分法速算

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 份数法与拆分法速算 |
| 适用题型 | 已知现期和增长率求增量，或总人数乘以占比 |
| 触发场景 | 增长率在特殊分数附近（如25%=1/4, 14.3%≈1/7, 33.3%≈1/3, 18%≈1/5.5）；或乘数在特殊分数附近 |
| 步骤逻辑 | 1. 份数法：将增率近似为分数，建立 基期:增量:现期 的份数关系- 如 25%→ 4:1:5，用现期÷5得增量- 如 14.3%→ 7:1:8，用现期÷8得增量；2. 拆分法：将乘数拆为特殊分数+余数- 如 36.2% ≈ 33.3% + 2.9%，即 ÷3 + ×2.9%；3. 先算特殊分数部分（口算），再加余数修正；4. 边算边看选项，够判断就停 |
| 高频错因 | 增率略小于特殊分数时用份数法算出的增量偏大，需向小方向微调 |
| confidence | medium |

## 补充说明

两种速算思路的共同原则是"先算特殊分数部分，再修正余数"。份数法适用于增率恰好接近常见分数的场景（如25%→1/4，33.3%→1/3），直接建立份数比一步到位。拆分法适用于增率在两个常见分数之间的情况（如36.2%≈33.3%+2.9%），先用口算算出主要部分，再加余数修正。两种方法都强调"边算边看选项，够判断就停"。

## 不适用条件

- 增率远离任何常见分数（如17.2%），近似误差过大
- 选项差距不足以覆盖估算误差，近似结果无法稳定区分
- 增率为负值时份数比需调整符号，初学者容易混淆对应关系

## 反向触发

- 当增率近似误差可能改变选项判断时，应切换为截位直除或精确验证
- 当题目需要精确到小数点后两位的结果时，份数法/拆分法精度不够
- 当拆分后的余数部分本身仍难以口算时，整体计算量可能不如直接直除
