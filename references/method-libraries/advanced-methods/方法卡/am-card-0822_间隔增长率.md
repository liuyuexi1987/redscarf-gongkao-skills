# 方法卡：间隔增长率

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 间隔增长率 |
| 适用题型 | 资料分析——两年时间间隔的增长率（如18年比16年） |
| 触发场景 | 题目中比较的两个时间点隔了一年（或一个间隔），如"22年比20年""18年3月比16年3月"；选项是百分数 |
| 步骤逻辑 | ① 画三个时间点小图（如18→17→16）；② 找R1（近段增速）和R2（远段增速）；③ 套公式 R = R1 + R2 + R1×R2；④ 两个百分数相乘：把一个换成小数或分数，消一个百分号 |
| 高频错因 | 忘记R1×R2项；负增长率时负负得正搞错符号；两个时间间隔不等时误判不能用 |
| confidence | medium |

## 补充说明

R1和R2的作用完全对称，先近段还是先远段不影响结果。两个时间间隔不需要相等（如1月到4月再到12月也可用），但需要三个连续时间点。R1×R2通常较小，有时两段相加已超过最大选项时可直接排除。负增长时注意符号：(-R1)+(-R2)+(-R1)×(-R2)，最后一项负负得正。当估算误差可能跨越选项或改变结论时，改用精算/验证。

## 不适用条件

1. 同比比较（只隔一年）或环比比较（相邻两期），时间跨度只有一层，不构成间隔。
2. 间隔超过两年的多层复合增长率，公式需扩展，不能直接套用R1+R2+R1×R2。
3. 选项间距极窄且R1×R2不可忽略时，简化计算可能导致误选。

## 反向触发

1. 忘记R1×R2项导致结果偏小，在选项中选到最接近但非正确答案。
2. R1和R2符号相反（一正一负）时，乘积项为负却被当正加，说明负负得正规则未掌握。
3. 两个时间间隔不等时误判公式不可用，实际只需三个连续时间点即可。
