# 方法卡：假设分配/小丑法求基期

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 假设分配/小丑法求基期 |
| 适用题型 | 资料分析——已知现期值和增长率求基期 |
| 触发场景 | 题目给出现期值和增长率，要求估算或精算基期值，且直接除以(1+r)计算量较大或精度不够 |
| 步骤逻辑 | ### 假设分配法；1. 设基期为一个"好算"的整数（如取100、700等）；2. 用基期 × 增长率算出增量；3. 基期 + 增量 = 现期，与题目现期做差微调；4. 最终得到近似基期值### 小丑法；1. 基期 ≈ 现期 × (1 - r + r²)，其中 r 为增长率；2. 即除以(1+r) ≈ 乘以(1 - r + r²)；3. r² 用"7%的平方≈0.49取0.4"之类近似；4. 适合增长率6%-10%的范围 |
| 高频错因 | 假设分配时取的初始值不合适，导致计算量大小丑法中 r² 的近似取值偏差过大两种方法混用导致公式混乱 |
| confidence | medium |

## 不适用条件

- 增长率超过20%时，小丑法的近似误差偏大，应改用精算（直接除以1+r）或假设分配法
- 题目要求精确到个位且选项差距很小时，两种近似方法的精度都不够，应直接做除法
- 增长率为负值（同比下降）时，小丑法的展开式需要调整符号，容易出错，建议用假设分配法

## 反向触发

- 若增长率数值不在6%-10%范围内且使用小丑法，需先评估r²近似项的误差是否可接受
- 若无法确定增长率的正负号（如增量为负但基数关系不明），先标记待核验再选方法
