# 方法卡：内外区分法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 内外区分法 |
| 适用题型 | 加强削弱——两个观点分别归因于"内部"和"外部" |
| 触发场景 | 题干出现两种对立归因（一内一外），需要判断选项支持哪一方 |
| 步骤逻辑 | ① 先把两个观点拆成"内因"和"外因"两条线；② 看清题目问支持还是削弱哪个观点；③ 逐个选项判断它归到哪条线、方向是否匹配；④ 若选项方向不明（如A选项"中毒"不确定是否与细菌相关），按最不利方向归类，只要不是支持目标方向就排除 |
| 高频错因 | 没有先做内外分类就直接逐项判断；选项含模糊概念时无法区分是削弱还是无关，误判方向 |
| confidence | high |

## 补充说明

内外因分类后，支持外因线可优先找指向"外因被人为施加"的必要条件选项。对模糊概念选项（无法确定归属内因还是外因），按最不利方向归类——只要不是支持目标方向就排除。必要条件作为支持力度有限但方向正确。

## 不适用条件

- 题干只有单一归因，不存在内外因对立时，不适用本方法。
- 两个观点并非归因对立，而是程度/范围/时间等维度的分歧时，不适用本方法。

## 反向触发

- 当选项中同时涉及内因和外因的交叉概念时，应换用"归因类削弱嵌套因果链"方法处理因果链关系。
- 当题干问的是"根本原因"而非"支持哪一方"时，应补充核验选项建立的是直接因果还是间接因果，避免方向误判。
