# 方法卡：软选项硬选项判断法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 软选项硬选项判断法 |
| 适用题型 | 言语理解——细节判断/中心理解 |
| 触发场景 | 选项中有表述偏绝对的和表述灵活的 |
| 步骤逻辑 | ① 标记选项中的范围词、程度词和绝对化词；② “一定/必须/所有”等硬表述优先核对原文是否提供同等强度依据；③ 软表述同样要核对范围，不能因语气保守就默认正确；④ 最终以原文对应关系为准 |
| 高频错因 | ① 仅凭硬表述就排除，漏掉原文明确支持的强结论；② 仅凭软表述就选择，忽略其主体、范围或关系仍可能被偷换 |
| confidence | medium |

## 不适用条件
- 四个选项软硬程度相近，无明显区分时
- 正确答案经原文验证确实是硬表述时（此法仅为概率辅助，非绝对规则）
- 题型为逻辑填空或数量关系等非选项判断类题型时

## 反向触发
- 选项出现"一定""必须""所有""绝不"等词时，优先回原文核对强度，不得仅凭用词排除
- 四个选项中仅有一个软选项时，也必须核对主体、范围和关系，不能据此直接选择

## 补充说明
软硬表述只用于安排核对顺序：硬表述重点查证据强度，软表述重点查范围是否扩大。它不能代替原文定位和逐项验证。
