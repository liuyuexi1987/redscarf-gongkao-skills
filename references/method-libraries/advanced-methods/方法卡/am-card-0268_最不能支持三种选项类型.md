# 方法卡：最不能支持三种选项类型

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 最不能支持三种选项类型 |
| 适用题型 | 论证题，问"最不能支持" |
| 触发场景 | 问法为"以下哪项最不能支持上述观点" |
| 步骤逻辑 | 1. 理解"最不能支持"有三种可能答案类型：- 有削弱选项 → 选削弱（削弱最"不能支持"）- 无削弱选项但有无关 → 选无关- 四个都能支持 → 选支持力度最弱的；2. 先逐项判断是否能削弱，有削弱直接选；3. 无削弱则找无关项；4. 若四个都支持，比较支持力度，选最弱的 |
| 高频错因 | 只考虑"选无关"一种路径，忽略了可能四个都能支持需要比力度的情况 |
| confidence | high |

## 不适用条件

1. 问法为"最能支持"或"最能削弱"，而非"最不能支持"
2. 题目是纯粹的事实判断或推理题，不涉及论证支持力度比较
3. 选项中只有一个与题干相关，其余均为无关项，无需三路径判断

## 反向触发

1. 若确认只有一个选项对论点构成削弱，可优先锁定；仍需核对题目问法确为“最不能支持”
2. 题目考查形式逻辑推理（如假言推理、排列），不涉及论证力度
3. 问法为"以下哪项如果为真，最能支持"，方向相反
