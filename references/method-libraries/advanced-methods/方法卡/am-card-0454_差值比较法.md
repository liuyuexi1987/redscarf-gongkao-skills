# 方法卡：差值比较法（上下期对比）

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 差值比较法（上下期对比） |
| 适用题型 | 资料分析——两组数据总量差值比较 |
| 触发场景 | 题目给出两组按月份（或分段）的数据，问哪一组总量更大或总量差值是多少，且直接加总计算量较大 |
| 步骤逻辑 | 1. 不建议逐段加总再比较（计算量大）；2. 逐月算出两期对应月份的差值（如135-147=正12）；3. 将所有差值正负累加；4. 总和为正 → 前者大；总和为负 → 后者大；5. 有些差值明显能消掉（一正一负），只需算剩余部分 |
| 高频错因 | 真的逐段加总再比较，浪费大量时间差值正负搞反（产量-销量 vs 销量-产量方向不一致）遗漏某个月份 |
| confidence | medium |

## 不适用条件

- 只有两三段数据、直接加总即可快速完成时，差值法反而增加操作步骤，不如直接加总
- 两组数据差异极大、明显一方远大于另一方时，无需逐月算差值，直接判断即可
- 题目要求的是精确总量差值而非"谁大谁小"时，差值累加法只能判断方向，不能给出精确值

## 反向触发

- 若月份（或分段）数量不一致（一组有12个月另一组只有10个月），先确认缺失月份是否为零，再决定是否使用本法
- 若差值正负号方向无法统一确认（如两组数据的单位或口径不一致），先标记待核验
