# 方法卡：反推验证法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 反推验证法 |
| 适用题型 | 片段阅读-中心理解题 |
| 触发场景 | 二选一纠结时，把文段盖住只看选项，反推它对应的原文应是什么类型 |
| 步骤逻辑 | 1. 盖住原文，只看选项；2. 根据选项内容推断：如果选它，原文应该是什么文段类型；3. 反推出的文段类型与实际文段类型一致则可选，不一致则排除；4. 例：选项是中性科普概括 → 反推原文应是科普类；但实际原文有对策 → 排除 |
| 高频错因 | 不做反推，凭感觉二选一；或反推时不考虑文段类型只看内容对错 |
| confidence | medium |

## 不适用条件

1. 题目属于资料分析或数量关系类，选项涉及具体数值和计算，不能用文段类型反推。
2. 所有选项表述风格一致（如都是中性概括或都是对策），反推无法产生区分度。
3. 考场时间极紧张，反推验证需要额外时间，可作为二选一的辅助手段而非首选方法。

## 反向触发

1. 如果反推出多个选项都匹配文段类型，需回到原文对比哪个选项最全面覆盖核心内容。
2. 如果反推时发现选项褒贬倾向与原文相反，直接排除，不必再比较内容。
3. 如果反推无法判断（文段类型本身模糊），应结合三类文段分类法先确定文段类型，再做排除。
