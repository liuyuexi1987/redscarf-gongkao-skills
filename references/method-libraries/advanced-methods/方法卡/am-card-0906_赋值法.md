# 方法卡：赋值法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 赋值法 |
| 适用题型 | 数量关系——方程/工程/比例题 |
| 触发场景 | 题目没有给出具体效率/速度等数值，只有时间或比例关系 |
| 步骤逻辑 | ① 判断题目是否涉及具体效率/速度值（如果没涉及，可以赋值）；② 根据比例关系赋方便计算的值（如效率比2:1就赋2和1）；③ 用赋值后的数据计算；④ 注意：若题目给出了具体值（如"效率是10"），则不能赋值 |
| 高频错因 | ① 在题目已有具体值时赋值导致冲突；② 赋值后忘记题目问的不是赋值的量 |
| confidence | high |

## 补充说明

判断能否赋值的标准：题目从头到尾有没有给出该量的具体数值。没有就可以赋值，赋值不影响答案因为答案与该量的具体值无关。

## 不适用条件

- 题目已明确给出该量的具体数值（如"效率为10"），赋值会与已知条件冲突。
- 题目所求恰好是被赋值量的真实数值本身（赋值无法还原原值）。
- 题目存在多个相互约束的具体量，赋值后无法同时满足所有约束。

## 反向触发

- 当题干给出多个具体数值并要求精算结果时，应改用直接列方程求解，不再赋值。
- 当赋值后计算出现非整数或矛盾中间结果时，应核验题目是否隐含具体值，必要时放弃赋值改用精算。
- 当题目问"该量本身是多少"时，应改用方程或比例还原原值，而非赋值。
