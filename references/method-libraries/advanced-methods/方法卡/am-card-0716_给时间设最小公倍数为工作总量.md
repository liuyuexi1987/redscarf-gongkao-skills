# 方法卡：给时间设最小公倍数为工作总量

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 给时间设最小公倍数为工作总量 |
| 适用题型 | 工程问题中，已知条件给出不同主体各自完成工作所需的时间 |
| 触发场景 | 题干给出"甲单独做需200天，乙单独做需300天"等具体完工时间 |
| 步骤逻辑 | 1. 取各人完成时间的最小公倍数，设为工作总量（如200和300 → 600）；2. 用总量除以各人时间，得到各自效率（甲=600/200=3，乙=600/300=2）；3. 后续计算全部基于整数效率，避免分数 |
| 高频错因 | 求完剩余工作量后忘记加上已合作的天数（如问"共需多少天"时漏加前面合作的天数）最小公倍数求错导致效率出现分数，后续计算复杂化设成公倍数但数值过大（如设12000），效率数字过大易算错 |
| confidence | medium |

## 不适用条件

- 各主体完成时间互质且数值较大，最小公倍数过大导致效率数字失控。
- 题目未给出各自完成时间，而是给出效率比或工作量比，无法直接取时间最小公倍数。

## 反向触发

- 当时间数值较大且互质时，应改用"效率比直接当效率用"以比例代替具体效率。
- 当题目涉及效率中途变化时，应先用"效率变化统一基准法"统一基准再设工作总量。
