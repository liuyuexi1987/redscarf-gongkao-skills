# 方法卡：生活化图形规律优先级

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 生活化图形规律优先级 |
| 适用题型 | 判断推理——图形推理 |
| 触发场景 | 图形是生活化物品（房子、水果、人物等） |
| 步骤逻辑 | ① 面（面的数量、相同面的形状）→② 部分数→③ 开闭性→④ 连接方式 |
| 高频错因 | ① 生活化图形画得乱→规律少→不要想太复杂；② 忽略面的考法 |
| confidence | high |

## 不适用条件

1. 非生活化图形（几何图形、抽象图形）时。
2. 只有单幅图且缺少可比对的选项或前后图时。
3. 图形明显考查属性类规律（对称、旋转）时。

## 反向触发

1. 当面、部分数、开闭性、连接方式均无规律时，应换用属性类或位置类规律。
2. 当生活化图形呈现明显位置变化时，应补充考察移动/旋转规律。
3. 当优先级路径均失败时，应核验是否为分类分组题。
