# 方法卡：中心理解预设答案

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 中心理解预设答案 |
| 适用题型 | 中心理解 |
| 触发场景 | 做完文段结构分析后，尚未看选项 |
| 步骤逻辑 | 1. 判断题型为中心理解；2. 从结构上分析文段（转折、并列、总分等），确定每句话的结构作用；3. 根据结构自行预设一个正确答案；4. 让选项符合你的预设，而非从选项中分辨对错 |
| 高频错因 | 先看选项再分析文段，被错误选项绕进去 |
| confidence | high |

## 不适用条件

1. 非中心理解题型（如细节判断题、标题填入题需结合选项风格）
2. 文段结构过于复杂，难以快速判断结构作用
3. 需要逐一对比选项细微差异的题目

## 反向触发

- 题干问"这段文字主要说明""这段文字意在""作者意在强调"等典型中心理解问法
