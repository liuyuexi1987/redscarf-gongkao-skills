# 方法卡：百分比转比例

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 百分比转比例 |
| 适用题型 | 数量关系·比例关系 |
| 触发场景 | 题目用"慢75%""慢50%"等百分比描述速度/效率差异 |
| 步骤逻辑 | 1. 将参照对象视为100%；2. "慢75%" → 自身为100%-75%=25% → 比例1:4；3. "慢50%" → 自身为50% → 比例1:2；4. 转化为比例后，再用正比/反比关系求解 |
| 高频错因 | 直接把75%当比例用，忘记要与100%做差 |
| confidence | high |

## 补充说明

百分比描述本质上就是"与参照物的比值关系"，转化为整数比更方便计算。

## 不适用条件

- 题干未指明参照对象（"慢75%"缺少基准——相对谁慢），无法确定比例基准。
- 百分比对应的是绝对值而非相对差（如"占75%"是占比，不是相对差异，不应做差转换）。
- 转换后的比例不是整数比或最简形式，进一步化简才能用，否则反而增加计算负担。

## 反向触发

- 当题目已直接给出整数比时，无需再做百分比转换，直接进入正比/反比求解。
- 当百分比表示占比而非相对差异时，应改用比例和份数法直接处理。
- 当题目需要精算而非估值时，应改用方程法避免比例转换中的舍入误差。
