# 方法卡：否前不否后——前件未满足推不出

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 否前不否后——前件未满足推不出 |
| 适用题型 | 判断推理——翻译推理类（条件命题推理） |
| 触发场景 | 题干给出A→B且C类条件命题，但前提A不成立（非A），问能推出什么 |
| 步骤逻辑 | ① 翻译条件命题为A→B且C；② 检查前提是否满足——如果给的是非A（前件为假），则箭头不成立，推不下去；③ 后件B和C的发生与否均未知：可能去了也可能没去，什么也推不出来；④ 只有肯前（A成立）才能推出后件；否前+肯后均不能推出确定结论；⑤ 类比："写完作业带你去公园和游乐场"→没写完→去没去公园不知道，去没去游乐场也不知道 |
| 高频错因 | 看到非A就想当然推出"非B且非C"（否前否后谬误）；误以为A推B切C的逆否可以对单个后件推出结论；被选项中的具体名词迷惑，忘记检查前件是否满足 |
| confidence | high |

## 补充说明

典型情况：条件为"A→B且C"，前提给出"非A"（前件不成立），则B是否成立、C是否成立均无法推出，所有涉及后件确定性的选项均选不出。迷惑性在于选项内容看似合理，但只要前件不满足就什么也推不出。口诀：否前无必然，推不出后件。

## 不适用条件

- 题目已给出肯前（A成立），可直接推出后件B且C，不涉及否前问题
- 条件命题是A→B（单一后件）且无附加"且"关系，逆否推理更直接
- 题目问的是"以下哪项为真"并有额外信息可联合推理，而非单纯考查条件命题本身

## 反向触发

- 若题目条件为非A且选项中出现"可能B也可能非B"这类表述，这是正确方向（否前推不出确定结论），不要排除
- 若给出的是"非B"（否后），应先推出"非A"（逆否命题），再看能否继续推理，不要套用"否前不否后"规则
