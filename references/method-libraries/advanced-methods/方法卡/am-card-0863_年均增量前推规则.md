# 方法卡：年均增量前推规则

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 年均增量前推规则 |
| 适用题型 | 资料分析——年均增量计算（涉及不同考试的出题逻辑差异） |
| 触发场景 | 题目问"从A年到B年的年均增量"，需要判断是否前推基期 |
| 步骤逻辑 | ① 常规问法（哪年到哪年年均增量）：仅江苏省前推一年，其他地方不推；② 五年计划问法：全国统一前推，基期为上一个五年计划最后一年；③ 问某几年中哪年增速最高：所有地方都需要考虑前一年数据；④ 问某几年中人均指标最高：所有地方都不需要前推 |
| 高频错因 | ① 非江苏考生误用前推规则；② 江苏考生忘记前推；③ 五年计划忘记前推；④ 混淆"逐年上升/下降"判断与年均增量的前推规则 |
| confidence | high |
| 不适用条件 | 题目问的是年均增长率而非年均增量（年均增长率有独立公式）；题目明确给出起止年份的具体数值，直接做差除以年数即可，无需判断是否前推 |
| 反向触发 | 题目考查的是年均增长率的计算（套用年均增长率公式）；题目问的是某一年的增量或增速，而非跨期的年均增量 |

## 补充说明

前推本质源于江苏将"年均增量"理解为"每年增量的平均值"，数学推导后等价于基期前推一年。可通过历年真题验证各地出题逻辑。
