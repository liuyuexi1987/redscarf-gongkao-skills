# 方法卡：工程问题设工作量为最小公倍数

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 工程问题设工作量为最小公倍数 |
| 适用题型 | 工程问题中给出两个或多个主体各自完成工作的时间 |
| 触发场景 | 题干给出甲单独完成需X天、乙单独完成需Y天，需要求合作效率或时间 |
| 步骤逻辑 | 1. 设工作总量 = 各人完成时间的最小公倍数（如8天和10天→设总量为40）；2. 各人效率 = 总量 ÷ 各自时间（如甲效率=40/8=5，乙效率=40/10=4）；3. 后续计算全部用整数效率，避免分数运算 |
| 高频错因 | 直接设工作量为1，导致效率全是分数，后续计算繁琐易错忘记设完工作量后要重新算效率 |
| confidence | medium |

## 补充说明

- 此技巧为工程问题的基础前置步骤，与"合作完工整体思想"配合使用。
- 例如两主体分别需8天和10天完成，设工作总量为最小公倍数40，则效率分别为5和4，整数计算更方便。

## 不适用条件

- 各主体完成时间互质且数值较大，最小公倍数过大导致效率数字失控。
- 题目给出的是效率比或工作量比而非完成时间，无法直接取时间最小公倍数。

## 反向触发

- 当时间数值较大且互质时，应改用"效率比直接当效率用"以比例代替具体效率。
- 当题目涉及效率中途变化时，应先用"效率变化统一基准法"统一基准再设工作总量。
