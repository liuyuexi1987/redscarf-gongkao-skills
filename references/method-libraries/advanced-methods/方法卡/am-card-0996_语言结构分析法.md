# 方法卡：语言结构分析法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 语言结构分析法 |
| 适用题型 | 逻辑填空——语法搭配 |
| 触发场景 | 选项词性不一致（有动词有名词有形容词），或并列结构要求词性一致 |
| 步骤逻辑 | ① 分析空格在句中的语法成分（主语→名词、谓语→动词、定语→形容词）；② 排除词性不匹配的选项；③ 并列的几个词词性必须一致 |
| 高频错因 | ① 不注意词性→选了动词填在名词位置；② 并列结构中一个动词一个名词→至少有一个是错的 |
| confidence | high |

## 补充说明
例如"动作施加对象要一致"：前面是"视而不见+静止的物体"→后面的词也必须是"什么什么+运动的物体"的结构。又如"手到擒来"一般不做定语（形容词），更多做谓语。判断时优先看空格在句中的语法成分，再排除词性不匹配的选项。

## 不适用条件
- 选项词性完全一致（同属动词、同属名词或同属形容词）时，本方法不产生区分价值。
- 文段无并列结构、空格所在成分单一明确时，无须做词性核验。
- 成语题中成语本身可充当多种成分（既可做谓语也可做定语），词性判断模糊时本方法可靠性下降。

## 反向触发
- 当词性排除后仍剩余多个候选时，应换用"自带逻辑词判断法"或"前后空呼应关系"做语义层面区分。
- 当并列结构内部词性要求与语法成分判断出现冲突时，应回到文段核验并列项的真实语法角色，避免误用本方法。
- 当选项间差异主要在语义轻重或感情色彩而非词性时，应改用语体色彩或语义轻重判断。
