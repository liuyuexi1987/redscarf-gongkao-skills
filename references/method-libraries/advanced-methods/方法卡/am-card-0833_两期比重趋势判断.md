# 方法卡：两期比重趋势判断

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 两期比重趋势判断 |
| 适用题型 | 资料分析——两期比重比较·定性分析（比重趋势），判断比重上升/下降 |
| 触发场景 | 题目问某部分占整体的比重"比上年上升/下降"或"高于/低于上年"，不要求算具体百分点 |
| 步骤逻辑 | ① 明确分子（部分）的增长率R1和分母（整体）的增长率R2；② 比较R1和R2的实际大小（带正负号比较，不是绝对值）；③ R1 > R2 → 比重上升，R1 < R2 → 比重下降，R1 = R2 → 比重不变；④ 若问过去（基期）比重大于还是小于今年，再推一步：比重上升则基期更小，比重下降则基期更大 |
| 高频错因 | ① 用绝对值比较R1和R2，忽略负号（如-5% > -10%）；② 把"比重趋势"和"比重差"混淆，趋势不求具体数值；③ 找R1/R2时张冠李戴，把分子分母对应的指标搞反；④ 混淆环比和同比，题目要求与上月比时误用同比增速 |
| confidence | medium |

## 补充说明

比重本质是一个分数（部分/整体），两期分别乘上(1+R1)和(1+R2)，分子分母谁涨得快决定了分数变大还是变小。R1和R2的比较看的是实际值大小，5% > -3%，-5% > -10%。该方法不做具体数值计算，只做定性判断，适用于"以下哪项正确/错误"的综合判断题和趋势题。若题目进一步问基期比重与本期的大小关系，见"比重趋势多步推基期"卡。

## 速算边界

当估算误差可能跨越选项或改变结论时，改用精算/验证。

## 不适用条件

- 题目要求求具体百分点数值时，本方法不够用，需转"比重差识别与速解"卡。
- R1或R2本身数值不确定（材料只给范围或"约"值）且两者接近时，趋势判断可能不成立，需谨慎。

## 反向触发

- 题目问"上升/下降了几个百分点"而非"上升还是下降"，直接用比重差公式。
- 材料没有给出R1或R2，无法做趋势判断，需先补数据。
