# 方法卡：季度产量用累计差减法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 季度产量用累计差减法 |
| 适用题型 | 资料分析-季度比较/季度产量计算 |
| 触发场景 | 题目问"某季度产量最高"或需要计算某季度数据，且表格只给累计值 |
| 步骤逻辑 | 1.理解累计含义：3月累计=1~3月总产量，6月累计=1~6月总产量；2.第一季度=3月累计（无需减法）；3.第二季度=6月累计-3月累计；4.第三季度=9月累计-6月累计；5.第四季度=全年累计-9月累计 |
| 高频错因 | 1.把累计值当成当月值；2.算第二季度时忘记减去第一季度；3.找错累计对应的列 |
| confidence | high |

## 不适用条件

1. 表格直接给出各季度（或各月）的独立数值而非累计值时，无需差减，直接读取即可。
2. 题目问的是月度数据而非季度数据——月度差减用的是相邻月累计之差，周期对应不同，不能套用季度逻辑。
3. 累计值的统计周期与标准季度不一致（如某些行业按财年而非自然年累计）时，需先确认累计区间再决定减法关系。

## 反向触发

1. 表格结构为"各季度独立列"而非累计列——直接读取，差减法不适用。
2. 题目只问全年总量或年度同比——不需要拆分季度，直接用全年累计或对应年度数据。
3. 需要计算的是季度间的同比增率（如Q2同比增速），此时需用本季累计差减得当季值，再和去年同季当季值比，步骤更复杂，不能只做差减。

## 补充说明

季度问题本质是累计值的差减。算基期时增率很小（<10%）可用化除为乘：基期=现期-现期×R。本集算Q4时用全年308.6减去前三季度累计222得到86，最大。注意不要找错增率列——累计产量对应的是累计增率，当月产量对应当月增率。
