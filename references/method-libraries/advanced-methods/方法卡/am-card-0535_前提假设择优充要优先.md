# 方法卡：方法卡：前提假设择优——充要>必要>充分（排除）

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 方法卡：前提假设择优——充要>必要>充分（排除） |
| 适用题型 | 前提假设类题目（逻辑判断） |
| 触发场景 | 题干问"必须补充的前提"，多个选项都像"必要条件"，需要择优选择 |
| 步骤逻辑 | 1. 先排除"唯一途径""唯一有效方法"类选项——前提不要求唯一性；2. 排除程度过高的选项（如"所有都满分"比"至少50人过75分"更强，但不是必要前提）；3. 优先选择"既充分又必要"的条件（充要条件）；4. 其次选"单独的必要条件"；5. 绝对不选"单独的充分条件"（过度/超出最小限度） |
| 高频错因 | 把"充分条件"当成前提（如"所有同学满分"可以推出结论，但它过度了，不是前提）看到能推出结论就选，忽略"最小限度"要求混淆"能推出"和"是必要前提" |
| confidence | high |

## 补充说明

- 用班成绩举例：结论"一半以上超75分"。A"都满分"是充分但过度→排除；B"至少51人过75"是充要→最优；C"都及格"是必要但推不出→勉强可选。优先级：B > C > 排除A。
- 充要条件既保证结论成立，又不超过必要限度，是前提题的首选。
- 否定代入法可辅助验证：否定所选项后结论是否不成立。

## 不适用条件

- 题干已明确只有一个选项可作为前提、无需择优时，直接用否定代入法验证即可。
- 论证结构为类比或归纳（非演绎推理），充要/必要/充分的逻辑区分不适用。
- 题目问"最能加强/支持"而非"必须补充的前提"时，前提优先级不适用（加强题优先搭桥）。

## 反向触发

- 当所有选项都是必要条件、无法按充要/必要分层时，改用否定代入法逐一验证。
- 当题干论据与结论之间存在明确概念断层时，优先用搭桥法找断点处的前提。
- 当选项涉及估算数据且误差可能跨越选项时，改用精算后再判断前提属性。
