# 方法卡：资料分析速算判定与估算边界

| 字段 | 值 |
|------|-----|

| 适用题型 | 资料分析——所有需要计算的题目 |
| 触发场景 | 定位数据后、开始计算前，决定用估算还是精算 |
| confidence | high |
| 反向触发 | - 纯读数题：数据可直接从材料读出，无需任何计算

## 适用条件

- 所有资料分析计算题
- 尤其适用于选项差距不明确、不确定该估还是该精算的情况

## 不适用条件

- 纯读数题（数据直接可读，无需计算）
- 纯比较题（只需判断大小关系，不需求值）

## 核心判断

先估算，估算能区分选项就直接选；估算不能区分再精算。不要上来就精算，也不要估算后不敢选。

## 步骤逻辑

1. **先看选项差距**：用比例法判断（差值÷较小选项），而非看绝对差值
   - 比例 > 20%：随便估
   - 比例 5%~20%：中等精度，放缩或份数
   - 比例 < 5%：需要高精度，放缩精细操作或直除
2. **估算一版**：用截位、百化分、放缩等方法快速算出近似值
3. **判断估算结果能否区分选项**：估算值落在两个选项之间且离边界很近→需要精算；估算值明显靠近某个选项→直接选
4. **估算不能区分时再精算**：用直除、假设分配等方法精确计算
5. **精算时保留足够精度**：分母含(1+增速)形式时保留4位有效数字，避免截位丢精度

## 高频错因

- 选项差距大时仍精算→浪费时间
- 选项差距小时仍粗估→误差跨选项选错
- 估算后不敢选，实际误差远小于选项差距
- 看绝对差值而非比例差值（选项差10，对于结果3是33%，对于结果300是3%）
- 分母是增速时只保留3位，把15.12%截成15.1%，丢失精度

## 是否允许估算

- 选项差距大（比例>20%）：允许粗估，误差可接受
- 选项差距中等（5%-20%）：允许中等精度估算
- 选项差距小（<5%）：不允许粗估，必须精算或高精度放缩

## 何时必须精算

- 选项比例差距 < 5%
- 估算结果落在两个选项边界附近，无法区分
- 题目要求精确值（如"以下哪个正确"的综合分析题）

## 常见误差来源

- 截位时分子分母反向截（一个变大一个变小），误差叠加
- 百化分选错近似分数（如把14.3%当成1/7，实际1/7≈14.2857%，误差约0.2%）
- 放缩方向不一致，导致结果偏大或偏小
- 量级搞错（如结果应该是0.2却选了2）

## 补充说明

- 速算判定三标签（可快速定位 / 不宜粗估需直除或精算 / 数据不足待核验）是讲解时的固定输出格式，本卡提供判定依据
- "可快速定位"的充要条件：允许近似 + 选项差距足够 + 数据可信，三者缺一不可
- 即使问法含"最接近/约为"，若选项间距很小，仍必须精算
