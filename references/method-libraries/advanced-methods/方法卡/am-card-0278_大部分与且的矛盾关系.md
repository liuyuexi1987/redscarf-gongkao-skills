# 方法卡：大部分与且的矛盾关系

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 大部分与且的矛盾关系 |
| 适用题型 | 逻辑判断中涉及"大部分"量词和选言/联言转换的题 |
| 触发场景 | 题干说"大部分A或B"，选项涉及A且B的数量判断时 |
| 步骤逻辑 | 1. "大部分A或B"的矛盾是"大部分A且B"（或变且、两边加非、大部分不变）；2. 因此"小部分非A且非B"（即A且B只能是小部分）一定成立；3. 若选项说"一半地区既干旱又寒冷"，因一半与大部分矛盾，该选项一定为假；4. 或命题只需一边成立即可为真：全部都是干旱但不寒冷的情况也可以满足"非干旱或非寒冷" |
| 高频错因 | 不理解"或"只需一边成立即可；误以为或命题两边都得满足 |
| 不适用条件 | 题干不涉及"大部分/小部分"量词与或/且逻辑的转换；量词为精确比例（如"恰好50%"）而非模糊量词 |
| 反向触发 | 题目只涉及简单命题的真假判断，不含或/且转换和量词矛盾关系 |
| confidence | high |
