# 方法卡：比值增长率

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 比值增长率 |
| 适用题型 | 资料分析——求平均数、人均、单价等比值的增长率（材料未直接给出该比值） |
| 触发场景 | 题目问某比值（如人均消费、出口均价）的增长率，但材料中找不到该比值的直接数据 |
| 步骤逻辑 | ① 识别：找不着量→想表达式→A=B/C→比值增长率；② 确定R1（分子增长率）、R2（分母增长率）；③ 套公式：R = (R1 - R2) / (1 + R2)；④ 用拆分法计算 |
| 高频错因 | R1/R2位置搞反（R1是分子，R2是分母）；忘记分母的"1+" |
| confidence | medium |

## 补充说明

识别口诀："找不着量想表达式"。如果A=B/C，且B、C的增长率已知，就套比值增长率公式。分子是R1，分母是R2（"正常人从上往下"）。大部分考的是平均数，但也有其他比值（如不良贷款率=不良贷款/贷款总额）。

## 不适用条件

- 目标量不是分子与分母的比值，或两者统计口径不一致。
- 分母增速缺失且无法由材料反推。

## 反向触发

- 只问比值升降方向时，先比较分子、分母增速，无需完整计算。
- 题目问比值差而非增长率时，转用对应平均数差或比重差公式。
