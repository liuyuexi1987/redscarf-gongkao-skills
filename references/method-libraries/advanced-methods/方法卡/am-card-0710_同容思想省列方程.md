# 方法卡：同容思想省列方程

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 同容思想省列方程 |
| 适用题型 | 工程问题中，已知总工作时间、各人效率，需要求某人实际工作了多长时间 |
| 触发场景 | 已设好工作总量和效率，出现"甲先做若干天，剩余由乙完成，共用了42小时"这类条件，传统做法需要列方程 |
| 步骤逻辑 | 1. 假设全部时间都由效率低的人来做，算出能完成的工作量；2. 用实际工作总量减去假设完成量，得到差额；3. 差额由效率高的人"替代"完成，每替代1小时多做（高效率-低效率）份工作；4. 差额 ÷ 效率差 = 效率高的人实际工作的小时数 |
| 高频错因 | 忘了求的是"共需多少天"还是"某人干了多少天"，答非所问效率差方向搞反（谁替代谁） |
| confidence | medium |

## 补充说明

- 本质是鸡兔同笼思想在工程问题中的应用：假设全部时间都由效率低的一方完成，算出与实际工作总量的差额，再用效率差去补。
- 若不适应假设法，可直接列方程求解，结果等价，本方法只是更快。

## 不适用条件

- 题目未给出"总工作时间"或无法确定总用时，假设法缺乏对照基准。
- 多于两人交替工作且各自效率不同，差额替代关系不单一，假设法反而更复杂。

## 反向触发

- 当题目求的是"总用时"而非"某人工作时长"时，应直接用"给时间设最小公倍数为工作总量"求合作时间。
- 当效率差为零（两人效率相同）时，假设法失效，应改用普通合作完工计算。
