# 方法卡：分数数列三种考法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 分数数列三种考法 |
| 适用题型 | 数量关系——数字推理（分数数列） |
| 触发场景 | 数列中出现分数 |
| 步骤逻辑 | ① 常规：反约分/通分（分子分母各自等差）→先倾向递增趋势化（如3→6）；② 进阶：分子分母各自有倍数关系→交叉递推；③ 高级：分数是外皮，本质是多级数列（分数间做差/做商） |
| 高频错因 | ① 只想到反约分→漏掉递推和多级数列；② 不做趋势化→看不出规律 |
| confidence | high |

## 补充说明
分数数列三种考法按难度递增：反约分（基础）→交叉递推（进阶）→多级数列（高级）。实际做题时按此顺序逐层尝试。

## 不适用条件
- 分数只是偶发形式，且整数项已经呈现更稳定规律时，先验证整数规律
- 分子分母无法通过约分、通分或趋势化形成稳定序列时，应改查递推、做差或做商
- 数列有明显负数或混合小数，应先处理符号/格式

## 反向触发
- 如果数列全为整数，不使用本方法
- 如果反约分后分子分母各自有规律但与选项不符，应考虑递推或多级数列
