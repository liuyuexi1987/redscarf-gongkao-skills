# 方法卡：五种行文结构判断法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 五种行文结构判断法 |
| 适用题型 | 言语理解——主旨概括/意图判断（所有文段类型） |
| 触发场景 | 需要判断文段行文结构以确定主旨句位置或概括方式时 |
| 步骤逻辑 | ① 后对策：提出问题→分析→最后给对策（选对策）；② 前对策：引出话题→直接给对策→后文论证或具体展开（对策是主旨句，若展开太碎则用宏观对策概括）；③ 总分/分总：总句是重点，直接对应；④ 并列(分分)/大并列(分分分)：无概括句，需全文概括，选A且B类选项；⑤ 二层结构：转折对比、因果、背景+正文、设问回答等，需具体分析 |
| 高频错因 | 并列文段只看部分不看整体；前对策文段后文展开太碎时纠结选宏观还是具体对策；分分分结构盯着单一句子提炼重点 |
| confidence | medium |

## 补充说明

- 前对策后文有两种可能：论证（后重复对策）或具体展开。绝大多数是论证，具体展开的较少。若对策展开太碎不好概括，用宏观对策。
- 并列和大并列文段，文段中没有概括句时需要自己概括，选项往往呈"A且B"形式，即一个选项等于另外几个选项之和。
- "单句重点"只适用于有主旨句的结构（后对策/前对策/总分/分总），并列结构必须全文概括。

## 不适用条件

1. 文段行文结构混杂，多种结构交织（如前半段总分、后半段转折），单一套用五种分类中的任何一种都可能遗漏重点。
2. 题目考查细节定位（如"以下哪项符合文段"），无需判断整体行文结构。
3. 文段过短（仅2-3句），结构信号不足以明确归类时，应直接比对选项与原文语义。

## 反向触发

1. 初步判断为某一结构但答案无法匹配时，应重新审视是否为混合结构，尝试用文段重心法（后半段或转折后）重新定位。
2. 并列结构中某一论点篇幅远大于其余时，需警惕是否实际为总分结构，而非简单并列。
