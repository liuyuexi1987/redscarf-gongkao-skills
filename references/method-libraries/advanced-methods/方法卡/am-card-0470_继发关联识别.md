# 方法卡：继发关联识别

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 继发关联识别 |
| 适用题型 | 判断推理 > 削弱质疑（归因题） |
| 触发场景 | 题干发现A和B同时出现，归因为A→B；实际可能A和B都是C的结果 |
| 步骤逻辑 | 1. 题干模式：A发生时B也发生 → 结论A导致B（相关≠因果）；2. 继发关联：存在C，C既导致A又导致B；A和B只是同时出现的两个结果；3. 正确质疑选项结构：C导致A，也导致B（两者并列，非因果）；4. 识别标志：选项出现"也导致""同时"等并列措辞 |
| 高频错因 | 只会"另有他因"和"因果倒置"两种质疑，不知道"共同原因导致两个并列结果"这种第三种归因质疑 |
| confidence | high |

## 不适用条件

1. 题干论证已明确排除共同原因（如设有对照组或已控制变量）。
2. A与B有明确的先后顺序或传导机制（非同时并列出现），继发关联模式不匹配。
3. 题干结论未做因果归因（仅描述相关性），质疑方向应针对推理跳跃而非共同原因。

## 反向触发

1. 选项结构为"其实是B导致A"（因果倒置），与继发关联（A和B都是C的结果）不同，因果倒置力度通常更强，应优先识别。
2. 当存在直接阻断A→B传导机制的选项时（如A和B之间无已知物理/逻辑联系），切断因果链条比引入第三变量更直接。
3. 选项既非共同原因结构也非因果倒置，而是"另有他因"（D导致B），此时归因方向不同，应按另有他因路径评估。
