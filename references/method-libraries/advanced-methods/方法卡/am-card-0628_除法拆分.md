# 方法卡：除法拆分

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 除法拆分 |
| 适用题型 | 资料分析——比重类除法（分子<分母）、百分比计算 |
| 触发场景 | 分子在分母的50%、10%、100%附近时；需要快速估算百分比 |
| 步骤逻辑 | ① 判断分子在分母的哪个百分比附近；② 取该百分比对应的分子值（如50%就取分母的一半）；③ 算差值，用"包子"比喻判断加减几个百分点；④ 组合结果 |
| 高频错因 | 1%（包子价）算错；加减方向搞反；分母为奇数时除二纠结 |
| confidence | medium |

## 补充说明

核心比喻：分母是买100个包子的总价，1%就是一个包子的价格（分母÷100）。分子比一半多/少几个包子，就在50%上加/减几个百分点。建议分母保留偶数（方便除二），用"同进同舍"原则。50%附近和100%附近都适用。

## 不适用条件

- 分子不接近熟悉比例，或选项需要高精度区分。
- 分母经过截位后会使误差方向不明或跨越选项。

## 反向触发

- 与基准比例的差值不便换算时，改用直除或选项反乘。
- 同进同舍后应检查比值变化方向，无法判断时不要继续近似。
