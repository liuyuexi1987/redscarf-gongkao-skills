# 方法卡：间隔增长率逆运用

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 间隔增长率逆运用 |
| 适用题型 | 资料分析 - 增长率计算 |
| 触发场景 | 已知间隔增长率R和某一年同比增速R1，求另一年R2（材料给的是两年对比三年的数据） |
| 步骤逻辑 | 1. 识别题型：材料给的是"比XX年增长X%"（间隔）和其中一年同比，求另一年同比 → 典型间隔逆运用；2. 用公式 R2 = (R - R1) ÷ (1 + R1)；3. 先判断符号：若R < R1且均为正 → R2为负值，可快速排选项；4. 口算：分子=间隔-同比（如R=23.3%、R1=105%→分子≈-82%），分母=1+R1≈2.05，结果≈-40% |
| 高频错因 | ①不识别题型，按普通增长率算 ②忘记R1是百分数要÷100参与运算 ③符号判断错误 |
| confidence | high |

## 不适用条件

- 材料直接给出两年同比增速，不需要反推
- 题目求的是间隔增长量而非间隔增速
- R和R1中有一个未给出且无法从材料推出

## 反向触发

- 若R与R1同向且数值接近，算出的R2极小（接近0），应检查是否误判了间隔关系
- 若计算出的R2符号与选项方向相反，先核对R1对应的是基期年还是报告期年，不要直接选负值最大项
