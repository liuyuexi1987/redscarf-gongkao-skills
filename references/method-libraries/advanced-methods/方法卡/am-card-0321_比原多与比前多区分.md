# 方法卡：比原多与比前多区分

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 比原多与比前多区分 |
| 适用题型 | 数量关系——工程问题、等差数列 |
| 触发场景 | 题干用“比原来多”或“比前一天多”描述效率变化，需要判断固定新效率还是逐期递增 |
| 步骤逻辑 | 1. **"比原来多X个"** → 效率从Y变为Y+X，是一个固定值（不是等差数列）；2. **"比前一天多X个"** → 每天递增X，形成公差为X的等差数列；3. 根据题意选择正确的效率模型列方程；4. 前者直接用(Y+X)×天数，后者用等差数列求和 |
| 高频错因 | 把"比原来多5个"误读为"每天递增5个"（等差数列），导致效率模型错误不仔细审题中的"原"vs"前"一字之差 |
| confidence | medium |
| 不适用条件 | 题目直接给出固定效率或固定产量、无任何"多/少"比较表述的工程问题；效率变化不符合固定增量或逐日递增模式的场景 |
| 反向触发 | 当"比原来多"和"比前一天多"的判断差异导致列式模型完全不同、无法确定时，回到原文逐字核实措辞再重新列式 |

## 补充说明

这是强化方法反复强调的审题陷阱。"比原来多"=固定增量，"比前一天多"=递增。一字之差，列式完全不同。考试中务必逐字审题。
