# 方法卡：语句填入并列动词取交集定宾语

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 语句填入并列动词取交集定宾语 |
| 适用题型 | 言语理解——语句填入题 |
| 触发场景 | 待填入句前面有多个并列动词（如"认定""核查""治疗"），需要确定它们共同的宾语 |
| 步骤逻辑 | ① 找到待填入句中需要搭配的并列动词；② 用最"挑剔"的动词来约束宾语范围——选择性最强、搭配范围最窄的动词决定了宾语的下限（如"治疗"只能接"病/疾病/健康问题"等，不能接"分类""规律""关系"等抽象对象）；③ 验证其他动词是否也能搭配该候选宾语（如"认定X""核查X""治疗X"都通顺）；④ 选择与所有并列动词都能自然搭配的选项 |
| 不适用条件 | 不适用于动词不并列（各自支配不同宾语）的情况；不适用于宾语已在题干中明确给出、无需推断的语句填入 |
| 高频错因 | 只看部分动词搭配通顺就选，忽略了某个动词对宾语的特殊限制；被表面通顺的表述迷惑，没验证所有动词的搭配兼容性 |
| confidence | high |
| 反向触发 | 并列动词数量过多且各动词搭配约束互相矛盾，导致无法找到共同宾语时，应转用语境线索和话题一致性来确定答案；待填入句既有动词搭配又有逻辑关系词（如"因此""但"），动词搭配与逻辑关系推断矛盾时，应以逻辑关系为优先 |
