# 方法卡：下文推断具体承接优先核对法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 下文推断具体承接优先核对法 |
| 适用题型 | 言语理解——下文推断 |
| 触发场景 | 下文推断题尾句停在宏观介绍，选项中出现对同一话题的具体展开 |
| 步骤逻辑 | 1. 先锁定尾句主体和未展开的信息；2. 含“具体内容/具体应用”的选项优先核对，但不能仅凭“具体”二字选择；3. 检查该选项是否承接同一主体并保持话题层级；4. 若出现主体偷换、概念扩大或提前跳转新话题，立即排除 |
| 高频错因 | 不识别"宏观→具体"的展开逻辑，被其他看似合理的选项干扰混淆"物质"和"技术"的概念（如穿膜肽 vs 穿膜肽技术），导致话题错位 |
| confidence | medium |

## 不适用条件

- 题目不是下文推断题时不使用本卡
- 尾句话题已转向新方向时，"具体XX"选项未必正确

## 反向触发

- 若"具体XX"选项的话题与尾句话题不一致，不能选
- 若其他选项有更好的尾句衔接逻辑，应优先考虑衔接性
