# 方法卡：否定之否定等于肯定

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 否定之否定等于肯定 |
| 适用题型 | 题干出现双重否定结构的质疑/支持题 |
| 触发场景 | 题干先提出观点A，然后否定观点A（说它不对），选项要求再质疑这个否定 |
| 步骤逻辑 | 1. 识别题干结构：观点A → 质疑A → 选项要求质疑"质疑A"；2. 质疑"质疑A" = 支持A（否定之否定等于肯定）；3. 因此选项方向应为支持原始观点A；4. 直接将题意转化为"支持A"来选答案 |
| 高频错因 | 被绕晕，分不清该支持还是反对哪一层 |
| 不适用条件 | 题干结构为单一质疑（A被质疑，选项直接质疑A）而非嵌套否定；题干不含双重否定逻辑链 |
| 反向触发 | 题干只有一层否定（如"以下哪项能反驳上述观点"），不存在"质疑的质疑"结构 |
| confidence | high |
