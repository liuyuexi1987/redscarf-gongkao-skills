# 方法卡：数推圈三法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 数推圈三法 |
| 适用题型 | 数量关系——数字推理（递推数列） |
| 触发场景 | 数列无明显等差/等比/做差规律，怀疑是递推 |
| 步骤逻辑 | ① 取连续三个较大数（含一个两位数更稳定）；② 固定第一个数不动；③ 尝试三种运算路径（加/减/乘）得到中间值；④ 验证该规律是否适用于前后其他数 |
| 高频错因 | ① 从最小的数入手→规律不稳定；② 只试一种运算就放弃→漏掉规律 |
| confidence | high |

## 补充说明
取数时优先选择稍大的数（含两位数更稳定），规律更易显现。例如对 3、2、9 三个数，可验证 3 的 2 次方=9，再据此验证其他位置是否符合同一规律。

## 不适用条件

1. 数列存在明显等差/等比规律时（直接用基础方法更快）。
2. 数列项数过少，无法取连续三个数时。
3. 数列呈现明显的周期性或分组规律时。

## 反向触发

1. 当三种运算路径均无法验证前后数时，应换用做差、做和等其他递推思路。
2. 当数列项数充足但取大数仍不稳定时，应补充考察小数位置的规律。
3. 当疑似递推但运算路径均失败时，应核验是否为分组或周期数列。
