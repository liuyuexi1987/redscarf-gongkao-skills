# 方法卡：置换等量关系（甲的溶质=乙的溶剂）

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 置换等量关系（甲的溶质=乙的溶剂） |
| 适用题型 | 两个容器互相倒换液体，求各容器中某成分的量 |
| 触发场景 | 甲杯纯液体A，乙杯纯液体B，互相倒换后求各杯中对方液体的量 |
| 步骤逻辑 | 1. 甲杯中B液体的量 = 乙杯中A液体的量（总量守恒）；2. 无论倒换多少次、过程多复杂，这个等量关系始终成立；3. 原因：总液体量不变，内部循环不外流 |
| 高频错因 | 试图追踪每次倒换的具体量，陷入计算泥潭 |
| confidence | high |

## 补充说明

此为整体性思维的典型应用，不关注过程细节，只看最终守恒关系

## 不适用条件

- 倒换过程中有液体外溢或总量变化时不适用
- 单容器内部浓度变化题不适用

## 反向触发

- 题目问具体每次倒换后的浓度时，应改用方程法逐步追踪
- 涉及多种成分混合时，应改用守恒方程组
