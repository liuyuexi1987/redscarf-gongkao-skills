# 方法卡：流水行船与比例法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 流水行船与比例法 |
| 适用题型 | 数量关系-行程问题-流水行船 |
| 触发场景 | 题目涉及上游/下游、顺流/逆流、船速与水速 |
| 步骤逻辑 | 1. 核心公式：顺流速度 = 船速+水速；逆流速度 = 船速-水速；2. 同一人往返（S相同）→ V和T成反比：时间比t1:t2 → 速度比=t2:t1；3. 列方程：(V船+V水)/(V船-V水) = t逆/t顺，解出V船与V水的关系；4. 不同人同一路程→速度比=路程比（T相同时S与V成正比）；5. 题目无实际速度数据时，可赋值V水=1简化计算（最终会抵消） |
| 高频错因 | 顺流逆流速度公式写反；时间比和速度比搞反（应成反比）；两人逆流比较时都应减水速而非一个加一个减 |
| confidence | medium |

## 不适用条件

1. 题目不涉及水流，仅为普通追击/相遇问题
2. 存在变速运动或加速度，速度不是恒定值
3. 两人为相向相遇而非同一路程往返，S相同的前提不成立

## 反向触发

1. 题目无"顺流""逆流""上游""下游"等关键词
2. 出现"加速""减速""变速"，速度非常量
3. 两人从两地出发相向而行，属于相遇问题
