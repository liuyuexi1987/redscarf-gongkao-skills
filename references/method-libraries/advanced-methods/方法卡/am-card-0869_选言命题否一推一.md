# 方法卡：选言命题否一推一

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 选言命题否一推一 |
| 适用题型 | 判断推理——涉及"A或B"命题的推理 |
| 触发场景 | 已知A或B为真，且已知其中一个不成立，需要推另一个 |
| 步骤逻辑 | ① A或B为真 → 至少一个成立（范围：三种情况）；② A或B为假 → 否A且否B（两个都不成立）；③ 在A或B为真的前提下：若已知A不成立 → B必成立；若已知B不成立 → A必成立（否一推一）；④ 但仅知A成立时，B可成立可不成立 |
| 高频错因 | ① 误以为知道A成立就能推B不成立（不能，A或B允许两个都成立）；② 混淆"A或B"和"要么A要么B" |
| confidence | high |

## 补充说明

A或B（相容选言）允许两个都成立，所以肯一无法推另一。要么A要么B（不相容选言）既能否一推一也能肯一推一，因为只允许恰好一个成立。A或B的矛盾面是"否A且否B"。

## 不适用条件

1. 当命题形式为"要么A要么B"（不相容选言）时，肯一可以推另一为假，逻辑方向不同，不能混用相容选言的规则。
2. 当三个及以上选言肢（A或B或C）中仅知一个不成立时，无法推出剩余哪个成立，只能缩小范围。

## 反向触发

1. 当已知选言命题为假时，应使用矛盾等价（否A且否B），而非否一推一。
2. 当题目涉及德摩根律变形（如对"否A或否B"取否得到"A且B"）时，优先用等价变换处理。
