# 方法卡：对比实验他因削弱必须回归分组

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 对比实验他因削弱必须回归分组 |
| 适用题型 | 判断推理——削弱类（对比实验型归因论证） |
| 触发场景 | 题干做了两组对比实验（如A组vs B组），结论归因于某差异，选项以"另有他因"方式削弱 |
| 步骤逻辑 | ① 识别对比实验的两组（如火星组vs地球组、>2h组vs<2h组）；② 真他因削弱：必须回到分组，指出实验组中存在另一个未被控制的变量（如"地球上还有河流限制火山生长"）；③ 伪他因削弱（无力度）：随便找一个别的因素但未回归分组（如"其他星体表面构造变化也能影响火山"），无法破坏实验严谨性；④ 直接排除伪他因选项 |
| 高频错因 | 看到"另有他因"就选，不检查是否回归分组；把伪他因（只提别的因素但不分组）当作有效削弱 |
| confidence | high |

## 补充说明

典型场景1（天文类对比实验）：火星vs地球巨大火山的对比，真他因削弱需回到地球组，指出地球上存在另一个未被控制的变量（如河流限制山峰生长）；而讨论其他星体的表面构造变化属于未回归分组的伪他因，无削弱力。典型场景2（学习时长vs成绩）：真他因需回到分组指出"兴趣高的那组学习习惯更好"，因果倒置力度强于他因削弱。核心区别：真他因必须回到实验分组中指出未控制变量，伪他因只提别的因素但不分组。

## 不适用条件

1. 当论证不是对比实验结构（无明确的两组对比）时，此法不适用，应换用一般因果削弱法
2. 当结论是形式逻辑关系（含"只有才""只要就"）而非实验归因时，应换用逻辑矛盾削弱法
3. 当题干给出的是自然观察数据而非实验设计时，"回归分组"的判断标准需调整

## 反向触发

1. 当削弱方向不是"另有他因"而是因果倒置时，因果倒置力度通常强于他因削弱，应优先判断是否存在因果倒置选项
2. 当选项讨论的是同一分组内的反例（如"实验组中也有不符合结论的个体"）时，这属于反驳结论本身而非他因削弱，力度判断方式不同
