# 方法卡：尾数法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 尾数法 |
| 适用题型 | 资料分析——精确求和（多个整数相加） |
| 触发场景 | 选项末位不同，或需要快速排除时；数据必须是精确整数（如机构数量、人次等） |
| 步骤逻辑 | ① 确认数据为精确求和（无四舍五入）；② 根据选项差异决定看一位还是两位尾数；③ 只加尾部数字，忽略高位 |
| 高频错因 | 对四舍五入后的数据使用尾数法（如4.9万+2.1万不能用）；看错位数 |
| confidence | medium |

## 补充说明

尾数法只适用于精确求和，如"公园数量""申请量"等不会出现小数的数据。若数据经过四舍五入（如4.9万），实际可能是4.94万或4.86万，尾数法会失效。选项末位不同时看一位，有相同时看两位。

## 不适用条件

- 数据经过四舍五入、单位换算后不再是精确整数。
- 选项尾数相同，或题目包含乘除而非单纯加减。

## 反向触发

- 尾数不足以区分选项时，增加核对位数或改做完整计算。
- 单位不统一时先统一单位，再决定能否使用尾数法。
