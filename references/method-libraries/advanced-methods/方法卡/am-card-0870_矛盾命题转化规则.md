# 方法卡：矛盾命题转化规则

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 矛盾命题转化规则 |
| 适用题型 | 判断推理——求命题的矛盾面/否定形式 |
| 触发场景 | 需要将"不同意""不可能""并非"等表述转化为逻辑表达 |
| 步骤逻辑 | ① ¬(A且B) = 否A或否B（且→或，各取反）；② ¬(A或B) = 否A且否B（或→且，各取反）；③ ¬(要么A要么B) = (A且B)或(否A且否B)（两个都成立或都不成立）；④ "不可能A且B"="否A或否B"，"至少一人"="A或B"，"至多一人"="否A或否B" |
| 高频错因 | ① 取反时忘记把"且"换成"或"或反之；② "至多"和"至少"的逻辑转化搞混；③ 不相容选言的矛盾面记忆错误 |
| confidence | high |
| 不适用条件 | 题目考查的是假言推理链（连锁推导），不是求矛盾面或否定形式；选项中的"不"是修辞强调而非逻辑否定，语义上不是求矛盾命题 |
| 反向触发 | 题目只需要判断A与B的推出关系，不需要取矛盾面；题干问"以下哪项与题干意思一致"，考查的是等价转化而非矛盾转化 |

## 补充说明

转化口诀：取反时符号带入、且↔或互换。"不同意A或B"→取矛盾面→否A且否B。"至多一个"="否A或否B"="至少一个不成立"。矛盾命题之间必然一真一假。
