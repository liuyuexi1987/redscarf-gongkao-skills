# 方法卡：不同完工情况列方程

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 不同完工情况列方程 |
| 适用题型 | 工程问题中，已知条件给出不同的完工方案（如甲先做X天再乙做Y天，或甲乙合作X天完成总量的N%） |
| 触发场景 | 题干出现"甲先做15天乙再做若干天""两种方案分别完成总量的90%和100%"等不同完工描述 |
| 步骤逻辑 | 1. 设各人效率为未知数（或设一个为x，用比例表示另一个）；2. 利用"不同方案完成的工作总量相等（或成比例）"列方程；3. 解方程求出效率，再求工作总量或时间 |
| 高频错因 | 两种完工情况的工作量关系搞混（如一个是100%，一个是90%，方程右边搞错）方程列对但解方程时计算出错 |
| confidence | medium |

## 不适用条件

- 题干只给出一种完工方案且无第二种方案可对比时，无法列等式方程。
- 各方案的工作量关系不明确（如未告知完成比例或天数），列方程缺乏等量依据。

## 反向触发

- 当两种方案给出的不是"完成总量"而是"完成同一部分工作量所用时间"时，应改用"效率比直接当效率用"或"份数思想对应实际量"。
- 当方程变量过多（超过2个未知效率）且无额外约束时，应换用"给时间设最小公倍数为工作总量"以避免方程组求解复杂化。
