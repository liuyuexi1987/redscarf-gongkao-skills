# 方法卡：中心理解四步法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 中心理解四步法 |
| 适用题型 | 言语理解——中心理解 |
| 触发场景 | 所有中心理解题 |
| 步骤逻辑 | ① 找主旨句：优先从后面找（最后一句/倒数第二句），关注"因此""需要""应该"等引导词；② 判断结构：尤其注意并列结构（一方面/另一方面、同时）；③ 找主题词：反复出现的词语，代词指代的对象；④ 详读内容：判断每句话的功能（论据/论证/背景/过渡） |
| 高频错因 | ① 只看最后一句忽略前面→漏掉主体或话题；② 并列结构找不到共性→以偏概全选了其中一个小点；③ 被主旨后的句子干扰→选了论据而非论点 |
| confidence | high |

## 补充说明
中心理解题应控制耗时：能迅速锁定主旨句的题不必过度纠结。并列结构是正确率最低的题型，关键是找各并列分支的共性，或寻找作者在并列前后给出的总结性语句作为主旨。若一时难以判断，可先标记跳过，待完成其他题后再回头审视，避免在单题上耗费过多时间。

## 不适用条件

- 语句排序、语句填空、接语选择等非中心理解题型，不套用本卡四步。
- 文段为说明性文字且无明确主旨句（如纯数据罗列、流程描述）时，四步法难以定位主旨，不适用。
- 题目问的是细节或对某句话的理解而非全文中心时，应改用细节查找法。

## 反向触发

- 当文段无明显主旨引导词（"因此""需要""应该"等均未出现）时，应换用话题词追踪法：以反复出现的核心词为主旨线索。
- 当并列结构各分支无明显共性、也无作者总结句时，应补一步共性提炼：将各分支语义抽象到更高层级，再据此比对选项。
- 当主旨句后还有大段论述时，应反向核验：确认该论述是论据支撑还是主旨转折，避免误把论据当主旨。
