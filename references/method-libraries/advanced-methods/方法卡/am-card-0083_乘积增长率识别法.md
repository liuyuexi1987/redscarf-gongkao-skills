# 方法卡：乘积增长率识别法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 乘积增长率识别法 |
| 适用题型 | 资料分析-日均产量/进口量等"日均"类材料的月度增长率 |
| 触发场景 | 材料给出"日均"数据，题目要求月度（当月）增长率或环比增长率 |
| 步骤逻辑 | 1. 识别公式：月产量 = 日均产量 × 天数；2. 这是两个因子的乘积，月产量的增速用乘积增长率公式：R = R1 + R2 + R1×R2；3. R1 = 日均的增长率，R2 = 天数的增长率；4. 天数增长率：30天→31天 = +3.3%，31天→30天 = -3.3%（即 1/30）；5. 两个 R 叠加即可，R1×R2 通常很小可忽略；6. 日均材料（原油产量/进口量/加工量）几乎必考此知识点 |
| 高频错因 | 直接用日均的增长率当月增长率，忽略天数变化用同比增长率代替环比增长率不知道 1/30 ≈ 3.3% 这个常用值 |
| confidence | high |

## 不适用条件

- 数据非"日均"口径而是直接给出月度总量时，无需套用乘积增长率公式
- 题目只要求比较日均量大小，不需要推算月度增长率时，不需要此法
- 天数相同的两个月之间比较时（如都是30天），R2=0，退化为直接比较日均增长率

## 反向触发

- 当题目直接给出月度数据或月度增长率时，无需通过日均×天数反推
- 当R1和R2都较大（如跨季度的大幅波动），R1×R2不可忽略时，应完整使用乘积公式而非近似
- 当题目问的是同比而非环比时，天数差异的影响方式不同，需区分同比/环比再决定是否适用
