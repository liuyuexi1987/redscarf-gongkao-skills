# 方法卡：利润率十字交叉混合
## 基本信息
| 字段 | 值 |
|------|-----|
| 方法名 | 利润率十字交叉混合 |
| 适用题型 | 数量关系-经济利润/打折促销问题 |
| 触发场景 | 分阶段销售，已知总利润为期望利润的百分比，求打折或另一阶段利润率 |
| 步骤逻辑 | 1.由"总利润是期望利润的X%"推算混合利润率=原利润率×X%；2.两阶段利润率十字交叉相减；3.分母之比=两阶段成本之比=销量之比（单个成本相同时）；4.由十字交叉结果求未知利润率；5.用打折=（1+折后利润率）÷（1+折前利润率）求折扣 |
| 高频错因 | 忘记利润率的混合前提是分母为各阶段总成本（单个成本×销量），而非直接用单价混合 |
| confidence | high |
## 补充说明
利润率=利润÷成本。两个阶段的利润率可以混合成总利润率，原理是A/B与C/D混为(A+C)/(B+D)。由于单个成本相同，分母之比等于销量之比。例如售出3/4剩余1/4，分母之比为3:1。隐藏公式：打折数=(1+折后利润率)÷(1+折前利润率)，因为成本不变时售价=成本×(1+利润率)。
## 不适用条件
- 各阶段单件成本不同（如进货价变动），分母之比不等于销量之比，十字交叉结果需调整。
- 混合阶段超过两个且无法分组为两两混合，需用加权平均或列方程替代。
- 题目涉及的是毛利率（毛利÷售价）而非成本利润率，公式需相应调整。
## 反向触发
- 题面含"混合""交叉"但混合对象是浓度或增长率而非利润率，需转用对应十字交叉模型。
- 打折问题可直接用"售价=原价×折扣"一步求解，无需先算利润率再转折扣。
