# 方法卡：推理方式题——三类常见谬误

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 推理方式题——三类常见谬误 |
| 适用题型 | 判断推理——推理方式/推理结构类 |
| 触发场景 | 题目问"与题干推理最为类似/犯了相同错误"，需要匹配推理结构 |
| 步骤逻辑 | ① 写出题干的推理结构（如A推B，B发生推出A）；② 对照三类常见错误：逆命题（A推B变成B推A）、否命题（A推B变成非A推非B）、分割谬误（整体属性误归于个体）；③ 在选项中找犯了同类型错误的；④ 不用管推理对错，"对要对的一样，错要错的一样" |
| 高频错因 | 把逆命题和否命题搞混；忽略分割谬误这种情况 |
| confidence | high |
| 不适用条件 | 题目未要求匹配推理结构（如直接判断推理对错、补充前提、质疑结论），或推理本身不含条件命题/三段论结构 |
| 反向触发 | 题干属于枚举归纳、类比等其他推理结构时，三类谬误模板不适用，应重新抽象论据和结论关系；推理涉及“有些”“所有”等量词时，还需检验量词范围与对当关系，不能只看条件命题方向。 |
