# 方法卡：说理类找句科普类概括

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 说理类找句科普类概括 |
| 适用题型 | 言语理解——中心理解（文段类型判断） |
| 触发场景 | 每道主旨题做题前先判断文段类型：说理类（有作者对策/观点）还是科普介绍类（纯介绍事实/现象），两类做题策略完全不同 |
| 步骤逻辑 | 1. **说理类**：每句话重要程度不同，全文为一个主旨句服务。找句子（前对策或后对策），选项对主旨句；2. **科普介绍类**：每句话重要程度差不多，比较"散"。不能找句子，要站在更高层次概括全文，找高频词/主题词/共性；3. 新闻类：突出一个"新"字即可；4. 科普类如果原文有新变化/新发现，选项必须体现这个"新" |
| 高频错因 | 科普类文段用"找句子"的方法做，选到片面选项；说理类文段用"概括"的方法做，选到论证段的内容；把新变化/新发现当成说理类的"观点否定"，其实原文只是在介绍现状 |
| confidence | medium |

## 不适用条件

- 文段兼有说理和科普特征、无法明确归类时，不强行套用本卡
- 题目问的是细节而非主旨时，不使用本卡

## 反向触发

- 若题目问的是"下列说法正确/不正确"（细节判断题），不使用本卡
- 若文段没有明确的作者观点或对策，也不属于纯科普介绍，应重新判断文段类型
