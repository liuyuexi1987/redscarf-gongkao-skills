# 方法卡：分数溶液类比法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 分数溶液类比法 |
| 适用题型 | 资料分析——分数大小比较 |
| 触发场景 | 比较两个分数（如A/B vs C/D）的大小 |
| 步骤逻辑 | ① 把分数看作溶液浓度（分子=溶质，分母=溶液）；② 分别看分子增长率和分母增长率；③ 分子增长率>分母增长率→后面的数更大（浓度升高）；④ 分子增长率<分母增长率→后面的数更小 |
| 高频错因 | ① 涉及减法时容易搞混方向→从右往左用加法思考不容易出错 |
| confidence | high |

## 不适用条件

1. 分子或分母含减法、负号等结构，无法稳定对应“溶质/溶液”关系时。
2. 分数形式复杂无法直接类比为浓度时。
3. 仅需比较绝对值而非增长率关系时。

## 反向触发

1. 当涉及减法运算方向混乱时，应换用从右往左加法思考。
2. 当溶液类比无法解释分数变化时，应补充用差分法或直除法核验。
3. 当分子分母增长率接近时，应改用精算避免估算误差跨越选项。
