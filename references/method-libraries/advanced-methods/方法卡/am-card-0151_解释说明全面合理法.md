# 方法卡：解释说明全面合理法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 解释说明全面合理法 |
| 适用题型 | 判断推理-解释说明类题目 |
| 触发场景 | 题干要求"解释上述矛盾/现象"，选项需判断哪个能合理解释题干中的看似矛盾的两个方面 |
| 步骤逻辑 | 1. 先数题干结论/现象中涉及了**几个点**（通常矛盾现象有A和B两个方面）；2. 正确答案必须**全面**覆盖所有点，不能只解释一半；3. 正确答案必须**合理**，即解释自己首先得信、符合常规逻辑；4. 只解释了其中一个点而遗漏其他点的选项→排除（不全面）；5. 解释方向违背常理的选项→排除（不合理） |
| 高频错因 | 只看选项能解释一个方面就选，忽略"全面性"要求选了听起来合理但只覆盖部分现象的选项 |
| confidence | high |

## 不适用条件

1. 题干只有一个现象需要解释，不存在"全面性"判断需求
2. 选项中没有任何一个能同时覆盖矛盾的两个方面，需退而求其次选覆盖更关键一方
3. 题目要求找"最不能解释"的选项（反向选择）

## 反向触发

1. 题干出现看似矛盾的两个事实，要求选"最能解释上述矛盾"的选项
2. 多个选项分别只解释矛盾的一个方面
3. 正确答案必须同时解释为什么A发生且为什么B也发生
