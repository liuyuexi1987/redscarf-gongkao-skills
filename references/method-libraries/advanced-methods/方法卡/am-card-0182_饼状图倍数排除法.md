# 方法卡：饼状图倍数排除法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 饼状图倍数排除法 |
| 适用题型 | 资料分析 — 饼状图选项辨别 |
| 触发场景 | 饼状图选项中多个扇区视觉相似，需要快速排除 |
| 步骤逻辑 | 1. 找到材料中对应部分的数值，估算两部分之间的倍数关系；2. 根据倍数关系判断扇区大小比（如三到四倍 vs 六七倍）；3. 对比各选项扇区的实际比例关系，排除倍数明显不符的选项；4. 配合顺时针排布规则进一步确认 |
| 高频错因 | 只看扇区"像不像"而不计算倍数关系忽略倍数量级差异（三倍和六倍扇区差异明显） |
| confidence | high |

## 不适用条件

1. 选项中扇区比例差异已经非常明显，肉眼即可区分，不需要估算倍数
2. 材料中无法直接找到对应扇区的数值数据
3. 题目只涉及单一扇区的识别而非比例比较

## 反向触发

- 题干要求识别饼状图中某部分对应哪个扇区，且选项中多个扇区视觉相似
