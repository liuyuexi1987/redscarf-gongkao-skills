# 方法卡：结语题尾句推断法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 结语题尾句推断法 |
| 适用题型 | 言语理解——结语题（下文推断） |
| 触发场景 | 题目问"作者接下来最可能讨论的是""这段文字接下来最可能讲的是" |
| 步骤逻辑 | ① 重点读文段最后一句话（尾句是衔接下文的关键）；② 提取尾句的核心话题和逻辑方向（提出问题→下文解决问题、引出新概念→下文展开解释、留下悬念→下文揭示答案）；③ 选与尾句话题直接衔接的选项；④ 排除：与尾句话题无关的、跳跃太远的、重复前文已说过的 |
| 高频错因 | ① 看文段首句或中间内容来推断下文（应该看尾句）；② 选了文段已经讨论过的内容（下文应该是新内容）；③ 选了跳跃太远的选项（下文应该是尾句的自然延伸） |
| confidence | high |

## 补充说明
结语题的核心技巧只有一个：看尾句。尾句的逻辑方向决定了下文的内容。如果尾句提出问题，下文通常是分析原因或提出对策；如果尾句引出新概念，下文通常是展开解释；如果尾句是转折，下文通常讨论转折后的内容。

## 不适用条件
- 题目非结语题，不问下文内容推断。
- 尾句为总结性陈述，逻辑闭合无延伸空间。
- 文段结构不完整，无法定位真正的尾句。

## 反向触发
- 当尾句逻辑方向不明确时，需结合行文脉络整体推断下文走向。
- 当选项均与尾句相关但方向不同时，应换用主旨一致性验证法筛选与全文主旨一致的选项。
- 当尾句为转折句但转折后内容已在前文讨论时，应换用话题新颖性分析法排除已述内容。
