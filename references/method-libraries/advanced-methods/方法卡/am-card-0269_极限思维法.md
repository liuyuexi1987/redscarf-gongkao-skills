# 方法卡：极限思维法（上下限取值法）

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 极限思维法（上下限取值法） |
| 适用题型 | 排列推理/预测类量化题 |
| 触发场景 | 题干出现"超过一半""至少""不超过"等上下限表述 |
| 步骤逻辑 | 1. 遇到"超过一半"（>50%）→ 取下限，按恰好50%算；2. 遇到"不超过"（≤50%）→ 取上限，按恰好50%算；3. 七人预测名次，"超过一半"即至少对4个（7×50%取上整）；4. 为使尽可能多人满足条件，每个名次下频次最高的预测者假设为正确；5. 只有某个预测者在所有名次上正确数仍不够4个时，才需要额外调整 |
| 高频错因 | 纠结"超过一半到底是60%还是70%"，不确定导致无法下手；不知道取边界值简化计算 |
| confidence | high |

## 不适用条件

1. 题干不含"超过一半""至少""不超过"等上下限或临界值表述
2. 涉及精确数值计算而非取边界值简化推理（如资料分析中的增长率计算）
3. 题目是纯言语理解、定义判断或图形推理题

## 反向触发

1. 题干给出的是精确确定数值，而非范围限制或模糊表述
2. 所有条件都是确定性条件（"恰好""一定是"），无"至少""不超过"等取值空间
3. 题目考查排列组合计数，而非条件约束下的临界值判断
