# 方法卡：基期比大小速判

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 基期比大小速判 |
| 适用题型 | 资料分析-基期排序/基期比较 |
| 触发场景 | 多项基期需要排序比大小，且现期和增率都已知 |
| 步骤逻辑 | 1.基期=现期/(1+R)；2.现期大+增率小→基期一定大（分子大分母小）；3.现期小+增率大→基期一定小（分子小分母大）；4.差距悬殊时直接按现期排序即可，增率在10%以内几乎不影响大小关系 |
| 高频错因 | 逐项精算各基期再排序；不利用现期差距排除选项 |
| confidence | high |

## 不适用条件

1. 各项现期差距很小且增率差异也不显著时，无法用"现期大+增率小"快速锁定，仍需逐项精算基期。
2. 增率存在正负混合（部分项正增长、部分项负增长）时，符号影响基期方向，速判规则需额外判断，不再简单适用。
3. 题目要求精确排出所有项的基期排序（而非仅判断某两项大小）时，速判只能用于排除，不能给出完整排序。

## 反向触发

1. 题目问的是"现期排序"而非基期排序——直接按现期排即可，无需用本法。
2. 增率数据缺失或只有图表近似值时，无法构造"(1+R)"的比较依据，速判失效。
3. 现期相近且增率差异可能改变基期排序时，不能仅靠现期排序，需按公式核验。

## 补充说明

本质公式：基期=现期/(1+R)。关键速判规则：(1)现期差距大时，增率小（<10%）根本翻不了大小关系，直接按现期排；(2)现期相近时才需要比较增率对基期的影响。本法可快速排除多个选项，只在必要时精算剩余项。增率正负也要注意：负增率意味着基期大于现期。
