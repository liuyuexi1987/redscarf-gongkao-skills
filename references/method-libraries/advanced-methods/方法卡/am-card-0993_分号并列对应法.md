# 方法卡：分号并列对应法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 分号并列对应法 |
| 适用题型 | 逻辑填空——分号并列结构 |
| 触发场景 | 两个分句用分号隔开，且每个分句各有一个空 |
| 步骤逻辑 | ① 识别分号分隔的两个并列分句；② 分句1的空1与分句2的空1形成对应；③ 分句1的空2与分句2的空2形成对应；④ 对应位置的词通常是近义或同类关系 |
| 高频错因 | ① 不注意分号的对应关系→分别独立判断→漏掉重要线索；② 对应位置词性不同（如一个是动词一个是名词）→排除 |
| confidence | high |

## 补充说明
分号并列是严格的结构对称。例如"一方面__，__；另一方面__，__"→第一个空对应第三个空，第二个空对应第四个空。对应位置的词通常构成近义或同类关系，可据此互推互验。

## 不适用条件
- 分号两侧并非真正的并列结构（如分号后是转折或递进的延续）时，不应套用位置对应。
- 分号两侧虽并列但分句内部空格数量不一致时，无法形成位置一一对应。
- 分号仅作列举分隔（如多项罗列），分句间不存在语义对应关系时，本方法无效。

## 反向触发
- 当分号并列对应得到多组候选词但仍难取舍时，应换用"前后空呼应关系"从分句内部逻辑呼应进一步筛选。
- 当对应位置词性不一时，应改用"语言结构分析法"做语法核验，确认是否存在词性陷阱。
- 当分号后出现代词指代前分句内容时，应结合"代词回找主题词法"确认对应对象，避免误判并列关系。
