# 方法卡：常识判断题策略

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 常识判断题策略 |
| 适用题型 | 常识判断——判断题/选择题 |
| 触发场景 | 常识判断选项含方向、主体、权限、时间或成对概念，需要核对是否发生关键词偷换 |
| 步骤逻辑 | ① 标出选项中的主体、方向、对象和作用环节；② 回到已知定义、法条或稳定事实逐项核对；③ 成对概念只作为核查线索，确认被对向替换后才能排除；④ 没有可靠知识依据时标注待核验，不根据题型或选项措辞猜正误 |
| 高频错因 | 只注意名词相似而漏看方向和主体；把成对概念的出现当成必错信号；没有依据时用“更像正确答案”的措辞猜测 |
| confidence | medium |
| 不适用条件 | 题目可由明确知识直接判断；考查最新政策或时政但当前无法核验；选项差异不在关键词方向、主体或权限上 |
| 反向触发 | 有明确法条、定义或稳定知识时直接按知识核验；涉及易变信息时转为权威来源核查；选项考查机制理解而非关键词替换时，改用对应领域方法 |

## 补充说明
方向词和成对概念可以帮助定位核查点，但不是答案分布规律。常识题应以事实依据为主；依据不足时只保留排除过程和待核验结论。
