# 方法卡：题干条件不足带选项反推

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 题干条件不足带选项反推 |
| 适用题型 | 数量关系（题干条件极少，无法正面列方程） |
| 触发场景 | 题干只描述了一个操作过程，未给任何具体数值，正面做无从下手 |
| 步骤逻辑 | 1. 确认正面条件确实不足（未知数多于方程数）；2. 将四个选项分别代入，模拟题干描述的操作过程；3. 验证哪个选项能使所有约束同时满足（如总数为平方数、余数条件等）；4. 排除不满足的选项，仅剩一个即为答案 |
| 高频错因 | 坚持正面硬解浪费时间；带入选项时遗漏某个约束条件 |
| confidence | high |

## 不适用条件

- 题干条件充足，可正面列方程求解（应优先用方程法，反推效率更低）
- 选项数值非常大或代入验证计算量极大（反推成本过高）
- 题目为不定方程或多解问题（代入可能找到多个满足条件的选项）

## 反向触发

- 当代入两个选项都满足约束条件时，说明约束条件不充分，应检查是否遗漏了某个条件
- 当代入验证耗时过长（超过 2 分钟）时，应重新审视是否有正面列式的可能性
- 当题目涉及连续变量（非离散选项）时，反推法不适用，应转为列方程
