# 方法卡：容斥交集范围

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 容斥交集范围 |
| 适用题型 | 资料分析——容斥问题·求同时满足两个条件的人数/占比的最小值或范围 |
| 触发场景 | 题目问"既A又B的人至少有多少"或"至少占比多少"，出现"至少""一定""可能"等关键词 |
| 步骤逻辑 | ① 确认两个属性的占比A和B（占总人数）；② 最小交集=A+B-100%（若<0则为0，可能无交集）；③ 最大交集=min(A,B)（较小的那个）；④ 注意分母：问"在所有人中至少占多少"→直接用最小交集；问"在A中至少占多少"→最小交集÷A |
| 高频错因 | ① 忘记检查A+B是否>100%——不超过100%时交集下界可为0，不能说“一定有”；② 分母搞混——问"在A中"时要再除以A的占比；③ 最大值取错——应取min(A,B) |
| confidence | high |

## 补充说明

容斥原理：两个集合的交集至少为A+B-全集（当A+B>全集时），至多为min(A,B)。可以用一维数轴理解：先把A放左边，B尽量往右放远离A，放不下必然重叠的部分就是最小交集。资料分析中的容斥通常只考双集合，且选项差距较大，直接算最小值+检查分母即可。

## 不适用条件

- 三个及以上集合的容斥问题（本方法仅覆盖双集合）
- 题目要求精确人数而非范围/极值时，需额外条件才能确定
- A或B的占比数据不明确、存在歧义时，先确认数据再套公式

## 反向触发

- 看到"既A又B至少/至多""至少占比""同时满足两个条件" → 用本方法
- 看到三个及以上条件的交集 → 不用本方法，需三集合容斥公式或枚举
- 看到"或"（并集）而非"且"（交集） → 不用本方法，应求并集
