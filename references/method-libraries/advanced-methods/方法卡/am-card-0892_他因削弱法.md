# 方法卡：他因削弱法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 他因削弱法 |
| 适用题型 | 判断推理——加强削弱·因果论证（由果推因） |
| 触发场景 | 题干猜A导致B，需要找削弱项 |
| 步骤逻辑 | ① 识别题干因果猜测（A→B）；② 找一个"与A同时发生的C"，且C也能导致B；③ 关键条件：C必须与A一起出现在同一组中（构成未控制好的变量） |
| 高频错因 | ① 选了"无关他因"（C没有与A同时发生，不构成对照组变量）；② 混淆"他因"和"无关项"——他因必须介入实验组 |
| confidence | high |

## 补充说明

他因本质是指出对照实验没控制好变量。区分他因和无关他因的关键：C是否和A同时发生在同一组中。如"喝啤酒→胖"，他因是"喝啤酒时吃下酒菜"（同组），无关他因是"爱吃炸鸡也是胖的原因"（未说明与啤酒同时发生）。

## 不适用条件

- 选项直接说”其实是 B 导致 A”时，属于因果倒置，读 `am-card-0891_因果倒置削弱.md`。
- 问题在样本选取或样本代表性时，应检查样本，不把样本缺陷统称为他因。

## 反向触发

- 题干猜测 A 导致 B（由果推因），且需要找削弱项。
- 选项中出现与 A 同时存在、但也能导致 B 的另一因素 C（构成未控制好的变量）。
