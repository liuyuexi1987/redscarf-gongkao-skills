# 方法卡：九宫格观察顺序

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 九宫格观察顺序 |
| 适用题型 | 判断推理——图形推理（九宫格） |
| 触发场景 | 九宫格图形推理题 |
| 步骤逻辑 | ① 按行看→找每行规律；② 行不通→按列看；③ 列不通→米字型/回字型/S型；④ 数量规律三种：每行同等数量/前两图数量相加=第三图/每行总数相等 |
| 高频错因 | ① 只按行看忽略列→错过规律；② 不知道米字型等特殊观察方式 |
| confidence | high |

## 不适用条件

1. 非九宫格形式的图形推理题。
2. 九宫格整体呈现单一连续规律（如整体旋转）时。
3. 单格图形间无明显行列对应关系时。

## 反向触发

1. 当行、列、米字型等观察顺序均无规律时，应换用整体法或属性类规律。
2. 当数量规律三种均不成立时，应补充考察样式规律（加减求同/求异）。
3. 当九宫格图形差异极大时，应核验是否为分类分组题而非九宫格规律题。
