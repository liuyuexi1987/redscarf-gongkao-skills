# 方法卡：有效数字快速判断

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 有效数字快速判断 |
| 适用题型 | 资料分析——除法/乘法选择题，选项量级一致 |
| 触发场景 | 选项在同一量级（如都是几千或都是几十），首位或第二位不同，不需要精确计算 |
| 步骤逻辑 | ① 观察选项是否在同一量级；② 若是，只保留2~3位有效数字做运算；③ 不管单位和小数点；④ 匹配选项的有效数字 |
| 高频错因 | 误判选项量级差异导致方向错误；有效数字精度不够选错选项 |
| confidence | high |

## 补充说明

核心原则：当选项量级一致时，只关注有效数字差异即可快速作答。典型场景包括：选项都是三万几（如15万÷4）、选项间距大（如349÷6.5）、选项都是几千（如479÷301）。此法在选项量级一致但首位或第二位不同时尤其高效。

## 不适用条件

1. 选项量级不一致（如有千位有万位）时，必须先判断量级，不能只看有效数字
2. 题目要求精确到小数点后某位时，2~3位有效数字的精度可能不够
3. 选项间有效数字非常接近（如810 vs 816）时，2位有效数字无法区分，需增加精度

## 反向触发

1. 当保留2~3位有效数字后结果仍与多个选项接近时，应换用精算模式增加精度
2. 当运算涉及多次乘除且每步都截断有效数字时，累积误差可能较大，需额外核验最终结果
3. 当题目涉及单位换算或小数点位置不确定时，"不管单位和小数点"的前提不成立，应先统一单位再用此法
