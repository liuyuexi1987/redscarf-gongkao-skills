# 方法卡：除法转分数简化计算

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 除法转分数简化计算 |
| 适用题型 | 资料分析、数量关系——小数除法与比例计算 |
| 触发场景 | 除数可准确转成熟悉分数，乘倒数后能够明显约分并简化运算 |
| 步骤逻辑 | 1. 识别小数对应的分数：37.5 = 3/8 × 100，即37.5/100 = 3/8；2. 将除法转化为乘以倒数：÷37.5 = ×(8/3)÷100；3. 用分数运算代替小数除法，更容易约分；4. 得到简洁结果后还原 |
| 高频错因 | 硬除37.5，长除法费时且容易算错不记得37.5% = 3/8这个常用换算 |
| confidence | medium |
| 不适用条件 | 小数无法对应熟悉且简洁的分数，或直接用小数计算已经很简洁、转化后反而增加步骤时，不使用本方法 |
| 反向触发 | 转化分数后计算得到非整数或无法约分的复杂结果时，改用小数直接除法可能更可靠；转化过程中别忘了还原单位和数量级（如37.5=3/8×100，除以37.5等于乘8/3再除以100） |

## 补充说明

数量关系中常用的分数-小数对照：1/8=12.5%，3/8=37.5%，5/8=62.5%，7/8=87.5%，1/16=6.25%。这些在方程计算中反复出现，熟记后可显著提速。本方法强调3/8和5/8在数量关系中使用频率最高。
