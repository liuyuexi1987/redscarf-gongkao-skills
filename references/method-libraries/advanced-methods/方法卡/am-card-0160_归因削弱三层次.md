# 方法卡：归因削弱三层次——否定因果/因果倒置/举反例

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 归因削弱三层次——否定因果/因果倒置/举反例 |
| 适用题型 | 判断推理——削弱类（因果归因型论证，含对比实验） |
| 触发场景 | 结论为"A导致B"或"A是B的原因"，需要削弱因果关系 |
| 步骤逻辑 | ① 否定因果（最强，极少出现）：直接断开因果联系，如"巨大火山形成和重力、频率无关"；② 因果倒置（力度很大）：把因和果反过来，如"不是学习时长导致兴趣高，而是兴趣高才导致学习时长长"；③ 举反例——无因有果/有因无果（力度较弱，最常见）：如金星重力相近但火山不高，实际检验因是否真正成立。出题人倾向用举反例，因力度弱需要辨别 |
| 高频错因 | 把"有因无果"看反成"无因有果"导致方向错判（如低重力→高火山，A举"金星无低重力也无高火山"是"无因无果"，属正面证据而非削弱；若举"地球有低重力但火山不高"才是"有因无果"的削弱）；忽略因果倒置选项，选了力度更弱的举反例 |
| confidence | high |

## 补充说明

因果倒置力度通常大于他因削弱和举反例。典型场景：论证将"学习时长"归因为"成绩提高"，选项中出现"兴趣高的学生才乐意花时间"属于因果倒置，力度强于他因削弱选项。注意：归因题中的"只有才"不要翻译为形式逻辑推理关系，应理解为因果关系。

## 不适用条件

1. 论证类型不是因果归因（如纯演绎推理、类比论证、统计相关性论证）时，三层次区分不适用
2. 当题目问的是"最能支持/加强"而非"削弱"时，方向相反，需反向运用
3. 多因一果的复杂归因中，单一否定因果可能不够，需要综合排除

## 反向触发

1. 当结论不是"A导致B"而是"A是B的充分/必要条件"时，应换用形式逻辑的真假判断法，而非归因削弱层次
2. 当选项中同时出现因果倒置和另有他因，且题目问"最能削弱"但两者力度接近时，需额外核验哪个选项直接针对结论的核心因果链
3. 当论证使用的是对比实验设计且存在混淆变量时，应补充核验实验分组是否合理，而非仅在三层次中选择
