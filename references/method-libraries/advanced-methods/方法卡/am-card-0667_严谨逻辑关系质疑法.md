# 方法卡：严谨逻辑关系质疑法（A且非B）

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 严谨逻辑关系质疑法（A且非B） |
| 适用题型 | 质疑类题目中选项含逻辑关联词（如果...就/只要...才/所有...都） |
| 触发场景 | - 题干结论可写成A→B的形式
- 选项中出现"如果...也会..."或"只有...才..."等逻辑词
- 需要用形式逻辑的方法找到质疑项 |
| 步骤逻辑 | 1. 将题干结论抽象为A→B；2. 找质疑项的两种标准形式：A且非B 或 A→非B；3. A→非B的常见表述：如果A，也会不B（如果不...可能...）；只有A才B；4. 识别"只能"="只有...才"等价翻译 |
| 高频错因 | 不会翻译"只能"——"只能选A"="只有A才能选"混淆正向和逆否——"行使推拥有"的逆否是"不拥有推不行使"，不是"不行使推不拥有"选项有逻辑词就选，没注意方向是否匹配 |
| confidence | medium |

## 补充说明

本法将形式逻辑（翻译推理）与论证题结合考查。本质是论证题但用逻辑关联词包装，表面上严谨实则存在可质疑的环节。关键翻译技巧："只能"="只有...才"=否后推否前。当选项用逻辑关联词编排时，先翻译再判断是否构成A→B的反例（A且非B 或 A→非B）。

## 不适用条件

- 题干结论无法抽象为清晰的A→B形式时，本方法不适用。
- 选项中不含逻辑关联词（如果...就/只要...才/所有...都等）时，应改用常规质疑法。

## 反向触发

- 当选项的逻辑关联词方向与题干一致（构成加强而非质疑）时，应换用支持类方法核验。
- 当翻译后选项不构成A→B的反例时，应转向论证漏洞分析而非强行套用形式逻辑质疑。
