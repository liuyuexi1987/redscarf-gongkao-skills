# 方法卡：主语决定动词搭配

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 主语决定动词搭配 |
| 适用题型 | 逻辑填空——语法搭配 |
| 触发场景 | 空格处是动词，需要判断能否与主语搭配 |
| 步骤逻辑 | ① 先看清主语是什么（如"工作重点"是一个"点"）；② 判断动词能否与该主语搭配（"点"不能"转型"，"工作"才能"转型"）；③ 主语不匹配→排除 |
| 高频错因 | ① 不看主语就选动词→搭配不当；② "工作重点"和"工作"是不同主语→动词不同 |
| confidence | high |

## 补充说明
## 不适用条件
- 空格处是名词或形容词而非动词时，本卡不适用
- 主语与动词的搭配在语法上均成立时，需换用语境分析
- 题目考的是语义逻辑而非语法搭配时，优先用逻辑排除

## 反向触发
- 若空格处需要填的不是动词，不使用本卡
- 若主语本身模糊（如省略主语或主语指代不明），先还原主语再决定是否用搭配法
