# 方法卡：细节题委婉选项优选法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 细节题委婉选项优选法 |
| 适用题型 | 言语理解-细节判断题/细节推断题 |
| 触发场景 | 选项中"可能、一定程度上"等委婉词与"全部、必然"等绝对词混用，需要核对原文表达强度 |
| 步骤逻辑 | 1. 标出选项中的范围和程度词 2. 回原文寻找同等力度的证据 3. 选项比原文更绝对时警惕过度推断 4. 委婉表达若偷换主体、范围或因果关系，同样应排除 |
| 高频错因 | 把委婉语气当成正确答案标志；忽略主体、范围和逻辑关系，只按措辞强弱猜选项 |
| confidence | high |

## 补充说明

委婉词只能提示选项力度较弱，不能证明内容正确。可靠用法是比较"原文力度"和"选项力度"：原文只说可能，选项写成必然属于放大；原文明确建立比较关系，选项如实复述则不能仅因措辞较强而排除。

## 不适用条件

1. 当文段本身就是明确的因果/对比论证，选项中出现比较级属于合理表述时，不应仅因比较级就排除
2. 当委婉选项的内容明显偏离题干讨论的主体或话题时，不能因"用了委婉词"就优选
3. 当有充足时间做题时，应以文段细节比对为主，不依赖此应急策略

## 反向触发

1. 当选项中出现多个都有委婉标志词的选项时，应换用细节比对法逐一验证
2. 当题干问的是"以下哪项正确/不正确"且需精确匹配原文时，应优先用定位-比对法而非委婉排除
