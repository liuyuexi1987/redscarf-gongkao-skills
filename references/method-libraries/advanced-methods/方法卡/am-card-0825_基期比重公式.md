# 方法卡：基期比重公式

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 基期比重公式 |
| 适用题型 | 资料分析——求去年/基期的比重 |
| 触发场景 | 材料给出现期比重、部分增长率和整体增长率，要求计算基期比重 |
| 步骤逻辑 | ① 识别题型：问题问"去年比重""基期占比"；② 列式：基期比重 = 现期比重 × (1+整体增长率)/(1+部分增长率)；③ 先算左边现期比重（拆分），再算右边比1大还是比1小做判断 |
| 高频错因 | 分子分母方向搞反——整体增长率跑上面、部分增长率跑下面（"反过来"）；误将现期比重直接当答案 |
| confidence | medium |
| 不适用条件 | 题目问的是现期比重（直接用部分÷整体即可）；材料未给出部分增长率或整体增长率中的任一个；题目考查比重变化量而非基期比重的具体数值 |
| 反向触发 | 题目问的是比重的增长率而非基期比重值；材料直接给出了基期部分和基期整体的数值，可直接做除法；题目考查的是比重的变化方向（升/降），只需比较部分与整体增长率大小即可 |

## 补充说明

"反过来"的意思：如果用字母推导，B/A × (1+R整)/(1+R部)，化简后整体现期×(1+R部)在分母、部分现期×(1+R整)在分子。口诀是"部分增长率下、整体增长率上"。建议每题先判断右侧分数是大于1还是小于1，结合现期比重快速估算。
