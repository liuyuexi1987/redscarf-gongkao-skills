# 方法卡：直接对应不脑补

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 直接对应不脑补 |
| 适用题型 | 逻辑填空——防错原则 |
| 触发场景 | 找到逻辑对应后选词时，以及看到选项能"强行解释"时 |
| 步骤逻辑 | ① 找到空格对应的原文线索；② 比较各选项需要补充多少未明说的中间逻辑；③ 优先选择与线索语义、搭配和程度直接一致的词；④ 再用完整句意复核，不能只凭单个对应词作答 |
| 验证动作 | 把选项代回原句，检查逻辑关系、搭配对象、感情色彩和语义程度是否同时成立 |
| 不适用条件 | 文段明确要求因果推导、比喻转换或上位概括时，不能机械追求字面复现 |
| 高频错因 | 为偏爱的选项脑补中间步骤；只看词面重复而忽略搭配和程度；把“相关”擅自加强成“相互促进” |
| confidence | high |
| 反向触发 | ['选项需要经过因果推理或多步逻辑链才能成立', '文段使用比喻、类比、象征手法，字面复现反而错误', '题目要求从具体事例概括到抽象上位概念'] |
