# 方法卡：整体结构优先于关联词

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 整体结构优先于关联词 |
| 适用题型 | 中心理解、标题拟定、语句填入 |
| 触发场景 | 看到"但""因此""然而"等关联词就想当然认为后面是重点；被关联词后的非重点内容带跑偏 |
| 步骤逻辑 | 1. 读文段时先判断整体行文结构（五大类：后对策/前对策/总分分总/并列/二层结构）；2. 确定结构后，再看各部分的功能（引话题/分析论证/给对策/给结论）；3. 关联词只是局部信号，不能代替整体结构判断；4. "因此"后不一定是最重要的话；"但"后不一定是重点——取决于它在整体结构中的位置 |
| 高频错因 | 看到"但"就选转折后内容，但实际文段是前对策结构（对策在前，转折在论证部分）；看到"因此"就选其后内容，忽略整体是时间对比结构 |
| confidence | medium |

## 补充说明

- 整体结构判断先于关联词判断：五大类结构（后对策/前对策/总分分总/并列/二层结构）确定后，再看各部分功能（引话题/分析论证/给对策/给结论）
- 关联词只是局部信号，"因此"后不一定是最重要的话，"但"后不一定是重点——取决于它在整体结构中的位置
- 典型错因：前对策结构中，对策在前，"但"出现在论证部分，若被"但"带跑偏就会选错

## 不适用条件

- 文段结构难以归入五大类（如纯记叙、纯说明性段落）时，本方法不适用
- 关联词本身就是文段主信号（如强转折后明确给出全文结论）时，不应机械否定关联词作用

## 反向触发

- 当按整体结构判断的答案与按关联词判断的答案冲突时，应回到首句主题词和文段类型核验，而非直接二选一
- 当文段含多个关联词叠加（如"虽然…但是…因此…"）时，应换用层次切分法，逐层判断主次
