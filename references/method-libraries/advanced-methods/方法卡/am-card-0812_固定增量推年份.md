# 方法卡：固定增量推年份

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 固定增量推年份 |
| 适用题型 | 现期 / 假设增量不变求哪年达标 |
| 触发场景 | 题目说"保持某年增量不变"，问哪一年首次达到/超过某目标值 |
| 步骤逻辑 | 1. 先算出每年的增量X（用假设分配或415）；2. 列不等式：基期 + N×X > 目标值；3. 解不等式得最小整数N；4. 当前年份 + N = 答案年份 |
| 高频错因 | 增量算错导致不等式方向反或N偏大偏小从当前年份算N时多算或少算一年 |
| confidence | medium |

## 不适用条件

1. 题目说的是"保持增长率不变"而非"保持增量不变"，属于固定增速模型，需逐期乘以(1+R)。
2. 增量本身随时间变化（如材料给出每年增量不同），不能用单一固定增量列不等式。
3. 题目要求的是"哪年达到"的精确值而非不等式的最小整数解。

## 反向触发

1. 用固定增速的等比模型处理"保持增量不变"的题目，误把增量当增长率逐期放大。
2. 从当前年份到答案年份的N计算时出现±1偏差，说明起始年份定位错误。
