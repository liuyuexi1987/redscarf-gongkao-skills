# 方法卡：部分vs很多削弱力度辨析

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 部分vs很多削弱力度辨析 |
| 适用题型 | 判断推理-削弱题（选项涉及"部分""有些"vs"很多""大部分"的程度副词） |
| 触发场景 | 题干用办卡人数/销量等数据推出整体有效，选项用"部分人没用""有部分如何"来削弱 |
| 步骤逻辑 | 1. 削弱力度排序：**大部分/很多 > 部分/有些**，差一个量级；2. "部分学生办卡后从未去过"→ 属于正常情况，削弱力度极弱，几乎无关；3. "大部分学生办卡后从未去过"→ 才构成强削弱（拆桥）；4. 看选项时注意程度副词：题目要求"最能削弱"时，"部分"几乎不可能是正确答案；5. 类似地："部分费用降低"对"普遍提高"几乎没有削弱力度（普遍允许小部分例外） |
| 高频错因 | 看到"有部分没去过"就认为能削弱，忽略力度大小不区分"部分"和"很多/大部分"的力度差异 |
| confidence | high |

## 不适用条件

1. 题干结论本身已经用了"部分""某些"等弱量化词，"部分"的削弱选项可能构成有效反驳
2. 题目要求找"最不能削弱"而非"最能削弱"的选项
3. "部分"在选项中指代的是决定性因素的关键少数，而非普通比例

## 反向触发

1. 题干用办卡人数/销量等数据推出整体有效的结论
2. 选项中出现"部分""有些"用于削弱一个普遍性结论
3. 对比选项中同时存在"部分"和"大部分/很多"的表述
