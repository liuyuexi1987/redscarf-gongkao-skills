# 方法卡：增量增速辨析口诀

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 增量增速辨析口诀 |
| 适用题型 | 资料分析 - 审题防错 |
| 触发场景 | 题目问"增长最多"或"增长最快"，需区分求的是增长量还是增长率 |
| 步骤逻辑 | 1. 记住口诀：多少/高低 → 增量（绝对值）；快慢 → 增速（百分比）；2. "增长最多"= 增长量最大，看柱状图直接做减法；3. "增长最快"= 增速最快，需算百分比；4. 审题时先判断关键词属于哪一类，再选择对应方法 |
| 高频错因 | 把"增长最多"误当成增速来算，或者把"增速"当成绝对增量来比较 |
| confidence | high |
| 不适用条件 | 1. 题目明确问的是绝对值变化或百分比增速，审题方向已确定，无需用口诀辨析\n2. 题目涉及增长量和增速的混合排序综合题，本口诀只解决审题方向判断，具体计算还需配合其他方法 |
| 反向触发 | 1. 口诀判定为"增长量"后，若柱状图差值接近难以肉眼判断，需改用截位直除等估算技巧精确比较\n2. 题目同时问多个指标的排序，口诀只能确定单个指标的计算方式，还需配合估算或截位直除快速比较 |
