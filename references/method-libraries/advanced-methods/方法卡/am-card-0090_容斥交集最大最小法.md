# 方法卡：容斥交集最大最小法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 容斥交集最大最小法 |
| 适用题型 | 资料分析-调查问卷/百分比材料中"既A又B"的占比范围 |
| 触发场景 | 题目问"既愿意X又倾向于Y"的人占比范围；或给出多个百分比选项判断交集区间 |
| 步骤逻辑 | 1. 交集**最大值** = min(A, B)，即让小的完全被大的包含；2. 交集**最小值** = A + B - 100%（两者尽量远离时的最小重叠）；3. 若最小值为负数，说明交集可以为零（两者可以不重叠）；4. 用文氏图辅助理解：圈越大越可能包含另一个圈；5. 江苏省考常考此类题型，连续多年出现 |
| 高频错因 | 最小值公式记反（不是 |A-B|，是 A+B-100%）混淆"不在同一整体"的百分比（不同人群的百分比可以直接相加超过100%） |
| confidence | high |

## 不适用条件

1. A 和 B 不属于同一整体的百分比（如不同人群的占比），此时 A+B-100% 无意义
2. 题目给的是具体人数而非百分比，需要先转为百分比再判断基数是否一致
3. 存在第三个条件 C 限制交集范围时，两两容斥公式不能直接套用

## 反向触发

1. 题目直接给出了既A又B的占比，只需验证而非求范围
2. 材料中 A、B 的基数不同（如"愿意X的受访者100人中占80%，倾向于Y的受访者200人中占60%"），不能直接做百分比容斥
