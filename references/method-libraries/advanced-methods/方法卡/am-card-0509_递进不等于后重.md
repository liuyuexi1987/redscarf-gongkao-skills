# 方法卡：递进不等于后重

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 递进不等于后重 |
| 适用题型 | 主旨题/中心理解题 |
| 触发场景 | 文段出现递进关联词（不仅…也/甚至/更），容易误判后面是重点 |
| 步骤逻辑 | 1)递进表示前后语义相近，只是后面程度更重 2)递进并不自动等于"后面最重要" 3)不能仅通过关联词就确定重点 4)要回到整体结构和内容去判断 |
| 高频错因 | 看到递进词就认定后文是重点，忽略了递进只是程度关系 |
| confidence | medium |

## 不适用条件

1. 递进结构配合转折或总结句时，重心取决于整体结构而非递进本身，需综合判断
2. 文段是并列结构伪装成递进（如"不仅…而且…"连接两个独立观点）时，可能需要概括全面

## 反向触发

1. 递进后紧接总结句或结论句时，重心可能在总结句而非递进的后半部分
2. 选项仅涵盖递进后半部分但遗漏前半关键内容时，应选择概括更全面的选项
