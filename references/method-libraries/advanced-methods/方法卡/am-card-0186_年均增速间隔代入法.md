# 方法卡：年均增速-间隔代入法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 年均增速-间隔代入法 |
| 适用题型 | 资料分析——求年均增长率，或判断年均增长率是否超过某值 |
| 触发场景 | 题干出现"年均增速""年均增长率"，年份差为3/4/5年 |
| 步骤逻辑 | ① 第一步：求末期相对基期的总增速R_总=（末期-基期）/基期，再除以年份差N，得到年均增速估算值，感受选项范围；② 第二步：取选项中间值代入，用间隔思路计算该年均增速对应的总增速；③ 间隔计算法：如年均7%，3年份差→先两段加和14%，再加乘积部分0.5%→14.5%，再与第三段7%间隔→加和21.5%+乘积1%=22.5%；④ 将计算结果与R_总比较：若代入值算出的总增速<R_总，则实际年均增速更大，选更大选项 |
| 高频错因 | ① 直接把总增速除以年数当作精确年均增速；② 代入候选值时漏掉复合增长的乘积项；③ 年份差数错或基期、末期方向颠倒 |
| confidence | high |

## 补充说明

本方法用候选值反推累计增速，适合选择题快速比较。选项接近时应保留复合增长项，并用 `(1+r)^N-1` 或连续乘法复核，不能把算术平均当成精确结果。

## 不适用条件

- 各年增长率不同，题目求实际年度平均而非复合年均增长率。
- 年份跨度或基期、末期数据不完整，无法确定复合期数。

## 反向触发

- 选项差距较大时可先用总增速除以期数定位，再代入验证。
- 选项接近或增长率较大时，改用连续乘法或幂次精算，避免省略乘积项。
