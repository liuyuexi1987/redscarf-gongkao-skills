# 方法卡：等差数列识别与常用和
## 基本信息
| 字段 | 值 |
|------|-----|
| 方法名 | 等差数列识别与常用和 |
| 适用题型 | 数量关系-数列/规律识别问题 |
| 触发场景 | 题面隐含公差为1的等差数列结构，如"各减一后排列不变"、"连续正整数"、"等间隔分配" |
| 步骤逻辑 | 1. 识别公差为1的等差数列结构（如"各减一后排列不变"→每个数减1仍是同一组数→公差为1）；2. 常用：1~9之和=45，1~10之和=55，1~n之和=n(n+1)/2；3. 若含0（如空杯），则0是首项，总和=n(n+1)/2；4. 由总和反推n值，再按题意求项数或其他量 |
| 高频错因 | 忘记空杯（值为0）也是数列的一部分；不熟悉常用数列和 |
| confidence | high |
## 补充说明
核心洞察："各减一颗后调整位置与原来一样" = 每个数减1后仍是同一组数 = 公差为1的等差数列。空杯=0是首项。常用记忆点：1+2+...+9=45，1+2+...+10=55，1~n之和=n(n+1)/2。这类题关键在于识别隐含的等差条件。常见识别关键词："各减一后排列不变""连续正整数""等间隔""从m到n"。
## 不适用条件
- 序列公差不为1或公差未知（"各减一后排列不变"的条件不出现）。
- 题目不要求求和，而是要求还原序列中某一项的具体值且其他条件不足以确定。
- 数列含空缺项或跳跃项，不是连续整数构成的等差数列。
## 反向触发
- 题面描述"等比""倍数""翻倍"等字眼，属等比数列或其他递推，不触发本法。
- "各减一后排列不变"表述变形为其他操作（如"各减二""乘以某数"），需重新判断公差。
