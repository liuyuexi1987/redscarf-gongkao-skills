# 方法卡：除法拆分

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 除法拆分 |
| 适用题型 | 资料分析——比重类、分数类除法（A/B求百分比） |
| 触发场景 | 分子在分母的50%、100%、10%、5%附近，或分子与分母接近（比值在1附近） |
| 步骤逻辑 | ① 分母直接抄下，分子拆成"好算部分+剩余"；② 好算部分先得出基准百分比（如分母的一半→50%）；③ 剩余部分用"包子法"估算：分母百分之一=分母小数点前移两位，看剩余能买几个包子；④ 基准±包子数=答案，允许估算 |
| 高频错因 | 分子拆分后数值写错；包子单价（1%）算错导致偏差；选项很近时仍粗略估算导致选错 |
| confidence | medium |

## 补充说明

此法比直除省去"试商"和乘法验证两步。分子分母可同时舍去末位（同舍或同进）以简化，但不能一舍一进。选项极近时（保留三位后差异很小）应转用直除。此法在比重类题目中通常效率较高。当估算误差可能跨越选项或改变结论时，改用精算/验证。

## 不适用条件

1. 分子不接近分母的50%/25%/10%/5%等基准，拆分无明显简化效果。
2. 选项间距极小，基准百分比加减包子数的精度不足以区分答案。
3. 分子分母无法同舍同进简化，且位数较多，拆分反而比直除慢。

## 反向触发

1. 比重类除法（A/B求百分比），且分子在分母的某一基准百分比附近。
2. 选项间距适中，基准百分比加减少量修正即可确定答案。
3. 分子分母可同舍同进简化计算量。
