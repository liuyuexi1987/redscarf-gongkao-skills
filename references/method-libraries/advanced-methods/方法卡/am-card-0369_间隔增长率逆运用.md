# 方法卡：间隔增长率逆运用

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 间隔增长率逆运用 |
| 适用题型 | 资料分析 - 已知间隔增速和同比增速，求基期增速 |
| 触发场景 | 题目给出现期较基期的增速（间隔增速）和同比增速，要求中间基期那年的增速 |
| 步骤逻辑 | 1. 间隔增长率公式：r12 = r1 + r2 + r1×r2；2. 由间隔增速和r1（同比增速），先做差 r12 - r1 得到粗略r2；3. 因为r1×r2为修正项，绝对值一定小于 r12 - r1；4. 所以r2的绝对值一定小于 r12 - r1 的绝对值，结合选项快速锁定 |
| 高频错因 | 忘记交叉项 r1×r2 的存在，直接用间隔增速减同比增速当精确答案 |
| confidence | high |

## 不适用条件

- 题目要求精确计算中间年份增速（本方法用于快速估算，不适用于精度要求高的情形）
- 间隔增速和同比增速符号相反且绝对值接近（交叉项 r1×r2 为负值，修正幅度大，粗略做差方向可能反转）
- 题目直接给出了中间年份增速（无需反推）

## 反向触发

- 当交叉项相对选项差距不可忽略时，不能只做增速差，应使用完整公式求解
- 当选项中有两个值与 r12 - r1 距离相近时，估算无法区分，应代入公式精确计算 r2
- 当题目出现多期间隔（如三年间隔）时，公式结构不同，不能直接套用间隔增长率公式
