# 方法卡：资料分析比较类题优先路径

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 资料分析比较类题优先路径 |
| 适用题型 | 资料分析——比较大小、排序、找最大/最小类题目 |
| 触发场景 | 需要比较多个分数/比值/增速的大小，或对多个指标排序 |
| confidence | high |
| 反向触发 | - 题目要求计算具体数值而非比较大小，走普通计算路径
| 不适用条件 | 只需比较两项且差距明显（直接看分子分母即可判断）；需要求具体数值而非比较大小 |

- 比较对象仅两个且分子分母差异明显，一眼可判断大小 |

## 适用条件

- 比较多个分数（如增速、比重、单价）的大小
- 对多个指标排序（从大到小或从小到大）
- 找最大/最小/最高/最低项

## 不适用条件

- 只需比较两项且差距明显（直接看分子分母即可判断）
- 需要求具体数值而非比较大小

## 核心判断

不要上来就动笔算。比较类题的核心是"看"而非"算"——先用观察法排除，不能排除再用比较法，最后才精算。

## 步骤逻辑

1. **先看分子分母关系**：在指标均为正数且口径一致时，分子大且分母小→比值更大；分子小且分母大→比值更小。用此排除明显最大/最小项
2. **看增速关系判断趋势**：分子增速 > 分母增速→比值变大；分子增速 < 分母增速→比值变小。不需求具体值
3. **看量级差异**：如果某项分子是其他项的10倍以上但分母差不多，直接判断它最大
4. **不能排除时用比较法**：趋势法、差分法、基准线法、盐水法（详见各专项卡）
5. **仍不能区分时才精算**：只算到能区分两个候选项的精度即可停

## 高频错因

- 上来就精算所有选项再比较→浪费大量时间
- 比较平均数增速时，只看分子（R1）不看分母（R2）→遗漏关键信息
- 排序题中某两项很接近时，粗估导致顺序颠倒
- 分子分母搞混（如"平均单价"是总价÷数量，总价是分子，数量是分母）
- 混合类比较用盐水法时，混合比例关系搞反

## 是否允许估算

- 大小关系明显时：不需要计算，直接看
- 需要排序但差距较大时：估算到能区分的精度即可
- 排序项之间差距很小时：需要精算到足够精度

## 何时必须精算

- 两个候选项的估算结果非常接近，无法判断先后
- 排序题要求严格顺序，粗估可能导致相邻两项颠倒

## 常见误差来源

- 趋势法判断时，分子分母增速差距很小导致趋势判断不稳
- 差分法使用时，差分后的分数与原分数方向不一致
- 混合比较时，混合比例（权重）判断错误

## 补充说明

- 比较类题是资料分析中"看起来要算很多但其实可以不算"的典型题型
- 排序题通常有1-2项可以明显排除，只需精确比较剩下的2-3项
- 平均数增速比较：R = (R1 - R2) / (1 + R2)，当R1-R2差距明显时直接看分子即可
- 比较题通常会留下观察或比较突破口，不要默认所有选项都需要完整精算
