# 方法卡：转折后论点优先论证非重点

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 转折后论点优先论证非重点 |
| 适用题型 | 中心理解 |
| 触发场景 | 文段有转折，转折后提出论点，后面接解释说明或正反论证 |
| 步骤逻辑 | 1. 识别转折前后语义关系，不按关联词机械切割；2. 判断转折后是否提出作者核心观点；3. 用后续解释、举例或正反论证确认观点的对象、范围和力度；4. 选择准确概括核心观点且不遗漏必要限定的选项 |
| 高频错因 | 从论证部分（解释说明）提炼内容当主旨 |
| confidence | high |

## 不适用条件

1. 转折后仅为事实补充而非论点（转折后是数据、举例等辅助信息）
2. 文段有多个转折，需判断哪个转折后的论点是最终重点
3. 题目问的是"文段讨论了哪些内容"之类全面概括，论证部分不可忽略

## 反向触发

1. 文段有转折（"但是""然而""不过"等），转折后提出论点并接解释说明/正反论证时，主旨取论点
2. 选项只复述论证细节而没有覆盖转折后的核心观点时，通常范围片面
3. 转折前内容常是背景或被修正观点，但若它限定了讨论对象，概括时仍需保留必要范围
