# 方法卡：内容决定问法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 内容决定问法 |
| 适用题型 | 片段阅读-中心理解题 |
| 触发场景 | 遇到"主旨/意图/主要介绍/意在说明"等不同问法时纠结是否要"往前推" |
| 步骤逻辑 | 1. 不是问法决定答案，而是文段内容决定问法；2. 说理类文段 → 出题人问"意在说明/意图强调/观点"（因为作者本身有意图）；3. 科普介绍类文段 → 出题人问"主要介绍了什么/概括"（因为作者是中性介绍）；4. 不需要根据问法机械地"往前推"或"不推"，回归文段类型判断即可 |
| 高频错因 | 机械地认为"意图题要推、概括题不推"，忽略了文段本身的类型 |
| confidence | medium |

## 不适用条件

1. 问法与文段类型出现矛盾（如科普类文段却问"意在强调"），此时仍以文段类型为准，选客观概括，不按问法"往前推"。
2. 题目属于非主旨类（语句排序、语句衔接、细节判断），问法直接决定解题策略，不适用本方法。
3. 文段本身类型模糊，作者既有介绍也有少量倾向，此时问法可作为辅助参考但不能单独决定答案方向。

## 反向触发

1. 判断文段类型后，说理类配合前对策结构抓对策法，科普类配合科普类客观概括法。
2. 如果问法是"主旨概括"但选项全是对策，需先判断文段是否有对策倾向，不能只凭问法排除对策选项。
3. 如果多个选项在"推/不推"上无差异，应结合主体一致性排除法判断。
