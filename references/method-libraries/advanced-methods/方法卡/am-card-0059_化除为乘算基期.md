# 方法卡：化除为乘算基期

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 化除为乘算基期 |
| 适用题型 | 资料分析-基期计算 |
| 触发场景 | 增率R很小（<10%），需要快速算基期 |
| 步骤逻辑 | 1.基期=现期/(1+R)；2.当R很小时，近似为：基期≈现期-现期×R；3.用现期乘以R算出增量，从现期中减去即得基期 |
| 高频错因 | 直接用长除法计算，计算量大且慢 |
| confidence | high |

## 不适用条件

1. 一阶近似1/(1+R)≈1-R的高阶误差可能跨越选项时，不宜使用。
2. 选项数值极为接近、近似误差可能跨越选项时，需回到完整除法。
3. R为负值且绝对值较大时，化除为乘需额外注意符号和近似误差，不如直接代入公式稳妥。

## 反向触发

1. 题目问的是"增长率"或"增速"而非基期值——应直接用增速=增量/基期，无需反推基期。
2. 现期与选项差距很大，即使粗估也能排除——此时无需近似计算，直接用量级判断即可。
3. 选项间距不足以覆盖近似误差时，应直接长除或交叉验证。

## 补充说明

数学原理：1/(1+R)≈1-R（当R很小时，泰勒展开一阶近似）。所以现期/(1+R)≈现期×(1-R)=现期-现期×R。R越小误差越小。R在10%以内时误差在1%以内，完全满足题目精度要求。此法将除法转化为乘法和减法，大幅降低心算难度。本集在算基期时反复使用此法。
