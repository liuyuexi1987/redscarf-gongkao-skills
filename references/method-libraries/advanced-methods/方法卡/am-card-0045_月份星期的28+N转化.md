# 方法卡：月份星期的28+N转化
## 基本信息
| 字段 | 值 |
|------|-----|
| 方法名 | 月份星期的28+N转化 |
| 适用题型 | 数量关系-时间日期/星期问题 |
| 触发场景 | 已知某月天数和限行/星期条件，推算某日是星期几 |
| 步骤逻辑 | 1.将月份天数转化为28+N形式（28=4个完整周期）；2.剩余N天的星期数与月初N天相同；3.根据题目限行/星期条件排除或锁定这N天是哪几天；4.由月初星期数反推整月 |
| 高频错因 | 忘记31天=28+3，误用30或31直接除7取余；未利用"前后N天星期数相同"的结论 |
| confidence | high |
## 不适用条件
- 月初是星期几未知且无法从题目条件推断——无法定位剩余天数
- 跨越多个月份且未给出跨月衔接条件——单月28+N转化无法连续使用
- 闰年2月涉及2月29日的特殊日期——29=28+1虽可转化但需额外确认闰年

## 反向触发
- 题目直接给出月初星期数，问的是具体日期而非星期——本法用于推星期，反向需其他方法
- 题目问"一个月最多有几个星期X"——需按4或5判断，非28+N转化的典型用法
- 题目涉及的天数范围跨越28天整周期且余数为0——前后部分完全对称，无需转化

## 补充说明
核心结论：31天中前三天与后三天星期数相同，30天中前两天与后两天相同，29天中前一天与后一天相同。因为28天恰好4个周期，余下的天数就是新周期的开头。利用题目条件（如周一和周五天数一样多且只能是4天）可排除不可能情况，锁定余下天数是周二三四，从而确定月初是星期二。
