# 方法卡：比例论证看分母

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 比例论证看分母 |
| 适用题型 | 比例类论证题（用绝对数量比较得出优劣结论） |
| 触发场景 | 题干仅用分子（如事故数、发病数、考过人数）做比较，忽略分母（总量、基数）时 |
| 步骤逻辑 | 1. 识别题干是否用绝对数量而非比率做比较；2. 正确答案一定从分母角度质疑/支持；3. 例如：南部事故多 → 北部更安全？需看南部运行线路数（分母）；4. 有烟家庭儿童中耳炎多 → 吸烟导致？需看有烟/无烟家庭总数（分母） |
| 高频错因 | 被绝对数量迷惑，未意识到真正的比较应是比率（发病率、事故率等） |
| 不适用条件 | 题干已给出比率/比例数据而非绝对数量，或分母相同无需比较时 |
| 反向触发 | 题干比较的是比率而非绝对数量，或已明确给出基数时 |
| confidence | high |
