# 方法卡：因果加强搭桥

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 因果加强搭桥 |
| 适用题型 | 判断推理——加强削弱·因果论证（由果推因·加强） |
| 触发场景 | 题干猜A导致B，需要找加强项 |
| 步骤逻辑 | ① 识别题干因果猜测；② 找一个解释"A为什么能导致B"的机制选项（搭桥）；③ 该选项给出A→B的合理因果路径 |
| 高频错因 | ① 选了重复论点的选项（只是换个说法重述因果关系）；② 选了无关项（与A→B的因果机制无关） |
| confidence | high |

## 补充说明

加强因果论证的核心：不是重述"A导致B"，而是解释"A通过什么机制导致B"。机制搭桥需要给出A到B之间的中间环节，使因果链条完整。

## 不适用条件

- 题干本身已给出完整因果机制时，本方法不适用。
- 题干要求削弱而非加强因果时，本方法不适用。
- 选项中无任何项能给出A→B中间机制时，本方法不适用。

## 反向触发

- 当题干要求用共同原因削弱原论证时，应换用共同原因削弱法。
- 当选项以"他因削弱"形式出现时，应补核验他因削弱力度。
- 当题干要求解释矛盾现象而非加强因果时，应换用解释转折现象法。
