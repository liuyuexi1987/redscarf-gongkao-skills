# 方法卡：图推数量规律分层排查法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 图推数量规律分层排查法 |
| 适用题型 | 判断推理——图形推理·数量规律 |
| 触发场景 | 整体规律（对称/曲直/开闭/部分数/一笔画）排查无果，各图差异大且无明显特征图，需转向数量规律时 |
| 步骤逻辑 | ① 确认进入数量排查：对称性排除、取值性排除、开闭性排除后转向数量；② 按高频优先级分层：面→笔画→元素→线→点→角；③ 面：数白色封闭区域，看是否等差/恒定/周期/运算；④ 笔画：先判断是否连通；连通图按奇点数÷2 向上取整，不连通图按各连通块分别计算后相加；⑤ 元素：数独立小图形的种类和数量，不同种类分别计数；⑥ 线：横线/竖线/斜线/平行线分别计数；⑦ 点：总交点数或框内交点数；⑧ 角：几乎只考直角，通常靠遍历发现 |

## 方法说明

数量规律是图推最常规的排查线路。当整体规律（对称/取值/开闭）无果后，大部分题落到数量规律。核心不是"数什么"，而是"按什么顺序数"。

高频三考点：**面、笔画、元素**。面和笔画几乎必考其一，元素因黑白块部分数的高频考查也非常重要。线、点、角出现频率较低但不能忽略。

排查时按优先级逐个验证，每个维度花 10-15 秒。若某维度有规律但选项无法区分，说明可能考的是该维度的细分规律（如最大最小面、两笔画/三笔画、元素种类），需进一步分析。

面的出题方式：图形被分割（外框内加线）或图形相交形成封闭区域。面必须是**白色+封闭**，黑色不算、有缺口不算。

## 使用边界

- 适用于：各图差异大、无明显特征图、整体规律排查无果
- 不适用于：有明显特征图时应优先用特征触发卡（1105-1112）
- 不适用于：高度相似的图应优先考虑移动/旋转/翻转/叠加

## 不适用条件

1. 有明显特征图时（应优先用1105-1112对应特征触发卡）
2. 高度相似的图（应优先考虑移动/旋转/翻转/叠加）
3. 图形以规整分割为主要特征时（应优先用1123规整图形专项分析法）

## 反向触发

1. 面规律验证无果时，应补充核验最大最小面/相同面等细分规律（参考1123）
2. 笔画规律验证无果时，应补充核验连通块数和奇点分布
3. 各维度均有微弱规律但无法锁定选项时，应换用1124图形间关系细分法

## 观察顺序

1. 确认整体规律已排除（对称→取值→开闭→部分数→笔画）
2. 按高频优先级排查：面→笔画→元素→线→点→角
3. 每个维度 10-15 秒验证
4. 某维度有规律但选不出时，转向该维度的细分规律

## 常见错因

1. 排查无序，想到什么数什么
2. 忽略面的定义（白色+封闭）
3. 笔画判定凭感觉，不先区分连通块再数奇点
4. 元素题不区分种类分别计数
