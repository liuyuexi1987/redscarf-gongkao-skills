# 方法卡：根本原因判断法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 根本原因判断法 |
| 适用题型 | 归因论证中两人观点对立的题目（原观点 vs 反对者） |
| 触发场景 | - 题干有两个人的观点：原观点认为X导致结果，反对者认为Y导致结果
| confidence | medium |
| 不适用条件 | 1. 题干只有一个人的观点，没有对立观点；2. 题目不是归因论证而是常规支持/质疑题；3. 两个观点不是针对同一结果的因果解释 |
| 反向触发 | 1. 题干出现两个人对同一现象给出不同因果解释（X导致结果 vs Y导致结果），立刻想到根本原因判断法；2. 看清题目问的是支持谁还是质疑谁，再决定谁做根本原因、谁做表面原因 |
- 问支持谁或质疑谁 |
| 步骤逻辑 | 1. 识别两个观点：原观点（X→结果）和反对者（Y→结果）；2. 若支持反对者：反对者的Y是根本原因，原观点的X是表面原因（反对者→原观点→结果）；3. 若质疑反对者：原观点的X是根本原因（原观点→反对者→结果）；4. 口诀：质疑谁谁就是表面原因，支持谁谁就是根本原因 |
| 高频错因 | 搞反根本原因和表面原因的归属没看清题目问的是支持还是质疑 |

## 补充说明

这是强化方法总结的归因论证特殊题型，结构固定为"两人说法对立"。快速判断口诀：支持谁就让谁做根本原因（原因的原因），质疑谁就让谁做表面原因。此法可快速排除干扰选项。
