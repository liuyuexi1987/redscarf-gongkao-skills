# 方法卡：递推数列圈三法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 递推数列圈三法 |
| 适用题型 | 数量关系——数字推理（递推数列） |
| 触发场景 | 数字推理中数字较大、差值无规律，怀疑是递推数列 |
| 步骤逻辑 | ① 圈三个数（最好含一个两位数，运算路径更少更易判断）；② 先固定一个数不动；③ 尝试三种运算路径（加/减/乘/除）得到中间值；④ 验证前后的数是否符合规律；⑤ 若运算中出现 0.5，可作为提示考虑除以 2 的路径，但仍需用后续项连续验证，不能仅凭 0.5 出现就锁定该路径 |
| 高频错因 | ① 圈的数太小（都是一位数）→运算路径太多无法判断；② 不固定一个数→三种路径都试→效率低 |
| confidence | high |

## 补充说明
递推数列的核心方法。关键：圈三个数时选一个两位数（如3和10→3×10-1=29），运算路径更少更容易判断。和数列（而非仅奇数列）频繁出现，三项做合是常见模式。

## 不适用条件
- 可用项太少、候选递推关系无法在后续项连续验证时。
- 数列明显呈等差/等比特征时，应优先用做差/做商法，圈三法反而绕远。
- 数列已呈现明显分组、幂次或倍数结构时，应先验证该结构，不必穷举圈三运算。

## 反向触发
- 当圈三后多种运算路径都"看似成立"时，应换用延展验证法：用疑似规律推下一项并比对，仅保留能覆盖全部已知项的路径。
- 当数列出现分数/小数且无明显倍数关系时，应补充通分或化为同分母后再分析，或转"分组数列识别总卡"。
- 当数列具备分组对应特征（奇偶项分别成规律）时，应改用"分组数列识别总卡"而非圈三递推。

## 最终验证动作

1. 用圈定的递推规律从首项逐项递推，确认每一项都与原数列完全吻合。
2. 推出目标项后与选项比对；若目标项与最近选项有固定差值，检查递推公式中是否有末项修正。
3. 对涉及三项的递推（如 a(n+2)=f(a(n),a(n+1))），必须验证递推关系在至少两个连续位置都成立。
