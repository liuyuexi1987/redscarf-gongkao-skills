# 方法卡：分段法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 分段法（减法） |
| 适用题型 | 资料分析——多位数减法、判断增量是否超过某阈值 |
| 触发场景 | 减法涉及借位、口算吃力时；需要判断增量是否大于某值（如500万） |
| 步骤逻辑 | ① 把减数和被减数按位分段（如前两位和后一位）；② 各段独立相减，互不干扰；③ 若末段不够减，可利用负数；④ 组合各段结果 |
| 高频错因 | 分段后各段互相干扰；负数处理错误 |
| confidence | medium |
| 不适用条件 | 1. 不适用于小数减法或百分数减法（应优先用小数对齐或直接计算）
| 反向触发 | 1. 看到两个数均为小数或百分数，不用分段法，改用小数对齐法
2. 两个数百位相同且尾数差距小，直接相减更快，不需要分段
3. 当基准值法能更快解决时（两数百位相邻），优先用基准值法替代分段法 |
2. 两个数字位数较少且相减不涉及借位时，直接口算更快
3. 要求精确到个位且选项间距极小时，分段法的负数合并容易出错 |

## 补充说明

分段法的关键：前两位减前两位、后一位减后一位，互不干扰。末段不够减时用负数处理（如1-8=-7），再与前段结果合并。判断增量是否超过某阈值时，先看百位以上是否够，再看零头是否够减。
