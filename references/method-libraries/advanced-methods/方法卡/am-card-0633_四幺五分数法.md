# 方法卡：四幺五分数法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 四幺五分数法（百化分） |
| 适用题型 | 资料分析——增长率转化为分数后的基期与增量计算 |
| 触发场景 | 增长率R可以近似为某个简单分数 1/n 时（如25%≈1/4，16.7%≈1/6） |
| 步骤逻辑 | ① 将R转化为分数：R≈1/n；② 基期A = B×n/(n+1)（即B除以n+1）；③ 增量X = B/(n+1)（即B除以n+1）；④ 快速验证：基期+n份 = 现期B |
| 高频错因 | 分母选错（n和n+1搞混）；负增长时忘记增量为负 |
| confidence | medium |
| 不适用条件 | 增长率无法简化为常用分数对照表内的简单分数时；选项间距极小需要精算区分时；负增长且选项含减少量的比值/倍数时（易混淆符号） |
| 反向触发 | 看到增长率约等于 1/3、1/4、1/5 等简单分数，且选项间距较大时，优先考虑四幺五分数法 |

## 补充说明

四幺五的本质是：若R=1/n，则基期是n份，增量是1份，现期是n+1份。负增长时（R=-1/n），基期是n份，增量是-1份，现期是n-1份。此方法与假设分配可配合使用：假设分配第一步用整百数，第二步当R在分数附近时直接用n+1分之一修正。
