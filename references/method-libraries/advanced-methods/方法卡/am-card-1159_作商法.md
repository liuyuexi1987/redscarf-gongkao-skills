# 方法卡：作商法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 作商法 |
| 适用题型 | 数量关系——数字推理（等比数列、倍数递推数列） |
| 触发场景 | 相邻两项之间存在明显倍数关系，或数列整体呈单向放大/缩小且增幅与项本身同量级 |
| 步骤逻辑 | ① 逐项计算后项÷前项的商；② 观察商序列是否为常数（等比）、等差/等比数列（多级等比）、或简单递推序列；③ 商为常数→直接定公比求下一项；④ 商自成规律→按规律推下一商，再乘回原数列末项得目标项；⑤ 商不成规律但接近某固定值→转"等比修正与乘法递推法" |
| 高频错因 | ① 数列只是单调递增就盲目作商，未先确认增幅与项同量级（如 2,4,6,8 作商得 2,1.5,1.33 反而失真）；② 商序列只看了前两项就断定是等比，未用后续项连续验证；③ 含负项或零项时直接作商，未先处理符号或零导致的除零问题 |
| confidence | high |

## 不适用条件

1. 相邻项增幅远小于项本身（如 100,105,110,115）时，作商得到的商接近 1，区分度低，应改用作差法。
2. 数列含零项时，若前项为 0，则“后项÷前项”无定义，作商路径会中断；若后项为 0，商虽可计算但通常不足以支持稳定规律，应结合其他路径验证。
3. 数列含正负交替项时，商的符号会掩盖幅度规律，应先抹平符号或改用其他路径。
4. 已知项少于 4 项时，商序列样本不足，作商结论不可靠。

## 反向触发

1. 当商序列只在前两项成立、第三项开始偏离时，应切换到"等比修正与乘法递推法"，检查是否存在固定修正项。
2. 当商序列呈无规律波动时，应回退到"数字推理总纲"的回退路径，改用作差或求和。
3. 当数列增幅剧烈（后项是前项的平方或更高次）时，作商得到的商本身仍呈指数增长，应改用幂次修正路径。

## 最终验证动作

1. 用求得的公比或商序列规律，从首项逐项乘回，确认每一项都与原数列完全吻合。
2. 推出目标项后，与选项比对；若目标项与最近选项有固定倍数差，检查是否存在末项倍数修正。
3. 对多级等比（商自成等差/等比），必须验证商序列的规律同样覆盖全部已知商，不能只验证末位。
