# 方法卡：两个选项对称时对比差异

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 两个选项对称时对比差异 |
| 适用题型 | 判断推理——图形推理 |
| 触发场景 | 图推选项中有两个选项看起来很像（对称/镜像） |
| 步骤逻辑 | ① 发现两个选项对称/很像→重点对比它们的差异；② 差异之处就是考点所在；③ 回到题干图形验证差异处的规律 |
| 高频错因 | ① 不注意选项间的差异→选了错误的对称方向；② 选项对称时犹豫不决→浪费时间 |
| confidence | high |

## 补充说明
图推出现对称选项是"二级规律"的信号。两个对称选项的区别就是考点——如左右镜像→考的是方向性；上下翻转→考的是翻转规律。

## 不适用条件
- 选项之间无对称/镜像关系时，本卡不适用
- 题目考查的是数量规律（如点、线、面数量）而非形状规律时，应换用数量分析
- 所有选项差异明显、无相似选项时，无需用对比差异法

## 反向触发
- 若选项中无任何两个选项看起来相似或对称，不使用本卡
- 若题干图形的规律明显是数量类（如交点数、线条数），先用数量规律排除
