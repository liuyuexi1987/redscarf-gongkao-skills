# 方法卡：鸡兔同笼假设法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 鸡兔同笼假设法 |
| 适用题型 | 数量关系——鸡兔同笼、两档单价或费率 |
| 触发场景 | 已知总数量和总费用，两类对象的单价或单位贡献不同，求各自数量 |
| 步骤逻辑 | 1. 假设全部按低价（或低费率）计算 → 理论总费用；2. 实际总费用 - 理论总费用 = 差额；3. 差额 ÷ 单价差 = 高价部分的数量；4. 总量 - 高价部分 = 低价部分的数量（或反向假设） |
| 高频错因 | 求的是哪个量搞反（假设全低价求出的是高价数量，反之亦然）单价差的方向搞错 |
| confidence | medium |
| 不适用条件 | 只有一种单价或费率；对象超过两类且缺少进一步约束；总数量和总费用都未知 |
| 反向触发 | 总量未知时先利用其他条件求总量；超过两类对象时改用方程组或分步假设；计算后数量不为可行整数时，回查假设方向和单位差 |
2. 涉及三档及以上阶梯价格时，两层假设法不再适用，需逐层分段计算 |
2. 已知高低两部分各自的数量，只需求总费用（直接加权即可，无需假设） |

## 补充说明

强化方法口诀"射鸡求兔"：假设全是鸡（低价），差额部分就是兔（高价）的数量。此题中天然气：假设全打折（3.2元/m³），理论花320元，实际花380元，多花60元，每立方差0.8元，所以标准用量=60÷0.8=75m³。也可反向假设全原价，求打折数量。
