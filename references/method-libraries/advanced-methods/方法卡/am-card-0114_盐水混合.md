# 方法卡：盐水混合

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 盐水混合 |
| 适用题型 | 资料分析·当月增速与累计增速比较、部分占比与总体占比推断 |
| 触发场景 | 累计值由两个分段混合得到，需要判断分段值与混合值的大小关系时 |
| 步骤逻辑 | 1. 识别混合数据（如1~6累计由1~3和4~6混合得到） 2. 确认混合比重在两个分段比重之间 3. 已知一个分段比重和混合比重，推断另一个分段比重的范围 |
| 高频错因 | 搞混谁是混合值谁是分段值；未注意同比/环比的时间基准 |
| confidence | high |

## 补充说明

盐水混合是资料分析中的高频考点方法。至少在三个场景使用：环比占比判断（混合值在两个分段值之间）、当月增速与累计增速比较（当月累计混合后增速在当月和前期累计之间）、增速范围限定。核心原理：混合后的值一定介于两个组成部分的值之间。

关键简化规则：当n期累计增速高于n-1期累计增速时，第n期当月增速大于n期累计增速（反之亦然）。原理：n期累计增速是第n期当月增速与前n-1期累计增速的加权平均，混合值高于其中一个分段，另一个分段必更高。

### 补充场景：去除部分后判断剩余部分范围
当已知整体比重和若干部分比重，求去除某部分后的比重时：若被去除部分比重高于整体比重，剩余部分比重必低于整体比重。

## 不适用条件
1. 当无法确定混合关系（即不确定整体由哪些部分构成）时，此法不适用
2. 当混合涉及时间加权或其他非简单混合因素时，需额外核验

## 反向触发
1. 当混合值不在两个分段值之间时，应重新检查数据或判断基准是否搞混
2. 当需要精确计算分段值而非判断范围时，应换用列方程法
