# 方法卡：高频切入法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 高频切入法 |
| 适用题型 | 排列匹配/组合对应题（一拖五、条件匹配） |
| 触发场景 | 多个元素需要放入时间/位置格子中，存在重复出现的元素 |
| 步骤逻辑 | 1. 统计每个元素在所有条件中出现的次数；2. 找出出现次数最高的元素（高频元素）；3. 从高频元素入手，结合限制条件确定其位置；4. 高频元素确定后，连锁推出其他元素 |
| 高频错因 | 从低频元素入手，信息不足导致大量试错；忽略"连续""不连续"等约束条件对高频元素的连锁影响 |
| 不适用条件 | 元素出现频率接近、无明显高频元素时；题干条件全部为全局约束（如"所有元素都满足X"）无法区分优先级 |
| 反向触发 | 题目元素数量极少（3个以下）且条件互相独立，不存在连锁推理关系 |
| confidence | high |
