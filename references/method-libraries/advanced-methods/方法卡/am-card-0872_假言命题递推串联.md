# 方法卡：假言命题递推串联

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 假言命题递推串联 |
| 适用题型 | 组合排列题、形式推理题 |
| 触发场景 | 题干给出多个假言命题，且其中出现频率高的对象在两个以上假言命题中重复出现 |
| 步骤逻辑 | 1. 找高频出现的对象（A在条件1和条件3中都出现）；2. 看能否串成链条：若命题1后件=命题2前件，则 A推B推C，可得 A推C；3. 也检查后件互为矛盾的情况：A推B、A推否B → A不成立；4. 还有前件相同的情况：A推B、否A推B → B必然成立（两难） |
| 高频错因 | 只写 A推C 忘记中间的 B 仍然成立；串不起来时卡住，不知道换一组对象尝试 |
| confidence | high |

## 补充说明

串联的核心条件是"讨论对象相同"。如果一个后件和另一个前件正好一正一反，可通过否后推否前转换后再串。

## 不适用条件

1. 各假言命题的对象完全独立、无重叠时，无法串联，应换用逐条假设法。
2. 题干中假言命题数量极少（仅一条）时，无需串联，直接使用肯前肯后或否后否前即可。

## 反向触发

1. 当串联推导出的结论与已知直言命题矛盾时，说明链条中某一步的条件未满足，需回溯检查哪条假言命题的激活前提不成立。
2. 当串联只能推出部分结论、无法确定最终答案时，应结合假设法对剩余可能性逐一排查。
