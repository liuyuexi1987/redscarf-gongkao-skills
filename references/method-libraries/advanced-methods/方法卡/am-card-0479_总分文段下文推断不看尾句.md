# 方法卡：总分文段下文推断不看尾句

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 总分文段下文推断不看尾句 |
| 适用题型 | 下文推断题（总分结构文段） |
| 触发场景 | 文段结构为"总对策 → 具体而言（分一、分二……）"，属于总分结构。尾句是分论点之一（并列结构的其中之一），不是全文总结。 |
| 步骤逻辑 | 1. 识别"具体而言""例如""一方面……另一方面"等提示词 → 确认总分结构；2. 总分文段中尾句 = 并列分句之一，**不能只看尾句推断下文**；3. 应基于**全文结构**考虑：总对策讲了"是什么/为什么" → 下文应讲"怎么做"；4. 对比选项时，选与总对策话题一致且逻辑在先的（如先立法再执法）；5. 出现在分句中的细节（如"执法"）≠ 文段重点方向 |
| 高频错因 | 惯性看尾句推下文，在总分文段中被尾句的分论点误导把分句中的细节当成下文展开方向 |
| confidence | high |

## 不适用条件

1. 文段为"分—总"结构时（尾句是总结句），尾句方向即为下文推断依据，可正常看尾句。
2. 文段为并列且无总论点的结构时，应选概括性选项而非从总对策方向推断。
3. 尾句为全文总结而非分论点之一时，尾句即文段重心，不能套用本方法。

## 反向触发

1. 如果选项与尾句话题一致且与总对策方向不矛盾，需验证是否确实为总分结构再决定，避免误判文段结构后用错方法。
2. 当出现"分—总"结构时，应切换为"看尾句总结方向推下文"的常规思路。
3. 若选项均与总对策无明确关联，应回到文段整体概括，避免强行套用总对策方向推断。
