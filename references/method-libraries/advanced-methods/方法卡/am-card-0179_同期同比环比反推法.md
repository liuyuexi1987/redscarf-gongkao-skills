# 方法卡：同期同比环比反推法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 同期同比环比反推法 |
| 适用题型 | 资料分析 — 比较同比基期与环比基期的大小 |
| 触发场景 | 同一现期值同时给出同比增减率和环比增减率，需要判断同比基期和环比基期谁大 |
| 步骤逻辑 | 1. 同一现期值下，增减百分比越小，其基期值越大；2. 若同比减少3.2%、环比减少16.7%，则同比基期（减少幅度小）> 现期 > 环比基期（减少幅度大）；3. 由此直接判断两个基期的大小关系，无需分别求出基期数值；4. 适用于选项分别问同比和环比基期的比较题 |
| 高频错因 | 误以为同比和环比减少比例越大基期越大（方向反了）分别计算两个基期再比较，浪费时间 |
| confidence | high |

## 不适用条件

- 题目要求计算具体的基期数值（而非比较大小），本方法只能判断大小关系，不能得出精确值。
- 同比和环比增减率符号相反（一个增长一个减少），方向判断需更谨慎，不能简单套用"幅度小→基期大"。
- 题目涉及多年期数据或多期链式比较，本方法仅适用于单一现期下的同比/环比两两比较。

## 反向触发

- 同一现期值同时给出同比和环比两个增减率时，提示用本方法快速判断基期大小。
- 选项直接比较"同比基期""环比基期"的大小关系时，提示无需分别计算。
