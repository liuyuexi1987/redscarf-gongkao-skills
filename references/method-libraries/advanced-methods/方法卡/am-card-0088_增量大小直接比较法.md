# 方法卡：增量大小直接比较法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 增量大小直接比较法 |
| 适用题型 | 资料分析-多月份增长量排序或判断是否超过某阈值 |
| 触发场景 | 需要比较两个时间段的增长量大小，且已知两者基期 B 和增长率 R 的关系 |
| 步骤逻辑 | 1. 增量 ≈ B × R（近似关系）；2. 若 A 的 B 更大且 R 也更大 → A 的增量一定更大，无需计算；3. 若一个 B 大但 R 小，则需要进一步估算；4. 实战中常用：把多个待比较的月份基期都取整到同一个数（如都当3000），只看 R 大小即可判断 |
| 高频错因 | 每次都精确计算增量，浪费大量时间忽略 B 和 R 的联合比较，只看 R 不看 B |
| confidence | high |

## 不适用条件

- 两个对象的B和R呈反向关系（一个B大R小、另一个B小R大）时，需要实际估算，不能直接判断
- 增长率为负数时，增量为负值，方向判断容易出错
- 题目要求精确计算增量值而非比较大小时，此法不适用

## 反向触发

- 当B和R一个大一个小互相交叉，无法直接判定时，应改用增量公式 Δ=B×R/(1+R) 精确估算
- 当题目要求选出"增长量最大/最小"的多个对象排序时，两两比较不够，需统一估算排序
- 当出现负增长时，增长量为负，"大小比较"需额外考虑绝对值和方向
