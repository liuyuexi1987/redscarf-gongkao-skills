# 方法卡：代词回找主题词法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 代词回找主题词法 |
| 适用题型 | 逻辑填空+言语理解——代词指代 |
| 触发场景 | 空格附近有代词（这、此、其、该、这种），需要确定指代对象 |
| 步骤逻辑 | ① 找到代词；② 往前找反复出现的词语（主题词）；③ 代词指代的就是主题词；④ 空格处的词要与主题词语义一致 |
| 高频错因 | ① 不回找主题词→凭感觉猜代词指代；② 代词在中间/靠后时是重要提示词，忽略它会丢失关键逻辑 |
| confidence | high |

## 补充说明
代词是连接前后文的桥梁。在逻辑填空中，代词帮助确定空格的逻辑方向；在中心理解中，代词帮助确定主旨句的指代对象。代词在中间或靠后位置时尤为重要，往往是解题关键。回找时应优先锁定文段中反复出现的主题词，再判断代词与该主题词的指代关系。

## 不适用条件
- 文段无代词或代词指向明确无须回找时，本方法不产生增量信息。
- 代词指代对象在文段外（依赖背景知识）时，本方法无法仅凭文段确定指代。
- 文段中多个主题词反复出现、代词指代存在歧义时，单一回找不足以确定，应配合其他线索。

## 反向触发
- 当代词回找得到多个候选主题词时，应换用"中心理解四步法（国考版）"从主旨句角度反向锁定指代对象。
- 当代词出现在并列结构中时，应结合"分号并列对应法"判断代词指代的是哪一分句的主题词。
- 当代词指向的主题词与空格逻辑方向不一致时，应核验是否漏读了转折或递进关联词，避免误判指代。
