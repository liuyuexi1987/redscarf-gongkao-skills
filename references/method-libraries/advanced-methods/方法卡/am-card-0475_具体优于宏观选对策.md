# 方法卡：具体优于宏观选对策

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 具体优于宏观选对策 |
| 适用题型 | 中心理解题（对策类文段） |
| 触发场景 | 两个选项都是对策类表述，但一个给出了具体做法（如"数据库""数字化"），另一个只有宏观方向（如"急需整理""加强管理"）。 |
| 步骤逻辑 | 1. 确认文段有对策；2. 对比候选对策选项：哪个更具体、更能回答"怎么做"；3. **具体的一定是大于宏观的**；4. 例：文段说"时刻资料数字化使需求成为可能" → 选"时刻数据库"（具体），不选"急需整理"（宏观）；5. 判断标准：选项是否给出了文段中提到的**具体手段/工具/路径** |
| 高频错因 | 觉得宏观表述"涵盖面广"所以更安全，反而错选没有识别出具体选项其实是宏观选项的上位展开 |
| confidence | high |

## 不适用条件

1. 文段未提及具体手段/工具/路径，两个对策选项均为宏观表述时，不能套用"具体>宏观"，需改用文段信息匹配度判断。
2. 文段给出了多个具体对策，选项只概括了其中一个，此时"具体"选项可能遗漏关键对策，需评估概括是否全面。
3. 文段对策指向的是方向而非手段（如"应转变思路"），具体选项可能是方向下的某一实现方式，未必等同于文段的对策意图。

## 反向触发

1. 当两个选项都具体但涉及不同的具体手段时，不能简单说"都具体所以都对"，应以文段明确提到的手段为准。
2. 具体选项与文段主题词范围不一致时（如文段说"档案管理"，选项说"数据库建设"），具体性让位于范围匹配。
3. 估算误差可能跨越选项时改用精算：具体选项和宏观选项分别与文段原文对比，逐句核对契合度。
