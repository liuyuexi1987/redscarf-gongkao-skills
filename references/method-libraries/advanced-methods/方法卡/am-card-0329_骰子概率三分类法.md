# 方法卡：骰子概率三分类法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 骰子概率三分类法 |
| 适用题型 | 数量关系——概率、分类计数 |
| 触发场景 | 三颗公平骰子或三个独立等可能结果，按全同、全异、两同一异分类求概率 |
| 步骤逻辑 | 1. **完全相同**（豹子）：第一个随意(6)，第二个1/6，第三个1/6 → 6种 / 216 = 1/36；2. **完全不同**：第一个6种，第二个5种，第三个4种 → A(6,3)=120种 / 216 = 20/36；3. **两同一异**（法语）：用 1 - 全同 - 全不同 = 15/36；4. 或直接算：选哪个数相同(6) × 选位置C(3,2) × 选不同数(5) = 90 / 216 = 15/36 |
| 高频错因 | 全不同直接算时忘记除以排列数（或用A而非C）两同一异用"补集"算更快，避免复杂的分类计数 |
| confidence | medium |
| 不适用条件 | 骰子数量不是三颗或存在特定点数约束；题目要求计算条件概率或多次投掷的复合概率 |
| 反向触发 | 全不同用排列A(6,3)而两同一异用组合C(3,2)选位置，两者计数逻辑不同，混用排列组合公式会导致错误，此时应统一用补集法（1减去全同和全不同概率）重新计算验证 |

## 补充说明

三颗骰子的分类是经典模型。英语（全同+全不同）概率 = 1/36 + 120/216 = 21/216 = 7/12。法语（两同一异）概率 = 1 - 7/12 = 5/12。用补集法（1减去英语概率）更快得到法语概率。
