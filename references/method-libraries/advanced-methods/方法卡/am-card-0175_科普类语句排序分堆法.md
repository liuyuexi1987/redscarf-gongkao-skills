# 方法卡：科普类语句排序分堆法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 科普类语句排序分堆法 |
| 适用题型 | 言语理解——语句排序题（科普类文段） |
| 触发场景 | 排序题中文段为科普介绍类（介绍知识点，无强烈逻辑论证），逐句推理耗时且容易卡壳 |
| 步骤逻辑 | ① 判断为科普类文段（介绍知识点，无强烈逻辑论证）；② 不逐句推理相邻关系，而是按话题把句子分成两堆或三堆；③ 找承上启下的句子（前半句属于A堆、后半句属于B堆），确定堆间顺序；④ 在选项中找符合分堆结果的排列 |
| 不适用条件 | 说理类文段（有明确论证逻辑链）不适用此法，仍需用逻辑推理法逐句判断 |
| 高频错因 | 对科普类文段用说理类的逻辑推理方法逐句推，耗时过长；忽略承上启下句的"一分为二"特征 |
| confidence | high |
| 反向触发 | 分堆后各堆内部仍有多种可能顺序时，需退回逐句推理确定堆内排列；若各堆间无明确承上启下句，堆间顺序难以确定，应结合选项代入验证或用逻辑推理法辅助 |
