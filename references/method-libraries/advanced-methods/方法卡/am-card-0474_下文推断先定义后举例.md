# 方法卡：下文推断先定义后举例

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 下文推断先定义后举例 |
| 适用题型 | 下文推断题 |
| 触发场景 | 文段尾部引出了一个新话题（如"丑建筑"），选项中既有对新话题的定义/特征归纳，又有具体举例/网友评论。 |
| 步骤逻辑 | 1. 确定文段落脚的新话题；2. 下文应围绕新话题展开，展开顺序遵循：**先说什么是什么（定义/特征）→ 再举例**；3. 如果选项A是举例、选项C是定义特征 → 应**先C再A**，选C；4. 排除与文段语气不匹配的选项（如官方严肃文件后接"网友评论"）；5. 下文推断题始终选**最先发生**的那一步 |
| 高频错因 | 看到例子选项更具体就选了例子，忽略了应先定义再举例的逻辑顺序混淆文段语气（如政府文件后跟网友评价） |
| confidence | high |

## 不适用条件

1. 所有选项都是举例或都是定义，"先定义后举例"的优先级规则无法区分，需改用语气一致性、范围匹配等其他标准。
2. 文段尾部已完成定义+举例的闭环（如总结性语句），下文应转向应用、对策或总结，而非继续展开定义或举例。
3. 文段为分总结构且尾句已给出结论，下文推断应围绕结论的延伸（如原因分析、实施建议），而非新话题的定义。

## 反向触发

1. 当选项中既有定义又有举例，但定义选项的范围超出了文段新话题的范围时，范围匹配优先于"先定义后举例"的顺序。
2. 文段尾部引出的新话题已有上下文暗示定义（如前文已简要解释），此时下文更可能直接进入举例或应用。
3. 语气一致性与顺序规则冲突时（如严肃学术文段后，定义选项语气偏口语），语气匹配优先。
