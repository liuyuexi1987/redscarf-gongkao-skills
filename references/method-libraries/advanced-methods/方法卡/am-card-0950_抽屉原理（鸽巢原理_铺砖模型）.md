# 方法卡：抽屉原理（鸽巢原理/铺砖模型）

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 抽屉原理（鸽巢原理/铺砖模型） |
| 适用题型 | 物品放入抽屉，求至少有一个抽屉有多少个 |
| 触发场景 | 题目出现"至少有一个不少于""保证至少"等关键词 |
| 步骤逻辑 | 1. 把"抽屉"想象成格子，"物品"想象成砖头；2. N+1个物品放入N个抽屉 → 至少有一个抽屉≥2个；3. M×N+1个物品放入N个抽屉 → 至少有一个抽屉≥M+1个；4. 理解方式：先铺满M层（M×N个），再多1个就必然到第M+1层 |
| 高频错因 | 不理解"至少"和"至多"在这种问题中是同一个意思（临界点） |
| confidence | high |

## 补充说明

铺砖模型是理解抽屉原理最直观的方式，关键是分清什么是"砖头"什么是"格子"

## 不适用条件

- 题目问"至多有多少个"而非"至少有一个"时不适用
- 抽屉数或物品数不固定时不适用

## 反向触发

- 求"最不利情况"的极值题应改用最不利原则
- 涉及排列组合的分配题应改用排列组合方法
