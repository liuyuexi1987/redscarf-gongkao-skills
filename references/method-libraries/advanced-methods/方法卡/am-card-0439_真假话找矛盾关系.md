# 方法卡：真假话-找矛盾关系

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 真假话-找矛盾关系 |
| 适用题型 | 判断推理-逻辑判断-真假话类（"只有一真/只有一假"） |
| 触发场景 | 题目说"只有一人为真""只有一人为假"等，需要判断谁真谁假 |
| 步骤逻辑 | 1. 在所有表述中找出一组矛盾关系（矛盾必一真一假） 2. 根据"只有一个真"或"只有一个假"的条件，确定真话/假话一定在矛盾对中 3. 从而得到其余表述为确定的假/真 4. 由确定信息往下推 |
| 高频错因 | 把反对关系误认为矛盾关系（如丙和丁都可为假）；未掌握三组标准矛盾关系 |
| confidence | high |

## 补充说明

矛盾关系的定义是"必然一真一假"。如果两个表述可以都为假（如丙和丁在某些情况下都假），那就不是矛盾，只是反对。标准矛盾关系包括：所有A是B vs 有些A不是B；所有A不是B vs 有些A是B；A推B vs A且非B。

## 不适用条件

- 题目条件为"不确定真假数量"（如"至少一人说真话"），无法用"唯一真/假"锁定矛盾对
- 所有表述之间找不到标准矛盾关系，且表述涉及模态逻辑或条件复合命题，无法直接套用三组标准矛盾

## 反向触发

- 当找到的"矛盾"对中两个表述可以同时为假时，说明这是反对关系而非矛盾关系，应放弃该对，重新检查其余表述之间的关系
- 当矛盾对锁定后，剩余表述的真假无法唯一确定（出现多种可能），说明可能漏看了题干中的额外约束条件，应重新审视题干限定词
