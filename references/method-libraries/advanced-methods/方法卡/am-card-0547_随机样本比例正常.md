# 方法卡：随机样本下任何比例都正常

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 随机样本下任何比例都正常 |
| 适用题型 | 削弱/质疑题中的样本有效性判断（逻辑判断） |
| 触发场景 | 选项提到"样本中X%对某事不感兴趣/不了解"，用来质疑样本有效性 |
| 步骤逻辑 | 1. 检查样本是否为随机选取；2. 若样本是随机选取的 → 无论比例是多少（50%、80%……），都属于正常情况；3. 比例高只能说明总体确实如此，不能说明样本有问题；4. 反过来，若样本是刻意选取的（如专门选军事学院学生），那才有问题 |
| 高频错因 | 看到"50%不感兴趣"就觉得样本有问题，忽略了"随机选取"这个关键前提把"总体特征"误当成"样本缺陷" |
| confidence | high |
| 不适用条件 | - 样本选取方式不明确或无法判断是否为随机抽取
- 题目质疑的不是样本代表性而是调查方式（如问卷设计、提问措辞）
- 题干结论涉及因果推断而非简单的总体特征描述 |
| 反向触发 | - 选项明确说明样本是刻意选取的（如只选某一群体），此时样本偏差成立，应选定该选项作为削弱
- 题目问"以下哪项最能支持调查结论"，需要选"样本为随机抽取且比例与已知总体一致"的选项 |

## 补充说明

第13题D选项。关键判断点不是比例高低，而是选取方式。随机选取→代表总体→比例正常；刻意选取（如只选军事迷）→样本偏差→有问题。
