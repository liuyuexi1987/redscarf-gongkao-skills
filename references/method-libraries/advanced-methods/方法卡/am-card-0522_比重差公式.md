# 方法卡：比重差公式

## 基本信息
| 字段 | 值 |
|------|-----|
| 方法名 | 比重差公式 |
| 适用题型 | 资料分析-某部分占总体比重比上年高/低多少个百分点 |
| 触发场景 | 题目出现"比重比上年同期高/低多少百分点" |
| 步骤逻辑 | 1. 识别题型为比重差<br>2. 找到R1（部分增速）和R2（总体增速）<br>3. 计算R1 - R2的正负判断升降方向，排除反向选项<br>4. 计算A/B（现期部分/总体）的比值<br>5. 套公式：比重差 = (R1 - R2) / (1 + R1) × (A/B) |
| 高频错因 | R1和R2找反；A/B找错（部分和总体混淆）；忽略1+R1导致精度不够 |
| confidence | high |

## 补充说明
- R1-R2为正则比重上升，为负则下降，可先用来排除选项方向。
- 当A/B接近50%且R1-R2较小时，结果可能卡在选项边界，需要精算。
- 精算时保留三位有效数字，公式右边(R1-R2)/(1+R1)接近1时用拆分法处理。
- 另一种变体公式（带基期比重的）也可以用，但本公式的优势在于不需要额外算基期。

## 不适用条件
1. 当部分增速R1和总体增速R2都接近零且选项间距较大时，比重几乎不变，直接用现期比重近似即可。
2. 当题目要求的是基期比重而非比重差时，用基期比重公式更直接。
3. 当部分和总体的口径不一致（如一个是全年一个是上半年）时，不能直接套公式。

## 反向触发
1. 当R1-R2为正且绝对值较大时，比重变化方向明确，可先用方向排除选项，减少计算量。
2. 当现期比重与增速差的乘积已经足以区分选项时可粗算；否则应保留分母修正并精算。
3. 当公式中R1接近-100%（即部分几乎消失），分母趋近零，公式不稳，应换用绝对量直接比较。
