# 方法卡：逻辑推理分情况讨论法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 逻辑推理分情况讨论法 |
| 适用题型 | 判断推理——逻辑推理（排列组合/真假话） |
| 触发场景 | 逻辑推理题中有多个不确定条件，需要分情况讨论 |
| 步骤逻辑 | ① 找到确定条件（"A是B""A不是B"等确定信息）；② 从确定条件出发，逐步排除不确定情况；③ 条件要梳理反向推导（如"如果A则B"→"非B则非A"）；④ 分情况讨论时利用确定条件逐步排除 |
| 高频错因 | ① 不先找确定条件→在不确定条件中打转；② 不做反向推导→漏掉隐含信息 |
| confidence | high |

## 补充说明
逻辑推理的核心策略：先确定后不确定。确定条件是解题的锚点，从锚点出发逐步排除。反向推导（逆否命题）往往能发现隐含信息。

## 不适用条件
- 题目条件全部确定、无需分情况时，本卡不适用
- 题目考查的是日常推理（如因果推断）而非形式逻辑时，应换用对应方法
- 分支过多、继续枚举会产生大量重复情况时，应先寻找确定条件、矛盾关系或选项代入来压缩分支

## 反向触发
- 若题目无"如果…则""或者""至少"等需要分情况的逻辑词，不使用本卡
- 若题目可通过单一确定条件直接得出答案，无需分情况讨论
