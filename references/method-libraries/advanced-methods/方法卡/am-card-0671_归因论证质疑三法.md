# 方法卡：归因论证质疑三法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 归因论证质疑三法 |
| 适用题型 | 归因论证类质疑题（对比实验归因/时间对比归因/一般归因） |
| 触发场景 | - 题干有既成事实，分析其原因（"归于一因"）
- 涉及实验分组、时间前后对比、一般因果关系 |
| 步骤逻辑 | 1. 识别归因类型：对比实验归因/时间对比归因/一般归因；2. 质疑三法：- **另有他因**：回归实验，指出对照组和实验组有另一个不同点（维他因不回归实验）- **因果倒置**：颠倒因果方向- **否定此因**：直接否定所归因的原因本身；3. 支持归因：解释说明 或 排除他因 |
| 高频错因 | 混淆"另有他因"和"维他因"——另有他因必须回归实验，维他因不看实验分组把"否定此因"理解为"另有他因"——否定此因不提替代原因 |
| confidence | medium |

## 补充说明

核心区分：另有他因必须指出实验分组中还存在另一个差异因素（回归实验），维他因则直接抛出一个无关实验分组的替代原因。归因论证的支持方式除了排除他因，还可以通过解释说明来加强因果链条。

## 不适用条件

- 题干不涉及因果关系归因（如纯定义判断、形式逻辑翻译题）时，本方法不适用。
- 题干为单一事实陈述、无对比结构且无因果归因时，应改用其他质疑法。

## 反向触发

- 当题干归因涉及多个可能原因交织时，应补充核验各原因的可分离性，避免简单套用三法之一。
- 当选项既非另有他因也非因果倒置而是直接否定此因时，应确认其是否真的不提替代原因，再决定归入本法。
