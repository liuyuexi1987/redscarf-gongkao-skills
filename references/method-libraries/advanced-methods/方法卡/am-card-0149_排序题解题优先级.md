# 方法卡：排序题解题优先级

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 排序题解题优先级 |
| 适用题型 | 判断推理-排序题（多人排名/排列顺序判断） |
| 触发场景 | 给出若干人的排名条件和相对位置关系，要求判断正确/错误的排序结论 |
| 步骤逻辑 | 1. **第一优先：确定信息**——直接能填入具体位置的条件（如"甲排名第四""第六是外国选手"）；2. **第二优先：跨度最大**——"谁和谁之间隔了几个人"，优先处理间隔最多的（能锁定最多位置）；3. **第三优先：跨度次大 或 捆绑关系**——根据具体情况判断，如果剩下空位只能放捆绑就先放捆绑，如果跨度次大只有唯一位置就先放跨度次大；4. 逐步填入，每步填完后检查剩余位置是否受限；5. 考场建议：乍一看如果判断排序题很复杂，果断跳过去做数量题（性价比更高） |
| 高频错因 | 不按优先级处理，随意从第一条开始推导致绕圈忽略"跨度最大"能快速锁定位置的优势 |
| confidence | high |

## 不适用条件

1. 不是排序/排列题，而是分组题或匹配题
2. 条件全部为相对关系（"甲在乙前面"），无任何确定信息或可量化的跨度条件
3. 题干要求计算排列组合总数而非确定具体排列

## 反向触发

1. 题干给出若干人/物的排名条件和相对位置关系
2. 选项需要判断某个具体排列是否正确
3. 条件中混合了确定位置、跨度间隔和捆绑关系
