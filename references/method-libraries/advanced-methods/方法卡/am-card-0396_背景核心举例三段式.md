# 方法卡：背景核心举例三段式

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 背景核心举例三段式 |
| 适用题型 | 中心理解题（主旨大意） |
| 触发场景 | 文段呈三段结构：第一句是普遍规律/背景→中间一句是核心→后文围绕核心分领域举例 |
| 步骤逻辑 | 1. 第一句是背景引入（普遍规律），不是主旨；2. 话题一转后的那一句是核心论点；3. 后文是围绕核心的分领域展开（如工业、农业、第三产业）；4. 主旨选核心句，不选背景句 |
| 高频错因 | 把背景句当主旨，选了只覆盖前半部分的选项把某个分领域举例当主旨 |
| confidence | high |

## 不适用条件

- 文段没有明确的"背景句→核心句→举例"三段式结构
- 背景句和核心句之间没有话题转换信号（如"其实""关键在于""但"等），难以区分谁是背景谁是核心
- 后文举例不是"分领域"展开，而是对核心的层层递进或因果分析

## 反向触发

- 若第一句和第二句之间缺乏明显转折或递进信号，可能整段是并列结构而非"背景+核心"结构，应先判断各句的逻辑关系再定主旨
- 若后文的"举例"篇幅远大于核心句且有独立论点，可能各部分是并列分论点而非围绕核心的展开，应换用并列归纳思路
- 若文段存在多个疑似核心句（不止一句有论断性质），应回看哪一句被后文最广泛地展开和支撑，选被支撑最多的那句
