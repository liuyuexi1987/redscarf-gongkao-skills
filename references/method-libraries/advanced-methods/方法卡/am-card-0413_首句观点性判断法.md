# 方法卡：首句观点性判断法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 首句观点性判断法 |
| 适用题型 | 中心理解（意在强调/最想表达/概括最准确） |
| 触发场景 | 文段首句为总起句，需判断首句是客观事实还是作者观点，以决定后面的论证部分能否省略 |
| 步骤逻辑 | ① 看首句是否有观点性（作者主观判断、对策呼吁、评价好坏）；② 若首句有观点性（如"不应该""大家都快去"），后面的解释说明/原因分析仅为论证，可省略，主旨=首句；③ 若首句无观点性（如"某商品销量很高""没有成为主流"），后面的原因解释与结果是并重的，主旨需概括前后所有内容 |
| 高频错因 | 首句无观点性时仍只抓首句，漏掉后面的原因解释，导致主旨片面 |
| confidence | high |
| 不适用条件 | 文段首句既非观点也非单纯客观事实（如设问句、过渡句）时，不能简单按观点/事实二分处理；文段结构为"先总后分再总结"的三段式时，首句和尾句均需关注，不能仅凭首句性质决定主旨 |
| 反向触发 | 首句为客观事实时，需结合后文的观点性表述概括主旨，不能只抓首句；首句为观点时，后文仅为论证支撑，主旨即首句本身，无需过度概括后文内容 |

## 补充说明

核心区分举例：「某商品今年销量很高」= 客观事实，无观点性，果因并重需概全；「大家都快去买这个商品」= 有观点性（对策/呼吁），后面的"一方面…另一方面…"仅为论证，可省。考场上用10秒判断首句性质，决定后面读多细。
