# 方法卡：两百分数相乘估算法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 两百分数相乘估算法 |
| 适用题型 | 增长率 / 间隔增长率乘积项计算 |
| 触发场景 | 需要计算两个百分数的乘积（如间隔增长率中的R1×R2项） |
| 步骤逻辑 | 1. 将其中一个百分数近似为简单分数；2. 保留另一个百分数单位并完成乘法；3. 检查近似方向和误差；4. 只有乘积项小到不足以影响选项判断时才可省略 |
| 高频错因 | 两个都换分数，导致结果变成分数形式（如1/30），反而不好换回百分数不知道两个10%相乘=1%这个参照点，无法快速估算 |
| confidence | medium |

## 补充说明

核心原则是只把其中一个百分数近似为便于计算的分数，另一个保留百分数形式。乘积项能否省略取决于它相对选项差距和最终表达式的影响，不能只因两个百分数看起来较小就忽略。

## 不适用条件

1. 两个百分数都无法近似为常用分数（如13.7%×27.3%），换分数后估算误差偏大。
2. 选项精度要求高，乘积项的微小差异会影响最终答案选择。
3. 乘积项本身已能轻松精算，或省略与否都不影响选项判断时，无需额外近似。

## 反向触发

1. 题目涉及间隔增长率或类似公式中的乘积项R1×R2需要估算。
2. 其中一个百分数接近常用分数值（如16.6%≈1/6、12.5%≈1/8）。
3. 选项间距较大，百分数乘积的估算精度足以区分答案。
