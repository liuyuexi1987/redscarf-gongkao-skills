# 方法卡：合并同类项速抓主旨

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 合并同类项速抓主旨 |
| 适用题型 | 言语理解——片段阅读主旨题（文段结构不清晰或车轱辘话较多时） |
| 触发场景 | 文段多句话反复出现相同关键词/内容，结构分析困难，逐句精读效率低 |
| 步骤逻辑 | ① 不纠结每句话的逻辑关系；② 找各句中重复出现的相同词语或相同内容；③ 合并这些高频信息，归纳出主旨；④ 选项应同时包含这些高频关键词 |
| 不适用条件 | 有清晰转折/因果/并列结构的文段（应优先用结构分析法，本法作为结构不清晰时的降级方案） |
| 高频错因 | 文段绕来绕去时被绕晕，忘记抓重复出现的核心词；被文段中某一句的次要信息带偏 |
| confidence | high |
| 反向触发 | 当重复高频词在各句中含义不同或被用来论证不同观点时，高频词不等于主旨，需退回结构分析；合并后归纳出的主旨若与文段末尾总结句矛盾，应以结构分析结论为准 |


> **使用边界**：本方法用于提供优先检查方向，不可单独据此作答；最终需回到题干关系、原文证据或选项条件完成验证。
