# 方法卡：有问题要体现问题

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 有问题要体现问题 |
| 适用题型 | 片段阅读-中心理解题 |
| 触发场景 | 文段提出问题但没有给出对策，选项中同时有问题概括和对策表述 |
| 步骤逻辑 | 1. 原文只有问题没有对策时，可概括问题也可选有针对性的对策；2. 但选项必须体现这个问题——问题是有作者感情倾向的，选项不能回避；3. 如果两个选项一个概括问题一个给对策，通常其中一个本身有错；4. 用反推验证：选项能否让读者感受到原文的问题严重性 |
| 高频错因 | 选了只提价值/优点的选项，忽略了作者批评问题的感情倾向 |
| confidence | medium |

## 不适用条件

1. 原文既提出了问题又给出了对策，此时应选对策而非只概括问题
2. 题目明确问的是对策或解决方案，不需要停留在问题层面
3. 原文只是客观介绍，没有作者的感情倾向或批评立场

## 反向触发

1. 选项中问题概括和对策表述都正确时，需要看题目问法——问主旨倾向选概括了问题的选项，问对策倾向选针对问题的对策选项
