# 方法卡：无关他因辨析

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 无关他因辨析 |
| 适用题型 | 判断推理——加强削弱·因果论证 |
| 触发场景 | 选项表面像他因，但实际是无关项 |
| 步骤逻辑 | ① 看选项中的"他因C"是否与A同时出现在同一组；② 若C没有与A一起发生（两组都可能有C），则C不是变量→无关项；③ 若C只在A组出现（实验组多了一个变量），则是真正的他因 |
| 高频错因 | ① 看到"也是XX的原因"就选，忽略了是否构成对照组变量 |
| confidence | high |
| 不适用条件 | 选项本身没有提出任何替代因素C，而是直接否定A→B的因果链或举反例，此时不是"他因"而是"拆桥"或"否定论据"；题干是比较实验，选项中的C与实验设计无关 |
| 反向触发 | 选项中提到的C是A的结果而非A的替代原因，属于因果链延续而非他因；题目问的是加强而非削弱，此时"他因"逻辑不适用 |

## 补充说明

口诀："他因要跟A在一起"。"非根本原因"（解释A为什么发生）也是无关项，因为讨论的核心是A→B，而非A本身的原因。
