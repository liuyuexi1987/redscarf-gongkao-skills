# 方法卡：年均增量计算与前推判定

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 年均增量计算与前推判定 |
| 适用题型 | 资料分析-年均增量 |
| 触发场景 | 题目问“年均增加多少”“平均每年增加多少”或“年均增量” |
| 必要输入 | 题目指定的起始年份及数值、结束年份及数值 |
| 步骤逻辑 | 1.从问法中锁定实际起始年份和结束年份；2.计算总增量=末年值-首年值；3.计算增长间隔 N=末年-首年；4.年均增量=总增量/N；5.用 首年值+年均增量×N=末年值 回代验证 |
| 高频错因 | 1.把年份个数当作增长间隔数；2.仅因材料给出前一年数据就自动前推；3.把年均增量与年均增长率公式混用；4.起止年份与起止数值没有一一对应 |
| confidence | high |

## 补充说明

例如2018年为100、2022年为140，2018年至2022年的增长间隔为4：

`年均增量 = (140-100) / (2022-2018) = 10`

回代：`100 + 10×4 = 140`。

年均增量通常直接使用题目指定的起止年份，不因材料额外给出2017年数据而前推。只有题目明确把统计区间定义为2017年至2022年，才改用2017年作为起点。

## 不适用条件

1. 题目问的是年均增长率，此时应使用复合增长公式，不使用简单做差。
2. 题目给的是累计值、移动平均值或口径变化后的数值，不能直接作为起止水平相减。
3. 题目要求各年度增量的算术平均且年度并不连续时，应按实际增量项数处理。

## 反向触发

1. 出现前一年数据不等于必须前推，先以题目明确指定的统计区间为准。
2. 若问法出现“增长率”“增速”，应切换到年均增速方法，不使用本卡。
3. 回代不能还原末年值时，检查年份差、起止值和单位口径，不要用调整期数来凑选项。
