# 方法卡：常识判断错因诊断卡

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 常识判断错因诊断卡 |
| 适用题型 | 常识判断——所有子领域通用错因诊断 |
| 触发场景 | 用户做错常识判断题后，讲解/复盘结束，需要判断错因并写入错因卡或弱点档案时 |
| 步骤逻辑 | ① 确认题目所属领域；② 判断错因类型（知识缺失/主体混淆/时间错配/概念混淆/绝对化误选/生活经验误判/时政过期）；③ 归因到具体层；④ 写入弱点档案 |
| 高频错因 | 知识点缺失、主体权限混淆、时间顺序错、概念张冠李戴、绝对化误选、生活经验误判、时政过期 |
| confidence | high |
| 不适用条件 | 1. 非常识判断类题目的错因诊断（言语理解、资料分析、数量关系错因各有专用诊断逻辑）
| 反向触发 | 1. 用户已给出思路但需要具体知识讲解时应读对应领域卡而非错因诊断卡
2. 判断推理类错因（图推规律、定义判断等）不适用常识错因诊断
3. 资料分析计算错误或言语理解成语混淆应读各自模块的错因逻辑 |
2. 题目尚在作答中、未到复盘阶段时不触发错因诊断
3. 官方答案未核验且存在冲突时，不得硬判错因 |

## 诊断流程

### 第一步：确认题目领域

- 法律类？政治类？经济类？科技类？历史人文类？地理类？公文管理类？时政类？
- 领域决定了后续归因方向和关联的方法卡

### 第二步：判断错因类型

按以下7种类型逐一排查：

1. **知识点缺失**：完全不知道这个事实→根本没学过或忘了
2. **主体权限混淆**：知道知识点但把A的权力/职能说成B的
3. **时间顺序错**：知道知识点但时间先后搞反了
4. **概念张冠李戴**：知道两个概念但搞混了对应关系
5. **绝对化误选**：选项含绝对化表述但没注意到，或机械排除了正确的绝对化表述
6. **生活经验误判**：用生活经验替代了专业科学判断
7. **时政过期**：用过期的时政信息作答

### 第三步：归因到具体层

- 领域→子领域→具体考点→具体错因
- 例如：常识-法律-行政法-行政强制措施vs强制执行混淆

### 第四步：写入弱点档案

- 错因卡：记录题面、用户答案、正确答案、错因、下次复习点
- 弱点档案：次数+1、追加本次错法、更新难度档

## 错因分类表

| 错因类型 | 判定信号 | 典型表现 | 写入弱点档案的建议标签 |
|----------|----------|----------|------------------------|
| 知识点缺失 | 用户说"不知道""没学过" | 完全无法作答或随机选 | 常识-{领域}-知识点缺失 |
| 主体权限混淆 | 用户知道相关知识但选错主体 | 把国务院职权说成全国人大职权 | 常识-{领域}-主体权限混淆 |
| 时间顺序错 | 用户知道事件但先后搞反 | 把唐朝制度放到宋朝 | 常识-{领域}-时间顺序错配 |
| 概念张冠李戴 | 用户知道两个概念但搞混 | 把光合作用和呼吸作用搞反 | 常识-{领域}-概念混淆 |
| 绝对化误选 | 选项含绝对化词汇，用户未注意 | 选了"所有""一定"等错误选项 | 常识-{领域}-绝对化误选 |
| 生活经验误判 | 用户用生活常识替代专业知识 | 以为铁在任何情况下都不能燃烧 | 常识-{领域}-生活经验误判 |
| 时政过期 | 用户用旧版政策/数据作答 | 用旧版主要矛盾表述 | 常识-{领域}-时政过期 |

## 写回建议

- `常识-法律-主体权限混淆`：知道相关法律知识但把A主体的权力/职能归给了B主体
- `常识-政治-概念混淆`：知道两个理论概念但搞混了对应关系（如主要矛盾vs矛盾主要方面）
- `常识-经济-财政货币政策混淆`：知道两种政策但搞混了实施主体或工具
- `常识-科技-生活经验误判`：用日常生活经验替代了科学事实判断
- `常识-历史人文-时间顺序错配`：知道历史事件但先后顺序搞反
- `常识-地理-区域特征混淆`：知道地理特征但把A区域的特征归给了B区域
- `常识-时政-信息版本待核验`：用可能过期的时政信息作答，需核验最新信息
- `常识-总纲-绝对化误选`：选项含绝对化表述但未注意，或机械排除了正确的绝对化表述

## 使用边界

1. 本卡只用于常识判断的错因诊断，不替代具体领域的方法卡。
2. 无官方/已核验答案的常识题，不得硬判错因，只能写方法倾向或待核对。
3. 涉及时政/法律修订的题目，错因中需标注"需核验最新信息"。
4. 用户给出思路时优先对照用户思路归因；没给思路时只能做低置信诊断。
5. 客观题官方答案冲突时先走冲突复核流程，不立即写错因卡。
6. 常识题错因诊断应结合具体领域方法卡（如法律常识对应am-card-1149，经济常识对应am-card-1151）。
