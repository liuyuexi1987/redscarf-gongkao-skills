# 方法卡：等差数列求和化完全平方

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 等差数列求和化完全平方 |
| 适用题型 | 数量关系——等差数列求和、方程不等式 |
| 触发场景 | 多组连续自然数求和可提取共同因式并化为完全平方，需要由总量上限反推项数 |
| 步骤逻辑 | 1. 两个等差数列各为 1,2,...,X，加上一项 X+1；2. 合并两个1到X：用求和公式 ×2 = X(X+1)；3. 再加 X+1 → X(X+1) + (X+1) = (X+1)(X+1) = (X+1)²；4. (X+1)² ≤ 200 → X+1 ≤ 14 → X ≤ 13；5. 广告页 = 1到14求和 = 15×7 = 105 |
| 高频错因 | 分别算两个等差数列再加总，计算繁琐易错不会提公因式化简为完全平方 |
| confidence | medium |
| 不适用条件 | 仅涉及单个等差数列常规求和的题目；数列结构不符合"两组1到X加X+1"形式的求和问题 |
| 反向触发 | 当数列结构不满足提公因式化为完全平方的条件时，改用等差数列求和公式直接计算；分别算两个数列再相加的做法计算繁琐且易出错，应优先尝试提公因式简化 |

## 补充说明

核心技巧：两个相同的1到X等差数列求和后加上(X+1)，恰好能提公因式化为(X+1)²。这个化简步骤是关键——直接得到平方数后，找不超过200的最大平方数（14²=196），即可确定X=13。
