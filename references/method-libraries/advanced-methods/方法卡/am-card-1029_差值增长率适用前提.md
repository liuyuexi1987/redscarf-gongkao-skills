# 方法卡：差值增长率适用前提

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 差值增长率适用前提 |
| 适用题型 | 资料分析——差值增长率/混合增长率 |
| 触发场景 | 使用线段法/差值增长率时 |
| 步骤逻辑 | ① 先确认求的是差值增长率还是混合增长率；② 线段法本质是加权混合，应以基期量为权重；③ 用现期量代替基期量时，先估计近似误差能否被选项间距吸收；④ 误差可能跨选项时，改用基期量精算并回代验证 |
| 高频错因 | ① 不检查适用前提→差距太大时用线段法→误差巨大；② 混淆差值增长率和混合增长率的适用范围 |
| confidence | high |

## 补充说明
线段法的关键不是背固定百分点阈值，而是看用现期量代替基期量后的误差是否会改变选项判断。能稳定排除时用近似；临界或选项紧密时算基期量并验证。

## 不适用条件

1. 增长率差距超出近似适用范围时。
2. 一增一减且近似误差可能跨越选项的场景。
3. 对结果精度要求高、不能接受近似误差时。

## 反向触发

1. 当增长率差距处于临界区间时，应补充精算核验。
2. 当出现一增一减时，先检查方向和误差；可能跨选项再换用基期量计算。
3. 当选项差距小于估算误差时，应改用精算。
