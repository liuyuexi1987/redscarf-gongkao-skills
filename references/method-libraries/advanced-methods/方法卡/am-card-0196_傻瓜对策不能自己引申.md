# 方法卡：傻瓜对策不能自己引申

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 傻瓜对策不能自己引申 |
| 适用题型 | 下文推断/中心理解 |
| 触发场景 | 需要推断或选择对策时 |
| 步骤逻辑 | 1. 问题是什么→对策只能反推对应（如"缺资源"→"提供资源"）；2. 不能自己脑补更具体做法（如"国家政策和执行"从未出现→无中生有）；3. 不能更换主体（问题出在企业→不能选行业/政府的对策）；4. 只能提"傻瓜对策"，一条引申都不能有 |
| 高频错因 | 自己脑补具体对策，超出文段能支撑的范围 |
| confidence | high |

## 不适用条件

1. 题干允许推断合理对策而非仅限文段直接支持的对策
2. 选项中所有对策均带有引申成分，需要比较引申程度而非排除
3. 非下文推断或中心理解题型

## 反向触发

- 需要推断或选择对策，且文段已有明确问题描述
