# 方法卡：所有有些两词互换否定法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 所有有些两词互换否定法 |
| 适用题型 | 逻辑——推出类/真假分析（题干含"所有/有些"的命题，需要取矛盾或取否定） |
| 触发场景 | 需要判断"所有A是B"为假时实际情况是什么，或需要找与"有些A是B"矛盾的命题 |
| 步骤逻辑 | ① “所有A是B”的矛盾是“有些A不是B”；② “有些A是B”的矛盾是“所有A不是B”；③ “所有A不是B”的矛盾是“有些A是B”；④ “有些A不是B”的矛盾是“所有A是B”；⑤ “有些A是B”可换位为“有些B是A” |
| 验证动作 | 用集合图检查两句话能否同时为真、能否同时为假；真正的矛盾关系必须一真一假 |
| 不适用条件 | 只有在题目确认 A 类非空或采用传统直言命题存在预设时，才可由“所有A是B”推出“有些A是B”；不要把这一存在预设当作纯形式逻辑恒真规则 |
| 高频错因 | 只加“不”而不改量词；把“有些”理解成“只有一部分”；把“有些是”误推成“有些不是” |
| confidence | medium |
| 反向触发 | - 题干不涉及"所有/有些/某个/全部"等量词命题，仅含逻辑关联词（如果那么/只有才）的翻译推理题，应触发am-card-0685或am-card-0692。- 题干问的是真假话排序或一一对应匹配（如甲说A乙说B丙说C谁说真话），不是全称特称取矛盾，应触发真假话排列法。 |
