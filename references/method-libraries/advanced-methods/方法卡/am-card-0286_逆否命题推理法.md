# 方法卡：逆否命题推理法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 逆否命题推理法 |
| 适用题型 | 翻译推理题、条件推理题 |
| 触发场景 | 题干出现"如果...那么..."条件句，需要从结果反推条件时 |
| 步骤逻辑 | 1. 将原命题翻译为 A → B 的箭头形式；2. 写出逆否命题：非B → 非A（方向反转、两边都加非）；3. 肯定后件（B成立）时无法正向推出任何结论；4. 否定后件（非B成立）时可通过逆否推出非A；5. 否定前件（非A成立）时也无法推出结论 |
| 高频错因 | 误以为"后件成立可推出前件"（肯后推肯前是错误的）；混淆"否后推否前"与"肯后推肯前" |
| 不适用条件 | 题干无条件句/非翻译推理题型，或考查的是直言命题推理而非假言命题推理时 |
| 反向触发 | 题干中不出现"如果...那么...""只要...就..."等条件关联词时 |
| confidence | high |
