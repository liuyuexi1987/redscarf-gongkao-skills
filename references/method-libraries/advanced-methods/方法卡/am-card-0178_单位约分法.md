# 方法卡：单位约分法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 单位约分法 |
| 适用题型 | 资料分析 — 涉及不同单位的数值计算 |
| 触发场景 | 分子分母单位不同（如万亿÷万、亿元÷万元），需要统一单位才能计算 |
| 步骤逻辑 | 1. 将单位视为可约分的"数"，例如万亿/万 = 亿、万亿/亿元 = 万；2. 利用E的指数差直接约掉，如万E(12)÷万E(8) = E(4) = 亿；3. 约分后只保留数值和剩余单位，避免手动换算；4. 检查约分结果的量级是否与选项匹配 |
| 高频错因 | 手动把万亿换算成亿元再除，容易多算或少算零忘记检查约分后的单位是否与题目要求一致 |
| confidence | high |

## 不适用条件

- 题目中单位一致（如亿元÷亿元），无需约分，直接计算即可。
- 单位之间不是简单的10的幂次关系（如涉及时间单位"月"和"年"混合），单位约分法不直接适用。
- 题目要求保留特定单位（如答案必须用"万元"表示），约分后还需额外转换步骤。

## 反向触发

- 看到分子分母单位不同（万亿÷万、亿元÷万元）的数值计算时，提示用单位约分法。
- 选项之间量级差距明显（如差10倍、100倍），提示可能在单位换算上出错。
