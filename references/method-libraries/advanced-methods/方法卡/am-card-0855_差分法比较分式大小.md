# 方法卡：差分法比较分式大小

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 差分法比较分式大小 |
| 适用题型 | 资料分析——分式比较·两个分式大小接近，无法直接判断时 |
| 触发场景 | 需要比较A/B和C/D的大小，但直接看不出来谁大谁小 |
| 步骤逻辑 | ① 将两个分式看作"基期比"和"现期比"；② 看分子增速和分母增速谁大：分子增速>分母增速→现期比>基期比（比值上升）；③ 分子增速<分母增速→现期比<基期比（比值下降）；④ 实际操作：算出差值分式(C-A)/(D-B)，看它更靠近哪个原分式，靠近哪个就比哪个大 |
| 高频错因 | ① 差值分式算错符号导致方向判断反；② 两个分式差距其实很明显却仍用差分法（杀鸡用牛刀）；③ 把差分法的结论当成精确值——它只判断大小，不算具体值 |
| confidence | medium |

## 不适用条件

- 两个分式差距明显，可直接判断大小
- 分式不满足"基期比→现期比"的递推结构
- 差值分式(C-A)/(D-B)的符号无法快速确定

## 反向触发

- 一眼能看出大小（如分子最大且分母最小）
- 分子或分母为负数，差值分式方向不确定

## 补充说明

差分法的核心思想：如果分子和分母都增加了，看谁增加的比例更大。分子增加的比例>分母增加的比例→分数变大。差分法适用于两个分式"看起来差不多"的情况。如果一眼能看出大小（如分子最大且分母最小），直接判断即可，不必用差分法。此方法在纯数学推导上是严格的，但实战中需要一定的数感训练。
