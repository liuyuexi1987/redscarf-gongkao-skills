# 方法卡：混合增速不变

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 混合增速不变 |
| 适用题型 | 现期 / 分段增速相同求全年 |
| 触发场景 | 题目说某几个分段（如前三季度和第四季度）增速相同，要求全年量或全年增速 |
| 步骤逻辑 | 1. 两盆温度相同的水混在一起温度不变——两部分增速相同则整体增速不变；2. 直接得出全年增速 = 分段增速（无需分段计算再相加）；3. 用全年增速 × 上年全年量 = 今年全年量，一步求出 |
| 高频错因 | 按常规思路先算分段基期、再算分段现期、最后相加，计算繁琐易错不理解"混合增速不变"的物理直觉，犹豫不敢跳步 |
| confidence | medium |

## 不适用条件

1. 各分段增速不同（如前三季度增速10%、第四季度增速20%），整体增速不再等于任一分段增速。
2. 材料只给整体增速，要求反推分段增速——方向相反，本方法无法直接使用。
3. 分段的时间跨度不同（如上半年为6个月、下半年为6个月但第四季度为3个月），加权结构不均衡时整体增速受权重大段影响更大。

## 反向触发

1. 各分段增速相同却分段计算基期和现期再相加，说明未意识到整体增速等于分段增速。
2. 混合后增速与分段增速不等，说明分段增速实际上不同，需要先分别计算。
