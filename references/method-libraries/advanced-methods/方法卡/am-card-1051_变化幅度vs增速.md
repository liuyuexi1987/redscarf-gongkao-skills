# 方法卡：变化幅度vs增速

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 变化幅度vs增速 |
| 适用题型 | 资料分析——审题陷阱 |
| 触发场景 | 题目问"变化幅度最小/最大" |
| 步骤逻辑 | ① 幅度=绝对值（不考虑正负）；② 增速=带正负号的值；③ "变化幅度最小"→比较绝对值→如-8%的幅度>6%的幅度；④ "增速最小"→考虑正负→-8%<6% |
| 高频错因 | ① 把"变化幅度"当"增速"比较→选错；② -8%幅度>6%幅度（绝对值更大） |
| confidence | high |

## 不适用条件
- 题目明确问"增速"而非"变化幅度"时，直接比较带正负号的值
- 所有数据均为正增长、不存在正负差异时，幅度与增速排序一致
- 题型为非资料分析的其他模块时

## 反向触发
- 看到"变化幅度最大/最小"时，立即提醒自己取绝对值比较
- 数据中同时存在正增长和负增长时，幅度排序可能与增速排序不同，需特别警惕
