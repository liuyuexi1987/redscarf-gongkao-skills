# 方法卡：读题串数据法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 读题串数据法 |
| 适用题型 | 数量关系——方程类题目 |
| 触发场景 | 所有数量关系方程题 |
| 步骤逻辑 | ① 一边读题一边在脑海/草稿中串联数据；② 每读到一个信息就思考它能和前面的信息组成什么公式关系；③ 标注能组成新信息的组合（如进价×数量=总成本）；④ 最后看问题问的是什么，对应到已建立的数据关系中 |
| 高频错因 | ① 先读完题再想→信息丢失；② 只关注最终问题而忽略了中间可推导的信息 |
| confidence | high |

## 补充说明

核心思想：出题人的设计逻辑就是"从公式中抠掉一个量，给其余量让你算"。所以边读边串联数据就能提前发现考察点。

## 不适用条件

- 题目为纯几何/计数类（不依赖公式串联）时，本方法不适用。
- 题干信息极少、无中间关系可推导时，本方法不适用。
- 题目为代入排除型（无需建立完整数据关系）时，本方法不适用。

## 反向触发

- 当题干含明显比例/百分比变化需精算时，应补用比例精算方法。
- 当题干为排列组合/概率问题时，应换用对应专项方法。
- 当数据关系复杂、串联易出错时，应改用列表/方程组结构化建模。
