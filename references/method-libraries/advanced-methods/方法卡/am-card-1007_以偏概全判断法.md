# 方法卡：以偏概全判断法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 以偏概全判断法 |
| 适用题型 | 言语理解——中心理解（选项分析） |
| 触发场景 | 选项只涵盖了文段的部分内容，需要判断是否以偏概全 |
| 步骤逻辑 | ① 选项内容在文段中出现过→检查它与其他内容的关系；② 如果是并列关系→以偏概全（不能只选其中一个并列项）；③ 如果是总分关系→不是以偏概全（选项是总括，文段是展开）；④ 例："讲好黄河故事"与"打造地标""激励行动"并列→只选"讲好故事"=以偏概全 |
| 高频错因 | ① 看到选项有原文对应就选→不检查是否以偏概全；② 并列项和总分项分不清→误判 |
| confidence | high |

## 补充说明
以偏概全是中心理解最常见的错误选项类型。判断方法：选项内容与其他内容是并列→以偏概全；是总分（选项是总括）→不是以偏概全。若选项只覆盖文段若干并列项之一，即为以偏概全，应排除。

## 不适用条件
- 选项覆盖文段全部内容（无以偏概全可能）
- 文段为总分结构且选项是总括句

## 反向触发
- 选项与文段非并列非总分→改用无中生有/偷换概念判断
- 多个选项都疑似以偏概全→改用择优法选覆盖度最高的选项
