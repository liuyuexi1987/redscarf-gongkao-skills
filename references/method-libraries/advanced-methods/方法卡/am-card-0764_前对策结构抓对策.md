# 方法卡：前对策结构抓对策

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 前对策结构抓对策 |
| 适用题型 | 片段阅读-中心理解题 |
| 触发场景 | 文段结构为"先说点好的做铺垫→转折引出问题→给出对策→展开说明" |
| 步骤逻辑 | 1. 中国人说话含蓄，常先说好的做铺垫，转折后引出问题；2. "对此/针对这一问题"后引出对策，这是全段重点；3. 后文具体展开对策怎么做，属于论证支撑不重要；4. 抓住中间的对策句即可锁定答案，不用细读展开部分 |
| 高频错因 | 陷在前文铺垫或后文展开中，错过了中间的对策句 |
| confidence | medium |

## 不适用条件

1. 文段结构不是"问题→对策"型，而是"对策先出→后文解释"的倒装结构，对策可能在开头而非中间。
2. 文段没有明确的对策句，通篇在分析原因或描述现象，不能硬找对策。
3. 文段提出多个对策且无主次之分，需要概括全文而非只抓其中一个对策。

## 反向触发

1. 对策句出现后如果紧跟转折（"但是……仍不足"），说明对策可能被作者否定，需用转折强弱判断法判断。
2. 如果选项中对策表述与原文对策不完全一致，需结合主体一致性排除法检查是否偷换了概念。
3. 如果文段为"对策+科普介绍"混合类型，对策是重点，但选项需要兼顾概括性，不能只抓对策中的一个细节。
