# 方法卡：二级辨析·程度递进

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 二级辨析·程度递进 |
| 适用题型 | 判断推理——类比推理·语义关系 |
| 触发场景 | 多个选项都是近义词，需要进一步区分 |
| 步骤逻辑 | ① 确认题干两词存在程度递进（如"炎热→酷暑"由轻到重）；② 选项中找也有相同程度递进方向的一组；③ 注意程度递进不能掺杂其他关系（如组成关系） |
| 高频错因 | ① 选了"看着有递进但实际还夹杂其他关系"的选项（如战斗/战役/战争还有组成关系）；② 忽略程度方向（题干是由轻到重，选项是由重到轻） |
| confidence | high |

## 补充说明

程度递进的识别：题干两词存在由轻到重或由重到轻的强度变化。需排除夹杂其他关系（如组成关系、因果关系）的干扰项。

## 不适用条件

- 题干两词不存在程度差异（如纯并列近义词）时，本方法不适用。
- 题干两词关系是组成/包含等非程度关系时，本方法不适用。
- 选项中无任何一组具备相同程度递进方向时，本方法不适用。

## 反向触发

- 当选项中含明显贬义词提示情感色彩差异时，应换用二级辨析·褒贬色彩。
- 当题干是成语拆字结构时，应换用拆字近义法。
- 当题干是整体近义关系而非程度递进时，应换用语义近义辨析。
