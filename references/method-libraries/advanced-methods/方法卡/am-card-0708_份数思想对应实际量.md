# 方法卡：份数思想对应实际量

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 份数思想对应实际量 |
| 适用题型 | 工程问题或比例问题中，已求出各人效率的份数比，需要结合一个实际数值算出总量或单量 |
| 触发场景 | - 算出效率比（如张:李=3:1），题目又给出"张比李每小时多包14个"
- 或算出总工作量的份数（如100份=20千米），需要求每份的实际值 |
| 步骤逻辑 | 1. 由效率比算出份数差（如3-1=2份）；2. 用实际差值除以份数差，得到每份的实际量（14÷2=7个/份）；3. 用总份数乘以每份实际量，得到总量（如总效率和=4份，8小时×4份×7=224个） |
| 高频错因 | 用实际总量除以份数比时搞混被除数和除数忘记时间维度（总产量=效率×时间×每份实际量） |
| confidence | medium |

## 不适用条件

- 题目未给出任何实际差值或实际总量，仅有份数比而无法建立份数与实际量的对应关系。
- 份数比尚未确定就急于求每份实际量，需先解出效率比再使用本方法。

## 反向触发

- 当题目直接给出各人具体效率（而非效率比）时，应跳过份数换算直接用"给时间设最小公倍数为工作总量"。
- 当差值或总量条件不足、份数关系无法唯一确定时，应改用"不同完工情况列方程"补足等量关系。
