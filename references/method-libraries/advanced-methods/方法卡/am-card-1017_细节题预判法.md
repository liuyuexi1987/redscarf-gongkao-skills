# 方法卡：细节题预判法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 细节题预判法 |
| 适用题型 | 言语理解——细节判断 |
| 触发场景 | 细节判断题（"以下说法正确/不正确的是"） |
| 步骤逻辑 | ① 先看选项，不看文段；② 预判哪个选项可能错（表述偏绝对的/数字的/因果的/比较的）；③ 带着预判去文段验证；④ 优先验证最可能错的选项 |
| 高频错因 | ① 正向通读文段再看选项→效率低；② 不预判直接验证→四个选项都要验证→浪费时间 |
| confidence | high |

## 不适用条件
- 题型不是细节判断（如中心理解、逻辑填空）时
- 四个选项表述均较模糊、无法预判时
- 时间紧迫需快速完成、无暇逐项预判时

## 反向触发
- 看到"以下说法正确/不正确的是"等细节题标志时，先看选项再看原文
- 选项中出现具体数字、因果关系、比较关系时，优先验证该选项
- 选项表述偏绝对（"一定""所有""绝不"）时，该选项更可能错误

## 补充说明
细节题的高效做法是"逆向做题"：先看选项预判→再验证。预判依据：表述绝对的（硬选项）更可能错；有数字/比较/因果的更可能偷换；表述灵活的（软选项）更可能对。
