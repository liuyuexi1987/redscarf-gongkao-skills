# 方法卡：区别比较联系类选项反推法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 区别比较联系类选项反推法 |
| 适用题型 | 言语理解——片段阅读主旨题 |
| 触发场景 | 选项中出现"独特""与众不同""不同之处""优势""劣势""区别""联系"等区别/比较/联系表述 |
| 步骤逻辑 | ① 识别选项属于区别比较联系类（含"独特""与众不同""优势劣势""不同之处"等关键词）；② 反推所需原文结构：如果选该选项，原文应有双主语，既有A的介绍也有B的介绍，且双方做了对比；③ 回文验证：原文是否真的在对比两个事物，双方是否都有详细介绍；④ 若原文只讲一个事物、没有双方对比结构，则排除该选项 |
| 不适用条件 | 原文只有一方介绍、未做真正对比的文段（简单提及另一事物不构成双主语对比） |
| 高频错因 | 看到选项"听起来有道理"就选，不回文验证对应结构；把"简单提及另一事物"误认为"双方对比" |
| confidence | high |
| 反向触发 | 原文虽有双主语但对比维度与选项表述的对比点不一致时，应排除该选项并回到主旨概括法；选项中的比较表述若仅是原文论证过程中的细节而非最终落脚点，同样应排除 |
