# 方法卡：同因异果质疑归因

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 同因异果质疑归因 |
| 适用题型 | 判断推理——削弱/质疑（归因论证，需补充对照组） |
| 触发场景 | 实验只观察了新环境下的脑部状态，缺少旧环境（熟悉环境）的对照数据 |
| 步骤逻辑 | ① 画出实验图：新环境 + 一半一半 → 睡不好；② 发现缺少对照组（旧环境的脑部状态）；③ 找"同因异果"选项：旧环境也一半一半 → 但睡得好 → 因果不成立；④ 该选项直接构成完整对比实验，质疑归因 |
| 高频错因 | 选了对策选项（如让被试采取干预措施以消除首夜效应）；选了另起实验讲别的机制的选项（讲其他生理指标的无关项） |
| confidence | high |

## 补充说明

这是"缺对照组质疑"的具体操作方式。识别"同因"（两组共享某条件）与"异果"（结果不同）→ 该共享条件并非结果差异的原因。题干若未补全对照组，先在选项中找能补全对照组的项，再判断结论是否成立。

## 不适用条件

- 题干已给出完整对照组（条件组、无条件组与对应结果均明确给出）时，无需再用此法补对照。
- 非归因论证（如纯演绎、必要性论证、纯定义判断）中不适用。
- 选项中无可补全对照组的项时，本法的选项定位失效。

## 反向触发

- 题干对照组完整但变量不唯一时，改用"另有他因/他因削弱"方法。
- 选项不含补对照组项而含切断因果联系项时，转用"切断因果联系"或"因果倒置"类削弱。
- 结论含"如果…那么""只有…才"等绝对化逻辑关联词时，改用"严谨逻辑关系质疑法"找A且非B反例。
