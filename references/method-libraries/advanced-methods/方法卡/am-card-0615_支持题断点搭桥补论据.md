# 方法卡：支持题断点搭桥补论据

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 支持题断点搭桥补论据 |
| 适用题型 | 判断推理——支持/加强题（论据与结论之间有断点） |
| 触发场景 | 实验结论跳过了中间环节（如实验测的是脑区组织变化，结论却说"有助于创造力"） |
| 步骤逻辑 | ① 识别论据（脑区组织增加）和结论（激发创造力）；② 发现断点：脑区组织 ≠ 创造力；③ 选搭桥选项（如"脑区组织增加会带来活跃的天马行空思维"= 创造力）；④ 排除话题无关项和类比项（小白鼠实验力度极弱） |
| 高频错因 | 选了看似相关但未搭桥的选项（如仅泛指"这些研究"而无具体内容）；选类比项（如跨物种类比）力度不够 |
| confidence | high |

## 补充说明

搭桥选项常以论据关键词或结论关键词的同义表达出现：当结论关键词较抽象时，选项可能用同义概念来建立连接。当漏洞方向确定后，正确答案只能从该方向出，即便看似有小瑕疵也可能是对的。

## 不适用条件

- 论据与结论关键词本就一致、无断点时，无需搭桥。
- 题干要求"质疑/削弱"而非"支持/加强"时不适用。
- 选项中没有能同时连接论据与结论关键词的项时，本法的选项定位失效。

## 反向触发

- 论据结论关键词一致但样本/范围有漏洞时，改用"样本代表性补充"或"范围搭桥"。
- 题干要求质疑且有断点时，转用"断点拆桥法"切断连接。
- 选项含程度限定词且结论也含程度词时，改用"程度词精准匹配法"。
