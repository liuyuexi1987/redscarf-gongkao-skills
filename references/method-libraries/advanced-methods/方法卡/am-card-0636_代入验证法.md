# 方法卡：代入验证法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 代入验证法 |
| 适用题型 | 资料分析——选项极其接近时（如五位数差个位） |
| 触发场景 | 假设分配/直除精度不够，选项差距极小时 |
| 步骤逻辑 | ① 用四幺五/假设分配大致判断在哪个选项区间；② 在两个近选项中选一个好算的数当增量X；③ 用B-X求出基期A；④ 用A×R验算，看结果接近哪个选项 |
| 高频错因 | 选的X不好算；忘记验算误差范围 |
| confidence | medium |

## 补充说明

核心思路是用候选答案反推题面。优先选便于计算的候选值，比较反推结果与题面数据的偏差；只有偏差足以区分相邻选项时才能作答。

## 不适用条件

- 选项不是可代入的具体数值，或代入后仍需解多个未知量。
- 相邻选项反推结果的差异小于计算误差。

## 反向触发

- 两个候选都能近似还原题面时，应提高计算精度或改用精算。
- 反推结果全部偏离题面时，先检查公式、单位和基期方向。
