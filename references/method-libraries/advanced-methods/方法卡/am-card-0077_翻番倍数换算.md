# 方法卡：翻番倍数换算

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 翻番倍数换算 |
| 适用题型 | 资料分析 - "翻番"类表述转换 |
| 触发场景 | 题目出现"翻一番""翻两番"等字眼 |
| 步骤逻辑 | 1. 翻一番 = 2倍；2. 翻两番 = 4倍；3. 翻N番 = 2的N次方倍；4. 求翻番年份：算出目标值（基期×倍数），逐年观察何时达到 |
| 高频错因 | 把"翻一番"误理解为增长一倍（变成100%+100%=2倍，实际翻一番就是2倍没问题，但有人搞混成3倍）；翻两番误当成2倍 |
| confidence | high |

## 不适用条件

- 题目用的是百分比增长表述（如"增长了50%"）而非"翻番"表述时，不使用翻番换算。
- "翻番"涉及的是时间序列中逐年复合增长的复杂计算（如给定年均增速求几年翻番），需列式逐步推算，不能仅靠倍数关系速判。
- 题目问的是具体增长量（绝对值）而非倍数关系时，翻番换算无直接帮助。

## 反向触发

- 题目未出现"翻番"字样，直接给出百分比或倍数关系，无需做翻番换算。
- 题目问"增长了多少"即求增长量，而非求目标值的倍数。
- "翻番"表述出现在选项中而非题干中，需先理解题干再判断是否涉及翻番。
