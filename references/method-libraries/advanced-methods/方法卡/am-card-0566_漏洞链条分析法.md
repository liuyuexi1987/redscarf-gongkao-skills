# 方法卡：漏洞链条分析法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 漏洞链条分析法 |
| 适用题型 | 判断推理——削弱/支持类（尤其是"支持专家观点""质疑上述推理"等间接支持/削弱问法） |
| 触发场景 | 题干呈现A→B→C→D的推理链条，需要找到链条中隐含的默认假设（漏洞）来削弱或支持 |
| 步骤逻辑 | ① 还原论据到结论的完整推理链条，识别每一步隐含假设；② 找出链条中最薄弱的环节（即默认成立但未被证明的跳跃）；③ 削弱：切断该环节（拆桥）；支持：补强该环节（补漏洞）；④ 选项必须精准站在漏洞上，与漏洞无关的选项即使"看起来相关"也不选 |
| 高频错因 | 只看结论关键词匹配选项，不分析中间链条；选了"听起来相关"但未站在漏洞上的选项 |
| confidence | high |

## 补充说明

链条拆解思路：还原论据到结论的完整推理链条后，漏洞通常出现在"前一步推不出后一步"的环节（如"收入增加→消费增加"这一跳跃，因收入增加不等于消费增加）。拆桥选项只需切断该环节（如指出购买力下降、不消费），即可削弱整个链条。

补漏洞思路：当链条中存在隐含假设（如"分享数据=坏事"）时，补漏洞选项只需补强该隐含假设（如指出数据易被泄露），即可支持整个链条。

干扰项识别：看似相关但未站在漏洞上的选项（如"某因素占比小""其他维度的质量"等）不选，必须精准站在最薄弱环节上。

## 不适用条件

- 题干推理链条只有一步（论据直接推出结论，无中间环节）时不适用，应换用断点搭桥或必要条件法。
- 题目问法为"前提假设"而非"削弱/支持"时，应换用前提假设三种答案优先级法。
- 推理链条中每个环节都已显式证明（无隐含假设）时，不存在漏洞可拆/可补。

## 反向触发

- 当链条中存在多个漏洞时，应比较哪个漏洞是"必经环节"，优先拆/补必经环节。
- 当选项看似站在漏洞上但方向相反（削弱题选了支持项）时，应核验问法方向。
- 当无法定位漏洞时，应换用"断点搭桥法"重新识别概念跳跃。
