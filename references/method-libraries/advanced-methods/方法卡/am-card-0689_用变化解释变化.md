# 方法卡：用变化解释变化

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 用变化解释变化 |
| 适用题型 | 逻辑——解释说明类（"最有助于解释上述现象"） |
| 触发场景 | 题干描述了某个主体在时间维度上的变化（从好变差、从无到有等），问哪个选项能解释该变化 |
| 步骤逻辑 | ① 定位矛盾点：找出题干中"过去→现在"的变化趋势；② 排除恒常因素：如果某选项描述的是一直都存在的状态（非新变化），直接排除——它解释不了"为什么最近变了"；③ 选择新变化：正确选项必须体现"近两年/最近"这个时间窗口内出现的新因素，用新变化来解释结果的变化 |
| 高频错因 | 选了一个一直都存在的因素（如"版权意识一直差"），忽略了题干要求解释的是"为什么最近才变差"；没区分"举例子重复现象"和"解释原因"——举例子只是支持，不等于解释因果 |
| confidence | medium |

## 补充说明

时间对比归因的核心规律：题干呈现"过去→现在"变化时，正确答案必须是对应时间窗口内出现的新变量，而非一直存在的恒常因素。恒常因素（如长期存在的状态）解释不了"为什么最近才发生变化"。区分"举例子重复现象"与"解释原因"——举例子只是支持现象，不等于解释因果。该方法适用于时间对比归因题和解释说明类题目。

## 不适用条件

- 题干未呈现时间维度的变化（仅静态描述现状）。
- 题干要求解释的是某现象为何出现，而非为何发生变化。

## 反向触发

- 当题干问的是"为何出现某现象"而非"为何变化"时，应换用常规解释说明方法。
- 当选项中无明显时间标记时，需补充核验各选项是否对应题干时间窗口内的新变化。
