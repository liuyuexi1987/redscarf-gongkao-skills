# 方法卡：不相容对象代入排除法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 不相容对象代入排除法 |
| 适用题型 | 组合排列中"可以推出哪项"且选项互不相容（如冠军只能一人） |
| 触发场景 | 选项ABCD讨论的是互斥的结果（谁是冠军、谁去了哪里），正面代入某选项无矛盾 |
| 步骤逻辑 | 1. 先用命题间关系排除明显错误的选项；2. 对剩余选项正面代入——假设该选项为真，看是否与条件矛盾；3. 若无矛盾→该选项"可能为真"→排除其他所有"必然为假"的选项；4. 因为选项互不相容，一个可能为真就排除了其他必然为真的可能 |
| 高频错因 | 在选项相容的题目中误用此法（如"甲丙参加"和"甲丁参加"可以同时为真） |
| confidence | high |

## 补充说明

此法的适用前提严格——选项之间必须互不相容（不能同时为真）。方法提醒"如果选项相容，正面代入无矛盾只能证明可能为真，不能排除其他选项"。

## 不适用条件

1. 选项之间相容（可同时为真）时，正面代入无矛盾不等于该选项正确，此法失效。
2. 题目问的是"必然为真"而非"可能为真"时，正面代入法只能验证可能性，需补充反面排除来确认必然性。

## 反向触发

1. 当正面代入多个选项均无矛盾时，说明选项可能并非严格互斥，应改用反面代入（假设选项为真看能否推出矛盾）来区分。
2. 当条件数量多、代入验证耗时过长时，应优先用命题间关系进行逻辑推导，缩小候选范围后再代入。
