# 方法卡：配对条件选人排除

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 配对条件选人排除 |
| 适用题型 | 形式推理——N选M配对约束题（如七选四，配对至少选一个但不能都选） |
| 触发场景 | 题干给出多组配对条件"至少一人参加但不能都参加"，求必然能推出的结论 |
| 步骤逻辑 | ① "至少一个但不能都参加"=异或（要么A要么B）=每对只出一人；② 从总名额减去已锁定的配对名额，算出剩余名额；③ 剩余名额 > 剩余组人数 - 1时，该组任意两人的"或/且"都必然成立；④ 用"3选2时任意两人都至少有一个"的逻辑直接判断 |
| 高频错因 | 只盯着给定条件推导，忘记用总名额做排除；把"至少一个但不能都参加"误当成"至少一个"（或关系），忽略了"不能都参加"的额外约束 |
| confidence | high |

## 补充说明

核心逻辑：每对"至少一个但不能都参加"等价于异或（要么A要么B），每对只出一人。将已锁定的配对名额从总名额中减去，得到剩余名额与剩余组人数的关系。当剩余组为"3选2"时，最多只能排除1人，因此该组任意两人的"或"关系都必然成立。据此可直接判定形如"A或B参加"的结论是否必然为真——若让A和B都不参加仍能满足所有条件，则该结论不必然成立。

## 不适用条件

- 题干配对条件不是"至少一个但不能都参加"（如仅给"至少一个"或仅给"不能都参加"）时，本方法的异或逻辑不适用。
- 题目问的是"可能为真"而非"必然为真"时，本方法的排除逻辑需调整为可能性判断。

## 反向触发

- 当剩余名额等于剩余组人数（即"3选3"）时，无法用"任意两人至少一个"的逻辑，应换用全员入选的确定性判断。
- 当配对约束超过两组且交叉影响复杂时，需补充画表或连线法核验，避免单纯靠名额推算遗漏交叉约束。
