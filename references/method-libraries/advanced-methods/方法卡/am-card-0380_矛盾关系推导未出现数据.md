# 方法卡：矛盾关系推导未出现数据

> 裁决：REWRITE_IN_PLACE

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 矛盾关系推导未出现数据 |
| 适用题型 | 资料分析——材料中未直接给出的分类数据 |
| 触发场景 | 题干问某分类数据（如"省内流动""非某类"），而材料中未直接给出该数据，但给出了其矛盾对立项及占比 |
| 步骤逻辑 | ① 识别两个分类是否为矛盾关系（如跨省 vs 省内，在外出整体内互补）；② 用已知部分及其占整体比重反求整体（部分 ÷ 占比 = 整体）；③ 整体减已知部分即得所求（1 - 已知占比 = 未知占比） |
| 验证动作 | 用已知的两部分相加，确认等于整体；矛盾关系的两部分占比之和应等于 100% |
| 不适用条件 | 两个分类不是矛盾关系而是交叉关系或独立分类时不能直接互补 |
| 高频错因 | 误将矛盾关系的两部分当作独立数据源，未识别互补关系导致多算一步；将非矛盾关系的分类误判为互补 |
| confidence | high |
| 反向触发 | 题目已明确给出两个分类各自的原始数据，无需互补推导直接计算即可；若材料中两个分类并非在同一整体内互补（如跨省/省内 vs 男/女属于不同维度），用1减已知占比会得到无意义结果，需先确认分类维度一致 |
