# 方法卡：科普文与说理文的选项匹配

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 科普文与说理文的选项匹配 |
| 适用题型 | 中心理解——需先判断文段类型再选选项 |
| 触发场景 | 文段为纯客观事实描述（无作者观点/倾向），或文段为说理类（有观点/对策/意义表述）；选项混搭了中性表述和观点性表述 |
| 步骤逻辑 | ① 判断文段类型：科普文=无观点性（如"越来越多作家思考定位"是客观事实）；说理文=有观点性（如"翻译模式促进了跨境传播"是意义评价）；② 科普文→不能选有观点性的选项（对策、意义、评价类）；说理文→不能选纯中性的选项（背景、客观事实）；③ 两类文段的选项池不交叉 |
| 高频错因 | 科普文中选了对策或评价性表述；说理文中选了纯客观事实的表述；分不清"客观事实"和"作者观点"的边界 |
| confidence | high |

## 补充说明

区分方法：客观事实=已发生/大家公认的事（"今天下雨""某商品销量很高"）；观点=作者的主观判断/倾向/评价（"田野是符合孩子天性的土壤""翻译模式太好了"）。如果拿不准，反问"这是所有人都认可的事实吗？"——不是→就是观点。

## 不适用条件

- 文段为混合型（前半部分陈述客观事实，后半部分转入作者观点），且题目问的是后半部分的主旨时，应按说理文处理而非科普文
- 四个选项全部为同一类型（全是对策或全是客观事实），无需区分科普/说理时
- 文段为叙事类（讲故事、举例说明），既非纯科普也非典型说理时，应根据故事隐含的观点倾向判断

## 反向触发

- 当文段大部分为客观事实但末尾出现一句隐含评价（如"这一现象值得关注"），应识别为说理文的变体，选项需匹配评价性而非纯中性
- 当选项中存在既像客观事实又像隐含观点的表述时，不可仅凭单一关键词判断，应结合文段整体倾向进行匹配
- 当科普文中出现少量评价性语句但并非文段核心时，选项仍应以客观表述为主，不可因出现观点性语句就切换为说理文模式
