# 方法卡：常见幂数多重表示速查法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 常见幂数多重表示速查法 |
| 适用题型 | 数量关系——数字推理 |
| 触发场景 | 数字推理中出现常见幂数 |
| 步骤逻辑 | ① 27→3³（条件反射）；② 64→8²/4³/2⁶（三种都要试）；③ 81→3⁴/9²（两种都要试）；④ 不要漏掉多种可能 |
| 高频错因 | ① 64只想到8²→漏掉4³和2⁶→找不到规律；② 81只想到9²→漏掉3⁴ |
| confidence | high |

## 不适用条件
- 题目不涉及数字推理或幂数识别时，本卡不适用
- 数字明显不是幂数（如质数、等差数列）时，应换用其他数字推理方法
- 题目已给出明确的规律提示（如"等比数列"），直接套用对应公式

## 反向触发
- 若题目考查的是等差、等比、递推等非幂数规律，不使用本卡
- 若数字超出熟悉的幂数范围，先用平方、立方或相邻幂反推验证，不要仅凭外形套用
