# 方法卡：合作完工——总量÷效率和

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 合作完工——总量÷效率和 |
| 适用题型 | 数量关系（工程问题） |
| 触发场景 | 多人同时工作且同时完工，求总时间或某人协助时间 |
| 步骤逻辑 | 1. 已知工作时间→设总量为各时间的公倍数（不必最小公倍数，任意公倍数均可）；2. 总量÷各自时间=各自效率（此时效率为整数，好算）；3. 总时间=总工作量÷效率之和；4. 求某人协助时间：先算其他人独立完成量，剩余量÷该人效率=协助时间 |
| 高频错因 | 设总量为1导致效率全是分数不好算；误以为有人可以"不工作"来缩短时间 |
| confidence | medium |

## 不适用条件

- 工作有先后顺序（非同时开工、非同时完工）时不适用此法，应换用分阶段计算。
- 各人工作效率未知且无法由工作时间反推得出时不适用此法。
- 工作总量本身已给定（无需设公倍数赋值）时不适用此法。

## 反向触发

- 当工作时间含分数或非整数倍关系导致公倍数过大、计算量激增时，应换用"设效率为1"或直接列方程求解。
- 当题目求"最少需要几人"或"能否在期限内完成"等优化类问题时，应补充用最值分析而非直接套用效率和。
- 当涉及"中途加入/离开"等动态变化时，应换用分段计算法，将总工程拆为多个阶段分别求解。
