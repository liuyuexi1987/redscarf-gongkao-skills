# 方法卡：图推圆形与相交图形特征触发法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 图推圆形与相交图形特征触发法 |
| 适用题型 | 判断推理——图形推理 |
| 触发场景 | 图形中出现圆形或椭圆的特殊组合方式：多个圆相交/相切、所有图都包含圆、圆与直线形成交点 |
| 步骤逻辑 | ① 识别圆的特征类型：相交圆（某一个图中有多个圆相交/相切）→ 均有圆（所有或大多数图都包含圆）→ 笑脸类（圆+内部简单元素）；② 相交圆的优先级：交点数（圆与圆的交点）→ 封闭区域数 → 对称性 → 笔画数；③ 均有圆的优先级：圆作为共同元素时，看圆与内部/外部元素的关系（圆内点数、圆上线条数、圆与直线交点数）；④ 笑脸类的优先级：圆内元素的形状/数量/位置变化、鼻子眼睛的曲直/方向/对称；⑤ 圆当曲线：圆有时不作为独立元素，而是作为曲线参与线条数量计算 |
| 高频错因 | ① 相交圆和均有圆混淆：相交圆是某一个图有多个圆相交，均有圆是每个图都有圆但不一定相交；② 看到圆就只数圆的数量，忽略圆与圆之间的交点数、圆与直线的交点数；③ 均有圆题中忽略圆作为"容器"的考点（圆内元素的数量/形状/位置）；④ 笑脸类题只看整体忽略内部细节变化 |
| confidence | high |

## 补充说明

**相交圆的触发逻辑：** 当某一个图中有两个或多个圆通过相交或相切形成的图形时，触发此判断。相交圆的图形特征非常明确，指向性很强。核心考点是圆与圆的交点数（两圆相交有2个交点，三圆两两相交有6个交点等），其次是圆相交形成的封闭区域数。

**均有圆的触发逻辑：** 当所有图或大多数图都包含圆时，触发此判断。与相交圆的区别：均有圆的圆通常是独立的，不一定与其他圆相交。核心考点是圆与其他元素的关系：圆内点数、圆上线条数、圆与直线的交点数、圆的大小变化等。

**笑脸类的触发逻辑：** 当图形由一个圆和内部简单元素（如点、线、小图形）组成时，触发此判断。这类图形信息量有限，考点集中在内部元素的形状、数量、位置变化。常见考法：内部元素的数量递增/递减、形状交替、位置旋转、曲直变化等。

**圆当曲线的特殊情况：** 圆有时不作为独立元素，而是作为曲线参与线条数量计算。此时圆的周长算一条曲线，与其他线条一起数线条总数。

## 不适用条件

1. 圆只是轮廓或背景，其数量、位置、相交关系都不能形成稳定规律时。
2. 直线、规整分割或对称特征已经能连续解释全组图并区分选项时。
3. 圆与其他图形的交点、相交面或内外关系无法从图片中可靠识别时。

## 反向触发

1. 圆作为独立元素验证无果时，应将圆作为曲线参与线条数量计算重新排查
2. 笑脸类题内部元素变化无规律时，应换用1124图形间关系细分法分析内外关系
3. 圆与直线交点数验证后选项仍无法区分时，应补充核验圆内点数和圆上线条数

## 输出要求

- 看到圆的特征时，先说明触发的是哪种子类型（相交圆/均有圆/笑脸类）
- 相交圆优先验证交点数和封闭区域数
- 均有圆优先验证圆与其他元素的关系
- 笑脸类优先验证内部元素的变化规律
- 圆的特殊用法（当曲线）需要单独说明
