# 方法卡：否定此因优先另有他因

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 否定此因优先另有他因 |
| 适用题型 | 判断推理——削弱/质疑类 |
| 触发场景 | 归因题选项中同时出现"另有他因"和"否定此因"两类质疑，需判断力度强弱 |
| 步骤逻辑 | ① 识别"另有他因"：指出可能还有其他原因导致结果（只是把水搅浑）；② 识别"否定此因"：直接证明原因为假——如重灾区根本无焚烧火点，数量大（1/3省）+程度强（重灾区），说明不是个例；③ 力度排序：否定此因 > 另有他因，因为否定此因直接砍断因果链，另有他因只是增加不确定性 |
| 高频错因 | 分不清"他因"（只是可能）和"否定此因"（直接否定）；忽略选项中的数量/程度词（如"11个省""重灾区"），这些词暗示不是个例 |
| 不适用条件 | 题干非归因论证结构；选项中无"另有他因"与"否定此因"的力度对比 |
| 反向触发 | 选项中出现直接反驳原因为假的表述（如"重灾区根本无焚烧火点"），应优先选择 |
| confidence | high |

## 补充说明

"人们普遍认为"这类表述质疑力度弱，因为看法≠事实。选项用数据/事实说话力度更强。
