# 方法卡：语句填入逗号一致性

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 语句填入逗号一致性 |
| 适用题型 | 语句填入 |
| 触发场景 | 空格前是逗号，且该句尚未结束 |
| 步骤逻辑 | 1. 先看空格前后的句法结构和指代关系，标点只作辅助信号；2. 逗号通常表示句子尚未结束，优先检查主语、话题和逻辑衔接是否连续；3. 若选项承担总结或转折功能，必须同时满足上下文语义和句法要求；4. 排除话题、指代或逻辑关系不一致的选项 |
| 高频错因 | 把总结性语句填入逗号后的分句位置（应放在句号后） |
| confidence | high |

## 不适用条件

1. 空格前是句号而非逗号——此时可以考虑话题转换或总结性语句
2. 空格在段首（无前文标点参照），需从段落整体逻辑判断
3. 文段为总分结构且空格在总结段的句号后，填入总结性语句是合理的

## 反向触发

1. 空格前是逗号时，填入内容必须与当前句话题一致，不能跳到全文总结或换话题
2. 选项具有总结性时，不因逗号直接排除；应继续核对它能否在当前复句中自然收束前文并衔接后文
3. 判断填入内容的主语/话题是否与逗号前半句一致，不一致直接排除
