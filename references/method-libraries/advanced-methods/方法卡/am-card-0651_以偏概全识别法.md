# 方法卡：以偏概全识别法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 以偏概全识别法 |
| 适用题型 | 逻辑判断——一般质疑（推理过程漏洞） |
| 触发场景 | 题干从一个特例/部分推出整体结论，或从相似点推出相同结论 |
| 步骤逻辑 | ① 识别漏洞：论据是特例/部分，结论是整体/全部；② 常见形式：骨髓瘤细胞有特定基因→所有癌细胞都有；武汉有樱花→杭州也有；③ 质疑方式：指出其他部分/整体不一定有这个特征 |
| 高频错因 | 没有识别出"特例→整体"的推理漏洞；质疑的是无关的点（如质疑"什么时候激活"而非"是否都有"） |
| confidence | medium |
| 不适用条件 | - 论据不是特例或部分，而是覆盖整体的统计数据或全面调查，不属于以偏概全\n- 论证漏洞是因果关系错误（如另有他因、因果倒置），应使用归因论证质疑法\n- 推理为严格演绎（三段论），不存在 |
| 反向触发 | - 论据覆盖了所有群体或多种情况，属于全面归纳而非以偏概全→用其他质疑方向\n- 需要质疑的是因果关系而非样本代表性→用归因论证质疑法（另有他因/否定此因） |

## 补充说明

以偏概全的两种形式：① 特例→整体（如"骨髓瘤细胞有特定基因→所有癌细胞都有"）；② 相似点→相同结论（如"武汉杭州地理条件相似→杭州也有樱花"）。质疑时要针对"是否所有/整体都有这个特征"，而非其他无关点。造句：虽然骨髓瘤细胞因特定基因休眠，但其他癌细胞不一定有特定基因，所以癌细胞躲过免疫系统不一定是因为特定基因激活。
