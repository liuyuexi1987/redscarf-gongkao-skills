# 方法卡：且或否定互换规则

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 且或否定互换规则 |
| 适用题型 | 逻辑——翻译推理（题干含"且/和/同时"或"或/至少一个"及其否定形式） |
| 触发场景 | 需要对"且"命题或"或"命题取否定，或翻译含"并非品学兼优""并非周六或周日"等否定复合命题 |
| 步骤逻辑 | ① A且B 的否定 = 非A或非B（且变或，各加非）；② A或B 的否定 = 非A且非B（或变且，各加非）；③ 记忆方式：否定进去后，"且"和"或"互换，原命题的每个部分都加"非"；④ "至少一个"A或B，"至多一个"非A或非B |
| 高频错因 | 否定时只否了一个部分（如只否A没否B），或忘了把"且"换成"或"/把"或"换成"且"；把"并非品学兼优"翻译成"品德不优且学习不优"（应该是"或"） |
| confidence | medium |

## 补充说明

复合命题取否定的应用：若"A且B→C"，则非C推出"非A或非B"（而非"非A且非B"）。日常语言中"并且"常省略（如并列多人名表示同时满足），但"或者/要么"不会省略，翻译时需注意补全。该规则在等价推出和逆否命题计算中反复使用：复合命题"A且B→C"的逆否命题为"非C→非A或非B"。

## 不适用条件

- 题干不含"且/或"复合命题的否定运算（仅单一命题的简单否定）。
- 题干为不相容选言命题（"要么…要么…"），需用不相容析取规则而非简单且或互换。

## 反向触发

- 当题干要求判断命题真值而非做否定运算时，应换用真值表法。
- 当复合命题含多重嵌套（如"且"内套"或"）时，需分层逐步取否并核验每一步的且或互换是否到位。
