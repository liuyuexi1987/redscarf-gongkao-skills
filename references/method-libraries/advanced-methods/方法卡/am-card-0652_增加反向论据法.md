# 方法卡：增加反向论据法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 增加反向论据法 |
| 适用题型 | 逻辑判断——一般质疑（以偏概全） |
| 触发场景 | 题干只考虑了好的方面没考虑坏的方面，或只考虑了一部分人没考虑另一部分人 |
| 步骤逻辑 | ① 识别漏洞：题干只说了优点/有利因素，没说缺点/不利因素；② 质疑方式：补充一个反向的论据（缺点/不利因素）；③ 例如：题干说材料好→选项说材料有致命缺陷；题干说珠峰冰川融化→选项说其他地方冰川没融化 |
| 高频错因 | 补充的反向论据与题干话题不一致；补充的是小瑕疵而非致命问题 |
| confidence | medium |
| 不适用条件 | - 题干已经列出了正反两方面的因素，漏洞不是 |
| 反向触发 | - 题干漏洞不是片面性，而是特例推整体→用以偏概全识别法\n- 题干的论据是个人观点而非对事物的片面评价→用质疑论据法\n- 需要用造句法检验选项是否成立→用虽然但是所以不造句法 |

## 补充说明

增加反向论据的关键：① 要找致命问题，不是小瑕疵（如"材料不隔热不耐久"是致命问题，"某些人会过敏"是小瑕疵）；② 要与题干话题一致（如题干说"喜马拉雅地区"，选项也要说"喜马拉雅地区"，不能说"全球"）；③ 要是实际情况，不是理论上的可能性。
