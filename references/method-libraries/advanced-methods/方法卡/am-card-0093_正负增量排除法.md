# 方法卡：正负增量排除法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 正负增量排除法 |
| 适用题型 | 资料分析-折线图趋势匹配题（给定增量变化趋势选正确折线图） |
| 触发场景 | 题目给出多个选项的折线图，问哪个反映某段时间的同比增量变化趋势；时间段内增量有正有负 |
| 步骤逻辑 | 1. 先判断各月增量的正负号（增长→正，下降→负）；2. 只要包含正增量月份（如7-8月），则折线末端应在零线以上（尾巴翘起来）；3. 只要包含负增量月份（如2-6月），则折线前段应在零线以下；4. 若选项的折线整体为正但实际有负增量 → 直接排除；5. 找增量差异最悬殊的两个月份做锚点比较（如3月 vs 6月），进一步排除；6. 负数的绝对值越大 → 该月增量越小（方向需翻转） |
| 高频错因 | 负增量比较时忘记绝对值越大反而越小不利用正负号差异先做粗排，直接逐月精确比较 |
| confidence | high |

## 不适用条件

1. 所有月份增量同号（全正或全负），无法通过正负号差异做粗排
2. 选项折线图表示的是绝对量趋势而非增量变化趋势，坐标含义不同
3. 增量差异极小，粗排后仍需逐月精算

## 反向触发

1. 题目问的是"哪个折线图反映总量变化"而非增量变化
2. 材料只有一期数据，不存在多月增量序列
