# 方法卡：严谨逻辑关系翻译找矛盾

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 严谨逻辑关系翻译找矛盾 |
| 适用题型 | 判断推理——削弱/反驳（结论含逻辑关联词） |
| 触发场景 | 结论中出现"除非…否则…""只有…才…""只要…就…""如果…那么…""所有"等逻辑关联词，且问法为削弱/反驳 |
| 步骤逻辑 | ① 识别题型：结论含逻辑关联词 + 削弱问法 → 严谨逻辑关系；② 先翻译结论为逻辑式：如"除非A否则B" → 非A→B；③ 找矛盾（A→B的矛盾为A且非B）；④ 选与矛盾形式匹配的选项 |
| 高频错因 | 翻译错误（如把"除非A否则B"搞反）；选了逆否方向的选项而非矛盾方向 |
| confidence | high |

## 补充说明

"除非A否则B"翻译为 非A→B，其矛盾为 A且非B（即 A 成立但 B 不成立）。"只有才""只要就""如果那么""除非否则""所有"均为严谨逻辑关联词触发标志，翻译结论后找与矛盾形式匹配的选项。注意区分"矛盾方向"与"逆否方向"：逆否并不削弱原命题，只有"A且非B"才构成反驳。

## 不适用条件

1. 结论不含严谨逻辑关联词（仅含因果或归纳关系）时不适用本方法。
2. 问法为加强/解释而非削弱/反驳时不适用。
3. 选项中没有任何与"A且非B"形式匹配的项时需复核翻译是否正确，不能强行套用。

## 反向触发

1. 若结论为因果主张而非严谨逻辑命题，应换用因果削弱方法（切断机制链/他因削弱）。
2. 若选项均无矛盾形式匹配项，应回看翻译方向是否搞反，而非按选项位置猜答案。
3. 若结论含"可能""大概"等模态词，逻辑命题变为概率命题，应换用样本或数据类削弱。
