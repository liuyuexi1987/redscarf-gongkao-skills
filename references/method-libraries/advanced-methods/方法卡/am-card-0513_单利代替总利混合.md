# 方法卡：单利代替总利混合
## 基本信息
| 字段 | 值 |
|------|-----|
| 方法名 | 单利代替总利混合 |
| 适用题型 | 数量关系-利润/促销/盐水混合 |
| 触发场景 | 题目给出促销折扣、销量倍数、利润倍数关系，求不同购买方式的人数比 |
| 步骤逻辑 | 1.将1.5倍利润转化为比例3:2，避免小数运算 2.销量倍数为2时利润倍数为1.5→销量倍数为1时利润倍数为0.75（即3/4） 3.计算两种购买方式的单个利润比：两件80/100=4/5，三件100/150=2/3 4.交叉相减得分母之比5:3 5.乘以每种方式的数量（2件和3件）得人数比5:2 |
| 高频错因 | 忘记将销量倍数换算为1倍（直接按1.5混而非0.75混）；得出人数比后忘记乘以每人购买数量（2和3） |
| confidence | high |

## 不适用条件

1. 销量倍数无法归一为整数比时（如倍数为无理数或复杂小数），交叉相减精度受影响，需改用总利润列方程
2. 两种购买方式的折扣结构不对称（如一个满减一个打折）时，不能直接用单利代替总利混合

## 反向触发

1. 利润倍数转化比例后交叉相减出现负数时，检查是否比例方向搞反，重新确认谁比谁
2. 题目给出的不是利润倍数而是利润率时，需先将利润率转化为利润额再套用混合思路
## 补充说明
本质是"拿单利当总利来混"，前提是令销量相同使数量能消掉。关键步骤：先将倍数转比例（1.5→3/2），再将销量倍数归一（2倍→1倍时利润倍数也减半为0.75=3/4），最后交叉相减得分母比（即人数比乘以数量前的比例）。该结构在同类"折扣+销量倍数"混合利润题中通用。
