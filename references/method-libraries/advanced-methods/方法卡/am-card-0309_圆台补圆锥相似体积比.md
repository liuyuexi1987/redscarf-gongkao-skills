# 方法卡：圆台补圆锥相似体积比

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 圆台补圆锥相似体积比 |
| 适用题型 | 数量关系——立体几何、圆锥圆台体积 |
| 触发场景 | 圆台可补成完整圆锥，且题目给出半径、高度或相似关系，适合用线度比推体积比 |
| 步骤逻辑 | 1. 把圆台补成完整圆锥（向上延伸顶点）；2. 利用半径比=高度比，确定小圆锥/中圆锥/大圆锥的尺寸比；3. 体积比 = 半径比的立方（相似体体积比等于线度比的三次方）；4. 用体积比的"份数"对应实际重量，构建方程求解 |
| 高频错因 | 直接套圆台公式，计算量巨大且易错混淆"高度一半"对应的半径关系（半径比不一定是1:2的中点） |
| confidence | medium |
| 不适用条件 | 题目只涉及圆台侧面积或底面积，不涉及体积；或圆台无法补成规则圆锥（如母线不共顶点）时 |
| 反向触发 | 题目给出的不是半径比而是母线长或斜高，或需要精确体积而非比例关系时，改用圆台体积公式直接计算 |

## 补充说明

圆台本质是大圆锥截掉顶部小圆锥。当题目给出口部半径是底部半径的2倍时，正好是"拦腰劈开"，高度比也是2:1。用相似比的立方求体积比，再用份数法对应实际量，比直接列圆台公式快得多。
