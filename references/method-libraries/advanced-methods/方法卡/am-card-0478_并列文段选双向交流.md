# 方法卡：并列文段选双向交流

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 并列文段选双向交流 |
| 适用题型 | 中心理解题（并列结构） |
| 触发场景 | 文段分为多个并列分句，分别讨论"引进来"和"走出去"（或类似双向关系），选项中有单向表述和双向表述的区分。 |
| 步骤逻辑 | 1. 拆分文段为分一、分二、分三……；2. 判断每个分句的方向：是"引进/借鉴"还是"输出/影响"；3. 如果既有引进又有输出 → 正确选项必须体现**双向交流**；4. 只体现单向（仅输出或仅引进）的选项 → 片面，不选；5. 注意范围词的精确匹配：如"陶瓷"vs"陶器"（大vs小），"各国"vs"全世界"（精确vs扩大） |
| 高频错因 | 忽略了并列中某一个方向，选了单向选项主题词范围不匹配（如用"陶器"覆盖了"瓷器"） |
| confidence | high |

## 不适用条件

1. 文段并列的各分句确实只涉及单向关系（如只讨论引进来或只讨论输出），强行选双向选项会过度概括。
2. 并列的各分句方向不一致但讨论的是不同主体或不同时期，不能简单合并为"双向交流"。
3. 文段虽有双向元素但重心在其中一个方向（如"引进来"占80%篇幅，"走出去"仅一笔带过），主旨可能是单向侧重。

## 反向触发

1. 当双向选项正确但主题词范围扩大时（如文段说"瓷器交流"，选项说"文化交流"），范围匹配比方向正确更需优先检查。
2. 选项体现双向但方向颠倒（如文段说"我们输出、他们引进"，选项说"相互借鉴"），方向的具体对应关系需逐项核实。
3. 估算误差可能跨越选项时改用精算：逐一拆分文段各分句的方向和范围，再与选项逐项对比。
