# 方法卡：年均增速比例法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 年均增速比例法 |
| 适用题型 | 资料分析——按相同年均增速预测、排序年均增速 |
| 触发场景 | 题目说"按照X~Y年的年均增速增长，预测Z年"，或"年均增速由大到小排序"；两个时期年数相等时可直接建立比例 |
| 步骤逻辑 | ① 确认年数（减出来不是数出来）；② 建比例式：(1+R)^n = 现期/基期；③ 若两段时期年数相同 → (1+R)相等 → 直接比较比值即可排序或求解；④ 预测题：前段比值=后段比值，代入数据求解 |
| 高频错因 | 年数算错（19~23年 = 5年，基期为18年）；排序时认为五个数据一定都出现在四个选项中；江苏题忘前推基期 |
| confidence | high |

## 补充说明

核心优势：避免开根号。排序题中五个数据但选项只给四个（最大项可能不出现在选项中），正确率通常很低；预测题可直接列比例（如600×600÷212≈1700）；当年数相等时可直接建立等式（如19~22年=3年、22~25年=3年）。

## 不适用条件

1. 两段时期年数不同时，不能直接用比值比较来排序，需要分别计算(1+R)^n
2. 题目要求精确到小数点的年均增速数值时，比例法只能给出近似结果
3. 基期值为负数或接近零时，比值法的参考意义下降

## 反向触发

1. 当年数不等且需要精确比较两个年均增速时，应换用间隔代入法或逐个代入验证
2. 当比例式计算过程中出现数值过大（如超过四位数乘除）导致心算困难时，应换用有效数字法或拆分计算
3. 当预测题中前段和后段的基数差异很大时，比例法的近似误差可能较大，需额外核验结果合理性
