# 方法卡：增量比现期替代增速

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 增量比现期替代增速 |
| 适用题型 | 资料分析——多个增速的大小排序 |
| 触发场景 | 题目要求"增速最快/最慢的是哪个"；材料直接给出增量和现期（无需自己算基期） |
| 步骤逻辑 | ① 用X/B（增量÷现期）替代R（增速=增量÷基期）；② 对每个选项算出X/B的近似值；③ 比较大小排序；④ 若分母可进一步简化（如4986≈5000，除以5000=乘以2/10000），直接口算 |
| 高频错因 | 用此法计算具体增速值（只能比大小，不能算精确值）；基期和现期差距大时替代误差增大 |
| confidence | high |

## 补充说明

口算技巧：分母看成整千数（如4986→5000），增量÷5000=增量×2÷10000。如657÷5000≈13.1%。类似地7492≈7500，803÷7500≈10.7%，可快速排序。

## 不适用条件

- 材料未直接给出增量和现期，需要自行计算时本法优势不大
- 需要精确增速值而非排序（如问"增速是多少"）
- 各选项的增量与现期比例接近，X/B近似法无法拉开差距

## 反向触发

- 若用X/B排序后相邻两项的差距不足以覆盖替代误差，应换用R=X/(B-X)精确比较
- 若X/B替代造成的排序可能与精确增速排序不同，不宜直接使用替代值
