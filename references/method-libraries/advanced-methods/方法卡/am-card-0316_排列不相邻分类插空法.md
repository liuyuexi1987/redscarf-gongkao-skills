# 方法卡：排列不相邻分类插空法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 排列不相邻分类插空法 |
| 适用题型 | 数量关系——排列组合、不相邻约束 |
| 触发场景 | 多个对象排列，部分对象要求不相邻，同时可能存在可相邻或必须相邻的分类情况 |
| 步骤逻辑 | 1. 分析约束条件：哪些对必须不相邻，哪些对没有限制；2. **分类讨论**：- 情况一：所有约束项都不相邻 → 纯插空法（先排无约束项，约束项插入空位）- 情况二：部分无约束对可以相邻但约束项不相邻 → 捆绑法+插空（将可相邻的捆绑为一个整体，再与其余约束项插空）；3. 每种情况分别计算，最后相加；4. 注意捆绑项内部可交换，需乘内部排列数 |
| 高频错因 | 只考虑"都不相邻"一种情况，遗漏"部分相邻但与约束项不相邻"的情况捆绑后忘记乘内部交换排列 |
| confidence | medium |
| 不适用条件 | 约束对象数超过可用空位数（即总位置数的一半），无解；题目约束是"必须相邻"而非"不相邻"，应用捆绑法 |
| 反向触发 | 若同时存在相邻约束和不相邻约束，先捆绑处理相邻项再插空；插空计算结果与选项不符时，回溯检查是否遗漏分类情况或捆绑项内部排列 |

## 补充说明

关键思路转换：把"人不能连续参赛"转化为"项目不相邻"。排项目比排人简单得多。先排无约束的单项形成空位，再处理约束项的插入。
