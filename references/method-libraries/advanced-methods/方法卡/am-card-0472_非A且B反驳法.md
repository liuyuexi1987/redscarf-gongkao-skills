# 方法卡：A推B用非A且B反驳

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | A推B用非A且B反驳 |
| 适用题型 | 判断推理 > 论证相似/反驳方式一致 |
| 触发场景 | 题干给出"A→B"并用"非A且B"来反驳，要求选反驳方式一致的选项 |
| 步骤逻辑 | 1. 把题干观点翻译成 A→B（如"不了解历史→必定重复错误"）；2. 题干反驳用了"非A且B"（如"了解了历史→仍然重复错误"），这是**错误的**反驳；3. 逐个翻译选项的反驳结构，找同样用"非A且B"来反驳的；4. 排除A∧¬B（正确反驳方式，与题干不一致）和无关结构 |
| 高频错因 | 混淆"正确的反驳"和"题干要求的反驳"——题目要求的是找跟题干**错得一样**的选项 |
| confidence | high |

## 不适用条件

1. 题干使用的是正确的反驳方式（A∧¬B），而非"非A且B"这种错误反驳，此时应按正确逻辑结构匹配。
2. 题干中的推理不是充分条件推理（A→B），而是类比或归纳推理，反驳结构的翻译方式不同。
3. 题目问的是"以下哪项最能反驳"（评估反驳力度），而非"以下哪项反驳方式与题干一致"（结构匹配），方法不适用。

## 反向触发

1. 所有选项都使用"非A且B"结构时，需进一步对比A和B的具体内容是否对应题干，不能仅凭结构相同就选。
2. 当题干未给出明确的A→B推理结构，而是给出论点+论据的论证时，应转用论证评价或力度比较方法。
3. 选项使用了"非A且非B"或"A且B"等其他非标准结构时，需逐个翻译排除，不能套用"非A且B"模板。
