# 方法卡：时间对比变化体现法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 时间对比变化体现法 |
| 适用题型 | 言语理解——主旨概括/意图判断（时间对比结构文段） |
| 触发场景 | 文段出现"过去……现在……""曾经……如今……"等时间对比结构时 |
| 步骤逻辑 | ① 识别文段为时间对比结构（过去vs现在、旧vs新）；② 正确选项应体现这种"变化"——如"正在改变""由竞争转为互补""学术界正在改变口头传承不受重视的状况"；③ 只概括其中一侧（只说过去或只说现在）的选项不够全面；④ 选项中有"正在"类表述，若原文确实是在讲变化过程，则"正在"是严谨的表述 |
| 高频错因 | 选了只体现"过去"或只体现"现在"的选项，漏掉了对比；看到"正在改变"就觉得不够确定而排除（其实"正在"恰好体现了变化过程）；被尾句吸引而忽略全篇的时间对比结构 |
| confidence | medium |

## 补充说明

- 典型案例：过去口头传承不被重视→现在学者认识到问题并改变→选"学术界正在改变口头传承不受重视的状况"（体现变化）。
- "正在改变"不等于"还没改"——它准确描述了变化进行中的状态。几千年传统不可能一下就变，"正在改变"比"已经纠正"更严谨。
- 对比文段中的"我国vs他国"结构：重点通常在我国。
- 时间对比文段不要只盯尾句，要分析整体结构判断尾句是否重要——如果是全文贯穿对比，则选体现变化的选项。

## 不适用条件

1. 时间词出现但不构成对比关系（如"唐代产生了XX，宋代发展了XX"为递进而非对比），不能套用变化体现法。
2. 文段虽有过去/现在对比，但重点在论证某一侧的具体内容（如详细解释现状原因），而非强调变化本身。
3. 文段为纯并列枚举不同时间点的事实，无褒贬或趋势含义时，选概括而非变化。

## 反向触发

1. 若选项中有体现变化的选项但表述过于宽泛（如"一切都变了"），而另一选项虽只概括一侧但更准确，应选后者。
2. 时间对比仅占文段一小部分且被其他结构（如因果、对策）主导时，应以主导结构为准选择答案。
