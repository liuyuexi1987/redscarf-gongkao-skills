# 方法卡：加强削弱三步法与论点先行

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 加强削弱三步法与论点先行 |
| 适用题型 | 判断推理——加强削弱类（支持/质疑/不能支持/不能质疑/最不能支持/最不能质疑） |
| 触发场景 | 所有加强削弱题型，题干有论据+论点结构 |
| 步骤逻辑 | ① 找论点：80%在最后一句，关注"据此认为""因此"等标志词；② 带着论点找论据：读文段时紧扣论点追问"凭什么这么说"；③ 分析论证过程：判断论据能否推出论点，找出逻辑漏洞/断点；④ 预判答案：漏洞本身往往就是正确答案方向，再看选项匹配。核心原则：论点是一切的锚点，选项必须紧扣论点关键词 |
| 高频错因 | 从第一个字开始读文段被背景信息干扰；直接看选项不预判，被出题人带坑；只关注论据而忽略论点关键词的覆盖范围 |
| confidence | high |

## 补充说明

三步法的核心不是步骤顺序，而是"论点先行"的思维模式。典型场景：论点含多个关键词（如"极端气候变化导致文化变迁"包含两类文化迁徙方向），选项只解释其中一个方面则覆盖不全，同时解释两方面的选项优于片面解释。能否覆盖论点全部关键词，是区分选项的关键。

## 不适用条件

1. 当题干是纯形式逻辑推理（含"只有才""只要就"等联结词）时，应优先用形式逻辑翻译法，此法更适用于归因/论证类题
2. 当论点隐含在论据中（无明显标志词）且文段结构为并列举例时，需先判断论证结构再选方法
3. 当题干问"以下哪项最能削弱"且选项涉及力度排序时，三步法仅用于定位方向，力度排序需额外判断

## 反向触发

1. 当论点包含形式逻辑联结词时，应换用严谨逻辑削弱法（A且非B）
2. 当论证类型为对比实验归因时，应换用对比实验他因削弱法（回归分组判断）
