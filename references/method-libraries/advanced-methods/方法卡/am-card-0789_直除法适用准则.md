# 方法卡：直除法适用准则

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 直除法适用准则 |
| 适用题型 | 资料分析-除法-倍数/平均数/比值类，或选项极近时 |
| 触发场景 | 分子分母位数差别大（如32671/1.46）；选项非常接近无法用拆分保证精度时 |
| 步骤逻辑 | 1. 判断是否适合拆分：与比重/分数有关优先拆分 2. 判断是否适合假设分配：与基期/增长率有关优先假设分配 3. 以上都不适合时（倍数/平均数/比值、选项极近）使用直除 4. 直除时尽量保留原始数据不截位，直接计算首位或前两位 |
| 高频错因 | 在选项极近时仍用估算方法导致误差选错；直除时截位过多导致精度不足 |
| confidence | medium |

## 不适用条件

1. 分子分母位数相近且选项差距大时，拆分或假设分配通常更快，不必动用直除
2. 题目明确要求精确到某一位小数时，直除可能不如直接笔算
3. 当估算误差可能跨越选项或改变结论时，改用精算/验证

## 反向触发

1. 用拆分或假设分配算完后仍无法区分选项时，应切换到直除
2. 选项保留三位有效数字后差距在0.5以内时，直除是必要手段
3. 自己反复在两个选项间犹豫时，检查是否应该用直除替代估算

## 补充说明

直除法的原则是"不滥用但该用就用"。不建议截位直除，因为截位可能让考生心里发慌、做后面的题时还惦记前面的精度。三类除法方法的分工：比重/分数类用拆分，基期/增长率类用假设分配，倍数/平均数/比值类及选项极近时用直除。判断选项是否"极近"的方法：保留三位有效数字后比较，如276.99和277.12仅差0.13，此时必须直除。当估算误差可能跨越选项或改变结论时，改用精算/验证。
