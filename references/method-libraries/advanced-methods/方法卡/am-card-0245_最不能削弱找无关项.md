# 方法卡：最不能削弱题——找完全无关项

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 最不能削弱题——找完全无关项 |
| 适用题型 | 判断推理——最不能削弱类 |
| 触发场景 | 题目问"以下哪项最不能削弱"，其他选项都有一点质疑力度但不强，需要挑出完全无关的选项 |
| 步骤逻辑 | ① 识别结论中的核心要素（如因果关系中的因和果）；② 逐个检查选项是否与结论的任何要素相关；③ 选完全无关的选项——它对结论既不支持也不削弱；④ 警惕"实验瑕疵"类选项（样本少、年龄跨度大等），这类选项有一丁点质疑力度但不强，最不能削弱题中一般不选它 |
| 高频错因 | 被有"极弱质疑力度"的选项（实验瑕疵）迷惑，误选为不能削弱；忽略完全无关选项的排除功能 |
| confidence | high |
| 不适用条件 | 题目问"最能削弱"或"最能支持"时，不适用"找无关项"思路；此时应评估削弱/支持力度大小 |
| 反向触发 | 题目问“最能支持”或“最能削弱”时，应比较选项对论点、论据或推理链的实际作用；无关项不触及结论要素，弱作用项至少会影响其中一个论证环节，二者不能混同。 |
