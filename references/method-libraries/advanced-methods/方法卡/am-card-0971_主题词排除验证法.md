# 方法卡：主题词排除验证法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 主题词排除验证法 |
| 适用题型 | 言语理解——主题词验证（选项排除） |
| 触发场景 | 主旨题/意图题中，选项表述看起来都对，但有的选项缺少核心主题词 |
| 步骤逻辑 | ① 提取文段的核心主题词（高频出现的名词/概念）；② 检查每个选项是否包含主题词；③ 不含主题词的选项直接排除（无论表述多好看）；④ 剩余选项再比较哪个更全面覆盖文段主旨 |
| 高频错因 | ① 被"看起来很对但没有主题词"的选项迷惑；② 把文段的次要话题当成了主题词 |
| confidence | high |

## 补充说明
主题词验证是主旨题的"第一道过滤器"——选项必须包含文段的核心话题，否则再好看也不能选。主题词通常是文段中反复出现的名词或概念。注意：主题词不等于"出现次数最多的词"，而是"文段围绕展开讨论的核心概念"。

## 不适用条件
- 文段无明确核心主题词，多个话题并列讨论无主次之分。
- 选项都包含主题词，主题词筛选无排除价值。
- 题目为细节题或语句衔接题，非主旨/意图题，主题词验证不适用。

## 反向触发
- 当主题词筛选后剩余多个选项时，需补充主旨概括分析或对策性选项优先原则进一步判断。
- 当文段多主题时，应换用行文脉络分析法确定核心论点。
- 当选项均不含主题词时，应重新审视主题词提取是否准确，或换用感情倾向分析法。
