# 方法卡：分数占比整除特性

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 分数占比整除特性 |
| 适用题型 | 和差倍比问题、方程/不定方程 |
| 触发场景 | 题干出现"某部分占整体的 分母分之分子"，尤其分母为大质数（17、19、23、29等）时 |
| 步骤逻辑 | 1. 由 `y = (分子/分母) × x`，x 为整体、y 为部分；2. y 必须是整数 → x 必须是**分母的倍数**（x 能约掉分母）；3. 变形为 `y = 分子 × (x/分母)` → y 是**分子的倍数**；4. 利用这些倍数关系 + 限制条件（范围/最大最小）确定唯一解 |
| 高频错因 | 忘记验证 x 是分母倍数，直接设未知数列方程求解，计算量大且易错。忽视题干限制条件，导致多组倍数中无法确定唯一解。 |
| confidence | medium |

## 补充说明

- 分母为质数时整除特性最强，几乎必考。
- 典型应用：题干给出某部分人数占总人数的质数分母分数，结合总人数范围确定唯一解。

## 不适用条件

- 占比的分母为合数且可约分，约分后整除关系改变，直接套用可能误判。
- 题目未给出任何范围或限制条件，仅有倍数关系无法锁定唯一解。

## 反向触发

- 当分子、分母均可约分时，应先约分再判断整除关系，避免使用未约分的原始分母。
- 当倍数关系给出多组候选解且无法通过整除唯一确定时，应补充"和差速算公式"或列方程缩小范围。
