# 方法卡：严谨逻辑题——质疑找A且非B

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 严谨逻辑题质疑——找A且非B |
| 适用题型 | 判断推理——削弱类（严谨逻辑关系/非因果命题） |
| 触发场景 | 题干为"只有A才B""除非A否则B"等条件命题，问"以下哪项能质疑/说明上述决定未得到贯彻" |
| 步骤逻辑 | ① 翻译题干为A推B的形式（除非否则→否前推后，只有才→后推前）；② A推B的矛盾是A且非B——找一个选项满足"A成立但B不成立"；③ 其他选项设置的干扰：A且B（支持）、非A且B（逆命题）、非A且非B（否命题）都不是正确答案 |
| 高频错因 | 把非因果命题当归因题，错误使用"另有他因"来质疑；翻译时遇到"不""否"就拆成非，把自己绕晕 |
| confidence | high |

## 不适用条件

1. 题干是因果关系命题（A导致B），质疑应用"另有他因"或"因果倒置"
2. 题目问的是"支持""加强"而非质疑/削弱
3. 题干中A和B不是充分/必要条件关系，而是相关性陈述

## 反向触发

1. 出现"导致""引起""原因"等因果关键词，走归因质疑路线
2. 题目问"以下哪项最能支持"，不是削弱题
3. 选项中有"另有他因"形式（C也能导致B），属于因果削弱而非条件命题削弱
