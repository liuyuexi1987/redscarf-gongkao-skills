# 方法卡：冠军模型快速判定

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 冠军模型快速判定 |
| 适用题型 | 判断推理 > 真假推理（冠军/唯一人选类） |
| 触发场景 | N人猜冠军，只有M人说对，判断冠军是谁；各人猜测多为"或"表述 |
| 步骤逻辑 | 1. 把每句话翻译成逻辑表达式（如"乙"、"丁或丙"、"甲或丁"、"非甲且非丙"→乙或丁）；2. 先用等价排除法排除等价对（如甲丙等价，排除）；3. 对剩余候选，分别假设为冠军，数真假句数；4. 哪个候选的真句数等于题干要求（如"两人说对"），即为答案；5. 规律：两人说对→找出现两次的；三人说对→找出现三次的 |
| 高频错因 | 未翻译就直接猜；忘记"唯一冠军"前提导致多重计算；等价对象未排除浪费时间 |
| confidence | high |

## 补充说明

冠军判定的核心流程：先将每句话翻译成逻辑表达式，再用等价排除法（如甲丙等价则排除一对），最后对剩余候选分别假设为冠军，数真假句数，取满足题干要求的候选。规律：若题干说"两人说对"，找在所有猜测中恰好出现两次的候选；"三人说对"则找出现三次的。此规律仅在猜测语句互不包含时成立，若存在包含关系需逐个验证。

## 不适用条件

- 题干猜测中无"或"关系（如全部为"甲""乙"等确定陈述），直接数出现次数即可，无需翻译和等价排除
- 题干未给出"只有N人猜对"的真假数量约束时，无法使用假设验证法，应改用直接推理
- 猜测中涉及"且"关系（如"甲且乙"表示两人都可能是冠军）而非"或"关系时，翻译逻辑不同，本法的等价排除步骤不适用

## 反向触发

- 若按等价排除后仍有多于一个候选满足题干真假数量要求，检查是否有遗漏的等价关系或包含关系，补全后再排除
- 若某个候选的真假句数计算出现歧义（如某句话对该候选既可为真又可为假），说明翻译有误，应回到原句重新分析逻辑结构
