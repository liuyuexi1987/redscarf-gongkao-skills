# 方法卡：比重差公式

| 字段 | 内容 |
|------|------|
| 方法名 | 比重差公式 |
| 适用题型 | 资料分析-比重差（如"比重比上年上升/下降多少百分点"） |
| 触发场景 | 题目问现期比重与基期比重的差值，单位为百分点 |
| 步骤逻辑 | 1. 识别考比重差 → 2. 找部分增速(RA)和整体增速(RB) → 3. 套公式：比重差 = (小A/大B) × (RA - RB)，其中小A为基期部分值，大B为现期整体值 → 4. RA-RB判断升降方向，小A/大B估算幅度 |
| 高频错因 | 混淆比值差和比值增长率（带单位是比重差，带百分号是比值增长率） |
| confidence | high |

补充说明：公式结果单位为百分点。现期比重较小时，比重差通常也受其压缩；可先用RA-RB判断方向，再结合现期比重和选项差距决定是否需要精算。

## 不适用条件

- 题目问的是比重本身的数值（需直接计算而非套差值公式）
- 题目问的是比值增长率（单位为%，而非百分点）
- 部分增速或整体增速无法从材料中直接获取

## 反向触发

- 当RA-RB方向与选项矛盾时，应检查是否找错了部分/整体的增速，而非直接否定选项
- 当现期比重与增速差共同造成的估算误差可能跨越选项时，应精算或代入验证
- 当题目问"比重提高/下降了多少个百分点"但选项为百分比形式时，应换用比值增长率公式
