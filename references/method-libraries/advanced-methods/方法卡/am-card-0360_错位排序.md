# 方法卡：错位排序
## 基本信息
| 字段 | 值 |
|------|-----|
| 方法名 | 错位排序（伯努利信封问题） |
| 适用题型 | 数量关系-排列组合/每人不在原位 |
| 触发场景 | N个人全不在原来位置上，求排列数；或"恰好k人不变，其余全错位" |
| 步骤逻辑 | 1.记结论序列Dn：n=1→0, n=2→1, n=3→2, n=4→9, n=5→44 2.与"不变的人"组合配合使用：先C(n,k)选谁不变，再对剩余n-k人做错位排序 3.若只需结果，直接查表或枚举小规模情况 |
| 高频错因 | D3=2记错为3或1；与全排列A(n,n)混淆——全排列允许回到原位，错位排序不允许；漏乘"选谁不变"的组合数 |
| confidence | high |
| 不适用条件 | 1. 元素数量大于5且无法组合化简，错位排序数值过大难以枚举或记忆\n2. 元素存在可重复身份（如多把相同的钥匙），错位排序公式不适用 |
| 反向触发 | 1. 题目要求"至少1人不在原位"而非"全不在原位"，应改用总数减去全在原位的排列数（反面法）\n2. 题目额外限制了某些元素只能去某些位置，错位排序通用公式不适用，需改用容斥原理或逐一枚举 |
## 补充说明
递推公式Dn=(n-1)(D(n-1)+D(n-2))，但建议直接记数字，因为"记不住数公式也记不住"。考试最常考D3=2和D4=9。D3=2可手动枚举验证：ABC三人，只有BCA和CAB两种全错位排列。
