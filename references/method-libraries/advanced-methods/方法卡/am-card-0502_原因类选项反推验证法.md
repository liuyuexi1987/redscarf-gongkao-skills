# 方法卡：原因类选项反推验证法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 原因类选项反推验证法 |
| 适用题型 | 主旨题/标题题 |
| 触发场景 | 选项出现因果表述（导致/使/为什么/原因），需判断文段是否在分析原因 |
| 步骤逻辑 | 1)先看文段有无因果关联词（所以/因此/之所以…是因为），若有且因果是重点则可选原因类选项 2)无因果关联词时，逆推回文段看原文是否在重点分析原因 3)文段讲"现象→原因→结果"链条的，原因类选项可以选 |
| 高频错因 | 文段没讲原因，选项却以"X导致Y"形式出现，被因果结构误导 |
| confidence | medium |

## 不适用条件

1. 文段没有因果逻辑链条而是并列或递进结构时，不能用原因类选项
2. 选项虽含因果词（"导致""使"）但实际是对比或描述变化时，因果词不等于因果逻辑

## 反向触发

1. 若文段有明确对策句，配合"原文对策选对策"方法
2. 若选项是"从X到Y"结构，配合"从X到Y表述不等于对策"方法
3. 若文段是历程描述，配合历程类选项识别方法
