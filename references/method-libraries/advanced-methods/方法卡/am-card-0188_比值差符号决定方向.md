# 方法卡：比值差-符号决定方向

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 比值差-符号决定方向 |
| 适用题型 | 资料分析——比值差/平均数差值，用公式法计算时需判断差值正负 |
| 触发场景 | 用比值差公式（A/B×(R1-R2)/(1+R1)）计算后，结果的有效数字需要判断是"加"还是"减"来确定最终答案 |
| 步骤逻辑 | ① 用比值差公式算出有效数字（如首位为9）；② 观察R1-R2的符号：若R1<R2（分子增速低于分母增速），则比值下降→结果为"9减"而非"9加"；③ 根据符号判断最终值是略大于还是略小于该有效数字，锁定选项 |
| 高频错因 | ① 只算有效数字不看符号，把"9减"误判为"9加"导致选错相邻选项；② 混淆R1和R2的对应关系（谁是分子增速谁是分母增速） |
| confidence | high |

## 补充说明

讲解比值差时特别强调符号判断的重要性。当选项首位不同但实际差值计算后首位相同（如810 vs 896），符号决定最终选哪个相邻选项。此技巧在选项"看起来差距大实际差距小"的题目中尤为关键。

## 不适用条件

1. 比值差公式不适用的题型（如纯加减关系的增长量比较）时，不能套用此符号判断法
2. 选项间距极大、不需要判断符号方向时，粗估即可锁定答案
3. 当分子分母增速相同（R1=R2）时，比值无变化，无需判断符号

## 反向触发

1. 当R1和R2的对应关系不明确（分不清谁是分子增速谁是分母增速）时，应先回溯题干确认分子分母，再代入公式
2. 当符号判断后结果仍与多个选项接近时，需换用精算模式逐位计算，不能仅凭符号方向选定
3. 当比值差公式计算出的首位与所有选项都不匹配时，应核验是否单位未统一或量级未还原
