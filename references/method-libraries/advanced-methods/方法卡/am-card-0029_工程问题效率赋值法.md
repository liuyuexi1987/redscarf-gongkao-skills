# 方法卡：工程问题效率赋值法
## 基本信息
| 字段 | 值 |
|------|-----|
| 方法名 | 工程问题效率赋值法 |
| 适用题型 | 数量关系-工程问题（多组效率比） |
| 触发场景 | 题目给出多组效率之比，已知总工作量或完成天数 |
| 步骤逻辑 | 1. 第一组已知比值直接赋值具体数（如5:4→甲=5乙=4）；2. 第二组若与前组无关联，设未知数（如丙=3X丁=2X）；3. 由已知天数求总工作量；4. 根据不同完工情况列方程解X |
| 高频错因 | 不同组之间关系未知时盲目赋值；忽略各组之间效率独立导致赋值冲突 |
| confidence | high |
## 补充说明
工程问题核心公式：工作总量 = 效率 × 时间。赋值原则：只在各组之间相互独立时才能直接赋值；若多组之间关系未知，第一组赋值后其余组设未知数。常见效率比记忆：1.25倍=5:4，1.5倍=3:2，1.2倍=6:5。总工作量由已知天数和赋值效率反推。

## 不适用条件
- 题目已直接给出具体工程量和具体效率数值，无需赋值操作
- 仅有一组效率比且无完工天数等独立条件，赋值后无法建立方程求解
- 效率在施工过程中发生变化（如中途加速/减速），静态赋值不适用

## 反向触发
- 看到"效率之比为X:Y""甲乙效率比""丙丁效率比"等多组效率比表述
- 题目给出完工天数或合作天数，但未给工作总量具体值
- 出现"先合干X天，再由甲单独干Y天完成"等需要列方程的完工情形
