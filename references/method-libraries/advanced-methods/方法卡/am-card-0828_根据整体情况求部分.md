# 方法卡：根据整体情况求部分

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 根据整体情况求部分 |
| 适用题型 | 资料分析——假设各部分增速与整体一致，求某部分数据 |
| 触发场景 | 题目说"假设各行业/各区域增速与全省/全国一致"，要求求某行业/区域的基期值或基期差值；题干描述绕但本质是套用整体增速到部分 |
| 步骤逻辑 | ① 翻译题干："各行业增速与整体一致"=用整体增速替代各部分增速；② 套用基期公式 A=B/(1+R) 求出各部分基期值；③ 做差或求比 |
| 高频错因 | 被题干绕晕，读不懂"假设增速和整体一致"的实际含义；误认为需要找各部分单独增速 |
| confidence | medium |

## 补充说明

这种题需要把"假设整体增速代替部分增速"翻译成计算操作。可用于求基期差值、基期占比等。本质是ABRX中"基期差值"知识点与比重知识点的结合。

## 速算边界

当估算误差可能跨越选项或改变结论时，改用精算/验证。

## 不适用条件

- 题目要求用各部分实际增速分别计算时，不能套用整体增速，需逐项求解。
- 整体增长率的精度不足（如材料只给"约XX%"）且选项间距极小，套用近似增速可能偏移。

## 反向触发

- 材料分别给出了各部分的实际增速，应优先用实际增速计算。
- 题干明确说"不考虑整体增速"或要求"按各自增速"时，不能用整体替代。
