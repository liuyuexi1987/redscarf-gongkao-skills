# 方法卡：对比实验查初始状态

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 对比实验查初始状态 |
| 适用题型 | 对比实验归因质疑题 |
| 触发场景 | 题干通过两组对比实验得出因果结论，需要质疑时 |
| 步骤逻辑 | 1. 识别题干为对比实验结构：实验组 vs 对照组，结论为某因素有效；2. 质疑时优先检查：两组初始状态是否一致；3. 若初始状态有差异，则最终结果一致不能说明该因素无效；4. 这是实验的根本漏洞，比"样本量小""时间长"等实验瑕疵力度更强 |
| 高频错因 | 选了"样本量太小""实验时间太长"等实验瑕疵选项，这类选项质疑力度极弱，基本不会是正确答案 |
| 不适用条件 | 题干非对比实验结构（如单一案例归因、问卷调查、统计数据描述）；题目已明确说明两组初始状态一致 |
| 反向触发 | 题目问的是实验结论的加强/支持而非质疑，或题干本身未给出对比实验结构 |
| confidence | high |
