# 方法卡：原命题逆命题识别

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 原命题逆命题识别 |
| 适用题型 | 形式推理——找推理方式与题干一致的选项 |
| 触发场景 | 题干先给出A→B，结论却用了B→A的推理（先验证后件，再推前件），要求找同样犯了"逆命题"错误的选项 |
| 步骤逻辑 | ① 拆解题干：原命题A→B + 逆命题B→A（先正后逆）；② 原命题只与逆否命题等价，与逆命题不等价，但题目的要求是"推理方式一致"而非"推理正确"；③ 逐个选项判断是原命题、逆命题、否命题还是逆否命题；④ 排除推理正确的选项（如从"所有"推到"个例"=正确推理）和命题类型不匹配的选项 |
| 高频错因 | 把"推理方式一致"误理解为"推理正确"；把因果倒置概念与形式推理的逆命题概念混为一谈 |
| confidence | high |

## 补充说明

判断推理方式一致性时，先识别题干结构：原命题A→B + 结论用B→A=逆命题（先正后逆）。逐个选项判断是原命题、逆命题、否命题还是逆否命题，匹配题干类型即可。排除推理正确的选项（如从所有推个例）和命题类型不匹配的选项（如等价转换）。形式推理与逻辑推理（加强削弱中的因果倒置）是不同分类，不要混淆。

## 不适用条件

- 题干要求找的是"推理正确"的选项而非"推理方式一致"时，不适用本方法。
- 题干结构并非"原命题+逆命题"的先正后逆模式，而是单纯的条件推理链时，不适用本方法。

## 反向触发

- 当题干涉及"否命题"或"逆否命题"而非"逆命题"时，应换用对应命题类型识别法，注意等价转换规则。
- 当选项中出现复合命题（联言/选言）时，应补充核验命题类型的分解是否正确，避免把联言误判为逆命题。
