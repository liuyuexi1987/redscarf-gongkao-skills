# 方法卡：个例不是≠有的不是辨析

| 字段 | 内容 |
|------|------|
| 方法名 | 个例不是不等于有的不是 |
| 适用题型 | 逻辑判断——真话假话题（涉及"有的是/有的不是"推导） |
| 触发场景 | 由某个具体人"不是"推出"有的不是"后，直接等同于题干中另一个人说的"有的不是"进行判断 |
| 步骤逻辑 | 1. "张不是"只能推出范围较小的"有的不是"（仅含张是→别人不是这一种情况） |
| | 2. 题干中"有的不是"包含两种可能：(a)张是且别人不是 (b)张不是且别人可能也是 |
| | 3. 推出的"有的不是"范围 < 题干"有的不是"范围→不能等价替代 |
| | 4. 应将已知信息代入原始命题，通过矛盾关系而非表面等价来判断真假 |
| 高频错因 | ①把"张不是"等价于"有的不是"直接用②混淆"推出"和"等价"——推出不意味着范围相同 |
| confidence | high |

## 不适用条件

- 题目中所有陈述均为全称命题（所有是/所有不是），没有特称命题参与，应直接用对当关系法。
- 题干信息已足够通过矛盾关系直接确定真假，无需进行个例推导。

## 反向触发

- 看到"有的是""有的不是"与"所有是""所有不是"并列出现时，提示应使用对当关系中的矛盾关系（有的是⇔所有不是为矛盾）。
- 看到"某个具体人不是"且题干要求判断"有的不是"的真假时，提醒不可直接等价。

**补充说明：**
- 核心区别：设讨论对象为{张,王,李}三种情况。(1)全部是 (2)部分是部分不是 (3)全不是。"有的是"含(1)(2)，"有的不是"含(2)(3)。"张不是"只能推出(3)中含张的一部分，范围远小于(2)(3)整体。
- 做题时不要被"写起来一样"的文字误导，要关注外延范围是否一致。
- 正确做法：把已知的确定信息（如张氏、张不是等）代入"有的是/有的不是"来判断真假，而非用"张不是→有的不是"这种表面等价。
