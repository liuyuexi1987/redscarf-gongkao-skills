# 方法卡：增加值与增长量辨析

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 增加值与增长量辨析 |
| 适用题型 | 资料分析——题干出现"增加值"时判断其含义是绝对量还是增长量 |
| 触发场景 | 题干问"X增加值占Y增加值的比重"，但材料中的数据是收入/产值等绝对量而非增加值字段 |
| 步骤逻辑 | ① 大多数题中材料直接给出"增加值"字段，此时增加值=具体绝对量，按正常比重计算即可；② 若材料中无"增加值"字段，而题干问"增加值占…的比重"→此时"增加值"实际指增长量X；③ 用部分增量X1除以总体增量X2求比重 |
| 高频错因 | 把"增加值"一律当绝对量处理，用现期量去算比重，结果完全错误；未检查材料中是否存在对应"增加值"数据字段 |
| confidence | high |

## 不适用条件

1. 材料中已有明确的"增加值"独立数据字段，可直接按绝对量计算
2. 题干中不涉及"增加值"概念，只问普通绝对量的比重

## 反向触发

- 题干出现"X增加值占Y增加值的比重"，但材料中没有"增加值"独立字段，此时增加值即增长量

## 补充说明

词义辨析称之为"易错题"。关键判断依据：材料中是否有"增加值"这个独立数据字段。有→按绝对量算；没有→增加值=增长量，用假设分配或直接做差求增量。此陷阱在近年山东省考中多次出现。
