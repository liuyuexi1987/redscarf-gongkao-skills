# 方法卡：直言命题联动推导法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 直言命题联动推导法 |
| 适用题型 | 组合排列题（一拖N、一拖二、一拖五） |
| 触发场景 | 题干给出多个假言命题 + 至少一个直言命题（"谁是什么""谁在哪天"等确定信息） |
| 步骤逻辑 | 1. 先把所有直言命题（确定信息）填入表格/位置；2. 用直言命题去"激活"假言命题——找与直言命题前件或后件相同的假言命题；3. 肯前推肯后 / 否后推否前，推出新信息；4. 新信息再去找能联动的假言命题，循环推到不能推为止 |
| 高频错因 | 忽略直言命题与假言命题之间的关联性，找不到"启动钥匙"；或把条件中的"如果…则…"误当直言命题 |
| confidence | high |

## 补充说明

方法提示：先看直言命题，没有直言命题时假言命题也难以继续推导。核心是把直言命题当作推理链条的"车钥匙"。

## 不适用条件

1. 题干中全部为假言命题、没有直言命题时，此法无法启动，需换用假设法或两难推理。
2. 直言命题与假言命题的前件后件完全不重叠、无法联动时，此法失效，应考虑其他组合排列策略。

## 反向触发

1. 当直言命题代入后推出矛盾时，说明前提假设不成立，需回溯并检查是否误读了某个条件。
2. 当推到底仍有信息未确定时，应补充使用假设法对剩余不确定项逐一验证。
