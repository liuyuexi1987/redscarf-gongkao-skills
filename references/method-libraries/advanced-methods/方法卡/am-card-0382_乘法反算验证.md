# 方法卡：乘法反算验证

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 乘法反算验证 |
| 适用题型 | 判断占比是否超过某阈值 |
| 触发场景 | 需要判断 a/b 是否超过 x%（如70%），直接除不好算 |
| 步骤逻辑 | 1. 不算 a÷b，而是算 b × x%；2. 若 b × x% > a，则 a/b < x%，未达到；3. 若 b × x% < a，则 a/b > x%，已超过；4. 优势：左边是个位数乘法，可口算 |
| 高频错因 | 硬除导致耗时过长或算错 |
| confidence | medium |

## 补充说明

核心思路是"不算除法，算乘法"：判断 a/b 是否超过 x% 时，直接算 b×x% 并与 a 比较。例如判断某值是否超过70%，只需算总数×70%（通常是个位数乘法或简单口算），再看结果是否大于分子即可。优势在于将可能需要多位除法的问题转化为简单乘法。此法特别适合x%为整十数或常见百分数（50%、75%、80%等）的场景。

## 不适用条件

- x%本身不方便快速乘算（如23.7%），此时乘法计算量未必比直接除小
- 需要精确求出 a/b 的值而非仅判断是否超过阈值
- a和b都是极大数且 x% 非整数，乘法反而比截位直除更麻烦

## 反向触发

- 当 b×x% 的计算量接近或超过直接截位直除时，应切换为直除
- 当需要判断 a/b 的精确值而非仅判断是否超过某阈值时，直接除法更合适
- 当有多个阈值需要逐一判断时，逐一做乘法不如一次除法后直接比较
