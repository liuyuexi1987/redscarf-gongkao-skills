# 方法卡：基期比重灵活求解

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 基期比重灵活求解 |
| 适用题型 | 资料分析——缺整体增长率时求基期比重 |
| 触发场景 | 题目要求基期比重，但材料没有整体增长率，只有两部分各自的现期量和增长率，无法直接套基期比重公式 |
| 步骤逻辑 | ① 识别无法套公式（缺整体增长率）；② 方法一：分别求两个基期量再做比（一个用415，一个用假设分配）；③ 方法二：求两部分的基期比值，再用比值求占比 M/(M+N) |
| 高频错因 | 强行套基期比重公式但缺少整体增长率导致无从下手；用盐水求整体增长率——但盐水用的是基期量之比，材料给的是现期量之比，近似误差大 |
| confidence | medium |

## 补充说明

当材料只有两部分的现期量和各自增长率、没有整体增长率时，推荐分别求两个基期量再比（方法一更直观）。注意：盐水法要求基期量之比，而材料只给现期量之比，用现期量代替会产生较大误差，一般不推荐。

## 速算边界

当估算误差可能跨越选项或改变结论时，改用精算/验证。

## 不适用条件

- 材料已直接给出整体增长率时，应直接套基期比重公式，无需分别求基期量。
- 两部分之一的基期量过小或增长率极不规则（如接近 -100%）时，分别求基期量的误差会放大，需精算。

## 反向触发

- 材料同时给了整体增长率和部分增长率，优先走标准基期比重公式。
- 选项间距极小（如 0.1 个百分点以内），分别求基期量再比的累积误差可能导致选错。
