# 方法卡：严谨逻辑关系质疑法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 严谨逻辑关系质疑法 |
| 适用题型 | 逻辑判断——结论有逻辑关联词（如果就、只有才、只要就、所有都） |
| 触发场景 | 结论可以翻译成A推B的形式，需要找质疑选项 |
| 步骤逻辑 | ① 将结论翻译成A推B；② 在选项中找A且非B；③ 如果找不到A且非B，可以用A推非B代替；④ 个例可以质疑"所有都/只有才"这类全称命题 |
| 高频错因 | 翻译方向搞反（B推A而非A推B）；选了非A且B而非A且非B；忽略逻辑关联词 |
| confidence | medium |
| 不适用条件 | - 结论不含逻辑关联词，无法翻译成A推B的形式，应使用一般质疑方法\n- 结论是因果关系陈述而非条件命题，不适用此法\n- 需要质疑的是论据的事实性而非推理结构→用质疑论据法 |
| 反向触发 | - 结论不含 |

## 补充说明

这是强化方法总结的固定题型，正确答案几乎总是长一个样。底层逻辑：A推B的矛盾是A且非B。但因为是论证题（非形式逻辑），A推非B也可以接受。例如：结论"走路就能健康"→找"不正确的走路不能健康"的选项。翻译时注意"只能"="只有才"="所有都"，都是全称命题。
