# 方法卡：工程合作完工时间
## 基本信息
| 字段 | 值 |
|------|-----|
| 方法名 | 工程合作完工时间 |
| 适用题型 | 数量关系-工程问题/多人同时开工同时完工 |
| 触发场景 | 多人合作完成各自工程，同时开工同时完工；或某人中途调换工地 |
| 步骤逻辑 | 1.同时开工同时完工→工作时间相同→T=总工作量÷效率和 2.求某人转场时间：先算固定工人的工作量→求剩余工作量→用此人效率算在原工地天数→转场日=工作天数+1 3.已知时间求效率比→设总量为时间的公倍数→效率=总量÷时间 |
| 高频错因 | 转场日误算为"干完当天"（应为下一天）；效率比与时间比搞反（时间越长效率越低）；两个工程总量设为相同值时效率变化但比值不变，不必纠结 |
| confidence | high |
| 不适用条件 | 1. 题目是交替施工或分段施工（如甲干3天后乙接手），不是同时开工同时完工的场景\n2. 题目只涉及一个人单独完成工作，不存在合作或调换 |
| 反向触发 | 1. 题干涉及水池同时进水和放水，应改用进水效率与放水效率做差的方法\n2. 题目只求效率比而不需要具体天数，用赋值法结合比例法更快捷\n3. 出现"先一起干再有人离开"的分段合作，需要分别列方程而非直接用效率和公式 |
## 补充说明
统筹问题核心口诀："干擅长的"。比较各人做甲乙工作的时间比（横比或纵比均可），时间短的代表擅长该项。需注意"总量设不设一样无所谓"，因为效率随总量变化而时间比值恒定。
