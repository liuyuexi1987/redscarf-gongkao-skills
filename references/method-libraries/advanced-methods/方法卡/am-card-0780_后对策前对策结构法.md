# 方法卡：后对策前对策结构法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 后对策前对策结构法 |
| 适用题型 | 言语理解——中心理解（对策结构识别） |
| 触发场景 | 文段含有对策或观点表述，需要判断是对策在前还是对策在后 |
| 步骤逻辑 | 1. **后对策结构**: 引出话题/问题 → 分析解释说明 → 最后给出对策或观点- 尾句是对策/观点，是主旨句- 前文是分析论证，不用细看；2. **前对策结构**: 首句给出对策/观点 → 后文进行论证- 首句是对策/观点，是主旨句- 后文是支撑论证，不用细看；3. **判断方法**: 看第二句是否是对策- 第二句是对策 → 前对策- 第二句是分析 → 继续看尾句，找对策 |
| 高频错因 | 把分析论证部分的内容当成主旨分不清对策和问题的位置，选错重点 |
| confidence | medium |

## 不适用条件

- 科普介绍类文段（无作者观点/对策）不使用本卡
- 文段为并列结构、无明显主次之分时，不使用本卡

## 反向触发

- 若文段对策位置不明确（既不在首句附近也不在尾句），应重新分析结构
- 若选项未体现对策的具体做法，而是描述问题或背景，不应选

> **使用边界**：本方法用于提供优先检查方向，不可单独据此作答；最终需回到题干关系、原文证据或选项条件完成验证。

**适用范围**：仅适用于说理类文段（作者有明确观点或指挥做法）。对策触发条件：问法含"应该""做法""建议""启示"等对策类提示词，或文段作者明确输出观点。定位对策句后必须回题验证选项是否准确反映对策的核心内容。
