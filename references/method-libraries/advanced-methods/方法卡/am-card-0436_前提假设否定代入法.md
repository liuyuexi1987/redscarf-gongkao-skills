# 方法卡：前提假设-否定代入法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 前提假设-否定代入法 |
| 适用题型 | 判断推理-逻辑判断-前提假设类 |
| 触发场景 | 题目问"哪项是所需假设""哪项是前提"，选项难以直接判断时 |
| 步骤逻辑 | 1. 对选项做否定 2. 若否定后结论不成立→该选项是必要前提，可选 3. 若否定后结论仍可成立→该选项只是"有它更好"，不选 |
| 高频错因 | 把"有它更好"（加强题答案）当成前提假设答案；忽略前提假设选的是必要条件而非充分条件 |
| confidence | high |

## 补充说明

前提假设类的正确答案是必要条件，不是充分条件。否定代入法是验证手段：把选项否定后看结论还能不能成立。"没它不行"=必要条件=正确答案；"有它更好"=充分条件=一般加强题答案，不能选。

## 不适用条件

- 题型为削弱题、支持题或结论推出题，这些题型用各自的判断框架而非否定代入
- 选项本身是否命题或包含双重否定，直接否定后语义混乱导致无法判断是否动摇结论

## 反向触发

- 当否定一个选项后结论确实不成立，但还有另一个选项否定后结论也不成立时，不能同时选两个，应进一步比较哪个是更根本的隐含前提（搭桥优先于修补漏洞）
- 当否定选项后结论明显不成立，但该选项属于"所有情况下必须为真"的绝对命题时，要注意前提假设可以只是"部分情况下的必要条件"，不必是恒真命题
