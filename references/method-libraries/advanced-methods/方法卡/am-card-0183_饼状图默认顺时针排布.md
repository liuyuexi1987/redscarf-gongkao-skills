# 方法卡：饼状图默认顺时针排布

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 饼状图默认顺时针排布 |
| 适用题型 | 资料分析 — 饼状图题 |
| 触发场景 | 材料给出饼状图，需要判断各部分对应哪个扇区 |
| 步骤逻辑 | 1. 默认饼状图从12点钟方向开始，按顺时针排布；2. 按材料中各部分的出现顺序，依次对应顺时针扇区；3. 如果按此规则算出的数值与某选项吻合，则可确认；4. 出题严谨时该规则可靠；若算不出选项，再尝试其他排布 |
| 高频错因 | 不知道饼状图有默认排布规则，盲猜扇区对应关系忽略材料中各部分的排列顺序 |
| confidence | high |

## 不适用条件

1. 材料中的饼状图已经标注了各扇区名称或数据，无需推断排布
2. 出题不规范，扇区排布不遵循默认顺时针规则
3. 题目不涉及扇区与数据的对应关系判断

## 反向触发

- 材料给出饼状图且题干需要判断各部分对应哪个扇区，但饼状图未标注各部分名称
