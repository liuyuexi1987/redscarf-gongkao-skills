# 方法卡：语句填空四型判断法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 语句填空四型判断法 |
| 适用题型 | 言语理解——语句填空 |
| 触发场景 | 语句填空题，空格在不同位置 |
| 步骤逻辑 | ① 首句/中间句：可能对应主旨，也可能只是引出后文（主旨一般出在文言文题，不能望文生义）；② 尾句：可能是总结，也可能推对策（按一般人的想法来推，不能推太远）；③ 半句话：注意前后衔接，必要时用语法知识判断；④ 未必需要有主题词，可能进行同义替换 |
| 高频错因 | ① 首句直接当主旨→可能只是引出话题；② 尾句直接当总结→可能是推对策；③ 半句话不注意语法→主语混乱 |
| confidence | high |

## 补充说明
语句填空是"易学难精"的题型，因为命题人出题思路不稳定。四种位置有不同做法，没有万能方法。方法提醒：这类题没有万能方法。

## 不适用条件
- 文段为纯数据/图表类语句填空，无明显语义逻辑
- 空格位于并列结构内部，前后句式完全对称
- 题目要求选"不恰当"的表述（反向选择题）

## 反向触发
- 如果文段是中心理解题型（无空格），不应使用本方法
- 如果空格位置已明确且前后衔接清晰，无需四型逐一判断
