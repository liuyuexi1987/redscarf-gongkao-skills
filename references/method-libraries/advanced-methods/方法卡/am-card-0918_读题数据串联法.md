# 方法卡：读题数据串联法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 读题数据串联法 |
| 适用题型 | 经济利润·多步骤计算 |
| 触发场景 | 题目信息多、需要逐步推导的经济利润题 |
| 步骤逻辑 | 1. 读到"收入"和"利润"→立刻写：成本 = 收入 - 利润；2. 读到"单件成本"和"总成本"→算出总件数；3. 读到各天销量和售价→算出总收入；4. 读题时发现两个能凑在一起的数据，就立刻用掉，不要等读完全题；5. 关键原则：读到什么用什么，边读边写边算 |
| 高频错因 | 读完全部题目再回头找数据，浪费时间且容易遗漏 |
| confidence | high |

## 补充说明

这种"边读边用"的敏感性适用于所有数量关系题型。

## 不适用条件

- 题目条件之间存在强依赖（必须先用A算出B才能用C）时，边读边算易出现顺序错乱。
- 题目含陷阱条件（多余数据、干扰项）时，过早串联可能误用无关数据。
- 信息量极大且关系复杂的题目，需先整体梳理结构再下笔，避免边读边算导致返工。

## 反向触发

- 当串联后发现结果与选项差距较大，应回读题目核验是否误用了干扰数据。
- 当题目条件含"如果……否则……"分支语义时，应补充核验分支条件，不能机械串联。
- 当涉及多个主体（甲乙丙）且数据交错时，应换用列表/画图法整理后再计算。
