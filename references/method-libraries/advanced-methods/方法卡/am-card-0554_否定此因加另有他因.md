# 方法卡：否定此因加另有他因

| 字段 | 内容 |
|------|------|
| 方法名 | 否定此因加另有他因（因果削弱最强方式） |
| 适用题型 | 逻辑判断——削弱题（归因类） |
| 触发场景 | 题干归因A导致B，需找最能质疑该归因的选项 |
| 步骤逻辑 | 1. 识别题干因果：A（原因）→ B（结果） |
| | 2. 最强削弱 = 否定此因 + 另有他因：告知A不是真正原因，真正原因是C |
| | 3. 其次：举反例（A发生但B未发生，或非A但B仍发生）→力度较弱（因人而异） |
| | 4. 副作用选项（如"该方法有副作用"）：若题干结论是纯理论→无关；若结论是方法推广→弱削弱 |
| 高频错因 | ①选了举反例/三圈质疑而非否定此因（力度不够）②把副作用选项当最强削弱（力度弱，非核心逻辑） |
| confidence | high |

**补充说明：**
- 削弱力度排序：否定此因+另有他因 > 举反例/三圈质疑 > 副作用选项。
- 副作用选项辨析：纯理论结论（"某植物能治感冒"）下副作用=无关；方法推广结论（"应作为草药推广"）下副作用=弱削弱。
- 诉诸权威辨析：选项以"某专家/研究表明"开头，若后面带有逻辑推理则非诉诸权威；若仅靠权威背书无逻辑则为诉诸权威。

## 不适用条件

- 题干结论不涉及因果归因（如纯加强/削弱论证中的前提或例证题），此法不适用。
- 题目要求"最能支持/加强"该归因时，否定此因是削弱手段，不适用。
- 归因选项中的"他因"与原因之间存在因果包含关系（他因是原因的子原因或结果），不是独立他因，此法不适用。

## 反向触发

- 当选项同时包含"否定此因"和"另有他因"两个要素时，直接判定为最强削弱，无需再与举反例或三圈质疑比较。
- 当"否定此因+另有他因"选项存在但因果方向存疑时，优先核实时间一致性，避免将无关项误判为此法。
- 当所有削弱选项都是举反例或副作用、无"否定此因+另有他因"时，改用力度排序选最优（举反例 > 副作用）。
