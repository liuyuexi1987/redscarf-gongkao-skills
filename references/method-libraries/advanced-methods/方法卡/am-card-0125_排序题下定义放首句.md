# 方法卡：排序题下定义句放首句

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 排序题下定义句放首句 |
| 适用题型 | 言语理解-语句排序题 |
| 触发场景 | 语句排序题中出现含"是指""是……的""定义为"等下定义标志的句子 |
| 必要输入 | 各选项排列中，下定义句所在的位置 |
| 步骤逻辑 | 1. 在待排序句子中识别下定义句：含"XX是指……""XX是……的""定义为"等明确下定义标志的句子 2. 下定义句通常是定位线索，提示话题引入位置，但不自动等于首句或排除主旨 3. 对比各选项排列：下定义句未出现在合理靠前位置的选项优先排除 4. 剩余选项中再用其他排序手段（关联词、话题顺承等）进一步确定 |
| 验证动作 | 将下定义句放在首句后，检查后文是否能围绕该定义展开；若后文内容与定义的对象不相关，则该下定义句可能不是真正的首句 |
| 不适用条件 | 文段中无明确下定义句式时不适用；引用他人定义但该引用属于文段中部论据时，不作为首句判断依据 |
| 高频错因 | 凭语感或句子的"通顺感"将下定义句放在中间位置，忽略其话题引入功能 |
| 反向触发 | ①下定义句是引述他人定义作为论据（如"张教授认为……"），并非话题引入，此时不优先放首句，应看其前后文逻辑关系；②两个选项均将下定义句放在靠前位置但顺序不同，本法无法区分，需用关联词或话题顺承进一步定位；③文段无明显下定义句式但有背景引入或设问引入，应改用其他首句判断标准（如背景铺垫优先、设问句优先） |
| confidence | high |


> **使用边界**：本方法用于提供优先检查方向，不可单独据此作答；最终需回到题干关系、原文证据或选项条件完成验证。
