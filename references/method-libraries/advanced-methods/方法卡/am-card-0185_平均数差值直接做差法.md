# 方法卡：平均数差值直接做差法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 平均数差值直接做差法 |
| 适用题型 | 资料分析——平均数差值（求两年平均数之差的具体数值） |
| 触发场景 | 题干问"同比约减少/增加多少"（求具体差值而非比率），且两年的分子和分母数据均已知或可求 |
| 必要输入 | 两年各自的分子（如收入）和分母（如人次），共四个数据 |
| 步骤逻辑 | ① 判定题型：求A/B的差值→平均数差值；② 确认两年的分子和分母是否全部已知（或可通过前题结果求得）；③ 若全部已知，分别算出两年的平均数；④ 用今年平均数减去年平均数，直接做差；⑤ 注意量级还原（如分子为万亿元、分母为亿人次时，差值单位为元/人次） |
| 验证动作 | 用差值加回其中一个平均数，反推另一个平均数，检查是否与原文数据一致 |
| 不适用条件 | 两年中任一数据缺失且无法通过前题推导时，需改用比值差公式 |
| 高频错因 | 忽略量级换算（分子万亿元÷分母亿人次，差值单位是元/人次而非万元）；未利用前题已求结果导致数据缺失；选项首位看似差距大实则差距极小，误以为可估算 |
| confidence | high |
| 反向触发 | 两年平均数差值极小且与选项精度接近时，量级还原的微小误差可能跨越正确选项，应用比值差公式精确验算；题目问的是比率（增长率/变化幅度）而非具体数值时，应换用对应公式，本法不适用 |
