# 方法卡：直言命题范围速记

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 直言命题范围速记 |
| 适用题型 | 判断推理——集合推理题中快速判断命题间推理关系 |
| 触发场景 | 需要快速判断"有的A是B"能否推出其他结论 |
| 步骤逻辑 | ① 有的A是B ⟺ 有的B是A（等价，可互推）；② 所有A都是B → 有的A是B、有的B是A（可推出）；③ 所有A都是B ↛ 有的B不是A（不能推出，可能重合）；④ 有的A不是B ↛ 有的B不是A（不能推出，A可能包住B） |
| 高频错因 | ① 误以为"有的A不是B"可以推出"有的B不是A"；② 忘记"所有A都是B"时A和B可能完全重合；③ 将"有的"理解为"只有一部分"（逻辑中"有的"包含"全部"的情况） |
| confidence | high |
| 不适用条件 | 题目考的是假言命题（如果…则…）推理，而非直言命题（所有/有的）之间的关系。；题目要求判断命题真假值（给定已知条件问谁真谁假），而非判断命题间的推出关系。 |
| 反向触发 | 题目涉及充分条件或必要条件的推理方向（前推后/后推前），应转用假言推理规则；题目要求找矛盾命题或等价命题转换，应转用矛盾关系法 |

## 补充说明

逻辑中的"有的"="至少有一个"，包含全部都是的情况。不能用日常语感去理解"有的…不是"。记住：有的A是B和有的A不是B都无法互推，这是初学者最常犯的错误。
