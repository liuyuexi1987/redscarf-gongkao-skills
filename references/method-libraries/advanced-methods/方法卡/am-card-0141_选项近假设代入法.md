# 方法卡：选项近假设代入法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 选项近假设代入法 |
| 适用题型 | 资料分析·求基期/增量（候选值接近且代入误差可控） |
| 触发场景 | 求基期或增量时，选项中存在便于计算的候选值，可用反乘或迭代代入快速核验 |
| 步骤逻辑 | 1. 选择便于计算的候选基期 2. 用候选基期×实际增率估算增量 3. 用现期减增量得到回推基期 4. 比较回推值与候选值，并确认误差不会跨越相邻选项后作答 |
| 高频错因 | 误认为必须精算基期；不敢大胆假设；不先看选项就盲目直除 |
| confidence | high |

## 补充说明

原理是候选基期的偏差会按增率传递到回推结果。选取接近整千或易拆分的候选值可提高口算效率，但必须比较传播误差与选项间距；误差可能跨选项时，应改用精算或逐项反乘。

## 不适用条件

1. 选项差距明显且截位直除已经能快速区分时，无需假设代入
2. 候选偏差经增率传播后可能跨越选项时，假设代入可靠性不足
3. 当题目要求精确计算而非估算时，此法不适用

## 反向触发

1. 当增率较大且选项间距较小时，假设代入的误差可能跨越选项，应改用精算
2. 当增率含有小数且计算繁琐时，可换用假设分配法或截位直除法
