# 方法卡：主旨优先级法则

> 裁决：REWRITE_IN_PLACE
> 关联：am-card-0508（选项主干优先不抠字眼）、am-card-1057（不完美选项接受规则）

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 主旨优先级法则 |
| 适用题型 | 言语理解——中心理解题（通用原则） |
| 触发场景 | 一个选项主旨方向正确但有细节瑕疵（如用词略有差异），其他选项主旨方向完全错误（选了问题而非对策、选了背景而非观点） |
| 步骤逻辑 | ① 先判断各选项的主旨方向是否正确（是否在说对策/问题/观点）；② 主旨方向错误的选项没有资格与主旨方向正确的选项竞争，即使后者有小瑕疵；③ 主体、范围、方向和因果错误均属致命错误，不可当作小瑕疵；主旨已对时不纠结出处、用词等细节差异 |
| 验证动作 | 将选项代回文段检验：该选项是否在回应文段的核心观点/对策/问题，而非只匹配局部信息 |
| 不适用条件 | 资料分析或数量关系题需要用公式、数据和逻辑链复核，不用言语主旨优先级；题目不问中心、主旨或意图时，不因某选项"看起来更重要"套用本卡 |
| 高频错因 | 主旨方向正确但有小瑕疵的选项被排除，选了主旨方向完全错误的选项；过度纠结出处细节而忽略了主旨匹配 |
| confidence | high |
| 反向触发 | 所有选项的主旨方向均正确且无致命错误时，需回到文段逐项比对细节差异（出处、用词、范围）来区分，不能仅凭主旨方向做决定；若某选项的瑕疵涉及主体、范围或因果关系错误，该瑕疵已属致命错误而非小瑕疵，应直接排除而非接受 |

> **使用边界**：本方法用于提供优先检查方向，不可单独据此作答；最终需回到题干关系、原文证据或选项条件完成验证。
