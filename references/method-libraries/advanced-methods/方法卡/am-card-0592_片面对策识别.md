# 方法卡：谨防对策中的对策（片面对策）

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 谨防对策中的对策（片面对策） |
| 适用题型 | 言语理解——中心理解题（对策类文段，尤其文段含多个并列对策） |
| 触发场景 | 文段给出多个并列对策（如对策1+对策2），选项只选取其中一个对策进行了展开说明，或选项虽是对策但遗漏了部分对策主体 |
| 步骤逻辑 | ① 识别文段是否给出多个对策，标出对策1、对策2...；② 检查选项是否只展开了其中一个对策，若是则为"对策的对策"，片面；③ 正确选项应对所有对策进行概括，而非单独展开某一个 |
| 高频错因 | 选项把其中一个对策展开得很具体，看起来很"对应"文段，但实际上片面；误认为"展开得越具体越正确"；忽略了文段的另一部分对策 |
| confidence | high |

## 补充说明

片面对策识别关键：当文段给出多个并列对策（如对策1+对策2），选项只对其中一个对策进行展开说明（如把对策1展开为"如何做到对策1"类表述），即为片面展开。正确选项应使用概括性表述（如"如何..."类问句）覆盖所有对策并关联核心问题，而非单独展开某一个对策的执行细节。

区分原则：展开某一个对策=片面；概括所有对策并加上对应问题=全面。当选项把"做什么"展开成"怎么做"时，尤其需要警惕是否只覆盖了部分对策。

## 不适用条件

- 文段仅给出单一对策时不存在"片面"问题，无需用此法。
- 选项是对文段对策的直接转述（非展开式表述）时，不适用此法判断片面性。
- 文段为纯描述性或叙述性结构、无明确对策提出时，不适用此法。

## 反向触发

- 当文段多个对策之间为递进或条件关系（而非并列）时，应换用"递进抓最终对策"法，锁定文段最终落点对策。
- 当选项特征接近（全部展开或全部概括）难以区分片面性时，应回归主题词与对策主体的匹配关系进行核验。
- 当文段对策数量难以判断时，应先用关联词（既…又…/不仅…还…/一方面…一方面…）切分文段结构，再判断是否存在并列对策。
