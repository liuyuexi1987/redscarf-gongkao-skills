# 方法卡：盐水精算-假设分配求基期增量

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 盐水精算-假设分配求基期增量 |
| 适用题型 | 资料分析——盐水混合（已知城镇/农村增速求总体增速，或类似两部分混合求整体） |
| 触发场景 | ① 判定为盐水题型；② 居中、偏向或十字交叉仍无法区分相邻选项；③ 需要进一步精算 |
| 步骤逻辑 | ① 判定题型：给部分增速求整体增速→盐水；② 观察选项差距，若极小则排除估算路径；③ 对每个部分分别做假设分配，同时求出基期A和增量X；④ 总增量=X1+X2，总基期=A1+A2；⑤ 整体增速=总增量/总基期，精算首位锁定答案 |
| 高频错因 | ① 选项差距小却仍用现期替代估算，导致精度不够选错；② 假设分配后忘记还原量级（如19.3写成193未还原为23.5）；③ 第一题错导致第四题连环错 |
| confidence | high |

## 补充说明

盐水题应先用居中、偏向或十字交叉判断范围；这些方法不足以区分选项时，再用假设分配同时求基期和增量。是否进入精算取决于估算误差能否跨越选项，不设固定百分比门槛。

## 不适用条件

1. 居中、偏向或十字交叉已经能锁定唯一选项时，无需精算
2. 题目只给一个部分的增速和总体增速、求另一部分增速时，用十字交叉更直观，假设分配反而增加计算量
3. 基期量级不明或单位不统一时，假设分配容易在量级还原环节出错

## 反向触发

1. 当居中和偏向已能明确排除其余选项时，可保持估算路径，无需切换精算模式
2. 当假设分配过程中基期还原出现异常（如凑整后量级明显不对）时，应换用十字交叉或线段法验证
3. 当盐水混合涉及三个及以上部分时，两两假设分配的误差会累积，需额外核验或换用代数列式精算
