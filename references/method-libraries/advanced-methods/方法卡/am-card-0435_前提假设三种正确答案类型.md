# 方法卡：前提假设-三种正确答案类型

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 前提假设-断点搭桥/修补漏洞/必要条件 |
| 适用题型 | 判断推理-逻辑判断-前提假设类 |
| 触发场景 | 做前提假设题，需要快速锁定正确答案的方向 |
| 步骤逻辑 | 1. 先看论据和结论之间有没有逻辑断点→有则找"搭桥"选项 2. 没有断点但有漏洞→找"修补漏洞"选项 3. 逻辑很严密没有明显漏洞→到选项中找"必要条件" |
| 高频错因 | 题目无断点时仍然只找搭桥选项；漏看必要条件型答案 |
| confidence | high |

## 补充说明

三种正确答案类型有优先级：先看断点搭桥（论据结论间概念跳跃），再看修补漏洞（推理有缺口），最后才看必要条件（逻辑严密时选项提供隐含前提）。这个排查顺序能显著提高做题效率。

## 不适用条件

- 题型不是前提假设类（如削弱/支持/结论型），应使用对应题型的判断方法
- 论据和结论之间存在明显因果倒置或偷换概念，需要先排除这些结构错误而非直接找搭桥

## 反向触发

- 当"搭桥"选项在论据和结论之间搭建了概念跳跃，但否定该选项后结论依然成立，说明它不是必要前提，应转向检查是否有真正的必要条件型答案
- 当所有选项都不能同时修补论据到结论的逻辑断点，且选项中有"取非验证"后结论明显不成立的，应优先选该必要条件型选项，而非继续找搭桥
