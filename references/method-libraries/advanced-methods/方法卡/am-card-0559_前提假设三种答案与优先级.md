# 方法卡：前提假设三种答案与优先级

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 前提假设三种答案与优先级 |
| 适用题型 | 判断推理——前提假设类 |
| 触发场景 | 题目问"补充以下哪项前提""基于哪项假设"等 |
| 步骤逻辑 | ① 读完题干判断论据与论点是否有关联性；② 三种正确答案按优先级依次选择：断点搭桥（论据与论点无逻辑关联时，在两者之间搭桥）> 修补漏洞（论据论点看似有关联但暗含因果方向等漏洞时补上）> 必要条件（既无断点也无漏洞时，选"没有它一定不行"的选项）；③ 若三种同时出现，优先选搭桥 |
| 高频错因 | 选了普通支持而非必要前提；在有断点或漏洞时去选必要条件；纠结选项细节而忽略题型对应的答案模式 |
| confidence | high |

## 补充说明

三种正确答案的典型识别场景：
- **断点搭桥典型**：论据中的概念与结论中的概念之间无逻辑关联（如某类物质与某类地质现象无直接关联），需在两者之间搭桥建立形成机制上的联系。
- **修补漏洞典型**：论据与论点看似有关联，但暗含因果方向漏洞（如某因子是因还是果不明确），需补上排除反向因果的前提（如"结果不会反过来导致该因子升高"）。
- **必要条件典型**：论据论点无明显漏洞，需选取"没有它一定不行"的选项（如分配类论证中"每个对象都能被分到某一类别"作为前提）。

三种答案同时出现时，优先级为：断点搭桥 > 修补漏洞 > 必要条件。

## 不适用条件

- 题目问法为"加强/支持"而非"前提假设"时，不适用此优先级序列，应按加强削弱力度比较。
- 题干论据与论点既无断点也无漏洞且不依赖任何必要条件时，三种答案模式均不直接适用。
- 选项中不存在搭桥项时，不应强行套用"搭桥优先"，应退而选用修补漏洞或必要条件。

## 反向触发

- 当题干存在概念跳跃但选项中没有连接两端的项时，应换用"必要条件"法排查选项。
- 当题干存在因果方向漏洞但选项中无排除反向因果的项时，应换用"他因削弱"或"漏洞链条分析"法。
- 当三种典型答案均未出现时，应回头核验是否漏看了断点或漏洞，而非选择普通支持项。
