# 方法卡：语境解释对应法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 语境解释对应法 |
| 适用题型 | 逻辑填空——语境关系（解释对应） |
| 触发场景 | 空格前后有解释说明的内容（冒号后、破折号后、"即""也就是说""换言之"后的解释），且解释内容能确定空格的语义方向 |
| 步骤逻辑 | ① 找到空格前后的解释说明信号（冒号/破折号/即/也就是说/换言之/比如/例如）；② 提取解释内容的核心语义；③ 选与解释内容语义一致的选项；④ 如果解释内容是具体例子→选能概括例子的词 |
| 高频错因 | ① 忽略了解释信号词（特别是隐性的"这就是说"）；② 把举例说明当成并列关系，选了与例子同级的词而不是概括词 |
| confidence | high |

## 补充说明
解释对应是逻辑填空中最"友好"的语境关系——原文直接告诉你空格处应该填什么方向的词。关键是要识别出解释信号：显式信号（冒号、破折号、"即"）容易发现，隐性信号（"这""这种""这样的"指代前文）需要多练习。

## 不适用条件
- 空格前后无任何解释说明信号，无冒号/破折号/"即"/"也就是说"等标志。
- 解释内容过于抽象或泛化，无法确定空格的具体语义方向。
- 题目以搭配或感情色彩为核心考点而非解释关系。

## 反向触发
- 当无显式解释信号时，应换用语境对应分析法寻找隐性呼应词。
- 当解释内容无法锁定空格时，需补充搭配验证选词法或词义轻重排序法。
- 当解释内容为具体例子但无法概括时，应结合主题词排除验证法辅助判断。
