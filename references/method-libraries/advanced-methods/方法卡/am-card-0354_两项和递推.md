# 方法卡：两项和递推（爬楼梯模型）
## 基本信息
| 字段 | 值 |
|------|-----|
| 方法名 | 两项和递推（爬楼梯模型） |
| 适用题型 | 数量关系-排列组合/爬楼梯/路径方案 |
| 触发场景 | 每次走1步或2步，求到达第N步的方案数 |
| 步骤逻辑 | 1.确定初始值D1=1、D2=2 2.递推公式Dn=D(n-1)+D(n-2)（最后一步迈1阶=D(n-1)方案，迈2阶=D(n-2)方案） 3.逐项算到目标项即为答案 |
| 高频错因 | 初始值D2误算为1（正确应为2：走两次1步或一次2步）；若允许走1/2/3步则变成三项递推，误用两项递推 |
| confidence | high |
## 补充说明
本质是斐波那契数列。若条件改为每次走1/2/3步，递推变为三项和Dn=D(n-1)+D(n-2)+D(n-3)，此时D3=4（不是3）。核心逻辑：要走到第N级，要么先到N-1再迈1步，要么先到N-2再迈2步，两类方案互斥，直接相加。

## 不适用条件

- 步长不是1和2的组合，而是任意步长（如每次必须走3步），不满足两项递推结构
- 路径存在额外限制条件（如某些台阶不能踩、方向可回头），标准递推公式不适用
- 题目要求的是排列而非组合（顺序不同算不同方案时，递推关系会改变）

## 反向触发

- 当递推结果与选项全部不符时，应检查是否允许走3步（三项递推）或存在禁止台阶等额外约束
- 当初始值D1、D2代入后序列开头不对时，应回退审题确认步长组合和起点定义
