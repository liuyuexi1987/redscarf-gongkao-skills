# 方法卡：前提假设三优先级

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 前提假设三优先级 |
| 适用题型 | 前提假设题（"上述论证依赖的假设是"） |
| 触发场景 | 题干从论据推出结论但中间有断点或未排除的干扰变量，问需要什么前提才能成立 |
| 步骤逻辑 | ① 搭桥优先：论据和结论之间的概念有跳跃时，找连接两者的选项；② 修补漏洞次之：排除其他可能的干扰变量（如教育水平、上辅导班等）；③ 必要条件兜底：否定该选项后结论不成立；④ 纯支持选项（补充对比实验等）不能选，因为它游离于论证体系之外 |
| 高频错因 | 把前提假设题当支持题做，选了"补充正向论据"的选项；忽略了修补漏洞选项的"并不比…差很多"这类精确表述恰恰是正确答案的信号 |
| confidence | high |

## 补充说明

前提假设题中，他因方向选项（如兴趣差异、训练差异等）属削弱，应排除；纯支持选项（如补充正向对比实验）游离论证体系外，应排除；修补漏洞选项（排除他因差异）才是正确方向。"并不比…差很多"这类精确表述往往是出题人有意为之的信号。

## 不适用条件

- 题干问的是"最能支持/最能削弱"而非"依赖的假设是"时，不适用本方法，应按加强削弱题处理。
- 题干扰变量已被完全控制（如随机对照实验），不存在需要修补的漏洞时，搭桥和必要条件优先级降低。

## 反向触发

- 当题干论据与结论之间无明显概念跳跃，且无他因需排除时，应换用必要条件法（否定代入）逐一验证选项。
- 当选项中出现"既…又…"联合命题时，应补充核验两段命题是否都为结论成立所必需，避免选了半必要条件。
