# 方法卡：语境递进选词法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 语境递进选词法 |
| 适用题型 | 逻辑填空——语境关系（递进） |
| 触发场景 | 题目出现"甚至/更/而且/不仅…还/何况/况且"等递进关联词 |
| 步骤逻辑 | ① 找到递进词，确认递进方向（程度加深或范围扩大）；② 空格在递进后→选比前文程度更重/范围更广的词；③ 空格在递进前→选比后文程度更轻/范围更窄的词；④ 验证：代入后是否符合"由浅入深"或"由小到大"的递进逻辑 |
| 高频错因 | ① 把"甚至"当成"或者"（并列），忽略递进关系；② 选了与前文程度相当的词，没有体现递进的"更进一步" |
| confidence | high |

## 补充说明
递进关系要求后项在程度、范围或重要性上超过前项。常见陷阱：递进前后是同一方向但不同强度，不要选反义词。"不仅…而且"和"不但…反而"的递进方向不同，后者有转折意味。

## 不适用条件

1. 文段为转折结构（"但""然而"），递进法不适用，应换用语境转折选词法。
2. 文段为并列结构（"既…也""一方面…另一方面"），无程度差异，应改用并列选词法。
3. 空格前后缺乏明确的递进关联词，且语义上无法判断程度递增方向。

## 反向触发

1. 当题目出现"但""然而""却"等转折词时，应换用语境转折选词法，不可套用递进法。
2. 当题目为纯并列结构、无强弱梯度时，应换用并列同义选词法。
3. 当题目关联词为因果类（"因此""导致"）时，应换用语境因果选词法，递进原则不适用。
