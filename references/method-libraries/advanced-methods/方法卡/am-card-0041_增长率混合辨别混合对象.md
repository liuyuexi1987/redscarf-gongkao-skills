# 方法卡：增长率混合辨别混合对象
## 基本信息
| 字段 | 值 |
|------|-----|
| 方法名 | 增长率混合辨别混合对象 |
| 适用题型 | 数量关系-混合比例/增长率问题（咖啡豆、商品混合涨价等） |
| 触发场景 | 给出两部分各自的涨价/降价百分比和混合后整体涨幅，求质量比 |
| 步骤逻辑 | 1.明确混合的是什么——不是单价混合，是总额（单价×数量）混合；2.由于数量不变，单价增长率=总额增长率；3.将增长率视为利润率/浓度，用十字交叉法混合；4.十字交叉得到的分母之比=总额之比=（单价×数量）之比；5.由总额之比除以单价之比反求数量之比 |
| 高频错因 | 直接用单价增长率十字交叉而不考虑数量权重；搞混"总额之比"和"数量之比"的转换关系 |
| confidence | high |
## 补充说明
混合的基本模型：A/B与C/D混为(A+C)/(B+D)。当混合对象是"总额的增长率"时，由于数量不变，增长率就是总额增长率。十字交叉得到的是总额（基期）之比，即(单价×数量)之比。已知单价，可反推数量之比。例如甲60元/kg、乙80元/kg，总额之比2:1，则数量A:B=2/60:1/80=8:3。
## 不适用条件
- 混合过程中数量本身发生变化（如买入卖出调整仓位），不能假设"数量不变"从而简化为总额增长率混合。
- 两部分增长率为同一主体在不同时间段的增长率（连乘结构），非两个独立部分的混合。
- 增长率含负数且绝对值大于100%（如跌价超过原价），十字交叉结果无实际意义。
## 反向触发
- 题面描述两种商品价格混合（加权平均），无增长率字眼，属浓度/混合问题而非增长率混合。
- 连续两期增长率求总增长率（跨期增长率），是同一对象的时间序列，用跨期公式而非十字交叉。
