# 方法卡：幻方/九宫格——从未知数最少的行列入手

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 幻方/九宫格——从未知数最少的行列入手 |
| 适用题型 | 数量关系（幻方/九宫格填数） |
| 触发场景 | 九宫格中部分格子已知、部分未知，求某个未知数 |
| 步骤逻辑 | 1. 扫描所有行和列，找到未知数最少（最好是1个）的行或列；2. 从该行/列直接求出这个未知数；3. 如果两个待求未知数在同一行/列且共用一个未知变量，先不管共用变量，直接用行和=列和消去它；4. 逐步从已知数最多的行列向未知区域推进 |
| 高频错因 | 随意选位置入手导致需要解二元方程；没有利用"共用变量可消去"的特性 |
| confidence | medium |

## 不适用条件

- 所有行和列的未知数数量均≥2个、无"未知数最少"的入口时不适用此法。
- 题目未提供"行和=列和"或类似的等量关系约束时不适用此法。
- 题目要求填满全部格子而非求某个特定未知数时不适用此法（应换用系统填数法）。

## 反向触发

- 当多个行列未知数数量相同、无明显"最少"入口时，应换用"联立方程组"法统一求解。
- 当幻方含特殊约束（如对角线和、中心和等于某定值）时，应补充用对角线/中心特性进行核验。
- 当未知数之间存在倍数或比例关系而非简单加减关系时，应换用比例方程法求解。
