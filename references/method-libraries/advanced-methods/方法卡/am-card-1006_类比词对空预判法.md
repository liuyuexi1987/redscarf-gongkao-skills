# 方法卡：类比词对空预判法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 类比词对空预判法 |
| 适用题型 | 判断推理——类比推理 |
| 触发场景 | 拿到类比推理题第一步 |
| 步骤逻辑 | ① 两个词都是成语→大概率考语义关系；② 两个词都是名词且词性相同→大概率考集合关系（交叉/种属）；③ 前后词性不同→大概率考对应关系（属性/功能）；④ 两词→优先想因果；三词→优先想时间 |
| 高频错因 | ① 不先判断题型就开始乱猜关系→浪费时间；② 两词题想时间关系（概率低）→忽略了因果关系 |
| confidence | high |

## 补充说明
类比推理优先解决一级辨析（词项间基本关系），多数题目一级辨析即可定位答案。朴素理解原则：优先选最直觉的对应关系，避免过度解读。

## 不适用条件
- 词项关系已在题干中明确标注（无需预判）
- 三词题且明显考查时间顺序或其他特定关系

## 反向触发
- 预判关系验证失败→换用其他关系类型重新预判
- 选项间差异在二级辨析→补充二级辨析（命名方式、范围大小等）
