# 方法卡：逻辑优先于搭配

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 逻辑优先于搭配 |
| 适用题型 | 逻辑填空——通用原则 |
| 触发场景 | 逻辑对应和固定搭配指向不同选项时 |
| 步骤逻辑 | ① 先找逻辑对应点→确定空格的逻辑含义；② 逻辑能确定→可作为排除线索，不用管搭配；③ 逻辑不确定→再用搭配排除；④ 固定搭配是倾向而非铁律，类似意思的词也可以选 |
| 高频错因 | ① 只看搭配不看逻辑→选了搭配对但逻辑不对的词；② 过于拘泥固定搭配→忽略了逻辑更匹配的词 |
| confidence | high |

## 不适用条件

- 成语辨析题中若四个选项搭配全部正确、逻辑也全部正确时，本法无法区分，需改用语义轻重或感情色彩等其他维度
- 关联词填空题（如"不但…而且"vs"虽然…但是"）主要考关联词搭配的语法功能，逻辑优先原则的作用有限

## 反向触发

- 若逻辑对应点和固定搭配指向同一个选项，不存在冲突，无需调用本法的优先级判断
- 若空格前后文的逻辑关系无法确定（如文段本身逻辑不清），先标记待核验再决定是否用搭配做排除
