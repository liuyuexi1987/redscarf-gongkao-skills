# 方法卡：论点型加强削弱法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 论点型加强削弱法 |
| 适用题型 | 只有论点、无论据的加强削弱题（"有人认为…""专家指出…"） |
| 触发场景 | 题干只抛出一个观点/结论，没有给出论据 |
| 步骤逻辑 | 1. 先抓论点的主谓宾（主体是谁、结论是什么）；2. 削弱：找能让论点“不一定成立”或降低其可信度的选项；3. 加强：找能提高论点可信度的直接论据；4. 关键：选项必须作用于同一论点，不能只与话题相关 |
| 高频错因 | 选项讨论的对象与论点不一致（如论点说"我国"，选项说"欧盟国家"）；把"没有覆盖全部"等同于"没有保护作用" |
| confidence | high |

## 不适用条件

- 题干有明确论据的论证型题目（需用搭桥/拆桥法）
- 逻辑型论证题（涉及假言命题、三段论等）

## 反向触发

- 题干给出"因为…所以…"或"研究表明…因此…"等论据+论点结构
- 题目涉及前提假设而非单纯观点判断

## 补充说明

方法强调"有和没有"与"多和少"是两种不同的概念。论点讨论的是"有没有保护作用"，ABC选项讨论的是"保护作用有多大"——这是偷换概念。
