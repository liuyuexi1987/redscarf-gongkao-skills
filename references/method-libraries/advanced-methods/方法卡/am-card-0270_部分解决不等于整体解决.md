# 方法卡：部分解决不等于整体解决（以偏概全削弱法）

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 部分解决不等于整体解决（以偏概全削弱法） |
| 适用题型 | 论证题（削弱），结论为"X是解决Y的重要途径" |
| 触发场景 | 题干背景给出Y由多个来源构成（如工业+生活），结论只针对其中一个来源提出解决方案 |
| 步骤逻辑 | 1. 看清论证链条：问题Y = 来源A + 来源B + ...；2. 结论只解决了来源A（如生活固废），就声称能解决整体问题Y；3. 削弱方向：来源A占整体的比例很小，即使全部解决也解决不了Y；4. 选项出现"XX主要由其他来源引起，本来源威胁较小"→直击占比问题→有效削弱 |
| 高频错因 | 看到"并非所有地区都适用"就选，但"有些不行"范围不明，无法确定整体是否受大影响；看到结论有"重要"二字就纠结，忽略题干背景已暗示占比关系 |

## 不适用条件

1. 结论已明确限定为"解决部分问题"而非声称解决整体问题，不存在以偏概全
2. 题干背景未提供多个来源的构成信息，无法判断占比
3. 选项中出现直接否定因果关系的削弱（如"X根本无法解决来源A"），力度比占比质疑更强

## 反向触发

1. 当结论使用"完全解决"等绝对表述时，应换用"绝对化表述"的削弱方式
2. 当题干问题只由单一来源构成时，以偏概全框架不适用，需换用其他削弱策略
3. 当剩余选项中有直接否定因果关系的项时，优先选择该项而非占比质疑
