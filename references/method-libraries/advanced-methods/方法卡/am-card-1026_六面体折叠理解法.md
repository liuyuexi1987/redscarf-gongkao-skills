# 方法卡：六面体折叠理解法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 六面体折叠理解法 |
| 适用题型 | 判断推理——图形推理（六面体折叠） |
| 触发场景 | 六面体折叠/展开图题 |
| 步骤逻辑 | ① 不要死记标点法/箭头法→要理解实际怎么折成的；② 确定每个面的相对位置（对面/相邻）；③ 如果空间想象不行→自己裁纸折一下；④ 买积木从各角度观察练习空间想象能力 |
| 高频错因 | ① 死记方法不理解→变形题就不会做；② 空间想象力不足→需要实际动手练习 |
| confidence | medium |

## 补充说明
六面体折叠的核心是理解而非死记。标点法/箭头法是工具，但底层是理解"哪两个面相对、哪几个面相邻"。轮廓题还要注意"实际摆放可能性"（重心、物理可行性）。

## 相对面排除

1. 先在展开图中标出三组相对面，不只凭折叠后的直觉判断。
2. 立体图中能同时看见的面必然相邻；选项若让一组相对面同时可见，直接排除。
3. 排除对面冲突后，再验证相邻面的公共边和方向，避免只靠一条规则强行选答案。

## 不适用条件

1. 非六面体折叠题（如平面图形拼接、立体剖面）时。
2. 题目考查视图而非折叠关系时。
3. 展开图过于复杂无法快速标定相对面时。

## 反向触发

1. 当理解法难以判断空间关系时，应补充使用标点法/箭头法核验。
2. 当相对面排除后仍有多个选项时，应换用相邻面公共边方向验证。
3. 当选项涉及轮廓摆放时，应补充核验物理可行性与重心。
