# 方法卡：拆桥识别——实验样本/工具不具代表性

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 拆桥识别——实验样本/工具不具代表性 |
| 适用题型 | 削弱/质疑题（逻辑判断） |
| 触发场景 | 题干通过某种实验/调查得出结论，但实验样本或工具可能不具代表性 |
| 步骤逻辑 | 1. 识别题干的实验方法：用了什么样本、什么工具、什么测量方式；2. 检查选项是否质疑了样本/工具的代表性；3. 若选项说"所选样本/工具不具代表性"→ 直接拆桥（实验→结论的桥梁断裂）；4. 拆桥类削弱力度通常很强（仅次于因果倒置）；5. 注意区分"全部不具代表性"（强拆桥）vs "部分不具代表性"（举例，力度弱） |
| 高频错因 | 只关注选项结论方向，不检查实验方法本身的有效性把"有些军事迷也未识别"（举例/部分）等同于"20种都不具代表性"（全面拆桥） |
| confidence | high |

## 补充说明

- 当选项指出"全部样本/工具都不具代表性"→全面拆桥，力度很强（仅次于因果倒置）。
- 当选项只说"部分样本也有类似情况"→举例削弱，只涉及部分，力度弱于全面拆桥。
- 全面拆桥 > 部分拆桥/举例，因为前者否定整个实验方法的有效性，后者只削弱个别样本。

## 不适用条件

- 题干论证不依赖实验/调查/样本（如纯形式逻辑或日常因果推理），代表性拆桥不适用。
- 选项质疑的是实验结果本身（如数据造假）而非样本/工具的代表性，不属于拆桥类。
- 题目要求"最能支持/加强"时，拆桥是削弱手段，不适用。

## 反向触发

- 当存在因果倒置选项时，因果倒置力度通常强于拆桥，优先选因果倒置。
- 当选项只质疑部分样本时，注意区分全面拆桥与举例削弱——全面拆桥优先。
- 当题干未描述具体实验方法、只给出因果结论时，拆桥无着力点，改用其他削弱方法。
