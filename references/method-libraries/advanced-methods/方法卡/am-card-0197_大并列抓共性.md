# 方法卡：大并列抓共性

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 大并列抓共性 |
| 适用题型 | 中心理解 |
| 触发场景 | 文段为大并列结构（三个或以上分句并列，含"同时""此外""此外"等标志），无总句 |
| 步骤逻辑 | 1. 判断文段为大并列结构；2. 从各分句中提炼共同话题/共性；3. 选择能涵盖所有分句共性的选项；4. 排除只对应某一分句的"片面"选项 |
| 高频错因 | 选了只对应分句一或分句三的片面选项 |
| confidence | high |

## 不适用条件

1. 文段有明确的总结句，可直接选总结句对应的选项
2. 文段不是并列结构（如转折、递进、总分）
3. 并列分句数量不足三个，共性提炼意义不大

## 反向触发

- 文段有三个或以上分句并列且无总结句，选项中有需要选择涵盖所有分句共性的表述
