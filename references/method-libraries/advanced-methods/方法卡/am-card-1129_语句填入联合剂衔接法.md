# 方法卡：语句填入联合剂衔接法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 语句填入联合剂衔接法 |
| 适用题型 | 言语理解——语句填入（横线在中间） |
| 触发场景 | 语句填入题中横线在文段中间，需要承上启下时 |
| 步骤逻辑 | ① 识别位置：横线在中间→起"联合剂"作用；② 分析上文：上文讲了什么论述方向/核心内容；③ 分析下文：下文讲了什么论述方向/核心内容；④ 选答案：必须同时衔接上文+开启下文，缺一不可 |
| 高频错因 | ① 只衔接上文不看下文→选了只总结前半段的选项；② 只看下文忽略上文→选了与前文无关的选项；③ 被"看起来通顺"的选项带走→没有检查是否真正连接了上下文 |
| confidence | high |

## 方法说明

语句填入横线在中间时，该句的作用是"联合剂"——把上文和下文粘合在一起。

**核心原则**：
- 上文讲什么方向，横线处必须衔接这个方向
- 下文讲什么方向，横线处必须开启这个方向
- 两个方向都必须兼顾，缺一不可

**解题流程**：
1. 先看上文的核心内容是什么（话题、论述方向）
2. 再看下文的核心内容是什么（话题、论述方向）
3. 找一个选项同时满足：①衔接上文 ②开启下文

**典型应用模式**：
- 上文若讨论某类具体对象（如某类文化符号/历史地标），下文若转向该对象的抽象意义（如象征性、精神价值），横线处须同时承接"具体对象描述"并开启"抽象意义阐述"
- 干扰选项常见模式：只谈上文未涉及的话题方向，或只重复下文已展开的内容而不真正开启下文

**特殊情况**：
- 上下文之间可能缺一个"桥"（如：上文说"要增添"，下文说"善于借用"→中间缺"有"这个桥）
- 此时要补上这个逻辑缺口

## 使用边界

- 适用于横线在中间的语句填入题
- 横线在开头时用"总结全文"法（见0411）
- 横线在结尾时用"总结全文/衔接上文/提对策"法
- 不适用于：逻辑填空（词语填空）

## 不适用条件

1. 横线在开头时，没有上文可承接，应改用话题引入、下文预告和首句功能核验。
2. 横线在结尾时，没有下文可开启，应改用总结、对策、结论或话题收束功能核验。
3. 逻辑填空题（词语填空，本方法不适用）

## 反向触发

1. 上下文方向均明确但无选项同时满足时，应补充核验是否需要补"桥"（逻辑缺口）
2. 上下文论述方向相近易混淆时，应回到上文具体话题和下文具体话题分别锚定
3. 干扰选项看起来通顺但与上下文方向不完全匹配时，应核验每个选项对上下文的覆盖度

## 复盘沉淀

用户错完后应该沉淀：
1. 自己是只看了上文还是只看了下文
2. 正确选项是如何同时衔接上下文的
3. 干扰选项分别遗漏了哪个方向
4. 该题上下文之间的逻辑关系类型
