# 方法卡：语句填入总括性

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 语句填入总括性 |
| 适用题型 | 语句填入题 |
| 触发场景 | 空格后面的文段出现"一方面…另一方面""同时"等并列结构 |
| 步骤逻辑 | 1. 识别空格后是否有并列展开（一方面/另一方面/同时/以及）；2. 读完并列的各部分内容，提炼它们的共同主语和共同问题；3. 填入的句子必须对后面的并列内容具有总括性；4. 主语要与并列项的实际主语一致（不是前面段落的主语）；5. 从结构和语义两个维度匹配，语感"读得通"不等于最优 |
| 高频错因 | 靠语感代入，觉得每句话都"读得通"就选了主语对不上（如并列项主语是"审核部门"，选项主语却是"干部"）选了一个没有概括性的选项（虽然读得通但不能总括并列内容） |
| confidence | high |

## 不适用条件

1. 空格后无并列结构（无"一方面/另一方面/同时"等标志词），而是递进或转折关系——总括性判断不适用，需按对应结构类型判断。
2. 空格在文段末尾，需要的是总结归纳而非总括引领——末尾空格应从前文内容归纳主旨。
3. 并列项之间存在明显的对比或转折关系（如"而/却"），不是真正的并列展开——对比关系不能简单总括。

## 反向触发

1. 空格后虽有"一方面…另一方面"，但实际是对同一观点的正反论证（不是并列展开不同方面），总括方向不同。
2. 并列项的主语各不相同且无共同主题，无法提炼出有效的总括句——此时应考虑其他判断维度。
3. 空格位于句中而非句首，填入内容是衔接而非总括——句中空格优先看前后句逻辑关系。
