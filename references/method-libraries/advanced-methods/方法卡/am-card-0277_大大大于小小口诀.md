# 方法卡：大大大于小小口诀

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 大大大于小小口诀 |
| 适用题型 | 人口/数量交叉分类比较题 |
| 触发场景 | 题干给出两个维度的分类（如本地/外地、男/女）并问交叉比较大小 |
| 步骤逻辑 | 1. 识别两个分类维度，各维度中较大的一方标记"大"；2. 口诀：大大大于小小——较大维度中的较大部分 > 较小维度中的较小部分；3. 例如本地>外地、男>女，则本地男 > 外地女；4. 若记不住口诀，画表格列方程：设本地男=X，即可推出各交叉项 |
| 高频错因 | 凭直觉猜大小关系而非用口诀或列方程验证 |
| 不适用条件 | 题干不涉及两个维度的交叉分类比较（如单一维度排序）；各维度内部数量关系未知或无法确定大小 |
| 反向触发 | 题目只要求排序一维数据或求绝对数值，不涉及交叉比较大小关系 |
| confidence | high |
