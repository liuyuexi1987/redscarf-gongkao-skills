# 方法卡：间隔增长率逆运用

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 间隔增长率逆运用 |
| 适用题型 | 资料分析——已知整体间隔增长率和其中一段，求另一段增长率 |
| 触发场景 | 材料给的是某量同比增速和较早年份的总增速（如"21年比19年增长16%，21年同比增24%"），求中间年份增速 |
| 步骤逻辑 | ① 画三时间点图；② 已知R整体和R1（或R2），套公式列方程；③ 移项求未知R；④ 用"拖后腿"直觉验证符号：整体增速 < 已知段增速→未知段必为负 |
| 高频错因 | 忽略R1×R2项导致符号判断错误；把24%当成1/4时需注意方向（估大则结果偏小需补偿） |
| confidence | medium |

## 补充说明

快速判断法：整体增速小于已知段增速时，未知段必为负（已知段在"拖后腿"），且数值比两者之差的绝对值稍小（因为还有符号为负的乘积项）。反之，整体增速大于已知段增速时，未知段为正且数值稍大于两者之差。当估算误差可能跨越选项或改变结论时，改用精算/验证。

## 不适用条件

1. 材料只给出整体间隔增长率，两段增速均未知，无法通过单一方程求解两个未知数。
2. R1和R2的乘积项不可忽略时（如两段增速均较大或一正一负绝对值大），简化移项可能产生明显误差。
3. 问题要求的是同比增速（非间隔增速的逆推），公式语境不匹配。

## 反向触发

1. 整体增速16%、已知段24%，未知段求出正值，说明忽略了"拖后腿"导致整体低于已知段的逻辑。
2. 直接用|整体-已知段|作为答案，忽略了R1×R2乘积项对结果的微调。
