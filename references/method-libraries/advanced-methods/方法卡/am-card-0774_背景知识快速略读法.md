# 方法卡：背景知识快速略读法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 背景知识快速略读法 |
| 适用题型 | 片段阅读-中心理解题 |
| 触发场景 | 文段前半部分出现大量专业术语/背景知识，读不懂 |
| 步骤逻辑 | 1. 看到前面非常专业的内容，快速判断为"背景知识铺垫"；2. 背景知识的作用是让读者理解后文，本身不是重点；3. 快速略过背景，跳到后文找新研究/新发现/正文结论；4. 常见结构：背景铺垫 → 研究团队发现 → 新结论（这才是重点） |
| 高频错因 | 陷在专业背景里纠结，浪费时间；或把背景知识当主旨选了 |
| confidence | medium |

## 不适用条件

1. 全文均为背景知识介绍，无后续新结论或新发现
2. 背景知识本身即为文段主旨，题目考查的正是该知识内容
3. 题目明确要求细节理解，需要在背景部分定位答案

## 反向触发

1. 背景知识段落之后未出现转折或新发现，后文仍在延续同一话题
2. 选项内容集中在前半段的专业术语或背景事实上
3. 文段为总分结构，背景知识本身就是总括句的展开
