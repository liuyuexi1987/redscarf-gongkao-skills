# 方法卡：百化分份数法求增量

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 百化分份数法求增量 |
| 适用题型 | 资料分析——增率接近常见分数（如1/5、1/7、1/8等）时求增量或基期 |
| 触发场景 | 增率可近似为某个简单分数（如19.6%≈1/5、14.3%≈1/7、12.5%≈1/8） |
| 步骤逻辑 | ①把增率化为分数形式→②直接得出基期:增量:现期的份数比（分母为1/n→基期:增量:现期=n:1:(n+1)）→③用已知的现期或基期数值除以对应份数得单位值→④乘以增量份数得增量 |
| 高频错因 | 增率不接近常见分数时强用此法导致误差过大；对份数对应关系记混（基期对应分母、增量对应分子1、现期对应分母+1） |
| confidence | high |

## 补充说明

百化分核心：增率接近常见分数时直接建立份数比。增率约1/7→基期:增量:现期=7:1:8，用现期÷8得增量；增率约1/5→基期:增量:现期=5:1:6，用现期÷6得增量。常见对应包括25%=1/4、约33.3%=1/3、12.5%=1/8。此法可同时辅助求基期和增量，但最终精度要结合选项差距核验。

## 不适用条件

- 增率不接近任何常见分数（如17.3%难以近似为简单分数），强用此法误差过大
- 需要精确到小数点后两位的计算，份数法为估算方法
- 增率为负值（下降率）时，份数比需调整符号，容易混淆

## 反向触发

- 当增率在两个常见分数之间且选项差距很小时，应切换为精算直除
- 当题目只求增量不求基期且选项首位不同时，截位直除可能更快
- 当份数近似不便口算或近似误差可能影响选项时，考虑用增长率公式直接算
