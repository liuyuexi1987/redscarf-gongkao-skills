# 方法卡：基期比重公式

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 基期比重公式 |
| 适用题型 | 资料分析 - 求基期某部分占总体的比重 |
| 触发场景 | 题目问"XX年A占B的比重"，但数据是当年的产量/销量和增速 |
| 步骤逻辑 | 1. 基期比重 = (A/B) × (1+Rb)/(1+Ra)；2. 其中Ra为A的增速，Rb为B的增速；3. 可做拆分或放缩简化：先算A/B（现期比重），再乘修正系数；4. 修正系数约等于 1+(Rb-Ra)，当增速接近时可忽略 |
| 高频错因 | 直接拿现期比重当基期比重；忘记增速是同比还是环比导致用错R值；搞混分子分母的增速方向 |
| confidence | high |

## 不适用条件

- 只求普通增长率、增长量或基期量，没有”部分占总体的比重”问法时，不使用基期比重公式。
- 题目问现期比重时，直接用现期部分量除以现期总体量，不额外乘增速修正系数。

## 反向触发

- 材料直接给出了基期部分量和基期总量，可直接相除得到基期比重，无需用公式推算。
- 题目问的是现期比重或比重变化量（百分点），而非基期比重。
- 两个量没有部分-整体的比重关系（如两个独立指标的比较），不能套用基期比重公式。
