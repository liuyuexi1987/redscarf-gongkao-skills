# 方法卡：效率比→时间比反推法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 效率比→时间比反推法 |
| 适用题型 | 工程问题·多人合作 |
| 触发场景 | 已知各人单独完成时间，求合作时间或某人工作天数 |
| 步骤逻辑 | 1. 由单独完成时间→效率比（时间比的反比）；2. 赋值效率（如甲30天乙25天→时间比6:5→效率比5:6→赋值甲效率5乙效率6）；3. 工程总量 = 效率 × 时间 = 5×30 = 150（或找公倍数）；4. 合作时间 = 工程总量 ÷ 效率之和 |
| 高频错因 | 效率比和时间比搞反 |
| confidence | high |

## 补充说明

边读边写，读到单独完成时间就立刻写出效率比，可快速进入计算。

## 不适用条件

- 效率随时间变化（如疲劳、提速）时，固定效率比前提不成立。
- 中途有人加入或退出时，合作效率需分段计算，不能整体套用效率比。
- 题目给的是"完成工作量"而非"完成时间"时，需先换算为时间，多一步转换易出错。

## 反向触发

- 当赋值效率后算出的工程总量与题目其他条件矛盾时，应反向核验效率比方向是否搞反。
- 当合作时间算出非整数且与选项无法匹配时，应补充核验工程总量是否取了正确公倍数。
- 当题目含"轮班""交替"等非同时工作语义时，应换用分阶段列式法。
