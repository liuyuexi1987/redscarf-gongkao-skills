# 方法卡：说理类对策优先法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 说理类对策优先法 |
| 适用题型 | 言语理解——主旨概括/意图判断（说理类文段） |
| 触发场景 | 文段属于说理类（作者在表达观点、提出问题、论述道理），出现"对策"和"问题概括"两个选项时 |
| 步骤逻辑 | ① 判断文段类型是否为说理类；② 原文有对策→一定选对策选项；③ 原文只有问题没有对策→问题概括和对策选项都可能对，无优先级；④ 二选一时，盯着两个选项看，找有毛病的那个排除——可能问题概括不准确，或对策过度推断 |
| 高频错因 | 原文没对策时强行优选对策；对策选项过度推断（如"应该更努力"变成"应该报班"）仍选它；问题概括选项的主语或范围有偏差但未察觉 |
| confidence | medium |
| 不适用条件 | 1. 科普介绍类、纯新闻报道类文段——应选客观概括，不选对策
| 反向触发 | 1. 文段属于纯介绍/说明性质，作者无意提建议——应回归客观概括
2. 对策选项推断过度，超出原文提到的问题范围——排除该对策选项
3. 原文有问题也有结论但结论不是对策（如因果总结）——应选结论概括而非对策 |
2. 文段是并列结构且无明确观点倾向——应选全面概括项
3. 选项中无对策类选项或无问题概括类选项——二选一前提不成立，此法不适用 |

## 补充说明

- 科普介绍类文段不适用此法，应选客观概括，不选对策。
- 新闻类注重"新"。
- 对策选项的逆推检查：把选项当标题，想原文会怎么写，若写不出来则选项有问题。
- "同学们应该更加努力"可接受，"应该报一个班"属过度推断——对策必须针对原文提到的问题。
