# 方法卡：比重趋势逆用-增速排序

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 比重趋势逆用-增速排序 |
| 适用题型 | 资料分析——给定各部分占比变化方向，反推增速排序或比较大小 |
| 触发场景 | 题干给出"某部分占比同比提高/下降"，需要判断各部分增速相对大小或排序 |
| 步骤逻辑 | ① 核心原理：占比提高→该部分增速R1 > 总体增速R2；占比下降→R1 < R2；② 若A占比提高、B占比下降，则 R_A > R_总 > R_B，即R_A > R_B；③ 结合此排序直接判断选项中增速大小关系，无需实际计算增速 |
| 高频错因 | ① 混淆方向：占比提高是R1>R2而非R1>R_其他部分；② 忽略"占比提高"只能得到与总体的比较，不能直接得出两部分间的精确倍数关系 |
| confidence | high |

## 不适用条件

1. 题目只要求判断比重变化方向，不需要反推增速关系
2. 材料中各部分的占比变化方向信息不完整

## 反向触发

- 题干给出"某部分占比同比提高/下降"且需要判断各部分增速相对大小或排序

## 补充说明

此法是比重差公式的逆运用。正向是已知增速求比重变化方向，逆向是已知比重变化方向推增速关系。在综合分析题中尤其高效，一条"占比提高/降低"的描述就能锁定两个增速的大小关系，用于排除选项。
