# 方法卡：月均增长计算

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 月均增长计算 |
| 适用题型 | 资料分析——月均增长量/月均增速 |
| 触发场景 | 题目问"从M月到N月的月均增长量" |
| 步骤逻辑 | ① 确定基期月份值和现期月份值；② 计算总增量=现期值-基期值；③ 数清楚月数（从基期到现期涨了几次，注意柱状图数量≠涨的次数）；④ 月均增量=总增量÷月数 |
| 高频错因 | ① 把柱子数量当成涨的次数（有N根柱子只涨了N-1次）；② 前推月份时搞混基期（如江苏从6月推到5月，但年数要从5月开始数）；③ 误以为月均增长是同比增量的月平均值 |
| confidence | high |

## 补充说明

月均增长本质是环比增量的平均数，与年均增长逻辑一致，只是时间单位从"年"变成"月"。真题中月均增长均为环比含义，未出现同比月平均的考法。

## 不适用条件

1. 题目问的是同比月均增长（即每个月的同比增速取平均），此方法不直接适用，需按同比口径分别计算。
2. 增长基数为零或负值时，月均增长量仍可计算，但解读含义不同，需结合题意判断是否合理。

## 反向触发

1. 当题目给的是"月均增长率"而非"月均增长量"时，应换用年均增长率公式（末期/初期）^（1/月数）-1。
2. 当柱状图中月份不连续或存在缺失时，需先确认实际有效月数，不能简单用柱子数量推算。
