# 方法卡：比重趋势多步推基期

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 比重趋势多步推基期 |
| 适用题型 | 资料分析——已知本期比重值和R1/R2，判断基期（去年/上月）比重的大小范围 |
| 触发场景 | 材料给了本期比重的具体数值，选项是基期比重的不同数值（如"3月份占比""去年占比"），需通过趋势推断基期落在哪一侧 |
| 步骤逻辑 | ① 找R1（分子增长率）和R2（分母增长率），判断比重上升还是下降；② 若比重上升，说明本期比重 > 基期比重 → 基期比重 = 本期值"减"（即比本期小）；③ 若比重下降，说明本期比重 < 基期比重 → 基期比重 = 本期值"加"（即比本期大）；④ 根据加减方向排除选项 |
| 高频错因 | ① 上升/下降方向搞反：比重上升了到71%，基期应该不到71%而非超过；② 误用同比增速替代环比增速（若题问"比上月"则应用环比）；③ 找错R1/R2对应指标 |
| confidence | medium |

## 补充说明

这是"两期比重趋势判断"的进阶用法，本质只是在趋势判断基础上多推一步。类比：某人体重先升后现在是某值，那过去一定比现在更轻；反之先降则过去更重。比重上升才到了当前值，所以基期更小；比重下降则基期更大。此方法常见于多类别对比题（如轿车/SUV/MPV各占乘用车比重，东中西部各占全国比重），可同时判断多个部分的基期大小关系。注意区分环比与同比：题目要求"比上月"时用环比增长率。

## 速算边界

当估算误差可能跨越选项或改变结论时，改用精算/验证。

## 不适用条件

- 题目给出了本期比重的具体数值且选项差距极小，趋势判断只能定方向不能定量，需配合比重差公式精算。
- R1和R2非常接近（如相差不到0.5个百分点），趋势方向不确定时，不能仅靠趋势排除选项。

## 反向触发

- 选项给的是具体百分点变化量而非比重数值，应走"比重差识别与速解"卡。
- 题目没有给出本期比重的具体数值，无法通过趋势反推基期数值范围。
