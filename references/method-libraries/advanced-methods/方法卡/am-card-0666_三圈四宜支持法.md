# 方法卡：三圈四宜支持法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 三圈四宜支持法 |
| 适用题型 | 归因论证中对比实验不完整的支持题 |
| 触发场景 | - 题干实验缺对照组或实验不完整
- 题干是纵向比较（跟自己过去比），选项应为横向（跟别人比）
- 需要补充实验使其完整 |
| 步骤逻辑 | 1. 三圈质疑：同因异果（共同原因→不同结果，说明原因不对）、异因同果（不同原因→共同结果，说明结果另有共同原因）；2. 四宜支持（因一果支持）：题干只有实验组缺对照组，从选项中找出对照组补上；3. 支持选项没有选题干已有的内容 |
| 高频错因 | 分不清"同因异果"和"异因同果"的逻辑方向在已有对照组时还去找对照组 |
| confidence | medium |

## 补充说明

"三圈"指三种归因质疑模式中的否定方向（同因异果、异因同果），"四宜"指支持方向——当实验不完整时，补充缺失的对照组。同因异果指共同原因却产生不同结果，说明所归原因不成立；异因同果指不同原因却产生共同结果，说明结果另有共同原因。支持方向的关键是补上题干缺失的对照组，使对比实验结构完整。

## 不适用条件

- 题干已具备完整对照组时，不应再补对照组，应改用排除他因或解释说明类支持。
- 非归因论证类题目（如纯形式逻辑翻译题）不适用本方法。

## 反向触发

- 当实验结构已完整、缺口在因果链解释而非对照组时，应换用断点搭桥或增加正向论据法。
- 当题干为横向比较而选项误给纵向比较时，应核验比较方向是否匹配而非强行补组。
