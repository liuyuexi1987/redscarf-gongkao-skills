# 方法卡：图推对称与位置关系特征触发法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 图推对称与位置关系特征触发法 |
| 适用题型 | 判断推理——图形推理 |
| 触发场景 | 图形呈现明显的对称特征（工整对仗）、相同位置有相同线条、或图中有重复出现的提示元素 |
| 步骤逻辑 | ① 识别对称特征：轴对称（沿某条线折叠重合）→ 中心对称（绕某点旋转180°重合）→ 既有轴对称又有中心对称；② 对称性优先级：先判断对称类型 → 画出所有对称轴/标出对称中心 → 看对称轴数量、方向、角度变化规律；③ 相同位置有相同线条：各图轮廓可能不同，但相同位置有相同的线条部分 → 核心考点是这些相同线条的规律（数量、位置、与其余部分的关系）；④ 提示图形：各图中都有相同的元素（如都有一个圆圈、都有两个黑点）→ 提示元素本身不是考点，围绕提示元素的变化才是考点；⑤ 对称轴方向规律：对称轴可能按固定角度旋转（如每次顺时针旋转45°） |
| 高频错因 | ① 看到对称就只判断"有没有对称"，不画对称轴找数量/方向规律；② 相同位置有相同线条时，只看相同部分忽略不同部分的变化规律；③ 提示图形题中被提示元素干扰，忽略围绕提示元素的真正考点；④ 中心对称和轴对称混淆，不区分判断方法 |
| confidence | high |

## 补充说明

**对称性的核心判断：** "万物皆可考对称"——任何图形都可以设计成对称图形。当一组图整体工整对仗时，优先考虑对称性。做法：画出所有对称轴，看对称轴数量是否恒定、方向是否旋转、角度是否有规律。轴对称用"折叠法"判断，中心对称用"旋转180°法"判断。

**相同位置有相同线条的触发逻辑：** 当各图轮廓不同，但某些位置的线条完全相同时，触发此判断。这类题的核心不是看相同的部分，而是看相同部分之外的变化。相同线条可能是"骨架"，变化围绕骨架展开。

**提示图形的触发逻辑：** 当各图中都有相同的元素（如圆圈、黑点、小图形）时，触发此判断。提示元素是考官给的"福利"，它本身不是考点，但它提供了观察的锚点。围绕提示元素的变化：提示元素的数量、位置、与其余元素的关系。

**与已有卡的关系：** am-card-1062（对称轴旋转规律）侧重对称轴旋转的具体分析方法，本卡侧重特征触发判断。am-card-1101（找相同识不同法）是更宏观的观察方法，本卡是具体特征层面的触发。

## 不适用条件

1. 图形无明显对称特征时（应改用1121数量规律分层排查法）
2. 对称类型、对称轴数量和方向均无法形成稳定规律，而重复元素或样式转化能解释全组图时。
3. 对称只是外形共性，黑白阴影的位置、数量或运算关系才能区分选项时。

## 反向触发

1. 对称类型判断后无法区分选项时，应补充核验对称轴的数量/方向/角度变化规律
2. 对称性验证无果时，应换用1122局部规律系统遍历法排查点线面角
3. 提示图形题围绕提示元素的变化无规律时，应补充核验提示元素本身的数量/位置

## 输出要求

- 看到对称特征时，先判断对称类型（轴对称/中心对称/两者兼具）
- 画出对称轴/标出对称中心，再找数量/方向规律
- 相同位置有相同线条时，先识别相同部分，再分析变化部分
- 提示图形题先识别提示元素，再分析围绕提示元素的变化
- 与 am-card-1062、am-card-1101 配合使用
