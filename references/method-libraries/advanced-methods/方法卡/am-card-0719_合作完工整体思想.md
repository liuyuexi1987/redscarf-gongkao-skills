# 方法卡：合作完工整体思想

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 合作完工整体思想 |
| 适用题型 | 数量关系——工程问题 |
| 触发场景 | 多人合作完成多项工作；中间有穿插帮忙、换场地等情况；题目问某人的工作时间 |
| 步骤逻辑 | 多人穿插帮忙时，不管怎么分工，只要没人闲着，就用总工作量÷总效率=总时间。；1. 设各项工作的工作总量；2. 求出各人效率；3. 总工作量÷总效率和 = 总时间；4. 用总时间减去已知时间→得到未知时间 |
| 高频错因 | 混淆各人的效率赋值；忘记设工作总量为最小公倍数 |
| confidence | medium |

## 补充说明

- 这种方法比按题目顺序列方程快很多
- 核心是抓住"没人闲着"这个本质

## 不适用条件

- 题目明确给出各人工作的先后顺序且有中断时，不能直接用整体思想，需按时间段分段计算
- 工作效率随时间变化（如递增/递减效率）时，不能用恒定效率的整体法
- 题目要求精确到某人在某段具体做了多少时，整体法无法给出分段结果

## 反向触发

- 若题目涉及的是追及/相遇问题而非工程合作，不使用本卡
- 若题目只有一人工作、不存在合作关系，不适用整体思想
