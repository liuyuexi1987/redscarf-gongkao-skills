# 方法卡：前提型论据结论颠倒识别

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 前提型论据结论颠倒识别 |
| 适用题型 | 判断推理——前提假设类（行文逻辑反常） |
| 触发场景 | 按原文顺序读，论据推出结论的逻辑不通顺（如"雅思重要→英语水平不够不录取"） |
| 步骤逻辑 | ① 按顺序读完后发现推导逻辑不通；② 尝试颠倒：前面变成结论，后面变成论据；③ 确认颠倒后逻辑成立（"英语水平不够→不录取"为论据，推出"雅思重要"为结论）；④ 此时再找论据与结论之间的断点，正常搭桥 |
| 高频错因 | 机械按原文顺序认定论据结论，导致断点识别错误；忽略结论中突兀出现而论据未铺垫的关键词（颠倒信号） |
| confidence | high |

## 补充说明

颠倒后论据与结论的概念差异处即为断点。若论据为"X 不达标→不录用"、结论为"Y 很重要"，断点常在"X"与"Y"之间，需找"Y 能反映 X"类选项搭桥。识别颠倒信号的关键是结论中出现论据未铺垫的突兀概念。

## 不适用条件

1. 原文顺序推导逻辑通顺时不适用，应直接断点搭桥。
2. 问法非前提假设类（如削弱、解释、加强）时不适用。
3. 颠倒后逻辑仍不通顺时，可能存在多重断点或论据结论关系非简单颠倒，不适用本方法。

## 反向触发

1. 若按原文顺序逻辑即通顺，应直接断点搭桥，不做颠倒处理。
2. 若颠倒后仍不通顺，应考虑是否存在多重断点，换用复合搭桥或反向代入法。
3. 若结论关键词并非突兀出现而是论据已铺垫，应回到正向断点搭桥，避免误判颠倒。
