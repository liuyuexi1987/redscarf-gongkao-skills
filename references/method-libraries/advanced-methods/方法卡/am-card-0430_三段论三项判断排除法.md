# 方法卡：三段论有效性初筛法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 三段论有效性初筛法 |
| 适用题型 | 判断推理-逻辑判断-三段论（前提假设型） |
| 触发场景 | 题目给出两句话前提+一个结论，问第三句前提应是什么；或问哪句话是必须假设的 |
| 步骤逻辑 | ① 标准化结论，确定主项、谓项；结论中未出现的概念是中项；② 全部前提与结论只能涉及三个概念，中项应分别连接另外两个概念；③ 两个否定前提不能推出结论；若有一个否定前提，结论必须是否定命题，反之亦然；④ 两个特称前提不能推出必然结论；若有特称前提，结论不能比前提更强；⑤ 初筛后仍有多个选项时，转入中项周延和文氏图复核 |
| 验证动作 | 将候选前提加入后，用文氏图或集合关系检查结论是否必然成立，而不是仅“可能成立” |
| 不适用条件 | 日常语言尚未标准化为直言命题；题目涉及关系命题、模态命题或复合命题时，不套三段论规则 |
| 高频错因 | 把量词搭配当成固定口诀；只检查三个概念是否各出现两次，却不检查否定关系和周延；把可能推出误当成必然推出 |
| confidence | high |
| 反向触发 | 初筛后仍有两个及以上候选选项时，应转入中项周延检查和文氏图复核，不可凭直觉在剩余选项中选定；结论涉及"有些""可能"等弱量词，而候选前提含"所有""必然"等强量词时，需验证前提强度是否超出结论要求 |
