# 方法卡：话题一致性判断法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 话题一致性判断法 |
| 适用题型 | 逻辑判断——一般质疑（选项筛选） |
| 触发场景 | 需要判断选项是否与题干讨论的是同一件事 |
| 步骤逻辑 | ① 提取题干核心话题（如"买电车是否为了省钱""杭州是否有樱花"）；② 看选项是否在讨论同一话题；③ 排除话题不一致的选项（如题干讨论"省钱"，选项讨论"环保"就是无关） |
| 高频错因 | 被选项的"大方向"迷惑（如选项说"冬天确实不容易过敏"，看似支持实则是同一方向）；把"比谁更好"当成质疑（如"那个方法比这个方法效果更好"不是质疑） |
| confidence | medium |
| 不适用条件 | - 选项话题与题干一致，需要进一步判断质疑力度而非排除无关项
| 反向触发 | - 选项话题明显一致且直接针对结论→进入实质性质疑判断（造句法/增加反向论据等）
- 需要判断因果关系选项→用归因论证方法而非话题筛选 |
- 题干是纯形式逻辑题（翻译推理），话题一致性不是筛选标准
- 所有选项话题一致，需要比较哪个更能动摇结论 |

## 补充说明

话题一致性是筛选选项的第一步。常见干扰项：① 话题不一致（如题干讨论"电车省钱"，选项讨论"电车环保"）；② 比较型干扰（如"那个方法比这个方法更好"不是质疑，因为题干没说这个方法是最好的）；③ 理论vs实际（如"理论上授粉阶段不够潮湿不会丰收"是理论，没说实际有没有这个问题）。
