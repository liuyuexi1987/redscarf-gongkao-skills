# 方法卡：搭配验证选词法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 搭配验证选词法 |
| 适用题型 | 逻辑填空——搭配分析 |
| 触发场景 | 空格处词语与前后文构成动宾/主谓/偏正搭配，且有1-2个选项明显搭配不当 |
| 步骤逻辑 | ① 找空格前后的搭配对象（宾语/主语/修饰语）；② 逐一代入选项，检验是否构成常见固定搭配；③ 搭配不当的直接排除；④ 剩余选项再用语境、感情色彩二次筛选 |
| 高频错因 | ① 只看词义不看搭配，选了语义通顺但搭配生硬的词；② 把临时搭配（语境允许的非常规组合）当成固定搭配，排除了正确选项 |
| confidence | high |

## 补充说明
搭配是逻辑填空的"硬约束"——搭配不对，语义再好也不能选。常见搭配类型：动宾（"陶冶情操"而非"锻炼情操"）、主谓（"蓝图描绘"而非"蓝图刻画"）、偏正（"深远影响"而非"深入影响"）。遇到搭配不确定的选项，先放着，用其他空排除。

## 不适用条件
- 空格处搭配关系不明显，无明确的动宾/主谓/偏正结构可供验证。
- 所有选项搭配均成立，差异在于语义方向或感情色彩而非搭配。
- 题目以语境逻辑关系或词义轻重为核心考点而非搭配。

## 反向触发
- 当搭配验证后剩余多个选项时，需补充感情色彩匹配法或语境对应分析法进行二次筛选。
- 当选项间差异为词义轻重而非搭配时，应换用词义轻重排序法。
- 当搭配判断不确定时，需结合语境解释对应法核验空格语义方向后再判定搭配。
