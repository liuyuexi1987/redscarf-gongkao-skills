# 方法卡：图推线条与笔画特征触发法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 图推线条与笔画特征触发法 |
| 适用题型 | 判断推理——图形推理 |
| 触发场景 | 图形中出现明显的线条特征：只有一根连续线、两根独立线、封闭面内嵌入线条、或线条数量有规律变化 |
| 步骤逻辑 | ① 识别线条特征：一根线（图形由单一连续线条构成）→ 两根线（图形由两条独立线条或内外嵌套构成）→ 封闭面内一根线（封闭区域内部有一条连续线段，头尾通常与边界相连）；② 一根线/两根线优先验证笔画数：一笔画考奇点数为0或2，两笔画考奇点数为4；③ 封闭面内一根线是升级版：当封闭面内线条与边界交点数有规律时，考交点数而非笔画数；④ 线条数量规律：各图线条总数、直线数、曲线数分别是否有增减或等量关系；⑤ 线面关系：线条穿过封闭面的数量、线条与面的交点数 |
| 高频错因 | ① 看到线条就只数笔画，忽略线条与封闭面的交点关系；② 两根线误判为一笔画（内外嵌套是两笔画）；③ 封闭面内线条不连边界时仍按标准思路做，忽略特殊命题方式；④ 线条数量规律与笔画规律混淆，未分别验证 |
| confidence | high |

## 补充说明

**一根线的核心判断：** 图形由单一连通线条构成时，可优先验证一笔画。用图论核验时，连通图的奇点数为 0 或 2 才能一笔画；不能只凭视觉上像“一根线”就下结论。

**两个独立部分的核心判断：** 内外嵌套或两个不相连的部分，即使每个部分都可一笔完成，整体也至少需要分开起笔。判断最少笔画数时要同时看连通分量和各分量的奇点数，不能把“两个部分”简化为“必有 4 个奇点”。

**封闭面内一根线的升级判断：** 这是封闭面与线条的复合特征。封闭面内部有一条连续线段，线段头尾通常与封闭面边界相连。考点可能在线条笔画数，也可能在线条与边界的交点数，也可能在封闭面被线条分割后的区域数。优先验证笔画，无规律再验证交点数和分割区域数。

**线条数量的常见规律：** 各图线条总数递增/递减/等量、直线数与曲线数分别有规律、某类线条（如水平线/竖直线）数量恒定。线条数量规律常与笔画规律混在同一组题中，需要分别验证。

## 不适用条件

1. 线条、笔画和奇点均无法形成稳定规律，而圆形、对称或规整分割特征能连续解释全组图时。
2. 图中的线条只是轮廓组成部分，线数或笔画数的变化不能区分选项时。
3. 图片过于模糊，连接点、断点或交点无法可靠识别时。

## 反向触发

1. 笔画数验证后选项仍无法区分时，应补充核验线条与封闭面的交点数
2. 线条数量规律无果时，应换用1122局部规律系统遍历法系统排查点、面、角
3. 封闭面内线条考点不确定时，应换用1124图形间关系细分法分析线面关系

## 输出要求

- 看到一根线/两根线特征时，先说明触发的是哪种子类型
- 优先验证笔画数，无规律再验证交点数、线条数量、线面关系
- 说明奇点判断方法（度数为奇数的点）
- 封闭面内线条要分别说明封闭面和线条各自的考点
- 与 am-card-1083（田字型两笔画识别）配合使用
