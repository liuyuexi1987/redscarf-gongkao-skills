# 方法卡：乘积增长率速算

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 乘积增长率速算 |
| 适用题型 | 资料分析-乘积增长率（占比类复合增长） |
| 触发场景 | 题目问由两个因素乘积构成的量的增长率（如产业数字化=数字经济×占比） |
| 步骤逻辑 | 1.列出关系式：C=A×B；2.识别这是乘积增长率问题（"看到占比想乘积"）；3.分别算出R1（A的增长率）和R2（B的增长率）；4.乘积增长率=R1+R2+R1×R2；5.R1和R2很小时可忽略交叉项，近似为R1+R2 |
| 高频错因 | 1.占比的增长率算错——用比重差(0.7%)当增率，忘记除以基期比重(80.2%)；2.不知道"看到占比想乘积"的考点 |
| confidence | high |

## 不适用条件
- 量的关系不是乘积而是商（如人均GDP=总量/人口）——乘积公式不适用，需用除法增长率公式
- R1或R2为负值且绝对值较大——R1+R2+R1*R2公式仍成立但交叉项影响大，速算优势减弱
- R1和R2均较大导致交叉项不可忽略——近似R1+R2会引入显著误差

## 反向触发
- 题目给出乘积增长率，要求反推某个因子的增长率——需逆用公式，非正向速算
- 占比重已给出且为定值（无变化）——只有一个变化因子，直接用单一增长率
- 题目涉及三个及以上因子的乘积——本法公式仅适用于两因子

## 补充说明

典型场景：数字产业化规模=数字经济总量×数字产业化占比。需要分别算两个增率再合并。占比增率的算法：(80.9%-80.2%)/80.2%=0.7%/80.2%≈0.87%，不是直接用比重差0.7%。最终R=R1+R2+R1×R2。当R1、R2都很小时，R1×R2可忽略。此法比用比重差公式逆推更快。
