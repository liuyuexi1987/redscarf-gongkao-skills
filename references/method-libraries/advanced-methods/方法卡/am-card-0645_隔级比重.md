# 方法卡：隔级比重

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 隔级比重 |
| 适用题型 | 资料分析——求小比重（如制造业占GDP的比重，材料只给了制造业占第二产业、第二产业占GDP的比重） |
| 触发场景 | 需要通过两个中间比重相乘得到目标比重 |
| 步骤逻辑 | ① 识别：小比重 = 中比重 × 大比重（或反之）；② 直接相乘即可；③ 注意量级和百分号 |
| 高频错因 | 搞混谁乘谁；忘记百分号 |
| confidence | medium |
| 不适用条件 | 材料直接给出了目标比重、不需要通过中间比重推导时；中间比重的数据缺失或不确定时；题目要求比较两年隔级比重的变化方向（需配合两期比重比较） |
| 反向触发 | 材料只给了两级比重（如A占B的比重、B占C的比重），题目问A占C的比重时，直接两级相乘即可 |

## 补充说明

例：制造业占第二产业比重35.8%，第二产业占GDP比重45%，则制造业占GDP比重 = 35.8% × 45%。本质是部分/整体 = (部分/中间) × (中间/整体)。
