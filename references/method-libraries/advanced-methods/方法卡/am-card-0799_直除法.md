# 方法卡：直除法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 直除法 |
| 适用题型 | 资料分析——倍数、平均数、比值类除法；或选项极近的任何除法 |
| 触发场景 | 分子分母位数相差大（如四位÷一位）；选项保留三位后差异极小；其他速算方法无法适用 |
| 步骤逻辑 | ① 保持原始数据尽量不截位；② 逐步试商做除法；③ 选项首位不同则一步出答案；④ 选项极近时老实算到能区分为止 |
| 高频错因 | 选项极近时仍用估算方法导致选错；截位后心里发慌反复验算浪费时间 |
| confidence | medium |

## 补充说明

此法反对截位直除，认为截位后容易心里发慌影响后续做题心态。直除定位是"兜底方法"——在拆分、假设分配都不适用时使用。优选级：比重用拆分，基期用假设分配，其余用直除。当估算误差可能跨越选项或改变结论时，改用精算/验证。

## 不适用条件

1. 分子分母位数差不明显，或选项首位已不同，一步即可出答案无需逐步试商。
2. 题目明确为比重类且分子在分母的50%/25%附近，除法拆分更高效。
3. 已知现期量和增长率求基期，假设分配法更适用。

## 反向触发

1. 拆分法和假设分配法均不适用，需要直接做除法计算。
2. 选项极近（保留三位后差异极小），必须老实算到能区分的位数。
3. 分子分母位数相差大（如四位除一位），试商步骤简单。
