# 方法卡：余数三句口诀

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 余数三句口诀 |
| 适用题型 | 余数问题（同余、同和、同差三种情况） |
| 触发场景 | 题干给出"除A余a，除B余b"，且余数相同、和相同、或差相同 |
| 步骤逻辑 | 1. 判断属于哪种情况：- **余同**：余数相同 → 表示为 lcm(A,B) × n + 余数- **和同**：(除数+余数)相同 → 表示为 lcm(A,B) × n + (除数+余数)- **差同**：(除数-余数)相同 → 表示为 lcm(A,B) × n - 差值；2. 用 n=1,2,3... 依次代入，结合题目范围筛选答案 |
| 高频错因 | 三种情况混淆，"和同"误用减法或"差同"误用加法 |
| confidence | medium |

## 补充说明

口诀用于把多个同余条件整理成“最小公倍数的倍数 ± 固定量”。整理后仍需代回每个除法条件，并结合题目范围验证。

## 不适用条件

- 条件不满足余同、和同或差同中的任一种。
- 除数不互质并导致条件互相矛盾，或题目要求全部解而非范围内最小解。

## 反向触发

- 口诀无法统一条件时，改用逐步同余合并、枚举或中国剩余定理。
- 得到候选值后必须逐项验余，不能只看形式相似。
