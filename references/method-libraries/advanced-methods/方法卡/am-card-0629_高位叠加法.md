# 方法卡：高位叠加法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 高位叠加法 |
| 适用题型 | 资料分析——多个多位数求和 |
| 触发场景 | 求多个数字之和，不想列竖式从个位加起时 |
| 步骤逻辑 | ① 从最高位开始加起；② 每低一位往后错一位写（像楼梯）；③ 遇到等差数列用中间项×项数；④ 能凑十的先凑十；⑤ 累加得出结果 |
| 高频错因 | 错位时对齐错误；忘记进位 |
| confidence | medium |

## 补充说明

高位叠加核心思路：不用抄数列竖式，直接在脑中从千位→百位→十位→个位依次累加，每低一位往后错一位。善用等差数列求和（奇数项：中间项×项数；偶数项：中间两项平均×项数）和凑十技巧可大幅提速。

## 不适用条件

- 加数过多且位数、正负号或小数位不统一，心算容易错位。
- 题目要求保留精确小数而非整数求和。

## 反向触发

- 出现连续进位或错位风险时，改用分组求和或竖式复核。
- 存在等差、凑整结构时先分组，再做高位叠加。
