# 方法卡：分式混合（线段混合）

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 分式混合（线段混合） |
| 适用题型 | 资料分析——增速混合·已知两部分增速求整体增速范围或方向 |
| 触发场景 | 题目给出上半年增速和下半年增速，问全年增速在什么范围或更靠近哪一侧；或给出A、B两个子类增速，问整体增速 |
| 步骤逻辑 | ① 确认两个部分的基期量均为正；② 整体增速是按基期量加权的结果，位于两个部分增速之间，两者不等时严格在二者之间；③ 整体更靠近基期量较大的一侧；④ 需要精确定位时使用基期量作权重，不能只凭现期量判断 |
| 高频错因 | ① 混淆"更靠近谁"——应靠近分母大的（权重大的），不是分子大的；② 用限期比代替基期比时，增速差太大（>30%）可能导致方向判断错误；③ 忘记混合后"取不到端点"——不可能等于任一部分的增速 |
| confidence | high |

## 补充说明

分式混合本质是基期量加权平均：先定范围，再看基期权重决定靠近方向。现期量只能用于粗略预判；选项接近或增速差较大时，应还原基期权重验证。

## 不适用条件

- 题目给出的不是增速而是绝对值（如金额、数量），需先转化为增速再判断
- 两部分增速差较大或选项接近时，不能用现期量代替基期量作权重
- 超过两个子部分的混合（如四个季度混合成全年），需分步两两混合或用加权平均

## 反向触发

- 看到"上半年/下半年→全年""A类+B类→整体"且问增速范围或更靠近哪侧 → 用本方法
- 看到"增长量"混合（绝对值混合） → 不用本方法，应直接相加
- 看到"比重"混合（占比混合） → 不用本方法，比重混合逻辑不同
