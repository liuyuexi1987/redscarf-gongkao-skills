# 方法卡：和差速算公式

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 和差速算公式 |
| 适用题型 | 已知两数之和与两数之差，求各数 |
| 触发场景 | 题干同时给出"两个量的和"与"两个量的差" |
| 步骤逻辑 | 1. 大数 = (和 + 差) ÷ 2；2. 小数 = (和 - 差) ÷ 2；3. 本质是跳过列方程的过程，直接用公式出结果 |
| 高频错因 | 和差混淆，把(和+差)和(和-差)搞反忘记除以2 |
| confidence | medium |

## 补充说明

- 本公式用于节省时间，本质与列方程等价。
- 当题干同时给出两个量的和与差时，直接套用公式即可，无需再设未知数列方程。

## 不适用条件

- 题干只给出"和"或只给出"差"，缺少其中之一，公式无法使用。
- 涉及三个及以上未知量，和差关系不局限于两数，公式不适用。

## 反向触发

- 当两个量的关系不是简单加减而是倍数关系时，应改用"份数思想对应实际量"。
- 当题目要求的是两个量的比值而非各自数值时，应直接用比例求解，无需先求各数。
