# 方法卡：转移论点/答非所问识别

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 转移论点/答非所问识别 |
| 适用题型 | 逻辑谬误相似性判断题 |
| 触发场景 | 讨论中一方不正面回应对方论点，而是扯到其他话题 |
| 步骤逻辑 | 1. 判断论点讨论的是什么（如"药效好不好"）；2. 看回应是否针对同一话题（谈"副作用"就不对——论点是药效不是副作用）；3. 常见形式：迟到被问"为什么迟到"→回答"我以前没迟到过"（转移话题） |
| 高频错因 | 把"间接相关"当作"正面回应"；选项中出现看似相关但实际讨论对象不同的干扰项 |
| confidence | high |

## 补充说明

转移论点的核心是"讨论对象不一致"。示例用"你对我有问题≠我对你没问题"说明两者不相干。

## 不适用条件

- 选项虽然换了个角度但仍在回应同一讨论对象（如从"效果"转到"副作用"但题目问的确实是综合评价），不构成转移论点。
- 题目考查的是逻辑推理形式（条件推理、搭桥拆桥），而非对话类谬误识别。

## 反向触发

- 题目明确考查"转移论点""答非所问""偷换概念"等谬误。
- 对话中一方的回应看似相关，但讨论的实际对象与原论点不一致。
