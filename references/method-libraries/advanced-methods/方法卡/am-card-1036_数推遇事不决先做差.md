# 方法卡：数推遇事不决先做差

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 数推遇事不决先做差 |
| 适用题型 | 数量关系——数字推理 |
| 触发场景 | 数字推理题看不出明显规律时 |
| 步骤逻辑 | ① 当数列呈平缓单调变化且无明显倍数/分组/幂次特征时，作差（后项-前项）是首选观察路径；② 一级差有规律→等差数列或多级数列，按规律推下一项；③ 一级差无规律→作二级差，观察二级差是否成等差/等比/质数等简单规律；④ 二级差也无规律→回退到"数字推理总纲"，按"作和→作商→递推→分组→幂次"顺序尝试其他路径 |
| 高频错因 | ① 数列有倍数/分组/幂次特征却仍先作差，错过更直接的路径；② 做差后不看差值序列本身的规律就直接放弃；③ 二级差无规律时仍坚持作三级差，未及时回退到其他路径 |
| confidence | high |

## 补充说明
作差是数列呈平缓单调变化时的首选观察路径，但并非"遇事不决"的万能规则。当数列有明显倍数关系（优先作商）、上下波动（优先作和）、含小数点/根号/分式（优先分组）、或多项接近幂数（优先幂次修正）时，应直接走对应专项路径，不应强行作差。作差路径成立的前提是：差值序列能覆盖全部已知项并形成可验证规律。

## 不适用条件
- 可用项太少、做差后无法对同一规律进行连续验证时。
- 数列含明显比例/倍数关系（如2,6,18,54）时，应优先做商而非做差。
- 数列呈现明显的奇偶分组或周期结构时，应先按组拆分，不宜把全部项直接做差。

## 反向触发
- 当一级差无规律且数列呈指数增长时，应换用作商法或"等比修正与乘法递推法"。
- 当数列项间差值大于原项本身时，应补充作和或分组递推核验。
- 当数列具备明显的位置特征（奇偶项分离、分组对应）时，应改用"分组数列识别总卡"。
- 当数列多项接近幂数时，应改用"幂次修正与因式分解数列"。

## 最终验证动作

1. 用求得的差值规律从首项逐项回代，确认每一项都与原数列完全吻合。
2. 推出目标项后与选项比对；若目标项与最近选项有固定差值，检查差值序列在末位是否有方向反转。
3. 对二级差成立的规律，必须验证二级差序列同样覆盖全部已知差值，不能只验证末位。
