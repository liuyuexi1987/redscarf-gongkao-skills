# 方法卡：图推简化思维原则

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 图推简化思维原则 |
| 适用题型 | 判断推理——图形推理 |
| 触发场景 | 所有图形推理题，尤其图形复杂时 |
| 步骤逻辑 | ① 不先想复杂规律；② 从最基本的"点线面角数"开始验证；③ 简单规律排除后再想复杂规律；④ 复杂长相+简单规律是常见命题套路 |
| 高频错因 | ① 看到复杂图形就想复杂规律→忽略简单规律；② 数量超过5个就不去数→其实规律就是数面/线/点 |
| confidence | high |

## 补充说明
图形推理优先尝试简单规律，简单规律无效时再考虑复杂规律。观察图形中的反常之处（如多出的笔画、不对称的元素），反常处往往是解题切入点。

## 不适用条件
- 图形明显考查复杂规律（如组合叠加、求同存异）
- 规律明显需要多步运算方能验证

## 反向触发
- 简单规律全部排除→转入复杂规律分析
- 图形有明确反常处→优先分析反常处而非继续数简单数量
