# 方法卡：选项差距伪大-量级还原后精算

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 选项差距伪大-量级还原后精算 |
| 适用题型 | 资料分析——选项首位不同看似差距大，但还原量级后实际差距极小，需精算 |
| 触发场景 | ① 比值差/平均数差值题中，分子分母单位不同（如万亿÷亿）；② 列完式子发现选项ABCD首位各异（如768/696/1068）但还原量级后实际值在800附近，选项间只差几十 |
| 步骤逻辑 | ① 列式后先检查单位是否匹配，不匹配则还原量级（如2.05万亿=20500亿）；② 还原后粗算结果范围（如约800）；③ 将结果范围与选项对比，若选项间距远小于结果本身（如800附近选项差10~20），则判断为"伪大差距"；④ 切换为精算模式，逐位精确计算 |
| 高频错因 | ① 被选项首位不同误导以为可估算，实际量级还原后差距极小；② 未还原量级直接算导致结果偏差巨大；③ 精算时精度不够（如810 vs 896差86，算成810 vs 890差80就选错） |
| confidence | high |

## 补充说明

判断"伪大差距"的关键动作是还原量级后看选项在结果中的相对位置。典型场景：选项768/696/1068看起来差距很大，但实际计算结果约800-896，相邻选项之间仅差几十，必须精算到三位有效数字。

## 不适用条件

1. 选项量级一致且间距较大时（如间距超过结果的10%），粗估即可锁定，无需精算
2. 单位已统一且选项首位明确不同时，可直接用有效数字法估算，不存在"伪大差距"问题
3. 题目要求的是排序或比较大小而非精确值时，不需要精算到三位有效数字

## 反向触发

1. 当还原量级后发现选项间距仍然较大时，说明不是"伪大差距"，应换回有效数字估算法
2. 当精算到三位有效数字仍无法区分两个相邻选项时，需额外核验原始数据精度或换用逐位精确除法
3. 当单位还原过程中发现题目数据本身可能有歧义（如"万"和"亿"表述不清）时，应先确认单位再计算
