# 方法卡：份数法与特殊分数记忆

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 份数法与特殊分数记忆 |
| 适用题型 | 资料分析——已知现期和增速求增量或基期 |
| 触发场景 | 增速接近某个特殊分数（如 11.1% ≈ 1/9、18% ≈ 1/5.5、20% = 1/5、25% = 1/4、33.3% = 1/3、50% = 1/2），求增量或基期 |
| 必要输入 | 现期值、增速百分比 |
| 步骤逻辑 | ① 识别增速接近哪个特殊分数；② 建立份数关系（如 11.1% → 基期:增量:现期 = 9:1:10）；③ 现期 ÷ 总份数 = 每份量；④ 增量 = 每份量 × 增量份数，基期 = 每份量 × 基期份数 |
| 验证动作 | 反算：每份量 × 总份数 = 现期；增速 = 增量份数 / 基期份数 ≈ 题给增速 |
| 不适用条件 | 增速与任何常见特殊分数差距较大时（如 7.3%、14.6%），用假设分配或其他方法更合适 |
| 高频错因 | ① 记错分数对应关系（如把 18% ≈ 1/5.5 记成 1/5）；② 用现期代替基期算增量（应为基期 ÷ 份数而非现期 ÷ 份数）；③ 近似误差不得跨越选项边界，需用误差上界与选项间距比较 |
| 反向触发 | ①近似误差可能跨越相邻选项时，份数法精度不足，应改用精确公式或假设分配法；②增速与可熟练使用的特殊分数不够接近，或换算后的份数关系过于复杂时，直接用公式更稳妥；③题目求基期但增速本身未知需反推时，份数法无法直接套用，需先列方程求增速 |
| confidence | high |

> **使用边界**：本方法用于提供优先检查方向，不可单独据此作答；最终需回到题干关系、原文证据或选项条件完成验证。
