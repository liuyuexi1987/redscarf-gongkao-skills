# 方法卡：常识成对词替换识别

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 常识成对词替换识别 |
| 适用题型 | 常识判断——判断题/单选题 |
| 触发场景 | 常识题选项中出现方向性词或成对概念 |
| 步骤逻辑 | ① 标出选项中有方向的成对概念，如"上到下"/"下到上"、"末端"/"源头"；② 回到基本定义或事实核对主体、方向和作用对象；③ 仅当关键概念被对向替换时排除该项，不根据“正确/错误项更容易出”猜答案 |
| 高频错因 | ① 不注意方向性→选了反向的选项；② 成对词看起来都对→选了替换后的错项 |
| confidence | medium |

## 不适用条件
- 选项为单一事实陈述、不含方向性词或成对概念时，本方法不适用。
- 题目考查具体法条/年份/数据等硬知识点时，方向性替换无法识别。
- 无法核对方向性概念的定义或事实时，本法不能代替知识判断。

## 反向触发
- 当选项间差异在程度词（如"主要""根本""唯一"）而非方向性时，应换用程度词核验法。
- 当题干明确要求"选出错误项"时，应反向使用替换识别，重点查找未替换项。
- 若涉及因果/递进关系判断，应补充分句逻辑核验，不能仅靠成对词替换判断。
