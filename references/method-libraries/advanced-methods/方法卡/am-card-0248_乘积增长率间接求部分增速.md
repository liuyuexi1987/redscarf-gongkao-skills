# 方法卡：乘积增长率间接求部分增速

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 乘积增长率间接求部分增速 |
| 适用题型 | 资料分析——已知整体增速和占比关系，间接求部分增速 |
| 触发场景 | 需要比较两个部分的增长量，但材料只给出整体增长率和各部分占比（没有直接给出部分增长率） |
| 步骤逻辑 | ① 记住公式：部分增速 = 整体增速 + 占比增速 + 整体增速×占比增速；② 算占比增速 = 占比增量÷基期占比；③ 若占比增速很小（增量1-2个点、基数很大），则部分增速 ≈ 整体增速；④ 两部分增速差距很小时，增长量大小主要由现期值（占比）决定 |
| 验证动作 | 用 `(1+整体增速)×(1+占比增速)-1` 复核部分增速；比较增长量时再用 `现期量×增速/(1+增速)` 验证 |
| 不适用条件 | 占比增速或乘积项足以跨越选项边界时，不得省略；两个部分增速差距不小时，不能只按现期占比判断增长量 |
| 高频错因 | 不知道部分增速可以通过整体增速和占比增速推导；未经误差判断就忽略占比增速或乘积项；把增速接近直接等同于增长量相同 |
| confidence | high |
| 反向触发 | 材料直接给出部分增长率时无需间接推导；占比增速或乘积项造成的误差可能跨越选项时，应代入完整公式精确计算；题目比较增长量且两部分增速差距不可忽略时，不能仅凭现期值判断，需分别计算增长量后比较。 |
