# 方法卡：计算方法选择

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 计算方法选择 |
| 适用题型 | 资料分析——所有需要估算的乘除运算·选择最优计算策略 |
| 触发场景 | 拿到数据后、开始计算前，需要决定用份数法、化除为乘还是放缩法 |
| 步骤逻辑 | ① 先比较选项差距与可接受误差；② 增率接近简单分数时考虑份数法；③ 分母接近便于口算的数且能控制同比例误差时考虑放缩法；④ 现期×R的R²修正项不影响选项时考虑化除为乘；⑤ 任一路径误差可能跨选项时切换精算或反乘验证 |
| 高频错因 | ① 不看选项就盲目选择方法，导致算得太粗或太细；② 所有题都用同一种方法，不根据数据特点灵活选择；③ 选项差距大时仍用高精度方法浪费时间；④ 选项差距小时仍用低精度方法导致选错 |
| confidence | high |

## 补充说明

计算方法没有固定的精度和速度排名。份数法依赖简单分数匹配，放缩法依赖可控的同比例调整，化除为乘依赖R²修正项足够小。实际做题时先看选项需要的精度，再选计算量最小且误差可验证的路径；误差可能跨越选项时改用精算或反乘验证。

## 不适用条件

1. 题目要求精确结果（如需要验证选项中非常接近的两个值），任何速算方法都不够。
2. 数据量很小且可以直接口算，无需选择策略。
3. 增长率类型、正负方向或数据口径尚未确认时，应先完成题型和公式识别。

## 反向触发

1. 拿到数据后不确定用哪种方法，需要快速判断选项差距和数据特点来选策略。
2. 一种方法尝试后精度不够，需要切换到另一种方法。
3. 同一篇材料连续多题，需要统一策略以提高整体做题速度。
