# 方法卡：图推黑白球做题顺序

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 图推黑白球做题顺序 |
| 适用题型 | 判断推理——图形推理（黑白球/阴影） |
| 触发场景 | 图形推理中出现黑白球/阴影元素 |
| 步骤逻辑 | ① 先看对称（轴对称/中心对称）；② 再看部分数（黑色部分数/白色部分数/加减关系）；③ 最后看移动（上下/左右/对角移动规律）；④ 注意近年趋势：黑白球可能有主体区分难度（黑色一套规律、白色一套规律） |
| 高频错因 | ① 一上来就数部分数→漏掉对称规律；② 不按固定顺序尝试→遗漏考点 |
| confidence | high |
| 不适用条件 | ['图推题目不涉及黑白球或阴影元素', '黑白球数量差异极大，应优先考虑数量规律', '黑白球之间存在大小、形状差异，非单纯颜色区分'] |
| 反向触发 | ['图推题目元素是纯线条、立体图形或叠加样式，无黑白球/阴影', '黑白球数量或面积差异明显，数量规律优先于对称和移动'] |

## 补充说明
黑白球是图推高频考点，按固定顺序尝试效率最高：对称→部分数→移动。近年考试趋势：黑白球难度升级，黑色和白色可能各有独立规律（如黑色旋转90°、白色旋转180°）。
