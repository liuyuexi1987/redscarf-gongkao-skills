# 方法卡：基期比重计算

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 基期比重计算 |
| 适用题型 | 资料分析——求基期比重 |
| 触发场景 | 题目给出某部分占整体的现期比重，以及部分增长率和整体增长率，要求计算基期比重 |
| 步骤逻辑 | ① 确认题型：出现"基期""比重"关键词；② 列式：基期比重 = 现期比重 × (1+整体增长率) / (1+部分增长率)；③ 观察分子分母关系：若分子分母中有一个接近1，可用估算或放缩直接判断选项 |
| 高频错因 | 分子分母方向搞反（应为"整体增长率在分子、部分增长率在分母"的倒数关系）；列式时误写成现期比重 × (1+部分增长率) / (1+整体增长率) |
| confidence | high |

## 补充说明

"反过来"是指：分子用 (1+整体增长率)，分母用 (1+部分增长率)，与直觉相反。实际做题时，可先判断右侧分数是大于1还是小于1，再结合现期比重估算。

## 不适用条件

- 题目要求的是比重变化量（百分点）或比重增长率时，公式不同，需换用比重变化公式。
- 题目给出的就是基期比重，无需再做基期计算。
- 当部分增长率和整体增长率非常接近时，右边分数接近 1，基期比重约等于现期比重，但若选项间距极小仍需精算。

## 反向触发

- 题目问"比重上升/下降了几个百分点"时，换用比重变化量公式。
- 仅需判断比重升降方向时，直接比较部分增长率与整体增长率大小即可。
- 当误差可能跨越选项或改变结论时，改用精算/验证。
