# 方法卡：前观点与反面论证构成总分总

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 前观点与反面论证构成总分总 |
| 适用题型 | 中心理解题 / 语句填入题 |
| 触发场景 | 文段第一句提出明确观点，中间部分的主题与该观点对立或相反（非并列、非补充），末尾回归前观点 |
| 步骤逻辑 | 1. 识别首句是否为明确观点句（含主观判断、主张或定性表述） 2. 判断中间部分是否为反面论证：其主题与前观点对立或相反（如前观点说"需要A"，中间说"不做A会怎样"），而非并列展开或补充说明 3. 若确认为反面论证，中间部分为"分"，作用是支撑前观点，本身非重点 4. 此结构为"总（前观点）—分（反面论证）—总（末句回扣）"，主旨仍在前观点 5. 选择回扣前观点的选项，排除仅出自反面论证部分的选项 |
| 验证动作 | 检查选项是否回扣首句观点的关键词/主题词；若选项内容仅出现在反面论证区域，属出处有误，应排除 |
| 不适用条件 | 中间部分为并列展开、举例说明或因果分析（非对立关系）时不适用；首句为背景事实而非观点时不适用；反面论证用于引出全新观点（非支撑前观点）时不适用 |
| 高频错因 | 把反面论证中出现的新话题当成文段主旨，选了出处有误的选项 |
| confidence | high |
| 反向触发 | ①末句未回扣前观点而是引出了新话题或转向对策，说明文段并非"总分总"结构，应换用其他结构分析法；②中间部分虽主题对立但包含独立新论据或新视角，可能并非纯粹反面论证而是转折后的新观点，此时主旨可能移至后半段；③各选项均不包含前观点关键词，需重新审视首句是否真为观点句，可能只是背景事实引入 |
