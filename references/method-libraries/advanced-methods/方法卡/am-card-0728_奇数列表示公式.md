# 方法卡：奇数列表示公式

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 奇数列表示公式 |
| 适用题型 | 等差数列求和中涉及奇数项的序列，或组合数列中需要表示奇数部分 |
| 触发场景 | 数列包含奇数数列（1,3,5,7...）或偶数数列（2,4,6,8...），需要用通项公式代入计算 |
| 步骤逻辑 | 1. 奇数数列通项公式：第n项 = 2n - 1（第一项为1）；2. 偶数数列通项公式：第n项 = 2n（第一项为2）；3. 当题目说"和为某奇数"，直接令 2n-1 = 该奇数，解出n即可定位项数；4. 代入选项对应的项数，检验和是否匹配 |
| 高频错因 | 忘记奇数列首项是1（n=1时2×1-1=1），误用2n+1导致偏移 |
| confidence | medium |

## 补充说明

- 奇数列通项公式必须熟记：第n项 = 2n - 1（首项为1）；偶数列第n项 = 2n（首项为2）
- 当题目给出"和为某奇数"时，直接令 2n-1 = 该奇数，解出 n 即可定位项数
- 数列由循环部分（如1,2,3,4 循环）和奇数部分组成时，先识别奇数部分贡献，再用上述通项定位项数
- 代入验证：算出候选 n 后，将相邻循环项代入核算总和是否匹配

## 不适用条件

- 题目数列不是等差数列（如等比数列、摆动数列）时，本公式不适用
- 奇数部分不在数列中独立存在（与循环部分纠缠无法分离）时，需先拆分再判断

## 反向触发

- 当通项代入后总和不匹配时，应反向检查循环周期长度是否识别错误
- 当题目要求项数远超循环周期时，应改用周期求和+余项分析，而非单纯奇数列公式
