# 方法卡：间隔增长率

## 基本信息
| 字段 | 值 |
|------|-----|
| 方法名 | 间隔增长率 |
| 适用题型 | 资料分析-年均增长率或跨期总体增长率计算 |
| 触发场景 | 已知每期增长率，求跨多期的总体增长率（如连续3年每年增长7%，求17到20年总体增率） |
| 步骤逻辑 | 1. 两期间隔公式：r = R1 + R2 + R1×R2<br>2. 多期叠加：每两个相邻期间先算间隔增率，再与下一期继续叠加<br>3. 每个增率用且只用一次<br>4. 乘积项量级很小（如7%×7%=0.5%），通过与10%比较来快速判断量级 |
| 高频错因 | 乘积项量级算错（把0.5%算成5%）；多期叠加时漏用或重复使用某个增率 |
| confidence | high |

## 补充说明
- 量级判断技巧：7%×7%，先算7%×10%=0.7%，实际乘的比10%小，结果应比0.7%小，所以是0.5%而非5%。
- 例如：3年叠加过程——先算第1→2年（两个7%得14.5%），再用14.5%和7%算第1→3年（得22.5%）。
- 算出总体增率后，用"现期÷(1+总增率)"求基期。
- 精度要求高时（选项间距1%），间隔增率计算的精度也要相应提高。

## 不适用条件
1. 当期间增长率差异较大（如10%和3%）时，间隔公式精度下降，应逐期精确计算。
2. 当期间包含负增长（下降期）时，公式中的乘积项符号需额外注意，容易出错。
3. 间隔超过两期且增长率各不相同时，逐期叠加的累积误差增大。

## 反向触发
1. 当题目直接给出两期的具体数值（现期和基期），直接用(现期-基期)/基期算增率，不必套公式。
2. 当算出的间隔增率明显偏离常识（如连续正增长却算出负值），说明计算有误，应回头检查。
3. 当题目要求的是年均增长率而非跨期总增率时，需要开方计算，不能直接用间隔增率。
