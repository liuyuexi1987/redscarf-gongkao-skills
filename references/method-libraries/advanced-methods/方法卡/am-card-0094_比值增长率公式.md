# 方法卡：比值增长率公式

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 比值增长率公式 |
| 适用题型 | 资料分析-平均数增长率/比值增长率（A/B 型比值的增速） |
| 触发场景 | 题目问"平均每X的Y"或任何 A÷B 型比值"比上年同期增/减百分之几" |
| 步骤逻辑 | 1. 识别比值 = 分子 ÷ 分母（如：人均旅客 = 旅客吞吐量 ÷ 起降架次）；2. 公式：R = (R₁ - R₂) ÷ (1 + R₂)；3. R₁ = 分子的增长率，R₂ = 分母的增长率；4. 分子增得快 → 比值上升；分母增得快 → 比值下降；5. 结果绝对值通常小于 |R₁ - R₂|（因为除以 1+R₂） |
| 高频错因 | 直接用 R₁ - R₂ 作为答案，忘记除以 (1+R₂)分子分母搞反 |
| confidence | high |

## 不适用条件

1. 分母增长率为 -100%（分母降为零），公式分母 1+R₂=0 无意义
2. 题目问的是比值的绝对值变化量而非变化率，公式不适用
3. 比值不是 A÷B 结构，而是复合比值（如 A÷B÷C），需多次套用或换思路

## 反向触发

1. 题目直接给出了 A 和 B 的具体数值，可直接算比值再比较，无需公式
2. 分子分母增长率数值相同，比值增长率恒为零，公式无区分度
