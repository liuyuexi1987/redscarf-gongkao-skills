# 方法卡：归因类削弱嵌套因果链

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 归因类削弱嵌套因果链 |
| 适用题型 | 加强削弱——归因类，存在"支持谁让谁做根本原因"或"反对谁让谁做直接原因"的判断 |
| 触发场景 | 题干A认为原因是X，反对者认为不是X而是Y，问"最能削弱反对者"或"最能削弱原观点" |
| 步骤逻辑 | ① 削弱反对者→让反对者的Y做直接原因，X做根本原因：X→Y→结果（如缺水→受凉→感冒）；② 削弱原观点→反过来：Y→X→结果；③ 快速判断方向：看选项是否建立了"谁导致谁"的因果链；④ 注意"类似症状"不等于"就是症状"，"某人声称"不等于"事实" |
| 高频错因 | 看到某选项建立了强因果链却觉得"太直接了"不敢选，转而去选有瑕疵的干扰项；把削弱反对者和支持反对者的方向搞反（X→Y=削弱反对者，Y→X=支持反对者） |
| confidence | high |

## 补充说明

归因类削弱的关键：先确认支持/削弱的方向，再建立因果链。削弱反对者→让反对者的原因做中间环节，原观点原因做根本原因（X→Y→结果）；支持反对者则反向建立因果链（Y→X→结果）。注意"类似症状"≠"就是症状"，"某人声称"≠"事实"，此类选项削弱力度不足。"直接根本原因"型选项若建立了强因果链，通常就是正确答案，不需要找其他瑕疵。

## 不适用条件

- 题干只有单一归因，不存在"原观点vs反对者"的对立结构时，不适用本方法。
- 题干因果链只有一层（无嵌套可能），选项只能直接切断或支持时，按普通归因削弱处理。

## 反向触发

- 当选项中出现"类似""号称"等模糊表述时，应换用"削弱力度比较法"横向比较选项力度。
- 当题干涉及多个结果变量而非单一结果时，应补充核验因果链终点是否匹配题干结论，避免方向正确但终点错位。
