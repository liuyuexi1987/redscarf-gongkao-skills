# 方法卡：综合分析未用数据预判法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 综合分析未用数据预判法 |
| 适用题型 | 资料分析——综合分析题（同一材料的最后一题） |
| 触发场景 | 同一篇材料的前面小题做完后，发现材料中某个表格、图表或数据维度在所有前面小题中均未被使用 |
| 步骤逻辑 | 1. 回顾前面小题各自涉及的数据部分，记录已使用的数据维度<br>2. 识别材料中未被使用的数据部分（如文字材料中的补充表格、附图等）<br>3. 在综合分析题的各选项中，优先验证涉及该未用数据的选项<br>4. 优先验证不等于直接选择，仍需完成排除式验证后作答 |
| 不适用条件 | 材料只有一种数据形式（如纯表格无附图）时无未用维度可预判；前面小题已覆盖材料所有数据维度时无预判空间；该规律为概率性倾向而非确定性规则，不可作为跳过验证的理由 |
| 高频错因 | 把"优先验证涉及未用数据的选项"理解为"该选项一定正确"，跳过排除验证直接选择；忽略材料中可能有多个未用数据维度，预判过窄 |
| confidence | medium |
| 反向触发 | ①前面小题中有题目使用了该"未用数据"，说明该维度已覆盖，预判失效；②综合分析题各选项均不涉及该未用数据维度，说明该题另有考查重点，不可强行关联；③涉及未用数据的选项验证后排除（数据本身不符合题意），此时直接切换到常规排除法，不继续沿用预判方向 |
