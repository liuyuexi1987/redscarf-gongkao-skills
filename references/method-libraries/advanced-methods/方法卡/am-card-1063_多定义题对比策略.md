# 方法卡：多定义题对比策略

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 多定义题对比策略 |
| 适用题型 | 判断推理——定义判断（多定义） |
| 触发场景 | 题目给出两个或多个相关定义 |
| 步骤逻辑 | ① 先找两个定义的相同点（都是"归因"）→排除不满足基本条件的选项；② 再找不同点（不变性vs折扣）→区分选项；③ 用相同点缩小范围，用不同点精确定位 |
| 高频错因 | ① 不找相同点直接比不同→范围太大不好判断；② 混淆两个定义的不同要求→选错 |
| confidence | high |

## 不适用条件
- 题目只给出单个定义时
- 两个定义完全无关、没有可比基础时
- 定义题中要求判断"属于哪个定义"但选项差异不在定义本身而在具体条件时

## 反向触发
- 题目只有一个定义且无对比要求时，应使用主体判断法或总分定义法
- 两个定义之间没有明显的相同点或对立关系时，对比策略效果有限
