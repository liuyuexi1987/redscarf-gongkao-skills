# 方法卡：后对策文段优选对策项

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 后对策文段优选对策项 |
| 适用题型 | 言语理解——中心理解题（对策类文段） |
| 触发场景 | 文段结构为"问题/背景+对策"（后对策），选项中同时出现对策项和问题项时 |
| 步骤逻辑 | ① 识别文段结构：前面描述问题或背景，后面用"需要/应该/应/必须/不能"等提出对策，判定为后对策；② 选项中若同时有对策和问题，优选对策；③ 对策项必须精准对应文段的主体和具体做法 |
| 高频错因 | 选了问题项（只概括了前半段）；对策项的主体不对（如文段说银行应做，选项说金融体系应做）；对策项表述过于绝对或偷换了文段的程度词 |
| confidence | high |

## 补充说明

后对策是各类公考言语题中高频出现的文段结构。优选对策项的核心理由是：对策项体现解决问题的导向，比仅概括问题的选项更契合文段重心。需注意对策项必须精准对应文段的主体和具体做法，不能偷换主体或扩大范围。

## 不适用条件

- 文段为纯问题阐述型（全文只列问题未提对策），选项中无对策项时，本方法不适用，应选概括最全面的选项。
- 文段为并列结构（问题与对策分量相当或前后并列两部分），不能简单优选对策项。

## 反向触发

- 当选项中的对策项偷换了文段主体（如文段说"银行应做"，选项说"金融体系应做"）时，应换用主体匹配法排除该对策项。
- 当文段重心在原因分析而非对策提出时，应换用因果类文段方法，选"原因"类选项。
