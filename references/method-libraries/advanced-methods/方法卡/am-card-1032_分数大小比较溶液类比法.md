# 方法卡：分数大小比较溶液类比法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 分数大小比较溶液类比法 |
| 适用题型 | 资料分析——分数大小比较 |
| 触发场景 | 需要比较两个分数大小（如A/B vs C/D） |
| 步骤逻辑 | ① 把分数看作浓度（溶质/溶液）；② 分子增长率>分母增长率→后面的数更大（浓度升高）；③ 分子增长率<分母增长率→后面的数更小（浓度降低）；④ 涉及减法时：从右往左用加法思考，不容易出错 |
| 高频错因 | ① 直接计算分数值→计算量大；② 不用增长率比较→效率低 |
| confidence | high |

## 补充说明
类比思维。把分数比大小转化为溶液浓度问题：分子=溶质，分母=溶液，增长率=浓度变化方向。基础要求：加减法口算要特别熟练。

## 不适用条件
- 分子或分母为负值或零时，浓度类比方向不再成立，需改用直接计算或符号判断。
- 分数含绝对值或开方等非线性运算时，类比关系失效。
- 增长率差异极小、估算误差可能跨越选项时改用精算。

## 反向触发
- 若两分数分母相近、分子差值显著，直接比较分子更省时，应换用分子优先法。
- 若题干给出的是比值/比例关系而非分数形式，应换用比例性质直接推导。
- 若涉及多步复合运算（乘除混合），应补充分步精算核验，避免类比失真。
