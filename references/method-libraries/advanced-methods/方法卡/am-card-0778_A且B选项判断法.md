# 方法卡：A且B选项判断法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | A且B选项判断法 |
| 适用题型 | 言语理解——概括类选项的判断与选择 |
| 触发场景 | 选项同时涵盖两个并列要素，需要判断其是否完整对应原文的并列结构 |
| 步骤逻辑 | 1. 识别"A且B"类选项：选项同时表达两个并列要素；2. 这类选项概括全面，是正确答案的概率较高；3. 看能否与原文并列结构对应上；4. 如果对应得上，优先检查这类选项 |
| 高频错因 | 被单一方面的选项带跑偏，忽略全面概括的选项只看到后一半内容对应，忽略前一半 |
| confidence | medium |

## 不适用条件

- 文段只论述一个方面时，"A且B"选项可能属于过度概括
- 当"A且B"选项中的某一部分在原文无依据时，不能仅凭结构全面就选
- 并列结构不等于正确概括，需逐一验证每个要素

## 反向触发

- 若原文只提到A未提到B，则"A且B"选项不可选
- 若存在更精准对应原文的单一要素选项，优先选精准项
