# 方法卡：效率差思想

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 效率差思想 |
| 适用题型 | 数量关系——工程问题 |
| 触发场景 | 两人合作完成工作，其中一人替另一人干活；已知总工作量和各自效率 |
| 步骤逻辑 | 当两个人效率不同时，可用效率差简化方程。1. 假设全部由效率较低者完成，算出假设工作量；2. 用实际工作量减去假设工作量，得到工作量差；3. 高效率者替代低效率者的时间=工作量差÷效率差；4. 代回总工作量核验 |
| 高频错因 | 效率差方向搞反（高减低还是低减高）；忘记用总工作量做比较基准 |
| confidence | medium |

## 补充说明

- 本质是把列方程解方程的步骤简化
- 不理解就直接列方程，效果一样

## 不适用条件

- 两人效率相同或效率差为零时，本法无意义
- 工作总量未给出或需要先推导时，应先求总量再判断是否可用效率差
- 涉及三人及以上替换时，效率差法的步骤会变复杂，建议列方程

## 反向触发

- 若题目问的是合作完成时间而非各自工作时间，优先用整体思想而非效率差
- 若题目只给效率比，可先按比例赋值；若无法建立工作量差与替代时间的对应关系，则改列方程
