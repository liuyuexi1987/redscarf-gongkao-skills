# 方法卡：自带逻辑词判断法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 自带逻辑词判断法 |
| 适用题型 | 逻辑填空——成语辨析 |
| 触发场景 | 选项中出现"举足轻重""不可或缺""有的放矢""行之有效""得天独厚"等自带逻辑的词 |
| 步骤逻辑 | ① 识别词是否"自带逻辑"（需要特定前提才能用）；② 检查文段是否有对应逻辑；③ 无对应→排除；④ 有对应→优先选 |
| 高频错因 | ① "举足轻重/不可或缺"前面必须有铺垫重要性，没有不能突然冒出；② "有的放矢"需要有"针对性"的对应；③ "行之有效"可直接填（措施都希望有效），无需逻辑对应 |
| confidence | high |

## 补充说明
自带逻辑词vs自然填入词的区分：自然填入的词（如"行之有效"）不需要额外逻辑对应；自带逻辑的词（如"有的放矢"需针对性、"独具匠心"需特别之处、"得天独厚"需优势体现）必须有对应逻辑才能选。

## 不适用条件
- 选项均为普通中性词、无自带逻辑前提的成语（如单纯描述状态的"宁静""安然"）时，本方法不产生区分价值。
- 文段逻辑关系明确且选项间无"自带逻辑词"特征差异时，应以语境呼应为主，无需套用本方法。
- 选项中的词虽看似自带逻辑，但所有选项同属一类（如都需"重要性铺垫"），彼此前提同质时无法用本方法排除。

## 反向触发
- 当自带逻辑词的对应前提在文段中模糊不清时，应换用"前后空呼应关系"或"正反对比反推法"从其他空格反推该空。
- 当选项差异不在逻辑前提而在语义轻重或感情色彩时，应改用语义辨析或语体色彩判断。
- 当选项含自带逻辑词但文段却故意给出反前提（陷阱题）时，应补充核验文段是否在转折后给出真正前提，避免误排除。
