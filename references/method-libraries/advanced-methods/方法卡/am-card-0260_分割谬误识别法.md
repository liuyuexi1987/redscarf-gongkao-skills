# 方法卡：分割谬误识别法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 分割谬误识别法 |
| 适用题型 | 推理方式/论证结构相似题（类比推理） |
| 触发场景 | 题干甲说"XX群体有Y特征"，乙用个体反驳；问哪项对话方式最相似 |
| 步骤逻辑 | 1. 识别题干中甲的表述是**集合概念**（如"杭州人美""人们没信仰"），描述的是群体整体特征；2. 乙把集合概念**误解为每个个体都有该特征**，然后用个例反驳；3. 这种错误叫**分割谬误**：集合特征 ≠ 个体特征；4. 在选项中找同样的结构：集合表述→误解为个体→个例反驳；5. 排除不含此结构的选项（如"你的受贿金额"是个体非集合；"别人"虽是集合但乙没把它当个体处理） |
| 高频错因 | 把"偷换概念"当万能答案；无法区分分割谬误和话题转移、类比不当等其他逻辑错误 |
| confidence | high |

## 不适用条件

1. 题干不含集合概念与个体反驳结构（如甲乙讨论同一对象、不存在"群体→个例反驳"模式）
2. 问法为"加强/削弱"而非推理方式/论证结构相似
3. 选项为纯形式逻辑推理（如三段论、假言推理），无集合-个体关系

## 反向触发

1. 题干中甲乙双方讨论的是同一个体，不存在集合概念被误解为个体的结构
2. 乙的反驳是话题转移或偷换论题，而非用个例反驳集合特征
3. 题干逻辑错误类型为类比不当、以偏概全，而非集合与个体的混淆
