# 方法卡：强加因果识别法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 强加因果识别法 |
| 适用题型 | 逻辑谬误相似性判断题、归因类加强削弱题 |
| 触发场景 | 两件事同时发生/相关性高，就断定有因果关系 |
| 步骤逻辑 | 1. 三种常见形式：①时间重叠→误判因果（公鸡打鸣→太阳升起）；②地点/群体重叠→误判因果；③因和果猜反了（考得好→爱学习 vs 爱学习→考得好）；2. 识别关键：两件事可能有共同原因（夏天→冷饮销量↑ & 溺水人数↑）；3. 做题时找"两件事本来无因果，仅因表面联系就断定因果"的选项 |
| 高频错因 | 把"先后发生"等同于"因果关系"；忽略可能存在共同原因或因果倒置 |
| confidence | high |

## 补充说明

方法强调"儿童鞋码大小与语言能力"是典型虚假相关——两者的共同原因是"年龄"。

## 不适用条件

- 题干已明确给出因果机制或实验设计，需要做的是具体推理而非识别虚假相关。
- 题目考查的是逻辑推理形式（如条件推理、搭桥），而非归因谬误。

## 反向触发

- 两件事同时发生或高度相关，选项或题干直接断定存在因果关系。
- 题目要求找"最能削弱上述因果推断"的选项，且可能存在共同原因或因果倒置。
