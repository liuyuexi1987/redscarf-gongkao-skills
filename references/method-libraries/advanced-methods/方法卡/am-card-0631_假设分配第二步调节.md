# 方法卡：假设分配第二步调节规则

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 假设分配第二步调节规则 |
| 适用题型 | 资料分析——假设分配法的第二步精细化 |
| 触发场景 | 假设分配第一步分完后，剩余金额需要第二步分配 |
| 步骤逻辑 | ① 当R在0%~10%附近：第二步用剩余×10%近似，然后根据R与10%的差距微调（R<10%则往下取整，R>10%则往上取整）；② 当R在分数附近（1/4、1/3、1/2等）：第二步直接用剩余除以(n+1)（即四幺五法）；③ 当R≈25%：第二步除5；④ 当R≈33%：第二步除4；⑤ 当R≈50%：第二步除3；⑥ 当R≈67%：第二步×0.4；⑦ 当R接近100%：第二步直接平分 |
| 高频错因 | 第二步过度精确计算，浪费时间；不根据R大小选择不同的调节策略 |
| confidence | medium |
| 不适用条件 | 1. R不在常用简化区间附近，没有对应简化策略时本方法不适用
| 反向触发 | 1. 看到R恰好是常见分数（25%、33%、50%），直接用对应简化策略（除5/除4/除3），不需要逐个试算
2. R很小（接近零），用剩余乘以近似值再微调即可
3. R接近全部，第二步直接平分，无需复杂调节
4. 第一步分配后剩余量极小，直接看选项能排除就停，不做第二步 |
2. 第一步分配后剩余金额已很小，继续精确分配对选项判断无意义
3. 增长率为负值（下降）时，假设分配整体策略需调整，第二步调节规则不直接适用 |

## 补充说明

第二步的核心原则："大头分完，小头随意"——第一步精确分配后，剩余金额很小，第二步的微小误差不会影响最终选项判断。核心要点："最后一步差一不是毛病"。
