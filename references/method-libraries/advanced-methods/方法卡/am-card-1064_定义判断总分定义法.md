# 方法卡：定义判断总分定义法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 定义判断总分定义法 |
| 适用题型 | 判断推理——定义判断 |
| 触发场景 | 定义判断中定义较长，先给总概念再给具体解释 |
| 步骤逻辑 | ① 识别"总"：大概念/核心定义（通常在第一句）；② 识别"分"：具体解释/举例/限定条件；③ 总概念决定范围，分解释决定细节；④ 选项必须同时满足总概念和分解释 |
| 高频错因 | ① 只看分解释不看总概念→范围判断错误；② 只看总概念不看分解释→细节遗漏 |
| confidence | high |

## 补充说明
总分定义法的关键是先识别"总差"（大概念）和具体解释。总概念给出定义的范围边界，分解释给出判断的具体标准。两者缺一不可。

## 不适用条件
- 定义只有一句话、没有总分结构时
- 题目给出多个定义需要对比时（应使用多定义对比策略）
- 定义虽长但没有先总后分的逻辑结构时

## 反向触发
- 定义简短且无层次结构时，不应强行拆分"总"和"分"
- 定义本身是并列结构而非总分结构时，总分定义法不适用
