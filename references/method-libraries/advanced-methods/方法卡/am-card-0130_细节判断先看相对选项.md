# 方法卡：细节判断先看相对选项

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 细节判断先看相对选项 |
| 适用题型 | 言语理解-细节判断题（原文相符/不符） |
| 触发场景 | 细节判断选项含比较、范围、程度或趋势词，需要优先回原文核对依据 |
| 步骤逻辑 | 1. 标出"高于、先于、主要、全部、越来越"等关系和力度词 2. 回原文核对是否存在同一主体、同一范围和明确比较依据 3. 原文仅分别陈述两个对象时，不能自行补出比较关系 4. 语气强弱只用于定位风险点，最终按原文证据判断 |
| 高频错因 | 把两个对象同时出现误当成比较；只看选项语气猜答案，没有回原文核对主体、范围和力度 |
| confidence | high |

## 补充说明

比较、范围和程度词是定位线索，不是答案规律。出现"高于、先于、重于、升华"等表述时，重点核对原文是否建立了相同对象之间的比较；没有明确依据时属于无中生有，有依据时不能因词语强就排除。

## 不适用条件
1. 当所有选项都含比较/对比表述时，此筛选策略失效，需逐个比对原文
2. 当所有选项用词都很委婉/相对时，无法通过表述强度快速区分

## 反向触发
1. 当有多个选项都含对比表述时，应逐一回到原文核实，不能仅凭比较词排除
2. 当题目的细节判断涉及数字/日期精确匹配而非语义判断时，此法不适用，需逐项核对
