# 方法卡：鸡兔同笼利润统筹
## 基本信息
| 字段 | 值 |
|------|-----|
| 方法名 | 鸡兔同笼利润统筹 |
| 适用题型 | 数量关系-统筹优化/利润最大化问题 |
| 触发场景 | 两种产品总数量固定，有成本约束，求利润最大时各产品数量 |
| 步骤逻辑 | 1. 确定总数量和成本上限；2. 假设全部生产高利润品，算出总成本；3. 与实际成本上限求差值；4. 差值除以两产品单件成本之差，得低价品数量 |
| 高频错因 | 混淆"利润高"和"利润率高"；忘记成本约束直接全产高价品 |
| confidence | high |
## 补充说明
本质是鸡兔同笼的假设法。先假设全部生产单件利润高的产品，算出成本与上限的差值，再用单件成本差来"降成本"。售价用于判断谁单件利润更高（确定生产方向），成本用于最终计算。关键：利润最大化时一定卡在成本约束的边界上。
## 不适用条件
- 产品种类超过两种或约束条件超过一条（利润函数或约束非线性），鸡兔同笼结构不适用。
- 单件利润随产量变化（如阶梯定价、批量折扣），成本或利润不是常数。
- 题目不要求利润最大，而是求特定产量组合或满足其他非利润目标。
## 反向触发
- 题面含"成本""利润"但是简单的盈亏计算或打折问题，无两种产品比较和约束优化结构。
- 问题为工程/合作效率问题用鸡兔同笼类比但实际约束为时间而非成本，需转用工程方法。
