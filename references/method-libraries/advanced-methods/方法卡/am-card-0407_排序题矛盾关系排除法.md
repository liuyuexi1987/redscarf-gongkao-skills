# 方法卡：排序题矛盾关系排除法

## 基本信息

| 字段 | 值 |
|---|---|
| 方法名 | 排序题矛盾关系排除法 |
| 适用题型 | 言语理解——语句排序题 |
| 触发场景 | 两个句子内容存在矛盾或对立关系（如一句引出旧认知/常见误解，另一句纠正或细化该认知），需判断谁先谁后 |
| 步骤逻辑 | ① 先找首句：排除有明确衔接词（如"但是""然而"）或依赖其他句子内容的选项；② 矛盾关系定先后：若两句存在矛盾关系，判断哪句是"引出旧认知/常见理解"、哪句是"纠正或细化"——旧认知在前，纠正/细化在后；③ 用连接词验证顺序：如存在"不仅…还…"等递进结构，确认递进方向与排序一致；④ 层次验证：若某句内容属于更高层次（如从技术层面升到文化层面），该句不能被低层次内容的过渡句包含 |
| 不适用条件 | 仅当排序题中存在明显矛盾/对立的句子对时才适用；无矛盾句时应优先使用下定义放首句、捆绑法等其他排序策略 |
| 高频错因 | 把矛盾关系的两句话顺序搞反（先讲结论再讲旧认知就不通顺）；把含递进连接词的过渡句误当首句；没注意句间的内容层次差异 |
| confidence | high |
| 反向触发 | 排序题中无明显矛盾/对立的句子对时，本方法不适用，应改用下定义放首句、捆绑法、时间顺序等其他排序策略；若仅通过矛盾关系定序后仍有多组候选排列无法确定，需用首句排除、衔接词验证等方法进一步缩小范围 |


> **使用边界**：本方法用于提供优先检查方向，不可单独据此作答；最终需回到题干关系、原文证据或选项条件完成验证。
