# 方法卡：断点拆桥法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 断点拆桥法 |
| 适用题型 | 逻辑判断——一般质疑（论据结论关键词不一致） |
| 触发场景 | 论据的关键词和结论的关键词看似相关但不是一回事；结论中出现论据里没有的突兀新词 |
| 步骤逻辑 | ① 对比论据关键词和结论关键词，确认是否真的是同一个概念；② 如不是一回事，指出推不出关系；③ 造句验证：虽然[论据]，但是[论据关键词≠结论关键词]，所以[结论]推不出来 |
| 高频错因 | 被论据结论的表面相似性忽悠，误以为是一回事；忽略结论中新增的关键词 |
| confidence | medium |

## 补充说明

断点拆桥的典型实例：① 下雪早晚 vs 冬天冷热程度（第一场雪早推不出冬天最冷）；② 实际节电量 vs 活动实际效果（节电量少不等于活动没效果）；③ 方法拙劣 vs 人愚蠢（方法拙劣推不出人愚蠢）；④ 销售额不变 vs 购买力不变（单价上涨时销售额不变意味着购买量下降）。注意：断点不明显时，要特别关注结论中是否有论据里没有的新词（如"预防""颠覆""实际效果"）。

## 不适用条件

- 论据与结论关键词完全一致、无新词出现时不适用。
- 题干为纯演绎推理（条件命题连锁）而非一般质疑时不适用。
- 题干要求支持/加强而非质疑时不适用。

## 反向触发

- 结论含程度限定词时，改用"程度词精准匹配法"。
- 结论含"如果…那么""只有…才"等绝对化关联词时，改用"严谨逻辑关系质疑法"找A且非B。
- 题干要求支持且有断点时，转用"支持题断点搭桥补论据"。
