# 方法卡：增量比现期替代增速比较

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 增量比现期替代增速比较 |
| 适用题型 | 资料分析——增速大小比较 |
| 触发场景 | 需要比较多个对象的增速（增长率）大小，且已知现期值和增量值 |
| 步骤逻辑 | ① 找出每个对象的增量和现期值；② 用增量÷现期替代增速进行比较（因增量/现期与增量/基期同向变化）；③ 直接比较各组增量/现期的大小即可判断增速高低 |
| 高频错因 | ① 混淆"比较大小"和"算具体值"，增量/现期不等于实际增速，仅用于比大小；② 忘记减少量（负增长）的直接排除 |
| confidence | high |

## 补充说明

增量/现期越大，增速越大，这是同向关系而非等量关系。比大小时无需算出基期，直接用材料给的现期和增量即可，节省时间。当估算误差可能跨越选项或改变结论时，改用精算/验证。

## 不适用条件

1. 增量为负值（负增长），增量/现期的比较方向需要额外判断，简单比大小可能出错。
2. 需要求出增速的具体数值（而非仅比大小），本法只能判断排序不能给出数值。
3. 各对象的现期值量级差异极大，增量/现期的比值含义可能受量纲影响。

## 反向触发

1. 需要比较多个对象的增速大小，且材料已给出各对象的现期值和增量值。
2. 基期值未直接给出，算基期需要额外一步减法，用增量/现期可省去此步。
3. 题目只要求排序（最快/最慢），不要求具体增速百分比。
