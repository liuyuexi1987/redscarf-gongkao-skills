# 方法卡：和差问题速算

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 和差问题速算 |
| 适用题型 | 数量关系——和差问题 |
| 触发场景 | 已知两个数的和与差；需要求这两个数 |
| 步骤逻辑 | 已知两个数的和与差，直接用公式求解，跳过列方程。；1. 大数 = (和 + 差) ÷ 2；2. 小数 = (和 - 差) ÷ 2 |
| 高频错因 | 和与差混淆，把"和+差"和"和-差"弄反；忘记除以2 |
| confidence | medium |

## 补充说明

- 本质是跳过列方程的过程，直接用公式
- 和列方程结果一样，只是更快

## 不适用条件

- 题目涉及三个或更多量时，不能直接用两量和差公式
- 和或差未直接给出、需要先推导时，应先列方程再判断是否可用
- 差的方向不明确时（谁减谁），需先确认再代入公式

## 反向触发

- 若题目给出的是积与差或商与差，不使用本卡
- 若题目问的不是两个量本身，而是它们的倍数关系或差值变化，需另行分析
