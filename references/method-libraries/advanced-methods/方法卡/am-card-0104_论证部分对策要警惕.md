# 方法卡：论证部分对策要警惕

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 论证部分对策要警惕 |
| 适用题型 | 中心理解题（说理类文段） |
| 触发场景 | 文段中有多处对策，其中某个对策出现在解释说明/原因解释的位置（如"毕竟""因为"引导的从句中） |
| 步骤逻辑 | 1. 识别"毕竟/因为/由于"等因果解释词；2. 由因果词引导的对策是对前面对策的解释说明，不是独立重点；3. 真正的主旨对策是被解释的那个对策，不是解释中的对策；4. 选项中出自论证部分的对策，出处有误，不能选；5. 判断是否为论证：看这个内容能否支撑你认定的主旨句 |
| 高频错因 | 看到"必须经历路考"这样的对策表述就选了，但它是"毕竟"引导的解释不能区分"主对策"和"论证中的对策"被出题人故意设置的"论证部分对策"选项迷惑 |
| confidence | high |

## 不适用条件

1. 文段只有一处对策，"因为/由于"引导的是对问题的原因分析而非对策的解释——因果词引导的是问题分析，不是对策论证。
2. 因果词引导的对策本身是全文唯一主旨对策，前文没有其他对策——不存在"主对策vs论证对策"的区分。
3. "因为/由于"引导的是对策的必要性论证（说明为什么要这样做），而非替代性对策——必要性论证仍服务于主对策。

## 反向触发

1. 被解释的对策在文段中位置靠前且后文有转折，说明它可能不是主旨——参见"转折前对策不抓"。
2. 因果词引导的内容是独立的新论点而非对前面对策的解释，应将其作为独立主旨判断。
3. 文段中多个对策方向一致且因果词只是串联关系，不存在"主从"之分——整体对策方向才是主旨。
