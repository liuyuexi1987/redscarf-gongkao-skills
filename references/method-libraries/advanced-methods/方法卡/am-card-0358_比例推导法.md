# 方法卡：比例推导法（行程几何题）
## 基本信息
| 字段 | 值 |
|------|-----|
| 方法名 | 比例推导法（行程几何题） |
| 适用题型 | 数量关系-行程问题/圆周跑道/已知速度比和时间比求半径 |
| 触发场景 | 两人同向沿不同半径跑道走，已知速度比和时间比，求面积或半径 |
| 步骤逻辑 | 1.路程=速度×时间→路程比=速度比×时间比（比例可直接乘除） 2.圆周路程=2πR→路程比=半径比 3.半径差=已知间距→用份数差求出每份实际长度→得各半径 4.代入面积公式S=πR²求解 |
| 高频错因 | 忘记半径比等于路程比；半径差对应份数差时份数算错；实际速度条件为冗余信息被误用 |
| confidence | high |
## 补充说明
用速度比与时间比直接算出路程比，进而得到半径比。关键点：甚至不需要代入具体速度值，比直接列方程快很多。比例可以直接乘除，不必额外列方程。已知半径间距与份数差即可求出实际半径，代入面积公式即可。

## 不适用条件

- 跑道不是同心圆或不是完整圆周（如椭圆跑道、半圆跑道），半径比等于路程比的前提不成立
- 两人运动方向不同（一人顺时针、一人逆时针），路程比计算方式会变化
- 题目给出的不是速度比而是具体速度值和时间值，可直接用公式计算，无需比例推导

## 反向触发

- 当半径比求出但代入间距后得到负数或无意义结果时，应回退检查路程比计算是否有速度比和时间比的乘法方向错误
- 当题目要求面积比而非具体面积时，半径比直接平方即可，不需要算出实际半径
