# 方法卡：选人/选物优先级法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 选人/选物优先级法 |
| 适用题型 | N选M的组合排列题（如五选三、四选二） |
| 触发场景 | 条件中出现"如果选A则也选B"或"若A则B"形式，且有明确的N选M背景 |
| 步骤逻辑 | 1. "选A则选B"意味着 B的优先级高于A（B始终踩在A头上）；2. 若A包含的对象数 ≥ N-M（未选中的人数），则B必选；3. 例：五选三，"选甲或乙则选丁"→丁踩着两个人，只排除2个名额，丁必选；4. 用此法快速锁定必选项，再结合其他条件推剩余排列 |
| 高频错因 | 把"选A则选B"和"选A且选B"混淆；忘记检查是否满足N-M的条件 |
| confidence | high |
| 不适用条件 | 条件中没有"如果选…则选…"形式的充分条件句，只有排除条件；题目是全排列，没有"选N人"的筛选背景 |
| 反向触发 | 条件表述为"选A则不选B"（排斥关系），而非"选A则选B"（包含关系），优先级法不适用；题目只要求排列顺序而非筛选组合 |

## 补充说明

方法提示：选A就选B，说明B被选中的优先级高于A。这个结论可直接用于快速排除选项。注意前件是"或"（A或B→选D）时，D踩着两个人。
