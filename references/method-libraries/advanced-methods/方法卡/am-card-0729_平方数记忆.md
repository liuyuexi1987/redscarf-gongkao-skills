# 方法卡：平方数记忆

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 平方数记忆 |
| 适用题型 | 数量关系——数列、年龄与平方差计算 |
| 触发场景 | 题目出现平方数、平方差或用平方数表示年龄，需要快速识别常见平方值 |
| confidence | medium |
| 步骤逻辑 | 1. 记住 1-20 的平方数和 25²=625；2. 验证常用平方数避免混淆（如 12²=144、13²=169、15²=225）；3. 遇到平方差时用 (a+b)(a-b) 分解，不逐个平方后相减 |
| 高频错因 | 相邻平方数记混（如 7²=49 与 8²=64）；a² 与 2a 混淆（如把 12² 记成 24） |

## 补充说明

- 年龄问题中常用：36岁（父母）、64岁（爷奶）
- 两个平方数之差 = (a+b)(a-b)
- 奇数数列公式：2n-1（第n项=2n-1）

## 不适用条件

- 题目涉及立方、高次幂或非整数平方根。
- 仅靠记忆平方数无法处理题目中的其他约束。

## 反向触发

- 超出熟悉范围时用邻近平方展开或乘法计算。
- 看到平方差结构时转用 `(a+b)(a-b)`，不要逐个平方后相减。
