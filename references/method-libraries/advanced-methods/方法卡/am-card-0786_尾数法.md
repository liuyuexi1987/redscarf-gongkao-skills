# 方法卡：尾数法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 尾数法 |
| 适用题型 | 资料分析-加减法-多个数字精确求和或求差 |
| 触发场景 | 题目要求多个精确整数求和/求差，且选项尾数有差异 |
| 步骤逻辑 | 1. 确认数据为精确值（无四舍五入的万/亿单位）2. 观察选项尾数差异，决定看最后一位还是两位 3. 只取每个数字对应位数相加，对齐选项选出答案 |
| 高频错因 | 数据有四舍五入（如"XX点X万"）时误用尾数法；忽略时间段导致加错年份 |
| confidence | medium |

## 不适用条件

1. 数据为四舍五入后的近似值（如"234.3万"、"约XX万"）时，尾数无意义，不可使用
2. 选项末几位完全相同，尾数法无法区分时，需改用其他方法
3. 加减混合运算中存在乘除步骤时，单纯尾数相加不成立

## 反向触发

1. 看到单位为"个/所/次"等整数且选项尾数不同时，立即考虑尾数法
2. 发现数据带有小数或"约"字时，暂停尾数法，改用其他方式
3. 自己用尾数法算出的结果不在选项中时，检查是否误用了四舍五入数据

## 补充说明

尾数法的使用前提是"精确求和"。如果数据带有小数且可能是四舍五入的结果（如"234.3万"），则不能使用尾数法，因为.3并非精确值。只有单位为"个/所/次"等不可分割的整数时才安全使用。看几位取决于选项设置：选项末一位不同看一位，末两位相同则看两位。此外资料分析必须注意时间段，这是首要出错点。当估算误差可能跨越选项或改变结论时，改用精算/验证。
