# 方法卡：细节题四要素核对法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 细节题四要素核对法 |
| 适用题型 | 言语理解——细节题 |
| 触发场景 | 题目问"以下说法正确/不正确的是""与原文相符/不符的是" |
| 步骤逻辑 | ① 先看选项，圈出每个选项的核心词（主体/数据/时间/关系）；② 回原文逐一定位，核对四要素：主体是否一致、数据是否准确、时间是否对应、关系是否偷换；③ 主体偷换/数据篡改/时间错位/关系颠倒→排除；④ 选"与原文最一致"的选项，不选"推断过度"的选项 |
| 高频错因 | ① 只看选项大意相近就选了，没逐项核对细节；② 被"偷换主体"迷惑（如原文说"A"选项说"B"）；③ 被"程度偷换"迷惑（原文"可能"选项"一定"） |
| confidence | high |

## 不适用条件
- 题型不是细节判断（如中心理解、逻辑填空、语句填空）时
- 原文过长且选项涉及多处分散信息、逐项核对成本过高时，需结合预判优先验证
- 选项为推断型而非原文对照型时，四要素核对法适用性降低

## 反向触发
- 看到"以下说法正确/不正确的是""与原文相符/不符的是"时，立即圈出每个选项的四要素（主体/数据/时间/关系）
- 选项中出现具体数字、时间、比较关系时，优先核对该要素
- 某选项的主体与原文不一致时，该选项大概率错误

## 补充说明
细节题是言语理解中最"不需要理解"的题型——答案就在原文里，只需要逐项核对。核心策略：先看选项再看原文，带着选项的关键词去定位。常见偷换方式：主体偷换、范围偷换（部分→全部）、程度偷换（可能→一定）、时间偷换（将来→已经）。
