# 方法卡：排序题捆绑法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 排序题捆绑法 |
| 适用题型 | 言语理解——语句排序 |
| 触发场景 | 语句排序题，需要确定句子的先后顺序 |
| 步骤逻辑 | ① 找转折词/桥梁词确定前后捆绑关系；② "一方面/另一方面"→必须相邻且顺序固定；③ 代词（这/此/其）→代词所在句必须紧跟被指代的句子；④ 先确定捆绑组，再确定组间顺序 |
| 高频错因 | ① 不找捆绑直接排序→选项间差异大无法判断；② 忽略代词指代→捆绑关系错误 |
| confidence | high |

## 补充说明
排序题的核心是"先捆绑后排序"。通过关联词（一方面/另一方面）、代词（这/此）、时间词（首先/然后/最后）确定哪些句子必须相邻，再确定整体顺序。

## 不适用条件

- 句子间无明显关联词、代词、时间词等捆绑线索时，无法构建捆绑组。
- 选项之间差异主要在首尾句而非中间顺序时，捆绑法效率降低。

## 反向触发

- 捆绑关系构建后仍无法确定组间顺序时，应换用"首尾句特征法"补充判断。
- 多个捆绑组相互冲突时，应优先验证代词指代的唯一性，再重新分组。
