# 方法卡：转折关注相反法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 转折关注相反法 |
| 适用题型 | 逻辑填空——转折结构 |
| 触发场景 | 转折词（但、然而、却、不过）出现在空格附近 |
| 步骤逻辑 | ① 找到转折词；② 转折前后逻辑相反；③ 从转折的另一侧推导空格方向；④ 例："有限"→转折后应是"无限"→选"永恒"或"不朽" |
| 高频错因 | ① 只关注搭配不关注转折→选了搭配对但逻辑不对的词；② 转折前后不一定是完全相反，也可能是程度递减 |
| confidence | high |

## 不适用条件
- 转折词不在空格附近、距离过远时，转折信号对空格的约束力减弱
- 文段为并列或递进结构，转折词仅起轻微让步作用时
- 空格处需要的不是语义相反方向，而是搭配或程度的精准匹配时

## 反向触发
- 看到"但""然而""却""不过"等转折词紧邻空格时，立即从转折另一侧推导空格方向
- 转折前为负面/否定表述时，转折后空格应选正面/肯定方向的词

## 补充说明
转折是最强的逻辑信号之一。"有限"→转折后必须是"无限"的方向→"永恒"比"光辉"更直接。搭配也要同时满足："永恒的定格"比"不朽的定格"搭配更好→选"永恒"。
