# 方法卡：加强削弱题——话题偷换识别法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 加强削弱题——话题偷换识别法 |
| 适用题型 | 判断推理——加强削弱类（选项看似相关但偷换话题） |
| 触发场景 | 选项讨论的问题表面与题干相关，但关键词（主体/属性/范围）与论点不一致 |
| 必要输入 | 已锚定论点核心关键词（主体+属性+范围） |
| 步骤逻辑 | ① 锚定论点核心关键词：明确论点讨论的主体、属性和范围；② 逐个检查选项是否严格对应这些关键词；③ 四种常见偷换方式：a) 主体偷换——论点说实际发生率，选项说个人倾向或可能性（倾向≠实际率）；b) 范围偷换——论点说某个状态的形成，选项说该状态的变化或表现；c) 属性偷换——论点讨论事物的起源/来源，选项讨论事物的含义/性质；d) 论据否定向——否定论据中的某个事实不等于拆桥（不攻击推理前提） |
| 验证动作 | 回看被排除的选项：能否用一句话说清"选项讨论的X ≠ 论点讨论的Y，因为____"；若说不出明确差异，可能并非偷换 |
| 不适用条件 | 不适用于论点本身模糊或含多个可竞争关键词的场景；本法识别"话题偷换"，与"有无vs多少"的方向偷换属于不同维度 |
| 高频错因 | 被选项表面相关性迷惑，不回到论点核对关键词；把"否论据"当成"拆桥" |
| confidence | high |
| 反向触发 | 1. 当选项与论点的主体一致但属性维度不同（如论点讨论"发生率"，选项讨论"严重程度"），且题目问的是"最能加强/削弱"时，属性不同不一定是偷换——可能是次优支持项，不应直接排除，应与其他选项比较后决策 2. 当排除所有偷换项后无剩余选项可选时，说明偷换判断可能过严，应回查是否将非偷换的合理关联误判为偷换 3. 当论点包含对比结构（如"A比B更有效"），选项需同时涉及A和B的对比，仅讨论A或仅讨论B的选项不是偷换而是片面，排除逻辑不同 |
