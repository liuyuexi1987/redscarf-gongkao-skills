# 方法卡：真假话-隐含条件扩充法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 真假话-隐含条件扩充法 |
| 适用题型 | 判断推理-逻辑判断-真假话类（涉及分配/配对问题） |
| 触发场景 | 真假话题涉及人与属性的分配（如血型、职位），且已知各人属性各不相同 |
| 步骤逻辑 | 1. 找出隐含条件：如"四人血型各不相同"→说"我是AB型"实际等于"我是AB型且其他人不是AB型" 2. 将扩充后的条件进行两两对比，找包含关系（A且B vs B） 3. 若B为假→A且B也为假→违反"只有一假"→所以B必为真 4. 由确定的真信息继续往下推 |
| 高频错因 | 忽略"各不相同"的隐含条件，只看表面表述，导致找不到逻辑链条 |
| confidence | high |

## 补充说明

此方法适用于分配类真假话题。核心思路是把单个表述扩展成复合表述，然后利用包含关系（如果B假则A且B必假）来锁定某些表述一定为真。熟练后可大幅减少假设次数，不必逐人假设。

## 不适用条件

- 真假话题不涉及分配/配对问题（如单纯命题真假判断），没有"各不相同"的隐含条件可扩充
- 题干中没有"各不相同""一一对应"等排他性条件，扩充后无法形成有效的包含关系

## 反向触发

- 当用扩充法推导后发现两个表述都可为假（不违反题干约束），说明包含关系在此题中不成立，应转向逐人假设法
- 当题干涉及的人/属性数量超过5个，扩充后组合过多导致难以比较，应优先考虑找矛盾关系简化，而非继续扩充
