# 方法卡：翻译推理与分析推理错因诊断卡

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 翻译推理与分析推理错因诊断卡 |
| 适用题型 | 充分必要、逆否、且或、除非、真假话、排序、分组、匹配 |
| 触发场景 | 用户做错该类题后，讲解/复盘结束，需要判断错因并写入错因卡或弱点档案时 |
| 步骤逻辑 | ① 先查条件翻译方向是否正确（充分/必要/除非否则）；② 再查推理形式是否有效（逆否、肯后否前）；③ 再查分析推理条件是否全部进入推理；④ 最后归因写入弱点档案 |
| 高频错因 | 翻译方向搞反、逆否误用、肯后否前当成有效推理、且或否定互换错、真假话矛盾没找到、分析条件漏用、从非确定信息入手 |
| confidence | high |
| 不适用条件 | 1. 日常逻辑推理题（非形式化论证）不在本卡诊断范围
| 反向触发 | 1. 用户做对翻译推理或分析推理题后自行复核答案且无需诊断错因
2. 题目属于纯公式记忆题（如问逆否命题公式）不涉及实际错因
3. 题目超出本卡覆盖范围（如削弱加强推理题） |
2. 资料分析模块中的排序比较题不属于本卡
3. 题干条件信息缺失无法进行完整推理时不做诊断 |

## 诊断流程

### 第一步：查条件翻译

- "如果 A 那么 B"→A 推 B，"只有 A 才 B"→B 推 A，方向有没有搞反？
- "除非 A 否则 B"→非 A 推 B（或等价的非 B 推 A），有没有翻译错？
- "A 或 B"的否定→非 A 且非 B，"A 且 B"的否定→非 A 或非 B，有没有搞混？
- 充要条件（当且仅当）→双向推出，有没有只推了一个方向？

### 第二步：查推理形式

- 逆否命题：A 推 B 的逆否是非 B 推非 A，是否正确使用？
- 肯后不推前：B 成立不能推出 A 成立，有没有犯这个错误？
- 否前不否后：非 A 成立不能推出非 B，有没有犯这个错误？
- 选言命题否一推一：A 或 B 中，非 A 成立→B 成立，方向有没有搞反？

### 第三步：查分析推理

- 所有条件是否全部进入推理？有没有漏掉"至少""至多""相邻""不相邻""同组""不同组"等约束？
- 是否从确定信息入手？有没有从非确定信息开始推理导致走弯路？
- 真假话问题：是否先找矛盾关系（一真一假）？矛盾找到了但剩下的话是否正确判断？
- 排列/分组/匹配：是否把所有约束条件用完才得出结论？

### 第四步：查验证与归因

- 翻译结果代回验证：原条件和翻译后的条件是否等价？
- 分析推理结果代回验证：是否满足所有约束条件？
- 归因到具体层：是翻译方向、推理形式、条件遗漏还是真假话矛盾？

## 错因分类表

| 错因类型 | 判定信号 | 典型表现 | 写入弱点档案的建议标签 |
|----------|----------|----------|------------------------|
| 翻译方向搞反 | "只有A才B"翻译成A推B（应为B推A） | 充分/必要条件方向错误，推出方向完全相反 | 判断-翻译推理-条件方向错误 |
| 逆否误用 | 使用了无效推理形式 | 否前、肯后当成有效结论 | 判断-翻译推理-有效形式误用 |
| 肯后当成有效推理 | B成立推出A成立 | 把"如果A那么B"的后件当成了前件的充分条件 | 判断-翻译推理-肯后推前错误 |
| 否前当成有效推理 | 非A成立推出非B成立 | 把必要条件当成了充分条件 | 判断-翻译推理-否前后错误 |
| 且或否定互换错 | A或B的否定写成非A或非B | 应为非A且非B，搞混了且或互换规则 | 判断-翻译推理-且或否定互换错误 |
| 除非否则翻译错 | "除非A否则B"翻译方向错 | 应为非A推B，翻译成A推B | 判断-翻译推理-除非否则翻译错误 |
| 真假话矛盾没找对 | 矛盾关系找错，导致真假判断全错 | 把反对关系当成了矛盾关系 | 判断-分析推理-矛盾关系定位错误 |
| 分析条件漏用 | 排列/分组条件没有全部进入推理 | 漏掉至少、至多、相邻、不相邻、同组、不同组 | 判断-分析推理-条件漏用 |
| 从非确定信息入手 | 没有从确定信息开始推理 | 推理链走弯路或走入死胡同 | 判断-分析推理-推理起点选择错误 |

## 写回建议

- `判断-翻译推理-条件方向错误`："只有A才B"应翻译为B推A，误翻为A推B导致推出方向相反
- `判断-翻译推理-有效形式误用`：A推B只能推出逆否（非B推非A），误用了肯后推前或否前推后
- `判断-分析推理-条件漏用`：排列分组题漏掉了"不相邻"约束，导致排列方案不满足条件
- `判断-分析推理-矛盾关系定位错误`：真假话问题把反对关系（可以同假）当成了矛盾关系（一真一假）

## 使用边界

1. 本卡只用于错因诊断，不替代具体解题方法卡（如 am-card-0661 必要条件翻译法、am-card-0690 等价推出速判法）。
2. 翻译推理和分析推理是可形式化题型，条件完整时可独立复核；若与官方答案冲突，先走冲突复核流程。
3. 用户给出思路时优先对照用户思路归因；没给思路时只能做低置信诊断。
4. 客观题官方答案冲突时先走冲突复核流程，不立即写错因卡。
