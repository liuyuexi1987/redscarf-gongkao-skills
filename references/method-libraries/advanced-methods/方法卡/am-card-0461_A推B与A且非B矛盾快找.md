# 方法卡：A推B与A且非B矛盾快找

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | A推B与A且非B矛盾快找 |
| 适用题型 | 判断推理 > 真假推理（含条件句的矛盾识别） |
| 触发场景 | 多句陈述中含"如果不是X就是Y"（即¬X→Y），需要快速找矛盾对 |
| 步骤逻辑 | 1. "不是X就是Y"可翻译为 ¬X→Y，也可视为 X∨Y（或关系）；2. 其矛盾命题是"既不是X也不是Y"即 ¬X∧¬Y（既非X且非Y）；3. 或者从 ¬X→Y 的矛盾是 ¬X∧¬Y，即前件成立但后件不成立；4. 找到一对矛盾，则这对矛盾必然一真一假；5. 题干说"只有N人猜对"，从矛盾对的真假数量约束入手，用剩余句确定答案 |
| 高频错因 | 把"不是X就是Y"只翻译成或关系，忘记它等价于 ¬X→Y；找矛盾时只看文字相似不看逻辑结构 |
| confidence | high |

## 补充说明

"不是X就是Y"在日常语境中常被理解为"二选一"，但逻辑上等价于"如果非X则Y"（¬X→Y）。其矛盾命题不是"X且Y"，而是"既非X也非Y"（¬X∧¬Y）。找矛盾时必须对照逻辑结构，不能只看文字表面。找到矛盾对后，利用"矛盾必一真一假"的性质，结合题干的真假数量约束，快速排除。

## 不适用条件

- 题干命题中不含"如果不是…就…"或"要么…要么…"等析取/条件句式，仅含简单肯定/否定陈述时，本法不适用
- 题目要求找"等价命题"而非"矛盾命题"时，应使用等价转换（逆否命题）而非矛盾识别
- 真假数量约束缺失（题干未说明几人猜对/猜错）时，矛盾对的性质无法用于推理

## 反向触发

- 若翻译出的矛盾对代入后无法满足题干真假数量约束，检查翻译是否正确——常见错误是把"不是X就是Y"误翻为"要么X要么Y"（互斥），后者矛盾命题不同
- 若题目存在多对矛盾，优先用数量最少的那一对（如二对矛盾中选与题干约束直接相关的），再用剩余命题交叉验证
