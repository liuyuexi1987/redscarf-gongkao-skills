# 方法卡：真假话问题套路解法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 真假话问题套路解法 |
| 适用题型 | 谁说真话谁说假话类题目 |
| 触发场景 | N个人中有人说真话有人说假话，给出各自陈述 |
| 步骤逻辑 | 1. 先看"谁说了关于特殊身份的话"——如"会计师说别人是会计师"→会计师必假（老实人不会说别人是老实人）；2. 用假设法：假设某人为真，顺着推看是否矛盾；3. 若矛盾→该假设为假→从其反面推；4. 串着说的真假话看"链条的首尾"——从最简单的人入手 |
| 高频错因 | 逐个假设所有人，浪费时间；不知道"骗子不会承认自己是骗子"的快速判断技巧 |
| confidence | high |

## 补充说明

方法提示"连锁型真假话"（张三说李四说谎，李四说王五说谎…）要从链条的"开头或结尾"入手，找最好判断的那个人先假设。

## 不适用条件

1. 所有人的陈述完全独立、无交叉引用时，无法利用链条特性简化，只能逐个假设。
2. 题目未明确"恰好一人说真话/假话"等约束条件时，假设法的验证标准不清晰，需先向题干确认约束。

## 反向触发

1. 当假设法推导出多个无矛盾的解时，说明遗漏了某个约束条件，应回头检查题干是否还有未使用的限制。
2. 当"特殊身份判断"技巧（如骗子不会承认自己是骗子）无法直接应用时，不要强行套用，老老实实从最简陈述入手假设。
