# 方法卡：排序题优先占位多

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 排序题优先占位多 |
| 适用题型 | 判断推理——排序/排列组合 |
| 触发场景 | 已知若干约束条件（间隔几人、先后顺序），问可能的排列 |
| 步骤逻辑 | ① 统计每个约束条件的"占位数"（如"乙丙间隔3人"占5个位置）；② 优先从占位最多的条件入手（限制最强，可能性最少）；③ 多个高频条件同时使用，逐步缩小可能排列；④ 逐一验证选项是否在可能排列中 |
| 高频错因 | 从占位少的条件入手导致可能性过多、分析混乱；遗漏顺序固定的条件（如"丁在前"） |
| confidence | high |

## 补充说明

示例：N个位置，若某条件"两人间隔3人"占5位，另一同类型条件（含顺序约束）也占5位，两者合用只剩1个空位。占位越多，剩余位置越少，排列可能性越少，越快出答案。

## 不适用条件

- 约束条件少且彼此独立、占位数相近时，"优先占位多"难以择优，需配合其他筛选。
- 题干只问"是否可能"而非"具体排列"时，本法的逐步缩小收益有限。
- 含动态变量（如轮换、循环位置）的排列中，固定占位思路不直接适用。

## 反向触发

- 所有条件占位数接近且无法择优时，改用"假设—排除"或"枚举验证"。
- 题干含循环/对称结构时，转用对称性分析或周期规律。
- 选项差异只在1-2个位置时，改用"代入选项验证"。
