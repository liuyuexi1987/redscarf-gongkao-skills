# 方法卡：说理类对策优先核对法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 说理类对策优先核对法 |
| 适用题型 | 片段阅读-中心理解题 |
| 触发场景 | 判断文段为说理类，原文出现对策表述（让/应该/需要/要怎么做） |
| 步骤逻辑 | 1. 判断文段是否表达作者观点或解决主张；2. 找到作者认可的对策句，并定位它针对的核心问题；3. 核对选项是否同时覆盖对策主体、动作和目标，排除第三方观点、局部措施和无中生有；4. 若对策只是附带内容或选项均未准确覆盖，再按文段结构判断问题、原因或观点概括 |
| 高频错因 | 把说理类文段选成中性概括，遗漏了对策；或被科普类干扰选项带偏 |
| confidence | medium |

## 不适用条件

1. 文段为科普类或客观介绍类，无作者观点态度
2. 文段虽为说理类但作者明确反对某对策，对策非作者主张
3. 对策句出现在非重点位置（如举例说明中），不是文段核心

## 反向触发

1. 对策句前有"有人认为/部分人觉得"等第三方标记，非作者主张
2. 文段重点在问题分析而非对策建议，对策只是附带提及
3. 四个选项均无对策表述，需回归问题概括或原因分析
