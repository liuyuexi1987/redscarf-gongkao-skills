# 方法卡：容斥尾数速算法
## 基本信息
| 字段 | 值 |
|------|-----|
| 方法名 | 容斥尾数速算法 |
| 适用题型 | 数量关系-容斥问题 |
| 触发场景 | 容斥题选项尾数各不相同 |
| 步骤逻辑 | 1.拿到容斥先看选项尾数是否不同 2.标记各已知数据的尾数 3.只追踪尾数的加减运算 4.锁定选项尾数快速锁定 |
| 高频错因 | 不先看选项就列完整算式；尾数加减算错 |
| confidence | high |

## 不适用条件

1. 选项尾数相同或接近，无法通过尾数锁定唯一答案
2. 运算过程涉及除法或乘方，尾数追踪规律不成立
3. 题目要求精确数值（如需填空而非选答案），尾数法只能验证不能求解

## 反向触发

1. 选项为 A.125  B.225  C.325  D.425（尾数均为 5），尾数法失效
2. 题目为简单的两集合容斥，直接心算即可无需尾数技巧
3. 题干给出的数据含小数或百分比，尾数运算不直接适用

## 补充说明
三级容斥公式：A+B+C-A∩B-A∩C-B∩C+A∩B∩C+都不=总数。因选项尾数不同，只需追踪个位即可，全程不做完整加减。实战约30秒完成。
