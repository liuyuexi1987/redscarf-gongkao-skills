# 方法卡：或关系联立推矛盾

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 或关系联立推矛盾 |
| 适用题型 | 形式推理——多个"或"条件联立，要求推出必然结论 |
| 触发场景 | 条件①为"A或B"型选言，条件②的前提为"非A或非B"型选言，且条件②的后件能与条件①的前件重叠 |
| 步骤逻辑 | ① 写出条件①：A或B→结论C；② 写出条件②：非A或非B→(D且非E)；③ 观察条件②后件中的D是否能启动条件①的前件（如"投资生态"触发"教育或生态"）；④ 若能则直接联立，不需要逆否；⑤ 联立后若推出矛盾（如同时要投资和不投资人工智能），则说明条件②前提不成立；⑥ 非A或非B不成立 → A且B（教育且医药必然投资） |
| 高频错因 | 机械逆否第一个条件（把A或B逆否为非A且非B），而忽略了可以直接联立；或者推出矛盾后不知道该否定哪一步 |
| confidence | high |

## 补充说明

多条件联立时，若某条件后件能启动另一条件的前件，可直接联立不需逆否。联立后若推出矛盾（同时要求某事成立和不成立），则说明触发矛盾的前提不成立，应反向确定其否定为必然结论。注意：机械逆否第一个条件（如把A或B逆否为非A且非B）可能忽略可直接联立的路径。

## 不适用条件

- 条件之间无前件/后件重叠，无法直接联立时，不适用本方法，应逐条逆否推导。
- 题干条件全部为"且"关系，不存在选言联立结构时，不适用本方法。

## 反向触发

- 当联立后未推出矛盾而只是推出新结论时，应换用"或关系否一推一逆推"方法沿链推导。
- 当条件②后件与条件①前件只是部分重叠时，应补充核验重叠部分是否足以触发条件①，避免误判联立成立。
