# 方法卡：分数速算（拆分与放缩）

## 基本信息
| 字段 | 值 |
|------|-----|
| 方法名 | 分数速算（拆分与放缩） |
| 适用题型 | 资料分析-分数比较/计算（占比、比重、单产等） |
| 触发场景 | 需要快速计算或比较分数值，尤其是分数靠近整数倍或两个分母接近时 |
| 步骤逻辑 | 【拆分法】<br>1. 找到分数靠近的整数（如接近1/2）<br>2. 拆成整数部分+余数部分<br>3. 分别估算余数占比<br>【放缩法】<br>1. 观察两个分数的分母差值<br>2. 分子分母同乘或同除使分母统一<br>3. 直接比较分子差值 |
| 高频错因 | 拆分时选错参照整数；放缩比例方向搞反 |
| confidence | high |

## 补充说明
- 拆分法示例：498/536拆成268/536（=50%）+ 230/536（≈43%），得到约93%。
- 放缩法示例：比较498/536与435/484，分母差52≈536的10%，将左式分子分母同减10%（498→448, 536→484），统一后比较448-435=13，用包子法13/4.8≈2.7个百分点。
- 当分数靠近整数（如11/118接近1/10=0.1），用拆分法（1-7%）比直接除更快。
- 包子法：统一后的分子差÷分母的千分数单位，快速得出百分点。

## 不适用条件
1. 分母差距很大（如500与300）时，放缩法精度下降明显，不如直接用计算器除。
2. 分数间需要做加减而非比较时，拆分法的优势不明显。
3. 涉及三个及以上分数同时比较时，放缩法难以统一基准。

## 反向触发
1. 当拆分后余数部分仍难以直接判断大小关系时，改用精算确认。
2. 当分数的分子或分母超过四位数且无明显近似整数倍关系时，直接除法可能更快。
3. 当多个候选放缩方向无法统一到同一分母时，应放弃放缩直接计算。
