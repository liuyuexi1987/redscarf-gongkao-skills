# 方法卡：整除特性部分占整体

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 整除特性部分占整体 |
| 适用题型 | 数量关系——整除特性/比例问题 |
| 触发场景 | 题干出现"某部分占整体的几分之几"；分母是大的质数（17/19/23/29等）；需要确定唯一解 |
| 步骤逻辑 | 题干出现"部分占整体的a/b"形式时，整体是分母b的倍数，部分是分子a的倍数。；1. 识别"部分 = (a/b) × 整体"的形式；2. 整体必须是分母b的倍数；3. 部分必须是分子a的倍数；4. 结合题目限制条件（如总人数范围、最多最少等）确定唯一解 |
| 高频错因 | 忘记整体必须是分母的倍数，直接按数值大小猜答案；多个比例关系时未取最小公倍数 |
| confidence | medium |

## 补充说明

- 如果分母是大质数（如17/19/23），基本可以确定考整除特性
- 多个比例关系时，找分母的最小公倍数确定整体

## 不适用条件

- 题干中比例关系不是"部分占整体"形式时（如两个独立量的比例），不能直接套用
- 分母为小数或百分比时，需先转化为分数形式再判断
- 缺少范围限制条件时，整除特性可能无法确定唯一解

## 反向触发

- 若题目问的是增长率、比重变化等资料分析概念，不使用本卡
- 若比例关系涉及的是三个以上独立量的连比，需先用其他方法化简
