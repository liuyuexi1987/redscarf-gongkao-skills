# 方法卡：代词回找主题词

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 代词回找主题词 |
| 适用题型 | 言语理解——中心理解 |
| 触发场景 | 文段中出现"这""此""其""该"等代词，尤其在靠后位置 |
| 步骤逻辑 | ① 代词出现→往前找它指代的内容；② 指代内容=反复出现的词语/主题词；③ 代词在靠后位置时是重要提示词→往往指向主旨核心 |
| 高频错因 | ① 不回找代词指代→凭感觉理解→偏差；② 代词指代的不是最近的词→需要跳过中间内容找真正的指代对象 |
| confidence | high |

## 不适用条件
- 文段中没有出现代词时
- 代词出现在文段开头且无明确指代对象时
- 题目问的是具体细节而非主旨时

## 反向触发
- 文段无代词或题目问细节而非中心主旨时，不应使用此方法
- 代词指代的是前文整个句子而非某个主题词时，需用其他方法判断主旨
