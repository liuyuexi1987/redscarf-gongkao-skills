# 方法卡：有占比想乘积触发口诀

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 有占比想乘积触发口诀 |
| 适用题型 | 资料分析-含占比的增速/增量题 |
| 触发场景 | 看到题目中有"占比"且需要求增速或增量，立即联想乘积增长率公式 |
| 步骤逻辑 | 识别部分 = 整体 × 占比 -> 判定可用乘积增长率 -> 套用 R = R1 + R2 + R1×R2 |
| 高频错因 | 看到占比变化就直接当增速用，忘记还需换算 |
| confidence | high |

## 不适用条件

1. 占比变化以增速形式直接给出时，无需联想口诀中的百分点换算步骤，直接使用乘积公式。
2. 占比为已知固定值（无变化）时，直接用"部分=整体×占比"求值，不涉及增长率。
3. 题目只要求占比差（百分点）而不要求部分增速时，不适用乘积增长率公式。

## 反向触发

1. 当看到"百分点""占比变化X个百分点"时，应立即联想乘积增长率公式，将百分点÷上期占比换算为R2。
2. 若题目给出整体增速和占比增速（非百分点），可跳过换算直接套用R=R1+R2+R1×R2。
3. 估算误差可能跨越选项时改用精算，完整计算R1+R2+R1×R2三项。
