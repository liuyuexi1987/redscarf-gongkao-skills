# 方法卡：两期比重差公式

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 两期比重差公式 |
| 适用题型 | 资料分析——利润率升降百分点、两期比重差、百分数做差 |
| 触发场景 | 选项为"上升/下降X个百分点"；问法涉及A/B形式的百分数（利润率=利润/收入）比上年变化 |
| 步骤逻辑 | ① 识别去年部分值a、今年整体值B、分子增速R1、分母增速R2；② 列式：a/B × (R1−R2)；③ 先判断R1−R2的正负确定升降方向；④ 算a/B的近似值（如1/8），乘以|R1−R2|（如5.5%），得到不到X个百分点 |
| 高频错因 | 把利润率当增速来算（利润率不能求增速，它不是增长率）；R1和R2对应关系搞反；用今年部分值替代去年部分值a |
| confidence | high |

## 补充说明

关键辨别："利润率能求增速吗？——不能。"利润率是比值，不是增长率。即使题目写成百分数形式，也不改变它"比重差"的本质。R1和R2必须是分子分母各自的实际增速。

## 不适用条件

- 材料未给出分子或分母的实际增速，无法确定R1和R2
- 题目要求的是具体利润率数值而非升降百分点
- 比重本身不是A/B形式（如纯倍数关系）

## 反向触发

- 若省略分母修正造成的误差可能影响选项选择，应使用完整公式计算
- 若算出的升降方向与直觉相反，先核对R1对应的是分子增速还是分母增速，不要急于选方向
