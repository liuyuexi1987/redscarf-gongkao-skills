# 方法卡：中心理解四步法（联考版）

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 中心理解四步法（联考版） |
| 适用题型 | 言语理解——中心理解（联考/省考） |
| 触发场景 | 联考/省考中心理解题，命题不够严谨 |
| 步骤逻辑 | ① 找结论句：通过引导词（因此/所以/必须）或问题反推；② 判断结构：尤其注意并列结构（并列结构是联考高频考点）；③ 找主题词：反复出现的词语，辅助定位；④ 详读内容：判断每一句的作用，确定核心话题 |
| 高频错因 | ① 联考命题不严谨→追求完美答案→反而选错；② 来源杂（论文/新闻降重后）→语句混乱→需要择优思维 |
| confidence | high |

## 补充说明
联考版与国考版的核心区别：联考命题不严谨，必须有"择优思维"——不追求完美答案，选"最不差"的。对策过长时往前找目的/问题；以偏概全判断法：选项内容与其他部分是并列→以偏概全，总分→不是。

## 不适用条件
- 国考中心理解题（国考命题较严谨，择优思维不适用）
- 主旨概括题（非中心理解，不属于本方法适用范围）

## 反向触发
- 文段结构清晰、主旨句明确→主旨对应项即为主要选项，无需走完四步
- 选项差异在细节而非主旨→改用选项差异分析法
