# 方法卡：有对策选对策速判

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 有对策选对策速判 |
| 适用题型 | 中心理解题、标题填入题 |
| 触发场景 | 文段中有明确对策表述（祈使句/关键词表对策/必要条件/禁止性/语义），选项中有对策有非对策 |
| 步骤逻辑 | 1. 快速扫描文段，识别对策表述（要/应该/必须/需要/只有才 等）；2. 如果文段有对策，先看选项中哪些是对策表述；3. 非对策表述的选项（中性描述、问题表述、意义表述）直接排除；4. 只有一个对策选项时直接快速锁定，不需要纠结细节；5. 多个对策选项时再比对动宾核心是否一致 |
| 高频错因 | 靠语感纠结非对策选项（如"依赖于太绝对了"）不敢选对策，因为觉得非对策选项"内容更多更全面"误把意义表述当成对策（如"保障人民当家做主"不是对策） |
| confidence | high |

## 不适用条件

1. 文段虽有对策表述，但该对策出现在论证/支撑部分（如"因为/毕竟"引导的从句中），主旨另有他物——此时对策是论证内容，参见"论证部分对策要警惕"。
2. 选项中不存在任何对策表述，全部选项均为问题概括或意义描述——速判失效，需逐项比对主旨。
3. 文段中的"只有才"等必要条件句是为引出后文问题服务，对策本身不是主旨方向——需配合转折判断。

## 反向触发

1. 看到"但是/然而/不过"出现在对策之后，应先判断转折后是否提出了新问题，不能直接抓对策。
2. 文段有多个对策且方向不一致，无法通过速判锁定时，应回归主旨结构逐一比对。
3. 选项中对策表述明显无中生有（动宾搭配文中未出现），即使文段有对策也不应选该对策选项。
