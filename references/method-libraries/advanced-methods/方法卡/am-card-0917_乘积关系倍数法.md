# 方法卡：乘积关系倍数法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 乘积关系倍数法 |
| 适用题型 | 经济利润·已知总利润变化求销量变化 |
| 触发场景 | 总利润 = 单件利润 × 销量，已知总利润倍数和单件利润倍数，求销量倍数 |
| 步骤逻辑 | 1. 总利润 = 单件利润 × 销量（A = B × C）；2. 若总利润变为1.8倍，单件利润变为1.5倍；3. 则销量 = 1.8 ÷ 1.5 = 1.2倍；4. 本质是A=B×C → C=A÷B的倍数关系 |
| 高频错因 | 倍数关系方向搞反 |
| confidence | high |

## 补充说明

这是资料分析中"乘积增长率"思想在数量关系中的应用。

## 不适用条件

- 三个及以上变量构成乘积关系时，简单的A=B×C倍数反推不再直接适用。
- 倍数关系非整数比（如1.37倍）且无法化简为分数时，直接除法易算错，应列方程。
- 题目涉及"先变后变回"等多步变化时，倍数链式相乘容易丢步骤，应分步列式。

## 反向触发

- 当题目既给倍数又给具体数值差额时，应优先用差额列方程核验，避免倍数方向错误。
- 当倍数关系涉及"增加""降低"等表述模糊时，应补充核验是"变为N倍"还是"增加N倍"。
- 当变量之间存在加减约束而非纯乘积约束时，应换用方程法。
