# 方法卡：话题一致性排除法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 话题一致性排除法 |
| 适用题型 | 判断推理——削弱加强类（方案可行性、建议类） |
| 触发场景 | 题干提出某个方案/建议解决特定问题，问最能削弱可行性的选项 |
| 步骤逻辑 | ① 明确题干要解决的问题是什么（如"公共场所吸烟问题"）；② 选项必须围绕同一话题——即该方案能否解决这个问题；③ 选项说"会带来副作用/其他问题"（如搞差厕所卫生）→话题不一致，属于无关选项；④ 选项说"即使采取了措施，问题仍然存在"（如仍有烟民去公共场所吸烟）→话题一致，有效质疑；⑤ 被质疑的选项有瑕疵（如"有些人"），但其他选项话题都不一致，有瑕疵的质疑也是最佳答案 |
| 高频错因 | 被"副作用"类选项迷惑，以为副作大就等于方案不可行；对正选项的"有些""部分"等限定词过度敏感，不敢选 |
| confidence | high |
| 不适用条件 | 1. 题干是因果论证而非方案/建议类论述（因果题用归因类方法）
| 反向触发 | 1. 当所有选项都与题干话题一致时，需改用力度强弱（如必然性 vs 可能性）而非话题一致性来区分
2. 方案类题目的正确选项讨论的是方案的代价/成本是否可接受，此时属于方案利弊权衡而非话题不一致 |
2. 所有选项都围绕同一话题展开讨论，无法用话题一致性做排除 |

## 补充说明

Q9为典型：建议把地铁厕所设为吸烟区解决公共场所吸烟问题。A"有些人还是会去禁烟区吸烟"话题一致，有效质疑。B"厕所卫生搞差"、C"不能解决火灾危险"均话题不一致。类比：药能治癌但掉头发——问药能不能治癌，你说掉头发→话题不一致。口诀：正确答案有瑕疵也要选，其他选项话题都不一致。
