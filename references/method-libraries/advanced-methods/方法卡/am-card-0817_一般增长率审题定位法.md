# 方法卡：一般增长率——和谁相比谁做基期

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 一般增长率——和谁相比谁做基期 |
| 适用题型 | 资料分析——求一般增长率 R = X / A |
| 触发场景 | 题目问增长率，且材料能直接找到该量的数据；关键陷阱：不是简单的"今年比去年"，而是"和谁相比谁做基期" |
| 步骤逻辑 | ① 审题找"和谁相比"→被比的量做分母A；② 套公式 R = (B - A) / A；③ 用拆分法计算；④ 注意保留三位有效数字 |
| 高频错因 | 非年份比较时分母搞反（如"55以上比46以下"，分母是46以下而非55以上）；下降时习惯性把小数做分母 |
| confidence | medium |
| 不适用条件 | 1. 非增长率类题目（如求增长量、求基期值）——使用对应公式\n2. 题目已明确标注 |
| 反向触发 | 1. 题目问 |

## 补充说明

口诀"和谁相比谁做基期"是核心审题要点。年份比较（如19年比18年）时学生通常不会错，但换成非年份表述（如"55以上比46以下"、"甲比乙"）时容易搞反分母。下降场景尤其要记住：分母是被比的那个量（即原来较大的量），而非习惯性认为的小数。
