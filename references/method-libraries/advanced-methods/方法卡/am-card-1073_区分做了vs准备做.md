# 方法卡：区分做了vs准备做

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 区分做了vs准备做 |
| 适用题型 | 逻辑填空——时间状态判断 |
| 触发场景 | 语境中有事件发生的时间状态（已发生/未发生/正在做） |
| 步骤逻辑 | ① 判断语境中事件是已发生还是未发生；② 已发生→选"功不可没/实至名归/大有可为"（结果性词）；③ 未发生→选"大有可为/前景广阔"（展望性词）；④ "大势所趋"=未发生但趋势明确 |
| 高频错因 | ① 未发生的事选了已发生的结果性词→时态不匹配；② "大势所趋"≠"共同构建"（前者未发生，后者已发生） |
| confidence | high |

## 补充说明
## 不适用条件
- 语境中事件的时间状态明确（只有已完成或只有未发生）时，无需区分
- 选项均为同一时间状态的词时，本卡不适用，需换用其他辨析方法
- 题目考的是因果关系而非时间状态时，应优先分析因果逻辑

## 反向触发
- 若语境无时间状态信号（如"已经""将""正在"等），先确认时间状态再决定是否用本卡
- 若选项全部是已完成的结果性词或全部是未发生的展望性词，不使用本卡
