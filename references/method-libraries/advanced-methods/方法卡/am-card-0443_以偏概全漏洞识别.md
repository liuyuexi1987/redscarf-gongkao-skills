# 方法卡：以偏概全漏洞识别

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 以偏概全漏洞识别 |
| 适用题型 | 加强/削弱论证——论据到结论存在范围跳跃（部分→整体、个别→所有） |
| 触发场景 | 论据说"某类人/某类情况"的特征，结论跳到"所有人/总体"的特征，中间存在明显的概念断层 |
| 步骤逻辑 | ① 梳理论据和结论，定位范围差异（如"成年人"vs"所有人"）；② 明确"还差谁"（如未成年人）；③ 奔着漏洞找选项：加强题找能补充"差的部分"也符合结论的选项，削弱题找"差的部分"反向的情况 |
| 高频错因 | 只看结论不做论据-结论对比，被与结论相关但未命中漏洞的选项（BCD）干扰 |
| confidence | high |

## 补充说明

典型表现：论据说"成年人患病比例减少"→结论"抑郁症发病率下降"。成年人≠所有人，漏洞缺"未成年人"。加强时找"未成年人比例也在降"，削弱时找"未成年人比例在增"。同理，从"一起车祸是女司机"推到"女司机容易出车祸"也是以偏概全——个别案例不能代表整体。

## 不适用条件

- 论据和结论的范围一致（都在说同一群体），不存在从部分到整体的跳跃
- 题干论据虽只涉及部分，但结论本身已明确限定范围（如"在成年人中"），此时不存在以偏概全
- 论域跳跃属于"以点带面"（从小论域到大论域的跨越）而非数量上的以少推多，应使用以点带面的判断方法

## 反向触发

- 当论据和结论讨论的是同一领域但维度不同（如从"网购行为"推到"家庭控制权"），应切换到"以点带面"而非继续用以偏概全的框架
- 当选项显示样本确实具有代表性（随机抽取、覆盖全面），说明不存在以偏概全漏洞，应转向检查是否有其他逻辑问题（如因果倒置）
