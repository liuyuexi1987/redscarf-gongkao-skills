# 方法卡：拆分法速算

| 字段 | 内容 |
|------|------|
| 方法名 | 拆分法速算 |
| 适用题型 | 资料分析-除法计算（求基期值、比值等） |
| 触发场景 | 需要快速求 A÷B 的结果，B可拆成整百整十的比例 |
| 步骤逻辑 | 1. 看B能拆出几个A（如295÷570，570能拆出约5个295） → 2. 5×570=2850，差100 → 3. 100÷570≈0.17 → 4. 结果约为5.17，取有效数字5.2 |
| 高频错因 | 拆分比例选不准导致误差大；忘记加回小数部分 |
| confidence | high |

补充说明：拆分法核心是"能拆出几个"——找B中最接近A倍数的整数，算出差额再修正。也可配合百分比近似（如16.7%≈1/7）加速。

## 不适用条件

- 除数无法合理拆分为整百整十的简单比例时，拆分复杂度可能超过直除
- 对精度要求高、拆分误差可能改变选项判断时，不宜使用粗拆分
- 被除数与除数量级差异过大时，拆分效果不佳

## 反向触发

- 当拆分后剩余差额仍较大、继续修正不比直除简便时，应改用直除或截位法
- 需要保留3位及以上有效数字时，拆分法精度通常只够2位，应换用更精确方法
- 题目中出现可用简单分数直接近似的比例时（如50%=1/2），直接用分数替换更高效
