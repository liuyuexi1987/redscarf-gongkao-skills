# 方法卡：A而不是B句式看"是什么"

## 基本信息

| 字段 | 值 |
|---|---|
| 方法名 | A而不是B句式看"是什么" |
| 适用题型 | 言语理解——片段阅读主旨题 |
| 触发场景 | 文段出现"A而不是B""不是A而是B"句式，需要判断哪半部分更重要；此句式在对策类、观点类文段中高频出现 |
| 步骤逻辑 | ① 识别"A而不是B"或"不是A而是B"句式；② 判断"是什么"（肯定的那一半）比"而不是什么"（否定的那一半）更重要——否定部分只是反衬，肯定部分才是作者真正要表达的核心；③ 选项应优先体现肯定部分的核心含义 |
| 不适用条件 | 不适用于文段没有明确"A而不是B""不是A而是B"句式的情况；"与其说A不如说B"等其他转折结构的重心判断规则可能不同，需另行分析 |
| 高频错因 | 把"而不是什么"（否定/排除的部分）当成重点选入选项；只关注被否定的内容，忽略了作者真正肯定的观点 |
| confidence | high |
| 反向触发 | 出现"与其说A不如说B""与其A不如B"等非标准句式时，重心判断规则可能不同，应换用转折重心分析法；文段同时包含"A而不是B"句式和递进、因果等其他逻辑结构时，需综合判断重心而不能只看句式 |
