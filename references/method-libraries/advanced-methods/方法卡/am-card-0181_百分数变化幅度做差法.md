# 方法卡：百分数变化幅度做差法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 百分数变化幅度做差法 |
| 适用题型 | 资料分析 — 百分数（使用率、占比、渗透率等）的变化幅度比较 |
| 触发场景 | 题目问"使用率变化幅度最大/最小"，且变化对象是百分数而非具体量 |
| 步骤逻辑 | 1. 判断变化对象是百分数（如使用率、覆盖率、占比）还是具体量（如人数、金额）；2. 若是百分数：变化幅度 = 两年数值直接做差，看绝对值；3. 若是具体量：变化幅度 = 增长率（需要除以基期）；4. 百分数理论上不求"增速"，差值即代表变化幅度 |
| 高频错因 | 对百分数也求增长率（除以基期），多此一举还容易算错忘记看绝对值，忽略了负变化也是"变化幅度" |
| confidence | high |

## 不适用条件

- 比较对象是具体量（人数、金额、产量等）而非百分数，必须用增长率法（除以基期）。
- 题目明确要求"增长率"或"增速"而非"变化幅度"，即使是百分数也需按增长公式计算。
- 百分数的基数（分母）本身差异很大时，差值法可能产生误导，需进一步分析基数差异。

## 反向触发

- 题面或选项中出现使用率、占比、渗透率等百分数的"变化幅度"比较时，提示直接做差。
- 选项接近时，先判断直接做差的结果是否足以区分选项；若不足，再补充精确核对，不能自设固定阈值。
