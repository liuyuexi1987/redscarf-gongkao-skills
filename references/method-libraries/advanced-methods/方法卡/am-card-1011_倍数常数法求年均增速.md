# 方法卡：倍数常数法求年均增速

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 倍数常数法求年均增速 |
| 适用题型 | 资料分析——年均增长率 |
| 触发场景 | 已知首末年数据，求年均增长率 |
| 步骤逻辑 | ① 算末年÷首年得到倍数；② 查常数表：2倍→75，2.5倍→100，3倍→125，1.5倍→42；③ 常数÷年数=年均增长率（%）；④ 倍数在两个常数之间时往偏向方向取一点 |
| 高频错因 | ① 3倍常数记成115（错）→实际是125；② 适用区间外（<1.5倍或>3倍）误差大 |
| confidence | high |

## 补充说明
这是一种年均增速速算方法。适用区间1.5倍~3倍最准。超出区间时用其他方法（间隔代入法等）。

## 不适用条件
- 倍数小于1.5或大于3（超出适用区间，估算误差可能跨越选项时改用精算）
- 非年均增长（如隔年增长、环比增长）

## 反向触发
- 倍数超出适用区间→改用间隔代入法或直接开方计算
- 选项差距极小→改用精算，避免速算误差跨越选项
