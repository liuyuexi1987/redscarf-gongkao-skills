# 方法卡：截位精度控制

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 截位精度控制 |
| 适用题型 | 资料分析——所有涉及截位的乘除运算·确定保留几位有效数字 |
| 触发场景 | 数据位数较多需要截位简化计算时，决定保留3位还是4位 |
| 步骤逻辑 | ① 一般情况保留3位有效数字，误差约1‰（如391978→392）；② 乘法截位时，一数进位一数退位以抵消误差（如392×25%而非391×25%）；③ 除法截位时，分子分母同向截位（同时进或同时退），误差可互相抵消；④ 特殊情况：分母为(1+增速)形式时保留4位（因截成3位会丢失增速的小数位，如15.12%截成151=15.1%误差较大） |
| 高频错因 | ① 分母是增速时仍只保留3位，把15.12%截成15.1%，造成增量计算误差；② 乘法截位时两个数同向调整（都变大或都变小），误差叠加；③ 四舍五入时分子变大分母变小（或反之），导致误差放大 |
| confidence | high |

## 补充说明

截位的本质是用较少位数近似原数。保留3位时误差约1/1000，保留2位时约1/100。分子分母同向截位时，误差方向相同可部分抵消（除法放缩原理）。分子分母反向截位时误差叠加，应避免。分母为(1+R)时必须保留4位的原因：若R=15.12%，(1+R)=1.1512，截成1.15相当于把15.12%当成15%，丢了0.12%≈1‰，但这个1‰是增速本身的精度而非截位误差，会影响增量计算。当估算误差可能跨越选项或改变结论时，改用精算/验证。

## 不适用条件

1. 数据位数本身就少（3位以内），无需截位。
2. 选项差距极小且数据本身精度敏感，截位累积误差可能跨越选项。
3. 题目要求精确到小数点后两位，截位法无法满足精度。

## 反向触发

1. 数据位数较多（5位及以上），直除或口算耗时，需要截位简化。
2. 乘除运算中分子分母均为大数，需要统一精度标准避免误差不可控。
3. 分母为(1+增速)形式且增速有小数位，需要特别注意保留4位的精度要求。
