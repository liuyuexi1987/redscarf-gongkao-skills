# 方法卡：追击问题比例法（含环形跑道）

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 追击问题比例法（含环形跑道） |
| 适用题型 | 数量关系-行程问题-追击 |
| 触发场景 | 两人从不同位置出发同向跑/走，问追上时的路程差或初始间距；环形跑道追上即套圈 |
| 步骤逻辑 | 1. 基本关系：路程差 = 速度差 × 时间（本质还是S=VT）；2. 同时出发同时追上 → T相同 → S和V成正比 → S甲:S乙 = V甲:V乙；3. 环形跑道：第一次追上 = 甲比乙多跑一圈(周长)；第二次追上 = 再多跑一圈；4. 设初始间距X，甲跑S甲时乙跑(S甲 - X)，建立比例关系；5. 速度变化后按新比例联立解方程 |
| 高频错因 | 环形跑道忘记追上=套一圈；甲跑的距离减去初始间距才是乙跑的距离，搞反减数被减数 |
| confidence | medium |

## 不适用条件

1. 两人相向而行（相遇问题），路程关系是相加而非相减
2. 涉及多人同时追击或队伍追击，无法用简单的两人路程差
3. 速度随时间变化（加速/减速），速度差不是常数

## 反向触发

1. 出现"相向而行""对面走来"，属于相遇而非追击
2. 题目涉及三人及以上同时运动，两人比例法不够
3. 出现"先加速再匀速"等变速描述，速度差不恒定
