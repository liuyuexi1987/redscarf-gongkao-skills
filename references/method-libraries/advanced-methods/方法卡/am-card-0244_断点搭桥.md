# 方法卡：断点搭桥

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 断点搭桥 |
| 适用题型 | 判断推理——前提假设题 |
| 触发场景 | 论据和结论之间存在信息断层，结论中出现论据未提及的新概念 |
| 步骤逻辑 | ① 读结论，圈出结论中的新概念（论据中没出现过的词）；② 回到论据，找到与新概念相关联的旧概念；③ 选一个选项同时包含新概念和旧概念，将论据与结论串成链；④ 其他选项若缺少结论中的新概念，直接排除 |
| 高频错因 | 不识别结论中的新概念，选了没有"桥接"功能的选项；被结论以外的细节干扰 |
| confidence | high |
| 不适用条件 | 论据与结论之间没有概念断层（结论是对论据的直接复述或简单等价替换），或题目要求选"削弱"而非"前提假设" |
| 反向触发 | 选项虽同时包含新旧概念，但取反后论证仍能成立时，它不是必要前提；结论包含多个新概念时，应检查完整的隐含前提链，不能只凭词语共现认定搭桥。 |
