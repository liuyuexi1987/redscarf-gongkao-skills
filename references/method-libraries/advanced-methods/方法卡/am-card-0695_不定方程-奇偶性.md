# 方法卡：不定方程-奇偶性

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 不定方程-奇偶性 |
| 适用题型 | 不定方程中系数有明显奇偶特征时，用于缩小解的搜索范围 |
| 触发场景 | 两数之差为偶数、方程右边为奇数而某项系数为偶数等奇偶矛盾场景 |
| 步骤逻辑 | 1. 判断目标变量或方程的奇偶约束（如差为偶数说明两数同奇同偶）；2. 利用"奇+奇=偶、偶+偶=偶、奇+偶=奇"等基本规则；3. 排除不符合奇偶条件的选项或取值；4. 在剩余取值中代入验证 |
| 高频错因 | 忽略奇偶性导致试算范围过大；误判奇偶关系（如把偶数系数项误认为可奇可偶） |
| confidence | medium |

## 补充说明

奇偶性是不定方程求解的第一步筛选工具。核心规则：两数差为偶数则两数同奇同偶；方程右边为奇数而某项系数为偶数，则另一项必为奇数。基本运算律：奇+奇=偶、偶+偶=偶、奇+偶=奇。奇偶性通常作为第一步筛选，配合倍数法使用效果最佳。

## 不适用条件

- 方程各项系数无明显奇偶特征（如均为奇数且右边为奇数，无法缩小范围）。
- 未知数本身可为非整数（如允许小数解，奇偶约束失效）。

## 反向触发

- 当奇偶性无法进一步缩小范围时，应换用倍数法或尾数法。
- 当方程含三个以上未知数时，需先消元降维为二元方程再判断奇偶。
