# 方法卡：公倍数赋值法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 公倍数赋值法 |
| 适用题型 | 工程问题·行程问题 |
| 触发场景 | 题目只给时间（或效率比），没有具体工程量/路程，需要快速设值 |
| 步骤逻辑 | 1. 找到各人时间（或效率）的公倍数；2. 将公倍数设为工程总量（或总路程）；3. 由此反推各自的效率；4. 例：甲3小时乙4小时 → 公倍数12 → 工程量12 → 甲效率4乙效率3；5. 合作时间=12÷(4+3)=12/7小时 |
| 高频错因 | 公倍数找错（尤其注意倍数关系时直接取大数即可，不必求最小公倍数） |
| confidence | high |

## 补充说明

在工程/行程/经济利润中无需追求最小公倍数，直接相乘即可；周期问题中才需要求最小公倍数。

## 不适用条件

- 题目已给出工程总量或路程的具体数值，赋值会与已知条件冲突。
- 各参与方的时间并非整数倍关系，强行取公倍数会引入分数难以计算。
- 题目要求精算具体数值而非合作时间，赋值法无直接对应路径。

## 反向触发

- 当题目已给具体总量时，应直接用真实总量反推效率，不再赋值。
- 当题目涉及周期重合（如多盏灯循环闪烁）时，应改用最小公倍数法处理周期。
- 当题目要求"效率比"形式输出而非具体时间时，应改用比例和份数法。
