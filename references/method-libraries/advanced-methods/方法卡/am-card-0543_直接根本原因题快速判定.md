# 方法卡：直接根本原因题快速判定

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 直接根本原因题快速判定 |
| 适用题型 | 直接/根本原因题（逻辑判断） |
| 触发场景 | 题干有原观点和反对者两个立场，问"支持谁"或"削弱谁" |
| 步骤逻辑 | 1. 识别原观点（A）和反对者（B）两个立场；2. 明确任务：支持谁 → 让谁成为根本原因；3. 构造因果链：根本原因 → 直接原因 → 结果；4. 若支持原观点A：选"A导致B"的选项，让A成为根本原因；5. 若削弱反对者B：同样选"A导致B"，把B降格为直接原因（被A推导）；6. 若削弱原观点A：选"B导致A"的选项 |
| 高频错因 | 看到两个观点就蒙了，不知道该支持谁、怎么构造因果链把A选项"之前科学界公认"当成因果倒置（但时间不一致，实际是无关） |
| confidence | high |

## 补充说明

- 当选项给出"科学界此前公认另一种说法"时，属于时间先后的背景陈述，不是因果倒置，应判为无关项。
- 区分关键：因果倒置要求A和B在同一时间框架内互换因果方向；仅说明"之前认为另一种解释"不构成因果倒置。
- 支持原观点时，优先选能把反对者的直接原因降格为被推导因素的选项。

## 不适用条件

- 题干只有一个观点、没有反对者立场时，直接根本原因判定框架不适用，按普通因果题处理。
- 题目问的是"以下哪项最能解释/说明"而非支持/削弱某一方时，此法不适用。
- 两个立场的因果链不共享任何中间变量时，构造因果链方法失效，需逐项独立分析。

## 反向触发

- 当选项涉及时间先后陈述而非因果方向互换时，判为无关项，不要当成因果倒置。
- 当原观点与反对者的因果链存在共同中间变量时，优先用搭桥或拆桥判断，再回到因果链分析。
- 当题干只给出单一因果结论、无对立观点时，改用标准削弱/加强方法（因果倒置、他因、四圈支持等）。
