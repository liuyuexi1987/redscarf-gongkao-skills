# 方法卡：最值问题人数公式与微调

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 最值问题人数公式与微调 |
| 适用题型 | 数量关系-最值问题（至少/最少有多少人） |
| 触发场景 | 问"至少有多少人得分大于X分"或类似"最少有多少人满足某条件" |
| 步骤逻辑 | 1. 核心公式：人数 = 该组总分 / 该组人均分数；2. 要让该组人数最少 → 总分尽可能少，人均分尽可能多；3. 让非目标组总分最大化（都取其最高分），剩余给目标组；4. 目标组人均取最高可能值（如满分3分）；5. 列方程解出人数，取整处理；6. 若取整后总人数溢出约束，需微调：在平均分配基础上，优先调低下限组1人、上调上限组1人，保持大小关系 |
| 高频错因 | 忽略取整方向导致总人数超限；微调时破坏了各组的大小关系约束 |
| confidence | medium |

## 不适用条件

1. 题目求的是"最多有多少人"（最大化问题），不适用最少人数的极值分配逻辑
2. 分数或比例不能取整、无明确人数上限约束的场景
3. 题目问的是总分或均值，而非满足某条件的人数

## 反向触发

1. 题目问"最多有多少人"，方向相反需另取极值
2. 出现"求平均分""求总分"，非人数最值问题
3. 条件中无下限/上限分数约束，无法确定目标组均分
