# 方法卡：代入验证法（综合分析题）

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 代入验证法（综合分析题） |
| 适用题型 | 资料分析 - 综合分析题（"以下说法正确/不正确的是"） |
| 触发场景 | 综合分析题中选项给出具体数值（如"增量超过X"），与其反向推算不如直接代入验证 |
| 步骤逻辑 | 1. 不要从材料算出结果再去匹配选项；2. 拿选项给出的数值当已知量代入条件；3. 例如：选项说"增量超6800"，材料给现期17037增速64.3% → 假设增量=6800，则基期=10237，增速=6800/10237≈66% > 64.3% → 说明增量给多了 → 实际增量<6800 → 选项错；4. 比正向计算快，尤其适合大数估算 |
| 高频错因 | ①习惯正向计算浪费时间 ②代入后不比较方向（大于/小于）③忘了"相差X倍"要减1 |
| confidence | high |

## 不适用条件

- 选项为区间范围或定性描述（如"先升后降"），无法直接代入数值验证
- 计算链条短且正向推算明显更快的简单题
- 题目涉及比值增长率或倍数关系，代入后需额外推导才能判断方向

## 反向触发

- 当代入后得到的结果与阈值非常接近、方向不明确时，应改用正向精算确认
- 当多个选项都需要代入且正向计算只需一步时，应切换为正向计算以节省时间
- 当涉及"相差X倍"表述时，需注意是否需要减1，避免误判倍数关系
