# 方法卡：四大类选项逆推法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 四大类选项逆推法 |
| 适用题型 | 言语理解——主旨概括（所有文段类型） |
| 触发场景 | 选项中出现"某某的原因""某某的发展历程""A与B的区别/关系""某某的方法/途径"等特定表述时 |
| 步骤逻辑 | ① 原因类选项（"某某的原因/由来"）→文段应为果因或因果结构；② 历程类选项（"某某的发展/变迁/历史"）→文段应为有清晰时间轴的大并列（如：最初→唐代→宋代→现代）；③ 区别比较联系类选项（"A与B的区别/关系"）→文段应为双主语，A和B地位相当、篇幅差不多；④ 具体类选项（"某某的方法/途径"）→文段应能提炼出1、2、3、4等具体条目或把一件事讲透 |
| 高频错因 | 看到选项类型不逆推文段结构就选；历程类选项选了但文段无清晰时间轴；区别比较类选了但文段只有一个主语；具体类选了但文段是笼统概括而非具体枚举 |
| confidence | medium |

## 补充说明

- 这四类选项不是说有毛病，而是"挑文段"——它们对应的文段结构相对固定。
- "由来"≈"原由"≈"原因"：如果文段有果因结构，"由来"类选项可以用。
- 区别比较联系类的陷阱：文段虽提到了A和B，但如果B只有一句话带过、不是重点，则不构成双主语结构。
- 具体类的判断：如果选项说"努力的方法"，原文应该能提炼出具体的1、2、3条方法，而非笼统论述。

## 不适用条件

1. 选项不属于这四大类（没有"原因""历程""区别""方法"等特征表述），此方法不适用，直接用常规主旨概括法。
2. 文段结构极度复杂（多层嵌套、多种结构混合），逆推匹配难度大时，应先判断文段重心再对照选项。
3. 文段明显为对策类或观点类结构，选项也是对策/观点表述时，无需逆推，直接按结构法选。

## 反向触发

1. 逆推匹配成功但选项内容与文段细节严重不符时，应放弃逆推结论，回到原文逐句验证。
2. 四大类选项均不匹配文段结构时，不要强行归类，改用"概括全文主旨→比对选项"的常规路径。
