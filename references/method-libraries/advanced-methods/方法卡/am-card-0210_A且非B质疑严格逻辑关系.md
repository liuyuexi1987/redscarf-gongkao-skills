# 方法卡：A且非B质疑严格逻辑关系

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | A且非B质疑严格逻辑关系 |
| 适用题型 | 判断推理——削弱/质疑类（结论含绝对化表述：所有A是B、必备条件、无人能…） |
| 触发场景 | 结论是"所有A都是B""A是B的必备条件""没有人能…"等严谨逻辑命题，可用A→B表示 |
| 步骤逻辑 | ① 将结论翻译为A→B（如"意图违规→被发现"）；② 唯一有效质疑：找A且非B（如"某人故意违规且未被发现"）；③ 非A（如无意违规）不能质疑——前件为假命题为真；非B（如没被发现但不是有意的）也不能质疑；④ 一个反例即足以推翻"所有/必备"类命题 |
| 高频错因 | 用"非A"（如无意违规没被发现）或"非B"（如没有发现）来质疑——这在逻辑上无法推翻A→B；误以为反例力度弱，在严格逻辑关系中反例力度极强 |
| confidence | high |

## 不适用条件

1. 结论为概率性/倾向性表述（如"通常""大多数""可能"）而非绝对化命题
2. 题目问的是"加强"而非"削弱/质疑"——加强时方向相反
3. 结论不是严格的 A→B 逻辑关系，而是因果推断或类比推理

## 反向触发

1. 结论含"所有""必备""没有人能"等绝对化表述时，立即翻译为 A→B，寻找 A且非B 反例
2. 选项出现"非A"（前件不成立）或"非B"单独出现——逻辑上无法推翻 A→B，不要选
3. 一个反例足以推翻"所有/必备"类命题——反例力度在严格逻辑关系中极强，不要低估

## 补充说明

辅助记忆：跟女儿说"考双百就带你出去玩"——她考了双百你没带（A且非B）才算你骗人；她没考双百你也没带（非A且非B）你没骗人；她没考双百你带了（非A且B）也不能说你骗人。反例在严谨逻辑关系中是"老鼠吃大象"级别的武器。
