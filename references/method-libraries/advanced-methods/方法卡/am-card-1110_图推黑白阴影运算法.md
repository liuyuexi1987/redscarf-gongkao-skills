# 方法卡：图推黑白阴影运算法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 图推黑白阴影运算法 |
| 适用题型 | 判断推理——图形推理 |
| 触发场景 | 图形中出现黑白球/黑白格（标准3×3/4×4/5×5网格或非标准网格）、封闭多边形内有单个阴影区域、或各图有明显的黑白/阴影元素 |
| 步骤逻辑 | ① 识别是完整黑白网格、不规则黑白图还是单阴影区域；② 网格类依次验证对称性、黑白部分数、移动和黑白运算；③ 单阴影区域优先看位置、与边界的公共边及与外框的关系；④ 整体规律无法解释时，把黑色和白色拆开，分别验证位置、旋转或数量规律；⑤ 用所有已知图和选项证伪，不因单幅图偶然符合就定规律 |
| 高频错因 | ① 标准黑白球一上来就数部分数，漏掉对称性这个优先级更高的考点；② 非标准黑白球意识不到与标准黑白球的解法一致，被非标准外形干扰；③ 单阴影区域与整体轮廓相同的黑白运算混淆，需要区分特征；④ 黑白分别看规律时只看整体不看部分，漏掉黑白各自的独立规律 |
| confidence | high |

## 补充说明

**完整黑白网格的触发逻辑：** 当图形由规则网格组成，且格子以黑白两种状态呈现时，优先验证对称性、部分数、移动和黑白运算。

**不规则黑白图的触发逻辑：** 网格不完整或外形不规则时，仍可沿用黑白网格的候选路径，但必须结合实际连接关系逐项验证，不默认两类题完全同构。

**单阴影区域的触发逻辑：** 当封闭多边形内有一个黑色区域，且各图只有一个阴影时，触发此判断。与整体轮廓相同的黑白运算区别：单阴影区域的外框可能不同，阴影只有一块。核心考点是阴影位置和阴影与外框的关系。

**与已有卡的关系：** am-card-1022（黑白球做题顺序）提供具体的做题顺序（对称→部分数→移动），本卡侧重特征触发判断。两者配合使用：本卡负责识别特征，1022负责具体分析。

## 不适用条件

1. 图形无黑白/阴影元素时（应改用1121数量规律分层排查法）
2. 图形以规整分割为主要特征时（应改用1123规整图形专项分析法）
3. 黑白只是辅助标记，而圆形、交点或其他结构已经形成更稳定规律时

## 反向触发

1. 标准黑白球对称性无果时，应按顺序补充核验部分数→移动→黑白运算
2. 黑白分别看规律无果时，应补充核验黑白之间的相接/相离/边数关系（参考1124）
3. 单阴影区域位置规律无果时，应换用1123规整图形专项分析法分析面特征

## 输出要求

- 看到黑白/阴影特征时，先说明触发的是哪种子类型
- 标准/非标准黑白球按固定顺序验证：对称→部分数→移动→黑白运算
- 单阴影区域优先验证阴影位置规律
- 整体规律失败时，再将黑色与白色分开验证
- 与 am-card-1022 配合使用
