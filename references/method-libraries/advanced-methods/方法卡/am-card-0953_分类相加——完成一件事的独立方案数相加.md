# 方法卡：分类相加——完成一件事的独立方案数相加

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 分类相加——完成一件事的独立方案数相加 |
| 适用题型 | 完成一件事有多种独立方式，求总方案数 |
| 触发场景 | 题目说"有几种方式可以选择"，每种方式都能独立完成任务 |
| 步骤逻辑 | 1. 把完成一件事分为若干类别（不重叠、不遗漏）；2. 每个类别中的方法可以独立完成这件事；3. 总方法数 = 各类方法数之和；4. 例如：高铁4种+大巴3种+飞机2种 = 9种出行方案 |
| 高频错因 | 把分类相加误用为分步相乘；分类时有遗漏或重叠 |
| confidence | high |

## 补充说明

判断标准——每种方案能否独立完成任务？能→加法；不能（需多步配合）→乘法

## 不适用条件

1. 各类方式之间存在依赖关系（必须依次完成），应改用分步相乘。
2. 各类之间存在重叠（同一方案被多类计入），需先去重再相加。
3. 题目要求考虑顺序的排列问题，单纯相加会漏算内部排列。

## 反向触发

1. 当题目描述出现"先…再…""然后"等步骤性词时，应换用分步相乘原理。
2. 当题目包含"既…又…"且方案被重复计数时，应配合容斥原理核验。
3. 当分类标准本身不清晰时，应先确认分类边界，避免直接相加导致遗漏或重复。
