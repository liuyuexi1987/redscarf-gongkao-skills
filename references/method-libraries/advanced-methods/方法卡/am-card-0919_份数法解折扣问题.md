# 方法卡：份数法解折扣问题

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 份数法解折扣问题 |
| 适用题型 | 经济利润·打折/提价问题 |
| 触发场景 | 题目涉及打折（八折、九折等）、提价百分比、利润率百分比 |
| 步骤逻辑 | 1. 将原价视为"10份"（对应十折）；2. 八折 = 8份，九折 = 9份，七五折 = 7.5份；3. 利润率40% = 进价的2/5 → 成本看作5份，利润2份，售价7份；4. 结合比例差：如"降价30元比打八折贵10元" → 原价(5份)与八折(4份)差1份=40元 → 原价=200元；5. 不需要纠结设什么未知数，直接看比例关系 |
| 高频错因 | 把"打八折"理解为"降价80%"（实际是保留80%，降价20%） |
| confidence | high |

## 补充说明

份数法相比方程法计算量更小，适合含折扣/利润率百分比的题目，熟练后可快速得出答案。

## 不适用条件

- 折扣涉及非整数比例（如87折、93折）且无法化为简单分数时，份数法优势减弱。
- 题目含多轮调价（先涨后降、分段折扣）时，单层份数法难以覆盖，应分层列式。
- 题目要求的是具体金额差而非比例关系时，份数法需额外换算，方程法更直接。

## 反向触发

- 当份数换算后出现非整数份且与选项无法匹配时，应反向核验份数设定是否合理，改用方程验证。
- 当题目同时涉及"折扣""赠品""返券"等多种促销方式时，应换用综合列式法。
- 当题目含"分批销售不同折扣"时，应分情况列式，不能整体套用份数法。
