# 方法卡：行程修车问题赋值假设法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 行程修车问题赋值假设法 |
| 适用题型 | 数量关系——行程问题、途中停留 |
| 触发场景 | 两物体有固定速度比，其中一方中途停留或修车，需由路程差反推停留期间另一方的行程 |
| 步骤逻辑 | 1. 甲速度是乙的3倍，乙走完全程4000米时甲只走了3600米（差400米）；2. 正常情况下甲走3600米时，乙应走 3600÷3 = 1200米；3. 但乙实际走了4000米，多走了 4000-1200 = 2800米；4. 这2800米就是乙在甲修车期间独自行走的距离（修车时间内乙走的路程） |
| 高频错因 | 试图列方程求修车时间和速度两个未知数，计算复杂没有利用"速度比"来简化，直接设未知数导致方程繁琐 |
| confidence | medium |
| 不适用条件 | 题目给出具体时间和速度数值可直接列方程的简单行程问题；需要求解具体修车时间而非多走路程的场景 |
| 反向触发 | 当速度比关系不清晰或路程差无法直接对应时，改用设未知数列方程的方法精算；忘记考虑修车期间未坏车持续行走这一隐含条件会导致逻辑错误，需回溯审题 |

## 补充说明

核心技巧：利用速度比把问题转化为"正常情况下乙应走多少 vs 实际走了多少"的差值。修车时间不影响最终结果——无论甲在哪修车，乙多走的距离都等于乙在甲停车期间走的路程。此法避免了设未知数列方程。
