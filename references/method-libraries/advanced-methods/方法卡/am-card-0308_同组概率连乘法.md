# 方法卡：同组概率连乘法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 同组概率连乘法 |
| 适用题型 | 数量关系——概率、随机分组 |
| 触发场景 | 若干对象随机进入等容量分组，求指定对象全部同组的概率 |
| 步骤逻辑 | 1. 先确定第一个对象的位置（任意位置都行，不影响概率）；2. 第二个对象与第一个同组的概率 = 同组剩余位置数 ÷ 剩余总位置数；3. 第三个对象继续连乘：剩余同组位置数 ÷ 剩余总位置数；4. 所有概率相乘即为最终同组概率 |
| 高频错因 | 忘记第一个对象已占据一个位置，导致分母算错同组剩余位置数要减去已占位的同组成员 |
| confidence | medium |
| 不适用条件 | 对象不是均分（各组容量不同），或题目求的是特定位置排列而非同组概率时 |
| 反向触发 | 题目涉及圆排列、不相邻排列等组合约束，或分组规则不均匀导致条件概率路径过长时，改用排列数除以总方案数的直接计数法 |

## 补充说明

此方法优势在于不需要算总排列数和满足条件排列数，直接用条件概率连乘。适合"几个对象分在同一组"的题目。例如9队分3组每组3队，求前三名同组：第一个随意，第二个2/8，第三个1/7，连乘得1/28。
