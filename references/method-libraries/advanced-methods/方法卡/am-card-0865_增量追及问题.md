# 方法卡：增量追及问题

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 增量追及问题 |
| 适用题型 | 资料分析——假设增量不变，求何时追上/超过/翻番 |
| 触发场景 | 题目说"保持某年增量不变，问哪一年A超过B"或"何时翻一番" |
| 步骤逻辑 | ① 计算当前两者的差距（或目标差距）；② 计算每年的增量差（相对速度）；③ 所需时间=差距÷增量差，向上取整；④ 翻番问题：目标值=当前值×2^n（n为翻番次数），需增加量=目标值-当前值 |
| 高频错因 | ① 翻番和翻倍混淆（翻一番=×2，翻两番=×4）；② 追及时间忘记向上取整（4.5年需要第5年才能超过）；③ 有比例目标时（如"超过1/3"）忘记先转化为同口径比较 |
| confidence | high |

## 补充说明

本质是行程追及问题的数学迁移：差距÷相对速度=追及时间。遇到"超过某比例"的题，可先两边同乘分母转化为整数比较，减少计算量。

## 不适用条件

1. 增量本身逐年变化（如给出增长率而非固定增量）时，不能用恒定增量追及模型，需逐年推算或列方程。
2. 题目要求的是精确时间点（如具体到某年某月）而非"第几年"时，需注意取整逻辑是否与题意匹配。

## 反向触发

1. 当"翻番"题中基数涉及复利增长而非固定增量时，应换用增长率指数模型（末期=初期×(1+r)^n）求解。
2. 当追及问题涉及三个及以上主体时，逐对比较可能遗漏条件，应改为列表逐年推算。
