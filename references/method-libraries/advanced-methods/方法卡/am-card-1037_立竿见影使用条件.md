# 方法卡：立竿见影使用条件

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 立竿见影使用条件 |
| 适用题型 | 逻辑填空——成语辨析 |
| 触发场景 | 选项中有"立竿见影"且文段有时间/效果描述 |
| 步骤逻辑 | ① 检查时间：必须极短（一天内或"马上"），一年不算；② 检查做法：必须有具体做法（政策/法律/措施），不能只是机制；③ 检查搭配：效果要与主动性/创造性等词搭配；④ 三个条件都满足才能选 |
| 高频错因 | ① "短短一年"就选立竿见影→一年不算"马上"；② 没有具体做法只有机制→不能用立竿见影 |
| confidence | high |

## 不适用条件
- 文段未给出明确时间跨度或效果反馈节点时，三条件核验无法落地。
- 选项中"立竿见影"与其他近义成语（如"一蹴而就""指日可待"）并列干扰时，需做整体语境辨析。
- 文段强调长期积累而非即时效果时，本方法不适用。

## 反向触发
- 当文段突出"长期才能见效"时，应换用表征长期过程的成语辨析法。
- 当选项侧重"难度大、难以实现"语义时，应换用"一蹴而就/遥不可及"等难度类成语辨析。
- 当文段考查对象是过程而非效果时，应补充语义重心核验，避免错配效果类成语。
