# 方法卡：对策内容与目标意义区分

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 对策内容与目标意义区分 |
| 适用题型 | 主旨题/中心理解题 |
| 触发场景 | 对策句后接"为…""以…""才能…"等目标/目的表述，选项把目标混入对策 |
| 步骤逻辑 | 1)定位对策句，区分"手段内容"和"实现目标" 2)"只有才"中间是对策，"才"后面是目标 3)"为…"后面是目标不是对策 4)选对策内容时不能把目标变成对策内容，也不能把目标当重点 |
| 高频错因 | 把目标意义（如"规避风险""彰显精神"）当成对策内容去选 |
| confidence | medium |

## 不适用条件

1. 文段没有"只有才""为…""以…"等对策句式时，本方法无适用基础
2. 对策句中手段和目标紧密融合（无法单独提取手段内容）时，需整体理解

## 反向触发

1. 若选项用"从X到Y"把对策和目标并列，配合"从X到Y表述不等于对策"方法排除
2. 若文段以目标为核心而对策是实现手段时，需重新判断文段主旨倾向
3. 若选项中对策内容差异明显，优先按对策本身筛选，无需进入目标区分环节
