# 方法卡：往返等路程处理技巧

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 往返等路程处理技巧 |
| 适用题型 | 行程问题·往返含上下坡 |
| 触发场景 | 去程有上坡下坡平路，回程同样的路反过来走，求往返平均速度 |
| 步骤逻辑 | 1. 往返时上坡总路程 = 下坡总路程（因为回来时原来的下坡变成上坡）；2. 先用调和平均数算出上下坡的等效平均速度；3. 若平路速度恰好等于调和平均数 → 整体平均速度就是该值；4. 若平路速度不等于调和平均数 → 分段列方程：平路时间+上下坡时间=总时间，平路路程+上下坡路程=总路程；5. 用鸡兔同笼思想求解 |
| 高频错因 | 忽略同一路线往返时，上坡总路程等于下坡总路程 |
| confidence | high |

## 不适用条件

- 单程行程问题（无回程）
- 去程与回程路线不同、路程不等的情况
- 全程为平路、无坡度变化的往返

## 反向触发

- 题目只求单程速度或单程时间
- 题目明确说明去程和回程走不同路线
- 题目给出的上下坡速度相同（无需区分坡型）

## 补充说明

去程和返程沿同一路线时，不管单程中上坡、下坡各占多少，上坡总路程都等于下坡总路程；若往返路线不同，则不能使用该结论。
