# 方法卡：因果倒置削弱

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 因果倒置削弱 |
| 适用题型 | 判断推理——加强削弱·因果论证（由果推因） |
| 触发场景 | 题干从两件事同时发生推测A导致B，选项说"其实是B导致A" |
| 步骤逻辑 | ① 识别论据是否只是 A 与 B 同时出现，论点却断言 `A→B`；② 检查选项是否提供相反方向 `B→A`；③ 若反向因果能解释同一相关现象，它是直接削弱，应优先核对；④ 仍需与共同原因、样本偏差等选项比较，判断哪项对当前论证更直接、证据更充分 |
| 验证动作 | 假设 `B→A` 成立，检查原论据是否仍能支持 `A→B`；若题干已有时间先后或实验控制排除了反向因果，则该选项力度下降 |
| 高频错因 | 看到因果倒置就不核对题干是否已排除反向方向；把“另有他因”误标成因果倒置；机械认定其永远最强 |
| confidence | high |
| 反向触发 | 选项讨论的是第三因素C同时影响A和B（共同原因），而非颠倒A、B的因果方向；题干论证已有时间先后或实验设计排除了反向因果，此时因果倒置选项力度不足，应优先对比其他削弱项 |
| 不适用条件 | 选项只是补充与 A 同时发生且也能导致 B 的因素 C，这是他因削弱，不是因果倒置。；选项只否定 A 能导致 B，但没有提出 `B→A`时，不标为因果倒置。 |

## 不适用条件

- 选项只是补充与 A 同时发生且也能导致 B 的因素 C，这是他因削弱，不是因果倒置。
- 选项只否定 A 能导致 B，但没有提出 `B→A`时，不标为因果倒置。
