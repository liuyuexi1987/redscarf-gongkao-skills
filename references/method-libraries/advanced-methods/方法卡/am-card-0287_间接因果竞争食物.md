# 方法卡：间接因果竞争食物

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 间接因果竞争食物 |
| 适用题型 | 归因题（A不吃B但A增多B减少） |
| 触发场景 | 题干质疑"不吃直接吃B的动物A不可能导致B减少"时 |
| 步骤逻辑 | 1. A不吃B不代表A对B无影响；2. 若A和B竞争同一食物C，A增多 → C被A大量消耗 → B因缺少食物而减少；3. 这是间接因果：通过争夺共同资源（食物、栖息地等）产生影响；4. 选项只要说明A和B有共同食物/资源，即可支持"A导致B减少" |
| 高频错因 | 被"不吃"迷惑，认为不吃就不可能导致减少 |
| 不适用条件 | A与B之间存在直接捕食关系，或题干讨论的是非生物因素导致的变化时 |
| 反向触发 | A与B之间已知存在直接因果链，或不存在共同资源竞争关系时 |
| confidence | high |
