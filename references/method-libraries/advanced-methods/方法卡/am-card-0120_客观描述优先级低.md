# 方法卡：客观描述优先级低

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 客观描述优先级低 |
| 适用题型 | 言语理解-中心理解题 |
| 触发场景 | 文段中出现纯客观事实描述（无作者主观观点）时 |
| 步骤逻辑 | 1. 识别文段中的客观事实描述（如现状、数据、现象） 2. 判断该描述是否带有作者观点或评价 3. 纯客观描述在说理类文段中优先级很低，可略看 4. 重点抓对策、问题或意义表述 |
| 高频错因 | 把客观事实当成文段重点，选了出处有误的选项 |
| confidence | high |
| 不适用条件 | ①文段为纯粹的现象描述型（无明显说理、无对策、无问题），客观描述本身可能就是主旨载体；②客观描述句中暗含作者倾向或评价（如使用"竟然""却""值得关注"等态度词），此时已非纯客观描述；③设问明确指向该描述涉及的具体内容（如"下列哪项符合原文描述"），客观描述即为答案依据 |
| 反向触发 | ①文段中所有选项均围绕客观描述内容展开，说明该描述并非铺垫而是核心信息，应放弃"优先级低"判断；②客观描述后紧接转折或递进（如"然而""更重要的是"），新方向才是重点，但需确认选项是否落在新方向而非描述区域；③描述内容为数据或具体案例且设问要求依据该数据推断，此时数据不可略看，需精算验证 |

## 补充说明

在说理类文段中，客观事实描述往往是背景铺垫或"装模作样的写点字数"来提高阅读难度。强化方法多次示范跳过客观描述直接找对策句或意义表述。区别客观描述与观点表述是关键：如果句子只是陈述"存在什么情况"而没有"好/坏/应该"等评价，则为客观描述。此方法与"意义表述=观点性表述"形成对比框架。
