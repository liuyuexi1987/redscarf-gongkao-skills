# 方法卡：预设前提陷阱识别

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 预设前提陷阱识别 |
| 适用题型 | 逻辑谬误题 |
| 触发场景 | 提问中暗含了一个前提，回答者在不知不觉中承认了该前提 |
| 步骤逻辑 | 1. 经典例子（邪不压正）："如果对方同意你做某事，你还会杀他吗？"→"当然不会"；2. 回答"不会"默认了"对方遭遇某事与我有关"这一前提；3. 做题时注意：提问中的"如果…还会…"形式可能设了陷阱 |
| 高频错因 | 被题目的叙事带入，默认了未被论证的前提 |
| confidence | medium |

## 补充说明

此类题出现频率不高但一旦出现极具迷惑性。关键是看回答是否隐含承认了某个未被证明的前提。

## 不适用条件

- 题目考查的是隐含前提的补全（"上述论证依赖的假设"），应转用隐含前提挖掘法。
- 提问是直接的事实判断，不涉及复合条件或隐含预设。

## 反向触发

- 提问中使用"如果…还会…""你是否还在…"等复合结构，回答"是"或"否"可能同时承认了另一个前提。
- 题目考查"提问是否合理""回答是否落入陷阱"等预设前提类谬误。
