# 方法卡：假设分配法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 假设分配法 |
| 适用题型 | 资料分析——已知现期和增长率，求基期和增长量 |
| 触发场景 | 已知现期和增长率，需要估算一个或多个基期量、增长量，且能选取便于计算的基期锚点 |
| 步骤逻辑 | ① 分配第一步：给"基期"分一个整数（如分800），用该数×增长率算出"增量"（如800×8%=64），现期-已分=余数；② 分配第二步：对余数取整修正（参照10%/5%/20%快速估），基期减/加调整，增量对应增/减；③ 余数极小（个位）则略过不分；④ 最终基期和增量同时得出 |
| 高频错因 | ① 用乘法由一份求基期导致误差放大（应用减法：b-x）；② 余数小时仍纠结细分，拖慢速度；③ 下降时忘把增量写负 |
| confidence | medium |

## 补充说明

基期、增量、现期和增长率构成分配关系。第一步分配大头，第二步修正余数；是否可以省略第二步，取决于误差是否可能改变选项，而不是固定增长率区间或余数位数。

## 不适用条件

- 无法选到便于计算且接近真实基期的锚点。
- 选项接近、题目要求精确值，或省略余数可能跨越选项。

## 反向触发

- 余数对结果仍有明显影响时继续分配或改用直除。
- 多个候选难以区分时，用原增长率反乘验证候选基期。
