# 方法卡：共同工作时间段法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 共同工作时间段法 |
| 适用题型 | 数量关系——工程问题 |
| 触发场景 | 多人合作完成某项任务；各人开始时间不同；已知某个时间点的总量 |
| 步骤逻辑 | 多人开始时间不同时，不往回推各自起始时间，而是找共同工作时间段，用已知总量推算。；1. 找出共同工作的那段时间（如12点到16点）；2. 算出共同时间段内每人/每台的工作量；3. 用已知总量减去共同时间段的工作量→得到某个时间点的存量；4. 用比例关系或继续推算 |
| 高频错因 | 共同时间段的起止点判断错误；忘记减去共同时间段的工作量 |
| confidence | medium |

## 补充说明

- 这个方法比列方程快
- 核心是"中间这段时间谁也没偷懒，一直在干"

## 不适用条件

- 各人效率随时间变化时，不能用恒定效率计算共同时间段的工作量
- 共同工作时间段不连续（中间有中断）时，需分段计算
- 题目未给出明确的时间节点或总量数据时，无法使用本法

## 反向触发

- 若所有参与者同时开始同时结束，直接用整体思想，不需要时间段法
- 若题目涉及的是进水出水等连续流量问题而非分段工作，不使用本卡
