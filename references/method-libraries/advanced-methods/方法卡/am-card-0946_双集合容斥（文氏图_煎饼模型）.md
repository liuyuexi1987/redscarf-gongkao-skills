# 方法卡：双集合容斥（文氏图/煎饼模型）

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 双集合容斥（文氏图/煎饼模型） |
| 适用题型 | 两个属性的集合计数问题 |
| 触发场景 | 题目涉及"满足A的有多少、满足B的有多少、同时满足AB的有多少" |
| 步骤逻辑 | 1. 把A和B想象成两张煎饼叠在桌上；2. A+B = 总人次（两张煎饼面积之和）；3. 总人数 = A+B - 重叠部分（撕掉第二层）；4. 重叠部分 = A+B - 总人数（撕掉第一层）；5. 有"都不"的情况：先减去"都不"的人数，再用剩余人数作为总人数 |
| 高频错因 | 忘记"都不"的情况需要先排除；把人次当人数直接加 |
| confidence | high |
| 不适用条件 | 题目涉及三个或三个以上集合的交集，煎饼模型直觉容易出错，应转用三集合容斥公式。；题目是条件概率或排列组合中的分配问题，不涉及集合计数。 |
| 反向触发 | 涉及三个或以上集合时，双集合直觉不适用，应转用三集合容斥公式；题目是条件概率或排列组合分配问题而非集合计数 |

## 补充说明

核心口诀"他问什么就撕什么"——问总人数撕第二层，问重叠撕第一层
