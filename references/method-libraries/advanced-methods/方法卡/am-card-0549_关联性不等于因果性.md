# 方法卡：关联性≠因果性

| 字段 | 内容 |
|------|------|
| 方法名 | 关联性≠因果性 |
| 适用题型 | 逻辑判断——加强/削弱题 |
| 触发场景 | 选项表述"存在关联性""有很强的相关性"，需判断其能否支持或削弱因果结论 |
| 步骤逻辑 | 1. 识别选项关键词："关联性""相关性"≠因果性 |
| | 2. 关联性存在三种可能：①A导致B（题干方向）②B导致A（因果倒置）③C同时导致A和B（共因/继发关联） |
| | 3. 因此"存在关联性"不能确定是哪种因果方向→不能作为因果论证的直接支持 |
| | 4. 优先选明确表述因果关系的选项，而非只说"关联性"的选项 |
| 高频错因 | ①把"存在很强关联性"等同于"因果关系成立"②忽略关联性可能是反向因果或共因导致 |
| confidence | high |

**补充说明：**
- 支持题中，明确说因果（如"肥胖会带来健康风险"）力度强于只说关联性（如"存在很强关联性"）。
- 削弱题中，因果倒置和继发关联（共因）力度最强，完全切断因果联系。

## 不适用条件

- 题干论证本身未声称因果关系、只说"存在关联"时，此法不适用（无需区分关联与因果）。
- 选项明确给出了因果机制（如具体作用路径），已超出"只说关联"的范围，应按因果论据直接评估。
- 选项明确提出因果关系但方向、主体或机制与题干不一致时，不能因其使用因果表述就优先选择。

## 反向触发

- 当支持题中同时存在因果和相关性选项时，比较其方向、主体和机制与题干结论的贴合度，不能只看表述强弱。
- 当削弱题中存在因果倒置选项时，因果倒置力度强于"关联性不等于因果性"的泛化削弱，优先选之。
- 当选项用"关联性"一词但后面补充了具体因果机制时，已不是纯关联性，按因果论据处理。
