# 方法卡：方程法设未知数技巧

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 方程法设未知数技巧 |
| 适用题型 | 数量关系——方程问题 |
| 触发场景 | 题目出现1.2倍、1.5倍等小数倍数关系；未知数之间有比例关系（如3:2）；需要设未知数列方程 |
| 步骤逻辑 | 设未知数时尽量设"好算的数"——找多个分母的最小公倍数，避免小数。；1. 观察题目中的倍数/比例关系；2. 找出这些数的最小公倍数；3. 设最小公倍数为未知数的系数 |
| 高频错因 | 直接设小数导致计算繁琐出错；未识别比例关系而多设了未知数 |
| confidence | medium |

## 补充说明

- 设成整数比设小数好算
- 比例法：未知数之间有比例关系时直接设比例（如3:2→设3x和2x）
- 方程法重要的是找到等式关系

## 不适用条件

- 题目中没有明确的等量关系或比例关系时，不能强行设未知数
- 比例关系只是近似值、区间或上下限而非精确等式时，不能直接按固定整数比设元
- 题目可以用代入排除法更快解决时，不必走设未知数路线

## 反向触发

- 若题目是不定方程（未知数多于方程个数），不使用本卡，应转不定方程解法
- 若题目问的是比例本身而非具体数值，可能不需要设未知数
