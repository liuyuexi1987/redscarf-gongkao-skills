# 方法卡：前对策结构识别

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 前对策结构识别 |
| 适用题型 | 言语理解——片段阅读（主旨/意图题） |
| 触发场景 | 文段首句或前几句直接给出对策，后文是对策的具体展开或分析论证 |
| 步骤逻辑 | ① 读首句/前几句，判断是否包含对策性表述（建议/禁止/必要条件/语义）；② 如首句即为对策，该对策即为重点，后续内容为具体展开或举例论证；③ 后文如出现"但是/因此"等关联词，不一定是重点转移，可能只是补充说明或免责提示；④ 选答案时以首句对策为核心，不被后文带跑偏 |
| 高频错因 | 只盯后文关联词（"但是""因此"）而忽略首句已给出的对策；误以为后文分析是重点；未识别首句中的指示代词概括性表述 |
| confidence | medium |

## 补充说明

前对策有两类：①引入话题后直接给对策+分析论证+结尾重复对策（此时两个对策同义，不用挑）；②先引出话题+给宏观对策+后文是对策的具体展开。后一种中，后文具体措施过于细致不好概括时，选宏观对策即可。指示代词（如"这方面"）往往是对策的概括性表述，需重视。

## 不适用条件

- 文段首句为引子或例子（非对策性表述）时，不应套用前对策结构识别
- 文段为后对策结构（先分析论证，尾句给对策）时，应换用后对策定位法

## 反向触发

- 当首句看似对策但后文出现强转折且转折后给出新对策时，应换用整体结构分析判断主次，而非固守首句对策
- 当后文具体展开与首句对策方向不一致时，应核验首句是否为宏观对策，或是否需要换用并列结构分析
