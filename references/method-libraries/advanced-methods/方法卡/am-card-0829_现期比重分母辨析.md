# 方法卡：现期比重分母辨析

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 现期比重分母辨析 |
| 适用题型 | 资料分析——现期比重计算 |
| 触发场景 | 题目求某部分占另一范围的比重，但材料给出的是该部分占其直接上级的比重，分母需要跨层选取 |
| 步骤逻辑 | ① 仔细审题确认"占谁的比重"，注意分母是哪个整体；② 材料中"其中"后的数据是部分，段首总数据才是整体；③ 出题人常在分母上挖坑——用小范围整体代替大范围整体 |
| 高频错因 | 没注意分母范围，用班女同学38人除班100人得到38%，实际应除全校人数；累计数据需用全年减12月得到1-11月 |
| confidence | medium |

## 补充说明

现期比重公式本身简单（部分÷整体），但分母范围是常见设错点。材料一般是总分结构：整体数据在段首或开头，各部分数据在"其中"之后。读题时一定要确认"占XX的比重"中XX对应的范围，注意跨层级选取分母。

## 不适用条件

- 材料数据结构为并列关系而非总分关系时，不存在跨层选取分母的问题，直接比即可。
- 题目已经明确写出分母对应的具体数据项时，无需辨析，直接计算。

## 反向触发

- 题目问的是"占XX比重"且XX在材料中只有一个明确数值，无需跨层。
- 数据为单一表格且无嵌套层级时，分母不会被干扰。
