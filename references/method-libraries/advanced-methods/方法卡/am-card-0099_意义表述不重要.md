# 方法卡：意义表述不重要

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 意义表述不重要 |
| 适用题型 | 中心理解题、标题填入题 |
| 触发场景 | 对策之后紧跟着"就能够/就能/可以/意义在于"等意义/好处表述 |
| 步骤逻辑 | 1. 识别对策之后是否有意义表述（做了这个对策能带来什么好处）；2. 意义表述属于论证部分，不是重点，不需要读；3. 主旨只抓对策本身，不抓意义；4. 选项中如果出自意义表述部分，出处有误，不能选；5. 选项分析只在两个选项主旨都对时才需要做 |
| 高频错因 | 把意义表述（好处/作用/影响）当成对策来选纠结选项中的"依赖于""太绝对"等细节，但主旨本身就不对选了一个"出自意义表述"的选项，虽然表述好但出处不对 |
| confidence | high |

## 不适用条件

1. 文段没有对策，只有意义/影响/作用表述，此时意义本身就是重点
2. 意义表述之后接了转折（如"但是/然而"）引出新观点，新观点才是主旨
3. 题目明确问"这样做的意义/好处是什么"，意义表述就是答案来源

## 反向触发

1. 所有选项都出自意义表述部分，需在意义之间比较而非排除意义
2. 文段结构为"背景→意义→对策"，对策才是最终主旨，意义只是中间层
