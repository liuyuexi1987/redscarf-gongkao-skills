# 方法卡：标准分数附近的增量一阶修正

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 标准分数附近的增量一阶修正 |
| 适用题型 | 资料分析——增长率不在标准分数附近时的增量/基期计算 |
| 触发场景 | 增长率不正好是1/6、1/7等标准分数，需要修正时 |
| 精确关系 | 已知现期量 B 和增长率 r，增长量 `X=B×r/(1+r)` |
| 步骤逻辑 | ① 选择靠近 r 的标准分数 `r0=1/n`；② 初步增长量 `X0=B/(n+1)`；③ 计算 `Δr=r-r0`；④ 用一阶近似 `X≈X0×[1+Δr/(r0×(1+r0))]` 修正；⑤ 若修正量可能跨越选项边界，直接使用精确公式 |
| 验证动作 | 将修正后的 X 代回 `X=B×r/(1+r)` 附近检查，或用 `B-X` 作为基期量再乘 r 验证 |
| 不适用条件 | r 与标准分数相差较大；选项接近；增长率接近 -100%；题目要求精确值 |
| 高频错因 | 把一阶修正当成精确公式；百分数差未转成小数；修正方向搞反；忽略选项误差边界 |
| confidence | medium |
| 反向触发 | 增长率不在标准分数上，但估算误差可能跨越选项时，用一阶修正精化四幺五的初值，而非直接切换精算 |
