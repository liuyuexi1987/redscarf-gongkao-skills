# 方法卡：工程量不变列方程法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 工程量不变列方程法 |
| 适用题型 | 工程问题 |
| 触发场景 | 同一工程多种完成方式（如不同效率、不同人数），求时间或效率 |
| 步骤逻辑 | 1. 核心公式：工程量 = 效率 × 时间；2. 写出不同情况下的效率×时间表达式；3. 因为工程量不变，各表达式相等，列方程求解；4. 例：每小时32个需8小时，中间故障1.5小时后提速到48个/小时正好完成 → 32T + 48(6.5-T) = 256 |
| 高频错因 | 忘记把故障时间从总时间中扣除 |
| confidence | high |

## 补充说明

这是工程问题最基础最保底的方法，想不出快法就用方程。

## 不适用条件

- 工程量本身发生变化（如新增工程、中途追加任务）时，"工程量不变"前提失效。
- 多人多阶段协作且效率不断变化时，单一方程难以表达，应分段列式或换用比例法。
- 题目只给比例关系无具体数值时，直接赋值法比方程法更快。

## 反向触发

- 当方程解出的时间与题目给定总时间矛盾时，应反向核验是否漏算故障/休息时间。
- 当方程涉及多个未知数且无法消元时，应换用盈亏思想或比例法简化。
- 当题目含"提前完成""延期完成"等结果语义时，应补充核验方程方向是否正确。
