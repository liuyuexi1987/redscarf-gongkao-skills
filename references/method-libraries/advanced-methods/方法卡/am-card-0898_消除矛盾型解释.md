# 方法卡：消除矛盾型解释

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 消除矛盾型解释 |
| 适用题型 | 判断推理——解释现象题（变体） |
| 触发场景 | 题干中对方认为两件事矛盾，但实际并不矛盾 |
| 步骤逻辑 | ① 分析对方为什么觉得矛盾（通常是混淆了概念，如比例vs数量、相对vs绝对）；② 选一个指出"其实不矛盾"的选项；③ 本质是纠正对方的理解错误 |
| 高频错因 | ① 没有识别出"不矛盾"的情况，当成了需要找原因的解释题 |
| confidence | high |

## 不适用条件

- 矛盾确实存在、需要找外部原因解释的解释题
- 题干要求解释"为什么"发生了某现象（而非指出不矛盾）

## 反向触发

- 题目问"以下哪项最能解释上述现象/矛盾"
- 矛盾双方涉及不同时间段、不同对象的真实变化

## 补充说明

典型场景：60%回答者在前20%→对方觉得矛盾，实际是回答者≠全班人数（幸存者偏差）。指出"回答者只是部分人"就消除了矛盾。
