# 方法卡：图推内外图形分析法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 图推内外图形分析法 |
| 适用题型 | 判断推理——图形推理（内外图） |
| 触发场景 | 图形有外框+内部复杂图形 |
| 步骤逻辑 | ① 有外框+内部复杂→考内外关系或内外分开看；② 内部最明显的元素（如点）优先数；③ 外框形状变化时也要警惕；④ 内部考点概率最大 |
| 高频错因 | ① 只看整体忽略内部→漏掉规律；② 不分别数内外→找不到规律 |
| confidence | high |

## 不适用条件
- 图形没有明显外框（如纯线条组合、立体图形）时
- 图形是单一整体元素、无内外区分时
- 外框和内部元素完全相同、无差异考点时

## 反向触发
- 图形无外框或只是简单形状叠加时，不应套用内外分析法
- 题目考查的是整体旋转、翻转等变换而非内外关系时
