# 方法卡：并列词同时搭配法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 并列词同时搭配法 |
| 适用题型 | 逻辑填空——并列结构 |
| 触发场景 | 空格前后有并列结构（和、与、及、同时、也、又），且并列项是多个词 |
| 步骤逻辑 | ① 找到并列结构，标记所有并列项；② 空格处的词必须能同时与所有并列项搭配；③ 如果只能搭配其中一个→排除；④ 例："随意取舍、记忆有误、心存故意"→选的词必须能同时搭配这三个原因 |
| 高频错因 | ① 只看最近的并列项就选词→漏掉远处的并列项；② 选了只能搭配部分并列项的词→如"虚构"只能搭配"故意"不能搭配"记忆有误" |
| confidence | high |

## 补充说明
并列结构中选词必须能同时搭配所有并列项。判断步骤：先标出全部并列项，再设想空格词与每一项分别搭配，只有与所有并列项都能成立才是合格选项。若某词只能与其中部分并列项搭配，则排除。

## 不适用条件

- 并列项之间是递进或转折关系（如"甚至""然而"连接），不适用"同时搭配"规则，应按递进/转折逻辑分别处理。
- 并列项是同类名词的简单堆叠且空格只修饰其中一个时，无需强求同时搭配全部并列项。
- 空格与并列项之间插入了较长修饰语或断句，搭配关系已被切断时，不套用本卡。

## 反向触发

- 当并列项较多（三个及以上）且语义差异大，单一词难以同时搭配时，应换用"找最大公约数"思路：选语义最宽泛、能覆盖各并列项的词，而非强行寻找精准搭配。
- 当怀疑并列项实为伪并列（仅形式并列、语义有主次）时，应补一步语义关系核验，确认是否真为并列后再决定是否同时搭配。
- 当选项中无任何词能同时搭配所有并列项时，应改用排除法：选能搭配最多并列项且不与任何一项冲突的词。
