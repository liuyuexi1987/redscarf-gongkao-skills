# 方法卡：正确识别抽屉原理中的"物品"和"格子"

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 正确识别抽屉原理中的"物品"和"格子" |
| 适用题型 | 抽屉原理的应用题 |
| 触发场景 | 需要从题目描述中判断什么是被分配的物品，什么是分配的容器 |
| 步骤逻辑 | 1. "格子"= 分类的依据（如颜色、组别、类型）；2. "砖头"= 被分配的个体（如取球的次数、人数）；3. 例如"6种颜色取球"→6种颜色是格子，取球次数是砖头；4. 例如"分4组至少有一组>2人"→4组是格子，男生是砖头 |
| 高频错因 | 把题目中的具体数字误认为是砖头数量（如把每种颜色的球数当成砖头） |
| confidence | high |

## 补充说明

题目中的具体球数（如每种11个）只是保证有球可取，与抽屉原理的计算无关

## 不适用条件

1. 题目未涉及"分配"或"分类容纳"结构（如纯计算题），不存在抽屉结构识别问题。
2. 题目已经明确告知分组方式与个体来源，无需自行判断物品/格子角色。
3. 题目属于"分组计数"而非"至少几件落入同一组"的极值问题，应改用排列组合方法。

## 反向触发

1. 当题目问"至少取几次才能保证某色出现N次"时，应换用最不利原则，本方法仅用于角色识别。
2. 当题目中物品与格子角色可能互换（如"人分组"vs"组分人"）时，应结合问题目标反向核验识别是否正确。
3. 当格子容量不一致或格子本身有附加约束时，需补充容量分析，否则本方法识别可能不充分。
