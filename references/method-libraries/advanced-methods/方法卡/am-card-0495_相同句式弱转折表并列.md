# 方法卡：相同句式弱转折表并列

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 相同句式弱转折表并列 |
| 适用题型 | 言语理解——中心理解（转折结构判断） |
| 触发场景 | 文段中出现"但"等转折词，但前后是相同句式（如"从X角度看不应开放""从Y角度看应开放"），此时"但"不表强转折，而是弱转折=并列 |
| 步骤逻辑 | 1. 看到"但"先判断是强转折还是弱转折；2. 判断标准：前后句式是否相同？如果句式一样、对称，就是并列；3. 强转折：前面铺垫不重要，后面引出重要内容（如相亲例子：人好工作好…但不来电）；4. 弱转折/并列：从不同角度看同一件事，两边同等重要；5. 并列结构选概括性选项，不能只选其中一边 |
| 高频错因 | 看到"但"就默认是强转折，选了后半截片面选项不看句式结构，凭语感判断转折强弱 |
| confidence | medium |

## 不适用条件

- 前后句式不对称、内容主次分明时，应按强转折处理
- 文段无转折词时不使用本卡

## 反向触发

- 若"但"前后话题完全不同（而非同一话题的不同角度），应按强转折处理
- 若题目问的是细节而非主旨，不使用本卡
