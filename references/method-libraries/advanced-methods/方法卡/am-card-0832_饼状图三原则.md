# 方法卡：饼状图三原则

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 饼状图三原则 |
| 适用题型 | 资料分析——饼状图比重判断选项 |
| 触发场景 | 题目给出饼状图选项，需要根据数据判断哪个图正确，或根据饼状图快速定位数据 |
| 步骤逻辑 | ① 抓特殊比例：看某部分是否占25%（1/4）、50%（1/2）等一眼可辨识的面积；② 看几部分之间的比例关系（如100:50对应2:1面积比）；③ 软件生成的饼图从12点钟方向顺时针依次排列各部分 |
| 高频错因 | 忽略饼图排列顺序规律，导致对应关系错乱；没有利用25%/50%等特殊比例快速排除选项 |
| confidence | medium |

## 补充说明

三个原则层层递进：先用特殊比例（约1/4、约1/2等一眼可辨识的面积）快速排除明显错误选项；再用两部分之间的倍数关系缩小范围；最后用顺时针排列规则确认。注意：手工绘制的饼图排列可能不完全符合软件顺时针规则，需结合数据验证。

## 不适用条件

- 饼图各部分比例非常接近（如四个25%左右的部分），面积肉眼难以区分时，此法失效，需改用精确计算。
- 题目选项以数字表格形式呈现而非饼图时，不需要图上判断，直接比较数据。

## 反向触发

- 选项均为纯数值、没有饼图，应直接计算比大小。
- 各部分比重差距极小且选项接近，面积比较不足以区分，需精确算。
