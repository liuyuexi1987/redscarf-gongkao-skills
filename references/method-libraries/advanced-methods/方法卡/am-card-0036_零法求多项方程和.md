# 方法卡：零法求多项方程和
## 基本信息
| 字段 | 值 |
|------|-----|
| 方法名 | 零法求多项方程和 |
| 适用题型 | 数量关系-不定方程/多项方程求和 |
| 触发场景 | 两个方程三个未知数，只需求三者之和（如A+B+C） |
| 步骤逻辑 | 1. 判断方程组有无穷多解，但所求表达式为定值；2. 令其中一个未知数为0（如A=0）；3. 解剩余两个未知数；4. 三者相加得结果 |
| 高频错因 | 不理解为何可令某未知数为0；解出负数时误以为做错（负数也合法） |
| confidence | high |
## 补充说明
原理：方程组秩 < 未知数个数，有无穷多组解，但所求表达式的值唯一。因此可取任意一组特解（如令某未知数=0），所得结果即为正确答案。也可用等量代换法：对方程做线性组合直接消去不需要的项。两种方法等价，零法更无脑。
## 不适用条件
- 方程组有唯一解（秩=未知数个数），不存在自由变量，不能随意赋值。
- 所求表达式的值随未知数取值变化（非定值），令某未知数为0会得到错误结果。
- 方程含非线性项（如乘积、平方），线性特解思路不成立。
## 反向触发
- 题面要求求出每个未知数的具体值，而非三者之和或其他组合表达式。
- 方程个数等于未知数个数且行列式非零，属确定方程组，直接求解即可。
