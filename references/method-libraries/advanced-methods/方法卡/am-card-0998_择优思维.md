# 方法卡：择优思维

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 择优思维 |
| 适用题型 | 言语理解——通用原则 |
| 触发场景 | 所有言语题，尤其联考题、选项有瑕疵时 |
| 步骤逻辑 | ① 不追求完美答案，选"最不差"的；② 选项有小瑕疵但其他选项更差→接受瑕疵；③ 不因选项有瑕疵就选一个完全错误的选项 |
| 高频错因 | ① 因为正确选项漏了"高水平"三个字→选了完全无关的选项；② 因为选项不是完美概括→选了以偏概全的选项 |
| confidence | high |

## 补充说明
联考命题不严谨，选项经常有小问题。当某个选项存在小瑕疵（如遗漏个别限定词）但整体方向正确，而其他选项存在更严重的问题（与文段无关、以偏概全、主体缺失）时，应接受有小瑕疵的选项而非选择完全错误的选项。择优的核心是比较"瑕疵的严重程度"，而非追求完美匹配。

## 不适用条件
- 选项中存在完全正确、无任何瑕疵的选项时，无需择优，该选项即为答案。
- 题目为细节题或严谨定义题（如定义判断、严谨的数学计算）时，不允许接受任何瑕疵。
- 所有选项瑕疵程度相近、难以区分优劣时，本方法不产生区分价值。

## 反向触发
- 当两个选项的瑕疵难以判断孰轻孰重时，应换用"中心理解四步法（国考版）"回到主旨句重新核验选项与主旨的匹配度。
- 当瑕疵涉及核心主体词缺失而非限定词遗漏时，应视为严重问题而非"小瑕疵"，改用主题词匹配排除。
- 当选项的"小瑕疵"实际改变了语义方向时，应重新评估，避免将语义错误误判为可接受的瑕疵。
