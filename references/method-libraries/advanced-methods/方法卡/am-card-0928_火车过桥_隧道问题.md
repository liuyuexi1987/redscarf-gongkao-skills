# 方法卡：火车过桥/隧道问题

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 火车过桥/隧道问题 |
| 适用题型 | 行程问题·火车过桥 |
| 触发场景 | 火车通过隧道或桥梁，已知隧道/桥梁长度和通过时间，求火车长度或速度 |
| 步骤逻辑 | 1. 总路程 = 隧道（桥梁）长度 + 火车自身长度；2. 火车头进入→火车尾离开，火车头走过的距离 = 隧道长 + 车长；3. 若两个隧道长度不同、时间不同 → 路程比 = 时间比（速度不变）；4. 路程差 = 隧道长度差 → 用比例差求车长；5. 例：600米用18秒，480米用15秒 → 时间比6:5 → 路程比6:5 → 差1份=120米 → 车长120米 → 速度=720÷18=40米/秒 |
| 高频错因 | 忘记加上火车自身长度 |
| confidence | high |

## 补充说明

此方法类似牛吃草的比例差思路——有不变量（车长/草长）+有变化量（隧道长/牛数）

## 不适用条件

- 火车未完全通过隧道（如车头未到达出口、车尾仍在隧道内）的中间状态题。
- 速度变化（加速/减速进隧道）的非匀速场景。
- 多列火车同时通过同一隧道的会车问题。

## 反向触发

- 仅有单一隧道数据无对比条件时，改用基础行程公式"总路程=速度×时间"列方程。
- 涉及会车（两车相向/同向）时，应换用相遇/追及模型并叠加两车车长。
- 火车长度可忽略（远小于隧道长）时，可直接按质点运动简化计算。
