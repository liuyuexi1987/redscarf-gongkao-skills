# 方法卡：解释转折现象

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 解释转折现象 |
| 适用题型 | 判断推理——解释现象题 |
| 触发场景 | 题干出现"但是/然而/却"，前后看似矛盾，要求解释 |
| 步骤逻辑 | ① 找转折词，确定"矛盾点"是转折后的事实B；② 只需为B找一个可能的原因；③ 不需要证明，提供可能性即可；④ 想越少越对，越直接越好 |
| 高频错因 | ① 当加强题去套（解释现象≠加强）；② 想太多，脑补复杂逻辑；③ 选了循环论证项（用结果解释结果） |
| confidence | high |

## 补充说明

解释现象是最简单的题型。铁律：只解释转折后的B为什么会发生，提供一个可能原因即可。选"结果性描述"选项是常见陷阱——用结果倒推结果属于循环论证，不能解释原因。

## 不适用条件

- 题干无转折结构（无"但是/然而/却"等转折词）时，本方法不适用。
- 题干要求加强或削弱论证而非解释现象时，本方法不适用。
- 选项中无任何项能给出转折后现象的合理解释时，本方法不适用。

## 反向触发

- 当题干要求对因果方向进行削弱时，应换用共同原因削弱法。
- 当题干要求搭桥加强因果机制时，应换用因果加强搭桥法。
- 当题干要求评价论证逻辑漏洞时，应换用论证评价题方法。
