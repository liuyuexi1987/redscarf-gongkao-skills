# 方法卡：天平问题找3的N次方

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 天平问题找3的N次方 |
| 适用题型 | 数量关系——统筹计数、天平称重 |
| 触发场景 | 已知一个次品且轻重方向确定，要求保证找出次品的最少称重次数 |
| 步骤逻辑 | 1. 一次称重可区分3包（称两包：同重→第三包，不同→轻的）；2. 两次称重可区分 3×3=9 包（每组3包，先找组，再找包）；3. N次称重可区分 3^N 包；4. 找比总数大的最小 3^N，该N即为最少称重次数 |
| 高频错因 | 题目问"至少称几次"但未说"保证"时，答案可以是1次（运气好一次就称出）记住是找**比目标数大**的那个 3^N，不是最接近的 |
| confidence | medium |
| 不适用条件 | 次品数量可能不止一个（三分法失效）；题目未要求"保证"且物品数很少，运气好一次就能确定 |
| 反向触发 | 若物品数恰好等于3的整数次幂，N直接就是答案无需再找"比它大的下一个"；若题目变体为不知道次品轻还是重，每次称重只能区分2种而非3种情况，需换用2的幂次公式 |

## 补充说明

天平每称一次三等分能力，所以是3的幂次。考试中注意题目措辞："保证找到"才取最坏情况，否则可取最好情况。
