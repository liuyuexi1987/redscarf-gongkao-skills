# 方法卡：词义轻重排序法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 词义轻重排序法 |
| 适用题型 | 逻辑填空——词义轻重/多空排除 |
| 触发场景 | 选项中多个词意思相近但程度不同（如"批评<指责<谴责<声讨"），需要根据语境选对应程度的词 |
| 步骤逻辑 | ① 将意思相近的选项按程度从轻到重排序；② 根据语境中的程度信号词（"稍有""严重""极其"等）确定需要的轻重级别；③ 选与语境程度最匹配的词；④ 如果语境没有明确程度信号，选中等程度的词（不偏不倚） |
| 高频错因 | ① 选了程度过重的词（如语境只需"影响"却选了"颠覆"）；② 选了程度过轻的词（如语境需要"根除"却选了"减少"） |
| confidence | high |

## 补充说明
词义轻重是多空题的核心解法之一。当第一空无法确定时，先看哪个空的选项轻重差异最大，从差异最大的空入手排除。"迥然不同"比"略有差异"程度重得多，要根据语境的"强调程度"来选。

## 不适用条件
- 选项词义轻重相近，无明显程度差异可供排序。
- 语境无程度信号词，且选项间差异不在轻重而在语义方向或搭配。
- 选项词义方向（褒贬）不同而非程度不同，轻重排序无意义。

## 反向触发
- 当词义轻重无法区分选项时，应换用搭配验证选词法或感情色彩匹配法。
- 当语境无明确程度信号时，需补充语境解释对应法寻找程度暗示。
- 当选项间存在同义词但适用对象不同时，应换用搭配验证选词法核验适用对象。
