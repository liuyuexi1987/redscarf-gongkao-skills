# 方法卡：年均值与年均增长区分

| 字段 | 内容 |
|------|------|
| 方法名 | 年均值与年均增长区分 |
| 适用题型 | 资料分析-含"年均"二字的题目 |
| 触发场景 | 题目出现"年均"，需要判断是求平均值还是年均增长率 |
| 步骤逻辑 | 1. 看"年均"后是否有"增长"二字 → 2. 无"增长"→年均值=总量÷年份数（除以n） → 3. 有"增长"→年均增长率=末期÷初期开(n-1)次方减一（除以n-1） |
| 高频错因 | 把年均值当年均增长率做；年均值除以n-1而非n |
| confidence | high |

补充说明：如19年到22年共4个数据点，年均值÷4，年均增长÷3。注意区分：有"增长"二字时除以n-1，无"增长"二字时除以n。"逐月""逐年"不用往前推起点，如2019~2022年只看这四年内的数据。

## 不适用条件

- "年均"出现在非统计语境（如年均收入但问的是单年数据）时，需先确认题意
- 起止年份界定不明确（如"近五年"是否含首尾年）时，n值无法确定
- 题目已明确给出年均增长率数值，不需要再做概念辨析

## 反向触发

- 当"年均"和"增长"同时出现但题目问的是增长量（绝对值）而非增长率时，应选用增长量公式
- 题目表述为"年均增长XX万元"（带绝对单位），这是年均增长量而非年均增长率，不要套开方公式
- 当年份区间跨越"五年规划"等政策区间时，需先确认n是4还是5，再决定用哪个公式
