# 方法卡：选项分析决定计算策略

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 选项分析决定计算策略 |
| 适用题型 | 资料分析——所有计算题的前置判断 |
| 触发场景 | 拿到任何资料分析计算题，动笔之前必须先看选项 |
| 步骤逻辑 | ①看选项差距：估算误差可能跨选项时精算，差距明显时算到足以区分即可；②看有效位：选项首位明显不同时可先算首位，但仍要核对量级和单位；③看选项形式：比例选项且两边合计为整体时，可转化为部分占总体的单值再比较 |
| 高频错因 | 不看选项直接精算浪费时间；选项差距大时仍逐位精算；选项为比例形式时仍算原始比值 |
| confidence | high |

## 补充说明

三种典型场景贯穿资料分析：选项差距不足以覆盖估算误差时改用精算；选项首位明显不同时可先算到足够区分的有效位；选项为比例形式且两边合计为整体时，可转化为部分占总体的单值再比较。核心是先看选项差距，再决定计算精度。

## 不适用条件

- 题目本身不需要计算（如直接读数题、趋势判断题）
- 选项形式特殊（如"无法确定""以上都对"等非数值选项），无法通过差距判断策略

## 反向触发

- 当判断选项差距大而大胆估算后，若两个选项结果非常接近，应立刻切换为精算确认
- 当选项为比例形式但两边加起来不等于100时，不能直接套用"转为部分/总体"的简化策略
- 当首位相同的选项有两个以上时，需继续算第二位有效数字，不能只看首位就选
