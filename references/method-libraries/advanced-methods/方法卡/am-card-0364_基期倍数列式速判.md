# 方法卡：基期倍数列式速判

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 基期倍数列式速判 |
| 适用题型 | 资料分析 - 两个指标的基期倍数判断 |
| 触发场景 | 已知A和B的现期值及各自增速，问A是B的几倍（基期口径） |
| 步骤逻辑 | 1. 列式：(A/B) × (1+rB)/(1+rA)；2. 先判断 A/B 的大致范围（大于1还是小于1）；3. 再判断 (1+rB)/(1+rA) 是否大于1；4. 两部分相乘后快速判断整体范围，结合选项选最近值 |
| 高频错因 | 拿现期倍数直接当基期倍数，忽略增速差异对倍数的修正 |
| confidence | high |

## 不适用条件

- 题目问的是现期倍数而非基期倍数（无需修正，直接 A/B 即可）
- 两个指标增速相同或非常接近（修正因子约等于 1，直接用现期倍数判断即可）
- 题目直接给出了基期值（不需要用公式还原，直接用基期值计算）

## 反向触发

- 当 A/B 已明显落在某个选项区间、修正因子又接近 1 时，不必套公式，直接取现期倍数最近的选项
- 当选项间距极小（修正后难以区分）时，应改用精确计算而非估算判断
