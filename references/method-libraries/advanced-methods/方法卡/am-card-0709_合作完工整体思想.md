# 方法卡：合作完工整体思想

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 合作完工整体思想 |
| 适用题型 | 数量关系——工程问题 |
| 触发场景 | 多人合作完成工作，中间有穿插帮忙；不需要算每个人具体干了多少 |
| 步骤逻辑 | 不管帮谁干活、怎么穿插，只要没闲着，就用总工作量÷总效率=总时间。；1. 设工作总量（通常是时间的最小公倍数）；2. 求出各人效率；3. 总工作量÷总效率=总时间 |
| 高频错因 | 忘记设工作总量为最小公倍数导致效率出现分数；误判"没人闲着"的条件 |
| confidence | medium |

## 补充说明

- 这个思想适用于简单合作问题
- 复杂穿插问题可能还是需要列方程

## 不适用条件

- 题目明确要求计算某人具体工作量或分段时间时，整体法无法给出精确答案
- 工作效率不是恒定值（如效率随时间递减）时，不能用恒定效率的整体法
- 有人中途休息或退出时，"没人闲着"的前提不成立

## 反向触发

- 若题目涉及的是追及/相遇问题，不使用本卡
- 若题目只有一人完成工作、不存在合作场景，不适用整体思想
