# 方法卡：因果倒置识别

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 因果倒置识别 |
| 适用题型 | 判断推理——归因削弱题（对比实验类：A组有X，B组无X，A组更Y，归因为X→Y） |
| 触发场景 | 题干将X归因为Y的原因；需要找最强削弱选项 |
| 步骤逻辑 | ① 提取归因结构：因为X所以Y（如适量饮酒→健康）；② 优先排查因果倒置选项：是否存在"本来就有Y的人才去做X"（如身体健康的人更倾向饮酒）；③ 因果倒置是最强削弱力度之一，遇到即可快速锁定，无需再比较其他选项 |
| 高频错因 | 被"不明确选项"（如一半加强一半削弱的选项）干扰；忽略了因果倒置是力度最强的削弱方式 |
| confidence | high |

## 补充说明

因果倒置选项直接反转因果方向（如题干归因"行为X→状态Y"，倒置选项指出"状态Y的人更倾向于行为X"），是最强削弱力度之一，遇到即可快速锁定。

常见干扰项识别：
- **不明确选项**：选项前后半句方向矛盾（前半加强后半削弱），综合为零，不作为最强削弱。
- **分组不一致选项**：对比维度与题干归因维度不匹配（如题干按是否饮酒分组，选项按地域分组），直接排除。

## 不适用条件

- 题干不是对比实验归因结构（无X→Y的因果主张）时不适用。
- 因果方向不可逆（如时间先后明确锁定原因在前、结果在后）时，因果倒置不成立。
- 题目问法为"加强/支持"而非"削弱/质疑"时，应换用补强思路。

## 反向触发

- 当题干因果方向不可逆（原因时间上先于结果）时，应换用"他因削弱"或"切断联系"法。
- 当选项中没有反转因果方向的项时，应换用"他因择优"或"样本代表性质疑"法。
- 当因果倒置选项存在但表述力度较弱时，应与其他削弱项比较力度，而非盲目锁定。
