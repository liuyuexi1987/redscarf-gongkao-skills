# 方法卡：小数转分数简化十字交叉

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 小数转分数简化十字交叉 |
| 适用题型 | 资料分析、数量关系——比例混合与十字交叉 |
| 触发场景 | 百分数可准确转成熟悉分数，换算后能明显简化约分或十字交叉 |
| 步骤逻辑 | 1. 识别关键小数：6.25% = 1/16，12.5% = 1/8，25% = 1/4；2. 将百分数拆分为整数部分 + 特殊小数部分，再转分数；3. 例如 56.25% = 50% + 6.25% = 1/2 + 1/16 = 9/16；4. 用分数进行十字交叉，直接约分得到最简比 |
| 高频错因 | 用小数硬算（如31.25和43.75去约分），耗时且易错不记得6.25% = 1/16这个关键换算 |
| confidence | medium |
| 不适用条件 | 百分数本身便于直接计算、转成分数不能减少步骤时，不必换算；题目只需估算且现有精度已足够区分选项时，无需追求精确约分 |
| 反向触发 | 转分数后分母出现较大数（如16的倍数叠加），计算复杂度反而上升，应改用小数直接计算；估算误差可能跨越选项时改用精算验证 |

## 补充说明

需要记忆的常用换算：1/8=12.5%，3/8=37.5%，5/8=62.5%，1/16=6.25%。这些在资料分析和数量关系中高频出现。本方法强调"分数好约分"，遇到类似小数优先转分数再计算。
