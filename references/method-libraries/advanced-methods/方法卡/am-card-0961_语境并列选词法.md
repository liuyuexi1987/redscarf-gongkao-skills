# 方法卡：语境并列选词法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 语境并列选词法 |
| 适用题型 | 逻辑填空——语境关系（并列） |
| 触发场景 | 题目出现"同时/此外/也/又/一方面…另一方面/既…又/不是…而是"等并列关联词，或两个空格用顿号/逗号连接 |
| 步骤逻辑 | ① 找到并列信号词，确认并列的两项内容；② 空格与已知词并列→选与已知词语义相近/同向的词；③ 两个空格并列→选同一语义场、同一感情色彩的词对；④ 验证：代入后并列的两项是否在语义上对称 |
| 高频错因 | ① 把"不是…而是"的并列（对比并列）当成转折，选了反义词；② 忽略顿号连接的隐性并列关系；③ 并列的两项感情色彩不一致（一褒一贬） |
| confidence | high |

## 补充说明
并列是逻辑填空中出现频率最高的语境关系。关键区分：同向并列（A和B方向一致）和对比并列（A和B方向相反但结构对称）。"不是…而是"是对比并列，前后语义相反但不是转折关系。

## 不适用条件
- 空格前后无任何并列关联词，且语义关系不明确，无法确认并列结构。
- 选项之间无同义/反义关系，无法通过并列验证筛选。
- 并列仅为形式对称（如对仗句式）但语义上实为递进或转折关系。

## 反向触发
- 当并列关系仅是表层形式，深层逻辑为递进或转折时，应换用递进/转折分析法重新判断语义方向。
- 当两个空格虽形式并列但分属不同语境层级时，需结合语境对应分析法补充核验各空的呼应词。
- 当并列项感情色彩一致但语义仍无法区分时，应换用词义轻重排序法或搭配验证选词法进一步筛选。
