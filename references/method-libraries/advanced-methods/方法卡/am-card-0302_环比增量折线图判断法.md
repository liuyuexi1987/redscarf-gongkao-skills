# 方法卡：环比增量折线图判断法

| 字段 | 内容 |
|------|------|
| 方法名 | 环比增量折线图判断法 |
| 适用题型 | 资料分析-折线图选择题（反映环比增量变化趋势） |
| 触发场景 | 题目要求选出能正确反映环比增量变化趋势的折线图，选项折线图有差异 |
| 步骤逻辑 | 1. 计算目标月份的环比增量（本月-上月） → 2. 找关键月份对（如7月和10月下降幅度相近） → 3. 对应折线图上两点应等高 → 4. 排除不符合的选项 |
| 高频错因 | 把环比增量当成绝对量，忽略"变化趋势"是看增量而非原值 |
| confidence | high |

补充说明：关键技巧是找"锚点"——两个环比增量相近的月份，在折线图上应等高。只需验证一个锚点就能排除多个选项。

## 不适用条件

- 题目问的是绝对量变化（原值走势）而非环比增量趋势
- 所有选项折线图形状相同，仅纵轴刻度不同
- 数据缺失月份过多，无法计算完整环比增量序列

## 反向触发

- 当某两个月份的环比增量数值接近但符号相反时，不应视为"等高"锚点，应分别按正负判断走势方向
- 当选项折线图差异仅在首尾端点时，应优先验证首尾月份而非中间锚点
- 当题目问的是"累计量走势"时，不应使用环比增量方法，应换用累计值直接比较
