# 方法卡：论证支撑部分是重点

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 论证支撑部分是重点 |
| 适用题型 | 中心理解题、语句衔接题 |
| 触发场景 | 文段第一句包含两个并列方面（如"A不仅是B，而且是C"），后文例子只论证其中一个方面 |
| 步骤逻辑 | 1. 第一句话如有并列结构，识别后文的论证支撑了哪个方面；2. 被论证支撑的那个方面就是重点，未被论证的不是；3. 前文不需要细读，只需判断后文论证的方向；4. 语句衔接题中，承接重点所在方面即可 |
| 高频错因 | 看到第一句有两个方面，以为都要兼顾没有分析后文论证了哪个方面，凭直觉选纠结选项的细节用词（如"依赖于太绝对"），忽略主旨是首要判断标准 |
| confidence | high |

## 不适用条件

1. 后文对并列的两个方面都有论证支撑，没有明显偏重——不能用此法判断，需回归文段整体主旨。
2. 后文论证的内容是转折或对比关系（如"但其实""然而"），而非对并列某一方面的支撑——转折结构优先。
3. 第一句的并列结构不是核心论点，而是背景铺垫——后文论证的可能不是首句的任何方面。

## 反向触发

1. 后文看似论证了某一方面，但实际是用该方面作铺垫引出真正的转折主旨——应检查后文是否有转折词。
2. 并列的两个方面在后文中以"一方面…另一方面"形式分别展开，说明两者都是重点，不能只抓一个。
3. 语句衔接题中空格在第一句之前，无法通过后文论证方向判断——应从文段整体结构入手。
