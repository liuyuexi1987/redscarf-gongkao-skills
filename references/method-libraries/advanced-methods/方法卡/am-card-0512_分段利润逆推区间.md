# 方法卡：分段利润逆推区间
## 基本信息
| 字段 | 值 |
|------|-----|
| 方法名 | 分段利润逆推区间 |
| 适用题型 | 数量关系-利润/分段分配 |
| 触发场景 | 利润按区间不同比例分配，给出最终分配倍数关系，求总量或分配变化 |
| 步骤逻辑 | 1.列各区间分配比例，判断在哪个区间内甲>乙或乙>甲 2.根据题目给出的倍数关系（如乙=1.2倍甲），反推总量落在哪个区间 3.设超出该区间的部分为X，按对应比例列方程 4.解出X后，对变化后的总量重新按比例分配 |
| 高频错因 | 未先判断总量所在区间就列方程；减半后未重新判断是否跨越区间 |
| confidence | high |

## 不适用条件

1. 利润分配只有单一比例不分区间时，无需判断区间，直接按比例列方程
2. 题目未给出倍数关系而给出具体金额时，逆推区间思路不适用，改为正向计算

## 反向触发

1. 分配比例有三段或更多区间时，需先验证目标区间是否唯一，不能默认只有一种可能
2. 减半或变化后的总量恰好落在区间边界时，需对相邻两个区间分别验证
## 补充说明
核心思路是"先定区间再列方程"：分别列出各区间甲乙所得比例，看哪个区间能满足乙>甲的条件，从而锁定总利润范围。后续问"减半后"需重新计算减半后总量是否仍在同一区间。
