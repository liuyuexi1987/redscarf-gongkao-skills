# 方法卡：多量混合求份数之比

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 多量混合求份数之比 |
| 适用题型 | 数量关系——混合比例、十字交叉 |
| 触发场景 | 已由十字交叉得到总成本或总量之比，还需结合单价、单浓度求实际数量之比 |
| 步骤逻辑 | 1. 先用盐水十字交叉求出**总成本之比**（如甲:乙 = 2:3）；2. 再求出**单个成本之比**（如甲单个45元，乙单个60元，化简为3:4）；3. 数量之比 = 总成本之比 ÷ 单个成本之比 = (2/3) ÷ (3/4) = 8/9；4. 即甲:乙 = 8:9 |
| 高频错因 | 直接把十字交叉结果当作数量之比（实际是总成本之比）忘记"总的是比单的"需要用除法 |
| confidence | medium |
| 不适用条件 | 各物品单价/单浓度相同，十字交叉结果直接就是数量比，无需额外除法；题目只求混合后的总浓度/总成本，不求具体数量 |
| 反向触发 | 数量之比计算结果非简单整数比时，回溯检查总成本比与单成本比是否抄对、除法是否变成乘倒数；若涉及三种以上物品混合，需分步两两十字交叉 |

## 补充说明

这是盐水十字交叉法的进阶应用。十字交叉给出的是"混合后的浓度比"（此处为总成本之比），要得到实际数量（件数），还需除以单个成本。比例的除法 = 分数形式的乘法（乘倒数）。
