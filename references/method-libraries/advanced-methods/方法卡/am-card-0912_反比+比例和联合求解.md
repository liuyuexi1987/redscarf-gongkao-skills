# 方法卡：反比+比例和联合求解

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 反比+比例和联合求解 |
| 适用题型 | 行程问题·工程问题（路程/工程量不变场景） |
| 触发场景 | 题目同时给出速度比（效率比）和时间总和，求各自时间 |
| 步骤逻辑 | 1. 在路程或工程量相同的前提下，由速度比或效率比反推时间比；2. 将时间比转成份数，结合时间总和求每份值；3. 得到各自时间后，再用“速度×时间”或“效率×时间”回代验证总量一致 |
| 高频错因 | 反比方向搞反（速度快的时间应该更短） |
| confidence | high |

## 补充说明

该方法整合反比与份数思想，是比例法中提速效果明显的核心技巧，适用于中等及以下难度的行程/工程问题，可在较短时间内完成求解。

## 不适用条件

- 题目未同时给出速度比（或效率比）与时间总和，缺其一则无法直接套用本联合求解流程。
- 总量并非不变（如路程随时间变化），反比前提不成立。
- 涉及三段及以上的运动或多人协作的复杂工程，二元反比模型不足以覆盖。

## 反向触发

- 当题目未给时间总和、只给速度比和差值时，应改用比例和份数法的差量分支。
- 当路程/工程量本身变化时，应改用正比关系识别法或方程法处理。
- 当关系结构超出 A=B×C 的二元乘积式时，应改用多元方程组求解。
