# 方法卡：政治理论与时政常识边界卡

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 政治理论与时政常识边界卡 |
| 适用题型 | 常识判断——政治理论、时政常识 |
| 触发场景 | 用户做政治理论/时政常识题，需要判断理论表述正误、区分稳定理论与易变时政时 |
| 步骤逻辑 | ① 区分是稳定理论还是时政热点；② 稳定理论按框架判断；③ 时政标注"需核验"；④ 检查表述是否偷换关键词 |
| 高频错因 | 理论表述偷换关键词、时政信息过期、混淆不同理论体系、把时政表述当永恒真理 |
| confidence | high |
| 不适用条件 | 1. 涉及最新官方数据、最新名单、最新机构调整的纯时政题，本卡只能标注需核验；2. 题目只考查具体政策细节而非规范表述、概念层级或状态区分时，不宜硬套本卡 |
| 反向触发 | 1. 题目属于经济/法律/地理类常识时应读对应领域卡；2. 纯时政题且题干已明确要求最新口径时，应先核验再判断 |

## 核心判断

政治理论题分两类：**稳定理论**（马哲、毛思想、中特理论框架）可以按知识框架判断；**时政热点**（最新会议、政策、数据）必须标注"需以最新官方信息为准"。

## 使用流程

### 第一步：区分稳定理论 vs 时政热点

| 特征 | 稳定理论 | 时政热点 |
|------|---------|---------|
| 内容 | 哲学原理、理论体系框架、党史大事件 | 最新会议、最新政策、年度数据 |
| 时效性 | 长期稳定 | 可能每年变化 |
| 判断方式 | 按知识框架判断 | 标注"需核验" |
| 典型题 | "下列关于矛盾的说法正确的是" | "下列关于XX会议精神的说法正确的是" |

### 第二步：稳定理论速查框架

#### 马克思主义哲学

| 原理 | 内容 | 易混点 |
|------|------|--------|
| 唯物论 | 物质决定意识，意识对物质有能动作用 | 不是"意识决定物质" |
| 辩证法 | 对立统一、质量互变、否定之否定 | 三大规律缺一不可 |
| 认识论 | 实践是认识的来源、动力、检验标准、目的 | 实践是"唯一"检验标准 |
| 矛盾的普遍性 | 矛盾存在于一切事物中 | 不是"矛盾可以调和" |
| 矛盾的特殊性 | 具体问题具体分析 | 不是"一刀切" |
| 主要矛盾 | 在事物发展中起决定作用的矛盾 | 抓主要矛盾≠忽视次要矛盾 |
| 矛盾的主要方面 | 决定事物性质的方面 | 主要方面≠主要矛盾 |

#### 毛泽东思想核心节点

| 时期/著作 | 核心内容 | 易混点 |
|----------|---------|--------|
| 《湖南农民运动考察报告》 | 农民问题是中国革命的中心问题 | 不是工人问题 |
| 《星星之火可以燎原》 | 农村包围城市、武装夺取政权 | 不是城市中心论 |
| 《矛盾论》《实践论》 | 哲学基础 | 不是军事著作 |
| 新民主主义革命 | 无产阶级领导的、人民大众的、反帝反封建的革命 | 领导阶级是无产阶级不是资产阶级 |
| 社会主义改造 | 三大改造（农业、手工业、资本主义工商业） | 不是"没收"而是"改造" |

#### 中国特色社会主义理论

| 理论 | 核心关键词 | 易混点 |
|------|-----------|--------|
| 邓小平理论 | 解放思想、实事求是、社会主义市场经济 | 市场经济不是资本主义专利 |
| "三个代表" | 先进生产力、先进文化、最广大人民根本利益 | 三者缺一不可 |
| 科学发展观 | 以人为本、全面协调可持续 | 不是"以经济建设为本" |
| 习近平新时代中国特色社会主义思想 | 中国梦、新发展理念、人类命运共同体 | 需核验最新表述 |

### 第三步：时政题处理规则

- 涉及"第X次全国代表大会""第X届中央委员会第X次全体会议"的具体内容，标注"需核验"
- 涉及"十四五""十五五"等规划的具体指标，标注"需核验"
- 涉及最新机构改革、人事调整，标注"需核验"
- 涉及年度GDP增速、CPI等数据，标注"需核验"

### 第四步：规范表述校验

题干含"根本/核心/首要/基础/主线/总布局/战略布局/发展理念"等层级关键词时，按以下步骤校验：

1. 判断是概念理解还是原文表述题。
2. 抽取关键词：主体、层级、范围、目标。
3. 排除增词、漏词、偷换词、顺序错置。
4. 涉及会议新提法、报告原文时标注需核验。

高频偷换排查：

| 偷换类型 | 示例 |
|----------|------|
| 层级偷换 | "根本制度"偷换为"基本制度"或"重要制度" |
| 概念错配 | "新发展理念"和"新发展格局"混为一组 |
| 目标路径混 | "高质量发展"替换为"高速增长" |
| 任务混用 | "主要矛盾""根本任务""中心任务"互换 |
| 旧表述套新阶段 | 把旧阶段表述套到新阶段文件 |

反向检查：不用口号化印象替代规范文本；不把政策目标、路径、原则混为一类。

### 第五步：时政状态区分

时政题涉及法律或政策时，区分以下状态，不同状态对应不同事实：

| 状态 | 含义 |
|------|------|
| 提出 | 仅提出动议或草案 |
| 审议 | 进入审议程序，尚未通过 |
| 通过 | 已表决通过 |
| 公布 | 已由有权机关公布 |
| 施行 | 到达生效日期，正式实施 |

要点：不把"拟""将""已"混为同一事实状态；不把媒体解读当正式文件；不用旧年度报告覆盖新年度政策。数据要看统计期、口径、单位、同比/环比。

## 速记/排除规则

- "意识决定物质"→唯心主义，错
- "实践不是检验真理的唯一标准"→错
- "新民主主义革命由资产阶级领导"→错，无产阶级领导
- "社会主义市场经济是资本主义"→错
- 含"根本/基本/核心/关键"的政治表述被偷换时，通常错
- 涉及具体会议/政策/数据的选项，无法确认时标注"需核验"

## 高频易混点

| 易混点 | 正确区分 | 常见误判 |
|--------|---------|---------|
| 主要矛盾 vs 矛盾的主要方面 | 主要矛盾=事物发展动力；矛盾的主要方面=事物性质 | 混淆两个概念 |
| 国体 vs 政体 | 国体=人民民主专政；政体=人民代表大会制度 | 答反 |
| 根本制度 vs 根本政治制度 | 根本制度=社会主义制度；根本政治制度=人民代表大会制度 | 混为一谈 |
| 基本路线的核心 | "一个中心两个基本点"（经济建设为中心，四项基本原则+改革开放） | 漏掉任何一个 |
| 理论创新 vs 实践创新 | 理论创新指导实践创新；实践创新是理论创新的基础 | 把理论创新说成唯一来源 |

## 写回/复盘标签

- 常识-政治-理论表述偷换
- 常识-政治-国体政体混淆
- 常识-政治-主要矛盾方面混淆
- 常识-时政-信息版本待核验
- 常识-时政-会议政策过期

## 使用边界

1. 本卡不是政治理论百科库，不能替代最新理论学习。
2. 时政热点、最新会议精神、最新政策表述必须提醒以最新权威来源为准。
3. 无法确认理论表述最新状态时，只能说"方法倾向/需核验"，不能硬判。
4. 政治理论速记只作辅助排除，不得编造理论表述。
