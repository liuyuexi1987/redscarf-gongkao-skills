# 方法卡：比重不变推R1=R2

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 比重不变推R1=R2 |
| 适用题型 | 资料分析-覆盖率/占比持平类题目 |
| 触发场景 | 材料说某覆盖率或占比"与上年持平"，需要求其中一个量的增速 |
| 步骤逻辑 | 覆盖率 = 覆盖面积 / 总面积 -> 覆盖率不变 -> R(覆盖面积) = R(总面积) -> 已知覆盖面积的增量和现期，即可算增速 -> 该增速也等于总面积的增速 |
| 高频错因 | 比重不变不代表各部分不变，只是部分与整体增速相同 |
| confidence | high |

## 不适用条件

1. 材料表述为"基本稳定""变化不大"等模糊说法而非"持平/不变"时，不能直接认定R(部分)=R(整体)，需核实具体数值。
2. 部分与整体的增速差异较大时，比重不可能持平，说明对题意理解有误，需重新审题。
3. 题目中存在多个部分（而非只有部分与整体的二元关系）时，比重不变只说明该部分与整体增速相等，不适用于其他部分。

## 反向触发

1. 当材料说"比重上升/下降"时，应切换为比重变化方向判断：R(部分)＞R(整体)则比重上升，反之下降。
2. 若题目已知部分和整体的具体数值，可直接验证比重是否持平，无需套用增速相等的推导。
3. 涉及的是同一指标不同时期的比重变化时（而非部分vs整体），应改用两期比重差公式。
