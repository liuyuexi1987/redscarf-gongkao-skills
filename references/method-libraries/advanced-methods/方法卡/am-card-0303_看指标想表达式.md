# 方法卡：看指标想表达式

| 字段 | 内容 |
|------|------|
| 方法名 | 看指标想表达式 |
| 适用题型 | 资料分析-全题型（判断题型、列式） |
| 触发场景 | 读题时看到具体指标名称（如"市场份额""平均每支""同比增速"），需要快速判断该指标对应什么数学表达式 |
| 步骤逻辑 | 1. 读题圈出指标名 → 2. 由指标名判断是比值/增长率/增量/比重差等哪种题型 → 3. 对应列式 → 4. 找数代入 |
| 高频错因 | 看到指标名不分析表达式，直接盲目找数列式；把比值题当增长量题做 |
| confidence | high |

补充说明：核心方法论——由指标名直接锁定题型和列式方向。"市场份额"→占比→比值→考比值增长率或比值倍数；"平均每X"→后边是分母；"同比增速"→考增长率比较。看到指标名就能确定该用哪类公式。

## 不适用条件

- 题目不涉及具体指标名称，仅问"以下哪项正确/不正确"
- 指标名称为自定义或非标准表述，无法直接对应常规公式
- 材料中指标数据缺失或需要多步换算才能得到题目所问量

## 反向触发

- 当"同比增速"出现在选项中但题目问的是比值关系时，不应套增长率公式，应先确认题型再列式
- 当指标名对应多种可能的表达式时（如"增长率"可能是同比、环比或间隔），应结合时间条件确定具体公式
- 当盲目找数列式导致结果不合理（如增速超过100%或比重大于1）时，应回头检查是否误判了题型
