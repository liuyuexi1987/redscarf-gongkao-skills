# 方法卡：没讲完往后看

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 没讲完往后看 |
| 适用题型 | 逻辑填空——线索定位 |
| 触发场景 | 空格所在句句号未出现（句子没写完），或空格在句中位置 |
| 步骤逻辑 | ① 空格所在句还没结束（没有句号）→逻辑提示通常在后文；② 不要在前文死找→往后看；③ 后面的内容才是对空格的直接提示 |
| 高频错因 | ① 只看前面不看后面→漏掉关键线索；② 句子没写完就在前文强行找对应 |
| confidence | high |

## 不适用条件

- 空格所在句已有句号（句子已完结），逻辑提示通常在前文或本句中，不宜机械地"往后看"
- 段首空格（第一句话开头）的线索通常在后文的展开中，但本法的"句号未出现"判断前提不适用，需结合文段结构整体分析

## 反向触发

- 若空格在文段最后一句且后文已无内容，本法失效，需在前文寻找逻辑提示
- 若后文出现了转折（如"但是""然而"），转折后的内容可能与空格方向相反，不能直接用后文的表面含义填空
