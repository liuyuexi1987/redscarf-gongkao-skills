# 方法卡：年均增量基础算法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 年均增量基础算法 |
| 适用题型 | 资料分析——年均增量/年均增速计算 |
| 触发场景 | 题目问"从A年到B年的年均增量是多少" |
| 步骤逻辑 | ① 找准基期值和现期值；② 计算总增量=现期-基期；③ 计算年数=现期年份-基期年份；④ 年均增量=总增量÷年数 |
| 高频错因 | ① 将年均增量等同于某一年的具体增量（年均只是整体均值，不代表任何单年）；② 基期现期找错导致年数算错 |
| confidence | high |

## 补充说明

年均增量是整体平均概念，不能用它反推某一年的具体值。年均增量为负值时表示整体年均在减少，计算逻辑不变。当估算误差可能跨越选项或改变结论时，改用精算/验证。

## 不适用条件

1. 题目问的是年均增速（百分比形式），需要的是年均增长率公式，而非简单做差除年数。
2. 需要判断某一年的具体增量，年均增量是整体均值不代表任何单年。
3. 基期和现期不在同一统计口径（如单位不同），直接做差无意义。

## 反向触发

1. 题干出现"年均增量"或"从X年到Y年平均每年增加多少"的表述。
2. 材料给了首尾两年的绝对值，可直接做差除年数。
3. 选项为带量纲的具体数值（万吨、亿元等），求的是平均变化量而非百分比。
