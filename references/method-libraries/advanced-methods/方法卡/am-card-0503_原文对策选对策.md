# 方法卡：原文对策选对策

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 原文对策选对策 |
| 适用题型 | 主旨题/标题题/中心理解题 |
| 触发场景 | 文段出现对策句（只有才/必须/需要/离不开/迫切需要等），选项中有对策项、问题项、目标意义项混在一起 |
| 步骤逻辑 | 1)定位原文对策句，提取对策内容 2)选项优先匹配对策内容本身 3)目标/意义/结果（"为…""以…""才能…"后面的部分）只是参考，不等于对策 4)如果两个选项对策内容一致，再对比目标是否匹配 |
| 高频错因 | 把目标意义当成对策内容；把对策和目标并重混淆（如"从X到Y"表述） |
| confidence | medium |

## 不适用条件

1. 文段没有对策句而是分析原因或描述历程时，不按对策类处理
2. 文段虽出现对策词（如"需要"）但不是核心重点而是举例或背景铺垫时

## 反向触发

1. 若文段是历程描述而非对策，配合历程类选项识别方法
2. 若选项是因果表述，配合"原因类选项反推验证法"
3. 若两个选项对策内容一致，配合"对策内容与目标意义区分"方法进一步筛选
