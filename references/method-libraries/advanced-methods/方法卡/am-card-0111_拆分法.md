# 方法卡：拆分法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 拆分法 |
| 适用题型 | 资料分析·乘法精算（百分比乘法、数据接近时的整理计算） |
| 触发场景 | 两个乘法项的百分比非常接近，需要提出公因式简化计算时 |
| 步骤逻辑 | 1. 将其中一个百分比拆分为相同部分+差值（如65.4%=64.8%+0.6%） 2. 提取公因式合并相同部分 3. 单独计算差值部分 4. 合并结果 |
| 高频错因 | 拆分后符号搞反；差值部分遗忘或计算错误 |
| confidence | high |

## 补充说明

拆分法是资料分析中百分比乘法的核心速算手段。典型场景：可将一个百分比拆成相近基准+差值，提取公因式后大幅降低计算难度。该方法在选项差距偏小时尤其关键。

## 不适用条件
1. 当两个百分比差距过大、无法找到接近的公因式时，拆分法失去简化意义
2. 当计算是加减法而非乘法时，拆分法不适用

## 反向触发
1. 当拆分后差值部分仍然较大，整体计算量未明显减少时，应换用截位或有效数字法
2. 当估算误差可能跨越选项时改用精算
