# 方法卡：基期月均值——先除后基期

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 基期月均值计算顺序选择 |
| 适用题型 | 资料分析——求基期月均值（已知现期总量、增长率、月数） |
| 触发场景 | 题目给出年度总量和年增长率，要求求去年月均值 |
| 步骤逻辑 | ① 方案A：先求现期月均（总量÷12），再除以 (1+R) 求基期月均；② 方案B：先求基期总量（总量÷(1+R)），再÷12；③ 选择原则：先做无误差的运算（除法精确无误差），把有误差的运算（÷(1+R)）放后面，因为无误差步骤不影响后续精度 |
| 高频错因 | 误以为月均值的增长率与整体增长率不同；先做有误差运算导致误差累积 |
| confidence | high |

## 补充说明

核心原则：先做精确运算，把需要估算的步骤放最后。月均值的增长率与整体增长率相同（"整体涨10%，平均每个人涨10%"）。

## 不适用条件

- 题目要求的是现期月均值而非基期月均值时，直接除以月数即可，无需除以 (1+R)。
- 当期数不是 12（如按季度、按日均值），需要调整除数，方法逻辑相同但分母数值不同。
- 当增长率极小（接近 0），现期月均值与基期月均值几乎相等，是否调整 (1+R) 对结果无实质影响。

## 反向触发

- 当总量和增长率不对应同一统计期间时，先确认数据一致性再列式。
- 当题目要求的是基期季度均值或日均值时，将 12 替换为对应期数。
- 当误差可能跨越选项或改变结论时，改用精算/验证。
