# 方法卡：盐水法判断比值大小

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 盐水法判断比值大小 |
| 适用题型 | 资料分析-综合分析题/比值大小判断-判断混合后比值是否超过某阈值 |
| 触发场景 | 题目给出两组数据混合后的比值，需快速判断是否大于/小于某个常见比例（如75%） |
| 步骤逻辑 | 1. 将分子分母拆成两部分：一部分恰好等于目标比例，另一部分单独看 2. 如(3300+13)/(4400+85)，3300/4400恰好=75% 3. 单看第二部分13/85不到75%，混合后会拉低整体 4. 因此最终比值不到75%；反之若第二部分高于阈值则整体会上升 |
| 高频错因 | 拆分后两部分比例关系判断错误；忘记混合稀释/浓缩的方向 |
| confidence | medium |
| 不适用条件 | 题目要求精确比值；无法把总量拆成两个可比较的子比值；目标比例、分子或分母的对应关系不一致 |
| 反向触发 | 题目只问混合比值相对某基准的大小时，可比较各部分子比值与基准的方向；若各部分分居基准两侧且权重会影响结论，必须结合分母权重计算，不能只看方向 |

## 补充说明

该方法本质是加权平均：若一部分比值恰好等于目标基准，新增部分低于基准，混合比值会下降；新增部分高于基准，混合比值会上升。若两部分分居基准两侧，则还要比较各自分母权重，不能仅凭方向判断。
