# 方法卡：基期比重已知现期比重速算

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 基期比重已知现期比重速算 |
| 适用题型 | 资料分析——基期比重计算，且题干直接给出现期比重（A比B） |
| 触发场景 | 题目问基期比重，材料中"占X%"恰好就是现期比重，同时给了部分增速R1和整体增速R2 |
| 步骤逻辑 | ① 识别题干中"占X%"即为现期比重A比B，直接抄用；② 套公式：基期比重 = 现期比重 × (1+R2)/(1+R1)；③ R1和R2带符号（负数为下降）；④ 左侧现期比重已知，只算右侧分数即可；⑤ 选项差距大时大胆估算（如R1很小则分母≈1，忽略不计） |
| 高频错因 | 找不到现期比重（"占X%"就是）；R1和R2方向搞反；忽略增速的正负号 |
| confidence | high |

## 补充说明

此类题型的巧妙之处在于：题干已经把现期比重给了，考生只需算右侧的修正因子。当R1极小时（如个位数千分比），分母1+R1≈1可忽略；当R2也较小时，分子1+R2也可近似。关键是先判断方向（增速正负→比重升降），再结合选项差距决定估算精度。

## 不适用条件

- 题干未直接给出现期比重（"占X%"），需要先从其他数据反推现期比重时，本速算法不适用。
- 选项差距极小，估算误差可能跨越选项时改用精算。

## 反向触发

- 当R1和R2方向相反且绝对值都较大时，修正因子偏离1较多，应放弃估算换用精算。
- 当材料给的是基期比重要求现期比重时，应换用反向公式：现期比重 = 基期比重 × (1+R1)/(1+R2)。
