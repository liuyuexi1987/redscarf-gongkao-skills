# 方法卡：图推高度相似预判法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 图推高度相似预判法 |
| 适用题型 | 判断推理——图形推理 |
| 触发场景 | 整体扫图后感觉各图高度相似，只有个别地方不同 |
| 步骤逻辑 | ① 整体扫图感觉"很像"→预判考移动/旋转/翻转/叠加/遍历等低变化规律；② 判断依据：图很像说明变化幅度小，而移转叠变常表现为原有元素的位置、方向或组合关系变化；③ 具体验证：对比相邻两图，找"哪一部分动了/哪个部分变了"→确认是移动、旋转、翻转还是叠加；④ 注意：高度相似的图如果先抠细节数笔画等，可能发现偶然成立的"微观规律"，应先完成宏观预判再验证细节 |
| 高频错因 | ① 看到高度相似的图却去数点线面，丢失"很像"这个宏观信号；② 发现微观规律（如笔画数恰好交替）就选了，忽略宏观上"图很像→考移转叠"的更强信号；③ 不区分旋转和翻转，用箭头法/时针法辨别 |
| confidence | high |

## 补充说明

当各图都呈现工整对仗的结构时，可优先核验轴对称、中心对称以及对称轴的数量和方向；验证失败后再转入其他属性或位置规律。

"移转叠变"四类规律的共同特征：变化幅度小，通常围绕原有元素的位置、方向、形态或叠加关系展开。先抓这个整体信号，再进入具体规律验证。

辨别旋转与翻转：箭头法（定位一条边画箭头，看方向是否反转）和时针法（定位两个点画连线，看顺逆时针是否反转）。

## 输出要求

- 讲图推时先说明观察顺序（宏观→预判→微观）
- 至少展示 2-3 层排查过程
- 图片不清、选项缺失、截图太小时，不得硬判答案
- 没读到具体细卡时，不得伪造卡号
- 有官方答案时按答案核验；无官方答案但图形清晰时，可写"按当前图形规律，我的复核倾向于 X"

## 不适用条件

- 图形整体不相似、差异明显时，预判"移转叠变"不成立，应换用数量或属性路径。
- 图形相似但相似点仅在颜色或填充方式时，本预判法不直接适用。

## 反向触发

- 宏观预判为"移转叠变"但具体验证全部失败时，应回查是否为"高度相似中的细微差异"规律（如某元素增减）。
- 旋转与翻转均无法解释变化时，应换用叠加或遍历路径补充核验。
