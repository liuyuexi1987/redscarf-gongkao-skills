# 方法卡：A推B真假判断-前假为真

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | A推B真假判断-前假为真 |
| 适用题型 | 判断推理-命题真假判断、矛盾命题找真假话 |
| 触发场景 | 给出命题"A→B"，需要判断在哪些条件下该命题为真/为假；或需要找A→B的否定/矛盾命题 |
| 步骤逻辑 | 1. A→B**只有A且非B时是假的**，其余三种情况（A真B真、A假B真、A假B假）都是真的；2. 口诀：**"前假为真"**——只要前件为假，命题自动为真；3. 口诀：**"后真为真"**——只要后件为真，命题自动为真；4. A→B的否定/矛盾 = **A且非B**（前件真、后件假）；5. 应用：遇到"坚决不同意""反驳""矛盾"等表述→找A且非B |
| 高频错因 | 误以为前件为假时命题无法判断真假（实际命题为真）把"或关系"理解为"要么A要么B"（实际A且B也是A或B的一种情况）"有些A是B"不意味着"有些A不是B"（有些可包含所有） |
| confidence | high |
| 不适用条件 | 1. 题目中的命题不是标准"如果A则B"的充分条件形式（如"只有A才B"的必要条件命题）时，前假为真的规则不直接适用，需先转换为等价命题再判断 2. 题目要求判断的是多个命题之间的真假传递关系而非单个命题的真值表时，应使用三段论或矛盾关系法而非逐个看前假后真 |
| 反向触发 | 1. 当命题涉及多层嵌套（如"如果A则(如果B则C)"），前假为真规则的应用容易在嵌套层次上出错，应逐层拆解后分别判断 2. 当题目要求找"等价命题"而非"矛盾命题"时，应使用逆否命题（非B→非A）而非A且非B的矛盾形式 3. 当多个命题中有相互矛盾关系需要同时判断真假话数量时，应画真值表或列矛盾对，不能仅凭口诀逐一判断 |
