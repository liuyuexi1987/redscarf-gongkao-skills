# 方法卡：纯问题文段抓问题

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 纯问题文段抓问题 |
| 适用题型 | 中心理解题（说理类文段） |
| 触发场景 | 文段只有问题表述，没有任何对策表述 |
| 步骤逻辑 | 1. 判断文段是否为纯问题文段（无对策）；2. 找出问题表述的具体内容；3. 主旨就是这个问题本身，或者可以提一个针对性的对策；4. 对策必须完全针对文中问题，不能延伸（不能提"出台规范""立法"等文中没有的内容）；5. 选项中问题概括必须准确完整 |
| 高频错因 | 看到选项里有"对策"就优先选，但对策是无中生有的问题概括不准确（如改成了"单纯发展第三产业"而非"工业发展不到位"）给对策添加文中没有的措施（出台规范、树立法规等） |
| confidence | high |

## 不适用条件

1. 文段末尾或关键位置有"因此/所以/应该"等引出隐含对策，实质不是纯问题文段——应转用对策优先判断。
2. 文段是因果分析结构（原因→结果），主旨是原因分析而非问题概括——问题概括法不适用。
3. 选项中对策有明确文段支撑且针对性强，而问题概括选项明显片面或不准确——参见"问题对策无优先级"。

## 反向触发

1. 扫描到文段有"必须/需要/只有才"等对策信号词，说明不是纯问题文段，应切换到对策抓取逻辑。
2. 文段末尾有递进或建议性表述（如"更重要的是""关键在于"），可能已隐含主旨对策方向。
3. 问题概括选项的表述与文段核心问题存在偷换主语或扩大/缩小范围，不能因为是"问题"就直接选。
