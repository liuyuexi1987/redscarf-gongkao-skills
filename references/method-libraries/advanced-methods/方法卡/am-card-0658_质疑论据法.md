# 方法卡：质疑论据法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 质疑论据法 |
| 适用题型 | 逻辑判断——一般质疑（论据是个人观点） |
| 触发场景 | 题干的论据是"有人认为""我认为"等个人观点，而非研究发现或既成事实 |
| 步骤逻辑 | ① 识别：论据是个人观点（如"有人认为""我认为""他们认为"）；② 质疑：指出这个观点的前提不成立；③ 例如：论据说"不戴头盔不影响他人"→质疑"不戴头盔其实影响了他人（保费上涨）" |
| 高频错因 | 没有顺着论据的逻辑质疑，而是引入无关因素；质疑的是结论而非论据 |
| confidence | medium |
| 不适用条件 | - 题干论据是研究数据、实验结果或既成事实，而非个人观点，应质疑推理过程而非论据\n- 题干论证的漏洞在推理过程（以偏概全、片面性等），而非论据本身\n- 选项是 |
| 反向触发 | - 论据不是个人观点，而是客观数据或研究→应质疑推理过程，用以偏概全识别法或增加反向论据法\n- 需要质疑的是因果关系→用归因论证质疑法\n- 选项的质疑方向是引入新因素而非反驳论据前提→用增加反向论据法或造句法 |

## 补充说明

质疑论据的关键：顺着论据的逻辑说。例如论据说"我不戴头盔不影响他人"，你要质疑就得说"你不戴头盔其实影响了他人（让保费上涨）"，而不是说"戴头盔能减少伤亡"（这是无关项）。质疑论据的题比较少（约5%），大部分题是质疑推理过程（约90%）。
