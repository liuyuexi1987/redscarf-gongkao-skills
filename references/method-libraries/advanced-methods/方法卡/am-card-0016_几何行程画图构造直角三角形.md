# 方法卡：几何行程画图构造直角三角形
## 基本信息
| 字段 | 值 |
|------|-----|
| 方法名 | 几何行程画图构造直角三角形 |
| 适用题型 | 数量关系-几何行程（划船绕岛、正北正南方向类） |
| 触发场景 | 题干出现"正北""正南""绕岛""相切"等方向描述 |
| 步骤逻辑 | 1.画图标注各主体位置（岛、湖、出发点、目标点） 2.找相切点→连接半径→构造直角三角形 3.利用勾股数/特殊角计算直角边 4.总路程=弧长+直角边长 |
| 高频错因 | 搞混"岛"和"湖"的主体；不画图直接算 |
| confidence | high |

## 不适用条件

1. 题目无方向描述（无正北/正南/垂直等），运动轨迹不构成直角三角形
2. 纯匀速直线运动求时间/距离，直接用路程=速度×时间即可
3. 题目涉及多段折线且无相切/垂直关系，无法构造直角三角形

## 反向触发

1. 题干描述的是追及/相遇问题，不涉及几何图形构造
2. 选项中无角度或勾股数相关数值，距离可通过简单加减得到
3. 题目为三维空间运动（如上下坡+转弯），无法用平面直角三角形建模

## 补充说明
示例提示：几何行程默认简单题、必做题型。会画图+知道常见勾股数(3-4-5, 1-√3-2, 7-24-25, 5-12-13, 8-15-17)就能做。以绕岛划船为例：绕岛弧长=60×2π×(120/360)=40π≈126，直角边=60√3≈104，合计≈230，÷60换算分钟得3分49秒。
