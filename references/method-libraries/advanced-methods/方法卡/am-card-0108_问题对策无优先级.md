# 方法卡：问题对策无优先级

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 问题对策无优先级 |
| 适用题型 | 中心理解题（纯问题文段的选项比较） |
| 触发场景 | 文段为纯问题文段，选项中同时出现"问题概括"和"对策"表述 |
| 步骤逻辑 | 1. 纯问题文段中，问题和对策本身没有优先级，都可以选；2. 关键在于：问题概括的准不准、全不全；3. 关键在于：对策有没有针对性，是不是无中生有；4. 如果对策完全没有文中支撑，即使形式上是对策也不能选；5. 如果问题概括准确且完整，可以优先选问题 |
| 高频错因 | 机械地认为"有对策必选对策"，忽略对策是否无中生有选了一个无中生有的对策选项（如文中没提"出台规范"却选了它）不对比问题概括的准确性和对策的针对性 |
| confidence | high |

## 不适用条件

1. 文段有明确的对策表述（祈使句/必要条件/关键词），不再是纯问题文段——有对策时参见"有对策选对策速判"。
2. 问题概括选项明显偷换主语或严重不准确，即使对策选项支撑不强也不能选问题——以准确性为准。
3. 文段属于转折结构，转折后提出新问题但选项中只有针对转折前的对策——结构判断优先于此方法。

## 反向触发

1. 对策选项的动宾搭配在文段中有明确对应，且问题概括选项存在遗漏或歪曲——应选对策。
2. 文段有隐含的对策信号（如"关键在于""核心是"），实质是隐含对策文段——不是纯问题文段。
3. 两个选项都是对策表述，一个有文中支撑一个无中生有——此时是对策选项的比对，不涉及问题vs对策的取舍。
