# 方法卡：选项时态匹配法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 选项时态匹配法 |
| 适用题型 | 言语理解——中心理解（选项分析） |
| 触发场景 | 选项表达的时态/状态与原文不匹配 |
| 步骤逻辑 | ① 注意原文的时间状态：已发生/正在发生/未发生/大势所趋；② 选项的时态必须与原文匹配；③ 例：原文"大势所趋"=未发生→选项说"共同构建"=已发生→不匹配→排除；④ 例：原文"正在探索"→选项说"已经实现"→不匹配 |
| 高频错因 | ① 不注意时态差异→选了时态不匹配的选项；② "大势所趋"看似肯定但其实是"趋势"=未完成 |
| confidence | high |
| 不适用条件 | 所有选项时态一致，无法通过时态差异排除；文段本身没有明确的时间状态标记；时态已匹配但区分点在语义、搭配或逻辑层面 |
| 反向触发 | 所有选项时态一致无法通过时态排除时，应转向语义、搭配或逻辑层面比较；文段本身没有明确时间标记且选项时态均为一般性陈述时，时态匹配法不产生区分力 |

## 补充说明
时态匹配是容易被忽略的细节。"大势所趋"="是趋势"=还没完全实现→选项用"共同构建"（暗示已在做）就不匹配。类似的："亟需"="迫切需要"=还没做→选项用"正在推进"就不匹配。
