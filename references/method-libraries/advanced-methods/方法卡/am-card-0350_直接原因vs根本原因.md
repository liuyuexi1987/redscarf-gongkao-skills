# 方法卡：直接原因vs根本原因

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 直接原因vs根本原因 |
| 适用题型 | 判断推理——削弱加强类（双方观点对立归因） |
| 触发场景 | 题干存在原观点（A导致C）和反对者（B导致C），问支持/质疑某一方 |
| 步骤逻辑 | ① 画出两条因果链：原观点 A→C，反对者 B→C；② 支持谁→让谁当根本原因（排在前面）：支持原观点选"A→B→C"，支持反对者选"B→A→C"；③ 质疑谁→让谁当表面原因（排在后面）：质疑反对者选"A→B→C"（B只是表面原因，A才是根本）；④ 直接看选项中谁"导致"谁即可匹配 |
| 高频错因 | 把"支持谁让谁是根本"和"质疑谁让谁是表面"搞反；题目让支持反对者时，习惯性只看原观点方向 |
| confidence | high |

## 补充说明

典型场景：原观点主张"A导致C"，反对者主张"B导致C"，题目要求质疑反对者。处理方式：让原观点的A成为根本原因，B成为中间环节，即选"A先导致B，再由B导致C"的因果排序。此为套路题型，考场可快速判断——质疑谁就让谁的原因排在后面（表面原因）。

## 不适用条件

- 题干只有一方观点，不存在对立归因场景
- 题目问的是"前提假设"而非"支持/质疑某一方观点"
- 原观点和反对者的结论C不同（不是对同一结果的归因分歧）

## 反向触发

- 当选项描述的是并列关系而非因果先后关系时，不能用因果链排序，应换用"排除他因"或"另有他因"的削弱方向
- 当题干出现三方及以上观点时，两两因果排序可能失效，应先判断各方观点的逻辑结构再选择方法
