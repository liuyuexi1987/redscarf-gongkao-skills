# 方法卡：综合分析题排除策略

## 基本信息
| 字段 | 值 |
|------|-----|
| 方法名 | 综合分析题排除策略 |
| 适用题型 | 资料分析-综合分析题（每篇最后一道4选1的判断题） |
| 触发场景 | 综合分析题需要判断ABCD四个选项的正误 |
| 步骤逻辑 | 1. 先看前面题目已选的选项，从未选过的选项开始验证<br>2. 优先挑最容易判断的选项先验（如数据直接可比、大小关系明显）<br>3. 先排除明显错的（如大小关系反了、量级不对），缩小范围<br>4. 需精算验证的选项放最后<br>5. 注意"其中""省vs省市""上半年末"等读题陷阱 |
| 高频错因 | 按ABCD顺序逐个验证浪费时间；读题不仔细（如全国vs省市、省vs省市）；没注意隐含数据需要反推 |
| confidence | high |

## 补充说明
- 从"整体观"出发：出题人不会让四个选项都需要大量计算，必然有容易判断的突破口。
- 常见突破口：大小关系（分子大分母小则比值大）、量级明显不符、增量远超/远不及预期。
- "其中"类陷阱：题目描述"其中XX"可能指的是整体中的某部分，不要用总体数据直接算。
- 隐藏数据识别：如图表只列出两种分类但总和不等于总量，说明有被隐藏的"其他"类别。
- 年份陷阱："上半年末"=6月，"上年上半年末"=上年6月，不要算错基准。

## 不适用条件
1. 当四个选项都需要大量计算且无明显突破口时，按策略排序收益不大，可能需要全部精算。
2. 当题目要求判断"一定正确"或"一定错误"的选项时，排除法需要对每个选项都做充分验证。
3. 当选项涉及跨年、跨地区混合比较时，读题陷阱多，策略排序容易遗漏。

## 反向触发
1. 当已验证两个选项后得到确定答案，不必继续验证剩余选项。
2. 当某个选项涉及"无法从材料中判断"类表述，优先验证其他定量选项以缩小范围。
3. 当选项中有一个明显最容易判断的，直接从该选项开始验证，不必按默认顺序。
