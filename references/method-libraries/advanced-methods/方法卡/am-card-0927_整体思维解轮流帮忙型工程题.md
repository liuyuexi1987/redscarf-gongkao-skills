# 方法卡：整体思维解轮流帮忙型工程题

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 整体思维解轮流帮忙型工程题 |
| 适用题型 | 工程问题·同时开始同时结束 |
| 触发场景 | 多人同时开工同时完工，其中一人在不同组之间来回帮忙 |
| 步骤逻辑 | 1. "同时开始同时结束" → 三个人一直在干活，总效率不变；2. 总时间 = 总工程量 ÷ 总效率；3. 知道总时间后，算出某人的总工作量（效率×总时间）；4. 用减法得到帮忙对象的工作量 → 再÷帮忙者的效率 = 帮忙时间；5. 例：总效率30，总工程量24 → 0.8小时完工 → 甲做了12×0.8=9.6 → 丙做了12-9.6=2.4 → 丙帮甲2.4÷8=0.3小时 |
| 高频错因 | 从帮忙者的角度去想导致混乱，应从整体角度出发 |
| confidence | high |

## 补充说明

关键是"同时开始同时结束"意味着所有人一直在工作

## 不适用条件

- 帮忙者并非全程在岗（中途有停工/休息）的场景。
- 各人工作效率不一致且随时间变化的问题。
- 帮忙对象不唯一（一人帮多人）导致总效率难以恒定的情况。

## 反向触发

- 帮忙时间被题目直接给出且帮忙者有独立空闲段时，改用分段工作量法分别核算。
- 工程量无法合并为单一总工程量时（如多任务并行），应分项目独立列方程。
- 帮忙行为改变其他人效率（如协同增效）时，需引入协同系数另行建模。
