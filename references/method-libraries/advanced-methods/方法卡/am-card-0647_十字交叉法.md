# 方法卡：十字交叉法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 十字交叉法 |
| 适用题型 | 资料分析——盐水类问题（已知三个浓度/增长率求量之比） |
| 触发场景 | 材料给出两部分的浓度/增长率和整体的浓度/增长率，求两部分的量之比 |
| 步骤逻辑 | ① 确认A=B/C形式，且是整体与两部分的关系；② 把三个浓度写成十字交叉形式（左A、右B、中间R）；③ 斜着做减法：|R-B|和|A-R|④ 量之比 = |R-B| : |A-R| |
| 高频错因 | 量之比与距离搞反（量大距离短）；忘记是基期量之比 |
| confidence | medium |
| 不适用条件 | 只知两部分不知整体浓度/增长率时；题目求具体数值而非量之比时；两部分不构成简单加和关系（如乘积型而非求和型混合） |
| 反向触发 | 题目给出两部分的浓度/增长率和整体浓度/增长率，问 |

## 补充说明

十字交叉法本质是解方程的快捷形式。混合浓度一定在两部分浓度之间，靠近量大的一边。量之比和距离成反比（类似天平原理）。增长率问题中，量之比是基期量之比（因为R=X/A，分母是基期）。
