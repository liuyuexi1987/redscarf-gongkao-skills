# 方法卡：同义替换意识

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 同义替换意识 |
| 适用题型 | 言语理解——中心理解（选项分析） |
| 触发场景 | 选项用词与原文不同但意思一致 |
| 步骤逻辑 | ① 选项用词与原文不同时，先比对主体、对象、动作、范围和感情方向；② 这些核心要素一致、只是换了说法时，才可视为同义替换；③ 若出现范围扩大缩小、因果倒置、主客体变化或程度升降，不能当作同义；④ 不因字面不同直接排除，也不因话题相近就认定等价 |
| 高频错因 | ① 选项词与原文不同就排除→排除了正确答案；② 不理解同义替换→选了字面匹配但逻辑错误的选项 |
| confidence | high |

## 补充说明
同义替换是“表达变了，核心命题没变”。判断时应回到文段语境和逻辑关系，不把概念相关或话题接近误当成同义。

## 不适用条件
- 选项差异在程度/范围而非同义替换时，应换用程度词或范围词核验。
- 文段涉及专有名词、法条术语等不可替换表述时，同义替换意识不适用。
- 选项与原文存在因果倒置或主客体颠倒时，需逻辑核验而非同义判断。

## 反向触发
- 当选项字面差异较大但语义相近时，应补充回到原文语境验证，避免过度同义化。
- 当选项含绝对化表述（"全部""唯一""必然"）时，应换用绝对词核验法。
- 当选项与原文存在概念扩大/缩小嫌疑时，应补充范围边界核验，确认替换可接受性。
