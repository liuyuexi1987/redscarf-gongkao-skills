# 方法卡：乘积增长率

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 乘积增长率 |
| 适用题型 | 资料分析——求乘积关系量的增长率（如总产量=面积×单产，收入=单价×销量，部分=整体×占比） |
| 触发场景 | 题目要求的增长率对应一个量，材料中找不到该量，但能表达为两个已知量的乘积 A=B×C |
| 步骤逻辑 | ① 确认目标量可写成 A=B×C；② 找到 B、C 的增长率 R1、R2；③ 用精确关系 `(1+R)=(1+R1)(1+R2)`，即 `R=R1+R2+R1×R2`；④ 只有在乘积项的绝对值小于选项允许误差时，才可先忽略乘积项定位 |
| 验证动作 | 将结果代回 `(1+R1)(1+R2)`；若省略乘积项，检查省略量是否可能跨越相邻选项边界 |
| 不适用条件 | 目标量不是两个量的乘积；增长率口径或时期不一致；乘积项足以影响选项判断 |
| 高频错因 | R1×R2的符号搞错；未经误差判断就省略乘积项；和比值增长率公式混淆 |
| confidence | medium |
| 反向触发 | 目标量可以直接从材料中读取或简单加减得出；题目考查的是基期量而非增长率；题目给出了目标量的现期值和增长率，无需通过乘积关系推导 |
