# 方法卡：归纳推断错因诊断卡

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 归纳推断错因诊断卡 |
| 适用题型 | 过度推出、范围扩大、程度强化、比较无中生有、因果强加 |
| 触发场景 | 用户做错该类题后，讲解/复盘结束，需要判断错因并写入错因卡或弱点档案时 |
| 步骤逻辑 | ① 先查材料范围限定（主体、时间、地域、条件）；② 再查选项是否超出材料能推出的程度；③ 再查是否有无中生有的比较或因果；④ 最后归因写入弱点档案 |
| 高频错因 | 范围扩大（部分→全部）、程度强化（可能→必然）、比较无中生有、因果强加、绝对化表述误选、关联性当因果 |
| confidence | high |
| 不适用条件 | 1. 资料分析模块中的推断题不在本卡诊断范围
| 反向触发 | 1. 用户做对归纳推断题后自行复核答案且无需诊断错因
2. 同一归纳推断题型连续答对多次无需诊断
3. 题目属于需要结合外部知识的推断题超出本卡范围 |
2. 题目只涉及简单材料理解不涉及过度推理时不做诊断
3. 纯计算题（如求增长率、比重）不归本卡 |

## 诊断流程

### 第一步：查材料范围限定

- 材料说的是"部分""某些""某类人"还是"所有""全部""每个人"？
- 材料限定的时间（过去/现在/将来）、地域（某地区/全国/全球）、条件（在某情况下）是否被选项突破？
- 选项是否把材料中的"成年人"泛化成了"所有人"？把"某省"泛化成了"全国"？

### 第二步：查推出程度

- 材料说"可能""也许""往往"，选项是否变成了"一定""必然""总是"？
- 材料说"存在关联性""有相关性"，选项是否变成了"因果关系"？
- 材料说"有助于""可能改善"，选项是否变成了"解决""根治"？
- 从"部分"推出"全部"、从"可能"推出"必然"——都是过度推出。

### 第三步：查比较与因果

- 材料没有做比较，选项是否凭空加了比较？（如材料说 A 好，选项说 A 比 B 好）
- 材料说 A 和 B 同时存在（关联性），选项是否说 A 导致 B（因果）？
- 材料说 A 发生在 B 之前（时间先后），选项是否说 A 导致 B（因果）？
- 因果强加：把先后关系、关联关系当成了因果关系。

### 第四步：查绝对化与归因

- 选项中是否有"所有""一定""不可避免""绝对"等绝对化表述？材料是否支持这种绝对程度？
- 以偏概全：个别案例能否推出普遍结论？
- 归因到具体层：是范围扩大、程度强化、比较无中生有还是因果强加？

## 错因分类表

| 错因类型 | 判定信号 | 典型表现 | 写入弱点档案的建议标签 |
|----------|----------|----------|------------------------|
| 范围扩大 | 选项主体范围超过材料 | 从"部分人"推出"所有人"，从"某省"推出"全国" | 判断-归纳推断-范围扩大 |
| 程度强化 | 选项程度超过材料 | 从"可能"推出"必然"，从"有助于"推出"解决" | 判断-归纳推断-程度强化 |
| 比较无中生有 | 材料没有比较，选项加了比较 | 材料说A好，选项说A比B好 | 判断-归纳推断-比较无中生有 |
| 因果强加 | 把关联/先后关系当成因果 | 材料说A和B相关，选项说A导致B | 判断-归纳推断-因果强加 |
| 绝对化表述误选 | 选项含绝对化词汇但材料不支持 | "所有""一定""不可避免"超出材料程度 | 判断-归纳推断-绝对化误选 |
| 以偏概全 | 从个别案例推出普遍结论 | 一个例子不能证明普遍规律 | 判断-归纳推断-以偏概全 |
| 时间范围突破 | 材料限定过去，选项推出将来 | 过去的趋势不一定延续到将来 | 判断-归纳推断-时间范围突破 |
| 主体范围突破 | 材料限定某类，选项推出所有 | 成年人的数据不能推出所有人 | 判断-归纳推断-主体范围突破 |

## 写回建议

- `判断-归纳推断-范围扩大`：材料说"部分人"，选项说"所有人"，从部分推出全是过度推出
- `判断-归纳推断-程度强化`：材料说"可能存在关联"，选项说"必然导致"，程度从可能升到必然
- `判断-归纳推断-因果强加`：材料说A和B同时存在（关联性），选项说A导致B（因果），关联≠因果
- `判断-归纳推断-比较无中生有`：材料只说了A的情况，选项凭空加了B做比较，属于无中生有

## 使用边界

1. 本卡只用于错因诊断，不替代具体解题方法卡（如 am-card-0443 以偏概全漏洞识别、am-card-0577 绝对化表述反例质疑）。
2. 无官方/已核验答案的归纳推断题，不得硬判错因，只能写方法倾向或待核对。
3. 用户给出思路时优先对照用户思路归因；没给思路时只能做低置信诊断。
4. 客观题官方答案冲突时先走冲突复核流程，不立即写错因卡。
