# 方法卡：余数问题三句话

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 余数问题三句话 |
| 适用题型 | 数量关系——余数问题、同余约束 |
| 触发场景 | 一个数除以多个数分别得到余数，需要识别余同、和同或差同关系 |
| confidence | medium |
| 不适用条件 | - 余数条件不满足"余同/和同/差同"任一模式时，三句话口诀不适用，需改用枚举法或中国剩余定理标准解法。- 只有一个除法关系的简单余数问题（如"某数除以7余3，求最小值"），不需要三句话框架，直接列式即可。 |
| 反向触发 | - 题目只涉及单一整除判定（如"能被3整除的数"），不涉及多条件余数筛选，应触发整除特性判定法。- 题目本质是最小公倍数/公约数计算而非余数约束，应触发辗转相除法或质因数分解。 |
| 步骤逻辑 | 余数问题用三句话解决：余同加余、和同加和、差同减差。；1. **余同加余**：如果除以不同数余数相同→答案 = 最小公倍数 + 余数；2. **和同加和**：如果除数与余数之和相同→答案 = 最小公倍数 + 和；3. **差同减差**：如果除数与余数之差相同→答案 = 最小公倍数 - 差 |
| 高频错因 |  |

- 记住"两个加一个减"的口诀
