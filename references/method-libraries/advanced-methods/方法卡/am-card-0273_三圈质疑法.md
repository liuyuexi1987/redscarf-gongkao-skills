# 方法卡：三圈质疑法（同因异果/异因同果）

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 三圈质疑法（同因异果/异因同果） |
| 适用题型 | 归因类质疑题 |
| 触发场景 | 题干给出对比实验或数据归因，需要质疑因果结论时 |
| 步骤逻辑 | 1. 识别题干归因结构：原因A → 结果B；2. 画三圈（原因相同但结果不同）可质疑：同因异果说明该原因非真正原因；3. 画三圈（原因不同但结果相同）也可质疑：异因同果说明该原因非真正原因；4. 画四圈（原因不同结果不同）则支持归因成立；5. 注意：另有他因（他因+否定词因）也是常见质疑方式 |
| 高频错因 | 误以为同因异果只有结果不同的情况，忽略异因同果也可质疑 |
| 不适用条件 | 题干无对比实验或归因结构（如纯枚举或统计数据描述）；需要质疑的是数据本身而非因果关系 |
| 反向触发 | 题目问的是"以下哪项最能支持上述结论"且选项均为补充论据，而非质疑归因逻辑 |
| confidence | high |
