# 方法卡：前提假设三类答案

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 前提假设三类答案 |
| 适用题型 | 前提假设类（问"以下哪项是上述论证的前提/假设"） |
| 触发场景 | 题干问"前提""假设""隐含的条件"时 |
| 步骤逻辑 | 1. 识别题型为前提假设类；2. 第一反应判断是否属于断点搭桥（占比约80%）；3. 若论据与结论存在话题跳跃，则选搭桥选项；4. 若涉及条件变化（如原来A现在B），则考虑补充漏洞（约10%）；5. 若选项讨论"能与不能"，则考虑必要条件（约10%） |
| 高频错因 | 不区分三类，盲目排除；看到"能与不能"选项却忽视 |
| 不适用条件 | 题目问"以下哪项最能削弱/加强"而非"前提/假设"时；论据与结论之间无话题跳跃且无条件变化 |
| 反向触发 | 题目明确要求选削弱或加强选项，而非找隐含前提 |
| confidence | high |
