# 方法卡：A推B真值表与命题真假判断

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | A推B真值表与命题真假判断 |
| 适用题型 | 判断推理——翻译推理/真假判断（含"若…则…""A→B"结构） |
| 触发场景 | 已知A→B为真（或"或"关系为真），需判断具体事实的真假；或需判断命题A→B何时为真/为假 |
| 步骤逻辑 | ① A→B为假仅一种情况：A且非B（前真后假）；② A→B为真有三种情况：A真B真、A假B真、A假B假——即只要不是A且非B就算为真；③ 命题为真不等于A或B实际发生了——前件为假时命题已为真，后件真假不确定；④ 辅助理解：A→B等价于非A或B（否一推一），用"或关系一真则真"来判断 |
| 高频错因 | 误以为"A→B为真"就代表A和B都发生了；误以为前件为假时能推出后件为假——实际后件不确定 |
| 不适用条件 | 题干不涉及条件命题（"若…则…"结构）或选言命题的真假判断；纯事实推理题 |
| 反向触发 | 题目要求判断A→B何时为假（答案为A且非B）；题目给出A→B为真且A为真，要求推B |
| confidence | high |

## 补充说明

辅助记忆："考双百就带你出去玩"——她没考双百（前件为假），我带不带她玩都不算骗人，命题仍为真。只有她考了双百我没带（前真后假），命题才为假。记忆口诀：前假必真，后真必真，唯前真后假才假。
