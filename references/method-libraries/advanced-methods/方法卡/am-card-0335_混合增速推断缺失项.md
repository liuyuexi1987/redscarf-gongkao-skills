# 方法卡：混合增速推断缺失项

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 混合增速推断缺失项 |
| 适用题型 | 资料分析 - 整体与部分增速关系 |
| 触发场景 | 整体增速已知，部分项增速已知但有1项缺失，需要判断该项增速大小或进行增量比较 |
| 步骤逻辑 | 1. 整体增速在已知各部分增速之间（盐水混合原理）；2. 已知部分混合后的增速 < 最高已知增速（因低增速项拉低）；3. 整体增速 - 已知部分混合增速 → 缺失项的增速方向；4. 若整体 > 已知部分混合 → 缺失项增速 > 整体增速；5. 结合增量比大小规则：B大R大则X大，判断缺失项增量大小 |
| 高频错因 | ①误以为整体增速等于各部分平均 ②忽略"混合"方向 ③遗漏某项的基数大小比较 |
| confidence | high |

## 不适用条件

- 所有部分增速均已知，无需推断缺失项
- 缺失项的基数极小，对整体增速的影响可忽略
- 题目要求精确计算缺失项的增速值而非判断方向

## 反向触发

- 当已知部分混合后的增速与整体增速几乎相等时，说明缺失项基数极小，继续推断方向意义不大，应换用直接计算
- 当整体增速不在已知各部分增速之间时，应检查数据或理解是否有误，而非强行套用盐水混合原理
- 当题目涉及多层级嵌套（如"某部分内部又分子项"）时，单层混合增速方法不适用，应分层计算
