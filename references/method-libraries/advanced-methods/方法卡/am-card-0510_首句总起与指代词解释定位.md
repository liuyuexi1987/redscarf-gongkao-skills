# 方法卡：首句总起与指代词解释定位

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 首句总起与指代词解释定位 |
| 适用题型 | 语句填空题/主旨题 |
| 触发场景 | 首句是概括性表述，后文出现指代词（他们/其/此）对前文模糊概念做具体解释 |
| 步骤逻辑 | 1)首句一般起总起概括作用，需能体现后文核心观点 2)后文指代词（如"他们"）指代前文内容并做具体解释 3)首句选项需呼应后文解释的具体内容，不能停留在模糊表述 4)如果后文解释了"内心需求"具体指科学，首句也应体现科学 |
| 高频错因 | 只看到首句的表面意思（如"关注内心需求"），没看后文指代词对它的具体解释（科学） |
| confidence | medium |

## 不适用条件

1. 首句不是总起句而是引出背景或问题时，指代词可能指代后文而非前文，需调整判断方向
2. 后文没有指代词而是直接展开论述时，不能套用"指代词解释定位"思路

## 反向触发

1. 首句选项有两个都能与后文指代词对应时，需比较哪个更精确地匹配后文具体解释内容
2. 后文指代词指代的对象在首句之前的上文中时，不能仅盯首句，需扩大阅读范围
