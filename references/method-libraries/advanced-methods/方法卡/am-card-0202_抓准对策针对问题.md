# 方法卡：抓准对策针对问题

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 抓准对策针对问题 |
| 适用题型 | 中心理解 |
| 触发场景 | 文段有两个或以上对策并列 |
| 步骤逻辑 | 1. 定位文段中明确提出的问题；2. 分析哪个对策直接针对该问题；3. 直接针对问题的对策是核心对策，另一个可能是"一直在做的"或"顺带一说"；4. 选核心对策，即使看起来"片面" |
| 高频错因 | 把所有对策等同看待，觉得选只含一个对策的选项是"片面" |
| confidence | high |

## 不适用条件

1. 文段只有一个对策，不存在多对策并列的情况
2. 文段未明确提出问题，对策之间是并列补充而非主次关系
3. 所有对策均直接针对同一问题，无法区分核心与非核心

## 反向触发

1. 看到两个以上对策并列时，先定位文段明确写出了什么问题，再判断哪个对策直击该问题
2. 选项只含一个对策且看起来"片面"时，不要因此排除——可能是核心对策
3. 若某对策是"一直在做的""顺带提及"而非针对核心问题，其优先级低于直接针对问题的对策
