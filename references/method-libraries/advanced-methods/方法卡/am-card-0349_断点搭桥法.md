# 方法卡：断点搭桥法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 断点搭桥法 |
| 适用题型 | 判断推理——加强类（前提假设/搭桥） |
| 触发场景 | 题干从A越来越少推到C越来越少，但A和C之间缺少逻辑连接；选项需要补上A→C的桥梁 |
| 步骤逻辑 | ① 提取前提A和结论C的关键词；② 发现A和C之间存在断点（如"自由流动河流减少"→"河流利益减少"，断点是"自由流动"与"利益"的关系）；③ 正确选项必须建立A与C的联系——"自由流动的河流能带来多种利益"；④ 无关选项（只介绍背景、没有自己观点）直接排除 |
| 高频错因 | 被背景介绍类选项迷惑（如A说"首次评估"、B说"大坝数量"，均无观点，不能搭桥）；忽视断点，选了与结论话题不完全对应的选项 |
| confidence | high |

## 补充说明

典型搭桥题场景：前提描述"某类事物减少"，结论推导"某利益减少"，但两者之间缺少逻辑连接。断点在于前提关键词与结论关键词的关系。正确选项需直接建立该联系。类比理解："金钱少了所以欢乐少了"——需要搭桥"金钱带来欢乐"。

## 不适用条件

- 题干前提与结论之间已有明确因果链条，无需额外补桥
- 题目要求削弱而非加强，应使用切断联系的思路而非搭桥
- 前提与结论关键词完全一致，断点不存在

## 反向触发

- 当选项中出现建立新因果联系但方向与结论相反时，不应继续套搭桥思路，应转为判断该选项是否构成削弱
- 当多个选项都能部分连接A与C但无法区分时，应补充做"必要性检验"：假设该选项不成立，结论是否必然不成立
