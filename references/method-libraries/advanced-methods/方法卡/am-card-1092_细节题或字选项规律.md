# 方法卡：细节题或字选项规律

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 细节题或字选项规律 |
| 适用题型 | 言语理解——细节判断题 |
| 触发场景 | 细节判断题中两个或多个选项均看似合理、需要依据表述倾向做排除时 |
| 步骤逻辑 | ① “或”只表示可能性，先回原文核对范围；② 对比项重点核对比较对象与依据；③ “一定/必须/所有”等绝对化表述重点核对是否获得原文支持；④ 因果项核对原文是否真正建立因果。以上均是优先核对线索，不是答案规律 |
| 高频错因 | ① 不注意限定语被偷换；② 对比类选项容易被选但实际错 |
| confidence | medium |

## 不适用条件

- 主旨概括题、意图判断题等非细节题型不适用本法，这些题型需要理解文段整体逻辑而非逐选项排查
- 当选项中有明确的原文对应可验证时，应优先用原文比对而非依赖表述倾向规律
- 本法是统计倾向而非确定性规则，不能作为唯一判据，需结合文段内容验证

## 反向触发

- 若所有选项都含"或"字或都含绝对化表述，本法的区分度失效，需回归文段逐项比对
- 无论题目要求选正确项还是错误项，都应先确认问法，再逐项回原文验证，不能把表述倾向直接当答案
