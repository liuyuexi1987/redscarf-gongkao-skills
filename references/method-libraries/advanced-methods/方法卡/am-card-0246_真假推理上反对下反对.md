# 方法卡：真假推理——上反对与韦恩图法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 真假推理——上反对与韦恩图法 |
| 适用题型 | 判断推理——真假分析（涉及"所有""有些"等量词命题） |
| 触发场景 | 题目给出多句话，告知其中一句为真/为假，涉及"所有A都是B"与"有些A不是B"等对当关系 |
| 步骤逻辑 | ① 找上反对关系："所有A都是B"和"所有A都不是B"必有一假；找下反对关系："有些A是B"和"有些A不是B"必有一真；② 另一种方法是假设法：假设某句话为真，看是否导致矛盾；③ 个例能推出"有些"（牛牛不是河南人→有些同学不是河南人），但"有些"推不出个例 |
| 高频错因 | 忘记上反对"必有一假"、下反对"必有一真"的基本关系；假设法推出矛盾后未及时切换 |
| confidence | high |
| 不适用条件 | 题目不涉及"所有/有些"等量词命题的真假判断（如纯选言/联言推理、朴素逻辑排列题） |
| 反向触发 | 真假条件涉及联言、选言或假言命题而非量词命题时，应转用对应推理规则、真值表或矛盾分析，不能套用对当关系；题目只给真假数量且不存在明确对当关系时，可改用假设法逐项验证。 |
