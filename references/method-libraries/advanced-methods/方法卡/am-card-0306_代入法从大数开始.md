# 方法卡：代入法从大数开始

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 代入法从大数开始 |
| 适用题型 | 数量关系——最值、整数约束与选项代入题 |
| 触发场景 | 问“最多/最大”，选项有序且把候选值代入约束后能立即判断是否可行 |
| 步骤逻辑 | 1. 问题问"最多/最大"时，从最大选项（CD）开始代入；2. 将选项值代入约束条件（如总页数公式），验证是否满足；3. 满足则直接选；不满足则退而求其次代入较小选项；4. 若选项值拆分为相邻数乘积（如210=14×15）能验证，说明该值合理 |
| 高频错因 | 从小数开始代入，浪费时间不利用"求最大"的题意方向来优化代入顺序 |
| confidence | medium |
| 不适用条件 | 题目问"最少/最小"但选项排序不明确，或约束条件无法通过单次代入判断是否满足时 |
| 反向触发 | 约束条件涉及多个变量耦合，代入一个值后无法独立判断是否满足；或题目求的是精确值而非最大/最小排序 |

## 补充说明

代入法配合"拆分为相邻数乘积"的验证技巧效果更好。例如验证某值是否合理，看它能否写成 n(n+1) 的形式。能拆开说明对应的X是整数，合理；拆不开则排除。
