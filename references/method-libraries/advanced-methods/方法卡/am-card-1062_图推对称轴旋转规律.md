# 方法卡：图推对称轴旋转规律

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 图推对称轴旋转规律 |
| 适用题型 | 判断推理——图形推理（对称） |
| 触发场景 | 图形推理中出现对称图形，且对称轴方向在变化 |
| 步骤逻辑 | ① 先判断是否对称（轴对称/中心对称）；② 标记每个图的对称轴方向；③ 常见旋转规律：竖→斜→横→斜→竖（45°递增）；④ 也可能是90°旋转：竖→横→竖→横 |
| 高频错因 | ① 只看对称不看对称轴方向→漏掉规律；② 对称轴角度判断不准→选错 |
| confidence | high |

## 补充说明
对称轴方向变化是图推高频考点。常见规律：45°递增（竖→斜→横→斜→竖）或90°旋转。观察时注意对称轴是穿过图形中心还是穿过某个元素。

## 不适用条件
- 图形不对称或同时有轴对称和中心对称干扰时
- 对称轴方向不变但对称轴位置在移动时
- 图形考查的是对称轴数量而非方向时

## 反向触发
- 图形无对称性时，不应使用此方法
- 对称轴方向固定不变但有其他变化（如数量增减）时，应换思路
