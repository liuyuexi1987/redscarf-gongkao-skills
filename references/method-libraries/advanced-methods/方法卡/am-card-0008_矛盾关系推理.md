# 方法卡：所有与有些不的矛盾关系

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 所有与有些不的矛盾关系 |
| 适用题型 | 判断推理——真假分析/矛盾推理 |
| 触发场景 | 题目中出现"所有S都是P"与"有些S不是P"的矛盾关系，用于真假判断 |
| 步骤逻辑 | ① 识别矛盾对："所有S都是P"与"有些S不是P"互为矛盾，必一真一假；② 矛盾推理：若已知"所有S都是P"为假，则"有些S不是P"必为真；③ 从假推真：假的命题不能直接用，必须先找其矛盾变为真命题才能继续推导 |
| 高频错因 | 混淆"矛盾"与"反对"关系（"所有都是"与"所有都不是"是反对关系，不是矛盾）；假命题直接往下推而不先找矛盾 |
| confidence | high |

## 补充说明

四种推理形式的分类：① 全是命题（由命题推命题）；② 由命题推事实；③ 由事实推命题；④ 由事实推事实。此方法主要用于第②种。

## 不适用条件

- 当题目涉及反对关系（如"所有都是"与"所有都不是"）而非矛盾关系时，"必一真一假"不成立，不能套用。
- 当需要确定所有命题的真假而非仅判断一对矛盾时，仅靠矛盾关系不够，需结合条件推理。
- 当命题涉及复合条件（如"如果…那么…"的假言命题）时，需用逻辑公式而非简单的全称/特称矛盾。

## 反向触发

- 出现"所有都不是"与"有些是"这对矛盾时，同样适用矛盾推理，注意识别。
- 题目要求确定所有命题的真假时，在矛盾关系基础上补充假设检验或条件推理。
- 当命题涉及假言连锁时，用逻辑链或真值表辅助。
