# 方法卡：倍数消元策略

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 倍数消元策略 |
| 适用题型 | 三元不定方程组（三个未知数两个方程），需消元降维后用奇偶/倍数法求解 |
| 触发场景 | 消元时有多个变量可选消，需要决定消谁使剩余方程最简单 |
| 步骤逻辑 | 1. 两个方程都乘以适当倍数使某个变量系数相同；2. 优先消去系数最大的变量（使乘的倍数最小，结果数最接近原方程）；3. 消元后两个未知数的和越小，后续枚举试算的可能性越少；4. 用奇偶性或倍数法对消元后的二元方程求解 |
| 高频错因 | 消去了系数最小的变量导致剩余方程数值过大、枚举困难；消元后忘记验证被消变量是否为正整数 |
| confidence | medium |

## 补充说明

消元策略的核心原则：优先消去系数最大的变量，使剩余方程的数值尽可能小，从而减少后续枚举试算的可能性（两数之和越小，可行解组合越少）。消元是不定方程组的通用前置步骤，消元后配合倍数法或奇偶法求解。消元后务必验证被消变量是否为正整数且满足题意约束。

## 不适用条件

- 方程组中各变量系数接近（无明显"最大系数"可优先消去）。
- 仅两个未知数一个方程（无需消元，直接用倍数/奇偶/尾数法）。

## 反向触发

- 当消元后剩余方程数值仍然过大、枚举困难时，应重新选择消去变量或换用代入法。
- 当消元过程引入较大倍数导致计算复杂时，需核验是否有更优消元路径。
