# 方法卡：语句衔接逗号看后文

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 语句衔接逗号看后文 |
| 适用题型 | 语句填空题 |
| 触发场景 | 填空后面是逗号（空+逗号+后续句子），而非句号 |
| 步骤逻辑 | 1)空后面是逗号，说明填的内容与后面的句子构成一个完整句子 2)填的内容应与后面句子衔接更紧密（因为逗号相连） 3)找后面句子的核心话题词作为切入点 4)整体句子再与前面句号句子形成衔接关系 |
| 高频错因 | 只看空前面的内容去衔接，忽略了逗号表示与后文是一个整体句子 |
| confidence | medium |

## 不适用条件

1. 填空后面是句号或分号，与后文并非同一句时，不能直接用"逗号看后文"思路
2. 空格处于文段开头，前面无上文可供衔接时，应转为关注后文话题词和整体结构

## 反向触发

1. 空格后面是分号或句号，但前后文有明显转折或因果关系时，改用结构逻辑法判断衔接
2. 多个选项都能与后文话题词匹配时，需回到前文句号句子验证话题一致性
