# 方法卡：流水行船赋值法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 流水行船赋值法 |
| 适用题型 | 数量关系（流水行船） |
| 触发场景 | 船速是水速的整数倍，求涉及顺流/逆流的比例问题 |
| 步骤逻辑 | 1. 直接赋值：设水速为1，船速为对应的倍数；2. 顺流速度=船速+水速，逆流速度=船速-水速；3. 化简速度比→相遇时路程比=速度比；4. 用路程比分配全程，转化为需要的量（如采样份数） |
| 高频错因 | 题目求的是"份"而非具体距离时不敢赋值；搞不清份数和间隔段数的关系（N份=N-1段） |
| confidence | medium |

## 不适用条件

- 船速与水速不是整数倍关系时不适用此赋值法（应换用方程法）。
- 题目要求具体数值（如实际距离、实际时间）而非比例关系时不适用此法。
- 涉及多段变速（船速变化、水速变化、中途停靠）时不适用此法。

## 反向触发

- 当赋值后比例化简结果与选项量纲不一致时，应换用方程法并设实际变量求解。
- 当题目涉及"往返平均速度"等需严格定义的量时，应补充用调和平均公式核验，避免直接用算术平均。
- 当赋值导致份数与间隔段数关系混乱时，应回归"路程=速度×时间"基础方程重新梳理。
