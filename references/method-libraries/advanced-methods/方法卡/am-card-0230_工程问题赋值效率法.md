# 方法卡：工程问题赋值效率法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 工程问题赋值效率法 |
| 适用题型 | 数量关系-工程问题 |
| 触发场景 | 已知各人完成时间，求合作用时或效率变化后的用时 |
| 步骤逻辑 | 1. 设总工程量 = 各时间的最小公倍数（使效率为整数，方便计算）；2. 各人效率 = 总工程量 / 个人用时（均为整数）；3. 分段计算：先一起干→有人休息/变化→效率变化→再合作；4. 各段工作量 = 效率 × 时间，剩余工作量逐段递减；5. 最终用时 = 各段时间之和；6. 与计划用时对比：计划用时 = 总工程量 / (原效率之和) |
| 高频错因 | 忘记有人休息时另一人仍在干活，只算休息时间没算另一人的产出；效率降低后忘记用新效率计算剩余部分 |
| 不适用条件 | 题干仅给出效率比例而无具体时间（不能取最小公倍数赋值）；单人单段完成无分段变化 |
| 反向触发 | 题目只给效率比且没有具体工时，无法按工时最小公倍数赋值总量，应改用效率比例法列方程；题目仅涉及单人、单段且效率不变时，直接使用“工作量=效率×时间”即可，无需额外赋值。 |
| confidence | medium |
