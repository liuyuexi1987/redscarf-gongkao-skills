# 方法卡：同行业比vs同职业比的定位区分

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 同行业比vs同职业比的定位区分 |
| 适用题型 | 资料分析 - 交叉表格（行业×职业）中的比较定位 |
| 触发场景 | 表格有行业行和职业列，题目说"同行业"或"同职业"，需要确定比较对象在表格中的位置 |
| 步骤逻辑 | 1. "同行业"→ 和该行业前面的总计列（行业平均工资）比；2. "同职业"→ 和最上面全省同职业的数值比；3. 例如：采矿业办事人员 vs 同行业 → 比采矿业平均工资；vs 同职业 → 比全省办事人员；4. 关键：看"同"字修饰的是行业还是职业 |
| 高频错因 | 把"同行业"理解为和全省同职业去比；把办事人员和上面的全省办事人员数值比较，而题目要求的是同行业总计 |
| confidence | high |

## 不适用条件

- 表格不是"行业×职业"的交叉结构（如只有一个维度的列表），不存在行/列定位区分问题。
- 题目直接指定比较对象名称（如"与A行业B职业比较"），不需要通过"同行业/同职业"定位。
- 表格中某一行或列数据缺失，无法完成定位比较。

## 反向触发

- 题目未出现"同行业""同职业"等字眼，而是直接给出比较对象或问绝对值。
- 题目要求比较的是同一行/列内的具体数值（如两个行业之间的差值），与行列交叉定位无关。
- 题目问的是某个具体单元格的数值，无需做行/列间的参照比较。
