# 方法卡：不完全相同推理

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 不完全相同推理 |
| 适用题型 | 排列组合/分析推理（判断推理） |
| 触发场景 | 题干要求多个对象的方案"不完全相同"（允许有部分重合，但不允许完全一样），且已有某个对象的方案被完全确定 |
| 步骤逻辑 | 1. 正确理解"不完全相同"：可以有一个要素相同，但不能所有要素都相同（即允许部分重合，禁止完全一致）；2. 找出已有确定方案的对象；3. 假设另一个对象的未定要素与确定方案完全一致，检查是否违反"不完全相同"约束；4. 若违反，则该对象在该要素上必须做出不同选择，从而推出确定信息 |
| 验证动作 | 将推出的确定信息代入原题，检查所有对象的方案是否确实互不完全相同；若有任意两组完全一致则推理有误 |
| 不适用条件 | 当所有对象的方案均未确定时，无法直接使用此法，需先用其他约束确定至少一个对象的方案；"不完全相同"仅约束"不完全一样"，不等于"完全不同"——部分重合是允许的 |
| 高频错因 | 把"不完全相同"理解为"完全不同"（过度限制，排除合法方案）；已有对象方案确定后忘记利用"不完全相同"约束反推其他对象 |
| confidence | high |
| 反向触发 | 利用"不完全相同"约束反推出的限制与另一已知条件矛盾时，说明之前的假设或推理链有误，应回溯检查；"不完全相同"约束与其他强约束（如"完全不同""互斥"）并存时，优先使用约束更强的规则，本法退为辅助验证 |
