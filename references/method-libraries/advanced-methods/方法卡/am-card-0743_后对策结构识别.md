# 方法卡：后对策结构识别

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 后对策结构识别 |
| 适用题型 | 言语理解——片段阅读（主旨/意图题） |
| 触发场景 | 文段先引出话题或提出问题，中间展开分析论证，结尾给出对策 |
| 步骤逻辑 | ① 首句判断为引出话题/提出问题，非对策；② 中间部分为分析论证（娓娓道来、一边介绍一边分析）；③ 结尾处找到对策性表述；④ 对策即为文段重点，选答案围绕对策展开 |
| 高频错因 | 被中间分析论证的具体细节吸引，误选描述问题或分析原因的选项；忽略首句中的关键信息（首句对全文有概括性，辅助判断选项） |
| confidence | medium |

## 补充说明

后对策结构中，首句虽然不是对策，但对全文有概括性作用，用词更全面、更有概括性。当两个选项纠结时，首句的关键信息可以帮助区分。另外，首句里面的关键词非常关键——"真的不知道选哪个了，看首句"。

## 不适用条件

1. 文段重点在首句（前对策或总分结构），而非结尾——需先判断行文结构再决定是否用此方法。
2. 结尾句仅为总结性回顾，没有提出新的对策或行动建议时，不能将尾句等同于对策。
3. 文段为并列结构，无明确的"问题→分析→对策"递进脉络时，此方法不适用。

## 反向触发

1. 首句本身已含对策（"应该/需要/必须"等标志词），应切换到前对策结构判断法。
2. 结尾虽有对策性表述，但文段主体是分析原因而非解决问题，应优先选"原因"类概括选项。
