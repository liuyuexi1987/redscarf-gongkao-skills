# 方法卡：2112分段法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 2112分段法 |
| 适用题型 | 资料分析-减法-多位数相减 |
| 触发场景 | 两个数字相减，希望避免借位、分段口算时 |
| 步骤逻辑 | 1. 观察个位是否够减：够减则从百位和十位之间切开（前两位减前两位，后两位减后两位）2. 个位不够减则从十位和个位之间切开（前三段 vs 后三段）3. 两段各自独立相减，结果直接拼接 4. 若某段不够减，引入负数处理（如80+(-1)=79） |
| 高频错因 | 分段位置选错仍需借位；不够减时忘记用负数处理 |
| confidence | medium |

## 不适用条件

1. 数据位数过少（如两位数减两位数）时，直接口算比分段更快，无需套用此法
2. 选项差异极大、估算即可区分时，不必精确分段计算
3. 当估算误差可能跨越选项或改变结论时，改用精算/验证

## 反向触发

1. 看到多位数减法需要借位时，提醒自己考虑分段而非硬借位
2. 自己在某一段算出负数时，不要卡住或重新借位，直接合并即可
3. 连续多道减法题用借位法耗时过长时，切换到分段法

## 补充说明

"2112"指分段模式：2位|1位 vs 1位|2位，或类似组合，核心原则是"怎么不借位就怎么分"。当某段结果为负数时（如221-142，分段后1-2=-1），用80+(-1)=79得到79。这需要改变长期的计算习惯，但一两天就能适应，且能显著提高速度。可配合增量判断题，是后续"分段法速判增量"的基础。
