# 方法卡：并列对策抓共性总意义

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 并列对策抓共性总意义 |
| 适用题型 | 中心理解 |
| 触发场景 | 文段有两个内容不同的对策并列（"一方面…另一方面…"），对策表面无共性 |
| 步骤逻辑 | 1. 不只看对策内容找共性；2. 看两个对策的目的/意义是否一致；3. 选择能概括共同目的的选项（可以是总意义而非总对策）；4. 类似申论小标题：可以写总对策，也可以写总意义 |
| 高频错因 | 只看对策内容不同就认为无共性；选了过于抽象的"干预体系"类选项 |
| confidence | high |

## 不适用条件

1. 两个对策内容相同或高度相似，可直接选对策本身
2. 文段有明确的总结句概括了对策的共同意义
3. 对策和意义都不一致，无法提炼共性

## 反向触发

- 文段有两个内容不同的对策并列，且选项中需要选择能概括共同目的的表述
