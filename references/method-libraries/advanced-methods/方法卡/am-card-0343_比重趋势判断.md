# 方法卡：比重趋势判断

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 比重趋势判断 |
| 适用题型 | 资料分析——比重升降趋势、多期比重变化 |
| 触发场景 | 问"比重成什么样的变化趋势"或"上升/下降"；给出部分和整体的增速（或可通过百分点推出） |
| 步骤逻辑 | ① 确定R1=部分增速，R2=整体增速；② 比较R1和R2：R1>R2则比重上升，R1<R2则下降；③ 对多期趋势，逐对比较相邻年份的R1和R2；④ 不需要算具体比重值 |
| 高频错因 | 混淆R1/R2分别对应部分还是整体；以为需要算出具体比重才能判断趋势 |
| confidence | high |

## 补充说明

连续三年的趋势需要比较两对R1/R2。只要所有年份都是R1<R2，趋势就是"持续下降"。提速关键：只需找增速，不碰具体数据计算。

## 不适用条件

- 题目要求具体比重数值而非趋势方向
- 材料未给出部分增速或整体增速，且无法从百分点数据推出
- R1与R2相等（比重不变），选项要求判断"先升后降"等复杂趋势时需额外计算

## 反向触发

- 若连续多期R1和R2大小关系交替（升降不定），应列出每对比较结果，不要凭中间某一期的趋势推断整体
- 若R1略大于R2但选项只有"持续上升"和"持续下降"，先确认是否所有年份R1均大于R2，不要仅看一期下结论
