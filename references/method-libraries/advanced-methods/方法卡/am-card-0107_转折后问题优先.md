# 方法卡：转折后问题优先

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 转折后问题优先 |
| 适用题型 | 中心理解题、主旨概括题 |
| 触发场景 | 文段出现"然而/但是/可是"等转折词，转折后提出问题表述 |
| 步骤逻辑 | 1. 快速定位转折词（然而/但是/可是）；2. 转折前的内容大概率不是重点，唯一作用是引出话题；3. 转折后的核心内容才是主旨方向；4. 如果转折后提出问题，则问题就是主旨抓取点；5. 问题后面若有冒号等展开说明，属于分析论证部分，不需要细读 |
| 高频错因 | 花大量时间细读转折前的背景/铺垫内容被转折前的正面表述（好处/意义）干扰判断把转折后的分析论证部分误当成独立的重点 |
| confidence | high |

## 不适用条件

1. 转折后是对策表述而非问题表述——对策优先于问题概括，应参见"有对策选对策速判"。
2. 转折后的问题是过渡性铺垫，紧跟着就有对策提出——主旨对策优先，问题只是引出对策的手段。
3. 转折后虽有"问题"表象，但实际是对比论证的反面论据而非核心问题——对比结构需整体判断。

## 反向触发

1. 转折后提出问题但文段末尾紧接着有"因此/应该/需要"等对策总结——应优先抓对策而非问题。
2. 转折后的问题带有明显的举例性质（如"比如""例如"），是论证而非核心问题。
3. 转折词是弱转折（如"当然""不过"），前后语义方向基本一致——弱转折不改变主旨方向。
