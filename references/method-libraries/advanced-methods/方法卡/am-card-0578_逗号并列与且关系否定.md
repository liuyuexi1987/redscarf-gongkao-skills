# 方法卡：逗号并列与且关系否定

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 逗号并列与且关系否定 |
| 适用题型 | 形式推理——判断题干两个事实是"且"关系还是"推出"关系 |
| 触发场景 | 题干用逗号连接两个事实（如"对所有标本进行了检测，没有发现阳性抗体"），问"若上述判断为假，哪项一定为真" |
| 步骤逻辑 | ① 判断连接方式：有逻辑关联词（如果…那么/结果/则）→推出关系；无关联词只用逗号→并列（且）关系；② 若为A且B，否定后为非A或非B（德摩根律）；③ 非A=不是对所有都检测=部分尚未检测；非B=不是没发现=已发现阳性抗体；④ 两个"或"分支至少有一个为真 |
| 高频错因 | 把逗号连接误判为推出关系A→B，否定后找"A且非B"，但选项中的量词（"部分""有些"）对不上"所有"，导致选错 |
| confidence | high |

## 补充说明

判断关键：原文无"结果""因此""则"等关联词时，逗号连接的两个事实为并列（且）关系而非推出关系。A且B为假→非A或非B（德摩根律），其中非A对应"不是对所有都检测=部分尚未检测"，非B对应"不是没发现=已发现阳性"。若误判为A→B，否定后为A且非B，此时选项中的量词（如"部分"）与原命题量词（如"所有"）会对不上，可据此排除。

## 不适用条件

- 题干中两个事实之间明确存在"如果…那么""则""因此""结果"等逻辑关联词时，本方法不适用，应按推出关系处理。
- 题干问的是"以下哪项能削弱/支持上述论证"等加强削弱题型，而非"上述为假时哪项一定为真"的否定题型。

## 反向触发

- 当题干确实为推出关系（A→B）时，应换用"假言命题否定→A且非B"的方法，而非本卡的德摩根律。
- 当选项中无任何量词对应（既无"部分"也无"所有"）时，需补充核验选项是否转换了命题的模态或范围。
