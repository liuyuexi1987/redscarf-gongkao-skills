# 方法卡：用历史趋势质疑当前数据

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 用历史趋势质疑当前数据 |
| 适用题型 | 判断推理 > 削弱质疑（措施有效性归因） |
| 触发场景 | 题干称"采取措施后某指标上涨X%"，归功于该措施 |
| 步骤逻辑 | 1. 题干漏洞：只看今年vs去年，没看历史趋势；2. 质疑方向：过去N年每年都涨X%以上，今年只涨了X%，说明措施可能无效甚至拖后腿；3. 选项含时间跨度（近5年/均/每一年）是关键信号词——保证质疑力度；4. 否定此因（整体上可能没用）> 另有他因（只是其中一个原因）> 细节质疑 |
| 高频错因 | 被另有他因（如新机器）干扰，忽略更根本的否定此因；不看选项中的时间跨度信号词 |
| confidence | high |

## 不适用条件

1. 结论本身已基于多年趋势（如"连续5年增长"），而非仅凭单一年份对比。
2. 题干中措施与指标之间有明确因果机制说明（如随机对照实验），而非仅靠时间先后推断因果。
3. 选项中没有任何时间跨度信号词，无法构建历史趋势对比。

## 反向触发

1. 题干讨论的是措施的必要性而非有效性时，质疑方向应改为否定措施前提，而非比较历史趋势。
2. 当选项能直接切断措施与指标之间的因果传导（如指标上涨另有直接原因），优先用切断因果链条的选项，力度通常优于历史趋势对比。
3. 题干结论仅说"指标上涨"但未归因于措施时，质疑应针对数据本身的可靠性，而非趋势对比。
