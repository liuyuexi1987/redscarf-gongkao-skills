# 方法卡：意型题对策表述辨析

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 意型题对策表述辨析 |
| 适用题型 | 中心理解题（意在说明类） |
| 触发场景 | 题干问"意在说明"（意型），选项中出现对策性表述（如"应该""应当"） |
| 步骤逻辑 | 1. 判断题干是意型（意在说明）还是异型（提出问题需解决）；2. 意型题干如果既无对策也无问题，则不应选对策性选项；3. 对策选项只在：题干本身提对策，或题干提了问题需要对策时才适用 |
| 高频错因 | 看到对策就选，不判断题干类型把"意型"题干当成"异型"来处理 |
| confidence | high |

## 不适用条件

- 题干明确提出了问题（异型），此时对策性选项是合理方向
- 文段本身包含对策性表述（如"应当""需要"），此时选择对策选项不违反题意
- 题干问的是"概括"或"主旨"，而非"意在说明"

## 反向触发

- 若题干同时有"问题+对策"结构，应先判断文段重心是问题还是对策，不能一律排斥对策选项，换用"对策表述适用条件"卡核验对策方向
- 若选项中的对策性表述实际是对文段评价性观点的同义改写（而非真正的行动建议），应重新辨析该选项是否属于对策
- 若多个选项都是对策表述且方向不同，单靠"意型不选对策"无法区分，应回文核对文段是评价型还是问题型来定夺
