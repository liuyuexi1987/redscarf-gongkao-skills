# 方法卡：图推找相同识不同法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 图推找相同识不同法 |
| 适用题型 | 判断推理——图形推理 |
| 触发场景 | 拿到图推题后的第一步观察动作 |
| 步骤逻辑 | ① 先扫所有图，找它们的共同点（相同元素、共同属性、共同结构）；② 共同点分两种：直观相同（都有圆/三角形/封闭区域）和隐晦相同（都是轴对称、都有最大面、都是三部分）；③ 若找到共同点→猜测规律围绕共同点展开，分析各图如何围绕共同点变化；④ 若找不到共同点→识不同：承认各图差异大，转向抠细节、找特殊图形作为破题口 |
| 高频错因 | ① 只看直观相同，忽略隐晦相同（如所有图都是轴对称、所有图都有一个最大面）；② 找不到相同就放弃，不切换到"识不同"策略；③ 把偶然凑出的微观共性（如笔画数恰好相同）当成主要规律 |
| confidence | high |

## 补充说明

找相同时把图放远看效果更好——远看能抓住整体轮廓和结构特征，不容易被局部细节干扰。

"相同"不一定是看得见的元素相同。所有图都有一个非常大的面、所有图都是轴对称、所有图都由三部分组成——这些都是隐晦的相同，往往是更高水平的命题手法。

识不同策略的核心：当图与图之间差异很大时，从特殊图形或特殊部位切入。问自己"这个图为什么这样画？"——箭头为什么拐了一下？为什么露出一段线头？为什么元素数量刚好如此？特殊处往往提示解题方向。

## 输出要求

- 讲图推时先说明观察顺序（宏观→预判→微观）
- 至少展示 2-3 层排查过程
- 图片不清、选项缺失、截图太小时，不得硬判答案
- 没读到具体细卡时，不得伪造卡号
- 有官方答案时按答案核验；无官方答案但图形清晰时，可写"按当前图形规律，我的复核倾向于 X"

## 不适用条件

- 图形数量过少（如仅2幅图）时，共同点或差异点难以构成稳定规律。
- 图形差异极大且无任何可比较的结构基础时，"找相同"策略不适用，应直接走"识不同"或数量路径。

## 反向触发

- 共同点找到后无法解释各图差异时，应换用"藏与找"模型或数量类规律补充核验。
- 特殊图形切入后仍无法锁定规律时，应回查整体特征是否遗漏，重新走总纲观察顺序。
