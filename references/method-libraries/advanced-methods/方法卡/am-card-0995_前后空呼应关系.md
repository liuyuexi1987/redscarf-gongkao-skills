# 方法卡：前后空呼应关系

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 前后空呼应关系 |
| 适用题型 | 逻辑填空——多空题 |
| 触发场景 | 多空题中，前后空格之间存在逻辑对应关系（如对策+意义、原因+结果） |
| 步骤逻辑 | ① 判断前后空格的逻辑关系类型（对策+意义、原因+结果、做法+效果等）；② 前后空的词必须逻辑对应；③ 例："采用XX方式"→"增强亲和力"（对策+效果对应），"采用XX方式"→"增强说服力"不对应（说服力与采用方式无关） |
| 高频错因 | ① 前后空独立选词不考虑呼应→选了逻辑不搭的组合；② 如"贴近受众"→效果应是"亲和力"而非"说服力" |
| confidence | high |

## 补充说明
多空题的前后空格往往存在呼应关系。如"贴近受众"→效果应该是"亲和力"（距离近了才有亲和力），而非"说服力"（说服力与距离无关）。又如"细分受众"→效果应该是"针对性"而非"亲和力"。判断要点是先确定前后空属于何种逻辑关系（对策+效果、原因+结果、做法+意义），再据此匹配词义方向。

## 不适用条件
- 多个空格分属不同分句且彼此无逻辑对应（各自独立填空）时，本方法不适用。
- 空格虽前后相邻但同属一个固定搭配（如"___地推进"），属于搭配关系而非呼应关系，应改用搭配辨析。
- 文段为单空题时无前后空呼应可言，本方法不适用。

## 反向触发
- 当前后空呼应关系得到多个候选组合时，应换用"自带逻辑词判断法"核验每个候选词的逻辑前提。
- 当前后空分属并列分句（分号隔开）时，应改用"分号并列对应法"做位置对应而非呼应关系。
- 当呼应判断依赖的效果词本身含糊（如"提升"既可接"亲和力"也可接"说服力"）时，应回到文段核验主体动作的语义重心，避免误判呼应方向。
