# 方法卡：或关系否一推一逆推

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 或关系否一推一逆推 |
| 适用题型 | 形式推理——逆推题，已知"A或B"要推出确定结论 |
| 触发场景 | 题干给出若干"或"条件和"如果…那么"条件，问"可以推出以下哪项"，结论尚未确定，需要反向推导 |
| 步骤逻辑 | ① 写出目标结论（如"小李教德语"）；② 利用或关系"否一推一"：想从A或B推出A，就否定B（小钱不教德语→小李教德语）；③ 若选项中无此中间结论，继续沿条件链推导，用逆否（A→B等价于非B→非A）；④ 推导链上任何一个中间结论成立都能作为正确答案，选项一般给出最后一步；⑤ 不要跳步蒙猜推理终点，出题人可能从中间截断 |
| 高频错因 | 跳步猜推理终点（如直接猜最后一个人的结果），被出题人从中间截断出题打败；忘记"或关系否一推一"和"逆否"两个核心转化工具 |
| confidence | high |

## 补充说明

或关系否一推一+逆否是逆推题的核心转化工具。推导时按以下顺序：先写出目标结论，用或关系否一推一定出中间结论；若选项无此结论，沿条件链用逆否逐步反推；推导链上任一中间结论成立都能作为正确答案，选项一般给出最后一步。不要跳步蒙猜推理终点，出题人可能从中间截断出题。

## 不适用条件

- 题干条件全部为"且"关系而非"或"关系时，不适用否一推一，应正向联立推导。
- 题干已给出确定前提，只需正向推导而非逆推时，不适用本方法。

## 反向触发

- 当条件链中出现"联立可推矛盾"的结构时，应换用"或关系联立推矛盾"方法处理。
- 当推导链过长且中间结论频繁截断时，应补充核验每一步的等价转换方向，避免逆否方向写反。
