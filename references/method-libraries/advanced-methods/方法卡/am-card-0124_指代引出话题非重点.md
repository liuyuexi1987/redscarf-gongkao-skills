# 方法卡：指代引出话题非重点

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 指代引出话题非重点 |
| 适用题型 | 中心理解题 |
| 触发场景 | 文段用"这种""这样的"等指代词承接上文，将话题从旧领域转移到新领域 |
| 步骤逻辑 | 1. 识别指代词（"这种""这样的"等）承接上文并将话题引向新领域 2. 指代词所在句子是过渡，本身非重点 3. 重点看指代后新领域中具体讨论了什么问题或对策 4. 选项应围绕指代后的新话题，而非指代前的旧话题 |
| 验证动作 | 选出答案后，检查选项主题词是否落在指代后的新领域；若选项仍在讨论指代前的旧话题，则选项出处有误 |
| 不适用条件 | 仅适用于指代词将话题转移到新领域的情况；若指代词仅回指前文同一话题（无话题转移），不适用本方法 |
| 高频错因 | 选项围绕指代前的旧话题，忽略了话题已通过指代词顺承到新领域 |
| confidence | high |
| 反向触发 | ①指代后的新领域讨论内容非常简短（一两句话即结束），而指代前的旧话题才是文段大量展开的内容，此时旧话题可能才是主旨；②指代词所在句子本身带有转折或递进逻辑词（如"但这种""而这样的"），提示指代句可能是观点而非单纯过渡；③文段整体为同一话题的不同角度展开（无真正的领域转移），指代词仅为行文衔接手段，不适用话题转移判断 |

---

> **使用边界**：本方法用于提供优先检查方向，不可单独据此作答；最终需回到题干关系、原文证据或选项条件完成验证。
