# 方法卡：共同原因削弱

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 共同原因削弱 |
| 适用题型 | 判断推理——加强削弱·因果论证（由果推因） |
| 触发场景 | 题干猜A导致B（两事同时出现），选项说C才是A和B的共同原因 |
| 步骤逻辑 | ① 识别题干是因果猜测；② 找"共同原因"型选项：C导致了A，也导致了B；③ A和B同时出现不是因为A→B，而是因为它们都是C的果 |
| 高频错因 | ① 误认为共同原因只是"他因"的一种（它更强，直接否定A→B的因果方向） |
| confidence | high |

## 补充说明

共同原因型的结构：C→A且C→B，所以A、B同时出现但A不是B的原因。力度等同于他因，属于强削弱。

## 不适用条件

- 题干中A与B不存在可识别的第三方共同原因候选时，本方法不适用。
- 题干讨论的是单一原因导致单一结果（无共现现象）时，本方法不适用。
- 题干因果方向已由题面明确限定（如实验干预直接操纵A）时，本方法不适用。

## 反向触发

- 当选项给出"A→B的因果机制"而非共同原因时，应换用因果加强搭桥法核验。
- 当题干要求解释转折后现象而非削弱因果时，应换用解释转折现象法。
- 当题干要求对论证逻辑漏洞进行问题式评价时，应换用论证评价题方法。
