# 方法卡：小分互换

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 小分互换 |
| 适用题型 | 资料分析——乘法中出现常见百分数（25%、12.5%等） |
| 触发场景 | 乘法中遇到25、50、125等数字，或百分数接近常见分数值 |
| 步骤逻辑 | ① 记忆核心对应：1/2=50%、1/3=33.3%、1/4=25%、1/5=20%、1/6=16.7%、1/7=14.3%、2/7=28.6%、3/7=42.9%、1/8=12.5%、1/9=11.1%；② 遇到对应数字时将乘法转为除法（如x25→÷4）；③ 选项能对上有效数字即可，后补零不影响选择 |
| 高频错因 | 记混2/7和3/7的值；乘以5或50忘记实质是除以2 |
| confidence | medium |

## 补充说明

核心对应关系（1/2=50%、1/3≈33.3%、1/4=25%、1/5=20%、1/8=12.5%等）可通过壁纸等工具辅助记忆。乘以5和乘以50本质都是除以2（50%=1/2）。后补零不影响有效数字匹配，选项通常不会设置仅差零位数的干扰项。当估算误差可能跨越选项或改变结论时，改用精算/验证。

## 不适用条件

1. 题目中百分数不在常用分数对应表中，强行近似会引入较大误差。
2. 选项间距极小（有效数字几乎一致），小分互换的精度不足以区分。
3. 乘数本身不是整数或简单百分数，转换后反而增加计算复杂度。

## 反向触发

1. 乘法中识别到25、50、125等与常用分数直接对应的数字。
2. 选项间距较大，只需匹配有效数字即可确定答案。
3. 运算中含50%、25%、12.5%、33.3%等常见百分数，可直接转化为除法简化。
