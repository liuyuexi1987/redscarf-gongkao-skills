# 方法卡：基准值法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 基准值法（减法） |
| 适用题型 | 资料分析——相邻两个百位数相减（如700多减600多） |
| 触发场景 | 两个数百位相邻，需要快速做减法时 |
| 步骤逻辑 | ① 取中间整百作为基准（如700）；② 算出各数与基准的差；③ 两个差相加即为结果 |
| 高频错因 | 基准值选取不当；差的符号弄反 |
| confidence | medium |
| 不适用条件 | 1. 两数百位相差较大（如800多减500多）时，基准值法效率低
| 反向触发 | 1. 看到两数百位差超过1（如800多减500多），不用基准值法，改用分段法
2. 两个数都是小数或百分数，改用小数对齐或直接计算
3. 数字位数较少且无借位，直接口算更快，无需取基准 |
2. 数字以小数或百分数为主时，基准值法不适用
3. 选项间距极小需要精确到个位以上时，差的符号容易弄反 |

## 补充说明

例：721-688，取基准700，721比700多21，688比700少12（即差-12），所以721-688=21+12=33。本质是把减法转化为加法，避免借位。
