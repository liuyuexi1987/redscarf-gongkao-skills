# 方法卡：固定增速逐年推现期

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 固定增速逐年推现期 |
| 适用题型 | 现期 / 假设增速不变求哪年达标 |
| 触发场景 | 题目说"保持某年增长率不变"，问哪一年首次达到某目标值；无法用不等式一步求解 |
| 步骤逻辑 | 1. 确定基期量和固定增长率R；2. 逐期计算下一期=本期×(1+R)；3. 每一步记录是否首次达到目标值；4. 期数较多时可改用幂次或对数估计，再回代相邻期验证 |
| 高频错因 | 误以为增长率不变则增量不变，用固定增量列不等式逐推时每期的增量需要重新计算（利滚利），不能直接加同一个X |
| confidence | medium |

## 不适用条件

1. 题目说的是"保持增量不变"而非"保持增长率不变"，属于固定增量模型，应用等差数列或不等式。
2. 题目要求用公式一步求解（如对数或不等式），而不需要逐年逐期迭代。
3. 连续推算期数较多或舍入误差可能影响首次达标期判断时，应改用幂次计算并回代验证。

## 反向触发

1. 用固定增量的等差模型处理"保持增长率不变"的题目，忽略每期增量递增。
2. 逐推时每期增量相同，说明误以为增速不变等同于增量不变。
