# 方法卡：非独立事件概率分类讨论

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 非独立事件概率分类讨论 |
| 适用题型 | 数量关系（概率） |
| 触发场景 | 题目给出P(A∩B)≠P(A)×P(B)，说明事件不独立，不能直接相乘 |
| 步骤逻辑 | 1. 先验证独立性：若P(AB)≠P(A)×P(B)，则事件不独立；2. 画文氏图（两个圈）辅助分类；3. 按互斥大类分类讨论（如"至少一人入选"vs"某人独自入选"）；4. 每大类内部用"单人入选=总入选-同时入选"求纯净概率；5. 各大类概率相加 |
| 高频错因 | 把不独立事件当独立事件直接相乘；不画图导致分类遗漏 |
| confidence | medium |

## 不适用条件

1. 事件已明确独立时直接相乘即可，不需分类讨论。
2. 古典概型等可能事件且事件间无交叉关系时不适用本分类法。
3. 题目已给出条件概率 P(B|A) 时直接套条件概率公式更高效。

## 反向触发

1. 若事件互斥，应换用加法公式 P(A∪B)=P(A)+P(B)。
2. 若题目需计算多次独立重复试验，应换用伯努利概型而非分类讨论。
3. 若分类后子事件数过多导致计算量爆炸，应改用对立事件法（1−对立面概率）。
