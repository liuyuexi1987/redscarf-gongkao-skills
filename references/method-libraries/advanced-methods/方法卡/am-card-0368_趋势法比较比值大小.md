# 方法卡：趋势法比较比值大小

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 趋势法比较比值大小 |
| 适用题型 | 资料分析 - 比重/比值排序题 |
| 触发场景 | 给多个指标的基期值和增速，要求按某个比值（如占总体比重）由大到小排序 |
| 步骤逻辑 | 1. 比值 = 部分 / 整体，整体相同时直接比部分大小即可；2. 部分不同时，看部分的基期值和增速的相对关系；3. 分子增得快（增速更高）则分数变大，分母增得快则分数变小；4. 只需比较分子增速与分母增速的差异趋势，无需精确计算 |
| 高频错因 | 拿现期值直接比大小而不考虑增速对趋势的影响；误以为增速大则比值一定大 |
| confidence | high |

## 不适用条件

- 题目要求精确计算比值（趋势法只做大小方向判断，不适用于求精确数值）
- 分子分母增速完全相同（趋势无法给出方向判断，需直接用基期值比较）
- 比值涉及多个分项相加（复合分母的增速趋势难以直接比较）

## 反向触发

- 当基期值差异极大、增速差异极小时，基期基数主导大小，应直接比基期值而不用趋势法
- 当题目要求"最大"和"最小"的比值差多少时，趋势法只判断大小关系，应改用精确计算
- 当出现三个以上指标排序且增速方向不一致时，趋势法可能产生排序歧义，需配合精确计算验证
