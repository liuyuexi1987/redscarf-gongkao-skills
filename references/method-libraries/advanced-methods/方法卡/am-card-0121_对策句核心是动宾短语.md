# 方法卡：对策句核心是动宾短语

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 对策句核心是动宾短语 |
| 适用题型 | 中心理解题（选项高度同义替换时） |
| 触发场景 | 找到对策句后，选项不是原词原句，而是做了大幅同义替换 |
| 步骤逻辑 | 1. 找到对策句，锁定句子中的动宾短语（核心行为） 2. 提取动宾短语的"动作+对象"，如"调整""专业链" 3. 比对选项：必须体现该动宾短语的核心含义 4. 选项中的主语、定语、修饰成分可以省略或替换，但动宾核心不可缺失 |
| 验证动作 | 选出答案后，回代检查：选项的动宾是否覆盖了对策句的核心行为；若选项动宾明显偏离，则排除 |
| 不适用条件 | 仅适用于对策句；背景句、问题描述句、意义表述句不适用此方法；需先确认文段确有对策表述 |
| 高频错因 | 要求选项包含文段全部关键词（主语、定语、修饰词），因选项"缺东西"而不敢选；对策句可能很长但核心动宾短语只有一个，修饰成分省略不影响正确性 |
| 反向触发 | ①对策句的动宾短语在选项中全部出现但含义分化时，仅靠动宾匹配无法区分，需回代验证哪个选项与文段对策方向一致；②文段有多句对策且动宾各不相同时，需判断哪句对策是文段核心主张，不能将各句动宾混搭选一个"都沾边"的选项；③选项动宾来自非对策句（如背景、问题描述），即使用词相似也不能选，应确认动宾出处与对策句一致 |
| confidence | high |
