# 方法卡：幂次修正与因式分解数列

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 幂次修正与因式分解数列 |
| 适用题型 | 数量关系——数字推理（幂次修正数列、因式分解数列） |
| 触发场景 | 数列变化幅度大且多项接近常见幂数（平方/立方/复合幂）；或数列全为合数且可拆为两个简单数列的乘积 |
| 步骤逻辑 | ① 幂次修正路径：先识别数列中接近幂数的项，写出底数序列与指数序列；② 判断幂次结构类型——指数为常数 m（如 n^3）、底数为常数 a（如 2^n）、底指都变（如 n^n 或 n^(n-1)）；③ 判断修正结构——修正项 p 为常数、为简单数列（等差/等比）、或与 n 相关（如 p=n）；④ 套用 a(n)=底^指+p 形式，逐项验证底、指、p 三序列各自规律；⑤ 因式分解路径：将每项分解为两个因子的乘积，观察两个因子序列是否各自成简单规律（如自然数×质数、偶数×合数）；⑥ 两条路径都必须覆盖全部已知项，且推得的目标项能唯一锁定选项 |
| 高频错因 | ① 只看到一项接近幂数就断定幂次修正，未用多项交叉验证底数/指数序列；② 底数或指数序列本身是递推数列时，只验证了前两项就下结论；③ 因式分解时只找到一种拆法就定型，未排除其他等价拆法导致的多解；④ 把幂次修正和因式分解混用，如对 n^3-1 的数列强行因式分解 |
| confidence | high |

## 不适用条件

1. 数列中只有一项接近幂数时，幂次修正假设缺乏支撑，应回退到作差/作和/递推。
2. 数列含质数较多时，因式分解路径受限（质数只能拆为 1×自身），应改用其他路径。
3. 项数少于 5 项时，底数/指数/修正项三序列样本都不足，幂次修正结论不可靠。
4. 因式分解存在多种等价拆法且都能覆盖已知项时，若无选项辅助裁决，本路径无法唯一锁定。

## 反向触发

1. 当幂次修正的底数或指数序列在前几项成立、末项偏离时，应检查是否为复合幂（如 n^(n-1) 而非 n^2）。
2. 当修正项 p 序列无规律时，应改用"幂次无修正"版本，或检查 p 是否与底/指相关（如 p=n、p=底-指）。
3. 当因式分解的一种拆法推出目标项不在选项中时，应尝试其他等价拆法，或回退到幂次修正路径。
4. 当数列同时满足幂次修正和因式分解两条路径时，优先选能覆盖更多项且规律更简洁的一条，并用选项二次裁决。

## 最终验证动作

1. 幂次修正：用求得的底、指、p 三序列逐项回代 a(n)=底^指+p，确认每一项完全吻合。
2. 因式分解：用两个因子序列逐项相乘回代，确认每一项完全吻合。
3. 推出目标项后，与选项比对；若目标项与最近选项有固定差值，检查末项的修正项 p 或因子是否有方向变化。
4. 对底指都变的复合幂（如 n^n），必须验证底数序列和指数序列各自规律都覆盖全部已知项，不能只验证乘积结果。
5. 对因式分解，必须排除其他等价拆法的多解可能，或用选项差距锁定唯一拆法。
