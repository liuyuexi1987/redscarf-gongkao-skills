# 方法卡：不定方程尾数法
## 基本信息
| 字段 | 值 |
|------|-----|
| 方法名 | 不定方程尾数法 |
| 适用题型 | 数量关系-不定方程/整数解 |
| 触发场景 | 两个方程三个未知量，消元后得到如 5Z+3X=43，需找正整数解 |
| 步骤逻辑 | 1.消掉不需要的未知量，保留目标未知量 2.观察目标未知量系数的尾数：若为5（如5Z），则5Z尾数只能是0或5 3.根据等式右边尾数（如43尾数为3），推出另一项3X的尾数为8或3 4.将选项逐一代入验证3X尾数是否匹配 5.代入后验证另一未知量是否为正整数 |
| 高频错因 | 代入后忘记验证剩余未知量是否为正（如领导人数不能为负）；忘记尾数法的前提是系数尾数为5 |
| confidence | high |

## 不适用条件

1. 消元后目标未知量系数尾数不是5或0时，尾数法无法直接使用，需改用奇偶性或代入排除
2. 方程系数较大且选项间隔较小时，尾数法只能缩小范围，仍需结合代入验证

## 反向触发

1. 系数尾数为5但选项全部尾数相同无法区分时，改用奇偶性或整除特性排除
2. 存在三个以上未知量且无法消到两个时，尾数法效率下降，改用枚举法
## 补充说明
尾数法适用条件：某个未知量的系数尾数恰好是5（或0）。判断要点是"什么时候用尾数——当系数尾数是5时"。比逐个代入更快，但代入后仍需验证其他未知量的正整数约束（如人数不能为负、不能为零等）。
