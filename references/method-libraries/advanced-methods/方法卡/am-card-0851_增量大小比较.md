# 方法卡：增量大小比较

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 增量大小比较 |
| 适用题型 | 资料分析——增量比较·比较多个对象的增量（变化量）谁大谁小 |
| 触发场景 | 题目要求比较A、B、C等多个对象的"同比增加量"或"增量"高低排序 |
| 步骤逻辑 | ① 先确认比较的是带符号的增量还是变化幅度；② 比较带符号增量时先按正负分组，正增量大于负增量；③ 对正增长项，现期量更大且增速更大时，增量必然更大；④ 两个因素方向相反或数值接近时，直接估算增量，不强行使用“大大则大” |
| 高频错因 | ① 把增量大小与变化幅度混为一谈；② 正负增量混排时只比较增速绝对值；③ 现期量与增速一大一小时仍强行速判 |
| confidence | high |

## 补充说明

增量=基期×增速。比较增量大小时，不需算出基期，用"限期比×增速比"即可判断：限期大的一方增速也大→增量一定更大。方向不一致时，可尝试用间隔增长率把增速低的一方限期拉上去补平差距，再比较。"大大则大"仅限绝对值比较：限期绝对值大、增速绝对值大→增量绝对值大。

## 不适用条件

- 题目要求算出具体增量值（而非仅比较大小）时，需用完整公式
- 增速为负的项与增速为正的项混排时，不能直接用"大大则大"，需先分正负再分别比较
- 限期比和增速比方向不一致且差距都很小时，速判可能不可靠，建议直接估算增量

## 反向触发

- 看到"同比增加量最大/最小""增量排序"且对象≥3个 → 用本方法
- 看到"增速最大/最小" → 不用本方法，应用 am-card-0854（增量÷现期比较增速）
- 看到"增长量是多少"（求具体值） → 不用本方法，应用四要素公式计算
