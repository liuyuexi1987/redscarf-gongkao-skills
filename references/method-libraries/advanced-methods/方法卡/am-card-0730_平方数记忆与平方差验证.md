# 方法卡：平方数记忆与平方差验证

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 平方数记忆与平方差验证 |
| 适用题型 | 平方数相关问题（页码、年龄、种类×台数 = 平方数等） |
| 触发场景 | 题目条件暗示结果为平方数（如"年龄的平方=年份""每种台数=种类数"），或需要在若干平方数中筛选 |
| 步骤逻辑 | 1. 背熟平方数表：1²~20²，外加25²=625；2. 根据实际约束缩小范围（如年龄问题：父母约25~36，祖父母约49~64）；3. 验证两数差时用平方差公式：a² - b² = (a+b)(a-b)，分解因数找解；4. 结合排除法（如"减2加2都是质数"→排除偶数平方，排除3的倍数附近） |
| 高频错因 | 平方数记不牢导致漏解；年龄问题代入时不考虑合理性（如十六岁当父母） |
| confidence | medium |
| 不适用条件 | - 题目是完全不涉及平方关系的四则运算、百分数、工程问题等，不需要调用平方数记忆。- 数字极大超出1~20范围（如100以上的平方），平方差公式仍在但口算平方记忆不再适用，需笔算。 |
| 反向触发 | - 题目明确要求计算增长率或基期量，属于资料分析常规公式，不涉及平方数筛选。- 题目条件给出的是立方关系（如体积、立方数列），应触发立方数记忆而非平方数。 |

## 补充说明

- 示例（页码问题）：页数为平方数，±2均为质数。11²=121→119/123不全是质数；13²=169→171是3倍数；15²=225→223/227均质数 ✓
  - 示例（年龄问题）：年龄²=年份，代入45²=2025，生于1980年 → 八零后 ✓
  - 示例（平方差）：X²-Y²=45，分解为 5×9 或 3×15 → 找出两对平方数
  - 词义辨析强调：年龄问题"一般父母25~36，爷爷奶奶49~64""十六行不行呢？也不行，不符合常识"
