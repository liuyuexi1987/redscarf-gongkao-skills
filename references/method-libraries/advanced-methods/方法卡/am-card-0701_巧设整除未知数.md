# 方法卡：巧设整除未知数

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 巧设整除未知数 |
| 适用题型 | 方程法中系数含小数/分数/百分比的题型 |
| 触发场景 | 题目中出现倍数关系如"是A的1.2倍""比B多25%"等，设未知数后需要做除法 |
| 步骤逻辑 | 1. 看清各量之间的倍数/分数关系（如1.2倍、1.5倍、多25%即多1/4）；2. 将倍数关系化为分数，取各分母的最小公倍数（如1.2=6/5分母5、1.5=3/2分母2，公倍数为10）；3. 将被比较的量设为公倍数乘以X（如设为10X），则其他量均为整数倍X；4. 后续方程计算全程无小数，降低出错率 |
| 高频错因 | 直接设3月为X导致后面X/1.2出现小数；没注意到多25%（1.25=5/4）的分母是4，直接设小倍数导致出现非整数 |
| confidence | medium |

## 补充说明

设未知数的核心原则：当各量之间存在倍数/分数关系时，将倍数化为分数，取各分母的最小公倍数，将被比较的量设为该公倍数乘以X，使其他量均为整数倍X，全程计算无小数。应用示例：若某量是另一量的1.2倍（6/5）同时也是第三量的1.5倍（3/2），分母5和2的最小公倍数为10，设另一量为10X则该量为12X、第三量为15X；若某量比另一量多25%（即多1/4），设另一量为4X则该量为5X。

## 不适用条件

- 题目中各量关系均为整数倍（无需处理小数/分数，直接设未知数即可）。
- 题目仅给出和差关系（无倍数/分数关系，无公倍数可求）。

## 反向触发

- 当各量关系复杂且公倍数难以直接识别时，应换用直接设未知数列方程。
- 当题目要求求具体数值而非比例关系时，需在解出X后还原为实际值并核验。
