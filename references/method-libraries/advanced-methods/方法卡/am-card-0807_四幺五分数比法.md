# 方法卡：四幺五分数比法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 四幺五分数比法 |
| 适用题型 | 资料分析——已知现期和增长率，求基期/增长量 |
| 触发场景 | 增长率能近似为简单分数（1/4、1/7、1/6、1/8等），选项精度要求不高 |
| 步骤逻辑 | ① 百化分：将增长率化为分数（如25%→1/4）；② 写分数比：基期:增量:现期 = 分母:分子:(分母+分子)（如4:1:5）；③ 算一份：现期实际值÷总份数 = 一份的量；④ 求结果：增量 = 一份，基期 = 现期 - 增量 |
| 高频错因 | ① 下降时忘写负号，比例写反（应为"四幺三"写成"四幺五"）；② 用乘法求基期导致误差扩大（应做减法：b-x）；③ 百化分时分母和份数搞混 |
| confidence | medium |

## 补充说明

四幺五的核心是"分数思想"：用现期实际值对应总份数，反推一份的量，从而同时得到基期和增量。与百化分的区别在于思维路径——四幺五先写比例关系再算，百化分先列式再换分数。基期用减法（b-x）而非乘法，避免误差放大。当增长率为负时，变化量份数也带负号，如下降25%为"四负一三"。常考的百化分对应：1/7≈14.3%、1/6≈16.6%、1/9≈11.1%、1/11≈9.1%。当估算误差可能跨越选项或改变结论时，改用精算/验证。

## 不适用条件

1. 增长率无法近似为简单分数（如17.3%、23.7%），强行百化分引入误差过大。
2. 选项精度要求很高且间距极小，分数比的精度不足以区分。
3. 增长率不能稳定近似为简单分数，或近似误差可能跨越选项时，需改用精算。

## 反向触发

1. 增长率可化为常见分数（1/4、1/7、1/6、1/8、1/5等），百化分精度足够。
2. 选项间距适中，分数比一份的量可直接对应答案。
3. 同时需要基期和增量，四幺五一步即可同时得出两个结果。
