# 方法卡：搭配方向一致性

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 搭配方向一致性 |
| 适用题型 | 逻辑填空——并列结构/搭配 |
| 触发场景 | 并列的对策/做法出现在同一文段，需要判断施动者角度是否一致 |
| 步骤逻辑 | ① 判断并列项的施动者是谁（管理者/党员/群众等）；② 所有并列项的施动者角度必须一致；③ 从错误角度出发的选项→排除 |
| 高频错因 | ① 不注意施动者角度→选了从错误主体出发的词；② 如"明方向、___、正风气、强免疫"→都是管理者角度→"守底线"是从党员角度→排除，应选"严法纪"（管理者角度） |
| confidence | high |

## 补充说明
并列结构不仅要求语义并列，还要求施动者/角度一致。判断要点：先确认每个并列项的发出者是谁（管理者、执行者、对象自身等），再核对空格词的施动者是否与之一致；若空格词的施动者与并列项不同，即使语义贴近也应排除。

## 不适用条件

- 并列项分属不同主体且各自独立成句时，不要求施动者统一，本卡不适用。
- 并列结构旨在对比不同主体行为（如"上做什么、下做什么"）时，施动者本就不同，不能用一致性排除。
- 空格所在分句与并列项不是同一层级（如总句与分句关系）时，不套用本卡。

## 反向触发

- 当难以判断施动者归属时，应补一步主语回溯：找到空格所在分句的显性或隐性主语，再与并列项主语比对，而非凭语感排除。
- 当并列项含有被动或使动结构时，应换用语态分析，确认施动者与受动者方向，再决定是否一致。
- 当选项中所有词的施动者角度一致、无法用本卡区分时，应改用语义轻重或感情色彩等其他维度辨析。
