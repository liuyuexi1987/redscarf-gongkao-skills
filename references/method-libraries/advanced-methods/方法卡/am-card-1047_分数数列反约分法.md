# 方法卡：分数数列反约分法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 分数数列反约分法 |
| 适用题型 | 数量关系——数字推理（分数数列） |
| 触发场景 | 数字推理中数列全部或部分是分数 |
| 步骤逻辑 | ① 分母分子分开看；② 先倾向递增趋势化（如分母3→6→12，分子1→2→4）；③ 找上下各自的规律（等差/等比/递推）；④ 反约分：把分数还原成未约分形式（如1/2→2/4→3/6）让规律更明显 |
| 高频错因 | ① 直接看分数值→找不到规律；② 不做反约分→分子分母的规律被约分掩盖 |
| confidence | high |

## 补充说明
分数数列的核心技巧是反约分——把分数还原成同分母形式，让分子的规律显现出来。分母和分子通常各有独立规律（等差/等比/递推）。

## 不适用条件
- 分数只是偶发项、整数项已经呈现更稳定规律时，优先验证整数规律
- 反约分后分子、分母仍无法形成稳定规律时，应切换到递推、做差或做商
- 数列本质是多级数列（分数间做差/做商），反约分无效

## 反向触发
- 如果数列全为整数，不使用反约分法
- 如果反约分后分子分母仍无明显规律，应切换到递推或多级数列思路
