# 方法卡：分式混合法（盐水法）

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 分式混合法（盐水法） |
| 适用题型 | 资料分析——一个分式可拆分为两个子分式之和时的大小比较 |
| 触发场景 | 分式形式为(a+c)/(b+d)，需要与a/b或c/d比较大小 |
| 步骤逻辑 | ① 将原分式拆成两个具有正权重的子分式；② 比较两个子分式值的高低；③ 混合值位于两者之间，两者不等时严格落在二者之间：加入较高值会拉升整体，加入较低值会拉低整体 |
| 高频错因 | ① 搞混混合后的大小方向；② 忽略正权重条件；③ 把“位于两者之间”误写成简单算术平均 |
| confidence | high |

## 不适用条件

- 分式不能拆分为两个子分式之和的形式
- 比较的是两个独立分式，不存在混合关系
- 两个子分式的"浓度"差异不明显，混合方向难以判断

## 反向触发

- 两个分式没有"原量+新增量"的混合结构
- 分式形式为(a+c)/(b+d)但a/b和c/d无法快速估算

## 补充说明

也被称为"王者荣耀法"（胜率比喻）。关键判断：新加部分的分式值比原分式高还是低，即可确定混合后的变化方向。适合竖着看（分子÷分母的倍数关系明显时）。
