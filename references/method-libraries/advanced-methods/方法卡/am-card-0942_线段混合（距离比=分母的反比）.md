# 方法卡：线段混合（距离比=分母的反比）

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 线段混合（距离比=分母的反比） |
| 适用题型 | 两种溶液混合后求浓度，或已知混合浓度反推比例 |
| 触发场景 | 给出两种溶液的浓度和质量，求混合后浓度；或已知混合浓度求质量比 |
| 步骤逻辑 | 1. 画数轴标出两个浓度A、B和混合浓度C（C在A、B之间）；2. 距离比 = |A-C| : |C-B|；3. 质量比 = 距离比的反比（质量越大，离混合浓度越近）；4. 距离 × 质量 = 常数（类似杠杆/跷跷板原理） |
| 高频错因 | 搞反正比反比；忘记距离比是质量的反比而非正比 |
| confidence | high |

## 补充说明

线段混合只适合特定为它出的题，大部分情况下方程法更快更稳；不要过度依赖

## 不适用条件

- 三种及以上溶液混合时不适用
- 涉及蒸发/加水的单溶液变化题不适用

## 反向触发

- 复杂混合或数值不整时，应改用方程法保证准确
- 反复混合操作时，应改用方程法逐步追踪
