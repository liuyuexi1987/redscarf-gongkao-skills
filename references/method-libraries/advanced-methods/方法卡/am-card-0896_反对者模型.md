# 方法卡：反对者因果链检查法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 反对者因果链检查法 |
| 适用题型 | 判断推理——加强削弱·反对者题型 |
| 触发场景 | 甲说X导致Y，乙反对说不是X而是Z导致Y，问如何削弱乙 |
| 步骤逻辑 | ① 识别争议：甲主张 X 导致 Y，乙以 Z 导致 Y 来排斥 X；② 检查选项能否建立 `X→Z→Y`，若能，Z 可能只是 X 影响 Y 的中间环节，乙对 X 的排斥被削弱；③ 再检查选项是否真的说明 X 导致 Z，而不是仅说 X、Z 同时出现；④ 与其他选项比较其是否更直接击中乙的排他性结论 |
| 验证动作 | 把选项加入乙的论证，检查“不是X导致”是否仍能成立；若乙并未排斥X，建立中介链未必构成削弱 |
| 不适用条件 | 甲乙讨论的结果不同；乙只补充原因而未否定甲；选项无法建立 X 到 Z 的因果关系 |
| 高频错因 | 见到两个原因就机械串联；把相关关系当成因果链；未确认乙是否真的排斥甲的原因 |
| confidence | medium |
| 反向触发 | 选项中的反对者并未直接否定核心论点，而是质疑论据来源或表述方式，此时反对者模型不适用；题干结论为纯数据统计而非因果或政策判断时，不存在明确的反对立场 |
