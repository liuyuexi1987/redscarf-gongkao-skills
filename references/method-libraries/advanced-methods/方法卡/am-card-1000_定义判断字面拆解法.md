# 方法卡：定义判断字面拆解法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 定义判断字面拆解法 |
| 适用题型 | 判断推理——定义判断 |
| 触发场景 | 遇到陌生概念名称时 |
| 步骤逻辑 | ① 看到概念名称先拆字面含义（如"监管竞次"→"竞"=多主体竞争）；② 围绕核心字去解释中寻找对应；③ 用字面含义预判核心考点→再读解释验证 |
| 高频错因 | ① 跳过概念名称直接读长解释→抓不住核心；② 忽略概念名称中包含的关键信息 |
| confidence | high |

## 补充说明
概念名称本身就是最大的线索。例如"互益素"→"互"+"益"→互相有益→排除"同种生物"选项。又如"化学动力学"→"化学"是限定→排除物理相关选项。拆解时应分别解析每个字/词的字面含义，再以核心字为锚点在解释中寻找对应条件。

## 不适用条件
- 概念名称为常见通用词（如"管理""监督"），无字面可拆的特殊结构时，本方法不产生增量信息。
- 概念名称为外文音译或专有名词（如人名、地名命名的定律），字面拆解无语义价值。
- 概念名称的字面含义与定义解释存在明显反差（故意命名）时，字面预判可能误导，应改以解释为准。

## 反向触发
- 当字面拆解得到的核心字在解释中无对应条件时，应放弃预判，回到解释全文按"定义判断要件法"逐项匹配。
- 当多个选项都符合字面预判时，应换用"择优思维"比较选项与定义要件的匹配程度。
- 当概念名称含否定性字眼（如"非""无""反"）导致字面方向反转时，应补充核验否定范围，避免方向性误判。
