# 方法卡：平均分堆除以A去重

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 平均分堆除以A去重 |
| 适用题型 | 排列组合-平均分堆问题 |
| 触发场景 | 将N个不同元素平均分成若干堆（每堆数量相同），求分法数 |
| 步骤逻辑 | 1. 先用组合数依次选堆：C(n,r1)×C(n-r1,r2)×...；2. 判断各堆数量是否相同（平均分堆）；3. 若有k堆数量相同，则除以A(k,k)去重；4. 例：2222分四堆→除以A44；222分三堆→除以A33；221分三堆→只除以A22（只有两组相同） |
| 高频错因 | 忘去除重因子导致结果偏大；分不清该除A几几（只除相同堆数的排列，非总堆数） |
| confidence | high |

## 有序与无序边界

- 各堆对应不同人、不同位置或不同标签时，堆之间有区别，按题意选取后不再除以 `A(k,k)`。
- 只有同大小的堆彼此无区别时，才对这部分堆的交换除重。

## 不适用条件

- 各堆分给不同的人或放入有标签的位置（堆有序，不需除以 A(k,k) 去重）
- 元素不全相异（存在相同元素时，组合数的计算前提不成立）
- 非平均分堆（各堆数量不同，只需在相同堆数的部分去重）

## 反向触发

- 当结果明显大于选项时，优先检查是否漏去除重因子
- 当堆的大小不完全相同（如 221 分三堆）时，只对相同大小的堆去重，不应对所有堆除以 A(k,k)
- 当题目条件暗示堆有顺序（如分配到指定位置）时，应跳过去重步骤
