# 方法卡：年均增速末比初代替法

| 字段 | 内容 |
|------|------|
| 方法名 | 年均增速末比初代替法 |
| 适用题型 | 资料分析-比较多个年均增速大小 |
| 触发场景 | 多个指标的年均增速需要排序比较，且增长次数n相同 |
| 步骤逻辑 | 1. 确认n相同（起点终点年份一致） → 2. 用末期值÷初期值代替年均增速比较 → 3. 末比初越大，年均增速越大 |
| 高频错因 | 不知道n相同时可以用末比初代替，逐个算年均增长率浪费时间 |
| confidence | high |

补充说明：原理是 年均增速 = (末/初)^(1/n) - 1，n相同时单调性与末/初一致。只需算现期÷基期即可比较排序。

## 不适用条件

- 各指标的起止年份不一致（n不相同）时，不能直接用末比初代替
- 题目要求求出年均增速的具体数值（而非仅比较大小）
- 初期值为负数或接近零时，比值法失去意义

## 反向触发

- 当候选年均增速对应的末初比非常接近、近似结果不足以区分选项时，应改用精确开方或代入验证
- 题目要求计算年均增速的具体百分比值时，应直接用年均增速公式
- 当存在初期值为负或初期值接近零的情况时，比值比较不可靠，应换用其他判断方式
