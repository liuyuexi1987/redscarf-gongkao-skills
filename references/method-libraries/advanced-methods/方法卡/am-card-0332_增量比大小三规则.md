# 方法卡：增量比大小三规则

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 增量比大小三规则 |
| 适用题型 | 资料分析 - 增量（增长量）比较 |
| 触发场景 | 需要比较多个部分的增量大小，如贡献率最低/最高的选择题 |
| 步骤逻辑 | 1. **B大R大则X大**：基数B大且增速R大 → 增量X一定更大（与增速大小无关）；2. **一大一小看倍数**：一个B大R小、另一个B小R大 → 分别算B的倍数和R的倍数，倍数更大的那个X更大；3. **两倍时看B**：B和R的倍数相同（如都是2倍）→ 基数B更大的X更大；4. 实操：先排除明显不符合的选项，再用倍数关系二选一 |
| 高频错因 | ①一大一小时只看增速不看倍数 ②混淆"增量大"和"增速大" ③没意识到B的决定性更强 |
| confidence | high |

## 不适用条件

- 所有选项的基数B和增速R均相近，无法用倍数关系区分
- 需要精确计算增量数值而非仅比较大小
- 题目涉及百分比口径的增长率，数值差异极小

## 反向触发

- 当B和R的倍数关系都相同时，应改用直接计算或有效数字法辅助判断，不可硬套规则
- 当混淆"增量大"和"增速大"导致排序异常时，应回到公式 X=B×R 重新确认
- 当题目要求算出具体增量值时，三规则不适用，应直接用增长量公式计算
