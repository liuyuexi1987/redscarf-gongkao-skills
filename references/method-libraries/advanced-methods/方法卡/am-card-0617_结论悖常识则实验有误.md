# 方法卡：结论悖常识则实验有误

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 结论悖常识则实验有误 |
| 适用题型 | 判断推理——削弱/质疑（结论明显违反常识） |
| 触发场景 | 实验结论如"努力完全没有意义""能力只由基因决定"等明显违背常识 |
| 步骤逻辑 | ① 结论有悖常识 → 100%实验做错了；② 往选项中找实验本身的问题（测量方式、样本选取等）；③ 与实验无关的选项（如讲个体心理偏差）直接排除 |
| 高频错因 | 被选项的"看起来相关"迷惑（如"能力差的个体会低估练习时间"与实验本身无关）；选了讨论基因但未质疑实验方案的选项 |
| confidence | high |

## 补充说明

实验中若代理测量指标受被试共享的固有属性（如遗传决定的生理特征）影响，则结果相同不能直接推出能力相同。另需警惕共因：两组结果相同可能源于共同的其他因素（如测量方式天花板效应），而非能力无差异。

## 不适用条件

- 结论虽反直觉但符合逻辑、不违背常识时，不适用本法。
- 题干未给实验、仅给纯演绎或定义判断时，无法质疑"实验本身"。
- 选项中无针对实验方案（测量方式、样本选取、变量控制）的项时，本法的选项定位失效。

## 反向触发

- 结论不悖常识但存在断点时，改用"断点拆桥法"或"支持题断点搭桥"。
- 结论含绝对化逻辑关联词时，改用"严谨逻辑关系质疑法"找A且非B反例。
- 选项指向另有他因而非实验缺陷时，转用"另有他因/他因削弱"方法。
