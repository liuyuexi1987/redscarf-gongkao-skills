# 方法卡：解释矛盾正能量优先

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 解释矛盾正能量优先 |
| 适用题型 | 判断推理-解释说明类题目（涉及人言行不一致的矛盾现象） |
| 触发场景 | 题干出现"大多数人表示支持X，但实际使用X的比例很低"等人言行不一的矛盾现象 |
| 步骤逻辑 | 1. 解释矛盾时，优先选择"表里如一""心口一致"的解释；2. 不选把人解释为"嘴上说一套实际做一套"的选项（这种解释力度低于正能量解释）；3. 例如：74%赞成购买国产化妆品，但70%没有自用 → 优先选"买了但用来送人"（表里如一），不选"就是嘴上说说实际不买" |
| 高频错因 | 选了"口是心非"类解释，看似能解释但不是最优解忽略选项同时需要解释"为什么说支持"和"为什么没自用"两个方面 |
| confidence | high |

## 不适用条件

1. 矛盾现象不涉及人的言行一致性，而是客观事件之间的矛盾
2. 正能量解释在逻辑上无法同时解释矛盾的两个方面
3. 题干中存在明确的欺诈或利益冲突证据，"口是心非"才是唯一合理解释

## 反向触发

1. 题干出现"大多数人表示支持X，但实际使用/购买X的比例很低"
2. 矛盾涉及人的表态与行为不一致
3. 选项包含"买了但另作他用""说支持但另有原因"等表里如一的解释
