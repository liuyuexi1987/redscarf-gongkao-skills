# 方法卡：鸡兔同笼假设法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 鸡兔同笼假设法 |
| 适用题型 | 数量关系——两类对象系数不同的总量问题 |
| 触发场景 | 两类对象，乘的系数不同，知道总量和总乘积 |
| 步骤逻辑 | ① 假设全都是系数小的那一类（如全是鸡/2只脚）；② 算假设情况下的总乘积；③ 用实际总乘积减去假设总乘积，得差值；④ 差值÷单个差额=另一类的数量（如差值÷2=兔子数） |
| 高频错因 | ① 假设方向搞反（应假设系数小的，更容易算）；② 差额算错（应是两类系数之差） |
| confidence | high |

## 补充说明

鸡兔同笼本质是方程的简化版。适用条件：两个对象、两个不同的乘积系数、知道总数和总乘积。常见应用结构包括"完好件+破损件"按不同单价结算、"折扣件+原价件"利润对账等两类对象系数不同的总量问题。

## 不适用条件

- 涉及三类及以上对象、各自系数不同（无法用二元假设法直接求解）。
- 仅知道总量和一类对象的系数，缺少另一类系数或总乘积。
- 总量或总乘积本身需要先经多步推导才能确定，且推导过程已超出假设法适用范围。

## 反向触发

- 当对象类别数超过两类时，应改用多元方程组求解。
- 当两类对象系数相同（无差额可利用）时，假设法失效，应改用普通方程或比例法。
- 当题干只给出比值而非总数和总乘积时，应改用比例和份数法还原。
