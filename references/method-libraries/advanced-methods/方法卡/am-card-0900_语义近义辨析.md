# 方法卡：语义近义辨析

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 语义近义辨析 |
| 适用题型 | 判断推理——类比推理·语义关系 |
| 触发场景 | 题干给出两个词，选项要求找关系最相似的一组 |
| 步骤逻辑 | ① 判断题干两词是近义、反义还是其他语义关系；② 排除明显不符的选项；③ 多个选项都是近义时，做二级辨析（程度递进/褒贬色彩） |
| 高频错因 | ① 看着像但描述方面不同（如"昙花一现"侧重时间短，"惊鸿一瞥"侧重点是印象深刻）；② 忽略二级辨析 |
| confidence | high |

## 补充说明

类比语义题核心是"描述的方面/侧重点"必须一致。成语题高频考点，平时需多积累成语含义。

## 不适用条件

- 题干两词不是近义/反义等语义关系（如全异、组成关系）时，本方法不适用。
- 选项中无任何一组与题干语义关系一致时，本方法不适用。
- 题干是成语拆分结构（前后字独立分析）时，应换用拆字近义法。

## 反向触发

- 当多个选项均为近义词需进一步区分时，应补用二级辨析·程度递进。
- 当选项中含明显贬义词提示情感色彩差异时，应补用二级辨析·褒贬色彩。
- 当题干是成语拆字结构时，应换用拆字近义法。
