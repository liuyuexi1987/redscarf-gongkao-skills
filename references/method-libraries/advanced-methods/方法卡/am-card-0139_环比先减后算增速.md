# 方法卡：环比先减后算增速

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 环比先减后算增速 |
| 适用题型 | 资料分析·已知累积量求环比趋势 |
| 触发场景 | 题干给1-2月、1-3月、1-4月等累积数据，问各月环比增速趋势 |
| 步骤逻辑 | 1. 累积相减得出每月数值（如3月=1-3月-1-2月） 2. 用相邻月份数值算环比增速（如4月环比=4月值/3月值-1） 3. 比较各月环比增速的方向（上升/下降）判断趋势 |
| 高频错因 | 只减出每月数值就直接比大小，忘记还要再算环比增速；把同比混入环比 |
| confidence | high |

## 补充说明

典型场景：从累积数据减出每月值后，需进一步算环比增速而非直接比较绝对量。月值高不代表增速高——必须用相邻月份数值算增速再比较。正确率较低，高错因是停在"减出每月数值"就比大小，没有继续算环比增速。另外注意：混合增长率只能用于同比，不能用于环比。

## 不适用条件

1. 当题目直接给出每月独立数据（非累积形式）时，无需先减后算，直接算环比即可
2. 当题目问的是同比增速而非环比增速时，不要套用此法
3. 当只有两个时期的数据时，不存在趋势比较，直接算一次环比即可

## 反向触发

1. 当累积数据中混入了不规则的统计口径调整（如新增/剔除某些样本）时，直接相减可能失真，应先确认数据口径
2. 当题目要求的是累计同比增速而非单月环比时，应换用同比计算法
