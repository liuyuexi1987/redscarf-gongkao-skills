# 方法卡：并列结构抓共性概括法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 并列结构抓共性概括法 |
| 适用题型 | 中心理解/标题拟定——文段含两个及以上并列分论点 |
| 触发场景 | 文段明显分为两个并列部分（用"另一个""也造成了""并"等连接），问主旨或标题；两部分内容差异大但有共同目标/共同危害/共同作用 |
| 步骤逻辑 | ① 识别并列结构（分号、并列连词、相同句式）；② 找两部分的共性——共同目标（都为了培育职业农民）、共同危害（都造成生物多样性丧失）、共同作用（都促进跨境传播）；③ 用共性作为主旨概括；④ 错误选项=只对应其中一个并列部分的片面表述 |
| 高频错因 | 选了只对应其中一个并列部分的片面选项；不会抽象共性，纠结于对策的具体细节无法概括 |
| confidence | high |

## 补充说明

并列对策概括技巧：当两方面对策的具体内容差异很大时（如"花钱培育"vs"制定标准配套监测"），不要试图概括对策本身，而是找它们的共同目标/意义。用目的/意义来统摄两方面对策，比试图概括对策内容更高效。

## 不适用条件

- 文段实际为递进、转折或因果结构，仅表面用并列连词连接时
- 两个并列部分的主题完全不同，不存在可提取的共性时，应分别概括而非强行求同
- 题目要求选"文段重点"且文段有一个并列部分明显比另一个更重要时，应选重点部分而非共性概括

## 反向触发

- 当选项中存在一个同时涵盖两个并列部分但侧重不均的表述时，不应选共性概括，应优先选侧重主要部分的选项
- 当两个并列部分的共性过于宽泛（如"都有好处"）导致无法区分选项时，应回到文段细节，用排除法筛掉只对应一个部分的片面选项
- 当文段并列部分之间存在隐含的因果或递进关系时，"共性概括"可能掩盖真正的逻辑主线，应重新判断文段结构类型
