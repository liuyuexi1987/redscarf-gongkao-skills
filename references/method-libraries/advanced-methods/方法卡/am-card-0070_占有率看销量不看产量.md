# 方法卡：占有率看销量不看产量

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 占有率看销量不看产量 |
| 适用题型 | 资料分析 - 市场占有率相关概念辨析 |
| 触发场景 | 题目问"市场占有率"，材料同时给出产量和销量数据 |
| 步骤逻辑 | 1. 市场占有率 = 该产品销量 / 全行业总销量；2. 不能用产量代替销量；3. 理由：产量大但卖不出去不构成实际市场占有 |
| 高频错因 | 看到"占有率"就拿产量去算；把产量和销量数据混用 |
| confidence | high |

## 不适用条件

- 材料只给出产量数据且无销量数据可换算时，本方法无法直接应用，需看题目是否允许用产量近似或需另找数据。
- 题目问的不是"市场占有率"而是"产能占比""产量份额"等与产量直接相关的指标时，应按题意用产量。
- 占有率的分母（全行业总销量）无法从材料中获得时，无法完成计算。

## 反向触发

- 题目给出的是"产量占有率"或"产能占比"而非"市场占有率"，此时产量可能是正确分母/分子。
- 材料仅提供产量而题目问的是产量排名或产量份额，不涉及销量概念。
- 题目问的是同比增长率或环比增长率，与占有率计算无关。
