# 方法卡：容斥画图方程法
## 基本信息
| 字段 | 值 |
|------|-----|
| 方法名 | 容斥画图方程法 |
| 适用题型 | 数量关系-容斥问题（三集合） |
| 触发场景 | 看到多类交叉分组（如选甲乙丙项目），求只选某一项的人数 |
| 步骤逻辑 | 1. 画三圈韦恩图，从中间（三集合交集）向外填已知数；2. 根据两两交集减去三交集，填入各重叠区；3. 设未知数表示缺失的交集；4. 利用总人数列方程求解；5. 由各圈总数减去重叠区，得只选一项的人数 |
| 高频错因 | 容斥公式中三交集被多减一次后忘加回；只选一项与含交集的总数混淆 |
| confidence | high |
## 补充说明
三集合容斥公式：A+B+C - 两两交集之和 + 三交集 = 总数。画图法优势：直观标记每块区域的人数，不易出错。关键：先填三交集（最中间），再填两两交集的"纯重叠"部分（两交集数减三交集数），最后用各集合总数反推只属于该集合的人数。设未知数时优先设题目未直接给出的交集。

## 不适用条件
- 集合数量超过三个，韦恩图画图和标注过于复杂，宜改用公式法
- 仅涉及两集合且已知全部交集信息，直接用两集合公式更简洁
- 题目未给出任何交集信息且无法通过总人数方程推导，缺少列方程条件

## 反向触发
- 看到"只选A""既A又B""只参加一项"等交叉分组描述
- 题目给出三类集合的各自总数和总人数，但缺少部分交集数据
- 出现"至少参加两项""三项都参加"等需要反推各区域人数的问法
