# 方法卡：混合靠大（混合平均趋近法则）

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 混合靠大（混合平均趋近法则） |
| 适用题型 | 资料分析——混合平均与比重混合判断 |
| 触发场景 | 两组或多组数据按数量、频次或基期量加权混合，需要判断混合值的范围、靠近方向或阈值关系 |
| 步骤逻辑 | 1. 先确认各组平均值及其权重；2. 混合值位于各组平均值的最小值与最大值之间；3. 两组混合时，权重较大的一组对结果影响更大，混合值更靠近该组平均值；4. 多组混合不能只看单个最大权重，必要时合并同侧权重或直接列加权平均式验证 |
| 高频错因 | 误认为混合后是简单算术平均，忽略了权重差异不知道"靠近大的"这个结论，逐项精算浪费时间搞反了"分母"指的是哪个量 |
| confidence | medium |

## 不适用条件

- 各组权重/分母未知或无法估算时，无法判断"谁大"
- 混合后要求精确值或多组权重关系复杂时，仅凭靠近方向不够，应使用加权平均公式
- 非加权平均场景（如几何平均、调和平均）不适用

## 反向触发

- 若题目未给出各组的数量/频次/权重信息，先标记待核验
- 若某些组位于阈值上方、另一些位于阈值下方，不能只看最大单组权重，应比较加权贡献
- 若需精确计算混合后的具体数值，改用加权平均公式
