# 方法卡：整体占比求值法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 整体占比求值法 |
| 适用题型 | 资料分析-比重/占比计算 |
| 触发场景 | 题目给出"部分值"和"占整体的比重"，要求求整体值 |
| 步骤逻辑 | 识别部分值和对应占比 -> 整体 = 部分 ÷ 占比 -> 简化除法估算 |
| 高频错因 | 搞反分子分母，把整体÷占比写成占比÷整体；找错部分值对应哪个占比 |
| confidence | high |

## 不适用条件

1. 题目给出的是增速或增长率而非具体部分值时，不能直接用部分÷占比求整体，需先还原为具体数值。
2. 占比本身为待求未知量（而非已知条件）时，本方法不适用，需先求占比。
3. 题目给出多个部分和多个不同占比但未一一对应时，需先确认部分值与占比的对应关系再计算。

## 反向触发

1. 当题目要求的是已知整体和占比求部分值时，应改用"整体×占比"的正向计算。
2. 若题目涉及的是两期比重比较（本期占比 vs 上期占比），应切换为比重差公式。
3. 估算误差可能跨越选项时改用精算，用精确除法求整体值。
