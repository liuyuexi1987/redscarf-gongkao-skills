# 方法卡：等距离平均速度（调和平均数）

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 等距离平均速度（调和平均数） |
| 适用题型 | 行程问题·往返/等距离 |
| 触发场景 | 两段等距离路程，速度不同，求整体平均速度 |
| 步骤逻辑 | 1. 公式：V平均 = 2V₁V₂ ÷ (V₁+V₂)；2. 速记数字：10-12-15 / 12-15-20 / 15-20-30（任意三个连续满足调和关系）；3. 调和平均数 < 算术平均数（除非V₁=V₂）；4. 验证方法：速度的倒数是等差数列；5. 公式记忆技巧：结果是速度单位 → 上面是速度的平方（V×V），下面是速度之和（V+V） |
| 高频错因 | 公式记反（上面加下面乘） |
| confidence | high |
| 反向触发 | 题目问的是总路程或总时间而非平均速度，不需要套调和平均数公式；两段路程不等距但题目给了路程比值，需要加权平均而非调和平均 |
| 不适用条件 | 两人相向相遇或同向追及：这类题看速度和/速度差，读 `am-card-1157_相遇追及基础公式卡.md`。；两段路程不相等时，不能直接套等距离调和平均数。 |

## 不适用条件

- 两人相向相遇或同向追及：这类题看速度和/速度差，读 `am-card-1157_相遇追及基础公式卡.md`。
- 两段路程不相等时，不能直接套等距离调和平均数。

## 补充说明

往返问题一定构成等距离（去的路回来再走一遍），直接用调和平均数
