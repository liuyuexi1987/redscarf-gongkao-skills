# 方法卡：比较题要说两边

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 比较题要说两边 |
| 适用题型 | 削弱/质疑题中的比较类结论（逻辑判断） |
| 触发场景 | 题干结论包含比较判断（如"没有提高""比之前更低""有所下降"），但只给了一侧数据 |
| 步骤逻辑 | 1. 识别结论是否在做比较："没有提高""没有增长""有所下降"等均含比较义；2. 检查题干是否给出了两侧数据（现状 vs 过去/对照组）；3. 若只给了现状 -> 最佳削弱是补充"过去更差"的信息；4. 若两个角度都击中，力度更强 |
| 高频错因 | 忽略"没有提高"是比较判断，只关注单侧数据；没有意识到题干缺少对照组这个逻辑漏洞 |
| confidence | high |
| 不适用条件 | - 结论是绝对水平判断（如"产量很高""达到目标"），不含比较义
- 题干已同时给出现状和历史/对照组数据，逻辑断点不在缺对照
- 问法是"以下哪项最能支持"而非削弱，补对照信息属于加强而非削弱 |
| 反向触发 | - 题干结论已给出对比双方数据，无需补充任何一侧信息
- 题目问"最能支持"且结论本身是比较类，此时应选加强两方关系的选项而非削弱 |

> **使用边界**：本方法用于提供优先检查方向，不可单独据此作答；最终需回到题干关系、原文证据或选项条件完成验证。
