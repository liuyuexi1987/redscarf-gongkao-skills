# 方法卡：假设分配法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 假设分配法 |
| 适用题型 | 资料分析-增量计算/基期计算 |
| 触发场景 | 需要精确计算增量或基期，份数法不够精确时 |
| 步骤逻辑 | 1.先取基期的一部分（如取整百），乘以增率算出第一轮增量；2.看剩余部分，再取一部分乘以增率算第二轮增量；3.累加增量直到逼近目标值；4.增量合计即为结果，基期=现期-增量 |
| 高频错因 | 分配轮次不够导致精度不足；取值不整导致计算反而变慢 |
| confidence | high |

## 不适用条件
- 增长率很小且简单近似已足以区分选项时，拆分分配反而更慢
- 要求精确到个位且选项数值非常接近——累加轮次不够时精度不足，不如直接除法
- 题目给出现期值和增长率但未给基期且选项差值大——直接估算即可，无需逐轮分配

## 反向触发
- 增长率为负且题目求的是下降量——分配法需处理减法累加，不如直接用基期乘下降率
- 题目给的是基期和增长率求现期——直接乘法即可，无需分配拆解
- 增长率可以精确转化为整数比（如50%=1/2）——份数法更简洁，无需假设分配

## 补充说明

本质是把复杂的除法拆成多次简单乘法累加。每次取值尽量取整（整百、整十），降低心算难度。本集用此法计算7月份增量（13.5%增率），先分200×10%=27，再分30×13%≈4，增量≈31，快速判断超过3万吨。相比直接精算，此法更灵活。
