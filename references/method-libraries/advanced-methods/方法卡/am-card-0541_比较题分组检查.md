# 方法卡：比较题分组检查

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 比较题分组检查 |
| 适用题型 | 削弱/加强题中的比较型选项（逻辑判断） |
| 触发场景 | 题干做了A和B的比较，选项中的分组维度必须与题干比较维度一致 |
| 步骤逻辑 | 1. 识别题干在比较什么（如"海洋vs陆地""冬天vs其他季节"）；2. 检查选项的分组维度是否与题干一致；3. 若分组维度不一致，直接排除；4. 若选项讨论的主体不是题干主体，属于主体不一致，排除 |
| 高频错因 | 看到选项提到了相关内容就选，不检查分组维度是否对齐；把某主体的结论强行套到题干主体上 |
| confidence | high |
| 不适用条件 | 题干未做A与B的比较（如只是单组因果论证或类比论证），选项不需要分组维度对齐时，本法不适用；选项本身是比较型但比较的维度题干未涉及（如题干比时间维度，选项比地域维度），此时不是分组维度不一致的问题，而是无关项 |
| 反向触发 | 分组维度检查通过但选项仍无法排除时，需进一步分析选项的因果方向是否与题干一致（另有方法处理）；题干结论依赖统计显著性或样本量而非分组比较时，本法无法判断选项力度，应转用精算或验证数据 |
