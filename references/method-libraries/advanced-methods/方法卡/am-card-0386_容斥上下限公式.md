# 方法卡：容斥上下限公式

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 容斥上下限公式 |
| 适用题型 | 容斥问题（两类分类标准交叉求交集人数区间） |
| 触发场景 | 题目给出两个不同分类标准的占比，求交集的人数介于什么区间；识别标志是"按年龄分"和"按功能分"等不同标准 |
| 步骤逻辑 | 1. 设两个占比为 A 和 B（A < B）；2. 上限 = min(A, B) = A；3. 下限 = A + B - 1（若为负数则下限为0）；4. 交集人数 = 总人数 × 占比区间；5. 人数必须为整数，有小数则向上取整（因为是下限） |
| 高频错因 | 把累计结余当期结余算；人数算出小数后忘记向上取整 |
| confidence | medium |

## 补充说明

容斥上下限公式的核心是：两个占比A和B的交集，上限取min(A,B)，下限取A+B-1（负数时取0）。实际应用时，用总人数乘以占比区间得到交集人数范围。特别注意：人数必须为整数，算出小数时下限向上取整（因为问的是"至少"）。此公式适用于只有两个分类标准交叉的情况。

## 不适用条件

- 三个或以上分类标准交叉的容斥问题，二元公式不直接适用
- 题目明确要求精确值而非区间范围时，此公式只给出上下限
- 占比数据本身不精确（如"约""左右"），公式结果的精度参考意义有限

## 反向触发

- 当算出的下限大于上限时，说明数据或理解有误，应重新检查题意
- 当题目给出的是具体人数而非占比时，直接用集合运算比套公式更直观
- 当交集上下限区间仍覆盖多个选项、无法形成有效排除时，需寻找额外约束条件
