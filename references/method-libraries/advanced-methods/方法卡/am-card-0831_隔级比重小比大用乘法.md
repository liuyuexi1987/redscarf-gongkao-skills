# 方法卡：隔级比重-小比大用乘法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 隔级比重-小比大用乘法 |
| 适用题型 | 资料分析——三层嵌套结构中求最小层占最大层的比重 |
| 触发场景 | 数据分三层（如GDP→二产→制造业，或全行业→信息技术→电子商务），求最内层占最外层的比重；材料只给小比中和中比大两个占比 |
| 步骤逻辑 | ① 理清三层关系（小、中、大）；② 小比大 = 小比中 × 中比大（乘法约掉中间层）；③ 如2021年"制造业占GDP比重35.8%"为小比大，"二产占GDP比重44.5%"为中比大，求制造业占二产=35.8/44.5 |
| 高频错因 | 没理清三层嵌套关系，用错数据年份（如用12年的占比代替21年）；直接用小的数据除以中的数据但没考虑年份 |
| confidence | medium |

## 补充说明

三层嵌套结构中，做题时先确认谁是大层、中层、小层，再决定用乘法（小比大 = 小比中 × 中比大）还是除法还原。注意时间对齐——不同年份的占比不能混用。

## 不适用条件

- 数据不是三层嵌套而是两层（只有部分/整体）时，直接用比重公式，不需要乘法约中间层。
- 两个占比来自不同年份或不同统计口径时，不能直接相乘，需先对齐时间。

## 反向触发

- 题目只涉及两层结构且直接给出了小比大，不需要中间步骤。
- 材料给出的是绝对量而非比重，应先算比重再判断关系。
