# 方法卡：替代比较法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 替代比较法 |
| 适用题型 | 资料分析-多个增速排序/找最大增速 |
| 触发场景 | 已知多个指标的增量和现期值，需比较它们的增速大小，但不需求精确值 |
| 步骤逻辑 | 令q=增量/现期，则增速r=q/(1-q)；在基期、现期为正且口径一致时，该变换单调递增，因此按q排序与按r排序一致；可用增量÷现期直接排序，但不能把q当作精确增速值 |
| 高频错因 | 把增量/现期当成精确增速；不同对象口径或正负方向不一致时仍机械排序 |
| confidence | high |

## 不适用条件

1. 题目要求精确计算增速值时，不能用增量÷现期替代，必须用增量÷基期（现期-增量）。
2. 各对象的现期、增量口径不一致，或基期不为正时，不能直接利用单调变换排序。
3. 涉及下降量时先统一增量正负定义，并验证q<1及基期为正，再判断能否比较。

## 反向触发

1. 当输入口径或增量正负定义不确定时，应改用精确公式逐项核对。
2. 若需要求具体增速值（如"增速约为多少"），必须放弃替代法，改用精确计算。
3. 估算误差可能跨越选项时改用精算，用增量÷（现期-增量）得到精确增速。
