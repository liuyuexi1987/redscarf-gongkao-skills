# 方法卡：结构相似题四步法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 结构相似题四步法 |
| 适用题型 | 判断推理——结构相似题 |
| 触发场景 | "以下哪项与题干推理方式/论证方式最为类似"类题目 |
| 步骤逻辑 | ① 直接对比：最简单，直接比对ABC位置；② 确定方向：注意"只有才""除非否则"等条件句的方向（A是B的必要条件=B推A）；③ 调整位置：注意因果前后是否颠倒；④ 变成人话：把生活化语言翻译成逻辑语言 |
| 高频错因 | ① "只有才"方向搞反→整题全错；② 大小前提搞混→大前提一般是大概念；③ 没讲"所有""有的"时默认是"所有" |
| confidence | high |

## 不适用条件

1. 题干与选项结构差异明显无需对比时。
2. 非结构相似类题目（如直接逻辑推断题）时。
3. 题干为简单命题无复合句式时。

## 反向触发

1. 当直接对比无法定位差异时，应换用逻辑符号化翻译。
2. 当条件句方向判断后仍无法排除时，应补充验证选项的大小前提对应。
3. 当四步法均无法收敛时，应核验是否需换用论证结构分析。
