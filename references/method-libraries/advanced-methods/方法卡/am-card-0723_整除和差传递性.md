# 方法卡：整除和差传递性

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 整除和差传递性 |
| 适用题型 | 判断某数是否为某因子的倍数，涉及多个部分之和/差的整除关系 |
| 触发场景 | 已知整体和部分都是某数的倍数，或需要通过"和与差"推导整除关系 |
| 步骤逻辑 | 1. 若 A 是 d 的倍数，B 也是 d 的倍数；2. 则 A + B 和 A - B 都是 d 的倍数；3. 原理：A = d×N，B = d×M → A+B = d(N+M)，A-B = d(N-M) |
| 高频错因 | 只考虑单个数的整除性，忽略"和/差也是倍数"的传递性质 |
| confidence | medium |

## 补充说明

- 应用要点：当整体与某一部分均为同一因子的倍数时，剩余部分也必为该因子的倍数，可用于锁定未知部分的取值。
- 此性质是整除问题的第二个常考点，常与"分数占比整除特性"配合使用。

## 不适用条件

- 各部分并非同一因子的倍数，和差传递性不成立。
- 涉及乘除混合运算而非加减关系，传递性不适用于乘除场景。

## 反向触发

- 当仅知单一部分为某因子倍数而整体未知时，应先用"分数占比整除特性"补全整体关系再判断。
- 当和差关系涉及非整数运算（如带余除法）时，应改用列方程取模分析。
