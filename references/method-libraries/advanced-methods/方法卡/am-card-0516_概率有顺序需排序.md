# 方法卡：概率有顺序需排序
## 基本信息
| 字段 | 值 |
|------|-----|
| 方法名 | 概率有顺序需排序 |
| 适用题型 | 数量关系-概率/古典概型 |
| 触发场景 | 多次独立事件，结果组合含不同元素，求特定总金额/结果的概率 |
| 步骤逻辑 | 1.先按结果分类：相同元素（如三个100）和不同元素（如100+200+未中奖） 2.相同元素类：概率直接相乘，无需排序（三个相同元素排列还是1种） 3.不同元素类：概率相乘后再乘A(n,n)全排列（如3个不同元素→A33=6） 4.各类概率相加得总概率 |
| 高频错因 | 相同元素类错误乘以排列数；不同元素类忘记排序（如第一次中100和第二次中100是不同情况） |
| confidence | high |
## 补充说明
判断是否排序的标准：n个事件结果是否各不相同。若全相同（如三次都中100），排列数为1；若各不同（如100+200+未中），排列数为A33=6。记忆口诀：相同不排、不同要排。

## 不适用条件
1. 事件结果为连续值（如时间、长度）而非离散组合时，不适用古典概型的排列计数。
2. 各事件概率不独立（如条件概率、不放回抽样）时，概率不能直接相乘。
3. 求的是非等可能事件的概率时，不能直接用排列数÷总情况数。

## 反向触发
1. 当所有事件结果只有一种组合方式（全相同或全不同仅一种排列），无需分类讨论，直接用一个概率乘积即可。
2. 当事件数超过5且排列情况过多时，分类讨论效率下降，可考虑用组合公式或反面求解。
3. 当题目已给出概率分布表或条件概率，直接按给定条件计算，不必套用排列计数。
