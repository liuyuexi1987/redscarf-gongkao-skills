# 方法卡：正比关系识别法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 正比关系识别法 |
| 适用题型 | 数量关系·和差倍比 |
| 触发场景 | 题目出现A=B×C的关系，且其中一个量不变，求另外两个量的变化关系 |
| 步骤逻辑 | 1. 识别三个量之间满足 A=B×C 的结构（如总价=单价×数量、路程=速度×时间、工程量=效率×时间）；2. 找到哪个量不变；3. 不变量两侧的两个量成正比：B不变→A与C正比；C不变→A与B正比；4. 用比例直接推算：若C变为2倍，则A也变为2倍 |
| 高频错因 | 忽略"不变量"前提，盲目套用正比 |
| confidence | high |

## 补充说明

常见A=B×C结构：总价=单价×数量、路程=速度×时间、工程量=效率×时间、收入=售价×销量。

## 不适用条件

- 三个量都在变化，没有不变量作为锚点（正比关系无立足点）。
- 关系结构不是 A=B×C 的乘积式（如 A=B+C 的加和关系不适用正比）。
- 题目所求为反比关系（总量不变时两因子反向变化），不应误用正比。

## 反向触发

- 当总量A不变、要求两因子的反向变化时，应改用反比关系识别法。
- 当缺乏不变量、需要直接求解各自具体值时，应改用比例和份数法或赋值法。
- 当乘积结构不成立、关系为加和或差量时，应改用方程法或差倍法。
