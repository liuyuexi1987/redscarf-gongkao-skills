# 方法卡：环比增量趋势判断

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 环比增量趋势判断 |
| 适用题型 | 资料分析——判断某段时间内环比增量的变化趋势（持续上升/下降/先升后降等） |
| 触发场景 | 给出柱形图的月度数据，问第一季度环比增量是否持续上升 |
| 步骤逻辑 | ① 逐月计算环比增量：当月-上月；② 2月、3月可直接从图中读取数据相减；③ 1月的环比需跟上一年12月比——用本年12月的同比增速反推去年12月数据；④ 将各月环比增量排列，判断趋势 |
| 高频错因 | 1月环比跟谁比搞错（应跟上一年12月，不是当年2月）；求去年12月数据时除法方向搞反；忽略了环比增量的正负号（负数的增量变大也叫"上升"） |
| confidence | high |

## 补充说明

此题的难点不在于计算，而在于思路：1月份环比增量需要用同比增速反推基期。具体操作：去年12月 = 今年12月现期量 ÷ (1+同比增速)。另需注意：环比增量看的是变化趋势，负值变大（如从较大负数变为较小负数）也算"持续上升"。

## 不适用条件

- 材料未给出12月的同比增速，无法反推去年12月数据时，本方法不适用。
- 题目问的是同比增量而非环比增量时，本方法的反推逻辑不适用。

## 反向触发

- 当材料直接给出去年12月数据时，无需用同比增速反推，应直接读取计算。
- 当环比增量各月正负交替时，不能简单判断"持续上升/下降"，需补充逐月趋势核验。
