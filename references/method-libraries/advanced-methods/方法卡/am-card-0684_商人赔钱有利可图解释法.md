# 方法卡：商人赔钱有利可图解释法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 商人赔钱有利可图解释法 |
| 适用题型 | 逻辑——解释说明类（题干问"为什么某企业/商家在亏损的情况下仍然坚持某业务"） |
| 触发场景 | 题干描述某项业务持续亏损，但商家始终不放弃，问最能解释此行为的选项 |
| 步骤逻辑 | ① 核心判断：商人逐利，赔钱还做必然"有利可图"——要么能带来未来利润，要么能带动其他盈利业务；② 排除"万能解释"：如"国家规定必须做""相信未来会好"这类解释力度弱的选项；③ 最优解释：捆绑销售/交叉补贴/引流效应——该项亏损业务能为其他高利润业务带来客户 |
| 高频错因 | 选"法律规定必须做"——虽然能解释为什么不放弃，但解释力弱且生硬，不如"通过捆绑其他盈利业务"有说服力；只看到题干说的亏损业务本身，忽略了整体商业布局 |
| confidence | medium |

## 补充说明

商人逐利原则的具体表现：某项业务亏损但仍坚持，通常因为该项业务能带动其他高利润业务（如捆绑销售、交叉补贴、引流效应）。整体利益视角是关键——不要只盯亏损业务本身，要看该业务在整体商业布局中的引流/配套价值。常见解释模式：低价业务为高价业务引流、配套业务带动主营、短期亏损换取长期客户黏性。

## 不适用条件

- 题干未涉及"亏损仍坚持"的矛盾现象（业务本身盈利或亏损原因明确）。
- 业务亏损由政策性/强制性原因导致，无需解释商业动机。

## 反向触发

- 当题干要求解释的是"为何开始亏损"而非"为何仍坚持"时，应换用"用变化解释变化"方法。
- 当选项中无明显"捆绑/引流"类解释时，需补充核验是否有其他利益补偿机制（如品牌战略、数据积累）。
