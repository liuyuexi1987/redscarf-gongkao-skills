# 方法卡：预判法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 预判法 |
| 适用题型 | 逻辑填空——提高速度和准确率 |
| 触发场景 | 找到逻辑对应点后、看选项之前 |
| 步骤逻辑 | ① 找到线索，确定空格的逻辑含义；② 不看选项，自己先预判可能填什么词；③ 带着预判去看选项，找最匹配的；④ 预判不到也不要死磕，用选项反推 |
| 高频错因 | ① 预判过于具体→选项没有完全匹配的就慌了；② 预判后不质疑→选项有更好的也看不到 |
| confidence | high |

## 不适用条件
- 文段晦涩或空格处无明确逻辑对应点时，预判难度大，应直接看选项排除
- 多空题中某一空无法预判时，不要死磕，切换到其他空或选项排除
- 预判后发现选项中无匹配项时，应回到选项逐个排除而非坚持预判

## 反向触发
- 找到明确的逻辑对应点（转折、递进、因果、并列）后，在看选项前先预判空格方向
- 预判词与某选项高度吻合时，该选项更可能是正确答案

## 补充说明
预判能锻炼用词能力，做题时也会更快。但不够熟练时千万不能太绝对，要时常质疑自己的语文水平。预判不了的情况也很正常，此时回到选项逐个排除即可。
