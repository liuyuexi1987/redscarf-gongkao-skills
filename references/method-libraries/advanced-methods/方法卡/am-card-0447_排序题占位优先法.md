# 方法卡：排序题占位优先法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 排序题占位优先法 |
| 适用题型 | 排列排序——给出多人相对位置关系，确定最终排列 |
| 触发场景 | 题干给出多人左右/前后关系，其中某些条件占据较多位置（如间隔3人=占5个位置），需要快速定位 |
| 步骤逻辑 | ① 先处理已确定位置的元素（如"甲在最左边"）；② 剩余元素中，优先处理"占位最多"的条件（间隔越长→可能性越少→确定性越高）；③ 结合排除条件（如"戊不在最右边"）进一步缩小范围，逐步确定全部位置 |
| 高频错因 | 从最不确定的元素开始排导致反复试错；忽略附加排除条件（如"不在最右"）导致多解 |
| confidence | high |

## 补充说明

占位推导示例：多个位置中某元素固定在最左端，另一对元素间隔3人（共占5个位置），在剩余位置中只有两组可能的排列；再结合"不在最右"的排除条件，可排除其中一组，锁定唯一排列。剩余元素逐个填入即可。核心原则：占位越多的条件可能性越少，确定性越高，应优先处理。

## 不适用条件

- 题目为自由排列（无位置编号，仅靠属性分类）而非线性排列时，占位法不适用，应改用分组排除法
- 所有条件均为相对位置（如"甲在乙左边"但无固定点），没有任何确定位置或大间隔条件时，需先结合多个小条件逐步约束，不能直接套占位优先
- 题目为环形排列时，占位计算逻辑与线性排列不同，需额外考虑首尾相接

## 反向触发

- 若按占位最多条件排布后出现多种可能而无法进一步缩小范围，检查是否遗漏了"不在某位置"等隐含排除条件，补全后再试
- 若所有元素占位条件强度接近（无明显"大占位"），应改用逐个假设排除法，不再依赖占位优先策略
