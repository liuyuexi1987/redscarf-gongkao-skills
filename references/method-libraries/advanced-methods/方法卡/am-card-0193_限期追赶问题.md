# 方法卡：限期追赶问题

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 限期追赶问题 |
| 适用题型 | 资料分析——假设增量不变，求几年后A第一次超过B（追及问题） |
| 触发场景 | 题干描述"保持同比增量不变，则到哪一年X将第一次超过Y" |
| 步骤逻辑 | ① 分别求出两个对象的同比增量X1、X2（大的减小的）；② 计算增量差=每年实际追赶量=|X1-X2|③ 计算当前两对象的现期差=A_现期-B_现期；④ 所需年数=现期差/每年追赶量（向上取整）；⑤ 从现期年份加上所需年数即为答案 |
| 高频错因 | ① 增量差计算时符号搞反；② 现期差与追赶量颠倒相除；③ 向下取整而非向上取整（如差4.5每年追1，需5年而非4年） |
| confidence | high |

## 不适用条件

1. 题干假设的是增速不变而非增量不变，需要用等比增长模型
2. 材料中无法获得两个对象的同比增量
3. 题目要求的是精确到月份或季度而非整年

## 反向触发

- 题干出现"保持增量不变""哪一年第一次超过"等表述，且材料中有两个对象的现期量和同比增量

## 补充说明

词义辨析称之为"后期追赶"或"追击思维"。本质是行程问题中的追及模型移植到资料分析。此题型一旦识别可快速判断，属于高性价比题型。注意追赶量=大增量-小增量（取绝对值），年数必须向上取整。
