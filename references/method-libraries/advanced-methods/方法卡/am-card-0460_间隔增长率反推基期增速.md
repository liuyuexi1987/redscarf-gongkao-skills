# 方法卡：间隔增长率反推基期增速

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 间隔增长率反推基期增速 |
| 适用题型 | 资料分析——间隔增长率相关计算 |
| 触发场景 | 已知年均增速求间隔增长率，或三个时间节点中已知两个增长率、反推第三个；选项差距较大时可用上界排除 |
| 步骤逻辑 | 1. 由两年平均增速 r̄ 求间隔增长率：R间 = r̄ + r̄ + r̄×r̄ ≈ 2r̄ + r̄²；2. 设所求年份增速为 x，代入间隔公式：R间 = r₁ + x + r₁×x；3. 由于 x 前还加一个正数乘积项，可快速判断 x < R间 - r₁（取差值上界）；4. 根据选项范围可作为排除线索，不必精算 |
| 高频错因 | 混淆"年均增速"与"间隔增速"的含义，误认为年均=间隔忘记间隔公式中的乘积项 r₁×x，导致上界判断偏大三个时间节点没有画清，导致 r₁ 和 x 的对应关系搞反 |
| confidence | medium |

## 不适用条件

- 只有两个时间节点（如直接给出基期和现期）时，用普通增长率公式即可
- 题目要求精确值且选项差距极小时，本法上界判断不足以区分选项
- 年均增长率直接求值的题目，不需绕道间隔公式

## 反向触发

- 若无法从题干确认三个时间节点的对应关系，先画时间轴再决定
- 若选项均为精确值且差距小于 1%，本法排除力度不足，需精算
