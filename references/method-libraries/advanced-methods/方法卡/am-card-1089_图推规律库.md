# 方法卡：图推规律库

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 图推规律库 |
| 适用题型 | 判断推理——图形推理 |
| 触发场景 | 所有图形推理题（系统性知识储备） |
| 步骤逻辑 | ① 心中要有规律池：对称性/面数/笔画数/平移/叠加运算/部分数/最大最小面/曲直交点/公共边/内外图形；② 熟悉特征图：圆→可能考框内点、黑白块→平移/部分数/面数、对称→区分轴/中心、元素相同→位置变化、元素相似→样式变化；③ 逐层排除：对称→面数→笔画→叠加→部分数 |
| 高频错因 | ① 规律池不全→漏掉可能的规律；② 不认识特征图→不知道考什么 |
| confidence | high |

## 不适用条件

- 非图形推理题不使用本卡
- 题目已明确考查特定规律（如六面体折叠、截面图）时，优先使用专项卡

## 反向触发

- 若题目是立体图形（六面体、截面、三视图）而非平面规律题，不使用本卡
- 若规律池中的规律无法解释题目图形变化，应重新观察或换用其他图推卡
