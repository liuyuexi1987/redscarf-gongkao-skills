# 方法卡：乘15技巧

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 乘15技巧 |
| 适用题型 | 资料分析·涉及15倍关系的计算（如公顷转亩、1.5倍等） |
| 触发场景 | 需要把某数乘以15（如公顷转万亩=×15，或数量的1.5倍） |
| 步骤逻辑 | 1. 任何数×15 = 该数×10 + 该数×5 = 该数×10 + 该数×10÷2 2. 即：先取10倍，再加上10倍的一半 3. 例如26×15=260+130=390 |
| 高频错因 | 直接硬乘15计算慢；不会用10+5的拆分 |
| confidence | high |

## 补充说明

典型场景：万公顷转万亩需算某数×15。示例：26×10=260, 260÷2=130, 260+130=390。口算即完成。此技巧在涉及公顷→亩换算时高频出现。

## 不适用条件

1. 当乘数不是15而是其他数值（如12、18）时，此拆分法不直接适用
2. 当需要精确到小数且选项间距极小时，口算拆分的精度可能不足

## 反向触发

1. 当乘数可拆为其他更简便的组合（如×25用×100÷4）时，应选用更简便的拆分方式
2. 当计算涉及多位小数且选项间距很小时，应改用精算
