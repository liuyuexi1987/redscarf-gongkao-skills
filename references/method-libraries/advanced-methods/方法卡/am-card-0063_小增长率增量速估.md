# 方法卡：小增长率增量速估

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 小增长率增量速估 |
| 适用题型 | 资料分析-增量计算/增量比较 |
| 触发场景 | 增长率R<10%，需要快速判断增量大小或是否超过某阈值 |
| 步骤逻辑 | 1.判断增率R是否小于10%；2.若R<10%，直接用现期×R近似增量（因现期≈基期，误差可忽略）；3.快速估算结果，与阈值比较 |
| 高频错因 | 错误使用完整公式(现期-现期/(1+R))导致计算量过大，浪费时间 |
| confidence | high |

## 不适用条件

1. 用现期×R替代精确增量产生的误差可能跨越选项时，不宜使用。
2. 选项数值极为接近，要求精确到个位或小数点后一位——本法是估算，精度有限，不足以在近选项间区分。
3. 需要精确的增量值用于后续计算（如精确算增速排名、精确算比重差）时，估算结果可能在多步运算中累积误差。

## 反向触发

1. 现期×R的误差不足以由选项差距吸收时，应回到完整公式增量=现期×R/(1+R)。
2. 题目要求精确算出增量而非判断是否超阈值——估算不够，需用完整公式。
3. 基期数据直接可用（如题目或材料已给出基期）——直接用"现期-基期"比估算更精确。

## 补充说明

此方法是估算方法，适用于判断增量是否超过某阈值的场景。R越小，现期≈基期的近似越精确。当需要精确值时仍需用完整公式。本集多处使用此法（3月、4月、8月增量判断），均在R<10%时直接用现期×R。
