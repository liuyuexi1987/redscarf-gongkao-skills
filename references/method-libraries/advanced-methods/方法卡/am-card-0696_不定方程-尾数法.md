# 方法卡：不定方程-尾数法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 不定方程-尾数法 |
| 适用题型 | 不定方程中目标值有特定小数/个位数，或系数含特定尾数特征 |
| 触发场景 | 方程右边含小数（如40.6），但某些项必为整数，需通过尾数反推某变量的取值 |
| 步骤逻辑 | 1. 识别方程中哪些项必为整数，确定小数部分只能由某一项产生；2. 分析该项系数的尾数特征（如1.7乘以几尾数是6）；3. 逐步枚举可能的尾数取值（1.7x8尾数为6）；4. 结合总量限制确定最终取值 |
| 高频错因 | 没注意到整数项不可能产生小数部分，导致把所有未知数混在一起分析；尾数枚举不全或算错 |
| confidence | medium |

## 补充说明

尾数法适用于方程中某些项必为整数、而另一项系数含小数的不定方程。核心步骤：先识别哪些项必为整数（确定小数部分只能由含小数系数的项产生），再分析该系数乘以何值能得到对应尾数，从而反推该未知数的取值。确定一个未知数后，剩余方程可再用奇偶法或倍数法求解。结合总量约束（如"总数尽量多→优先满足便宜项"）可进一步锁定最终取值。

## 不适用条件

- 方程各项系数均为整数（无小数尾数特征可利用）。
- 未知数本身允许为小数（不满足整数约束，尾数分析无意义）。

## 反向触发

- 当方程无明显小数特征时，应优先尝试倍数法或奇偶性法。
- 当尾数枚举结果较多时，需结合总量约束或其他条件进一步筛选，或改用精算代入。
