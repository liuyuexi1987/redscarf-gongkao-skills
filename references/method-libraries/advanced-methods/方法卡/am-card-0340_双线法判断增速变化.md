# 方法卡：双线法判断增速变化

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 双线法判断增速变化 |
| 适用题型 | 资料分析——柱状图增速排序、"增速逐年递增"类判断 |
| 触发场景 | 需判断连续年份增速是否单调递增/递减；柱状图可读取增量（相邻柱高差）和基期 |
| 步骤逻辑 | ① 从柱状图提取每年增量X（柱高差）；② 基期B逐年递增（柱高上升）；③ 若某年X下降而B上升，则R=X/B必然下降（分子减小分母增大）；④ 该年增速一定小于前一年，即为排序突破口 |
| 高频错因 | 只看柱高上升就认为增速上升（忽略了增速=增量/基期，增量可能在缩小） |
| confidence | high |

## 补充说明

"双线"指增量线和基期线。只要两线反向（一升一降），增速必变。同向时需比较变化幅度。实战中先算增量（取三位即可），一眼扫出反向年份。

## 不适用条件

- 材料无柱状图或无法从图中读取增量（文字型材料）
- 需要精确计算增速数值而非判断趋势
- 基期或增量变化幅度极小，肉眼无法判断反向

## 反向触发

- 若双线同向（同增或同降），不能直接判断增速变化方向，需比算变化幅度，不应凭直觉下结论
- 若柱状图中某年出现断崖式变化（如异常值），应先排除数据异常再套用双线法
