# 方法卡：盐水平均数速解
## 基本信息
| 字段 | 值 |
|------|-----|
| 方法名 | 盐水平均数速解 |
| 适用题型 | 数量关系-平均数/浓度/比重混合 |
| 触发场景 | 题干出现"人均""混合成活率""混合浓度"等两组混合平均值，且给了一组单独值 |
| 步骤逻辑 | 1.识别三个值：单独值A、另一组均值B、混合均值M 2.求距离之比(M-B):(A-M)，取反得量之比 3.用量之比求各组数量 4.若有最值条件，再进入核定最值 |
| 高频错因 | 混合均值与单独值位置搞反导致距离比取反；混淆"距离之比"和"量之比"的方向关系 |
| 不适用条件 | 题干仅含单一组数据无混合过程；涉及三组及以上混合且无分步拆分条件 |
| 反向触发 | 题干出现两组混合平均值且给了其中一组单独值，立即套用距离比取反求量比 |
| confidence | high |
## 补充说明
盐水模型在数量和资料分析中都常见。数量中常见"人均多多少量/钱"，资料分析中常见"城镇人均收入/农村人均收入求城乡人数比"。可将此类题统称"盐水平均数型"，核心是距离比取反得量比。第四种类型为"增速型"（资料分析常见），其余偏向分母的比例。
