# 方法卡：比重变化趋势（部分vs整体增速）

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 比重变化趋势（部分vs整体增速） |
| 适用题型 | 资料分析——比重变化趋势判断 |
| 触发场景 | 题目问"比重比上年上升/下降"或"比重变化方向"，且材料给出部分增速和整体增速（或现期值+增量可算出增速） |
| 步骤逻辑 | 1. 部分增速 > 整体增速 → 比重上升；2. 部分增速 < 整体增速 → 比重下降；3. 材料中往往直接给出相关增速，或现期值+增量可算出增速；4. 只需比较大小，不需要精确计算比重值 |
| 高频错因 | 直接去算两年的比重再比较，浪费时间搞反部分和整体的对应关系增速的正负号搞混 |
| confidence | medium |

## 不适用条件

- 题目要求精确计算比重具体数值时，本法只判断方向，不能替代精确计算
- 材料只给出绝对量未给出增速，且无法通过现期值+增量推算增速时，本法不适用
- 比重变化涉及多层嵌套（如"某部分占部分再占整体"）时，需逐层分析，不宜直接套用

## 反向触发

- 若材料中部分增速和整体增速的正负号无法确认（如增量为负但基数方向不明），先标记待核验
- 若题目问的是"比重相差多少个百分点"而非"上升/下降"，应切换到精确比重差值计算
