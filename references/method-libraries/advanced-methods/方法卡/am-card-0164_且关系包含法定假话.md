# 方法卡：且关系包含法定假话

| 字段 | 内容 |
|------|------|
| 方法名 | 且关系包含法定假话 |
| 适用题型 | 逻辑判断——真话假话题（有复合"且"关系） |
| 触发场景 | 多人陈述中存在包含关系：一句话是A，另一句话是A且B且C（复合且），只有N人说谎 |
| 步骤逻辑 | 1. 找到最"长"的复合陈述（含且最多者） |
| | 2. 若该陈述为真→被它包含的其他陈述必然全真 |
| | 3. 若该陈述为假→则至少一个分量为假，但不导致其他陈述必假 |
| | 4. 综合"只有N人说谎"的约束→复合陈述必为假，被包含的陈述为真 |
| 高频错因 | ①忽略隐含的且关系（如"所有糖果都没了"可补"且第三人吃了"）②未识别谁的陈述范围更大/更严格 |
| confidence | high |

## 不适用条件

- 多人陈述之间无包含或重叠关系（各说各的独立事件），无法构造复合且，应改用矛盾法或假设法。
- 题目仅有两句话且构成直接矛盾（如"只有一个人说谎"），矛盾法更直接，无需构造复合陈述。

## 反向触发

- 出现"只有一个人说真话/假话"且某人陈述明显比其他人"更长/更严格"时，优先想到本方法。
- 题干中某人的话可以拆成多个独立分量时，提示构造复合且关系。

**补充说明：**
- 典型案例：明明说"我吃了"（A），强强说"我没吃"（非B），亮亮说"我和强强都没吃"（非B且非C）。因所有糖果没了，亮亮的话实际隐含"非B且非C且A"（含明明吃了）。此复合句若真→前两句必真→违背只有一人说谎→复合句必假→亮亮说谎。
- 核心技巧：善于把题干隐含条件"补"进某人的话中，构造出最严格的复合陈述，该陈述一定是说谎者。
