# 方法卡：量级与有效数字分离法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 量级与有效数字分离法 |
| 适用题型 | 资料分析——乘除法运算中简化计算 |
| 触发场景 | 需要做多步乘除法计算，选项有效数字不同但小数点位置不同 |
| 步骤逻辑 | ① 统一题目与选项单位；② 将参与乘除的数字写成“有效数字×10的幂”；③ 先用有效数字完成比较或估算，同时单独记录各次移动小数点产生的总幂次；④ 只有候选答案量级已经确定、有效数字足以区分选项时，才可先按有效数字选择 |
| 验证动作 | 把记录的总幂次还原，检查结果数量级和单位是否与选项一致 |
| 不适用条件 | 选项跨越不同数量级；加减法运算；小数点位置本身决定答案；单位尚未统一 |
| 高频错因 | 移动小数点后忘记记录补偿幂次；把乘除法技巧误用于加减法；只看有效数字而选错数量级 |
| confidence | high |
| 反向触发 | 选项前三位有效数字相同时，有效数字法不足以区分答案，需精算或换用其他估算精度更高的方法；多次乘除导致幂次记混时，应停下还原校验再继续，不要仅凭记忆选定答案 |
