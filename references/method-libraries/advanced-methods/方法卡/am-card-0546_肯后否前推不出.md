# 方法卡：肯后否前推不出——原命题只保证逆否

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 肯后否前推不出——原命题只保证逆否 |
| 适用题型 | 翻译推理题（逻辑判断） |
| 触发场景 | 题干给出"A→B"的推出关系，选项用"肯后推肯前"或"否前推否后"来干扰 |
| 步骤逻辑 | 1. 已知"A→B"为真；2. 能推出的：逆否命题"非B→非A"（否后推否前）= 必真；3. 推不出来的：逆命题"B→A"（肯后推肯前）= 不确定；4. 推不出来的：否命题"非A→非B"（否前推否后）= 不确定；5. 口诀：原命题与逆否命题等价，逆命题和否命题无法判断 |
| 高频错因 | 把"肯后推肯前"（B→A）当成正确推理把"否前推否后"（非A→非B）当成正确推理不区分"原命题""逆命题""否命题""逆否命题" |
| confidence | high |
| 不适用条件 | - 题干不涉及条件命题推理（如纯排列组合、类比推理、归纳推理）
- 题目问"以下哪项推理错误"而非"以下哪项可以推出"，需要反向识别无效推理
- 推理链涉及三段论（大前提+小前提→结论）而非单一条件命题 |
| 反向触发 | - 题目问"以下哪项推理存在谬误"，需要选定肯后推肯前或否前推否后的选项作为错误推理
- 题干给出多个条件命题形成连锁推理，需要同时运用原命题和逆否命题进行链式推导 |
