# 方法卡：假设分配法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 假设分配法 |
| 适用题型 | 基期 / 增量 / 现期 |
| 触发场景 | 已知现期量B和增长率R，求基期A或增量X，且可用简单份数或取整修正降低计算量 |
| 步骤逻辑 | 1. 将R近似为便于分配的简单比例，先分出基期和增量的大致份额；2. 用剩余部分按R继续修正，多分则减、少分则加；3. 基期与增量相加应回到现期；4. 做差题分别估算后再相减，并检查两边误差是否同向、能否抵消；5. 根据选项差距决定保留位数，必要时用原公式验证 |
| 高频错因 | 第一步分得太粗（如该分300只分200），导致第二步计算量增大且误差累积做差题中一边进位一边不进位，反而放大误差增长率极小时仍硬套分配，不如直接近似基期=现期 |
| confidence | medium |

## 补充说明

核心步骤：第一步根据增长率大小选择合适的整百分配比例（r约20%向下取整，约33%按3:1，约50%按2:1，约66%按3:2，约100%对半）；第二步用剩余部分乘以r分配，多分则减、少分则加。两个基期做差题分别做两次假设分配再相减，做差时误差自动抵消。选项离得近时保留更多位数，离得远时可粗略分配。当估算误差可能跨越选项或改变结论时，改用精算/验证。

## 不适用条件

1. 增长率无法转成便于分配的简单比例，或分配计算并不比公式更简便。
2. 选项间距极小，分配法的估算精度不足以区分答案，应转用精算。
3. 题目不涉及基期或增量求解，假设分配法无应用场景。

## 反向触发

1. 已知现期量B和增长率R，需要求基期A或增量X。
2. 选项间距适中，整百分配的精度足以确定答案。
3. 需要比较两个基期的差值，做差时假设分配的误差可自动抵消。
