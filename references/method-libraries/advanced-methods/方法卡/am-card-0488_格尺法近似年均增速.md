# 方法卡：格尺法近似年均增速

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 格尺法近似年均增速 |
| 适用题型 | 资料分析-年均增长率估算（适用4年期） |
| 触发场景 | 年均增长率在两个已知N次方数之间，需快速估算精确值 |
| 步骤逻辑 | 记住常见四次方数(5%/1.216, 10%/1.46, 15%/1.75, 20%/2.07) -> 确定目标比值落在哪两个区间 -> 将区间五等分做线性插值 -> 对应R值即为估算结果 |
| 高频错因 | 仅适用于4年期且R在5%-15%时较准；增速越大误差越大 |
| confidence | high |
| 不适用条件 | 年期不是4年（如3年、5年、10年）时不适用格尺法；年均增速处于极端低位或高位时，线性插值误差显著增大，不宜使用 |
| 反向触发 | 估算结果处于两个相邻选项的中间地带、无法明确选定答案时，应改用精算（列式开方或代入验证）；选项之间间隔极小（如差1个百分点以内）时，格尺法精度不足，应改用精算确认 |
