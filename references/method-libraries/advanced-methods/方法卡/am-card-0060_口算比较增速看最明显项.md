# 方法卡：口算比较增速看最明显项

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 口算比较增速看最明显项 |
| 适用题型 | 资料分析-增速比较/增速排序 |
| 触发场景 | 多个年份/类别的增速需要比较大小 |
| 步骤逻辑 | 1.先观察数据，找最突出的年份（增量大、基期小→增速一定高）；2.从最明显的差异入手，不需要逐年精算；3.分子最小+分母最大→分数值一定最小，反之一定最大 |
| 高频错因 | 从头到尾逐年精算，浪费时间；不先观察就动手算 |
| confidence | high |

## 不适用条件

1. 所有项的增量和基期量级都非常接近，没有明显突出项——此时"先看最明显"无法快速定位，仍需逐项估算。
2. 题目要求精确排出完整排序（如"从大到小排列"）而非仅选出最大/最小——只靠最明显项不够，中间项需要逐个比较。
3. 数据呈现为图表且刻度较粗，前几位有效数字无法准确读取时，口算判断的精度下降。

## 反向触发

1. 题目明确要求算出每个年份/类别的具体增速数值——应逐项用增速公式精算，不能只看最明显项。
2. 增量与基期的比值跨数量级（如有项是千级基期、有项是万级基期），需要先统一量级再比较，不能直接观察。
3. 选项中存在陷阱项（如增速接近但正负号不同），需逐项验证符号后再比较。

## 补充说明

增速=增量/基期。比较增速时，可先寻找“增量明显更大且基期相近”或“增量相近但基期明显更小”的项目，再用交叉乘或数量级复核。只有优势足以覆盖估算误差时才能锁定极值；中间项或接近项仍需逐项比较。
