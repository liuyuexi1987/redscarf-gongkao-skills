# 方法卡：归因题质疑三法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 归因题质疑三法 |
| 适用题型 | 判断推理——削弱类（因果论证/对比实验归因） |
| 触发场景 | 题干根据两件事同时发生就认为存在因果关系（A是因B是果），要求质疑该因果结论 |
| 步骤逻辑 | ① 确认题干是归因类（两件事同时发生，认为有因果关系）；② 三种质疑方式选一：另有他因（有其他原因导致B）、否定此因（A和B之间没有因果联系）、因果倒置（其实是B导致A，不是A导致B）；③ 若选项说明AB共同发生变化的东西不一定有因果联系，属于否定此因 |
| 高频错因 | 归因题中用"支持了结果而非因果关系"的选项来质疑（如"确实强震多发"支持了相关性但没支持因果）；把归因题和严谨逻辑题的方法混用 |
| confidence | high |
| 不适用条件 | 结论不是因果关系（如并列描述、时间先后但未断言因果），或题目要求"支持"而非"质疑"时，不套用质疑三法 |
| 反向触发 | 多种质疑方式同时出现时，需比较各选项攻击因果链的位置与力度，不能只按方法名称选择；题干已承认关联、仅讨论程度或机制时，应评估选项对具体论证环节的影响，而非机械套用三类质疑。 |
