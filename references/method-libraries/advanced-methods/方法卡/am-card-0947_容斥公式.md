# 方法卡：容斥公式 |A∪B| = |A| + |B| - |A∩B|

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 容斥公式 |A∪B| = |A| + |B| - |A∩B| |
| 适用题型 | 双集合容斥问题的标准解法 |
| 触发场景 | 已知两个集合的大小和某些关系，求总人数或重叠人数 |
| 步骤逻辑 | 1. 总人次 = |A| + |B|；2. 总人数 = 总人次 - 重叠人次（即既A又B的人被多算了一次）；3. 重叠人数 = |A| + |B| - 总人数；4. 若有n个"都不"：实际参与的总人数 = 总人数 - n |
| 高频错因 | 忘记重叠部分被重复计算；混淆"人次"和"人数" |
| confidence | high |

## 补充说明

人次≠人数，人次是各集合大小直接相加的结果，人数要去重

## 不适用条件

- 三集合及以上容斥时不适用本公式（需用三集合公式）
- 题目问"只满足A"或"只满足B"人数时，本公式只是中间步

## 反向触发

- 三集合容斥应改用三集合容斥公式
- 求"只A"或"只B"人数应在求出重叠后改用"只满足A/B"求法
