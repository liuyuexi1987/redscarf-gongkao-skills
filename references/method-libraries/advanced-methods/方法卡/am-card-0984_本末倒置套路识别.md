# 方法卡：本末倒置套路识别

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 本末倒置套路识别 |
| 适用题型 | 逻辑填空——成语辨析 |
| 触发场景 | 题目出现"根本目的""根本在于"等词，且后面有手段/做法损害了根本目的 |
| 步骤逻辑 | ① 识别根本目的（本）和手段/做法（末）；② 如果手段损害了根本目的→选"本末倒置"；③ 区分："本末倒置"强调颠倒优先级，"得不偿失"强调得失比较，"背道而驰"强调做法与初衷相反 |
| 高频错因 | ① 混淆"本末倒置"和"得不偿失"→前者是颠倒，后者是得失；② 混淆"本末倒置"和"背道而驰"→前者有根本vs枝节的关系，后者只有初衷vs做法 |
| confidence | high |

## 补充说明
"背道而驰"的触发条件：题目有"初衷""原本"等词，做法与初衷方向相反。"得不偿失"的触发条件：前面有明确的"得到"和"失去"的描述。三者区分是高频考点。

## 不适用条件

- 题目只描述做法与目标的简单矛盾，未涉及"根本/枝节"的层级关系时，不套用本末倒置识别。
- 文段强调的是结果好坏而非手段颠倒（如"得不偿失""因小失大"语境）时，本卡不适用。
- 选项中不含"本末倒置"及其近义成语时，本卡无识别对象。

## 反向触发

- 当三个成语同时出现在选项时，应换用"语境关键词反查"思路：回到题干找"初衷/原本/得到/失去/根本"等触发词，再对应排除。
- 当题干同时出现"根本目的"与"得失"两类线索时，应补一步主次判断：以更靠后的总结句为准，避免被中间句误导。
- 当"本末倒置"与"舍本逐末"同时出现时，应改用语素拆解核验：前者重在"颠倒"，后者重在"追求枝节"，不可混选。
