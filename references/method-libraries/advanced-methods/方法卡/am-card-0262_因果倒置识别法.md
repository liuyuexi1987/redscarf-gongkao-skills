# 方法卡：因果倒置识别法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 因果倒置识别法 |
| 适用题型 | 归因类论证题（支持/削弱） |
| 触发场景 | 选项出现"XX的特征""XX的表现"等暗示先患病后表现的表述 |
| 步骤逻辑 | 1. 题干结论为"A导致B"（如玩手机导致抑郁）；2. 选项出现"XX是B的特征"——特征意味着先患病后显现，即**先B后表现**；3. 若该选项中"表现"恰好是A（如逃避现实→玩手机），则因果顺序被颠倒：B先于A；4. 结论是A→B，选项暗示B→A，构成因果倒置，不能支持 |
| 高频错因 | 看到"抑郁的特征"就认为在解释因果，忽略了"特征"一词暗含的时序关系——先有病才有特征 |
| confidence | high |

## 不适用条件

1. 题干结论不是因果关系（如并列、条件、时间顺序等非因果表述）
2. 选项未出现"特征""表现""结果""症状"等暗示先B后显现的时序词汇
3. 问法为"补充前提"或"推理"，而非支持/削弱

## 反向触发

1. 选项明确描述A→B的正向因果链条，方向与题干一致
2. 题干结论中A和B是并列或相关关系，不构成因果判断
3. 选项讨论的是独立的第三方因素C，与A和B均无关
