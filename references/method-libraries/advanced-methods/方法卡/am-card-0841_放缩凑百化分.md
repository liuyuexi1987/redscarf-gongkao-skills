# 方法卡：放缩凑百化分

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 放缩凑百化分 |
| 适用题型 | 资料分析——除法估算·分母可凑成N分之一形式的题目 |
| 触发场景 | 放缩法中，分母不一定要凑整数，也可以凑成接近常用分数的数值，使除法转化为乘法 |
| 步骤逻辑 | ① 看分母接近哪个百化分值（167、143、125、111等）；② 将分母调整到百化分数值，同时按大致比例调整分子；③ 除以N分之一等于乘以N，可快速得到结果；④ 常用百化分：1/9≈111、1/8=125、1/7≈143、1/6≈167、1/4=250、1/3≈333 |
| 高频错因 | ① 记错百化分对应值（如把1/7记成142）；② 分母凑百化分后，分子调整幅度过大或方向错误；③ 只知道凑整数一种思路，遇到不好凑整的分母时束手无策 |
| confidence | high |

## 补充说明

百化分是放缩法的第二种思路。常用百化分中，111(1/9)、125(1/8)、143(1/7)、167(1/6)出现频率最高，因为资料分析中分母常为"1+增速"形式，增速多为百分之几到百分之二十几，对应分母1.0x到1.2x，正好靠近这些百化分值。不建议背1/12、1/15等两位数倒数，因为最终还要乘两位数，反而增加计算负担。

## 不适用条件

- 分母远离常见百化分值（如178、196等）且不好凑近时，本方法效率不高，建议用普通放缩凑整
- 分子调整幅度超过10%时，凑百化分带来的精度损失可能影响选答案
- 选项差距不足以容纳百化分近似误差时，应提高精度或改用直除、反代验证

## 反向触发

- 看到除法估算且分母接近111/125/143/167等百化分值 → 用本方法
- 分母是整百/整十（如200、300、500） → 不用本方法，用普通放缩凑整更直接
- 分母是"1+增速"且增速为5%/8%/10%/15%/20%等常见值 → 优先考虑百化分
