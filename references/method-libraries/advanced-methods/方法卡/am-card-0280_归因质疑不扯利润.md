# 方法卡：归因质疑不扯利润

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 归因质疑不扯利润 |
| 适用题型 | 可行性/有效性质疑题（非归因题也适用） |
| 触发场景 | 题干讨论某措施"能否达到目的"，选项从经济利益角度反驳时 |
| 步骤逻辑 | 1. 先确定题干讨论的核心问题是什么（能否达到效果 vs 是否划算）；2. 若题干问的是"能否增加乘客求生机会"（保命问题），则利润/成本类选项跑题；3. 若题干问的是"是否可行"，利润/利益角度通常不是正确答案；4. 正确选项应从"能否达到目的"的角度直接回应 |
| 高频错因 | 习惯性用"企业不愿花钱""成本太高"等经济理由做质疑，但题干讨论的是可行性而非经济性 |
| 不适用条件 | 题干本身讨论的就是经济可行性/成本效益问题时，利润类选项属于正确角度 |
| 反向触发 | 题干明确讨论"是否划算""成本是否合理"等经济性问题，利润/成本类反驳在此场景下有效 |
| confidence | high |
