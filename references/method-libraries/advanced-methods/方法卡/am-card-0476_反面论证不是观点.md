# 方法卡：反面论证是论证不是观点

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 反面论证是论证不是观点 |
| 适用题型 | 中心理解题 / 标题题 |
| 触发场景 | 文段正面说完一个观点后，用"没有……就会……""如果不……则……"等反面表述来加强论证。选项内容仅对应反面论证部分。 |
| 步骤逻辑 | 1. 识别反面论证结构：正面说好 → 反面说不好会怎样（正反对比论证同一观点）；2. 反面论证的作用是**论证前面的观点**，它本身不是文段重点；3. 如果选项只出现在反面论证区域 → 该选项**出处有误**；4. 反面论证带出的危害/后果有多个时，选其中一个还会**片面**；5. 正确答案应回到正面观点或对策 |
| 高频错因 | 把反面论证的内容当成文段主旨选项只对应反面论证中的某一个危害，既出处有误又片面 |
| confidence | high |

## 不适用条件

1. 反面论证部分包含了对策或建议（如"不这样做就会……所以应该……"），而正面部分仅为意义描述，此时反面论证中的对策可能就是主旨。
2. 文段没有正面观点，仅通过反面论证引出问题（如"如果继续忽视……将导致……"），反面论证的后果描述即为主旨铺垫，后续对策才是主旨。
3. 文段正面观点和反面论证属于并列关系（非论证-被论证关系），两者同等重要，不能仅排除反面部分。

## 反向触发

1. 当选项同时涉及正面观点和反面论证的补充说明时，需判断哪个是核心、哪个是支撑，不能仅凭"出处在反面"就排除。
2. 正面观点表述过于宽泛或模糊，而反面论证更具体地指向了问题和对策时，反面论证区域的选项可能更贴近文段落脚点。
3. 题目问的是"文段意在强调"且文段结尾落在反面论证的严重后果上，此时结尾落脚点可能是作者真正强调的重点。
