# 方法卡：语境对应分析法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 语境对应分析法 |
| 适用题型 | 逻辑填空——语境关系（对应） |
| 触发场景 | 题目中空格前后有明显的语义呼应词（同义复现、反义对照、因果呼应），但没有显式关联词 |
| 步骤逻辑 | ① 找空格前后的"呼应词"——与空格词语义相同、相反或因果相关的词；② 如果呼应词与空格同向→选与呼应词语义相近的词；③ 如果呼应词与空格反向→选与呼应词语义相反的词；④ 验证：代入后是否与呼应词构成合理的语义照应 |
| 高频错因 | ① 找不到呼应词，凭感觉选；② 把弱对应（话题相关）当成强对应（语义等价），选了过于具体的词 |
| confidence | high |

## 补充说明
对应关系是逻辑填空中最隐性的语境信号。呼应词可能在空格的前一句、后一句甚至段首。核心技巧：先确定空格处需要什么方向的词（正面/负面/中性），再在选项中找匹配项。"协同发展和单打独斗"就是典型的反义对应。

## 不适用条件
- 空格前后找不到任何呼应词，无语义呼应信号可供判断方向。
- 题目以纯语法搭配为核心考点，不存在语义对应关系。
- 文段过长且呼应关系跨段落，单凭对应分析无法稳定定位呼应词。

## 反向触发
- 当呼应关系不明确或为弱对应时，应换用语境解释对应法寻找显式解释信号（冒号、破折号、"即"等）。
- 当选项间差异在搭配而非语义方向时，需补充搭配验证选词法进行二次筛选。
- 当语境方向难以判断时，应换用感情色彩匹配法或词义轻重排序法辅助定位。
