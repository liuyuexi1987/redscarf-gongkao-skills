# 方法卡：有对策优先抓对策

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 有对策优先抓对策 |
| 适用题型 | 言语理解-中心理解题（说理类文段） |
| 触发场景 | 文段中同时出现"问题描述"和"对策描述"时 |
| 步骤逻辑 | 1. 判断文段是否有对策表述（如"因此""应该""要"等关键词）2. 有对策时，主旨优先选对策形式的选项 3. 排除形式上就不是对策的选项 4. 只从对策选项中比较筛选 |
| 高频错因 | 纠结于问题表述的选项，忽略对策优先级更高 |
| confidence | high |

## 补充说明

核心逻辑：说理类文段中，对策表述（祈使句、"要""应""应有之义"等）的优先级高于问题表述和客观事实描述。当选项形式上不对策时可直接排除，大幅缩减判断范围。同时需注意：对策不能无中生有，必须能在文段中找到支撑依据。

## 不适用条件
1. 当文段为纯并列结构（多个事实并列、无主次之分）时，不存在"对策优先"
2. 当文段为因果论证结构（A导致B）且无对策表述时，主旨应选因果关系选项

## 反向触发
1. 当文段同时含对策和因果论证时，应先判断论证类型再选方法
2. 当所有选项都是对策形式时，需比较对策的具体程度和文段支撑度，不能直接选
