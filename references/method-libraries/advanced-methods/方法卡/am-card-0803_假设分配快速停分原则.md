# 方法卡：假设分配快速停分原则

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 假设分配快速停分原则 |
| 适用题型 | 资料分析——假设分配法的效率优化 |
| 触发场景 | 假设分配第一步完成后余数很小（个位数），需判断是否继续细分 |
| 步骤逻辑 | ① 完成第一轮假设分配并记录余数；② 估计省略余数会给结果带来的最大偏差；③ 将偏差与相邻选项间距比较；④ 偏差不足以改变选项时可停止细分，否则继续分配或转精算 |
| 高频错因 | 只看余数位数就决定停算，没有估计其对最终结果的影响；选项接近时仍省略修正；为追求无意义的末位精度反复细分 |
| confidence | medium |
| 不适用条件 | 省略余数产生的误差可能跨越选项；题目要求精确值；当前分配无法给出可靠的误差方向或上界 |
| 反向触发 | 相邻选项差值落在估算误差范围内时改用精算；余数对目标量的影响仍明显时继续拆分；若换一个假设值能显著减少余数，可重新选取锚点 |

## 补充说明

假设分配不必追求每一步都算到末位，停止标准是“当前误差是否仍可能改变选项”。只有在误差上界小于选项安全间距时才能停算；不能仅凭余数看起来较小就跳过验证。
