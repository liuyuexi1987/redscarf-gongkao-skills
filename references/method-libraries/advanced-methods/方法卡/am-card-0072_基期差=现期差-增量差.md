# 方法卡：基期差=现期差-增量差

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 基期差=现期差-增量差 |
| 适用题型 | 资料分析 - 基期差值计算 |
| 触发场景 | 题目求两个量的基期差值，且选项差距较大（如几千以上），不必精确到个位 |
| 步骤逻辑 | 1. 计算现期差 B1-B2；2. 分别估算两个量的增量 X1、X2（可粗估）；3. 基期差 = (B1-B2) - (X1-X2)；4. 若选项差很大，先算现期差即可判断方向，无需继续 |
| 高频错因 | 直接拿基期分别列式再相减，浪费时间且容易出错；不注意增速大小关系导致增量差方向搞反 |
| confidence | high |

## 不适用条件

- 选项差距极小（如个位数级别差异），粗估增量差不足以区分答案时，需精确计算每个基期量再相减。
- 两个量单位或量纲不同，无法直接做差时，不适用本公式。
- 题目求的不是两个量的基期差值，而是单个量的基期值或基期比重等其他指标。

## 反向触发

- 题目直接给出了两个量的基期值或基期增速，可直接算出基期量，无需用"现期差-增量差"间接求。
- 题目要求精确到个位且选项非常接近，粗估增量差无法区分。
- 只有一个量需要求基期，不存在"差值"的计算前提。
