# 方法卡：反推法验证选项

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 反推法验证选项 |
| 适用题型 | 标题拟定、中心理解 |
| 触发场景 | 纠结于两个选项，无法通过正面分析判断哪个更对 |
| 步骤逻辑 | 1. 拿起一个纠结的选项，假设它是标题/主旨；2. 反推：如果原文真是这个主旨，作者应该怎么写？会写哪些内容？；3. 对比反推出来的内容和实际原文，是否吻合；4. 若反推内容与原文大方向不一致（如选项是科普式概括但原文是说理式指出问题），则排除该选项 |
| 高频错因 | 不做反推就选了"看起来也对"的选项；忽略文段类型和选项类型的匹配关系 |
| confidence | medium |

## 补充说明

- 反推法的核心是"假设选项为主旨→逆推作者写法→与原文比对"，本质上是用选项反验文段类型与行文方向是否匹配
- 反推时必须关注文段类型与选项类型的匹配：科普式概括不应匹配说理式指出问题的原文，反之亦然

## 不适用条件

- 文段主旨明确、正面分析即可确定答案时，无需使用反推法（避免增加判断环节）
- 选项之间存在明显硬伤（无中生有、偷换概念等）时，应先用排错法排除，不必反推

## 反向触发

- 当反推内容与原文部分吻合但部分偏离时，应换用首句主题词+整体结构分析核验，而非强行取舍
- 当两个选项反推后都与原文方向吻合时，应回到选项覆盖面比较（概括全文 vs 对应分句），而非继续反推
