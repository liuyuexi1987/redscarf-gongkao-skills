# 方法卡：首句主题词必抓

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 首句主题词必抓 |
| 适用题型 | 中心理解、标题拟定、下文推断、语句填入 |
| 触发场景 | 排除两个选项后在剩余选项中纠结；选项看起来都对但覆盖面不同 |
| 步骤逻辑 | 1. 读首句，圈出概括全文的核心话题词（主语/关键词）；2. 正确选项必须体现该主题词；3. 选项中没有主题词的直接排除，无论它表述多"高级"；4. 多个选项含主题词时，比较覆盖面：概括全文 > 对应某一分句 |
| 高频错因 | 被尾句细节带跑偏，选了不含主题词的选项；选项用了"高大上"词汇（如"色彩文化""社会发展"）就以为有高度，实际比原文范围大或小 |
| confidence | medium |

## 补充说明

- 首句主题词决定选项范围：正确选项必须体现该主题词，没有主题词的选项直接排除
- 多个选项含主题词时，比较覆盖面：概括全文 > 对应某一分句
- 注意"高大上"词汇陷阱：选项用"色彩文化""社会发展"等大词不等于有高度，实际可能比原文范围大或小

## 不适用条件

- 文段首句为例子、引子或背景描述（非全文话题引入）时，首句主题词可能不是全文主题词，本方法不适用
- 文段为主题句在中部或尾部的结构时，应换用对策定位法或结构分析法

## 反向触发

- 当所有选项都不含首句主题词时，应重新核验首句是否为话题引入句，可能主题词在第二句或尾句
- 当多个选项都含主题词但覆盖面相近时，应换用整体结构分析或反推法区分主次
