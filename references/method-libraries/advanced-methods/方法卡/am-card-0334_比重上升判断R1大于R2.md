# 方法卡：比重上升判断R1>R2

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 比重上升判断R1>R2 |
| 适用题型 | 资料分析 - 比重变化判断 |
| 触发场景 | 问"占比/比重提高的地区有几个"或"哪一年占比上升"——不需要算比重差，只需比较增速 |
| 步骤逻辑 | 1. 占比重提高 → 部分增速(R1) > 整体增速(R2)；2. 先口算或估算整体增速R2（取位除法，如387÷1020≈38%）；3. 逐一比较各部分增速与R2，大于R2的即为"提高"；4. 计数即可得出答案 |
| 高频错因 | ①直接算比重再比较（浪费时间）②整体增速算错导致全部判错 ③混淆"提高"和"最高" |
| confidence | high |

## 不适用条件

- 题目要求计算比重上升/下降的具体百分点数值
- R1与R2非常接近，需要精确计算才能判断方向
- 题目问的是"比重最高"而非"比重提高"

## 反向触发

- R1与R2的大小关系仍可准确判断升降；若题目要求具体变化幅度，再用比重差公式计算
- 当整体增速R2估算错误时会导致所有判断连锁出错，应在比较前先验证R2的合理性
- 当题目问"哪一年比重最高"时，不应使用增速比较法，应直接计算各年比重
