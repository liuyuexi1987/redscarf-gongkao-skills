# 方法卡：引号高频词不是答案标志

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 引号高频词不是答案标志 |
| 适用题型 | 片段阅读-中心理解题 |
| 触发场景 | 文段或选项中出现引号标注的词，容易误认为是答案 |
| 步骤逻辑 | 1. 引号里的词只是修辞手法，不是答案标志；2. 不能看到引号就选含该词的选项；3. 重点看文段反复出现的高频主体词，而非引号词；4. 高频反复出现的词 > 引号词 > 首次出现的词 |
| 高频错因 | 看到引号就选，忽略了文段真正的高频主体 |
| confidence | medium |

## 不适用条件

1. 引号词本身是文段的高频主体词，且在非引号位置也多次出现，此时引号词和高频主体重合，不能因有引号就反向排除。
2. 题目明确问"这个词的含义是什么"或"这个词指代什么"，引号词本身就是考察对象。
3. 引号词是文段提出的新概念或核心话题，文段围绕该词展开论述，它就是答案主体。

## 反向触发

1. 如果引号词是高频主体且出现在非引号位置，优先用主体一致性排除法验证选项。
2. 如果多个选项都包含引号词，需比较哪个选项与文段整体内容匹配，不能只看关键词匹配。
3. 如果引号词出现在转折后或对策句中，需结合转折强弱判断法或前对策结构抓对策法判断其重要性。
