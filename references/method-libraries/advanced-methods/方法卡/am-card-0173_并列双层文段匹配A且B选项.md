# 方法卡：并列双层文段匹配A且B选项

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 并列双层文段匹配A且B选项 |
| 适用题型 | 言语理解——片段阅读主旨题（A且B结构选项） |
| 触发场景 | 选项呈现"A且B"结构（同时提及两个方面），文段前后恰好分两层，各对应A和B |
| 步骤逻辑 | ① 看到A且B结构的选项，回文将文段分成两层；② 检查前半部分是否正好对应A、后半部分是否正好对应B；③ 两层要"严丝合缝"对应，不能字面对应但语义跑偏；④ 如果文段确实分两层且分别语义对应A和B，则该选项正确 |
| 不适用条件 | 文段不是前后双层结构（如大并列三段以上、因果结构）；A且B选项与文段仅字面对应但语义不匹配 |
| 高频错因 | 只看字面有对应词就选，不验证语义是否匹配；把文段中提及但非重点的词当成对应 |
| confidence | high |
| 反向触发 | 文段虽分两层但其中一层为背景铺垫或过渡而非独立论点时，A且B选项应排除；文段实际分三层及以上而选项仅覆盖其中两层时，该选项概括不全需换用全面覆盖的选项 |


> **使用边界**：本方法用于提供优先检查方向，不可单独据此作答；最终需回到题干关系、原文证据或选项条件完成验证。
