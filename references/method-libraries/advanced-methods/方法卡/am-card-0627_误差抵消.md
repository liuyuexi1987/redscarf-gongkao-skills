# 方法卡：误差抵消

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 误差抵消 |
| 适用题型 | 资料分析——乘法估算时需要控制精度 |
| 触发场景 | 拆分法计算过程中，某一步估大/估小了，需要在另一步反向调整 |
| 步骤逻辑 | ① 某步估大了（如把2.8%当成3%），下一步就让对应乘数稍小（如6.28当6）；② 此消彼长，乘积基本不变；③ 边算边看选项，能选出来就停 |
| 高频错因 | 两步都往同一方向偏差；过度追求精度浪费时间 |
| confidence | medium |
| 不适用条件 | 1. 选项间距极小，估算误差可能跨越选项时改用精算
| 反向触发 | 1. 拆分乘法时两步都往同一方向偏差（如都估大），说明未掌握误差抵消，应改用分步精算
2. 看不出哪个乘数应反向调整时，改用直接计算
3. 当拆分后的两个乘数均为精确值、不需要估算时，直接乘即可，无需误差抵消 |
2. 乘法中只有一个有效乘数需要估算时，没有另一侧可做反向调整
3. 题目要求精确计算结果而非估算时不用本方法 |

## 补充说明

误差抵消的核心：乘法中一个乘数估大、另一个估小，乘积误差会相互抵消。关键是要"胆大心细"——大胆估算，同时有意识地反向调整。99%的题选项间距足够大，微小误差不影响选答案。
