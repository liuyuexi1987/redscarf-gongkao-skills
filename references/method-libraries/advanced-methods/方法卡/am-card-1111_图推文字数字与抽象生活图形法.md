# 方法卡：图推文字数字与抽象生活图形法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 图推文字数字与抽象生活图形法 |
| 适用题型 | 判断推理——图形推理 |
| 触发场景 | 图形中出现汉字、英文字母、数字、或抽象的生活化图形（如乐器、动物、日用品等） |
| 步骤逻辑 | ① 识别文字/数字类型：汉字 → 英文字母 → 数字 → 抽象生活图形；② 汉字的优先级：面数量（汉字的封闭区域数）→ 笔画数（汉字的笔画总数）→ 对称性（汉字是否轴对称/中心对称）→ 结构（左右/上下/包围结构）→ 部分数；③ 英文字母/数字的优先级：对称性（哪些字母/数字是轴对称/中心对称）→ 封闭区域数（如A有1个、B有2个）→ 笔画数 → 曲直性（含曲线/纯直线）；④ 抽象生活图形的优先级：部分数（最常考）→ 面数量 → 对称性 → 笔画数；⑤ 抽象生活图形信息量有限，能考的规律也有限，面数量和部分数是最常见的考点 |
| 高频错因 | ① 汉字题看到汉字就头疼，不知道从哪入手，忽略面数量这个最简单的考点；② 英文字母/数字题忽略对称性（如A是轴对称、N是中心对称）；③ 抽象生活图形题试图数边数（边数有争议），不如直接数面数量和部分数；④ 不区分不同文字/数字类型的考点差异，用同一套思路做所有文字题 |
| confidence | high |

## 补充说明

**汉字的触发逻辑：** 当图形中出现汉字时，触发此判断。汉字的信息量比普通图形丰富，能考的规律也更多。最常见考点是面数量（汉字的封闭区域数），如"口"有1个面、"日"有2个面、"目"有3个面。其次是笔画数和对称性。汉字的结构（左右/上下/包围）也是考点之一。

**英文字母/数字的触发逻辑：** 当图形中出现英文字母或数字时，触发此判断。英文字母只有26个、数字只有10个，结构比汉字简单。最常见考点是对称性（哪些是轴对称、哪些是中心对称、哪些两者兼具）。其次是封闭区域数（如A有1个、B有2个、8有2个）。

**抽象生活图形的触发逻辑：** 当图形由乐器、动物、日用品等生活化图形组成时，触发此判断。这类图形的边数往往有争议（到底算几条边），所以边数不是好考点。最常考的是面数量和部分数，其次是笔画数和对称性。

**与已有卡的关系：** am-card-1020（生活化图形规律优先级）侧重生活化图形的具体分析方法，本卡侧重特征触发判断。两者配合使用：本卡负责识别特征，1020负责具体分析。

## 不适用条件

1. 图形为普通几何图形（非文字/数字/生活图形）时（应改用1121数量规律分层排查法）
2. 文字、数字或生活图形只是载体，而黑白阴影的位置、数量或运算关系能连续解释时。
3. 文字含义或生活语义与规律无关，实际考查圆形、线条、对称或其他几何属性时。

## 反向触发

1. 汉字面数量验证无果时，应补充核验笔画数和对称性
2. 英文字母/数字对称性验证无果时，应补充核验封闭区域数和曲直性
3. 抽象生活图形面数量和部分数无规律时，应换用1122局部规律系统遍历法

## 输出要求

- 看到文字/数字/生活图形特征时，先说明触发的是哪种类型
- 汉字优先验证面数量，再验证笔画数和对称性
- 英文字母/数字优先验证对称性，再验证封闭区域数
- 抽象生活图形优先验证面数量和部分数
- 与 am-card-1020 配合使用
