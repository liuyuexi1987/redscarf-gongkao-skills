# 方法卡：假设分配法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 假设分配法 |
| 适用题型 | 资料分析——求基期值和增量（已知现期B和增长率R） |
| 触发场景 | 需要同时估算 `B÷(1+R)` 的基期值和增长量，且可选取便于心算的基期锚点 |
| 步骤逻辑 | ① 本质：假设分配是直除的变形，底层逻辑相同；② 第一步：选一个比B稍小的整百数作为假设基期A₁（如B=645选A₁=600）；③ 计算假设增量：X₁ = A₁ × R（如600×5.6%=33.6，可近似写34）；④ 计算剩余：剩余 = B - (A₁+X₁)（如645-634=11）；⑤ 第二步分配剩余：剩余很小时可近似把剩余都给基期份额，得A和X |
| 高频错因 | 第一步选数不当（选太小导致需要多步）；第二步不会调节，导致误差偏大 |
| confidence | medium |

## 补充说明

假设分配的核心优势是同时得到基期和增长量。第二步能否简化，不看余数位数本身，而看省略后的误差是否会改变选项。

## 不适用条件

- 无法选出接近真实基期且便于计算的锚点。
- 选项接近，剩余分配误差可能跨越选项。

## 反向触发

- 第一轮余数仍显著影响结果时继续分配或改用直除。
- 需要精确值时，用公式或反乘验证，不以“余数较小”作为停算依据。
