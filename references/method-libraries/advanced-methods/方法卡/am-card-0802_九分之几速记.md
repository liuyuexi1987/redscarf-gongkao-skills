# 方法卡：九分之几速记

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 九分之几速记 |
| 适用题型 | 资料分析——百化分/四幺五/假设分配 |
| 触发场景 | 题目增长率在11.1%、22.2%、33.3%、44.4%等附近，需快速判断对应分数 |
| 步骤逻辑 | ① 九分之一 = 11.1%，九分之二 = 22.2%，依此类推；② 三分之一 = 33.3%（特记）；③ 九分之七 = 77.7%，九分之八 = 88.8%；④ 反向应用：看到11.1%→1/9，看到22.2%→2/9 |
| 高频错因 | 把11.1%误认为1/10（应为1/9）；九分之几的分子搞错（22.2%是2/9不是1/4.5） |
| confidence | medium |
| 不适用条件 | 1. 增长率不在九分之几附近（如九分之一、九分之二对应的简单分数），应使用其他百化分或截位法
| 反向触发 | 1. 增长率偏离九分之一的整数倍较远——放弃九分之几速记，改用精算
2. 题目问的是增长量且已知基期——直接用X=AR公式，无需百分数转分数
3. 材料已直接给出增长率数值——无需反向推断分数形式 |
2. 题目要求精算而非近似判断——速记精度不足
3. 题目考查的是分数大小比较而非百分数转换 |

## 补充说明

除九分之几外，还需额外记住：十一分之一 = 9.1%（唯一一个需要记的"小于九分之一"的数，用于增长率约-9.1%时的四幺五）。配合常用百化分：1/7≈14.3%、1/6≈16.6%、1/4=25%、1/3≈33.3%、1/2=50%。
