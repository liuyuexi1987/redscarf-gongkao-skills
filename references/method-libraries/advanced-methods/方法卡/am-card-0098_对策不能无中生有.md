# 方法卡：对策不能无中生有

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 对策不能无中生有 |
| 适用题型 | 中心理解题、标题填入题 |
| 触发场景 | 选项中出现对策表述，但对策的具体措施在文段中找不到支撑 |
| 步骤逻辑 | 1. 识别选项中的对策表述（祈使句、动宾短语、必要条件等）；2. 回到文段中寻找该对策的具体支撑；3. 如果文段完全没有提到该措施（如"出台规范""立法""树立法规"），则属于无中生有；4. 对策必须从文中问题直接推导，不能添加外部信息；5. 对策只能"傻瓜式"地重复问题本身，不加任何延伸 |
| 高频错因 | 觉得选项的对策"听起来合理"就选了自己脑补文中没有的信息来支持对策对策和问题不对应（问题讲抄袭，对策讲出台规范） |
| confidence | high |

## 不适用条件

1. 文段中虽未直接提到对策的字面表述，但问题本身已隐含对策方向（如"缺乏监管"隐含"加强监管"），此时可合理推导
2. 题目考查的是"文段意在强调"的概括能力，选项是对文意的归纳而非对策，此卡不适用

## 反向触发

1. 所有选项都是对策表述，需要判断哪个对策与问题最对应，而非判断对策是否无中生有
2. 文段本身就在列举多项对策，选项是对策的归纳总结，不存在"无中生有"
