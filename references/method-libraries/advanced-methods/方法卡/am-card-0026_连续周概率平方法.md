# 方法卡：连续周概率平方法
## 基本信息
| 字段 | 值 |
|------|-----|
| 方法名 | 连续周概率平方法 |
| 适用题型 | 数量关系-概率（连续时间段内重复事件） |
| 触发场景 | 问"连续两周""连续N次"恰好都能发生的概率，且每周/每次独立 |
| 步骤逻辑 | 1.先求单周概率P 2.连续两周概率=P的平方 3.找选项中P²的表达式快速锁定 |
| 高频错因 | 用组合公式过度计算；不识别"连续"暗示独立重复 |
| confidence | high |
## 补充说明
示例：小李选4天、小王选2天，单周相遇概率=4/5×3/4=3/5，两周概率=(3/5)²=9/25。排除判断时直接在选项中找"几分之几的平方"，排除非平方项即可大幅缩小范围。

## 不适用条件
- 各次事件之间不独立，如前一周的结果影响后一周的概率分布
- 题目要求的是"至少连续N次"而非"恰好连续N次"，涉及更复杂的概率模型
- 单周概率本身难以计算或依赖多个条件组合，平方操作意义不大

## 反向触发
- 看到"连续两周""连续N次""每次都"等表述，暗示各次独立，联合概率为幂次
- 已算出单周概率P，选项中出现P²、P³等平方/立方表达式
- 题目问"恰好都能发生"而非"至少一次"，适合直接乘方
