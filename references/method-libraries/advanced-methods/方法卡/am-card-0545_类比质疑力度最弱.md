# 方法卡：类比质疑力度最弱

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 类比质疑力度最弱 |
| 适用题型 | 削弱/质疑题（逻辑判断） |
| 触发场景 | 选项用动物实验或类比推理来质疑题干结论，需要判断力度强弱 |
| 步骤逻辑 | 1. 识别选项是否为类比推理（用动物/他物来类比人/此物）；2. 类比天然有瑕疵——动物跟人不能完全等价；3. 在"最不能质疑"题目中，类比质疑往往就是正确答案（力度最弱的那个）；4. 在普通质疑题中，若只有类比选项可用则仍需选择，但有原理性质疑时优先选原理 |
| 高频错因 | 看到"最不能质疑"就选"完全无关"的，忽略题目问的是"不能质疑"而非"无关"不了解类比质疑力度最弱这一判断标准 |
| confidence | high |
| 不适用条件 | - 题目问"以下哪项最能质疑/削弱"而非"最不能质疑"，此时类比质疑不应作为首选排除
- 选项不是类比推理而是直接针对因果机制或统计方法的质疑
- 题干结论本身就是关于类比关系的有效性（如"动物实验能否推广到人类"） |
| 反向触发 | - 题目问"以下哪项最能质疑"，选项中出现类比推理时，该选项应作为力度较弱的排除项（与本卡方向相反）
- 题目问"最能支持"且有类比选项，类比支持力度也相对有限但不应直接排除 |

## 补充说明

第11题核心技巧。A用恒河猴类比人类，是类比质疑→力度最弱→最不能质疑选A。BCD从原理层面质疑（其他染色体可替代、单性繁殖可行、回文结构可自我修复），力度均强于类比。
