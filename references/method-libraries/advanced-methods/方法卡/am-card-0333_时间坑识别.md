# 方法卡：时间坑识别（上年末vs同比）

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 时间坑识别（上年末vs同比） |
| 适用题型 | 资料分析 - 综合分析题、直接查找题 |
| 触发场景 | 材料数据标注"比上年末"但题目问"同比"，或材料是累计期但题目问某月 |
| 步骤逻辑 | 1. 圈出材料中每个数据的时间基准（上年末=去年12月末，同比=去年同期末）；2. 圈出题目问的时间点；3. 对比两者是否一致，不一致则该选项可能错；4. 典型坑：材料给"比上年末（2020年12月末）"，题目问"同比（2020年2月末）"→ 时间不匹配 |
| 高频错因 | ①看到"上年"就认为是同比 ②忽略"末"字 ③审题时只看数字不看时间 |
| confidence | high |

## 不适用条件

- 材料和题目使用同一时间基准（如同为"上年末"或同为"同比"）
- 题目明确标注了与材料一致的时间点
- 材料中每个数据的时间基准已逐一标注且无歧义

## 反向触发

- 当时间基准已确认一致但答案仍不合理时，应检查是否找错了数据行或列，而非继续纠结时间
- 当"比上年末"和"同比"同时出现在同一选项中时，应分别对应不同的数据源，不可混用
- 当材料使用累计期数据但题目问单月时，应换用差值法（本期累计-上期累计）而非直接引用
