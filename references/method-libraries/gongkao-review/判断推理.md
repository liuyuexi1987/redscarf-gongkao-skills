# 判断推理综述校验

## 使用边界

用于判断推理主卡之后的分类与结论复核。不同子题型使用不同证据，不把“看起来像”当成共同方法。

## 分题型检查

| 题型 | 优先动作 | 结论验证 | 反向检查 |
|---|---|---|---|
| 图形推理 | 记录可见事实，再按整体、属性、数量、位置、样式、空间逐层排查 | 候选规律覆盖全部已知图，并能区分唯一选项 | 缺图、图像不清或多个规律都成立时不硬判；不能只找“都有线/都有圆”这类弱共性 |
| 定义判断 | 拆出主体、对象、行为、目的、条件和结果等必要要件 | 逐项核对是否满足全部关键要件 | 题目考已有法律、经济等知识时应转常识判断；不能因选项符合日常理解就忽略题干定义 |
| 类比推理 | 先定一级关系，再比较主体类别、功能、材料、顺序等二级属性 | 前后词对关系方向和层级保持一致 | 只共享一个表面联系不足以构成同构关系 |
| 翻译推理 | 准确翻译充分、必要、且、或等逻辑关系 | 使用逆否、矛盾或真值约束验证，不做无效逆推 | 肯定后件、否定前件通常不能推出确定结论 |
| 分析推理 | 把全部条件结构化，优先使用确定条件和限制最强条件 | 最终安排满足全部条件且无漏项 | 局部可行不等于整体可行，条件不能只验证一部分 |
| 削弱加强 | 先找论点、论据和推理缺口，再判断选项作用位置 | 选项是否真正改变论证成立程度，并比较作用强弱 | 相关背景、重复论点或只谈论据细节不当然构成加强削弱 |
| 前提假设 | 找论据到论点之间不可缺少的连接 | 否定选项后，论证是否难以成立 | 能加强不等于必要前提，额外充分条件也未必是必需条件 |
| 归纳推断 | 只使用题干明确给出的事实和范围 | 选项是否能由题干推出，且没有扩大范围或强化程度 | 不补常识、不添因果、不把可能改成必然 |

## 统一结论前复核

1. 是否先识别了对象和关系，而不是先看选项印象？
2. 当前规则是否覆盖题干全部条件，而非只解释局部？
3. 排除项的失败点能否用具体条件指出？
4. 客观可验证题是否完成唯一性或代入验证？
