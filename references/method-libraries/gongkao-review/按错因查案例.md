# 按错因查案例

本页不存放真实题目，只提供错因检索线索。正式归因仍需结合当前题证据和专项错因卡。

| 可观察表现 | 需要核对的证据 | 可选错因 | 下次动作 |
|---|---|---|---|
| 一开始就用了不匹配的公式或题型方法 | 问法、核心条件、方法适用条件 | 题型识别错误 / 公式模型错误 | 先写题型和变量含义，再调用主卡 |
| 公式正确但取错年份、主体或单位 | 取数位置、单位换算、题干限定 | 审题定位错误 | 圈出时间、主体、单位、问法后取数 |
| 言语选项相关但没有覆盖核心关系 | 文段结构、核心话题、选项范围 | 局部概括 / 选项偷换 / 逻辑关系误判 | 用主体、话题、范围、程度、关系逐项核对 |
| 逻辑填空某个空顺眼但整组不成立 | 每个空的语境、搭配和词义 | 搭配误判 / 词义误判 / 多空验证缺失 | 从证据最强的空缩小组合，再全句代回 |
| 判断推理只验证了部分条件 | 条件清单、排除步骤、唯一性 | 条件遗漏 / 验证缺失 | 将每个条件对应到候选答案并逐项勾选 |
| 数量题列式正确但答案偏离 | 中间计算、符号、单位和近似过程 | 计算错误 / 精度错误 | 保留关键中间量并反算或回代 |
| 排列组合结果重复或漏项 | 分类标准是否互斥、是否覆盖全部状态 | 分类遗漏或重复 | 先定分类标准，再检查互斥与完备 |
| 图推规律能解释部分图但不能唯一选项 | 全部已知图、候选规律、选项验证 | 条件遗漏 / 规律过拟合 | 用全部图验证，并检查是否只剩唯一选项 |
| 用户未说明思路，只给了错误选项 | 选项差异能否唯一反推出错误步骤 | 低置信候选错因 | 明示“按选项差异推测”，不要写成确定事实 |
| 题面或答案仍有冲突 | 完整题干、选项、答案页和 OCR 可靠性 | 暂停归因 | 先完成答案核验，不写错因卡 |

错误标签只是检索入口。若证据同时支持多个标签，优先选择最早发生、最能指导下次动作的那个。
