# 数量关系综述校验

## 使用边界

用于数量关系主卡后的方法选择和结果复核。具体公式、模型和技巧以题型协议及已读取主卡为准。

## 题型与方法选择

| 题型 | 先看什么 | 可选路径 | 不得机械套用 |
|---|---|---|---|
| 工程问题 | 总量、效率、时间及合作关系 | 整体赋值、效率赋值、方程 | 人数增加不代表效率按人数等比例增加，除非题干给出同效条件 |
| 行程问题 | 路程、速度、时间、方向和相遇/追及关系 | 画图、比例、方程、相对速度 | 往返平均速度、相遇和追及公式不能跨场景混用 |
| 经济利润 | 成本、售价、利润、利润率的基准量 | 列表赋值、方程、比例 | 折扣率、利润率、增长率的分母不同，不能只看百分数相加减 |
| 排列组合 | 是否有序、是否分步、是否分类、是否重复 | 分类分步、捆绑、插空、反面计数 | 分类之间不互斥会重复，分步遗漏条件会漏计 |
| 概率 | 样本空间是否等可能、事件是否独立 | 有利数/总数、分类概率、对立事件 | 非等可能情形不能直接数个数，相关事件不能相乘 |
| 几何 | 长度、面积、体积及相似关系 | 公式、相似比、割补、坐标 | 长度比、面积比、体积比的幂次不能混用 |
| 最值/容斥/构造 | 至少、至多、恰好以及集合重叠 | 极端构造、容斥、反向求补 | 只满足总量而破坏局部限制的构造无效 |
| 和差倍比/年龄 | 未知量关系和时间变化 | 方程、比例、代入 | 年龄差不变但年龄倍数会变，不能沿用静态倍数 |

## 方法触发原则

- **代入**：选项数量有限且代入成本低，或题干要求满足离散约束时使用。
- **赋值**：题目只给比例、效率或相对关系，绝对量不影响结论时使用。
- **方程**：未知量关系明确、约束可以稳定翻译为等式或不等式时使用。
- **枚举**：状态有限且能证明覆盖完整、没有重复时使用。
- **特性排除**：题干能推出整除、奇偶、尾数或范围约束时使用，不能因选项外观整齐而启用。

## 结论前复核

1. 单位是否统一，时间和速率是否对应同一尺度。
2. 结果是否满足正数、整数、人数、概率区间等题目边界。
3. 整除、奇偶、大小关系和极端情形是否与答案一致。
4. 把结果代回原条件，所有约束是否同时成立。
5. 若使用近似，误差是否影响选项判断。
