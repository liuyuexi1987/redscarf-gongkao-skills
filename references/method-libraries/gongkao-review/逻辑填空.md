# 逻辑填空综述校验

## 使用边界

用于逻辑填空主卡和词义辨析笔记之后的整题复核。词语辨析笔记只作辅助，不替代语境判断；没有官方或已核验答案时只给方法倾向。

## 五步检查

1. **语境关系**：识别解释、对应、转折、递进、并列、因果或反向关系，确认空格承接哪一侧。
2. **词义约束**：比较词语的核心义、适用对象和动作方向，先排除词义与语境冲突项。
3. **搭配验证**：检查主谓、动宾、偏正、固定搭配及关联词组合，避免只看词义相近。
4. **色彩与程度**：核对褒贬、中性、语体、轻重和范围是否匹配。
5. **多空一致性**：从证据最清楚的空缩小组合，再把全部选项代回通读，确认各空共同成立。

## 常见反向检查

| 情形 | 应做检查 | 不得这样处理 |
|---|---|---|
| 出现陌生词 | 读取词义辨析资源，并利用其他空、搭配和语境交叉验证 | 仅因陌生就降低该选项优先级 |
| 两词都能搭配 | 比较词义侧重、对象、程度和上下文呼应 | 只凭“读起来顺”确定答案 |
| 一个空很确定 | 用它缩小组合，再验证其余空 | 用单空确定感覆盖其他空的明显冲突 |
| 出现转折或对照 | 明确空格位于哪一侧，判断前后语义方向 | 看到转折词就默认只取后半句字面词 |
| 成语字面相关 | 核对完整含义、使用对象和感情色彩 | 只抓成语中的某个字与题干对应 |

## 结论前复核

- 每个空是否都能指出明确语境证据？
- 词义、搭配、感情色彩和程度是否同时成立？
- 若选项差异集中在一个词，是否真正读过对应词义辨析条目？
- 代回整句后，逻辑关系和话题方向是否保持一致？
