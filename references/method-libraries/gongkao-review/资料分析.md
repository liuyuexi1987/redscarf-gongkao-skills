# 资料分析综述校验

## 使用边界

本文件只做跨步骤防错。公式和专项速算以 `data-notes/` 公式卡、题型协议和已读取主卡为准。

## 计算闭环

1. **定位口径**：圈定时间、主体、指标、单位、累计/当期、部分/整体和同比/环比。
2. **选择公式**：根据问法判断现期、基期、增长率、增长量、比重、平均数、倍数或混合关系。
3. **速算判定**：结合问法精度、选项差距、数据量级和误差传播，决定估算、直除、反乘或精算。
4. **控制误差**：估算前判断误差方向；多步计算时关注误差叠加是否可能跨选项。
5. **结果验证**：检查方向、数量级和单位，必要时用选项反代或乘除互验。

## 高频反向检查

| 信号 | 应检查 | 易误用路径 |
|---|---|---|
| 题问基期 | 现期与增长率的时间方向是否一致 | 把现期数据直接当基期，或负增长仍按正增长直觉判断 |
| 增长率为负 | 分母、增减方向和基期/现期大小关系 | 看到“下降”就把所有结果都向下调整 |
| 求比重变化 | 分子增速与分母增速分别对应哪个指标 | 只看现期比重，或交换部分与整体增速 |
| 题干写“约为” | 选项差距是否容纳当前近似误差 | 把“约为”当成可以任意粗估 |
| 选项接近 | 近似误差是否会跨选项 | 沿用百化分或大幅凑整后强行选最近项 |
| 综合判断 | 哪个选项最容易核验，口径是否一致 | 固定按选项字母顺序或预设某个选项优先 |
| 图表/OCR | 数字、单位、年份、图例是否完整 | 用残缺数据补全题意后继续计算 |

## 结论前复核

- 结果方向是否符合增减关系和部分/整体关系？
- 数量级与原始数据是否相称，单位是否完成换算？
- 快算结果是否落在稳定区间，而非选项分界附近？
- 反乘、反除或选项代入能否回到题干条件？
